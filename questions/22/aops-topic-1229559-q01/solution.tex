Sort by residue modulo $6$. A number $11p+17q$ has residue $5p+5q\equiv-(p+q)\pmod6$, so in residue class $r$ the smallest representable number uses $p+q\equiv-r\pmod 6$ with $p+q$ as small as possible and all of it on $11$ (the smaller coin): class $5$: $11$; class $4$: $22$; class $3$: $33$; class $2$: $44$; class $1$: $55$; class $0$: $0$. (Using $17$ in place of $11$ only makes the number larger, and $p+q\ge6$ adds at least $66$.)

Once one number of a class is representable, so is every larger number of that class (add $6$s). Hence the largest non-representable number is the largest class minimum minus $6$: $55-6=\boxed{49}$.
