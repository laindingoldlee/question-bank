We need $2^{2000}\bmod100$. Euler's theorem cannot be used modulo $100$ directly, since $\gcd(2,100)\ne1$, so split $100=4\cdot25$.
\begin{itemize}
\item Modulo $4$: $2^{2000}\equiv0$.
\item Modulo $25$: $\gcd(2,25)=1$ and $\varphi(25)=20$, so $2^{20}\equiv1$ and $2^{2000}=\left(2^{20}\right)^{100}\equiv1$.
\end{itemize}
The number in $\{0,\dots,99\}$ that is $\equiv1\pmod{25}$ and $\equiv0\pmod4$ is among $1,26,51,76$; only $76$ is divisible by $4$. The last two digits are $\boxed{76}$.
