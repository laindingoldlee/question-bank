In the $xy$-plane, consider all circles of a fixed radius $r>0$ whose centres lie on the parabola $y=\dfrac{1}{2}x^2+\dfrac{7}{2}$. Let $m$ be the number of these circles that are tangent to the line $y=x+7$, and let $n$ be the number of these circles that are tangent to the line $y=x$. If $m$ is odd, find $m+n+r^2$.
