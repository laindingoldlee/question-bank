The five odd positions form a uniformly chosen set of size five. Each row must contain an odd count, forcing row counts $(3,1,1)$, and likewise for columns. Thus the odd positions form the union of one full row and one full column. Conversely every such union works. There are $9$ patterns, so the probability is $\boxed{\dfrac{9}{\binom95}=\dfrac{1}{14}}$.
