Factor:
\[
a^3-a^2b-ab^2+b^3=a^2(a-b)-b^2(a-b)=(a-b)(a^2-b^2)=(a+b)(a-b)^2 .
\]
So $(a-b)^2$ divides $72$. If $a-b=1$, then $a+b=72$; but $a+b$ and $a-b$ have the same parity, so this is impossible. If $a-b=2$, then $a+b=18$, giving $a=10$, $b=8$, and indeed $18\cdot4=72$. The minimum is $\boxed{2}$.
