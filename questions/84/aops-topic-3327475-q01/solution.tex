After deleting every second entry the start is $1,3,5,7,9,11,13,15,\ldots$. Deleting every third of these removes $5,11,17,\ldots$, leaving the start $1,3,7,9,13,15,19,21,\ldots$. Deleting every fourth remaining entry removes $9,21,\ldots$, leaving $1,3,7,13,\ldots$. Every later stage deletes positions numbered at least five, so it never changes these first four entries. The answer is $\boxed{13}$.
