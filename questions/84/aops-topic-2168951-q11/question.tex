A fair coin is flipped $10$ times. What is the probability that the number of tails is a factor of the number of heads? Assume that $0$ is not a factor of any number, but that $10$ is a factor of $0$.

$\textbf{(A) } \dfrac{317}{1024} \qquad \textbf{(B) } \dfrac{77}{256} \qquad \textbf{(C) } \dfrac{5}{16} \qquad \textbf{(D) } \dfrac{161}{512} \qquad \textbf{(E) } \dfrac{3}{8}$
