\textbf{(a)} Let the integers be $m,m+1,\dots,m+n-1$. Their remainders upon division by $n$ are all different: if two of them, $m+i$ and $m+j$ with $0\le i<j\le n-1$, had the same remainder, then $n$ would divide $j-i$, which lies strictly between $0$ and $n$. So the $n$ remainders are $0,1,\dots,n-1$ in some order, and exactly one of the integers is congruent to $k$. A block of $qn$ consecutive integers splits into $q$ blocks of $n$ consecutive integers, each containing exactly one such number.

\textbf{(b)} The three-digit integers $100,\dots,999$ are $900=15\cdot60$ consecutive integers, so by (a) exactly $\boxed{15}$ of them are congruent to $12$ modulo $60$ (namely $132,192,\dots,972$). This is why the "probability" estimate $\dfrac{900}{60}$ works here: $900$ is a multiple of $60$.

\textbf{(c)} Now $900=128\cdot7+4$. The first $896$ numbers $100,\dots,995$ contain exactly $128$ numbers of each residue modulo $7$. The remaining four numbers $996,997,998,999$ have residues $2,3,4,5$ (since $994=7\cdot142$). So there are $\boxed{129}$ three-digit numbers congruent to $2$ and $\boxed{128}$ congruent to $0$ modulo $7$. In general, a set of consecutive integers is split equally among the residues only when its size is a multiple of $n$; otherwise some residues get one more element than others, and $\dfrac{900}{7}\approx128.6$ is not even an integer.
