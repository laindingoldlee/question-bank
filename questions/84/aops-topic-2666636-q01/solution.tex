Clearly $(0,0,0)$ is a solution. Suppose there is another, and choose one with $|x|+|y|+|z|>0$ as small as possible.

Since $x^3=9z^3-3y^3$ is divisible by $3$, so is $x$; write $x=3x_1$. Then $27x_1^3+3y^3=9z^3$, i.e. $9x_1^3+y^3=3z^3$, so $3\mid y$; write $y=3y_1$. Then $9x_1^3+27y_1^3=3z^3$, i.e. $3x_1^3+9y_1^3=z^3$, so $3\mid z$; write $z=3z_1$. Dividing by $27$,
\[x_1^3+3y_1^3=9z_1^3.\]
So $(x_1,y_1,z_1)=\left(\dfrac x3,\dfrac y3,\dfrac z3\right)$ is a solution, not all zero, with $|x_1|+|y_1|+|z_1|=\dfrac13\left(|x|+|y|+|z|\right)$ smaller. This contradicts minimality.

Hence the only solution is $\boxed{(x,y,z)=(0,0,0)}$.
