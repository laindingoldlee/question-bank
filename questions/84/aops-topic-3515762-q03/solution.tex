Put $t=\log_9x$. Then $\log_3(x^3)=6t$, so $16t^4=36t^2+10$. With $u=t^2\ge0$, this is $8u^2-18u-5=0$, or $(4u+1)(2u-5)=0$. Only the nonnegative root is allowed: $\boxed{u=\dfrac{5}{2}}$.
