Divide first: $x^2-20=(x^2-4x)+(4x-20)$, so the expression is $1+\dfrac{4x-20}{x(x-4)}$. Write $\dfrac{4x-20}{x(x-4)}=\dfrac {A}{x}+\dfrac{B}{x-4}$, so $A(x-4)+Bx=4x-20$. Setting $x=0$ gives $A=5$, and $x=4$ gives $B=-1$. Hence
\[
\dfrac{x^2-20}{x^2-4x}=\boxed{1+\dfrac{5}{x}-\dfrac{1}{x-4}}.
\]
