The function $y=2^x$ takes every real $x$ to a positive number and is strictly increasing, so it is one-to-one onto $(0,\infty)$. To invert it, swap $x$ and $y$ and solve for $y$: $x=2^y$ means, by definition of the logarithm, $y=\log_2x$.

So the inverse is $\boxed{y=\log_2x}$, defined for $x>0$. Check: $2^{\log_2x}=x$ for $x>0$ and $\log_2\left(2^x\right)=x$ for all real $x$.
