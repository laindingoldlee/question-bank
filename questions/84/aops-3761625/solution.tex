For each $n$, set $A=3^{n^2+n-1}$ and $D=(3^n-3)(3^n+1)>0$. The exact integer part is $q = \lfloor \sqrt{\lfloor \dfrac{A^2}{D} \rfloor} \rfloor$, because $q^2 \le \dfrac{A^2}{D} < (q+1)^2$. The fractional-part condition is equivalent to $\dfrac{A}{\sqrt{D}} < q + \dfrac{1}{3}$, hence to the integer comparison $9A^2<D(3q+1)^2$. Applying this exact test for $n=2,\ldots,20$ yields $n=5,6,7,8,11,14,15,16,17,18,19,20$. Thus the count is $\boxed{12}$. The integer-square-root method avoids subtracting nearly equal large floating-point numbers.
