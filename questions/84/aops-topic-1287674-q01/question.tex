Twelve-sided dice are made by writing one of the integers $1,2,\dots,12$ on each of the $12$ faces; integers may be repeated, and enough copies of each integer are available. Two dice are considered the same if they give the same probability of rolling each of $1,2,\dots,12$, that is, if they use each integer the same number of times. How many distinct dice are there?
