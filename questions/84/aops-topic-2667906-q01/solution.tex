\textbf{(a)} The squares greater than $4$ are $3^2,4^2,5^2,\dots$ and those greater than $9$ are $4^2,5^2,6^2,\dots$. The map
\[n^2\longmapsto(n+1)^2\qquad(n\ge3)\]
sends $9\mapsto16$, $16\mapsto25$, and so on. It is one-to-one, and every square $m^2>9$ (so $m\ge4$) is the image of $(m-1)^2>4$. So it is a bijection.

\textbf{(b)} Two sets have the same size (cardinality) when there is a bijection between them, so by (a) the two sets are the same size. At the same time the second set is a proper subset of the first: it is the first set with the single element $9$ removed. For finite sets a proper subset is always smaller, but for infinite sets it need not be. Removing one element from an infinite set does not change its cardinality (``$\infty-1=\infty$''), which is the resolution of the apparent paradox.
