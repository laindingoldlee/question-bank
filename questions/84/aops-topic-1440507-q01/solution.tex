Write the edges as $m-d$, $m$, $m+d$ with integers $m>d\ge0$. Then
\[
\dfrac{832}{2}=(m-d)m+m(m+d)+(m-d)(m+d)=3m^2-d^2,
\]
so $3m^2-d^2=416$. Since $0\le d^2<m^2$, we get $3m^2\ge416$ and $2m^2<416$, so $m^2\ge139$ and $m^2<208$, i.e.\ $m\in\{12,13,14\}$:
\begin{itemize}
\item $m=12$: $d^2=432-416=16$, $d=4$;
\item $m=13$: $d^2=507-416=91$, not a square;
\item $m=14$: $d^2=588-416=172$, not a square.
\end{itemize}
So the edges are $8$, $12$, $16$ (check: $2(96+128+192)=832$).

\begin{asy}
usepackage("amsmath");
size(5cm);
defaultpen(fontsize(10pt));
real a=16,bb=12,c=8; pair d=(0.5,0.35)*bb;
pair O=(0,0);
draw(O--(a,0)--(a,c)--(0,c)--cycle,linewidth(0.9));
draw((0,c)--(0,c)+d--(a,c)+d--(a,c),linewidth(0.9)); draw((a,0)--(a,0)+d--(a,c)+d,linewidth(0.9));
draw(O--d,dashed); draw(d--d+(0,c),dashed); draw(d--(a,0)+d,dashed);
label("$16$",(a/2,0),S); label("$8$",(0,c/2),W); label("$12$",(a,0)+d/2,SE);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

The volume is $8\cdot12\cdot16=\boxed{1536}\text{ cm}^3$.
