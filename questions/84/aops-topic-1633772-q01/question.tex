How many $9$-digit integers use each of the digits $1,2,\dots,9$ exactly once and satisfy both of the following?
\begin{enumerate}
\item The first five digits are strictly decreasing (for example $96321$).
\item The last five digits are strictly increasing (for example $25789$).
\end{enumerate}
