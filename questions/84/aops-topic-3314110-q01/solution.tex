For the complement, never use both faces of any pair $\{1,6\},\{2,5\},\{3,4\}$. If exactly one face type occurs, there are 6 outcomes. If exactly two types occur from distinct pairs, choose their pairs and faces in $\binom32 2^2=12$ ways and use both types in $2^7-2$ sequences. If three types occur, choose one from each pair in 8 ways and use all types in $3^7-3\cdot2^7+3$ sequences. Thus the complement count is $6+12(126)+8(1806)=15966$. The desired probability is $1-\dfrac{15966}{6^7}\approx\boxed{0.943}$. Simply using $8\cdot3^7$ overcounts outcomes omitting one or two of the chosen face types.
