Squaring doubles the exponent, so $a_n=10^{2^n}$ for every $n\ge0$ (by induction: $a_0=10^1$ and $\left(10^{2^n}\right)^2=10^{2^{n+1}}$). Hence
\[a_1a_2\cdots a_n=10^{2+4+\cdots+2^n}=10^{2^{n+1}-2},\]
which has $2^{n+1}-1$ digits. We need $2^{n+1}-1\ge100$, that is, $2^{n+1}\ge101$. Since $2^6=64<101\le128=2^7$, the smallest choice is $n+1=7$, so $n=\boxed{6}$ (with $127$ digits; for $n=5$ there are only $63$).
