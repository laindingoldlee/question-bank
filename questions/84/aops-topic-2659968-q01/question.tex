Ten letters $A,B,C,D,E,F,G,H,I,J$ stand for the ten digits $0,1,\dots,9$, each digit used exactly once. Five four-digit PINs are formed (a PIN may begin with $0$):
\[\overline{5ABC},\qquad\overline{BDEF},\qquad\overline{FGH4},\qquad\overline{H0J7},\qquad\overline{I29J},\]
where, for example, $\overline{H0J7}$ has digits $H,0,J,7$ in that order. The digits of each PIN add up to $18$. Find the largest possible value of
\[M=\overline{5ABC}+\overline{BDEF}+\overline{FGH4}+\overline{H0J7}+\overline{I29J}.\]
