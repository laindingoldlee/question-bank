If the base $b=\cos2x$ is zero, the right side is undefined. If $b=1$, both sides equal 1, giving $x=0,\pi$. For $0<|b|<1$, taking absolute values forces the exponent to be $-1$. This is equivalent to $2\cos3x+4\cos x=0$, or $2\cos x(4\cos^2x-1)=0$. On $[0,\pi]$, the resulting values are $x = \dfrac{\pi}{3} , \dfrac{\pi}{2} , \dfrac{2 \pi}{3}$. The middle value has base $-1$ and also exponent $-1$, so it is valid; more generally it is the only possible point with base $-1$. Direct substitution verifies all five values. Thus there are $\boxed5$ solutions under the convention that negative bases are allowed when the exponent is an integer.
