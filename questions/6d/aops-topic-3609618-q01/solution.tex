Write the original counts as $4k,9k$. Then $16(4k-2)=7(9k-4)$, so $64k-32=63k-28$, giving $k=4$. The remaining counts are $16-2=\boxed{14\text{ tables}}$ and $36-4=\boxed{32\text{ chairs}}$.
