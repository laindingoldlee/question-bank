The number of friend requests an AoPS user receives in second $t$ is
\[f(t)=\dfrac{t^4-10t^3+35t^2-50t+24}{t^2-7t+12}\]
for every positive integer $t$ for which this expression is defined. An integer $t$ is chosen uniformly at random from those integers $1,2,\dots,7$ for which $f(t)$ is defined. What is the probability that $f(t)$ is a multiple of $4$?
