Let $q=1-p$. Getting $5$ tails is the same as getting $2$ heads, so
\[\dbinom74p^4q^3=\dbinom72p^2q^5\iff35p^2=21q^2\]
(dividing by $p^2q^3>0$). So $\dfrac{p^2}{q^2}=\dfrac35$, and since $p,q>0$,
\[\dfrac pq=\sqrt{\dfrac35},\qquad p=\dfrac{\sqrt3}{\sqrt3+\sqrt5}=\dfrac{\sqrt3\left(\sqrt5-\sqrt3\right)}{5-3}=\boxed{\dfrac{\sqrt{15}-3}{2}}.\]
(Numerically $p\approx0.436$.)
