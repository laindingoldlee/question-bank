We have $a=k(b+c)$, $b=k(c+a)$, $c=k(a+b)$. Adding, $a+b+c=2k(a+b+c)$.
\begin{itemize}
\item If $a+b+c\ne0$, then $k=\dfrac{1}{2}$ (for example $a=b=c=1$).
\item If $a+b+c=0$, then $b+c=-a$ and $k=\dfrac{a}{-a}=-1$ (for example $a=b=1$, $c=-2$: $\dfrac{1}{-1}=\dfrac{1}{-1}=\dfrac{-2}{2}=-1$).
\end{itemize}
So there are exactly $2$ possible values, $\dfrac{1}{2}$ and $-1$: $\boxed{\text{(B) } 2}$.
