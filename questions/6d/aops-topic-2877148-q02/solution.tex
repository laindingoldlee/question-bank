Write $u=f(x)=\log_3(x-1)$, which needs $x>1$. Then $g(u)$ needs $u\ne1$ and $\dfrac{u}{u-1}\ge0$, i.e. $u\le0$ or $u>1$.
\begin{itemize}
\item $u\le0$ means $0<x-1\le1$, i.e. $1<x\le2$.
\item $u>1$ means $x-1>3$, i.e. $x>4$.
\end{itemize}
So the domain is $\boxed{(1,2]\cup(4,\infty)}$.

For the range: as $u$ runs over $(-\infty,0]$, $\dfrac{u}{u-1}=1-\dfrac{1}{1-u}$ takes every value in $[0,1)$. As $u$ runs over $(1,\infty)$, $\dfrac{u}{u-1}=1+\dfrac1{u-1}$ takes every value in $(1,\infty)$. Taking square roots, the range is $\boxed{[0,1)\cup(1,\infty)}$.
