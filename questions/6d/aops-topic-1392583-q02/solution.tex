Check $r=1,2,\dots$ in turn, reducing modulo $1000$:
\[
1^1=1,\quad 2^2=4,\quad 3^3=27,\quad 4^4=256,\quad 5^5=3125\equiv125,\quad 6^6=46656\equiv656,\quad 7^7=823543\equiv543,
\]
and
\[
8^8=2^{24}=16777216\equiv216\pmod{1000}.
\]
So the smallest rich number is $\boxed{8}$.
