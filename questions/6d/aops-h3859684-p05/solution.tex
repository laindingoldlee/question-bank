The condition is $n(n-1)\equiv0\pmod{1000}$. As consecutive integers are coprime and $1000=8\cdot125$, each of $8,125$ must divide one of $n,n-1$. The four residue classes modulo $1000$ are $0,1,376,625$ (direct substitution verifies the two mixed cases). The three-digit suffix must start with a nonzero digit, leaving $376,625$. The first five values are $376,625,1376,1625,2376$, so the answer is $\boxed{2376}$.
