Lighting a string at both ends halves the remaining time, whatever the unevenness, because the two flames together consume the remaining time at double rate.

Use three strings of brand $X$ (brand $Y$ is not needed).
\begin{itemize}
\item At time $0$, light string $1$ at both ends and string $2$ at one end.
\item At $30$ minutes string $1$ burns out. String $2$ has $30$ minutes of burning left: light its other end. At the same moment light string $3$ at one end.
\item At $45$ minutes string $2$ burns out. String $3$ has $45$ minutes left: light its other end, and \textbf{start the sprinklers now}.
\item String $3$ burns out $\dfrac{45}{2}=22.5$ minutes later: \textbf{turn the sprinklers off}.
\end{itemize}
This measures exactly $22$ minutes $30$ seconds.
