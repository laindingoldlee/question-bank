When $k$ boxes are shaded, each turn shades a new box with probability $\dfrac{10-k}{10}$, so the expected wait for the next new box is $\dfrac{10}{10-k}$. Adding over $k=0,\dots,9$:
\[10\left(1+\dfrac{1}{2}+\dfrac{1}{3}+\cdots+\dfrac{1}{10}\right)=\boxed{\dfrac{7381}{252}}\approx29.29.\]
