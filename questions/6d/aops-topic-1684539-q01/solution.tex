Since $73$ is odd, exactly one of $pq$ and $r$ is even.

If $r$ is even, then $r=2$ and $pq=71$, which is impossible because $71$ is prime. So $pq$ is even, and one of $p,q$ is $2$; say $p=2$. Then $r=73-2q$ and
\[
p+q+r=2+q+73-2q=75-q,
\]
so we want the largest prime $q$ for which $73-2q$ is also a prime. We need $73-2q\ge2$, so $q\le35$. Trying $q=31$: $r=11$, a prime. ($q=33,35$ are not prime.) So the least value is $75-31=\boxed{44}$, attained by $2\cdot31+11=73$.
