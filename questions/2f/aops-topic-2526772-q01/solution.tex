Check each choice using the principal values of the inverse functions.
\begin{itemize}
\item \textbf{(A)}: $2\theta=\sin^{-1}0.75$, so $\sin(2\theta)=0.75$. This works.
\item \textbf{(B)}: $2\theta=\cos^{-1}0.8\in[0,\pi]$, so $\sin(2\theta)=\sqrt{1-0.64}=0.6$.
\item \textbf{(C)}: $\sin(2\theta)=0.8$.
\item \textbf{(D)}: $\sec(2\theta)=1.25$ means $\cos(2\theta)=0.8$ with $2\theta=\cos^{-1}0.8$, so again $\sin(2\theta)=0.6$.
\end{itemize}
