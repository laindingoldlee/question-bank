Ten different digits means that each of the digits $0,1,\dots,9$ is used exactly once. The tens digits are five different nonzero digits, so $0$ is a units digit.

\textbf{Greatest range.} The largest number is at most $98$ and the smallest at least $10$, so the range is at most $88$. This is attained, for example, by $98,76,54,32,10$.

\textbf{Least range.} Let the tens digits be $t_1>t_2>\dots>t_5$, and let $u$ and $v$ be the units digits of the largest and the smallest number. The range is
\[
10(t_1-t_5)+(u-v)\ge10(t_1-t_5)-9 .
\]
Five different digits satisfy $t_1-t_5\ge4$. If $t_1-t_5\ge5$, the range is at least $50-9=41$. If $t_1-t_5=4$, the range is $40+u-v\ge40-9=31$, with equality only if $u=0$ and $v=9$. This is attained: $50,48,37,26,19$ (tens digits $5,4,3,2,1$, all ten digits used once) has range $50-19=31$. So the least range is $31$.

The difference is $88-31=\boxed{57}$.
