Using $1+2+\cdots+n=\dfrac{n(n+1)}{2}$:
\[
x=\dfrac{\dfrac{1000\cdot1001}{2}}{\dfrac{100\cdot101}{2}}=\dfrac{1000\cdot1001}{100\cdot101}=\dfrac{10\cdot1001}{101}=\boxed{\dfrac{10010}{101}}\approx99.1 .
\]
(It is tempting to guess $x=100$, but the ratio is $\dfrac{500500}{5050}$, which is not an integer.)
