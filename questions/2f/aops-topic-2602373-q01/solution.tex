Let $X$ be a set with $n$ elements. $\dbinom nk$ is the number of $k$-element subsets of $X$, so the left side counts the nonempty subsets of $X$.

On the other hand, a subset is chosen by deciding for each of the $n$ elements whether it is in or out, which gives $2^n$ subsets. Removing the empty set leaves $2^n-1$ nonempty subsets. So both sides count the same thing and are equal. $\blacksquare$

This also explains the pattern $1,3,7,15,\dots$ noticed in the list: adding a new element doubles the number of subsets, so if $a_n=2^n-1$ then $a_{n+1}=2a_n+1=a_n+2^n$.
