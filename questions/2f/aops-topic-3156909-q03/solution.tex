An 11-bit palindrome is determined by its first six bits. The prefix of 2015 is 111110; the preceding possible prefix is 111101, which reflects to 11110101111. Its decimal value is $ 1024+512+256+128+32+8+4+2+1=\boxed{1967}$. Smaller prefixes give smaller numbers, and every number with fewer bits is smaller still.
