If $A,B$ were known positive proportions, the prescribed value would be $\lfloor\dfrac{1}{A^2B^2}\rfloor$. Their values depend on actual contestant results, which are not supplied. For instance $A=B=1$ gives 1, while $A=B=\dfrac{1}{2}$ gives 16. If either proportion is zero, the displayed expression is undefined. Thus no unique numerical estimate can be deduced from the statement alone.
