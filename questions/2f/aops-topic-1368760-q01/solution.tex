Pair the outer and the inner factors:
\[(a+1)(a+4)=a^2+5a+4,\qquad (a+2)(a+3)=a^2+5a+6 .\]
Put $t=a^2+5a+5$, the number halfway between them. Then the product is $(t-1)(t+1)=t^2-1$, so
\[(a+1)(a+2)(a+3)(a+4)-120=t^2-121=(t-11)(t+11)=(a^2+5a-6)(a^2+5a+16).\]
The first factor splits as $(a-1)(a+6)$. The second has discriminant $25-64<0$, so it does not factor further. Hence
\[(a+1)(a+2)(a+3)(a+4)-120=\boxed{(a-1)(a+6)(a^2+5a+16)} .\]

(With $+120$, as in the post, the same substitution gives $t^2+119$, which has no factorization over the integers; the intended problem is the classic one with $-120$.)
