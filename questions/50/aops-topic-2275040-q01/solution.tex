A number is a sum of distinct powers of $3$ exactly when its base-$3$ representation uses only the digits $0$ and $1$ (base-$3$ representations are unique).

Reading such a digit string in base $2$ instead gives a bijection between the list and the positive integers, and it preserves order: for strings of $0$s and $1$s, comparing them as base-$3$ numbers or as base-$2$ numbers gives the same result (a longer string is larger, and strings of the same length are compared at the first differing digit). So the $k$th number in the list is obtained by writing $k$ in base $2$ and reading the digits in base $3$. (Check: $k=1,2,3,4$ give $1_3=1$, $10_3=3$, $11_3=4$, $100_3=9$.)

Now $500=256+128+64+32+16+4=111110100_2$, so the $500$th number is
\[111110100_3=3^8+3^7+3^6+3^5+3^4+3^2=6561+2187+729+243+81+9=\boxed{9810}.\]
