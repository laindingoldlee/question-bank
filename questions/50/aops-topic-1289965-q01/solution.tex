Write each die as $1+y_i$ with $0\le y_i\le5$. We need $y_1+y_2+y_3+y_4=10$.

Without the upper limit there are $\dbinom{13}{3}=286$ solutions. If $y_1\ge6$, put $y_1=6+y_1'$; then the sum of the four is $4$, with $\dbinom73=35$ solutions, and the same holds for each of the $4$ dice. Two variables cannot both be at least $6$, since $12>10$. By inclusion-exclusion the count is
\[
286-4\cdot35=\boxed{146}.
\]
