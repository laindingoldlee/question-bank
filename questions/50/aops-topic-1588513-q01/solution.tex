\textbf{Each step has two choices.} From every letter there are exactly two closest letters in the row beneath it (down-left and down-right), and every path from G to the bottom row spells G, R, E, A, T in order. A path is therefore determined by $4$ independent left/right choices, so there are
\[
2^4=\boxed{16}
\]
paths.

\textbf{Check with Pascal's triangle.} Writing at each letter the number of paths reaching it gives the rows $1$; $1,1$; $1,2,1$; $1,3,3,1$; $1,4,6,4,1$, and $1+4+6+4+1=16$.
