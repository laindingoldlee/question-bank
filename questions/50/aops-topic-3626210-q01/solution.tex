Start with $N=4^{3^{2^1}}=4^9>2$, which uses all four numbers once. Form $N,N!,N!!,\ldots$, where repeated exclamation marks here mean iterated factorials, not double-factorial notation. For every integer $m>2$, $m!>m$. Thus this sequence is strictly increasing and supplies infinitely many distinct integers.
