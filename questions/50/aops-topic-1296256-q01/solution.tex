Pick a point $(x_0,y_0)$ on the first line, so $Ax_0+By_0=-C_1$. The distance between the lines is the distance from this point to the second line, which by the point-to-line formula is
\[
d=\dfrac{\left|Ax_0+By_0+C_2\right|}{\sqrt{A^2+B^2}}=\boxed{\dfrac{|C_2-C_1|}{\sqrt{A^2+B^2}}}.
\]

\begin{asy}
usepackage("amsmath");
size(5cm);
defaultpen(fontsize(10pt));
draw((-1,0)--(5,3),blue); draw((-1,-2)--(5,1),blue); pair P=(1,1); pair Q=P+(1,-2)*0.8; draw(P--Q,red+dashed); dot(P); dot(Q);
label("$Ax+By+C_1=0$",(5,3),E,blue); label("$Ax+By+C_2=0$",(5,1),E,blue); label("$d$",(P+Q)/2,E,red);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

It does not depend on the chosen point, as expected for parallel lines. (Both equations must use the same $A$ and $B$; e.g. rewrite $2x+4y=1$ as $x+2y-\dfrac{1}{2}=0$ before comparing with $x+2y+3=0$.)
