Multiplying both sides by an expression that contains the variable is allowed only where that expression is nonzero; where it is zero, the new equation can have solutions that the original does not (extraneous solutions). Here $x-3=0$ at $x=3$, and $x=3$ is not in the domain of the original equation, because it makes both denominators zero.

So for $x\ne3$, the equation is equivalent to $x^2=9$, giving $x=\pm3$, and we must reject $x=3$. The only solution is $\boxed{x=-3}$. Check: $\dfrac{9}{-6}=\dfrac{9}{-6}$.

(Rule of thumb: when you clear denominators, state the excluded values first and check every answer in the original equation.)
