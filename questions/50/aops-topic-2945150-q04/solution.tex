Put $u=x\sin x>0$. The expression is $9u+\dfrac{4}{u}\ge2\sqrt{36}=12$ by AM–GM, with equality when $u=\dfrac{2}{3}$. This value occurs: $x\sin x$ is continuous, tends to 0 as $x\to0^+$, and equals $\dfrac{\pi}{2}>\dfrac{2}{3}$ at $x=\dfrac{\pi}{2}$. The intermediate value theorem supplies an admissible equality point. Therefore the minimum is $\boxed{12}$.
