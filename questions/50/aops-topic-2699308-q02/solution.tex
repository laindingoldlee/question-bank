Write $a=\rho\left(\cos\theta+i\sin\theta\right)$ with $\rho>0$. By De Moivre's theorem, $z=r\left(\cos\varphi+i\sin\varphi\right)$ satisfies $z^n=a$ exactly when $r^n=\rho$ and $n\varphi=\theta+2k\pi$ for an integer $k$. So $r=\sqrt[n]\rho$ and $\varphi=\dfrac{\theta+2k\pi}{n}$. The values $k=0,1,\dots,n-1$ give $n$ different angles mod $2\pi$, and any other $k$ repeats one of them. So there are exactly $n$ roots. $\blacksquare$ ($a=0$ is excluded: its only root is $0$.)
