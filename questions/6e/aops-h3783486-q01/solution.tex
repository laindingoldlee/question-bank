Write $M+1213=v^2$, $M+3773=u^2$ with $u>v\ge0$. Then $(u-v)(u+v)=2560$. The factors have the same parity and must both be even. Set $d=u-v$; then $v=\dfrac{\dfrac{2560}{d}-d}{2}$, which decreases as positive $d$ increases. The smallest possible $d$ is $2$, yielding $u+v=1280$ and $v=639$. Thus $M=639^2-1213=407108$, whose units digit is $\boxed{8}$, choice E.
