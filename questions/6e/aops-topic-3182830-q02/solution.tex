The equation is $17a+13b=300$, with $a,b\ge0$. Modulo $13$ it gives $4a\equiv1$, so $a\equiv10\pmod{13}$. Since $0\le a\le17$, we must have $a=10$, which gives $b=10$. Thus there is $\boxed1$ ordered pair.
