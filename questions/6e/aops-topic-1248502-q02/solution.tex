Write $x=\overline{tu}$ and $y=\overline{t'u'}$ as two-digit strings (a leading $0$ allowed). Since $x+y=99$ and no column can produce a carry, $u+u'=9$ and $t+t'=9$. The digits actually written are $u$, $9-u$ and the nonzero leading digits.
\begin{itemize}
\item $1\le t\le8$: both numbers have two written digits, using $\{t,9-t,u,9-u\}$; this has only two elements exactly when $u=t$ or $u=9-t$: $2$ choices of $u$ for each of $8$ values of $t$, giving $16$ pairs.
\item $t=9$: $x=\overline{9u}$ and $y=9-u$, using $\{9,u,9-u\}$; we need $u\in\{0,9\}$: $(90,9)$ and $(99,0)$.
\item $t=0$: $x=u$ and $y=\overline{9(9-u)}$, using $\{u,9,9-u\}$; again $u\in\{0,9\}$: $(0,99)$ and $(9,90)$.
\end{itemize}
In total $16+2+2=\boxed{20}$ ordered pairs.
