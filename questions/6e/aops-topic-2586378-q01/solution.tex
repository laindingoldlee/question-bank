Subtracting $10x$ from both sides of the first equation gives $5=12$, which is false for every $x$: the first equation has no solutions. The second becomes $6=6$, which is true for every $x$: every real number is a solution, so there are infinitely many. Answer: $\boxed{\text{no solutions; every real }x\text{ is a solution}}$.
