Raise both to the $90$th power: compare $9^{10}$ with $10^9$. Since $\left(\dfrac{10}9\right)^9=\left(1+\dfrac19\right)^9<e<9$, we get $10^9<9\cdot9^9=9^{10}$. So $\boxed{\sqrt[9]9}$ is larger.
