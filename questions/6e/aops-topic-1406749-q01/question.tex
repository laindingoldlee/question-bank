You have two coins of each of the values $1,2,4,8,16,32$ and $64$ cents. In how many ways can you choose some of these coins with a total value of $50$ cents? (Coins of the same value are identical, so a way is determined by how many coins of each value, $0$, $1$ or $2$, you use.)
