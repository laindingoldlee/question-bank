How many sequences $a_1,a_2,\dots,a_{15}$ satisfy $a_i\in\{2,3\}$ for all $1\le i\le15$ and have the property that
\[\sum_{j=1}^{k}a_j\]
is divisible by $5$ if and only if $k=15$?

$\textbf{(A)}\ 144 \qquad\textbf{(B)}\ 178 \qquad\textbf{(C)}\ 233 \qquad\textbf{(D)}\ 288 \qquad\textbf{(E)}\ 466$
