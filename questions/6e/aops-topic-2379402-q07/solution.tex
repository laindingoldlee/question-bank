Going from $(-9,6)$ to $(-3,9)$, the run is $-3-(-9)=6$ and the rise is $9-6=3$:

\begin{asy}
usepackage("amsmath");
size(4.5cm);
defaultpen(fontsize(10pt));
import graph;
draw((-10.5,0)--(1,0),Arrow(5)); draw((0,-0.5)--(0,10.5),Arrow(5));
label("$x$",(1,0),E); label("$y$",(0,10.5),N);
pair P=(-9,6), Q=(-3,9);
draw((-10.5,5.25)--(-1,10),blue);
draw(P--(-3,6)--Q,red+dashed); label("$6$",(-6,6),S,red); label("$3$",(-3,7.5),E,red);
dot(P); dot(Q); label("$(-9,6)$",P,NW); label("$(-3,9)$",Q,NW);
\end{asy}

so the slope is $\dfrac{3}{6}=\boxed{\dfrac12}$.
