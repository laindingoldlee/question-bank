Decide each element separately. An element of $\{1,\dots,5\}$ can be in $A$ only, $B$ only, both, or neither: $2$ choices put it in $A\,\Delta\,B$ and $2$ keep it out. An element of $\{6,\dots,10\}$ is in $A\,\Delta\,B$ exactly when it is in $B$: $1$ choice each way. If $j$ of the elements $1$ to $5$ and $3-j$ of the elements $6$ to $10$ are in the symmetric difference, the count is
\[\sum_{j}\binom5j2^j\cdot2^{5-j}\cdot\binom5{3-j}=2^5\sum_j\binom5j\binom5{3-j}=32\binom{10}{3}=\boxed{3840},\]
using Vandermonde's identity.
