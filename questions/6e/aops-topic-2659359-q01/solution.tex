Compute successive powers modulo $23$:
\[6^1\equiv6,\quad6^2=36\equiv13,\quad6^3\equiv78\equiv9,\quad6^4\equiv54\equiv8,\quad6^5\equiv48\equiv2,\quad6^6\equiv12,\quad6^7\equiv72\equiv3.\]
So the smallest such $n$ is $\boxed{7}$.
