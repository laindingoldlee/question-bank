Write $N=3\cdot10^{n-1}+x$, where $0\le x<10^{n-1}$ is the number formed by the other $n-1$ digits. Then $M=10x+3$.

\textbf{(a)} If $M=3N$, then $10x+3=9\cdot10^{n-1}+3x$, so
\[7x=9\cdot10^{n-1}-3 .\]
For $n=1$ this gives $7x=6$, impossible. For $n\ge2$ we have $2\cdot10^{n-1}>3$, so $7x>7\cdot10^{n-1}$ and $x>10^{n-1}$, contradicting $x<10^{n-1}$. So $M=3N$ never happens. (Informally: $3N$ starts with $9$ or has $n+1$ digits, but $M$ has at most $n$ digits and starts with the second digit of $N$.)

\textbf{(b)} Now $3(10x+3)=3\cdot10^{n-1}+x$, so
\[29x=3\cdot10^{n-1}-9=3\left(10^{n-1}-3\right).\]
Conversely, if $29$ divides $10^{n-1}-3$, then $x=\dfrac{3\cdot10^{n-1}-9}{29}$ is an integer with $0<x<10^{n-1}$, and $N=3\cdot10^{n-1}+x$ works. So we need the least $n$ with
\[10^{n-1}\equiv3\pmod{29}.\]
Since $3\cdot10=30\equiv1\pmod{29}$, the number $3$ is the inverse of $10$ modulo $29$, and the condition is equivalent to $10^{n}\equiv1\pmod{29}$. So $n$ must be a multiple of the order of $10$ modulo $29$. That order divides $28$, and
\begin{align*}
10^2&=100\equiv13, & 10^4&\equiv13^2=169\equiv24,\\
10^7&=10^4\cdot10^2\cdot10\equiv24\cdot130\equiv24\cdot14=336\equiv17, & 10^{14}&\equiv17^2=289\equiv-1\pmod{29}.
\end{align*}
So $10^d\not\equiv1$ for the divisors $d=1,2,4,7,14$ of $28$, the order is $28$, and the least $n$ is $\boxed{28}$.

The number itself is
\[N=3103448275862068965517241379,\qquad M=1034482758620689655172413793,\]
and indeed $3M=N$.

\emph{Remark.} The familiar puzzle of this kind has leftmost digit $1$: moving it to the end of $142857$ gives $428571=3\cdot142857$.
