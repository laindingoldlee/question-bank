$\dfrac{m-1}{m^2}=\dfrac1m-\dfrac1{m^2}$, so the sum is $(H_x-1)-(H^{(2)}_x-1)=\boxed{H_x-H^{(2)}_x}$. As $x\to\infty$, $H^{(2)}_x$ converges (to $\dfrac{\pi^2}6$) while $H_x\to\infty$, so the infinite series diverges.
