The solutions are $x=3\pm\sqrt{9+4n^2+32}=3\pm\sqrt{4n^2+41}$, so we need $4n^2+41=m^2$ for an integer $m\ge0$. Then $(m-2n)(m+2n)=41$, which is prime, so $m-2n=1$ and $m+2n=41$: $m=21$, $n=10$. This gives $x=24$ or $x=-18$. So there is exactly $\boxed{1}$ value, $n=10$.
