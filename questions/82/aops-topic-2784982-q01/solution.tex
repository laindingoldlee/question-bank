Write $f(x)=-2\left(\dfrac15\right)^x$.

(a) If $x_1<x_2$, then $5^{-x_1}>5^{-x_2}>0$, and multiplying by $-2$ reverses the inequality: $f(x_1)<f(x_2)$. So $f$ is \textbf{increasing}.

(b) As $x\to\infty$, $5^{-x}\to0$, so $f(x)\to0$ from below ($f$ is always negative); the line $y=0$ is a horizontal asymptote. As $x\to-\infty$, $5^{-x}\to\infty$, so $f(x)\to-\infty$.

(c) Here $a=-2$ and $b=\dfrac15<1$. The size $|f(x)|=2\left(\dfrac15\right)^x$ shrinks by a factor of $5$ for each unit increase of $x$: this is \textbf{exponential decay}, and the graph is the decay curve $y=2\left(\dfrac15\right)^x$ reflected in the $x$-axis. The student is right in this standard sense, which depends on the base $b$. The teacher is right that the values of $f$ increase (towards $0$), but ``increasing'' is not the same as exponential growth, which would need $b>1$.
