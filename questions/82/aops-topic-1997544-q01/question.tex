The factorial can be extended to non-integers by the gamma function, which satisfies $x!=x\cdot(x-1)!$ for all $x>0$ and $\left(\dfrac{1}{2}\right)!=\dfrac{\sqrt\pi}{2}$. Using these facts, compute $1.5!$ and $2.5!$.
