(a) $y^2=x-12$, so $\boxed{y=\pm\sqrt{x-12}}$ (for $x\ge12$).

(b) $|-4|-|-5|+6=4-5+6=5$, so $x=y+5$ and $\boxed{y=x-5}$.

(c) $\dfrac{2}{5}\cdot\dfrac{1}{2}y=\dfrac {y}{5}=\dfrac{1}{100}$, so $\boxed{y=\dfrac{1}{20}}$.
