Rewrite the equation as
\[x^3-y^3=2x(7x-y).\tag{1}\]
\textbf{Case $y\ge x$.} The left side of (1) is $\le0$, so $7x-y\le0$, i.e.\ $y\ge7x\ge7$. Then
\[y^3-x^3\ge y^3-\dfrac{y^3}{343}>y^2,\qquad\text{while}\qquad 2x(y-7x)<2xy\le\dfrac{2y^2}{7},\]
so (1) cannot hold. Hence $y<x$.

\textbf{Case $y<x$.} Put $d=x-y\ge1$, so $y=x-d$. Then $x^3-y^3=3x^2d-3xd^2+d^3$ and $14x^2-2xy=12x^2+2xd$, and (1) becomes
\[(3d-12)x^2-(3d^2+2d)x+d^3=0.\tag{2}\]
\begin{itemize}
\item $d\le3$: (2) says $(12-3d)x^2+(3d^2+2d)x=d^3$, but for $x\ge1$ the left side is at least $3d^2-d+12$, which exceeds $d^3$ for $d=1,2,3$ ($14>1$, $22>8$, $36>27$).
\item $d=4$: (2) becomes $-56x+64=0$, with no integer solution.
\item $d\ge5$: (2) is a quadratic in $x$ with discriminant
\[(3d^2+2d)^2-4(3d-12)d^3=d^2\left(60d+4-3d^2\right).\]
For an integer root, $r^2=60d+4-3d^2$ must be a perfect square, and it must be nonnegative, so $d\le20$. Checking $d=5,\dots,20$, the values of $60d+4-3d^2$ are $229,256,277,292,301,304,301,292,277,256,229,196,157,112,61,4$; the squares occur at $d=6\ (16^2)$, $d=14\ (16^2)$, $d=16\ (14^2)$, and $d=20\ (2^2)$. The roots $x=\dfrac{3d^2+2d\pm dr}{6d-24}$ are:
\begin{itemize}
\item $d=6$: $x=\dfrac{120\pm96}{12}$, so $x=18$ (then $y=12$) or $x=2$ (then $y=-4<0$).
\item $d=14$: $x=\dfrac{616\pm224}{60}$, so $x=14$ (then $y=0$, not positive), or a non-integer.
\item $d=16$: $x=\dfrac{800\pm224}{72}$, so $x=8$ (then $y=-8$), or a non-integer.
\item $d=20$: $x=\dfrac{1240\pm40}{96}$, so $x=\dfrac{40}{3}$ or $x=\dfrac{25}{2}$, neither an integer.
\end{itemize}
\end{itemize}
The only solution is $\boxed{(x,y)=(18,12)}$. Check: $18^3-14\cdot18^2+2\cdot18\cdot12-12^3=5832-4536+432-1728=0$.
