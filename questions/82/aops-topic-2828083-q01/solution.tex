A runner reaches second only on a double, and is still there at the next double only if that double comes in the same inning. So no run scores exactly when the $5$ hits fall in $5$ different innings:
\[P=\dfrac{9\cdot8\cdot7\cdot6\cdot5}{9^5}=\dfrac{15120}{59049}=\boxed{\dfrac{560}{2187}}\approx0.256.\]
