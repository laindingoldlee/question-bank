We need the inverse of $11$ modulo $19$. Since $19=11+8$, $11=8+3$, $8=2\cdot3+2$, $3=2+1$, back-substitution gives
\[1=3-2=3-(8-2\cdot3)=3\cdot3-8=3(11-8)-8=3\cdot11-4\cdot8=3\cdot11-4(19-11)=7\cdot11-4\cdot19 .\]
So $11\cdot7\equiv1\pmod{19}$; indeed $77=4\cdot19+1$. Because $\gcd(11,19)=1$, the inverse is unique modulo $19$, so
\[\boxed{y\equiv7\pmod{19}},\]
that is, $y=7+19k$ for integers $k$.
