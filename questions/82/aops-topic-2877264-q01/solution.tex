The objection assumes that $-x$ is negative. But $-x$ is the \emph{opposite} of $x$, and when $x<0$ it is positive. For example, if $x=-7$ then $-x=7$. So the definition always outputs a nonnegative number: $x$ itself when $x\ge0$, and the positive number $-x$ when $x<0$.

Since $-7<0$, $|-7|=-(-7)=\boxed{7}$. Since $\pi>3$, $3-\pi<0$, so $|3-\pi|=-(3-\pi)=\boxed{\pi-3}$.
