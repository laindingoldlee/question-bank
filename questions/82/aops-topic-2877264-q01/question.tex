The absolute value is defined by $|x|=x$ if $x\ge0$ and $|x|=-x$ if $x<0$. A student objects: ``$|x|$ is never negative, so it can never equal $-x$.'' Explain the error in this objection. Then use the definition to evaluate $|-7|$ and $|3-\pi|$.
