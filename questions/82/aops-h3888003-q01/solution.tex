Set $t=\dfrac{(x^2+y^2)}{(x^2-y^2)}$. The identity
\[
\dfrac{x^4+y^4}{x^4-y^4}=\dfrac{1}{2}\left(t+\dfrac{1}{t}\right)=\dfrac{k}{2}
\]
then gives, by applying the same identity again,
\[
u=\dfrac{x^8+y^8}{x^8-y^8}=\dfrac{1}{2}\left(\dfrac{k}{2}+\dfrac{2}{k}\right)=\dfrac{k^2+4}{4k}.
\]
Thus the answer is
\[
u+\dfrac{1}{u}=\boxed{\dfrac{k^4+24k^2+16}{4k(k^2+4)}}.
\]
Here $|k|\ge2$, so the displayed denominators are nonzero.
