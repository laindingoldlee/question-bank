Let $f(x)=\dfrac{ax+b}{cx+d}$, where $c\ne0$ and $ad-bc\ne0$.
\begin{enumerate}
\item[(a)] Prove that $f(f(x))=x$ for every $x$ for which both sides are defined if and only if $a+d=0$.
\item[(b)] Deduce that $f(x)=\dfrac{4x-5}{x-4}$ is its own inverse, and check this directly for $x=0$.
\end{enumerate}
