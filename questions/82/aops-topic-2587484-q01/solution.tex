\textbf{(a)} For $x\ne-\dfrac dc$,
\[f(f(x))=\dfrac{a\dfrac{ax+b}{cx+d}+b}{c\dfrac{ax+b}{cx+d}+d}=\dfrac{\left(a^2+bc\right)x+b(a+d)}{c(a+d)x+\left(bc+d^2\right)}.\]
If $f(f(x))=x$ for all (infinitely many) admissible $x$, then $c(a+d)x^2+\left(bc+d^2\right)x=\left(a^2+bc\right)x+b(a+d)$ holds for infinitely many $x$, hence as a polynomial identity. The $x^2$-coefficient gives $c(a+d)=0$, so $a+d=0$ because $c\ne0$.

Conversely, if $d=-a$, then
\[f(f(x))=\dfrac{\left(a^2+bc\right)x}{a^2+bc}=x,\]
since $a^2+bc=-(ad-bc)\ne0$. Moreover $f(x)$ never equals $-\dfrac dc=\dfrac ac$: that would give $c(ax+b)=a(cx+d)$, i.e. $bc=ad$. So $f(f(x))$ is defined whenever $f(x)$ is. $\blacksquare$

\textbf{(b)} Here $a=4$, $b=-5$, $c=1$, $d=-4$, with $ad-bc=-16+5=-11\ne0$ and $a+d=0$. So $f$ is its own inverse. Check: $f(0)=\dfrac{-5}{-4}=\dfrac54$ and $f\left(\dfrac54\right)=\dfrac{5-5}{\dfrac54-4}=0$.

Geometrically, a function is its own inverse exactly when its graph is symmetric about the line $y=x$.
