Work modulo $2n+1$, where $2n\equiv-1$. Then
\[16(n^4+n^2)=(2n)^4+4(2n)^2\equiv1+4=5\pmod{2n+1}.\]
Since $2n+1$ is odd, it is coprime to $16$, so $2n+1\mid n^4+n^2$ if and only if $2n+1\mid5$, i.e. $2n+1\in\{\pm1,\pm5\}$, giving $n\in\{0,-1,2,-3\}$. Check: $1\mid0$, $-1\mid2$, $5\mid20$, $-5\mid90$. The answer is $\boxed{n\in\{-3,-1,0,2\}}$.
