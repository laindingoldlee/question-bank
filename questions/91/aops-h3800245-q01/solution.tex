Eight draws are insufficient: four $1$s and four $2$s give five-ball sums $6,7,8,9$, never a multiple of five.
Now consider any nine draws. If some label occurs at least five times, choose five of it. Otherwise sort the nine labels as $a_1\le\cdots\le a_9$. Pair $a_i$ with $a_{i+4}$ for $i=1,2,3,4$, leaving $a_9$. Every pair contains different labels, since equality would require at least five copies.
For each pair choose one label, working modulo five. The possible sums from the first pair form a set of size two. Adding another two-element choice increases the number of residues by at least one unless all five already occur. Indeed, it forms a union $S+r\cup S+s$; equality with $|S|$ would make the proper nonempty set $S$ invariant under the nonzero shift $s-r$, whose repeated additions visit all five residues. After four pairs, all five residues are obtainable. Choose sum $-a_9$ modulo five and add the leftover ball. Thus nine always suffice, and the minimum is $\boxed9$.
