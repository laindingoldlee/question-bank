Three tasks await completion. Each attempt uses one worker to carry a task up a mountain and return. Independently on ascent and descent, an accident occurs with probability $x\in[0,1]$. An ascent accident leaves two tasks pending: the original and a new rescue task. If ascent succeeds, the original is completed; a descent accident creates one rescue task. A safe round trip creates none. Each pending task is attempted in the same way. Find the least $x$ for which the expected total number of attempts is infinite. Write it as $\dfrac{a-\sqrt b}{c}$ with positive integers $a,b,c$ and squarefree $b$, and find $|c^a-2b|$.
