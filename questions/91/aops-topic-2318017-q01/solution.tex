By the rational root theorem, any integer root divides $6$. Trying $x=-1$: $-1+7-6=0$, so $x+1$ is a factor (factor theorem). Dividing,
\[x^3-7x-6=(x+1)(x^2-x-6)=\boxed{(x+1)(x+2)(x-3)}.\]
So the solutions are $\boxed{x=-1,\ x=-2,\ x=3}$.
