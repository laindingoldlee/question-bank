\textbf{The error.} Multiplying both sides by $2-7x$ keeps the direction of the inequality only if $2-7x>0$; if $2-7x<0$ the direction must be reversed. The student's answer includes values that do not work: for example $x=1$ gives $(2-7)^{-1}=-\dfrac{1}{5}<5$.

\textbf{Correct solution.} The expression is undefined at $x=\dfrac{2}{7}$. If $2-7x<0$, the left side is negative, so it cannot be at least $5$. So we need $2-7x>0$, that is, $x<\dfrac{2}{7}$, and then multiplying by the positive number $2-7x$ is allowed:
\[1\ge5(2-7x)\iff35x\ge9\iff x\ge\dfrac{9}{35}.\]
Hence the solution set is
\[\boxed{\dfrac{9}{35}\le x<\dfrac{2}{7}}\qquad\left(\text{that is, } \dfrac{9}{35}\le x<\dfrac{10}{35}\right).\]
