We need $x\equiv3\pmod{13}$ and $x\equiv5\pmod7$. Write $x=3+13k$. Then $3+13k\equiv5\pmod7$, and since $13\equiv-1\pmod7$, $-k\equiv2$, so $k\equiv5\pmod7$. Thus $x=3+13(5+7m)=68+91m$. The smallest positive value is $\boxed{68}$, and the possible values are exactly $68,159,250,\dots$, i.e. $x\equiv68\pmod{91}$.
