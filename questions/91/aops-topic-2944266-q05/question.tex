An undirected acquaintance network on $n$ people has these properties: each person knows exactly $k$ others; each acquainted pair has exactly $\ell$ common acquaintances; and each nonacquainted distinct pair has exactly $m$ common acquaintances. Prove $m(n-k)-k(k-\ell)+k-m=0$.
