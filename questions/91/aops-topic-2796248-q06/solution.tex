The left side is non-negative, so $5x+2\ge0$, i.e. $x\ge-\dfrac25$; then $x+1>0$.

If $x\ge\dfrac32$: $x+1+x-\dfrac32=5x+2$ gives $x=-\dfrac56$, contradiction.
If $-\dfrac25\le x<\dfrac32$: $x+1+\dfrac32-x=\dfrac52=5x+2$ gives $x=\dfrac1{10}$, which is in range.

So $x=\boxed{\dfrac1{10}}$.
