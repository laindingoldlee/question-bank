For every integer $k$, set $R(x)=k$ when $k-\dfrac{1}{2}\le x<k+\dfrac{1}{2}$. Equivalently, $\boxed{R(x)=\lfloor x+\dfrac{1}{2}\rfloor}$. The graph consists of horizontal half-open steps: each left endpoint is included and each right endpoint excluded.
\begin{asy}
usepackage("amsmath");
size(7cm);
draw((-3,0)--(3,0),Arrow);draw((0,-3)--(0,3),Arrow);for(int k=-2;k<=2;++k){draw((k-.5,k)--(k+.5,k),blue);dot((k-.5,k));filldraw(circle((k+.5,k),.045),white,black);}label("$x$",(3,0),S);label("$R(x)$",(0,3),W);
\end{asy}
