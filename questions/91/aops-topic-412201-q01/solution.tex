The light arrives essentially instantly, so the sound travelled for $10$ seconds: $10\cdot1088=10880$ feet. In miles this is $\dfrac{10880}{5280}\approx2.06$, which is nearest to $2$ among the half-miles. The answer is $\boxed{\text{(C)}\ 2}$.
