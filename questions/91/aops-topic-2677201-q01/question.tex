Call a set of $n$ squares chosen from an $n\times n$ grid \emph{rookable} if no two chosen squares lie in the same row or the same column. How many rookable sets of $4$ squares are there in a $4\times4$ grid, if two sets are considered the same when one can be rotated or reflected onto the other?
