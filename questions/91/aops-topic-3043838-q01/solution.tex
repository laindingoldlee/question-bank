Write the number as $n=100a+10b+c$ and its reversal as $r=100c+10b+a$, where $1\le a\le9$ and $0\le b,c\le9$. If both are divisible by 27, so is $n+r=101(a+c)+20b$. Modulo 27 this is $20(a+b+c)$. Since $\gcd(20,27)=1$, the digit sum must be divisible by 27. It lies between 1 and 27, so it equals 27, forcing $a=b=c=9$. Conversely $999=37\cdot27$ and its reversal is itself. Therefore the least, and only, three-digit solution is $\boxed{999}$.
