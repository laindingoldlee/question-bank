$\underbrace{9\cdots9}_k=10^k-1$, so we need $10^k\equiv1$, which requires $\gcd(n,10)=1$; this explains $n=5$.

\emph{For $31$:} $10^3=1000\equiv8\pmod{31}$ and $2^5=32\equiv1$, so $10^{15}\equiv8^5=2^{15}\equiv1$. The order of $10$ divides $15$, and $10^1\equiv10$, $10^3\equiv8$, $10^5\equiv25$ are not $1$. So the order is $15$, and $31$ divides the string exactly when $15\mid k$; the shortest has $\boxed{15}$ nines.

\emph{For $7$:} $10\equiv3$, and the powers of $3$ mod $7$ are $3,2,6,4,5,1$. So the order is $6$, and the shortest string is $999999$ ($\boxed{6}$ nines); in general $6\mid k$.
