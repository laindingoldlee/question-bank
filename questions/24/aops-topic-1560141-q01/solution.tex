Regroup the left side in pairs of reciprocals:
\[
\dfrac{a+b}{c}+\dfrac{a+c}{b}+\dfrac{b+c}{a}=\left(\dfrac {a}{b}+\dfrac {b}{a}\right)+\left(\dfrac {a}{c}+\dfrac {c}{a}\right)+\left(\dfrac {b}{c}+\dfrac {c}{b}\right).
\]
For positive numbers $x$, $y$,
\[
\dfrac {x}{y}+\dfrac {y}{x}-2=\dfrac{x^2+y^2-2xy}{xy}=\dfrac{(x-y)^2}{xy}\ge0 ,
\]
with equality exactly when $x=y$. So each bracket is at least $2$ and the left side is at least $6$, with equality exactly when $a=b$, $a=c$ and $b=c$. Hence the equation holds if and only if $a=b=c$ (and then each fraction equals $2$). $\blacksquare$

(The argument works for all positive real numbers, not only digits; the digits must be nonzero for the fractions to be defined.)
