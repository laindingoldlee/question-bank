Regard each student's chosen set as a block. Every pair of the seven classes belongs to exactly one block, so distinct blocks intersect in at most one class, and $\sum\binom{|B|}{2}=21$. Let $m$ be the largest block size. We cannot have $m=7$, since no pair would remain for the other students, or $m\le2$, since seven blocks would cover only seven pairs. If $m=4$ or $5$, let $M$ be a largest block. Every other block contains at most one point of $M$. If it contains $t$ outside points, it covers at most $t$ cross-pairs and $\binom t2$ outside pairs. Since $t\le\binom t2+1$ for $t\ge1$, the six other blocks can cover at most $\binom{7-m}{2}+6$ cross-pairs. But there are $m(7-m)$ cross-pairs, which is $12>9$ for $m=4$ and $10>7$ for $m=5$. Thus only $m=6$ or $3$ is possible. If $m=6$, the other blocks are the six pairs joining the remaining class to each member of the block. There are seven such block systems. If $m=3$, all seven blocks must be triples. Fix one class. Its three triples pair up the other six classes, in $\dfrac{6!}{2!^3\,3!}=15$ ways. Each of the remaining four triples chooses one class from each pair. To cover every cross-pair once, these four choices must be one of the two parity classes of the three binary selections; once the triple containing any chosen pair is fixed, the other three are forced. Thus there are $15\cdot2=30$ triple systems. Each of the $7+30=37$ systems has seven distinct blocks, assignable to the seven students in $7!$ ways. The answer is $37\cdot7!=\boxed{186480}$.
