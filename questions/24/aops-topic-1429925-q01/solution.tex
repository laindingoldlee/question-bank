Group the boys by first name (first-name groups) and, separately, by last name (last-name groups). A boy in a group of size $g$ answers $g-1$. So the number $k$ occurs among the answers exactly when some first-name group or some last-name group has size $k+1$. Hence each of the sizes $1,2,\dots,7$ occurs among the groups.

The first-name groups contain all $14$ boys, and so do the last-name groups, so the sizes of all the groups (of both kinds) add up to $28$. But $1+2+\cdots+7=28$ already. Therefore there are no other groups: there are exactly seven groups in total, with sizes $1,2,\dots,7$, some of them first-name groups and the rest last-name groups. Let there be $k$ first-name groups; then there are $7-k$ last-name groups, so there are $k$ different first names and $7-k$ different last names.

Suppose no two boys share both names. Then the $14$ boys have $14$ different (first name, last name) pairs, so
\[
14\le k(7-k)\le3\cdot4=12,
\]
a contradiction ($k(7-k)$ is at most $12$ for integers $k$). Hence two boys have the same first name and the same last name. $\blacksquare$
