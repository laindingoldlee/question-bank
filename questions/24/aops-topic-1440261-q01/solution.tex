A distance cannot be negative, and any distance $d\ge0$ is possible, so the domain is $d\ge0$ and $x=\boxed{0}$. The cost $60+0.27d$ increases with $d$, takes the value $60$ at $d=0$, and takes every value above $60$, so the range is $c\ge60$ and $y=\boxed{60}$.
