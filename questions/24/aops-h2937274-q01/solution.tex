The domain excludes $x=2,6$. Cross-multiplication gives
\[
(x-1)(x-6)=(x-k)(x-2),\qquad(k-5)x=2k-6.
\]
At $k=5$, this reads $0=4$, so there is no solution. At $k=1,2,3,4$, the solutions are respectively $1,\dfrac{2}{3},0,-2$, all allowed. Thus the answer is $\boxed{\text{(E) }5}$.

When $k=1$, the actual solution is $x=1$, making both original numerators zero. Dividing by $x-1$ excludes exactly that valid solution. Such division is only reversible after separately handling $x=1$.
