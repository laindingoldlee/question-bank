Let $f(n)=\dfrac {x}{n}$. Then $f(f(n))=\dfrac{x}{\dfrac {x}{n}}=n$, so applying $f$ twice changes nothing.

With $16$ boxes, $f$ is applied an even number of times, so the result is $n$ for \emph{every} nonzero $x$: the condition puts no restriction on $x$.

With $15$ boxes the result is $f(n)=\dfrac {x}{n}$, and $\dfrac {x}{n}=n$ gives $x=n^2$.

(With infinitely many boxes the expression alternates between $n$ and $\dfrac {x}{n}$ and has no value unless $x=n^2$.)
