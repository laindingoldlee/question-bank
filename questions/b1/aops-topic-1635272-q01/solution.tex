Let the combination have $n$ nickels, $d$ dimes and $q$ quarters: $5n+10d+25q=60$, i.e.\ $n+2d+5q=12$ with $n,d,q\ge0$. Count by the number of quarters:
\begin{itemize}
\item $q=0$: $n+2d=12$, $d=0,1,\dots,6$: $7$ ways;
\item $q=1$: $n+2d=7$, $d=0,1,2,3$: $4$ ways;
\item $q=2$: $n+2d=2$, $d=0,1$: $2$ ways.
\end{itemize}
($q\ge3$ is too much.) In each case $n$ is then determined, so there are $7+4+2=\boxed{13}$ combinations.
