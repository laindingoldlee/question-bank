Let the common value be $k>0$. If $k=1$ then $x=0$, which is excluded, so $k\ne1$, and
\[
x=\log_3k,\qquad y=\log_4k,\qquad xy=\log_{12}k .
\]
Taking reciprocals, $\dfrac{1}{x}=\log_k3$, $\dfrac{1}{y}=\log_k4$, $\dfrac{1}{xy}=\log_k12=\log_k3+\log_k4$. So
\[
\dfrac{1}{x}+\dfrac{1}{y}=\dfrac{1}{xy}\iff\dfrac{x+y}{xy}=\dfrac{1}{xy}\iff x+y=\boxed{1}.
\]
(Such $x,y$ exist: for instance $k$ with $\log_3k+\log_4k=1$, i.e. $\log k=\dfrac{\log 3\log 4}{\log 12}$.)
