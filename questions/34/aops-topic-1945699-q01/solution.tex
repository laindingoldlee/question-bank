\textbf{(a)} $2018^{2017}=2018\cdot2018^{2016}$ is a multiple of $2018$, so the remainder is $\boxed{0}$.

\textbf{(b)} Modulo $2019$ we have $2018\equiv-1$, so
\[
2018^{2017}\equiv(-1)^{2017}=-1\equiv2018\pmod{2019}.
\]
The remainder is $\boxed{2018}$. This is what modular arithmetic is for: replacing a number by a small number with the same remainder makes huge powers easy.
