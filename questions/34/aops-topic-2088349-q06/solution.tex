We need $x\ge0$; put $t=\sqrt x\ge0$. The equation becomes $2t^2+3=t$, that is, $2t^2-t+3=0$. But
\[2t^2-t+3=2\left(t-\dfrac{1}{4}\right)^2+\dfrac{23}{8}>0\]
for every real $t$ (equivalently, the discriminant $1-24$ is negative). So the equation has \textbf{no real solutions}.
