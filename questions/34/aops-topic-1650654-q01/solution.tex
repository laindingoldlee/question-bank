For $k\ge5$, $k!$ contains the factors $2$ and $5$, so it ends in $0$. Hence the units digit of the sum equals the units digit of
\[
1!+2!+3!+4!=1+2+6+24=33,
\]
which is $3$. A number ending in $3$ has $\boxed{0}$ trailing zeros.
