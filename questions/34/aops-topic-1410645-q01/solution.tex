\textbf{No: $x^y>0$ for every positive $x$ and real $y$.}

For a positive base, powers are built up as follows, and positivity survives each step.
\begin{itemize}
\item Positive integer $y=n$: $x^n=x\cdot x\cdots x$ is a product of positive numbers, so it is positive. Also $x^0=1>0$.
\item $y=-n$: $x^{-n}=\dfrac{1}{x^n}$ is the reciprocal of a positive number, so it is positive.
\item Rational $y=\dfrac {p}{q}$ with $q>0$: $x^{\dfrac {p}{q}}$ is defined as the positive $q$-th root of $x^p$ (it exists because $x^p>0$). It is positive by definition.
\item Irrational $y$: $x^y$ is the limit of $x^{r}$ for rationals $r\to y$. All these values are positive, so the limit is at least $0$; and it is not $0$, because if $r_0<y<r_1$ are rationals then $x^y$ lies between $x^{r_0}$ and $x^{r_1}$ (powers of a fixed $x>0$ are monotonic in the exponent), both positive.
\end{itemize}
Equivalently, $x^y=e^{y\ln x}$, and the exponential function takes only positive values.

(For a negative base the question changes: $(-2)^3=-8$ is negative, which is why one restricts to $x>0$ when allowing real exponents.)
