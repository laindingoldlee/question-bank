A path to the deli is an arrangement of $3$ N's and $3$ W's: $\dbinom63=20$ choices. The return path is also one of $20$ shortest paths (traced in reverse), but it may not be the same as the one he used, leaving $19$ choices. So there are $20\cdot19=\boxed{380}$ round trips.

(The count $\dbinom{12}{6}$ would treat the twelve blocks of the round trip as one long path, which is not what is being chosen.)
