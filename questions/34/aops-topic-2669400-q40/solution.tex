We have $p(p+1)=r(r+1)-q(q+1)=(r-q)(r+q+1)$, and $r>p$, $r>q$. By symmetry in $p$ and $q$ assume $p\ge q$.

If $p\mid r-q$, then $r-q\ge p$ and $r+q+1>p+1$, so $(r-q)(r+q+1)>p(p+1)$, impossible. So the prime $p$ divides $r+q+1$; write $r+q+1=kp$. Then $p+1=k(r-q)$, so $r-q=\dfrac{p+1}{k}$. If $k=1$ then $r-q=p+1>p=r+q+1$, impossible; so $k\ge2$. Subtracting,
\[2q+1=kp-\dfrac{p+1}{k}\le2p+1,\qquad\text{so}\qquad p\left(k^2-2k-1\right)\le k+1.\]
\begin{itemize}
\item $k\ge4$: $p\left(k^2-2k-1\right)\ge2\left(k^2-2k-1\right)>k+1$, since $2k^2-5k-3=(2k+1)(k-3)>0$. Impossible.
\item $k=3$: $2p\le4$, so $p=2$; then $r-q=1$ and $r+q+1=6$, so $q=2$, $r=3$.
\item $k=2$: $4q+2=4p-(p+1)$, i.e. $3p=4q+3$, so $3\mid q$, $q=3$, $p=5$, and $r=q+\dfrac{p+1}{2}=6$, not prime.
\end{itemize}
The only solution is $\boxed{(p,q,r)=(2,2,3)}$: $6+6=12=3\cdot4$.
