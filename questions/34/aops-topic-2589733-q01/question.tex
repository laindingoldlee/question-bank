Suppose we try to add a new number $\infty$ to the real numbers so that $\dfrac1\infty=0$, which means $0\cdot\infty=1$, while keeping the distributive law $(x+y)z=xz+yz$ for all numbers, including $\infty$. Show that this forces $1=2$, so no such extension of ordinary arithmetic is possible.
