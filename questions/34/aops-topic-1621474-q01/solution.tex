If a letter is in position $p$ of the alphabet, George gives it $p$ and the correct value is $27-p$. The positions of $M,A,T,H,R,O,C,K,S$ are
\[
13,1,20,8,18,15,3,11,19,
\]
with sum $108$, so George's value is $108$. The correct value is $9\cdot27-108=135$. The difference is $135-108=\boxed{27}$.
