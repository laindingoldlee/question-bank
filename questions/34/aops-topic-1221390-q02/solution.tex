For a largest unpayable amount to exist the values $a<b$ must be coprime (and $a\ge2$), and then it is $ab-a-b$ (Frobenius). So $ab-a-b=35$, i.e. $(a-1)(b-1)=36$. Factor pairs with $a-1<b-1$: $(1,36),(2,18),(3,12),(4,9)$ give $(2,37)$, $(3,19)$, $(4,13)$, $(5,10)$; the last is not coprime ($(6,6)$ gives equal coins). The answer is $\boxed{3}$.
