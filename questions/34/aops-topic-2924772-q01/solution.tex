You must win $4$ fair games in a row (rounds with $16,8,4,2$ leaders), each with probability $\dfrac12$: $\left(\dfrac12\right)^4=\boxed{\dfrac1{16}}$. By symmetry this equals $\dfrac1{16}$ for everyone, as it must.
