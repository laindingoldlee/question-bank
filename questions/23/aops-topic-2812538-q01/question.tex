A set $S$ of positive integers is relatively open if the set $T=\{s_1+s_2:s_1,s_2\in S,\ s_1\ne s_2\}$ misses at least half of the integers from $\min S$ to $\max S$ inclusive. For example $\{1,2,3,10\}$ is relatively open, but $\{1,2,3,5,6,10\}$ is not. How many nonempty subsets of $\{1,2,3,4,5,6\}$ are relatively open?
