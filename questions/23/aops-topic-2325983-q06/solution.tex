A cube has $12$ edges.

\begin{asy}
usepackage("amsmath");
size(3.5cm);
defaultpen(fontsize(10pt));
real s=2; pair d=(0.9,0.6);
draw(box((0,0),(s,s)),linewidth(0.9)); draw((0,s)--(0,s)+d--(s,s)+d--(s,s),linewidth(0.9)); draw((s,0)--(s,0)+d--(s,s)+d,linewidth(0.9));
draw((0,0)--d--(0,s)+d,dashed); draw(d--(s,0)+d,dashed);
label("$10$ in",(s/2,0),S,fontsize(8pt)); label("$12$ edges",(s/2,s)+d,N,fontsize(8pt));
\end{asy}

So each cube needs $12\cdot10=120$ inches of tape, and $24$ cubes need $24\cdot120=2880$ inches, which is $\dfrac{2880}{12}=\boxed{240}$ feet.
