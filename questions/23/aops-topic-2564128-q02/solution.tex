The number of balls per bin must divide both $18$ and $24$, so it divides $\gcd(18,24)=6$: it is $1$, $2$, $3$ or $6$. Since it is greater than $4$, each bin holds $\boxed{6}$ balls (three red bins and four yellow bins).
