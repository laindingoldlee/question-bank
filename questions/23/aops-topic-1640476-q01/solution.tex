$25^{21}=5^{42}$, so
\[
25^{21}\times2^{48}=5^{42}\cdot2^{42}\cdot2^{6}=64\cdot10^{42}.
\]
This is $64$ followed by $42$ zeros, which has $2+42=\boxed{44}$ digits.
