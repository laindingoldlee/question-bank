Let $t=\log_AB$. Then $\log_BA=\dfrac{1}{t}$ (change of base: $\log_BA=\dfrac{\ln A}{\ln B}$ and $t=\dfrac{\ln B}{\ln A}$; both logarithms are nonzero since $A,B\ne1$). So $t=\dfrac{1}{t}$, $t^2=1$ and $t=\pm1$. If $t=1$ then $B=A$, which is excluded. So $t=-1$, i.e.\ $B=A^{-1}$, and $AB=\boxed{1}$. (For example $A=2$, $B=\dfrac{1}{2}$: $\log_2\dfrac{1}{2}=-1=\log_{\dfrac{1}{2}}2$.)
