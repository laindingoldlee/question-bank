All truth-tellers must give the same true answer, so there is at most one. There cannot be zero truth-tellers: if all $25$ lied, the answer $25$ would be true. Thus there is exactly one truth-teller and $\boxed{24}$ liars. The person answering $24$ tells the truth, and every other answer is false.
