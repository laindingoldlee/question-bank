Since $b\ge1$, the fraction $\dfrac{1}{b+\dfrac{1}{c+\dfrac{1}{d}}}$ lies strictly between $0$ and $1$, so $a$ is the integer part of $\dfrac{181}{42}=4+\dfrac{13}{42}$: $a=4$. Then
\[
b+\dfrac{1}{c+\dfrac{1}{d}}=\dfrac{42}{13}=3+\dfrac{3}{13}.
\]
Again the fraction lies strictly between $0$ and $1$ (as $c\ge1$ and, if $c=1$, $d\ge1$ keeps $c+\dfrac{1}{d}>1$), so $b=3$ and $c+\dfrac{1}{d}=\dfrac{13}{3}=4+\dfrac{1}{3}$. If $d=1$ then $c+1=\dfrac{13}{3}$ is not an integer, so $d\ge2$, $\dfrac{1}{d}<1$, and $c=4$, $d=3$.

Hence $a+b+c+d=4+3+4+3=\boxed{14}$.
