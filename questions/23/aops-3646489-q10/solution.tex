Use $A$ as the origin and a unit direction $u$ for the line. A circle with centre vector $O_i$ passing through zero meets that line again at signed parameter $t_i=2O_i\cdot u$, from $|tu-O_i|^2=|O_i|^2$. Therefore $XY=2|(O_2-O_1)\cdot u|\le2|O_2-O_1|=20$. Equality occurs for the line through $A$ parallel to the line of centres. Hence the maximum is $\boxed{20}$.
\begin{asy}
import graph;import geometry;usepackage("amsmath");size(7cm);
pair O1=(0,0),O2=(10,0),A=(3.6,4.8),B=(3.6,-4.8),X=(-3.6,4.8),Y=(16.4,4.8);draw(circle(O1,6));draw(circle(O2,8));draw(X--Y,blue);draw(O1--O2,dashed);dot(A);dot(B);label("$A$",A,(0,1));label("$B$",B,(0,-1));label("$X$",X,(-1,1));label("$Y$",Y,(1,1));label("$O_1$",O1,(0,-1));label("$O_2$",O2,(0,-1));label("$10$",(5,0),(0,-1));
\end{asy}
