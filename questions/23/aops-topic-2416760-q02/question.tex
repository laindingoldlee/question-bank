A grain silo is built from two right circular cones and a right circular cylinder. Its internal measurements are: the cylinder has diameter $10$ feet and height $10$ feet, and a cone with the same diameter and height $5$ feet is attached to each end of the cylinder. Of the following, which is closest to the volume of the grain silo, in cubic feet?

$\textbf{(A) } 261.8\qquad\textbf{(B) } 785.4\qquad\textbf{(C) } 916.3\qquad\textbf{(D) } 1047.2$
