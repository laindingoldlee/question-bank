Imagine that all $7$ marbles are drawn, in a uniformly random order. The process stops as soon as one colour is exhausted, and the last marble it draws is white exactly when the white marbles run out first, i.e.\ when all $3$ white marbles come before the last red one. That happens exactly when the marble in position $7$ of the full order is red. Each marble is equally likely to be in position $7$, so the probability is
\[
\boxed{\dfrac{4}{7}}.
\]
