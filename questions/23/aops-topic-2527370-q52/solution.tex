We need $|x|=2|x-12|$. If $x=2(x-12)$ then $x=24$; if $x=-2(x-12)$ then $3x=24$ and $x=8$. (Check: $24$ is $24$ from $0$ and $12$ from $12$; $8$ is $8$ from $0$ and $4$ from $12$.) The distance between them is $24-8=\boxed{16}$.
