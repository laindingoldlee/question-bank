An attempt succeeds with probability $\dfrac9{10}\cdot\dfrac7{10}\cdot\dfrac3{10}\cdot\dfrac1{10}=\dfrac{189}{10000}$. The number of attempts is geometric, so its expected value is $\boxed{\dfrac{10000}{189}}\approx52.9$.
