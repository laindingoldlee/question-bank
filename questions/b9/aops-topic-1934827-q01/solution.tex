The first digit is not $0$, so $\overline{ab}$ is a two-digit square: $16,25,36,49,64,81$, which is $6$ choices.

The last two digits form a square from $0$ to $99$: $00,01,04,09,16,25,36,49,64,81$, which is $10$ choices.

The two choices are independent, so there are $6\cdot10=\boxed{60}$ such integers. (If $\overline{cd}$ also had to be a genuine two-digit square, the answer would be $6\cdot6=36$.)
