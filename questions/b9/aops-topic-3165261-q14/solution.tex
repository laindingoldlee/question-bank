The first equation describes the diamond $|x-1|+|y-1|=4$. Squaring the second gives $k=x\pm y^2$, so the maximum must use $k=x+y^2$. For fixed $y\in[-3,5]$, the largest possible $x$ is $5-|y-1|$. Thus maximize $y^2+5-|y-1|$. On each interval $[-3,1]$ and $[1,5]$ this is a convex quadratic, so its maximum occurs at an endpoint. The values at $y=-3,1,5$ are $10,6,26$. The greatest is $\boxed{k=26}$, attained at $(x,y)=(1,5)$.
