By the sine definition, $\sin17^\circ=\dfrac{25}{x}$, so $x=\dfrac{25}{\sin17^\circ}\approx\boxed{85.5}$. The angle is in degrees, so a calculator must use degree mode or convert $17^\circ$ to $\dfrac{17\pi}{180}$ radians.
\begin{asy}
usepackage("amsmath");
size(7cm);
pair A=(0,0),B=(25/tan(17*pi/180),0),C=(25/tan(17*pi/180),25);draw(A--B--C--cycle);label("$17^\circ$",A+(12,2));label("$25$",(B+C)/2,E);label("$x$",(A+C)/2,N);
\end{asy}
