Modulo $a$, $(a+6)^2\equiv36$, so the divisibility condition is equivalent to $a\mid36$. A positive integer has an odd divisor count exactly when it is a square, because nonsquare divisors pair with distinct complementary divisors. The square divisors of $36$ are $\boxed{1,4,9,36}$.
