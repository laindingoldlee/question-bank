The conjecture is false. Checking small primes:
\[p=2:13,\ 17;\quad p=3:19;\quad p=5:31;\quad p=7:43;\quad p=11:67;\quad p=13:79;\quad p=17:103,\]
always giving a prime, but for $p=19$,
\[6\cdot19+1=115=5\cdot23,\qquad 6\cdot19+5=119=7\cdot17,\]
and both are composite. So $\boxed{p=19}$ is a counterexample (the smallest one).
