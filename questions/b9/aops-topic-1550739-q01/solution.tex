Complete the square in $x$:
\[
4x^2+6xy+4y^2=4\left(x^2+\dfrac{3}{2}xy\right)+4y^2=4\left(x+\dfrac{3}{4}y\right)^2-\dfrac{9}{4}y^2+4y^2=4\left(x+\dfrac{3}{4}y\right)^2+\dfrac{7}{4}y^2 .
\]
Both terms are squares times positive constants, so the expression is at least $0$. $\blacksquare$

Equality needs both terms to be $0$: $y=0$ and then $x+\dfrac{3}{4}y=x=0$. So equality holds only at $\boxed{x=y=0}$. (In fact the expression is positive for every other pair.)

Alternatively, $4x^2+6xy+4y^2=3(x+y)^2+(x^2+y^2)$, which is $0$ only when $x=y=0$.
