Use the identity \(1^3+2^3+\cdots+n^3=\left(\dfrac{n(n+1)}{2}\right)^2=(1+2+\cdots+n)^2\). The equation becomes \((1+\cdots+6)^2=(1+\cdots+n)^2\), so \(1+\cdots+n=21=1+\cdots+6\), and since the partial sums increase strictly, \(n=\boxed{6}\).
