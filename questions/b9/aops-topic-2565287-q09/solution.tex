Of the $36$ equally likely outcomes, the number with sum $s$ is $s-1$ for $s\le7$, so the sums $2$ to $6$ occur in $1+2+3+4+5=15$ outcomes. The sum exceeds $6$ in the other $36-15=21$ outcomes, so the probability is $\dfrac{21}{36}=\boxed{\dfrac{7}{12}}$.
