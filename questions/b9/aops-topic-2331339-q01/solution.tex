Red Cat's statement is true exactly when Blue Cat did it (then Red Cat is also innocent); Blue Cat's statement is true exactly when Blue Cat did it; Green Cat's statement is true exactly when Red Cat did it. Check the three possibilities:
\begin{itemize}
\item Blue Cat did it: Red and Blue tell the truth, two truth-tellers. Impossible.
\item Green Cat did it: all three statements are false. Impossible.
\item Red Cat did it: only Green Cat tells the truth. This fits.
\end{itemize}
So $\boxed{\text{Red Cat}}$ scratched the couch.
