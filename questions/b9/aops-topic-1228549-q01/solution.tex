The squares modulo $7$ are $0^2,1^2,\dots,6^2\equiv0,1,4,2,2,4,1$, so a square is $\equiv0,1,2$ or $4$. If $x^2+y^2\equiv0$ with $x^2\equiv u$, $y^2\equiv v$, then $u+v\equiv0$ with $u,v\in\{0,1,2,4\}$. The only possibility is $u=v=0$ ($1+6$, $2+5$, $4+3$ would need $6,5,3$, which are not squares). So $7\mid x^2$ and $7\mid y^2$, and since $7$ is prime, $7\mid x$ and $7\mid y$. $\blacksquare$
