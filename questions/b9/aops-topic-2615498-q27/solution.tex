Write $x=p^aq^br^c$. Then $x^2$ has $(2a+1)(2b+1)(2c+1)=1001=7\cdot11\cdot13$ divisors. Each factor is at least $3$, and $1001$ has exactly three prime factors, so $\{2a+1,2b+1,2c+1\}=\{7,11,13\}$ and $\{a,b,c\}=\{3,5,6\}$. So $x$ has $4\cdot6\cdot7=\boxed{168}$ divisors.
