Adding red marbles only lowers the average, so add $k$ blue marbles. The expected value is $\dfrac{3\cdot1+3(2+k)}{5+k}=\dfrac{9+3k}{5+k}$, and
\[\dfrac{9+3k}{5+k}\ge\dfrac52\iff18+6k\ge25+5k\iff k\ge7.\]
More generally, with $r$ red and $k$ blue added, the condition is $0.5k\ge3.5+1.5r$, so $k\ge7$ in every case. The least number is $\boxed{7}$.
