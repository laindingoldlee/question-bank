$\dfrac{1}{3}\pi\cdot12^2h=432\pi$ gives $h=9$, so the slant height (the paper's radius) is $\sqrt{12^2+9^2}=15$. The used sector's arc is the cone's base circumference $24\pi$, out of the full $30\pi$, so it spans $\dfrac{24}{30}\cdot360^\circ=288^\circ$. The unused sector has angle $360^\circ-288^\circ=\boxed{72^\circ}$.

\begin{asy}
usepackage("amsmath");
size(2.8cm);
defaultpen(fontsize(10pt));
draw(arc((0,0),2,0,288),linewidth(1)); fill((0,0)--arc((0,0),2,288,360)--cycle,lightgray); draw((0,0)--(2,0)); draw((0,0)--2*dir(288)); label("$B$",(0,0),W); label("$C$",(2,0),E); label("$A$",2*dir(288),S); label("$15$",(1,0),N);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}
