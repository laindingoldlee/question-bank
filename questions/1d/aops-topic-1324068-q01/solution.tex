Go around the table starting from Arendelle. Each step to the next neighbour changes the number of rolls by $+1$ or $-1$, and after $8$ steps we return to Arendelle's $7$, so exactly $4$ steps are $+1$ and $4$ are $-1$. Every such sequence gives a valid assignment (the smallest possible number is $7-4=3\ge0$), and different sequences give different assignments. So the number of ways is $\dbinom84=\boxed{70}$.
