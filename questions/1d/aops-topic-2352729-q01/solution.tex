With the $2$ kept, the four rerolled dice must show either $1,3,4,5$ or $3,4,5,6$ in some order. Each set of four different values can appear in $4!=24$ orders, so $48$ of the $6^4=1296$ equally likely outcomes work. The probability is
\[\dfrac{48}{1296}=\boxed{\dfrac{1}{27}}.\]
