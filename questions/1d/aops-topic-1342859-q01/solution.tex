The third angle is $180^\circ-45^\circ-60^\circ=75^\circ$, so the smallest angle is $45^\circ$ and the shortest side lies opposite it. Name the triangle $ABC$ with $\angle A=45^\circ$, $\angle B=60^\circ$, $BC=12$, and drop the altitude $CH=h$ to $AB$.

\begin{asy}
usepackage("amsmath");
size(6cm);
defaultpen(fontsize(10pt));
path ra(pair P,pair u,pair v,real s=0.2){return P+s*unit(u)--P+s*unit(u)+s*unit(v)--P+s*unit(v);}
real h=6*sqrt(3);
pair A=(0,0), B=(h+6,0), C=(h,h), H=(h,0);
draw(A--B--C--cycle,linewidth(0.9)); draw(C--H,red+dashed); draw(ra(H,B-H,C-H,0.8));
label("$A$",A,SW); label("$B$",B,SE); label("$C$",C,N); label("$H$",H,S);
label("$12$",(B+C)/2,NE);
label("$h$",(C+H)/2,W,red);
draw(arc(A,2.2,0,45)); label("$45^\circ$",A+3.3*dir(22.5),fontsize(8pt));
draw(arc(B,1.8,120,180)); label("$60^\circ$",B+2.9*dir(150),fontsize(8pt));
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

Triangle $BCH$ is a $30$-$60$-$90$ triangle with hypotenuse $12$, so $h=6\sqrt3$ and $HB=6$. Triangle $ACH$ is a $45$-$45$-$90$ triangle, so $AH=h=6\sqrt3$. Hence $AB=6\sqrt3+6$ and
\[
[ABC]=\dfrac{1}{2}\cdot AB\cdot h=\dfrac{1}{2}\left(6+6\sqrt3\right)\cdot6\sqrt3=\boxed{54+18\sqrt3}.
\]
