From $\dfrac{g(x)}{f(x)}=10x$ we get $f(x)=\dfrac{11x^2-1}{10x}$. Setting $f(x)=1$:
\[
11x^2-1=10x\iff11x^2-10x-1=0\iff(11x+1)(x-1)=0 .
\]
So $x=1$ or $x=-\dfrac{1}{11}$, and the negative value is $\boxed{-\dfrac{1}{11}}$. (Check: $g\left(-\dfrac{1}{11}\right)=\dfrac{11}{121}-1=-\dfrac{10}{11}=10x$, so $f=1$ there.)
