Since $2x+2=2(x+1)$, for $x>-1$
\[\dfrac{(2x+2)(2x+1)}{(x+1)^2}=\dfrac{2(2x+1)}{x+1}=\dfrac{4x+2}{x+1}=4-\dfrac{2}{x+1}.\]
As $x\to\infty$, $\dfrac{2}{x+1}\to0$, so the limit is $\boxed{4}$.
