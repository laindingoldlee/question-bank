Let $t=x+\dfrac{1}{x}>0$. Then $t^2=x^2+2+\dfrac{1}{x^2}=15$, so $t=\sqrt{15}$. Using $\left(x+\dfrac{1}{x}\right)^3=x^3+\dfrac{1}{x^3}+3\left(x+\dfrac{1}{x}\right)$,
\[
x^3+\dfrac{1}{x^3}=t^3-3t=15\sqrt{15}-3\sqrt{15}=\boxed{12\sqrt{15}}.
\]
(Without the condition $x>0$, also $t=-\sqrt{15}$ is possible, giving $-12\sqrt{15}$.)
