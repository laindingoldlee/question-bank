$60$ apples and $60$ pears are shared out among several boxes, so that every box contains at least one apple and at least one pear, every box contains the same number of apples, and no two boxes contain the same number of pears. What is the maximum number of boxes that can be filled in this way?

$\textbf{(A) }20\qquad\textbf{(B) }15\qquad\textbf{(C) }12\qquad\textbf{(D) }10\qquad\textbf{(E) }6$
