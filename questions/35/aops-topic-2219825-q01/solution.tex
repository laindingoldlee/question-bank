Compare consecutive coefficients. For $0\le k\le n-1$,
\[\dfrac{\dbinom{n}{k+1}}{\dbinom nk}=\dfrac{\dfrac{n!}{(k+1)!\,(n-k-1)!}}{\dfrac{n!}{k!\,(n-k)!}}=\dfrac{n-k}{k+1}.\]
This ratio is greater than $1$ exactly when $n-k>k+1$, i.e. $k<\dfrac{n-1}{2}$, and less than $1$ when $k>\dfrac{n-1}{2}$. Since $n$ is even, $\dfrac{n-1}{2}$ is not an integer, so the ratio is never equal to $1$.

Write $m=\dfrac {n}{2}$. For $k\le m-1$ we have $k<\dfrac{n-1}{2}$, so
\[\dbinom n0<\dbinom n1<\cdots<\dbinom nm,\]
and for $k\ge m$ we have $k>\dfrac{n-1}{2}$, so
\[\dbinom nm>\dbinom n{m+1}>\cdots>\dbinom nn.\]
Hence $\dbinom n{\dfrac {n}{2}}$ is strictly the largest. $\blacksquare$

(For odd $n$ the same computation shows that the two middle coefficients $\dbinom n{\dfrac{n-1}{2}}=\dbinom n{\dfrac{n+1}{2}}$ are the largest.)
