Let $N=10^9$. The function $x^{- \dfrac{2}{3}}$ is strictly decreasing, so $\int_1^{N+1} x^{- \dfrac{2}{3}} \, d x < \sum_{k=1}^{N} k^{- \dfrac{2}{3}} < 1 + \int_1^N x^{- \dfrac{2}{3}} \, d x$. The lower bound is $3 ((N+1)^{\dfrac{1}{3}} - 1) > 2997$; the upper bound is $1+3(1000-1)=2998$. The sum lies strictly between these consecutive integers, so its integer part is $\boxed{2997}$.
