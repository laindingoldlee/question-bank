The student counted the ways the first $6$ games can be split $3$--$3$, but forgot that the Grunters must then actually win game $7$, which has probability $\dfrac{3}{4}$. (The value $\dfrac{135}{1024}$ is the probability that the series reaches a seventh game with the Grunters having won exactly $3$ of the first $6$, i.e. that it is tied $3$--$3$.) The correct probability is
\[\dbinom63\left(\dfrac{3}{4}\right)^3\left(\dfrac{1}{4}\right)^3\cdot\dfrac{3}{4}=\dfrac{135}{1024}\cdot\dfrac{3}{4}=\boxed{\dfrac{405}{4096}}\approx0.099.\]
The book's approach (choose which $3$ of the first $6$ games the Grunters win, then require game $7$) gives the same value.
