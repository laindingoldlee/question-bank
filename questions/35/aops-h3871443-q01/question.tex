A password begins with the single letter $\mathrm{A}$. In each round, every $\mathrm{A}$ is replaced by $\mathrm{AB}$ and every $\mathrm{B}$ is replaced by $\mathrm{A}$, with all replacements occurring simultaneously.

The first few passwords are

\[
\mathrm{A},\qquad
\mathrm{AB},\qquad
\mathrm{ABA},\qquad
\mathrm{ABAAB}.
\]

How many letters are in the password after $10$ rounds?
