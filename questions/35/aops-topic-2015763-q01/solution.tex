Since $48=16\cdot3=2^4\cdot 3$,
\[
\log_2\dfrac{1}{48}=-\log_2 48=-\left(\log_2 16+\log_2 3\right)=\boxed{-4-\log_2 3}.
\]
The equation $2^x=\dfrac{1}{48}$ has the unique real solution $x=\log_2\dfrac{1}{48}=-4-\log_2 3\approx-5.585$. Logarithms are exactly the tool that solves equations in which the unknown is an exponent: without them there is no way to write this $x$ in closed form, since $48$ is not a power of $2$.
