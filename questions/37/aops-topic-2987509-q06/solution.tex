Omar ends with $2^k$ dollars exactly when the first $k$ rolls are sixes and the next is not: probability $\left(\dfrac16\right)^k\dfrac56$. So
\[E=\sum_{k\ge0}2^k\left(\dfrac16\right)^k\dfrac56=\dfrac56\sum_{k\ge0}\left(\dfrac13\right)^k=\dfrac56\cdot\dfrac32=\dfrac54.\]
The expected value is $\boxed{\$1.250}$.
