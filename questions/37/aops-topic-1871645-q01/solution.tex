A choice is correct exactly when the value it shows equals the probability of picking a correct choice at random, which is $\dfrac{1}{4}$ times the number of choices that show the correct value. Test each possible value:
\begin{itemize}
\item If $25\%$ were correct, then both (a) and (d) would be correct, and a random choice would be correct with probability $\dfrac{2}{4}=50\%\ne25\%$.
\item If $50\%$ were correct, only (b) would be correct, giving probability $\dfrac{1}{4}=25\%\ne50\%$.
\item If $75\%$ were correct, only (c) would be correct, giving probability $25\%\ne75\%$.
\end{itemize}
Each assumption contradicts itself, so $\boxed{\text{no choice is consistent}}$: the question has no correct answer among its options (it is a self-referential paradox).
