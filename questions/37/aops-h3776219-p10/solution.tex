We have $1\le\dfrac{3}{a}$, so $a\le3$, while $a=1$ is impossible. If $a=3$, each reciprocal is at most $\dfrac{1}{3}$, forcing $(3,3,3)$. If $a=2$, then $\dfrac{1}{b}+\dfrac{1}{c}=\dfrac{1}{2}$, so $3\le b\le4$. For $b=3$ we get $c=6$, and for $b=4$ we get $c=4$. Thus $\boxed{(2,3,6),(2,4,4),(3,3,3)}$.
