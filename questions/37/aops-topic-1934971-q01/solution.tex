The equation is $3n^2-72+8p^3=2019$, that is, $3n^2+8p^3=2091=3\cdot697$. Since $3$ divides $3n^2$ and $2091$, it divides $8p^3$, so $3\mid p$ and $p=3$. Then $3n^2=2091-216=1875$, so $n^2=625$ and $n=25$.

Check: $3(625-24)+6^3=1803+216=2019$. So $\boxed{n=25,\ p=3}$.
