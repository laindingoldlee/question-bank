Write the number as $\overline{abc}$ with $a\ge1$. Its sum with the reversal is
\[
(100a+10b+c)+(100c+10b+a)=101(a+c)+20b,
\]
which must be less than $1000$. Let $s=a+c$. For $1\le s\le8$, $101s+20b\le808+180<1000$ for every digit $b$ ($10$ choices); for $s=9$, we need $20b<91$, i.e. $b\le4$ ($5$ choices); for $s\ge10$ the sum is at least $1010$. For $1\le s\le9$ there are $s$ pairs $(a,c)$ with $a\ge1$, $c\ge0$ and $a+c=s$. So the count is
\[
10(1+2+\dots+8)+5\cdot9=360+45=\boxed{405}.
\]
