A remainder of $2$ on dividing $100$ by $n$ requires $n\mid98$ and $n>2$, so $n\in\{7,14,49,98\}$. After learning that $n<X$, Diana knows $n$ exactly when exactly one candidate is less than $X$, which must be $7$; so $7<X\le14$. The greatest possible value is $X=\boxed{14}$.
