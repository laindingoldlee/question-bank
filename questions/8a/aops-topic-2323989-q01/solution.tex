We need $a,b\ne0$. Multiplying by $6ab$ gives $6b+6a=ab$, that is,
\[ab-6a-6b+36=36\quad\Longleftrightarrow\quad(a-6)(b-6)=36.\]
Conversely, every factorisation $36=uv$ gives $a=u+6$, $b=v+6$, which is a solution as long as $a,b\ne0$.

$36$ has $9$ positive divisors, so there are $9$ ordered factorisations $36=uv$ with $u,v>0$ and $9$ with $u,v<0$. A solution fails only if $a=0$ or $b=0$, that is $u=-6$ or $v=-6$, which happens only for $u=v=-6$. So there are $18-1=\boxed{17}$ ordered pairs.
