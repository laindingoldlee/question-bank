Since $2010$ is a multiple of $3$, each of $a,b,c$ is equally likely to be $0,1,2\pmod3$, independently. Write $abc+ab+a=a(bc+b+1)$.
\begin{itemize}
\item If $3\mid a$ (probability $\dfrac{1}{3}$) it is divisible.
\item Otherwise we need $b(c+1)\equiv2\pmod3$: either $b\equiv1$, $c\equiv1$, or $b\equiv2$, $c\equiv0$; probability $\dfrac{2}{9}$.
\end{itemize}
Total: $\dfrac{1}{3}+\dfrac{2}{3}\cdot\dfrac{2}{9}=\boxed{\dfrac{13}{27}}$.
