A ball is dropped from a height of $10$ meters. Each rebound reaches $p$ times the preceding height, where $0\le p<1$. A fall from height $h$ takes $\sqrt{\dfrac{2h}{g}}$ seconds, where $g=9.8$ meters per second squared; the corresponding upward trip takes the same time. Impacts are instantaneous. Find the limiting total time of all the motion.
