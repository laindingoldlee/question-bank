The three residues of $0,x,2x$ modulo 3 are distinct. In each residue class the least nonnegative representable number is respectively $0,x,2x$: a representation in that class has $v$ congruent to 0,1,2 modulo 3, so cannot be smaller. The largest missing number in each class is therefore its least representative minus 3. The largest overall is $\boxed{2x-3}$. If $3\mid x$, there are arbitrarily large nonmultiples of 3 that are not representable, so no largest missing integer exists.
