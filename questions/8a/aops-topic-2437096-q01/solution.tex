Choose the president ($10$ ways), then the vice-president from the other $9$ members ($9$ ways): $10\cdot9=\boxed{90}$ ways.

Multiplying by $2!$ would be wrong. The count $10\cdot9$ already treats ``Alice president, Bob vice-president'' and ``Bob president, Alice vice-president'' as different outcomes, which they are, because the offices are different. Multiplying by $2!$ would count each outcome twice.

For a two-person committee the two places are the same, so each committee $\{$Alice, Bob$\}$ is counted twice by $10\cdot9$, and the number of committees is $\dfrac{10\cdot9}{2!}=45=\dbinom{10}{2}$.
