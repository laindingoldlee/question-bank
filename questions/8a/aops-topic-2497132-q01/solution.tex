The prime digits are $2,3,5,7$. Condition (iii) says $d\ge c+5$. If $c\ge3$ then $d\ge8$, which is not a prime digit; so $c=2$ and $d=7$. Condition (ii) says $a\le b+2\le c=2$, so $b=0$ and $a\le2$, hence $a=2$. The only number is $\boxed{2027}$. (Check: $\dfrac22=1\le1\le\dfrac22$ and $\dfrac{7}{7}=1\le1$.)
