$70^n=2^n\cdot5^n\cdot7^n$, so the exponent of $5$ in $70^n$ is exactly $n$. By unique factorisation, $5^{16}\mid70^n$ if and only if $n\ge16$. The least value is $n=\boxed{16}$.
