$ n-n^2=-n(n-1)\le0 $, with equality at $ n=1 $, so its greatest value is $ 0 $. Given any real lower bound candidate $ L $, taking $ n $ sufficiently large makes $-n(n-1)<L $. Thus it is not bounded below.
