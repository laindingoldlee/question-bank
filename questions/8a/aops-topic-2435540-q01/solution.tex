The smallest possible sum is $1+2+3+4=10$ and the largest is $47+48+49+50=194$. Every integer in between occurs. Start from $\{1,2,3,4\}$ and raise one number by $1$ at a time, always keeping the four numbers distinct:
\begin{itemize}
\item raise the largest number from $4$ up to $50$: sums $10,11,\dots,56$;
\item then raise the third number from $3$ up to $49$ (the set is $\{1,2,k,50\}$): sums $57,\dots,102$;
\item then raise the second number from $2$ up to $48$: sums $103,\dots,148$;
\item then raise the smallest number from $1$ up to $47$: sums $149,\dots,194$.
\end{itemize}
Each step increases the sum by exactly $1$, so all of $10,11,\dots,194$ occur, and the number of possible values is $194-10+1=\boxed{185}$.
