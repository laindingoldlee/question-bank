Let \(s=\sin\theta\), which takes every value in \([-1,1]\). We need \(f(s)=s^2-2as-a^2+3\ge 0\) for all \(s\in[-1,1]\). The parabola \(f\) has its vertex at \(s=a\).
\begin{itemize}
\item If \(-1\le a\le 1\): the minimum is \(f(a)=3-2a^2\ge 3-2>0\). Every such \(a\) works.
\item If \(a>1\): the minimum on \([-1,1]\) is \(f(1)=4-2a-a^2\), and \(4-2a-a^2\ge 0\iff a^2+2a-4\le 0\iff -1-\sqrt5\le a\le -1+\sqrt5\). So \(1<a\le\sqrt5-1\).
\item If \(a<-1\): the minimum is \(f(-1)=4+2a-a^2\ge 0\iff 1-\sqrt5\le a\le 1+\sqrt5\). So \(1-\sqrt5\le a<-1\).
\end{itemize}
Combining,
\[
\boxed{1-\sqrt5\le a\le \sqrt5-1}.
\]
