Write such a number as $110b+101c$, with digits $b,c\ge0$ and $1\le b+c\le9$. For each $n=1,\ldots,22$, examples divisible by $n$ are respectively 101,202,303,404,505,606,707,808,909,110,110,312,312,826,615,624,918,918,817,220,945,110. Each has the required digit property. Modulo 23, the expression is $18b+9c=9(2b+c)$, so divisibility by 23 requires $2b+c\equiv0\pmod{23}$. But $1\le2b+c\le18$, impossible. Therefore the answer is $\boxed{23}$.
