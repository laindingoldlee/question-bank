First inequality: $6.2x+1.8x\ge12-6$, i.e.\ $8x\ge6$, so $x\ge\dfrac{3}{4}$.

Second inequality: $-x+2x\ge3.5-2$, i.e.\ $x\ge1.5$.

Both must hold, so the solution is $\boxed{x\ge\dfrac{3}{2}}$.
