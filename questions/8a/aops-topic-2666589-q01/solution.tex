Since $(a+b)^4=a^4+4a^3b+6a^2b^2+4ab^3+b^4$,
\[\dfrac{a^4+b^4+(a+b)^4}{2}=a^4+2a^3b+3a^2b^2+2ab^3+b^4.\]
On the other hand,
\[\left(a^2+ab+b^2\right)^2=a^4+a^2b^2+b^4+2a^3b+2a^2b^2+2ab^3=a^4+2a^3b+3a^2b^2+2ab^3+b^4.\]
So the expression under the square root equals $\left(a^2+ab+b^2\right)^2$, and its square root is $\left|a^2+ab+b^2\right|$. Finally $a^2+ab+b^2=\left(a+\dfrac b2\right)^2+\dfrac{3b^2}{4}\ge0$, so the absolute value can be dropped. $\blacksquare$
