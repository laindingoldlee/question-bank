Two values $f(m)$, $f(n)$ with $m>n$ differ by $a\left(m!-n!\right)$, so we need $a(m!-n!)=20$ for some $m>n\ge1$. The differences of factorials that divide $20$:
\begin{itemize}
\item $2!-1!=1$, giving $a=20$;
\item $3!-2!=4$, giving $a=5$;
\item $3!-1!=5$, giving $a=4$.
\end{itemize}
Every other difference is too big or does not divide $20$: $4!-3!=18$, $4!-2!=22$, $4!-1!=23$, and from $5!$ on the differences exceed $20$. So the least possible $a$ is $4$ (with $f(3)-f(1)=4\cdot5=20$). Since $f(1)=a+b$ and $b\ge1$, the least value of $f(1)$ is $4+1=\boxed{5}$ (e.g.\ $f(n)=4\cdot n!+1$: $f(1)=5$, $f(3)=25$).
