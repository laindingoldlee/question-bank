\begin{enumerate}
\item[(i)] $x^2-36x+323=(x-17)(x-19)$, so $x=17$.
\item[(ii)] $x=10$.
\item[(iii)] Clearing denominators, $60b+60a=ab$, i.e. $(a-60)(b-60)=3600$. Since $3600=2^4\cdot3^2\cdot5^2$ has $5\cdot3\cdot3=45$ positive divisors, there are $90$ ordered pairs of integer factors $(a-60,b-60)=\left(d,\dfrac{3600}{d}\right)$ with $d=\pm$ a divisor. Exactly one of them, $d=-60$, gives $a=0$ (and $b=0$), which is not allowed. So $x=89$.
\item[(iv)] The positive integers with exactly $4$ divisors are $6,8,10,14,15,\dots$, so $x=14$.
\item[(v)] The eleventh prime is $31$, and $49+320+600+31=1000$.
\end{enumerate}
The probability of (vi) is
\[1-\left(\dfrac1{17}+\dfrac1{10}+\dfrac1{89}+\dfrac1{14}+\dfrac1{1000}\right)=\boxed{\dfrac{8022809}{10591000}}\approx0.758,\]
using the common denominator $10591000=1000\cdot7\cdot17\cdot89$.
