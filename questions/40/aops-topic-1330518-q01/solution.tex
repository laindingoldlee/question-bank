By Euler's formula $e^{i\theta}=\cos\theta+i\sin\theta$, so $e^{i\pi x}=\cos\pi x+i\sin\pi x$. For $x=3$, $e^{3\pi i}=\cos3\pi+i\sin3\pi=\boxed{-1}$. For an integer $x$, $\sin\pi x=0$ and $\cos\pi x=(-1)^x$, so $e^{i\pi x}=(-1)^x$.
