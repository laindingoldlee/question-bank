The number $\dfrac{(2n)!}{(n!)^2}=\dbinom{2n}{n}$ counts the $n$-element subsets of a $2n$-element set, so it is an integer. Moreover
\[
\dbinom{2n}{n}=\dfrac{2n}{n}\cdot\dfrac{(2n-1)!}{(n-1)!\,n!}=2\dbinom{2n-1}{n-1},
\]
and $\dbinom{2n-1}{n-1}$ is an integer, so $\dbinom{2n}{n}$ is even.

(Combinatorially: pair each $n$-subset of $\{1,\dots,2n\}$ with its complement, which is a different $n$-subset; so the subsets come in pairs and their number is even.) $\blacksquare$
