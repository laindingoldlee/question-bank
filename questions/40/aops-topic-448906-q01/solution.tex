The pattern has $8+17=25$ tiles, so it is a $5\times5$ square. Adding a border makes a $7\times7$ square, so the border has $49-25=24$ tiles, all black. The extended pattern has $8+24=32$ black tiles and still $17$ white tiles, so the ratio is $\boxed{\textbf{(D)}\ 32:17}$.
