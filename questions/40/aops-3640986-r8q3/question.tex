A number is square-free if no perfect square greater than$ 1$ divides it. For example, $15$ is square-free, but $63$ is not because $9$ divides $63$. Estimate the number of positive square-free integers less than or equal to $1, 000, 000$. If the true value is $t$, and your estimate is $x$, you will receive $10e^{-100(ln( \dfrac{x}{t} ))^2}$ points.
