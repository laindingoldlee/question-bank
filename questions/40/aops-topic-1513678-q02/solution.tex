For $n\ne0$,
\[
A=\dfrac{5n-16}{n}=5-\dfrac{16}{n}.
\]
For $A$ to be an integer, $n$ must divide $16$: $n\in\{\pm1,\pm2,\pm4,\pm8,\pm16\}$.
\begin{itemize}
\item If $n<0$, then $A=5+\dfrac{16}{|n|}>0$, so all five negative divisors work ($A=21,13,9,7,6$).
\item If $n>0$ we need $\dfrac{16}{n}<5$, i.e.\ $n>3.2$: $n=4,8,16$ give $A=1,3,4$, while $n=1,2$ give $A=-11,-3$.
\end{itemize}
Hence
\[
n\in\boxed{\{-16,-8,-4,-2,-1,4,8,16\}} .
\]
(If $0$ is counted as a natural number nothing changes, since $A=0$ would need $\dfrac{16}{n}=5$.)
