Let the sides be $a\le b\le c$ with $a+b+c=14$. The triangle inequality reduces to $a+b>c$, i.e. $14-c>c$, so $c\le6$. Also $c\ge\dfrac{14}{3}$, so $c\in\{5,6\}$.

\textbf{$c=6$:} $a+b=8$ with $a\le b\le6$: $(2,6)$, $(3,5)$, $(4,4)$.

\textbf{$c=5$:} $a+b=9$ with $a\le b\le5$: $(4,5)$.

\begin{asy}
usepackage("amsmath");
size(8cm);
defaultpen(fontsize(10pt));
void side(pair P,pair Q,pair G,string s){pair m=(P+Q)/2;label(s,m+0.6*unit(m-G));}
void tri(pair o,real p,real q,real r,string lp,string lq,string lr){
 real x=(p^2+q^2-r^2)/(2p); real y=sqrt(q^2-x^2);
 pair A=o,B=o+(p,0),C=o+(x,y),G=(A+B+C)/3;
 draw(A--B--C--cycle,linewidth(0.9));
 side(A,B,G,lp);side(A,C,G,lq);side(B,C,G,lr);}
tri((0,5.5),6,6,2,"$6$","$6$","$2$");
tri((8,5.5),6,5,3,"$6$","$5$","$3$");
tri((0,0),6,4,4,"$6$","$4$","$4$");
tri((8,0),5,5,4,"$5$","$5$","$4$");
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

So the triangles are $(2,6,6)$, $(3,5,6)$, $(4,4,6)$, $(4,5,5)$, and there are $\boxed{4}$ of them. (Two triangles with the same three side lengths are congruent by SSS, so each triple counts once.)
