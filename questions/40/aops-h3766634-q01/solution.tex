There are six odd elements and five even elements. An even sum requires an even number of odd elements; odd total cardinality then requires an odd number of even elements. Exactly half the subsets of a nonempty set have each cardinality parity, by toggling one fixed element. Thus there are $2^5\cdot2^4=512$ choices. The full set has odd cardinality and sum $66$, but is not proper, so subtract it. The answer is $\boxed{511}$.
