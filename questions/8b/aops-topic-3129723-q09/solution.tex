After the first block of three, exactly three songs remain unheard. Let $T$ be the number of additional blocks needed. There is one shuffle before each additional block, so the requested count is $T$. For a specified set of $j$ initially missing songs, a random three-song block avoids it with probability $q_j=\dfrac{\binom{6-j}{3}}{20}$, giving $q_1=\dfrac{1}{2},q_2=\dfrac{1}{5},q_3=\dfrac{1}{20}$. Inclusion–exclusion yields $\Pr(T>k)=3q_1^k-3q_2^k+q_3^k$ for $k\ge0$. Summing this tail gives $\mathbb E[T]=6-\dfrac{15}{4}+\dfrac{20}{19}=\dfrac{251}{76}$. Thus $\boxed{a+b=327}$.
