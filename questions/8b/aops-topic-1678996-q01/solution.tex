Let there be $c$ chickens and $2c$ cows. The legs number $2c+4\cdot2c=10c=1250$, so $c=125$. There are $\boxed{125\text{ chickens and }250\text{ cows}}$; this is the only combination. Check: $250+1000=1250$.
