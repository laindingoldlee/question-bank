The coefficients of the degree-$2015$ sum are symmetric, so terms cancel in pairs at $x=-1$. Thus $P(-1)=1$. If an integer $r\ne-1$ were a root, the integer $r+1$ would divide $P(r)-P(-1)=-1$, forcing $r=0$ or $-2$. The constant term is positive, so $0$ is not a root. At $-2$, every nonconstant term is even and the constant $1+2016!$ is odd, so the value is nonzero. Consequently there are $\boxed0$ integer roots.
