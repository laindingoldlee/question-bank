Consecutive integers are coprime, so the equation becomes $2xy=4x+3y$. If $y=x+1$, then $2x^2-5x-3=(2x+1)(x-3)=0$, giving $(x,y)=(3,4)$. If $y=x-1$, then $2x^2-9x+3=0$, whose discriminant $57$ is not a square, so it has no integer roots. The only value is $3^2+4^2=\boxed{25}$, choice B.
