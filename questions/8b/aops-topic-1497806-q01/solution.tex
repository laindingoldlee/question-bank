The number $2011$ is the $1006$th odd number, since $2011=2\cdot1006-1$. Each row holds four consecutive odd numbers, and $1006=4\cdot251+2$, so $2011$ is the second of the four numbers in row $n=252$. Row $252$ holds $2009$, $2011$, $2013$, $2015$.

Row $252$ is even, so it is written from right to left:
\[
2015,\ 2013,\ 2011,\ 2009 .
\]
So $2011$ is in column $m=3$, and $n+m=\boxed{255}$.
