First take out $x^4$:
\[x^{12}+x^{10}+x^8+x^6+x^4=x^4\left(x^8+x^6+x^4+x^2+1\right).\]
Now complete a difference of squares. Since $\left(x^4+x^2+1\right)^2=x^8+2x^6+3x^4+2x^2+1$,
\[x^8+x^6+x^4+x^2+1=\left(x^4+x^2+1\right)^2-\left(x^6+2x^4+x^2\right)=\left(x^4+x^2+1\right)^2-\left(x^3+x\right)^2,\]
so
\[x^{12}+x^{10}+x^8+x^6+x^4=\boxed{x^4\left(x^4+x^3+x^2+x+1\right)\left(x^4-x^3+x^2-x+1\right)}.\]
(Another way to see it: $x^8+x^6+x^4+x^2+1=\dfrac{x^{10}-1}{x^2-1}=\dfrac{x^5-1}{x-1}\cdot\dfrac{x^5+1}{x+1}$.)

\textbf{The quartics do not factor further.} $Q(x)=x^4+x^3+x^2+x+1$ has no integer root ($Q(1)=5$, $Q(-1)=1$), so it has no linear factor. If $Q=\left(x^2+ax+b\right)\left(x^2+cx+d\right)$ with integers, then $bd=1$, so $b=d=\pm1$, and comparing the $x^3$ and $x^2$ coefficients gives $a+c=1$ and $ac+2b=1$. For $b=1$, $ac=-1$ with $a+c=1$ has no integer solution; for $b=-1$, the $x$ coefficient $ad+bc=-(a+c)=-1\ne1$. So $Q$ is irreducible, and so is $x^4-x^3+x^2-x+1=Q(-x)$.
