$n^3-m^3=(n-m)(n^2+nm+m^2)=1331=11^3$ and $n>m\ge0$, so $n-m\in\{1,11,121,1331\}$. Put $n=m+d$; then $n^2+nm+m^2=3m^2+3dm+d^2$.

$d=1$: $3m^2+3m+1=1331$, i.e. $3(m^2+m)=1330$, impossible since $3\nmid1330$.

$d=11$: $3m^2+33m+121=121$, so $m=0$, $n=11$.

$d=121$ or $1331$: $3m^2+3dm+d^2\ge d^2>\dfrac{1331}d$, impossible.

The only solution is $\boxed{(m,n)=(0,11)}$, so there are none in positive integers.
