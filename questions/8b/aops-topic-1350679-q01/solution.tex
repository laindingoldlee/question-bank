Expand and collect terms:
\[
6x-10a+18a-63b+15a-6x=23a-63b .
\]
So the equation is equivalent to $23a-63b=0$, which does not involve $x$ at all.
\begin{itemize}
\item If $23a=63b$, the equation is true for every $x$: every real number is a solution.
\item If $23a\ne63b$, the equation is false for every $x$: there is no solution.
\end{itemize}
In particular, $x$ cannot be found from this equation; the answer is $\boxed{\text{all real }x\text{ if }23a=63b,\ \text{no }x\text{ otherwise}}$.
