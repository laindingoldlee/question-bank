The number $34685$ has $5$ digits, its left-most digit is $3$, and each pair of consecutive digits ($34$, $46$, $68$, $85$) forms a two-digit number divisible by $17$ or by $23$. An integer with $100$ digits has left-most digit $3$, and each pair of its consecutive digits forms a two-digit number divisible by $17$ or by $23$. How many such integers are there?
