A function $f$ is defined on the real numbers as follows: if $x$ is an integer, $f(x)=\dfrac x3$; if $x$ is not an integer, $f(x)$ is undefined. Starting from a number in $\{1,2,\dots,100\}$ and applying $f$ repeatedly, we stop when the output is undefined. What is the largest number of applications of $f$ needed?
