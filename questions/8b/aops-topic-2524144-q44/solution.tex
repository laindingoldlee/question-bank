Write $x=3^km$ with $3\nmid m$. The first $k$ applications give $3^{k-1}m,\dots,3m,m$, all integers; the $(k+1)$st gives $\dfrac m3$, which is not an integer; and the $(k+2)$nd is undefined. So $x$ needs exactly $k+2$ applications. For $x\le100$ the largest $k$ is $4$ (for $x=81$; $3^5=243>100$). The answer is $4+2=\boxed{6}$: $81\to27\to9\to3\to1\to\dfrac13\to$ undefined.
