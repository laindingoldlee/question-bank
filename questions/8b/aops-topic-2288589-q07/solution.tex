The three groups use different kinds of characters, so the condition is that the characters within each group are distinct. By the multiplication principle:
\begin{itemize}
\item the four digits: $10\cdot9\cdot8\cdot7=5040$ ways;
\item the three lowercase letters: $26\cdot25\cdot24=15600$ ways;
\item the three capital letters: $26\cdot25\cdot24=15600$ ways.
\end{itemize}
The number of passwords is
\[5040\cdot15600\cdot15600=\boxed{1{,}226{,}534{,}400{,}000}.\]
