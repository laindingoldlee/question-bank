While the dog runs $7$ m, the rabbit runs $5$ m, so the gap closes by $2$ m. Closing the $150$ m gap takes $\dfrac{150}{2}=75$ such stretches, so the dog runs $75\cdot7=\boxed{525\text{ m}}$ (and the rabbit $375$ m).
