Completing squares: $(y+3)^2-9-4(x-4)^2+64-91=0$, i.e.
\[\dfrac{(y+3)^2}{36}-\dfrac{(x-4)^2}{9}=1.\]
This hyperbola has centre $(4,-3)$ and a vertical transverse axis, with $a^2=36$ and $b^2=9$, so $c=\sqrt{a^2+b^2}=3\sqrt5$. The foci are $\boxed{\left(4,\,-3\pm3\sqrt5\right)}$.

\begin{asy}
usepackage("amsmath");
size(3.5cm);
defaultpen(fontsize(10pt));
import graph;
real up(real x){return -3+6*sqrt(1+(x-4)^2/9);} real dn(real x){return -3-6*sqrt(1+(x-4)^2/9);}
draw((-1.5,0)--(9.5,0),gray,Arrow(4));draw((0,-15)--(0,10),gray,Arrow(4));
draw(graph(up,-1,9),linewidth(0.8));draw(graph(dn,-1,9),linewidth(0.8));
draw((-1,7)--(9,-13),dashed);draw((-1,-13)--(9,7),dashed);
pair F1=(4,-3+3*sqrt(5)),F2=(4,-3-3*sqrt(5));dot(F1);dot(F2);dot((4,-3));
label("$F_1$",F1,E,fontsize(7pt));label("$F_2$",F2,E,fontsize(7pt));
\end{asy}
