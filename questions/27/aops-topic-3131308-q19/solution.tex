Modulo $2$, the sum condition allows zero or two odd entries. Two odd entries would make $xy+yz+zx$ odd, so all entries are even. Modulo $3$, the identity $(x+y+z)^2=x^2+y^2+z^2+2(xy+yz+zx)$ shows the sum of their squares is $0$. Thus either all are $0$ modulo $3$ or all are nonzero modulo $3$. In the latter case their sum is $0$ only when all three have the same residue. Consequently all three entries must have one common residue $0,2,$ or $4$ modulo $6$; this condition also suffices. The counts of available values in these classes are $8,9,8$, so the answer is $8^3+9^3+8^3=\boxed{1753}$.
