Write $n=2^a3^bm$ with $\gcd(m,6)=1$ and let $D$ be the number of divisors of $m$. Then
\[(a+2)(b+1)D=28,\qquad(a+1)(b+2)D=30.\]
So $D$ divides $\gcd(28,30)=2$.
\begin{itemize}
\item $D=1$: subtracting $ab+a+2b+2=28$ from $ab+2a+b+2=30$ gives $a=b+2$, then $(b+4)(b+1)=28$, so $b=3$, $a=5$. Check: $(a+1)(b+2)=6\cdot5=30$.
\item $D=2$: similarly $a=b+1$ and $(b+3)(b+1)=14$, which has no integer solution.
\end{itemize}
So $n=2^5\cdot3^3$ (times nothing else), and $6n=2^6\cdot3^4$ has $7\cdot5=\boxed{35}$ divisors.
