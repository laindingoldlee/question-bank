Use $2025=81\cdot25$. Modulo 81, $2^9=512\equiv26$, $2^{18}\equiv28$, and $2^{27}\equiv28\cdot26\equiv-1$. Since $2025=27\cdot75$, the residue is $-1\equiv80$. Modulo 25, $2^{20}\equiv1$ and $2025\equiv5\pmod{20}$, giving $2^{2025}\equiv7$. Write the answer as $80+81t$. Then $5+6t\equiv7\pmod{25}$, so $t\equiv17$. Taking $t=17$ gives $\boxed{1457}$, choice B.
