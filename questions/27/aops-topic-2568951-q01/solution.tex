Let $p=\dfrac1{86400}$ and let $K$ be the second in which the problem is solved, so $P(K=k)=(1-p)^{k-1}p$. Let $E$ be the expected value of $K$. Condition on the first second: with probability $p$ the problem is solved and $K=1$; with probability $1-p$ one second has passed and, by independence, the situation starts afresh, so the expected value is $1+E$. Hence
\[E=p\cdot1+(1-p)(1+E)\quad\Longrightarrow\quad pE=1\quad\Longrightarrow\quad E=\dfrac1p=\boxed{86400}.\]
(This uses that $E$ is finite, which holds because $\sum k(1-p)^{k-1}p$ converges.)
