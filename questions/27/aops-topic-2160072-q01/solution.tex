Count the appearances in each place value.
\begin{itemize}
\item \textbf{Units digit.} Among every $10$ consecutive integers exactly one ends in $6$, so among $1$ to $500$ there are $\dfrac{500}{10}=50$ such numbers ($6,16,\dots,496$).
\item \textbf{Tens digit.} In each block of $100$ the ten numbers $60$ to $69$ (shifted by the hundreds) have tens digit $6$, so there are $5\cdot10=50$ appearances ($60$--$69$, $160$--$169$, \dots, $460$--$469$).
\item \textbf{Hundreds digit.} None, since all the numbers are below $600$.
\end{itemize}
The total is $50+50=\boxed{100}$.
