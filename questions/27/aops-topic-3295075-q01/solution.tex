The displayed equality is $48=48$. In general, $10(a+c)+2b=acb^2$. This finite digit problem can be solved by testing $1\le a,b,c\le9$; an exact algorithm is given below. Each successful triple gives the ordered pair $(10a+b,10c+b)$, and reversing the pair is allowed.\begin{verbatim}
answers=[]
for a in range(1,10):
    for b in range(1,10):
        for c in range(1,10):
            if 10*(a+c)+2*b==a*c*b*b:
                answers.append((10*a+b,10*c+b))
print(answers)
# [(14,34),(34,14)]
\end{verbatim}
