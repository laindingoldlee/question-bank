For each choice of the first digit there are $4!=24$ integers. So positions $1$--$24$ start with $1$, positions $25$--$48$ with $2$, positions $49$--$72$ with $3$, positions $73$--$96$ with $4$, and positions $97$--$120$ with $5$.

The integers starting with $5$ in increasing order are $51234$ (97th), $51243$ (98th), $51324$ (99th), $51342$ (100th). The answer is $\boxed{51342}$.
