Each letter in the subtraction $\mathrm{HANOI}-\mathrm{IMSO}$ represents a digit, different letters represent different digits, and $H$ and $I$ are nonzero. How many possible values of $\mathrm{IMSO}$ are there such that the result of the subtraction is a three-digit number? (A student argues that the answer is $\dbinom72\cdot5\cdot4=420$; find the error.)
