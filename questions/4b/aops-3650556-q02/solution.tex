Write the digits as $a,b,c,d$ with $1\le a\le9$, $0\le b,c,d\le9$. Enumerate $a,b,c$ and set $d=12-a-b-c$, retaining it only if it is a digit. Require both specified digits to occur. The digit sum ensures divisibility by three, so divisibility by 12 requires $10c+d\equiv0\pmod4$. These tests produce $\boxed{25}$ integers. For a reproducible check, their leading-digit counts for $a=1,\ldots,9$ are $(9,4,2,2,2,2,1,1,2)$.
