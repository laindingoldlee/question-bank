These are the integers from $1$ to $999$. Write each as a three-digit string with leading zeros ($7=007$); leading zeros are not $3$, $4$ or $5$, so this does not change which numbers count, and $000$ does not count anyway.

Choose the position of the special digit ($3$ ways) and its value ($3$ ways); each of the other two positions holds one of the $7$ digits $0,1,2,6,7,8,9$. The count is
\[
3\cdot3\cdot7^2=\boxed{441}.
\]
