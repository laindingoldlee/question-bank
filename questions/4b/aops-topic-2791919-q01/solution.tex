$T>k$ means the first $k$ draws are all different: $P(T>k)=\dfrac{n(n-1)\cdots(n-k+1)}{n^k}$ for $0\le k\le n$ (and $0$ for $k>n$). Using $E[T]=\sum_{k\ge0}P(T>k)$,
\[E[T]=\sum_{k=0}^{n}\dfrac{n!}{(n-k)!\,n^k}.\]
The expected number of numbers chosen before the repeat is $E[T]-1$. For $n=3$: $1+1+\dfrac23+\dfrac29=\boxed{\dfrac{26}9}$.
