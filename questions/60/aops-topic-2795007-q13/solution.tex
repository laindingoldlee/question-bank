Call the expression $k$; we need $x\ge\dfrac{\sqrt{2011}}2$, and $k>0$ since the first root is larger. Squaring,
\[k^2=2x-2\sqrt{x^2-\dfrac{2011}4}=2x-\sqrt{4x^2-2011}.\]
So $\sqrt{4x^2-2011}=2x-k^2$ is an integer $m\ge0$, and $4x^2-m^2=2011$, i.e. $(2x-m)(2x+m)=2011$. Since $2011$ is prime and $2x+m>0$, we get $2x-m=1$, $2x+m=2011$, so $x=503$, $m=1005$. Then $k^2=1006-1005=1$, so $k=1$ works.

Answer: $x=\boxed{503}$.
