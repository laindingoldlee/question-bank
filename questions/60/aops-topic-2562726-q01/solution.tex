Write $s=a+c$ and $t=b+d$, so $s+t=63$. Then
\[ab+bc+cd=(a+c)(b+d)-ad=st-ad\le st-1.\]
Since $st=\dfrac{(s+t)^2-(s-t)^2}{4}$ and $s-t$ is odd, $st\le\dfrac{63^2-1}{4}=992$. Hence $ab+bc+cd\le991$. Equality holds for $a=d=1$, $b=31$, $c=30$: $31+930+30=991$. The maximum is $\boxed{991}$.
