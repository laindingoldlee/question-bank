Write the number as $\overline{abcd}$ with $1\le a\le9$ and $0\le b,c,d\le9$. The condition is $d=a+b$, which is a digit exactly when $a+b\le9$.

For each $a=1,\dots,9$ there are $10-a$ choices of $b$ (namely $b=0,\dots,9-a$), giving $9+8+\dots+1=45$ pairs $(a,b)$. Then $d$ is determined and $c$ is any of $10$ digits, so the count is
\[
45\cdot10=\boxed{450}.
\]
