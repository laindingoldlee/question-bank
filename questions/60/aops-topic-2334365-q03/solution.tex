\textbf{Yes.} Take $f(x)=|x|$ and $g(x)=x-|x|$ for all real $x$. Then $f(x)+g(x)=x$, a polynomial.

\emph{$f$ is not a polynomial.} Suppose $|x|=p(x)$ for all real $x$, with $p$ a polynomial. Then $p(x)-x=0$ for all $x\ge0$, so the polynomial $p(x)-x$ has infinitely many roots and is identically zero, i.e. $p(x)=x$. But $p(-1)=|-1|=1\ne-1$, a contradiction.

\emph{$g$ is not a polynomial.} Suppose $x-|x|=q(x)$ for all real $x$. Then $q(x)=0$ for all $x\ge0$, so $q$ is identically zero; but $q(-1)=-1-1=-2\ne0$, a contradiction. $\blacksquare$
