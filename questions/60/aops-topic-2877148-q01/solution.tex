We need $x>0$ for the inner logarithm, and $\log_{\dfrac15}x>0$ for the outer one. Since the base $\dfrac15$ is less than $1$, $\log_{\dfrac15}x>0$ exactly when $0<x<1$. So the domain is $\boxed{(0,1)}$.

As $x$ runs over $(0,1)$, $\log_{\dfrac15}x$ takes every value in $(0,\infty)$, and $\log_6$ maps $(0,\infty)$ onto all real numbers. So the range is $\boxed{\mathbb{R}}$.
