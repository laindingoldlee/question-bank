\textbf{Domain.} The denominator vanishes only at $x=1$, so the domain is $\boxed{(-\infty,1)\cup(1,\infty)}$.

\textbf{Range.} Put $t=x-1\ne0$. Then
\[f(x)=\dfrac{(t-2)^2}{t}=t-4+\dfrac4t.\]
For $t>0$, $t+\dfrac4t\ge4$ (AM-GM, with equality at $t=2$), so $f\ge0$; and every value $y\ge0$ is attained, since $t+\dfrac4t=y+4$ is the quadratic $t^2-(y+4)t+4=0$, whose discriminant $(y+4)^2-16\ge0$ and whose roots have product $4>0$ and positive sum. For $t<0$, $t+\dfrac4t\le-4$, so $f\le-8$, and in the same way every value $y\le-8$ is attained. Values strictly between $-8$ and $0$ are not attained. The range is
\[\boxed{(-\infty,-8]\cup[0,\infty)}.\]
