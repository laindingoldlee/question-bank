A diagonal joins two vertices that are not neighbours. From each of the $7$ vertices there are $7-3=4$ diagonals (to every vertex except itself and its two neighbours; red in the figure for $V_1$). This counts every diagonal twice, once from each end, so there are
\[\dfrac{7\cdot4}{2}=\boxed{14}\]
diagonals. (Equivalently, $\dbinom72-7=21-7=14$: all pairs of vertices minus the $7$ sides.)

\begin{asy}
usepackage("amsmath");
size(4cm);
defaultpen(fontsize(10pt));
pair[] V; for(int k=0;k<7;++k) V.push(dir(90+360*k/7));
for(int i=0;i<7;++i) for(int j=i+2;j<7;++j) if(!(i==0 && j==6)) draw(V[i]--V[j],(i==0)?red+linewidth(0.9):gray);
draw(V[0]--V[1]--V[2]--V[3]--V[4]--V[5]--V[6]--cycle,linewidth(1));
for(int k=0;k<7;++k) dot(V[k]);
label("$V_1$",V[0],N);
\end{asy}
