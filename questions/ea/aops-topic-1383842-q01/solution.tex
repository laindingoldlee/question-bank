The last two digits of a number are its remainder modulo $100$, so work modulo $100$ and find when the powers of $3$ repeat:
\[
3^5=243\equiv43,\qquad 3^{10}\equiv43^2=1849\equiv49,\qquad 3^{20}\equiv49^2=2401\equiv1\pmod{100}.
\]
So the last two digits of $3^n$ repeat with period $20$, and $3^n\equiv3^{\,n\bmod 20}$. Since $2016=20\cdot100+16$,
\[
3^{2016}\equiv3^{16}=3^{10}\cdot3^{5}\cdot3\equiv49\cdot43\cdot3\equiv49\cdot29=1421\equiv21\pmod{100}.
\]
The last two digits are $21$, so the tens digit is $\boxed{2}$. For any exponent $n$, reduce $n$ modulo $20$ and compute $3^{\,n\bmod20}$ modulo $100$ in the same way.
