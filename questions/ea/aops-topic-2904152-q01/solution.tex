Sam runs $100$ m in the time Sal runs $90$ m. Sam needs $\dfrac{110}{100}=1.1$ units of time, while Sal needs $\dfrac{100}{90}\approx1.11$. So $\boxed{\text{Sam wins}}$, by about $1$ m (when Sam finishes, Sal has run $99$ m).
