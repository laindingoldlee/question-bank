Since $y\ge3$, $x^3<121$, so $x\le4$.
\begin{itemize}
\item $x=2$: the sum is $2^{y+1}-1$, and $122$ is not a power of $2$.
\item $x=3$: $1+3+9+27+81=121$, so $y=4$ works.
\item $x=4$: the sums are $1,5,21,85,341,\dots$, skipping $121$.
\end{itemize}
So $\boxed{x=3,\ y=4}$.
