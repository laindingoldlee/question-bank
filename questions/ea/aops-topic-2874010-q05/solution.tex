It would be $\dfrac{100}{0}$, which is undefined in real arithmetic: no real $x$ solves $0x=100$. An application may display an infinity symbol by convention, but it is not a real-valued quotient supplied by the formula. Thus $\boxed{\text{the ratio is undefined as a real number}}$.
