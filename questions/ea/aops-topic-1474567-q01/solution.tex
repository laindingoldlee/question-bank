Treat the two adjacent letters as one block. The plate then consists of the block and $4$ digits, which are $5$ items in a row. The block can occupy any of the $5$ positions. The letters in the block can be chosen in $26^2$ ways, and the $4$ digits in $10^4$ ways. Different choices give different plates, so the number of plates is
\[
5\times10^4\times26^2 ,
\]
answer $\boxed{\textbf{(C)}}$.
