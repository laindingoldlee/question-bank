Each term telescopes: $\dfrac{k-1}{k!}=\dfrac{k}{k!}-\dfrac{1}{k!}=\dfrac{1}{(k-1)!}-\dfrac{1}{k!}$. So
\[
\sum_{k=2}^{n}\dfrac{k-1}{k!}=\dfrac{1}{1!}-\dfrac{1}{n!}\to\boxed{1}.
\]
