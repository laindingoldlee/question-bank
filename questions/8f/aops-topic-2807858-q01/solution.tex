The thousands digit is $1$ to $5$, the middle digits $0$ to $5$, the units digit $0$, $2$ or $4$: $5\cdot6\cdot6\cdot3=540$ numbers.

Each thousands digit occurs $6\cdot6\cdot3=108$ times; each hundreds or tens digit $5\cdot6\cdot3=90$ times; each units digit $5\cdot6\cdot6=180$ times. The sum is
\[108\cdot15\cdot1000+90\cdot15\cdot100+90\cdot15\cdot10+180\cdot(0+2+4)=1620000+135000+13500+1080=\boxed{1769580}.\]
The attempted solution treated the units digit like the others ($90\cdot(1+\cdots+5)$); only the even digits $0,2,4$ can be in the units place, each $180$ times.
