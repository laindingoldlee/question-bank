Enumerate each valid Gregorian date exactly once and compare its digit string to its reverse:
\begin{verbatim}
from datetime import date
count = 0
for year in range(2000,2100):
    for month in range(1,13):
        for day in range(1,32):
            try:
                date(year,month,day)
            except ValueError:
                continue
            s = str(month)+str(day)+f"{year%100:02d}"
            count += (s == s[::-1])
print(count)
# 306
\end{verbatim}
Invalid dates are rejected, and all others are checked once, proving the answer $\boxed{306}$.
