Let there be $n$ numbers with average $m$. Removing a number equal to the current average does not change the average, so after removing $85$ the average is $74$; hence $m=75$. Then $nm-85=(n-1)\cdot74$, i.e. $75n-85=74n-74$, giving $n=\boxed{11}$.
