The terms in odd positions appear to be $1,3,5,7,\dots$ and those in even positions $2,0,-2,\dots$. We prove $a_{2m-1}=2m-1$ and $a_{2m}=4-2m$ by induction. It holds for $a_1,\dots,a_4$. If it holds up to $a_{n-1}$:
\begin{itemize}
\item for $n=2m$ even: $a_{2m}=a_{2m-3}+a_{2m-2}-a_{2m-1}=(2m-3)+(6-2m)-(2m-1)=4-2m$;
\item for $n=2m+1$ odd: $a_{2m+1}=a_{2m-2}+a_{2m-1}-a_{2m}=(6-2m)+(2m-1)-(4-2m)=2m+1$.
\end{itemize}
So $a_{2010}=4-2010=\boxed{-2006}$, choice (A).
