Let $f$ be the number of field goals and $t$ the number of touchdowns:
\[
f+t=36,\qquad 3f+7t=212 .
\]
Substituting $t=36-f$: $3f+252-7f=212$, so $4f=40$ and $f=\boxed{10}$ (and $t=26$; check: $30+182=212$).

The student's idea is right, but the last step is missing. If all $36$ scores were touchdowns the total would be $252$, which is $40$ too many. Replacing one touchdown by a field goal lowers the total by $7-3=4$ points, not by $1$, so the number of field goals is $\dfrac{40}{4}=10$, not $40$.
