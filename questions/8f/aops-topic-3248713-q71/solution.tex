We prove $T_n=n$ by induction. It holds for the first two terms. If $T_{n-1}=n-1$ and $T_n=n$, then $T_{n+1}=\dfrac{n^2-1}{n-1}=n+1$, since $n\ge2$. This determines every term, so $\boxed{T_{2023}=2023}$.
