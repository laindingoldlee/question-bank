Work modulo $4$.
\begin{itemize}
\item If $x\in A$, then $x=5^a-3$. Since $5\equiv1\pmod4$, $5^a\equiv1$, so $x\equiv1-3\equiv2\pmod4$.
\item If $x\in B$, then $5x=13^b-1$. Since $13\equiv1\pmod4$, $13^b-1\equiv0$, so $5x\equiv x\equiv0\pmod4$.
\end{itemize}
No integer is congruent to both $2$ and $0$ modulo $4$, so
\[A\cap B=\boxed{\varnothing}.\]
(This holds whether or not $0\in\mathbb N$.)
