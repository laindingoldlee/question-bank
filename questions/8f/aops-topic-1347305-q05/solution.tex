Jenny's factorisation $x^9-y^9=(x-y)\left(x^8+x^7y+\cdots+xy^7+y^8\right)$ is correct, so Gherko is \textbf{not} right that it is wrong. It is, however, not complete: the second factor still factors.

Use $x^9-y^9=(x^3)^3-(y^3)^3$:
\[
x^9-y^9=(x^3-y^3)\left(x^6+x^3y^3+y^6\right)=(x-y)\left(x^2+xy+y^2\right)\left(x^6+x^3y^3+y^6\right).
\]
The quadratic $x^2+xy+y^2$ has no rational linear factors (its discriminant $1-4<0$), and $x^6+x^3y^3+y^6$ is also irreducible over the integers, so the complete factorisation is
\[
\boxed{x^9-y^9=(x-y)\left(x^2+xy+y^2\right)\left(x^6+x^3y^3+y^6\right)}.
\]
