Positivity gives $f(m)\le m$ for $m\ge2$. At $n=1$, $f(2)$ is $1$ or $2$. If $f(2)=1$, the $n=2$ equation gives $f(1)+f(3)=4$, so $f(1)\in\{1,2,3\}$. Each is impossible: values $1,2$ give $f(f(1))+f(2)=2$, and value $3$ forces $f(3)=1$, again giving $2$. Hence $f(2)=2$, and then $f(3)=2$. Inductively for $m\ge3$, $2\le f(m-1)\le m-1$ implies $f(f(m-1))\le m-1$, so $f(m)\ge2$. Thus only $f(1)$ can equal $1$. Since the $n=1$ equation gives $f(f(1))=1$, we conclude $f(1)=1$. The recurrence now determines each value, since $f(n)\le n$. Its values at $1$ through $20$ are $1,2,2,3,4,4,5,5,6,7,7,8,9,9,10,10,11,12,12,13$. Therefore $\boxed{f(20)+f(16)=13+10=23}$.
