Write everything as powers.

\textbf{Numerator.} $81\sqrt[3]3=3^4\cdot3^{\dfrac{1}{3}}=3^{\dfrac{13}{3}}$, so $\sqrt{81\sqrt[3]3}=3^{\dfrac{13}{6}}$. Then
\[
243\cdot3^{\dfrac{13}{6}}=3^{5+\dfrac{13}{6}}=3^{\dfrac{43}{6}},\qquad \sqrt{3^{\dfrac{43}{6}}}=3^{\dfrac{43}{12}},
\]
so the numerator is $\dfrac{43}{12}$.

\textbf{Denominator.} $\sqrt[4]{64}=2^{\dfrac{6}{4}}=2^{\dfrac{3}{2}}$, so $\log_2\sqrt[4]{64}=\dfrac{3}{2}$, and $\log_ee^{-10}=-10$. The denominator is $\dfrac{3}{2}-10=-\dfrac{17}{2}$.

Hence the value is
\[
\dfrac{\dfrac{43}{12}}{-\dfrac{17}{2}}=-\dfrac{43}{12}\cdot\dfrac{2}{17}=\boxed{-\dfrac{43}{102}}.
\]
