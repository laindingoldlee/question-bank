Because $TB=TC$, triangle $BCT$ has base angles 29 degrees, so $\angle ABT=87^\circ-29^\circ=58^\circ$. Angle $A$ is 64 degrees, giving $\angle ATB=58^\circ$. Thus $AB=AT$, and $AB+BT=AT+TC=AC=\boxed{37}$.
\begin{asy}
usepackage("amsmath");
size(7cm);
pair A=(0,0),C=(37,0),B=37*sin(29*pi/180)/sin(87*pi/180)*dir(64);real tx=(37*37-abs(B)^2)/(2*(37-B.x));pair T=(tx,0);draw(A--B--C--cycle);draw(B--T,blue);label("$A$",A,SW);label("$B$",B,N);label("$C$",C,SE);label("$T$",T,S);
\end{asy}
