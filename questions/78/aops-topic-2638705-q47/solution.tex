Committee proof: a subset of an $n$-person set is chosen by independently including or excluding each person, giving $2^n$ subsets. Grouping them by size gives $\sum\binom nk$. Path proof: starting at the top of Pascal's triangle, make $n$ steps, each down-left or down-right. There are $2^n$ paths. Exactly $\binom nk$ paths end at position $k$ of row $n$, because one chooses which $k$ steps go right. Summing over endpoints gives the same identity.
