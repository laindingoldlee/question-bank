The polynomial changes sign when any two of $a,b,c$ are interchanged, so it is divisible by $(a-b)(b-c)(c-a)$. Its degree is $4$, so the quotient is a symmetric homogeneous linear polynomial, hence a constant multiple of $a+b+c$. Substituting $(a,b,c)=(1,2,0)$ gives value $6$ for both the original expression and $(a-b)(b-c)(c-a)(a+b+c)$, so the constant is $1$. Thus
\[
\boxed{a(b-c)^3+b(c-a)^3+c(a-b)^3=(a-b)(b-c)(c-a)(a+b+c)}.
\]
