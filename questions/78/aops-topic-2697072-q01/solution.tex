If there are $k$ terms, each ends in $7$, so the sum ends in the last digit of $7k$, which is $0$ only when $10\mid k$; so $k=10$. Then the sum is even and a multiple of $5$. It is also a multiple of $3$, since its digit sum is congruent to $7\cdot12$, which is divisible by $3$ (each term made of $L$ sevens is $\equiv7L\pmod3$). So we need exactly $9$ plus signs in the $11$ gaps: $\dbinom{11}{9}=\boxed{55}$ ways.
