The sum equals $\boxed{2^n}$.

\emph{Counting proof.} Count the subsets of an $n$-element set. Each element is either in a subset or not, so there are $2^n$ subsets. On the other hand, $\dbinom nk$ of them have exactly $k$ elements, for $k=0,1,\dots,n$; adding over $k$ counts every subset exactly once.

\emph{Algebraic proof.} By the binomial theorem, $(1+x)^n=\sum_{k=0}^n\dbinom nkx^k$; put $x=1$. $\blacksquare$

For example, for $n=4$: $1+4+6+4+1=16=2^4$.
