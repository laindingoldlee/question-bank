Independent generators return uniformly random elements of $A=\{12,24,36,48,60\}$, $B=\{15,30,45,60\}$, and $C=\{20,40,60\}$. Use them in repeating order $A,B,C$ for thirty draws. After each draw record the running total. What is the expected number of recorded multiples of $60$?
