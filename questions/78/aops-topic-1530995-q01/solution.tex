Every digit is one of $1,\dots,6$. A number formed this way exceeds $400$ exactly when its first digit is $4$, $5$ or $6$: if the first digit is $4$, the number is at least $411>400$, and if it is $1$, $2$ or $3$, the number is below $400$. So there are $3$ choices for the first digit and $6$ for each of the others:
\[
3\cdot6\cdot6=\boxed{108}.
\]
