Six of Jupiter's moons have a race: Io, Ganymede, Callisto, Thebe, Metis and Cyllene. There are no ties, and
\begin{itemize}
\item the winner's name starts with C;
\item each moon with the longest name finished ahead of each moon with the shortest name, and not directly next to it;
\item the two moons with five-letter names finished next to each other;
\item Callisto finished ahead of Io but behind Cyllene;
\item Thebe finished ahead of Metis.
\end{itemize}
Find all possible finishing orders.
