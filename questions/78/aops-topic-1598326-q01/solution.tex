A descending number is determined by its set of digits: any $3$ distinct digits from $0,1,\dots,9$, written in decreasing order, form a $3$-digit descending number (the first digit is the largest, so it is not $0$). Conversely, every $3$-digit descending number has $3$ distinct digits. Hence there are
\[
\binom{10}{3}=\boxed{120}
\]
such numbers (from $210$ up to $987$).
