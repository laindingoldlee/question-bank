Set $a=f(1)\in\mathbb Q$. For every integer $p$, $f(p)=pa$. If $x=\dfrac{p}{q}$ with integer $p$ and positive integer $q$, the condition gives $qf(\dfrac{p}{q})=f(p)=pa$. Therefore $f(x)=ax$. Conversely every function $\boxed{f(x)=ax,\ a\in\mathbb Q}$ satisfies the condition directly.
