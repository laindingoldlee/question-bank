A student wrote the following proof of Ptolemy's theorem for a convex quadrilateral $ABCD$ inscribed in a circle, namely $AB\cdot CD+BC\cdot AD=AC\cdot BD$.

\begin{quote}
Locate a point $P$ such that $\angle ACB=\angle PCD$. Because angles $BAC$ and $BDC$ subtend the same arc, $\angle BAC=\angle BDC$. Because $\angle BAC=\angle BDC$ and $\angle ACB=\angle PCD$, we have $\triangle ABC\sim\triangle DPC$. Therefore $\dfrac{CD}{PD}=\dfrac{AC}{AB}$, so $CD\cdot AB=PD\cdot AC$. Using a similar method we have $\triangle BCP\sim\triangle ACD$, using $\angle BCP=\angle ACD$. This gives $BC\cdot AD=AC\cdot BM$. Adding, $CD\cdot AB+BC\cdot AD=AC\cdot BP+PD\cdot AC=AC\cdot BD$.
\end{quote}
Point out the gaps and errors in this proof, and write a complete, correct proof.
