The overall factor is
\[F=\dfrac{2\cdot4\cdots100}{3\cdot5\cdots99}=\dfrac{(2\cdot4\cdots100)^2}{100!}=\dfrac{\left(2^{50}\cdot50!\right)^2}{100!}=\dfrac{2^{100}}{\dbinom{100}{50}}.\]
So the starting number is
\[\dfrac{200}{F}=\boxed{\dfrac{200\dbinom{100}{50}}{2^{100}}}\approx15.92.\]
(Since $\dbinom{2n}{n}\approx\dfrac{4^n}{\sqrt{\pi n}}$, this is about $\dfrac{200}{\sqrt{50\pi}}\approx15.96$, a good check.)
