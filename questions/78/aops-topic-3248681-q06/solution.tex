The first two congruences say $n\equiv-2\pmod{45}$, so $n=45k-2$. Modulo four this requires $k-2\equiv2$, hence $k\equiv0\pmod4$. Thus $n\equiv178\pmod{180}$, and the minimum is $\boxed{178}$.
