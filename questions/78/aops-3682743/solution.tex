Write $a=BC,c=AB$. The sine rule gives $\sin C=\dfrac{c\sin A}{a}$, the same value in both triangles. Since both $C,C\prime$ lie strictly between zero and $90^\circ$, sine is injective there, so $C=C\prime$. Then the remaining angles agree, and the equal included side $AB=A\prime B\prime$ gives congruence by ASA. Without acuteness, supplementary choices for $C$ explain the usual SSA ambiguity.
