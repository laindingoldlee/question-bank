Map $(a,b,c)\mapsto(a,\ b+1,\ c+2)$. This is a bijection from triples with $0\le a\le b\le c\le11$ onto triples with $0\le a<b+1<c+2\le13$, i.e. onto $3$-element subsets of $\{0,1,\dots,13\}$ (the inverse subtracts $0,1,2$ from the elements in increasing order). So the count is $\binom{14}3=\boxed{364}$, which agrees with the casework $\binom{12}3+2\binom{12}2+\binom{12}1$.
