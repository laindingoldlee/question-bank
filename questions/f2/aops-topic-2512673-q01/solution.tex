\textbf{(a)} $n\mapsto\{n\}$ is one-to-one: different numbers give different one-element sets.

\textbf{(b)} Let $f:\mathbb N\to\mathcal P(\mathbb N)$ be any function. Define
\[D=\{n\in\mathbb N:\ n\notin f(n)\}.\]
Suppose $D=f(m)$ for some $m$. If $m\in D$, then by the definition of $D$, $m\notin f(m)=D$; if $m\notin D=f(m)$, then by the definition $m\in D$. Both cases are contradictory, so $D$ is not a value of $f$. Hence no function from $\mathbb N$ to $\mathcal P(\mathbb N)$ is onto, and in particular none is a bijection. $\blacksquare$

\textbf{(c)} Two sets have the same size if there is a bijection between them, and $A$ is at most as big as $B$ if there is a one-to-one function from $A$ to $B$. By (a), $\mathcal P(\mathbb N)$ is at least as big as $\mathbb N$ (so it is infinite), and by (b) it is not the same size. So its size is strictly bigger than $\aleph_0$.

The argument in (b) works for every set $S$: no function from $S$ to $\mathcal P(S)$ is onto (replace $\mathbb N$ by $S$). So $\mathcal P(\mathcal P(\mathbb N))$ is bigger still, and so on: there is no largest infinite size.
\[\boxed{\text{Yes: }\mathcal P(\mathbb N)\text{ is strictly bigger than }\aleph_0.}\]
