Write the number as $\overline{20xy}$. The first pair gives $2$, which is prime. We need $x=0+x$ prime, so $x\in\{2,3\}$ (here $x\in\{2,3,4\}$).
\begin{itemize}
\item $x=2$ ($2021$--$2029$): $2+y$ prime for $y=1,3,5,9$: $4$ numbers.
\item $x=3$ ($2030$--$2039$): $3+y$ prime for $y=0,2,4,8$: $4$ numbers.
\end{itemize}
The answer is $\boxed{8}$.
