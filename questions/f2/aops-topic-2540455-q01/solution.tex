Let $N$ be the number of flips. We need more than $k$ flips exactly when the first $k$ flips are all tails, so $P(N>k)=(1-p)^k$ for $k\ge0$. Since $N$ is a positive integer, $N=\sum_{k\ge0}\left[N>k\right]$ (it counts the values $k=0,1,\dots,N-1$), so
\[E[N]=\sum_{k=0}^{\infty}P(N>k)=\sum_{k=0}^{\infty}(1-p)^k=\dfrac{1}{1-(1-p)}=\boxed{\dfrac1p}.\]
(Another way: the first flip is heads with probability $p$; otherwise one flip is used up and the situation starts over, so $E=1+(1-p)E$, again giving $E=\dfrac1p$.)
