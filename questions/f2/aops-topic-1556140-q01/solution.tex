The expression equals $\dfrac{4a^2+15b^2}{4ab}$, so we need $4ab\mid4a^2+15b^2$.

\textbf{$a\mid15$.} $a$ divides $4a^2+15b^2$, hence $a\mid15b^2$, and $\gcd(a,b)=1$ gives $a\mid15$. In particular $a$ is odd.

\textbf{$b\mid4$.} Similarly $b\mid4a^2$ and $\gcd(a,b)=1$ give $b\mid4$.

\textbf{$b=2$.} If $b=1$, then $4a^2+15$ is odd but $4ab$ is even. If $b=4$, we need $16a\mid4a^2+240$, i.e.\ $4a\mid a^2+60$; but $a^2+60$ is odd. So $b=2$, and the condition is $8a\mid4a^2+60$, i.e.\ $2a\mid a^2+15$. This holds for every odd $a\mid15$: $a^2+15$ is even and divisible by $a$, and $\gcd(2,a)=1$.

So $(a,b)=(1,2),(3,2),(5,2),(15,2)$, giving the values $8$, $4$, $4$ and $8$ of the expression. There are $\boxed{4}$ pairs.
