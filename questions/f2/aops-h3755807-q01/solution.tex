Permutations of the same decimal digits have the same digit sum, and hence the same residue modulo 9. Thus $3n\equiv4n\pmod9$, so $9\mid n$. The smallest three-digit multiple of 9 is 108. It works because $3(108)=324$ and $4(108)=432$, which are digit permutations. Therefore the answer is $\boxed{108}$.
