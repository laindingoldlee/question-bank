The number is even, so $2$ divides it. It is also divisible by $3$, since both summands are. Modulo $5$, $3^{222}\equiv3^2\equiv4$ and $111\equiv1$, so $5$ divides it. Since $2,3,5$ are the three smallest primes of all, these are exactly the requested divisors: $\boxed{2,3,5}$.
