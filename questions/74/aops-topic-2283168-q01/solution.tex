\textbf{$n=2$ works:} $\log_2(2!)=\log_22=1$, and $\dfrac{5!}{1}=120$.

\textbf{No $n\ge3$ works.} Suppose $\log_n(n!)$ were rational, say $\dfrac {p}{q}$ with positive integers $p,q$. Then $n!=n^{\dfrac {p}{q}}$, so $(n!)^q=n^p$. For $n\ge3$, the number $n-1\ge2$ has a prime factor $\ell$; it divides $(n-1)!$ and hence $n!$, but it does not divide $n$, because $\gcd(n-1,n)=1$. Then $\ell$ divides $(n!)^q$ but not $n^p$, a contradiction. So for $n\ge3$ the number $L=\log_n(n!)$ is irrational. (It is positive, since $n!>1$.)

If $\dfrac{(n+3)!}{L}=m$ were an integer, then $L=\dfrac{(n+3)!}{m}$ would be rational, which is impossible. Hence the only value is $\boxed{n=2}$ (and the sum of all possible values of $n$ is $2$).
