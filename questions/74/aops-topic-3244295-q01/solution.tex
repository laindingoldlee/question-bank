Each maximal monochromatic run must have length at least two. Compositions of seven into such parts have one run ($1$ possibility), two runs ($2+5,3+4,4+3,5+2$: $4$), or three runs (permutations of $2,2,3$: $3$). There are two choices for the first run colour, and subsequent colours alternate. Thus $\boxed{2(1+4+3)=16}$.
