For a nonnegative integer $k$, $\left\lfloor\log_3n\right\rfloor=k$ exactly when $3^k\le n<3^{k+1}$. Since $3^6=729<1000<2187=3^7$, the even values of $k$ that occur are $0,2,4,6$:
\begin{itemize}
\item $k=0$: $1\le n\le2$, which is $2$ integers;
\item $k=2$: $9\le n\le26$, which is $18$ integers;
\item $k=4$: $81\le n\le242$, which is $162$ integers;
\item $k=6$: $729\le n\le999$, which is $271$ integers (the interval is cut off at $999$).
\end{itemize}
The total is $2+18+162+271=\boxed{453}$.
