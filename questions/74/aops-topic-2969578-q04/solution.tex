$f(2)=5$, $f(5)=11$, $f(11)=23$, $f(23)=5$. So after the first step the values cycle $5,11,23$ with period $3$: $f^n(2)=5,11,23$ for $n\equiv1,2,0\pmod3$. Since $2022\equiv0$, $f^{2022}(2)=\boxed{23}$.
