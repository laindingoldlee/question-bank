By the specified extension and recurrence, $\left(\dfrac{1}{2}\right)!=\Gamma\left(\dfrac{3}{2}\right)=\dfrac{1}{2}\Gamma\left(\dfrac{1}{2}\right)=\boxed{\dfrac{\sqrt\pi}{2}}$. The usual finite-product definition for integer factorials alone does not define a half-factorial; the gamma extension has been explicitly supplied.
