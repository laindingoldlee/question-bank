$\sqrt{x}$ is the nonnegative real number whose square is $ x $ and is defined over the reals only for $ x\ge0 $. For every real $ x $, $\sqrt{x^2}=|x|$, so the equation says $ y=|x|$. For example $\sqrt{x}=-1 $ has no real solution, but squaring gives $ x=1 $; this is extraneous because substitution gives $ 1=-1 $. Squaring can lose sign information, so candidates must be checked in the original equation.
