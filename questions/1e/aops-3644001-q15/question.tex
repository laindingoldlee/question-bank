A permutation of a set of $n$ integers is any arrangement of its elements in a specific order. For example, permutations of the list $(1, 2, 3)$ include $(1, 3, 2)$ and $(3, 2, 1)$. Let a permutation $(a_1, a_2, a_3, ..., a_n)$ of the positive integers from $1$ to $n$, inclusive, be a katamari if, for all $1 \le i \le n$, the inequality $a_i < 2 + a_1 + a_2 + a_3 +... + a_{i-1}$ holds. For example, the permutation $(1, 2, 3, 4, 5, 7, 6)$ is a katamari but $(5, 4, 1, 2, 3)$ is not. Compute the number of permutations of $(1, 2, 3,,,,, 9)$ that are katamaris.
