We have $10!=2^8\cdot3^4\cdot5^2\cdot7$. Writing $M=10!$,
\[(10!)^{M}=2^{8M}\cdot3^{4M}\cdot5^{2M}\cdot7^{M},\]
so the number of positive divisors is
\[d=(8M+1)(4M+1)(2M+1)(M+1).\]
Since $210=2\cdot3\cdot5\cdot7$ divides $M=10!$, each factor is $\equiv1\pmod{210}$, and so $d\equiv1\pmod{210}$. The remainder is $\boxed{1}$.
