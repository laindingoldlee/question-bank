\begin{enumerate}
\item[1.] Order matters (first place differs from second place): $n(n-1)(n-2)(n-3)(n-4)=\boxed{\dfrac{n!}{(n-5)!}}$ ways.
\item[3.] Order does not matter: $\dbinom72=\boxed{21}$.
\item[4.] Order does not matter: $\dbinom54=\boxed{5}$.
\item[6.] Order matters, and dots and dashes may repeat, so this is neither a permutation nor a combination of distinct objects: a signal is a sequence of $1$ to $4$ symbols, each of $2$ kinds, giving $2+2^2+2^3+2^4=\boxed{30}$ signals.
\item[7.] Order does not matter: $\dbinom62=\boxed{15}$.
\item[9.] Order does not matter: $\dbinom42=\boxed{6}$.
\item[10.] Order does not matter: $\dbinom{40}{5}=\dfrac{40\cdot39\cdot38\cdot37\cdot36}{120}=\boxed{658008}$.
\end{enumerate}
In general, use permutations when the selected objects get different roles or positions (as in item 1), and combinations when only the set chosen matters.
