In base ten, $0.4\overline2_8=\dfrac{4}{8}+\dfrac{2}{64}\cdot\dfrac{1}{1-\dfrac{1}{8}}=\dfrac{1}{2}+\dfrac{1}{28}=\dfrac{15}{28}$, which is in lowest terms. In base $8$, $15=17_8$ and $28=34_8$, so the fraction is $\boxed{\dfrac{17_8}{34_8}}$.
