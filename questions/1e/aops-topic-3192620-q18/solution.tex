For each integer in the stated finite range, inspect its ordinary binary representation without leading zeros. The following exhaustive algorithm tests the two conditions directly.\begin{verbatim}
ans=[]
for n in range(1,2021):
 s=bin(n)[2:]
 if '11' not in s and 2*s.count('1')>=len(s):ans.append(n)
print(len(ans))
\end{verbatim}
Each integer is tested once, so the required count is $\boxed{21}$.
