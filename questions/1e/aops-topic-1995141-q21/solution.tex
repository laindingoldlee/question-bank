Let $p(x)=x^{2020}+2x^{2019}+\cdots+2021=\sum_{k=0}^{2020}(k+1)x^{2020-k}$. Since $p$ is monic, $p(x)=\prod_{i}(x-r_i)$, so
\[
\prod_i(r_i+1)=\prod_i\bigl(-(-1-r_i)\bigr)=(-1)^{2020}p(-1)=p(-1).
\]
Now $(-1)^{2020-k}=(-1)^k$, so
\[
p(-1)=\sum_{k=0}^{2020}(k+1)(-1)^k=1-2+3-4+\cdots-2020+2021=1010\cdot(-1)+2021=\boxed{1011}.
\]
