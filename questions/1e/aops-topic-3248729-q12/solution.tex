Let $a_n$ count length-$n$ strings with no consecutive heads. Such a string ends in $T$ after any valid length-$n-1$ string, or in $TH$ after any valid length-$n-2$ string. Thus $a_n=a_{n-1}+a_{n-2}$ with $a_0=1,a_1=2$. The values through $n=6$ are $1,2,3,5,8,13,21$. Therefore the probability is $\boxed{1-\dfrac{21}{64}=\dfrac{43}{64}}$.
