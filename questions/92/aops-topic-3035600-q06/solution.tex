If $\sqrt2=\dfrac{a}{b}$ in lowest terms with positive integers $a,b$, then $a^2=2b^2$, so $a$ is even. Write $a=2c$; then $b^2=2c^2$, forcing $b$ even too. This contradicts the fraction being reduced.
