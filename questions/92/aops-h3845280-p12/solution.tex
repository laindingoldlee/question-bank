The qualifying integers are $3(N+1)$ times positive odd integers. The first such integer exceeds $N$. If $N=0$, the interval contains $600$ qualifying positive integers, so it does not work. For $N>0$, exactly $N$ qualify if and only if
\[
3(N+1)(2N-1)\le3600-N<3(N+1)(2N+1).
\]
Equivalently $6N^2+4N\le3603$ and $6N^2+10N>3597$. The first forces $N\le24$ (it fails at $25$ and increases thereafter); the second forces $N\ge24$ (it fails at $23$ and is increasing). At $N=24$ both hold. Hence $\boxed{N=24}$.
