When Carla catches up, Brian has run for $12$ minutes, which is $\dfrac{1}{5}$ hour, so he has covered $5\cdot\dfrac{1}{5}=1$ mile. Carla covers the same $1$ mile in $10$ minutes, i.e.\ in $\dfrac{1}{6}$ hour, so her speed is $1\div\dfrac{1}{6}=\boxed{6}$ mi/h.
