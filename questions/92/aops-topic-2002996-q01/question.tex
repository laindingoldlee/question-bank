Five rows of bricks are stacked as in the figure: each row contains $5$ bricks numbered $1$ to $5$ from left to right, rows $1$, $3$, $5$ are aligned, and rows $2$, $4$ are shifted right by half a brick. Thus brick $k$ of row $2$ or row $4$ touches bricks $k$ and $k+1$ of each neighbouring row (brick $5$ touches only brick $5$). Two bricks in adjacent rows are \emph{adjacent} if they touch along part of an edge.

\begin{asy}
usepackage("amsmath");
size(6cm);
defaultpen(fontsize(10pt));
real w=2,h=1;
for(int r=0;r<5;++r){
  real off=(r%2==1)?1:0;
  for(int k=0;k<5;++k){
    pair p=(off+k*w,-r*h);
    draw(p--p+(w,0)--p+(w,h)--p+(0,h)--cycle);
    label("$"+string(k+1)+"$",p+(w/2,h/2),fontsize(8pt));
  }
  label("row "+string(r+1),(-0.3,-r*h+h/2),W,fontsize(8pt));
}
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

In how many ways can Mario choose five bricks, one in each row, so that any two bricks chosen in adjacent rows are adjacent?
