The numbers $1$ to $9$ use $1+2+\cdots+9=45$ digits. Each two-digit number $n$ is written $n$ times and uses $2n$ digits, so after finishing $m$ (with $10\le m\le99$) the total is
\[45+2(10+11+\cdots+m)=45+m(m+1)-90.\]
For $m=44$ this is $45+1980-90=1935$, and for $m=45$ it is $2025$. So the $2005$th digit is the $2005-1935=70$th digit of the string $454545\ldots$ (forty-five copies of $45$). Even positions in this string hold $5$, so the digit is $\boxed{5}$.
