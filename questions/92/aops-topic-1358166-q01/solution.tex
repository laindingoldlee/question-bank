Inside the brackets: $5(7x-2)-2(5x-7)=35x-10-10x+14=25x+4$. So the equation is
\[
14x-35-(25x+4)=-72\iff -11x-39=-72\iff -11x=-33\iff x=\boxed{3}.
\]
