Each number appears in $4$ of the sums, so the ten sums total $4S$, where $S$ is the sum of the five numbers, an even number. If the last digits were $0,1,\dots,9$, the total would end in the same digit as $45$, i.e. be odd. So $\boxed{\text{no}}$.
