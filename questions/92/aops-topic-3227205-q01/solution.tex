No. For each expression length there are only finitely many strings over a finite alphabet. Listing strings by length therefore lists all allowed expressions in a sequence, so they represent at most countably many values. In contrast, the real numbers, hence the complex numbers, are uncountable: if all infinite binary strings were listed, changing the $n$th digit of the $n$th string would give a string absent from the list. Mapping such strings to real numbers with ternary digits $0$ and $2$ is injective (the first differing digit dominates the sum of all later differences unless all later digits are opposite, in which case the difference is still positive). Thus no such fixed finite symbolic system represents every complex number.
