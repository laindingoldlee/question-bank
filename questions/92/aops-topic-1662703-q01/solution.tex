Let there be $n$ teams, so $M=\dbinom n2$ matches, of which $D$ are draws. A decided match gives $3$ points in total and a drawn match gives $2$, so the total is
\[
3(M-D)+2D=3M-D=74,\qquad D=3M-74 .
\]
We need $0\le D\le M$, that is $3M-74\ge0$ and $2M\le74$: so $\dfrac{74}{3}\le M\le37$, i.e. $25\le M\le37$. The triangular numbers $\dbinom n2$ in this range are $28$ ($n=8$) and $36$ ($n=9$).
\begin{itemize}
\item $n=8$: $M=28$, $D=84-74=10$ draws ($18$ decided matches: $54+20=74$).
\item $n=9$: $M=36$, $D=108-74=34$ draws ($2$ decided matches: $6+68=74$).
\end{itemize}
Both can happen (the points add up regardless of which teams win). So the number of draws is $\boxed{10 \text{ (with } 8\text{ teams) or } 34 \text{ (with } 9\text{ teams)}}$.
