Since $S=2$, each denominator is $4-(S-x_i)=2+x_i$, so
\[
\dfrac {m}{n}=2\sum_{i=1}^4\dfrac{1}{x_i+2}.
\]
From $Q(x)=\prod(x-x_i)$ we get $\dfrac{Q'(x)}{Q(x)}=\sum\dfrac{1}{x-x_i}$, so $\sum\dfrac{1}{x_i+2}=-\dfrac{Q'(-2)}{Q(-2)}$.

Now find $Q$. It is monic with $x^3$-coefficient $-S=-2$: $Q(x)=x^4-2x^3+ax^2+bx+c$. The conditions give
\[
Q(-1)=3+a-b+c=2,\qquad Q(-2)=32+4a-2b+c=5,\qquad Q(3)=27+9a+3b+c=10,
\]
i.e.\ $a-b+c=-1$, $4a-2b+c=-27$, $9a+3b+c=-17$. Subtracting: $3a-b=-26$ and $5a+5b=10$, so $a+b=2$, $4a=-24$, $a=-6$, $b=8$, $c=13$. Thus $Q(x)=x^4-2x^3-6x^2+8x+13$, $Q(-2)=16+16-24-16+13=5$ and $Q'(x)=4x^3-6x^2-12x+8$, $Q'(-2)=-32-24+24+8=-24$. Hence
\[
\dfrac {m}{n}=2\cdot\dfrac{24}{5}=\dfrac{48}{5},\qquad m+n=\boxed{53}.
\]
