Sarkie trains for a race. Her first run is $1.389$ miles in $10$ minutes, and her second run is also $1.389$ miles in $10$ minutes. After that, each run is twice as long, in both distance and time, as the run before it ($2.778$ miles in $20$ minutes, then $5.556$ miles in $40$ minutes, and so on). Her runs on the first day take $5$ hours $20$ minutes in total. How many miles does she run that day?
