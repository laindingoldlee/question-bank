$1296=2^4\cdot3^4$, so we need $k$ divisible by neither $2$ nor $3$. By inclusion--exclusion the count is
\[200-\left\lfloor\dfrac{200}{2}\right\rfloor-\left\lfloor\dfrac{200}{3}\right\rfloor+\left\lfloor\dfrac{200}{6}\right\rfloor=200-100-66+33=\boxed{67}.\]
