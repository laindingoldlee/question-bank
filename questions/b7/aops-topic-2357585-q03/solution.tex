$2000=2^4\cdot5^3$. If one of $a,b$ had both a factor $2$ and a factor $5$, it would be divisible by $10$. So all the factors $2$ go to one number and all the factors $5$ to the other (a factor $1\cdot2000$ is impossible, since $2000$ is divisible by $10$): $\{a,b\}=\{16,125\}$, and $a+b=\boxed{141}$.
