A positive integer with decimal digits $a_1a_2\ldots a_k$ (so $a_1>0$) is \emph{very uphill} if $a_{i+1}\ge3a_i-1$ for all $1\le i<k$. For example, $1$ is the smallest very uphill number. How many very uphill numbers are there (including $1$)?
