Let $L(x,y)$ count paths from $(0,0)$ to $(x,y)$ using unit right and up steps. Define $S=\sum_{x=0}^{2020}\sum_{y=0}^{2020}L(x,y)$. Write $S=\binom{2k}{k}-j$ with $k,j$ positive integers and $k$ as small as possible. Find $k+j$.
