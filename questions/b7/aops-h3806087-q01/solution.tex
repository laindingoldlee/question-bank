Once a value is below $20$, every function sends it to a still smaller value; once above $26$, every function sends it to a still larger value. Thus every intermediate value of a successful list must remain in the interval.
From $20.5$, exactly two choices remain there, giving $21$ and $21.5$. The reachable set thereafter is
\[
S=\{20,21,21.5,22,23,24,24.5,26\}.
\]
For these eight inputs, the allowed outputs, counting distinct function choices, are respectively
\[
(20,20),(22,23),(23,24.5),(24,26),(26,20),(22,20),(23,21.5),(26,26).
\]
Every value therefore has exactly two allowed continuations, and all outputs lie in $S$. Consequently the count is $\boxed{2^8=256}$.
