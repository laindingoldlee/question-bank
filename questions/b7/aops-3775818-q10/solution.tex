Insert a digit $d$ into one of the ten gaps in $223334444$. If $d$ already occurs $c_d$ times, insertion immediately before or after each such occurrence gives the same string; accounting for these coincidences leaves $10-c_d$ distinct strings for that digit. Different inserted digits have different digit counts, so never coincide. Summing gives $10\cdot10-9=91$ strings. The single string obtained by inserting zero at the front is not ten-digit. Thus the answer is $\boxed{90}$.
