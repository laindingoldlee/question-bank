A six-digit repeating integer is made of a block of length $1$, $2$ or $3$ repeated $6$, $3$ or $2$ times. A block of length $1$ repeated is also a block of length $2$ (and $3$) repeated, so it suffices to count numbers of the form $\overline{ab}\,\overline{ab}\,\overline{ab}$ or $\overline{abc}\,\overline{abc}$.
\begin{itemize}
\item Period $2$: $a\ne0$, so $9\cdot10=90$ numbers.
\item Period $3$: $a\ne0$, so $900$ numbers.
\item Both: then the number has period $\gcd(2,3)=1$, i.e. all six digits equal: $9$ numbers.
\end{itemize}
By inclusion-exclusion there are $90+900-9=\boxed{981}$.
