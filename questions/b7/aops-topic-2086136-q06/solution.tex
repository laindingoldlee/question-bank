The triangle is isosceles with apex \(B\), so the altitude \(BH\) bisects \(AC\): \(AH=HC=21\).

\begin{asy}
usepackage("amsmath");
size(5.5cm);
defaultpen(fontsize(10pt));
pair A=(0,0), C=(42,0), B=(21,20), H=(21,0);
draw(A--B--C--cycle,linewidth(0.9)); draw(B--H,dashed);
draw(H--(H+(1.5,0))--(H+(1.5,1.5))--(H+(0,1.5)));
dot(A);dot(B);dot(C);dot(H);
label("$A$",A,SW); label("$C$",C,SE); label("$B$",B,N); label("$H$",H,S);
label("$29$",(A+B)/2,NW); label("$29$",(B+C)/2,NE); label("$21$",(A+H)/2,S); label("$21$",(H+C)/2,S); label("$20$",(B+H)/2,E);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

By Pythagoras, \(BH=\sqrt{29^2-21^2}=\sqrt{400}=20\). The area is \(\dfrac{1}{2}\cdot 42\cdot 20=\boxed{420}\).
