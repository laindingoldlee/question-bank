\textbf{Disproved.} For a polynomial with integer coefficients and integers \(a\ne b\), \(a-b\) divides \(P(a)-P(b)\), because each term satisfies \(a-b\mid c(a^j-b^j)\).

If \(P(k)=2^k\) for all positive integers \(k\), then with \(a=4\), \(b=1\) we would need \(3\mid P(4)-P(1)=16-2=14\), which is false. So no such polynomial exists.

(The condition can be met for \(k=1,2,3\) only, e.g. \(P(x)=x^2-x+2\) gives \(2,4,8\), but it already fails at \(k=4\). Even without the integer-coefficient condition no polynomial works for all \(k\), since \(2^k\) eventually exceeds any polynomial.)
