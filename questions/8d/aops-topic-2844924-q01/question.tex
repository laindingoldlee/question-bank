Queneau's book \emph{Cent mille milliards de po\`emes} contains $10^{14}$ sonnets of $14$ lines each. Each page carries one sonnet, cut into $14$ strips (one per line), and any strip can be turned independently, so a poem is formed by choosing, for each of the $14$ line positions, the line from any one page. How many pages does the book need?
