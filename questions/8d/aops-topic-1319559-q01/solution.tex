No. If $a=-r$ and $b=-s$ with $r,s>0$, then
\[
\sqrt a\cdot\sqrt b=(i\sqrt r)(i\sqrt s)=i^2\sqrt{rs}=-\sqrt{rs},\qquad\text{while}\qquad\sqrt{ab}=\sqrt{rs}.
\]
These differ, since $\sqrt{rs}>0$. For example $\sqrt{-1}\cdot\sqrt{-1}=-1$, but $\sqrt{(-1)(-1)}=1$. (For $a,b\ge0$ the rule holds because $\sqrt a\sqrt b\ge0$ and its square is $ab$; it also holds when exactly one of $a,b$ is negative.)
