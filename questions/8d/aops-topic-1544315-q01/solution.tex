Suppose $M=kN$ with $M\ne N$ both of these numbers, so $k\ge2$ is an integer. The smallest such number is $2457$ and the largest is $7542<4\cdot2457$, so $k=2$ or $k=3$.

\textbf{$k=3$.} Then $N\le\dfrac{7542}{3}=2514$, so $N$ is $2457$ or $2475$. Now $3\cdot2457=7371$ (not allowed) and $3\cdot2475=7425$, which uses the digits $7,4,2,5$.

\textbf{$k=2$.} Then $N\le\dfrac{7542}{2}=3771$, so $N$ begins with $2$: $N\in\{2457,2475,2547,2574,2745,2754\}$, and $2N\in\{4914,4950,5094,5148,5490,5508\}$. None of these uses the digits $2,4,5,7$.

So the number is $\boxed{7425}=3\cdot2475$.
