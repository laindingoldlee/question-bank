The difference $A-B$ (also written $A\setminus B$) is the set of elements of $A$ that are not in $B$. The elements $2$, $4$, $6$ of $A$ are in $B$, so
\[
A-B=\{1,3,5\}.
\]
Similarly, $B-A$ consists of the elements of $B$ that are not in $A$; only $8$ qualifies:
\[
B-A=\{8\}.
\]
So $\boxed{A-B=\{1,3,5\},\ B-A=\{8\}}$. Note that in general $A-B\ne B-A$.
