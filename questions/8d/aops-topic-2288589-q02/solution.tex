There are $26^4=456976$ equally likely outcomes (one letter from each bin, in order). The player wins exactly when the four letters are J, A, K, E in some order: the four bins show a permutation of these four letters, which can happen in $4!=24$ ways. So the probability is
\[\dfrac{24}{456976}=\boxed{\dfrac{3}{57122}}.\]
