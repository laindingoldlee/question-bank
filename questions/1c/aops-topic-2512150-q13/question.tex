Sabrina has $2^{100}$ unit cubes. Using all of them, she builds a solid rectangular box, each of whose edge lengths must be at least $512$. How many different boxes can she make, if boxes whose edge lengths are the same numbers listed in a different order (length, width, height) are counted as different?
