The exponent $2$ applies to the whole parenthesis $(2-3)$, which must be evaluated first. The student instead squared only the $3$, computing $2-3^2$. Correctly, $(2-3)^2=(-1)^2=1$, so the value is $1\cdot5\div4=\boxed{\dfrac54}$.
