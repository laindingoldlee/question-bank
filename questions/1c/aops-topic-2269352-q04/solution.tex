As $|x|^6=1$, $|x|=1$; write $x=\cos\theta+i\sin\theta$. Since $-i=\cos270^\circ+i\sin270^\circ$, De Moivre's theorem gives $6\theta=270^\circ+360^\circ m$, so
\[\theta=45^\circ+60^\circ m:\qquad45^\circ,\ 105^\circ,\ 165^\circ,\ 225^\circ,\ 285^\circ,\ 345^\circ.\]
Only $\theta=45^\circ$ lies strictly between $0^\circ$ and $90^\circ$, so
\[x=\boxed{\dfrac{\sqrt2}{2}+\dfrac{\sqrt2}{2}i}.\]
(Check: $x^2=i$, so $x^6=i^3=-i$.)
