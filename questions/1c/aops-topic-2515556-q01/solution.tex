For $50\le n\le89$ let $p_n=\dfrac{n(n+1)}{10000}$; note $p_n\le p_{89}=\dfrac{8010}{10000}<1$. While the rate is $n$, each second independently raises it with probability $p_n$. So the number $T_n$ of seconds spent at rate $n$ (including the second in which it rises) is geometric, with
\[E(T_n)=\dfrac{1}{p_n}=\dfrac{10000}{n(n+1)}=10000\left(\dfrac1n-\dfrac1{n+1}\right).\]
The total time is $T_{50}+T_{51}+\cdots+T_{89}$, so by linearity of expectation and telescoping,
\[E(T)=10000\left(\dfrac1{50}-\dfrac1{90}\right)=10000\cdot\dfrac{4}{450}=\boxed{\dfrac{800}{9}}\approx88.9\text{ seconds}.\]
