The right side is positive, so $a>b,c$. It is odd, forcing exactly one of $b,c$ to be zero; if both were zero, $2^a=1025$, impossible. Suppose $c=0$. Then $2^b(2^{a-b}-1)=1024=2^{10}$. The odd factor must be 1, giving $b=10,a=11$. Exchanging $b,c$ yields exactly $(11,10,0),(11,0,10)$. The count is $\boxed2$.
