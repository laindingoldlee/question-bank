For every real $t$, $\sqrt{t^2}=|t|$. Since $7\sqrt2=\sqrt{98}>\sqrt{16}=4$, the number $4-7\sqrt2$ is negative. So
\[\sqrt{\left(4-7\sqrt2\right)^2}+\sqrt{\left(4+7\sqrt2\right)^2}=\left(7\sqrt2-4\right)+\left(4+7\sqrt2\right)=\boxed{14\sqrt2}.\]
