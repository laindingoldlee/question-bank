The second condition gives $\dfrac{ab+bc+ca}{abc}=0$, so $ab+bc+ca=0$.

(a) We have
\[
\dfrac{1}{a^2}+\dfrac{1}{b^2}+\dfrac{1}{c^2}=\left(\dfrac{1}{a}+\dfrac{1}{b}+\dfrac{1}{c}\right)^2-2\cdot\dfrac{a+b+c}{abc}=-\dfrac{4}{abc},
\]
which depends on $abc$. Two examples:
\begin{itemize}
\item $c=1$, $a,b=\dfrac{1\pm\sqrt5}{2}$: then $a+b=1$, $ab=-1$, so $a+b+c=2$, $ab+bc+ca=-1+1=0$, $abc=-1$, and the value is $4$.
\item $c=\dfrac{1}{2}$, $a,b=\dfrac{3\pm\sqrt{21}}{4}$: then $a+b=\dfrac{3}{2}$, $ab=-\dfrac{3}{4}$, so $a+b+c=2$, $ab+c(a+b)=-\dfrac{3}{4}+\dfrac{3}{4}=0$, $abc=-\dfrac{3}{8}$, and the value is $\dfrac{32}{3}$.
\end{itemize}
So the value is not determined.

(b) $a^2+b^2+c^2=(a+b+c)^2-2(ab+bc+ca)=4-0=\boxed{4}$.
