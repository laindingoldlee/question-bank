\textbf{Symmetry.} Replacing each die value $d$ by $7-d$ is a bijection between the outcomes, and it turns a sum $s$ into $7n-s$. So the sums $s$ and $7n-s$ are equally likely. Moreover the probabilities strictly increase from the smallest sum $n$ up to the middle, so $1994$ shares its probability only with $7n-1994$ (and itself).

\textbf{Smallest $n$.} A sum of $1994$ is possible only if $6n\ge1994$, i.e.\ $n\ge333$ (since $6\cdot332=1992$). The value $S=7n-1994$ is smallest for $n=333$:
\[
S=7\cdot333-1994=2331-1994=\boxed{337}.
\]
(It is a possible sum, since $333\le337\le1998$.)
