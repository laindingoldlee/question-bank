Adding the two equations gives
\[2a^2+2b^2+2c^2-2ab-2ac-2bc=14,\qquad\text{that is,}\qquad (a-b)^2+(b-c)^2+(a-c)^2=14 .\]
Let $p=a-b\ge0$ and $q=b-c\ge0$, so $a-c=p+q$ and $p^2+q^2+(p+q)^2=14$, that is, $p^2+pq+q^2=7$. If $p=0$ or $q=0$, the other would satisfy a square equal to $7$, impossible; so $p,q\ge1$, and then $p^2+pq+q^2=7$ forces $\{p,q\}=\{1,2\}$.
\begin{itemize}
\item $p=1$, $q=2$: $b=a-1$, $c=a-3$, and the first equation becomes $a^2-(a-1)^2-(a-3)^2+a(a-1)=7a-10=2011$, so $7a=2021$, not an integer.
\item $p=2$, $q=1$: $b=a-2$, $c=a-3$, and the first equation becomes $a^2-(a-2)^2-(a-3)^2+a(a-2)=8a-13=2011$, so $a=253$.
\end{itemize}
Then $(a,b,c)=(253,251,250)$, which satisfies both equations (the second because the sum is right and the first holds). So $a=\boxed{253}$.
