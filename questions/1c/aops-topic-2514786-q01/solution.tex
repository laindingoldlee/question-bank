\textbf{(a)} We need $x+2\ge0$ (a real square root) and $x^2-9\ne0$ (a nonzero denominator), i.e. $x\ge-2$ and $x\ne\pm3$. Since $-3<-2$, only $x=3$ has to be removed:
\[\boxed{[-2,3)\cup(3,\infty)}.\]

\textbf{(b)} For real $z$, $z^2\ge0$, so $g(z)=z^2+4\ge4>0$: no real zeros. Over the complex numbers,
\[z^2+4=(z-2i)(z+2i),\]
and a product of complex numbers is $0$ only if a factor is $0$. So the zeros are exactly $\boxed{z=2i\text{ and }z=-2i}$.

So whether complex numbers are in the domain is a choice made when the function is defined. The same formula can define different functions, with different properties, on different domains.
