The domain of a function is part of its definition, and it need not be all real numbers.
\begin{enumerate}
\item[(a)] Find the largest set of real numbers on which $f(x)=\dfrac{\sqrt{x+2}}{x^2-9}$ is defined (as a real number).
\item[(b)] Consider $g(z)=z^2+4$. Show that $g$ has no zeros if its domain is the real numbers, but has exactly two zeros if its domain is the complex numbers, and find them.
\end{enumerate}
