Modulo $n+3$, $n\equiv-3$, so $n^3-3\equiv-27-3=-30$. So we need $n+3\mid30$, with $n+3\ne0$. The number $30$ has $8$ positive divisors, hence $16$ divisors in all, giving $\boxed{16}$ integers $n$ (from $n=-33$ to $n=27$).
