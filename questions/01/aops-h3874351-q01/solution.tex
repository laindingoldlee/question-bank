View the equation as a quadratic in $y$:
\[
(x^2-1)y^2-10xy+16-x^2=0.
\]
Its discriminant is $4(x^2+4)^2$, so for $x\ge2$,
\[
y=\dfrac{5x\pm(x^2+4)}{x^2-1}
=\dfrac{x+4}{x-1}\quad\text{or}\quad\dfrac{4-x}{x+1}.
\]
The second expression is positive only for $x=2,3$, when it is $\dfrac{2}{3},\dfrac{1}{4}$, respectively. The first is $1+\dfrac{5}{(x-1)}$, an integer only when $x-1$ is $1$ or $5$. These give $(x,y)=(2,6)$ and $(6,2)$, of which only the latter has $x>y$. Hence $\boxed{100x+y=602}$.
