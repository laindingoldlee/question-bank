Suppose the set of real numbers were finite, with $n$ elements. The numbers $1,2,\dots,n+1$ are $n+1$ different real numbers, which is impossible. Hence the set of real numbers is infinite. $\blacksquare$

(Equivalently: a finite set of real numbers has a largest element $M$, but $M+1$ is a larger real number.)
