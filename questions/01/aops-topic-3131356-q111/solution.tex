Rearrange as $ x(y-1)=y^2 $. The value $ y=1 $ is impossible. Otherwise $ x=y+1+\dfrac{1}{y-1}$, so integrality requires $ y-1=\pm1 $. These yield $(x,y)=(0,0)$ and $(4,2)$. Thus there are $\boxed{2}$ pairs.
