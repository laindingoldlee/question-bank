\textbf{(a)} $(x-1)(x+1)+899=x^2-1+899=x^2+898$; divide by $x+1$.

\textbf{(b)} For an integer $x$, the number $x-1$ is an integer, so the expression is an integer exactly when $\dfrac{899}{x+1}$ is an integer, that is, when $x+1$ divides $899$ (written $x+1\mid899$). Since $899=900-1=29\cdot31$, the positive divisors are $1,29,31,899$. With $x\ge1$ we need $x+1\ge2$, so
\[x+1\in\{29,31,899\},\qquad x\in\boxed{\{28,\,30,\,898\}}.\]
