\textbf{(a)} By Pascal's identity, $\dbinom{21}{11}=\dbinom{20}{10}+\dbinom{20}{11}$, so the equation says $\dbinom{20}{n}=\dbinom{20}{11}$ (and this needs $0\le n\le20$, since the right side is positive). In row $20$ of Pascal's triangle the entries strictly increase up to $\dbinom{20}{10}$ and then strictly decrease, symmetrically. So each value other than the middle one occurs exactly twice, and $\dbinom{20}{11}=\dbinom{20}{9}$ occurs only for $n=9$ and $n=11$. The sum is $9+11=\boxed{20}$.

\textbf{(b)} Symmetry only shows that the solutions can be grouped into pairs $\{n,20-n\}$, plus possibly $n=10$ on its own. The sum is then $20$ times the number of pairs (plus $10$ if $n=10$ is a solution), which is $20$ only if there is exactly one pair. The student skips the essential step of showing that there are exactly two solutions. For example, $\dbinom{20}{n}=\dbinom{20}{10}$ has the single solution $n=10$, with sum $10$, and $\dbinom{20}{n}=1000$ has no solutions at all. In (a), the monotonicity of row $20$ is what shows there is exactly one pair.
