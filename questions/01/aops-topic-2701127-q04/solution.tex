A strictly decreasing sequence is determined by choosing $5$ distinct ranks ($\binom{13}5$ ways) and a suit for each ($4^5$ ways); the order is then forced. There are $52\cdot51\cdot50\cdot49\cdot48$ ordered draws. So the probability is
\[\dfrac{\binom{13}{5}4^5}{52\cdot51\cdot50\cdot49\cdot48}=\dfrac{1287\cdot1024}{311875200}=\boxed{\dfrac{88}{20825}}.\]
