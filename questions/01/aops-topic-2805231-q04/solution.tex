If $n$ is written first, the number is $1000n+(n+1)=1001n+1\equiv1\pmod{1001}$. If $n+1$ is written first, it is $1000(n+1)+n=1001n+1000\equiv1000\pmod{1001}$. Neither is $0$. $\blacksquare$
