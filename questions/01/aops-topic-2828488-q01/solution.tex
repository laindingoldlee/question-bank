Let $N=p_1\cdots p_n$, which is even but not divisible by $4$. If $N+1=k^2$, then $N=(k-1)(k+1)$. The two factors differ by $2$, so they have the same parity. If both are odd, $N$ is odd; if both are even, $4\mid N$. Either way we get a contradiction. $\blacksquare$

The quoted argument is correct: since $2$ divides $N$ exactly once, in any factorisation $N=uv$ exactly one of $u,v$ is even. That contradicts $k-1$ and $k+1$ having the same parity. (It is the same proof, phrased with ``exactly one factor of $2$''.)
