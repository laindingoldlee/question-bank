Split the modulus. Modulo $3$: $n^3\equiv n$ (Fermat), so $n\equiv0\pmod3$. Modulo $5$: the cubes of $0,1,2,3,4$ are $0,1,3,2,4$, so $n^3\equiv3$ forces $n\equiv2\pmod5$. The only $n<15$ with $n\equiv0\pmod3$ and $n\equiv2\pmod5$ is $\boxed{n=12}$; indeed $12^3=1728=115\cdot15+3$.
