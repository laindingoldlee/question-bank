The height is $h=\dfrac{2\cdot120}{7+17}=10$. Triangle $ACD$ has base $AD=17$ and height $h$ (as $C$ lies on the other base), so $[ACD]=85$. Triangle $CDB$ has base $BC=7$ and height $h$ (as $D$ lies on the other base), so $[CDB]=35$.

\begin{asy}
usepackage("amsmath");
size(5cm);
defaultpen(fontsize(10pt));
pair A=(0,0),D=(17,0),B=(4,10),C=(11,10);
draw(A--B--C--D--cycle,linewidth(0.9)); draw(A--C,blue); draw(B--D,red);
label("$A$",A,SW); label("$D$",D,SE); label("$B$",B,NW); label("$C$",C,NE); label("$17$",(A+D)/2,S); label("$7$",(B+C)/2,N);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

The difference is $85-35=\boxed{50}$.
