The equation only makes sense for $x\ne0$. For such $x$, it is equivalent to $y=-\dfrac x2$. So the graph is the line $y=-\dfrac x2$ with the origin removed. If $x\ne0$ then $y=-\dfrac x2\ne0$, and conversely every $y\ne0$ is reached (at $x=-2y$).
\begin{asy}
usepackage("amsmath");
size(5cm);
defaultpen(fontsize(10pt));
import graph;
draw((-3,0)--(3,0),Arrow);draw((0,-1.8)--(0,1.8),Arrow);
label("$x$",(3,0),E);label("$y$",(0,1.8),N);
draw((-3,1.5)--(3,-1.5),blue);
filldraw(circle((0,0),0.09),white,blue);
label("$y=-\dfrac{x}{2}$",(-2.2,1.1),N,blue);
label("hole at $(0,0)$",(0.15,0.1),NE);
\end{asy}

The domain is $\boxed{x\ne0}$ and the range is $\boxed{y\ne0}$. Multiplying by $x$ to get $y=-\dfrac x2$ is valid only when $x\ne0$, so the point $(0,0)$ of that line does not satisfy the original equation.
