Carol $=$ David$^2$ with distinct numbers from $1$ to $6$ forces David $=2$ and Carol $=4$. The others have $\{1,3,5,6\}$. Frederick knows Eve's number only if exactly one remaining number exceeds his: with his number $5$, Eve must be $6$ (with $1$ or $3$ there would be several options). Then Alice and Bob have $1$ and $3$, so Alice $=1$. The sum is $1+4+6=11$. Answer $\boxed{\textbf{(C)}\ 11}$.
