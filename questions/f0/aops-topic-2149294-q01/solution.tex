Use Pascal's rule $\dbinom{m}{k}+\dbinom{m}{k+1}=\dbinom{m+1}{k+1}$ twice (it holds for all $m\ge0$, with $\dbinom mk=0$ when $k>m$):
\[\dbinom{n-2}{4}+\dbinom{n-2}{5}=\dbinom{n-1}{5},\qquad \dbinom{n-1}{5}+\dbinom{n-1}{6}=\dbinom n6 .\]
So the inequality is $\dbinom n6>\dbinom n5$. For $n\le5$ the left side is $0$, so it fails. For $n\ge6$,
\[\dfrac{\dbinom n6}{\dbinom n5}=\dfrac{n-5}{6},\]
so we need $n-5>6$, that is, $n>11$. The least value is $\boxed{12}$. (For $n=11$ the two sides are equal: $\dbinom{11}{6}=\dbinom{11}{5}=462$; for $n=12$, $924>792$.)
