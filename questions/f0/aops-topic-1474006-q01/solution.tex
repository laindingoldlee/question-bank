Radicals can be added directly only when they have the same radicand (like terms). First simplify each radical: $\sqrt{18}=\sqrt{9\cdot2}=3\sqrt2$, so
\[
\sqrt6+\sqrt{18}=\boxed{\sqrt6+3\sqrt2},
\]
and $\sqrt6$ and $3\sqrt2$ are not like terms, so this cannot be combined further (it factors as $\sqrt6\left(1+\sqrt3\right)$).

It is not $\sqrt{6+18}=\sqrt{24}=2\sqrt6$: in general $\sqrt a+\sqrt b\ne\sqrt{a+b}$ for $a,b>0$, because $\left(\sqrt a+\sqrt b\right)^2=a+b+2\sqrt{ab}>a+b$. Numerically $\sqrt6+3\sqrt2\approx6.69$, while $\sqrt{24}\approx4.90$.
