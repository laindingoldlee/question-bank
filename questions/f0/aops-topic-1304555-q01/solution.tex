Write the angles as $a-d$, $a$, $a+d$ with $d\ge1$. Their sum is $3a=180$, so $a=60$, and we need $60-d\ge1$, i.e. $1\le d\le59$. Each $d$ gives a different set of angles, hence a different similarity class: $\boxed{59}$ triangles.
