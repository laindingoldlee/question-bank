An operation $@$ on positive integers gives
\[4@6=11,\qquad 9@11=98,\qquad 15@20=59,\qquad 24@36=71 .\]
\begin{enumerate}
\item[(a)] Show that all four results agree with the rule $a@b=\operatorname{lcm}(a,b)-1$.
\item[(b)] Using this rule, find $1602@(7@13)$.
\end{enumerate}
