If $k\ge6$, then $9$ divides $k!$, forcing $n^3\equiv2\pmod9$. But cubes modulo $9$ are only $0,1,8$, a contradiction. For $k=1,2,3,4,5$, the values $k!+2$ are $3,4,8,26,122$, of which only $8$ is a cube. Hence $\boxed{(n,k)=(2,3)}$.
