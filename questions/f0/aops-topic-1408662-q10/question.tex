Each cell of a $3\times3$ array is filled with a digit from $1$ to $9$ so that:
\begin{enumerate}
\item each digit $1$ through $9$ is used exactly once;
\item each row, read from left to right, is an odd three-digit multiple of $3$ that is not a multiple of $9$;
\item each column, read from top to bottom, is an odd three-digit multiple of $3$ that is not a multiple of $9$;
\item the diagonal read from lower-left to upper-right is an odd three-digit multiple of $9$.
\end{enumerate}
What three-digit number is formed by the diagonal read from upper-left to lower-right?
