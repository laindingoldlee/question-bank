Write the array as
\[
\begin{array}{ccc} a&b&c\\ d&e&f\\ g&h&k \end{array}
\]

\textbf{Odd and even cells.} Every row ends in an odd digit, so $c,f,k$ are odd; every column ends in an odd digit, so $g,h,k$ are odd. These are five cells and there are exactly five odd digits $1,3,5,7,9$, so $a,b,d,e$ are $2,4,6,8$ in some order.

\textbf{Digit sums.} A number is a multiple of $3$ but not of $9$ when its digit sum is a multiple of $3$ but not of $9$. Three different digits sum to between $6$ and $24$, so every row and column sum is in $\{6,12,15,21,24\}$. The last row $g+h+k$ and the last column $c+f+k$ are sums of three odd digits, hence odd: each is $15$ or $21$. Together they use all five odd digits, with $k$ twice:
\[
(g+h+k)+(c+f+k)=25+k\in\{30,36,42\}\quad\Longrightarrow\quad k=5,\ g+h+k=c+f+k=15 .
\]
So $\{c,f\}$ and $\{g,h\}$ are the pairs $\{1,9\}$ and $\{3,7\}$ (each pair sums to $10$).

\textbf{The anti-diagonal.} $g+e+c$ is a multiple of $9$, and it is even ($g,c$ odd, $e$ even), so $g+e+c=18$. Because the conditions are symmetric under reflecting the array in the main diagonal (rows and columns swap, the anti-diagonal and the main diagonal are each mapped to themselves), we may assume $\{c,f\}=\{1,9\}$ and $\{g,h\}=\{3,7\}$. Then $e=18-g-c$ must be one of $2,4,6,8$:
\[
c=1:\ e=17-g\in\{14,10\}\ (\text{impossible});\qquad c=9:\ e=9-g\in\{6,2\}.
\]
\begin{itemize}
\item $c=9$, $g=7$, $e=2$: then $f=1$, and the top row needs $a+b=15-9=6$ (the row sums of rows $1$ and $2$ are $15$ each, since they are in $\{12,15,21,24\}$ and add up to $45-15=30$, and $30$ cannot be written as a sum of two of these other than $15+15$). But $a+b=6$ forces $\{a,b\}=\{2,4\}$, and $2$ is already used. Impossible.
\item $c=9$, $g=3$, $e=6$: then $f=1$, $h=7$; the top row gives $a+b=6$, so $\{a,b\}=\{2,4\}$, and the second row gives $d=15-6-1=8$. The first column gives $a=15-d-g=15-8-3=4$, so $b=2$. The second column is $b+e+h=2+6+7=15$. The array is
\[
\begin{array}{ccc} 4&2&9\\ 8&6&1\\ 3&7&5 \end{array}
\]
with rows $429,861,375$ and columns $483,267,915$ (all odd with digit sum $15$) and anti-diagonal $369=9\cdot41$.
\end{itemize}
The only other solution is the reflection of this array in its main diagonal, which has the same main diagonal. The upper-left to lower-right diagonal reads $\boxed{465}$.
