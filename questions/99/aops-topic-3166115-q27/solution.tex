A string of length $n$ has only $n-2$ length-three windows, so at least eight characters are needed. If the length were eight, all six windows would have to be different permutations. However, whenever two adjacent windows are both permutations, the new character must equal the one that just left. Consequently all windows being permutations forces period three, producing at most three different permutations, a contradiction. The length-nine string $123121321$ contains $123,231,312,213,132,321$. Thus the minimum is $\boxed9$.
