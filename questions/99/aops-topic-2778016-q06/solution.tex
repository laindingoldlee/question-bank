Factor as $(n+1)(n+19)$. For a positive prime product, the factors have the same sign and one has absolute value 1. If both are positive, the smaller $ n+1 $ must be 1, giving $ n=0 $ and prime 19. If both are negative, the larger $ n+19 $ must be $-1 $, giving $ n=-20 $ and again 19. These exhaust the cases, so $\boxed{n\in\{-20,0\}}$.
