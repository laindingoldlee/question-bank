Balls labelled $1,2,\ldots,8$ arrive in an arbitrary order through an input tube at the upper-left cell of a board with two rows and eight columns. An output tube leaves the lower-right cell. Each move inserts the next input ball, moves a ball one cell right or down, or removes a ball into the output tube. Each cell holds at most one ball.
\begin{enumerate}
\item Give a procedure that always rearranges the balls into output order $1,2,\ldots,8$.
\item How many moves does a successful procedure use, counting insertion and removal as one move each? Prove that this count is the same for every successful procedure.
\end{enumerate}
