A chord joining vertices $k$ steps apart has length $2R\sin(\dfrac{k\pi}{40})$. For $1\le k\le20$, it exceeds $R$ precisely when $k\ge7$. There are $40\cdot\dfrac{37}{2}=740$ diagonals in all. The excluded step sizes $2,3,4,5,6$ each contribute 40 diagonals, so the probability is $\dfrac{(740-200)}{740}=\boxed{\dfrac{27}{37}}$.
