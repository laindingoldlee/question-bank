The denominator $x^2-5x+9=\left(x-\dfrac52\right)^2+\dfrac{11}{4}$ is always positive, so the expression $y=\dfrac{x}{x^2-5x+9}$ is defined for all real $x$. A real number $y$ is a value of it exactly when
\[yx^2-(5y+1)x+9y=0\]
has a real solution $x$. For $y=0$ this happens ($x=0$). For $y\ne0$ it is a quadratic in $x$, with a real root exactly when its discriminant is nonnegative:
\[(5y+1)^2-36y^2=(1-y)(11y+1)\ge0\iff-\dfrac1{11}\le y\le1.\]
Hence every value lies in $\left[-\dfrac1{11},1\right]$. $\blacksquare$

Directly: $1-y=\dfrac{(x-3)^2}{x^2-5x+9}\ge0$ and $y+\dfrac1{11}=\dfrac{(x+3)^2}{11\left(x^2-5x+9\right)}\ge0$. So equality holds at $\boxed{x=3\ (\text{value }1)\text{ and }x=-3\ \left(\text{value }-\dfrac1{11}\right)}$.
