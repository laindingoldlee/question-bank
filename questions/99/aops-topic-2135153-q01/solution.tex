For $n\ge2$,
\[T_n=100^{T_{n-1}}=\left(10^2\right)^{T_{n-1}}=10^{2T_{n-1}},\]
which is written as a $1$ followed by $2T_{n-1}$ zeros. So $T_n$ has
\[\boxed{2T_{n-1}+1}\]
digits. (With the convention $T_0=1$, this also covers $n=1$: $T_1=100$ has $3=2\cdot1+1$ digits.)

For example, $T_1=100$ has $3$ digits, $T_2=100^{100}=10^{200}$ has $201$ digits, and $T_3=10^{2\cdot10^{200}}$ has $2\cdot10^{200}+1$ digits.
