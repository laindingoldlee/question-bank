Each term is $(2k)^2=4k^2$ for $k=1,2,\dots,25$, so
\[
2^2+4^2+\cdots+50^2=4\left(1^2+2^2+\cdots+25^2\right)=4\cdot5525=\boxed{22100}.
\]
(As a check, $1^2+\cdots+25^2=\dfrac{25\cdot26\cdot51}{6}=5525$.)
