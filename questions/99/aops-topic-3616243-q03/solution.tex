If $B$ is truthful, $A,C,D$ all make false statements, giving a consistent possibility. If $C$ is truthful, $B$ is lying, and taking $A,D$ to be liars makes all four statements consistent as well. If $A$ or $D$ were the sole truthful person, $B$ would lie and $C$ would consequently also speak truth, a contradiction. Thus exactly $\boxed{B\text{ or }C}$ can be the truth teller.
