From $\dfrac {a}{a+b}=\dfrac {c}{b+c}$: $ab+ac=ac+bc$, so $ab=bc$ and $a=c$. Then $\dfrac{a}{a+b}=\dfrac{a+b}{2a+b}$ gives $2a^2+ab=a^2+2ab+b^2$, i.e. $a^2-ab-b^2=0$. With $t=\dfrac {a}{b}$: $t^2-t-1=0$, so
\[\dfrac {a}{b}=\boxed{\dfrac{1\pm\sqrt5}{2}}.\]
(Both values are possible, e.g. $b=1$, $a=c=t$; the denominators are nonzero.)
