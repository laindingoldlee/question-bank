``Bob'' is $3$ of the $9$ entries, so each run picks Bob with probability $\dfrac{1}{3}$, independently. Exactly two Bobs in three runs means choosing which two runs give Bob ($\dbinom32=3$ ways):
\[
3\cdot\left(\dfrac{1}{3}\right)^2\cdot\dfrac{2}{3}=\boxed{\dfrac{2}{9}}.
\]
