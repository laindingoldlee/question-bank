A program picks a name at random from the list
\[
\text{Bob, Bob, Jeff, Jeff, Bob, Joe, Joe, Equinox, Westminister},
\]
each of the $9$ entries being equally likely. The program is run three times, independently. What is the probability that it picks ``Bob'' exactly twice?
