A real angle exists exactly when $-1\le C\le1$. On $[0,\pi]$, cosine is one-to-one, so the principal angle is $\boxed{\theta=\arccos C}$. By evenness and period $2\pi$, all real solutions are $\boxed{\theta=2k\pi\pm\arccos C,\ k\in\mathbb Z}$. At the endpoint values some expressions coincide, which does not change the solution set.
