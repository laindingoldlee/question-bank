When every $k$-th number is removed from a list of $n$ numbers, $\left\lfloor\dfrac{n}{k}\right\rfloor$ numbers go, and $n-\left\lfloor\dfrac{n}{k}\right\rfloor$ remain. Only the lengths of the lists matter:
\begin{itemize}
\item Round 1: $1000\to1000-500=500\to500-166=334\to334-66=268$.
\item Round 2: $268\to268-134=134\to134-44=90\to90-18=72$.
\item Round 3: $72\to72-36=36\to36-12=24\to24-4=20$.
\end{itemize}
So $\boxed{20}$ numbers are left.
