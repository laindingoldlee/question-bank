By Vieta, $p=a+b+c=-4$, $q=ab+bc+ca=-3$, $r=abc=3$. Then
\[
a^3+b^3+c^3=p^3-3pq+3r=-64-36+9=\boxed{-91}.
\]
(Alternatively, each root satisfies $x^3=-4x^2+3x+3$; summing, $a^3+b^3+c^3=-4(a^2+b^2+c^2)+3p+9=-4\cdot22-12+9=-91$, using $a^2+b^2+c^2=p^2-2q=22$.)
