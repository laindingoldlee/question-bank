A free spinner has $9$ equal sectors, each labelled with an integer number of dollars, which you win (or pay, if negative) when the spinner lands on it. The $9$ labels have median $4$ and range $9$; the mode is $3$, which appears exactly $3$ times, and no other number appears more than once. Find the smallest possible expected value of the winnings. Is it worth playing?
