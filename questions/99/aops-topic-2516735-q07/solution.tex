Sort the labels: $x_1\le x_2\le\dots\le x_9$, so $x_5=4$. The value $4$ appears only once, so $x_4<4<x_6$.
\begin{itemize}
\item The three $3$'s are among $x_1,\dots,x_4$. If $x_1=x_2=x_3=3$, then $3<x_4<4$, impossible for an integer. So $x_2=x_3=x_4=3$ and $x_1\le2$.
\item $x_6<x_7<x_8<x_9$ are distinct integers greater than $4$, so $x_6\ge5$, $x_7\ge6$, $x_8\ge7$, $x_9\ge8$.
\item The range is $9$, so $x_1=x_9-9$.
\end{itemize}
Hence
\[\sum x_i=(x_9-9)+3\cdot3+4+x_6+x_7+x_8+x_9\ge(8-9)+9+4+5+6+7+8=38,\]
with equality for the labels $-1,3,3,3,4,5,6,7,8$, which satisfy all the conditions. The expected winnings are the mean label, so the smallest possible expected value is
\[\boxed{\dfrac{38}{9}\approx\$4.22}.\]
Since it costs nothing to play and the expected winnings are positive for every possible spinner, it is worth playing (even though one sector may cost $\$1$).
