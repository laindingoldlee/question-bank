\begin{enumerate}
\item[(a)] Let $A$ and $B$ be finite sets with the same number of elements, and suppose every element of $A$ is an element of $B$. Prove that $A=B$.
\item[(b)] Show that the statement in (a) fails for infinite sets: find sets $A\subseteq B$ with $A\ne B$ whose elements can nevertheless be paired off one-to-one with each other, so that they have ``the same size''.
\end{enumerate}
