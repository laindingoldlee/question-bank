A student argues: ``Suppose $a\rightarrow b$. Start from the true statement $a\rightarrow a$ and replace the first $a$ using $a\rightarrow b$; this gives $b\rightarrow a$. So every implication implies its converse.'' Find the error, and give a counterexample to the conclusion.
