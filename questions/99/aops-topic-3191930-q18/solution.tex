Within a fixed column a path must be monotone vertically, because reversing vertical direction would revisit a point. It can never return to a previous column. Choose the height of the rightward exit from each of columns 0,1,2,3 independently from 0 through 4. In the last column travel monotonically to height 4. This is a bijection with four choices of five values, giving $\boxed{5^4=625}$.
