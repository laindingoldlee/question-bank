From $5x=6y$, $6$ divides $5x$; since $\gcd(6,5)=1$, $6\mid x$. Likewise $5$ divides $6y$ and $\gcd(5,6)=1$, so $5\mid y$. Write $x=6m$. Then $2z=5x=30m$, so $z=15m$ and $15\mid z$. $\blacksquare$
