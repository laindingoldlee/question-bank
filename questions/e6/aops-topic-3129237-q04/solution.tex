Call cards $1$ through $50$ desired. Two exchanges can replace any one undesired hand card by any one desired table card while preserving the other $49$ hand cards: first take all table cards except the desired card, then take the original hand with the undesired card replaced by that desired card. If the initial hand has $k\ge25$ desired cards, perform this swap $50-k$ times, using at most $50$ exchanges. If $k<25$, first exchange for a hand containing all $50-k$ desired table cards. It then lacks only $k$ desired cards, which take $2k$ more exchanges to acquire. The total $1+2k\le49$. Thus $50$ always suffices.
