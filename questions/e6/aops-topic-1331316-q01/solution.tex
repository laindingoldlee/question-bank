List the products $pq<100$ with $3\le p<q$ odd primes:
\begin{itemize}
\item $p=3$: $q\in\{5,7,11,13,17,19,23,29,31\}$ ($3q<100$ needs $q\le33$): $9$ numbers;
\item $p=5$: $q\in\{7,11,13,17,19\}$: $5$ numbers;
\item $p=7$: $q\in\{11,13\}$: $2$ numbers;
\item $p\ge11$: $11\cdot13>100$, none.
\end{itemize}
By unique factorisation these are all different, so there are $9+5+2=\boxed{16}$.
