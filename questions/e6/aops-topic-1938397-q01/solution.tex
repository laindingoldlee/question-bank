A number is a multiple of $9$ exactly when its digit sum is. For $x$: $2+5+9+1+A+0+B=17+A+B$, so $A+B\equiv1\pmod9$, i.e.\ $A+B=1$ or $10$. For $y$: $1+0+2+4+2+A+B+C=9+A+B+C$, so $A+B+C\equiv0\pmod9$. If $A+B=1$ then $C=8$; if $A+B=10$ then $C\equiv-10\equiv8\pmod9$, so again $C=8$. Hence $C=\boxed{8}$.
