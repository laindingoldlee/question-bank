For $k=1$, the value is $9$. If odd $k\ge3$, then modulo $8$ the expression is $3$, not a square residue. If $k=2m$ is even, then $11^k-2^k=(11^m)^2-4^m$. Since $0<4^m<2\cdot11^m-1$, the value lies strictly between $(11^m-1)^2$ and $(11^m)^2$. It is not a square. Therefore $\boxed{k=1}$.
