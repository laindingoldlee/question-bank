The base is $\sqrt{\sqrt{300}}=300^{\dfrac{1}{4}}$. If $\left(300^{\dfrac{1}{4}}\right)^t=300$, then $\dfrac{t}{4}=1$, so
\[
\log_{\sqrt{\sqrt{300}}}300=\boxed{4}.
\]
