For a positive integer $Z$, its digit count is $\lfloor\log_{10}Z\rfloor+1$. Thus the answer is $\boxed{\lfloor\sum_{i=1}^t\log_{10}E_i\rfloor+1}$. It is not a fixed numerical value without the submissions. For example all submissions one give one digit, whereas a single submission $1000$ gives four. The original competitive estimation score depends on other teams's answers, so it has no standalone numerical solution.
