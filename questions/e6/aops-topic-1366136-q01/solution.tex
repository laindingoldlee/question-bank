Let $d$ be a common divisor of $u=a^3+2a$ and $v=a^4+3a^2+1$. Use the Euclidean algorithm:
\[
v-a\cdot u=a^4+3a^2+1-a^4-2a^2=a^2+1,
\]
so $d\mid a^2+1$. Next
\[
u-a\left(a^2+1\right)=a^3+2a-a^3-a=a,
\]
so $d\mid a$. Finally $\left(a^2+1\right)-a\cdot a=1$, so $d\mid1$.

Hence the only positive common divisor is $1$ and the fraction cannot be reduced. (For $a=0$ the fraction is $\dfrac{0}{1}$, which is also in lowest terms.)
