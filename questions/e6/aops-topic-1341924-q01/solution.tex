(a) For $n=1$ we get $1+3=4=2^2$, but for $n=2$ we get $8+9=17$, which is not a square. So the claim is false.

(b) \textbf{Proof.} Let $n=2m$, so $3^n=\left(3^m\right)^2$ and $n^3+3^n>\left(3^m\right)^2$. We show $n^3+3^n<\left(3^m+1\right)^2=3^{2m}+2\cdot3^m+1$ for $m\ge7$, i.e.\ $8m^3<2\cdot3^m+1$; it is enough to prove $8m^3<2\cdot3^m$ for $m\ge7$.

For $m=7$: $8\cdot343=2744<4374=2\cdot3^7$. If it holds for some $m\ge7$, then
\[
8(m+1)^3=8m^3\left(1+\dfrac{1}{m}\right)^3\le8m^3\left(\dfrac{8}{7}\right)^3<3\cdot8m^3<3\cdot2\cdot3^m=2\cdot3^{m+1},
\]
since $\left(\dfrac{8}{7}\right)^3=\dfrac{512}{343}<3$. By induction it holds for all $m\ge7$. So for even $n\ge14$ the number $n^3+3^n$ lies strictly between the consecutive squares $\left(3^m\right)^2$ and $\left(3^m+1\right)^2$ and is not a square.

The remaining even values are checked directly:
\[
\begin{array}{c|cccccc}
n&2&4&6&8&10&12\\ \hline
n^3+3^n&17&145&945&7073&60049&533169
\end{array}
\]
and these lie strictly between $4^2$ and $5^2$, $12^2$ and $13^2$, $30^2$ and $31^2$, $84^2$ and $85^2$, $245^2$ and $246^2$, $730^2$ and $731^2$ respectively. So $n^3+3^n$ is never a square for even $n$.
