Six friends independently receive a purchase code with probability $\dfrac{3}{7}$ each. A code allows buying up to four tickets, all at one chosen price: $ 50,100 $, or $ 200 $. All ticket types are available; surplus tickets can certainly be resold for twice their purchase price. The friends pool purchases and receipts, retain one ticket each (possibly in different sections), and require resale revenue to cover all purchases. Find the success probability.
