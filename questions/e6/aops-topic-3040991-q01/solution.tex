The first terms are $2,3,6,8,8,4,2,8,6,8$. The pair $(a_3,a_4)=(6,8)$ repeats as $(a_9,a_{10})=(6,8)$. Since each next term is determined by the preceding pair, the block $6,8,8,4,2,8$ repeats from position $3$ onward with period $6$. Now $2023-3=2020\equiv4\pmod6$, so position $2023$ has the fifth entry of that block: $\boxed2$.
