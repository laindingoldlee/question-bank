For every real $x$, $\sqrt{x^2}=|x|$, because the square root symbol means the nonnegative root. So $\sqrt{x^2}=x$ exactly when $x\ge0$, and $\sqrt{x^2}\ne x$ exactly when $x<0$ (then $\sqrt{x^2}=-x>0>x$). The greatest such integer is $\boxed{-1}$: $\sqrt{(-1)^2}=1\ne-1$, while $\sqrt{0^2}=0$.
