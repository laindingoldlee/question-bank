With $a=b=0$: $3f(0)=4f(0)-2$, so $f(0)=2$. With $a=0$: $f(b)+2f(-b)=6+f(-b)-2$, so $f(b)+f(-b)=4$. With $b=a$: $f(2a)+2f(0)=3f(a)+f(-a)-2=2f(a)+2$, so $f(2a)=2f(a)-2$, i.e. $g=f-2$ satisfies $g(2a)=2g(a)$.

Then $g(32)=96$ gives $g(16)=48$, $g(8)=24$, and $f(8)=\boxed{26}$. (Such an $f$ exists: $f(x)=3x+2$ satisfies the equation.)
