Write $T$ or $F$ for each statement. Statement 1 is true exactly when exactly one of statements 2 and 3 is false; statement 3 is true exactly when statements 1 and 2 are both true; statement 2 is consistent with either value.

\textbf{Statement 3 is false.} If it were true, statements 1 and 2 would be true, so statements 2 and 3 would both be true, and statement 1 would be false. Contradiction.

Since statement 3 is false, statements 1 and 2 are not both true. On the other hand, with statement 3 false, statement 1 is true exactly when statement 2 is true (exactly one of statements 2 and 3 is then false). So statements 1 and 2 have the same truth value and are not both true, hence both are false. The only consistent assignment is
\[\boxed{(F,F,F)}.\]
It checks: statement 1 is false because both statements below it are false, statement 2 can consistently be false, and statement 3 is false because statements 1 and 2 are false. This answers (b), and since no statement is true, (a) follows. $\blacksquare$
