If there are $k$ correct options, the probability is $\dfrac{k}{4}$. Probability $0$ makes the $0\%$ option correct, contradicting $k=0$. Probability $\dfrac{1}{4}$ makes two $25\%$ options correct, contradicting $k=1$. Probability $\dfrac{1}{2}$ makes only one $50\%$ option correct, contradicting $k=2$. Probabilities $\dfrac{3}{4}$ and $1$ have no matching options, contradicting $k=3,4$. All possibilities fail, so the premise has no consistent answer.
