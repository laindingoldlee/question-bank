Expand each power with the binomial theorem (or by repeated multiplication), then collect like terms.

\textbf{(a)} $(t-1)^3=t^3-3t^2+3t-1$ and $5(2t-4)^2=5\left(4t^2-16t+16\right)=20t^2-80t+80$. So
\[(t-1)^3+5(2t-4)^2+6=t^3+(-3+20)t^2+(3-80)t+(-1+80+6)=\boxed{t^3+17t^2-77t+85}.\]

\textbf{(b)} Using the coefficients $1,4,6,4,1$,
\[(x-3)^4=x^4-4\cdot3x^3+6\cdot9x^2-4\cdot27x+81=x^4-12x^3+54x^2-108x+81,\]
and $6(2x+3)^2=6\left(4x^2+12x+9\right)=24x^2+72x+54$. So
\[(x-3)^4+6(2x+3)^2+7=\boxed{x^4-12x^3+78x^2-36x+142}.\]
