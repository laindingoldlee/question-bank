ORDERED has the letters O, R, R, D, D, E, E. Glue one R, one E and one D into a block $[\mathrm{RED}]$. The remaining letters O, R, D, E are all different, so with the block there are $5$ different symbols and $5!=120$ arrangements. Every arrangement containing RED arises this way.

An arrangement is produced twice exactly when it contains RED twice (either occurrence can be the glued block). Two copies of RED use both R's, both E's and both D's, so only O is left; the arrangements of the symbols RED, RED, O are
\[
\mathrm{REDREDO},\quad \mathrm{REDORED},\quad \mathrm{OREDRED},
\]
that is, $\dfrac{3!}{2!}=3$ of them. (RED cannot overlap itself, so there is no other way to see it twice.) By inclusion--exclusion, the number of arrangements containing RED is
\[
120-3=\boxed{117}.
\]
