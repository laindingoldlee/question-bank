For a Poisson variable $X$ with mean $\lambda$, $P(X=k)=e^{-\lambda}\dfrac{\lambda^k}{k!}$. Using the complement,
\[P(X>3)=1-e^{-2.7}\left(1+2.7+\dfrac{2.7^2}{2}+\dfrac{2.7^3}{6}\right)=1-e^{-2.7}(1+2.7+3.645+3.2805).\]
The bracket is $10.6255$ and $e^{-2.7}\approx0.067206$, so $P(X>3)\approx1-0.7141=\boxed{0.286}$.
