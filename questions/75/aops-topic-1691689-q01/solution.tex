$\boxed{\text{False.}}$ Two sets are equal exactly when they have the same elements. The empty set $\varnothing$ has no elements, while $\{\varnothing\}$ has exactly one element, namely the set $\varnothing$. So the sets differ (for instance $\varnothing\in\{\varnothing\}$ but $\varnothing\notin\varnothing$). What is true is $\varnothing\in\{\varnothing\}$ and $\varnothing\subseteq\{\varnothing\}$.
