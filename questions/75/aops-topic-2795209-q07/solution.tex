Write the numbers as $100a+b$ and $100c+d$ with digits $a,c\ge1$. Then
\[(100a+b)(100c+d)=10000ac+100(ad+bc)+bd=328042.\]
Since $bd\le81<100$, $bd$ equals the last two digits, $42$, so $\{b,d\}=\{6,7\}$. Then $100ac+(ad+bc)=3280$. Because $ad+bc\le 9\cdot7+9\cdot6=117$, we need $ac=32$ and $ad+bc=80$, so $\{a,c\}=\{4,8\}$. With $a=4,c=8$: $4d+8b=80$ forces $b=7,d=6$.

The numbers are $407$ and $806$ (indeed $407\cdot806=328042$), with sum $\boxed{1213}$.
