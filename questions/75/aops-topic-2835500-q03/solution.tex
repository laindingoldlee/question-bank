(a) If $3\mid2^n-3$ then $3\mid2^n$, which is impossible because $2^n$ has no prime factor $3$.

(b) Since $2\equiv-1\pmod3$, $2^n\equiv(-1)^n\pmod 3$. This is $1$ exactly when $n$ is even. So $3\mid2^n-1$ iff $\boxed{n\text{ is even}}$.
