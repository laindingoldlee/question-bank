Let $q$ be the number of quarters and $d$ the number of dimes. In cents, $25q+10d=1300$, that is $5q+2d=260$. So $5q$ is even, $q$ is even, and $d=\dfrac{260-5q}{2}\ge0$ gives $q\le52$. Hence $q\in\{0,2,4,\dots,52\}$: $27$ solutions $(q,d)$, from $(0,130)$ to $(52,0)$.
\begin{enumerate}
\item[(b)] All of these are allowed: $\boxed{27}$ ways.
\item[(a)] We must remove $(0,130)$ and $(52,0)$, which use only one kind of coin: $\boxed{25}$ ways.
\end{enumerate}
