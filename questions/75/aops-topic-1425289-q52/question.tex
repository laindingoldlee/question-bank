\begin{enumerate}
\item[(a)] In how many ways can $\$13$ be made using only quarters and dimes, if at least one coin of each kind is used?
\item[(b)] In how many ways can $\$13$ be made using quarters and/or dimes, that is, using only these two kinds of coins but not necessarily both?
\end{enumerate}
