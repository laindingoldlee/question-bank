Factor $k^4+\dfrac{1}{4}=(k^2-k+\dfrac{1}{2})(k^2+k+\dfrac{1}{2})$. Since $k^2+k+\dfrac{1}{2}=(k+1)^2-(k+1)+\dfrac{1}{2}$, consecutive factors cancel across the alternating product. The result is $\dfrac{\dfrac{1}{2}}{(2n)^2 + 2 n + \dfrac{1}{2}} = \dfrac{1}{(4n+1)^2}$. Thus $4n+1=29$, giving $\boxed{n=7}$.
