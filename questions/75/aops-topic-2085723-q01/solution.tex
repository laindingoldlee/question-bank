Reduce modulo \(9\): \(17\equiv -1\) and \(541=540+1\equiv 1\), so \(-x\equiv 1\), i.e.\ \(x\equiv 8\pmod 9\). With \(x=8\), \(9y=541-136=405\), so \(y=45\). Since \(17\cdot 9=9\cdot 17\), all integer solutions are
\[
x=8+9k,\qquad y=45-17k\qquad(k\in\mathbb Z).
\]
(Any solution \((x,y)\) satisfies \(17(x-8)=9(45-y)\), and \(\gcd(17,9)=1\) forces \(9\mid x-8\).) Positivity requires \(k\ge 0\) and \(45-17k>0\), so \(k\in\{0,1,2\}\):
\[
\boxed{(x,y)=(8,45),\ (17,28),\ (26,11)}.
\]
