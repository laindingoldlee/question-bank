Put $m=\lceil\dfrac{n}{2}\rceil$. There are $m$ independent positions, so $10^m$ sequences. At every fixed position each value in $S$ occurs exactly $10^{m-1}$ times, giving total $55\cdot10^{m-1}$. Interchanging the two finite sums, the answer is $\boxed{\dfrac{55\cdot10^{m-1}(10^n-1)}{9}}$. This is a weighted sum, not a decimal-digit representation: the value 10 is explicitly allowed.
