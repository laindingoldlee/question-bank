First $ 8@4=512+256-8-4=756 $. Next $ 4@756=64+756^4-4-756=326653398600 $. Writing this last integer as $ v $, the requested value is $ 27+v^4-3-v=v^4-v+24 $. Thus an exact compact answer is $\boxed{326653398600^4-326653398576}$.
