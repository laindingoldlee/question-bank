In each minute: only akliu succeeds with probability $\dfrac1{10}\cdot\dfrac45=\dfrac4{50}$; only cj with $\dfrac9{10}\cdot\dfrac15=\dfrac9{50}$; both with $\dfrac1{50}$. Minutes with no success just repeat, so the answer is $\dfrac{4}{4+9+1}=\boxed{\dfrac27}$.
