For the square root to be defined we need $(x+5)^3\ge0$, i.e. $x\ge-5$. Squaring, $(x+5)^3=729=9^3$, and since a real number has only one real cube root, $x+5=9$, so $x=4$. Check: $\sqrt{9^3}=\sqrt{729}=27$. There is just one solution, so the sum is $\boxed{4}$.
