There are $\dbinom{49}{2}=1176$ equally likely pairs of squares. Adjacent pairs: each row has $6$ horizontally adjacent pairs, so there are $7\cdot6=42$; similarly $42$ vertical pairs. The probability is
\[
\dfrac{84}{1176}=\boxed{\dfrac{1}{14}}.
\]
