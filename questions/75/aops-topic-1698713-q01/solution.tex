Let $d(n)$ be the number of divisors. We need $d(n)=\dfrac {n}{2}$, so $n$ is even.

\textbf{A bound.} The divisors of $n$ pair up as $(d,\dfrac {n}{d})$, and in each pair the smaller one is at most $\sqrt n$. So $d(n)\le2\sqrt n$. Then $\dfrac {n}{2}\le2\sqrt n$ gives $\sqrt n\le4$, so $n\le16$.

\textbf{Check the even $n\le16$.}
\[
\begin{array}{c|cccccccc}
n&2&4&6&8&10&12&14&16\\\hline
d(n)&2&3&4&4&4&6&4&5\\
\dfrac {n}{2}&1&2&3&4&5&6&7&8
\end{array}
\]
Equality holds only for $n=8$ (divisors $1,2,4,8$) and $n=12$ (divisors $1,2,3,4,6,12$). The answer is $\boxed{n=8\text{ and }n=12}$.
