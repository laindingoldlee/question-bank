Whenever $\sqrt x$ is defined (as a real number), $\sqrt x-\sqrt x=0$ holds automatically. And $\sqrt x$ is defined exactly when $x\ge0$. So the solution set is $\boxed{\text{all real }x\ge0}$, the interval $[0,\infty)$.
