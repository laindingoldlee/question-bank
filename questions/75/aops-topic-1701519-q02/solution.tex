In base $3$ the digits after the point have place values $\dfrac{1}{3},\dfrac{1}{9},\dots$, so
\[
0.12_3=\dfrac{1}{3}+\dfrac{2}{9}=\dfrac{3}{9}+\dfrac{2}{9}=\boxed{\dfrac{5}{9}}.
\]
