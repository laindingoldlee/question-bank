In standard form the equation is $-2x^2+9x-4=0$, so $a=-2$, $b=9$, $c=-4$; the student used $c=4$. The answer is $\boxed{\textbf{(C)}}$. ((A) is wrong because $-b=-9$ is correct, (B) because $81+32=113$ is computed correctly, and (D) because dividing by $a$ is not required.)

Correctly, $b^2-4ac=81-32=49$, so
\[x=\dfrac{-9\pm7}{-4},\qquad x=\boxed{\dfrac12}\ \text{or}\ x=\boxed{4}.\]
