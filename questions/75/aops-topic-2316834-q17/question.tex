A student solved $-2x^2+9x=4$ with the quadratic formula as follows:
\[x=\dfrac{-9\pm\sqrt{9^2-4(-2)(4)}}{2(-2)}=\dfrac{-9\pm\sqrt{113}}{-4},\qquad x\approx0.41\text{ and }x\approx4.91.\]
Which statement describes the error?

$\textbf{(A)}$ In the numerator, $-9$ should be $9$.

$\textbf{(B)}$ The expression $9^2-4(-2)(4)$ does not simplify to $113$.

$\textbf{(C)}$ The equation is not in the form $ax^2+bx+c=0$, so the wrong value $c=4$ was used instead of $c=-4$.

$\textbf{(D)}$ Before using the quadratic formula, both sides must be divided by $-2$.

Correct the error and find the solutions.
