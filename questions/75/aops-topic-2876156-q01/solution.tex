Let $p=0.09\%=0.0009$.

(a) The runs are independent, so the $23$rd run drops the item with probability $\boxed{0.0009}$, regardless of what happened before.

(b) The player stops after exactly $23$ runs when runs $1$ to $22$ all fail and run $23$ succeeds:
\[(1-p)^{22}p=(0.9991)^{22}(0.0009)\approx\boxed{0.000882}.\]
