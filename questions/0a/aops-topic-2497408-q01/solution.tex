Since $3x+4y\le70$, we need $5z\ge18$, so $z\ge4$. Reducing mod $3$: $4y+5z\equiv88$, i.e. $y+2z\equiv1$, so $y\equiv1+z\pmod3$. For each $z$, list the $y\le10$ in the right residue class and compute $x=\dfrac{88-5z-4y}{3}$, keeping $1\le x\le10$:
\begin{itemize}
\item $z=4$ ($3x+4y=68$, $y\in\{2,5,8\}$): $x=20,16,12$; none.
\item $z=5$ ($63$, $y\in\{3,6,9\}$): $x=17,13,9$; gives $(9,9,5)$.
\item $z=6$ ($58$, $y\in\{1,4,7,10\}$): $x=18,14,10,6$; gives $(10,7,6)$, $(6,10,6)$.
\item $z=7$ ($53$, $y\in\{2,5,8\}$): $x=15,11,7$; gives $(7,8,7)$.
\item $z=8$ ($48$, $y\in\{3,6,9\}$): $x=12,8,4$; gives $(8,6,8)$, $(4,9,8)$.
\item $z=9$ ($43$, $y\in\{1,4,7,10\}$): $x=13,9,5,1$; gives $(9,4,9)$, $(5,7,9)$, $(1,10,9)$.
\item $z=10$ ($38$, $y\in\{2,5,8\}$): $x=10,6,2$; gives $(10,2,10)$, $(6,5,10)$, $(2,8,10)$.
\end{itemize}
So there are $\boxed{12}$ solutions:
\[(9,9,5),\ (10,7,6),\ (6,10,6),\ (7,8,7),\ (8,6,8),\ (4,9,8),\ (9,4,9),\ (5,7,9),\ (1,10,9),\ (10,2,10),\ (6,5,10),\ (2,8,10).\]
