The first row, with no adjacent equal colors, is either type ABA or type ABC. Each type has six labeled choices. For a fixed ABA row, the remaining rows have two valid completions; for a fixed ABC row, there are four. These counts can be checked by listing the twelve length-three rows with adjacent unequal entries, retaining pairs whose vertical entries differ and whose total color counts are each three. Thus the number is $6\cdot2+6\cdot4=\boxed{36}$.
