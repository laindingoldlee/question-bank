Let the counts be $s,g\ge0$. Then $7s-17g=1$, so $s\equiv5\pmod{17}$. The least nonnegative solution is $s=5,g=2$; all others are $s=5+17t,g=2+7t$ with $t\ge0$ and have larger total. The minimum value is $35+34=\boxed{69}$.
