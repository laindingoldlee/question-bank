\textbf{(a)} Yes: $0=n\cdot0$ for every integer $n$, so $0$ is a multiple of every integer. (Contest problems that ask for ``positive multiples'' exclude it.)

\textbf{(b)} $m=0\cdot k=0$ for every $k$, so the only multiple of $0$ is $\boxed{0}$ itself.

\textbf{(c)} They are $7k$ with $-20\le7k\le20$, i.e. $k=-2,-1,0,1,2$: the multiples $-14,-7,0,7,14$, so there are $\boxed{5}$ (including $0$).
