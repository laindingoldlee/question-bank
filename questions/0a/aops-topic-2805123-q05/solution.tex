A rational root exists iff the discriminant $b^2-4ac$ is a perfect square. Since $b$ is odd, $b^2\equiv1\pmod8$, and $4ac\equiv4\pmod8$ since $ac$ is odd. So $b^2-4ac\equiv5\pmod8$. But odd squares are $\equiv1\pmod8$, so the discriminant is not a square. $\blacksquare$
