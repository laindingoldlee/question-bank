The two triangles have the same altitude $CD$, so $AD:DB=1:4$. Write $AD=t$, $DB=4t$. The altitude theorem for a right triangle gives $CD^2=AD\cdot DB=4t^2$, so $CD=2t$. Now
\[
16=[ACD]=\dfrac{1}{2}t(2t)=t^2,
\]
hence $t=4$ and $\boxed{AB=5t=20}$.
