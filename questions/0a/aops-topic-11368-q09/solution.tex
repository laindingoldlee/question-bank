Move everything to one side: $(x+5)(x^2-x-12)=0$, i.e. $(x+5)(x-4)(x+3)=0$, so $x\in\{-5,-3,4\}$ and the smallest is $\boxed{-5}$. Dividing by $x+5$ is only valid when $x+5\ne0$, so it loses the solution $x=-5$.
