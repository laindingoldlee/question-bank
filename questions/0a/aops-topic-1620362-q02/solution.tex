The last block is $0001$, the one before it $0002$, and so on, so
\[
N=\sum_{k=1}^{2017}k\cdot10^{4(k-1)} .
\]
Since $10^2=100\equiv-1\pmod{101}$, we get $10^4\equiv1\pmod{101}$, so every power $10^{4(k-1)}$ is $\equiv1$. Hence
\[
N\equiv\sum_{k=1}^{2017}k=\dfrac{2017\cdot2018}{2}=2017\cdot1009\pmod{101}.
\]
Now $2017=19\cdot101+98\equiv-3$ and $1009=9\cdot101+100\equiv-1$, so $N\equiv(-3)(-1)=3$. The remainder is $\boxed{3}$.
