\textbf{(a)} \emph{Changing any two lamps.} Let $X\ne Y$ be lamps and choose a set $T$ of $18$ other lamps (possible since $169\ge20$). Using the remote on $\{X\}\cup T$ and then on $\{Y\}\cup T$ changes every lamp of $T$ twice and $X$, $Y$ once each: the net effect is to change exactly $X$ and $Y$.

\emph{Changing one lamp.} Change $X$ together with $18$ other lamps in one use, and then change those $18$ lamps back in $9$ pairs as above. The net effect is to change $X$ alone.

So any single lamp can be switched, and switching every lamp that is on turns all lamps off.

\textbf{(b)} Suppose $k$ uses turn all lamps off. Each lamp must be changed an odd number of times, so each is changed at least once, and the total number of changes $19k$ is a sum of $169$ odd numbers, so $19k\ge169$ and $19k$ is odd. Hence $k\ge9$ ($19\cdot8=152<169$) and $k$ is odd.

Nine uses suffice: $9\cdot19=171=169+2$, so we let one lamp $X$ be changed three times and every other lamp once. Split the other $168$ lamps into three groups of $18$ and six groups of $19$ ($3\cdot18+6\cdot19=168$). Use the remote on each group of $18$ together with $X$, and on each group of $19$. Then $X$ is changed $3$ times, an odd number, and every other lamp exactly once, so all lamps end up off.

So the least number of uses is $\boxed{9}$.
