Clue 738 eliminates 7,3,8. Thus 380 shows that 0 occurs but not in the last position. Digit 6 cannot be present:682 would put it first, contradicting 614's wrong-position condition. Hence 682 puts 2 last. Then 206 requires 0 as its other present digit and forbids 0 in the middle; consequently 0 is first. In 614, digit 1 cannot be the middle digit because that would be its shown position, so 4 is the remaining digit and goes in the middle. The code is $\boxed{042}$, which satisfies every clue.
