Write $[XYZ]$ for the area of triangle $XYZ$.

\begin{asy}
usepackage("amsmath");
size(5cm);
defaultpen(fontsize(10pt));
pair A=(0,0), B=(6,0), C=(2,4);
pair D=(A+B)/2, E=A+(2/3)*(C-A);
pair O=extension(C,D,B,E);
fill(B--D--O--cycle,paleblue); fill(C--E--O--cycle,palered);
draw(A--B--C--cycle,linewidth(0.9));
draw(C--D,linewidth(0.8)); draw(B--E,linewidth(0.8));
dot(A); dot(B); dot(C); dot(D); dot(E); dot(O);
label("$A$",A,SW); label("$B$",B,SE); label("$C$",C,N); label("$D$",D,S); label("$E$",E,W); label("$O$",O,NE);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

Add $[BOC]$ to both shaded triangles:
\[[BDO]+[BOC]=[BDC],\qquad [CEO]+[BOC]=[BEC].\]
So $[BDO]-[CEO]=[BDC]-[BEC]$, and we do not need to locate $O$ at all.

Triangles $BDC$ and $ABC$ have the same height from $C$, and $BD=\dfrac{1}{2}AB$, so $[BDC]=\dfrac{1}{2}\cdot12=6$. Triangles $BEC$ and $ABC$ have the same height from $B$, and $CE=\dfrac{1}{3}CA$, so $[BEC]=\dfrac{1}{3}\cdot12=4$. Hence
\[[BDO]-[CEO]=6-4=\boxed{2}.\]
