The condition says exactly that the set $A$ of colours used on the north side and the set $B$ used on the south side are disjoint. Count by $k=|A|$; the north side uses $k\in\{1,2,3\}$ colours, and then each south house can be any of the $4-k$ other colours (at least one is needed, so $k\le3$).

The number of ways to paint $3$ houses using exactly the colours of a given $k$-set is $1$ for $k=1$, $2^3-2=6$ for $k=2$, and $3!=6$ for $k=3$. Hence
\[
\binom41\cdot1\cdot3^5+\binom42\cdot6\cdot2^5+\binom43\cdot6\cdot1^5=972+1152+24=\boxed{2148}.
\]
