The displayed hours in this interval are $12,1,2,\dots,11$. Those using only $0$s and $1$s are $1$, $10$ and $11$: three choices ($12$ contains a $2$).

Minutes run from $00$ to $59$; the binary ones are $00,01,10,11$: four choices. Likewise four choices for seconds.

Total: $3\cdot4\cdot4=\boxed{48}$.
