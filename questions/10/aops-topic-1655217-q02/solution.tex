Adding the same amount $8$ to every value shifts every value by $8$ without changing their order or which values are equal.
\begin{itemize}
\item The middle value, the most common value and the average each go up by $8$: median $22$, mode $22$, mean $23$ ounces.
\item The range, a difference of two values, is unchanged: $8$ ounces.
\end{itemize}
\[
\boxed{\text{median }22,\ \text{mean }23,\ \text{mode }22,\ \text{range }8\ \text{(ounces)}}
\]
