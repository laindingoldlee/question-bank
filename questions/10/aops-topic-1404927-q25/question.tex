$55$ schoolchildren took part in a mathematics olympiad. Each problem on each paper was marked ``$+$'' if it was solved, ``$-$'' if it was attempted but not solved, or ``$0$'' if it was skipped. It turned out that no two papers had both the same number of ``$+$'' marks and the same number of ``$-$'' marks. What is the least possible number of problems in the olympiad?

(A) $6$\quad (B) $9$\quad (C) $10$\quad (D) $11$\quad (E) $12$
