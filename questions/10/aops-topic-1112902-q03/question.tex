A Bachet square is an arrangement of the sixteen cards Ace, King, Queen, Jack of each of the four suits in a $4\times4$ square so that each row, each column and each of the two main diagonals contains one Ace, one King, one Queen and one Jack, and also one card of each suit. How many Bachet squares are possible?
