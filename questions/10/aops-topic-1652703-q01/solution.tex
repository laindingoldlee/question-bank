Number the vertices $0,1,\dots,9$ around the decagon, vertex $k$ at angle $36k^\circ$ on a unit circle. The chord joining vertices $i$ and $j$ is perpendicular to the direction at angle $18(i+j)^\circ$, so two chords are parallel exactly when $i+j\equiv i'+j'\pmod{10}$. The chords therefore fall into $10$ classes, according to $s\equiv i+j\pmod{10}$.

\begin{asy}
usepackage("amsmath");

 for(int k=0;k<10;++k){draw(c+dir(36k)--c+dir(36(k+1)),linewidth(0.9));dot(c+dir(36k));label("$"+string(k)+"$",c+1.17*dir(36k),fontsize(9pt));}
}
int[][] A={{2,9},{3,8},{4,7}};

\textbf{$s$ odd} (left, $s=1$). The pairing $i\leftrightarrow s-i$ has no fixed vertex, so it splits the $10$ vertices into $5$ parallel chords. Two of them are sides (here $\{0,1\}$ and $\{5,6\}$, drawn thick), because $j-i=1$ gives $2i\equiv s-1\pmod{10}$, which has $2$ solutions. So each odd class contains $3$ parallel diagonals, giving $\dbinom32=3$ pairs.

\textbf{$s$ even} (right, $s=4$). The pairing fixes the two vertices with $2i\equiv s$ (here $2$ and $7$, marked), and the other $8$ vertices form $4$ parallel chords. None is a side, because $i+j$ even makes $j-i$ even. So each even class contains $4$ parallel diagonals, giving $\dbinom42=6$ pairs.

Check: $5\cdot3+5\cdot4=35$ diagonals. The number of pairs is
\[
5\cdot3+5\cdot6=\boxed{45}.
\]
There is no contradiction with having only $35$ diagonals: a pair is a choice of two diagonals, and the same diagonal belongs to several pairs (each diagonal in a class of $4$ is in $3$ pairs). Already $35$ diagonals form $\dbinom{35}{2}=595$ pairs in all.
