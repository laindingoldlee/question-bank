Use the Euclidean algorithm and back-substitute (one valid pair $(x,y)$ is given; others differ by multiples of $\left(\dfrac {b}{d},-\dfrac {a}{d}\right)$).
\begin{enumerate}
\item[(i)] $9002=4\cdot2009+966$, $2009=2\cdot966+77$, $966=12\cdot77+42$, $77=42+35$, $42=35+7$, $35=5\cdot7$. So $\gcd=7=2009\cdot(-233)+9002\cdot52$.
\item[(ii)] The algorithm ends with remainder $1$: $\gcd=1=13579\cdot247+2468\cdot(-1359)$.
\item[(iii)] $987654321=8\cdot123456789+9$ and $9\mid123456789$, so $\gcd=9=123456789\cdot(-8)+987654321\cdot1$.
\item[(iv)] $233$ and $144$ are consecutive Fibonacci numbers, so $\gcd=1=233\cdot(-55)+144\cdot89$.
\item[(v)] $234=143+91$, $143=91+52$, $91=52+39$, $52=39+13$, $39=3\cdot13$: $\gcd=13=234\cdot(-3)+143\cdot5$.
\end{enumerate}
