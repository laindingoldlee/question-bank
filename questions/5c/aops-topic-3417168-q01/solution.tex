Ignore results $2,6$. Among $1,3,4,5$, symmetry makes every order of first appearance equally likely. The event occurs exactly when $4$ is last among these four first appearances. This has probability $\boxed{\dfrac{1}{4}}$. All four eventually occur with probability one in an indefinitely extended sequence.
