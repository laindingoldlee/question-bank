For $n\ge10$, $n!!$ contains the factor $10$, so it ends in $0$. The first four terms are $2$, $8$, $48$ and $384$, with units digits summing to $2+8+8+4=22$. The units digit is $\boxed{\textbf{(B)}\ 2}$.
