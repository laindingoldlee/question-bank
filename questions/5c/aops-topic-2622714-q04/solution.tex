\textbf{(a)} There are nonzero constants $p$ and $q$ with $x=py$ and $x=\dfrac qz$. Then $py=\dfrac qz$, so $yz=\dfrac qp$ is constant. This agrees with the data: $25\cdot8=40\cdot5=200$. When $z=20$, $y=\dfrac{200}{20}=\boxed{10}$.

\textbf{(b)} The data involve only $y$ and $z$. For any nonzero constant $p$, the relations $x=py$ and $x=\dfrac{200p}{z}$ satisfy every condition, and then $x=10p$ when $z=20$. So $x$ could be any nonzero number; one known value of $x$ would be needed to find $p$.
