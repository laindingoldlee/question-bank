Find the error in the following argument.

``Since $i^4=1$, we have $i^5=i$. Taking square roots, $i^{2.5}=\left(i^5\right)^{0.5}=i^{0.5}=\sqrt{i}=\dfrac{1+i}{\sqrt2}$. On the other hand, $i^{2.5}=i^2\cdot i^{0.5}=-\sqrt i=-\dfrac{1+i}{\sqrt2}$. Therefore $\dfrac{1+i}{\sqrt2}=-\dfrac{1+i}{\sqrt2}$, so $1+i=0$.''\,
