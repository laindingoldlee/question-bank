Write $K=3(N-8)(N-28)$. Then $K=0$ for $N=8$ and $N=28$, and $K<0$ (not a square) for $8<N<28$. Also $K(36-N)=3(28-N)(8-N)=K(N)$, so the values are symmetric about $N=18$.

For $N=2,3,4,5,6,7$ we get $K=468,375,288,207,132,63$, and none is a square:
\[
21^2<468<22^2,\ 19^2<375<20^2,\ 16^2<288<17^2,\ 14^2<207<15^2,\ 11^2<132<12^2,\ 7^2<63<8^2 .
\]
By the symmetry, $N=29,\dots,34$ give the same six values. Next,
\[
N=35:\ 567\ (23^2<567<24^2),\qquad N=36:\ 672\ (25^2<672<26^2),\qquad N=37:\ 783\ (27^2<783<28^2),
\]
and $N=38$ gives $K=3\cdot30\cdot10=900=30^2$. So the answer is $N=\boxed{38}$.
