Euler's theorem cannot be applied modulo $100$ directly, since $\gcd(2,100)\ne1$, so work modulo $4$ and $25$. Modulo $4$: $2^{2013}\equiv0$. Modulo $25$: $\varphi(25)=20$ and $2013\equiv13\pmod{20}$, so $2^{2013}\equiv2^{13}=8192\equiv17\pmod{25}$. The number in $[0,100)$ that is $\equiv0\pmod4$ and $\equiv17\pmod{25}$ is $92$. The last two digits are $\boxed{92}$.
