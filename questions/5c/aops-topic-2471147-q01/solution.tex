From $na+b=ab+a+b$ we get $na=ab+a=a(b+1)$. Since $a\ge1$, we can divide by $a$: $n=b+1$, so $b=n-1$. (Conversely, every two-digit base-$n$ number with last digit $n-1$ has this property: $ab+a+b=a(n-1)+a+(n-1)=na+(n-1)$.)

Then $a+b=9$ gives $a+n-1=9$, i.e. $a+n=10$. As $a\ge1$, we need $n\le9$. The only perfect cube $n$ with $2\le n\le9$ is $n=8$. Hence $a=2$ and $b=7$, which are valid base-$8$ digits, and Bob's age is
\[8\cdot2+7=\boxed{23}.\]
(Check: $23=27_8$; the digits have sum $9$ and product $14$, and $14+9=23$.)
