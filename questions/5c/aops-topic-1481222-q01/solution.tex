A rectangle is determined by choosing $2$ of the $7$ horizontal grid lines and $2$ of the $10$ vertical grid lines, so there are $\dbinom72\dbinom{10}2=21\cdot45=945$ rectangles.

Count the complement. A rectangle of size $h\times w$ has an odd number of squares exactly when $h$ and $w$ are both odd. In a direction of length $6$ there are $6-h+1$ positions for a side of length $h$, so the number of odd lengths with positions is $6+4+2=12$ (for $h=1,3,5$). In the direction of length $9$ the count is $9+7+5+3+1=25$ (for $w=1,3,5,7,9$). So there are $12\cdot25=300$ rectangles with an odd number of squares, and
\[
945-300=\boxed{645}
\]
rectangles with an even number of squares.
