Prove the following facts for positive integers.
\begin{enumerate}
\item The number of positive divisors of $n$ is odd if and only if $n$ is a perfect square.
\item If $na$ is a perfect square and $\gcd(n,a)=1$, then $n$ and $a$ are both perfect squares.
\item If $nk^2$ is a perfect square, then $n$ is a perfect square.
\item For every integer $x$, both $4(x^2+x)+1$ and $4(x^2-x)+1$ are perfect squares.
\end{enumerate}
