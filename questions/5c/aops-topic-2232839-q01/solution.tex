Using $3^2=9\equiv-1\pmod5$,
\[3^{19}=\left(3^2\right)^9\cdot3\equiv(-1)^9\cdot3=-3\equiv\boxed{2}\pmod5 .\]
The student's set-up is right, but $(-1)^9=-1$ (an odd power), so the result is $-3$, not $3$ or $-1$; and $-3$ leaves remainder $2$ on division by $5$. Check: $3^4=81\equiv1$, so $3^{19}=\left(3^4\right)^4\cdot3^3\equiv27\equiv2\pmod5$.
