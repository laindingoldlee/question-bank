Work backwards. Before the square root the value was $4^2=16$. Undoing the additions and subtractions: $16+14-10+30-2=48$, which is $\dfrac {N}{3}$. So $N=144$.

In base $3$: $144=81+2\cdot27+9=1\cdot3^4+2\cdot3^3+1\cdot3^2+0\cdot3+0$, so
\[
N=\boxed{12100_3}.
\]
Check: $\dfrac{144}{3}+2-30+10-14=16$ and $\sqrt{16}=4$.
