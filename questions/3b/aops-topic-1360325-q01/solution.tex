A nondecreasing number is determined by how many times each digit $1,2,3,4$ is used: given the counts, there is only one nondecreasing order. So we count solutions of
\[
n_1+n_2+n_3+n_4=4,\qquad n_i\ge0 .
\]
By stars and bars ($4$ stars and $3$ bars) there are $\dbinom{7}{3}=\boxed{35}$ such numbers.
