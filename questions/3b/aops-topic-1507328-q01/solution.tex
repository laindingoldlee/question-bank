There are only three colours. By the pigeonhole principle, any four socks include two of the same colour: if all four had different colours there would have to be four colours. So the event is certain, and the probability is $\boxed{1}$.

(No counting is needed; the numbers $6$, $5$, $7$ only matter for drawing three socks or fewer.)
