If incrementing $n$ does not cause a carry, every digit except the units digit survives, so only one-digit numbers qualify: 1 through 9. Otherwise all digits before the final run of nines must disappear or change. For two digits, the possibilities are $19,29,39,49,59,69,79,99$; 89 fails because 90 still has a nine. For three digits they are $199,299,399,499,599,699,799,999$ by the same reasoning; any longer unchanged prefix would be shared. Thus there are $9+8+8=\boxed{25}$ values.
