Since $100\equiv-1\pmod{101}$, split into two-digit blocks from the right: $43,65,87,b9,2a,1$ with alternating signs:
\[43-65+87-\overline{b9}+\overline{2a}-1\equiv0\pmod{101}.\]
This is $64+(20+a)-(10b+9)=75+a-10b\equiv0$. Then $a-10b\equiv-75\equiv26$. With digits, $a-10b\in[-90,9]$, so $a-10b=-75$, i.e. $b=8$, $a=5$. Answer $10a+b=\boxed{58}$.
