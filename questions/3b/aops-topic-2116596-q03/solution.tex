There are $900$ three-digit numbers. Count the pairs $(S,E)$ with $1\le S\le9$, $0\le E\le9$ and $S\cdot E\le9$; each such pair gives exactly one number, with $O=S\cdot E$.
\begin{itemize}
\item $E=0$: all $9$ values of $S$ work (then $O=0$).
\item $E\ge1$: we need $S\cdot E\le9$. For $S=1,2,\dots,9$ the number of possible $E$ is $\left\lfloor\dfrac{9}{S}\right\rfloor=9,4,3,2,1,1,1,1,1$, a total of $23$.
\end{itemize}
So there are $9+23=32$ such numbers, and the probability is
\[\dfrac{32}{900}=\boxed{\dfrac{8}{225}}.\]
