\textbf{$x=75^\circ$ works.} Then $x-60^\circ=15^\circ$ and $105^\circ-x=30^\circ$, so the equation holds.

\textbf{It is the only solution.} Let $f(x)=\dfrac{\sin(x-60^\circ)}{\sin(105^\circ-x)}$ on $60^\circ<x<105^\circ$. There both angles $x-60^\circ$ and $105^\circ-x$ lie strictly between $0^\circ$ and $45^\circ$, where the sine is positive and increasing. As $x$ increases, $x-60^\circ$ increases, so the numerator increases; and $105^\circ-x$ decreases, so the positive denominator decreases. Hence $f$ is strictly increasing on the interval, and it takes the value $\dfrac{\sin15^\circ}{\sin30^\circ}$ at most once:

\begin{asy}
usepackage("amsmath");
size(7.5cm);
defaultpen(fontsize(10pt));
import graph;
real xs=0.1;
real f(real x){return Sin(x-60)/Sin(105-x);}
real F(real t){return f(60+t/xs);}
draw((0,0)--(4.4,0),Arrow(6));draw((0,0)--(0,3.6),Arrow(6));
label("$x$",(4.4,0),E);label("$y$",(0,3.6),N);
draw(graph(F,0.001,3.55),blue+linewidth(0.9));
real L=Sin(15)/Sin(30);
draw((0,L)--(4.2,L),dashed);
pair X=(1.5,L);dot(X);draw(X--(1.5,0),dotted);
label("$60^\circ$",(0,0),S);label("$75^\circ$",(1.5,0),S);label("$95^\circ$",(3.5,0),S);draw((3.5,0)--(3.5,0.07));
label("$\dfrac{\sin15^\circ}{\sin30^\circ}$",(0,L),W);
label("$y=\dfrac{\sin(x-60^\circ)}{\sin(105^\circ-x)}$",(3.0,2.6),W,blue);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

Since $f(75^\circ)=\dfrac{\sin15^\circ}{\sin30^\circ}$, the only solution is $x=75^\circ$. $\blacksquare$
