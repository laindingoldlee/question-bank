Let $P(x)=1+x+\cdots+x^{99}$, so $P(x)=\dfrac{1-x^{100}}{1-x}$ for $x\ne1$.
\begin{itemize}
\item $x\ge1$: every term is at least $1$, so $P(x)\ge100>8$.
\item $x\le-1$: $P(x)=(1+x)(1+x^2+x^4+\cdots+x^{98})\le0$, since $1+x\le0$.
\item $-1<x\le0$: $P(x)=\dfrac{1-x^{100}}{1-x}\le\dfrac{1}{1-x}\le1$.
\item $0<x<1$: each term $x^k$ is increasing, so $P$ is continuous and strictly increasing, with $P(0)=1<8<100=P(1)$.
\end{itemize}
So there is exactly one real solution, and it lies in $(0,1)$. Now
\[
P\!\left(\dfrac{7}{8}\right)=8\left(1-\left(\dfrac{7}{8}\right)^{100}\right)<8,\qquad P\!\left(\dfrac{8}{9}\right)=9\left(1-\left(\dfrac{8}{9}\right)^{100}\right).
\]
By Bernoulli's inequality, $\left(\dfrac{9}{8}\right)^{100}=\left(1+\dfrac{1}{8}\right)^{100}\ge1+\dfrac{100}{8}>9$, so $\left(\dfrac{8}{9}\right)^{100}<\dfrac{1}{9}$ and $P\!\left(\dfrac{8}{9}\right)>9-1=8$. Since $P$ is increasing on $(0,1)$, the solution lies strictly between $\boxed{\dfrac{7}{8}\text{ and }\dfrac{8}{9}}$ (numerically it is about $0.875$).
