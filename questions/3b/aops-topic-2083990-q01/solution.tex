Let $R$ be the event that it is raining and $T$ the event that all three Martians say it is raining.

If it is raining, all three say so exactly when all three are truth-tellers: $P(T\mid R)=\left(\dfrac{4}{5}\right)^3=\dfrac{64}{125}$. If it is not raining, all three say it is raining exactly when all three are liars: $P(T\mid \text{not }R)=\left(\dfrac{1}{5}\right)^3=\dfrac{1}{125}$. By Bayes' theorem,
\[P(R\mid T)=\dfrac{\dfrac{3}{10}\cdot\dfrac{64}{125}}{\dfrac{3}{10}\cdot\dfrac{64}{125}+\dfrac{7}{10}\cdot\dfrac{1}{125}}=\dfrac{192}{192+7}=\boxed{\dfrac{192}{199}}\approx0.965 .\]
