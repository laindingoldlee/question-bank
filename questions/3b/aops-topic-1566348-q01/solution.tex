Inverse proportionality means $x^2y^2$ is constant: $x^2y^2=3^2\cdot12^2=1296$. When $y=6$, $36x^2=1296$, so $x^2=36$ and
\[
x=\boxed{6\text{ or }-6}.
\]
(The condition only involves $x^2$, so it cannot distinguish $6$ from $-6$; if $x$ is known to be positive, the answer is $6$.)
