Find the number of ways to label the squares in a $6\times 6$ grid satisfying the following conditions:

\begin{enumerate}

\item Each square contains exactly one number, which is in the set $\{1,2,3,6\}$.

\item The numbers within each row and column multiply to $6$.

\item Each row and column contains no more than two numbers greater than $1$.

\end{enumerate}
