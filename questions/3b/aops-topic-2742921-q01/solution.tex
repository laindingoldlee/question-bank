We need nonnegative integers $a,b$ with $2a+5b=2020$. Then $5b$ is even, so $b$ is even: $b=0,2,4,\dots,404$, and each gives one $a=\dfrac{2020-5b}{2}\ge0$. That is $\boxed{203}$ ways. (If both kinds of note must be used, $b=0$ and $b=404$ are excluded, leaving $201$.)
