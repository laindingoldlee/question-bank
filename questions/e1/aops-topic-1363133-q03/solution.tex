Let $f_k=k+2$. Then
\[
f_k^2=k^2+4k+4=(k+4)+k(k+3)=(k+4)+k\,f_{k+1},
\]
so $f_k=\sqrt{(k+4)+k\,f_{k+1}}$ for every $k\ge1$. This suggests the value $f_1=\boxed{3}$; we check that the truncations really converge to it.

Let $T_N$ be the truncation in which the radical at level $N$ is replaced by $0$, and let $u_k$ ($k\le N$) be the values of the levels in the truncation, so $u_N=0$ and $u_k=\sqrt{(k+4)+k\,u_{k+1}}$. Then
\[
|u_k-f_k|=\dfrac{k\,|u_{k+1}-f_{k+1}|}{\sqrt{(k+4)+k u_{k+1}}+\sqrt{(k+4)+k f_{k+1}}}\le\dfrac{k}{k+2}\,|u_{k+1}-f_{k+1}|,
\]
because the second square root in the denominator equals $f_k=k+2$. Multiplying these inequalities for $k=1,\dots,N-1$,
\[
|T_N-3|=|u_1-f_1|\le\dfrac{1}{3}\cdot\dfrac{2}{4}\cdot\dfrac{3}{5}\cdots\dfrac{N-1}{N+1}\cdot(N+2)=\dfrac{2(N+2)}{N(N+1)}\to0 .
\]
So the expression equals $3$.
