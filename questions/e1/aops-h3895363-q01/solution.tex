Choose a sufficiently large rectangular period, so neighbour counting can be performed with opposite boundaries identified. If it contains $M$ mines and $S$ safe cells, count adjacent mine--safe pairs. Every safe cell contributes one, while every mine contributes at most eight, so $S\le8M$. Hence the density is $\dfrac{M}{M+S}\ge\dfrac{1}{9}$. Equality is attained by placing mines at cells whose two integer coordinates are both divisible by $3$. Each safe cell is adjacent to exactly one such mine; the $3\times3$ repeating tile contains one mine.
