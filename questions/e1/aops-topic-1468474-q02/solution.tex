Condition on the event $|a-b|=c$, where $a,b,c$ are the three rolls. All $216$ outcomes are equally likely, so we count outcomes. Since $c\ge1$ we need $a\ne b$, and then $c=|a-b|$ is determined: there are $6\cdot5=30$ outcomes $(a,b)$ with $a\ne b$, each giving one valid triple.

Count those with no $3$: $a,b\in\{1,2,4,5,6\}$, $a\ne b$, and $|a-b|\ne3$. Ordered pairs from these five values with $a\ne b$: $20$. Those with difference $3$: $\{1,4\},\{2,5\}$, giving $4$ ordered pairs. So $16$ outcomes have no $3$, and $30-16=14$ have at least one $3$.

The probability is $\dfrac{14}{30}=\boxed{\dfrac{7}{15}}$.
