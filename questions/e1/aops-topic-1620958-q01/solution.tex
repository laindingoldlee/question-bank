The left side is defined exactly when $x\ne0$ and $1+\dfrac{1}{x}\ne0$, that is $x\ne0$ and $x\ne-1$. For such $x$,
\[
\dfrac{1}{1+\dfrac{1}{x}}=\dfrac{x}{x+1}.
\]
So we need $x\ne0,-1$ with $x=a(x+1)$, that is $x(1-a)=a$.
\begin{itemize}
\item If $a=1$: the equation becomes $0=1$, so there is no solution.
\item If $a\ne1$: the only candidate is $x=\dfrac{a}{1-a}$. It is never $-1$ (that would need $a=a-1$). It is $0$ exactly when $a=0$, which is not allowed. So for $a\ne0,1$ there is exactly one solution, and for $a=0$ there is none. (Indeed the left side is a fraction with numerator $1$, so it is never $0$.)
\end{itemize}
The equation has no solution exactly for $\boxed{a=0\text{ and }a=1}$.
