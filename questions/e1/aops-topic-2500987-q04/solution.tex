Write $x_i=2y_i+1$ with $y_i\ge0$. Then $2(y_1+y_2+y_3)+3=13$, so $y_1+y_2+y_3=5$. By stars and bars the number of nonnegative solutions is $\dbinom{5+2}{2}=\boxed{21}$.
