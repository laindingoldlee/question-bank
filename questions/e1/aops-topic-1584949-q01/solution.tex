Let the base be $b$. Single digits mean the same in every base larger than them, so only the two-digit numerals change: $32$ means $3b+2$, $50$ means $5b$ and $10$ means $b$.

\textbf{Find the base.} The first equation says $\dfrac{3b+2}{4}=5$, so $3b+2=20$ and $b=6$.

\textbf{Check with the second.} In base $6$, $50$ means $30$, and $\dfrac{30}{5}=6$, which is written $10$ in base $6$. So the second equation holds too.

\textbf{Answer.} In base $6$, $10$ means $6$, and $\dfrac{1}{3}\times6=2$, written $\boxed{2}$ in base $6$.
