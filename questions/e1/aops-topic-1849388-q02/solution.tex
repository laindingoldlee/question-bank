Let there be $T$ square tables and $c$ chairs. Used singly, the tables seat $4T$, so $c=4T-9$. Doubled up there are $\dfrac {T}{2}$ big tables seating $6\cdot\dfrac {T}{2}=3T$, so $c=3T+9$. Then $4T-9=3T+9$, so $T=18$ and $c=\boxed{63}$ chairs.
