The Cheesy Pasta restaurant has a certain number of chairs and some square tables, each of which seats $4$ guests. Two square tables can be pushed together to make a bigger table that seats $6$ guests. If all the square tables are used individually, the restaurant would need $9$ more chairs than it has. If all the tables are used only as doubled-up tables, there would be $9$ chairs left over. How many chairs does the restaurant have?
