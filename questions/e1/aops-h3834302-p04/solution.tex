All terms have the same remainder exactly when $ar\equiv a\pmod{12}$: multiplication by $r$ then preserves that congruence inductively. For fixed $a\in\{1,\ldots,12\}$, the number of $r$ in the same range satisfying $12\mid a(r-1)$ is $\gcd(a,12)$. These gcds are $1,2,3,4,1,6,1,4,3,2,1,12$, summing to $\boxed{40}$.
