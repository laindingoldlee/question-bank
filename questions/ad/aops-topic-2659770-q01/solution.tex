Using $1^2+\cdots+n^2=\dfrac{n(n+1)(2n+1)}6$ and $1^3+\cdots+n^3=\dfrac{n^2(n+1)^2}4$, the ratio is
\[\dfrac{2(2n+1)}{3n(n+1)}.\]
For $n=1$ it equals $\dfrac{6}{6}=1$. For $n\ge2$, $3n(n+1)-2(2n+1)=3n^2-n-2=(3n+2)(n-1)>0$, so the ratio lies strictly between $0$ and $1$ and is not an integer. The only value is $\boxed{n=1}$.
