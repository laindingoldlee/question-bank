The time is $5\cdot60+20=320$ seconds, which is $\dfrac{320}{3600}=\dfrac{4}{45}$ hours. So the average speed is
\[16.12\div\dfrac{4}{45}=\dfrac{16.12\cdot45}{4}=\boxed{181.35}\text{ miles per hour}.\]
