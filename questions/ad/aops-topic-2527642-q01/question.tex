Using the numbers $5,4,3,2,1$ in this order, each exactly once, together with the operations $+$, $-$, $\times$, $\div$, exponentiation and parentheses (but without joining digits into longer numbers), one can make many integers; for example $5+4\times(3+2)-1=24$.
\begin{enumerate}
\item[(a)] A list claims $5-4-3^2+1=12$ and $5+4+3^2+1=17$. Check these, and give correct expressions for $12$ and $17$.
\item[(b)] Give an expression for each integer from $21$ to $40$.
\end{enumerate}
