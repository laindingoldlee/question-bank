The two blue marbles separate three ordered gaps. Each gap can contain only red marbles or only green marbles, because a mixed gap would contain a forbidden adjacent colour change. If the reds occupy one gap and greens another, there are $3\cdot2=6$ arrangements. If reds split between two gaps, greens must both fill the third, giving three arrangements. Splitting greens instead gives three more. Both colours cannot split because there are only three gaps. Total: $\boxed{12}$.
