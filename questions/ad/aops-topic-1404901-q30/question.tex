A bar code consists of alternate strips of black and white, always beginning and ending with a black strip. Each strip (of either colour) has width $1$ or $2$, and the total width of the bar code is $12$. How many different codes are possible, reading from left to right?

(A) $24$\quad (B) $132$\quad (C) $66$\quad (D) $12$\quad (E) $116$
