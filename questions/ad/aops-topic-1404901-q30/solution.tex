Since the colours alternate starting and ending with black, a code is determined by the sequence of strip widths, and the number of strips is odd. If there are $m$ strips, $t$ of which have width $2$, then $m+t=12$, so $m=12-t$ must be odd, i.e. $t$ is odd; also $t\le m$, so $t\le6$. For each $t$, the number of codes is the number of ways to choose which $t$ of the $m$ strips are wide:
\[
t=1:\ \binom{11}{1}=11,\qquad t=3:\ \binom{9}{3}=84,\qquad t=5:\ \binom{7}{5}=21 .
\]
The total is $11+84+21=\boxed{116}$, choice (E).
