\textbf{(a)} The decimal with $n$ nines is
\[0.\underbrace{99\ldots9}_{n}=\dfrac{9}{10}+\dfrac{9}{100}+\cdots+\dfrac{9}{10^n}=1-\dfrac{1}{10^n}.\]
Its distance from $1$ is $\dfrac{1}{10^n}$, which becomes smaller than any positive number as $n$ grows. So the decimals approach $1$, and $0.999\ldots=1$. (There is no ``last digit'' missing: if $0.999\ldots$ were less than $1$ by some positive amount $\varepsilon$, then $\dfrac{1}{10^n}\ge\varepsilon$ for all $n$, which is false.)

\textbf{(b)} $99.999\ldots=99+0.999\ldots=99+1=100$.

\textbf{(c)} Let the last nonzero digit $d\ge1$ of the terminating decimal be in the $k$-th place after the decimal point (for a whole number, $k=0$ refers to the units digit). Lower that digit by $1$ and append infinitely many 9s. By (a), the 9s from place $k+1$ on add up to $\dfrac{1}{10^k}\cdot0.999\ldots=\dfrac{1}{10^k}$, exactly the amount removed. So the value is unchanged. For example,
\[3.27=3.26+0.01=3.26+0.00999\ldots=\boxed{3.26999\ldots}.\]
