Every nonzero real number $t$ can be written as $\dfrac{2020}{x}$, with $x=\dfrac{2020}{t}$. Substituting this $x$,
\[f(t)=2020\cdot\dfrac{2020}{t}=\dfrac{2020^2}{t}.\]
So
\[f(x)=\boxed{\dfrac{2020^2}{x}}=\dfrac{4080400}{x}\qquad(x\ne0).\]
Check: $f\left(\dfrac{2020}{x}\right)=\dfrac{2020^2}{\dfrac{2020}{x}}=2020x$.
