The equation implies $x^3-y^3\ge1$, so $a=x-y$ is a positive integer. Put $b=x+y$; then
\[
(3a-4)b^2+8b+a^3-8=0.
\]
For $a\ge3$, the left side has minimum over real $b$ equal to $a^3-8-\dfrac{16}{(3a-4)}>0$, so this is impossible. For $a=1$, the equation is $-b^2+8b-7=0$, giving $b=1,7$. For $a=2$, it is $2b(b+4)=0$, giving $b=0,-4$.

Using $x=\dfrac{(a+b)}{2}$, $y=\dfrac{(b-a)}{2}$, all four pairs are
\[
\boxed{(1,0),(4,3),(1,-1),(-1,-3)}.
\]
Each satisfies the original equation.
