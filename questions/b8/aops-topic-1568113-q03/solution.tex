Such a number is determined by its set of digits: choose any $7$ of the nine digits $1,\dots,9$, and there is exactly one way to write them in increasing order. Conversely every such number gives a $7$-element set. So there are
\[
\dbinom97=\dbinom92=\boxed{36}
\]
numbers. No casework is needed: choosing the set already fixes the order. (Equivalently, choose the $2$ nonzero digits that are left out.)
