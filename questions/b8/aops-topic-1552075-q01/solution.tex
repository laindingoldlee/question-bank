Instead of the $6$ apples, look at the $3$ empty cells. A row contains $3$ apples exactly when it has no empty cell; so every row and every column must contain at least one empty cell. With only $3$ empty cells and $3$ rows, each row has exactly one empty cell, and likewise each column. So the empty cells form a permutation pattern: choosing the empty column in each row, with all columns different, gives $3!=\boxed{6}$ ways.
