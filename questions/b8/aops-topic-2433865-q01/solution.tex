\textbf{(a)} The real cube root of $-1$ is $-1$, so
\[(-1)^{\dfrac23}=\left(\sqrt[3]{-1}\right)^2=(-1)^2=\boxed{1}.\]
(Equivalently $\sqrt[3]{(-1)^2}=\sqrt[3]{1}=1$.)

\textbf{(b)} We need $w^3=1$, i.e. $(w-1)\left(w^2+w+1\right)=0$. So
\[w=1\qquad\text{or}\qquad w=\dfrac{-1\pm\sqrt3\,i}{2}.\]
In the complex numbers $-1=e^{i\pi}$, and the principal value is
\[e^{\dfrac23\cdot i\pi}=\cos120^\circ+i\sin120^\circ=\boxed{-\dfrac12+\dfrac{\sqrt3}{2}i},\]
one of the three cube roots of $1$. So the answer depends on the convention: with real cube roots the value is $1$, while the principal complex value is $-\dfrac12+\dfrac{\sqrt3}{2}i$.
