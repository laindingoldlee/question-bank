The pattern has period $5$ and contains $2$ red bulbs. Since $32=6\cdot5+2$, a string has $6$ full periods ($12$ red bulbs) followed by the bulbs blue, red, which add $1$ red bulb. So each string has $13$ red bulbs, and seven strings have $7\cdot13=\boxed{91}$.
