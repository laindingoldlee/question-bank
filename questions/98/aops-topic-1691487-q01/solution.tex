\textbf{Key fact.} Every open interval $(p,q)$ with $p<q$ contains a rational and an irrational number. Indeed, choose a positive integer $n$ with $\dfrac{1}{n}<q-p$; some multiple $\dfrac {m}{n}$ lies in $(p,q)$ (the multiples are spaced $\dfrac{1}{n}$ apart), so a rational lies in it. Similarly, choose $n$ with $\dfrac{\sqrt2}{n}<q-p$; some number $\dfrac{m\sqrt2}{n}$ with $m\ne0$ lies in $(p,q)$ (if $0$ is in the interval, use a nonzero multiple close to it), and it is irrational because $\sqrt2$ is.

\textbf{(a)} A segment of the line $y=1$ in the graph would mean $f(x)=1$ for every $x$ in some interval, i.e.\ the interval contains only rationals; this contradicts the key fact. In the same way no interval consists only of irrationals, so the graph contains no segment of $y=0$. On the other hand every interval contains a rational $r$ and an irrational $s$, giving the graph points $(r,1)$ and $(s,0)$. So the graph is two ``dotted lines'': infinitely many points on each of $y=0$ and $y=1$, dense in each line but with gaps everywhere. Having infinitely many points does not make a line; the graph on $y=1$ misses every irrational $x$.

\textbf{(b)} Fix $a$. For every $\delta>0$ the interval $(a-\delta,a+\delta)$ contains a rational $r$ and an irrational $s$, and $|f(r)-f(s)|=1$. So $|f(x)-f(a)|\ge\dfrac{1}{2}$ for $x=r$ or for $x=s$. With $\varepsilon=\dfrac{1}{2}$ no $\delta$ works in the definition of continuity, so $f$ is discontinuous at $a$. Since $a$ was arbitrary, $f$ is continuous nowhere. $\blacksquare$
