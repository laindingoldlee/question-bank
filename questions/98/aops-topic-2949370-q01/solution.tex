By definition $\lfloor a\rfloor$ is the unique integer $b$ with $b\le a<b+1$. Rearranging $a<b+1$ as $a-1<b$ shows that $b\le a<b+1$ is the same as $a-1<b\le a$.

For $a=3$, $b=\lfloor a\rfloor=3$, but $a-1\le b<a$ reads $2\le3<3$, which is false. So that version fails exactly at integers. $\blacksquare$
