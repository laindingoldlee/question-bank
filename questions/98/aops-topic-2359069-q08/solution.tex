$2018=2\cdot1009$ with $1009$ prime. Modulo $2$: $k^{2018}\equiv k$, and there are $1009$ odd $k$, so the sum is $\equiv1$. Modulo $1009$: for $1009\nmid k$, Fermat gives $k^{2018}=(k^{1008})^2k^2\equiv k^2$, and $k=1009$ contributes $0$. The values $k=1,\dots,2017$ run through each nonzero residue twice, so the sum is $\equiv2\sum_{r=1}^{1008}r^2=2\cdot\dfrac{1008\cdot1009\cdot2017}6\equiv0$. The number that is $\equiv0\pmod{1009}$ and odd is $\boxed{1009}$.
