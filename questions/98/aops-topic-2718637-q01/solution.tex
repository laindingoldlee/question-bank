Let $K=k_1+\cdots+k_{n-1}$. First arrange the letters of types $1,\dots,n-1$: $\dfrac{K!}{k_1!\,k_2!\cdots k_{n-1}!}$ ways. These leave $K+1$ gaps (including the two ends), and the $k_n$ letters of type $n$ go into distinct gaps: $\dbinom{K+1}{k_n}$ ways. Every valid word arises exactly once, so the count is
\[\boxed{\dfrac{K!}{k_1!\,k_2!\cdots k_{n-1}!}\dbinom{K+1}{k_n}},\]
which is $0$ when $k_n>K+1$.
