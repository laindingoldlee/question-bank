There are $\dfrac{10+15+17}{2}=21$ games. Alex rests in 11. No one can rest in consecutive games, so the only way to rest 11 times among 21 games is to rest on every odd-numbered game. Alex therefore plays game 2 and rests in game 3, meaning $\boxed{\text{Alex}}$ loses game 2.
