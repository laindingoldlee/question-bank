\textbf{(a)} If $f(x)=cx$, then $f(3x)=c\cdot3x=3(cx)=3f(x)$. Any $c\ne0$ gives a nonzero solution, for example $f(x)=x$.

\textbf{(b)} If $f(x)=|x|$, then $f(3x)=|3x|=3|x|=3f(x)$. But $|x|$ is not of the form $cx$: that would need $c=f(1)=1$ and $-c=f(-1)=1$ at the same time.

\textbf{(c)} Put $x=0$: $f(0)=3f(0)$, so $2f(0)=0$ and $f(0)=0$.

(The condition only links the values at $x,3x,9x,\dots$ and $\dfrac {x}{3},\dfrac {x}{9},\dots$, so there is a lot of freedom: one may choose $f$ arbitrarily for $1\le x<3$ and for $-3<x\le-1$ and extend by $f(3^kx)=3^kf(x)$.)
