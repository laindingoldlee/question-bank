Let the cost be $c$ cents. If $c$ is a whole number of dollars, Alex tips $0$, which is not more than Lev's tip. Otherwise write $c=100k+r$ with $1\le r\le99$. Alex tips $100-r$ cents and Lev tips $\dfrac{c}{5}$ cents, so we need
\[
100-r>\dfrac{100k+r}{5}\iff 500-5r>100k+r\iff 6r<500-100k .
\]
Since $r\ge1$, this requires $k\le4$. For $k=4$ it says $6r<100$, i.e.\ $r\le16$, so the largest cost is $c=416$: Alex tips $84$ cents and Lev $83.2$ cents. For $k<4$ the cost is below $400$. The answer is $\boxed{416}$ cents.
