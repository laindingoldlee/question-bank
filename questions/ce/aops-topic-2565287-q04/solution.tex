If $f(x)=a_3x^3+a_2x^2+a_1x+a_0$, then $f(1)=a_3+a_2+a_1+a_0$ is exactly the sum of the coefficients. So the sum is $f(1)=\boxed{12}$. (The value $f(0)=5$, the constant term, is not needed.)
