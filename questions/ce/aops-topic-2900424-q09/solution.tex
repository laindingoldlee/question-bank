Rearrange: $(x-y)(x^2+xy+y^2)=(x-y)(x+y)$. If $x\ne y$, then $x^2+xy+y^2=x+y$. But for positive integers $x^2\ge x$ and $y^2\ge y$, while $xy>0$, so this is impossible. Hence $x=y$, giving $\boxed{2021}$ pairs.
