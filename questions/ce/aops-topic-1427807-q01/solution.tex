At an intersection point $x=y^4$ and $x=1-y^2$, so $y^4+y^2-1=0$. As a quadratic in $y^2$,
\[
y^2=\dfrac{-1+\sqrt5}{2}
\]
(the other root is negative). So the intersection points are $P=(x_0,s)$ and $Q=(x_0,-s)$ with $s=\sqrt{\dfrac{\sqrt5-1}{2}}$ and the same $x_0=s^4$.

\begin{asy}
usepackage("amsmath");
size(5cm);
defaultpen(fontsize(10pt));
draw((-0.3,0)--(1.5,0),gray,Arrow(4)); draw((0,-1.3)--(0,1.35),gray,Arrow(4));
label("$x$",(1.5,0),E,gray); label("$y$",(0,1.35),N,gray);
guide g1,g2;
for(int i=0;i<=80;++i){real y=-1.08+2.16*i/80; g1=g1--(y^4,y);}
for(int i=0;i<=80;++i){real y=-1.2+2.4*i/80; g2=g2--(1-y^2,y);}
draw(g1,blue+linewidth(0.9)); draw(g2,heavygreen+linewidth(0.9));
pair P=(0.3820,0.7862), Q=(0.3820,-0.7862);
draw(P--Q,red+dashed+linewidth(0.9));
dot(P,red); dot(Q,red);
label("$P$",P,NE); label("$Q$",Q,SE);
label("$x=y^4$",(1.36,1.08),E,blue); label("$x=1-y^2$",(0.05,1.2),NE,heavygreen);
label("$1$",(1.04,-0.02),SE);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

The segment $PQ$ is vertical, so its length is
\[
PQ=2s=\sqrt{4\cdot\dfrac{\sqrt5-1}{2}}=\sqrt{-2+2\sqrt5}.
\]
Hence $(u,v)=\boxed{(-2,2)}$.
