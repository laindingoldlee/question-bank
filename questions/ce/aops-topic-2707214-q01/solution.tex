The number is $64\cdot11+R=704+R$ with $0\le R<64$, and it is $\equiv26\pmod{46}$. Since $704=15\cdot46+14$, we need $R\equiv12\pmod{46}$, so $R=12$ or $R=58$. Both work: the number is $\boxed{716\text{ or }762}$ ($716=15\cdot46+26$, $762=16\cdot46+26$).
