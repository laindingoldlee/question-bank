Every path consists of $3$ steps along the length, $2$ along the width and $2$ along the height, $7$ steps in all, in some order. Conversely, every arrangement of these $7$ steps is a path that stays on the edges of the box. So the number of paths is the number of arrangements of the letters $LLLWWHH$:
\[\dfrac{7!}{3!\,2!\,2!}=\dfrac{5040}{24}=\boxed{210}.\]
The student's errors: the box measures $3\times2\times2$, so a path has $3+2+2=7$ steps, not $3+2+3=8$; the student uses three steps in two of the three directions (and, read literally, steps to the left and steps to the right would cancel each other). Moreover, even the word $LLLUURRR$ has $\dfrac{8!}{3!\,2!\,3!}=560$ arrangements, not $\dfrac{8!}{2!\,2!\,3!}$: one of the repeated letters appears three times, not twice.
