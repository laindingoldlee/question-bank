A $3\times2\times2$ box is built from $12$ unit cubes. A path goes from one corner of the box to the opposite corner along edges of the unit cubes, and every step moves one unit in the positive direction of the length, the width or the height. A student counts the paths as follows: "We need three moves left, two up and three right, so the answer is the number of rearrangements of LLLUURRR, namely $\dfrac{8!}{2!\,2!\,3!}$." Find the errors in this argument and give the correct number of paths.
