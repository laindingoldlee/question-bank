Let $t=(x-20)(x-25)$. Pairing the original factors gives $(t+4)(t+6)=2025$, so $(t+5)^2=2026$. Thus $t=-5\pm\sqrt{2026}$. For real $x$, however, $t=(x-\dfrac{45}{2})^2-\dfrac{25}{4}\ge-\dfrac{25}{4}$. The negative branch violates this bound, while the positive branch is attained. The sum of the distinct attainable values is therefore $\boxed{\sqrt{2026}-5}$.
