Write $2^{60}=\left(2^{10}\right)^6=1024^6=10^{18}\cdot1.024^6$. Now
\[
1<1.024^6<1.03^6<1.2<10,
\]
(because $1.03^2=1.0609$ and $1.0609^3<1.07^3<1.23$), so $10^{18}<2^{60}<10^{19}$. A number between $10^{18}$ and $10^{19}$ has $\boxed{19}$ digits. Indeed $2^{60}=1\,152\,921\,504\,606\,846\,976$.

(Equivalently, $\log_{10}2^{60}=60\log_{10}2\approx60\cdot0.30103=18.06$, and the number of digits is $\lfloor18.06\rfloor+1=19$.)
