Let $p=10^{-6}$. After $n$ trials the event has not happened with probability $(1-p)^n$, and we need $(1-p)^n\le0.01$. Using $e^{-\dfrac{p}{1-p}}\le1-p\le e^{-p}$, this holds when $np\ge\ln100$ and fails when $\dfrac{np}{1-p}<\ln100$. So the least such $n$ lies between $(1-p)\cdot10^6\ln100$ and $10^6\ln100+1$, that is,
\[n\approx10^6\ln100\approx4605170.\]
The closest choice is $\boxed{\textbf{(D) }5000000}$ (the next closest, $2000000$, is about $2.6$ million away). Note that $1000000$ trials give only about $1-e^{-1}\approx63\%$ certainty.
