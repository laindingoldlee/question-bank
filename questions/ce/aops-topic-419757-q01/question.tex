A board game spinner is divided into three regions labeled $A$, $B$ and $C$. The probability of the arrow stopping on region $A$ is $\dfrac13$ and on region $B$ is $\dfrac12$. The probability of the arrow stopping on region $C$ is

$\textbf{(A) } \dfrac1{12}\qquad\textbf{(B) } \dfrac16\qquad\textbf{(C) } \dfrac15\qquad\textbf{(D) } \dfrac13\qquad\textbf{(E) } \dfrac25$
