Let $c_n$ count strings of these digits with sum $n$, allowing the empty string only for $n=0$. Then $c_0=1$ and $c_n=c_{n-1}+c_{n-3}+c_{n-4}$, with negative-index terms zero, according to the last digit. This recurrence counts every possible length and order exactly once. The successive values for $n=0$ through $22$ are $1,1,1,2,4,6,9,15,25,40,64,104,169,273,441,714,1156,1870,3025,4895,7921,12816,20736$. Thus the answer is $\boxed{20736}$.
