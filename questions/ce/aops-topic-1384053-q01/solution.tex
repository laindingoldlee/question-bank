Write $\sigma(m)$ for the sum of the divisors of $m$. Between $49$ and $55$ the only abundant number is $54$ ($\sigma(54)=120>108$; for instance $\sigma(50)=93$, $\sigma(52)=98$). For $n=55$, $n+1=56$ is abundant ($\sigma(56)=120>112$), so it fails. For $n=56$, $n-1=55$ is deficient. For $n=57$: $n-1=56$ is abundant and $n+1=58=2\cdot29$ is deficient ($\sigma=90<116$). The answer is $\boxed{57}$.
