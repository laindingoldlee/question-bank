Monika and Marcelo's family owns two lawnmowers, a riding mower and a push mower. A person using the riding mower can mow the family's whole yard in $45$ minutes, and a person using the push mower can mow it in $105$ minutes. If Monika uses the riding mower and Marcelo uses the push mower, how many minutes will it take them to mow the yard together? Express your answer as a decimal to the nearest tenth.
