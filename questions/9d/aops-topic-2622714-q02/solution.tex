The distance is $30\cdot\dfrac12=15$ miles. Arriving $10$ minutes earlier means taking $20$ minutes, which is $\dfrac13$ hour, so the speed must be $\dfrac{15}{\dfrac13}=\boxed{45\text{ miles per hour}}$.

(For a fixed distance, speed is inversely proportional to time: $30\cdot30=v\cdot20$ gives $v=45$.)
