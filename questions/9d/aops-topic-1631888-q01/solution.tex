Either $8<3x+4<32$ or $-32<3x+4<-8$.

In the first case $4<3x<28$, so $\dfrac{4}{3}<x<\dfrac{28}{3}$, giving the integers $x=2,3,\dots,9$: $8$ values.

In the second case $-36<3x<-12$, so $-12<x<-4$, giving $x=-11,-10,\dots,-5$: $7$ values.

In total there are $8+7=\boxed{15}$ integers.
