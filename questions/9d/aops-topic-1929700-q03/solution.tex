If a digit is $0$, the product is $0$ while the sum is positive, so all three digits are at least $1$. Let the digits in increasing order be $x\le y\le z$. Then $xyz=x+y+z\le3z$, so $xy\le3$, i.e.\ $(x,y)\in\{(1,1),(1,2),(1,3)\}$.
\begin{itemize}
\item $(1,1)$: $z=2+z$, impossible.
\item $(1,2)$: $2z=3+z$, so $z=3$: digits $1,2,3$ ($6=6$).
\item $(1,3)$: $3z=4+z$, so $z=2<y$, contradicting $y\le z$.
\end{itemize}
So the digits must be $1,2,3$ in some order, giving the $3!=\boxed{6}$ numbers $123,132,213,231,312,321$.
