$\sin^{-1}$ returns the angle in $\left[-\dfrac\pi2,\dfrac\pi2\right]$ with the given sine. Since $\dfrac{4\pi}{7}>\dfrac\pi2$, it is not the answer; but $\sin\dfrac{4\pi}{7}=\sin\left(\pi-\dfrac{4\pi}{7}\right)=\sin\dfrac{3\pi}{7}$, and $\dfrac{3\pi}{7}$ lies in the range. So the value is $\boxed{\dfrac{3\pi}{7}}$.

\begin{asy}
usepackage("amsmath");
size(3cm);
defaultpen(fontsize(10pt));
draw(unitcircle,gray);draw((-1.3,0)--(1.3,0),gray,Arrow(4));draw((0,-1.2)--(0,1.3),gray,Arrow(4));
pair P=dir(180*4/7),Q=dir(180*3/7);
draw((0,0)--P,linewidth(0.8));draw((0,0)--Q,linewidth(0.8));draw(P--Q,dashed);dot(P);dot(Q);
label("$\dfrac{4\pi}{7}$",P,NW,fontsize(8pt));label("$\dfrac{3\pi}{7}$",Q,NE,fontsize(8pt));
\end{asy}
