Since $(a-b)^2=(b-a)^2$ and $b^2-a^2=(b-a)(b+a)$, the denominator is
\[(b-a)\cdot(b-a)(b+a)\cdot(2b-a)=(b-a)^2(b+a)(2b-a),\]
which is exactly the numerator $(b+a)(2b-a)(b-a)^2$. So the expression equals $\boxed{1}$ whenever it is defined, that is, whenever the denominator is not $0$: $a\ne b$, $a\ne-b$ and $a\ne2b$.
