Write $1024=a+b$ with $1\le a\le b$. Then $a\le512$, and every $a=1,2,\dots,512$ works, with $b=1024-a\ge a$. So there are $\boxed{512}$ ways. (If the order mattered, there would be $1023$ ways, one for each $a=1,\dots,1023$.)
