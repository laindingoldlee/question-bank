The numbers from $1$ to $100$ with remainder $5$ on division by $13$ are $5,18,31,44,57,70,83,96$; their remainders on division by $7$ are $5,4,3,2,1,0,6,5$. Only $31$ leaves remainder $3$. So the number is $\boxed{31}$, which is indeed prime.

The first two clues determine the number modulo $13\cdot7=91$ (Chinese remainder theorem), and only one number from $1$ to $100$ is congruent to $31$ modulo $91$ (the next one is $122$). So the third clue is not needed, which is how the number can be guessed at once.
