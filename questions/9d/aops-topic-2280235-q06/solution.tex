Write $s=\sqrt2$, $t=\sqrt3$. Over the common denominator $(1+s+t)(1+s-t)$, the numerator is
\[(1-s-t)(1+s-t)+(1-s+t)(1+s+t)=\bigl[(1-t)^2-s^2\bigr]+\bigl[(1+t)^2-s^2\bigr]=(2-2t)+(2+2t)=4,\]
using $(1\mp t)^2-s^2=1\mp2t+3-2$. The denominator is $(1+s)^2-t^2=1+2s+2-3=2s=2\sqrt2$. So the sum is
\[\dfrac{4}{2\sqrt2}=\boxed{\sqrt2}.\]
