Greedily pair the two farthest remaining points, remove them, and repeat. The first player always moves to the partner of the current point. Suppose an opponent responds with a longer edge. Its new endpoint must belong to a pair removed earlier: if it were still present when the previous pair was chosen, the greedy maximality would forbid this longer edge. The new point\textquotesingle s own pairing edge is longer than the opponent\textquotesingle s move, since both endpoints were available at the earlier pairing stage and distances are distinct. Thus the pairing reply is always legal. Pair indices strictly decrease after each opponent move, so eventually the opponent has no move.
