Let $t=\sqrt{x^2-x-1}\ge0$ (we need $x^2-x-1\ge0$). Then $-x-1=t^2-x^2$, so
\[
4x^2-6x-6=4x^2+6(-x-1)=4x^2+6(t^2-x^2)=6t^2-2x^2 .
\]
The equation becomes $6t^2-xt-2x^2=0$, which factors as
\[
(3t-2x)(2t+x)=0 .
\]
\emph{Case $3t=2x$.} Then $x\ge0$ and $9(x^2-x-1)=4x^2$, i.e.\ $5x^2-9x-9=0$, so $x=\dfrac{9\pm3\sqrt{29}}{10}$. Only $x=\dfrac{9+3\sqrt{29}}{10}$ is non-negative; it satisfies $t=\dfrac{2x}{3}\ge0$ by construction, so it is a solution.

\emph{Case $2t=-x$.} Then $x\le0$ and $4(x^2-x-1)=x^2$, i.e.\ $3x^2-4x-4=0$, $(3x+2)(x-2)=0$. Only $x=-\dfrac{2}{3}$ is $\le0$. Check: $x^2-x-1=\dfrac{4}{9}+\dfrac{2}{3}-1=\dfrac{1}{9}$, $t=\dfrac{1}{3}=-\dfrac {x}{2}$. It is a solution.

The solutions are
\[
\boxed{x=-\dfrac{2}{3}\quad\text{and}\quad x=\dfrac{9+3\sqrt{29}}{10}}.
\]
