\textbf{(a)} For $n=1$: $3\cdot1-20\cdot0=3$, which is not divisible by $7$. (Likewise $n=14$ gives $42-20=22$.)

\textbf{(b)} With $n=10a+b$,
\[3n-20a=30a+3b-20a=10a+3b\equiv3a+3b=3(a+b)\pmod7.\]
Since $\gcd(3,7)=1$, $7\mid3(a+b)$ if and only if $7\mid a+b$. So the congruence holds exactly when $\left\lfloor\dfrac n{10}\right\rfloor$ plus the last digit of $n$ is a multiple of $7$ (for example $n=16$: $48-20=28$). $\blacksquare$
