\textbf{(a)} For each $k\ge1$,
\[x^k-a^k=(x-a)\left(x^{k-1}+x^{k-2}a+\cdots+a^{k-1}\right).\]
If $p(x)=\sum c_kx^k$, then $p(x)-p(a)=\sum c_k\left(x^k-a^k\right)$, and every term has the factor $x-a$. So $p(x)=(x-a)q(x)+p(a)$ for a polynomial $q$; since the remainder on division by $x-a$ is a constant, it is $p(a)$. In particular $x-a$ divides $p(x)$ exactly when this remainder $p(a)$ is $0$.

\textbf{(b)} Substitute $x=\dfrac {r}{s}$ and multiply by $s^n$:
\[a_nr^n+a_{n-1}r^{n-1}s+\cdots+a_1rs^{n-1}+a_0s^n=0 .\]
All terms except the last contain the factor $r$, so $r$ divides $a_0s^n$. As $\gcd(r,s)=1$, $r$ shares no prime factor with $s^n$, so $r\mid a_0$. Likewise all terms except the first contain $s$, so $s\mid a_nr^n$ and hence $s\mid a_n$. $\blacksquare$

\textbf{(c)} By (a), the remainder on division by $x+2=x-(-2)$ is $p(-2)=-24-16+10+2=\boxed{-28}$.

By (b), a rational root $\dfrac {r}{s}$ has $r\mid2$ and $s\mid3$: the candidates are $\pm1,\pm2,\pm\dfrac{1}{3},\pm\dfrac{2}{3}$. Testing, $p(2)=24-16-10+2=0$, so by (a) $x-2$ is a factor, and dividing,
\[3x^3-4x^2-5x+2=(x-2)(3x^2+2x-1)=(x-2)(3x-1)(x+1).\]
The rational roots are $\boxed{2,\ \dfrac{1}{3},\ -1}$.
