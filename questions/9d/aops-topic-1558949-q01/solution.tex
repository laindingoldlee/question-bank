Write $ab^2-a^2b=b\cdot a(b-a)$. For fixed $b$, AM-GM gives $a(b-a)\le\left(\dfrac{a+(b-a)}{2}\right)^2=\dfrac{b^2}{4}$, with equality at $a=\dfrac {b}{2}$. So
\[
ab^2-a^2b\le\dfrac{b^3}{4}\le\dfrac{1}{4} ,
\]
with equality when $b=1$ and $a=\dfrac{1}{2}$ (which satisfy $0<a\le b\le1$). The greatest value is $\boxed{\dfrac{1}{4}}$.
