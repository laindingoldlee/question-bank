A $40$-problem test can be attacked with three theorems: FTWA, Adihaya's Lemma and WLT. WLT can be used only on problems where Adihaya's Lemma can also be used. On average, FTWA can be used on $50\%$ of the problems, Adihaya's Lemma on $40\%$ and WLT on $30\%$. Assume that whether FTWA can be used on a problem is independent of whether the other two can. What is the expected number of problems on which all three theorems can be used?
