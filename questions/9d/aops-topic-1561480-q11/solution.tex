A juice box costs $\dfrac{\$120}{120}=\$1$, so a bag of popcorn costs $\$0.50$. The number of bags sold is $\dfrac{120}{3}=40$, so the popcorn brought in
\[
40\cdot\$0.50=\boxed{\$20}.
\]
