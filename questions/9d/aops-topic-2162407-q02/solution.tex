Let $k$ be the common value. Then $a=k-1$, $b=k-2$, $c=k-3$, $d=k-4$, so $a+b+c+d=4k-10$. The last equality says $k=(4k-10)+5$, so $3k=5$ and $k=\dfrac{5}{3}$. Hence
\[a+b+c+d=4\cdot\dfrac{5}{3}-10=\boxed{-\dfrac{10}{3}}.\]
