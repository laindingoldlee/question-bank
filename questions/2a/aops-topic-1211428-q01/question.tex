Marco cubes a real number $t$ and then adds $10^3$, getting $m$. Julie adds $10$ to the same number $t$, getting $j\ne0$. They tell Tom only the value $x=\dfrac {m}{j}$. Tom (correctly) says: ``There are exactly two possible values of Marco's original number.'' Over all values of $x$ for which Tom's statement could be false, what is the greatest?
