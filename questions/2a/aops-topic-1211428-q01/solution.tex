Since $t^3+1000=(t+10)(t^2-10t+100)$ and $t\ne-10$,
\[x=\dfrac {m}{j}=t^2-10t+100=(t-5)^2+75.\]
For a given $x$, the possible $t$ are the solutions of $t^2-10t+100=x$ other than $t=-10$:
\begin{itemize}
\item if $x<75$ there are none, and if $x=75$ there is one ($t=5$);
\item if $x>75$ there are two real solutions, symmetric about $5$, unless one of them is $-10$. That happens when $x=(-10)^2-10(-10)+100=300$, whose solutions are $t=-10$ (excluded) and $t=20$.
\end{itemize}
So Tom's statement is true for every $x>75$ except $x=300$, and the greatest value of $x$ for which it fails is $\boxed{300}$.
