Exam C needs $21$ blocks, costing $210$. For A and B, each point costs at least $\dfrac{1}{2}$ unit of effort, so at least $100$ effort is necessary. If $3a+7b=100$, then $6a+10b=200-4b$, so meeting the target forces $b=0$, but $3a=100$ is impossible. If effort were $101$, the score would be $202-4b$; thus $b=0$, but $3a=101$ is also impossible. Effort $102$ works using $34$ A-blocks, scoring $204$. The total minimum is $\boxed{312}$.
