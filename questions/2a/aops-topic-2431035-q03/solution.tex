Let there be $c$ chests. With $9$ coins in each of $c-2$ chests all coins are used, and with $6$ coins in each of the $c$ chests $3$ coins are left, so the number of coins is
\[9(c-2)=6c+3\iff3c=21\iff c=7.\]
So there are $9\cdot5=\boxed{45}$ gold coins. (Check: $6\cdot7+3=45$.)
