Since $0+0=0$, distributivity gives $a0=a(0+0)=a0+a0$. Subtract $a0$ to obtain $a0=0$. If $b\ne0$, defining $\dfrac{b}{0}=q$ would require $0q=b$, contradicting $0q=0$. For $\dfrac{0}{0}$, every $q$ would satisfy $0q=0$, so it also fails to define a unique quotient.
