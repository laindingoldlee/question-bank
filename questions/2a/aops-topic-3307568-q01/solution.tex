The horizontal and vertical displacements are each $7$. If $d,r,u$ count diagonal, right, and up moves, then $d+r=d+u=7$ and $d+r+u=9$. Thus $d=5,r=u=2$. Every ordering stays in the board because all moves are monotone. The number is $\boxed{\dfrac{9!}{5!2!2!}=756}$.
\begin{asy}
usepackage("amsmath"); size(220);
for(int k=0;k<8;++k){draw((k,0)--(k,7),gray);draw((0,k)--(7,k),gray);}draw((0,0)--(5,5)--(7,5)--(7,7),blue+linewidth(1.4));dot((0,0));dot((7,7));label("$A$",(0,0),SW);label("$B$",(7,7),NE);
\end{asy}
