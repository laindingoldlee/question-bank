We need the discriminant to be positive: $b^2-4c>0$, i.e. $b^2>4c$.
\begin{itemize}
\item If $c<0$, then $4c<0\le b^2$ for every $b$: all $b\in(-\infty,\infty)$ work.
\item If $c\ge0$, then $b^2>4c$ means $|b|>2\sqrt c$: $b\in\left(-\infty,-2\sqrt c\right)\cup\left(2\sqrt c,\infty\right)$.
\end{itemize}
So the answer is
\[\boxed{b\in(-\infty,\infty)\text{ if }c<0;\qquad b\in\left(-\infty,-2\sqrt c\right)\cup\left(2\sqrt c,\infty\right)\text{ if }c\ge0.}\]
