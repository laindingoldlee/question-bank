The squares from $10^2$ to $31^2$ that read the same both ways: the last digit of a square is in $\{0,1,4,5,6,9\}$, and it must equal the first digit. Checking the squares with first digit $1,4,5,6,9$ ($100$--$196$, $400$--$484$, $529$--$576$, $625$--$676$, $900$--$961$) gives $121=11^2$, $484=22^2$ and $676=26^2$. Answer $\boxed{3}$.
