For a positive integer $n$ define
\[f(n)=\begin{cases}\dfrac n2,&n\text{ even},\\3n+1,&n\text{ odd}.\end{cases}\]
The \emph{Collatz conjecture} says that for every positive integer $n$, repeatedly applying $f$ eventually gives $1$. It is a famous unsolved problem, so no complete proof is expected. Prove the following partial results.
\begin{enumerate}
\item[(a)] If $n$ is a power of $2$, repeatedly applying $f$ reaches $1$.
\item[(b)] If $n>1$ and $n$ is even, then $f(n)<n$; if $n>1$ and $n\equiv1\pmod4$, then $f(f(f(n)))<n$.
\item[(c)] Suppose that every integer $n>1$ eventually reaches a value smaller than $n$ when $f$ is applied repeatedly. Prove that then the conjecture is true.
\end{enumerate}
