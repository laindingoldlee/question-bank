The digit sum is always $45$, so the integer is always divisible by $9$. It remains to be divisible by $2\cdot5^3=250$, which holds exactly when the last three digits form a multiple of $250$: $000$, $250$, $500$ or $750$. With distinct digits only $250$ and $750$ are possible. Each fixes the last three positions and leaves $7!$ arrangements of the others, so the probability is
\[\dfrac{2\cdot7!}{10!}=\dfrac2{720}=\dfrac1{360},\]
answer $\boxed{\textbf{(B)}\ \dfrac1{360}}$.
