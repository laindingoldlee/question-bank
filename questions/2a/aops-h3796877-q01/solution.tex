Since $91=7\cdot13$ and $K,O$ are digits, they must be $1,7$ in either order. The four middle digits must sum to $13$ and avoid $1,7$. The four-element subsets of $\{0,2,3,4,5,6,8,9\}$ with sum $13$ are $\{0,2,3,8\},\{0,2,5,6\},\{0,3,4,6\}$. To see completeness, a set without zero has sum at least $2+3+4+5=14$; with zero, listing triples from the remaining set gives exactly these three. Each set has $4!$ orders. Thus there are $2\cdot3\cdot24=\boxed{144}$ assignments.
