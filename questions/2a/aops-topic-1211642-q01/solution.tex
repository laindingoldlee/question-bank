Let $y=\dfrac{4x-16}{3x-4}$. Then $y^2+y-12=0$, so $y=3$ or $y=-4$.
\begin{itemize}
\item $y=3$: $4x-16=9x-12$, so $x=-\dfrac{4}{5}$.
\item $y=-4$: $4x-16=-12x+16$, so $x=2$.
\end{itemize}
Neither makes $3x-4=0$. The greatest value is $\boxed{2}$.
