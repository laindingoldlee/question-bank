Divisibility by $5$ requires the last digit to be $0$ or $5$, so it is $0$. Divisibility by $3$ requires the digit sum, which is $4$ times the number of $4$'s, to be a multiple of $3$; so there are at least three $4$'s. The smallest number with at least three $4$'s and last digit $0$ has four digits, and the only four-digit candidate is $4440$. So the answer is $\boxed{4440}=15\cdot296$.
