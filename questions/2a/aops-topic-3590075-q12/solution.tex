Write each number as $5k$. Since $5$ is coprime to $12$, the restriction is that $k$ is divisible by neither $3$ nor $4$. In each block of $12$, the allowed residues are $1,2,5,7,10,11$, six values. Since $78=13\cdot6$, the $79$th allowed $k$ is $13\cdot12+1=157$. The required number is $\boxed{785}$.
