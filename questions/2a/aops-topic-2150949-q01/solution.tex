The units digit of $378^E$ is the units digit of $8^E$, and the units digits of $8^1,8^2,8^3,8^4,\dots$ are $8,4,2,6$, repeating with period $4$ (for $E\ge1$). So we need $E$ modulo $4$.

\textbf{Top down.} Here $E=95^{23^{51}}$. Since $95\equiv-1\pmod4$ and $23^{51}$ is odd,
\[E\equiv(-1)^{\text{odd}}=-1\equiv3\pmod4 .\]
So the units digit is that of $8^3=512$, namely $\boxed{2}$.

\textbf{Left to right.} Now the number is $378^{95\cdot23\cdot51}$. Since $95\equiv23\equiv51\equiv-1\pmod4$, the exponent is $\equiv(-1)^3\equiv3\pmod4$, and the units digit is again $2$. So the answer does not change.
