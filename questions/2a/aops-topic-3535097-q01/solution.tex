Modulo 5, $3^4\equiv 1$, so $3^{2009}\equiv 3$. Also $7\equiv 2$ and $2007\equiv 3\pmod 4$, so $7^{2007}\equiv 2^3\equiv 3\pmod 5$. Their difference is 0 modulo 5, proving the claim.
