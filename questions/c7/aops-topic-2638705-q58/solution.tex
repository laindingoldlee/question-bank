Write $n=x-\{x\}=\lfloor x\rfloor$. For integer $x$, the ceiling is $n$, so the sum is $\boxed{2x-2\{x\}}$. For noninteger $x$, the ceiling is $n+1$, so the sum is $\boxed{2x-2\{x\}+1}$.
