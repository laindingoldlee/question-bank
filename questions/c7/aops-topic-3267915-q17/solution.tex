For each of the $201^2$ allowed pairs evaluate the two integer expressions and retain precisely those equal. This has no rounding or numerical tolerance:
\begin{verbatim}
sol = []
for m in range(-100,101):
    for n in range(-100,101):
        if m**3+n**3+231 == m*m*n*n+m*n:
            sol.append((m,n))
print(sol)
\end{verbatim}
This exhaustive algorithm yields the solution set displayed below. Every allowed pair is checked, so none can be missed.
\[\boxed{\{(4, 5),(5, 4)\}}.\]
