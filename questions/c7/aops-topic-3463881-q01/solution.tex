Write $x=da,y=db$ with $\gcd(a,b)=1$. Then $\operatorname{lcm}(x,y)=dab$, so $ab=10$. The ordered coprime pairs are $(1,10),(10,1),(2,5),(5,2)$. The first two allow $1\le d\le10$, and the last two allow $1\le d\le20$. Thus there are $2(10)+2(20)=\boxed{60}$ pairs.
