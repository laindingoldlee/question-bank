First combine the factors: $(a+3b)^2(a-3b)^2=\left[(a+3b)(a-3b)\right]^2=(a^2-9b^2)^2$. So the expression is
\[
(a^2-9b^2)^4=\sum_{k=0}^{4}\dbinom{4}{k}(a^2)^{4-k}(-9b^2)^k,
\]
which has one term for each $k=0,1,2,3,4$, all nonzero and of different degrees in $a$. There are $\boxed{\textbf{(b) }5}$ terms: $a^8-36a^6b^2+486a^4b^4-2916a^2b^6+6561b^8$.
