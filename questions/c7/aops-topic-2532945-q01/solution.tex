Complete the square: $x^2+14x+51=(x+7)^2+2\ge2$, with equality exactly when $x=-7$. The denominator is positive, so the fraction is largest when the denominator is smallest:
\[\dfrac{20}{(x+7)^2+2}\le\dfrac{20}{2}=10,\]
with equality at $x=-7$. The maximum value is $\boxed{10}$.
