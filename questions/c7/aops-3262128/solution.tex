Use $\sin x + \cos x = \sqrt{2} \sin (x + \dfrac{\pi}{4})$. Thus $\sin (x + \dfrac{\pi}{4}) = \dfrac{\sqrt3}{2}$, with $x + \dfrac{\pi}{4} \in [\dfrac{\pi}{4} , \dfrac{5 \pi}{4}]$. The only angles in this interval are $\dfrac{\pi}{3}$ and $\dfrac{2 \pi}{3}$. Subtracting $\dfrac{\pi}{4}$ gives $\boxed{x=\dfrac{\pi}{12},\dfrac{5\pi}{12}}$.
