Both right angles show that $AD$ is a diameter of the circumcircle. Put $A=(0,0),D=(12,0)$. Convex cyclic order puts $B,C$ on the same side of $AD$; reflect if necessary to put them above it. Triangle $ABD$ is a $30$-$60$-$90$ triangle, so $B=(3,3\sqrt3)$. Triangle $ACD$ is right isosceles, so $C=(6,6)$. Hence
\[BC^2=3^2+(6-3\sqrt3)^2=72-36\sqrt3,\]
giving $\boxed{BC=3(\sqrt6-\sqrt2)}$.

usepackage("amsmath");
size(7cm);
pair A=(0,0),D=(12,0),B=(3,3*sqrt(3)),C=(6,6);draw(circle((6,0),6),gray);draw(A--B--C--D--cycle);draw(A--C,dashed);draw(B--D,dashed);label("$A$",A,W);label("$B$",B,NW);label("$C$",C,N);label("$D$",D,E);label("$12$",(6,0),S);
\end{asy}
