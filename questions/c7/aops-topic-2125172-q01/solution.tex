Folding up the sides gives a box with base $(6-2x)$ by $(3-2x)$ and height $x$ (the flaps are glued inside, so they do not change the shape), where $0<x<\dfrac{3}{2}$:

\begin{asy}
usepackage("amsmath");
size(6cm);
defaultpen(fontsize(10pt));
real xx=(3-sqrt(3))/2;
draw((0,0)--(6,0)--(6,3)--(0,3)--cycle,linewidth(1));
pair[] Cn={(0,0),(6-xx,0),(6-xx,3-xx),(0,3-xx)};
for(int k=0;k<4;++k) filldraw(shift(Cn[k])*scale(xx)*unitsquare,paleblue,gray);
draw((xx,xx)--(6-xx,xx)--(6-xx,3-xx)--(xx,3-xx)--cycle,dashed);
draw((xx,0)--(xx,xx),red+linewidth(1.2)); draw((6-xx,0)--(6-xx,xx),red+linewidth(1.2));
draw((xx,3)--(xx,3-xx),red+linewidth(1.2)); draw((6-xx,3)--(6-xx,3-xx),red+linewidth(1.2));
label("$6$",(3,0),S); label("$3$",(6,1.5),E);
label("$x$",(xx/2,0),S,fontsize(8pt)); label("$x$",(0,xx/2),W,fontsize(8pt));
label("$6-2x$",(3,xx),N,fontsize(8pt)); label("$3-2x$",(xx,1.5),E,fontsize(8pt));
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

\[V(x)=x(6-2x)(3-2x)=4x^3-18x^2+18x .\]

\textbf{(a)} Then
\[V'(x)=12x^2-36x+18=6\left(2x^2-6x+3\right),\]
which is zero at $x=\dfrac{3\pm\sqrt3}{2}$. Only $x=\dfrac{3-\sqrt3}{2}\approx0.634$ lies in $\left(0,\dfrac{3}{2}\right)$ (the other root is about $2.37$). On the interval, $V'>0$ before this point and $V'<0$ after it, so it gives the maximum. There $6-2x=3+\sqrt3$ and $3-2x=\sqrt3$, so
\[V_{\max}=\dfrac{3-\sqrt3}{2}\cdot\left(3+\sqrt3\right)\cdot\sqrt3=\dfrac{9-3}{2}\cdot\sqrt3=3\sqrt3\approx5.20\text{ in}^3 .\]
So the maximum volume is $\boxed{3\sqrt3}$ cubic inches, at $\boxed{x=\dfrac{3-\sqrt3}{2}}\approx0.634$ inches.

\textbf{(b)} The midpoint rule works for a quadratic, whose graph is symmetric about the vertical line halfway between its roots. A cubic has no such symmetry. Indeed $V(0.75)=0.75\cdot4.5\cdot1.5=5.0625<3\sqrt3\approx5.196$, so $x=0.75$ does not give the largest box.
