The last digit of $n^2$ depends only on the last digit of $n$. Squaring $0,1,\dots,9$ gives $0,1,4,9,16,25,36,49,64,81$, with last digits $0,1,4,9,6,5,6,9,4,1$. The possible last digits are $0,1,4,5,6,9$, so the answer is $\boxed{6}$.
