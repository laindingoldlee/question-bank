Scale so $AB=AC=L$ and choose $A=(0,0),B=(L,0),C=(Lu,Lv)$, where $u^2+v^2=1$, $v>0$. Put $D=(d,0)$. The stated ordering forces $0<d<Lu<L$, so $u>0$.
Line intersections give
\[
F=(d,\dfrac{dv}{u}),\qquad E=(d,\dfrac{v(L-d)}{1-u}).
\]
Using vertical base $EF$ for the first area,
\[
[CEF]=\dfrac{v(Lu-d)^2}{2u(1-u)},\qquad
[ADF]=\dfrac{d^2v}{2u}.
\]
The area condition therefore gives $(Lu-d)^2=2d^2(1-u)$. Since $CE$ lies along $BC$,
\[
CE=\dfrac{Lu-d}{L(1-u)}\,BC
=(Lu-d)\sqrt{\dfrac{2}{1-u}},
\]
using $BC=L\sqrt{(1-u)^2+v^2}=L\sqrt{2(1-u)}$. Squaring yields $CE^2=4d^2$, and positivity gives $\boxed{CE=2AD}$.
