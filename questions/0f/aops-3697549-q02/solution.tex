No one-digit permitted number gains twelve. For a two-digit number $10a+b$, the rotated value is $10R(b)+R(a)$, where $R(0)=0,R(1)=1,R(8)=8,R(6)=9,R(9)=6$. Testing these five digit choices subject to a nonzero leading digit gives the first solution $86\mapsto98$, a gain of twelve. Thus $\boxed{86}$. Since it is two-digit, no longer number can be smaller.
