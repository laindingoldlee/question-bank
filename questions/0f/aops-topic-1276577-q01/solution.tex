$(x-4)(x+4)=x^2-16=609$, so $x=25$ and the sides are $21$ and $29$.

\begin{asy}
usepackage("amsmath");

defaultpen(fontsize(10pt));
path ra(pair P,pair u,pair v,real s=0.2){return P+s*unit(u)--P+s*unit(u)+s*unit(v)--P+s*unit(v);}
pair A=(0,0),B=(29,0),C=(29,21),D=(0,21); draw(A--B--C--D--cycle); draw(A--C,blue); draw(B--D,blue);
label("$A$",A,SW); label("$B$",B,SE); label("$C$",C,NE); label("$D$",D,NW); label("$x+4=29$",(14.5,0),S); label("$x-4=21$",(29,10.5),E);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

Each diagonal has length $\sqrt{21^2+29^2}=\sqrt{441+841}=\sqrt{1282}$, and $1282=2\cdot641$ has no square factor. The sum is $\boxed{2\sqrt{1282}}$.
