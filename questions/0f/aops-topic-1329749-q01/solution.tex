Count how the regions grow. Drawing a segment inside a region-divided convex polygon adds $1+(\text{number of crossings on it})$ regions. Start with $1$ region. The $5$ diagonals each add $1$, and in a convex pentagon every set of $4$ vertices gives one crossing, so there are at most $\dbinom54=5$ crossings, each adding $1$ region (no three diagonals of a pentagon can be concurrent at a crossing). Hence the number of regions is
\[
1+5+5=\boxed{11}.
\]
In general a convex $n$-gon with no three diagonals concurrent is divided into $1+\left(\dbinom n2-n\right)+\dbinom n4$ regions.
