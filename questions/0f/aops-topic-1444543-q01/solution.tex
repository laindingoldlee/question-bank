Let $N=\overline{abcd}$, so $4\cdot\overline{abcd}=\overline{dcba}$.
\begin{itemize}
\item $4N<10000$, so $N<2500$ and $a\in\{1,2\}$. Also $\overline{dcba}=4N$ is even, so its last digit $a$ is even: $a=2$.
\item Then $4N\ge8000$, so $d\ge8$; and the last digit of $4d$ must be $a=2$, so $d=8$ ($4\cdot8=32$; $d=9$ gives $36$).
\item Now $4(2000+100b+10c+8)=8000+100c+10b+2$, that is, $8032+400b+40c=8002+100c+10b$, which simplifies to $1+13b=2c$. So $b$ is odd and $2c\le18$ forces $b=1$, $c=7$.
\end{itemize}
Hence $N=\boxed{2178}$, and indeed $4\cdot2178=8712$. It is the only such number.
