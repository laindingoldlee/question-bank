\textbf{Anna.} She knows $B+C=14-A$. She can be sure $B\ne C$ only if $14-A$ is odd, i.e. $A$ is odd.

\textbf{Brett.} He knows $A+C=14-B$. He was sure that $A\ne C$, so $14-B$ is odd and $B$ is odd. He was also sure that $A\ne B$ and $C\ne B$; if $B\le6$, then $A=B$, $C=14-2B\ge2$ would be possible. So $B\ge7$, and $B\in\{7,9,11\}$ (as $A,C\ge1$).

\textbf{Chris.} He knows $C$ and $A+B=14-C$, with $A$ odd and $B\in\{7,9,11\}$; so $14-C$ is even and $C$ is even.
\begin{itemize}
\item $C=2$: $(A,B)=(5,7),(3,9),(1,11)$.
\item $C=4$: $(3,7),(1,9)$.
\item $C=6$: $(1,7)$ only.
\end{itemize}
Chris can deduce everything only if $C=6$, giving $A=1$, $B=7$, $C=6$ and $ABC=\boxed{42}$.
