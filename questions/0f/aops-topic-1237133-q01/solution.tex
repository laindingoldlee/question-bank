Write $n$ in binary: $n=8c_3+4c_2+2c_1+c_0$ with each $c_i\in\{0,1\}$; this is possible for every $0\le n\le15$. Hand over the boxes of $2^i$ marbles for which $c_i=1$. (For example $13=8+4+1$.) $\blacksquare$
