Zero cannot occur, so each number chooses a nonempty subset of digits $1$ through $9$, written in increasing order. There are nine one-digit numbers and $\binom92=36$ two-digit numbers, so the desired number is the 55th three-digit number. Those beginning with $1$ number $\binom82=28$; those beginning with $2$ number $\binom72=21$. Thus it is the sixth number beginning with $3$. These start $345,346,347,348,349,356$, giving $\boxed{356}$.
