Write $a=5$. Squaring, $a-x=a^2-2ax^2+x^4$, i.e. $a^2-(2x^2+1)a+x^4+x=0$. This factors as
\[\bigl(a-(x^2+x)\bigr)\bigl(a-(x^2-x+1)\bigr)=0.\]
\begin{itemize}
\item $x^2+x=5$: $x=\dfrac{-1\pm\sqrt{21}}2$. Here $5-x^2=x$, which must be $\ge0$, so only $x=\dfrac{-1+\sqrt{21}}2$ remains; then $5-x=x^2$ and $\sqrt{5-x}=x$ as required.
\item $x^2-x+1=5$: $x=\dfrac{1\pm\sqrt{17}}2$. Here $5-x^2=1-x\ge0$ forces $x\le1$, so $x=\dfrac{1-\sqrt{17}}2$; then $5-x=(1-x)^2$ and the equation holds.
\end{itemize}
The solutions are $\boxed{x=\dfrac{-1+\sqrt{21}}2\text{ and }x=\dfrac{1-\sqrt{17}}2}$.
