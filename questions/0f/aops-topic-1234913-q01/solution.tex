Factor: $n^9-n^3=n^3\left(n^3-1\right)\left(n^3+1\right)=n^3\left(n^6-1\right)$.
\begin{itemize}
\item Mod $8$: if $n$ is even, $8\mid n^3$; if $n$ is odd, $n^2\equiv1\pmod8$, so $n^6\equiv1$ and $8\mid n^6-1$.
\item Mod $9$: if $3\mid n$, $27\mid n^3$; otherwise $n^6\equiv1\pmod9$ (Euler, $\varphi(9)=6$).
\item Mod $7$: $n^7\equiv n$, so $n^9-n^3=n^2\left(n^7-n\right)\equiv0$.
\end{itemize}
So $8\cdot9\cdot7=504$ always divides it. At $n=2$, $n^9-n^3=504$, so nothing larger works. The answer is $\boxed{504}$.
