Complete the square in each variable:
\[x^2+8x+y^2-4y+z^2+2z=(x+4)^2+(y-2)^2+(z+1)^2-16-4-1 .\]
Each square is at least $0$, and all three are $0$ at $(x,y,z)=(-4,2,-1)$. So the minimum value is $\boxed{-21}$.
