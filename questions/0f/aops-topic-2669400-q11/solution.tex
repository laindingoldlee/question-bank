Put $x=2t$, $y=t$: $f(t)=f(2t)f(t)$, and dividing by $f(t)\ne0$ gives $f(2t)=1$ for every $t$. Hence $f\equiv1$ (every real number is $2t$ for some $t$), which indeed satisfies the equation. So $f(1977)=\boxed{1}$.
