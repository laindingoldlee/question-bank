Using 50 pennies as the baseline gives 32 extra cents. If there are $n,d,q$ nickels, dimes, quarters, then $4n+9d+24q=32$. Since $q\ge1$, we must have $q=1$, leaving $4n+9d=8$. Thus $d=0,n=2$, and the remaining 47 coins are pennies. The probability is $\boxed{\dfrac{47}{50}}$.
