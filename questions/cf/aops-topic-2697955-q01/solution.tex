Triangles $ABD$ and $ABC$ have the same base $AB$ and the same height (the distance between the parallel lines $AB$ and $CD$), so $[ABD]=[ABC]$. Subtracting the common triangle $ABE$ gives $[AED]=[BEC]$. $\blacksquare$

\begin{asy}
usepackage("amsmath");
size(3cm);
defaultpen(fontsize(10pt));
pair A=(0,0),B=(5,0),C=(3.6,2),D=(1,2);pair Ep=extension(A,C,B,D);
fill(A--Ep--D--cycle,lightgray);fill(B--Ep--C--cycle,lightgray);
draw(A--B--C--D--cycle,linewidth(0.8));draw(A--C);draw(B--D);
label("$A$",A,SW);label("$B$",B,SE);label("$C$",C,NE);label("$D$",D,NW);label("$E$",Ep,N);
\end{asy}
