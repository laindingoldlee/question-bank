Count the $m\times n$ arrays of $0$s and $1$s. Row by row: each row is one of $2^n$ binary strings of length $n$, and there are $m$ rows, so $(2^n)^m$ arrays. Column by column: each column is one of $2^m$ strings and there are $n$ columns, so $(2^m)^n$ arrays. Hence $(2^m)^n=(2^n)^m$.

In general, $\left(2^{b_1}\right)^{b_2}$ counts functions from a $b_2$-element set to binary strings of length $b_1$, i.e. binary arrays of shape $b_1\times b_2$. By induction, the tower $\left(\cdots\left(2^{b_1}\right)^{b_2}\cdots\right)^{b_k}$ counts the $k$-dimensional binary arrays of shape $b_1\times b_2\times\cdots\times b_k$, by fixing the coordinates one at a time. A binary array is just a function from the set of cells to $\{0,1\}$, and the number of cells $b_1b_2\cdots b_k$ does not depend on the order. So every ordering gives $2^{a_1a_2\cdots a_k}$. $\blacksquare$
