Write $\sqrt{25-x^2}=k$. The principal root gives $k\in\{0,1,2,3,4,5\}$. For $k=0,1,2,3,4$, $x=\pm\sqrt{25-k^2}$ gives two distinct values each. For $k=5$, only $x=0$ occurs. Thus the count is $\boxed{11}$.
