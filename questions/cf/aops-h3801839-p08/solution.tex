There are $1+2+\cdots+10=55$ roses, so $k$ must divide 55. Also $k\le10$ because there are ten vases and at most one rose per vase may be taken daily. Thus only $k=1,5$ are possible. One works trivially. For five, use eleven days: write 55 slots labelled by days $1,2,\ldots,11$ repeated five times, and assign consecutive blocks of lengths $1,2,\ldots,10$ to the ten vases. Each block has distinct day labels, and every day has five slots. This is a valid schedule, so there are $\boxed2$ possible values of k.
