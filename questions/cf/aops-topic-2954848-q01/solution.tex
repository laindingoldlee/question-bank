\emph{Last digit.} For every digit $d$, $d^5\equiv d\pmod{10}$, so $d^{13}=d^5\cdot d^5\cdot d^3\equiv d^5\equiv d$. The number ends in $9$, so $x$ ends in $9$.

\emph{Size.} $80^{13}=2^{39}\cdot10^{13}\approx5.5\times10^{24}$, which is smaller than $N\approx2.2\times10^{25}$. And $90^{13}=3^{26}\cdot10^{13}\approx2.5\times10^{25}$, which is larger than $N$. So $80<x<90$, and with last digit $9$, $x=\boxed{89}$.
