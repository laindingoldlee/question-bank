Write the fraction as $\dfrac{a}{b}$ in lowest terms with $a,b>0$. Cross-multiplication gives $(6-a)b=18a$, so $1\le a\le5$. Then $b=\dfrac{18a}{6-a}$ gives, for $a=1,2,3,4,5$, respectively $\dfrac{18}{5},9,18,36,90$. Only $(a,b)=(2,9)$ has integer denominator coprime to $a$. The answer is $\boxed{\dfrac{2}{9}}$; indeed $\dfrac{14}{21}=\dfrac{2}{3}$.
