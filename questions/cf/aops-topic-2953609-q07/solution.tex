Write $n=10q+r$. Then $10(q-3r)=n-31r$. If $p=31$ and $31\mid q-3r$, then $31\mid n$, so the rule holds for $31$.

Conversely, take $n=31$ ($q=3$, $r=1$): $q-3r=0$ is divisible by every $p$, so $p\mid31$. Hence $p=\boxed{31}$.
