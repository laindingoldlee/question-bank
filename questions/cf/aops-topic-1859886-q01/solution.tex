Let $t=\sqrt[3]{3}$, so $t^3=3$ and $x-3=t+t^2$. Cubing,
\[
(x-3)^3=(t+t^2)^3=t^3+3t^4+3t^5+t^6=3+9t+9t^2+9=12+9(t+t^2)=12+9(x-3).
\]
So $x^3-9x^2+27x-27=9x-15$, that is, $x^3-9x^2+18x-12=0$. Therefore
\[
x^3-9x^2+18x-10=(x^3-9x^2+18x-12)+2=\boxed{2}.
\]
