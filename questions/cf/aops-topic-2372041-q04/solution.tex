Both moduli are multiples of $4$, so each congruence fixes $N$ modulo $4$:
\begin{itemize}
\item $N\equiv5\pmod8$ means $N=8k+5=4(2k+1)+1$, so $N\equiv1\pmod4$;
\item $N\equiv7\pmod{12}$ means $N=12m+7=4(3m+1)+3$, so $N\equiv3\pmod4$.
\end{itemize}
These contradict each other, so the system has $\boxed{\text{no solution}}$. (The Chinese remainder theorem does not apply because $\gcd(8,12)=4\ne1$; a solution would need $5\equiv7\pmod4$.)
