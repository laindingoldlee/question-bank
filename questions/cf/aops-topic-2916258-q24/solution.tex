Track $e=v_2(n)$. The moves send $e$ to $2e+1$, $2e$, or $2e-2$, the last being an integer only if $e\ge1$. From $e\ge2$ every move gives $e\ge2$, so the walk is safe forever. Let $p_e$ be the probability of success from $e$. Then $p_0=\dfrac13p_1+\dfrac13p_0+\dfrac13\cdot0$ and $p_1=\dfrac13\cdot1+\dfrac13\cdot1+\dfrac13p_0$. The first gives $p_1=2p_0$, and then $2p_0=\dfrac23+\dfrac{p_0}3$, so $p_0=\boxed{\dfrac25}$.
