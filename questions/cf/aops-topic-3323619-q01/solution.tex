Using $(x-y)^2=2(x^2+y^2)-(x+y)^2$, any solution must satisfy $(x-y)^2=2r-r^2=r(2-r)$. With $r>0$, there are two solutions when $r<2$, none when $r>2$, and exactly one when $r=2$, namely $(x,y)=(1,1)$. Hence $\boxed{r=2}$.
