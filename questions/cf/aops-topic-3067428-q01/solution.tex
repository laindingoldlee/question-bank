Pair every divisor $d$ of $n$ with $\dfrac{n}{d}$. These are distinct except when $d^2=n$. If $n$ is not a square, all divisors form pairs, giving an even count. If $n$ is a square, exactly one divisor, $\sqrt n$, is paired with itself, leaving an odd total.
