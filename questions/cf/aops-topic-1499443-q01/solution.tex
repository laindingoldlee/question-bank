\textbf{Unordered sets.} There are $\binom{25}{4}=12650$ equally likely sets of four points. A rectangle with sides parallel to the grid is determined by choosing $2$ of the $5$ rows and $2$ of the $5$ columns, in $\binom52\binom52=100$ ways. So the probability is
\[
\dfrac{100}{12650}=\dfrac{2}{253}.
\]

\textbf{One point at a time.} Choosing a random set of four points is the same as choosing four distinct points one after another, each uniformly among the remaining points, and then forgetting the order. Every set of four arises from exactly $4!$ orders, so all sets are still equally likely. The event ``the four points form such a rectangle'' depends only on the set, so we may compute its probability with the ordered process.

The first point is arbitrary.
\begin{itemize}
\item With probability $\dfrac{8}{24}$ the second point is in the same row or column as the first. The third point must then lie on one of the two lines through the first two points perpendicular to their line ($8$ of the remaining $23$ points). The fourth point is then forced ($1$ of $22$).
\item With probability $\dfrac{16}{24}$ the second point is in a different row and column. The two points are then opposite corners, the other two corners are determined, and the probability of choosing them next is $\dfrac{2}{23}\cdot\dfrac{1}{22}$.
\end{itemize}
So the probability is
\[
\dfrac{1}{3}\cdot\dfrac{8}{23}\cdot\dfrac{1}{22}+\dfrac{2}{3}\cdot\dfrac{2}{23}\cdot\dfrac{1}{22}=\dfrac{8+4}{3\cdot23\cdot22}=\boxed{\dfrac{2}{253}}.
\]

\textbf{Why they agree.} Order is a tool, not part of the event. In the ordered count, each good set appears $4!$ times among the $25\cdot24\cdot23\cdot22$ ordered choices, and every set appears $4!$ times. So the ratio is the same as for unordered sets:
\[
\dfrac{100\cdot4!}{25\cdot24\cdot23\cdot22}=\dfrac{100}{\binom{25}4}.
\]
