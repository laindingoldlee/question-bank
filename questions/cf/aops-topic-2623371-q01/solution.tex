Write $n=d_k10^k+\cdots+d_110+d_0$ with digits $d_i$. Since $10\equiv1\pmod9$, we have $10^i\equiv1\pmod9$ for all $i\ge0$, so
\[n\equiv d_k+\cdots+d_1+d_0=S(n)\pmod9.\ \blacksquare\]
(Equivalently, $n-S(n)=\sum d_i\left(10^i-1\right)$ and each $10^i-1=99\cdots9$ is a multiple of $9$.)
