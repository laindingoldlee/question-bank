\textbf{Which amounts can be bought.} Look at the amounts $20b$ for $b=0,1,\dots,8$:
\[
0,\ 20,\ 40,\ 60,\ 80,\ 100,\ 120,\ 140,\ 160,
\]
whose remainders on division by $9$ are $0,2,4,6,8,1,3,5,7$: all nine remainders, each exactly once. If $n$ has the same remainder as $20b$ and $n\ge20b$, then $n=20b+9a$ with $a\ge0$, so $n$ can be bought.

\textbf{$151$ cannot be bought.} $151$ leaves remainder $7$, the remainder of $160$. Suppose $151=9a+20b$ with $a,b\ge0$. Then $20b\le151$, so $b\le7$, and $20b\equiv151\pmod9$. But among $b=0,\dots,7$ the remainders of $20b$ are $0,2,4,6,8,1,3,5$, never $7$. So $151$ cannot be bought.

\textbf{Every $n\ge152$ can be bought.} Let $b\in\{0,\dots,8\}$ be the value with $20b\equiv n\pmod9$. If $b\le7$, then $20b\le140<n$. If $b=8$, then $n\equiv160\equiv151\pmod9$ and $n\ge152$, so $n\ge160=20b$. In both cases $n\ge20b$, so $n$ can be bought.

So the largest amount that cannot be bought is $\boxed{151}$, which agrees with the formula $9\cdot20-9-20=151$.
