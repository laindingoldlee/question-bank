Write $\overline{2t6}=206+10t$ and $\overline{2v160}=20160+1000v$. Then
\[
135(206+10t)=27810+1350t=20160+1000v,
\]
so $1000v-1350t=7650$, i.e.\ $20v-27t=153$.

Since $0\le v\le9$, $20v\le180$, so $27t=20v-153\le27$ and $t\le1$. Also $27t=20v-153$ must be a nonnegative multiple of $27$: $t=0$ would need $20v=153$, impossible, while $t=1$ gives $20v=180$, $v=9$. Check: $135\times216=29160$.

So $t=1$, $v=9$ and $t+v=\boxed{10}$.
