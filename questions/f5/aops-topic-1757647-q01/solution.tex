Rearranging, $9x^2-6x+1<0$, that is, $(3x-1)^2<0$. A square of a real number is never negative, so $\boxed{\text{there is no real solution}}$. (With $\le$ instead of $<$, the only solution would be $x=\dfrac{1}{3}$.)
