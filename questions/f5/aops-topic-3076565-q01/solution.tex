Let $2a+3b=2016$, where $a,b$ are nonnegative integers. Modulo $2$, $b$ must be even, so write $b=2k$. Then $a=1008-3k\ge0$, giving $0\le k\le336$. Every one of these $337$ integers gives a distinct representation. The answer is $\boxed{337}$.
