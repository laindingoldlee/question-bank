Use the complement: the number of correct postings is binomial with $n=10$, $p=0.7$. Then
\[
P(X\le3)=\sum_{k=0}^{3}\dbinom{10}{k}(0.7)^k(0.3)^{10-k}\approx0.0000059+0.000138+0.001447+0.009002=0.010592,
\]
so $P(X\ge4)=1-P(X\le3)\approx\boxed{0.9894}$ (exactly $\dfrac{618379951}{625000000}$).
