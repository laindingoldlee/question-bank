For every $k$, $(k+1)^3-k^3=3k^2+3k+1$. Add these identities for $k=1,2,\dots,n$; the left side telescopes:
\[(n+1)^3-1=3\sum_{k=1}^n k^2+3\sum_{k=1}^n k+n=3S+\dfrac{3n(n+1)}{2}+n,\]
where $S=\sum k^2$. Hence
\[3S=(n+1)^3-(n+1)-\dfrac{3n(n+1)}{2}=(n+1)\left(n^2+2n-\dfrac{3n}{2}\right)=\dfrac{(n+1)n(2n+1)}{2},\]
so $S=\dfrac{n(n+1)(2n+1)}{6}$. $\blacksquare$
