The solutions are the $x$-coordinates of the intersections of $y=7\cos(3x-18^\circ)$ with the horizontal line $y=4$. The cosine graph has amplitude $7>4$ and period $\dfrac{360^\circ}{3}=120^\circ$, so it crosses the line twice per period, six times in $[0^\circ,360^\circ)$.

\begin{asy}
usepackage("amsmath");
size(9cm);
defaultpen(fontsize(10pt));
import graph;
real sx=1/36, sy=0.3;
real f(real x){return 7*Cos(3*x-18);}
path g=graph(new real(real t){return sy*f(t/sx);},0,10,400);
draw((0,0)--(10.4,0),gray,Arrow(5)); draw((0,-7.6*sy)--(0,7.8*sy),gray,Arrow(5));
draw(g,blue+linewidth(0.8));
draw((0,4*sy)--(10,4*sy),red);
label("$y=4$",(10,4*sy),E,red);
label("$y=7\cos(3x-18^\circ)$",(5.0,-7*sy),S,blue);
real a=aCos(4/7)/3;
real[] xs={6+a,126-a,126+a,246-a,246+a,366-a};
for(real x: xs){ dot((x*sx,4*sy),red); draw((x*sx,4*sy)--(x*sx,0),red+dashed); }
for(int k=1;k<=3;++k){ draw((120k*sx,0)--(120k*sx,-0.12),gray); label("$"+string(120k)+"^\circ$",(120k*sx,-0.12),S,gray); }
label("$7$",(0,7*sy),W,gray); label("$-7$",(0,-7*sy),W,gray);
draw((-0.08,7*sy)--(0.08,7*sy),gray); draw((-0.08,-7*sy)--(0.08,-7*sy),gray);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

Algebraically, $\cos\theta=\dfrac{4}{7}$ with $\theta=3x-18^\circ$. Let $\alpha=\arccos\dfrac{4}{7}\approx55.150^\circ$. Then
\[
3x-18^\circ=\pm\alpha+360^\circ k\quad\Longrightarrow\quad x=6^\circ\pm\dfrac{\alpha}{3}+120^\circ k,
\]
with $\dfrac{\alpha}{3}\approx18.383^\circ$. The values in $[0^\circ,360^\circ)$ are
\[
x\approx\boxed{24.4^\circ,\ 107.6^\circ,\ 144.4^\circ,\ 227.6^\circ,\ 264.4^\circ,\ 347.6^\circ}.
\]
