(a) Each ball independently chooses one of two boxes, giving $2^3=\boxed8$. (b) Only the counts matter: the first box contains $0,1,2,$ or $3$ balls, which determines the second count. Thus there are $\boxed4$ distributions. Distinguishability changes the sample space, so it must be specified.
