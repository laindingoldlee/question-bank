(a) The corners can be permuted in $8!$ ways and oriented in $3^8$ ways; the edges can be permuted in $12!$ ways and oriented in $2^{12}$ ways. So there are
\[8!\cdot3^8\cdot12!\cdot2^{12}=519\,024\,039\,293\,878\,272\,000\]
reassemblies.

(b) Each condition keeps exactly a fraction of the reassemblies:
\begin{itemize}
\item corner twist: once $7$ corners are oriented, the last corner's orientation is forced, so only $3^7$ of the $3^8$ orientations satisfy it (factor $\dfrac{1}{3}$);
\item edge flip: similarly only $2^{11}$ of the $2^{12}$ (factor $\dfrac{1}{2}$);
\item parity: for any corner permutation, exactly half of the $12!$ edge permutations have the matching parity (factor $\dfrac{1}{2}$).
\end{itemize}
So the number of reachable positions is
\[\dfrac{8!\cdot3^8\cdot12!\cdot2^{12}}{12}=8!\cdot3^7\cdot\dfrac{12!}{2}\cdot2^{11}=\boxed{43\,252\,003\,274\,489\,856\,000}.\]
(In particular a randomly reassembled cube is solvable with probability $\dfrac{1}{12}$.)
