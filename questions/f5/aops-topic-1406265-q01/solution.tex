\textbf{(a)} By induction, $a_k<2$: $a_1=\sqrt2<2$, and if $a_k<2$ then $a_{k+1}=\sqrt2^{\,a_k}<\sqrt2^{\,2}=2$. Also $a_k$ is increasing: $a_2=\sqrt2^{\sqrt2}>\sqrt2^{\,1}=a_1$, and if $a_{k+1}>a_k$ then $a_{k+2}=\sqrt2^{\,a_{k+1}}>\sqrt2^{\,a_k}=a_{k+1}$, because $t\mapsto\sqrt2^{\,t}$ is increasing. An increasing sequence bounded above converges, say to $L$ with $\sqrt2\le L\le2$, and by continuity $L=\sqrt2^{\,L}$, that is, $2^{\dfrac{L}{2}}=L$.

On $[\sqrt2,2]$ the only solution is $L=2$: the function $g(t)=\dfrac{t}{2}\ln2-\ln t$ is convex, $g(2)=g(4)=0$, so $g<0$ strictly between $2$ and $4$ and $g>0$ for $t<2$. Hence the tower with $x=\sqrt2$ equals $\boxed{2}$, not $4$.

\textbf{(b)} Suppose some $x>0$ gave a convergent tower with value $4$. The substitution step is valid for a convergent tower: the exponent is the same tower, so $x^4=4$ and $x=\sqrt2$. But by (a), the tower for $x=\sqrt2$ is $2$. This contradiction shows that $\boxed{\text{the equation has no solution}}$.

The student's error is to assume that the tower converges to $4$ and only then solve. The substitution gives a \emph{necessary} condition ($x=\sqrt2$), but one must check that the tower for $x=\sqrt2$ really equals $4$; it equals $2$. (The same substitution applied to the equation with right side $2$ also gives $x=\sqrt2$, and there it is correct.)
