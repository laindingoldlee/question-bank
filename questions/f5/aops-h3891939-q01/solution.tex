If a prime $p$ divides $n+1$, it must divide $n(n+9)$. It cannot divide $n$, so it divides $(n+9)-(n+1)=8$. Hence $n+1=2^k$ for some $k\ge1$, and $n$ is odd.

Any prime dividing $n$ must divide $(n+1)(n+24)$, and cannot divide $n+1$. It therefore divides 24. Since $n$ is odd, $n=3^r$ for some $r\ge0$. We need $3^r+1=2^k$. If $r=0$, $n=1$. If $r>0$ is even, the left side is 2 modulo 8, forcing $k=1$ and a contradiction. If $r$ is odd, the left side is 4 modulo 8, forcing $k=2,r=1$, so $n=3$.

For $n=1$, the products are 10 and 50, both with prime set $\{2,5\}$. For $n=3$, they are 36 and 108, both with prime set $\{2,3\}$. Thus the full answer is $\boxed{\{1,3\}}$.
