If $p$ is the eventual win probability, conditioning on the first game gives $p=\dfrac{3}{8}+\dfrac{1}{2}p$. Thus $\boxed{p=\dfrac{3}{4}}$. The probability of infinitely many draws is 0, so this accounts for all outcomes.
