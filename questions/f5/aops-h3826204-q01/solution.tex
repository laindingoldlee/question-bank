Write a decimal integer as $N=\sum_{i=0}^kd_i10^i$. Modulo $9$, $10^i\equiv1$, so $N\equiv\sum d_i$; therefore $9\mid N$ exactly when its digit sum is divisible by $9$. Modulo $11$, $10\equiv-1$, so $N\equiv d_0-d_1+d_2-\cdots$; therefore $11\mid N$ exactly when the alternating digit sum is divisible by $11$.
