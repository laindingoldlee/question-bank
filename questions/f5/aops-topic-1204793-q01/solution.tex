Replace each die value $d_i$ by $e_i=7-d_i$, also a die value from $1$ to $6$. The sum $27$ becomes $e_1+\cdots+e_5=35-27=8$. In positive integers summing to $8$, each $e_i\le8-4=4$, so the upper limit $6$ never matters, and stars and bars gives $\dbinom{8-1}{5-1}=\dbinom74=\boxed{35}=\dbinom73$. So the answer is a binomial coefficient because sums near the maximum correspond to small sums, where the cap of $6$ is irrelevant.
