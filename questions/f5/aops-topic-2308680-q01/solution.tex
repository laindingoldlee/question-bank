A positive integer with exactly $2$ positive divisors is a prime. Put $a=17352-x$; then $17358-x=a+6$, and the number is $|a|\cdot|a+6|$. Neither factor can be $0$ (the product must be positive), and if both $|a|\ge2$ and $|a+6|\ge2$, the product is composite. So one of the factors has absolute value $1$, and then the other must be prime:
\begin{itemize}
\item $a=1$: $|a+6|=7$, prime; $x=17351$.
\item $a=-1$: $|a+6|=5$, prime; $x=17353$.
\item $a+6=1$, $a=-5$: $|a|=5$, prime; $x=17357$.
\item $a+6=-1$, $a=-7$: $|a|=7$, prime; $x=17359$.
\end{itemize}
The sum is $17351+17353+17357+17359=\boxed{69420}$.
