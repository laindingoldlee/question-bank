It must first hit one of $-3,3$, and will do so with probability one. Suppose that first endpoint is $3$. Success then means hitting $-3$ before $4$. For a fair walk the hitting probability is linear between the absorbing endpoints, so it is $\dfrac{4-3}{4-(-3)}=\dfrac{1}{7}$. Starting from the first endpoint $-3$ gives the same result by symmetry. Therefore the unconditional probability is $\boxed{\dfrac{1}{7}}$.
