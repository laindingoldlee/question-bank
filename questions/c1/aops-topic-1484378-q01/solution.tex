\textbf{No.} The first values are
\[
3,\ 7,\ 31,\ 211,\ 2311,
\]
all prime, but for $n=6$,
\[
2\cdot3\cdot5\cdot7\cdot11\cdot13+1=30031=59\cdot509 .
\]
So $a_6+1$ is composite, and the answer is $\boxed{\text{no}}$.

However, $a_n+1$ leaves remainder $1$ on division by each of $p_1,\dots,p_n$, so none of them divides it. Since $a_n+1>1$, it has some prime factor, which must therefore be a prime other than $p_1,\dots,p_n$ (for $n=6$: $59$ and $509$). This is Euclid's argument that there are infinitely many primes; it does not say that $a_n+1$ itself is prime.
