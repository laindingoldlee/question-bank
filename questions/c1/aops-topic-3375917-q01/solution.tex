Let the integers be $a,b$, so the blank is $3b-a=3b-\dfrac{60}{b}$. Positivity requires $b^2>20$. The divisors of $60$ satisfying this are $5,6,10,12,15,20,30,60$, giving blank values $3,8,24,31,41,57,88,179$. They are distinct, so the answer is $\boxed8$, choice (C).
