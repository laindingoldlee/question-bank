\textbf{(a)} By Vieta's formulas $-\dfrac ba=-\dfrac32$, so $b=\dfrac{3a}2$. Since $b$ is an integer, $a$ is even: $a=2k$ and $b=3k$ for a nonzero integer $k$. From $f(2)=3$ we get $8k+6k+c=3$, so $c=3-14k$. Thus
\[f(x)=2kx^2+3kx+3-14k\qquad(k\ne0\text{ an integer}),\qquad a+b+c=3-9k.\]
The discriminant is $9k^2-8k(3-14k)=121k^2-24k=k(121k-24)$. Both factors have the same sign for every nonzero integer $k$, so it is positive, and the roots are real.

\textbf{(b)} $|3-9k|\le100$ means $-97\le9k\le103$, that is $-10\le k\le11$. With $k\ne0$ this gives $21$ values, whose sum is $11$. So the required sum is
\[21\cdot3-9\cdot11=\boxed{-36}.\]

\textbf{(c)} $|3-9k|\le1000$ means $-997\le9k\le1003$, that is $-110\le k\le111$. With $k\ne0$ this gives $221$ values with sum $111$, so the sum is
\[221\cdot3-9\cdot111=\boxed{-336}.\]
