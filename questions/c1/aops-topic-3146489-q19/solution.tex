Use inclusion--exclusion on the four events that a particular colour's two chairs are adjacent. For a specified set of $k$ such events, merge each designated pair into one circular block. There are $8-k$ blocks; the remaining $4-k$ colours still have two identical single chairs. The number of arrangements on the original eight labelled positions is $\dfrac{8(7-k)!}{2^{4-k}}$: count oriented circular orders of temporarily distinguishable blocks, choose an original starting position in eight ways, then divide by the swaps of each identical pair. This formula also gives $\dfrac{8!}{2^4}=2520$ when $k=0$. Consequently the desired count is $\sum_{k=0}^4(-1)^k\binom4k\dfrac{8(7-k)!}{2^{4-k}}=2520-2880+1440-384+48=\boxed{744}$.
