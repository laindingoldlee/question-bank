Write $z=x+iy$. The real part of $\dfrac{z-i}{z-1}$ is $\dfrac{x(x-1)+y(y-1)}{(x-1)^2+y^2}$. Thus the locus is $(x - \dfrac{1}{2})^2 + (y - \dfrac{1}{2})^2 = \dfrac{1}{2}$, with $(1,0)$ excluded. The distance from $(2,2)$ to its centre is $\dfrac{3}{\sqrt{2}}$ and its radius is $\dfrac{1}{\sqrt{2}}$, so the minimum distance is $\boxed{\sqrt2}$. The nearest point is $(1,1)$, which is allowed.
\begin{asy}
import graph;
usepackage("amsmath");
import geometry;
size(7cm);
pair O=(.5,.5),P=(2,2),Q=(1,1);draw(circle(O,sqrt(.5)));draw(O--P,dashed);dot(P);dot(Q);label("$(2,2)$",P,(1,1));label("$(1,1)$",Q,(1,-1));label("$(\dfrac{1}{2} , \dfrac{1}{2})$",O,(-1,0));
\end{asy}
