In general, if $ca\equiv cb\pmod m$ then $m\mid c(a-b)$, and we may conclude $a\equiv b\pmod m$ only when $\gcd(c,m)=1$; otherwise we only get $a\equiv b\pmod{\dfrac{m}{\gcd(c,m)}}$.

(a) $\gcd(3,10)=1$, so $10\mid3(2-12)$ implies $10\mid2-12$: the conclusion $2\equiv12\pmod{10}$ is valid (and indeed true).

(b) $\gcd(2,10)=2$, so we can only conclude $1\equiv6\pmod5$; the claim $1\equiv6\pmod{10}$ is false.

Answer: $\boxed{\text{(a) yes, since }\gcd(3,10)=1;\ \text{(b) no}}$.
