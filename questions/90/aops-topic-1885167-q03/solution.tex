If $n=p_1^{e_1}\cdots p_k^{e_k}$, the number of divisors is $(e_1+1)\cdots(e_k+1)$. This equals the prime $3$ only if $k=1$ and $e_1=2$, so $n=p^2$ for a prime $p$. Then $n^3=p^6$ has $6+1=\boxed{7}$ divisors.
