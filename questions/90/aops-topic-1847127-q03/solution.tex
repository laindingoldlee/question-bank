We need $y\ne0$ for $\dfrac {x}{y}$ to exist, so $x+y\ne x-y$. Hence the three equal numbers are $xy$, $\dfrac {x}{y}$ and one of $x+y$, $x-y$.

From $xy=\dfrac {x}{y}$ we get $x\left(y^2-1\right)=0$.
\begin{itemize}
\item If $x=0$, then $xy=\dfrac {x}{y}=0$, but $x+y=y\ne0$ and $x-y=-y\ne0$. Impossible.
\item If $y=1$, then $xy=\dfrac {x}{y}=x$, but $x+1\ne x$ and $x-1\ne x$. Impossible.
\item If $y=-1$, then $xy=\dfrac {x}{y}=-x$. Either $x+y=x-1=-x$, giving $x=\dfrac{1}{2}$, or $x-y=x+1=-x$, giving $x=-\dfrac{1}{2}$.
\end{itemize}
So $(x,y)=\left(\dfrac{1}{2},-1\right)$ or $\left(-\dfrac{1}{2},-1\right)$, and in both cases $|y|-|x|=1-\dfrac{1}{2}=\dfrac{1}{2}$. The answer is $\boxed{\textbf{(C)}\ \dfrac{1}{2}}$.
