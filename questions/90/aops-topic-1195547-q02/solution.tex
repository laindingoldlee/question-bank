There are $99$ possible numbers. After $k$ questions the possible answer patterns number at most $2^k$, and different numbers must give different patterns, so $2^k\ge99$, i.e. $k\ge7$. Seven questions suffice: ask for the binary digits of the number one at a time (``is the $2^j$ digit $1$?''), since every number below $128$ has at most $7$ binary digits; equivalently, halve the set of possibilities with each question. So the answer is $\boxed{7}$.
