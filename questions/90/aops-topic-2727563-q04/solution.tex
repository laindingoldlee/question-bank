For $x\in[k,k+1)$ with integer $k\ge1$, $kx$ ranges over $[k^2,k^2+k)$, so $f$ takes the $k$ values $k^2,\dots,k^2+k-1$. These blocks are disjoint for different $k$. On $[0,1)$, $f=0$, and at $x=1000001$, $f=1000001^2$. With $N=1000001$, the count is $1+\displaystyle\sum_{k=1}^{N-1}k+1=\dfrac{1000000\cdot1000001}2+2=\boxed{500000500002}$.
