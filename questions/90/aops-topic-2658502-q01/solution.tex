Divisibility by $5$ makes the last digit $0$ or $5$, and the first digit equals it and is nonzero, so the number is $\overline{5bcd5}$. Its digit sum is $10+b+c+d$, so we need $b+c+d\equiv0\pmod5$. For each of the $100$ choices of $b,c$, exactly two digits $d\in\{0,\dots,9\}$ have the required residue mod $5$. The count is $100\cdot2=\boxed{200}$.
