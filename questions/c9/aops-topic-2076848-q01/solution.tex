Treat the expression \(P(a,b,c)\) as a polynomial in \(a\) with coefficients involving \(b,c\). By the factor theorem, \(a-b\) is a factor if \(P(b,b,c)=0\):
\[
P(b,b,c)=b^3(b-c)+b^3(c-b)+c^3(b-b)=0.
\]
The expression changes sign when any two variables are swapped (it is antisymmetric), so by the same argument \(b-c\) and \(c-a\) are also factors. These are distinct irreducible factors, so \((a-b)(b-c)(c-a)\) divides \(P\). Since \(P\) has degree \(4\), we get \(P=(a-b)(b-c)(c-a)\,L\) with \(L\) linear and symmetric, so \(L=k(a+b+c)\) for a constant \(k\).

To find \(k\), take \(a=0,b=1,c=2\): \(P=0+1\cdot(2-0)+8(0-1)=-6\), while \((a-b)(b-c)(c-a)(a+b+c)=(-1)(-1)(2)(3)=6\). So \(k=-1\):
\[
\boxed{a^3(b-c)+b^3(c-a)+c^3(a-b)=-(a-b)(b-c)(c-a)(a+b+c)}.
\]
