If the side length is $s$, $\dfrac{\sqrt 3}{4}s^2=6$, so $s=\sqrt{8\sqrt 3}$. The two perimeters together count each original side once and the altitude $CD$ twice. Since $CD=\dfrac{\sqrt 3}{2}s$, the sum is $\boxed{(3+\sqrt 3)\sqrt{8\sqrt 3}}$.
\begin{asy}
import geometry; size(220);
pair A=(0,0),B=(2,0),C=(1,sqrt(3)),D=(1,0);draw(A--B--C--cycle);draw(C--D,dashed);label("$A$",A,SW);label("$B$",B,SE);label("$C$",C,N);label("$D$",D,S);
\end{asy}
