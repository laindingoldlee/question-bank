All digits must be valid in base $5$, so $A,B,C\le4$, with $A,B\ge1$. Then $49A+7B+C=25B+5C+A$ gives $48A=18B+4C$, i.e. $24A=9B+2C$. Since $9B+2C\le44$, $A=1$, and $9B+2C=24$ forces $B$ even: $B=2$ gives $C=3$. The number is $\overline{123}_7=\boxed{66}$ (and $\overline{231}_5=66$).
