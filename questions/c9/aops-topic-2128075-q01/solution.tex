\textbf{(a)} Multiplying $x+\dfrac{1}{x}=p$ by $x$ gives $x^2-px+1=0$. This quadratic has the real root $x$, so its discriminant is nonnegative: $p^2-4\ge0$, that is, $|p|\ge2$.

If $x>0$, then by AM-GM $x+\dfrac{1}{x}\ge2\sqrt{x\cdot\dfrac{1}{x}}=2$, so $p\ge2$. If $x<0$, the same argument applied to $-x>0$ gives $p\le-2$. So $p\ge2$ exactly when $x>0$; the claim ``$p\ge2$ by AM-GM'' needs $x$ to be positive.

\textbf{(b)} We have
\[\left(x-\dfrac{1}{x}\right)^2=x^2-2+\dfrac{1}{x^2}=\left(x+\dfrac{1}{x}\right)^2-4=p^2-4,\]
so $x-\dfrac{1}{x}=\pm\sqrt{p^2-4}$, and by the difference of squares
\[x^2-\dfrac{1}{x^2}=\left(x+\dfrac{1}{x}\right)\left(x-\dfrac{1}{x}\right)=\boxed{\pm\,p\sqrt{p^2-4}}.\]
Both signs really occur. If $x$ satisfies $x+\dfrac{1}{x}=p$, then so does $\dfrac{1}{x}$, and replacing $x$ by $\dfrac{1}{x}$ changes the sign of $x^2-\dfrac{1}{x^2}$. For example, $x=2$ and $x=\dfrac{1}{2}$ both give $p=\dfrac{5}{2}$, but $x^2-\dfrac{1}{x^2}$ equals $4-\dfrac{1}{4}=\dfrac{15}{4}$ for $x=2$ and $-\dfrac{15}{4}$ for $x=\dfrac{1}{2}$; indeed $p\sqrt{p^2-4}=\dfrac{5}{2}\cdot\dfrac{3}{2}=\dfrac{15}{4}$.

More precisely, the value is $p\sqrt{p^2-4}$ when $x-\dfrac{1}{x}\ge0$ (that is, when $x\ge1$ or $-1\le x<0$) and $-p\sqrt{p^2-4}$ otherwise. Only when $p=\pm2$ (so $x=\pm1$) is the value determined, namely $0$.
