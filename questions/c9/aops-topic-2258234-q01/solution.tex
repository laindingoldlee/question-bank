Yes. Squaring a number means multiplying it by itself, so $\left(25^{\dfrac{1}{2}}\right)^2=25^{\dfrac{1}{2}}\cdot25^{\dfrac{1}{2}}$ for exactly that reason. Both are equal to
\[25^{\dfrac{1}{2}+\dfrac{1}{2}}=25^1=\boxed{25};\]
directly, $25^{\dfrac{1}{2}}=\sqrt{25}=5$ and $5\cdot5=25$.

(When typing this, the exponent $\dfrac{1}{2}$ must be grouped with brackets: if ``$25$ to the power $1$, divided by $2$'' is typed without them, the order of operations reads it as $\dfrac{25^1}{2}=12.5$.)
