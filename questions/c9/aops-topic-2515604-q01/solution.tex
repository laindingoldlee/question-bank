\textbf{(a)}
\begin{itemize}
\item $-3\mid12$: true, $12=(-3)(-4)$.
\item $3\mid-12$: true, $-12=3\cdot(-4)$.
\item $-3\mid-12$: true, $-12=(-3)\cdot4$.
\item $5\mid0$: true, $0=5\cdot0$ (every integer divides $0$).
\item $0\mid5$: false, since $0\cdot k=0\ne5$ for every $k$.
\item $0\mid0$: true by this definition, since $0=0\cdot k$ (some books require $a\ne0$ in the definition and then exclude this case).
\end{itemize}
So negative numbers are allowed on both sides.

\textbf{(b)} If $b=ak$, then $|b|=|a|\,|k|$ with $|k|$ an integer, so $|a|\mid|b|$. Conversely, if $|b|=|a|m$ for an integer $m$, write $a=\varepsilon|a|$ and $b=\delta|b|$ with $\varepsilon,\delta\in\{1,-1\}$. Then
\[b=\delta|a|m=a\cdot(\varepsilon\delta m),\]
since $\varepsilon^2=1$. So $a\mid b$. $\blacksquare$

$\boxed{\text{All true except }0\mid5;\ a\mid b\iff|a|\mid|b|}$
