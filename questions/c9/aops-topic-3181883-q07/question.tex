Each minute, a student receives a message with probability $0.6$. If a message arrives, the student checks the phone with probability $0.9$, wasting $30$ seconds; otherwise there is no wasted time. If no message arrives, the student checks with probability $0.3$, wasting $10$ seconds. Find the expected study time in a $100$-minute session.
