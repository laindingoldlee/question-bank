For $n>1$, exponents occur in ascending order; for $0<n<1$, in descending order. If $n<-1$, negative odd powers come first with odd exponents descending, followed by even exponents ascending. If $-1<n<0$, odd exponents ascend and even exponents descend. These are four distinct orders, each attainable. Values $n=-1,0,1$ have repeated powers and cannot give strict order. Thus $\boxed4$ arrangements exist.
