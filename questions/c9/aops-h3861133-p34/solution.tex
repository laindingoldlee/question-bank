One exact enumeration method is to generate rooted trees recursively: a rooted tree is a root joined to an unordered multiset of smaller rooted trees. For each size up to ten, list these multisets with total child size one less than the desired size. Encode each rooted tree by sorted parenthesized child encodings; for an unrooted tree choose the smallest encoding over all choices of root. Deduplication leaves $106$ trees of order ten. For each tree, a breadth-first search from each of its ten vertices supplies all ordered distances. The sum of these distance totals over the $106$ trees is $26082$. Thus the exact expectation is $\dfrac{26082}{106}=\dfrac{13041}{53}\approx\boxed{246.056604}$.
