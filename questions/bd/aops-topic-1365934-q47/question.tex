In a standard set of dominoes, a face of each domino has a line through the centre, with $0$ to $6$ dots on each side of the line. Each possible combination of dots is used exactly once, one combination per domino. What is the probability that a randomly selected domino will have the same number of dots on both sides of the line? Express your answer as a common fraction.
