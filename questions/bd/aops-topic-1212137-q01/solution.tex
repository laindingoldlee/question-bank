Let there be $k$ knights and $s$ serfs, $d_1$ damsels who answer truthfully first (pattern true, lie, true) and $d_2$ damsels who lie first (lie, true, lie).

\begin{itemize}
\item ``Are you a knight?'': knights say yes; serfs lie, so yes; $d_1$-damsels truthfully say no; $d_2$-damsels lie, so yes. Thus $k+s+d_2=17$.
\item ``Are you a damsel?'': knights no; serfs lie, so yes; $d_1$-damsels now lie, so no; $d_2$-damsels now tell the truth, so yes. Thus $s+d_2=12$.
\item ``Are you a serf?'': knights no; serfs lie, so no; $d_1$-damsels truthfully say no; $d_2$-damsels lie, so yes. Thus $d_2=8$.
\end{itemize}
Hence $s=4$, $k=17-12=5$ and $d_1=25-17=8$. There are $\boxed{5}$ knights, answer $\textbf{(B)}$.
