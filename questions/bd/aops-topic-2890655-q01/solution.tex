For example, $0.1+\dfrac{\sqrt2}{100}\approx0.11414$ and $0.1+\dfrac{\sqrt3}{100}\approx0.11732$. Each is irrational, since a rational number plus an irrational number is irrational, and both lie in $(0.1,0.12)$ because $1<\sqrt2<\sqrt3<2$.
