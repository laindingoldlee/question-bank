Since $T_{100}=5050$, we need $T_1,\dots,T_{99}$. Checking them by size:
\begin{itemize}
\item one digit: $T_1=1$, $T_2=3$, $T_3=6$;
\item two digits ($T_4$ to $T_{13}$: $10,15,21,28,36,45,55,66,78,91$): $55$ and $66$;
\item three digits ($T_{14}=105$ to $T_{44}=990$): a palindrome $\overline{aba}$ is $T_n$ exactly when $8\cdot\overline{aba}+1$ is a perfect square; running through the list gives $171=T_{18}$, $595=T_{34}$ and $666=T_{36}$;
\item four digits ($T_{45}=1035$ to $T_{99}=4950$): only $3003=T_{77}$.
\end{itemize}
So there are $\boxed{9}$: $1,3,6,55,66,171,595,666,3003$.
