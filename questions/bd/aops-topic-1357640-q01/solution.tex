Since $2016=3\cdot672$, group the numbers into the $672$ triples $\{3k+1,3k+2,3k+3\}$, $k=0,1,\dots,671$, and rotate each triple:
\[
f(3k+1)=3k+2,\qquad f(3k+2)=3k+3,\qquad f(3k+3)=3k+1 .
\]
Applying $f$ three times moves each number once around its triple, so $f(f(f(x)))=x$ for all $x$; and $f(1)=2$, so $f$ is not the identity. For example $f(f(f(5)))=f(f(6))=f(4)=5$.

A constant function $f(x)=c$ gives $f(f(f(x)))=c$, which differs from $x$ for any $x\ne c$, so no constant function works. (More generally, $f\circ f\circ f=\mathrm{id}$ forces $f$ to be a bijection whose cycles all have length $1$ or $3$.)
