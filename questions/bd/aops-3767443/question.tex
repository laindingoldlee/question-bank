Consider the Tree $T_5$, which consists of a set $V$ of $63$ vertices $V_1, V_2, ..., V_{63}$ such that for each $1 \leq i \leq 31,$ vertex $V_i$ connects to vertices $V_{2i}$ and $V_{2i+1}$ via an edge. Call a labeling of the vertices $f: V \to \mathbb{R}$ a \emph{family-tree labeling} if it satisfies $f(V_i) \in \{0, 1\}$ for all $i \geq 32$ and for each $1 \leq i \leq 31$, $f(V_i) = \dfrac{f(V_{2i}) + f(V_{2i+1})}{2}.$ Let $N$ be the number of distinct \emph{family-tree labelings} of $T_5$ that satisfy $f(V_1) = \dfrac{1}{2}$. Find the remainder when $N$ is divided by $1000.$ Note: two labelings are considered equivalent if there exists an automorphism of $T_5$ mapping the former labeling to the latter.
