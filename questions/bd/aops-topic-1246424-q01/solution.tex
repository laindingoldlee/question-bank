Each record is blue with probability $\dfrac{1}{2}$, independently, so we count binary strings of length $10$ with no three consecutive B's. Let $a_n$ be the number of such strings of length $n$. A valid string ends in R, RB or RBB after a shorter valid string (or is one of the short strings), giving
\[a_n=a_{n-1}+a_{n-2}+a_{n-3},\qquad a_0=1,\ a_1=2,\ a_2=4.\]
Then $a_3,\dots,a_{10}=7,13,24,44,81,149,274,504$. The probability is $\dfrac{504}{1024}=\boxed{\dfrac{63}{128}}$.
