(a) The number of red balls never decreases and initially equals 2. An all-green state is impossible, so its hitting time is infinite. (b) The only reachable monochromatic state is all red. With two green balls, the chance of replacing one at each draw is $\dfrac{2}{4}$, giving a geometric waiting time with mean 2. With one green ball left, the chance is $\dfrac{1}{4}$, giving mean 4. By adding the successive waiting-time expectations, the answer is $\boxed{2+4=6}$ steps.
