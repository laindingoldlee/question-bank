\emph{Four digits.} A four-digit palindrome is $\overline{abba}=1001a+110b=11(91a+10b)$. If it is a square, $11^2$ divides it, so $11\mid 91a+10b$, i.e. $11\mid 3a-b$, so $b\equiv3a\pmod{11}$, and then $91a+10b=11m^2$. The pairs with $1\le a\le9$ are $(a,b)=(1,3),(2,6),(3,9),(4,1),(5,4),(6,7),(8,2),(9,5)$ ($a=7$ would need $b=10$), giving $\dfrac{91a+10b}{11}=11,22,33,34,45,56,68,79$. None of these is a square, so there are \emph{no} four-digit palindromic squares.

\emph{Five digits.} Here $\overline{abcba}=n^2$ with $100\le n\le316$. The last digit of a square is $0,1,4,5,6,9$ and must equal the leading digit $a\ne0$. Go through $a$, using the range of $n$ and the last digit of $n$:
\begin{itemize}
\item $a=1$: $100\le n\le141$, $n$ ends in $1$ or $9$: $101^2=10201$, $109^2=11881$, $111^2=12321$, $119^2=14161$, $121^2=14641$, $129^2=16641$, $131^2=17161$, $139^2=19321$, $141^2=19881$. Palindromes: $10201,12321,14641$.
\item $a=4$: $200\le n\le223$, ending in $2$ or $8$: $202^2=40804$, $208^2=43264$, $212^2=44944$, $218^2=47524$, $222^2=49284$. Palindromes: $40804,44944$.
\item $a=5$: $224\le n\le244$, ending in $5$: $225^2=50625$, $235^2=55225$. None.
\item $a=6$: $245\le n\le264$, ending in $4$ or $6$: $246^2=60516$, $254^2=64516$, $256^2=65536$, $264^2=69696$. Palindrome: $69696$.
\item $a=9$: $300\le n\le316$, ending in $3$ or $7$: $303^2=91809$, $307^2=94249$, $313^2=97969$. Palindrome: $94249$.
\end{itemize}
Answer: \boxed{\text{no four-digit ones; five-digit: }10201,\ 12321,\ 14641,\ 40804,\ 44944,\ 69696,\ 94249}.
