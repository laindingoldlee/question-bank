If Carl's statement were true, it would be the unique true statement. Alice and Bob would then be false, while Dave being false would imply Alice holds the coin, a contradiction. Thus Carl's statement is false. If Alice held the coin, only Alice's statement would be true, contradicting Carl being false. If Bob or Dave held it, only Dave's statement would be true, again a contradiction. If Carl holds it, Bob and Dave are true and Alice and Carl false, consistently. Hence $\boxed{\text{Carl}}$.
