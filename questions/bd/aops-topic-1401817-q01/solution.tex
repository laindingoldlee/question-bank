The first row can be any arrangement of $1,2,3$: $3!=6$ ways. In the second row no entry may equal the entry above it, so the second row is a rearrangement of the first in which every digit moves; for three digits there are exactly $2$ such rearrangements (the two cyclic shifts). The third row is then forced: each column already contains two different digits, and the missing digit of each column must go below them; these three digits are all different (each digit is missing from exactly one column), so the third row is valid.

Hence there are $6\cdot2\cdot1=\boxed{12}$ ways.
