Multiplications are done before additions:
\[8\times3+7\times0+32+8\times13=24+0+32+104=\boxed{160}.\]
The computation shown works strictly from left to right. For example, it adds $24+7$ before multiplying, computing $(24+7)\times0$ instead of $24+(7\times0)$, and later $(32+8)\times13$ instead of $32+(8\times13)$.
