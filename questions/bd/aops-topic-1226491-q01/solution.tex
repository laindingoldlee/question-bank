Let the weights be $w_1,\dots,w_4$ and $d_i=w_i-1\in\{0,1,2\}$. Then
\[d_1+3d_2+9d_3+27d_4=95-40=55.\]
This is a base-$3$ representation with digits $d_i$, which is unique: $55=2\cdot27+0\cdot9+0\cdot3+1$. So $(d_1,d_2,d_3,d_4)=(1,0,0,2)$ and the weights are $\boxed{2,\ 1,\ 1,\ 3}$ ounces for bags $1,2,3,4$.
