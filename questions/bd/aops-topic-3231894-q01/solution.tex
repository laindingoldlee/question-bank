The fourth root corresponds to an exponent of $\dfrac{1}{4}$, so $\sqrt[4]{5^3}=\boxed{5^{\dfrac{3}{4}}}$. The mixed number is instead $5+\dfrac{3}{4}=\dfrac{23}{4}$. These notations represent different operations.
