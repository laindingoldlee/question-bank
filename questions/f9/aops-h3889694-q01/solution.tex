Write a candidate as $j^2=\dfrac{k(k+1)}{2}$, where $1\le j\le44$. Equivalently, $8j^2+1=(2k+1)^2$. Testing these $44$ values gives $j=1,6,35$, corresponding to triangular indices $1,8,49$.

For a shorter exhaustive test, compare consecutive values of $\dfrac{k(k+1)}{2}$ with $1^2,2^2,\ldots,44^2$ using $1\le k\le63$; the same three equalities are $1=1$, $36=8\cdot\dfrac{9}{2}$, and $1225=49\cdot\dfrac{50}{2}$. Thus $N=1262\equiv\boxed2\pmod7$.
