Choose starting point $(\dfrac{1}{2},\dfrac{1}{2})$ and aim at $(\dfrac{1}{4},1)$, direction $(-1,2)$. In the unfolded square grid its path is $(\dfrac{1}{2},\dfrac{1}{2})+t(-1,2)$. Images of the centre have half-integer coordinates, first reached again at $t=1$. A vertex would require $t$ half-integral from the first coordinate, but then the second remains half-integral, so no vertex is hit. Thus the distance is $\boxed{\sqrt5}$. The folded path visits $(\dfrac{1}{4},1),(0,\dfrac{1}{2}),(\dfrac{1}{4},0)$ before returning.
