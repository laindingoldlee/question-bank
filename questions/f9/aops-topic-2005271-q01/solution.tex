The right side equals $\dfrac{12.21}{40.44}\,x$. Moving everything to one side,
\[
x\left(1-\dfrac{12.21}{40.44}\right)=0.
\]
Since $\dfrac{12.21}{40.44}\ne1$, the bracket is a nonzero number ($\dfrac{28.23}{40.44}$), so the only solution is $\boxed{x=0}$.
