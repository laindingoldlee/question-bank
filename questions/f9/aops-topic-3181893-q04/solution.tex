Each 8-unit edge must run along the 9-unit direction. Any two 8-unit height intervals inside a 9-unit interval overlap, so all blocks must have disjoint 1-by 3 footprints in the 4-by 4 base. Area gives an upper bound $\left\lfloor\dfrac{16}{3}\right\rfloor=5$. Place four horizontal 1-by 3 footprints in the left three columns, one in each row, and one vertical 1-by 3 footprint in the rightmost column. This fits 5 blocks, so $\boxed5$.

\end{asy}
