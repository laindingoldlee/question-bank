Let $g(x)=\dfrac{\ln x}x$. Then $g'(x)=\dfrac{1-\ln x}{x^2}<0$ for $x>e$, so $g$ is strictly decreasing on $[e,\infty)$. Since $\pi>e$, $\dfrac{\ln\pi}\pi<\dfrac{\ln e}e=\dfrac1e$, so $e\ln\pi<\pi$ and $\pi^e<e^\pi$. So $\boxed{e^\pi}$ is larger.
