Let the equal pair be in positions $i,i+1$ ($1\le i\le9$). Merge these two positions into one ``block''. Then the number is described by a sequence of $9$ blocks, each a digit, in which neighbouring blocks are different (otherwise there would be another equal pair) and the first block is not $0$; conversely each such sequence and each choice of $i$ give exactly one valid number.

The first block has $9$ choices ($1$ to $9$), and each later block has $9$ choices (any digit except the previous one). So for each $i$ there are $9^9$ numbers, and the total is
\[
9\cdot9^9=9^{10}=\boxed{3486784401}.
\]
