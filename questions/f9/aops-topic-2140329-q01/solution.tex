Since $9^5=59049<59305<9^6$, we have $y\le5$.
\begin{itemize}
\item If $y\le4$, then $9^y\le6561$, so $2^x=59305-9^y$ lies between $59305-6561=52744$ and $59305$, strictly between $2^{15}=32768$ and $2^{16}=65536$. So $2^x$ is not a power of $2$, impossible.
\item If $y=5$, then $2^x=59305-59049=256=2^8$, so $x=8$.
\end{itemize}
Hence $(x,y)=(8,5)$ and $x+y=\boxed{13}$.
