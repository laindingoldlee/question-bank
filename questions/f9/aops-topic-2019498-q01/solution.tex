Let $m=2n-1$, an odd positive integer. For odd $m$ we have the factorisation
\[
x^{m}+1=(x+1)\left(x^{m-1}-x^{m-2}+x^{m-3}-\cdots-x+1\right),
\]
which can be checked by expanding: the terms telescope, leaving $x^m+1$ because the last sign, on the constant term $1$, is $+$ when $m$ is odd. Putting $x=8$ gives $x+1=9$, so
\[
\dfrac{8^{2n-1}+1}{9}=8^{2n-2}-8^{2n-3}+8^{2n-4}-\cdots-8+1=\sum_{k=0}^{2n-2}(-8)^k ,
\]
an integer. Hence $9\mid 8^{2n-1}+1$. (Alternatively, $8\equiv-1\pmod9$, so $8^{2n-1}\equiv(-1)^{2n-1}=-1\pmod9$.)

For example, $n=2$ gives $\dfrac{513}{9}=57=64-8+1$. The quotient is
\[
\boxed{\dfrac{8^{2n-1}+1}{9}=\sum_{k=0}^{2n-2}(-8)^k}.
\]
