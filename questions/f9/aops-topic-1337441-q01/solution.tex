Let $s_{10}(n)$ and $s_{17}(n)$ be the digit sums. Since $10\equiv1\pmod9$ and $17\equiv1\pmod{16}$, we have $n\equiv s_{10}(n)\pmod9$ and $n\equiv s_{17}(n)\pmod{16}$. If both digit sums equal $s$, then $9\mid n-s$ and $16\mid n-s$, so $144\mid n-s$.

For $n>10$ we have $s<n$ (a number with at least two digits is larger than its digit sum), so $n-s\ge144$, i.e. $n\ge144+s\ge145$. Now test $n=144+s$ for $n=145,146,\dots$:
\begin{itemize}
\item $n=145,\dots,149$: $s_{10}(n)=10,\dots,14\ne n-144$.
\item $n=150,151,152$: $s_{10}(n)=6,7,8=n-144$, but in base $17$, $150=8\cdot17+14$, $151=8\cdot17+15$, $152=8\cdot17+16$, with digit sums $22,23,24$.
\item $n=153=9\cdot17$: $s_{10}=1+5+3=9$ and in base $17$ it is written $90_{17}$ with digit sum $9$.
\end{itemize}
So the answer is $\boxed{153}$.
