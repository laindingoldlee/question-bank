The number is even when its last digit is $2$, $4$ or $6$: $3\cdot6!$ equally likely arrangements. It is greater than $4{,}000{,}000$ exactly when its first digit is $4$, $5$, $6$ or $7$. Count by the last digit:
\begin{itemize}
\item last digit $2$: first digit from $\{4,5,6,7\}$: $4$ choices;
\item last digit $4$: first digit from $\{5,6,7\}$: $3$ choices;
\item last digit $6$: first digit from $\{4,5,7\}$: $3$ choices.
\end{itemize}
The middle five digits can be arranged in $5!$ ways in each case, so the probability is
\[\dfrac{(4+3+3)\cdot5!}{3\cdot6!}=\dfrac{1200}{2160}=\boxed{\dfrac59}.\]
