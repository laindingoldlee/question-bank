It is \textbf{undefined}. The expression contains $\dfrac {y}{0}$, and division by zero is not defined for any $y$ (there is no number $q$ with $0\cdot q=y$ when $y\ne0$, and every $q$ works when $y=0$). An expression containing an undefined part is undefined; one cannot ``divide by infinity'' to get $0$.
