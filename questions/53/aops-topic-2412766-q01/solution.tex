\textbf{Structure.} Such an $f$ is a bijection (it is its own inverse). If $f(a)=b$ with $b\ne a$, then $f(b)=f(f(a))=a$. So the elements fall into fixed points ($f(a)=a$) and pairs $\{a,b\}$ that are swapped. Conversely, any choice of disjoint pairs, with all other elements fixed, gives such a function.

\textbf{Counting.} Let $k$ be the number of swapped pairs, so $0\le k\le3$. Choose the $2k$ paired elements in $\dbinom{7}{2k}$ ways and split them into pairs: the smallest chosen element has $2k-1$ possible partners, the smallest remaining one $2k-3$, and so on, giving $(2k-1)(2k-3)\cdots1$ ways.
\begin{itemize}
\item $k=0$: $1$;
\item $k=1$: $\dbinom72\cdot1=21$;
\item $k=2$: $\dbinom74\cdot3=105$;
\item $k=3$: $\dbinom76\cdot5\cdot3\cdot1=105$.
\end{itemize}
In total $1+21+105+105=\boxed{232}$.
