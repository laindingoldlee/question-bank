Adding the equations and completing squares gives $9[(x-\dfrac{2}{3})^2+(y-\dfrac{1}{3})^2+(z-\dfrac{2}{3})^2]=0$. Each square is nonnegative, so $x=z=\dfrac{2}{3}$ and $y=\dfrac{1}{3}$. These values satisfy all three equations. The desired value is $6\cdot\dfrac{4}{9}+9\cdot\dfrac{1}{9}+12\cdot\dfrac{4}{9}=\boxed9$.
