Write $e^{2775}=10^{2775\log_{10}e}$. Now
\[
2775\log_{10}e=2775\cdot0.4342944819\ldots=1205.16718\ldots,
\]
so
\[
e^{2775}=10^{1205}\cdot10^{0.16718\ldots}.
\]
Since $10^{0.16718}\approx1.4696$ (because $\log_{10}1.4696\approx0.16718$), the number is
\[
e^{2775}\approx\boxed{1.47\times10^{1205}}.
\]
(The value of $2775\log_{10}e$ must be known to about five decimal places, which the given value of $\log_{10}e$ provides: its error is at most $2775\cdot10^{-10}$.)
