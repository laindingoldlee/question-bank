Let him have $n$ nickels and $12-n$ dimes. Measured in units of $5$ cents, a combination of $a$ nickels and $b$ dimes ($0\le a\le n$, $0\le b\le12-n$, not both $0$) is worth $a+2b$.

If $n=0$, only the even values $2,4,\dots,24$ occur: $12$ values, not $17$. If $n\ge1$, let $d=12-n$; every integer from $1$ to $n+2d=24-n$ occurs: an even value $2b\le2d$ uses $b$ dimes, an odd value $2b+1\le2d-1$ uses $b$ dimes and one nickel, and a value $v$ with $2d<v\le2d+n$ uses all $d$ dimes and $v-2d$ nickels. So there are $24-n$ values, and $24-n=17$ gives $n=\boxed{7}$.
