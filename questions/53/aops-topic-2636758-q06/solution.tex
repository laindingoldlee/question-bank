The last five binary digits encode $3^{257}\bmod 32$. Now $3^8=6561=205\cdot32+1\equiv1\pmod{32}$ and $257=8\cdot32+1$, so $3^{257}\equiv3\pmod{32}$. In five binary digits, $3=00011_2$, so the last five digits are $\boxed{00011}$.
