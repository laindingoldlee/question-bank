Suppose no value occurs more than twice. Then the sum is at most what we get by using each of $1,2,\dots,1006$ exactly twice:
\[\sum\dfrac{1}{\sqrt{x_i}}\le2\sum_{k=1}^{1006}\dfrac{1}{\sqrt k}.\]
For $k\ge2$, $\dfrac{1}{\sqrt k}<\dfrac{2}{\sqrt k+\sqrt{k-1}}=2\left(\sqrt k-\sqrt{k-1}\right)$, so
\[\sum_{k=1}^{1006}\dfrac{1}{\sqrt k}<1+2\left(\sqrt{1006}-1\right)=2\sqrt{1006}-1<2\cdot31.72-1=62.44.\]
(Indeed $31.72^2=1006.16>1006$.) So the sum is less than $124.88<125$, a contradiction. $\blacksquare$
