Each row adds $7$ each time, so all numbers in a row have the same remainder on division by $7$: row $A$ has remainder $1$, $B$ remainder $3$, $C$ remainder $2$, $D$ remainder $4$ ($11=7+4$) and $E$ remainder $6$ ($13=7+6$). Since $86=7\cdot12+2$, the number $86$ has remainder $2$ and appears in row $\boxed{C}$ (as $2+7\cdot12$, the $13$th term).
