The squares of $0,1,2,3,4,5,6$ leave remainders $0,1,4,2,2,4,1$ on division by $7$, so a square is congruent to $0$, $1$, $2$ or $4$ modulo $7$.

Suppose $7\nmid x$. Then $x^2\equiv1$, $2$ or $4$, and $7\mid x^2+y^2$ would need $y^2\equiv-1\equiv6$, $-2\equiv5$ or $-4\equiv3\pmod7$, none of which is a square residue. So $7\mid x$, and then $y^2\equiv0$, so $7\mid y$. Conversely, if $7\mid x$ and $7\mid y$ then $49\mid x^2+y^2$.

So the pairs are exactly those with \textbf{both $x$ and $y$ multiples of $7$}. There are $\left\lfloor\dfrac{100000}{7}\right\rfloor=14285$ multiples of $7$ from $1$ to $10^5$, so the number of ordered pairs is
\[
14285^2=\boxed{204061225}.
\]
