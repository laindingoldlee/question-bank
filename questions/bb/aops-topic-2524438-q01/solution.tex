\textbf{(a)} We show that each truth value leads to a contradiction.
\begin{itemize}
\item Suppose $L$ is true. Then what $L$ says holds, and $L$ says that $L$ is false. So $L$ is false, and $L$ would be both true and false, which is impossible.
\item Suppose $L$ is false. Then what $L$ says, namely that $L$ is false, is the case, so $L$ is true. Again $L$ would be both true and false.
\end{itemize}
So $L$ can be given neither truth value. A statement must be true or false, so
\[\boxed{L\text{ is neither true nor false, so it is not a statement.}}\]
Calling $L$ ``indeterminate'' and saying that it is ``not a statement'' describe the same fact: in classical logic every statement has a truth value, so a sentence such as $L$ that cannot consistently have one is simply not admitted as a statement.

\textbf{(b)} The sentence ``this sentence has five words'' consists of the five words \emph{this}, \emph{sentence}, \emph{has}, \emph{five}, \emph{words}. So what it says is the case, and it is true; it cannot be false, since it does have five words. It has exactly one truth value, so it is a statement, and a \textbf{true} one.

So referring to itself is not, by itself, what goes wrong in (a). The trouble with $L$ is that its truth value would have to be the opposite of itself.
