In classical logic, a \emph{statement} (or proposition) is a sentence that is either true or false, but not both.
\begin{enumerate}
\item[(a)] Let $L$ be the sentence ``$L$ is false'', that is, ``this statement is false''. Prove that $L$ can be neither true nor false, and conclude that $L$ is not a statement in this sense.
\item[(b)] The sentence ``this sentence has five words'' also talks about itself. Is it a statement? If so, is it true or false?
\end{enumerate}
