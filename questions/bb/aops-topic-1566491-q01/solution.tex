Every value $\dfrac {m}{d}$ (month $m$, day $d$) equals a unique fraction $\dfrac {p}{q}$ in lowest terms, and then $(m,d)=(kp,kq)$ for some positive integer $k$. If $(kp,kq)$ is a date of 2018, so is $(p,q)$: for $k=1$ it is the same date, and for $k\ge2$ the month $p<kp$ is valid and the day $q\le\dfrac{31}{2}$ exists in every month. Hence each value is taken by exactly one date with $\gcd(m,d)=1$, and the number of different values equals the number of dates with $\gcd(m,d)=1$.

So the answer is the number of dates with $\gcd(m,d)=1$. Count by month, with month lengths $31,28,31,30,31,30,31,31,30,31,30,31$ in 2018 (not a leap year):
\begin{itemize}
\item $m=1$: all $31$ days.
\item $m=2$: odd days up to $28$: $14$.
\item $m=3$: days up to $31$ not divisible by $3$: $31-10=21$.
\item $m=4$: odd days up to $30$: $15$.
\item $m=5$: days up to $31$ not divisible by $5$: $31-6=25$.
\item $m=6$: days up to $30$ coprime to $6$: $30-15-10+5=10$.
\item $m=7$: days up to $31$ not divisible by $7$: $31-4=27$.
\item $m=8$: odd days up to $31$: $16$.
\item $m=9$: days up to $30$ not divisible by $3$: $20$.
\item $m=10$: days up to $31$ coprime to $10$: $31-15-6+3=13$.
\item $m=11$: days up to $30$ not divisible by $11$: $30-2=28$.
\item $m=12$: days up to $31$ coprime to $12$: $31-15-10+5=11$.
\end{itemize}
The total is $31+14+21+15+25+10+27+16+20+13+28+11=\boxed{231}$.
