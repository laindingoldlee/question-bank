Expanding, $M=2+\dfrac {x}{y}+\dfrac {y}{x}=2+t+\dfrac{1}{t}$ where $t=\dfrac {y}{x}$. Since $1\le x<y\le2$, we have $1<t\le\dfrac{2}{1}=2$. The function $t+\dfrac{1}{t}$ is increasing for $t\ge1$ (because $t_2+\dfrac{1}{t_2}-t_1-\dfrac{1}{t_1}=(t_2-t_1)\left(1-\dfrac{1}{t_1t_2}\right)>0$ for $1\le t_1<t_2$), so $M\le 2+2+\dfrac{1}{2}=\dfrac{9}{2}$, with equality at $t=2$, i.e. $x=1$, $y=2$. The maximum is $\boxed{\dfrac{9}{2}}$.
