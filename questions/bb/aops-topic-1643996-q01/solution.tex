\textbf{(a)} Let $b=a^{\dfrac{1}{n}}$, so $b>0$ and $b^n=a$. For integer exponents the usual rules hold, so
\[
\left(b^m\right)^n=b^{mn}=\left(b^n\right)^m=a^m .
\]
Thus $b^m$ is a number whose $n$-th power is $a^m$, and $b^m>0$ because $b>0$. A positive number has only one positive $n$-th root (the map $t\mapsto t^n$ is strictly increasing for $t>0$), so $b^m=\sqrt[n]{a^m}$, that is,
\[
a^{\dfrac{m}{n}}=\left(\sqrt[n]{a}\right)^m=\sqrt[n]{a^m}. \qquad\blacksquare
\]

\textbf{(b)} If the rule $\left(a^r\right)^s=a^{rs}$ is to hold for rational exponents, then $\left(a^{\dfrac{1}{n}}\right)^n=a^1=a$, so $a^{\dfrac{1}{n}}$ must be an $n$-th root of $a$; choosing the positive one makes it unique. Then $a^{\dfrac{m}{n}}=a^{\dfrac{1}{n}\cdot m}=\left(a^{\dfrac{1}{n}}\right)^m$ is forced, and part (a) shows this equals $\sqrt[n]{a^m}$.

For $a<0$ the rules break down. For example, $\dfrac{1}{3}=\dfrac{2}{6}$, but $\sqrt[3]{-8}=-2$ while $\sqrt[6]{(-8)^2}=\sqrt[6]{64}=2$. So the value would depend on how the fraction is written, which is why the definition requires $a>0$. (For $a>0$ there is no such problem: if $\dfrac{m}{n}=\dfrac{km}{kn}$, then $\sqrt[kn]{a^{km}}=\sqrt[n]{a^m}$, because both are positive and their $kn$-th powers are both $a^{km}$.)
