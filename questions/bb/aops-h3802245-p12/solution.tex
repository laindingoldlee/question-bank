Within one digit length, a successor changes the rightmost $4$ to $7$ and replaces the $k$ trailing $7$s by $4$s. The difference is
\[3\cdot10^k-3\dfrac{10^k-1}{9}=\dfrac{8\cdot10^k+1}{3},\qquad k=0,1,\ldots,6.\]
All seven values occur. At a transition from length $\ell$ to length $\ell+1$, the difference from all $7$s to all $4$s is
\[4\dfrac{10^{\ell+1}-1}{9}-7\dfrac{10^\ell-1}{9}=\dfrac{11\cdot10^\ell+1}{3},\qquad\ell=1,\ldots,6.\]
These six values also occur. Both lists increase strictly. The first list is $3,27,267,\ldots$; the second is $37,367,3667,\ldots$, so they are disjoint. Therefore there are $\boxed{13}$ distinct differences.
