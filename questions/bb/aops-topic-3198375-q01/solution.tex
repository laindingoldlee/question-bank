The first differences are $-4,-1$, so the constant second difference is $3$. The next difference is $2$, giving next term $\boxed8$. Without a stated rule the continuation is not unique: the quadratic through the three values can be modified by $k(n-1)(n-2)(n-3)$ without changing the first three values but changing the fourth by $6k$.
