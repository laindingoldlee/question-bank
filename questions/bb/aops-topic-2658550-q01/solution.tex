We need $7^{7^7}\bmod100$. Since $7^2=49$ and $7^4=2401\equiv1\pmod{100}$, only the exponent modulo $4$ matters. As $7\equiv-1\pmod4$, $7^7\equiv(-1)^7\equiv3\pmod4$; write $7^7=4m+3$. Then
\[7^{7^7}=(7^4)^m\cdot7^3\equiv343\equiv43\pmod{100}.\]
The last two digits are $\boxed{43}$.
