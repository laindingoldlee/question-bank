\textbf{Lemma.} Let $P$ be a point and $UV$ a segment. For every point $Q$ of the segment strictly between $U$ and $V$, $PQ<\max(PU,PV)$.

\emph{Proof.} Write $Q=(1-t)U+tV$ with $0<t<1$. By the triangle inequality for vectors,
\[
PQ=\left|(1-t)(U-P)+t(V-P)\right|\le(1-t)PU+t\,PV\le\max(PU,PV).
\]
If both inequalities were equalities, then $U-P$ and $V-P$ would point in the same direction and $PU=PV$ (the second equality with $0<t<1$ forces this), so $U=V$, which is impossible. Hence $PQ<\max(PU,PV)$.

\textbf{Proof of the claim.} Apply the lemma three times.
\begin{itemize}
\item $E$ is strictly inside segment $CA$, so $DE<\max(DC,DA)$.
\item $D$ is strictly inside segment $BC$, so $DC<BC$.
\item $D$ is strictly inside segment $BC$, so (with $P=A$) $DA<\max(AB,AC)\le BC$.
\end{itemize}
Therefore $DE<\max(DC,DA)<BC$. $\blacksquare$
