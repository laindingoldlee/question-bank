Consider the four statements:
\begin{itemize}
\item Statement 1: Statement 2 is false.
\item Statement 2: Statement 3 is false.
\item Statement 3: Statement 4 is false.
\item Statement 4: Statement 1 is false.
\end{itemize}
Each statement is either true or false. How many of the statements are true?
