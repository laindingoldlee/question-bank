Statement $k$ is true exactly when statement $k+1$ is false (with statement $5$ meaning statement $1$). So consecutive statements have opposite truth values, and the truth values alternate around the cycle $1\to2\to3\to4\to1$. Since the cycle has even length, this is consistent, and there are exactly two possibilities:
\begin{itemize}
\item statements $1$ and $3$ true, statements $2$ and $4$ false;
\item statements $2$ and $4$ true, statements $1$ and $3$ false.
\end{itemize}
One checks each directly: in the first, statement 1 says ``2 is false'' (true), statement 2 says ``3 is false'' (false, as it should be), and so on. Which case occurs cannot be decided, but in both of them exactly $\boxed{2}$ statements are true.

(With an odd number of statements in such a cycle there would be no consistent assignment at all, as in the liar paradox.)
