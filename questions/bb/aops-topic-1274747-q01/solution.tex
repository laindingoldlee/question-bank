\textbf{Bound.} There are only $7$ distinct one-digit numbers. If $n_1\le7$ one-digit and $n_2$ two-digit numbers are formed, then $n_1+2n_2\le49$, so
\[
n_1+n_2\le n_1+\dfrac{49-n_1}{2}=\dfrac{49+n_1}{2}\le28 .
\]
\textbf{Construction.} Use $1,2,\dots,7$ as one-digit numbers, and the $21$ two-digit numbers $\overline{ij}$ with $1\le i<j\le7$. Each digit appears in exactly $6$ of these two-digit numbers, so each digit is used $1+6=7$ times. This gives $7+21=\boxed{28}$ numbers.
