Multiply each amount by $3$:
\begin{itemize}
\item bug splatter: $3\cdot\dfrac43=\boxed{4}$ cups;
\item sardines: $3\cdot\dfrac94=\dfrac{27}{4}=\boxed{6\dfrac34}$ cups;
\item dishwater: $3\cdot\dfrac34=\dfrac94=\boxed{2\dfrac14}$ cups;
\item asparagus: $3\cdot\dfrac23=\boxed{2}$ cups.
\end{itemize}
