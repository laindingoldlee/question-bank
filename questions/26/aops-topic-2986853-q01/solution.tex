Every rational number has a unique representation $\dfrac pq$ with $q\ge1$ and $\gcd(p,q)=1$ (take $\dfrac01$ for zero). Define its \emph{height} to be $|p|+q$. For each height $h\ge1$ there are finitely many such fractions (at most $2h$).

List the rationals by increasing height, and within a height by increasing $p$:
\[\dfrac01;\ \dfrac{-1}1,\dfrac11;\ \dfrac{-2}1,\dfrac{-1}2,\dfrac12,\dfrac21;\ \dfrac{-3}1,\dfrac{-1}3,\dfrac13,\dfrac31;\ \ldots\]
Every rational appears exactly once, at some finite position, since only finitely many rationals have smaller or equal height. Sending $n$ to the $n$th rational in the list is a bijection from the positive integers to $\mathbb Q$. $\blacksquare$

The spiral numbers all lattice points, but different points name the same rational ($\dfrac12=\dfrac24$), and points with $q=0$ name no rational at all, so the map from positions to rationals is neither one-to-one nor defined everywhere. It can be repaired by skipping points with $q\le0$ or $\gcd(p,q)\ne1$, which is essentially the listing above.
