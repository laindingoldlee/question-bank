Deriving a true statement from the claim proves nothing by itself (a false claim can also imply a true statement). The argument becomes valid only because each step is reversible, and it should be written in the forward direction. Expanding,
\[(a^2+b^2)(c^2+d^2)-(ac+bd)^2=a^2d^2+b^2c^2-2abcd=(ad-bc)^2\ge0,\]
which proves the inequality, with equality exactly when $ad=bc$. (The post also has a typo: the intermediate inequality should read $(ad)^2+(bc)^2\ge2abcd$, not $(ad)^2+(bd)^2\ge2abcd$.)
