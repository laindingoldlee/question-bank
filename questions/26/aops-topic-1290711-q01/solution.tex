By the rational root theorem, any integer root divides $6$. Trying $x=1$: $1-6+11-6=0$, so $x-1$ is a factor. Dividing, $x^3-6x^2+11x-6=(x-1)(x^2-5x+6)=\boxed{(x-1)(x-2)(x-3)}$.
