Call the left side $P(x)$. Compare it with the fifth powers of $x^2+x+1$ and $x^2+x+2$. Expanding,
\[(x^2+x+1)^5=x^{10}+5x^9+15x^8+30x^7+45x^6+51x^5+45x^4+30x^3+15x^2+5x+1,\]
so
\[P(x)-(x^2+x+1)^5=x^8+10x^7+55x^6+49x^5+55x^4+10x^3+x^2>0\quad\text{for }x>0 .\]
Also
\[(x^2+x+2)^5-P(x)=4x^8+10x^7+5x^6+61x^5+110x^4+160x^3+144x^2+75x+31>0 .\]
Hence for every positive integer $x$,
\[(x^2+x+1)^5<P(x)<(x^2+x+2)^5 .\]
If $P(x)=y^5$, then $x^2+x+1<y<x^2+x+2$, which is impossible for an integer $y$ because the bounds are consecutive integers. So there are $\boxed{\text{no solutions}}$ in positive integers.
