Completing the square, $y=-(x^2-4x)+c=-(x-2)^2+4+c$. So the maximum is at $x=2$ (as stated) with maximum value $4+c$. This must be $0$, so $c=\boxed{-4}$, and the parabola is $y=-(x-2)^2$, which touches the $x$-axis at its vertex $(2,0)$.

\begin{asy}
usepackage("amsmath");
size(5.5cm);
defaultpen(fontsize(10pt));
import graph;
real f(real x){return -(x-2)^2;}
draw((-0.8,0)--(4.8,0),Arrow(TeXHead));draw((0,-5.2)--(0,1.2),Arrow(TeXHead));
label("$x$",(4.8,0),E);label("$y$",(0,1.2),N);
draw(graph(f,-0.25,4.25),blue+linewidth(0.9));
dot((2,0));label("$(2,0)$",(2,0),N);dot((0,-4));label("$(0,-4)$",(0,-4),W);
label("$y=-x^2+4x-4$",(2,-5.5),S,blue);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}
