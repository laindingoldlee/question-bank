Write $N=25q+r$ with $0\le r\le24$. Greedily using as many quarters as possible minimizes the coin count, so $q+r=66$ and $N=1650-24r$. Similarly $N=10d+s$, $0\le s\le9$, with $d+s=147$, hence $N=1470-9s$. Thus $8r-3s=60$. Modulo three, $r=3t$, giving $s=8t-20$. The digit bound on $s$ forces $t=3$, so $r=9,s=4$ and $\boxed{N=1434}$. It indeed uses $57+9=66$ coins or $143+4=147$.
