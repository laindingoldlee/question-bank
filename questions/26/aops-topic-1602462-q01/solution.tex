Take
\[
x+y=1,\qquad x+y=3 .
\]
\textbf{No solution.} If $(x,y)$ satisfied both equations, then $1=x+y=3$, which is false. So the system has no solution.

\textbf{Geometric meaning.} Each equation describes a line; a solution is a common point. These two lines both have slope $-1$ and different $y$-intercepts $1$ and $3$, so they are parallel and never meet:

\begin{asy}
usepackage("amsmath");
size(5cm);
defaultpen(fontsize(10pt));
import graph;
draw((-1.5,0)--(4,0),gray,Arrow(TeXHead));draw((0,-1.5)--(0,4),gray,Arrow(TeXHead));
label("$x$",(4,0),E,gray);label("$y$",(0,4),N,gray);
draw((-1.2,2.2)--(2.4,-1.4),blue+linewidth(1));draw((-0.6,3.6)--(3.6,-0.6),red+linewidth(1));
label("$x+y=1$",(2.4,-1.4),SE,blue);label("$x+y=3$",(3.6,-0.6),E,red);
dot((1,0));dot((0,1));dot((3,0));dot((0,3));
label("$1$",(1,0),S);label("$3$",(3,0),S);label("$1$",(0,1),W);label("$3$",(0,3),W);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

In general, a system $ax+by=e$, $cx+dy=f$ has no solution exactly when its left sides are proportional but its right sides are not (parallel, distinct lines); for instance $2x+4y=1$, $x+2y=5$ is another example.
