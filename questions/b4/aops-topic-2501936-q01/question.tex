There are $11$ suitcases and $11$ keys. Each key opens exactly one suitcase, and each suitcase is opened by exactly one key, but we do not know which key opens which suitcase. An \emph{attempt} consists of trying one key in one suitcase. What is the smallest number of attempts that guarantees that we can determine which key opens each suitcase, however unlucky we are? A student claims the answer is $11+10+9+\cdots+1=66$. Is this right?
