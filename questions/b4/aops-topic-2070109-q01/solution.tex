(a) If $k\ge0$ then $b-k\le b<a$, so $a>b-k$. If $k<0$, the conclusion can fail: take $b=0$ and $a=\dfrac{-k}{2}$; then $a>b$, but $b-k=-k>a$. So the inequality is guaranteed exactly for $\boxed{k\ge0}$.

(b) If $j\ge0$ then $a+j\ge a>b$. If $j<0$, take $b=0$ and $a=\dfrac{-j}{2}>0$; then $a+j=\dfrac{j}{2}<0=b$. So it is guaranteed exactly for $\boxed{j\ge0}$.

In words: lowering the smaller side or raising the larger side preserves a strict inequality, but ``subtracting any amount'' is only safe when the amount is non-negative.
