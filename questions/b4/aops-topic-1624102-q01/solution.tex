We have $\overline{abc}_{13}=169a+13b+c$. Since $169\equiv1$ and $13\equiv1\pmod4$,
\[
\overline{abc}_{13}\equiv a+b+c\pmod4 .
\]
A number is divisible by $2$ but not by $4$ exactly when it is $\equiv2\pmod4$, so we need $a+b+c\equiv2\pmod4$.

Since $a\ge1$, $p=a+3b+2c\ge1$. The value $p=1$ forces $a=1$, $b=c=0$, and $a+b+c=1\not\equiv2$. The value $p=2$ with $a\ge1$ forces $(a,b,c)=(2,0,0)$ (as $b=0$, and $c=0$ since $a\ge1$), and $a+b+c=2$ works: $200_{13}=338=2\cdot169$, which is even, and $169$ is odd, so $4\nmid338$.

The smallest value is $\boxed{2}$.
