Let $a$, $b$, $c$ be base-$13$ digits (integers from $0$ to $12$) with $a\ne0$, and let $p=a+3b+2c$. Find the smallest value of $p$ for which the base-$13$ number $\overline{abc}_{13}$ is divisible by $2$ but not by $4$.
