If $a$, $b$, $c$ bricks contribute $1$, $2$, $\pi$, the height is $a+2b+c\pi$ with $a+b+c=6$. Because $\pi$ is irrational, two heights $m+c\pi$ and $m'+c'\pi$ (with integers $m,m'$) are equal only if $c=c'$ and $m=m'$. For a fixed $c$, $a+b=6-c$ and $a+2b$ takes every value from $6-c$ to $2(6-c)$: $7-c$ values. Summing over $c=0,\dots,6$: $7+6+\dots+1=\boxed{28}$.
