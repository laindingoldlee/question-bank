A second-degree equation $Ax^2+Bxy+Cy^2+Dx+Ey+F=0$ (with $A,B,C$ not all zero) whose graph is a non-degenerate conic is an ellipse (possibly a circle) if $B^2-4AC<0$, a parabola if $B^2-4AC=0$, and a hyperbola if $B^2-4AC>0$. Prove this by rotating the axes.
