Work modulo $13$.

For the first term, $2^{6}=64=5\cdot13-1$, so $2^6\equiv-1$ and $2^{12}\equiv1\pmod{13}$. Hence
\[
2^{60}=\left(2^{12}\right)^5\equiv1\pmod{13}.
\]
For the second term, $7^2=49=3\cdot13+10\equiv10\equiv-3$, so $7^6=\left(7^2\right)^3\equiv(-3)^3=-27\equiv-1\pmod{13}$. Hence
\[
7^{30}=\left(7^{6}\right)^5\equiv(-1)^5=-1\pmod{13}.
\]
Adding, $2^{60}+7^{30}\equiv1+(-1)=0\pmod{13}$, so $13$ divides $2^{60}+7^{30}$. $\blacksquare$

(Both $2^{12}\equiv1$ and $7^{12}\equiv1$ also follow from Fermat's little theorem, but the smaller powers $2^6\equiv7^6\equiv-1$ are what make the computation quick.)
