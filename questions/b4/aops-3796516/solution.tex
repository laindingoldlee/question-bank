The map $t \mapsto 2^{\dfrac{t}{2}}$ is increasing. Since $a_1>a_0$, induction shows $a_{k+1}>a_k$. Also, if $a_k<2$, then $a_{k+1}<2$, so all terms are bounded above by $2$. The sequence therefore converges to $L\in[1,2]$, with $L = 2^{\dfrac{L}{2}}$. On $[1,2]$, the function $\log t-\dfrac{t}{2}\log2$ has derivative $\dfrac{1}{t}-\dfrac{1}{2}\log2>0$, so its only zero there is $2$. Thus $\boxed{L=2}$. The other fixed point $4$ is outside the interval containing every term.
