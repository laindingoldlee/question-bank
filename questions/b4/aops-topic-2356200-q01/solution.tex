Each term is half or double the next one, so going forward each term is double or half the previous one.
\begin{itemize}
\item $a_1$ is $22$ or $\dfrac{11}{2}$; it must be an integer, so $a_1=22$.
\item $a_3$ is $22$ or $\dfrac{11}{2}$, so $a_3=22$.
\item $a_4$ is $44$ or $11$.
\item If $a_4=11$, then $a_5=22$ (not $\dfrac{11}{2}$); if $a_4=44$, then $a_5=88$ or $22$.
\end{itemize}
The possible sums are
\[22+11+22+11+22=88,\quad22+11+22+44+22=121,\quad22+11+22+44+88=187.\]
The average has fractional part $0.2$ exactly when the sum leaves remainder $1$ on division by $5$. The remainders are $3$, $1$ and $2$, so the sum is $121$ and the average is $\dfrac{121}{5}=\boxed{24.2}$.
