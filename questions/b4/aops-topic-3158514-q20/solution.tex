Write $ a_i=k_i+t_i $ with integer $ k_i $ and $ 0\le t_i<\dfrac{1}{2}$. Each pair satisfies $\lfloor a_i+a_j\rfloor=k_i+k_j $, so the target is $ 9\sum k_i=9(20-\sum t_i)$. The sum $\sum t_i $ is an integer in $[0,5)$, hence 0, 1, 2, 3, 4. All occur by taking each $ t_i $ equal to one tenth of the chosen total and choosing integers $ k_i $ summing to the required remainder. The possible target values are 180,171,162,153,144, whose sum is $\boxed{810}$.
