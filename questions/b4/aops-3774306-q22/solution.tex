Since $7^2+24^2=25^2$, the triangle is right. Its circumcircle has the hypotenuse as diameter, so the radius is $\boxed{\dfrac{25}{2}=12.5}$.
\begin{asy}
import graph;
usepackage("amsmath");
import geometry;
size(7cm);
pair[] p={(0,0),(24,0),(0,7)}; pair labelCentre=(0,0);for(pair labelVertex:p)labelCentre+=labelVertex;labelCentre/=p.length; draw(p[0]--p[1]--p[2]--cycle); dot(p[0]);label("$A$",p[0],unit(p[0]-labelCentre));dot(p[1]);label("$B$",p[1],unit(p[1]-labelCentre));dot(p[2]);label("$C$",p[2],unit(p[2]-labelCentre));draw(circle((12,3.5),12.5));dot((12,3.5));label("$O$",(12,3.5),(1,1));
\end{asy}
