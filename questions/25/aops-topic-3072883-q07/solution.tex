The addition identity $F_{r+s}=F_rF_{s+1}+F_{r-1}F_s$ holds for $r\ge1,s\ge0$. For $s=0,1$ it follows directly from the initial values and recurrence. If it holds for consecutive values of $s$, adding those identities and using the Fibonacci recurrence proves the next, so induction establishes it for all $s$. Now take $r=n,s=n-1$: $F_{2n-1}=F_nF_n+F_{n-1}F_{n-1}$, as required.
