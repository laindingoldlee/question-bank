We need $x\ne0$. If $x<0$, both terms are less than $1$, so the sum is less than $2$. So $x>0$.

\emph{Two solutions.} $x=2$ gives $9+2=11$. Also $x=\log_32$ works: then $3^x=2$ and $\dfrac1x=\log_23$, so $4^{\dfrac1x}=\left(2^{\log_23}\right)^2=9$, and $2+9=11$.

\emph{No others.} On $x>0$ the function $f(x)=3^x+4^{\dfrac1x}$ is strictly convex: $3^x$ is strictly convex, and $4^{\dfrac1x}=e^{\dfrac{\ln4}{x}}$ is an increasing convex function ($e^t$) of a convex function ($\dfrac{\ln4}{x}$). A strictly convex function takes any value at most twice.

So $\boxed{x=2\ \text{or}\ x=\log_32}$.
