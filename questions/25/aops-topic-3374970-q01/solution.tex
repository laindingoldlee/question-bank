The notation $f(x)$ names the output of a function with input $x$. Setting $y=f(x)$ gives exactly the equation $y=2x+3$, so the graphs coincide. We have $\boxed{f(4)=11}$ and graph point $\boxed{(4,11)}$.
\begin{asy}
usepackage("amsmath");
size(7cm);
draw((-1,0)--(5,0),Arrow);draw((0,-1)--(0,13),Arrow);draw((-1,1)--(5,13),blue);dot("$(4,11)$",(4,11),E);dot("$(0,3)$",(0,3),W);label("$x$",(5,0),S);label("$y=f(x)$",(0,13),W);
\end{asy}
