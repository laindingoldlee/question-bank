Multiplying by \(2\), the inequality is equivalent to
\[
2a^2+2b^2\ge a^2+2ab+b^2\iff a^2-2ab+b^2\ge0\iff (a-b)^2\ge0,
\]
which is true for all real \(a,b\). Each step is reversible, so the original inequality holds, with equality exactly when \(a=b\). \(\blacksquare\)
