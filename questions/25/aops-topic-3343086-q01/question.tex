A $9\times9$ grid is divided into nine $3\times3$ blocks, numbered $1$ through $9$ left-to-right, top-to-bottom. Cells inside each block are numbered the same way. Given block number $a$ and local cell number $b$, find global column $c$ and row $d$, numbered $0$ through $8$.
