By Vieta's formulas, $a+c=-a$, $ac=-b$, $b+d=-c$ and $bd=d$. So $c=-2a$ and $b=-ac=2a^2$, and $d(b-1)=0$.
\begin{itemize}
\item $d=0$: then $b=-c=2a$, so $2a^2=2a$: $a=0$ (giving $(0,0,0,0)$) or $a=1$ (giving $(1,2,-2,0)$).
\item $b=1$: then $2a^2=1$, $a=\pm\dfrac{\sqrt2}{2}$, $c=\mp\sqrt2$, and $d=-c-b=\pm\sqrt2-1$.
\end{itemize}
So $(a,b,c,d)$ is one of
\[\boxed{(0,0,0,0),\ (1,2,-2,0),\ \left(\dfrac{\sqrt2}{2},1,-\sqrt2,\sqrt2-1\right),\ \left(-\dfrac{\sqrt2}{2},1,\sqrt2,-\sqrt2-1\right)}.\]
Each can be checked directly; e.g. $x^2+x-2$ has roots $1,-2$ and $x^2-2x$ has roots $2,0$.
