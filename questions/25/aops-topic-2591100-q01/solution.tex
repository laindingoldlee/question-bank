\textbf{(a)} The square has $8$ symmetries: the rotations by $0^\circ,90^\circ,180^\circ,270^\circ$ and four reflections. Each of them maps the set of seats to itself. No symmetry other than the identity fixes any seat: a non-trivial rotation moves every seat to another side; a reflection in a midline swaps the two seats on each side it crosses and swaps the two sides it does not cross; a reflection in a diagonal swaps the two seats next to each corner on that diagonal and swaps the other two sides.

Take any seating $\sigma$ and apply all $8$ symmetries. If two different symmetries $g\ne h$ gave the same seating, then $h^{-1}g$ would be a non-identity symmetry leaving every person in place, which is impossible since it moves every seat and all people are different. So each seating is ``the same'' as exactly $8$ seatings (itself included). The $8!$ seatings therefore fall into classes of $8$, and the number of different seatings is
\[\dfrac{8!}{8}=\boxed{5040}.\]

\textbf{(b)} Each class contains $8$ seatings, one for each symmetry, not $4\cdot4=16$. Dividing by $4$ for the rotations is correct when only rotations are allowed ($10080$ seatings). Adding the reflections only doubles the class size: once rotations are allowed, every reflection is a rotation followed by one fixed reflection. So one should divide by $2$ more, not by $4$.
