Group the terms in pairs, starting from the left. For an even number $n$ from $4$ to $66$,
\[n(n-1)-(n-1)(n-2)=(n-1)\bigl(n-(n-2)\bigr)=2(n-1).\]
The pairs start at $n=66,64,\dots,4$, so they contribute
\[2(65+63+\cdots+3).\]
The odd numbers from $1$ to $65$ are the first $33$ odd numbers, with sum $33^2=1089$, so $65+63+\cdots+3=1088$. Adding the last term $2\times1$, the value is
\[2\cdot1088+2=\boxed{2178}.\]
