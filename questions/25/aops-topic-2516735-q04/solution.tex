The hours $AB$ run from $00$ to $23$ and the minutes $CD$ from $00$ to $59$. For each of the $24$ hours $h$ there is exactly one minute value $CD=h$ (possible since $h\le23<60$). So $24$ of the $1440$ times work, and the probability is
\[\dfrac{24}{1440}=\boxed{\dfrac{1}{60}}.\]
