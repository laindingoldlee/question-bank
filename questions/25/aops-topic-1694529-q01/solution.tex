Work modulo $4$. Since $4\mid180$, the right side is $\equiv2\pmod4$. If $n$ is even, then $4\mid n^2$ and the left side is $\equiv0\pmod4$. If $n$ is odd, then $n^2$ is odd, and $m^3n^2\equiv2\pmod4$ would need $m^3\equiv2\pmod 4$; but $m^3$ is odd when $m$ is odd and divisible by $8$ when $m$ is even. So the left side is never $\equiv2\pmod4$, and there are $\boxed{0}$ solutions.
