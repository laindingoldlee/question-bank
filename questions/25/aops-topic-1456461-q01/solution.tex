\textbf{(a)} Let $2\le k\le p$. Then $k$ has a prime factor $r$, and $r\le k\le p$, so $r$ is one of the primes in the product $q$. Hence $r\mid q$ and $r\mid k$, so $r\mid q+k$. Since $q+k>k\ge r$, the number $q+k$ has a divisor $r$ with $1<r<q+k$, so it is composite.

\textbf{(b)} Hardy's point is that the conclusion we want, long runs of composite numbers, follows in either case.
\begin{itemize}
\item If there are infinitely many primes (Euclid's theorem), then for any $m$ we can choose a prime $p\ge m+1$. Part (a) gives $p-1\ge m$ consecutive composite numbers.
\item If there were only finitely many primes, with largest prime $P$, then every integer greater than $P$ would have no prime "of its own" and would be composite. Every number from $P+1$ on would be composite, and again there would be $m$ consecutive composite numbers (for example $P+1,\dots,P+m$).
\end{itemize}
Either way, for every $m$ there are $m$ consecutive composite numbers. $\blacksquare$

(Of course the second case does not happen: the number $2\cdot3\cdots P+1$ would be greater than $1$ but not divisible by any prime. Hardy's remark only says that the gap result does not need this.)
