BEGINNING has the letters B, E, G, G, I, I, N, N, N. Fix an N in front; the remaining letters B, E, G, G, I, I, N, N can be arranged in $\dfrac{8!}{2!\,2!\,2!}=\boxed{5040}$ ways.
