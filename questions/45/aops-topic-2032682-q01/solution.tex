Note that $m\ne-3$ and
\[\dfrac{m+5}{m+3}=1+\dfrac{2}{m+3}=1+2\cdot\dfrac{1}{m+3}.\]
So if $k=\dfrac{1}{m+3}$ is an integer, then $\dfrac{m+5}{m+3}=1+2k$ is automatically an integer. The only condition is that $\dfrac{1}{m+3}$ is an integer $k$; necessarily $k\ne0$, and $m=\dfrac{1}{k}-3$.

(a) If $m$ is an integer, then $m+3$ is an integer dividing $1$, so $m+3=\pm1$, giving $\boxed{m=-2\text{ or }m=-4}$. (Check: $m=-2$ gives $1$ and $3$; $m=-4$ gives $-1$ and $-1$.)

(b) If $m$ is real, the solutions are exactly
\[\boxed{m=-3+\dfrac{1}{k}\ \text{ for some nonzero integer } k},\]
for example $m=-2,-4,-\dfrac{5}{2},-\dfrac{7}{2},\dots$; for each such $m$ the two fractions equal $k$ and $1+2k$.
