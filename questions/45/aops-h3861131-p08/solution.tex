Canceling factorials yields $\dfrac{22!}{a!}=b(b-1)(b-2)(b-3)$. Necessarily $1\le a\le22$ and $b\ge4$. For each of these twenty-two values of $a$, the right side is strictly increasing in $b\ge4$, so there is at most one candidate, found by integer binary search between $4$ and $\dfrac{22!}{a!}+4$. Exact evaluation yields only $a=18,b=22$: $\dfrac{22!}{18!}=22\cdot21\cdot20\cdot19$. Thus $\boxed{a+b=40}$.
