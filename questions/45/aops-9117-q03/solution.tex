If $a,b$ were both odd, reduction modulo 4 would give $1\equiv2+c^2$, impossible. Hence $ab$ is even, so $a^2+b^2+c^2\equiv0\pmod4$. A sum of three squares is 0 modulo 4 only when each is 0, so all three variables are even. After division by 4, the same argument applies to the halved variables because the left side remains a multiple of 4. Repeating shows every variable is divisible by every power of two, forcing $\boxed{(a,b,c)=(0,0,0)}$.
