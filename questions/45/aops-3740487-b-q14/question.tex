There are twenty pandas in a colony. Independently each night, four uniformly chosen pandas stand guard while the others sleep/eat. While guarding, the pandas play poker. If each of the four guards has a $\dfrac{1}{4}$ chance of winning, what is the expected value of the number of nights it takes so that every panda wins a game? Express your answer to the nearest whole number.

$\textbf{(A)}~82\qquad\textbf{(B)}~80\qquad\textbf{(C)}~72\qquad\textbf{(D)}~5\qquad\textbf{(E)}~89\qquad$
