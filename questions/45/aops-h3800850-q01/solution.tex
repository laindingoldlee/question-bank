The elements $1,4,9$ are forbidden. Among the remaining elements, at most one of each pair $\{2,7\},\{3,6\}$ can be chosen, because their sums are nine. Thus a set of size five would have to contain $5,8,10$ and one member of each of those two pairs.
It cannot contain three, since $3+5+8=16$, so it must contain six. But $6+10=16$ is then already a contradiction. Hence no size-five set exists, and neither does any larger set.
The set $\{5,6,7,8\}$ works: singleton sums are between five and eight, pair sums between eleven and fifteen, triple sums between eighteen and twenty-one, and the total is twenty-six. None is a square. Therefore the maximum is $\boxed4$.
