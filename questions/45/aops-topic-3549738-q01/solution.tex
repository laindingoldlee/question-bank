The domain excludes $x=0$. For every allowed $x$, $x^0=1$, so the equation reduces to $1-3x+4=1$, or $x=\dfrac{4}{3}$. This value is nonzero and satisfies the original equation. The solution is $\boxed{\dfrac{4}{3}}$.
