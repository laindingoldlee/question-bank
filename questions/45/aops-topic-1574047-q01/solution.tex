\textbf{$D$ is false.} If $D$ were true, then $A$ and $B$ would be true; but $A$ says $B$ is false, a contradiction.

\textbf{$A$ is false.} If $A$ were true, then $C$ would be true, and $C$ says $A$ is false, a contradiction.

So $A$ and $D$ are false, and the two true statements must be $B$ and $C$. Check that this assignment is consistent:
\begin{itemize}
\item $A$ (``$B$ false and $C$ true'') is false, since $B$ is true. Correct.
\item $B$ (``$C$ true and $D$ false'') is true. Correct.
\item $C$ (``$D$ false and $A$ false'') is true. Correct.
\item $D$ (``$A$ true and $B$ true'') is false, since $A$ is false. Correct.
\end{itemize}
The true statements are $\boxed{B\text{ and }C}$.
