Find the equations of the asymptotes of the hyperbola
\[\dfrac{(x-3)^2}{16}-\dfrac{(y+2)^2}{4}=1 .\]
One student writes the answer as $x-3=\pm 2(y+2)$, while a book writes $y+2=\pm\dfrac{2}{4}(x-3)$. Determine whether these describe the same lines.
