Since $198=2\cdot3^2\cdot11$, there are $198(1-\dfrac{1}{2})(1-\dfrac{1}{3})(1-\dfrac{1}{11})=60$ such integers. Pair each $a$ with $198-a$; each pair sums to $198$. Therefore the sum is $30\cdot198=\boxed{5940}$.
