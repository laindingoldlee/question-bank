If $S$ contains a multiple of seven, it cannot contain any other number, because their product would be divisible by seven. Otherwise the permitted residue classes are $1,2,3,4,5,6$, with at most one class selected from each pair $\{1,6\},\{2,5\},\{3,4\}$. Since $2023=7\cdot289$, each class contains $289$ integers. Therefore $|S|\le3\cdot289=867$. Taking all numbers congruent to $1,2,3$ attains this bound, since no sum of two such residues is zero modulo seven and no factor is zero. Thus $\boxed{867}$.
