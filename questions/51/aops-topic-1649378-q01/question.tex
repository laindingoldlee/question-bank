Johnny and Mark play a sequence of card games. In the first game there are $2$ cards, and before each new game Johnny adds one more card, so the $k$-th game uses $k+1$ cards. In each game Johnny shuffles the cards and Mark wins if he guesses their order exactly; Mark's guess is a uniformly random ordering, and the games are independent. The games go on for ever. Show that the probability that Mark wins at least one game is
\[
1-\prod_{n=2}^{\infty}\left(1-\dfrac{1}{n!}\right),
\]
and find this probability correct to three decimal places.
