Exact integer multiplication avoids all logarithmic rounding issues. The following complete computation gives $\boxed{14348}$ as the first five digits.\begin{verbatim}
import sys
sys.set_int_max_str_digits(50000)
v=1
for n in range(1,7287):v*=n
s=str(v)
assert len(s)==24981 and s[:5]=="14348"
\end{verbatim}
