Choose the box labelled ``Apples and Oranges, choice D. Its label is wrong, so it contains only one kind of fruit. If the drawn fruit is an apple, this box contains only apples. The box labelled ``Oranges cannot contain only oranges, so it must be the mixed box, and the remaining box contains only oranges. If the fruit is an orange, reverse the roles: the box labelled ``Apples is mixed, and the remaining box contains only apples. Either draw determines all three boxes.
