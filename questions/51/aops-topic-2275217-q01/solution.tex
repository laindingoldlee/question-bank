\textbf{(a)} Rewrite the equation as $c(ab-1)=a+b$. If $ab=1$, this forces $a+b=0$, so $b=-a$ and $ab=-a^2=1$, which is impossible for real $a$. Hence always $ab\ne1$, and
\[c=\dfrac{a+b}{ab-1}.\]
Conversely, for any reals $a,b$ with $ab\ne1$ this $c$ gives a solution. So the solutions are exactly $\left(a,\ b,\ \dfrac{a+b}{ab-1}\right)$ with $ab\ne1$. (For example, if $A+B+C=180^\circ$ and no angle is $90^\circ$, then $(\tan A,\tan B,\tan C)$ is a solution.)

\textbf{(b)} False. Besides permutations such as $(2,3,1)$, there are $(0,0,0)$, $(5,-5,0)$ and non-integer solutions such as $a=b=2$, $c=\dfrac{4}{3}$.

\textbf{(c)} If one number is $0$, say $c=0$, then $a+b=0$: the solutions $(t,-t,0)$ and their permutations, for any integer $t$. Now let all three be nonzero and, by symmetry, $|a|\le|b|\le|c|$. Then
\[|ab|\,|c|=|a+b+c|\le3|c|,\]
so $|ab|\le3$, and $(|a|,|b|)$ is $(1,1)$, $(1,2)$ or $(1,3)$. Use $c(ab-1)=a+b$:
\begin{itemize}
\item $|a|=|b|=1$: if $ab=1$ then $a+b=\pm2\ne0$, impossible; if $ab=-1$ then $a+b=0$ and $c=0$, excluded.
\item $|a|=1,|b|=2$: if $ab=2$, then $c=a+b=\pm3$, giving $(1,2,3)$ and $(-1,-2,-3)$; if $ab=-2$, then $c=-\dfrac{a+b}{3}=\mp\dfrac{1}{3}$, not an integer.
\item $|a|=1,|b|=3$: if $ab=3$, then $c=\dfrac{a+b}{2}=\pm2$, so $|c|<|b|$, against the ordering; if $ab=-3$, then $c=-\dfrac{a+b}{4}=\pm\dfrac{1}{2}$, not an integer.
\end{itemize}
So the integer solutions are the permutations of $\boxed{(1,2,3),\ (-1,-2,-3),\ (t,-t,0)}$ for integers $t$.
