With the chairs numbered there are $7\cdot6\cdot5\cdot4\cdot3=2520$ seatings. Each rotation class contains exactly $7$ seatings (a nontrivial rotation moves every student), so there are
\[
\dfrac{2520}{7}=\boxed{360}
\]
seatings.
