Let the set cost $x$ francs. He loses $x\%$ of $x$, i.e.\ $\dfrac{x^2}{100}$ francs, so
\[
x-\dfrac{x^2}{100}=24\quad\Longrightarrow\quad x^2-100x+2400=0\quad\Longrightarrow\quad (x-40)(x-60)=0 .
\]
\begin{itemize}
\item If $x=40$, he loses $40\%$ of $40$, which is $16$ francs ($40-16=24$).
\item If $x=60$, he loses $60\%$ of $60$, which is $36$ francs ($60-36=24$).
\end{itemize}
So the loss is $\boxed{16\text{ or }36\text{ francs}}$; the data do not decide between them.
