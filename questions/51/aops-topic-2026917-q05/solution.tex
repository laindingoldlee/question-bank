Multiplying by $6x+9$ (which must be nonzero): $4x-20=30x+45$, so $-26x=65$ and $x=-\dfrac{5}{2}$. Then $6x+9=-6\ne0$, so the solution is valid:
\[\boxed{x=-\dfrac{5}{2}}.\]
