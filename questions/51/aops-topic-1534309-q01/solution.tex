For any positive integers, $\gcd(m,n)\cdot\operatorname{lcm}(m,n)=mn$ (for each prime, the exponents $\min$ and $\max$ add up to the two exponents). So the number is
\[
145860\cdot22147804=2^4\cdot3\cdot5\cdot7^2\cdot11\cdot13\cdot17^4\cdot23 ,
\]
and its number of positive divisors is
\[
(4+1)(1+1)(1+1)(2+1)(1+1)(1+1)(4+1)(1+1)=5\cdot2\cdot2\cdot3\cdot2\cdot2\cdot5\cdot2=\boxed{2400}.
\]
