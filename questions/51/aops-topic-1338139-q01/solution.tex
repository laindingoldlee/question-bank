Write the number as $\overline{htu}$ with $h\ge1$. By (1), $t+u=9$, so the digit sum is $h+9$. A number is a multiple of $3$ exactly when its digit sum is, so (3) means $3\mid h$, that is, $h\in\{3,6,9\}$.

By (2), $u$ is even: $u\in\{0,2,4,6,8\}$, and then $t=9-u\in\{9,7,5,3,1\}$ is a valid digit in each case.

The choices of $h$ and $u$ are independent, so there are $3\cdot5=\boxed{15}$ such numbers (for example $390,372,354,336,318$ with $h=3$).
