Draw from the drawer labeled MIXED. Because that label is wrong, this drawer is pure, so the drawn item identifies its entire contents. If it contains spoons, the drawer labeled FORKS cannot contain forks and cannot be the already identified spoon drawer, so it is mixed; the drawer labeled SPOONS contains forks. If the drawn item is a fork, interchange spoons and forks in this reasoning. Thus one draw always determines all three drawers.
