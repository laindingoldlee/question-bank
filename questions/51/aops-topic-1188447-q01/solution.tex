Write $\sigma(n)$ for the sum of divisors. It is multiplicative, $\sigma(p)=p+1$, $\sigma\left(p^2\right)=1+p+p^2$, and $\sigma(n)\ge n+1$, so only $n<\sigma(n)$ need be checked.

$\sigma(n)=48$: write $48$ as a product of values $\sigma\left(p^k\right)$ for distinct primes. Prime values $p+1$: $48=\sigma(47)$, $4\cdot12=\sigma(3)\sigma(11)$, $6\cdot8=\sigma(5)\sigma(7)$; other factorisations ($2\cdot24$, $3\cdot16$, $2\cdot\ldots$) need $p+1=2$ or $p+1\in\{16,24\}$ with $p$ composite, and prime-power values $3,7,13,15,31,\dots$ do not combine to $48$. So $n=\boxed{33,\ 35,\ 47}$.

$\sigma(n)=144$: in the same way, $144=3\cdot4\cdot12=\sigma(2)\sigma(3)\sigma(11)$, $3\cdot6\cdot8=\sigma(2)\sigma(5)\sigma(7)$, $3\cdot48=\sigma(2)\sigma(47)$, $6\cdot24=\sigma(5)\sigma(23)$, $8\cdot18=\sigma(7)\sigma(17)$, giving $n=\boxed{66,\ 70,\ 94,\ 115,\ 119}$; a search over all $n<144$ confirms there are no others.
