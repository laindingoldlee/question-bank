Let $e_a$ be the expected number of further rolls when the last roll is $a$. The next roll $b$ ends the game iff $b\mid a$, which has probability $\dfrac{d(a)}6$; otherwise we move to state $b$. So $e_a=1+\dfrac16\sum_{b\nmid a}e_b$ for $a=1,\dots,6$.

Solving this $6\times6$ linear system, the expected total is $1+\dfrac16\sum_ae_a=\boxed{\dfrac{343}{102}}\approx3.36$.
