Digits 2 and 3 require $k\ge4$. The repeating block has value $2k+3$, so the geometric series gives
\[0.\overline{23}_k=\dfrac{2k+3}{k^2}+\dfrac{2k+3}{k^4}+\cdots=\dfrac{2k+3}{k^2-1}.\]
Set this equal to $\dfrac{7}{51}$. Cross multiplication yields $7k^2-102k-160=0$, or $(7k+10)(k-16)=0$. The permitted base is $\boxed{16}$.
