Evaluate each piece:
\[
\left(\dfrac{1}{25}\right)^{-\dfrac{1}{2}}=25^{\dfrac{1}{2}}=5,\qquad 0.017^0=1,\qquad 0.\overline{8}=\dfrac{8}{9} .
\]
(For the last one: if $r=0.\overline8$, then $10r-r=8$, so $r=\dfrac{8}{9}$.) The bracket is $8+\dfrac{1}{3}+5+1=\dfrac{43}{3}$, and dividing by $\dfrac{8}{9}$ means multiplying by $\dfrac{9}{8}$:
\[
\dfrac{43}{3}\cdot\dfrac{9}{8}=\dfrac{129}{8}.
\]
The value is $\boxed{\dfrac{129}{8}}$.
