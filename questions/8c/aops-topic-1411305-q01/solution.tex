Let $x=a-2020$ and $y=2020-b$, so $xy=2020^2$ with $x>-2020$ (because $a\ge1$) and $y<2020$ (because $b\ge1$). Every integer pair $(x,y)$ with these properties gives exactly one pair $(a,b)$, and conversely. Since $2020=2^2\cdot5\cdot101$, the number $2020^2=2^4\cdot5^2\cdot101^2$ has $5\cdot3\cdot3=45$ positive divisors.

\textbf{$x,y>0$.} Then $y$ is a positive divisor of $2020^2$ less than $2020$. The divisors other than $2020$ pair up as $d\leftrightarrow\dfrac{2020^2}{d}$ with exactly one of each pair below $2020$, so there are $\dfrac{45-1}{2}=22$ choices.

\textbf{$x,y<0$.} Then $|x|<2020$, so $|y|=\dfrac{2020^2}{|x|}>2020$ and $y<2020$ holds automatically. The number of choices is the number of divisors $|x|<2020$, again $22$.

The total is $22+22=\boxed{44}$.
