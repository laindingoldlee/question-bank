The set $A$ consists of the odd integers that are at least $-1$.

\textbf{Every element of $A\cap B$ has the stated form.} Let $x=801-9m\in A$. Since $x$ is odd and $801$ is odd, $9m$ is even, so $m$ is even: $m=2k$ with $k\in\mathbb N$, and $x=801-18k$. Since $x\ge-1$, we get $18k\le802$, so $k\le44$ (as $18\cdot45=810$).

\textbf{Every such number is in $A\cap B$.} For $1\le k\le44$, $x=801-18k$ equals $801-9m$ with $m=2k\in\mathbb N$, so $x\in B$; and $x$ is odd with $x\ge801-792=9\ge-1$, so $x=2n-3$ with $n=\dfrac{x+3}{2}\in\mathbb N$, and $x\in A$.

Hence $A\cap B=\{783,765,\dots,9\}$, with $\boxed{44}$ elements. $\blacksquare$
