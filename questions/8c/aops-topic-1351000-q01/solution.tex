Fix one particular student, Ann. In a seating, read the other seven students in clockwise order starting from Ann's left; this gives one of $7!$ sequences, and different sequences give different rotation classes. So there are $7!=5040$ arrangements up to rotation.

Two of these have exactly the same neighbour pairs only when one is the mirror image of the other (reading clockwise versus counterclockwise). A mirror image is never a rotation of the same arrangement when there are $8\ge3$ distinct students, because the student on Ann's left would have to equal the student on her right. So the $5040$ arrangements pair up, and the number of different seatings is
\[
\dfrac{7!}{2}=\boxed{2520}.
\]
