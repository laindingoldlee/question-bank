For example,
\[
\boxed{15\times5+40+10=125},
\]
since $15\times5=75$ and $75+40+10=125$. Another correct expression is $(40-15)\times(10-5)=25\times5=125$. Any expression that uses each of the four numbers exactly once and equals $125$ is a correct answer.
