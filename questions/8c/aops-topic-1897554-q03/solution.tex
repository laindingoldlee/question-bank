We need $2n+1$ to be a perfect square. Since $2n+1$ is odd, it must be the square of an odd number $k$, and then $n=\dfrac{k^2-1}{2}$ is a positive integer for every odd $k\ge3$. The condition $0<n<1000$ means $3\le2n+1\le1999$. The odd squares in this range are $3^2,5^2,\dots,43^2=1849$ (the next one is $45^2=2025$). The odd numbers $3,5,\dots,43$ number $\boxed{21}$, so there are $21$ such $n$ (namely $n=4,12,24,\dots,924$).
