First, $3^{100}\equiv1\pmod{1000}$: indeed $3^{10}=59049\equiv49$, so $3^{20}\equiv49^2=2401\equiv401$, $3^{40}\equiv401^2=160801\equiv801$, $3^{80}\equiv801^2=641601\equiv601$, and $3^{100}=3^{80}\cdot3^{20}\equiv601\cdot401=241001\equiv1\pmod{1000}$. So we need the exponent $N=7^{17^3}$ modulo $100$.

Since $7^4=2401\equiv1\pmod{100}$, we need $17^3$ modulo $4$: $17\equiv1$, so $17^3\equiv1\pmod4$ and $N\equiv7^1=7\pmod{100}$. Therefore
\[3^{N}\equiv3^7=2187\equiv187\pmod{1000},\]
and the last three digits are $\boxed{187}$.
