The factors of $n$ pair up as $d$ and $\dfrac{n}{d}$; a factor is paired with itself only when $d^2=n$. So $n$ has an odd number of factors exactly when $n$ is a perfect square.

The largest six-digit number is $999999$, and $999^2=998001\le999999<1000000=1000^2$. So the largest six-digit perfect square is $999^2=\boxed{998001}$.
