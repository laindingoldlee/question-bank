\textbf{By converting.}
\[52B19_{13}=5\cdot13^4+2\cdot13^3+11\cdot13^2+1\cdot13+9=142805+4394+1859+13+9=149080,\]
\[1A7_{13}=169+10\cdot13+7=306 .\]
Now $149080=306\cdot487+58$, and
\[487=2\cdot169+11\cdot13+6=2B6_{13},\qquad 58=4\cdot13+6=46_{13}.\]

\textbf{Directly in base 13 (long division).} The multiples of the divisor that are needed are $1A7_{13}\cdot2=381_{13}$, $1A7_{13}\cdot B=16BC_{13}$ and $1A7_{13}\cdot6=AB3_{13}$.
\begin{itemize}
\item $52B_{13}$ contains the divisor $2$ times: $52B_{13}-381_{13}=17A_{13}$.
\item Bring down $1$: $17A1_{13}$ contains it $B$ times: $17A1_{13}-16BC_{13}=B2_{13}$.
\item Bring down $9$: $B29_{13}$ contains it $6$ times: $B29_{13}-AB3_{13}=46_{13}$.
\end{itemize}
So the division is not exact:
\[52B19_{13}=1A7_{13}\cdot2B6_{13}+46_{13},\qquad\text{quotient }\boxed{2B6_{13}},\quad\text{remainder }\boxed{46_{13}}.\]
