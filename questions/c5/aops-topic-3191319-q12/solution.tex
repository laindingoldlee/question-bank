Let the third side be $x$. If $x\le20$, acuteness requires $20^2<16^2+x^2$, hence $x>12$. If $x\ge20$, it requires $x^2<20^2+16^2=656$, so integral $x\le25$. The resulting integers $13,14,\ldots,25$ all satisfy the triangle inequality and the strict acute condition. There are $\boxed{13}$.
