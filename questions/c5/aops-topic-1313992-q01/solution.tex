If all $70$ were nickels the value would be $3.50$ dollars; each dime adds $5$ cents more, and we need $2.05$ dollars more, so there are $\dfrac{205}{5}=41$ dimes and $29$ nickels. The difference is $\boxed{12}$. (Algebraically: $n+d=70$, $5n+10d=555$.)
