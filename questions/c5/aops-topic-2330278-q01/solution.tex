For every number $n$,
\[n(n+1)(n+2)(n+3)+1=\bigl(n(n+3)\bigr)\bigl((n+1)(n+2)\bigr)+1=(n^2+3n)(n^2+3n+2)+1.\]
With $m=n^2+3n+1$ this is $(m-1)(m+1)+1=m^2$. So
\[n(n+1)(n+2)(n+3)+1=(n^2+3n+1)^2.\]
For $n=500$, $n^2+3n+1=250000+1500+1=251501>0$, so
\[\sqrt{500\cdot501\cdot502\cdot503+1}=\boxed{251501}.\]
