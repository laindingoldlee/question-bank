A knight changes square color on every move. Squares a 1 and h 8 have the same color. After the odd number $25$ of moves the knight is on the opposite color, so the number of paths is $\boxed0$.
\begin{asy}
usepackage("amsmath");
size(7cm);
for(int i=0;i<8;++i)for(int j=0;j<8;++j)filldraw((i,j)--(i+1,j)--(i+1,j+1)--(i,j+1)--cycle,(i+j)%2==0?lightgray:white,gray);dot("a1",(.5,.5),W);dot("h8",(7.5,7.5),E);draw((.5,.5)--(1.5,2.5),blue,Arrow);
\end{asy}
