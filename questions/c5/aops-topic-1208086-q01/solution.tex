We need $\sqrt x$ to be defined, so $x\ge0$, and $\sqrt x$ to lie in $(-1,1)$; since $\sqrt x\ge0$ this means $\sqrt x<1$, i.e. $x<1$. The domain is $\boxed{[0,1)}$.
