For rationals $ a<b $, the rational midpoint $\dfrac{a+b}{2}$ lies strictly between them. This is density, not completeness. The set $ S $ is nonempty and bounded above by $ 2 $. If a rational $ q $ were its least upper bound, then $ 1\le q\le2 $. Equality $ q^2=2 $ is impossible: writing $ q=\dfrac{u}{v} $ in lowest terms forces both $ u,v $ even. For $ q^2\ne2 $, define $ q\prime=\dfrac{2q+2}{q+2}$. Direct calculation gives $ q\prime-q=\dfrac{2-q^2}{q+2}$ and $(q\prime)^2-2=\dfrac{2(q^2-2)}{(q+2)^2}$. If $ q^2<2 $, then $ q\prime\in S $ and $ q\prime>q $, contradicting that $ q $ bounds $ S $. If $ q^2>2 $, then $ 0<q\prime<q $ and $(q\prime)^2>2 $, so $ q\prime $ is a smaller upper bound. Both cases contradict the assumption.
