The determinant is $1\cdot(-a)-(-13)\cdot5=65-a$. If $a\ne65$, there is exactly one solution. If $a=65$, the second equation reads $5(x-13y)=7$, i.e. $x-13y=\dfrac75\ne7$, so there is no solution. Hence $\boxed{\text{(1) }a=65;\ \text{(2) }a\ne65}$.
