Prove the AM--GM inequality: for all nonnegative real numbers $a_1,a_2,\dots,a_n$,
\[\dfrac{a_1+a_2+\cdots+a_n}{n}\ge\sqrt[n]{a_1a_2\cdots a_n},\]
with equality if and only if $a_1=a_2=\cdots=a_n$.
