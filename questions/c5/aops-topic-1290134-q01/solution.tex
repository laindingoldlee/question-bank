Since $y,z,w\le x$, we have $2008=3x+y+z+w\le6x$, so $x\ge\dfrac{2008}{6}=\dfrac{1004}{3}>334$. As $x$ is an integer, $x\ge335$.

$x=335$ is possible: then $y+z+w=2008-1005=1003$, for example $y=335$, $z=334$, $w=334$, which satisfies $0\le w\le z\le y\le x$. So the minimum is $\boxed{335}$.
