The divisors of $n$ come in pairs $\{d,\dfrac {n}{d}\}$, and a pair has only one member exactly when $d=\dfrac {n}{d}$, i.e.\ $d=\sqrt n$. So $n$ has an odd number of divisors if and only if $n$ is a perfect square.

Since $44^2=1936\le2018<2025=45^2$, the perfect squares from $1$ to $2018$ are $1^2,2^2,\dots,44^2$, so the answer is $\boxed{44}$.
