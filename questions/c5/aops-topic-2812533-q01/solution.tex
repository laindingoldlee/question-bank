$\binom n2\binom{n+1}2=\dfrac{n(n-1)}2\cdot\dfrac{(n+1)n}2=\dfrac{n^2(n^2-1)}4$, so the term is $\dfrac4{n^2-1}=2\left(\dfrac1{n-1}-\dfrac1{n+1}\right)$. The sum telescopes:
\[2\left(1+\dfrac12-\dfrac1{10}-\dfrac1{11}\right)=2\cdot\dfrac{72}{55}=\dfrac{144}{55}.\]
So $p+q=\boxed{199}$.
