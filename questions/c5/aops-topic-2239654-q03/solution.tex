Every game eliminates exactly one person, and every person except the winner is eliminated exactly once. So the games correspond one-to-one to the eliminated people, and there are
\[128-1=\boxed{127}\]
games. (This does not depend on how the games are scheduled; for a bracket it is $64+32+16+8+4+2+1=127$.)
