\begin{enumerate}
\item[I.] True: if $n$ is an integer, $n^2$ is an integer and $n^2\ge0$, so it is a whole number.
\item[II.] False: $a=1$, $b=2$, $c=1$ satisfy $a\ne b$ and $b\ne c$, but $a=c$.
\item[III.] False: $0$ has no multiplicative inverse, since $0\cdot x=0\ne1$ for every $x$. (Every nonzero integer $n$ does have the rational inverse $\dfrac{1}{n}$.)
\item[IV.] True: a positive number $m$ has the real square root $\sqrt m$ (the positive real number whose square is $m$).
\end{enumerate}
So the true statements are $\boxed{\text{I and IV}}$.
