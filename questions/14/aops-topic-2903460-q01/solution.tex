A two-digit number with a four-digit cube is between $10$ and $21$. The cube ends in the same digit as $\overline{ab}-4$, so $b^3\equiv b-4\pmod{10}$. Checking $b=0,\dots,9$, only $b=7$ works ($343$ ends in $3$). So $\overline{ab}=17$, and indeed $17^3=4913=100\cdot49+17-4$. The number is $\boxed{4913}$.
