(a) If M used $m$, then $2m=m+3+7$, so M used $10$ and F used $13$. Thus F wins with probability $\boxed{\dfrac{13}{23}}$. (b) With $L$ losses the cost is $2^L-1$. The loss probability is $q=\dfrac{10}{23}$, so the binomial theorem gives $E[2^L]=(1-q+2q)^5=(1+q)^5$. The expected cost is $\boxed{(\dfrac{33}{23})^5-1}$.
