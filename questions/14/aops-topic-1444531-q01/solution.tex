A three-digit number with one repeated digit is $111d=3\cdot37\cdot d$ with $1\le d\le9$. It must equal $\dfrac{n(n+1)}{2}$, so
\[
n(n+1)=2\cdot3\cdot37\cdot d .
\]
The prime $37$ divides $n$ or $n+1$. Since $\dfrac{n(n+1)}{2}<1000$ gives $n\le44$, we need $n=37$ or $n+1=37$.
\begin{itemize}
\item $n=37$: $\dfrac{37\cdot38}{2}=703$, not a repdigit.
\item $n=36$: $\dfrac{36\cdot37}{2}=666$, a repdigit.
\end{itemize}
So the number is $\boxed{666}=1+2+\cdots+36$.
