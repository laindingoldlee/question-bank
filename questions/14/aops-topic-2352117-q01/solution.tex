\textbf{Small values of $a$ fail.} If $0<a\le1$, then $a^2\le1<2$, so $x=2$ does not work. So $a>1$; write $a=e^k$ with $k>0$.

\textbf{Reformulation.} For $x\le0$ we have $a^x>0\ge x$, so only $x>0$ matters. For $x>0$, taking natural logarithms,
\[a^x\ge x\iff kx\ge\ln x\iff k\ge\dfrac{\ln x}{x}.\]
So we need $k\ge g(x)$ for all $x>0$, where $g(x)=\dfrac{\ln x}{x}$.

\textbf{The maximum of $g$.} We have
\[g'(x)=\dfrac{1-\ln x}{x^2},\]
which is positive for $0<x<e$ and negative for $x>e$. So $g$ increases up to $x=e$ and decreases afterwards, and its largest value is $g(e)=\dfrac1e$.

Hence $a^x\ge x$ for all real $x$ exactly when $k\ge\dfrac1e$, that is, when $a\ge e^{\dfrac1e}$. The smallest such $a$ is
\[a=\boxed{e^{\dfrac1e}}\approx1.4447.\]
For this value, $a^x-x\ge0$ with equality only at $x=e$ (there $a^e=e$): the graph of $y=a^x$ touches the line $y=x$ at $(e,e)$.

\textbf{Strict inequality.} The same computation shows that $a^x>x$ for all real $x$ exactly when $k>\dfrac1e$, that is, $a>e^{\dfrac1e}$. This set of values of $a$ has no smallest element (for any such $a$, the number $\dfrac{a+e^{\dfrac1e}}{2}$ is smaller and still works), so with ``strictly above the $x$-axis'' there is no smallest $a$, only the boundary value $e^{\dfrac1e}$.
