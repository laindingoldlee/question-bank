The left side is a multiple of $10$, so the inequality is equivalent to $3a+5b+7c\le34$. Set $A=a-1$, $B=b-1$, $C=c-1$, obtaining nonnegative integers with $3A+5B+7C\le19$. For $C=0,1,2$, count $A$ for each possible $B$:
\[
\begin{array}{c|c|c}
C&\text{counts as }B\text{ increases from }0&\text{subtotal}\\\hline
0&7,5,4,2&18\\
1&5,3,1&9\\
2&2,1&3
\end{array}
\]
There are $\boxed{18+9+3=30}$ triples.
