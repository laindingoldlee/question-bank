Every path consists of $6$ right steps and $6$ up steps in some order, so there are $\dbinom{12}{6}=924$ paths without the restriction.

A path through $(3,3)$ is a path from $(0,0)$ to $(3,3)$ followed by a path from $(3,3)$ to $(6,6)$, so there are $\dbinom63\cdot\dbinom63=20\cdot20=400$ of them.

So the number of paths avoiding the mouse is $924-400=\boxed{524}$.
