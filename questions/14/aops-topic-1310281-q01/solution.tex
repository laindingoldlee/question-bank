Each finite stage is correct: if $x_1=1$ and $x_{k+1}=2-x_k$, then every $x_k=1$. The error is ``removing the parentheses'': $2-(2-x)$ equals $x$, not $2-2-x$. Subtracting a bracket flips the signs inside it, so the expression alternates $2-2+2-2+\cdots$ (with a final $\pm1$), not $2-2-2-\cdots$. Moreover an infinite nesting has no value by itself; it can only be defined as a limit of the finite stages, and that limit is $1$. No contradiction arises.
