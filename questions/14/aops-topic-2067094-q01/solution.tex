The yellow cells contain exactly one cell in each row and each column, so they are given by a permutation $\sigma$ of $\{1,\dots,5\}$: in row $i$ the yellow cell is in column $\sigma(i)$. There are $5!=120$ choices. Similarly the green cells are given by a permutation $\tau$, and ``no cell gets both colours'' means $\tau(i)\ne\sigma(i)$ for every $i$.

For fixed $\sigma$, the map $i\mapsto\sigma^{-1}(\tau(i))$ is a permutation with no fixed points, and conversely each derangement $\pi$ gives $\tau=\sigma\circ\pi$. The number of derangements of $5$ objects is
\[
D_5=5!\left(1-1+\dfrac{1}{2!}-\dfrac{1}{3!}+\dfrac{1}{4!}-\dfrac{1}{5!}\right)=44 .
\]
So the number of colourings is $120\cdot44=\boxed{5280}$.
