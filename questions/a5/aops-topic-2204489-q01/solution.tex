Line up the $20$ candies; there are $19$ gaps between neighbouring candies. Choosing $3$ of these gaps for dividers splits the candies into $4$ nonempty groups (for the children in order), and every distribution arises exactly once. So the number of ways is
\[\dbinom{19}{3}=\boxed{969}.\]
