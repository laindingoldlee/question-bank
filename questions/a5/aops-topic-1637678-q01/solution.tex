$1{,}000{,}000=10^6=2^6\cdot5^6$. If one factor were divisible by both $2$ and $5$, it would be divisible by $10$ and end in $0$. So one factor must contain all the $2$s and the other all the $5$s:
\[
1{,}000{,}000=\boxed{64\times15625}.
\]
Neither $64$ nor $15625$ contains the digit $0$. (Apart from the order of the factors this is the only way: the other split, $1\times1{,}000{,}000$, fails because $1{,}000{,}000$ has zeros.)
