From the first two, $c^2-2ab=c^2-c-6$, so $ab=\dfrac{c+6}{2}$. Then $a^3+b^3=c^3-3abc=c^3-\dfrac{3c(c+6)}{2}$. Setting this equal to $c^3-2c^2-5c$: $-\dfrac{3}{2}c^2-9c=-2c^2-5c$, so $\dfrac{1}{2}c^2-4c=0$, $c=0$ or $c=8$.
\begin{itemize}
\item $c=0$: $a+b=0$, $ab=3$: $a^2=-3$, no real solution.
\item $c=8$: $a+b=8$, $ab=7$: $\{a,b\}=\{1,7\}$.
\end{itemize}
The solutions are $\boxed{(1,7,8)\text{ and }(7,1,8)}$.
