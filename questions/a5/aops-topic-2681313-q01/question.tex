Using only the basic laws of arithmetic (addition and multiplication are commutative and associative, multiplication distributes over addition, $a+0=a$, $1\cdot a=a$, and every $a$ has an additive inverse $-a$ with $a+(-a)=0$), and defining subtraction by $u-v=u+(-v)$, prove:
\begin{enumerate}
\item[(a)] $(-a)b=-(ab)$, so ``negative times positive is negative'';
\item[(b)] $(-a)(-b)=ab$, so ``negative times negative is positive'' (for example $(-x)(-x)=x^2$);
\item[(c)] $a-(-b)=a+b$, so ``subtracting a negative is adding''.
\end{enumerate}
