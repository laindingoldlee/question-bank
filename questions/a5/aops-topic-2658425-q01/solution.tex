Let $F(x)=(4x-3)\sqrt[5]{9x+5}$; it is continuous.
\begin{itemize}
\item $x>\dfrac34$: both factors are positive and increasing, so $F$ is increasing. Since $F(3)=9\sqrt[5]{32}=18$, $x=3$ is the only solution here.
\item $-\dfrac59\le x\le\dfrac34$: $4x-3\le0\le\sqrt[5]{9x+5}$, so $F(x)\le0<18$; no solutions.
\item $x<-\dfrac59$: $F(x)=(3-4x)\sqrt[5]{-9x-5}$ is a product of two positive factors that both decrease as $x$ increases, so $F$ is decreasing. Now
\[F(-2)=11\sqrt[5]{13}>18\quad\text{since}\quad\left(\dfrac{18}{11}\right)^5=\dfrac{1889568}{161051}<12<13,\]
and $F(-1)=7\sqrt[5]4<7\cdot2=14<18$. So there is exactly one solution $x_0$ here, and $-2<x_0<-1$.
\end{itemize}
Hence the equation has exactly two real solutions: $\boxed{x=3}$ and one solution $x_0$ with $\boxed{-2<x_0<-1}$ (numerically $x_0\approx-1.96$).

(With $v=\sqrt[5]{9x+5}$ the equation becomes $4v^6-47v-162=0$, which factors as $(v-2)(4v^5+8v^4+16v^3+32v^2+64v+81)=0$. The root $v=2$ gives $x=3$; the quintic factor has one real root $v_0\approx-1.661$, giving $x_0=\dfrac{v_0^5-5}{9}$.)
