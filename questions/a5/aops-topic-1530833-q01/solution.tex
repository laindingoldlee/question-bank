Each girl knows only her own score and Kaleana's score $K$.
\begin{itemize}
\item Quay can be sure that two of the four have the same score only if her own score equals Kaleana's: $Q=K$. (Otherwise she has no information about a tie.)
\item Marty can be sure he is not the lowest only if he scored more than someone whose score he knows, i.e.\ $M>K$.
\item Shana can be sure she is not the highest only if she scored less than Kaleana: $S<K$.
\end{itemize}
Hence $S<K=Q<M$, and the order from lowest to highest is $\boxed{S,\ Q,\ M}$.
