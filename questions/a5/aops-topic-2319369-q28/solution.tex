For an item priced $p$ dollars, with $p\ge7.5$ so that neither final price is negative:
\begin{itemize}
\item discount first, then coupon: $0.8p-6$;
\item coupon first, then discount: $0.8(p-6)=0.8p-4.8$.
\end{itemize}
So apply the $\boxed{20\%\text{ discount first, then the coupon}}$; this saves $\boxed{1.20\text{ dollars}}$ more, whatever the price. (For an item priced between $6$ and $7.50$ dollars, discount first brings the price down to $0$, which is still at least as good, but the gain is smaller.)
