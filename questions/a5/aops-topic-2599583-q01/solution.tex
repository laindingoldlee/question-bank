\textbf{Each game.} By symmetry, John's card and his opponent's card are a uniformly random ordered pair of different cards, and each of the $6$ ordered pairs is equally likely. Exactly half of them have John's card higher. So John wins each game with probability $\dfrac12$, independently of the other games.

\textbf{Stopping after $k$ wins.} John ends with money only if he wins all of his first $k$ games, which has probability $\left(\dfrac12\right)^k$; he then has $10000\cdot2^{k-1}$ dollars. His expected winnings are
\[\left(\dfrac12\right)^k\cdot10000\cdot2^{k-1}=\boxed{\$5000},\]
the same for every $k$. Each double-or-nothing game is a fair bet, so it never changes the expected value. Hence the expected value of the game is $\$5000$ for every strategy that stops after some fixed number of wins. (If John never stops, he loses everything with probability $1$.)
