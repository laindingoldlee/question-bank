Rearrange to $(7m-2025)(7n-2025)=2025^2=3^8\cdot5^4$. The original equation gives $7m>2025$ and $7n>2025$, so both factors are positive. Let $a=3^c5^d$ be the first factor, where $0\le c\le8$, $0\le d\le4$. We need $a\equiv-2025\equiv5\pmod7$; the second factor then also has residue $5$ because the total product has residue $4$. Since $3\equiv5^{-1}\pmod7$ and $5$ has order six, the condition is $d-c\equiv1\pmod6$. The allowed pairs are $(0,1),(1,2),(2,3),(3,4),(5,0),(6,1),(7,2),(8,3)$, eight in all. Each determines exactly one ordered pair $(m,n)$, so the answer is $\boxed8$.
