Work backwards. If $R_3$ pages were left before the third day, then $\dfrac23R_3-18=62$, so $R_3=120$. Before the second day: $\dfrac34R_2-15=120$, so $R_2=180$. Before the first day: $\dfrac45N-12=180$, so $N=240$. The book has $\boxed{\textbf{(C) }240}$ pages.
