A trial version of a game offers four different minigames. Each time the game is installed it chooses one of the four minigames at random (each with probability $\dfrac{1}{4}$, independently of earlier installs), and only that minigame can be played. A player keeps uninstalling and reinstalling the game until every minigame has been offered at least once.
\begin{enumerate}
\item[(a)] What is the expected number of installs, counting the first one?
\item[(b)] Find a formula for the expected number of installs if there are $n$ minigames.
\end{enumerate}
