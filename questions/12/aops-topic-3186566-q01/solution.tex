Pair corresponding terms: $1+99=100$, $2+98=100$, through $50+50=100$. There are $50$ pairs, so the result is $\boxed{5000}$. The ordinary sum through $100$ is $5050$. The first expression contains every integer $1$ through $99$ once and an extra $50$, so it replaces the $100$ by $50$, explaining the difference $50$. Rearranging uses commutativity, and regrouping uses associativity.
