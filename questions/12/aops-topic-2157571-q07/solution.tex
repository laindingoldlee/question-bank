A path one way consists of $7$ horizontal and $5$ vertical steps, so there are $\dbinom{12}{5}=792$ paths to the far corner. The return trips are the same $792$ routes traversed backwards, and exactly one of them is the route already used. So the number of round trips is
\[792\cdot791=\boxed{626472}.\]
