In a $5\times7$ grid of unit squares, a path from the bottom-left corner to the top-right corner moves along the grid lines using only steps up and to the right. Someone travels from the bottom-left corner to the top-right corner along such a path, and then returns to the bottom-left corner along a path using only steps down and to the left, but not along exactly the same route as the way there. How many such round trips are there? (You may leave the answer as a product.)
