\textbf{(a)} In base ten, $A4FB_{16}=10\cdot16^3+4\cdot16^2+15\cdot16+11=40960+1024+240+11=42235$.

\emph{Base $2$.} Each hexadecimal digit is four binary digits: $A=1010$, $4=0100$, $F=1111$, $B=1011$. So
\[A4FB_{16}=1010\,0100\,1111\,1011_2=1010010011111011_2.\]
\emph{Base $3$.} Divide $42235$ by $3$ repeatedly and record the remainders:
\[42235=3\cdot14078+1,\ 14078=3\cdot4692+2,\ 4692=3\cdot1564+0,\ 1564=3\cdot521+1,\ 521=3\cdot173+2,\]
\[173=3\cdot57+2,\ 57=3\cdot19+0,\ 19=3\cdot6+1,\ 6=3\cdot2+0,\ 2=3\cdot0+2.\]
Reading the remainders from the last to the first, $A4FB_{16}=2010221021_3$.
