Write the expression as
\[ab+ac+ad+bc=a(b+c+d)+bc=a(4-a)+bc.\]
By AM-GM, $bc\le\left(\dfrac{b+c}2\right)^2\le\left(\dfrac{4-a}2\right)^2$, since $b+c\le4-a$. Put $t=4-a$, so $0\le t\le4$. Then
\[ab+ac+ad+bc\le(4-t)t+\dfrac{t^2}4=4t-\dfrac{3t^2}4=\dfrac{16}3-\dfrac34\left(t-\dfrac83\right)^2\le\dfrac{16}3.\]
Equality holds for $t=\dfrac83$, $b=c$ and $d=0$, that is $a=b=c=\dfrac43$, $d=0$. Then $ab+ac+bc=3\cdot\dfrac{16}9=\dfrac{16}3$.

The largest value is $\boxed{\dfrac{16}{3}}$.
