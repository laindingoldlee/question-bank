Count pairs $(j,k)$ with $j^2\mid k$ and $1\le k\le10000$. For each $1\le j\le100$, there are $\lfloor\dfrac{10000}{j^2}\rfloor$ possible multiples. Hence the sum is
\[\sum_{j=1}^{100}\left\lfloor\dfrac{10000}{j^2}\right\rfloor=\boxed{16307}.\]
The finite arithmetic is reproduced by:
\begin{verbatim}
print(sum(10000//(j*j) for j in range(1,101)))
# 16307
\end{verbatim}
