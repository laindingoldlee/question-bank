The remainder on division by $7$ is always in $\{0,1,\dots,6\}$, so ``remainder $4$'' means $n=7k+4$ for an integer $k$. A negative number like $-4=7(-1)+3$ has remainder $3$, not $4$, so the student's negative values are wrong.

We need $-46<7k+4<46$, i.e. $-50<7k<42$, so $-7\le k\le5$. These $13$ values give $n=-45,-38,\dots,32,39$. The answer is $\boxed{13}$.
