Let $ABC$ be right-angled at $B$, with $AB=1$ and $C$ above $AB$. Point $D$ is below line $AB$, its perpendicular projection $H$ is strictly between $A$ and $B$, $\angle CDA=90^\circ$, and $BC=4DH$. Write $\phi=\angle ABD$.
\begin{enumerate}
\item If $\angle BAC=3\phi$, find $\tan^2\phi$.
\item In a separate configuration with the same basic conditions, if $\angle BCA=3\phi$, find $\tan^2\phi$.
\end{enumerate}
