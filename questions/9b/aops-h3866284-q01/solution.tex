The rays $BD$ and $BC$ point in the same direction, so $\angle DBC=0^\circ$. Likewise $DB$ and $DC$ point in the same direction, so $\angle BDC=0^\circ$. At $C$, the rays $CB$ and $CD$ point in opposite directions, so $\angle BCD=180^\circ$. Consequently the proposed $15^\circ$ and $30^\circ$ conditions cannot hold.
