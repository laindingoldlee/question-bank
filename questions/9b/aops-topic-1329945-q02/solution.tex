Since $n^2+4=(n+3)(n-3)+13$, we have $\gcd(n^2+4,\,n+3)=\gcd(13,\,n+3)$, which exceeds $1$ exactly when $13\mid n+3$, i.e. $n\equiv10\pmod{13}$. The values are $10,23,\dots,2010$, which is
\[
\dfrac{2010-10}{13}+1=\boxed{155}
\]
integers.
