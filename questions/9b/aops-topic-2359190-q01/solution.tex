Group the terms in blocks between consecutive powers of $2$: the block $\dfrac1{2^j}+\dfrac1{2^j+1}+\cdots+\dfrac1{2^{j+1}-1}$ has $2^j$ terms.
\begin{itemize}
\item Each term of the block is at most $\dfrac1{2^j}$, so the block is at most $1$.
\item Each term of the block is more than $\dfrac1{2^{j+1}}$, so the block is more than $\dfrac12$.
\end{itemize}
Since $2^{29}=536870912<10^9<2^{30}=1073741824$, the sum $H$ contains the complete blocks $j=0,1,\dots,28$ and is contained in the blocks $j=0,1,\dots,29$. Hence
\[29\cdot\dfrac12<H<30.\]
Every number between $14.5$ and $30$ is closer to $20$ than to $100$ (or any other choice). So the answer is $\boxed{\textbf{(A) }20}$. (In fact $H\approx\ln10^9+0.5772\approx21.3$.)
