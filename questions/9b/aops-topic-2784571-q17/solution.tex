Compute the sequence modulo $360$:
\[a_0,a_1,\dots,a_{14}\equiv0,1,3,14,57,241,288,269,87,166,213,29,72,1,3.\]
Since $a_{13}\equiv a_1$ and $a_{14}\equiv a_2$, and each term depends only on the previous two, $a_{n+12}\equiv a_n\pmod{360}$ for all $n\ge1$. As $2020=4+12\cdot168$, $a_{2020}\equiv a_4=\boxed{57}$.

(Check modulo $5$: $a_n\equiv3a_{n-1}$, so $a_{2020}\equiv3^{2019}\equiv3^3\equiv2$, and $57\equiv2\pmod5$.)
