Henri starts in column $1$, row $1$. He reaches a star as soon as he reaches row $3$ (after $2$ heads) or column $4$ (after $3$ tails), whichever happens first. Teresa wins exactly when the game ends in the shaded rightmost column, i.e.\ when $3$ tails occur before $2$ heads. (The shaded top-right corner can only be entered from a square that already has a star, so the game never reaches it.)

The game is decided within $4$ flips: imagine flipping exactly $4$ coins. Three tails come before two heads exactly when at most one of the first $4$ flips is a head, i.e.\ when there are at least $3$ tails among the $4$ flips. So
\[
P(\text{Teresa wins})=\dfrac{\binom43+\binom44}{2^4}=\dfrac{4+1}{16}=\boxed{\dfrac{5}{16}}.
\]
