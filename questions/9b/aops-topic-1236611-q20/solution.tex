Let $w_n$ be the number of ways for $n$. The last summand is $1$ or $2$, so $w_n=w_{n-1}+w_{n-2}$, with $w_1=1$, $w_2=2$. Then $w_3,\dots,w_8=3,5,8,13,21,34$. The answer is $\boxed{34}$.
