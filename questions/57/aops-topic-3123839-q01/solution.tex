An exact finite enumeration is valid because the range has only $2023$ integers. For each $n$, compute $u=\lfloor\sqrt{2n^2+3n}\rfloor$ using integer square root and test $u^2=2n^2+3n$. This gives $n=0,12,432$, with corresponding squares $0,324,374544=612^2$. Their sum is $\boxed{444}$. The following certificate checks every permitted integer without floating-point rounding.
\begin{verbatim}
from math import isqrt
v=[n for n in range(2023) if isqrt(2*n*n+3*n)**2==2*n*n+3*n]
assert v==[0,12,432]
assert sum(v)==444
\end{verbatim}
