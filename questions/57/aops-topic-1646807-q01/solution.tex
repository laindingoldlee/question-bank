Each mile is $1.609344$ km, so the number of miles is
\[
\dfrac{12}{1.609344}\approx\boxed{7.46}\ \text{miles}.
\]
(The rough rule ``$5$ miles $\approx8$ km'' gives $12\cdot\dfrac{5}{8}=7.5$.)
