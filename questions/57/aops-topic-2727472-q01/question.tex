For $0<x<3$ let
\[k=\dfrac{x+6}{\sqrt{\left(\dfrac{(x+6)^2+9x^2}{9}\right)\left(\dfrac{(x+6)^2+9(3-x)^2}{9}\right)}}.\]
Find the maximum possible value of $k$ and the $x$ at which it occurs.
