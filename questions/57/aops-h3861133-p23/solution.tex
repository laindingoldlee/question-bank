Assume $a\le b$. If $a=b$, then $c^2=2^{a+1}$, so $a$ is odd and $c=2^k$ with $k\ge1$. There are ten such values below $2025$. If $a<b$, then $c^2=2^a(1+2^{b-a})$, so $a$ is even and the odd factor is a square $u^2$. The factors $(u-1)(u+1)=2^{b-a}$ differ by two, forcing them to be $2,4$. Thus $u=3$, $b-a=3$, and $c=3\cdot2^k$ with $k\ge1$. There are nine such values below $2025$. The families are disjoint, giving $\boxed{19}$.
