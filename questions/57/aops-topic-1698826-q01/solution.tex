$6\times\dfrac{2}{7}=\dfrac{6\cdot2}{7}=\boxed{\dfrac{12}{7}}$. This equals the mixed number $1\dfrac{5}{7}$, which is the same number; an answer checker that asks for ``a fraction'' expects the improper fraction $\dfrac{12}{7}$.
