$p-q>0$ is prime, so $p>q$. If both were odd, $p+q$ would be an even number greater than $2$. So $q=2$, and $p-2$, $p$, $p+2$ are all prime. One of three numbers spaced by $2$ is divisible by $3$, so it equals $3$; this forces $p-2=3$. The only pair is $\boxed{(5,2)}$ ($3$ and $7$ are prime).
