For $x\ne0$,
\[\dfrac{12x+24}{x}=12+\dfrac{24}{x}.\]
This is an integer exactly when $x$ divides $24$, i.e. $x\in\{\pm1,\pm2,\pm3,\pm4,\pm6,\pm8,\pm12,\pm24\}$.
\begin{itemize}
\item All $8$ positive divisors work, giving $36,24,20,18,16,15,14,13$.
\item For $x=-d$ with $d>0$ we need $12-\dfrac{24}{d}\ge1$, i.e. $d\ge\dfrac{24}{11}$, so $d\ge3$: $x=-3,-4,-6,-8,-12,-24$ work (values $4,6,8,9,10,11$), while $x=-1$ and $x=-2$ give $-12$ and $0$.
\end{itemize}
So there are $8+6=\boxed{14}$ such integers.
