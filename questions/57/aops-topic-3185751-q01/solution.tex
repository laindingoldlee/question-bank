Multiplication is performed before addition unless parentheses specify otherwise: $3+4\cdot5=3+20=\boxed{23}$, whereas $(3+4)\cdot5=7\cdot5=\boxed{35}$. Operator precedence is a convention that makes expressions unambiguous; the parentheses explicitly change the grouping. It is not a theorem that one convention is intrinsically correct.
