There are $12$ people. If everyone shook hands with everyone else, there would be $\dbinom{12}{2}=66$ handshakes, one for each pair of people. Exactly $6$ of these pairs are married couples, who do not shake hands. So there are
\[66-6=\boxed{60}\]
handshakes. (Equivalently, each person shakes $10$ hands, and each handshake involves $2$ people: $\dfrac{12\cdot10}{2}=60$.)
