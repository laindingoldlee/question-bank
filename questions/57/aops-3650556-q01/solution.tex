Write the digits as $a,b,c,d$ with $1\le a\le9$, $0\le b,c,d\le9$. Enumerate $a,b,c$ and set $d=18-a-b-c$, retaining it only if it is a digit. Require both specified digits to occur. The digit sum already ensures divisibility by nine, so divisibility by 18 requires even $d$. These tests produce $\boxed{49}$ integers. For a reproducible check, their leading-digit counts for $a=1,\ldots,9$ are $(18,2,4,2,4,2,4,9,4)$.
