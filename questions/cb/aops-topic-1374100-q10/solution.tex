If everyone shook hands with everyone, there would be $\binom{20}{2}=190$ handshakes. The missing $190-182=8$ handshakes are exactly the sibling pairs, one for each two-child family. So there are $8$ two-child families with $16$ children, and the number of only children is
\[
20-16=\boxed{4}.
\]
