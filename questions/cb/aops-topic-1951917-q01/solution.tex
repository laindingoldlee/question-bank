Every integer is divisible by $1$, so any two integers are congruent modulo $1$; in particular $ab\equiv1\pmod1$ holds for all integers $a,b$, because $1\mid ab-1$. Hence $\boxed{\text{every integer has an inverse modulo }1}$, and every integer is an inverse of it. For example, $5\cdot7=35\equiv1\pmod1$ since $35-1=34$ is a multiple of $1$. (This is consistent with the rule that $a$ is invertible modulo $m$ exactly when $\gcd(a,m)=1$, since $\gcd(a,1)=1$ for every $a$.)
