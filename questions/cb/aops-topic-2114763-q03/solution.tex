The function $t+\dfrac{2}{t}$ is continuous wherever $t\ne0$, in particular at $t=5$, so the limit is its value there:
\[\lim_{t\to5}\left(t+\dfrac{2}{t}\right)=5+\dfrac{2}{5}=\dfrac{27}{5}.\]
Hence $\dfrac {x}{2}=\dfrac{27}{5}$ and $x=\boxed{\dfrac{54}{5}}$.
