A subset of $A$ is formed by deciding, for each of the $10$ elements, whether it is in the subset or not: $2$ choices for each element, so $2^{10}=1024$ subsets in all. One of them is the empty set (every element left out). The number of non-empty subsets is $1024-1=\boxed{1023}$.
