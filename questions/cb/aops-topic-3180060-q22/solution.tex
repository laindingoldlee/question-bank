Only the balls initially one, two, or three positions before an urn can enter it. Each independently misses with probability $\dfrac{2}{3}$, so the urn is empty with probability $\dfrac{8}{27}$. Linearity gives expected empty count $20\cdot\dfrac{8}{27}=\dfrac{160}{27}$. Hence $\boxed{160027}$.
