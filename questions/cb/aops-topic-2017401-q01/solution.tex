We use the factorisation
\[
a^n-1=(a-1)\left(a^{n-1}+a^{n-2}+\cdots+a+1\right),
\]
which holds for every positive integer $n$ (expand the right-hand side: the sum telescopes to $a^n-1$). The second factor is an integer. Since $a\equiv1\pmod3$, $3$ divides $a-1$, so $3$ divides $a^n-1$. That is, $a^n\equiv1\pmod3$.

(Equivalently: congruences may be multiplied, so $a\equiv1$ gives $a^n\equiv1^n=1\pmod3$.)
