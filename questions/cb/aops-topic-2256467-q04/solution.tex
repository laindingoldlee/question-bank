The logarithm is defined only for $3x-5>0$. Since the base $8$ is greater than $1$, $\log_8$ is increasing, so $\log_8(3x-5)<2=\log_8 64$ means $3x-5<64$. Hence
\[0<3x-5<64\iff \boxed{\dfrac{5}{3}<x<23}.\]
