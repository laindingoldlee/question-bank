There are $\dbinom{52}{3}=22100$ equally likely sets of three cards, and each value occurs on $4$ cards.

List the value patterns $a\le b\le c$ with $a+b+c=16$ and $c\le13$ (three equal values are impossible since $3\nmid16$):
\begin{itemize}
\item $a=1$: $(1,2,13),(1,3,12),(1,4,11),(1,5,10),(1,6,9),(1,7,8)$;
\item $a=2$: $(2,3,11),(2,4,10),(2,5,9),(2,6,8)$ and the patterns with a repeated value $(2,2,12),(2,7,7)$;
\item $a=3$: $(3,4,9),(3,5,8),(3,6,7)$ and $(3,3,10)$;
\item $a=4$: $(4,5,7)$ and $(4,4,8),(4,6,6)$;
\item $a=5$: $(5,5,6)$.
\end{itemize}
That is $14$ patterns with three different values and $6$ with a repeated value. A pattern of three different values can be realised by $4^3=64$ sets of cards, and a pattern $(p,p,q)$ by $\dbinom42\cdot4=24$ sets. So the number of favourable sets is
\[14\cdot64+6\cdot24=896+144=1040,\]
and the probability is
\[\dfrac{1040}{22100}=\boxed{\dfrac{4}{85}}\approx0.047 .\]
