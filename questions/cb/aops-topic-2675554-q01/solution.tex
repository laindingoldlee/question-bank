$|n+100|\le25$ means $-125\le n\le-75$. With $n=7k+4$ (remainders are taken in $\{0,\dots,6\}$): $-129\le7k\le-79$, so $-18\le k\le-12$. These $7$ values give $n=-122,-115,-108,-101,-94,-87,-80$. The answer is $\boxed{7}$.
