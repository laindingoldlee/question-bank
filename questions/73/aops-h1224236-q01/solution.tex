Put $\alpha=13+2\sqrt{42}$ and $\beta=13-2\sqrt{42}$, so $\alpha\beta=1$ and $0<\beta<1$. The given number is $\alpha^{500}$. The integers $S_n=\alpha^n+\beta^n$ satisfy $S_0=2,S_1=26,S_n=26S_{n-1}-S_{n-2}$. Modulo $100$ the sequence starts $2,26,74,98,74,26,2,26$; the pair repeats, establishing period six. Since $500\equiv2\pmod6$, $S_{500}\equiv74\pmod{100}$. Finally $0<\beta^{500}<1$, so $\lfloor\alpha^{500}\rfloor=S_{500}-1$. The last two digits are $\boxed{73}$.
