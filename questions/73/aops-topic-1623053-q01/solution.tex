For $n\ge7$, $n!$ contains the factor $7$, so it is divisible by $7$. Only the first six terms matter:
\[
1!+2!+3!+4!+5!+6!=1+2+6+24+120+720=873 .
\]
Since $873=7\cdot124+5$, the remainder is $\boxed{5}$.
