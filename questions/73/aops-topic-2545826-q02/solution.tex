Let the numbers be $a\le b\le c$ with $abc=a+b+c$. Then $abc\le3c$, so $ab\le3$, leaving $(a,b)=(1,1),(1,2),(1,3)$.
\begin{itemize}
\item $(1,1)$: $c=2+c$, impossible.
\item $(1,2)$: $2c=3+c$, so $c=3$.
\item $(1,3)$: $3c=4+c$, so $c=2<b$, contradicting $b\le c$.
\end{itemize}
So the only triple is $\boxed{\{1,2,3\}}$ (in any order): $1+2+3=6=1\cdot2\cdot3$.
