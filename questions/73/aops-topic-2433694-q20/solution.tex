Each number has the form $\dfrac{n}{n+14}=1-\dfrac{14}{n+14}$, which increases as $n$ increases (the subtracted fraction gets smaller). So
\[\dfrac{5}{19}<\dfrac{7}{21}<\dfrac{9}{23}\]
(check: $5\cdot21=105<133=7\cdot19$ and $7\cdot23=161<189=9\cdot21$). The answer is $\boxed{\textbf{(B)}}$.
