Let $S$ be the total number of ones. Enumerate every rectangle with row endpoints $r_1\le r_2$ and column endpoints $c_1\le c_2$. If its area is $A$ and it contains $K$ ones, the error is $(A-K)+(S-K)=A+S-2K$: zeros inside plus ones outside. Return yes if any rectangle has error at most four, and no otherwise. Prefix sums evaluate $K$ from four table entries, giving $O(m^2n^2)$ rectangle tests after $O(mn)$ preparation. This is exhaustive because every allowable rectangle appears once.
