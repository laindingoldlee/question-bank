Parity forces $p=2$, hence $3q+r=29$. Since $r\ge2$, $q\le9$, so $q\in\{2,3,5,7\}$. These give $r=23,20,14,8$, respectively. Only 23 is prime, so $(p,q,r)=(2,2,23)$ and the requested sum is $\boxed{27}$.
