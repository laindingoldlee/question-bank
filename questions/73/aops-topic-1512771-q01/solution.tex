A positive integer $N$ has $k$ digits in base $5$ exactly when $5^{k-1}\le N<5^k$. So we need the integer $k$ with $5^{k-1}\le10^{100}<5^k$, i.e.\ $k-1\le100\log_5 10<k$.

Now $\log_5 10=\dfrac{1}{\log_{10}5}$ and $\log_{10}5=0.69897\ldots$, so
\[
100\log_5 10=\dfrac{100}{0.69897\ldots}=143.07\ldots .
\]
(Check: $143\log_{10}5=99.95\ldots<100<100.65\ldots=144\log_{10}5$, so $5^{143}<10^{100}<5^{144}$.) Hence $k-1=143$ and a googol has $\boxed{144}$ digits in base $5$.
