If $n$ leaves remainder $r$, then $n^2$ leaves the same remainder as $r^2$. Checking $r=0,1,2,3,4$:
\[0^2=0,\quad1^2=1,\quad2^2=4,\quad3^2=9\equiv4,\quad4^2=16\equiv1\pmod5 .\]
So $n^2\equiv1\pmod5$ exactly when $n$ leaves remainder $\boxed{1\text{ or }4}$. (Listing all five residues is wrong: for example $n=2$ has $n^2=4$, which leaves remainder $4$, not $1$.)
