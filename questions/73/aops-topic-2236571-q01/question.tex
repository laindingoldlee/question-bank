There is exactly one triple $(x,y,z)$ of real numbers that satisfies
\[x<y<z,\qquad x+y+z=3,\qquad xy+yz+zx=-12,\qquad xyz=4 .\]
Given that $z$ can be written as $\dfrac{a+\sqrt b}{c}$ in simplest form with $c$ positive, find $a+b+c$.

$\textbf{(A) } 36 \qquad \textbf{(B) } 37 \qquad \textbf{(C) } 38 \qquad \textbf{(D) } 39 \qquad \textbf{(E) } 40$
