If an odd prime $p$ divides the number, then $2025^8\equiv-1\pmod p$, so $2025$ has multiplicative order exactly $16$: its order divides $16$ but does not divide $8$. Thus $16\mid p-1$.

The only prime of the form $16k+1$ below $97$ is $17$ (the intermediate values $33,49,65,81$ are composite). Modulo $17$, $2025\equiv2$ and $2^8\equiv1$, so $17$ fails. Modulo $97$,
\[
2025\equiv-12,\quad (-12)^2\equiv47,\quad (-12)^4\equiv75,\quad (-12)^8\equiv-1.
\]
Since $97$ is prime, the answer is $\boxed{97}$.
