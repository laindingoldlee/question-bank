We need $5\mid6-4x$, i.e. $4x\equiv6\equiv1\pmod5$, i.e. $x\equiv4\pmod5$ (as $4\cdot4=16\equiv1$). Then $y=\dfrac{6-4x}{5}$ is an integer. The values $x=4,9,\dots,2014$ number $\dfrac{2014-4}{5}+1=\boxed{403}$.
