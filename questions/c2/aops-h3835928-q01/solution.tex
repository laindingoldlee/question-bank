Write the entries as $\binom Nk,\binom N{k+1},\binom N{k+2}$, so their row number is $N+1$. The ratios give
\[
\dfrac{N-k}{k+1}=\dfrac{4}{3},\qquad
\dfrac{N-k-1}{k+2}=\dfrac{5}{4}.
\]
Equivalently $3N-7k=4$ and $4N-9k=14$. Solving yields $k=26,N=62$. These indices are valid, and the equations show there is no other possible row. Thus the answer is $\boxed{63}$.
