With $5$ turns, the path consists of $6$ runs alternating in direction, so it has $3$ runs of rights and $3$ runs of ups (whichever direction it starts with). Splitting the $9$ rights into $3$ nonempty runs can be done in $\dbinom82=28$ ways, and the $5$ ups into $3$ nonempty runs in $\dbinom42=6$ ways. The path may start with either direction, so the total is $2\cdot28\cdot6=\boxed{336}$.
