The numbers $1$--$9$ use $9$ digits and $10$--$99$ use $90\cdot2=180$ digits, $189$ in all. That leaves $2016-189=1827=3\cdot609$ digits, which are exactly the digits of the first $609$ three-digit numbers, $100,101,\dots,708$. So the $2016$th digit is the last digit of $708$, namely $\boxed{8}$.

(Only the first $2016$ digits are needed; the string contains many more digits.)
