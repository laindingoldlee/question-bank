$\dfrac{a+b}{c}=\dfrac{20-c}{c}=\dfrac{20}{c}-1$, an integer exactly when $c\mid20$. Also $c\le18$, since $a+b\ge2$. So $c\in\{1,2,4,5,10\}$, giving the values $19,9,4,3,1$: $\boxed{5}$ values.
