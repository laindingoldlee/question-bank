\textbf{Free part.} Colour the $4\times5$ block in the first $4$ rows and first $5$ columns arbitrarily: $2^{20}$ ways.

\textbf{The rest is forced.} In each of rows $1$ to $4$, the square in column $6$ is forced (blue exactly when the first five squares of that row contain an odd number of blue squares). Likewise, in each of columns $1$ to $5$, the square in row $5$ is forced. Finally the corner square (row $5$, column $6$) must make row $5$ even, and also column $6$ even. These two requirements agree: both say the corner is blue exactly when the total number of blue squares outside row $5$ and column $6$, that is in the $4\times5$ block, is odd. (Row $5$ outside the corner has as many blue squares, mod $2$, as the block, column by column; and column $6$ outside the corner likewise, row by row.)

So every colouring of the block extends in exactly one way, and every valid colouring arises this way. The number of colourings is
\[
2^{(5-1)(6-1)}=2^{20}=\boxed{1048576}.
\]
