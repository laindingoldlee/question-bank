Let $E_i$ mean the $i$th pair sits opposite. For a fixed pair this has probability $\dfrac{1}{5}$. Given one opposite pair, the next pair is opposite with probability $\dfrac{1}{3}$, so $P(E_iE_j)=\dfrac{1}{15}$. If two pairs are opposite, the third pair is forced opposite, so $P(E_1E_2E_3)=\dfrac{1}{15}$. Inclusion--exclusion gives
\[P(\text{none})=1-\left(\dfrac{3}{5}-\dfrac{3}{15}+\dfrac{1}{15}\right)=\boxed{\dfrac{8}{15}}.\]
