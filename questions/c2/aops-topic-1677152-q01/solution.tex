The statement $(-1)^2=1^2$ is true (both sides are $1$). The error is the step ``take the square root of both sides''. The function $t\mapsto\sqrt{t^{2}}$ gives $|t|$, not $t$: from $u^2=v^2$ one can only conclude
\[
\sqrt{u^2}=\sqrt{v^2},\quad\text{i.e.}\quad |u|=|v|,\quad\text{i.e.}\quad u=v\ \text{or}\ u=-v .
\]
Here $|-1|=|1|=1$, which is true, and the case $u=-v$ is the one that occurs. The ``rule'' that we may apply any operation to both sides only preserves equality; squaring is not one-to-one, so ``undoing'' it with a square root does not give back the original numbers. So $\boxed{\text{the step }\sqrt{u^2}=u\text{ is invalid for }u<0}$.

(The same mistake appears in the post's warm-up example: from $4x^2=9y^8$ one gets $|2x|=3y^4$, i.e.\ $2x=\pm3y^4$, not just $2x=3y^4$.)
