Since $n\equiv S(n)\equiv S(S(n))\pmod9$, we need $3n\equiv2007\equiv0\pmod 9$, so $n\equiv0\pmod3$. Also $n<2007$, so $S(n)\le28$ and $S(S(n))\le10$, giving $n\ge2007-38=1969$.

Check the multiples of $3$ from $1971$ to $2004$: $n+S(n)+S(S(n))$ equals $2007$ exactly for $n=1977$ ($1977+24+6$), $1980$ ($1980+18+9$), $1983$ ($1983+21+3$) and $2001$ ($2001+3+3$). The others fail (e.g. $1974+21+3=1998$, $2004+6+6=2016$). So there are $\boxed{4}$ values.
