A positive integer $N$ has exactly $n$ digits when $10^{n-1}\le N<10^n$.

\textbf{$n=24$ works.} $24!=620448401733239439360000\approx6.2\cdot10^{23}$, which has $24$ digits.

\textbf{No $n\ge25$ works.} We have $25!=25\cdot24!\approx1.55\cdot10^{25}\ge10^{25}$. If $n!\ge10^n$ for some $n\ge25$, then
\[
(n+1)!=(n+1)\cdot n!\ge10\cdot10^n=10^{n+1},
\]
so by induction $n!\ge10^n$ for every $n\ge25$, and then $n!$ has at least $n+1$ digits.

So the greatest such $n$ is $\boxed{24}$. (The values of $n$ for which $n!$ has $n$ digits are $1$, $22$, $23$ and $24$.)
