For safe strings, keep counts $v_t(0),\ldots,v_t(3)$ according to the number of trailing heads. Initially $v_0=(1,0,0,0)$. Appending a tail gives new state zero from every old state; appending a head changes $0,1,2$ into $1,2,3$. Thus $v_{t+1}=(\sum v_t,v_t(0),v_t(1),v_t(2))$. At twelve tosses the safe total is $2872$, so the desired probability is $1-\dfrac{2872}{4096}=\dfrac{153}{512}\approx\boxed{0.299}$.
