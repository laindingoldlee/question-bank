The vertices lie on a circle, and $CF$ joins opposite vertices, so it is a diameter. Hence $\angle CAF=90^\circ$ (Thales). In triangle $ACF$, $\angle AFC$ is an inscribed angle on arc $AC$, which is $120^\circ$ (two sides of the hexagon), so $\angle AFC=60^\circ$. Therefore
\[
\angle ACF=180^\circ-90^\circ-60^\circ=\boxed{30^\circ}.
\]

\begin{asy}
usepackage("amsmath");
size(4.5cm);
defaultpen(fontsize(10pt));
path ra(pair P,pair u,pair v,real s=0.2){return P+s*unit(u)--P+s*unit(u)+s*unit(v)--P+s*unit(v);}
pair[] V; string[] L={"$A$","$B$","$C$","$D$","$E$","$F$"};
for(int k=0;k<6;++k) V[k]=dir(180-60*k);
draw(V[0]--V[1]--V[2]--V[3]--V[4]--V[5]--cycle,linewidth(0.9));
for(int k=0;k<6;++k) label(L[k],V[k],dir(180-60*k));
draw(V[0]--V[2],blue); draw(V[2]--V[5],blue); draw(ra(V[0],V[5]-V[0],V[2]-V[0],0.12));
draw(arc(V[2],0.3,degrees(V[5]-V[2]),degrees(V[0]-V[2])),red); label("$30^\circ$",V[2]+0.42*dir(225),red+fontsize(8pt));
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}
