Let the digits be $h,t,u$ with $h\ge1$ and $u=h+t$. The number is even, so $u\in\{0,2,4,6,8\}$; $u=0$ is impossible because $h\ge1$. For a given $u$, the hundreds digit can be $h=1,2,\dots,u$, and then $t=u-h$ is a digit: $u$ choices. The total is
\[2+4+6+8=\boxed{20}.\]
