A standard Catan board is made of $19$ regular hexagonal tiles arranged in the shape of a large hexagon with $3$ tiles along each edge (rows of $3,4,5,4,3$ tiles), as shown. How many tiles does such a hexagonal board with $N$ tiles along each edge have?

\begin{asy}
usepackage("amsmath");
size(4cm);
defaultpen(fontsize(10pt));
real s=1;
pair hc(int q,int r){return (sqrt(3)*(q+r/2),1.5*r)*s;}
path hx(pair c){ path p; for(int k=0;k<6;++k) p=p--(c+s*dir(30+60k)); return p--cycle; }
for(int q=-2;q<=2;++q) for(int r=-2;r<=2;++r){ if(abs(q+r)<=2){ filldraw(shift(hc(q,r))*(dir(30)--dir(90)--dir(150)--dir(210)--dir(270)--dir(330)--cycle),rgb(0.95,0.9,0.75),linewidth(0.8)); } }
\end{asy}
