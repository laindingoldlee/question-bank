\textbf{Directly in base 11.} Multiply $192_{11}$ by each digit of $3AA_{11}$:
\[192_{11}\cdot A=1739_{11}\qquad(\text{since }222\cdot10=2220=1\cdot1331+7\cdot121+3\cdot11+9),\]
\[192_{11}\cdot3=556_{11}\qquad(\text{since }222\cdot3=666=5\cdot121+5\cdot11+6).\]
Add the shifted partial products in base $11$:
\[\begin{array}{r}1739\\17390\\+\ 55600\\\hline73619\end{array}\]
Column by column from the right: $9$; $3+9=12=11+1$, write $1$ carry $1$; $7+3+6+1=17=11+6$, write $6$ carry $1$; $1+7+5+1=14=11+3$, write $3$ carry $1$; $1+5+1=7$.

\textbf{Check in base 10.} $192_{11}=121+99+2=222$ and $3AA_{11}=363+110+10=483$, so the product is $222\cdot483=107226$, and
\[73619_{11}=7\cdot14641+3\cdot1331+6\cdot121+1\cdot11+9=107226 .\]
So the product is $\boxed{73619_{11}}$.
