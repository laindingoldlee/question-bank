Every end run of one colour must have length one, since an end book in a longer run has no opposite-colour neighbour. Every internal run has length at most two. If the end colours differ, the only valid arrangements are $\mathrm{BPBBP}$ and $\mathrm{PBBPB}$. If both ends are blue, the sole possibility is $\mathrm{BPBPB}$. Both ends pink would force all three blue books into a single internal run, which fails. Thus there are $\boxed3$ arrangements.
