Let $d=\gcd(m,n)$ and write $m=da$, $n=db$ with $\gcd(a,b)=1$. The condition $d^2ab\mid d^2(a^2+b^2)$ becomes $ab\mid a^2+b^2$.

Then $a\mid a^2+b^2$, so $a\mid b^2$. As $\gcd(a,b)=1$, this forces $a=1$. In the same way $b\mid a^2$ forces $b=1$. Hence $m=n=d$. $\blacksquare$
