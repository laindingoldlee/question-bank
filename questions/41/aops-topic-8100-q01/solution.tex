First, $\dfrac{16!}{125}$ is an integer, since $16!$ contains the factors $5$, $10$, $15$, each with one $5$. Dividing by $125=5^3$ does not change the power of $2$. The exponent of $2$ in $16!$ is
\[\left\lfloor\dfrac{16}{2}\right\rfloor+\left\lfloor\dfrac{16}{4}\right\rfloor+\left\lfloor\dfrac{16}{8}\right\rfloor+\left\lfloor\dfrac{16}{16}\right\rfloor=8+4+2+1=15,\]
so $n=\boxed{15}$.
