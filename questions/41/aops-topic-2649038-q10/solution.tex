If Bill were honest, Daniel's statement would be true, so exactly one student would be honest, but Bill and Daniel would both be honest. So Bill lies, and Carl, who says so, is honest. Bill's second statement is false, so Daniel lies; hence the number of honest students is not $1$. Carl is honest, so someone else is: it must be Adria (Bill and Daniel lie). This is consistent: Adria got $75\%$ and Bill's claim that she got $90\%$ is false. So $\boxed{2}$ students are honest (Adria and Carl).
