Let $A_i$ be the set of permutations in which $i$ is immediately followed by $i+1$ ($1\le i\le7$). Any $k$ of these conditions glue the numbers into $8-k$ blocks, which can be arranged in $(8-k)!$ ways. By inclusion-exclusion,
\[\sum_{k=0}^7(-1)^k\binom7k(8-k)!=40320-35280+15120-4200+840-126+14-1=\boxed{16687}.\]
