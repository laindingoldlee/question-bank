Dividing by $2016$, $f(x)=2016\left(x^3-2x^2+3x-\dfrac{8}{3}\right)$, so by Vieta $a+b+c=2$, $ab+bc+ca=3$, $abc=\dfrac{8}{3}$. Since $b+c-1=1-a$ and so on, the expression is
\[\sum a^2(1-a)=\left(a^2+b^2+c^2\right)-\left(a^3+b^3+c^3\right).\]
Now $a^2+b^2+c^2=2^2-2\cdot3=-2$ and
\[a^3+b^3+c^3=(a+b+c)^3-3(a+b+c)(ab+bc+ca)+3abc=8-18+8=-2.\]
The value is $-2-(-2)=\boxed{0}$.
