For a positive integer $n$, define $f(n)=\dfrac{n}{3}$ if $3\mid n$, $f(n)=n^2+4n-5$ if $n\equiv1\pmod3$, and $f(n)=n^2+n-2$ if $n\equiv2\pmod3$. How many initial integers $2\le n\le1000$ eventually reach $1$ under iteration, stopping when $1$ is reached?
