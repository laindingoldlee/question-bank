Adding a constant to every number, or multiplying every number by a positive constant, keeps the numbers in the same order and keeps equal numbers equal (and different numbers different).
\begin{itemize}
\item The average: the sum changes from $T$ to $T+12n$ (or $2T$), so the average changes from $\dfrac{T}{n}$ to $\dfrac{T}{n}+12$ (or $2\cdot\dfrac{T}{n}$).
\item The median: the middle number (or the average of the two middle numbers) is transformed in the same way, since the order is kept.
\item The mode: each value occurs exactly as often as before, so the most frequent value is transformed in the same way.
\end{itemize}
\textbf{(a)} Average $\boxed{26}$, median $\boxed{33}$, mode $\boxed{23}$.

\textbf{(b)} Average $\boxed{28}$, median $\boxed{42}$, mode $\boxed{22}$.
