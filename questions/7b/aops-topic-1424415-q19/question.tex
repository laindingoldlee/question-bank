How many ordered pairs of sets $(A,B)$ have all of the following properties?
\begin{enumerate}
\item $A\subseteq\{1,2,3,4,5,6\}$;
\item $B\subseteq\{2,3,4,5,6,7,8\}$;
\item $A\cap B$ has exactly $3$ elements.
\end{enumerate}
