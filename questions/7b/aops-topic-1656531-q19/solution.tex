\textbf{Range of the leading coefficient.} Let $c=a^2+ab-b^2$. As a function of $b$ for fixed $a$, $c=-\left(b-\dfrac {a}{2}\right)^2+\dfrac{5}{4}a^2\le\dfrac{5}{4}a^2\le\dfrac{5}{4}$; as a function of $a$ for fixed $b$, $c=\left(a+\dfrac {b}{2}\right)^2-\dfrac{5}{4}b^2\ge-\dfrac{5}{4}$. Both bounds are attained ($a=1,b=\dfrac{1}{2}$ and $a=-\dfrac{1}{2},b=1$), and $c$ is continuous on the square, so $c$ takes exactly the values in $\left[-\dfrac{5}{4},\dfrac{5}{4}\right]$.

\textbf{Which roots occur.} A number $r\ne0$ is a root when $cr^2+3r-1=0$, i.e.\ $c=\dfrac{1-3r}{r^2}$. So $r$ can be a root exactly when $\dfrac{1-3r}{r^2}\in\left[-\dfrac{5}{4},\dfrac{5}{4}\right]$:
\begin{itemize}
\item $r=\dfrac{1}{2}$: $c=-2$, impossible.
\item $r=\dfrac{5}{3}$: $c=-\dfrac{36}{25}<-\dfrac{5}{4}$, impossible.
\item $r=\dfrac{8}{3}$: $c=-\dfrac{63}{64}$, possible.
\item $r=3$: $c=-\dfrac{8}{9}$, possible.
\item $r=-18$: $c=\dfrac{55}{324}$, possible.
\end{itemize}
The values that cannot be roots are \boxed{\textbf{(a)}\ \dfrac{1}{2}\text{ and }\textbf{(b)}\ \dfrac{5}{3}}.
