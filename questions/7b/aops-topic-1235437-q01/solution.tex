An $m\times n$ diagonal crosses $m-1$ vertical and $n-1$ horizontal interior lines, and enters a new square at each crossing, except that it passes through $\gcd(m,n)-1$ interior lattice points where it crosses two lines at once. So it meets $m+n-\gcd(m,n)$ squares.

$50\times13$: $\gcd=1$, so $50+13-1=\boxed{62}$. $50\times14$: $\gcd=2$, so $50+14-2=\boxed{62}$.
