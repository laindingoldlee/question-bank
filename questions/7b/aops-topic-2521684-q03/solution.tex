Let there be $2m$ people. Every pair of people shakes hands except the pairs who know each other, which are exactly the pairs inside the group of $m$. So the number of handshakes is
\[\dbinom{2m}{2}-\dbinom m2=m(2m-1)-\dfrac{m(m-1)}{2}=\dfrac{3m^2-m}{2}.\]
Setting this equal to $145$: $3m^2-m-290=0$, i.e. $(m-10)(3m+29)=0$, so $m=10$. There are $\boxed{20}$ people. (Check: $190-45=145$.)
