Number the sectors $0,\dots,5$ around the circle and let $T$ be the sum of the sector numbers of the fish. Each command changes one fish's number by $\pm1$ or by $\pm5$ (between sectors $5$ and $0$), an odd amount, so $T$ changes parity at every command. Initially $T=0+1+\cdots+5=15$, odd; after $30$ commands $T$ is still odd. If all fish are in sector $s$, $T=6s$ is even. So $\boxed{\text{no}}$.
