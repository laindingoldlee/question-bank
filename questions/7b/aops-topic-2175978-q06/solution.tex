Completing the squares,
\[(x-2)^2+(y+3)^2\le12+4+9=25 ,\]
so we count the lattice points in the closed disc of radius $5$ centred at $(2,-3)$. With $u=x-2$ and $v=y+3$ we count integer pairs with $u^2+v^2\le25$:
\begin{itemize}
\item $u=0$: $|v|\le5$, $11$ values;
\item $u=\pm1$, $u=\pm2$, $u=\pm3$: $v^2\le24$, $21$, $16$, so $|v|\le4$, $9$ values each, $6\cdot9=54$;
\item $u=\pm4$: $v^2\le9$, $7$ values each, $14$;
\item $u=\pm5$: $v=0$, $2$.
\end{itemize}

\begin{asy}
usepackage("amsmath");
size(5.5cm);
defaultpen(fontsize(10pt));
for(int x=-3;x<=7;++x) for(int y=-8;y<=2;++y){ if((x-2)^2+(y+3)^2<=25) dot((x,y),blue+linewidth(3.2)); else dot((x,y),gray(0.75)+linewidth(2)); }
draw(circle((2,-3),5),red+linewidth(0.9));
draw((-3.6,0)--(7.6,0),Arrow(TeXHead)); draw((0,-8.6)--(0,2.6),Arrow(TeXHead));
label("$x$",(7.6,0),E); label("$y$",(0,2.6),N);
label("$(2,-3)$",(2,-3),SE,fontsize(8pt));
draw((2,-3)--(7,-3),red+dashed); label("$5$",(2,-3)--(7,-3),N,fontsize(8pt));
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

The total is $11+54+14+2=\boxed{81}$.
