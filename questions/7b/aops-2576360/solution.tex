Take the angle bisector as the horizontal axis, with $C=(0,0)$, $B=(b\cos\theta,b\sin\theta)$ and $A=(a\cos\theta,-a\sin\theta)$. The foot is $M=(b\cos\theta,0)$. Then $[AMC] = \dfrac{a b \sin \theta \cos \theta}{2}$, while $[ABC] = \dfrac{a b \sin (2\theta)}{2} = a b \sin \theta \cos \theta$. Therefore $\boxed{[AMC] = \dfrac{[ABC]}{2}}$.

import graph;
usepackage("amsmath");
import geometry;

pair C=(0,0),B=(3,2),A=(4.5,-3),M=(3,0);draw(C--B--A--cycle);draw(C--M--B,dashed);draw(A--M);label("$A$",A,(1,-1));label("$B$",B,(0,1));label("$C$",C,(-1,0));label("$M$",M,(1,0));
\end{asy}
