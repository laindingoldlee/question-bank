My three-digit code is $023$. Reckha can't choose a code that is the same as mine in two or more of the three digit-positions, nor one that is the same as mine except for switching the positions of two digits (so $320$ and $203$, for example, are forbidden, but $302$ is fine). Reckha can otherwise choose any three-digit code where each digit is in the set $\{0,1,2,\dots,9\}$. How many codes are available for Reckha?
