Can the numbers $1,2,\dots,9$ be arranged in a row so that there are an odd number of numbers between $1$ and $2$, between $2$ and $3$, $\dots$, and between $8$ and $9$? For which $n\ge2$ can $1,2,\dots,n$ be arranged in this way?
