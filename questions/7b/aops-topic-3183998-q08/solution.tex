The mean is $\dfrac{28+n}{5}$. If $n\le6$, the median is $6$, yielding $n=2$. If $6\le n\le9$, the median is $n$, yielding $n=7$. If $n\ge9$, the median is $9$, yielding $n=17$. Each satisfies its range, so there are $\boxed3$ values.
