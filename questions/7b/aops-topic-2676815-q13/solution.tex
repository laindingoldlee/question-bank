Only parrots have wings ($2$ each), so there are $7$ parrots with $14$ legs. The remaining $48$ legs belong to hamsters ($4$ each), so there are $12$ hamsters. Goldfish have no legs, so there are $24-7-12=\boxed{5}$ goldfish.
