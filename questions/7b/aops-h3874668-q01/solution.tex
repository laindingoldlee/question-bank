There are $\dfrac{2!}{1!1!}\dfrac{5!}{2!2!1!}=60$ paths through $P$, and $\dfrac{5!}{2!2!1!}\dfrac{2!}{1!1!}=60$ through $Q$. Paths through both must visit $P$ first and number $2\cdot3!\cdot2=24$. The sum of the first two counts counts each such path twice, whereas it should count it zero times. Therefore the required count is $60+60-2\cdot24=\boxed{72}$.
