(a) If \(a\) is odd, \(a^2\) is odd; write \(a^2=2k+1\). Then \(\left\lfloor\dfrac{a^2}{2}\right\rfloor=k\) and \(\left\lceil\dfrac{a^2}{2}\right\rceil=k+1\), and
\[
a^2+k^2=2k+1+k^2=(k+1)^2 .
\]
So \(\left(a,\ \dfrac{a^2-1}{2},\ \dfrac{a^2+1}{2}\right)\) is a Pythagorean triple, for example \((3,4,5)\), \((5,12,13)\), \((7,24,25)\).

(b) If \(a\) is even, \(\dfrac{a^2}{2}\) is an integer, so the floor and ceiling are equal, and the identity would say \(a^2=0\), which is false for \(a>0\). For example \(a=2\) gives \(4+4=8\ne 4\). \(\blacksquare\)
