\textbf{(a)} Ignore the $1$ for a moment. The digits $2,2,0$ can appear in the orders $220$, $202$, $022$, and only $202$ has the $0$ between the $2$s. So the $2$s and the $0$ must appear in the order $2,0,2$, and the $1$ can be in any of the $4$ positions:
\[1202,\quad 2102,\quad 2012,\quad 2021.\]
None of these begins with $0$, so there are $\boxed{4}$ arrangements.

\textbf{(b)} Now $202$ must be a block, with the $1$ before or after it: $1202$ and $2021$, so $\boxed{2}$ arrangements.
