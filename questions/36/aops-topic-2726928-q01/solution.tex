Write $N=22(10^m-1)=22\cdot10^m-22$. Then
\[N=21\,9\cdots9\,78,\quad2N=43\,9\cdots9\,56,\quad3N=65\,9\cdots9\,34,\quad4N=87\,9\cdots9\,12,\]
each with $m-2$ nines (subtract $22,44,66,88$ from $22,44,66,88$ followed by $m$ zeros). Reading these, the reversal of $N$ is $4N$, and the reversal of $3N$ is $2N$. So
\[N\mapsto N-4N=-3N\mapsto-3N+2N=-N\mapsto-N+4N=3N\mapsto3N-2N=N.\]
For example $2178\to-6534\to-2178\to6534\to2178$. $\blacksquare$

(The post claims this for $21\ast78$ with \emph{any} digits $\ast$, which is false in that form: for example $21078\to-65934\to-21978\to\cdots$ falls into the cycle of $21978$ but never returns to $21078$.)
