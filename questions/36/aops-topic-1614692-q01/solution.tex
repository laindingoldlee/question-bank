Eliminate the constants: $3$ times the first equation minus $2$ times the second gives
\[
6x^2+15xy+9y^2-12x^2-16xy-8y^2=0\iff y^2-xy-6x^2=0\iff(y-3x)(y+2x)=0 .
\]
\begin{itemize}
\item $y=3x$: the first equation becomes $2x^2+15x^2+27x^2=44x^2=2$, so $x^2=\dfrac{1}{22}$; the second, $6x^2+24x^2+36x^2=66x^2=3$, agrees. Then $x^2+y^2=10x^2=\dfrac{5}{11}$.
\item $y=-2x$: the first equation becomes $2x^2-10x^2+12x^2=4x^2=2$, so $x^2=\dfrac{1}{2}$; the second, $6x^2-16x^2+16x^2=6x^2=3$, agrees. Then $x^2+y^2=5x^2=\dfrac{5}{2}$.
\end{itemize}
Every solution of the system is in one of these cases, so the maximum is $\boxed{\dfrac{5}{2}}$, attained at $(x,y)=\pm\left(\dfrac{\sqrt2}{2},-\sqrt2\right)$.
