Clearly an element cannot be less than $1$, so it suffices to show $1$ is possible. Write the set as $a<b<c<d<e<f\le13$. The mean gives a total of $48$ and the median gives $c+d=16$. The set $\{1,6,7,9,12,13\}$ has total $48$, median $\dfrac{7+9}{2}=8$ and largest element $13$. So the least possible value is $\boxed{1}$.
