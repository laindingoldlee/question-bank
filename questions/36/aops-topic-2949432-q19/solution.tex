$2.5=2+\dfrac12$, and $f\!\left(t+\dfrac1t\right)=t^2+\dfrac1{t^2}$. So $f^7(2.5)=2^{128}+2^{-128}=\dfrac{2^{256}+1}{2^{128}}$, with $a=2^{256}+1$ (odd) and $b=2^{128}$. Then
\[ab+a+b-1=(a+1)(b+1)-2=(2^{256}+2)(2^{128}+1)-2=2^{384}+2^{256}+2^{129}=2^{129}(2^{255}+2^{127}+1).\]
The last factor is odd, so $n=\boxed{129}$.
