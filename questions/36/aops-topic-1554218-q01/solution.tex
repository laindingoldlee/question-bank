Applying the condition with $d=3$ and $d=4$,
\[
f(5)-f(3)=\bigl(f(5)-f(4)\bigr)+\bigl(f(4)-f(3)\bigr)=3+3=6,
\]
so $f(3)-f(5)=\boxed{-6}$. (Indeed $f(x)=3x+c$ for some constant $c$: a linear function has constant slope, here $3$.)
