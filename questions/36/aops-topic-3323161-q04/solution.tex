The two numbers have the same number of digits, so their ratio is strictly between $\dfrac{1}{10}$ and $10$. Thus $2^{|r-s|}<10$, which implies $|r-s|\le3$. Equal digit sums also imply $2^r\equiv2^s\pmod9$, hence $2^{|r-s|}\equiv1\pmod9$. The powers for exponents $0,1,2,3$ have residues $1,2,4,8$. Only exponent zero works, so $r=s$.
