Write it as $\overline{abba}$, where $a\in\{1,\ldots,9\}$ and $b\in\{0,\ldots,9\}$. The digit sum condition is $2a+2b=8$, so $(a,b)=(1,3),(2,2),(3,1),(4,0)$. There are four successes among $9000$ four-digit integers, giving $\boxed{\dfrac{1}{2250}}$.
