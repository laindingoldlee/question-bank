First require each row to contain a black square. There are $(2^3-1)^3=343$ such boards. Use inclusion-exclusion on the events that specified columns are entirely white. If $k$ specified columns are white, each row has $2^{3-k}-1$ nonempty black subsets available. Hence the required count is
\[
\sum_{k=0}^3(-1)^k\binom3k(2^{3-k}-1)^3
=343-3\cdot27+3\cdot1=\boxed{265}.
\]
