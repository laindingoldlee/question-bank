Adding $b+c=ka$, $c+a=kb$, $a+b=kc$ gives $2(a+b+c)=k(a+b+c)$. If $a+b+c\ne0$, then $k=2$ (e.g. $a=b=c$). If $a+b+c=0$, then $b+c=-a$ and $k=-1$ (e.g. $a=b=1$, $c=-2$). So $k=\boxed{2\text{ or }-1}$.
