If there are $n$ terms, $l=ar^{n-1}$, so $\dfrac{l}{a}=r^{n-1}>0$. Taking logarithms gives $\boxed{n=1+\dfrac{\log(\dfrac{l}{a})}{\log r}}$. The data describe such a finite sequence only if this is a positive integer. If $r=1$, all terms equal $a$; $l=a$ then gives no information about the number of terms, while $l\ne a$ is impossible.
