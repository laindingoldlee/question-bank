Let $u=\sqrt2+1$ and $v=\sqrt2-1$, so $u^2=3+2\sqrt2$, $v^2=3-2\sqrt2$ and $uv=1$. If among the $149$ adjacent pairs there are $p$ pairs $(u,u)$, $q$ pairs $(v,v)$ and $149-p-q$ mixed pairs, then
\[\sum x_ix_{i+1}=3(p+q)+(149-p-q)+2\sqrt2(p-q).\]
This is an integer exactly when $p=q$ (as $\sqrt2$ is irrational), and then $S=149+4p$.

The number of mixed pairs is $149-2p$; it is odd, so at least $1$, giving $0\le p\le74$. Every such $p$ occurs: start with $p+1$ copies of $u$, then $p+1$ copies of $v$, then alternate $u,v,u,\dots$ to length $150$; this has $p$ pairs of each pure type. So the possible integers are $149,153,\dots,445$, all between $1$ and $1000$: $\boxed{75}$ values.
