The element $1$ must be in both sets. Each of the other nine elements $2,3,\dots,10$ must be in the union but not in the intersection, so it lies in exactly one of $A$ and $B$: $2$ choices for each. No other elements can appear. By the multiplication principle there are
\[
2^9=\boxed{512}
\]
ordered pairs.
