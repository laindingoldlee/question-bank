First split the $9$ letters into three consecutive blocks of sizes $x_1,x_2,x_3\ge 2$ with $x_1+x_2+x_3=9$. Writing $x_i=2+y_i$, we need $y_1+y_2+y_3=3$ with $y_i\ge0$, which has $\dbinom{5}{2}=10$ solutions (sticks and stones). Then decide which friend wears the first, second and third block: $3!=6$ ways. The total is $10\cdot 6=\boxed{60}$.

This is exactly the poster's method: giving each friend two letters first and distributing the remaining $3$ letters with stars and bars always works for ``at least $k$'' conditions, so it was not luck.
