If $3n\mid n^2-2n+6$, then $n^2-2n+6=3n\cdot t=n\cdot(3t)$ for an integer $t$, so $n\mid n^2-2n+6$ (a divisor of a divisor is a divisor). Since $n\mid n^2-2n$, it follows that $n\mid6$, so $n\in\{1,2,3,6\}$. Checking:
\[n=1:\ \dfrac53,\qquad n=2:\ \dfrac66=1,\qquad n=3:\ \dfrac99=1,\qquad n=6:\ \dfrac{30}{18}.\]
So $n=\boxed{2\text{ or }3}$.
