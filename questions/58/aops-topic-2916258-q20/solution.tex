Tangent segments from $Q$ are equal: $QA=QP=QB$, so $PQ=\dfrac{AB}2$. The external tangent length is $AB=\sqrt{(2+8)^2-(8-2)^2}=8$.
\begin{asy}
usepackage("amsmath");
size(3.5cm);
defaultpen(fontsize(10pt));
pair O1=(0,2),O2=(8,8);draw(circle(O1,2));draw(circle(O2,8));pair A=(0,0),B=(8,0),P=O1+2*unit(O2-O1);pair Q=(4,0);draw((-2,0)--(12,0));draw(Q--P);dot(A);dot(B);dot(P);dot(Q);
label("$A$",A,S);label("$B$",B,S);label("$P$",P,NW);label("$Q$",Q,S);
\end{asy}

So $PQ=\boxed{4}$.
