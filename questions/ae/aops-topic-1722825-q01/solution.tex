Write $t=|y|\ge0$. The equation is $x^2+2|x|t-3=t$, i.e.
\[
t\,(2|x|-1)=3-x^2 .
\]
\begin{itemize}
\item If $|x|=\dfrac{1}{2}$: the left side is $0$ but $3-\dfrac{1}{4}\ne0$. No solution.
\item If $|x|<\dfrac{1}{2}$: $2|x|-1<0$ while $3-x^2>0$, so $t<0$. No solution.
\item If $|x|>\dfrac{1}{2}$: $t=\dfrac{3-x^2}{2|x|-1}$, which is $\ge0$ exactly when $x^2\le3$. Then $y=\pm t$ works.
\end{itemize}
So the set of such $x$ (the ``domain'' of the relation) is $\boxed{-\sqrt3\le x<-\dfrac{1}{2}\ \text{ or }\ \dfrac{1}{2}<x\le\sqrt3}$.
