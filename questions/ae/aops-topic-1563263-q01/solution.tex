We count the derangements of $5$ objects (permutations with no fixed point) by inclusion--exclusion. The number of permutations fixing a given set of $k$ students is $(5-k)!$, so
\[
D_5=\sum_{k=0}^{5}(-1)^k\binom5k(5-k)!=120-120+60-20+5-1=44 .
\]
(Equivalently, $D_n=(n-1)(D_{n-1}+D_{n-2})$ with $D_1=0$, $D_2=1$ gives $D_3=2$, $D_4=9$, $D_5=44$.) There are $5!=120$ equally likely assignments, so the probability is
\[
\dfrac{44}{120}=\boxed{\dfrac{11}{30}}.
\]
