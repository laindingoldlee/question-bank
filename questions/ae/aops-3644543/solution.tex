(a) Switching wins exactly when the initial choice was wrong, probability $\boxed{\dfrac{2}{3}}$. (b) If the initial choice is correct, probability $\dfrac{1}{3}$, the host necessarily reveals empty. If it is wrong, probability $\dfrac{2}{3}$, the host reveals empty with probability $\dfrac{1}{2}$. The observed empty event therefore has probability $\dfrac{2}{3}$, with equal contributions from initially right and initially wrong. Conditional on that event, switching wins with probability $\boxed{\dfrac{1}{2}}$. The host' s selection rule changes the information carried by an empty reveal.
