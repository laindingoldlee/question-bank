Using $\sqrt[n]{y^m}=y^{\dfrac {m}{n}}$ for $y\ge0$:
\[
\sqrt{y^3}=y^{\dfrac{3}{2}},\qquad \sqrt[3]{y^2}=y^{\dfrac{2}{3}}.
\]
Also $\sqrt{y^3}=\sqrt{y^2\cdot y}=\sqrt{y^2}\,\sqrt y=y\sqrt y$ (since $y\ge0$, $\sqrt{y^2}=y$). So
\[
\boxed{\sqrt{y^3}=y^{\dfrac{3}{2}}=y\sqrt y,\qquad \sqrt[3]{y^2}=y^{\dfrac{2}{3}}}.
\]
