The equation is $7x^2+63x+56=0$, i.e. $x^2+9x+8=0$. By Vieta's formulas $x_1+x_2=-9$ and $x_1x_2=8$, so the value is $\left|x_1x_2\left(x_1+x_2\right)^2\right|=8\cdot81=\boxed{648}$.
