Let $f(n)$ count selections totaling $n$, with $f(0)=1$ and $f(-1)=0$. For odd $n=2m+1$, exactly one unit note is needed, giving $f(2m+1)=f(m)$. For positive even $n=2m$, there are either zero or two unit notes, so $f(2m)=f(m)+f(m-1)$. Dividing the remaining note values by $2$ explains both recurrences. Successive applications give
\[
\begin{array}{c|rrrrrrrrrrr}n&2&3&5&6&11&12&24&25&49&50&100\\\hline
f(n)&2&1&2&3&2&5&7&5&7&12&19\end{array}
\]
Thus there are $\boxed{19}$ selections.
