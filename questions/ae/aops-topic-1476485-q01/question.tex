Prove that for every integer $n$ and every positive integer $k$,
\[
n^k-1=(n-1)n^{k-1}+(n-1)n^{k-2}+\cdots+(n-1)n^{1}+(n-1)n^{0},
\]
and explain why, for $n\ge2$, this means that the number written in base $n$ with $k$ digits all equal to $n-1$ is $n^k-1$ (for example $666_7=7^3-1$).
