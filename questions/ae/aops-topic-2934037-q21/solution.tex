Every entry divides 30, so it is a product of a subset of the primes 2, 3, 5. For each prime separately, mark cells whose entries contain it. The marked cells are closed under moving upward or rightward, and the top-right cell is marked. Such a marked region is determined by a monotone boundary path with 3 horizontal and 3 vertical steps, giving $\binom63=20$ possibilities including the empty region. Excluding that region leaves 19. The three primes can be chosen independently, so the number is $\boxed{19^3=6859}$.
