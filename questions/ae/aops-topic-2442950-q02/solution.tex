\textbf{Removing the extra term.} Try $g(n)=f(n)+cn+d$ with constants chosen so that $g$ satisfies the Fibonacci recurrence. We need
\[f(n)+cn+d=f(n-1)+c(n-1)+d+f(n-2)+c(n-2)+d,\]
i.e. $2n+cn+d=2cn-3c+2d$ for all $n$, which holds for $c=2$, $d=6$. So $g(n)=f(n)+2n+6$ satisfies
\[g(n)=g(n-1)+g(n-2),\qquad g(1)=9,\quad g(2)=11.\]

\textbf{Matching with Fibonacci numbers.} The sequence $h(n)=7F_n+2F_{n+1}$ satisfies the same recurrence, with $h(1)=7+2=9$ and $h(2)=7+2\cdot2=11$. Two sequences with the same recurrence and the same first two terms agree, so $g(n)=7F_n+2F_{n+1}$ and
\[f(n)=7F_n+2F_{n+1}-2n-6.\]
(Check: $f(3)=1+1+6=8=7\cdot2+2\cdot3-12$, and $f(4)=8+1+8=17=7\cdot3+2\cdot5-14$.) Therefore
\[f(2021)=\boxed{7F_{2021}+2F_{2022}-4048}\]
(equivalently $9F_{2021}+2F_{2020}-4048$).
