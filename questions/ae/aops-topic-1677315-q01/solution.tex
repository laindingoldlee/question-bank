\textbf{Odd integers.} Write $n=2m+1$. Then $n^2=4m^2+4m+1=4m(m+1)+1$. One of the consecutive integers $m$, $m+1$ is even, so $8\mid4m(m+1)$ and $n^2\equiv1\pmod8$.

\textbf{Even integers.} Write $n=2m$, so $n^2=4m^2$. If $m$ is even, $m^2$ is even and $8\mid4m^2$, so $n^2\equiv0\pmod8$. If $m$ is odd, $m^2$ is odd, $4m^2=8\cdot\dfrac{m^2-1}{2}+4$ with $\dfrac{m^2-1}{2}$ an integer, so $n^2\equiv4\pmod8$.

Hence $n^2\equiv0$, $1$ or $4\pmod8$ for every integer $n$. (Equivalently: the remainders $0,1,\dots,7$ have squares $0,1,4,9,16,25,36,49\equiv0,1,4,1,0,1,4,1\pmod8$.) $\blacksquare$
