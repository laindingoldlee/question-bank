A number is divisible by $4$ exactly when the number formed by its last two digits is. So we need $4\mid\overline{bb}=11b$, i.e. $4\mid b$, so $b\in\{0,4,8\}$ ($00$, $44$, $88$). The leading digit $a$ can be any of $1,\dots,9$. There are $9\cdot3=\boxed{27}$ such numbers.
