There are $366$ possible birthdays.

\textbf{$366\cdot2017$ people are not enough.} If exactly $2017$ people have each of the $366$ birthdays, no birthday is shared by $2018$ people.

\textbf{$366\cdot2017+1$ people suffice.} If every birthday were shared by at most $2017$ people, there would be at most $366\cdot2017$ people (pigeonhole principle).

So the least number is
\[
366\cdot2017+1=\boxed{738223}.
\]
(If February $29$ is ignored, so that there are $365$ possible birthdays, the answer is $365\cdot2017+1=736206$.)
