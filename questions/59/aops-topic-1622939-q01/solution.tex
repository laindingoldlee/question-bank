Let the common digit sum be $s$. A number is congruent to its digit sum modulo $9$, so the four numbers add up to $4s\pmod9$. As $2015\equiv2+0+1+5=8\pmod9$, we need $4s\equiv8$, i.e. $s\equiv2\pmod9$ (multiply by $7$, the inverse of $4$ modulo $9$). With $1\le s\le27$ this leaves $s=2$, $11$ or $20$.
\begin{itemize}
\item $s=2$ is impossible: the only three-digit numbers with digit sum $2$ are $101$, $110$, $200$, fewer than four.
\item $s=11$ is possible: $119+146+830+920=2015$.
\item $s=20$ is possible: $299+389+398+929=2015$.
\end{itemize}
The sum of the possible values is $11+20=\boxed{31}$.
