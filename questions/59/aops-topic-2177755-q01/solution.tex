For a prime $p$ write $v_p(m)$ for the exponent of $p$ in $m$. For every prime $p$,
\[\min\left(v_p(x),v_p(y)\right)=v_p(99),\qquad \max\left(v_p(x),v_p(y)\right)=v_p(99!),\]
so the pair of exponents $\left(v_p(x),v_p(y)\right)$ is $\left(v_p(99),v_p(99!)\right)$ in one of the two orders. Conversely, each such choice of orders for all primes gives a valid pair $(x,y)$.

For primes $p>99$ both exponents are $0$ and there is one choice. For each prime $p<99$ the two exponents are different: $99=3^2\cdot11$, so $v_p(99)=0<v_p(99!)$ for $p\ne3,11$, while
\[v_3(99!)=33+11+3+1=48\ne2,\qquad v_{11}(99!)=9+0=9\ne1 .\]
So each of these primes gives $2$ choices. There are $25$ primes below $99$ (namely $2,3,5,\ldots,89,97$), so the number of ordered pairs is
\[2^{25}=\boxed{33554432}.\]
