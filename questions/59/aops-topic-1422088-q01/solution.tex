Let the subset contain $q$ quarters, $d$ dimes and $n$ nickels, so $25q+10d+5n=50$, with $q\le2$, $d\le3$, $n\le4$. Count by the number of quarters.
\begin{itemize}
\item $q=2$: $d=n=0$; $\dbinom22=1$ way.
\item $q=1$: $10d+5n=25$, so $2d+n=5$: $(d,n)=(1,3)$ or $(2,1)$ (and $(0,5)$ is impossible). This gives $\dbinom21\left[\dbinom31\dbinom43+\dbinom32\dbinom41\right]=2(12+12)=48$ ways.
\item $q=0$: $2d+n=10$ with $d\le3$, $n\le4$ forces $(d,n)=(3,4)$: $1$ way.
\end{itemize}
In total there are $1+48+1=\boxed{50}$ ways.
