Let $a=BC,b=CA,c=AB$, semiperimeter $s$, and inradius $r$. Then $DC+AC=a-c+b=2(s-c)$. The tangent length from $C$ equals $s-c=r\cot(\dfrac{C}{2})$, while $IC=r\csc(\dfrac{C}{2})$. Hence $2r\cot(\dfrac{C}{2})=\sqrt3r\csc(\dfrac{C}{2})$, so $2\cos(\dfrac{C}{2})=\sqrt3$. Since $0<\dfrac{C}{2}<90^\circ$, this gives $\boxed{C=60^\circ}$.

import graph;import geometry;usepackage("amsmath");size(7cm);
pair B=(0,0),C=(5,0),A=(3.5,1.5sqrt(3));real c=abs(A-B),b=abs(A-C);pair D=(c,0),I=(5A+b*B+c*C)/(5+b+c);draw(A--B--C--cycle);draw(C--I,blue);dot(D);label("$A$",A,(0,1));label("$B$",B,(-1,-1));label("$C$",C,(1,-1));label("$D$",D,(0,-1));label("$I$",I,(-1,0));
\end{asy}
