An alien has three hands with $12$ fingers on each hand. It counts in base $12$, using each hand to show one base-$12$ digit: raising $k$ fingers on a hand shows the digit $k$, for $0\le k\le11$. The three hands show, from left to right, the $144$s digit, the twelves digit and the units digit.
\begin{enumerate}
\item[(a)] How does the alien show the number $97$?
\item[(b)] What is the largest number the alien can show this way?
\end{enumerate}
