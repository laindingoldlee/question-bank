Measure angles clockwise from the $12$.
\begin{itemize}
\item The minute hand moves $6^\circ$ per minute, so at $42$ minutes it is at $42\cdot6=252^\circ$.
\item The hour hand moves $30^\circ$ per hour, i.e.\ $0.5^\circ$ per minute. At 5:42 it is at $5\cdot30+42\cdot0.5=150+21=171^\circ$.
\end{itemize}
The angle between them is $252-171=81^\circ$, which is less than $180^\circ$, so the smaller angle is $\boxed{81^\circ}$.
