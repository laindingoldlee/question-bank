The sum of the coefficients is the value at $x=1$, namely $(1-2+2-1+p+q)^2=(p+q)^2$. So $(p+q)^2=(pq)^2$, i.e. $pq=\pm s$ where $s=p+q$. Also $p^3+q^3=s^3-3pq\,s=196$.
\begin{itemize}
\item $pq=s$: $s^3-3s^2-196=(s-7)\left(s^2+4s+28\right)=0$, so $s=7$ (the quadratic has no real roots).
\item $pq=-s$: $s^2(s+3)=196$. An integer solution needs $s+3>0$ dividing $196$; checking $s+3\in\{1,2,4,7,14,28,49,98,196\}$ gives no solution.
\end{itemize}
So $p+q=\boxed{7}$ (with $pq=7$, so $p,q=\dfrac{7\pm\sqrt{21}}{2}$ are real).
