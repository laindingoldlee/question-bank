Write the number as $100a+10b+c$ with digits $a\ge1$, $b$, $c$. The condition is
\[
100a+10b+c=a^3+b^3+c^3\iff a(100-a^2)+b(10-b^2)=c^3-c=(c-1)c(c+1).
\]
