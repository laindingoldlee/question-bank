Complete the square:
\[4\left(n^2+5n+8\right)=4n^2+20n+32=(2n+5)^2+7.\]
Suppose $49\mid n^2+5n+8$. Then $49\mid(2n+5)^2+7$, so in particular $7\mid(2n+5)^2$. Since $7$ is prime, $7\mid2n+5$, and then $49\mid(2n+5)^2$. Subtracting,
\[49\mid\left((2n+5)^2+7\right)-(2n+5)^2=7,\]
which is false. So $49\nmid n^2+5n+8$ for every integer $n$ (in particular every positive integer). $\blacksquare$
