\textbf{(a)} For $x\ne0$, $x^{-2}=\dfrac1{x^2}$, so
\[\dfrac{8}{x^{-2}}=\dfrac{8}{\ \dfrac1{x^2}\ }=8x^2.\]

\textbf{(b)} At $x=0$, $g(0)=0$, but $x^{-2}=\dfrac1{0^2}$ is undefined, so $f(0)$ is undefined. So $f$ and $g$ agree everywhere except at $\boxed{x=0}$, where $g$ is defined and $f$ is not.

Hence, after simplification, $\dfrac{8}{x^{-2}}$ equals the polynomial $8x^2$ (a monomial of degree $2$) for all $x\ne0$. As written, however, it is not a polynomial expression (it contains a negative power of $x$), and the function it defines has the domain $x\ne0$, unlike the polynomial function $8x^2$, which is defined for all real $x$.
