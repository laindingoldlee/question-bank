By the triangle inequality, applied twice,
\[PQ\le PS+SQ\le PS+SR+RQ,\]
so $10\le PS+3+4$, that is, $PS\ge3$.

The value $3$ is attained when the four points lie on a line in the order $P,S,R,Q$, for example $P=0$, $S=3$, $R=6$, $Q=10$ on a number line (bottom picture); in any other position the path $P\to S\to R\to Q$ is bent and $PS$ is longer (top picture).

\begin{asy}
usepackage("amsmath");
size(6.5cm);
defaultpen(fontsize(10pt));
pair P=(0,2.6), Q=(10,2.6), R=(6.9,5.4), Sx=(4.1,4.4);
draw(P--Q,linewidth(0.9)); draw(Q--R--Sx,blue+linewidth(0.9)); draw(P--Sx,red+dashed);
dot(P); dot(Q); dot(R); dot(Sx);
label("$P$",P,W); label("$Q$",Q,E); label("$R$",R,N); label("$S$",Sx,N);
label("$10$",(5,2.6),S,fontsize(8pt)); label("$4$",(Q+R)/2,NE,blue+fontsize(8pt)); label("$3$",(R+Sx)/2,N,blue+fontsize(8pt));
pair P2=(0,0), S2=(3,0), R2=(6,0), Q2=(10,0);
draw(P2--Q2,linewidth(0.9)); draw(S2--R2--Q2,blue+linewidth(1.3)); draw(P2--S2,red+linewidth(1.3));
dot(P2); dot(S2); dot(R2); dot(Q2);

label("$3$",(P2+S2)/2,N,red+fontsize(8pt)); label("$3$",(S2+R2)/2,N,blue+fontsize(8pt)); label("$4$",(R2+Q2)/2,N,blue+fontsize(8pt));
label("$P$",P2,S); label("$S$",S2,S); label("$R$",R2,S); label("$Q$",Q2,S);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

The smallest possible distance is $\boxed{3}$.
