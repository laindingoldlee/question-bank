Two different integers are chosen from $\{1,2,3,\dots,500\}$. In how many ways (the order does not matter) can this be done so that their average is an integer? A student argues: ``There are $500$ choices for the first number and $250-1=249$ choices for a second number with the same parity, and each pair is counted twice, so the answer is $\dfrac{500\cdot249}{2}$.'' Is this argument correct? Find the answer.
