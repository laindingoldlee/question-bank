\textbf{$n$ is odd.} Modulo $3$: $7\equiv1$ and $2\equiv-1$, so $7^n+2^n\equiv1+(-1)^n$. For even $n$ this is $2\pmod3$, but squares are $0$ or $1\pmod3$. So $n$ is odd.

\textbf{$n=1$.} Modulo $4$: for odd $n$, $7^n\equiv(-1)^n=-1\equiv3$; and for $n\ge2$, $2^n\equiv0$. So for odd $n\ge3$, $7^n+2^n\equiv3\pmod4$, which is not a square (squares are $0$ or $1\pmod 4$). Hence $n=1$, and then $7+2=9=3^2$.

The only solution is $\boxed{(n,k)=(1,3)}$.
