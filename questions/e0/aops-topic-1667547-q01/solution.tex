The first three values are $(x+1)^2$ at $x=1,2,3$. So $g(x)=f(x)-(x+1)^2$ is a polynomial of degree $3$ with roots $1,2,3$:
\[
f(x)=(x+1)^2+c(x-1)(x-2)(x-3)
\]
for a constant $c$. From $f(4)=25+6c=37$ we get $c=2$. Hence
\[
f(5)=36+2\cdot4\cdot3\cdot2=\boxed{84}.
\]
(Check with finite differences: the values $4,9,16,37$ have differences $5,7,21$, second differences $2,14$ and third difference $12$, which is constant for a cubic. Continuing, the next second difference is $26$, the next first difference $47$, and $f(5)=37+47=84$.)
