Each region is described by which of the three sets contain it.
\begin{itemize}
\item $R_1$ (in all three): $A\cap B\cap C$.
\item $R_2$ (in $A$ and $B$, not $C$): $(A\cap B)\cap C'$.
\item $R_3$ (in $A$ and $C$, not $B$): $(A\cap C)\cap B'$.
\item $R_4$ (in $A$ only): $A\cap(B\cup C)'$, which equals $A\cap B'\cap C'$.
\item $R_5$ (in $B$ and $C$, not $A$): $(B\cap C)\cap A'$.
\item $R_6$ (in $B$ only): $B\cap(A\cup C)'$.
\item $R_7$ (in $C$ only): $C\cap(A\cup B)'$.
\item $R_8$ (in none of them): $(A\cup B\cup C)'$, which equals $A'\cap B'\cap C'$.
\end{itemize}
