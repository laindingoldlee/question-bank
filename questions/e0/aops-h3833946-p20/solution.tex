Condition on the number $K$ of included cards. For $K=k>0$, the expected number of decreasing runs is $1+\dfrac{k-1}{2}=\dfrac{k+1}{2}$, since each adjacent pair is equally likely to be an ascent or descent. Therefore $E[\text{score}]=\dfrac{E[K]+\Pr(K>0)}{2}=\dfrac{\dfrac{7}{2}+\dfrac{127}{128}}{2}=\dfrac{575}{256}$. The requested sum is $\boxed{831}$.
