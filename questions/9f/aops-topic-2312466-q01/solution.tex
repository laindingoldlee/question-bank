Each pick is red with probability $p=\dfrac{27}{69}=\dfrac{9}{23}$, independently of earlier picks, because blue balls are returned. Let $q=1-p=\dfrac{14}{23}$. The game lasts exactly $n$ picks with probability $q^{n-1}p$, so the expected number of picks is
\[E=\sum_{n=1}^{\infty}n\,q^{n-1}p=\dfrac{p}{(1-q)^2}=\dfrac1p=\dfrac{23}{9},\]
using $\displaystyle\sum_{n\ge1}nq^{n-1}=\dfrac{1}{(1-q)^2}$ for $|q|<1$. (Alternatively: after the first pick the game ends with probability $p$ or starts afresh, so $E=1+qE$, giving $E=\dfrac1p$.)

The average winnings are therefore
\[0.10\cdot\dfrac{23}{9}=\boxed{\dfrac{23}{90}\text{ dollars}}\approx0.26\text{ dollars}.\]
