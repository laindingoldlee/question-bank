Write the angles in increasing order as $a$, $a+d$, $a+2d$, $a+3d$ with $d\ge0$, so $x=a+3d$. They add up to $360^\circ$:
\[4a+6d=360,\qquad\text{so}\qquad 2a+3d=180 .\]
Since $a$ and $a+d$ are integers, $d$ is an integer; and $3d=180-2a$ is even, so $d$ is even. Also
\[x=a+3d=a+(180-2a)=180-a,\]
so we want $a$ as small as possible. Writing $d=2e$ gives $a=90-3e$, and $a\ge1$ forces $e\le29$. The smallest value is $a=3$ (with $e=29$, $d=58$), giving the angles
\[3^\circ,\ 61^\circ,\ 119^\circ,\ 177^\circ,\]
which add up to $360^\circ$ and are all less than $180^\circ$. Such a convex quadrilateral exists: because $3+177=180=61+119$, a trapezoid with base angles $3^\circ$ and $61^\circ$ has exactly these angles. (The sketch shows the same shape of trapezoid for a less extreme progression, $60^\circ,80^\circ,100^\circ,120^\circ$; in every case $a+(a+3d)=180^\circ=(a+d)+(a+2d)$.)

\begin{asy}
usepackage("amsmath");
size(5.5cm);
defaultpen(fontsize(10pt));
pair A=(0,0), B=(5,0);
real h=2.2;
pair D=(h/Tan(60),h), C=(5-h/Tan(80),h);
draw(A--B--C--D--cycle,linewidth(1));
draw(A--B,MidArrow(5)); draw(D--C,MidArrow(5));
draw(arc(A,0.45,0,60)); draw(arc(B,0.45,100,180)); draw(arc(C,0.4,180,280)); draw(arc(D,0.4,-120,0));
label("$a$",A+0.7*dir(30),fontsize(9pt));
label("$a+d$",B+0.85*dir(146),fontsize(9pt));
label("$a+2d$",C+0.75*dir(230),fontsize(9pt));
label("$a+3d$",D+0.95*dir(-24),fontsize(9pt));
label("example: $a=60^\circ$, $d=20^\circ$",(2.5,-0.5),fontsize(9pt));
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

So the largest possible value is $x=\boxed{177}$.
