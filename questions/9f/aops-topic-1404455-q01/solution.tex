Since $x^2-3x+2=(x-1)(x-2)$, we need $x\ne1,2$. Bring everything to one side over the common denominator:
\[
\dfrac{2(x-2)-(x-1)-1}{(x-1)(x-2)}=\dfrac{x-4}{(x-1)(x-2)}>0 .
\]
The sign changes only at $x=1,2,4$:
\begin{itemize}
\item $x<1$: numerator $-$, denominator $+$: negative;
\item $1<x<2$: numerator $-$, denominator $-$: positive;
\item $2<x<4$: numerator $-$, denominator $+$: negative;
\item $x>4$: positive.
\end{itemize}
At $x=4$ the expression is $0$, which is not allowed. So the solution set is $\boxed{1<x<2\ \text{or}\ x>4}$.
