Check small values: $n=1$: $1<2$; $n=2$: $4=4$; $n=3$: $9>8$; $n=4$: $16=16$; $n=5$: $25<32$.

For $n\ge5$ we have $n^2<2^n$, by induction: it holds for $n=5$, and if $n^2<2^n$ with $n\ge5$ then
\[
(n+1)^2=n^2+2n+1<n^2+n^2=2n^2<2\cdot2^n=2^{n+1},
\]
using $2n+1<n^2$ for $n\ge3$. So the inequality holds exactly for $n=2,3,4$: $\boxed{3}$ values.
