Using $1^2+2^2+\cdots+n^2=\dfrac{n(n+1)(2n+1)}{6}$ with $n=24$,
\[1^2+2^2+\cdots+24^2=\dfrac{24\cdot25\cdot49}{6}=4\cdot25\cdot49=4900=70^2 .\]
So the side length is $\boxed{70}$.

(Remarkably, $n=24$ is the only $n>1$ for which $1^2+2^2+\cdots+n^2$ is a perfect square; this is the classical ``cannonball problem''.)
