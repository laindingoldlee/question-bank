If $(u,v)=(x+y,x-y)$, then $u+v=2x$ and $u-v=2y$. So
\[
f^{-1}(u,v)=\boxed{\left(\dfrac{u+v}{2},\ \dfrac{u-v}{2}\right)},
\]
and one checks $f\left(\dfrac{u+v}{2},\dfrac{u-v}{2}\right)=(u,v)$.
