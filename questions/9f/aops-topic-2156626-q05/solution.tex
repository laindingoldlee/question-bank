Since $\left(a^2-b^2-c^2\right)^2=a^4+b^4+c^4-2a^2b^2-2a^2c^2+2b^2c^2$, the expression equals
\[\left(a^2-b^2-c^2\right)^2-4b^2c^2=\left(a^2-b^2-c^2-2bc\right)\left(a^2-b^2-c^2+2bc\right)=\left(a^2-(b+c)^2\right)\left(a^2-(b-c)^2\right).\]
Each factor is again a difference of squares, so
\[a^4+b^4+c^4-2a^2b^2-2a^2c^2-2b^2c^2=\boxed{(a+b+c)(a-b-c)(a-b+c)(a+b-c)}.\]
