This is a $45^\circ$-$45^\circ$-$90^\circ$ triangle, so each leg is $\dfrac{50}{\sqrt2}=25\sqrt2$. The perimeter is $\boxed{50+50\sqrt2}$ metres.
\begin{asy}
usepackage("amsmath");
size(7cm);
pair C=(0,0),A=(1,0),B=(0,1);draw(A--B--C--cycle);label("$A$",A,SE);label("$B$",B,NW);label("$C$",C,SW);label("$50$",(0.5,0.5),NE);
\end{asy}
