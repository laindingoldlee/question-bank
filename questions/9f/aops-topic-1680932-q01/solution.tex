Since $\overline{abcdef}$ has six digits, $a\ne0$ and $100\le\overline{abc}\le999$. Then $\overline{def}>\overline{abc}\ge100$, so $\overline{def}$ is also between $100$ and $999$. Conversely, any two different numbers from $\{100,\dots,999\}$, the smaller written first, give exactly one valid six-digit number. So the count is
\[
\binom{900}{2}=\dfrac{900\cdot899}{2}=\boxed{404550}.
\]
