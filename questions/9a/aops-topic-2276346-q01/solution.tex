Let $s=x+\dfrac{1}{x}=6$.

\textbf{Squares.} $s^2=x^2+2+\dfrac{1}{x^2}$, so
\[x^2+\dfrac{1}{x^2}=s^2-2=36-2=\boxed{34}.\]

\textbf{Cubes.} $s^3=x^3+3x+\dfrac{3}{x}+\dfrac{1}{x^3}=x^3+\dfrac{1}{x^3}+3s$, so
\[x^3+\dfrac{1}{x^3}=s^3-3s=216-18=\boxed{198}.\]

\textbf{Fourth powers.} Squaring the first result, $\left(x^2+\dfrac{1}{x^2}\right)^2=x^4+2+\dfrac{1}{x^4}$, so
\[x^4+\dfrac{1}{x^4}=34^2-2=1156-2=\boxed{1154}.\]
(Check: $x=3+2\sqrt2$ satisfies $x+\dfrac{1}{x}=(3+2\sqrt2)+(3-2\sqrt2)=6$, and $x^2=17+12\sqrt2$, $\dfrac{1}{x^2}=17-12\sqrt2$, whose sum is $34$.)
