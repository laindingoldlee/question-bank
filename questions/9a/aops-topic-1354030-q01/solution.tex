Write each number as $2^km$ with $m$ odd; its greatest odd divisor is $m$.

\emph{Claim.} The numbers $2007,2008,\dots,4012$ (that is, $n+1,\dots,2n$ with $n=2006$) have greatest odd divisors $1,3,5,\dots,4011$, each exactly once.

Proof: if two numbers $2^km$ and $2^lm$ with $k<l$ in this range had the same odd part, the second would be at least twice the first, which is impossible because $2n<2(n+1)$. So the $2006$ odd parts are distinct, and each is an odd number at most $4012$, i.e.\ one of the $2006$ odd numbers $1,3,\dots,4011$. Hence they are exactly these numbers.

So the sum for $2007,\dots,4012$ is $1+3+\cdots+4011=2006^2=4\,024\,036$. Adding the greatest odd divisor of $2006=2\cdot1003$, which is $1003$, the total is
\[
4\,024\,036+1003=\boxed{4025039}.
\]
