None of $x,y,z$ is $0$ (otherwise one of the left sides would be $0$), so we may take reciprocals:
\[\dfrac1x+\dfrac1y=1,\qquad\dfrac1x+\dfrac1z=\dfrac12,\qquad\dfrac1y+\dfrac1z=\dfrac13.\]
Adding, $2\left(\dfrac1x+\dfrac1y+\dfrac1z\right)=\dfrac{11}{6}$, so $\dfrac1x+\dfrac1y+\dfrac1z=\dfrac{11}{12}$. Subtracting each equation in turn,
\[\dfrac1z=\dfrac{11}{12}-1=-\dfrac1{12},\qquad\dfrac1y=\dfrac{11}{12}-\dfrac12=\dfrac5{12},\qquad\dfrac1x=\dfrac{11}{12}-\dfrac13=\dfrac7{12}.\]
So $\boxed{(x,y,z)=\left(\dfrac{12}{7},\dfrac{12}{5},-12\right)}$, and all denominators $x+y$, $x+z$, $y+z$ are nonzero, so this is the unique solution.
