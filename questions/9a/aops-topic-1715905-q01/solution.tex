The six trucks drove $6\cdot8=48$ truck-hours, so one truck uses $\dfrac{720}{48}=15$ litres per hour. Nine trucks driving $6$ hours each make $54$ truck-hours and use $54\cdot15=\boxed{810}$ litres.
