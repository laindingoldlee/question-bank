Take the first lock and try keys on it: in the worst case $4$ tries are needed (if the first $4$ keys fail, the $5$th key must fit, without trying). Then $3$ tries for the next lock with the $4$ remaining keys, then $2$, then $1$, and the last key goes to the last lock untried. The worst case is $4+3+2+1=\boxed{10}$ tries, and the bad luck described can actually happen, so fewer tries do not always suffice.
