Note that $n^3-(n-1)^3=3n^2-3n+1=f(n)$. So the sum telescopes:
\[\sum_{n=1}^{2010}f(n)=\sum_{n=1}^{2010}\left(n^3-(n-1)^3\right)=2010^3-0^3=8\,120\,601\,000 .\]
The last four digits are $\boxed{1000}$.
