The sphere contains $\dfrac{4}{3}\pi3^3=36\pi$. The prism holds $2\pi\cdot4\cdot3=24\pi$, leaving $12\pi$. Each cone holds $\dfrac{1}{3}\pi2^2\cdot3=4\pi$, so $\boxed3$ cones are filled.
