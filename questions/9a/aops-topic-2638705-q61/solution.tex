If $x$ is an integer, the left side is $x^2$, but $33^2<1122<34^2$, so no integer works. Otherwise put $n=\lfloor x\rfloor$, so $n(n+1)=1122=33\cdot34$. Solving gives $n=33$ or $n=-34$. Therefore $\boxed{x\in(-34,-33)\cup(33,34)}$.
