There are $9000$ four-digit numbers. Those with all digits different number $9\cdot9\cdot8\cdot7=4536$ (the leading digit is not $0$). So the probability is
\[1-\dfrac{4536}{9000}=\dfrac{4464}{9000}=\boxed{\dfrac{62}{125}}.\]
