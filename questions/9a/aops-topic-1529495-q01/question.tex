A $2016$ cm tower is built by stacking $5$ cm blocks and $3$ cm blocks (any number of each, possibly none of one kind). All the $5$ cm blocks are placed below all the $3$ cm blocks. For example, the tower can be built from twelve $5$ cm blocks followed by six hundred fifty-two $3$ cm blocks. In how many ways can the $2016$ cm tower be built?
