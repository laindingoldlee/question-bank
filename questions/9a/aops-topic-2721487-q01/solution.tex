One one-digit multiple ($7$) uses $1$ digit; the $13$ two-digit multiples ($14$ to $98$) use $26$; the $128$ three-digit multiples ($105$ to $994$) use $384$. That is $411$ digits. The remaining $2020-411=1609=4\cdot402+1$ digits run through $402$ four-digit multiples and then the first digit of the next. The four-digit multiples start at $1001$, so the $403$rd is $1001+7\cdot402=3815$, and the $2020$th digit is $\boxed{3}$.
