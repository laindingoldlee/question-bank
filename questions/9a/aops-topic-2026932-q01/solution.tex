Using $a^3+b^3=(a+b)(a^2-ab+b^2)$ with $a=2^5=32$, $b=1$,
\[
2^{15}+1=(32+1)(1024-32+1)=33\cdot993=3\cdot11\cdot3\cdot331.
\]
The number $331$ is prime: it is not divisible by $2,3,5,7,11,13,17$, and $19^2=361>331$. So the largest prime factor is
\[\boxed{331}.\]
