The polynomial factors as $(n^2+n+1)(n^4+n^3+n^2+n+1)$. For the first factor, either $n=1\pmod p$ and $p=3$, or $n$ has multiplicative order 3 and $p\equiv1\pmod3$. For the second, similarly either $p=5$ or $p\equiv1\pmod5$. These conditions leave exactly the 16 candidate primes 3, 5, 7, 11, 13, 19, 31, 37, 41, 43, 61, 67, 71, 73, 79, 97. They all work: respective witnesses are 1, 1, 2, 3, 3, 7, 2, 10, 10, 6, 9, 29, 5, 8, 23, 35, verified by substitution into one factor. There are 25 primes below 100, so the probability is $\dfrac{16}{25}$ and $\boxed{a+b=41}$.
