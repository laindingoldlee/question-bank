First look for a four-digit solution $n=\overline{abcd}$ with $9n=\overline{dcba}$. Since $9n<10000$, we have $n\le1111$, so $a=1$. Then $9n=\overline{dcb1}$ is at least $9\cdot1000$, so $d=9$. Now
\[9\left(1000+100b+10c+9\right)=9000+100c+10b+1,\]
which simplifies to $890b+80=10c$, that is, $c=89b+8$. Since $c$ is a digit, $b=0$ and $c=8$.

So $n=1089$ is the only four-digit solution, and indeed $9\cdot1089=9801$. Every number greater than $1000$ and smaller than $1089$ has four digits and is not a solution, so the answer is $\boxed{1089}$.
