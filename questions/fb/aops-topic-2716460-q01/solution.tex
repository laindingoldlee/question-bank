Each throw gives doubles with probability $\dfrac6{36}=\dfrac16$, independently. If $E$ is the expected number of throws, then after one throw you are done with probability $\dfrac16$ and start over otherwise: $E=1+\dfrac56E$, so $E=\boxed{6}$.
