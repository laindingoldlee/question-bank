The subset $\boxed{\{3,5,7\}}$ works because $3+5+7=15$. Checking this proposal only requires adding its entries and verifying membership. Exhaustive search can test all $2^4=16$ subsets. This example illustrates verification versus one search method, but does not prove any general separation between computational complexity classes.
