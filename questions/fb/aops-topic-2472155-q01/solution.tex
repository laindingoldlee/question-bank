\textbf{(a)} If $0<x\le1$, then $x^x\le1^x=1<512$, so there is no solution in $(0,1]$.

For $x>1$ write $x^x=e^{g(x)}$ with $g(x)=x\ln x$. On $(1,\infty)$ both $x$ and $\ln x$ are positive and strictly increasing, so their product $g$ is strictly increasing, and hence so is $x^x$. Therefore $x^x=512$ has at most one solution with $x>1$. The function $x^x$ is continuous, with
\[4^4=256<512<3125=5^5,\]
so by the intermediate value theorem there is a solution in $(4,5)$. Hence there is exactly one positive solution, and it lies between $4$ and $5$. $\blacksquare$

\textbf{(b)} Suppose the solution is rational, $x=\dfrac pq$ with positive integers $p,q$ and $\gcd(p,q)=1$. Then
\[\left(\dfrac pq\right)^{\dfrac pq}=2^9\ \Longrightarrow\ \left(\dfrac pq\right)^{p}=2^{9q}\ \Longrightarrow\ p^p=2^{9q}q^p.\]
If $q>1$, a prime factor of $q$ divides $p^p$ and hence $p$, contradicting $\gcd(p,q)=1$. So $q=1$ and $x=p$ is an integer. But no integer lies strictly between $4$ and $5$, a contradiction. Hence the solution is irrational. $\blacksquare$

(Numerically, $x\approx4.2863$. It can be written with the Lambert $W$ function as $x=e^{W(9\ln2)}$, but not in terms of elementary functions in any simple way; an equation such as $x^x=256$ is easy only because its solution $x=4$ happens to be an integer.)
