Neither. Dividing $x$ by $0$ would mean finding the number $q$ with $0\cdot q=x$.
\begin{itemize}
\item If $x\ne0$, there is no such number, since $0\cdot q=0$ for every $q$.
\item If $x=0$, every number $q$ works, so there is no single value to call $\dfrac{0}{0}$.
\end{itemize}
Either way $\dfrac{x}{0}$ is not a number, so the expression $0\times\dfrac{x}{0}$ is \textbf{undefined} for every $x$.

The first student applies the rule $0\cdot q=0$, which is true only when $q$ is a number. The second student cancels the zeros, but cancelling $\dfrac{0}{0}$ to $1$ is exactly the illegal step: it would also ``prove'' $0\times\dfrac{1}{0}=1$ and $0\times\dfrac{2}{0}=2$, although both are $0\times(\text{something})$.
