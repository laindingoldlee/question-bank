In the binomial expansion, odd powers of $\sqrt{41}$ cancel; the sum is a polynomial with integer coefficients in $41$. Since $71^2\equiv41\pmod{1000}$, it has the same residue as $(-15)^{10}+127^{10}$. This is $2\pmod8$ and $2^{10}\equiv24\pmod{125}$. Write the residue as $24+125k$. Modulo $8$, $5k\equiv2$, so $k\equiv2\pmod8$. The residue between $0$ and $999$ is $\boxed{274}$.
