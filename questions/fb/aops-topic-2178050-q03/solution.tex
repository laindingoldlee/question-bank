Write $f(x)=mx+c$. Then $8m-2m=18-6$, so $m=2$ and $c=2$: $f(x)=2x+2=2(x+1)$. Hence
\[p(x)=2^8(x+1)^8=256x^8+2048x^7+\cdots,\]
which has the single root $x=-1$ with multiplicity $8$. The sum of the roots counted with multiplicity is $8\cdot(-1)=-8$ (by Vieta's formulas, $-\dfrac{2048}{256}=-8$), and its absolute value is $\boxed{8}$.

(The equation has only one distinct solution, $x=-1$; if repeated roots were counted once, the answer would be $1$.)
