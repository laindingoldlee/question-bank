The function $g(x)=10^{-x}-x-5$ is strictly decreasing because $g^{\prime}(x)=-(\ln10)10^{-x}-1<0$. Also $g(-1)=6>0$ and $g(0)=-4<0$, so there is exactly one real solution, in $(-1,0)$. For an exact special-function form, put $y=x+5>0$. Then $y e^{(\ln10)y}=10^5$, giving $\boxed{y = \dfrac{W (10^5\ln10)}{\ln 10} , \quad x = y - 5}$, where $W(t)$ denotes the unique nonnegative $w$ satisfying $we^w=t$. This equation does not reduce to a usual elementary logarithmic formula.
