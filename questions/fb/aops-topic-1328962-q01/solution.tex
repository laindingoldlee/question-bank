Use the Euclidean algorithm.
\begin{itemize}
\item A: $629-391=238$, $391-238=153$, $238-153=85$, $153-85=68$, $85-68=17$, $68=4\cdot17$: $\gcd=17$.
\item B: $2501-2\cdot1159=183$, $1159-6\cdot183=61$, $183=3\cdot61$: $\gcd=61$.
\item C: $1007-667=340$, $667-340=327$, $340-327=13$, $327=25\cdot13+2$, $13=6\cdot2+1$: $\gcd=1$.
\item D: $2001-1403=598$, $1403-2\cdot598=207$, $598-2\cdot207=184$, $207-184=23$, $184=8\cdot23$: $\gcd=23$.
\end{itemize}
Only pair $\boxed{\text{C}}$ is relatively prime ($1007=19\cdot53$, $667=23\cdot29$).
