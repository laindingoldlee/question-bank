Alice and Bob run around a circular track at constant speeds, Alice clockwise and Bob counterclockwise, starting from the same point at the same time. Exactly $\dfrac{70}{27}$ seconds after the start, Alice and Bob pass each other. After $60$ seconds Alice has completed $15$ laps (but not $16$) and Bob has completed $8$ laps (but not $9$). The maximum possible speed of Alice, in laps per second, is $\dfrac {m}{n}$, where $m$ and $n$ are relatively prime positive integers. What is $m+n$?

$\textbf{(A) } 5 \qquad \textbf{(B) } 44 \qquad \textbf{(C) } 263 \qquad \textbf{(D) } 527 \qquad \textbf{(E) } 529$
