Let one lap be $L$ miles. After $t$ hours the fish with speed $k$ has swum $\dfrac{kt}{L}$ laps, and it is at the starting point exactly when this is an integer. All five are at the start when $\dfrac{kt}{L}$ is an integer for $k=1,2,3,4,5$; for $k=1$ this says $\dfrac tL$ is an integer, and then all the others are integers too. So the first time is $t=L$ hours (the least common multiple of the lap times $L,\dfrac L2,\dots,\dfrac L5$), when the slowest fish has swum one lap and the fastest fish has swum $\boxed{5}$ laps.
