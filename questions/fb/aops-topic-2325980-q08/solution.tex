We need $N\equiv6\pmod{13}$, $N\equiv7\pmod{10}$ and $N\equiv0\pmod7$.

From the last two: $N=7m$ with $7m\equiv7\pmod{10}$, so $m\equiv1\pmod{10}$ and $N\equiv7\pmod{70}$. Write $N=7+70t$. Then $7+70t\equiv6\pmod{13}$; since $70\equiv5\pmod{13}$, this is $5t\equiv-1\equiv12\pmod{13}$. The inverse of $5$ modulo $13$ is $8$ ($5\cdot8=40=3\cdot13+1$), so $t\equiv96\equiv5\pmod{13}$ and $N\equiv7+350=357\pmod{910}$.

The smallest possibility is $357$, and the second smallest is $357+910=\boxed{1267}$. (Check: $1267=13\cdot97+6=10\cdot126+7=7\cdot181$.)
