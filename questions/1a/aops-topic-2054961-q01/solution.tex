Since $a$ is a root, $a^2=5a+10$. By Vieta's formulas, $a+b=5$. Therefore
\[a^2+b=5a+10+b=4a+(a+b)+10=4a+15 .\]
The value depends on which root is called $a$. The roots are $\dfrac{5\pm\sqrt{65}}{2}$, so
\[4a+15=2\left(5\pm\sqrt{65}\right)+15=25\pm2\sqrt{65}.\]
The possible values are $\boxed{25+2\sqrt{65}\ \text{and}\ 25-2\sqrt{65}}$; these are $a^2+b$ for $a=\dfrac{5+\sqrt{65}}{2}$ and for $a=\dfrac{5-\sqrt{65}}{2}$, respectively.
