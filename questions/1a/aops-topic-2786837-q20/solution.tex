The number of choices is $TS+T+S=50$, so $(T+1)(S+1)=51=3\cdot17$. Since $S\ge1$, $S+1\ge2$, so $S+1=3$ and $T+1=17$. Thus $T=16$, $S=2$ and $T-S=\boxed{14}$.
