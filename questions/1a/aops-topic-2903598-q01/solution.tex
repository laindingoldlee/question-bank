If $2x+1>0$: $x^2-10x-6=0$, so $x=5\pm\sqrt{31}$; only $5+\sqrt{31}$ has $2x+1>0$. If $2x+1<0$: $x^2+10x+4=0$, so $x=-5\pm\sqrt{21}$; only $-5-\sqrt{21}$ has $2x+1<0$. The solutions are $\boxed{x=5+\sqrt{31}\text{ or }x=-5-\sqrt{21}}$.
