The disk radius satisfies $r^2=\dfrac{1000}{\pi}$. The square diagonal has length $n\sqrt2$, so containment requires $n\sqrt2\le2r$. This is also sufficient by centering the square in the disk. Thus $n^2\le\dfrac{2000}{\pi}$. Since $625<\dfrac{2000}{\pi}<676$, the largest possible integer is $\boxed{25}$.
