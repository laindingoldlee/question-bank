After $k$ complete sets the number of blue beads is $\sum_{n=1}^k\dfrac{n(n+1)}2=\dfrac{k(k+1)(k+2)}{6}$. For $k=21$ this is $1771$; for $k=22$ it is $2024$. So the $2012$th blue bead is the $2012-1771=241$st blue bead of set $22$.

After $21$ sets there are $21$ red, $1+\cdots+21=231$ white and $1771$ blue beads: $2023$ beads. Set $22$ then contributes $1+22+241=264$ beads. The total is $2023+264=\boxed{2287}$.
