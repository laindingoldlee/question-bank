Mary strings beads in sets. The $n$th set consists of $1$ red bead, then $n$ white beads, then $\dfrac{n(n+1)}{2}$ blue beads. So she starts with red, white, blue; then $1$ red, $2$ white, $3$ blue; then $1$ red, $3$ white, $6$ blue; and so on. When she places the $2012$th blue bead, how many beads are on the string in total?
