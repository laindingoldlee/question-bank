Factor: $xy-3x+5y-15=-15$, i.e.
\[(x+5)(y-3)=-15.\]
Each integer divisor $d$ of $-15$ gives exactly one solution, $x+5=d$, $y-3=-\dfrac{15}{d}$. There are $8$ divisors ($\pm1,\pm3,\pm5,\pm15$), so there are $\boxed{8}$ pairs.
