Take the numbers to be $1,2,\dots,50$. There are $\dbinom{50}{2}=1225$ equally likely unordered pairs. Count each pair once, by its smaller number $i$: the larger number can be $i+1,\dots,i+10$ if $i\le40$ ($10$ choices) and $i+1,\dots,50$ if $41\le i\le49$ ($50-i$ choices). So the number of favourable pairs is
\[40\cdot10+(9+8+\cdots+1)=400+45=445,\]
and the probability is $\dfrac{445}{1225}=\boxed{\dfrac{89}{245}}$.

(This is why each ticket contributes only $10$: counting partners on both sides, up to $20$ per ticket, counts every pair twice. That count, $890$ ordered pairs, must be compared with the $50\cdot49=2450$ ordered draws, which gives the same answer.)
