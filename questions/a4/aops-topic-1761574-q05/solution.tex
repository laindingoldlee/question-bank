Write the $i$-th child's number of gifts as $2y_i+1$ with $y_i\ge0$. Then $\sum(2y_i+1)=25$ gives $y_1+\cdots+y_5=10$, which by stars and bars has $\dbinom{14}{4}=1001$ solutions. So $N=1001$ and $9N-8=\boxed{9001}$.
