Let $S,U>0$ be the sold and unsold apartment counts, and let $n$ be the number of equal-sized entrances. Then $S+U=n(\dfrac{S}{5}+\dfrac{U}{7})$. Because both counts are positive, the right-hand average per entrance puts $5<n<7$. The only integer is $\boxed6$. Feasibility follows, for example, from $S=5k,U=7k$: each entrance has $2k$ units, including $k$ of each status in the first entrance.
