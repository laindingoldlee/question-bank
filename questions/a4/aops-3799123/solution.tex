Write $N=100a+10b+c$. If no digit is zero, each digit occurs twice in each place, so $S=22(a+b+c)$. Hence $89a=b+10c$. Since $b+10c\le98$, $a=1$; then $b+10c=89$, giving $b=9,c=8$, or $N=198$. If $b=0$, the allowed integers sum to $21(a+c)$, so $179a=19c$, impossible for nonzero digits $a,c\le9$. If $c=0$, similarly $21(a+b)=200a+20b$, giving $b=179a$, impossible. Therefore $\boxed{198}$ is the only solution; its six two-digit numbers sum to $396$.
