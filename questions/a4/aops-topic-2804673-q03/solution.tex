Each rook occupies a row and a column that no later rook may use, and a move is available exactly while some row and some column are both unused (their intersection is then free and unattacked). So every game lasts exactly $8$ moves, whatever the players do, and the second player makes the last move. The $\boxed{\text{second player}}$ always wins.
