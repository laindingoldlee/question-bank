The equation has a real root exactly when its discriminant is nonnegative:
\[49+4ac\ge0,\qquad\text{that is,}\qquad c\ge-\dfrac{49}{4a}\quad(\text{as }a>0).\]
Since $a>3$, we have $\dfrac{49}{4a}<\dfrac{49}{12}$, so $c>-\dfrac{49}{12}=-4\dfrac{1}{12}$. As $c$ is an integer, $c\ge-4$.

The value $c=-4$ is possible: it needs $-4\ge-\dfrac{49}{4a}$, that is, $a\le\dfrac{49}{16}=3.0625$. For example, $a=\dfrac{49}{16}$ gives $\dfrac{49}{16}x^2+7x+4=\left(\dfrac{7}{4}x+2\right)^2$, with the double root $x=-\dfrac{8}{7}$. So the least possible value is $\boxed{-4}$.

\emph{Remark.} If $a$ had to be an integer, then $a\ge4$ and $c\ge-\dfrac{49}{16}$, so the least value would be $-3$.
