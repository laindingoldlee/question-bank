We have $10!=2^8\cdot3^4\cdot5^2\cdot7$.

\textbf{Positive quadruples.} Each prime's exponent is shared out among $a,b,c,d$ independently. The number of ways to write an exponent $e$ as an ordered sum of four nonnegative integers is $\dbinom{e+3}{3}$ (stars and bars). So the number of positive quadruples is
\[\dbinom{11}{3}\dbinom{7}{3}\dbinom{5}{3}\dbinom{4}{3}=165\cdot35\cdot10\cdot4=231000.\]
\textbf{Signs.} The product is positive, so an even number of the four entries is negative: $\dbinom40+\dbinom42+\dbinom44=8$ sign patterns.

The total is $231000\cdot8=\boxed{1848000}$.
