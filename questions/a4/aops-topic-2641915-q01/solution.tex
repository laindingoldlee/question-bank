Split the sum of $1$ to $n+r+1$ into three blocks and use the hypothesis:
\[(1+\cdots+n)+(n+1)+\left((n+2)+\cdots+(n+r+1)\right)=2\cdot\dfrac{n(n+1)}{2}+(n+1)=(n+1)^2.\]
With $m=n+r+1$ this says $\dfrac{m(m+1)}{2}=(n+1)^2$, i.e.
\[m(m+1)=2(n+1)^2.\]
Suppose $p=n+1$ is prime. Since $\gcd(m,m+1)=1$, $p$ divides exactly one of $m,m+1$, so $p^2$ divides that one.
\begin{itemize}
\item If $p^2\mid m$, then $m\ge p^2$ and $m(m+1)>p^4\ge2p^2$.
\item If $p^2\mid m+1$, then $m+1\ge p^2$, $m\ge p^2-1\ge3$, and $m(m+1)\ge3p^2>2p^2$.
\end{itemize}
Both contradict $m(m+1)=2p^2$. Since $n+1\ge2$ and it is not prime, it is composite. $\blacksquare$

(Example: $n=5$, $r=2$: $1+2+3+4+5=15=7+8$, and $n+1=6$.)
