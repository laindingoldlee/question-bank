Since $n\equiv-3\pmod{n+3}$, we get $n^2+7\equiv(-3)^2+7=16\pmod{n+3}$. (Equivalently, $n^2+7=(n+3)(n-3)+16$.) So $n+3$ divides $n^2+7$ exactly when $n+3$ divides $16$. For positive $n$, $n+3\ge4$, so $n+3\in\{4,8,16\}$ and $n\in\{1,5,13\}$:
\[1+3=4\mid8,\qquad 5+3=8\mid32,\qquad 13+3=16\mid176.\]
There are $\boxed{3}$ such integers.

The congruence $n\equiv1\pmod{n+3}$ would mean $n+3\mid n-1$, hence $n+3\mid4$, giving only $n=1$; it loses the solutions $5$ and $13$, so it does not follow from $n^2-n+4\equiv0\pmod{n+3}$. The correct reduction uses $n\equiv-3$: $n^2-n+4\equiv9+3+4=16$.
