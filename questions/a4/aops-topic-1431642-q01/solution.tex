The negative three-digit integers are $-999,\dots,-100$; we want the one closest to $0$ with remainder $1$ on division by $18$. Since $-100=18\cdot(-6)+8$, we have $-100\equiv8\pmod{18}$, so we must go down $7$ more:
\[
-107=18\cdot(-6)+1\equiv1\pmod{18}.
\]
None of $-100,\dots,-106$ works (they are $\equiv8,7,\dots,2$), so the answer is $\boxed{-107}$.
