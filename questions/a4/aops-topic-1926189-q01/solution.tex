If $5\mid k^2$, then $5\mid k$ because $5$ is prime; so the squares in question are $(5j)^2=25j^2$ with $j\ge1$. The condition $25j^2<90000$ means $j^2<3600$, i.e.\ $j\le59$. So there are $\boxed{59}$ such squares.
