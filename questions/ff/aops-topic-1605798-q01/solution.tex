Work backwards, undoing each step. Before the last subtraction of $\dfrac{1}{2}$ the value was $10+\dfrac{1}{2}=\dfrac{21}{2}$; before halving it was $21$; before the first subtraction of $\dfrac{1}{2}$ it was $21+\dfrac{1}{2}=\dfrac{43}{2}$; and before the first halving it was $n=\boxed{43}$.

Check: $\dfrac{43}{2}-\dfrac{1}{2}=21$, then $\dfrac{21}{2}-\dfrac{1}{2}=10$.
