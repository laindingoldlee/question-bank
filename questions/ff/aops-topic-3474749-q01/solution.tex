There are five choices for each digit in $x$, so $x=5^{12}$. If leading zeros were allowed in the eleven-digit strings, there would be $\binom{11}{5}5^{11}$. Invalid strings with first digit zero number $\binom{10}{4}5^{10}$. Therefore $\dfrac{y}{x}=\dfrac{5\binom{11}{5}-\binom{10}{4}}{25}=\dfrac{2310-210}{25}=\boxed{84}$.
