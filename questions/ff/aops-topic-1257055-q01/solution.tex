There are $\dbinom{12}{5}=792$ equally likely selections. Count those missing some kind, by inclusion--exclusion:
\begin{itemize}
\item no T-shirt: $\dbinom95=126$; no jacket: $\dbinom85=56$; no long shirt: $\dbinom75=21$;
\item missing two kinds: only long shirts, $\dbinom55=1$ (only jackets or only T-shirts is impossible with $5$ garments).
\end{itemize}
So $126+56+21-1=202$ selections miss a kind, and the probability is
\[\dfrac{792-202}{792}=\dfrac{590}{792}=\boxed{\dfrac{295}{396}}.\]
The attempted count $3\cdot4\cdot5\cdot\dbinom92$ overcounts: a selection with, say, two T-shirts is counted once for each choice of which T-shirt is ``the'' T-shirt, so selections are counted up to $8$ times.
