I start with one fair four-sided die (faces $1,2,3,4$). In each move I roll all the dice I have and compute the sum $S$ of the values. If $S\ge4$, I stop. Otherwise I gather dice so that I now have exactly $S$ dice, and I make another move. What is the expected number of moves?
