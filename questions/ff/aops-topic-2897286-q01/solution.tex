Suppose not. By symmetry assume $1$ is red, and let $b\ge2$ be the smallest blue number, so $1,2,\dots,b-1$ are red.

Let $x$ be blue. Then $x+b$ is a blue sum, so it is not a red sum. For each red $r\in\{1,\dots,b-1\}$, $x+b=r+(x+b-r)$, so $x+b-r$ must be blue. Hence $x+1,x+2,\dots,x+b-1$ are all blue.

Starting from $x=b$, then $x=b+1$, and so on, every integer $\ge b$ is blue. This contradicts there being infinitely many red numbers. $\blacksquare$
