The domain has $x\ge1$. Squaring yields $2\sqrt{x(x-1)}=2-x$, so $x\le2$. Squaring again gives $4x(x-1)=(2-x)^2$, or $3x^2=4$. The positive value $x=\dfrac{2}{\sqrt3}$ lies in $[1,2]$, where both sides of the prior squared equations are nonnegative, so it is valid. Thus $x^2=\dfrac{4}{3}$ and $\boxed{m+n=7}$.
