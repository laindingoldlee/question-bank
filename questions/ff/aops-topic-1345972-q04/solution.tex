Let $T$ be the roll on which the pattern $1,2,3,4,5,6$ is first completed, and let $p=\dfrac{1}{6^6}$, the probability that six given consecutive rolls form the pattern.

\textbf{Key property.} The pattern cannot overlap a shifted copy of itself: no proper ending of $123456$ is a beginning of it (an ending would start with $2,3,\dots,6$, a beginning starts with $1$). So two occurrences of the pattern ending at rolls $n'<n$ must satisfy $n'\le n-6$.

\textbf{An equation for $P(T=n)$.} Fix $n\ge6$. The pattern occupies rolls $n-5,\dots,n$ with probability $p$. If it does, then either this is the first occurrence ($T=n$), or the first occurrence ended earlier, and by the key property $T\le n-6$. Conversely, the event $\{T=k\}$ depends only on rolls $1,\dots,k$, which for $k\le n-6$ are independent of rolls $n-5,\dots,n$. Hence
\[
p=P(T=n)+\sum_{k\le n-6}P(T=k)\,p=P(T=n)+p\,P(T\le n-6),
\]
so $P(T=n)=p\,P(T>n-6)$ for every $n\ge6$.

\textbf{Summing.} $T$ is finite with probability $1$ (the disjoint blocks of rolls $1$-$6$, $7$-$12$, \dots\ each contain the pattern with probability $p$, independently), so summing over $n\ge6$,
\[
1=\sum_{n\ge6}P(T=n)=p\sum_{j\ge0}P(T>j)=p\,E[T].
\]
Therefore $E[T]=\dfrac{1}{p}=6^6=\boxed{46656}$.
