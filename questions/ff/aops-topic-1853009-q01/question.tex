In the notation $N_b$, the subscript $b$ is the base in which the digits of $N$ are written; for example $12_3=1\cdot3+2=5$.
\begin{enumerate}
\item[(a)] A student asks whether $55_3$ means ``the number fifty-five written in base $3$'' or $5\cdot3^1+5\cdot3^0$. Which reading matches the notation, and why is $55_3$ not actually a valid base-$3$ numeral?
\item[(b)] Write the number fifty-five in base $3$.
\end{enumerate}
