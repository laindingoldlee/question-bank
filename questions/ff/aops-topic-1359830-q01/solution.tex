A counterexample needs only one move. Let the pirates have $1,2,3,\dots,13$ gold coins, all different, with total $91$ and average $7$. Let the $12$ pirates other than the one with $7$ coins pool their gold: they have $91-7=84$ coins, so each receives $\dfrac{84}{12}=7$. Now all $13$ pirates have $7$ coins. So the claim is $\boxed{\text{false}}$.

More generally, all pirates can be made equal in one move whenever one pirate already holds exactly the average amount. (Also, without that, two moves often suffice: for example, first equalise a suitable group so that some pirate reaches the overall average, then pool the other twelve.)
