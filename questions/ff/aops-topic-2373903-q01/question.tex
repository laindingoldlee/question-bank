What is printed when the following program is run? (The operation \texttt{\textasciicircum} is exponentiation and is done before \texttt{*} and \texttt{/}, which are done from left to right; \texttt{int(x)} is the integer part of \texttt{x}.)
\begin{center}
\begin{tabular}{l}
\texttt{a = 20: b = 5: c = 2}\\
\texttt{d = a / b}\\
\texttt{e = c \textasciicircum{} 2 * a / b}\\
\texttt{if e > a then a = e - a}\\
\texttt{if d / 2 = int(d / 2) then b = a / c}\\
\texttt{if b = e then e = e - 2 else b = 2 * b}\\
\texttt{if d * c < a * b then a = d - c else c = d + c}\\
\texttt{print (c + d) / a - b / a + e}\\
\texttt{end}
\end{tabular}
\end{center}
