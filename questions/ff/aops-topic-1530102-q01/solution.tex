The two co-presidents have the same role, so the order of choosing them does not matter. The number of ways is
\[
\dbinom{15}{2}=\dfrac{15\cdot14}{2}=\boxed{105}.
\]
(Choosing an ordered pair gives $15\cdot14=210$ and counts each pair twice.)
