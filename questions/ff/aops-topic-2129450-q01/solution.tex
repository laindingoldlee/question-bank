The numerator factors: $2x^4+38x^2+140=2\left(x^4+19x^2+70\right)=2\left(x^2+5\right)\left(x^2+14\right)$. Since $x^2+5>0$,
\[\dfrac{2x^4+38x^2+140}{x^2+5}+4=2\left(x^2+14\right)+4=2x^2+32\ge32,\]
with equality exactly when $x=0$. The smallest value is $\boxed{32}$.
