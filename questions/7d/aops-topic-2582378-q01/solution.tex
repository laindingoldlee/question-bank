\textbf{(a)} If $x$ is real, the real part of $x^2+ix+2i$ is $x^2$ and the imaginary part is $x+2$. Both would have to be $0$, giving $x=0$ and $x=-2$ at once, which is impossible. So there is no real solution. (Its discriminant $i^2-8i=-1-8i$ is not real, so it has no sign at all.)

\textbf{(b)} The discriminant is $(2i)^2-4\cdot(-2)=-4+8=4>0$. But the quadratic formula, which is valid for complex coefficients, gives
\[x=\dfrac{-2i\pm2}{2}=1-i\quad\text{or}\quad-1-i,\]
and neither is real.

\textbf{(c)} $x^2-(1+i)x+i=(x-1)(x-i)$, so $x=1$ is a real solution. The discriminant is $(1+i)^2-4i=2i-4i=-2i$.

So for non-real coefficients the discriminant cannot be used to decide whether the roots are real. The reason is that the argument behind the test (the roots are $\dfrac{-p\pm\sqrt{p^2-4q}}2$, with $p$ real) needs $p$ and $q$ to be real.
