The numbers start
\[
1,\ 9,\ 17,\ 14,\ 11,\ 8,\ 16,\ 13,\ 10,\ 7,\ 15,\ 12,\ 9,\ \dots
\]
From the second student on, the numbers repeat with period $11$: $9,17,14,11,8,16,13,10,7,15,12$. Student $k\ge2$ says the $(k-1)$th term of this cycle (counting from $1$, modulo $11$). For $k=2010$, $k-1=2009=11\cdot182+7$, so the last student says the $7$th term of the cycle, which is $\boxed{13}$.
