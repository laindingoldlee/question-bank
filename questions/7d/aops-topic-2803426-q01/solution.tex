By induction, $1^3+\cdots+n^3=\left(\dfrac{n(n+1)}2\right)^2$: true for $n=1$, and if true for $n-1$ then adding $n^3$ gives $\dfrac{n^2(n-1)^2}4+n^3=\dfrac{n^2\big((n-1)^2+4n\big)}4=\dfrac{n^2(n+1)^2}4$. Since $\dfrac{n(n+1)}2$ is an integer, the sum is a perfect square. $\blacksquare$
