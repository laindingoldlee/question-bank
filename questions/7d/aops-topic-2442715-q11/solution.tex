Cross-multiplying, $5(10x-3y)=3(13x-2y)$, i.e. $50x-15y=39x-6y$, so $11x=9y$. Hence
\[x:y=\boxed{9:11}.\]
(Then $13x-2y=\dfrac{117y-22y}{11}=\dfrac{95y}{11}\ne0$ for $y\ne0$, so the fraction is defined.)
