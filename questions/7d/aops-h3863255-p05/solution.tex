Except for events of probability zero, if a semicircle contains the three points, exactly one point starts a clockwise semicircle containing the other two. For each specified starting point, the probability is $(\dfrac{1}{2})^2$. The three events are disjoint, so the probability is $3\cdot\dfrac{1}{4}=\boxed{\dfrac{3}{4}}$. The uniqueness follows because the complementary gap between consecutive points is greater than a semicircle, and there is at most one such gap.

texpreamble("\usepackage{amsmath,amssymb}");

draw(unitcircle); pair A=dir(10),B=dir(55),C=dir(140); dot(A);dot(B);dot(C);label("$A$",A,(1,0));label("$B$",B,(1,1));label("$C$",C,(-1,1));draw(A--(-A),dashed);
\end{asy}
