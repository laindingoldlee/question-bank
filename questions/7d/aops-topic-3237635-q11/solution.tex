Write $x=k+t$ with $k$ integer and $0\le t<1$. The equation becomes $k=99t+50$, so $50\le k<149$. Conversely every integer $k=50,\ldots,148$ determines the valid $t=\dfrac{k-50}{99}$. Thus there are $\boxed{99}$ solutions.
