A relation is a function when no input is paired with two \emph{different} outputs. Listing the same ordered pair twice does not create a new pair: as a set, the relation is
\[
\{(-6,-8),(-4,-1),(8,6),(1,8)\},
\]
and the inputs $-6,-4,8,1$ are all different. So $\boxed{\text{yes, it is a function}}$, with domain $\{-6,-4,1,8\}$ and range $\{-8,-1,6,8\}$.

(It would not be a function if it contained, say, both $(8,6)$ and $(8,7)$. Two inputs with the same output, such as $(1,8)$ and $(-6,8)$, would still be fine.)
