\textbf{(C) is never prime.} If $p=2$, then $p^2+26=30$. If $p=3$, then $p^2+26=35=5\cdot7$. If $p>3$, then $p$ is not a multiple of $3$, so $p\equiv\pm1\pmod3$ and $p^2\equiv1\pmod3$; hence $p^2+26\equiv27\equiv0\pmod3$, and $p^2+26>3$ is composite.

\textbf{The others can be prime:} $5^2+16=41$, $7^2+24=73$, $5^2+46=71$ and $19^2+96=457$ are primes.

The answer is $\boxed{\textbf{(C)}}$.

(A good way to find this quickly: every prime $p>3$ has $p^2\equiv1\pmod3$, so $p^2+k$ is a multiple of $3$ for all such $p$ exactly when $k\equiv2\pmod3$; among $16,24,26,46,96$ only $26$ has this property.)
