Let $k=\dfrac {p}{q}=\dfrac {r}{s}$, so $p=kq$ and $r=ks$. Then
\[
\dfrac{p^2+q^2}{r^2+s^2}=\dfrac{(k^2+1)q^2}{(k^2+1)s^2}=\boxed{\dfrac{q^2}{s^2}}
\]
(and $k^2+1>0$, so nothing is divided by zero). This depends on $q$ and $s$: for example $p=q=r=s=1$ gives $1$, while $p=1$, $q=2$, $r=2$, $s=4$ gives $\dfrac{1+4}{4+16}=\dfrac{1}{4}$. So the value is not determined by the condition alone, and the student's answer $\dfrac{1}{4}$ is correct exactly when $\dfrac{q^2}{s^2}=\dfrac{1}{4}$, i.e.\ when $q=\pm\dfrac {s}{2}$ (for instance if the exam also gave $s=2q$).
