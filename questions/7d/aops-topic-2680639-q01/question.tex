A student proposes the definition: ``A positive integer $k$ is prime if and only if $\gcd(k,m)=1$ for every integer $m$ with $1<m<k$.'' Prove that this agrees with the usual definition of a prime for every $k\ge2$, and find the positive integer(s) for which it disagrees.
