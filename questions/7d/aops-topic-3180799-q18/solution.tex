Fix its starting vertex. The first edge must connect to a neighbour on the convex hull: a diagonal would separate unvisited vertices onto both sides, and after leaving the starting endpoint the path could not visit both sides without crossing that first edge. Remove the start and apply the same reasoning to the remaining convex polygon. At each stage with at least three vertices there are exactly two choices for the next vertex, the two hull neighbours of the current one; at the final two vertices the choice is forced. Conversely these choices produce a noncrossing path, since each removed edge is a boundary edge of the remaining hull. There are $2^6=64$ orders per fixed start, among $7!$ equally likely orders. The probability is $\boxed{\dfrac{4}{315}}$.
