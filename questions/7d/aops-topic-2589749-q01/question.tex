John is getting ready to run a marathon. He ran a certain distance every day for the last $7$ days: on $2$ of the days he ran $8$ miles each day, on $2$ other days he ran $10$ miles each day, and on the remaining days he ran $12$ miles each day. How many miles did he run in total over the week?
