Suppose some ladder $w_0=\text{SHIP},w_1,\dots,w_m=\text{DOCK}$ has no word with exactly two vowels. We show by induction that every $w_i$ has exactly one vowel, in position $3$.

This holds for $w_0=\text{SHIP}$. Suppose it holds for $w_i$, and $w_{i+1}$ differs from $w_i$ in position $j$.
\begin{itemize}
\item If $j=3$, positions $1,2,4$ of $w_{i+1}$ are the consonants of $w_i$; as $w_{i+1}$ has a vowel, it is in position $3$, and it is the only one.
\item If $j\ne3$, position $3$ still holds a vowel and the other unchanged positions hold consonants. If the new letter were a vowel, $w_{i+1}$ would have exactly two vowels, which we excluded. So $w_{i+1}$ again has exactly one vowel, in position $3$.
\end{itemize}
But DOCK has its only vowel in position $2$ and the consonant C in position $3$. This contradiction shows that some word has exactly two vowels. $\blacksquare$

(The example ladder has SOOT, LOOT and LOOK.)
