Write the number as $10t+d$, where $t$ is its first three digits. Deleting the last digit requires $t\mid d$. Since $t\ge100$ and $0\le d\le9$, $d=0$. Write the number as $100u+10c$, with $u$ its first two digits. Deleting the third digit gives $10u$, so $u\mid c$; as $u\ge10$, $c=0$. The number is therefore $1000a+100b$. Deleting the first digit requires $b\ne0$ and $b\mid10a$; deleting the second requires $a\mid b$. Put $b=ka$. Then $k\mid10$ and $ka\le9$, so $k=1,2,5$. These allow respectively $9,4,1$ values of $a$. All other deletions also work for these numbers. The answer is $\boxed{14}$.
