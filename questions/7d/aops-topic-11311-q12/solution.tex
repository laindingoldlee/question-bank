One hour in SP mode uses $\dfrac{1}{2}$ of the tape, one hour in LP mode uses $\dfrac{1}{4}$, and one hour in EP mode uses $\dfrac{1}{6}$. Together
\[
\dfrac{1}{2}+\dfrac{1}{4}+\dfrac{1}{6}=\dfrac{6+3+2}{12}=\dfrac{11}{12}
\]
of the tape is used, leaving $\dfrac{1}{12}$ of it. In SP mode the whole tape holds $120$ minutes, so $\dfrac{1}{12}\cdot120=\boxed{10}$ minutes remain.
