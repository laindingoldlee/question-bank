Student $2$ closing every second locker is the same as toggling it, since all were open. Locker $n$ is toggled once for each divisor of $n$, so it ends open iff $n$ has an odd number of divisors. Divisors pair up as $d\leftrightarrow\dfrac nd$, and a divisor is unpaired only when $d=\dfrac nd$, so this happens iff $n$ is a perfect square. There are $31$ squares up to $1000$ ($31^2=961<1000<1024$). So the principal closes $\boxed{31}$ lockers.
