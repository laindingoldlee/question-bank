Divide by $4^x>0$: $1+\left(\dfrac32\right)^x=\left(\dfrac94\right)^x=\left(\left(\dfrac32\right)^x\right)^2$. With $t=\left(\dfrac32\right)^x>0$ this is $t^2-t-1=0$, whose only positive root is $t=\dfrac{1+\sqrt5}2$. Hence
\[x=\boxed{\dfrac{\ln\dfrac{1+\sqrt5}{2}}{\ln\dfrac32}}\approx1.1868,\]
i.e. $x=\log_{\dfrac32}\dfrac{1+\sqrt5}2$, and this is the only solution.
