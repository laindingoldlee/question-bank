Double count pairs (three-digit number, distinct canonical substring). For single digits, each nonzero digit occurs in $900-8\cdot 9^2=252$ numbers, while 0 occurs in $900-9^3=171$, giving $9(252)+171=2439$. For two-digit substrings, all 900 prefixes count, and 810 suffixes have a nonzero first digit. The prefix and suffix coincide only in the nine numbers 111 through 999 with equal digits, so count $900+810-9=1701$. Each number contributes its own three-digit substring, giving 900 more. Total pairs are 5040. The expectation is $\dfrac{5040}{1000}=\dfrac{126}{25}$, so $m+n=\boxed{151}$.
