\textbf{Counting proof.} Count the nonempty subsets of an $n$-element set. Each element is either in a subset or not, so there are $2^n$ subsets in all, and $2^n-1$ nonempty ones. On the other hand, the number of subsets with exactly $k$ elements is $\dbinom nk$, so the number of nonempty subsets is $\dbinom n1+\dbinom n2+\cdots+\dbinom nn$. The two counts agree. $\blacksquare$

\textbf{Algebraic proof.} By the binomial theorem,
\[
2^n=(1+1)^n=\sum_{k=0}^{n}\dbinom nk1^k1^{n-k}=\dbinom n0+\dbinom n1+\cdots+\dbinom nn ,
\]
and $\dbinom n0=1$. Subtracting $1$ gives the result. For example, for $n=4$: $4+6+4+1=15=2^4-1$.
