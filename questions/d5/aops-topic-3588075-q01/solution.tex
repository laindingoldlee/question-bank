Six divisors require $M=p^5$ or $M=p^2q$ for distinct primes $p,q$. In the first case the divisor sum is $1+p+\cdots+p^5$. For primes $p=2,3$ this is $63,364$, and for $p\ge5$ it is at least $3906$, so this case is impossible. In the second case, $(p^2+p+1)(q+1)=3500$. The odd factor $p^2+p+1$ must divide $875$ and therefore belongs to $\{1,5,7,25,35,125,175,875\}$. Solving $p^2+p+1=d$ for these values (or checking whether $4d-3$ is an odd square) gives only $d=7,p=2$. Hence $q+1=500$, $q=499$, which is prime by trial division through $\sqrt{499}<23$. Therefore $\boxed{M=2^2\cdot499=1996}$.
