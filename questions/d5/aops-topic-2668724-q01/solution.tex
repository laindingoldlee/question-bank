By definition, $1-(-1)=1+\bigl(-(-1)\bigr)$, where $-(-1)$ is the number that gives $0$ when added to $-1$.

\emph{Additive inverses are unique.} If $y+b=0$ and $z+b=0$, then $y=y+\bigl(b+z\bigr)=(y+b)+z=z$.

Since $(-1)+1=1+(-1)=0$, the number $1$ is an additive inverse of $-1$, so $-(-1)=1$. Therefore $1-(-1)=1+1=2$. $\blacksquare$
