A one-digit number $n$ would need $n=7n$, so $n=0$, which is not positive. For a two-digit number $\overline{ab}=10a+b$ we need $10a+b=7(a+b)$, i.e. $3a=6b$, or $a=2b$. With $b\ge1$ the possibilities are $21,42,63,84$, and the smallest is $\boxed{21}$ (indeed $2+1=3$ and $7\cdot3=21$). All numbers with more digits are larger.
