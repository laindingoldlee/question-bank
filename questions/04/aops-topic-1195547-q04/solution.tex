Each year multiplies the amount by $1.075$, so after $4$ years the value is $1000\cdot1.075^4$. Compute $1.075^2=1.155625$ and $1.155625^2=1.335469\ldots$, so the value is $\$1335.47\ldots\approx\boxed{\$1335}$.
