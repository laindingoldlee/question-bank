$256=2^8=4^4$, so $x=4$ works. It is the only positive solution: for $0<x\le1$, $x^x\le1$; for $x\ge1$, increasing $x$ increases both the base and the exponent, so $x^x$ is increasing. The answer is $\boxed{4}$.
