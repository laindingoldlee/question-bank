Write the number as $100k+23$, where $10\le k\le99$. Divisibility by $3$ requires $k+2\equiv0\pmod3$, or $k\equiv1\pmod3$. These values are $10,13,\ldots,97$, giving $\dfrac{97-10}{3}+1=\boxed{30}$.
