Let $p=ab$. For positive $a,b$ with $a+b=x$ we have $0<p\le\dfrac{x^2}{4}$ by AM-GM, and every $p$ in this interval occurs (take $a,b$ to be the roots of $t^2-xt+p=0$, which are real and positive). So we minimise $f(p)=p+\dfrac{1}{p}$ on $0<p\le\dfrac{x^2}{4}$.

For $0<q<p$,
\[
f(p)-f(q)=(p-q)\left(1-\dfrac{1}{pq}\right),
\]
so $f$ is decreasing on $(0,1]$ and increasing on $[1,\infty)$, with minimum $f(1)=2$.
\begin{itemize}
\item If $x\ge2$, then $1\le\dfrac{x^2}{4}$, so $p=1$ is allowed and the minimum is $\boxed{2}$ (for instance $a,b$ the roots of $t^2-xt+1=0$).
\item If $0<x<2$, then $\dfrac{x^2}{4}<1$ and $f$ is decreasing on the whole interval, so the minimum is at $p=\dfrac{x^2}{4}$, that is $a=b=\dfrac {x}{2}$:
\[
\boxed{\dfrac{x^2}{4}+\dfrac{4}{x^2}} .
\]
\end{itemize}
