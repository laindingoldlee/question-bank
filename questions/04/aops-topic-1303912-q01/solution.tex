Any hill of length $h$ is run once uphill and once downhill, taking $\dfrac {h}{3}+\dfrac {h}{6}=\dfrac {h}{2}$ hours for $2h$ miles, which is exactly the time at $4$ mph. Level ground is also run at $4$ mph. So the whole $4$-hour run averages $4$ mph, and the total distance is $4\cdot4=\boxed{16\text{ miles}}$, however the route is made up.
