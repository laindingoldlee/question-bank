Let \(x\) wear only blue, so \(x+1\) wear only green; let \(y\) wear only red and \(z\) wear exactly red and blue. Green: \((x+1)+2=7\), so \(x=4\). Blue: \(x+z+2=8\), so \(z=2\). Red: \(y+z+2=5\), so \(y=1\). Check the total: \(4+5+1+2+2=14\). Exactly \(\boxed{1}\) guest wore only red.
