Let $a=\sqrt[3]{n}$, so $n=a^3$, and erasing the last three digits leaves $a$: $n=1000a+r$ with $0\le r\le999$. Hence
\[0\le a^3-1000a=a(a^2-1000)\le999.\]
We need $a^2\ge1000$, so $a\ge32$. For $a=32$: $32^3=32768=1000\cdot32+768$ \checkmark. For $a\ge33$: $a(a^2-1000)\ge33\cdot89>999$. So $n=\boxed{32768}$.
