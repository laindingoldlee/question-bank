Writing the number as $10a+b$ with $1\le a\le9$, $0\le b\le9$, test the two divisibilities. The complete finite list is 10,12,18,40,72,90, so the answer is $\boxed6$. The following exact enumeration certifies completeness.
\begin{verbatim}
good=[10*a+b for a in range(1,10) for b in range(10)
      if (10*a+b)%(a+1)==0 and (10*a+b)%(b+1)==0]
assert good==[10,12,18,40,72,90]
\end{verbatim}
