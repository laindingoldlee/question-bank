Let $N(s)$ be the number of the $6^4$ outcomes with sum $s$. Replacing each die value $d$ by $7-d$ turns sum $s$ into $28-s$, so $N(s)=N(28-s)$: the distribution is symmetric about $14$.

Count with stars and bars and inclusion-exclusion: writing each value as $1+e$ with $0\le e\le5$, the number of outcomes with sum $s$ is
\[N(s)=\dbinom{s-1}{3}-4\dbinom{s-7}{3}+6\dbinom{s-13}{3}-\cdots\]
(terms with negative top are $0$). For $s=4,5,\ldots,14$ this gives
\[1,\ 4,\ 10,\ 20,\ 35,\ 56,\ 80,\ 104,\ 125,\ 140,\ 146,\]
for example $N(14)=\dbinom{13}{3}-4\dbinom73=286-140=146$ and $N(13)=220-80=140$. These increase up to $s=14$, and by symmetry they decrease after it. So the most likely sum is $\boxed{14}$, with probability $\dfrac{146}{1296}=\dfrac{73}{648}$.
