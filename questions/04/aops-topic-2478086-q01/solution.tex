The elements of $S$ are $-2021+\dfrac k2$ for $k=0,1,\dots,8084$, so $|S|=8085$.

\begin{itemize}
\item $\lceil x\rceil-\lfloor x\rfloor$ is $0$ when $x$ is an integer and $1$ otherwise. So the first condition says $x$ is not an integer.
\item $\sqrt{x^2}=|x|$, so the second condition says $x\ge0$.
\end{itemize}
The winning elements are therefore $0.5,1.5,\dots,2020.5$, which is $2021$ numbers. The probability is
\[\boxed{\dfrac{2021}{8085}}.\]
This is in lowest terms, since $2021=43\cdot47$ and $8085=3\cdot5\cdot7^2\cdot11$.
