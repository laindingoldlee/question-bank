The equation requires $x\ne0$. Multiply both sides by $x$: $y=90x$. Then divide by $90$:
\[
\boxed{x=\dfrac{y}{90}} .
\]
Since $x\ne0$, this needs $y\ne0$; if $y=0$ there is no solution.
