The game is finite, so every position is winning or losing under optimal play. Suppose the initial position were losing. The first move $n$ would leave a winning position, in which the next player has some winning move $d\ne n$. But choosing $d$ immediately from the original position leaves exactly the same legal divisors as choosing $n$ and then $d$: since $d\mid n$, the move $d$ already forbids $n$. This would give a winning first move, a contradiction. Thus the first player wins. The proof works for any integer $n>1$; the exponent-pair board for $p^aq^b$ is the usual rectangular Chomp game with the $(0,0)$ corner forbidden.
