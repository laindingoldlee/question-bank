Ms.\ Bindergarten lines up all of her students in rows every day, with the same number of students in each row and no student left over. On day $1$ there are $44$ students in each row, and on day $2$ there are $24$ students in each row, and she has the least number of students for which this is possible. If she uses a different number of students per row every day, for how many days in total (including days $1$ and $2$) can she do this without repeating a row length?
