The label multiplicities are 2, 3, 2, 1, so the tie probability is $\dfrac{2^2+3^2+2^2+1^2}{64}=\dfrac{9}{32}$. By symmetry each strict ordering gets half the remaining probability. Hence $\boxed{\dfrac{23}{64}}$.
