Squaring means multiplication of the base by itself: $(\dfrac{1}{3})^2=\dfrac{1}{3}\cdot\dfrac{1}{3}=\boxed{\dfrac{1}{9}}$. The identity $(a^m)^n=a^{mn}$ changes the exponent, so $((\dfrac{1}{3})^1)^2=(\dfrac{1}{3})^2$, not $\dfrac{2}{3}$.
