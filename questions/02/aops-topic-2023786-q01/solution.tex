During the $n$th mile, $n-1$ miles have already been travelled, so the speed is $v_n=\dfrac{k}{n-1}$ miles per hour for some constant $k$. For the second mile, $v_2=k$, and covering $1$ mile takes $2$ hours, so $k=\dfrac{1}{2}$.

Hence $v_n=\dfrac{1}{2(n-1)}$, and the time for the $n$th mile is
\[
\dfrac{1}{v_n}=\boxed{2(n-1)}\text{ hours}.
\]
