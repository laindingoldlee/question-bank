Since $1<\dfrac{4}{a}$, $a\le3$; and $a\ge2$. If $a=3$, then $\dfrac{1}{b}+\dfrac{1}{c}+\dfrac{1}{d}\le\dfrac{1}{4}+\dfrac{1}{5}+\dfrac{1}{6}<\dfrac{2}{3}$; so $a=2$ and $\dfrac{1}{b}+\dfrac{1}{c}+\dfrac{1}{d}=\dfrac{1}{2}$, with $3\le b<6$.
\begin{itemize}
\item $b=3$: $\dfrac{1}{c}+\dfrac{1}{d}=\dfrac{1}{6}$, $(c-6)(d-6)=36$ with $c<d$: $(7,42),(8,24),(9,18),(10,15)$.
\item $b=4$: $\dfrac{1}{c}+\dfrac{1}{d}=\dfrac{1}{4}$, $(c-4)(d-4)=16$ with $4<c<d$: $(5,20),(6,12)$.
\item $b=5$: $\dfrac{1}{c}+\dfrac{1}{d}=\dfrac{3}{10}$ with $c\ge6$: then $\dfrac{1}{c}+\dfrac{1}{d}\le\dfrac{1}{6}+\dfrac{1}{7}<\dfrac{3}{10}$, none.
\end{itemize}
There are $\boxed{6}$ quadruples.
