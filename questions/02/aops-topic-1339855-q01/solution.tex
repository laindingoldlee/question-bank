The number of eggs is proportional both to the number of chickens and to the number of days. Going from $1.5$ to $13.5$ chickens multiplies the eggs by $9$, and going from $1.5$ to $13.5$ days multiplies them by $9$ again. So the answer is
\[
1.5\cdot9\cdot9=\boxed{121.5}\text{ eggs}.
\]
The pitfall is to answer $13.5$ by scaling only once. Per chicken per day the rate is $\dfrac{1.5}{1.5\cdot1.5}=\dfrac{2}{3}$ egg, and $13.5\cdot13.5\cdot\dfrac{2}{3}=121.5$.
