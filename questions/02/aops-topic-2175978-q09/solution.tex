Let $k=x-46$. Since $x^2-92x+2099=(x-46)^2-17$, the condition is
\[\left|k^2-17\right|+8=2^a3^b .\]
The left side is a positive integer, and $2^a3^b$ is an integer only when $a,b\ge0$ (if $a<0$ or $b<0$, the denominator $2^{-a}$ or $3^{-b}$ cannot cancel against the other prime). So we need $\left|k^2-17\right|+8$ to be \emph{$3$-smooth}, that is, of the form $2^a3^b$ with $a,b\ge0$.

\textbf{Lemma (consecutive $3$-smooth numbers).} If $m$ and $m+1$ are both $3$-smooth, then $m\in\{1,2,3,8\}$. Indeed, consecutive integers are coprime, so one of them is a power of $2$ and the other a power of $3$. If $2^i=3^j+1$: for $j=0$, $i=1$; for $j\ge1$, $2^i\equiv1\pmod3$ forces $i=2c$, and $(2^c-1)(2^c+1)=3^j$ makes $2^c-1$ and $2^c+1$ powers of $3$ differing by $2$, so they are $1$ and $3$, giving $3+1=4$. If $3^j=2^i+1$: $i=0$ is impossible, $i=1$ gives $3=2+1$, and for $i\ge2$, $3^j\equiv1\pmod4$ forces $j=2d$, and $(3^d-1)(3^d+1)=2^i$ makes them powers of $2$ differing by $2$, so they are $2$ and $4$, giving $9=8+1$.

\textbf{Case 1: $|k|\le4$.} Then $\left|k^2-17\right|+8=25-k^2\in\{25,24,21,16,9\}$ for $|k|=0,1,2,3,4$. The $3$-smooth values are $24$, $16$, $9$, so $|k|\in\{1,3,4\}$.

\textbf{Case 2: $|k|\ge5$.} Then $\left|k^2-17\right|+8=k^2-9=(|k|-3)(|k|+3)$, so $m=|k|-3\ge2$ and $m+6$ must both be $3$-smooth.
\begin{itemize}
\item If $m$ is odd, both $m$ and $m+6$ are odd, hence powers of $3$; the only such pair is $3,9$, so $m=3$.
\item If $m=2m'$, then $m'$ and $m'+3$ are $3$-smooth. If $3\mid m'$, write $m'=3m''$: then $m''$ and $m''+1$ are $3$-smooth, so $m''\in\{1,2,3,8\}$ and $m\in\{6,12,18,48\}$. If $3\nmid m'$, then $3\nmid m'+3$, so both are powers of $2$ differing by $3$, which forces $1$ and $4$; so $m=2$.
\end{itemize}
Thus $m\in\{2,3,6,12,18,48\}$ and $|k|\in\{5,6,9,15,21,51\}$ (for example $|k|=51$ gives $48\cdot54=2592=2^5\cdot3^4$).

\textbf{Collecting.} The possible values are $|k|\in\{1,3,4,5,6,9,15,21,51\}$, and $x=46\pm|k|$. Both signs give positive $x$ except for $|k|=51$, where only $x=97$ is positive. The eight values $|k|\le21$ give pairs $46\pm|k|$ with sum $92$ each, so the total is
\[8\cdot92+97=\boxed{833}.\]
