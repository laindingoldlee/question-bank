Let $b_k$ be the number at the end of Day $k$, so $b_k=\left\lceil\dfrac{b_{k-1}}{2}\right\rceil+60-k$ with $b_0=35$. Computing:
\[b_1=77,\ b_2=97,\ b_3=106,\ b_4=109,\ b_5=110,\ b_6=109,\ b_7=108,\ b_8=106.\]
\emph{Claim:} $b_k=122-2k$ for $k\ge8$. It holds for $k=8$, and if $b_{k-1}=124-2k$ then $b_k=62-k+60-k=122-2k$.

So $b_k<4$ first when $122-2k<4$, i.e. $k>59$. The answer is Day $\boxed{60}$ (with $2$ boxes left).
