Write the counts from top to bottom as $a<b<c$ with $a+b+c=10$. If $a=1$, the possible pairs are $(b,c)=(2,7),(3,6),(4,5)$. If $a=2$, only $(3,5)$ works. If $a\ge3$, the minimum total is $3+4+5=12$, too large. Thus there are $\boxed4$ distributions.
