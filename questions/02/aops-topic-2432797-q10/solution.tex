Track the amounts (in cups) as (dandelion, daisy).
\begin{itemize}
\item After the first pour: first container $\left(1,\dfrac23\right)$, second $\left(0,\dfrac13\right)$.
\item Pouring $\dfrac23$ of the first into the second moves $\left(\dfrac23,\dfrac49\right)$: first $\left(\dfrac13,\dfrac29\right)$, second $\left(\dfrac23,\dfrac79\right)$.
\item Pouring $\dfrac23$ of the second into the first moves $\left(\dfrac49,\dfrac{14}{27}\right)$: first $\left(\dfrac13+\dfrac49,\ \dfrac29+\dfrac{14}{27}\right)=\left(\dfrac79,\dfrac{20}{27}\right)$.
\end{itemize}
The ratio is $\dfrac79:\dfrac{20}{27}=21:20$, so the answer is $\boxed{21:20}$.
