Let $M$ be the number of boy-girl handshakes. Each child shakes exactly $2$ hands. Counting the hands of boys: each boy-boy handshake uses two boy hands and each mixed handshake one, so $2b=2B+M$. Similarly $2g=2G+M$. Subtracting, $2b-2g=2B-2G$, i.e. $b-g=B-G$. $\blacksquare$
