Fix the first vertex's color. Let $e_n,d_n$ count proper colorings of a path of $n$ vertices that end in the first color or a different color. Then $e_1=1,d_1=0$, $e_{n+1}=d_n$, and $d_{n+1}=5e_n+4d_n$. Successive pairs are $(0,5),(5,20),(20,105),(105,520),(520,2605)$. To close the six-cycle we need a different last color, giving $2605$ choices for each first color. The total is $6\cdot2605=\boxed{15630}$.
