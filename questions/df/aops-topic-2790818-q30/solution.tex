If $p<q$ are consecutive primes with gap $g=q-p$, the values $n=p+1,\dots,q$ contribute $(g-1)+(g-2)+\cdots+0=\dfrac{g(g-1)}2$. So the sum is $1$ (from $n=1$) plus $\dfrac{g(g-1)}2$ over the prime gaps up to $9973$, plus the partial last gap: $n=9974,\dots,10000$ have $f(n)=10007$ and contribute $7+8+\cdots+33=540$. Adding up the gaps (by computer) gives $\boxed{57134}$. (A rough estimate: gaps near $n$ average about $\ln n$, so the sum is roughly $\sum\dfrac{\ln n}2$, a few tens of thousands.)
