$33\,000\,000$ dollars is $132\,000\,000$ quarters, a stack of $132\,000\,000\cdot0.069=9\,108\,000$ inches. A mile is $5280\cdot12=63\,360$ inches, so the height is $\dfrac{9\,108\,000}{63\,360}=\boxed{143.75}$ miles.
