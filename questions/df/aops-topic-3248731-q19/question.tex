A triangular grid has $2024$ points in its bottom row. Each morning a walker moves to one of the two adjacent points in the next row. Each noon one new bottom-row point is blocked. The walker stops as soon as all bottom points reachable from the current position are blocked. What is the least number of completed moves possible before stopping, over all paths and blocking choices?
