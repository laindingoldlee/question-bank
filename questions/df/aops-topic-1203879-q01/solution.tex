With real cube roots, $(-64)^{\dfrac{1}{3}}=-4$, so the product is
\[(-4)^{-5}\cdot(-4)^4=(-4)^{-1}=\boxed{-\dfrac{1}{4}}.\]
(Equivalently, add the exponents: $(-64)^{-\dfrac{1}{3}}=-\dfrac{1}{4}$; this is legitimate here because both exponents have odd denominator $3$.)
