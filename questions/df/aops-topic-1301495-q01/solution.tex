\textbf{Weighing 1:} put $3$ packets on each pan, leaving $2$ aside.
\begin{itemize}
\item If one pan is lighter, the light packet is among its $3$. \textbf{Weighing 2:} put one of these against another. If they balance, the third is light; otherwise the lighter pan has it.
\item If the pans balance, the light packet is one of the $2$ set aside. \textbf{Weighing 2:} weigh them against each other; the lighter one is it.
\end{itemize}
So $2$ weighings always suffice. (In fact $2$ weighings can handle up to $9$ packets, since each weighing has $3$ outcomes.)
