Choosing which $3$ of the $5$ presents: $\dbinom53=\boxed{10}$ ways. If the order (left to right) also matters, each set of $3$ can be arranged in $3!=6$ ways, giving $5\cdot4\cdot3=\boxed{60}$ ways.
