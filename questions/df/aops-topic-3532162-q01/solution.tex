The given equation implies $x=z^2y$. Since all variables are positive, $\sqrt x=z\sqrt y$. Therefore $\dfrac{\sqrt z}{\sqrt x}=\dfrac{\sqrt z}{z\sqrt y}=\boxed{\dfrac{1}{\sqrt{yz}}}$.
