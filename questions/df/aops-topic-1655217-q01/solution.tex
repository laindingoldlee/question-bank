Write the weights in increasing order, $w_1\le w_2\le\dots\le w_7$. The data say:
\[
w_4=14,\qquad w_1+\dots+w_7=7\cdot15=105,\qquad w_7=w_1+8,
\]
and $14$ occurs more often than any other value.

\textbf{(a)} For example $10,14,14,14,17,18,18$: the median is $14$, the sum is $105$, the range is $18-10=8$, and $14$ (three times) beats $18$ (twice).

\textbf{(b)} \emph{Bounds for $w_1$.} Since $w_2,w_3\le14$, $w_5,w_6\le w_7=w_1+8$,
\[
105\le w_1+28+14+3(w_1+8)=4w_1+66,
\]
so $w_1\ge10$. Since $w_2,w_3\ge w_1$ and $w_5,w_6\ge14$,
\[
105\ge 3w_1+14+28+(w_1+8)=4w_1+50,
\]
so $w_1\le13$. Also $w_2+w_3+w_5+w_6=105-14-w_1-w_7=83-2w_1$.

\emph{The four cases.} For each $w_1$ we list the possibilities for $w_2\le w_3\le14\le w_5\le w_6\le w_7$ with the required sum, and keep those in which $14$ is the only mode.
\begin{itemize}
\item $w_1=10$, $w_7=18$, $w_2+w_3+w_5+w_6=63$. Since $w_5+w_6\le36$, we need $w_2+w_3\ge27$, so $(w_2,w_3)=(13,14)$ or $(14,14)$. With $(14,14)$: $w_5+w_6=35$, so $(w_5,w_6)=(17,18)$, giving $10,14,14,14,17,18,18$, valid. With $(13,14)$: $w_5+w_6=36$, so $(w_5,w_6)=(18,18)$, giving $10,13,14,14,18,18,18$, in which $18$ occurs more often than $14$; invalid. \quad\emph{1 list.}
\item $w_1=11$, $w_7=19$, sum $61$. The valid lists are
$11,12,14,14,17,18,19$;\ $11,13,14,14,16,18,19$;\ $11,14,14,14,14,19,19$;\ $11,14,14,14,15,18,19$;\ $11,14,14,14,16,17,19$. \quad\emph{5 lists.}
\item $w_1=12$, $w_7=20$, sum $59$. The valid lists are
$12,12,14,14,14,19,20$;\ $12,13,14,14,14,18,20$;\ $12,13,14,14,15,17,20$;\ $12,14,14,14,14,17,20$;\ $12,14,14,14,15,16,20$. \quad\emph{5 lists.}
\item $w_1=13$, $w_7=21$, sum $57$. The valid lists are
$13,13,14,14,14,16,21$;\ $13,14,14,14,14,15,21$. \quad\emph{2 lists.}
\end{itemize}
(In each case the omitted candidates have a second value occurring as often as $14$, for example $11,13,13,14,\dots$ or $12,12,14,15,\dots$, or break the order $w_3\le14\le w_5$.) Altogether there are
\[
1+5+5+2=\boxed{13}
\]
possible lists.
