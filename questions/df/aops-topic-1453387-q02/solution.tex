Each quarter the balance is multiplied by $1+\dfrac{0.06}{4}=1.015$, and $5$ years contain $20$ quarters. So the balance is
\[
5000\cdot1.015^{20}\approx5000\cdot1.3468550=\boxed{\$6734.28}.
\]
