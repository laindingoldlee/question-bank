Use the complement. $P(0)=\left(\dfrac34\right)^5=\dfrac{243}{1024}$ and $P(1)=5\cdot\dfrac14\cdot\left(\dfrac34\right)^4=\dfrac{405}{1024}$. So the answer is $1-\dfrac{648}{1024}=\boxed{\dfrac{47}{128}}$.
