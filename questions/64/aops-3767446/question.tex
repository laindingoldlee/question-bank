Denote a permutation $\sigma \in S_n$ as \emph{cute} if it can be written as $\sigma = T_1 T_2 ... T_k$ where $0 \leq k < n$, each of the $T_i$s is a  transposition in the form $(j \text{    }j+1)$ for some $1 \leq j < n$, and $T_1, T_2, ..., T_k$ are all distinct. Let $f(n)$ be the number of \emph{cute} permutations $\sigma$ in $S_n.$ Find the remainder when the nearest integer to $\dfrac{f(2027)}{f(2019)}$ is divided by $1000.$
