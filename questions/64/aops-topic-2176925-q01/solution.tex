Note that $z=\sqrt2(1+i)$, so
\[z^2=2(1+i)^2=2\cdot 2i=4i,\qquad z^8=\left(z^2\right)^4=(4i)^4=256,\qquad z^{16}=256^2=65536 .\]
Hence, using $z\bar z=|z|^2=2+2=4$,
\[z^{15}=\dfrac{z^{16}}{z}=\dfrac{65536\,\bar z}{z\bar z}=\dfrac{65536\left(\sqrt2-i\sqrt2\right)}{4}=\boxed{16384\sqrt2-16384\sqrt2\,i}.\]
(Equivalently, $z=2\left(\cos45^\circ+i\sin45^\circ\right)$, and by De Moivre's theorem
\[z^{15}=2^{15}\left(\cos675^\circ+i\sin675^\circ\right)=32768\left(\dfrac{\sqrt2}{2}-\dfrac{\sqrt2}{2}i\right),\]
since $675^\circ=720^\circ-45^\circ$.)
