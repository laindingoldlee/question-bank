The five chickens eat $\dfrac{10}{20}=\dfrac{1}{2}$ bag per day, so each chicken eats $\dfrac{1}{10}$ bag per day. Then $18$ chickens eat $\dfrac{18}{10}=\dfrac{9}{5}$ bags per day, and $100$ bags last
\[
100\div\dfrac{9}{5}=\boxed{\dfrac{500}{9}=55\dfrac{5}{9}\text{ days}}.
\]
(As a joint proportion: the time is proportional to the number of bags and inversely proportional to the number of chickens, so it is $20\cdot\dfrac{100}{10}\cdot\dfrac{5}{18}=\dfrac{500}{9}$ days.)
