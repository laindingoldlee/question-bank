Represent a subset by a binary string of length $7$. If it has $k$ ones in $r$ nonempty runs, it has $k-r$ consecutive pairs. Thus $r=k-2$. The run lengths can be chosen in $\binom{k-1}{r-1}$ ways. After placing the required $r-1$ separating zeros, distributing the other zeros among the $r+1$ gaps gives $\binom{8-k}{r}$ choices. Feasibility leaves $k=3,4,5$, so the total is
\[
\binom20\binom51+\binom31\binom42+\binom42\binom33
=5+18+6=\boxed{29}.
\]
