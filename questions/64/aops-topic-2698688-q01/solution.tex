The polynomial factors as $n(n-1)\left(n^2-n+1\right)\left(n^2-n+2\right)$. Let $m=n(n-1)$, which is even, say $m=2j$. Then $n^2-n+2=m+2=2(j+1)$, so the product contains $2j\cdot2(j+1)=4j(j+1)$, which is divisible by $8$. Mod $3$: if $n\equiv0$ or $1$ then $3\mid n(n-1)$, and if $n\equiv2$ then $n^2-n+1\equiv4-2+1\equiv0$. Hence $8\cdot3=24$ divides the expression. $\blacksquare$
