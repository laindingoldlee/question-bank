Division gives
\[
g(x)=\dfrac{-2(x-7)-11}{x-7}=-2-\dfrac{11}{x-7}.
\]
\begin{itemize}
\item \textbf{Domain:} all real $x\ne7$.
\item \textbf{Range:} $y=g(x)$ means $\dfrac{11}{x-7}=-2-y$, which has a solution $x$ exactly when $y\ne-2$. So the range is all real $y\ne-2$.
\item \textbf{Asymptotes:} vertical asymptote $x=7$ (the denominator vanishes and the numerator is $-11\ne0$ there); horizontal asymptote $y=-2$, since $\dfrac{11}{x-7}\to0$ as $x\to\pm\infty$.
\end{itemize}
The graph is a hyperbola: the graph of $y=-\dfrac{11}{x}$ moved $7$ right and $2$ down. It crosses the $x$-axis at $\left(\dfrac{3}{2},0\right)$ and the $y$-axis at $\left(0,-\dfrac{3}{7}\right)$.
\begin{asy}
usepackage("amsmath");
size(7cm);
defaultpen(fontsize(10pt));
import graph;
real g(real x){return (3-2*x)/(x-7);}
real xmin=-9, xmax=23, ymin=-13, ymax=9;
draw(graph(g,xmin,7-11/(ymax+2)),blue+linewidth(0.9));
draw(graph(g,7+11/(-2-ymin),xmax),blue+linewidth(0.9));
draw((7,ymin)--(7,ymax),red+dashed); draw((xmin,-2)--(xmax,-2),red+dashed);
xaxis(xmin,xmax,Arrow); yaxis(ymin,ymax,Arrow);
dot((0,-3/7)); dot((1.5,0));
label("$x=7$",(7,ymax),E,red); label("$y=-2$",(xmin+3,-2),S,red);
label("$x$",(xmax,0),N); label("$y$",(0,ymax),W);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}
