Write $x=n+t$, where $n=\lfloor x\rfloor$ is a nonnegative integer and $0\le t<1$. Then
\[
\lfloor x\rfloor+\lfloor2x\rfloor=3n+\lfloor2t\rfloor.
\]
The last floor is either $0$ or $1$. The equation $3n+\lfloor2t\rfloor=12$ therefore forces $n=4$ and $\lfloor2t\rfloor=0$. Equivalently $0\le t<\dfrac{1}{2}$, so
\[
\boxed{4\le x<\dfrac{9}{2}}.
\]
There is no largest real solution: for any solution $x$, the number $\dfrac{x+\dfrac{9}{2}}{2}$ is a larger solution. The upper bound $\dfrac{9}{2}$ is not attained. The only integer solution, and hence the largest integer solution, is $\boxed{4}$.
