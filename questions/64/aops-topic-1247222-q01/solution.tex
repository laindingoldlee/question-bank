If $n=p_1^{e_1}\cdots p_k^{e_k}$, the number of divisors is $(e_1+1)\cdots(e_k+1)=2015=5\cdot13\cdot31$. The possible exponent lists (sorted decreasingly) are
\[(2014),\ (402,4),\ (154,12),\ (64,30),\ (30,12,4).\]
To make $n$ small, give the largest exponent to $2$, the next to $3$, and so on. Comparing, $2^{30}3^{12}5^4$ is far smaller than $2^{64}3^{30}$ or the others (for instance $\dfrac{2^{64}3^{30}}{2^{30}3^{12}5^4}=\dfrac{2^{34}3^{18}}{5^4}>1$). The answer is $\boxed{2^{30}\cdot3^{12}\cdot5^4}$.
