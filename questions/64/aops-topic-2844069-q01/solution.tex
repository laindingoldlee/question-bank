With $x=y=0$: $f(0)^2=f(0)$, so $f(0)\in\{0,1\}$. With $y=0$: $f(x)f(0)=f(0)+x$. If $f(0)=0$ this gives $x=0$ for all $x$, a contradiction. So $f(0)=1$ and $f(x)=1+x$.

Check: $(1+x)(1+y)=1+xy+x+y=f(xy)+x+y$. The only solution is $\boxed{f(x)=x+1}$.
