$101,111,121,\dots,191$ has $10$ terms (difference $10$).

\emph{Upper bound.} The palindrome $\overline{aba}$ has first and last digit $a$ and lies in $[101a,101a+90]$. If the difference $d$ is a multiple of $10$, all terms have the same last digit, hence the same $a$, so they lie in an interval of length $90$ with spacing at least $10$: at most $10$ terms. If $10\nmid d$, consecutive terms have different last digits, hence different first digits, which strictly increase. So there are at most $9$ terms. The maximum is $\boxed{10}$.
