$f(f(x))=x$ forces $d=-a$ (compare coefficients). The fixed points solve $cx^2+(d-a)x-b=0$, i.e. $cx^2-2ax-b=0$, with roots $19,97$. So $\dfrac{2a}c=116$ and $\dfrac ac=58$.

A M\"obius map misses exactly the value $\dfrac ac$ (the limit at infinity). So the range is $\boxed{\mathbb R\setminus\{58\}}$.
