Since $132=2^2\cdot3\cdot11$, $n^2$ is divisible by $132$ exactly when $2\mid n$, $3\mid n$ and $11\mid n$: a prime divides $n^2$ only if it divides $n$, and if $2\mid n$ then $4\mid n^2$. So $132\mid n^2$ if and only if $66\mid n$. The number of multiples of $66$ among $1,\dots,100000$ is $\left\lfloor\dfrac{100000}{66}\right\rfloor=\boxed{1515}$.
