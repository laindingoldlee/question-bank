Expand both sides using positional values. Their difference simplifies to $99[A(C-B-1)+B]$. Thus $B=A(B+1-C)$, so $B=kA$ and $C=k(A-1)+1$ for a positive integer $k$. Distinctness excludes $k=1$, so $A\le4$. To maximise the three-digit number take $A=4$; the only possible $k\ge2$ with $kA\le9$ is 2, giving $B=8,C=7$. These digits are distinct and satisfy the equation. Hence $\boxed{487}$.
