For positive $a$, $b$ we have $a\triangle b=\sqrt[b]{b}\cdot\sqrt[b]{a^b}=a\sqrt[b]{b}$. Hence $2\triangle2=2\sqrt2$ and
\[(2\triangle2)\triangle2=2\sqrt2\cdot\sqrt2=4,\]
an integer, so the answer is $\boxed{\textbf{(B)}}$.

For completeness, the other choices are not integers:
\begin{itemize}
\item (A) $4\triangle4=4\sqrt[4]4=4\sqrt2$ is irrational.
\item (C) $25\triangle5=25\sqrt[5]5$ is irrational, because $\sqrt[5]5$ is irrational (if $\sqrt[5]5=\dfrac {p}{q}$ then $p^5=5q^5$, but the exponent of $5$ in $p^5$ is a multiple of $5$ and in $5q^5$ it is not).
\item (D) $2\sqrt2-4\sqrt2+8\sqrt[8]8=8\cdot2^{\dfrac{3}{8}}-2\sqrt2$. Since $1.29^8<8<1.3^8$, we have $10.32<8\cdot2^{\dfrac{3}{8}}<10.4$, and $2.82<2\sqrt2<2.83$, so the value lies strictly between $7$ and $8$.
\item (E) $2\triangle\left(2\sqrt2\right)=2\left(2\sqrt2\right)^{\dfrac{1}{2\sqrt2}}=2\cdot2^{\dfrac{3\sqrt2}{8}}$. Here $0<3\sqrt2<4.5$, so $1<2^{3\sqrt2}<2^{4.5}=16\sqrt2<23<\left(\dfrac{3}{2}\right)^8$, and taking eighth roots, $1<2^{\dfrac{3\sqrt2}{8}}<\dfrac{3}{2}$. The value lies strictly between $2$ and $3$.
\end{itemize}
