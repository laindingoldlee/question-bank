Write $A=(0,0),B=(1,0),C=(0,1)$. Parametrize $D=(1-t,t)$ on line $BC$, $E=(0,u)$ on line $CA$, and $F=(v,0)$ on line $AB$. Their collinearity determinant, expanded directly, gives $uv-vt-u(1-t)=0$. Using directed ratios $\dfrac{\overline{BD}}{\overline{DC}} = \dfrac{t}{1-t}$, $\dfrac{\overline{CE}}{\overline{EA}} = \dfrac{1-u}{u}$, and $\dfrac{\overline{AF}}{\overline{FB}} = \dfrac{v}{1-v}$, the product is $-1$ exactly when $tv(1-u)+u(1-t)(1-v)=0$, which expands to the same determinant equation. Therefore the signed Menelaus product is $\boxed{-1}$. The minus sign records that an odd number of the three division points are external.

\end{asy}
