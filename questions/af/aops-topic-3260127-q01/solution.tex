Adjacent digits must have opposite parity. If the first digit is odd, it has five choices, and each remaining digit has five choices of the required parity, giving $5^{2n}$. If it is even, it has four nonzero choices, and the remaining positions each have five choices, giving $4\cdot5^{2n-1}$. The total is $\boxed{9\cdot5^{2n-1}}$.
