In base $7$, each place is worth $7$ times the place to its right: the places are ones, sevens, forty-nines, and so on, just as base-$10$ places are ones, tens, hundreds. The digits $3,6,4$ count how many forty-nines, sevens and ones the number contains. So
\[364_7=3\cdot49+6\cdot7+4=147+42+4=\boxed{193}.\]
