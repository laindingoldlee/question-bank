\textbf{(a)} The differences are $13-5=8$, $29-13=16$ and $53-29=24$, an arithmetic sequence with common difference $8$. The next difference is $32$, so the next term is $53+32=\boxed{85}$.

\textbf{(b)} The $k$th difference is $8k$, so
\[a_n=5+\sum_{k=1}^{n-1}8k=5+8\cdot\dfrac{(n-1)n}{2}=4n^2-4n+5=\boxed{(2n-1)^2+4}.\]
Check: $1+4=5$, $9+4=13$, $25+4=29$, $49+4=53$, and $81+4=85$.
