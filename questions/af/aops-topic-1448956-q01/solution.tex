$N$ is a square, cube, fourth and fifth power exactly when every exponent in its prime factorisation is divisible by $\operatorname{lcm}(2,3,4,5)=60$; and it is a multiple of $60=2^2\cdot3\cdot5$, so $2$, $3$ and $5$ divide $N$.

Let $N=x^y$. Then $2,3,5$ divide $x$, so $x\ge30$. Write $e_p$ for the exponent of a prime $p$ in $x$; then $60\mid y\,e_p$ for every $p\mid x$.
\begin{itemize}
\item If $y\ge60$, then $x+y\ge30+60=90$.
\item If $y<60$, then $\dfrac{60}{\gcd(60,y)}\ge2$ divides each $e_p$, so $e_2,e_3,e_5\ge2$ and $x\ge30^2=900$, so $x+y>90$.
\end{itemize}
Equality $x+y=90$ holds for $N=30^{60}$, $x=30$, $y=60$: this $N$ is a multiple of $60$ and is a $60$th power. The least value is $\boxed{90}$.
