Prove the following rule for squaring a number ending in $5$: if $N=\overline{d_1d_2\ldots d_k5}$ and $n=\overline{d_1d_2\ldots d_k}$, then the decimal representation of $N^2$ is obtained by writing the number $n(n+1)$ followed by the digits $25$. (For example, $45^2=2025$ because $4\cdot5=20$.)
