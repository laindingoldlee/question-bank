We need $0.7y<x<\dfrac{11}{14}y\approx0.786y$. Testing $y=1,2,3$:
\[y=1:\ 0.7<x<0.79;\qquad y=2:\ 1.4<x<1.58;\qquad y=3:\ 2.1<x<2.36,\]
and none of these intervals contains an integer. For $y=4$: $2.8<x<3.15$, so $x=3$; indeed $\dfrac7{10}<\dfrac34<\dfrac{11}{14}$ since $0.7<0.75<0.785\ldots$. The smallest $y$ is $4$, and then $x=\boxed{3}$.
