Multiply by $36$: $3x+y=36$, so $y=36-3x$. We need $y\ge1$, i.e.\ $3x\le35$, so $x\le11$; and $x\ge1$. Each of $x=1,2,\dots,11$ gives a positive integer $y=33,30,\dots,3$. There are $\boxed{11}$ pairs.
