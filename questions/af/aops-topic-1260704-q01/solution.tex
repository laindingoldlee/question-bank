The condition is $100a+b=9(10a+b)=90a+9b$, so $10a=8b$, i.e. $5a=4b$. With digits $a\in\{1,\dots,9\}$ and $b\in\{0,\dots,9\}$, the only solution is $a=4$, $b=5$. So the only number is $\boxed{45}$ (indeed $9\cdot45=405$).
