Convert each decimal.
\begin{itemize}
\item $0.\overline{23}=\dfrac{23}{99}$.
\item If $x=0.2333\ldots$, then $100x-10x=23.333\ldots-2.333\ldots=21$, so $x=\dfrac{21}{90}=\dfrac{7}{30}$.
\item If $y=0.23444\ldots$, then $1000y-100y=234.444\ldots-23.444\ldots=211$, so $y=\dfrac{211}{900}$.
\end{itemize}
The least common denominator of $99=3^2\cdot11$, $30=2\cdot3\cdot5$ and $900=2^2\cdot3^2\cdot5^2$ is $9900$, so the sum is
\[\dfrac{2300}{9900}+\dfrac{2310}{9900}+\dfrac{2321}{9900}=\boxed{\dfrac{6931}{9900}}.\]
This is in lowest terms, because $6931=29\cdot239$ shares no prime factor with $9900=2^2\cdot3^2\cdot5^2\cdot11$.
