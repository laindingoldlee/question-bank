We need $3a+7b=100$ with $a,b\ge0$. Modulo $3$: $7b\equiv b\equiv100\equiv1$, so $b\in\{1,4,7,10,13\}$ (as $7b\le100$). These give $a=31,24,17,10,3$. There are $\boxed{5}$ possibilities.
