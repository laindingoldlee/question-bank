Sam's thermometer shows the boiling temperature of ethanol as $78^\circ$C, but the actual boiling temperature (in this problem) is $75^\circ$C. Assume that this thermometer always reads the same number of degrees too high. Anna uses the same thermometer and reads the boiling temperature of soybean oil as $260^\circ$C. What is the actual boiling temperature of the soybean oil? What would the answer be if instead the thermometer's readings were always too high by the same \emph{percentage}?
