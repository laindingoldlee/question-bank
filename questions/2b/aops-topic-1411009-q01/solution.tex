\textbf{Constant offset.} The thermometer reads $78-75=3$ degrees too high, so the actual temperature is $260-3=\boxed{257^\circ\text{C}}$.

\textbf{Constant percentage.} The reading is $\dfrac{78}{75}=1.04$ times the actual temperature, so the actual temperature would be $\dfrac{260}{1.04}=250^\circ$C.

One data point cannot tell these two error models apart; the problem's intended model is the constant offset, which gives $257^\circ$C.
