Write $n=\sum d_k10^k$ and let $s=\sum d_k$. Since $10\equiv1\pmod3$, $10^k\equiv1$ for every $k$, so $n\equiv s\pmod3$. Equivalently, $n-s=\sum d_k(10^k-1)$ and each $10^k-1=99\ldots9$ is a multiple of $3$. So $3\mid n\iff3\mid s$. $\blacksquare$
