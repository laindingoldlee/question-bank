A positive integer is called \emph{orz} if its decimal digits include each of the digits $6$, $9$, $1$ and $3$ at least once (in any order), and \emph{omighty} if it contains none of these four digits. For example, $1963$ is orz, $5000$ is omighty, and $6000$ is neither. How many six-digit orz numbers are there, and how many six-digit omighty numbers?
