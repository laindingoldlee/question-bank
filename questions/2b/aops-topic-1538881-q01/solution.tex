In the first $36$ minutes Rob runs $\dfrac{36}{3}=12$ laps, so $52-12=40$ laps remain when Kat starts. From then on, together they run
\[
\dfrac{1}{3}+\dfrac{1}{2}=\dfrac{5}{6}\text{ lap per minute}.
\]
So they need $40\div\dfrac{5}{6}=\boxed{48}$ more minutes. (In that time Rob runs $16$ laps and Kat $24$, and $12+16+24=52$.)
