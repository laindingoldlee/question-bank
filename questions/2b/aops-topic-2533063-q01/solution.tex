Each integer $n=2^k\cdot m$ with $m$ odd appears in the block for the power $2^k$, and the blocks come in order $k=0,1,2,\dots$.

\textbf{(a)} Since $2^{12}=4096\le5005<8192=2^{13}$, the last nonempty block is $k=12$: the multiples of $4096$ up to $5005$ that are not multiples of $8192$. That block contains only $4096$, so the last integer listed is $\boxed{4096}$.

\textbf{(b)} The first block contains the $2503$ odd numbers $1,3,\dots,5005$. So the $2000$th number listed is the $2000$th odd number, $2\cdot2000-1=\boxed{3999}$.
