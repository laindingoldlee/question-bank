Modulo 11, $x\equiv0$, so write $x=11k$ and $y=70-7k$. Strict positivity gives $k=1,\ldots,9$. The arithmetic progression $11,22,\ldots,99$ has average $\boxed{55}$.
\begin{asy}
usepackage("amsmath");
size(7cm);
draw((0,70)--(110,0));for(int k=1;k<=9;++k)dot((11*k,70-7*k));label("(0,70)",(0,70),N);label("(110,0)",(110,0),E);label("7x+11y=770",(55,35),NE);
\end{asy}
