The function $x\mapsto6^x$ is strictly increasing (since $6>1$), so it takes each value only once. As $6^2=6^2$, the only solution is $\boxed{x=2}$. (Equivalently, take logarithms base $6$: $x=\log_6 6^2=2$.)
