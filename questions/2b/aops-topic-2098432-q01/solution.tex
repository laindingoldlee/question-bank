Since $\dfrac{2}{n(n+2)}=\dfrac{1}{n}-\dfrac{1}{n+2}$, the sum telescopes:
\[\sum_{n=1}^{2009}\left(\dfrac{1}{n}-\dfrac{1}{n+2}\right)=\left(\dfrac{1}{1}+\dfrac{1}{2}+\cdots+\dfrac{1}{2009}\right)-\left(\dfrac{1}{3}+\dfrac{1}{4}+\cdots+\dfrac{1}{2011}\right)=1+\dfrac{1}{2}-\dfrac{1}{2010}-\dfrac{1}{2011}.\]
Now $\dfrac{1}{2010}+\dfrac{1}{2011}\approx0.000498+0.000497=0.000995$, so the sum is about $1.5-0.000995=1.499005$, which is $\boxed{1.499}$ to the nearest thousandth.
