Write $ x=k\dfrac{yz}{w}$. The first values give $ 4=k\dfrac{40}{6}$, so $ k=\dfrac{3}{5}$. Hence the new value is $\dfrac{3}{5}\dfrac{90}{4}=\boxed{\dfrac{27}{2}}$.
