Consider the lines in the coordinate plane that pass through the point $(3,3)$.
\begin{enumerate}
\item[(a)] How many of these lines have a $y$-intercept $K$ that is an integer with $-3000\le K\le3000$?
\item[(b)] How many of these lines have both an integer $y$-intercept and an integer $x$-intercept?
\end{enumerate}
