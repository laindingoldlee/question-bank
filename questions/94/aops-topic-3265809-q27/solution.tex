The equation is $100a+10b+c=(10a+b)(10b+c)$, with $a\ge1$. Rearrangement gives
\[100a(b-1)+c(10a+b-1)+10b(b-1)=0.\]
If $b\ge1$, every term is nonnegative, forcing $b=1$ and then $c=0$. Each $a=1,\ldots,9$ works, giving $110,210,\ldots,910$.
If $b=0$, the equation reduces to $c(10a-1)=100a$, so $c=\dfrac{100a}{10a-1}>10$, impossible for a digit. Thus the count is $\boxed9$.
