The right side must be an integer: put $n=3x-7\in\mathbb Z$, so $x=\dfrac{n+7}{3}$. Then
\[
x^2-3x+2=\dfrac{(n+7)^2}{9}-(n+7)+2=\dfrac{n^2+5n+4}{9}=\dfrac{(n+1)(n+4)}{9}.
\]
The equation says $n\le\dfrac{n^2+5n+4}{9}<n+1$.
\begin{itemize}
\item $9n\le n^2+5n+4\iff(n-2)^2\ge0$: always true.
\item $n^2+5n+4<9n+9\iff n^2-4n-5<0\iff(n-5)(n+1)<0\iff-1<n<5$.
\end{itemize}
So $n\in\{0,1,2,3,4\}$, and the solutions are
\[
\boxed{x=\dfrac{7}{3},\ \dfrac{8}{3},\ 3,\ \dfrac{10}{3},\ \dfrac{11}{3}} .
\]
(For example $x=3$: $\lfloor2\rfloor=2=9-7$.)
