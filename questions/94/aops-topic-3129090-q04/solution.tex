The inscribed angle $ACB$ subtends the same minor arc $AB$ as the central angle $AOB$, so it is half as large: $\boxed{31^\circ}$.
\begin{asy}
usepackage("amsmath");
size(7cm);
pair O=(0,0),B=(-1,0),C=(1,0),A=dir(118);draw(unitcircle);draw(A--B--C--cycle);draw(A--O);label("$A$",A,N);label("$B$",B,W);label("$C$",C,E);label("$O$",O,S);
\end{asy}
