Start with labels 1 through 1500 in a row. On pass 2 delete the first label and every second label thereafter, counting only the current row. On pass 3 start at the right endpoint and delete the first encountered label and every third thereafter. Continue with passes 4,5,..., alternating endpoints, always deleting the first encountered label and then every kth label on passk. Stop when one label remains. Find it.
