As $x$ runs over the reals, $3^x$ takes every positive value, so $3^x+18$ takes every value in $(18,\infty)$ and $f(x)$ takes every value in $\left(0,\dfrac{2016}{18}\right)=(0,112)$. The integers in this open interval are $1,2,\dots,111$: there are $\boxed{\textbf{(c)}\ 111}$.
