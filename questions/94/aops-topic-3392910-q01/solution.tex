Division gives $7=1\cdot4+3$, so $\dfrac{7}{4}=\boxed{1\dfrac{3}{4}}$. Both denote exactly the same number. An improper fraction is often more convenient in algebra because it is one quotient; a mixed number may be useful in a measurement. A required answer format is a convention, not a change in value.
