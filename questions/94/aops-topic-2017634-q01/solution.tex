Let there be $n$ trees. Each girl numbers the trees $1,2,\dots,n$ around the circle, so $n\ge 94$.

\textbf{Same direction.} Then Valerie's number is Nicole's number shifted by a constant modulo $n$. From the first fact the shift is $7-20=-13$, so Nicole's $7$th tree has Valerie number $\equiv 7-13=-6\pmod n$. Thus $94\equiv -6\pmod n$, i.e. $n\mid 100$. With $n\ge 94$ this forces $n=100$.

\textbf{Opposite directions.} Then Nicole's number plus Valerie's number is constant modulo $n$: $20+7\equiv 7+94\pmod n$, so $n\mid 74$, which contradicts $n\ge 94$. So the girls walked in the same direction.

(Check with $n=100$: Valerie's number is Nicole's number minus $13$ modulo $100$; $20\mapsto 7$ and $7\mapsto -6\equiv 94$.)

There were $\boxed{100}$ trees.
