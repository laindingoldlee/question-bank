Consider the sign of $x$.
\begin{itemize}
\item $x>0$: then $1=x^y=e^{y\ln x}$ gives $y\ln x=0$, since the exponential function is one-to-one and $e^0=1$. So $y=0$, case (c), or $\ln x=0$, i.e.\ $x=1$, case (b).
\item $x=0$: then $y>0$ and $0^y=0\ne1$, so this cannot happen.
\item $x<0$: then $y$ is an integer and $x^y=(-1)^y|x|^y$ with $|x|^y>0$. Since $x^y=1>0$, $(-1)^y=1$, so $y$ is even, and $|x|^y=1$. By the first case applied to $|x|>0$, $|x|=1$ or $y=0$. If $y=0$ we are in case (c); otherwise $|x|=1$, so $x=-1$ and $y$ is even, case (a).
\end{itemize}
In every possible case one of (a), (b), (c) holds. $\blacksquare$

\emph{Remark.} The convention matters. If one also allows $x<0$ with rational exponents of odd denominator, using real odd roots, then for example $(-1)^{\dfrac{2}{3}}=\left(\sqrt[3]{-1}\right)^2=1$, and statement (a) would have to be widened to ``$y$ is a rational number whose numerator is even and whose denominator is odd''.
