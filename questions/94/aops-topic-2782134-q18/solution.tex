Write $ P=(x,y)$. Equality of the first areas gives $ 27y=54(36-y)$, so $ y=24 $. Each is then 324. The trapezoid area is $\dfrac{27+54}{2}\cdot36=1458 $, so the two other triangles each have area $\dfrac{1458-648}{2}=405 $. Since $[ADP]=18x $, we get $ x=\dfrac{45}{2}$. Thus $[AHPK]=xy=\boxed{540}$.
