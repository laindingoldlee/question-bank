\begin{enumerate}
\item[(a)] Convert $2123_4$ to base ten, and explain why computing $2\cdot4^3+1\cdot4^2+2\cdot4+3$ works.
\item[(b)] Convert the base-ten number $2123$ to base $4$.
\item[(c)] In base $4$, the number ten is written $22_4$. Show that if all arithmetic is done in base $4$, then evaluating $2\cdot(22_4)^3+1\cdot(22_4)^2+2\cdot22_4+3$ gives the answer to (b).
\end{enumerate}
