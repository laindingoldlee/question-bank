We have $8^9-9^8=2^{27}-3^{16}=134217728-43046721=91171007$. Since $\gcd(27,16)=1$, there is no algebraic factorisation of the type $x^k-y^k$, so we look for a prime factor with modular arithmetic.

\textbf{Trying $257=2^8+1$.} Modulo $257$ we have $2^8=256\equiv-1$, so
\[2^{27}=2^3\left(2^8\right)^3\equiv8\cdot(-1)^3=-8\pmod{257}.\]
By repeated squaring, $3^4=81$, $3^8=6561=25\cdot257+136\equiv136$ and
\[3^{16}\equiv136^2=18496=71\cdot257+249\equiv249\equiv-8\pmod{257}.\]
So $2^{27}\equiv3^{16}\pmod{257}$, i.e. $257\mid8^9-9^8$, and
\[8^9-9^8=257\cdot354751.\]
\textbf{The other factor.} Since $596^2>354751$, the number $354751$ is prime if no prime $p\le593$ divides it; checking these divisions (by hand this is long, by computer immediate) shows that none does. So $354751$ is prime, and
\[8^9-9^8=\boxed{257\cdot354751}.\]
