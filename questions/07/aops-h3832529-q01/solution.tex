If the first digit is $1$ or $2$, every arrangement works: $2\cdot6!$ cases. If it is $3$, the second digit must be $1$: $5!$ cases. A prefix $32$ is already larger than $3{,}200{,}000$ because the remaining digits are positive. Thus the probability is $\dfrac{2\cdot6!+5!}{7!}=\boxed{\dfrac{13}{42}}$.
