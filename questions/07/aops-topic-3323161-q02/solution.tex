Reality of $R_1$ requires $x\ge0$. If $R_n=y$ is an integer, the identity $R_{n-1}=y^2-x$ makes $R_{n-1}$ an integer; repeating shows every earlier radical is an integer. In particular write $R_1=m\ge0$, so $x=m^2$, and $R_2^2=m^2+m$. For $m>0$, this lies strictly between $m^2$ and $(m+1)^2$, impossible for an integer square. Hence $m=0$, giving $\boxed{(x,y)=(0,0)}$ for every depth $n\ge2$. At depth one, the pairs are $\boxed{(x,y)=(m^2,m),\ m\ge0}$.
