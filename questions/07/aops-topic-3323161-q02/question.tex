Let $R_1=\sqrt{x}$ and $R_{j+1}=\sqrt{x+R_j}$, using principal real square roots. For a fixed finite depth $n\ge2$, find all integer pairs $(x,y)$ with $R_n=y$. Also state the answer when $n=1$.
