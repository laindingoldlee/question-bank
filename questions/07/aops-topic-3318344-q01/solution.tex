Start Reactor cannot finish on day 2, since Fuel Engines occupies that day, so it finishes on day 1 and Blue finishes on day 3. Orange must therefore finish on day 1 and has Start Reactor. Red cannot finish on day 2 because Red has Chart Course, nor on days 1 or 3 already assigned, so Red finishes on day 4. Green is left on day 2 with Fuel Engines. Blue's remaining task is Fix Wiring. Thus Orange--Start Reactor--day 1; Green--Fuel Engines--day 2; Blue--Fix Wiring--day 3; Red--Chart Course--day 4.
