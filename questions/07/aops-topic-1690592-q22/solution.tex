The number $1$ must be in the top-left cell and $6$ in the bottom-right cell. The top row is then $1<p<q$, and the bottom row consists of the other three numbers in increasing order; the only remaining condition is that each top number is less than the number below it. Choose the pair $\{p,q\}$ from $\{2,3,4,5\}$:
\begin{itemize}
\item top $1,2,3$; bottom $4,5,6$: valid;
\item top $1,2,4$; bottom $3,5,6$: valid;
\item top $1,2,5$; bottom $3,4,6$: valid;
\item top $1,3,4$; bottom $2,5,6$: valid;
\item top $1,3,5$; bottom $2,4,6$: valid;
\item top $1,4,5$; bottom $2,3,6$: invalid ($4>3$ in the middle column).
\end{itemize}
So there are $\boxed{5}$ arrangements.

A faster way: read the numbers $1$ to $6$ in order and write U if the number goes in the top row and D if it goes in the bottom row. A valid grid corresponds exactly to a sequence of three U's and three D's in which, at every point, the number of D's so far does not exceed the number of U's. These are counted by the Catalan number $C_3=\dfrac{1}{4}\dbinom63=5$.
