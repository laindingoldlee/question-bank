Add the three equations. Expanding the products,
\[(b-30)(c-26)+(c-28)(a-31)+(a-26)(b-27)=ab+bc+ca-55a-52b-61c+2350,\]
so the sum of the equations is
\[a^2+b^2+c^2+ab+bc+ca-55a-52b-61c+1197=0 .\]
Now use $u=a+b$, $v=b+c$, $w=c+a$. Then
\[a^2+b^2+c^2+ab+bc+ca=\dfrac{1}{2}\left(u^2+v^2+w^2\right),\]
and since $a=\dfrac{u-v+w}{2}$, $b=\dfrac{u+v-w}{2}$, $c=\dfrac{-u+v+w}{2}$,
\[55a+52b+61c=\dfrac{(55+52-61)u+(-55+52+61)v+(55-52+61)w}{2}=23u+29v+32w .\]
Multiplying the summed equation by $2$,
\[u^2+v^2+w^2-46u-58v-64w+2394=0\iff(u-23)^2+(v-29)^2+(w-32)^2=23^2+29^2+32^2-2394=0 .\]
Since $u,v,w$ are real, $u=23$, $v=29$, $w=32$. Then $a+b+c=\dfrac{23+29+32}{2}=42$, so
\[c=42-23=19,\qquad a=42-29=13,\qquad b=42-32=10 .\]
These satisfy the original equations: $169+(-20)(-7)=309$, $100+(-9)(-18)=262$, $361+(-13)(-17)=582$. Therefore
\[a(2c-b)=13\,(38-10)=\boxed{364}.\]
