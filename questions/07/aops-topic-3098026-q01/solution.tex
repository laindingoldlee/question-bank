A's wine is $24\cdot\dfrac{3}{4}=18$ dollars and B's drink is $3$. B's side is $8$, so A's bread is $\dfrac{3+8}{2}=5.50$. A's main dish is $3(18+3)=63$. Thus A pays $18+63+5.50+6=\boxed{\$92.50}$. B pays $3+34+8+10=\boxed{\$55.00}$. C pays $0+14+4(1.20)+7+4=\boxed{\$29.80}$.
