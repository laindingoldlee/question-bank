One liter is $1000$ cubic centimeters, so the required volume is $1500\text{ cm}^3$. If the height is $h$, $100h=1500$, giving $\boxed{h=15\text{ cm}}$. The closed box has surface area $2(10^2)+4(10)(15)=\boxed{800\text{ cm}^2}$.
