For a positive integer $m$, let $\phi(m)$ be the number of integers $k$ with $1\le k\le m$ and $\gcd(k,m)=1$. For every integer $n\ge10$ the following is done: $\phi$ is applied to $n$ repeatedly until a one-digit number is obtained, and that one-digit number is put into a set $S$ (which starts empty). How many elements does $S$ have at the end?
