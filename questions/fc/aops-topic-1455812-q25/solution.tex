Work backwards. Let $s_L$ be the smallest starting number whose sequence has $L$ numbers, and let $f(m)=m-k^2$ where $k=\lfloor\sqrt m\rfloor$; note $0\le f(m)\le2k$, because $m<(k+1)^2=k^2+2k+1$.

A number $m$ has a sequence of length $L$ exactly when $f(m)$ has a sequence of length $L-1$, so $f(m)\ge s_{L-1}$. Then $2k\ge f(m)\ge s_{L-1}$ gives $k\ge\left\lceil\dfrac{s_{L-1}}{2}\right\rceil$, and
\[
m=k^2+f(m)\ \ge\ \left\lceil\dfrac{s_{L-1}}{2}\right\rceil^2+s_{L-1}.
\]
Equality is reached with $k=\left\lceil\dfrac{s_{L-1}}{2}\right\rceil$ and $f(m)=s_{L-1}$, which is allowed since $s_{L-1}\le2k$. So $s_L=\left\lceil\dfrac{s_{L-1}}{2}\right\rceil^2+s_{L-1}$ for $L\ge3$ (for $L=2$ we need $m\ge1$, so $s_2=1$). Starting from $s_1=0$ and $s_2=1$:
\[
s_3=1+1=2,\quad s_4=1+2=3,\quad s_5=4+3=7,\quad s_6=16+7=23,\quad s_7=144+23=167,\quad s_8=84^2+167=7223 .
\]
Indeed $7223,\,167,\,23,\,7,\,3,\,2,\,1,\,0$ has $8$ numbers. So $N=7223$, whose units digit is $3$: $\boxed{\textbf{(B)}}$.
