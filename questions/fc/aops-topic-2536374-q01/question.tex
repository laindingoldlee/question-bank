Call a quintuplet of integers $(i,n,m,y,t)$ \emph{quintessential} if $1\le i,n,m,y,t\le32$ and
\[n\ge2i,\qquad m\ge2n,\qquad y\ge2m,\qquad t\ge2y.\]
How many quintessential quintuplets are there?

$\textbf{(A) } 201 \qquad \textbf{(B) } 202 \qquad \textbf{(C) } 203 \qquad \textbf{(D) } 204 \qquad \textbf{(E) } 205$
