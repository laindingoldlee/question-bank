Define $x\star y=x^2+y^2+xy+x+y$. (a) Is $\star$ commutative? (b) If $\spadesuit$ is any binary operation on real numbers, possibly noncommutative, is $x*y=(x\spadesuit y)\star(y\spadesuit x)$ commutative?
