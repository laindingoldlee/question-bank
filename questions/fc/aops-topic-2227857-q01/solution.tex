A $5$-digit palindrome is $\overline{abcba}=10001a+1010b+100c$ with $a\in\{1,\ldots,9\}$ and $b,c\in\{0,\ldots,9\}$, so there are $900$ of them. Pair each palindrome $\overline{abcba}$ with $\overline{a'b'c'b'a'}$, where $a'=10-a$, $b'=9-b$, $c'=9-c$; this is again a $5$-digit palindrome, and the pair sums to
\[10001\cdot10+1010\cdot9+100\cdot9=100010+9090+900=110000 .\]
(The pairing never matches a palindrome with itself, since $b=9-b$ is impossible.) So the $900$ palindromes form $450$ pairs, and the sum is $450\cdot110000=\boxed{49\,500\,000}$.
