Choose $f(0)$ arbitrarily and choose the two values $f(1),f(-1)$ independently from $\{-1,1\}$. Choose any function $g$ taking nonzero real values on $\{x:|x|>1\}$. Define $f(x)=g(x)$ there, and for $0<|x|<1$ set
\[
f(x)=\dfrac{1}{g(\dfrac{1}{x})}.
\]
These choices give every solution. Indeed, the reciprocal map pairs the points with $|x|>1$ with those with $0<|x|<1$, and each pair must have reciprocal nonzero values. Its only fixed points are $\pm1$, at which the value must square to one; zero is unrestricted. Conversely these rules directly satisfy the equation. Power functions are only a small subfamily.
