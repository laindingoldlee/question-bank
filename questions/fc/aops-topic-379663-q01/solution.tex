\textbf{(A) is impossible:} $a>0$ and $c>b$ give $a+c>c>b$.

All the others can happen:
\begin{itemize}
\item (B) $a=1$, $b=2$, $c=3$: $ab=2<3$.
\item (C) $a=1$, $b=2$, $c=4$: $a+b=3<4$.
\item (D) $a=\dfrac{1}{10}$, $b=1$, $c=2$: $ac=\dfrac{1}{5}<1$.
\item (E) $a=\dfrac{1}{2}$, $b=2$, $c=4$: $\dfrac {b}{c}=\dfrac{1}{2}=a$.
\end{itemize}
The answer is $\boxed{\textbf{(A)}}$.
