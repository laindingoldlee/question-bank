\[
\dfrac{(819+n)^2}{n}=\dfrac{819^2}{n}+2\cdot819+n .
\]
This is an integer exactly when $n$ divides $819^2$. The divisors of $819^2$ include the negative ones, the least of which is $-819^2$. So the least $n$ is $\boxed{-670761}$ (then the expression equals $\dfrac{(819-670761)^2}{-670761}=-669124$, an integer).

If only positive $n$ are allowed, the least value is simply $n=1$, which is why the problem is interesting only with negative values allowed.
