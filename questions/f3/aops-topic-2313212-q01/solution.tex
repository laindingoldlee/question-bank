\textbf{(a)} For $k\ge2$ we have $(k-1)^2=k^2-2k+1\le k^2-1<k^2$, so $k-1\le\sqrt{k^2-1}<k$ and $\left[\sqrt{k^2-1}\right]=k-1$. Hence
\[\sum_{k=2}^{n}\left[\sqrt{k^2-1}\right]=1+2+\cdots+(n-1)=\dfrac{n(n-1)}{2}.\]
For $n=2$ this is $1$, while $\dfrac{(n-1)n(4n+1)}{6}=3$; so the two expressions are different.

\textbf{(b)} For $m=1,2,\dots,n-1$, we have $\left[\sqrt k\right]=m$ exactly when $m^2\le k\le(m+1)^2-1$, which happens for $(m+1)^2-m^2=2m+1$ values of $k$. These blocks of values of $k$ cover $1,2,\dots,n^2-1$ exactly once. Therefore
\[\sum_{k=1}^{n^2-1}\left[\sqrt k\right]=\sum_{m=1}^{n-1}m(2m+1)=2\cdot\dfrac{(n-1)n(2n-1)}{6}+\dfrac{(n-1)n}{2}=\dfrac{(n-1)n\bigl(2(2n-1)+3\bigr)}{6}=\dfrac{(n-1)n(4n+1)}{6}.\]
$\blacksquare$
