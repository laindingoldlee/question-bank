B\textquotesingle s report cannot be entirely true: it forces three against-votes, leaving at most three for-votes, so a strict majority for is impossible. The same argument excludes F\textquotesingle s report. If C\textquotesingle s report is true, A and F vote against. Any of A,D,E being truthful would additionally force C against, again preventing more for-votes than against-votes. Thus C could be the only truthful report among A,C,D,E, contrary to there being three. Hence C\textquotesingle s report is false too. Therefore the three entirely true reports are $\boxed{A,D,E}$. Feasibility is witnessed by votes $(0,+,-,+,0,+)$, where $0$ means abstention.
