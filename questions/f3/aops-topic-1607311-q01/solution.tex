Each flip is tails with probability $\dfrac{3}{7}$, independently. Exactly six tails (and four heads) can occur in $\dbinom{10}{6}=210$ orders, each with probability $\left(\dfrac{3}{7}\right)^6\left(\dfrac{4}{7}\right)^4$. So
\[
P=210\cdot\dfrac{3^6\cdot4^4}{7^{10}}=\dfrac{210\cdot729\cdot256}{282\,475\,249}=\dfrac{39\,191\,040}{282\,475\,249}.
\]
The only common factor is one $7$ (from $210=2\cdot3\cdot5\cdot7$), so in lowest terms
\[
P=\boxed{\dfrac{5\,598\,720}{40\,353\,607}}\approx0.139 .
\]
