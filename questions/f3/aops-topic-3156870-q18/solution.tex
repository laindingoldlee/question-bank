The names below twenty and the tens names determine every value unambiguously. Exact enumeration gives the sole two-cycle $ 14\leftrightarrow16 $: FOURTEEN has 8 letters and SIXTEEN has 7. Hence $\boxed{x+y=30}$.
\begin{verbatim}
small=['','one','two','three','four','five','six','seven','eight','nine',
       'ten','eleven','twelve','thirteen','fourteen','fifteen','sixteen',
       'seventeen','eighteen','nineteen']
tens=['','','twenty','thirty','forty','fifty','sixty','seventy','eighty','ninety']
def f(n):return 2*len(small[n] if n<20 else tens[n//10]+small[n%10])
assert [(x,f(x)) for x in range(1,100) if x<f(x)<100 and f(f(x))==x]==[(14,16)]
\end{verbatim}
