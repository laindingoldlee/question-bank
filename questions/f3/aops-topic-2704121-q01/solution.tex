$\dfrac{n(n+1)(2n+1)}{6}-\dfrac{n(n+1)}{2}=\dfrac{n(n+1)(2n-2)}{6}=\dfrac{(n-1)n(n+1)}{3}$. So $(n-1)n(n+1)=6539016$. Since $187^3\approx6.54\cdot10^6$, try $n=187$: $186\cdot187\cdot188=6539016$. Hence $n=\boxed{187}$.
