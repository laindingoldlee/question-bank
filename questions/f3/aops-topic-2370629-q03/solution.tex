Let $a_k(d)$ be the number of valid strings of $k$ digits that start with a nonzero digit and end with the digit $d$. Then $a_1(d)=1$ for $d=1,\dots,9$ and $a_1(0)=0$, and for $k\ge1$
\[a_{k+1}(d)=a_k(d-2)+a_k(d-1)+a_k(d+1)+a_k(d+2),\]
where terms with an index outside $0,\dots,9$ are $0$. The values (columns $d=0,1,\dots,9$) are:

For example, $a_2(0)=a_1(1)+a_1(2)=2$ and $a_3(1)=a_2(0)+a_2(2)+a_2(3)=2+3+4=9$. The number of $10$-digit integers is the total in the last row, $\boxed{965561}$.
