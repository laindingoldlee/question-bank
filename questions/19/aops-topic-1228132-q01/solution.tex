Squares of $0,1,2,3,4,5,6$ modulo $7$ are $0,1,4,2,2,4,1$. So the possible remainders are $0,1,2,4$, and a square can never leave remainder $\boxed{3,\ 5\text{ or }6}$. (For a nonzero integer, $0$ is still possible, e.g. $7^2$.)
