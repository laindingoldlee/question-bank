Place $A=(0,0)$, $B=(20,0)$, $C=(20,6)$, $D=(0,6)$. Line $DA$ is $x=0$ and line $CD$ is $y=6$, so the point inside the rectangle is $P=(12,1)$.

\begin{asy}

fill(A--P--C--D--cycle,rgb(0.8,0.88,1));
draw(A--B--C--D--cycle,linewidth(1));
draw(A--P--C,blue+linewidth(1));
draw(B--P,dashed);
draw(P--(0,1),dotted);draw(P--(12,6),dotted);
dot(P);
label("$A$",A,SW);label("$B$",B,SE);label("$C$",C,NE);label("$D$",D,NW);label("$P$",P,1.8*NW);
label("$20$",(10,0),S);label("$6$",(20,3),E);
label("$12$",(6,1),N);label("$5$",(12,3.5),W);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline

Quadrilateral $APCD$ is the rectangle minus triangles $ABP$ and $BCP$:
\begin{itemize}
\item $[ABP]=\dfrac{1}{2}\cdot AB\cdot(\text{height of }P\text{ above }AB)=\dfrac{1}{2}\cdot20\cdot1=10$;
\item $[BCP]=\dfrac{1}{2}\cdot BC\cdot(\text{distance from }P\text{ to }BC)=\dfrac{1}{2}\cdot6\cdot8=24$.
\end{itemize}
So $[APCD]=20\cdot6-10-24=\boxed{86}$.
