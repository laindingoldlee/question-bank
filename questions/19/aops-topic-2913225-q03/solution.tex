The value is nondecreasing in $x$. The median of the $1001$ values is the value at $x=500$: $\lfloor22.36+7.94\rfloor=30$. The mode is the value attained most often, i.e. with the longest run. Near the top the increments slow down: the value $39$ is attained for the $50$ integers $x=868,\dots,917$ and $40$ for the $50$ integers $x=918,\dots,967$; no value lasts longer. Taking the mode as $39$ (the first of the tied values; $40$ gives difference $10$), the difference is $\boxed{9}$.
