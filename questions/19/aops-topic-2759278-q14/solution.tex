$2a+3b=95$ with $a,b\ge0$. Then $b$ is odd and $3b\le95$, so $b\in\{1,3,\dots,31\}$: $16$ values, each giving a different $a=\dfrac{95-3b}2$. Answer $\boxed{\textbf{(A)}\ 16}$.
