Since $n\equiv-2\pmod{n+2}$, $n^4+3\equiv16+3=19$, so $n+2$ must divide $19$: $n+2\in\{\pm1,\pm19\}$, i.e. $n\in\{-1,-3,17,-21\}$.
\begin{itemize}
\item $n=-1$: $\dfrac{4}{1}=4$. \checkmark
\item $n=-3$: $\dfrac{84}{-1}=-84$, not positive.
\item $n=17$: $\dfrac{83524}{19}=4396$. \checkmark
\item $n=-21$: $\dfrac{194484}{-19}<0$.
\end{itemize}
So $n=\boxed{-1\text{ or }17}$.
