Before one success, the expected number of failures is $\dfrac{\dfrac{3}{5}}{\dfrac{2}{5}}=\dfrac{3}{2}$: conditioning on the first shot gives $F=\dfrac{3}{5}(1+F)$. Thus there are $5\cdot\dfrac{3}{2}=\dfrac{15}{2}$ expected failures before five successes. Each breaks a club with probability $\dfrac{1}{2}\cdot\dfrac{4}{5}=\dfrac{2}{5}$, so the expected number is $\dfrac{15}{2}\cdot\dfrac{2}{5}=\boxed3$.
