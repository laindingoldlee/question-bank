He walks at $7$ meters per minute, so the distance is
\[70n+7(120-n)=840+63n,\qquad 1\le n\le 120.\]
This is at least $903$, which rules out (A), (B), (C). For (D), $1000-840=160$ is not a multiple of $63$. For (E), $1281-840=441=63\cdot7$, so $n=7$ works. The answer is $\boxed{\textbf{(E) } 1281}$.
