A man drives for the first $n$ minutes, where $n$ is a positive integer, and then walks for the remaining $120-n$ minutes. He drives at $70$ meters per minute and walks at $\dfrac{1}{10}$ of that rate. Which of the following could be the total distance he covers, in meters?

$\textbf{(A) } 840\qquad\textbf{(B) } 830\qquad\textbf{(C) } 120\qquad\textbf{(D) } 1000\qquad\textbf{(E) } 1281$
