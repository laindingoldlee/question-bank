Find the error in the following argument.

``We know that $a^{\dfrac bc}=\sqrt[c]{a^b}$. This means that $(-1)^{\dfrac35}=\sqrt[5]{(-1)^3}=\sqrt[5]{-1}=-1$. It also means that $(-1)^{\dfrac{6}{10}}=\sqrt[10]{(-1)^6}=\sqrt[10]{1}=1$. Since $\dfrac35=\dfrac{6}{10}$, we have $(-1)^{\dfrac35}=(-1)^{\dfrac{6}{10}}$, and therefore $1=-1$.''

What is the correct value of $(-1)^{\dfrac35}$ as a real number?
