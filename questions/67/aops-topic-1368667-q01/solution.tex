Treat each pair as a block. Rotate the table so that the farmers' block comes first (clockwise). Going clockwise, the other two blocks come in one of two orders:
\[F\,F\,L\,L\,M\,M\qquad\text{or}\qquad F\,F\,M\,M\,L\,L .\]
These are different: one is the mirror image of the other, and no rotation turns one into the other (the lawyers are clockwise-next to the farmers in the first but not in the second). So there are $\boxed{2}$ seatings.

\textbf{The error.} Count seatings in the six labelled seats first. The three blocks occupy either seats $\{1,2\},\{3,4\},\{5,6\}$ or seats $\{2,3\},\{4,5\},\{6,1\}$ ($2$ ways), and the blocks can be assigned to these positions in $3!=6$ ways, giving $12$ labelled seatings. No seating is unchanged by a nontrivial rotation, so each rotation class has $6$ members and the answer is $\dfrac{12}{6}=2$. The student's $3\cdot2\cdot1=6$ counts only the block orders and forgets the factor $2$ for the two ways the blocks can sit relative to the seats, but still divides by all $6$ rotations. (Only if mirror images were also considered the same would the answer be $1$.)
