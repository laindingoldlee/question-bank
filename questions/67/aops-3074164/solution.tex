Multiply by ratios of equal quantities, each equal to one: $60\dfrac{\mathrm{mi}}{\mathrm{h}}\cdot\dfrac{5280\mathrm{ft}}{1\mathrm{mi}}\cdot\dfrac{1\mathrm{h}}{3600\mathrm{s}}=\boxed{88\dfrac{\mathrm{ft}}{\mathrm{s}}}$. Cancelling a unit with the same unit in the denominator expresses the same physical quantity using a different unit; the factors change the numerical measure without changing the speed.
