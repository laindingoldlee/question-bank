$4^{-1}$ modulo $9$ means a number $x$ with $4x\equiv1\pmod9$. Since $4\cdot7=28=3\cdot9+1$, $x=7$ works, so $4^{-1}\equiv\boxed{7}\pmod9$. To find it in general, use the Euclidean algorithm: $9=2\cdot4+1$, so $1=9-2\cdot4$, giving $4\cdot(-2)\equiv1$ and $-2\equiv7\pmod9$.
