A single-elimination tournament starts with $64$ teams and has six rounds. A correct prediction in round $r$ earns $10\cdot2^{r-1}$ points. (a) Find the expected score if every game prediction has marginal correctness probability $\dfrac{3}{4}$. (b) In a different model, a predicted winner of a round-$r$ game is correct with probability $(\dfrac{3}{4})^r$. Find that expected score. (c) Explain why the fraction of correct predictions alone does not determine the score.
