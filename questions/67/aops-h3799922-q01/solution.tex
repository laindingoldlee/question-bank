There are $2^{6-r}$ games in round $r$, so each round has $2^{6-r}\cdot10\cdot2^{r-1}=320$ possible points. By linearity of expectation, (a) gives $6\cdot320\cdot\dfrac{3}{4}=\boxed{1440}$.
For (b), the expectation is
\[320\sum_{r=1}^{6}\left(\dfrac{3}{4}\right)^r=960\left(1-\left(\dfrac{3}{4}\right)^6\right)=\boxed{\dfrac{50505}{64}}.\]
The two answers use different marginal probabilities. (c) Later-round successes carry larger weights. For example, predicting only the eventual champion's six-game path correctly gives $10+20+40+80+160+320=630$ points from six correct predictions, whereas predicting all $32$ first-round games correctly and none later gives $320$ points. Thus a higher unweighted accuracy can have a lower score.
