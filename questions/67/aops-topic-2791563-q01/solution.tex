If Red is Papa, then "I'm Green's daughter" is false, so "I'm Blue's dad" is true and Blue is Baby; then Green is Mama, and both of Blue's statements are true, impossible. If Red is Mama, both of her statements are false. So Red is Baby; "I'm Blue's dad" is false, so "I'm Green's daughter" is true: Baby is a girl. Now Blue's second statement ("Red and Green are my parents") is false, so the first is true: Red (a girl) and Green have opposite genders, so Green is Papa. Hence $\boxed{\text{Baby: red, Papa: green, Mama: blue}}$.
