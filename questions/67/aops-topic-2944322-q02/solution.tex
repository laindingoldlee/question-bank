No digit can be $0$. Every digit can end up last, so every digit is even. For digits $x,y$ in the last two places, $10x+y\equiv2x+y\equiv y\pmod4$ (as $x$ is even). So every digit is a multiple of $4$, i.e. each digit is $4$ or $8$. With $k$ fours, the digit sum is $4k+8(4-k)=32-4k$, which is divisible by $3$ iff $k\equiv2\pmod3$, so $k=2$. The numbers are the arrangements of $4,4,8,8$: $\dbinom42=\boxed{6}$ ($4488,4848,4884,8448,8484,8844$).
