$E\left[\dfrac xa+\dfrac xb\right]=\dfrac{11}{2}\left(\dfrac1a+\dfrac1b\right)$, which equals $1$ exactly when $\dfrac1a+\dfrac1b=\dfrac2{11}$, i.e. $(2a-11)(2b-11)=121$. With $a\ne b$ positive, $\{2a-11,2b-11\}=\{1,121\}$, so $\{a,b\}=\{6,66\}$. Then the expectation is exactly $1$ and $a+b=\boxed{72}$. (Allowing negative integers would also permit $\{5,-55\}$.)
