Solving the linear recurrence gives
\[
a_n=\left(a_0-\dfrac{1}{5}\right)(-3)^n+\dfrac{1}{5}\,2^n.
\]
This follows by subtracting the particular solution $\dfrac{1}{5}\,2^n$, leaving a sequence multiplied by $-3$. Put $C=a_0-\dfrac{1}{5}$. Then
\[
a_{n+1}-a_n=-4C(-3)^n+\dfrac{1}{5}\,2^n.
\]
If $C\ne0$, along one parity of $n$ the first term is negative, and its magnitude eventually exceeds the second because $\left(\dfrac{3}{2}\right)^n\to\infty$. Hence strict increase fails. If $C=0$, every difference is positive. Thus $\boxed{a_0=\dfrac{1}{5}}$.
