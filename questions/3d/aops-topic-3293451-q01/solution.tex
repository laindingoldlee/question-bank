The last term is $10^{51}+1$, so the total is $1+\sum_{j=1}^{51}(10^j+1)=\sum_{j=1}^{51}10^j+52$. Before adding $52$, the decimal digits are fifty-one ones followed by zero. Adding $52$ changes the tens digit from $1$ to $6$ and the units digit to $2$, with no further carry. Fifty ones remain, so the digit sum is $\boxed{50+6+2=58}$.
