Work modulo $9$. Cubes modulo $9$ are only $0,1,8$: indeed $0^3\equiv(\pm3)^3\equiv0$, $(\pm1)^3\equiv\pm1$, $(\pm2)^3=\pm8\equiv\mp1$ and $(\pm4)^3=\pm64\equiv\pm1$. Since $144=9\cdot16$, the equation gives $x^3\equiv2\pmod9$, which is impossible. So there are $\boxed{0}$ such pairs.
