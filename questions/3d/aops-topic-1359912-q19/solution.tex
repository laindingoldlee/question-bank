Reflecting across $x=1$ sends $(x,y)$ to $(2-x,y)$, so $(0,0)\mapsto(2,0)$. Reflecting across $y=2$ sends $(x,y)$ to $(x,4-y)$, so $(2,0)\mapsto(2,4)$.

\begin{asy}
usepackage("amsmath");
size(4.5cm);
defaultpen(fontsize(10pt));
import graph;
draw((-0.8,0)--(3.2,0),gray,Arrow(4)); draw((0,-0.8)--(0,4.8),gray,Arrow(4));
label("$x$",(3.2,0),E,gray); label("$y$",(0,4.8),W,gray);
draw((1,-0.6)--(1,4.6),blue+dashed); draw((-0.6,2)--(3,2),red+dashed);
label("$x=1$",(1,4.6),E,blue); label("$y=2$",(3,2),N,red);
pair O=(0,0), P=(2,0), Q=(2,4);
draw(O--P,Arrow(6)); draw(P--Q,Arrow(6));
dot(O); dot(P); dot(Q);
label("$(0,0)$",O,SW); label("$(2,0)$",P,SE); label("$(2,4)$",Q,E);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

The resulting point is $\boxed{(2,4)}$.
