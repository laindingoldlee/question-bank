For each integer $1 \le n \le 10$, Abe writes the number $2^n + 1$ on a blackboard. Each minute, he takes two numbers $a$ and $b$, erases them, and writes $\dfrac{ab-1}{a+b-2}$ instead. After $9$ minutes, there is one number $C$ left on the board. The minimum possible value of $C$ can be expressed as $\dfrac{p}{q}$ for relatively prime positive integers $p, q$. Find $p + q$.
