There are $9000$ four-digit numbers. Those with no $9$ number $8\cdot9^3=5832$ (first digit $1$--$8$, others $0$--$8$). Those with neither $9$ nor $8$ number $7\cdot8^3=3584$. So $5832-3584=2248$ numbers qualify, and the probability is
\[\dfrac{2248}{9000}=\boxed{\dfrac{281}{1125}\approx0.2498}.\]
