$\dbinom{1}{2n}$ is the number of ways to choose $2n$ objects from a set of $1$ object. Since $2n\ge2>1$, this is impossible, so $\dbinom1{2n}=\boxed{0}$.

$C_{2n}^1=\dbinom{2n}{1}$ is the number of ways to choose $1$ object from $2n$ objects, so $C_{2n}^1=\boxed{2n}$.

The two expressions differ because the roles of the two numbers are swapped: in $\dbinom{1}{2n}$ the set has $1$ element, while in $C_{2n}^1$ it has $2n$ elements. (The symbol that equals $C_{2n}^1$ is $\dbinom{2n}{1}$.)
