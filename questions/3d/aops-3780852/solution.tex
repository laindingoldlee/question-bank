The value 8 is attained by $(a,b,c,d,e)=(1,3,9,2,4)$. To prove minimality, if $a\ge3$ the expression exceeds $3\cdot3=9$. If $a=2$, distinctness gives $d+e\ge4$, so it exceeds 8. Thus a value below 8 would require $a=1$. Then $d+e\ge5$. If $d+e\ge7$, positivity makes the expression greater than 7, so no smaller integer is possible. If $d+e=5$, its digits are 2 and 3, forcing $b\ge4,c\le9$, and the value is at least $5 (1 + \dfrac{4}{9}) > 7$. If $d+e=6$, the available minimum ratio is $\dfrac{3}{9}$, giving at least 8. Thus the smallest integer is $\boxed8$.
