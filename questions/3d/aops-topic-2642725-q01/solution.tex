There are $400$ red and $100$ blue balls. Only red balls are removed, so the $100$ blue balls must make up $25\%$ of the remaining balls. Then $400$ balls remain, so $\boxed{100}$ red balls must be removed. (Check: $\dfrac{300}{400}=75\%$.)
