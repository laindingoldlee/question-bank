Translate each equation.
\begin{itemize}
\item $(x\#y)\,@\,z=(x+2y)-z$, so $x+2y-z=4$.
\item $x\#\dfrac {y}{2}=x+y$, so $\left[x+(x+y)\right]@\,(-z)=2x+y+z$, and $2x+y+z=-2$.
\item $(x\#y)\,@\,(-z)=x+2y+z$, so $x+2y+z=2$.
\end{itemize}
Subtracting the first equation from the third gives $2z=-2$, so $z=-1$. Then $x+2y=3$ and $2x+y=-1$. Doubling the second and subtracting the first: $3x=-5$, so $x=-\dfrac{5}{3}$ and $y=-1-2x=\dfrac{7}{3}$. The solution is
\[
\boxed{(x,y,z)=\left(-\dfrac{5}{3},\ \dfrac{7}{3},\ -1\right)}.
\]
(Check: $-\dfrac{5}{3}+\dfrac{14}{3}+1=4$, $-\dfrac{10}{3}+\dfrac{7}{3}-1=-2$, $-\dfrac{5}{3}+\dfrac{14}{3}-1=2$.)
