Each identical tunnel requires $100000$ worker-years. Productivity adds and all workers have the same rate. Complete the four cases: (a) $10000$ workers build four tunnels: time? (b) $10000$ workers work two years: tunnels? (c) $20000$ workers build eight tunnels: time? (d) Two tunnels in half a year: workers?
