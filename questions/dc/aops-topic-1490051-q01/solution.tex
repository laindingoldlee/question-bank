Let the grandson be $s\ge1$ and the grandfather $g$ years old, with $g>s$. For $k=0,1,\dots,5$ we need $s+k\mid g+k$. Since $s+k\mid s+k$, this is equivalent to
\[
s+k\mid (g+k)-(s+k)=g-s\qquad(k=0,1,\dots,5).
\]
So $g-s$ is a positive multiple of $L=\operatorname{lcm}(s,s+1,\dots,s+5)$.
\begin{itemize}
\item Any six consecutive integers include a multiple of $4$, a multiple of $3$ and a multiple of $5$, so $L$ is always a multiple of $60$. If $s\ge2$, then $L=60$ would need all of $s,s+1,\dots,s+5$ to divide $60$; but the divisors of $60$ that are at least $2$ are $2,3,4,5,6,10,12,\dots$, which contain no run of six consecutive integers. Hence $L\ge120$ and $g\ge s+L>120$, impossible.
\item If $s=1$, then $L=\operatorname{lcm}(1,2,3,4,5,6)=60$, so $g-1\in\{60,120,\dots\}$; with $g<120$ this forces $g=61$.
\end{itemize}
Check: $61,62,63,64,65,66$ are divisible by $1,2,3,4,5,6$ respectively. The grandfather is $\boxed{61}$ and the grandson is $\boxed{1}$.
