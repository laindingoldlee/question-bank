Count the $s$'s: Lee's ($1$), sis ($2$), is ($1$), Mississippi ($4$), miss ($2$), Chriss ($2$): $12$ in all. The last one is shifted by $1+2+\cdots+12=78=3\cdot26$ places, a whole number of laps around the alphabet. So it is replaced by $\boxed{s}$ itself.
