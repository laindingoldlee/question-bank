A number with exactly $4$ divisors is either $p^3$ or $pq$ for distinct primes $p,q$.
\begin{itemize}
\item $a=p^3$: if $p=3$, then $3a=3^4$ has $5$ divisors; if $p\ne3$, then $3a=3p^3$ has $2\cdot4=8$. Neither is $6$.
\item $a=pq$ with $3\nmid a$: $3a=3pq$ has $8$ divisors. No.
\item $a=3q$ with $q\ne3$ prime: $3a=3^2q$ has $3\cdot2=6$ divisors. Yes.
\end{itemize}
So $a=3q$ and $a^2=3^2q^2$ has $3\cdot3=\boxed{9}$ divisors. (For example $a=6$: $18$ has $6$ divisors and $36$ has $9$.)
