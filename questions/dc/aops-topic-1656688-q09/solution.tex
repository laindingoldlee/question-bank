Multiplying by $x-1$ gives $x^5-1=0$, so $x^5=1$ (and $x\ne1$). Then $x^4=\dfrac{1}{x}$ and $\dfrac{1}{x^4}=x$, so
\[
x^4+\dfrac{1}{x^4}=x+\dfrac{1}{x}=:y .
\]
Dividing the given equation by $x^2$: $x^2+\dfrac{1}{x^2}+x+\dfrac{1}{x}+1=0$, i.e.\ $(y^2-2)+y+1=0$, so $y^2+y-1=0$ and
\[
y=\dfrac{-1\pm\sqrt5}{2}.
\]
Both values occur (for the four roots $x$). The positive value is $\boxed{\dfrac{\sqrt5-1}{2}}$.
