Going from an $(n-1)\times(n-1)$ square to an $n\times n$ square adds $n^2-(n-1)^2=2n-1$ tiles. The last step adds $25=2n-1$ tiles, so $n=13$. The floor is a $\boxed{13\times13}$ square of tiles, using $169$ tiles in all. (Check: $1+3+5+\cdots+25=13^2=169$.)
