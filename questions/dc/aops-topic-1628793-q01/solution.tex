Suppose $2\sqrt3=\dfrac {p}{q}$ with positive integers $p,q$. Squaring, $12=\dfrac{p^2}{q^2}$, so $\sqrt3=\dfrac{p}{2q}$ would be rational. We show it is not.

Suppose $\sqrt3=\dfrac {a}{b}$ in lowest terms, with positive integers $a,b$. Then $a^2=3b^2$, so $3\mid a^2$. Since $3$ is prime, $3\mid a$; write $a=3c$. Then $9c^2=3b^2$, so $b^2=3c^2$ and in the same way $3\mid b$. Then $3$ divides both $a$ and $b$, contradicting lowest terms. So $\sqrt3$ is irrational.

Therefore $2\sqrt3$ is irrational too: if it were rational, so would be $\sqrt3=\dfrac{1}{2}\cdot2\sqrt3$. $\blacksquare$
