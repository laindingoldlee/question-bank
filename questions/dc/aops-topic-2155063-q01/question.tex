Four girls, Frances, Gabi, Heidi and Iris, take the four places $1$st to $4$th in a running contest, with no ties. Afterwards each girl says where she placed:
\begin{itemize}
\item Frances: ``I placed neither first nor fourth.''
\item Gabi: ``I did not place first.''
\item Heidi: ``I placed first.''
\item Iris: ``I placed fourth.''
\end{itemize}
A reliable witness says that exactly three of these statements are true and one is false. In what place did Gabi finish?
