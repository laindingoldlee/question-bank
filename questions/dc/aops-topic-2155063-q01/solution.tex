Consider which statement is false.
\begin{itemize}
\item \emph{Heidi's.} Then Heidi is not first; Frances and Gabi are not first (their statements are true) and Iris is fourth. Nobody is first, impossible.
\item \emph{Frances's.} Then Frances is first or fourth. Heidi is first and Iris is fourth (true statements), so there is no place for Frances. Impossible.
\item \emph{Gabi's.} Then Gabi is first, but Heidi is first too. Impossible.
\item \emph{Iris's.} Then Heidi is first, Iris is not fourth, and Frances is neither first nor fourth. So Frances and Iris take second and third, and Gabi is fourth, consistent with her true statement.
\end{itemize}
So Iris's statement is the false one and Gabi finished \boxed{4\text{th}}.
