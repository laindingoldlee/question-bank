Let the common ratio be $k$. The resulting homogeneous linear system has matrix $\begin{pmatrix}1&-k&-k\\-3k&1&-3k\\-k&-3k&1\end{pmatrix}$. A nonzero solution requires determinant $1-13k^2-12k^3=-(k+1)(4k-1)(3k+1)=0$. If $k=-1$, the equations force $b=0,a=-c$, making $3a+3c=0$, forbidden. If $k=-\dfrac{1}{3}$, they force $a=0,b=-c$, making $b+c=0$, also forbidden. For $k=\dfrac{1}{4}$, solving after scaling $c=1$ gives $a=\dfrac{7}{13},b=\dfrac{15}{13}$; all denominators are nonzero. Therefore the only value is $\boxed{\dfrac{22}{13}}$.
