The pairs are $(n,n+1)$ with $2000\le n\le2999$. Write $n=\overline{2abc}$.
\begin{itemize}
\item $c\le8$: then $n+1=\overline{2ab(c+1)}$. No carrying requires $c+(c+1)\le9$, $b+b\le9$, $a+a\le9$ (and $2+2\le9$), i.e. $a,b,c\in\{0,\ldots,4\}$: $5^3=125$ pairs.
\item $c=9$, $b\le8$: $n+1=\overline{2a(b+1)0}$. Units: $9+0$; tens: $b+(b+1)\le9$; hundreds: $2a\le9$. So $a,b\le4$: $25$ pairs.
\item $c=b=9$, $a\le8$: $n+1=\overline{2(a+1)00}$. Need $a+(a+1)\le9$, so $a\le4$: $5$ pairs.
\item $n=2999$: $2999+3000=5999$ involves no carrying: $1$ pair.
\end{itemize}
The total is $125+25+5+1=\boxed{156}$.
