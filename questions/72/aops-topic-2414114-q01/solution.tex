Subtracting $44$ from each of the integers $45,46,\dots,317$ turns the list into $1,2,\dots,273$, which has $273$ members. So there are $317-45+1=\boxed{273}$ integers. (The difference $317-45=272$ counts the steps from one integer to the next; the list has one more integer than steps.)
