Cutting a log into $4$ pieces takes $3$ cuts, so each cut takes $\dfrac{12}{3}=4$ minutes. Cutting a log into $6$ pieces takes $5$ cuts, which take $5\cdot4=\boxed{20\text{ minutes}}$ (not $18$ minutes, which would come from treating the time as proportional to the number of pieces).
