Use complementary counting with inclusion-exclusion. There are $9000$ four-digit integers.
\begin{itemize}
\item With no digit $1$: the first digit has $8$ choices (not $0$ or $1$) and each other digit $9$, so $8\cdot9^3=5832$.
\item With no digit $7$: likewise $5832$.
\item With neither $1$ nor $7$: $7\cdot8^3=3584$.
\end{itemize}
The integers lacking a $1$ or lacking a $7$ number $5832+5832-3584=8080$. So the answer is
\[
9000-8080=\boxed{920}.
\]
