A performance is a $3$-element subset of the $12$ songs, so there are
\[
\binom{12}{3}=\dfrac{12\cdot11\cdot10}{3\cdot2\cdot1}=220
\]
performances. The answer is $\boxed{\textbf{(D)}\ 220}$. (If the order of the songs mattered, there would be $12\cdot11\cdot10=1320$, which is not among the choices.)
