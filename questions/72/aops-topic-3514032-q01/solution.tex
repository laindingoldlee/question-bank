Only units digits $0,2,4,5,6,8$ guarantee compositeness: for each of $1,3,7,9$ there is a two-digit prime ending in that digit ($11,13,17,19$). If the tens digit is $1$ modulo $3$, eligible units digits are $2,5,8$; if it is $0$ modulo $3$, they are $0,6$; if it is $2$ modulo $3$, the only eligible units digit is $4$. Basilio can identify the number only in the last case. Thus Crispin received $\boxed4$.
