Let original side be $s$ and inradius $r=\dfrac{s\sqrt3}{6}$. Each new line is shifted outward by $s$, so the larger concentric equilateral triangle has inradius $r+s$. The similarity factor is $1+\dfrac{s}{r}=1+2\sqrt3$, giving area ratio $\boxed{(1+2\sqrt3)^2=13+4\sqrt3}$. This ratio is irrational.
\begin{asy}
usepackage("amsmath");
size(7cm);
pair[] V={(-.5,0),(.5,0),(0,sqrt(3)/2)};pair I=(0,sqrt(3)/6);real k=1+2*sqrt(3);for(int j=0;j<3;++j){pair P=V[j],Q=V[(j+1)%3],v=Q-P,n=(v.y,-v.x);draw(P--Q--Q+n--P+n--cycle,gray);draw((I+k*(P-I))--(I+k*(Q-I)),blue);}draw(V[0]--V[1]--V[2]--cycle);
label("$A$",V[0],SW);label("$B$",V[1],SE);label("$C$",V[2],N);label("larger triangle",(0,-1.2),S);
\end{asy}
