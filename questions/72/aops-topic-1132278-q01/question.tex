A student argues as follows.

``Every perfect number has the form $2^{p-1}(2^p-1)$, where $2^p-1$ is a Mersenne prime. Since $p\ge 2$, the factor $2^{p-1}$ is even, so every perfect number is even. Hence there are no odd perfect numbers.''

Find the error in this argument.
