$360=2^3\cdot3^2\cdot5$. For each prime with exponent $e$, the exponents in $x,y$ are in $\{0,\dots,e\}$ with maximum $e$: $2e+1$ choices. So there are $7\cdot5\cdot3=105$ ordered pairs. Exactly one has $x=y$ (namely $360,360$), so the number of unordered pairs is $\dfrac{105-1}2+1=\boxed{53}$.
