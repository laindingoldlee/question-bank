Since $2\equiv-1\pmod3$, we have $2^n\equiv(-1)^n\pmod 3$, which is $1$ for even $n$ and $-1\equiv2$ for odd $n$.

\textbf{(1)} If $3\mid2^n-1$, then $2^n\equiv1$. For odd $n$ we would have $2^n\equiv2\not\equiv1$, so $n$ is even.

\textbf{(2)} If $3\mid2^n-2$, then $2^n\equiv2$. For even $n$ we would have $2^n\equiv1\not\equiv2$, so $n$ is odd. $\blacksquare$

(The converses also hold: $3\mid2^n-1$ for every even $n$, and $3\mid2^n-2$ for every odd $n$.)
