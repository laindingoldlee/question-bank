Six different colours are available. In how many distinguishable ways can the faces of a cube be painted, each face with one colour (not all colours need be used), so that any two faces sharing an edge have different colours? Two colourings are the same if one can be rotated into the other. In particular, explain why exactly $30$ of these colourings use all six colours.
