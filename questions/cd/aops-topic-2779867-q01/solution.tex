Each random pairing is one of the $5!=120$ equally likely matchings of left gloves to right gloves, and exactly one of them matches every pair. So each attempt succeeds with probability $p=\dfrac1{120}$, independently. The number of attempts is geometric, with expectation $\dfrac1p=\boxed{120}$.
