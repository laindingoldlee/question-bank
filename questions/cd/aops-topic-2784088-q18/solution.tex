There are $\dfrac{20\cdot17}2=170$ diagonals. A diagonal joins vertices $k$ apart, $2\le k\le10$; for each $k<10$ there are $20$ of them, and for $k=10$ (the diameters, the longest) there are $10$. The shortest ($k=2$) number $20$. So the probability is $\dfrac{170-20-10}{170}=\boxed{\dfrac{14}{17}}$.
