(a) Take $k=n=2,x=2$. The left side is $8$ and the right side is $10$, so the original claim is false.

(b) First take $k=n+1$. The difference between the two sides is
\[
nx^{n+1}-(2x-1)(x^n+1)
=(n-2)x^{n+1}+(x^n-x^2)+(x-1)^2\ge0.
\]
For the induction step put $L_k=(k-n+1)x-(k-n)=1+(k-n+1)(x-1)$. Then
\[
xL_k-L_{k+1}=(x-1)(L_k-1)\ge0.
\]
Multiplying the inequality at $k$ by $x$ therefore gives the inequality at $k+1$. This proves it for every $k\ge n+1$.

If $x>1$, the square in the base case is positive, so the inequality is strict thereafter. If $x=1$, it reduces to $n\ge2$, with equality exactly at $n=2$. Thus equality holds precisely when $\boxed{x=1,\ n=2}$.
