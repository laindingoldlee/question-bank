The digit set can start at $0,1,2,3,4,$ or $5$. For the five sets not containing zero, all $5!$ permutations form five-digit numbers, giving $5\cdot120=600$. For $\{0,1,2,3,4\}$, exclude the $4!$ permutations starting with zero, leaving $120-24=96$. The total is $\boxed{696}$.
