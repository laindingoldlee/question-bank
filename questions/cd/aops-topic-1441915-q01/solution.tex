Divisors of $n$ come in pairs $\{d,\dfrac{n}{d}\}$, and a pair has only one member exactly when $d=\dfrac{n}{d}$, that is, $d^2=n$. So $n$ has an odd number of divisors exactly when $n$ is a perfect square. The squares below $2010$ are $1^2,2^2,\dots,44^2=1936$ (since $45^2=2025$), so there are $\boxed{44}$ such numbers.
