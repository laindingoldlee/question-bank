Write $v=2v'+1$, and so on, with $v',w',x',y',z'\ge0$. Then $2(v'+w'+x'+y'+z')+5=113$, so $v'+\cdots+z'=54$. By stars and bars the number of solutions is $\binom{54+4}4=\binom{58}4=\boxed{424270}$.
