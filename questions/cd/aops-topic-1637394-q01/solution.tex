Each week Jem keeps $96\%$ of what he had, so after $w$ weeks he has
\[
200\cdot0.96^w\text{ dollars}.
\]
Since $0.96^w>0$ for every $w$, this is never $0$: the amount gets smaller every week (for example below one dollar after $130$ weeks, as $0.96^{130}<0.005$), but it is always positive. So the answer is \boxed{\text{never}}: Jem never reaches exactly $0$ dollars. (Only if the amounts were rounded to whole cents could the money run out; the problem does not say so.)
