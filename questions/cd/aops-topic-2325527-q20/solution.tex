There are $2\cdot5=10$ one-way trips per week, so each is $\dfrac{150}{10}=15$ miles. At $30$ miles per hour this takes $\dfrac{15}{30}=\dfrac12$ hour, i.e. $\boxed{30\text{ minutes}}$.
