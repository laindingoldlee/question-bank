Each step lowers the number of balls in the barrel by exactly $1$, so the process ends after $2016+2017-1=4032$ steps with one ball. Now follow the number of white balls:
\begin{itemize}
\item two whites drawn: it decreases by $2$;
\item two blacks drawn: it does not change (one black returns);
\item one of each: it does not change (the white returns).
\end{itemize}
So the parity of the number of white balls never changes. It starts odd ($2017$), so it is never $0$; in particular the last ball is $\boxed{\text{white}}$. The wise man can predict this with certainty.
