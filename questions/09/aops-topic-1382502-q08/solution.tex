We have $(f\circ g)(x)=f(-x^2)=3(-x^2)-4=-3x^2-4$. Note that $g(x)=-x^2$ means $-(x^2)$, so $g(-2)=-4$, not $4$.

(a) $g(2)=-4$ and $f(-4)=-12-4=\boxed{-16}$.

(b) $g(-2)=-4$ as well, so $(f\circ g)(-2)=\boxed{-16}$.
