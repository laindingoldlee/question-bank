The condition makes the five digits an arithmetic progression $a,a+d,a+2d,a+3d,a+4d$ with integer common difference $d$. If $d=0$, there are $9$ choices for $a$. For $d=1,2$, the valid first digits number $5,1$, respectively. For $d=-1,-2$, they number $6,2$, respectively. No larger absolute difference fits in the digit range $0$ through $9$. Thus the total is $9+5+1+6+2=\boxed{23}$.
