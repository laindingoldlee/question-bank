The denominator factors as $(x+2)(x+3)$, so the function is undefined at $x=-2$ and $x=-3$. The numerator is not zero there ($5\cdot(-2)+2=-8$ and $5\cdot(-3)+2=-13$), so the function is unbounded near both points. The vertical asymptotes are
\[\boxed{x=-2\ \text{and}\ x=-3}.\]
