There are $\dbinom93=84$ equally likely selections. The only other possibility is that all three balls have the same color: $\dbinom43=4$ all-white and $\dbinom53=10$ all-black selections. So the probability is
\[1-\dfrac{4+10}{84}=1-\dfrac16=\boxed{\dfrac56}.\]
