If $x$ is a positive integer root, then $k=x^2-x=x(x-1)$, which is never negative. The values are $0,2,6,12,\dots,72,90,110,\dots$; the largest two-digit one is $10\cdot9$, so $k=\boxed{90}$ (with root $x=10$).
