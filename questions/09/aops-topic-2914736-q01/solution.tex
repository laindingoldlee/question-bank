\emph{Zero.} If one of them is $0$, say $d=0$, then $b^0=1$ but $0^b$ is $0$ or undefined. Impossible.

\emph{Opposite signs.} Say $d>0>b$. Then $d^b=\dfrac1{d^{|b|}}\in(0,1]$ while $b^d$ is a nonzero integer, so both equal $1$. This forces $d=1$ and then $b=b^1=1$, a contradiction.

\emph{Both positive,} with $d<b$. From $\dfrac{\ln d}d=\dfrac{\ln b}b$ and the fact that $\dfrac{\ln x}x$ increases on $(0,e]$ and decreases on $[e,\infty)$, we get $d<e<b$, so $d\in\{1,2\}$. $d=1$ gives $b=1$. $d=2$: $2^b=b^2$ with $b\ge3$; $b=3$ fails, $b=4$ works, and for $b\ge5$, $2^b>b^2$ (by induction). So $\{d,b\}=\{2,4\}$.

\emph{Both negative,} $d=-m$, $b=-n$. Taking reciprocals, $(-m)^n=(-n)^m$. Absolute values give $m^n=n^m$, so $\{m,n\}=\{2,4\}$, and indeed $(-2)^4=(-4)^2=16$.

In every case $\{d,b\}=\{2,4\}$ or $\{-2,-4\}$, so $db=8$. $\blacksquare$
