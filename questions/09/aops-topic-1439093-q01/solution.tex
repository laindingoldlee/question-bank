Divide by $4$: $30\le2x+5y\le40$, so $0\le y\le8$. For each $y$, $x$ runs over the integers with $\dfrac{30-5y}{2}\le x\le\dfrac{40-5y}{2}$ and $x\ge0$:
\[
\begin{array}{c|ccccccccc}
y&0&1&2&3&4&5&6&7&8\\ \hline
x&15\text{--}20&13\text{--}17&10\text{--}15&8\text{--}12&5\text{--}10&3\text{--}7&0\text{--}5&0\text{--}2&0\\
\text{count}&6&5&6&5&6&5&6&3&1
\end{array}
\]
For $y\le6$ the interval for $2x$ has length $10$, so it contains $6$ values of $x$ when $y$ is even and $5$ when $y$ is odd; for $y=7,8$ the lower limit $x\ge0$ cuts it off. The total is $6+5+6+5+6+5+6+3+1=\boxed{43}$.
