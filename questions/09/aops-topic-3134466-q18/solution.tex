For digits $a,b,c,d$, the sum condition is $10a+11(b+c)+d=99$. If $a=1$, this forces $b+c=8,d=1$, incompatible with divisibility by 8 because the integer is odd. If $a=2$, it forces $b+c=7,d=2$. Then the last three digits are $100b+10(7-b)+2=90b+72$, divisible by 8 exactly when $b$ is a multiple of 4. Since $1\le b\le6$, $b=4$, giving $c=3$. Thus $\boxed{2432}$ is the smallest; indeed $24+43+32=99$ and $2432=8(304)$.
