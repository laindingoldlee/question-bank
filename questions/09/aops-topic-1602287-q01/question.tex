A function $f$ is defined on all real numbers by
\[
f(x)=\begin{cases}2+(x-2)^2, & x\le2,\\ k(x), & x>2.\end{cases}
\]
Find the function $k$ (defined for $x>2$) for which $f$ is its own inverse, that is, $f(f(x))=x$ for every real $x$.
