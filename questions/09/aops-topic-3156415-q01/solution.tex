Write $ x=1+7a $. Modulo $ 11 $, $ 7a\equiv1 $, so $ a\equiv8 $ and $ x=57+77b $. Modulo $ 13 $, $ 5+12b\equiv3 $, so $ b\equiv2 $. Hence $\boxed{x=211+1001k\ (k\in\mathbb Z)}$. The three moduli are pairwise coprime, so this is exactly one class modulo their product; direct substitution verifies it.
