Factor out $y$: $y\left(1-\dfrac{1}{a}\right)=b$, i.e. $y\cdot\dfrac{a-1}{a}=b$. Since $a\ne1$ we can divide:
\[
y=\boxed{\dfrac{ab}{a-1}}.
\]
(If $a=1$ the left side is $0$, so there is no solution unless $b=0$, when every $y$ works.)
