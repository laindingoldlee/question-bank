Write the original number as $10a+b$, with $1\le a\le9$ and $0\le b\le9$. The result is $10a+b+6b-3a=7(a+b)$, so every result is divisible by $7$. The input $10$ gives result $7$, so the gcd is exactly $\boxed7$.
