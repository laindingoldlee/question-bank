In a string of digits, any two adjacent digits are read as a two-digit number; for instance, the string $11012$ contains the numbers $10$, $11$ and $12$ (the pair $01$ is not a two-digit number). What is the smallest number of digits in a string that contains every two-digit number from $10$ to $99$, inclusive?
