Let $p_n$ be the probability that mouse $n$ survives. Mouse $n+1$ is eaten only if mouse $n$ is alive and chooses to eat, so $p_{n+1}=1-\dfrac{p_n}2$. From $p_1=1$: $p_2=\dfrac12$, $p_3=\dfrac34$, $p_4=\dfrac58$, $p_5=\dfrac{11}{16}$. So $b-a=16-11=\boxed{5}$.
