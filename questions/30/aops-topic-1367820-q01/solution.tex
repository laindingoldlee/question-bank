Run the Euclidean algorithm on $73$ and $31$:
\[73=2\cdot31+11,\qquad 31=2\cdot11+9,\qquad 11=1\cdot9+2,\qquad 9=4\cdot2+1 .\]
Now work backwards, writing each remainder in terms of $73$ and $31$:
\[1=9-4\cdot2=9-4(11-9)=5\cdot9-4\cdot11=5(31-2\cdot11)-4\cdot11=5\cdot31-14\cdot11,\]
\[1=5\cdot31-14(73-2\cdot31)=33\cdot31-14\cdot73 .\]
Reducing modulo $73$ gives $33\cdot31\equiv1\pmod{73}$, so $x=\boxed{33}$. Check: $31\cdot33=1023=14\cdot73+1$.

\textbf{Why it always works.} If $\gcd(a,m)=1$, the Euclidean algorithm ends with remainder $1$, and back-substitution writes $1=ax+my$ for some integers $x,y$ (B\'ezout's identity). Reducing modulo $m$ gives $ax\equiv1\pmod m$, so $x$ is an inverse of $a$. If $\gcd(a,m)=d>1$ there is no inverse, because $ax-1$ would be a multiple of $m$, hence of $d$, while $d$ divides $ax$ but not $1$.
