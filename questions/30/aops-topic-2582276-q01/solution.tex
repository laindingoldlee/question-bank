\textbf{(a)}
\begin{itemize}
\item $7\mid91$ is true, since $91=7\cdot13$.
\item $91\mid7$ is false: $7=91k$ would need $k=\dfrac1{13}$, which is not an integer.
\item $-4\mid20$ is true, since $20=(-4)\cdot(-5)$.
\item $6\mid0$ is true, since $0=6\cdot0$.
\item $0\mid6$ is false, since $0\cdot k=0\ne6$ for every $k$.
\end{itemize}
So the answers are \boxed{\text{true, false, true, true, false}}.

\textbf{(b)} Write $b=ak$ and $c=al$ with integers $k,l$. Then $mb+nc=a(mk+nl)$, and $mk+nl$ is an integer, so $a\mid mb+nc$. $\blacksquare$

(The vertical bar has other meanings too: $|x|$ is the absolute value, $P(A\mid B)$ is a conditional probability, and in $\{x\mid x>0\}$ it means ``such that''.)
