Only positive integers have the intended finite divisor count. Write $n=m^2$, since $\sqrt n$ must be an integer. A square has an odd number of divisors, so $m$ is odd. If $m=\prod p^{a_p}$, then $d(m^2)=\prod(2a_p+1)$. For odd primes $p$, $2a+1\le3^a\le p^a$, with equality for $a\ge1$ only when $p=3,a=1$ (the first inequality follows by induction). Therefore $d(m^2)=m$ only for $m=1$ or 3. The two integers are $n=1,9$, giving $\boxed2$.
