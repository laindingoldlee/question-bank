Total distance is $\boxed{80\text{ m}}$. The last displacement is $(10,-10\sqrt3)$, so the endpoint relative to the start is $(30,20-10\sqrt3)$. Its distance is $\sqrt{30^2+(20-10\sqrt3)^2}=20\sqrt{4-\sqrt3}\approx30.12$, rounding to $\boxed{30\text{ m}}$.
