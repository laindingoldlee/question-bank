Put the $12$ candies in a row. A distribution in which every child gets at least one candy corresponds to choosing $3$ of the $11$ gaps between neighbouring candies for dividers (the first child takes the candies before the first divider, and so on; no two dividers in the same gap, so no child gets nothing). So the number is
\[
\dbinom{11}{3}=\boxed{165},
\]
and the student is right.

The number $\dbinom{15}{3}=455$ counts the distributions in which children may get \emph{no} candy: arranging $12$ candies and $3$ dividers in a row of $15$ places. It answers a different question. (Equivalently, giving each child one candy first leaves $8$ candies to distribute freely: $\dbinom{8+3}{3}=165$.)
