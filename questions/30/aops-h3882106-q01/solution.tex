A polynomial of degree at most three fitting the first list has constant third difference 26, giving next value $208$. A polynomial of degree at most five fitting the second list gives next value $1797$ by extending its finite-difference table. More generally, if a polynomial $P$ fits values at $1,\ldots,k$, then $P(x)+c\prod_{j=1}^k(x-j)$ fits the same list but changes the next value by $ck!$. Thus either list can have any chosen next real value under an appropriate rule.
