If the value is $x$, then the expression under the first radical is $1+2x$, so $x=\sqrt{1+2x}$, $x^2=1+2x$ and
\[
x^2-2x-1=0,\qquad x=1\pm\sqrt2 .
\]
Since $x>0$, $x=\boxed{1+\sqrt2}$.

\textbf{The limit exists.} Let $L=1+\sqrt2$, so $L^2=1+2L$. If $0\le x_n<L$, then $x_{n+1}=\sqrt{1+2x_n}<\sqrt{1+2L}=L$, and $x_{n+1}>x_n$ because $x_n^2<1+2x_n$ for $0\le x_n<L$. So the sequence increases and is bounded by $L$; its limit $x$ satisfies $x=\sqrt{1+2x}$, so it is $L$.

\textbf{The poster's error.} After squaring, $x^2=1+2\sqrt{1+2\sqrt{\cdots}}=1+2x$, not $1+2+x$; and even from $x^2=3+x$ the equation is $x^2-x-3=0$, not $x^2-x+3=0$. (The poster's $\dfrac{1+\sqrt{13}}{2}$ would be the value of $\sqrt{3+\sqrt{3+\sqrt{3+\cdots}}}$.)
