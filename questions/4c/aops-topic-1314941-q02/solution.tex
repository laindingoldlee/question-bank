If North won, then (a), (c), (d) are true and so is (b) (a winner scores), already four true predictions. So North did not win, and (c) is false.

If the game was a draw, (a) is false and (d) true, so both (b) and (e) must be true; but a draw has an even total, not $3$. So North lost: (a) is true and (c), (d) are false, and both (b) and (e) must be true. North scored, three goals were scored, and North lost, so the score was $\boxed{\text{North }1,\ \text{South }2}$.
