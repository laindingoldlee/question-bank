Inside the parentheses, $4^2\div4=16\div4=4$. Then the multiplications and divisions are done from left to right:
\[10\times4=40,\qquad 2\times4\div2\div\dfrac12=8\div2\div\dfrac12=4\div\dfrac12=8.\]
So the value is $40-8+9=\boxed{41}$.
