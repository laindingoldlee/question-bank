Let $X=\overline{abcde}$, so $\overline{abcdef}=10X+f$ and $\overline{fabcde}=100000f+X$. Then $70X+7f=500000f+5X$, i.e. $65X=499993f$. Since $499993=13\cdot38461$ and $65=5\cdot13$, this is $5X=38461f$, so $5\mid f$, giving $f=5$ and $X=38461$. The number is $384615$ (check: $7\cdot384615=2692305=5\cdot538461$), so $d=\boxed{6}$.
