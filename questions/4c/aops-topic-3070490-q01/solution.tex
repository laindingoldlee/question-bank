There are $\binom{64}{2}=2016$ unordered placements. (a) Each $2\times3$ rectangle contains two attacking knight pairs. There are $7\cdot6$ rectangles in each orientation, so there are $2\cdot2\cdot7\cdot6=168$ attacking pairs. The answer is $\boxed{1848}$. (b) Row or column attacks account for $16\binom{8}{2}=448$ pairs. For one diagonal direction, the diagonal lengths are $1,2,\ldots,7,8,7,\ldots,1$, giving $2\sum_{j=1}^7\binom j2+\binom82=140$ pairs. Both directions contribute 280. Distinct squares cannot share both a row or column and a diagonal, so the answer is $2016-448-280=\boxed{1288}$.
