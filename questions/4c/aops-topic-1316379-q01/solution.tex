A positive integer $N$ has $k$ digits exactly when $10^{k-1}\le N<10^k$, i.e. when $k-1\le\log_{10}N<k$, i.e. $k=\lfloor\log_{10}N\rfloor+1$. For $N=2^{50}$, $\log_{10}N=50\log_{10}2\approx50\cdot0.30103=15.05$, so $2^{50}$ has $15+1=\boxed{16}$ digits. (Indeed $2^{50}=1125899906842624$.) Note that $\log_{10}2^{50}=50\log_{10}2$, not $\log_{10}$ of $50\cdot2$.
