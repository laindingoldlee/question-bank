A problem asks for $f(1)+f(2)+\cdots+f(10)$, where $f$ is a function defined for all nonzero real numbers with
\[
f(x)+x^2f\left(\dfrac{1}{x}\right)=x^2-1\qquad\text{for all }x\ne0 .
\]
A student substituted $\dfrac{1}{x}$ for $x$, eliminated $f\left(\dfrac{1}{x}\right)$, and obtained $f(x)=\dfrac{2x^2-1}{1-x^4}$.
\begin{enumerate}
\item[(a)] Prove that no function $f$ satisfies the condition, so the problem has no answer.
\item[(b)] Check that the student's formula does not satisfy the condition, and explain what went wrong.
\end{enumerate}
