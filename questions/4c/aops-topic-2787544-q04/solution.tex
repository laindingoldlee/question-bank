First, in any $4\times4$ magic square the four corners sum to $34$. Let $K$ be the corner sum, $E$ the sum of the $8$ non-corner border cells and $Z$ the sum of the $4$ centre cells. Rows $1,4$ and columns $1,4$ give $2K+E=4\cdot34$; all cells give $K+E+Z=136$; the diagonals give $K+Z=68$. The first two give $K=Z$, so $K=34$.

Now $a_{13}+a_{14}=29$, so $\{a_{13},a_{14}\}$ is $\{13,16\}$ or $\{14,15\}$; and $a_{31}+a_{41}=28$, so $\{a_{31},a_{41}\}$ is $\{12,16\}$ or $\{13,15\}$. These pairs must be disjoint, which forces $\{a_{13},a_{14}\}=\{14,15\}$ and $\{a_{31},a_{41}\}=\{12,16\}$.

Corners: $a_{44}=32-a_{14}-a_{41}$, which is $6,2,5,1$ for $(a_{14},a_{41})=(14,12),(14,16),(15,12),(15,16)$; $2$ is taken. In the remaining three cases the main diagonal needs $a_{22}+a_{33}=32-a_{44}\in\{26,27,31\}$. But $12,14,15,16$ are already used, so $a_{22}+a_{33}\le13+11=24$. Contradiction, so $\boxed{\text{no}}$, Steve cannot complete the square (confirmed by exhaustive search).
