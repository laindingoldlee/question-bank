The numbers are $x,x+2,x+4,\dots,x+26$ (the $14$th number is $x+2\cdot13$). Their sum is
\[
14x+2(0+1+\dots+13)=14x+2\cdot91=14x+182,
\]
and the average is $x+13$, the average of the first and last terms. So $x+13=119$ and the smallest number is $\boxed{106}$ (the numbers run from $106$ to $132$).

The student's list skips $x+16$ and runs to $x+28$, so it is not a list of $14$ consecutive even numbers ending at $x+26$; also the sum should be set equal to $14\cdot119=1666$, not divided by $14$ again. With the correct list, $14x+182=1666$ gives $x=106$.
