The triangle inequality and reverse triangle inequality applied to $A,P,C$ give
\[
|PA-PC|\le AC\le PA+PC,
\]
so $3\le AC\le5$.

Both endpoints are achievable while keeping $ABC$ nondegenerate and right-angled. Take $C=(0,0)$ and $B=(0,4\sqrt3)$. For $AC=3$, set $A=(3,0),P=(-1,0)$; for $AC=5$, set $A=(5,0),P=(1,0)$. In each case $PA=4,PC=1$, and $PB=\sqrt{1+48}=7$. Thus the minimum is $\boxed3$ and the maximum $\boxed5$.
\begin{asy}
texpreamble("\usepackage{amsmath,amssymb}");
size(240);
defaultpen(fontsize(9pt));
pair C=(0,0),A=(3,0),B=(0,4*sqrt(3)),P=(-1,0);draw(A--B--C--cycle);draw(P--A,blue);draw(P--B,dashed);label("$A$",A,(1,-1));label("$B$",B,(0,1));label("$C$",C,(0,-1));label("$P$",P,(-1,-1));label("$AC=3$",(1.5,-1));
\end{asy}
\begin{asy}
texpreamble("\usepackage{amsmath,amssymb}");
size(240);
defaultpen(fontsize(9pt));
pair C=(0,0),A=(5,0),B=(0,4*sqrt(3)),P=(1,0);draw(A--B--C--cycle);draw(P--B,dashed);dot(P);label("$A$",A,(1,-1));label("$B$",B,(0,1));label("$C$",C,(-1,-1));label("$P$",P,(0,-1));label("$AC=5$",(3,-1));
\end{asy}
