Since $t=\lfloor t\rfloor+\{t\}$ for each variable, adding the three equations gives $2(x+y+z)=6.6$, so $x+y+z=3.3$. Subtracting each equation from this:
\begin{align*}
\{y\}+\lfloor z\rfloor&=2.2,\\
\{x\}+\lfloor y\rfloor&=1.1,\\
\lfloor x\rfloor+\{z\}&=0 .
\end{align*}
In each line an integer is added to a number in $[0,1)$, so the integer is the integer part of the right side and the fractional part is its fractional part: $\lfloor z\rfloor=2$, $\{y\}=0.2$; $\lfloor y\rfloor=1$, $\{x\}=0.1$; $\lfloor x\rfloor=0$, $\{z\}=0$. Hence
\[
\boxed{x=0.1,\quad y=1.2,\quad z=2},
\]
and indeed $0.1+1+0=1.1$, $0+0.2+2=2.2$, $0.1+1.2+2=3.3$. This is the only solution.
