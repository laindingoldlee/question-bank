\textbf{Describe the possible angle sets.} The angles of a hexagon add up to $(6-2)\cdot180^\circ=720^\circ$, so their average is $120^\circ$. Write the progression as $a,a+d,\dots,a+5d$ (in any order around the hexagon). Then $6a+15d=720$, i.e.\ $2a+5d=240$. Since $a$ and $a+d$ are integers, $d$ is an integer, and $5d=240-2a$ is even, so $d=2e$ for an integer $e$. The six angles are symmetric about the average:
\[
120^\circ\pm e,\qquad 120^\circ\pm3e,\qquad 120^\circ\pm5e .
\]
\textbf{Convexity.} Every angle is less than $180^\circ$ (and positive), so $120+5|e|<180$, i.e.\ $|e|\le11$. Conversely, for every integer $e$ with $|e|\le11$ the six angles lie strictly between $0^\circ$ and $180^\circ$ and add up to $720^\circ$, and such a convex hexagon exists (for example, the one below has $e=6$).

\begin{asy}
usepackage("amsmath");

string[] a={"$126^\circ$","$90^\circ$","$138^\circ$","$114^\circ$","$150^\circ$","$102^\circ$"};
draw(P[0]--P[1]--P[2]--P[3]--P[4]--P[5]--cycle,linewidth(0.9));

for(int i=0;i<6;++i){
  pair u=unit(P[(i+5)%6]-P[i]),v=unit(P[(i+1)%6]-P[i]);
  pair w=unit(u+v);
  label(a[i],P[i]+0.75*w,fontsize(9pt));
}
for(int i=0;i<6;++i) dot(P[i]);

\end{asy}

\textbf{The choices.} An angle $x$ is possible exactly when $|x-120|$ equals $|e|$, $3|e|$ or $5|e|$ for some integer $|e|\le11$.
\begin{itemize}
\item (B) $|90-120|=30=3\cdot10$; (C) $|109-120|=11$; (D) $|140-120|=20=5\cdot4$; (E) $|147-120|=27=3\cdot9$: all possible.
\item (A) $|84-120|=36$: this would need $|e|=36$ or $|e|=12$ (both more than $11$), and $36$ is not a multiple of $5$. Impossible.
\end{itemize}
The answer is $\boxed{\text{(A) }84^\circ}$.
