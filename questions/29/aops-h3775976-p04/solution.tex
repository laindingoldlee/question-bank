If increasing $AB$ by one causes no carry, the tens digit stays $A$, so $B=A$ and $C=A+1$. For the next increase to have tens digit $C$, a carry must then occur, forcing $C=9$, $A=B=8$, and $D=0$. This gives $88,89,90$. If the first increase carries, then $AB=89$ and $BC=90$, but the next overlapping number would start with $0$, not a two-digit integer. Therefore the four-digit number is $\boxed{8890}$.
