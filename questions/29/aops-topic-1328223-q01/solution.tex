The integers from $-10$ to $10$ cancel in pairs and sum to $0$, so we need $11+12+\dots+N=50$. Since $11+12+13+14=50$, we get $N=\boxed{14}$.

(Algebraically, there are $N+11$ terms with average $\dfrac{N-10}{2}$, so the sum is $\dfrac{(N+11)(N-10)}{2}=50$, i.e. $N^2+N-210=0=(N-14)(N+15)$, so $N=14$; the root $-15$ is less than $-10$. The value $-1.488$ comes from an arithmetic slip.)
