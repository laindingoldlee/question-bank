Let $s=a+b+c+d$. The equations say $s+3d=5$, $s+3a=5$, $s+3b=5$ and $s+3c=5$, so $a=b=c=d$. Adding all four equations gives $7s=20$, so $s=\dfrac{20}{7}$ and each variable is $\dfrac{s}{4}=\dfrac{5}{7}$. The solution is $\boxed{a=b=c=d=\dfrac{5}{7}}$. (Check: $7\cdot\dfrac{5}{7}=5$.)
