Since $(2x-1)(2x-3)=4x^2-8x+3$, we have
\[4\left(x^2-2x+7\right)=(2x-1)(2x-3)+25 .\]
The number $2x-1$ is odd, so it has no common factor with $4$. Hence $2x-1$ divides $x^2-2x+7$ exactly when it divides $4\left(x^2-2x+7\right)$, which by the identity happens exactly when $2x-1$ divides $25$. So
\[2x-1\in\{\pm1,\pm5,\pm25\},\qquad x\in\{1,0,3,-2,13,-12\}.\]
(Check: the quotients are $6,-7,2,-3,6,-7$.) Thus $S$ has $6$ elements and $2^6=\boxed{64}$ subsets.
