If you know $k$ answers, the $100-k$ unknown questions are each wrong with probability $\dfrac{3}{4}$, independently, so
\[
P(\text{all wrong})=\left(\dfrac{3}{4}\right)^{100-k}.
\]
(a) This equals $1$ only when $100-k=0$: any unknown question is answered correctly by accident with probability $\dfrac{1}{4}$. So you must know $\boxed{100\%}$ of the answers.

(b) We need $\left(\dfrac{3}{4}\right)^{m}\ge\dfrac{1}{2}$ with $m=100-k$. Now $\left(\dfrac{3}{4}\right)^2=\dfrac{9}{16}\ge\dfrac{1}{2}$ but $\left(\dfrac{3}{4}\right)^3=\dfrac{27}{64}<\dfrac{1}{2}$, so $m\le2$ and $k\ge98$. You must know $\boxed{98\%}$.
