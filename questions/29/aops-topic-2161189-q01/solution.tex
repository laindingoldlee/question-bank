Substituting $x=y^3$ into $x-y^2=2$ gives
\[y^3-y^2=2,\qquad\text{that is,}\qquad y^2(y-1)=2 .\]
Every solution $y$ gives exactly one pair, with $x=y^3$, so we count the real solutions $y$.
\begin{itemize}
\item If $y\le1$, then $y^2\ge0$ and $y-1\le0$, so $y^2(y-1)\le0<2$: no solutions.
\item If $y>1$, both factors $y^2$ and $y-1$ are positive and strictly increasing, so $y^2(y-1)$ is strictly increasing. It is $0$ at $y=1$ and $4$ at $y=2$, and it changes continuously, so it takes the value $2$ exactly once, for some $y$ between $1$ and $2$.
\end{itemize}
Hence there is exactly $\boxed{1}$ pair. (Numerically $y\approx1.696$ and $x=y^3\approx4.875$; there is no integer solution. Over the complex numbers the cubic $y^3-y^2-2=0$ has two further, non-real roots, giving three pairs in all.)
