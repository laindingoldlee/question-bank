An $8\times 8$ checkerboard is colored black and white such that the top left cell is white. A set of $4$ distinct cells of the checkerboard is called stable if

\begin{itemize}

\item the four cells are not all the same color,

\item the centers of the four cells form a square with sides parallel to the gridlines, and

\item the top right cell of the four is black.

\end{itemize}

Find the number of ways to select $16$ stable sets such that no black cell is in two sets.
