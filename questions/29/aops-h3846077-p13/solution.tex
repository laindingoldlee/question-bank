For neighboring positive terms, define
\[
K_n=\dfrac{a_n^2+a_{n-1}^2+2016}{a_na_{n-1}}.
\]
Using $a_{n+1}=\dfrac{a_n^2+2016}{a_{n-1}}$ and simplifying gives $K_{n+1}=K_n$. Its initial value is $\dfrac{9+9+2016}{9}=226$. Hence the unfloored target equals
\[
226-\dfrac{2016}{a_{2016}a_{2015}}.
\]
Now $a_3=675$, and the recurrence gives
$\dfrac{a_{n+1}}{a_n}=\dfrac{a_n}{a_{n-1}}+\dfrac{2016}{a_na_{n-1}}$.
Thus successive ratios strictly increase from $1$, and all terms from $a_2$ onward increase. In particular $a_{2016}a_{2015}\ge a_3a_2=2025>2016$. The target lies strictly between $225$ and $226$, so the answer is $\boxed{225}$.
