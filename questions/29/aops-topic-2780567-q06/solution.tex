If $ b=0 $, the value is $\dfrac{1}{c}+d\le4 $. If $ a=0 $, it is $ d\le3 $. Otherwise zero is $ d $ (since it is not $ c $), and $ a,b,c $ permute 1,2,3. The possibilities for $ \dfrac{a^b}{c} $ are $\dfrac{1}{3},\dfrac{1}{2},\dfrac{2}{3},8,\dfrac{3}{2},9 $. The maximum is $\boxed9 $, attained by $(a,b,c,d)=(3,2,1,0)$.
