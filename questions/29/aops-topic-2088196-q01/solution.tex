Sort each roll into one of four types:
\begin{itemize}
\item $X$: a $2$ (both score), $1$ face;
\item $P$: an odd prime $3,5,7$ (only Rob scores), $3$ faces;
\item $E$: $4,6,8,10$ (only Amy scores), $4$ faces;
\item $Z$: $1$ or $9$ (nobody scores), $2$ faces.
\end{itemize}
If the four rolls contain $x$, $p$, $e$, $z$ rolls of these types, Amy has $2(x+e)$ points and Rob $3(x+p)$, so Amy is ahead exactly when $2e>x+3p$. The number of the $10^4$ equally likely roll sequences with given $(x,p,e,z)$ is $\dfrac{4!}{x!\,p!\,e!\,z!}\cdot1^x3^p4^e2^z$. The cases with $2e>x+3p$ are:
\[\begin{array}{cccc|c}
x&p&e&z&\text{sequences}\\\hline
0&0&1&3&4\cdot4\cdot8=128\\
1&0&1&2&12\cdot4\cdot4=192\\
0&0&2&2&6\cdot16\cdot4=384\\
1&0&2&1&12\cdot16\cdot2=384\\
2&0&2&0&6\cdot16=96\\
0&1&2&1&12\cdot3\cdot16\cdot2=1152\\
0&0&3&1&4\cdot64\cdot2=512\\
1&0&3&0&4\cdot64=256\\
0&1&3&0&4\cdot3\cdot64=768\\
0&0&4&0&256
\end{array}\]
(With $e\le1$ we need $e=1$ and $x+3p\le1$; with $e=2$ we need $x+3p\le3$; with $e=3$, $x+3p\le5$ and $x+p\le1$.) The total is $4128$, so the probability is $\dfrac{4128}{10000}=\boxed{41.28\%}$.
