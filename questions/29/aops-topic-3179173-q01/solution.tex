Write $f(x)=\sum_{k=0}^n a_kx^k$. Subtracting gives $f(x)-f(-x)=2\sum_{k\text{ odd}}a_kx^k$, identically zero. A polynomial which vanishes for every real input is the zero polynomial, so all its coefficients vanish. Therefore $\boxed{a_k=0\text{ for every odd }k}$. Conversely, a polynomial containing only even powers plainly satisfies the identity.
