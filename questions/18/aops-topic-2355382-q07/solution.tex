There are $700-150-300=250$ yellow feathers. The number of ways to choose three feathers is $\dbinom{700}{3}=\dfrac{700\cdot699\cdot698}{6}=56921900$, and the number of ways to choose one of each color is $150\cdot300\cdot250=11250000$. So the probability is
\[\dfrac{11250000}{56921900}=\boxed{\dfrac{112500}{569219}}\approx0.198.\]
