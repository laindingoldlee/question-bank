By AM-GM, $x+y\ge2\sqrt{xy}=2\sqrt{\dfrac{50}{63}}=2\cdot\dfrac{5\sqrt2}{3\sqrt7}=\dfrac{10\sqrt{14}}{21}$, with equality when $x=y=\sqrt{\dfrac{50}{63}}=\dfrac{5\sqrt{14}}{21}$. So the minimum is $\boxed{\dfrac{10\sqrt{14}}{21}}$.
