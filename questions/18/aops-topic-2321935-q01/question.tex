A secret code consists of four digits (each from $0$ to $9$; the code may start with $0$). The clues are:
\begin{enumerate}
\item[(a)] the third digit is greater than the second digit;
\item[(b)] the third and fourth digits differ by $3$;
\item[(c)] the sum of the four digits leaves remainder $3$ when divided by $5$;
\item[(d)] the sum of the four digits leaves remainder $3$ when divided by $6$.
\end{enumerate}
Find the code.
