The interior angles of a polygon with $s$ sides add up to $180^\circ(s-2)$: the diagonals from one vertex cut it into $s-2$ triangles, as in the sketch for $s=14$. We need $180(s-2)\ge2021$, i.e. $s-2\ge\dfrac{2021}{180}\approx11.2$, so $s-2\ge12$. The least value is $s=\boxed{14}$ (with angle sum $2160^\circ$; for $13$ sides it is only $1980^\circ$).

\begin{asy}
usepackage("amsmath");
size(3.5cm);
defaultpen(fontsize(10pt));
int n=14;
pair[] V; for(int k=0;k<n;++k) V.push(dir(90+360*k/n));
draw(V[0]--V[1]--V[2]--V[3]--V[4]--V[5]--V[6]--V[7]--V[8]--V[9]--V[10]--V[11]--V[12]--V[13]--cycle,linewidth(0.8));
for(int k=2;k<n-1;++k) draw(V[0]--V[k],gray);
dot(V[0]);
\end{asy}
