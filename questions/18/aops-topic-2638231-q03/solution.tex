For real $t$, $\sqrt{t^2}=|t|$. Since $2\sqrt3=\sqrt{12}>3$, we have $\left|3-2\sqrt3\right|=2\sqrt3-3$, so the sum is
\[\left(2\sqrt3-3\right)+\left(3+2\sqrt3\right)=\boxed{\textbf{(D) }4\sqrt3}.\]
(The trap is to write $\sqrt{\left(3-2\sqrt3\right)^2}=3-2\sqrt3$, which is negative, and get $6$.)
