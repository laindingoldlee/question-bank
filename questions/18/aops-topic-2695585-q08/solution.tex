$kn+54k+2n+106=(k+2)(n+54)-2$, so $(k+2)(n+54)\equiv6\equiv1\pmod5$. With $k+2\equiv3$, $n+54\equiv2$ (as $3\cdot2=6\equiv1$). So $n\equiv2-54\equiv\boxed{3}\pmod5$.
