We have $3\#x=\dfrac{(4-x)^2}{(x-2)^2}$ and $x\ne 2$. At $x=1,3,4$ the values are $9,1,0$. For $x\ge 5$, $0<x-4<x-2$, so the value lies strictly between $0$ and $1$. Hence the maximum is $\boxed 9$.
