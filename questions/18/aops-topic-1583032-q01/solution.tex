Using $9^{-\dfrac {x}{2}}=\left(9^{\dfrac{1}{2}}\right)^{-x}=3^{-x}=\left(\dfrac{1}{3}\right)^x$,
\[
y=\boxed{2\left(\dfrac{1}{3}\right)^x}.
\]
The base $\dfrac{1}{3}$ is between $0$ and $1$, so this is \textbf{exponential decay}: each time $x$ increases by $1$, $y$ is multiplied by $\dfrac{1}{3}$. It loses $1-\dfrac{1}{3}=\dfrac{2}{3}$ of its value, so the rate of change is
\[
\boxed{-66\dfrac{2}{3}\%\text{ per unit of }x}
\]
(a decrease of about $66.7\%$).
