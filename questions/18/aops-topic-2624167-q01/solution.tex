A schedule is an ordered list of $7$ distinct $3$-element subsets of the $7$ problems, covering all problems. If the problems in a given set of $j$ problems are all avoided, each day's set is one of the $\dbinom{7-j}{3}$ subsets of the others, and the number of ordered lists of $7$ distinct such sets is $P\left(\dbinom{7-j}3,7\right)$, where $P(M,7)=M(M-1)\cdots(M-6)$. By inclusion-exclusion,
\[P(35,7)-7P(20,7)+21P(10,7)-35P(4,7)+\cdots,\]
and all terms from $P(4,7)$ on are $0$. Here $P(35,7)=33891580800$, $P(20,7)=390700800$ and $P(10,7)=604800$, so the number of schedules is
\[33891580800-2734905600+12700800=\boxed{31169376000}.\]
