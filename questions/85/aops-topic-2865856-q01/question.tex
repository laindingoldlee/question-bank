A machine tests calculators for a rare defect. If a calculator has the defect, the machine says so with probability $95\%$; if it does not, the machine says it is fine with probability $95\%$. One calculator in every $224$ has the defect. What is the probability that a calculator flagged by the machine actually has the defect?
