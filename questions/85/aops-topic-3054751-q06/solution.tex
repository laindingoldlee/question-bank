A unique mode can arise only by repeating one of the four existing values, so the mode is $x$. Equality with the mean requires $\dfrac{44+x}{5}=x$, giving $x=11$. The sorted list is 8,9,11,11,16, whose median and unique mode are both 11. Thus $\boxed{x=11}$.
