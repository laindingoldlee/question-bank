\begin{enumerate}
\item The equations are $\boxed{ab=27.2,\ ab^6=14.8}$.
\item Dividing gives $b^5=\dfrac{14.8}{27.2}=\dfrac{37}{68}$. Hence
\[
b=(\dfrac{37}{68})^{\dfrac{1}{5}}\approx\boxed{0.88540},\qquad
a=27.2(\dfrac{68}{37})^{\dfrac{1}{5}}\approx\boxed{30.72065}.
\]
\item The average rate is $\dfrac{(14.8-27.2)}{(6-1)}=\boxed{-2.48}$ thousand dollars per year.
\item The secant line is $A(t)=27.2-2.48(t-1)$, so $\boxed{A(3)=22.24}$ thousand dollars.
\item $V''(t)=ab^t(\log b)^2>0$. Thus the graph is strictly convex, and its chord lies strictly above the graph between the two endpoints: $A(t)>V(t)$ for $1<t<6$.
\item Solving $ab^t=2$ gives
\[
T=\dfrac{\log(\dfrac{2}{a})}{\log b}\approx22.44359.
\]
The model for the retained value before donation therefore has domain $\boxed{[0,T)}$. At $T$ the stated donation rule replaces the model with value zero.
\end{enumerate}
