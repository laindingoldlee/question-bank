Notice that in each congruence the remainder is $5$ less than the modulus: $2=7-5$, $3=8-5$, $4=9-5$. So
\[
x+5\equiv0\pmod7,\qquad x+5\equiv0\pmod8,\qquad x+5\equiv0\pmod9,
\]
i.e.\ $x+5$ is a common multiple of $7$, $8$ and $9$. These are pairwise relatively prime, so $\operatorname{lcm}(7,8,9)=504$, and $x+5$ is a positive multiple of $504$. The smallest is $x+5=504$, so $x=\boxed{499}$.

Check: $499=7\cdot71+2=8\cdot62+3=9\cdot55+4$.

(Without this shortcut one can sieve: the numbers $\equiv4\pmod9$ are $4,13,22,31,\dots$; the first one $\equiv3\pmod8$ is $67$, so $x\equiv67\pmod{72}$; then among $67,139,211,283,355,427,499$ the first one $\equiv2\pmod7$ is $499$.)
