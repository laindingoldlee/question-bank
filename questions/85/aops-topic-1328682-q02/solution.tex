A longer number is larger, so first maximise the number of digits. With first digits $a\ge1$ and $b$, the $k$th digit is $F_{k-2}a+F_{k-1}b$ for $k\ge2$, where $F_0=0$, $F_1=1$, $F_2=1$, $F_3=2,\dots$ are the Fibonacci numbers. The $7$th digit is $5a+8b$, and $5a+8b\le9$ forces $a=1$, $b=0$. So a number with at least $7$ digits must begin $1,0$, and then it is
\[
1,0,1,1,2,3,5,8,
\]
which stops after $8$ digits because $5+8=13$. Every other start gives at most $6$ digits, so the largest such integer is $\boxed{10112358}$.
