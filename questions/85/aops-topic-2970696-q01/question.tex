Let $S_n=1+2+\cdots+n$. Prove that for every number $M$ there is an $n$ with $S_n>M$, so the series $1+2+3+\cdots$ has no finite sum in the usual sense. (The value $-\dfrac1{12}$ sometimes quoted is a regularised value assigned by other methods, not the limit of the partial sums.)
