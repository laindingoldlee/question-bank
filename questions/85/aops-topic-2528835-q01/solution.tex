\textbf{(a)} Dividing by $x^{-1}=\dfrac1x$ is the same as multiplying by $x$, so $\dfrac{x^2}{x^{-1}}=x^2\cdot x=\boxed{x^3}$ (exponents of equal bases add: $2-(-1)=3$). It is not $x^2+x$.

\textbf{(b)} Write the negative powers as fractions:
\[(x+y)y^{-1}-2x(x+y)^{-1}=\dfrac{x+y}{y}-\dfrac{2x}{x+y}=\dfrac{(x+y)^2-2xy}{y(x+y)}=\dfrac{x^2+y^2}{y(x+y)},\]
\[(x-y)y^{-1}+2x(x-y)^{-1}=\dfrac{x-y}{y}+\dfrac{2x}{x-y}=\dfrac{(x-y)^2+2xy}{y(x-y)}=\dfrac{x^2+y^2}{y(x-y)}.\]
Since $y\ne0$, $x^2+y^2>0$, so we may cancel $\dfrac{x^2+y^2}{y}$:
\[\dfrac{(x+y)y^{-1}-2x(x+y)^{-1}}{(x-y)y^{-1}+2x(x-y)^{-1}}=\boxed{\dfrac{x-y}{x+y}}.\]
