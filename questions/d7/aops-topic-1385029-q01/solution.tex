The sum is $A+11A+2(100B+11A)=34A+200B=2004$, so $17A+100B=1002$. Then $17A\equiv1002\equiv2\pmod{100}$; as $0\le17A\le153$, we need $17A=2$ or $102$, so $A=6$, and $100B=1002-102=900$ gives $B=9$. The only solution is $\boxed{A=6,\ B=9}$: $6+66+966+966=2004$.
