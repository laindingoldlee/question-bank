Modulo $2$, the equation forces $a$ odd. Write $a=1+2t$ for an arbitrary integer $t$. Then $b=-1-7t$. Thus all integer solutions are $\boxed{(a,b)=(1+2t,-1-7t),\ t\in\mathbb Z}$, giving infinitely many. If $a\ge0$, then $t\ge0$, forcing $b<0$. Hence there are $\boxed0$ nonnegative solutions.
