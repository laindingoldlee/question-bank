There are $\dfrac{11(11-3)}{2}=44$ diagonals, hence $\binom{44}2=946$ equally likely unordered pairs. A favourable pair has four distinct endpoints. For endpoints $a<b<c<d$, the two noncrossing pairings are $(a,b),(c,d)$ and $(a,d),(b,c)$; the third pairing crosses. Count each listed pairing only when neither edge is a polygon side and each endpoint sum is odd. A direct bounded count by the smallest endpoint $a=1,2,\ldots,8$ gives respectively $22,19,7,6,1,1,0,0$, totaling $56$. This count can be reproduced by looping over all $1\le a<b<c<d\le11$, testing the two pairings, rejecting index differences $1$ or $10$, and testing odd endpoint sums. Thus the probability is $\dfrac{56}{946}=\dfrac{28}{473}$, and $\boxed{p+q=501}$.
