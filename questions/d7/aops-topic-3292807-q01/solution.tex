Assign number $k$ weight $2^{13-k}$ and code a subset by the sum of its weights. Unique binary expansion makes the map one-to-one; its maximum is $2^{13}-1=8191<10000$. The code $8191$ uses all thirteen weights and specifies the whole set. Since $6145=4096+2048+1=2^{12}+2^{11}+2^0$, it specifies $\boxed{\{1,2,13\}}$.
