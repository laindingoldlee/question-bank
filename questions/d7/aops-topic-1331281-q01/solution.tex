If $n=p_1^{e_1}\cdots p_m^{e_m}$, then $n$ has $(e_1+1)\cdots(e_m+1)$ divisors. To minimise $n$, use small primes with larger exponents on smaller primes.
\begin{itemize}
\item $k=1$: only $n=1$.
\item $k=2$: $n$ prime, smallest $2$.
\item $k=3$: $n=p^2$, smallest $4$.
\item $k=4$: $n=p^3$ or $pq$; smallest $\min(8,6)=6$.
\item $k=5$: $n=p^4$, smallest $16$.
\item $k=6$: $n=p^5$ or $p^2q$; smallest $\min(32,\,2^2\cdot3)=12$.
\end{itemize}
So the answers are $\boxed{1,\ 2,\ 4,\ 6,\ 16,\ 12}$.
