Twenty-six friends, Al, Bob, Cal, Dave, Eve, Flo, Gabe, Han, Ian, Jim, Kayla, Leo, Mack, Nala, Owen, Pam, Quavo, Rick, Sara, Tom, Ula, Vick, Willy, Xander, Yoda and Zane, each draw a different number from $1$ to $26$. Denote each person's number by the first letter of their name ($A$ for Al, $B$ for Bob, and so on). Use the clues to find everyone's number.
\begin{enumerate}
\item $W-V=D$.
\item $\dfrac Z6=\dfrac B3=J$.
\item $B^3=J+L$.
\item $K+E=H-C$.
\item Everyone whose name starts with a vowel (A, E, I, O, U; not Y) has a prime number.
\item Written out in English, Flo's, Tom's and Sara's numbers start with the same letter as their names.
\item Eve's number is even and Owen's number is odd.
\item $G+10=F$ and $C+10=A$.
\item Flo's, Mack's and Owen's numbers are three consecutive integers, in some order.
\item $E+B=G$.
\item $E,D,R,X,P$ is an arithmetic sequence, in this order, with common difference $G$.
\item $N+Q=U-I$.
\item $Y-T=N$.
\end{enumerate}
