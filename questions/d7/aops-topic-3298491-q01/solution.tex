For a sum $s$, exactly $10-s$ of Steve’s numbers exceed it. Each element is equally likely to be included, so the expected two-number sum is twice the mean of $1,\ldots,5$, namely $6$. Averaging the conditional probability yields $\dfrac{10-E(s)}{10}=\boxed{\dfrac{2}{5}}$. All sums lie between $3$ and $9$, so no truncation is needed.
