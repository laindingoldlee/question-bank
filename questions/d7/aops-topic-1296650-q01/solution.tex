The common last four digits must be $0$s and $1$s; call the string $d_3d_2d_1d_0$. Then $n\equiv s\pmod{16}$ with $s=8d_3+4d_2+2d_1+d_0$ and $n\equiv t\pmod{625}$ with $t=125d_3+25d_2+5d_1+d_0$. By the Chinese remainder theorem each of the $16$ strings gives exactly one residue $n\bmod10000$, i.e. one number in $1,\dots,10000$.

The residue is $n=s\cdot e_1+t\cdot e_2\pmod{10000}$, where $e_1\equiv1\pmod{16}$, $e_1\equiv0\pmod{625}$ and $e_2\equiv0\pmod{16}$, $e_2\equiv1\pmod{625}$; one finds $e_1=625$ and $e_2=9376$. Summing over all $16$ strings, each digit $d_i$ is $1$ in exactly $8$ strings, so
\[
\sum s=8(8+4+2+1)=120,\qquad\sum t=8(125+25+5+1)=1248,
\]
and $x\equiv625\cdot120+9376\cdot1248\equiv75000+11701248\equiv5000+1248=6248\pmod{10000}$. The remainder is $\boxed{6248}$. (The string $0000$ gives $n=10000$, which contributes $0$ modulo $10000$, consistent with the computation.)
