For every number $y\ne0$ we have $y^0=1\ne0$. For $y=0$, the expression $0^0$ is either left undefined or, by the usual convention in algebra and counting, set equal to $1$; in neither case is it $0$. So no number $y$ satisfies $y^0=0$, and $\sqrt[0]{0}$ has \textbf{no value}: it is undefined.

The same conclusion comes from writing an $n$th root as a power, $\sqrt[n]{a}=a^{\dfrac1n}$: for $n=0$ the exponent would be $\dfrac10$, which is itself undefined. (For comparison, ``$\sqrt[0]{1}$'' fails for the opposite reason: every $y\ne0$ satisfies $y^0=1$, so no single value could be chosen.)
