Factor the left side: $1+x+x^2+x^3=(1+x)\left(1+x^2\right)$. Both factors are positive integers whose product is a power of $2$, so each is a power of $2$.

\textbf{$x=0$:} $1=2^y$ gives $y=0$.

\textbf{$x\ge1$:} $1+x\ge2$ is a power of $2$, so $x$ is odd. Then $x^2\equiv1\pmod4$ (the square of an odd number), so $1+x^2\equiv2\pmod4$. A power of $2$ that is $2$ modulo $4$ equals $2$, so $1+x^2=2$ and $x=1$. Then $1+1+1+1=4=2^2$, so $y=2$.

The solutions are $\boxed{(x,y)=(0,0)\text{ and }(1,2)}$; if $\mathbb N$ is taken to start at $1$, the only solution is $(1,2)$.
