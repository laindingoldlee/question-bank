\textbf{(a)} By the binomial theorem,
\[11^4=(10+1)^4=\binom40 10^4+\binom41 10^3+\binom42 10^2+\binom43 10+\binom44=1\cdot10^4+4\cdot10^3+6\cdot10^2+4\cdot10+1 .\]
Each coefficient is a single digit, so the entries of row $4$ are exactly the digits: $11^4=\boxed{14641}$.

\textbf{(b)} Not directly: $11^5=1\cdot10^5+5\cdot10^4+10\cdot10^3+10\cdot10^2+5\cdot10+1$, and the entries $10$ must be carried. Working from the right: units $1$; tens $5$; hundreds $10$ gives $0$, carry $1$; thousands $10+1=11$ gives $1$, carry $1$; ten-thousands $5+1=6$; hundred-thousands $1$. So $11^5=\boxed{161051}$. (Check: $14641\cdot11=146410+14641=161051$.)
