You are locked in a room whose door code is $11^4$, and you have no pencil, but there is a picture of Pascal's triangle on the wall.
\begin{enumerate}
\item[(a)] Explain how row $4$ of Pascal's triangle, $1\ 4\ 6\ 4\ 1$, gives $11^4$ immediately, and find $11^4$.
\item[(b)] Does row $5$, $1\ 5\ 10\ 10\ 5\ 1$, give $11^5$ in the same way? Find $11^5$.
\end{enumerate}
