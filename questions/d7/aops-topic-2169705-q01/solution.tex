\textbf{Units column of the sum.} $B+A$ ends in the digit $A$, so $B+A=A$ or $B+A=A+10$; the second is impossible because $B\le9$. So $B=0$ and there is no carry, which gives $A+C=D$ in the tens column.

\textbf{The difference.} Now $AB=10A$ and $CA=10C+A$, so
\[10A-(10C+A)=A,\qquad 8A=10C,\qquad 4A=5C .\]
Since $A$ is a nonzero digit (it leads $AB$), $5\mid A$, so $A=5$ and $C=4$. Then $D=A+C=\boxed{9}$.

Check: $50+45=95$ and $50-45=5$.

(A general tip for such problems: start with the units column, which has no carry coming in, and use it to pin down a digit or a carry; then turn the remaining columns into equations between digits.)
