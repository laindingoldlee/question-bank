$P$ cows graze $Q$ fields bare in $R$ days, $P'$ cows graze $Q'$ fields bare in $R'$ days, and $P''$ cows graze $Q''$ fields bare in $R''$ days. All fields start with the same amount of grass, the grass in each field grows at the same constant daily rate, and all cows eat the same amount per day. Find the relation between $P,Q,R,P',Q',R',P'',Q'',R''$.
