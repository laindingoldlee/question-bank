Problems on which nobody scores change nothing, so only the problems on which someone scores matter, and with probability $1$ there will be such problems. Given that someone scores on a problem, Farley scores with probability $\dfrac{0.4}{0.7}=\dfrac47$ and Bohan with probability $\dfrac37$, independently from one scoring problem to the next.

Farley needs $1$ more point and Bohan needs $2$. Bohan wins only if he scores on the next two scoring problems, with probability $\left(\dfrac37\right)^2=\dfrac{9}{49}$. So Farley wins with probability
\[1-\dfrac{9}{49}=\boxed{\dfrac{40}{49}}.\]
