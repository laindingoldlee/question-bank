By independence, probabilities of ``and'' events multiply.
\begin{enumerate}
\item[(a)] $0.97\cdot0.64=\boxed{0.6208}$.
\item[(b)] $0.64\cdot0.5=\boxed{0.32}$.
\item[(c)] $1-0.34=\boxed{0.66}$.
\item[(d)] $0.97\cdot0.64\cdot0.34\cdot0.5=\boxed{0.105536}$.
\item[(e)] Each dislikes it with probability $0.03$, $0.36$, $0.66$, $0.5$, so the answer is $0.03\cdot0.36\cdot0.66\cdot0.5=\boxed{0.003564}$.
\end{enumerate}
