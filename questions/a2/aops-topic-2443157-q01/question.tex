Let $P(x)$ be a polynomial with real coefficients such that
\[P(1)=1,\quad P(2)=2,\quad P(3)=3,\quad P(4)=4,\quad P(5)=5,\quad P(6)=6,\quad P(7)=8.\]
How many of the following statements must be true?
\begin{enumerate}
\item[I.] If $P(9)$ is an integer, then $P(8)$ is rational.
\item[II.] If $P$ has degree $6$, then $P(n)$ is an integer for every integer $n$.
\item[III.] If $P$ has degree $7$ and $P(9)=9$, then $P(n)$ is an integer for every integer $n$.
\end{enumerate}
