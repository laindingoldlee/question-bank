A remainder must satisfy $0\le a<b$, so each subset has only one possible labelling: its smaller element is $a$. Test the $45$ pairs:
\begin{verbatim}
pairs=[(a,b) for a in range(1,11)
       for b in range(a+1,11) if pow(a,b,b)==a]
print(len(pairs)) # 23
\end{verbatim}
For an explicit check, the counts by larger entry $b=2,3,\ldots,10$ are $1,2,1,4,3,6,1,2,3$, summing to $\boxed{23}$.
