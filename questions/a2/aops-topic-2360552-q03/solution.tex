We show $f(n)=n+1$ by strong induction. $f(1)=2$. If $n$ is even, $f(n)=n+1$ from $f(n-1)=n$. If $n>1$ is odd, $f(n)=(n-1)+2=n+1$. Hence $f(2017)=\boxed{2018}$.
