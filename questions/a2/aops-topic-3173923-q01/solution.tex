If $c^2\ne5$, the coefficient determinant is nonzero, so the system has a unique solution. If $c=\sqrt5$, the first equation is $\sqrt5$ times the second, so solutions exist. If $c=-\sqrt5$, multiplying the second by $-\sqrt5$ gives the first left-hand side but right-hand side $-\sqrt5$, contradicting the first equation. Thus the only value is $\boxed{-\sqrt5}$.
