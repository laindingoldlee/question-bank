There is positive height only for $1\le x<12$. On each unit interval $[k,k+1)$, k=0,...,11, the height is 12k. Thus the area is $12(0+1+\cdots+11)=12\cdot66=\boxed{792}$.

texpreamble("\usepackage{amsmath,amssymb}");

\end{asy}
