Each brother gets $40$ sacks, so Charlie's $\$1400$ pays for $40$ sacks: $\$35$ per sack. Adam bought $45$ and kept $40$, so he supplied $5$ of Charlie's sacks; Ben bought $75$ and kept $40$, supplying $35$. So Adam receives $5\cdot35=\boxed{\$175}$ and Ben receives $35\cdot35=\boxed{\$1225}$.
