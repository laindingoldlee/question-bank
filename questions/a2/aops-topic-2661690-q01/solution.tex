The function $g(x)=x^5+5x^3+5x$ is strictly increasing, so there is exactly one real root.

Substitute $x=t-\dfrac1t$ with $t>0$ (every real $x$ arises this way). Expanding,
\[x^5=t^5-5t^3+10t-\dfrac{10}t+\dfrac5{t^3}-\dfrac1{t^5},\qquad5x^3=5t^3-15t+\dfrac{15}t-\dfrac5{t^3},\qquad5x=5t-\dfrac5t,\]
so $g(x)=t^5-\dfrac1{t^5}$. The equation becomes $u-\dfrac1u=1$ with $u=t^5>0$, i.e. $u^2-u-1=0$, so $u=\dfrac{1+\sqrt5}2$ and $\dfrac1u=\dfrac{\sqrt5-1}2$. Therefore the only real root is
\[x=\boxed{\sqrt[5]{\dfrac{1+\sqrt5}{2}}-\sqrt[5]{\dfrac{\sqrt5-1}{2}}}\approx0.1928.\]
