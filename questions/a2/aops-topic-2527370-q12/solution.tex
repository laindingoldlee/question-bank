The sum of the first $n$ odd numbers is $n^2$: pairing the first and last, the second and second-to-last, and so on, gives $\dfrac n2$ pairs each summing to $2n$ (or use $1+3+\cdots+(2n-1)=\dfrac{n(1+2n-1)}{2}$). So the sum is $50^2=\boxed{2500}$.
