Marcus loses only if Al wins the next three counted rounds before Marcus wins one, which has probability $\left(\dfrac{1}{2}\right)^3=\dfrac{1}{8}$. So Marcus avoids the dishes with probability
\[
1-\dfrac{1}{8}=\boxed{\dfrac{7}{8}}.
\]
Equivalently, the outcomes W, LW, LLW have probabilities $\dfrac{1}{2}$, $\dfrac{1}{4}$, $\dfrac{1}{8}$, which add to $\dfrac{7}{8}$.

The student's list of outcomes is correct, but the four outcomes are \emph{not} equally likely: W takes one round, while LLL takes three. Counting them as $1$ case each gives the wrong value $\dfrac{3}{4}$. The posted solution avoids this by imagining that all three rounds are always played: then the $8$ strings of length $3$ are equally likely, and only LLL is a loss for Marcus; continuing to play after the game is decided does not change who wins.
