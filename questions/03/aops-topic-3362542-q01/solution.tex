The green balls can be distributed in $\binom{2+3-1}{3-1}=\binom42=6$ ways. Independently, the red balls have six distributions. Thus there are $6^2=\boxed{36}$ distributions. A case split based only on total occupancy must retain the colour composition; otherwise some cases receive an incorrect multiplicity.
