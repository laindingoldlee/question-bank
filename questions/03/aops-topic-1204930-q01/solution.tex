Replace the digit $6$ by $3$: this is an order-preserving correspondence between our numbers and base-$4$ numerals. So the terms, in order, correspond to $0,1,2,3,\dots$ written in base $4$. The number $2016$ corresponds to $2013_4=2\cdot64+0\cdot16+1\cdot4+3=135$. Since $0$ is the first term, $135$ is the $136$th, so $N=\boxed{136}$.
