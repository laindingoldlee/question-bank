Each step lowers the number of cats in the box by $1$, so the process ends. The number of tabbies either stays the same (different patterns, or two striped) or drops by $2$ (two tabbies). So its parity never changes, and it stays odd. At the end one cat remains and the tabby count is odd, so it is $1$: the last cat is $\boxed{\text{tabby}}$.
