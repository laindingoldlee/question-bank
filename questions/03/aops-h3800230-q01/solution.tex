Regard the card values as vertices of a graph joined when they differ by one or two. A valid cyclic order is a Hamiltonian cycle. This graph has exactly one undirected Hamiltonian cycle. To prove this by induction, the smallest vertex $1$ must have neighbours $2,3$. For more than three vertices, deleting $1$ and replacing the path $2,1,3$ by edge $2,3$ yields a Hamiltonian cycle of the same type on $2,\ldots,n$. Conversely every such smaller cycle contains edge $2,3$, because $2$ has only neighbours $3,4$ there, and inserting $1$ recovers a valid cycle. The base case of three vertices is unique.
Explicitly the unique order is $1,2,4,6,\ldots,50,49,47,\ldots,3$, up to direction and rotation. With fixed people, choose the holder of card $1$ in $50$ ways and the direction in two ways. The total is $\boxed{100}$.
