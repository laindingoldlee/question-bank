Use Burnside's lemma on the $24$ rotations acting on the $\dbinom84=70$ colourings, counting colourings fixed by each rotation (a colouring is fixed when it is constant on each cycle of unit cubes).
\begin{itemize}
\item Identity: $70$.
\item $90^\circ$ and $270^\circ$ about face axes ($6$ rotations): two $4$-cycles; one must be white: $2$ each, $12$ in all.
\item $180^\circ$ about face axes ($3$): four $2$-cycles; choose two: $6$ each, $18$.
\item $120^\circ$ and $240^\circ$ about body diagonals ($8$): two fixed cubes and two $3$-cycles; white is one $3$-cycle plus one fixed cube: $2\cdot2=4$ each, $32$.
\item $180^\circ$ about edge axes ($6$): four $2$-cycles: $6$ each, $36$.
\end{itemize}
The number of different cubes is $\dfrac{70+12+18+32+36}{24}=\dfrac{168}{24}=\boxed{7}$.
