Suppose $\dfrac{491}{1024}=\dfrac{1}{a}+\dfrac{1}{b}$ with positive integers $a\le b$.

\textbf{Bounding $a$.} Since $\dfrac{1}{b}\le\dfrac{1}{a}$, we get $\dfrac{491}{1024}\le\dfrac{2}{a}$, so $a\le\dfrac{2048}{491}<5$. Since $\dfrac{1}{b}>0$, we get $\dfrac{1}{a}<\dfrac{491}{1024}<\dfrac{1}{2}$, so $a\ge3$. Hence $a=3$ or $a=4$.

\textbf{The two cases.}
\begin{itemize}
\item $a=3$: $\dfrac{1}{b}=\dfrac{491}{1024}-\dfrac{1}{3}=\dfrac{1473-1024}{3072}=\dfrac{449}{3072}$. Since $3072=2^{10}\cdot3$ and $449$ is odd and not a multiple of $3$, this fraction is in lowest terms with numerator $449\ne1$, so it is not $\dfrac{1}{b}$ for an integer $b$.
\item $a=4$: $\dfrac{1}{b}=\dfrac{491}{1024}-\dfrac{256}{1024}=\dfrac{235}{1024}$, again in lowest terms ($235$ is odd) with numerator $235\ne1$.
\end{itemize}
Both cases are impossible, so no such $a,b$ exist. $\blacksquare$

\emph{Remark.} Allowing negative integers does not help. Both negative is impossible since the sum would be negative. If, say, $a>0>b$, write $b=-c$; then $\dfrac{1}{a}=\dfrac{491}{1024}+\dfrac{1}{c}>\dfrac{491}{1024}$ forces $a\in\{1,2\}$, and $\dfrac{1}{c}=1-\dfrac{491}{1024}=\dfrac{533}{1024}$ or $\dfrac{1}{c}=\dfrac{1}{2}-\dfrac{491}{1024}=\dfrac{21}{1024}$, neither of which is a unit fraction.
