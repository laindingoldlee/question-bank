Let $L$ be the \emph{lead}, the number of heads minus the number of tails. It starts at $0$ and each flip changes it by $+1$ or $-1$ with probability $\dfrac{1}{2}$ each. The flipping stops when $L$ first reaches $1$.

\textbf{Key observation.} Whatever the current value $j$ of the lead, the future flips are fair and independent of the past, so the chance that the lead ever rises from $j$ to $j+1$ is the same number $p$ for every $j$, and the number of flips this takes has the same distribution as the stopping time $T$ of the original game.

\textbf{(a)} Condition on the first flip. With probability $\dfrac{1}{2}$ it is heads and we stop at once. With probability $\dfrac{1}{2}$ it is tails and the lead is $-1$; to stop, the lead must first rise from $-1$ to $0$ (probability $p$) and afterwards from $0$ to $1$ (probability $p$, independently of how the first rise happened). Hence
\[
p=\dfrac{1}{2}+\dfrac{1}{2}p^2\qquad\Longleftrightarrow\qquad p^2-2p+1=(p-1)^2=0,
\]
so $p=1$: the flipping stops with probability $1$. $\blacksquare$

\textbf{(b)} Suppose the expected number of flips $m=E[T]$ were finite. Again condition on the first flip. If it is heads, $T=1$. If it is tails, $T=1+T_1+T_2$, where $T_1$ is the number of flips for the lead to rise from $-1$ to $0$ and $T_2$ the number for it to rise from $0$ to $1$; each has the same distribution as $T$, so each has mean $m$. Therefore
\[
m=\dfrac{1}{2}\cdot1+\dfrac{1}{2}\left(1+m+m\right)=1+m,
\]
which is impossible for a finite number $m$. Hence $E[T]=\infty$. $\blacksquare$

So the answer to the question in the post is: the flipping stops with probability $k=1$, but the expected number of flips is infinite. (In fact $P(T>n)$ is of order $\dfrac{1}{\sqrt n}$, which tends to $0$ too slowly for the expectation to be finite.)
