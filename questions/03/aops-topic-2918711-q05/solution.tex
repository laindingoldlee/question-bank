Whatever the parentheses, $45$ ends up in the numerator and $46$ in the denominator; each of $47,\dots,52$ can end up in either. The value is smallest when all of them are in the denominator, which the ordinary left-to-right evaluation achieves:
\[\dfrac{45}{46\cdot47\cdot48\cdot49\cdot50\cdot51\cdot52}=\boxed{\dfrac1{14983870720}}.\]
