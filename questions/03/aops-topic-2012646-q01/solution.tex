Factor out $x^{10}$:
\[\left(x+x^2+\cdots+x^6\right)^{10}=x^{10}\left(1+x+\cdots+x^5\right)^{10}=x^{10}\left(\dfrac{1-x^6}{1-x}\right)^{10}.\]
So we need the coefficient of $x^{15}$ in $(1-x^6)^{10}(1-x)^{-10}$. Using
\[(1-x^6)^{10}=\sum_{k\ge0}(-1)^k\dbinom{10}{k}x^{6k},\qquad (1-x)^{-10}=\sum_{j\ge0}\dbinom{j+9}{9}x^j,\]
the coefficient of $x^{15}$ is
\[\sum_{k=0}^{2}(-1)^k\dbinom{10}{k}\dbinom{15-6k+9}{9}=\dbinom{24}{9}-10\dbinom{18}{9}+45\dbinom{12}{9}.\]
Now $\dbinom{24}{9}=1307504$, $\dbinom{18}{9}=48620$ and $\dbinom{12}{9}=220$, so the coefficient is
\[1307504-486200+9900=\boxed{831204}.\]
(Equivalently, this is the number of ways for ten standard dice to show a total of $25$.)
