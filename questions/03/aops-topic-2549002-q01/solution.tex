The equation is $9(xyz+x+y+z)=100x+10y+z$, i.e.
\[9xyz=91x+y-8z.\]
If a digit is $0$, the left side is $0$, so $91x+y=8z\le72$, impossible since $x\ge1$. So all digits are at least $1$. Write the equation as
\[x\left(91-9k\right)=8z-y,\qquad k=yz,\]
where $-1\le8z-y\le71$.
\begin{itemize}
\item If $k\ge11$, the left side is at most $-8$: impossible.
\item If $k=10$, then $x=8z-y$ with $(y,z)=(2,5)$ or $(5,2)$, giving $x=38$ or $x=11$: not digits.
\item If $k\le9$, then $91-9k\ge10$, and $x\ge1$ needs $8z-y\ge91-9yz$, i.e. $9yz+8z-y\ge91$. With $yz\le9$:
\begin{itemize}
\item $z=1$: $8y+8\ge91$ needs $y\ge11$; impossible.
\item $z=2$ (so $y\le4$): $17y+16\ge91$ needs $y\ge5$; impossible.
\item $z=3$ (so $y\le3$): $26y+24\ge91$ forces $y=3$, and then $x=\dfrac{21}{10}$.
\item $z=4$ (so $y\le2$): $35y+32\ge91$ forces $y=2$, and then $x=\dfrac{30}{19}$.
\item $z\ge5$ (so $y=1$): $x=\dfrac{8z-1}{91-9z}$, which is $\dfrac{39}{46},\dfrac{47}{37},\dfrac{55}{28},\dfrac{63}{19},\dfrac{71}{10}$ for $z=5,\dots,9$.
\end{itemize}
None of these is an integer.
\end{itemize}
So no three-digit number has the property. $\blacksquare$
