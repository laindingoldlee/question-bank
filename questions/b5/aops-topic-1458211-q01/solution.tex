Write $c_1,c_2,c_3$ for the carries out of the units, tens and hundreds columns. There is no carry out of the thousands column, since the sum has four digits, so the columns give
\[
2E=M+10c_1,\qquad K+M+c_1=A+10c_2,\qquad A+O+c_2=X+10c_3,\qquad T+H+c_3=E .
\]
To make $\overline{EXAM}$ large, try $E=9$ first.

\textbf{$E=9$.} Then $M=8$ and $c_1=1$. In the tens column $K+9=A+10c_2$. If $c_2=0$ then $A=K+9>9$, so $c_2=1$ and $A=K-1$.

Next we make $X$ as large as possible. $X\ne8,9$, so try $X=7$. Then $A+O+1=7+10c_3$. With $c_3=1$ we would need $A+O=16$, impossible since $A,O\le6$ are distinct. So $c_3=0$, $A+O=6$ and $T+H=9$.

Now make $A$ as large as possible, with $A+O=6$ and $A\ne O$:
\begin{itemize}
\item $A=5$, $O=1$, $K=6$: the unused digits are $2,3,4$, and no two of them sum to $9$. This fails.
\item $A=4$, $O=2$, $K=5$: the unused digits are $1,3,6$, and $T+H=9$ with $\{T,H\}=\{3,6\}$. This works.
\end{itemize}
So $\overline{EXAM}=\boxed{9748}$, for example $3459+6289=9748$. No larger value is possible: $E\le9$ and $M=8$ is forced; $X\le7$; with $X=7$, $A=4$ is the largest that works.
