A $4\times4$ grid of rooms has doors between cells sharing a side and a nonnegative integer painting count in each room. Every shortest seven-room path from bottom-left to top-right has the same painting total. The same is true for paths from bottom-right to top-left. Prove the museum cannot have 500 paintings.
