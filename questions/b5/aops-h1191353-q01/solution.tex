Count row by row. The allowable sets of occupied columns within one row are $\mathcal M=\{\varnothing,\{1\},\{2\},\{3\},\{4\},\{5\},\{1,4\},\{1,5\},\{2,5\}\}$. If the preceding two row sets are $P,Q$, the next set $M$ is legal precisely when it has no column equal or adjacent to a column of $P$, and $M\cap Q=\varnothing$. More distant rows impose no restrictions. Start with count $D_0(\varnothing,\varnothing,0)=1$. For every legal $M$, add $D_r(P,Q,k)$ to $D_{r+1}(M,P,k+|M|)$. Discard counts above five occupied cells. The totals by number of rows $r$ and occupied cells $k=0,\ldots,5$ are \[\begin{array}{c|rrrrrr}r\backslash k&0&1&2&3&4&5\\1&1&5&3&0&0&0\\2&1&10&18&2&0&0\\3&1&15&53&40&2&0\\4&1&20&113&204&93&6\\5&1&25&198&598&642&187\end{array}\] This recurrence enumerates every placement exactly once, so the answer is $\boxed{187}$.
