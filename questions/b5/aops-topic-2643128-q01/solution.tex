\textbf{(a)} There are $n^2$ equally likely ordered pairs $(x,y)$. For a fixed $y\ge2$, the number of $x<y$ with $\gcd(x,y)=1$ is $\varphi(y)$; for $y=1$ there are none. By symmetry the pairs with $x>y$ give the same count. A pair $(x,x)$ is coprime only for $x=1$. So the number of coprime pairs is
\[2\left(\varphi(2)+\cdots+\varphi(n)\right)+1=2\left(\varphi(1)+\cdots+\varphi(n)\right)-1,\]
using $\varphi(1)=1$. Dividing by $n^2$ gives the formula. $\blacksquare$

\textbf{(b)} $\varphi(1),\dots,\varphi(10)=1,1,2,2,4,2,6,4,6,4$, with sum $32$. The probability is $\dfrac{2\cdot32-1}{100}=\boxed{\dfrac{63}{100}}$.

(As $n\to\infty$ the probability tends to $\dfrac{6}{\pi^2}\approx0.608$, a classical result not proved here.)
