Put $T=a+c$, so $0\le T\le18$. Divisibility by $11$ requires $(11+b)-(19+T)=b-T-8$ to be $0,-11,$ or $-22$. Divisibility by $9$ requires $30+b+T\equiv0\pmod9$. If $T=b-8$, then $b=8,9$ and neither digit sum works. If $T=b+3$, the congruence becomes $33+2b\equiv0$, giving $b=6$, $T=9$, which is attainable. If $T=b+14$, then $0\le b\le4$ and $44+2b$ is never divisible by $9$. Thus only $b=6$ works, and the requested sum is $\boxed6$.
