Let the pond contain $N$ fish. If the tagged fish are mixed evenly, the fraction of tagged fish in the second catch should be about the same as in the whole pond:
\[
\dfrac{13}{20}\approx\dfrac{20}{N}\qquad\Longrightarrow\qquad N\approx\dfrac{20\cdot20}{13}=\dfrac{400}{13}\approx30.8 .
\]
So the pond has about $\boxed{31}$ fish. (This is the capture-recapture, or Lincoln-Petersen, estimate. It is only an estimate; the data show only that there are at least $20+7=27$ fish, since $7$ untagged fish were caught.)
