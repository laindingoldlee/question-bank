Expand $f(x)=6x^3-39x^2+60x$. Its derivative is $6(3x-10)(x-1)$, so the stationary points are one and $\dfrac{10}{3}$. The first is a local maximum, with value 27, and the second a local minimum. The endpoint x=4 gives zero, while $f(x)\to-\infty$ as $x\to-\infty$. Hence the global maximum for $x\le4$ is $\boxed{27}$.
