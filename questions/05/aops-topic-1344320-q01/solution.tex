The number $N$ satisfies $N-2$ divisible by each of $15,\dots,20$, so $N-2$ is a multiple of
\[
\operatorname{lcm}(15,16,17,18,19,20)=2^4\cdot3^2\cdot5\cdot17\cdot19=232560 .
\]
The case $N-2=0$ gives $N=2$, which is excluded, so the smallest possibility is $N=232560+2=\boxed{232562}$.
