In square $ABCD$, $M$, $N$, $O$, $P$ are points on sides $\overline{AB}$, $\overline{BC}$, $\overline{CD}$ and $\overline{DA}$, respectively. If $AB = 4$, $AM = BM$ and $DP = 3AP$, the least possible value of $MN + NO + OP$ can be expressed as $\sqrt{x}$ for some positive integer $x$. Find $x$.
