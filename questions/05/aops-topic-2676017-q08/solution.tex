$AB$ is perpendicular to both parallel sides, so it is the height $h$. Then $[ABD]=\dfrac{h\cdot AD}{2}$ and $[ABCD]=\dfrac{h(AD+BC)}{2}$. The condition gives $AD+BC=3AD$, so $BC=2AD$. Since $[ABC]=\dfrac{h\cdot BC}{2}$,
\[\dfrac{[ABC]}{[ABD]}=\dfrac{BC}{AD}=\boxed{2}.\]
