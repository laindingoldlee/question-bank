Page $8$ contributes one digit; the nine two-digit pages $18,28,\ldots,98$ contribute $18$, for a running total of $19$. Each further omitted page up to $998$ contributes three digits. Since $230<289=19+90(3)$ but $230-19=211$ is not divisible by three, (a) is impossible. For (b), $232-19=213=71(3)$, so the omitted three-digit pages are $108$ through $808$. The next is $818$, so $N$ can be as large as $\boxed{817}$.
