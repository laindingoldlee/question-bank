For a quadratic, the second differences of $f(1),f(2),f(3),\dots$ are constant. The values $3,1,2$ have first differences $-2,1$ and second difference $3$. Continuing, the first differences are $-2,1,4,7,10$, so
\[f(4)=6,\quad f(5)=13,\quad f(6)=23.\]
Hence $f(1+2+3)=f(6)=\boxed{23}$. (Explicitly, $f(x)=\dfrac{3x^2-13x+16}{2}$.)
