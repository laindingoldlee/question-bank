\textbf{$7^{123}$ modulo $100$.} $7^4=2401\equiv1$, so $7^{123}=\left(7^4\right)^{30}\cdot7^3\equiv343\equiv43\pmod{100}$.

\textbf{$8^{61}$ modulo $100$.} Modulo $4$: $8^{61}\equiv0$. Modulo $25$: $8^2=64\equiv14$, $8^4\equiv196\equiv-4$, $8^5\equiv-32\equiv-7$, $8^{10}\equiv49\equiv-1$, so $8^{20}\equiv1$ and $8^{61}=\left(8^{20}\right)^3\cdot8\equiv8\pmod{25}$. The number below $100$ that is $\equiv8\pmod{25}$ and divisible by $4$ is $8$ (the candidates are $8,33,58,83$). So $8^{61}\equiv8\pmod{100}$.

The total is $\equiv43+8=51\pmod{100}$: the last two digits are $\boxed{51}$.
