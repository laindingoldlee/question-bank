No: $-3<2$ but $9>4$. The correct rule: if $0\le a<b$, then $a^2<b^2$, because $b^2-a^2=(b-a)(b+a)>0$. More generally, squaring preserves an inequality between nonnegative numbers. If both sides are negative it reverses ($a<b\le0$ gives $a^2>b^2$), and if the signs differ no conclusion follows.
