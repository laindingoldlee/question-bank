Expanding both sides,
\[
x^2+(x+1)^2=2x^2+2x+1,\qquad 2x(x+1)+1=2x^2+2x+1,
\]
so they are equal. More generally, $(a-b)^2=a^2-2ab+b^2$, so
\[
a^2+b^2=2ab+(a-b)^2 .
\]
For two consecutive numbers $a=x+1$, $b=x$ we have $(a-b)^2=1$, which gives the observed identity. (For example, $13^2+14^2=365=2\cdot13\cdot14+1$.) It is a form of the square-of-a-difference identity; it also shows $a^2+b^2\ge2ab$, with equality only when $a=b$.
