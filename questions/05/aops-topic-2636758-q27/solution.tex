We need $xy=4\cdot2(x+y)=8x+8y$, i.e. $(x-8)(y-8)=64$. If both factors were negative, each would be greater than $-8$ (as $x,y>0$), so their product would be less than $64$. So both are positive divisors of $64$, giving
\[\boxed{(9,72),\ (10,40),\ (12,24),\ (16,16),\ (24,12),\ (40,10),\ (72,9)}.\]
