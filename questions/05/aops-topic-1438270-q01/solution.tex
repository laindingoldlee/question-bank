\textbf{(a)} The residual of $P$ is $3-1=2$, so $P$ corresponds to $\boxed{(1,2)}$.

\textbf{(b)} The clockwise rotation by $45^\circ$ about the origin is $(x,y)\mapsto\left(\dfrac{x+y}{\sqrt2},\dfrac{y-x}{\sqrt2}\right)$; it maps $(t,t)$ to $(\sqrt2\,t,0)$, so it does take the line $y=x$ onto the $x$-axis. It maps $P$ to $\left(\dfrac{4}{\sqrt2},\dfrac{2}{\sqrt2}\right)=\boxed{(2\sqrt2,\sqrt2)}$.

\textbf{(c)} \textbf{No.} The residual plot is obtained by the map $(x,y)\mapsto(x,\ y-mx-c)$, which moves every point \emph{vertically}. It keeps each point's $x$-coordinate and its \emph{vertical} distance to the line (red, length $2$ for $P$). A rotation keeps the \emph{perpendicular} distance to the line instead (green, length $\sqrt2$ for $P$), and it also moves points horizontally. In general the rotated height is the residual times $\dfrac{1}{\sqrt{1+m^2}}$, and the horizontal positions are changed too. So the two pictures agree only when $m=0$, where the residual plot is the scatterplot shifted down by $c$. For $m\ne0$ the residual plot is a \emph{shear} of the scatterplot, not a rotation: the pattern of points above and below the line is kept (the sign of each residual is the same), but distances and shapes are distorted.
