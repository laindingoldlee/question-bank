A line of best fit $y=mx+c$ is drawn for a scatterplot. The residual plot shows, for each data point $(x,y)$, the point $(x,\ y-(mx+c))$. A student claims: ``if both plots use equal units on both axes, the residual plot is just the scatterplot rotated so that the line of best fit becomes the $x$-axis.''
\begin{enumerate}
\item[(a)] For the line $y=x$ and the data point $P(1,3)$, find the point of the residual plot that corresponds to $P$.
\item[(b)] Find the image of $P$ under the clockwise rotation by $45^\circ$ about the origin, which takes the line $y=x$ onto the $x$-axis.
\item[(c)] Is the student's claim correct? Explain.
\end{enumerate}
