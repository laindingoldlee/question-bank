A proper fraction is a fraction $\dfrac kd$ with integers $1\le k<d$. Find the sum of all proper fractions $\dfrac kd$ with denominator $d\le69$, where each pair $(k,d)$ is counted once (so, for example, $\dfrac12$ and $\dfrac24$ are both counted).
