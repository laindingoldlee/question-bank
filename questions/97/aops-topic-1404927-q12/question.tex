There are $2009$ kangaroos, each of them either light or dark, and they compare their heights. It is known that one light kangaroo is taller than exactly $8$ dark kangaroos, one light kangaroo is taller than exactly $9$ dark kangaroos, one light kangaroo is taller than exactly $10$ dark kangaroos, and so on, each number occurring for exactly one light kangaroo, up to exactly one light kangaroo that is taller than all the dark kangaroos; there are no other light kangaroos. What is the number of light kangaroos?

(A) $1000$\quad (B) $1001$\quad (C) $1002$\quad (D) $1003$\quad (E) this situation is impossible
