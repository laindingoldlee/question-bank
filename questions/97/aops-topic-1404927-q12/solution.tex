Let there be $d$ dark kangaroos. The light kangaroos correspond one-to-one to the numbers $8,9,\dots,d$, so there are $d-7$ of them. Hence
\[
d+(d-7)=2009\quad\Longrightarrow\quad d=1008,
\]
and the number of light kangaroos is $1008-7=1001$. The situation is possible: order the dark kangaroos by height and, for each $k=8,\dots,1008$, put one light kangaroo between the $k$th and the $(k+1)$st shortest dark kangaroo (the last one above all of them). The answer is $\boxed{\text{(B) } 1001}$.
