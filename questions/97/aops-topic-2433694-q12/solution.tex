The first four numbers add up to $4\cdot5=20$, the last four to $4\cdot8=32$, and all seven to $7\cdot6\dfrac47=46$. The fourth number belongs to both groups of four, so it is counted twice in $20+32$:
\[20+32-46=6.\]
The answer is $\boxed{\textbf{(B)}\ 6}$.
