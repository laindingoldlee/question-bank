There are $2^{16}$ images, and each one differs in exactly one pixel from exactly $16$ others (flip any one pixel). Counting ordered pairs gives $2^{16}\cdot16$, and each unordered pair is counted twice, so there are $2^{16}\cdot8=2^{19}=\boxed{524288}$ pairs.
