If Robert's time is $ t $, Jonathan has run 450 metres then, so Jonathan's full time is $\dfrac{4}{3}t $. The 25-second difference gives $\dfrac{t}{3}=25 $, hence $ t=75 $ and Jonathan's time 100. Gavin takes 120 seconds, so his speed is 5 metres per second. After 75 seconds he has 375 metres behind him, leaving $\boxed{225}$ metres.
