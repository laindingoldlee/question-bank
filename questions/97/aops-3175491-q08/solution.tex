Write $k=300+10a+b$, where $1\le a,b\le9$. The exclusion modulo 11 is exactly $a\ne b$. Its sole different permutation still in $S$ is $300+10b+a$. Thus test the 36 unordered digit pairs $a<b$ for gcd one. The successful pairs are $(1,3),(1,4),(1,6),(1,7),(1,9),(2,3),(2,5),(3,4),(3,5),(3,7),(3,8),(4,7),(4,9),(5,6),(5,8),(5,9),(6,7),(7,9),(8,9)$. Each yields both orders, so the answer is $\boxed{38}$.
