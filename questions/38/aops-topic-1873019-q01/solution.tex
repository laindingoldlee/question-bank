\textbf{(a)} Write $a=nq_1+r_1$ and $b=nq_2+r_2$ with $0\le r_1,r_2\le n-1$, so $r_1=a\bmod n$ and $r_2=b\bmod n$. Then $a-b=n(q_1-q_2)+(r_1-r_2)$, so $n\mid a-b$ exactly when $n\mid r_1-r_2$. But $|r_1-r_2|\le n-1$, and the only multiple of $n$ in that range is $0$. Hence $a\equiv b\pmod n$ if and only if $r_1=r_2$.

\textbf{(b)} Take $a=17$, $b=2$, $n=5$: $17-2=15$ is divisible by $5$, so $17\equiv2\pmod5$ is true; but $2\bmod5=2\ne17$, so ``$17=2\bmod5$'' is false. A congruence says that two numbers have the same remainder; it does not say that one of them \emph{is} the remainder.

\textbf{(c)} $2^3=8\equiv1\pmod7$, and congruences can be multiplied, so $2^{99}=(2^3)^{33}\equiv1^{33}=1$ and $2^{100}=2^{99}\cdot2\equiv2\pmod7$. The remainder is $\boxed{2}$.
