Write the two-digit blocks as u,v and set $s=u+v$. Then $100u+v=s^2$, so $99u=s(s-1)$. Four-digit squares have $32\le s\le99$. The divisibility condition requires $s\equiv0$ or one modulo both nine and eleven. Checking these congruences in the interval gives $s=45,55,99$, with valid blocks.
