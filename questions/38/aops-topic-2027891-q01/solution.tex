We have the factorisation
\[
n^k-1=(n-1)\left(n^{k-1}+n^{k-2}+\dots+n+1\right),
\]
which can be checked by expanding: the product telescopes to $n^k-1$. The second factor is an integer, so $n-1\mid n^k-1$.

(Alternatively: $n\equiv1\pmod{n-1}$, so $n^k\equiv1^k=1\pmod{n-1}$.) $\blacksquare$
