The first line is true, but only because $a=b$ makes both sides equal to $0$; it is not an identity. The second line is a correct factorisation of the first.

The error is the step from the second line to the third: it divides both sides by $a-b$. Since $a=b$, this is \textbf{division by $a-b=0$}, which is not allowed. From $(a+b)(a-b)=-(a+b)(a-b)$ one can only conclude $2(a+b)(a-b)=0$, which is true for every pair with $a=b$ and says nothing about $a+b$.

Indeed the conclusion is false: $a=b=1$ satisfies $a=b$, but $a+b=2\ne0$. (The conclusion $a+b=0$ together with $a=b$ would force $a=b=0$.)
