The exterior angle is $180^\circ-150^\circ=30^\circ$. The exterior angles total $360^\circ$, so $n=\dfrac{360}{30}=\boxed{12}$.
\begin{asy}
import graph;import geometry;usepackage("amsmath");size(7cm);
path p;for(int i=0;i<12;++i)p=p--dir(30*i);draw(p--cycle);label("regular dodecagon",(0,-1.3));draw(dir(0)--(2dir(0)-dir(330)),dashed);label("$30^\circ$",(1.25,.1));
\end{asy}
