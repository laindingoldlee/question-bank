$\prod_{k=2}^n(k-1)(k+1)=(n-1)!\cdot\dfrac{(n+1)!}2=\bigl((n-1)!\bigr)^2\cdot\dfrac{n(n+1)}2$. So the product is a square iff the triangular number $\dfrac{n(n+1)}2$ is a square. For $n=2,\dots,8$ these are $3,6,10,15,21,28,36$, so the smallest is $n=\boxed{8}$ ($36=6^2$).
