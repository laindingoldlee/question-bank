Using $F_0=0,F_1=1$, the residues $F_0$ through $F_{17}$ modulo 7 are $0,1,1,2,3,5,1,6,0,6,6,5,4,2,6,1,0,1$. Thus the initial consecutive pair $(0,1)$ returns at indices 16 and 17. Since each next residue is determined by the preceding pair, the sequence repeats with period 16. As $1000\equiv8\pmod{16}$, the residue is $F_8\equiv\boxed0$, choice A.
