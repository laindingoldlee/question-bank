An integer greater than $1$ that is both a square and a cube is a sixth power, so $a=2^6=64$ and $\dfrac{36}{a}=\dfrac{9}{16}$.

The whole chain has probability
\[\dfrac27\cdot\dfrac89\cdot\dfrac{11}{12}\cdot\dfrac{6}{11}\cdot\dfrac{9}{16}\cdot\dfrac23=\dfrac{1}{21}.\]
The dog does not jump with probability $\dfrac57=\dfrac{15}{21}$. These events are disjoint, so the answer is
\[\dfrac{1}{21}+\dfrac{15}{21}=\boxed{\dfrac{16}{21}}.\]
