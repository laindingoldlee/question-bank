There is no need to add up the flea's trips. The dogs close the gap at $10+10=20$ feet per second, so they collide after $\dfrac{500}{20}=25$ seconds. The flea flies at $25$ feet per second during all of this time, so it flies
\[
25\cdot25=\boxed{625\text{ feet}}.
\]
(This is the reasoning in the post, and it is correct; the problem looks hard only if one tries to sum the infinitely many shorter and shorter trips.)
