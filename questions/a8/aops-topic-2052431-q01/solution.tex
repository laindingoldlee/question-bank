The condition says $|f(z)-z|=|f(z)|$ for every $z$, that is,
\[|(a-1+bi)z|=|(a+bi)z|\quad\Longrightarrow\quad|a-1+bi|\,|z|=|a+bi|\,|z| .\]
Taking any $z\ne0$, $|a-1+bi|=|a+bi|$, so $(a-1)^2+b^2=a^2+b^2$, which gives $a=\dfrac{1}{2}$. (Geometrically, $a+bi=f(1)$ is equidistant from $1$ and $0$, so it lies on the line $\operatorname{Re}w=\dfrac{1}{2}$.) Then
\[b^2=|a+bi|^2-a^2=64-\dfrac{1}{4}=\boxed{\dfrac{255}{4}}.\]
