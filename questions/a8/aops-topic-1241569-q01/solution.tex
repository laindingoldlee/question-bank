There are $900^2=810000$ ordered pairs. Count those with no carry. In the units column, a digit pair $(u,u')$ with $u+u'\le9$ can be chosen in $1+2+\cdots+10=55$ ways (including $0$s); the tens column likewise has $55$ choices; the hundreds digits are nonzero with sum at most $9$: $\dbinom92=36$ ways. So there are $36\cdot55\cdot55=108900$ no-carry pairs, and
\[810000-108900=\boxed{701100}\]
pairs need a carry. The attempted count used $45$ for the units and tens columns, which omits the $10$ pairs containing the digit $0$ ($0+0,0+1,\dots,0+9$ and their reverses: in all $55-45=10$). For example $713+512$ requires a carry out of the hundreds column, so it counts.
