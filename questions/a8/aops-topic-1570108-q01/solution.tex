Let $D_j(s)$ count ways to make $s$ dollars with the first $j$ denominations, listed in increasing order as $d_1,\ldots,d_6$. Set $D_0(0)=1$, $D_0(s)=0$ for $s>0$, and use $D_j(s)=D_{j-1}(s)+D_j(s-d_j)$, with negative arguments zero. The two terms partition collections according to whether they contain a $d_j$ bill; removing one such bill gives the second term. Equivalently, initialize an array with $D(0)=1$ and all other entries zero; for each denomination $d$ in order, for $s=d,d+1,\ldots,12345$ set $D(s)\leftarrow D(s)+D(s-d)$. The increasing order allows any number of the current bill while counting each multiset once. Evaluation gives $\boxed{12283518278472}$ collections.
