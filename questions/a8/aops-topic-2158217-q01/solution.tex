First add the fractions exactly:
\[\dfrac{1}{7}+\dfrac{8}{9}=\dfrac{9+56}{63}=\dfrac{65}{63}=1+\dfrac{2}{63}.\]
Long division gives $\dfrac{2}{63}=0.\overline{031746}$ (check: $\dfrac{31746}{999999}=\dfrac{2}{63}$, since $999999=63\cdot15873$ and $2\cdot15873=31746$). So the digits after the decimal point repeat the block $0,3,1,7,4,6$. Since $16=2\cdot6+4$, the $16$th digit is the $4$th digit of the block, which is $\boxed{7}$.

(Adding the decimals $0.\overline{142857}$ and $0.\overline{8}$ digit by digit also works, but one must handle the carries; adding the fractions first avoids that.)
