Every number obtained has the form $2^x3^y$, starting with $12=2^2\cdot3^1$, where $x+y=3$. Each operation changes exactly one of $x$, $y$ by $\pm1$, so it changes the parity of $x+y$. After $60$ operations (an even number) $x+y$ is odd again.

The choices are $12=2^2\cdot3$ ($x+y=3$), $18=2\cdot3^2$ ($3$), $36=2^2\cdot3^2$ ($4$), $72=2^3\cdot3^2$ ($5$) and $108=2^2\cdot3^3$ ($5$). Only $36$ has $x+y$ even, so it cannot be obtained. The others can: for example, reach $18$ ($\div2$, then $\times3$), $72$ ($\times2$, then $\times3$) or $108$ ($\times3$, then $\times3$) in two steps, then use the remaining $58$ steps in pairs ``$\times2$, $\div2$''; $12$ itself is reached with $30$ such pairs.

The answer is $\boxed{\textbf{(C) }36}$.
