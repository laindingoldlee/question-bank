With $6$ and $9$ we get exactly the multiples of $3$ except $3$. Using $20$s changes the residue modulo $3$: $0$ boxes give residue $0$ (largest impossible $3$), one box gives residue $2$ (largest impossible $20+3=23$), two boxes give residue $1$ (largest impossible $40+3=43$). Using $3$ or more boxes of $20$ is never needed, since $60$ can be replaced by ten $6$s. So the largest impossible number is $\boxed{43}$.
