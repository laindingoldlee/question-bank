We need $C=\dfrac {F}{5}$. Then $F=\dfrac{9}{5}\cdot\dfrac {F}{5}+32=\dfrac{9F}{25}+32$, so $\dfrac{16F}{25}=32$ and $F=\boxed{50}$ (which is $10^\circ$C).
