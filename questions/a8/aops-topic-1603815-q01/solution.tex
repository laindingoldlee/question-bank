\textbf{Finding $x$.} If $a_n\to5$, then letting $n\to\infty$ in $a_{n+1}^2=x+a_n$ gives $25=x+5$, so $x=20$.

\textbf{Checking convergence for $x=20$.} We have $a_1=\sqrt{20}<5$. If $a_n<5$, then $a_{n+1}=\sqrt{20+a_n}<\sqrt{25}=5$, so every term is below $5$. Also $a_{n+1}>a_n$ whenever $a_n<5$, because $a_n^2-a_n-20=(a_n-5)(a_n+4)<0$ gives $a_n<\sqrt{20+a_n}$. So the sequence is increasing and bounded above by $5$, hence it converges to some limit $L\le5$ with $L>0$ and $L^2=20+L$, i.e.\ $(L-5)(L+4)=0$, so $L=5$.

Therefore $x=\boxed{20}$.
