Write $0,\dots,999$ with three digits (leading zeros do not affect $f$). Then $g$ is multiplicative over the digits: each digit contributes $1$ if it is $0$--$4$ and $3$ if it is $5$--$9$, so
\[\sum_{i=0}^{999}g(i)=(5\cdot1+5\cdot3)^3=20^3=8000.\]
Remove $i=0$ ($g=1$) and add $i=1000$ ($g=1$): the sum is $\boxed{8000}$.
