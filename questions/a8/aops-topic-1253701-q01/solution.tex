Since $x=y$, the factor $x-y$ equals $0$. ``Cancelling'' it means dividing both sides by $0$, which is not allowed: from $a\cdot0=b\cdot0$ nothing follows about $a$ and $b$ (both sides are $0$ for every $a,b$). That is the false step; everything before it is correct, and $(x+y)\cdot0=y\cdot0$ is a true statement.

The expression $\dfrac{0}{0}$ is undefined: $\dfrac{0}{0}=c$ would mean $c\cdot0=0$, which every number $c$ satisfies, so no single value can be assigned. (The final division by $y$ is also invalid if $y=0$.)
