With $16$ balls he might have exactly $4$ of each colour, so $16$ is not enough. With $17$ balls, if no colour appeared $5$ times there would be at most $4\cdot4=16$ balls, a contradiction (pigeonhole principle). There are $50$ balls of each colour, so the worst case is possible. The answer is $\boxed{17}$.
