Define the four-variable function $F(a,b,c,d)=24$ for every real quadruple. For any given numbers $w,x,y,z$, the expression $F(w,x,y,z)$ uses each once and is $\boxed{24}$. Thus allowing arbitrary functions makes the task automatic; a meaningful puzzle must restrict the permitted operations.
