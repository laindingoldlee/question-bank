For each pair of cars, the passes between them alternate, starting with the car behind. Let $x,y,z\in\{0,1\}$ record whether the pairs (Ford, Toyota), (Ford, Honda), (Toyota, Honda) end up swapped. Let $a$ = times Toyota passed Ford, $c$ = Ford passed Toyota, $b$ = Honda passed Ford, $e$ = Ford passed Honda, $d$ = Honda passed Toyota, $f$ = Toyota passed Honda. Then $a=c+x$, $b=e+y$, $d=f+z$, and
\[a+b=3,\quad c+d=5,\quad e+f=8.\]
So $e+f=(b-y)+(d-z)=(3-c-x)+(5-c)-y-z=8-2c-x-y-z$. Setting this equal to $8$ gives $2c+x+y+z=0$, so $c=x=y=z=0$. No pair is swapped, and the finishing order is $\boxed{\text{Ford, Toyota, Honda}}$.
