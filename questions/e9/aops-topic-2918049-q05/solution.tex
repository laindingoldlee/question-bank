$BC=\sqrt{101^2-20^2}=\sqrt{9801}=99$, so $DB=\dfrac{99}2$. Triangle $ADB$ has base $DB$ on line $BC$ and height $AC=20$, so its area is $\dfrac12\cdot\dfrac{99}2\cdot20=\boxed{495}$.

\end{asy}
