Factor the right sides:
\[
5100=2^2\cdot3\cdot5^2\cdot17,\quad 33462=2\cdot3^2\cdot11\cdot13^2,\quad 17150=2\cdot5^2\cdot7^3,\quad 914760=2^3\cdot3^3\cdot5\cdot7\cdot11^2 .
\]
\begin{itemize}
\item From $ac^2d^3=2\cdot5^2\cdot7^3$: $d^3$ divides $2\cdot5^2\cdot7^3$, so $d=7$ (as $d>1$). Then $ac^2=50=2\cdot5^2$, so $c=5$ and $a=2$.
\item From the first equation, $4\cdot25\cdot bg=5100$, so $bg=51=3\cdot17$, and $\{b,g\}=\{3,17\}$.
\item From the second, $2b^2ef^2=33462$, so $b^2ef^2=16731=3^2\cdot11\cdot13^2$. As $17\nmid16731$, $b=3$ and $g=17$; then $ef^2=11\cdot13^2$, so $f=13$ and $e=11$.
\end{itemize}
Check the fourth equation: $2^3\cdot3^3\cdot5\cdot7\cdot11^2=914760$. So the unique solution is
\[
\boxed{(a,b,c,d,e,f,g)=(2,3,5,7,11,13,17)} .
\]
