With four cards it is possible to have three red and one black, giving only one disjoint same-color pair. For five cards, if the color counts are $r$ and $5-r$, the number of disjoint pairs is $\lfloor \dfrac{r}{2}\rfloor+\lfloor\dfrac{5-r}{2}\rfloor=2$. Thus five always suffice and four need not, so the minimum is $\boxed 5$.
