The $7$ face-up cards are a uniformly random set of $7$ cards from the deck, so there are $\dbinom{52}{7}=133784560$ equally likely sets. Count the complement:
\begin{itemize}
\item no ace: $\dbinom{48}{7}=73629072$ sets;
\item exactly one ace: $4\dbinom{48}{6}=4\cdot12271512=49086048$ sets.
\end{itemize}
So
\[
P(\text{at least two aces})=1-\dfrac{73629072+49086048}{133784560}=\dfrac{11069440}{133784560}=\boxed{\dfrac{128}{1547}}\approx0.083 .
\]
