The $k$th factor is $2^k$ under $k$ square roots, contributing $2^{\dfrac{k}{2^k}}$. So the value is $2^{S}$ with
\[
S=\sum_{k\ge1}\dfrac{k}{2^k}=2
\]
(since $\sum kx^k=\dfrac{x}{(1-x)^2}$, which is $2$ at $x=\dfrac{1}{2}$). The value is $2^2=\boxed{4}$.
