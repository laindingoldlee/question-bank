A student claims that $1+2+4+8+16+\cdots=-1$, with this argument: let $J=1+2+4+8+\cdots$. Then $J=1+2(1+2+4+\cdots)=1+2J$, and subtracting $2J$ from both sides gives $-J=1$, so $J=-1$. Find the error.
