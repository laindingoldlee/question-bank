If $n$ of each are made, $n-\lfloor\dfrac{n}{5}\rfloor$ of each sell. One set of three earns $12+37+41=90$ dollars, so at least ten sell per flavour. For $n=11$ only nine sell, while $n=12$ leaves ten. The sold count is nondecreasing with $n$, proving the minimum is $\boxed{3\cdot12=36}$ pies.
