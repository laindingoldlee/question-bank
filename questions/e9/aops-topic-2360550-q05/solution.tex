Every real $x$ can be written as $x=n+t$ with $n=\lfloor x\rfloor$ an integer and $0\le t<1$. Then $f(x)=n-(n+t)=-t$. As $t$ runs over $[0,1)$, $-t$ runs over $(-1,0]$, and every such value occurs (for example with $x=t\in[0,1)$). The range is $\boxed{(-1,0]}$.
