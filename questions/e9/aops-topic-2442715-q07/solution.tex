Let the number be $N=\overline{abc}$ with $a\ge1$, so $100\le N\le999$ and $N=a!+b!+c!$.
\begin{itemize}
\item No digit is $7$ or more, since $7!=5040>999$.
\item If all digits are at most $4$, then $N\le3\cdot4!=72<100$. So some digit is $5$ or $6$.
\item If some digit is $6$, then $N\ge6!=720$, so $a\ge7$, which is impossible. So no digit is $6$, and some digit is $5$.
\item Then $N\le3\cdot5!=360$, so $a\le3$; in particular $a\ne5$, and the $5$s are among $b,c$.
\item If $b=c=5$, then $N=a!+240$ is one of $241,242,246$, but $N=\overline{a55}$ is one of $155,255,355$: no solution.
\item So exactly one of $b,c$ is $5$ and the other digit $d$ is at most $4$. Then $N=a!+120+d!\le1\cdot6+120+24=150$ (using $a\le3$), so $a=1$ and $N=121+d!$.
\begin{itemize}
\item If $b=5$: $N=150+d=121+d!$ needs $d!=d+29$, impossible for $d\le4$ (since $d!\le24$).
\item If $c=5$: $N=100+10d+5=121+d!$ needs $d!=10d-16$; checking $d=0,1,2,3,4$ gives $1,1,2,6,24$ against $-16,-6,4,14,24$, so $d=4$.
\end{itemize}
\end{itemize}
So the only such number is $\boxed{145}$, and indeed $1!+4!+5!=1+24+120=145$.
