The $k$-th term is $\dfrac{1}{T_{k+1}}$, where $T_m=\dfrac{m(m+1)}{2}$ is the $m$-th triangular number (so $T_2=3$, $T_3=6$, \dots). Each term splits as a difference:
\[
\dfrac{1}{T_m}=\dfrac{2}{m(m+1)}=2\left(\dfrac{1}{m}-\dfrac{1}{m+1}\right).
\]
The first $n$ terms use $m=2,3,\dots,n+1$, so the sum telescopes:
\[
\sum_{m=2}^{n+1}2\left(\dfrac{1}{m}-\dfrac{1}{m+1}\right)=2\left(\dfrac{1}{2}-\dfrac{1}{n+2}\right)=\dfrac{n+2-2}{n+2}=\dfrac{n}{n+2}.
\]
The last term $\dfrac{1}{105}$ is $\dfrac{1}{T_{14}}$, so the sum has $n=13$ terms and equals $\boxed{\dfrac{13}{15}}$.
