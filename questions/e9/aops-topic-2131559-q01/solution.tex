Imagine that, instead of stopping, we keep drawing until the bag is empty. Drawing at random without replacement produces a uniformly random ordering of the $100$ coins, and the actual process is just the beginning of this ordering, so it is enough to work with the full ordering.

The process stops when one colour runs out, and the coin drawn at that moment is the last coin of that colour. So the last coin drawn is silver exactly when the silver coins run out first, that is, when all $30$ silver coins appear before the last gold coin. This happens exactly when the \emph{last coin of the full ordering is gold}. (If the last coin of the full ordering is gold, every silver coin comes before it, so silver runs out first; if it is silver, gold runs out first.)

In a uniformly random ordering, the last position is equally likely to hold any of the $100$ coins, so it holds a gold coin with probability $\dfrac{70}{100}$. The answer is $\boxed{\dfrac{7}{10}}$.
