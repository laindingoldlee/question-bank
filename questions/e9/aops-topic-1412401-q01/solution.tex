The possible values are $N=\overline{ab4}$ with $1\le a\le9$ and $0\le b\le9$, so there are $9\cdot10=90$ equally likely values ($104,114,\dots,994$).

Every such $N$ is even, so $N$ is divisible by $6$ exactly when it is divisible by $3$, that is, when its digit sum $a+b+4$ is a multiple of $3$.

\textbf{Quick count.} Fix the hundreds digit $a$. As $b$ runs through $0,1,\dots,9$, the ten numbers $\overline{a04},\overline{a14},\dots,\overline{a94}$ differ by $10$ each time. Since $10\equiv1\pmod 3$, their remainders mod $3$ cycle through all three values: among any three consecutive $b$ exactly one works. So for each $a$ the number of good $b$ is $3$ or $4$:
\[
a+4\equiv0:\ b\in\{0,3,6,9\},\qquad a+4\equiv1:\ b\in\{2,5,8\},\qquad a+4\equiv2:\ b\in\{1,4,7\}\pmod 3 .
\]
Each of the three residues of $a$ occurs for exactly three values of $a\in\{1,\dots,9\}$, so the number of good $N$ is $3(4+3+3)=30$.

So the probability is $\dfrac{30}{90}=\boxed{\dfrac{1}{3}}$.

(For a countdown answer: consecutive candidates differ by $10\equiv1\pmod3$, so the $90$ candidates $104,114,\dots,994$ hit the residues $2,0,1,2,0,1,\dots$ in turn, and $90$ is a multiple of $3$; exactly one third of them are multiples of $3$.)
