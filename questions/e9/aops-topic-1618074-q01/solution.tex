For $x$ in the domain of $g^{-1}$, the statement $g^{-1}(x)=0$ means that $0$ is the input that $g$ sends to $x$, that is $x=g(0)$. Since $b\ne0$, $g(0)=\dfrac{1}{d\cdot0+b}=\dfrac{1}{b}$ is defined. So the only solution is
\[
x=\boxed{\dfrac{1}{b}}.
\]
(Check with the inverse: from $y=\dfrac{1}{dx+b}$ we get $x=\dfrac{1-by}{dy}$, so $g^{-1}(x)=\dfrac{1-bx}{dx}$, which is $0$ exactly when $x=\dfrac{1}{b}$.)
