Let $n=244592271$. The map $d\mapsto\dfrac {n}{d}$ pairs up the positive divisors of $n$, and $d\cdot\dfrac {n}{d}=n$ ends in $1$.

If $d$ ends in $3$, then the units digit $u$ of $\dfrac {n}{d}$ satisfies $3u\equiv1\pmod{10}$, so $u=7$. Conversely, if $d$ ends in $7$, then $7u\equiv1\pmod{10}$ gives $u=3$. So $d\mapsto\dfrac {n}{d}$ is a bijection between the divisors ending in $3$ and the divisors ending in $7$, and there are $\boxed{16}$ divisors ending in $7$.

(In fact $n=3^3\cdot7^7\cdot11$ has $64$ divisors, $16$ ending in each of $1,3,7,9$.)
