The elements of $S$ add up to $1+2+\cdots+10=55$. Pair each subset $T$ with its complement $S\setminus T$; this splits the $2^{10}=1024$ subsets into $512$ pairs. If $T$ has sum $t$, its complement has sum $55-t$. Since $55$ is odd, $t\ne55-t$, so exactly one of $t$ and $55-t$ is at least $28$ (if $t\ge28$ then $55-t\le27$, and if $t\le27$ then $55-t\ge28$). So each pair contains exactly one subset with sum more than $27$, and the answer is $\boxed{512}$.
