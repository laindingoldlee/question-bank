Work modulo \(10\). For any integer \(n\) and any exponent \(m\ge 1\), \(n^{m+4}\equiv n^m\pmod{10}\). Indeed, modulo \(2\) both sides have the parity of \(n\). Modulo \(5\), both are \(0\) if \(5\mid n\), and otherwise \(n^4\equiv 1\) by Fermat's little theorem. Hence
\[
(n+20)^{n+20}\equiv n^{n+20}\equiv n^{n}\pmod{10},
\]
since \(20\) is a multiple of \(4\). So the units digit of \(n^n\) depends only on \(n\bmod 20\). For \(n=1,\dots,20\) the units digits of \(n^n\) are
\[
1,4,7,6,5,6,3,6,9,0,\ 1,6,3,6,5,6,7,4,9,0,
\]
with sum \(94\). Therefore
\[
\sum_{n=1}^{100}n^n\equiv 5\cdot 94=470\equiv 0\pmod{10},
\]
and since \(100^{100}\equiv 0\), \(S\equiv 0\pmod{10}\). The units digit is \(\boxed{0}\).
