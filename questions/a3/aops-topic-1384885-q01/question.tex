A student is confused about the equation $xy=0$:
\begin{enumerate}
\item[(a)] Describe the set of all points $(x,y)$ in the coordinate plane with $xy=0$. Is it the graph of a function $y=f(x)$?
\item[(b)] The student rewrites $xy=0$ as $y=\dfrac{0}{x}$ and also as $x=\dfrac{0}{y}$, and says these are ``the same''. Describe the set of points satisfying each of these two equations, and explain what went wrong.
\end{enumerate}
