The fraction is undefined exactly when the denominator is $0$. Since $4x^2-68x+289=(2x)^2-2\cdot2x\cdot17+17^2=(2x-17)^2$, this happens only for $x=\dfrac{17}{2}$. So there is $\boxed{1}$ such value.
