Write the nonnegative outer square root as an integer $k$. Then $\sqrt x=2009-k^2\ge0$, so $0\le k\le44$. Each of the $45$ such integers gives one distinct real value $x=(2009-k^2)^2$. Thus there are $\boxed{45}$ values.
