Since $27^{\dfrac{y}{3}}=3^y$ and $729=3^6$, the equation is
\[
\left(\dfrac{1}{2}\right)^{a}+1=3^{k},\qquad a=x^{2015},\quad k=y+6,
\]
with $a$ and $k$ integers.
\begin{itemize}
\item If $a\ge1$, the left side lies in $\left(1,\dfrac{3}{2}\right]$, which contains no integer power of $3$ ($3^0=1$, $3^1=3$).
\item If $a=0$, the left side is $2$, not a power of $3$.
\item So $a<0$. Write $m=-a\ge1$; then $2^m+1=3^k$ with $k\ge1$.
\end{itemize}
Solve $2^m+1=3^k$. If $k$ is odd, then $3^k\equiv3\pmod 8$, so $2^m\equiv2\pmod8$, which forces $m=1$, $k=1$. If $k=2j$ is even, then $2^m=(3^j-1)(3^j+1)$, so both factors are powers of $2$ that differ by $2$; they must be $2$ and $4$, so $j=1$, $k=2$, $m=3$.

Thus $a=-1$ or $a=-3$. Since $a=x^{2015}$ with $x$ an integer, $a=-3$ is impossible and $a=-1$ gives $x=-1$. Then $k=1$, so $y=-5$. Finally
\[
x^{2015}+y^5=-1+(-5)^5=-1-3125=\boxed{-3126}.
\]
Check: $\left(\dfrac{1}{2}\right)^{-1}+1=3$ and $27^{-\dfrac{5}{3}}=3^{-5}$, so the left side is $3\cdot3^5=729$.
