Each three-weekday block has changes $+1,+1,-1$, net $+1$. After $28$ blocks, or $84$ weekdays, progress is $28$; the next two weekdays raise it to $30$. No earlier block reaches $30$, because block $28$ peaks at $29$. Thus weekday $86$ is required, which is $17$ complete weeks after weekday one, namely $\boxed{\text{June 14, 2024}}$.
