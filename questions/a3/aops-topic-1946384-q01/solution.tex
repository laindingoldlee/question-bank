At that moment, $a-b$ is even (both even or both odd) and positive (if the order $a>b$ still holds; if already $a=b$ there is nothing to prove). Write $a-b=2k$ with $k\ge1$. Each second $a-b$ decreases by exactly $2$. After $k$ seconds,
\[
(a-k)-(b+k)=a-b-2k=0,
\]
so $a=b$ at that moment, and both equal $\dfrac{a+b}{2}$ (the sum $a+b$ never changes). $\blacksquare$

(If $a-b$ is odd, it stays odd, so $a=b$ never happens; the parity condition is exactly what is needed.)
