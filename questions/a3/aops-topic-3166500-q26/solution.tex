Use $A=(0,0)$, $P=(3,0)$, $D=(-\dfrac{9}{2},\dfrac{3\sqrt3}{2})$, and $E=(-\dfrac{9}{2},-\dfrac{3\sqrt3}{2})$. Put $v=D-P$, $w=E-P$, and let $J$ rotate vectors counterclockwise by $90^\circ$. A tangent contact vector $u=F-P$ satisfies $|u|=3$ and $u\cdot v=9$, so $u=\dfrac{v}{7}\pm\dfrac{\sqrt6}{7}Jv$, using $|v|^2=63$. Now $|w|^2=63$, $w\cdot v=\dfrac{99}{2}$, and $w\cdot Jv=\dfrac{45\sqrt3}{2}$. Therefore $EF^2=|w-u|^2=72-\dfrac{99}{7}\mp\dfrac{135\sqrt2}{7}$. The two possible values are $\boxed{\dfrac{405-135\sqrt2}{7},\ \dfrac{405+135\sqrt2}{7}}$.
