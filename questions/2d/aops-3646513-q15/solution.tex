With ordinary precedence, all additive blocks after the first have equally likely positive and negative signs, so their expected contributions cancel. Let $E_n$ be the expected first multiplicative block among $n$ twos. The first gap ends that block with probability one half, contributing one to the expectation; multiplication or division continues with combined expected multiplier $\dfrac{(2+\dfrac{1}{2})}{4}=\dfrac{5}{8}$. Hence $E_n=1+(\dfrac{5}{8})E_{n-1}$, with $E_1=2$. Solving gives $E_{10}=\dfrac{8}{3}-(\dfrac{2}{3})(\dfrac{5}{8})^9$. The source format with four positive integer parameters is not appropriate; the well-defined answer is this rational expectation.
