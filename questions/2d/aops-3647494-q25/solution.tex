The rule does not specify a numerical answer independently of the submitted estimates. For estimates $E_1,\ldots,E_m$, the score must solve $S=\max_i 10\cdot2^{-|S-E_i|}$, and the stated rule selects the smallest solution before rounding. Such a solution exists: the continuous difference between the right side and $S$ is positive at zero and nonpositive at ten. Its value changes with the estimates. For example, with a single estimate zero it solves $S2^S=10$, whereas with a single estimate ten, $S=10$ is one solution and the smallest solution satisfies a different equation. Thus a numerical result requires the actual estimates.
