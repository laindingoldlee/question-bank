Put $t=x-3\to0^+$; we need $\lim_{t\to0^+}t^2\ln t$. Write it as $\dfrac{\ln t}{t^{-2}}$, a quotient of the form $\dfrac{-\infty}{\infty}$, and use L'H\^opital's rule:
\[
\lim_{t\to0^+}\dfrac{\ln t}{t^{-2}}=\lim_{t\to0^+}\dfrac{\dfrac{1}{t}}{-2t^{-3}}=\lim_{t\to0^+}\left(-\dfrac{t^2}{2}\right)=0 .
\]
So the limit is $\boxed{0}$.
