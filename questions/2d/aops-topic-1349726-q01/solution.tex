Move the $x$ terms to one side:
\[
2m=x(m-n)+x(m+n)=2mx\qquad\Longleftrightarrow\qquad 2m(1-x)=0 .
\]
\begin{itemize}
\item If $m\ne0$, we can divide by $2m$: $\boxed{x=1}$ (for every $n$).
\item If $m=0$, the equation reads $-xn=-xn$, which is true for every $x$: $\boxed{\text{every real }x\text{ is a solution}}$.
\end{itemize}
