A square frame has outer side $105$ inches and inner side $95$ inches. It is divided into congruent isosceles trapezoids with angles $45^\circ,135^\circ$, each with one base on an outer edge and the other on the corresponding inner edge. Along each outer side an odd number of bases alternate long, short, long, and so on. Find the greatest possible total number of trapezoids.
