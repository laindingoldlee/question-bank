There are $2^3=8$ equally likely sex patterns for three children. ``At least one female'' excludes only $MMM$, leaving $7$ patterns. Among these, ``at least one male'' fails only for $FFF$. So the conditional probability is $\boxed{\dfrac{6}{7}}$.
