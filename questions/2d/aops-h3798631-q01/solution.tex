The two-digit number cannot be $10$, because every multiple of ten ends in zero, which would force $S=O$. It cannot be $11$, since $N\ne O$. Thus $\overline{NO}\ge12$. A three-digit number with distinct digits is at most $987$, so $k\le\lfloor\dfrac{987}{12}\rfloor=82$. This bound is attained by $82\cdot12=984$, using five distinct digits $N=1,O=2,Y=9,E=8,S=4$. Hence $\boxed{k=82}$.
