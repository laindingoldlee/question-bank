Use vectors with origin $O$, and write $\vec A,\vec B,\vec C$ for the position vectors; each has length $R$, the radius.

\begin{asy}
usepackage("amsmath");
size(5cm);
defaultpen(fontsize(10pt));
real R=2; pair O=(0,0),A=R*dir(0),C=R*dir(60),B=R*dir(25);
pair M=A/2,Q=C/2,Nn=(A+B)/2,P=(B+C)/2;
draw(arc(O,R,-20,80),gray); draw(O--A); draw(O--C); draw(A--B--C,gray);
draw(M--P,blue); draw(Nn--Q,red);
label("$O$",O,SW); label("$A$",A,E); label("$B$",B,E); label("$C$",C,NE);
label("$M$",M,S); label("$Q$",Q,NW); label("$N$",Nn,E); label("$P$",P,NE);
dot(M); dot(Q); dot(Nn); dot(P);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

Then $\vec M=\dfrac{\vec A}{2}$, $\vec Q=\dfrac{\vec C}{2}$, $\vec N=\dfrac{\vec A+\vec B}{2}$ and $\vec P=\dfrac{\vec B+\vec C}{2}$, so
\[
\vec{MP}=\dfrac{(\vec C-\vec A)+\vec B}{2},\qquad \vec{NQ}=\dfrac{(\vec C-\vec A)-\vec B}{2}.
\]
Hence
\[
\vec{MP}\cdot\vec{NQ}=\dfrac{|\vec C-\vec A|^2-|\vec B|^2}{4}.
\]
Triangle $AOC$ is isosceles with apex angle $60^\circ$, so it is equilateral and $|\vec C-\vec A|=AC=R=|\vec B|$. The dot product is $0$, so $MP\perp NQ$. $\blacksquare$
