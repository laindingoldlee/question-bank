There are $\dbinom{16}2=120$ pairs. A pair with horizontal and vertical offsets $(a,b)$, $0\le a,b\le3$, has distance $\sqrt{a^2+b^2}$, which is less than $2.5$ exactly when $a^2+b^2<6.25$, i.e. $a^2+b^2\in\{1,2,4,5\}$.

The number of unordered pairs with offsets $(a,b)$ (counting both diagonal directions when $a,b>0$) is $(4-a)(4-b)$ for $a=0$ or $b=0$ and $2(4-a)(4-b)$ otherwise:
\begin{itemize}
\item distance $1$, offsets $(1,0),(0,1)$: $12+12=24$;
\item distance $\sqrt2$, offsets $(1,1)$: $2\cdot9=18$;
\item distance $2$, offsets $(2,0),(0,2)$: $8+8=16$;
\item distance $\sqrt5$, offsets $(2,1),(1,2)$: $2\cdot6+2\cdot6=24$.
\end{itemize}
That is $82$ pairs, and the probability is $\dfrac{82}{120}=\boxed{\dfrac{41}{60}}$.
