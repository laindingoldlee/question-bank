Fix A first and identify reversed circular orders. There are $\dfrac{4 !}{2} = 12$ orders. The following table gives the number of true claims for A,B,C,D,E, in that order:\[\begin{array}{c|c@{\quad}c|c}ABCDE&11201&ABCED&01210\\ABDCE&10110&ABDEC&10010\\ABECD&02111&ABEDC&12002\\ACBDE&20111&ACBED&12112\\ACDBE&21012&ACEBD&11021\\ADBCE&10220&ADCBE&12212\end{array}\]A valid count list must contain two zeros, two twos and one one. Only ABEDC and ADBCE pass. In ABEDC the fairies B,E are neighbours, so it is excluded. In ADBCE the fairies C,D are not neighbours. Thus $\boxed{\text{fairies C,D; witches B,E; harpy A}}$.
