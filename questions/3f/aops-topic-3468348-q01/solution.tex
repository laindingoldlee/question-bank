For every integer-coefficient polynomial, $a-b$ divides $P(a)-P(b)$, because $a-b$ divides each $a^k-b^k$. Here 4 would have to divide $13-11=2$, which is false. Thus $\boxed{\text{no such polynomial exists}}$.
