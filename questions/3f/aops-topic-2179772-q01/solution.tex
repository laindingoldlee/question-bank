For a base $a>0$ with $a\ne1$, the function $t\mapsto a^t$ takes every positive value exactly once, so $\log_a y$ is well defined for $y>0$, and to show that $\log_a y=t$ it is enough to check that $a^t=y$. We use only the laws of exponents.

\textbf{(a)} Let $t=\log_a b$, so $a^t=b$. Then $a^{nt}=\left(a^t\right)^n=b^n$, hence $\log_a b^n=nt=n\log_a b$.

\textbf{(b)} Let $s=\log_a b$ and $t=\log_a c$, so $a^s=b$ and $a^t=c$. Then $a^{s+t}=a^sa^t=bc$, hence $\log_a(bc)=s+t$.

\textbf{(c)} With the same $s,t$: $a^{s-t}=\dfrac{a^s}{a^t}=\dfrac{b}{c}$, hence $\log_a\dfrac {b}{c}=s-t$.

\textbf{(d)} Let $u=\log_c b$, so $c^u=b$. By (a),
\[\log_a b=\log_a c^u=u\log_a c .\]
Since $\log_a c=0$ would mean $c=a^0=1$, and $c\ne1$, we have $\log_a c\ne0$, and dividing gives $\dfrac{\log_a b}{\log_a c}=u=\log_c b$.

\textbf{(e)} By (d), $\log_c d=\dfrac{\log_a d}{\log_a c}$ and $\log_c b=\dfrac{\log_a b}{\log_a c}$. Hence both sides of (e) equal $\dfrac{\left(\log_a b\right)\left(\log_a d\right)}{\log_a c}$.

\textbf{(f)} Since $a>0$, $a\ne1$ and $n\ne0$, the base $a^n$ is positive and different from $1$. Let $t=\log_a b$. Then
\[\left(a^n\right)^t=a^{nt}=\left(a^t\right)^n=b^n,\]
so $\log_{a^n}b^n=t=\log_a b$. $\blacksquare$
