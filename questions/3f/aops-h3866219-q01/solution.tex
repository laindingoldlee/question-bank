Every block of four consecutive integers contains a multiple of $4$. A semiprime divisible by $4$ must be $2\cdot 2=4$; any larger multiple of $4$ has at least three prime factors counted with multiplicity. A run of four would therefore contain $4$. The four possible length-four intervals containing $4$ start at $1,2,3,4$, and each contains $1$, a prime, or $8$, so none works. But $33=3\cdot 11$, $34=2\cdot 17$, and $35=5\cdot 7$ are consecutive semiprimes. Thus the maximum is $\boxed 3$, choice B.
