Using $\sin^2x=\dfrac{1-\cos2x}2$ and $\cos^2(1-x)=\dfrac{1+\cos(2-2x)}2$,
\[f(x)=1+\dfrac{\cos(2-2x)-\cos2x}{2}=1-\sin1\cdot\sin(1-2x),\]
by $\cos P-\cos Q=-2\sin\dfrac{P+Q}2\sin\dfrac{P-Q}2$. As $\sin(1-2x)$ takes all values in $[-1,1]$, $f$ ranges over $[1-\sin1,\ 1+\sin1]$.

\begin{asy}
usepackage("amsmath");
size(5.5cm);
defaultpen(fontsize(10pt));
import graph;
real f(real x){return 1-sin(1)*sin(1-2x);}
draw(graph(f,-3,3),linewidth(0.8));
draw((-3.2,0)--(3.3,0),gray,Arrow(4));draw((0,-0.2)--(0,2.1),gray,Arrow(4));
draw((-3,1+sin(1))--(3,1+sin(1)),dashed);draw((-3,1-sin(1))--(3,1-sin(1)),dashed);
label("$1+\sin1$",(3,1+sin(1)),E,fontsize(7pt));label("$1-\sin1$",(3,1-sin(1)),E,fontsize(7pt));
\end{asy}

The marshinization is $\dfrac{(1+\sin1)-(1-\sin1)}{2}=\boxed{\sin1}\approx0.841$.
