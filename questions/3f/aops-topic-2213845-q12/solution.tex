From the equation, $y=\dfrac{x(x-4)}{8}$, which must be a positive integer, so $x>4$. For $x=8k$,
\[y=\dfrac{8k(8k-4)}{8}=4k(2k-1),\]
a positive integer for every $k\ge1$. So the smallest $x$ is $8$ (with $y=4$), and the smallest value of $\sqrt x$ is $\sqrt8=\boxed{2\sqrt2}$.
