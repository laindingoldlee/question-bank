By linearity of expectation, the expected sum is the sum of the expected values of the two dice. One die has expected value
\[
\dfrac{1+2+3+4+5+6}{6}=\dfrac{21}{6}=\dfrac{7}{2} ,
\]
so the expected sum is $\dfrac{7}{2}+\dfrac{7}{2}=\boxed{7}$.

(Directly: the $36$ outcomes pair up as $(a,b)\leftrightarrow(7-a,7-b)$, with sums $s$ and $14-s$, so the average sum is $7$.)
