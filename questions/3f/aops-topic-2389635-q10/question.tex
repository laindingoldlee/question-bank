Assign a number to each letter of the alphabet: $A=1$, $B=2$, \dots, $Z=26$. A teacher writes the letters SOMETHINGFISHY on a board. Every ten seconds, the teacher erases two of the letters and replaces them with the single letter whose value is congruent to the sum of the two erased values modulo $26$. Is it possible for the board ever to show the letters PUFFER (in some order)?
