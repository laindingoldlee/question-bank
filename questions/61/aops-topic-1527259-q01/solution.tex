Each fraction is $1$ plus a reciprocal:
\[
\dfrac{1+xy}{xy}+\dfrac{1+xz}{xz}+\dfrac{1+yz}{yz}=3+\dfrac{1}{xy}+\dfrac{1}{xz}+\dfrac{1}{yz}=3+\dfrac{z+y+x}{xyz}.
\]
Since $x+y+z=xyz\ne0$, the last fraction is $1$, and the value is $\boxed{4}$. (For example, $x=1$, $y=2$, $z=3$ satisfy $1+2+3=1\cdot2\cdot3$.)
