For a regular $k$-gon, the angle is $180-\dfrac{360}{k}$. It is an even integer exactly when $\dfrac{360}{k}$ is an even integer, equivalently $k\mid180$. The number $180=2^2 3^2 5$ has $3\cdot3\cdot2=18$ positive divisors. Exclude $k=1,2$, which are not polygons. Each remaining $k$ gives a distinct positive even angle, so the answer is $\boxed{16}$.

\end{asy}
