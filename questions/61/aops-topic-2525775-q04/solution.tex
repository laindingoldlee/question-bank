Count the complement: $4$-digit numbers in which no two consecutive digits are equal. The first digit has $9$ choices ($1$--$9$), and each later digit has $9$ choices (any digit except the previous one), giving $9^4=6561$. There are $9000$ four-digit numbers, so the answer is $9000-6561=\boxed{2439}$.
