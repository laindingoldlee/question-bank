Put $s=x+y$ and $d=x-y$. These are integers with the same parity (their sum $2x$ is even). The fraction equals $\dfrac15\ne0$, so $x^2-y^2=sd\ne0$; in particular $d\ne0$.

\textbf{Rewriting the equation.} Since $xy=\dfrac{s^2-d^2}{4}$ and $x^2+xy+y^2=s^2-xy=\dfrac{3s^2+d^2}{4}$, the denominator is
\[d\cdot\dfrac{3s^2+d^2}{4}+\dfrac{s^2-d^2}{4}=\dfrac{(3d+1)s^2+d^3-d^2}{4}.\]
The equation says that the denominator is $5\left(x^2-y^2\right)=5sd$, i.e.
\[(3d+1)s^2-20d\,s+d^2(d-1)=0.\tag{$*$}\]
\textbf{Bounding $d$.} As $d$ is an integer, $3d+1\ne0$, so $(*)$ is a quadratic equation in $s$. Its discriminant is
\[400d^2-4(3d+1)\,d^2(d-1)=4d^2\left(100-(3d+1)(d-1)\right)=4d^2\left(101+2d-3d^2\right).\]
Since $s$ is an integer, $(*)$ has a rational root, so its discriminant must be the square of a rational number; as $d\ne0$, this means that $m=101+2d-3d^2$ must be a perfect square. In particular $3d^2-2d\le101$, which allows only $-5\le d\le6$ (for $d=-6$ and $d=7$ the left side is $120$ and $133$). For $d=-5,-4,-3,-2,-1,1,2,3,4,5,6$ the values of $m$ are
\[16,\ 45,\ 68,\ 85,\ 96,\ 100,\ 93,\ 80,\ 61,\ 36,\ 5,\]
and the perfect squares occur only for $d=-5$, $d=1$ and $d=5$.

\textbf{Solving.} The roots of $(*)$ are $s=\dfrac{20d\pm2|d|\sqrt m}{2(3d+1)}=\dfrac{d\left(10\pm\sqrt m\right)}{3d+1}$.
\begin{itemize}
\item $d=1$, $m=100$: $s=\dfrac{10\pm10}{4}$, so $s=5$ or $s=0$. But $s=0$ has the wrong parity (and would give $sd=0$). So $s=5$: $(x,y)=(3,2)$.
\item $d=5$, $m=36$: $s=\dfrac{5(10\pm6)}{16}$, so $s=5$ or $s=\dfrac54$. Only $s=5$ is an integer: $(x,y)=(5,0)$.
\item $d=-5$, $m=16$: $s=\dfrac{-5(10\pm4)}{-14}$, so $s=5$ or $s=\dfrac{15}{7}$. Only $s=5$ is an integer: $(x,y)=(0,5)$.
\end{itemize}
\textbf{Check.} For $(3,2)$ the fraction is $\dfrac{5}{1\cdot19+6}=\dfrac5{25}$; for $(5,0)$ it is $\dfrac{25}{125}$; for $(0,5)$ it is $\dfrac{-25}{-125}$. All equal $0.2$.

So the only possible value is $x+y=\boxed{5}$.

(Without the condition that $x$ and $y$ are integers, $x+y$ is not determined: for $y=1$ the equation becomes $x^3-5x^2+x+4=0$, which has a root $x\approx4.593$, giving $x+y\approx5.593$.)
