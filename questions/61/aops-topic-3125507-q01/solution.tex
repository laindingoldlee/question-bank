It is not. The input has residue $4$ modulo $5$. Cubing fixes residues $0,1,4$ and interchanges $2,3$, so the conditions do not connect residue $4$ with residue $1$. For example the constant function $f=1$ is valid. Another valid function equals $1$ on residue $1$ and $0$ on all other residues. These give respectively $1$ and $0$ at the requested input.
