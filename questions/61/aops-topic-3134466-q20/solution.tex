Total paths number $\binom{10}4=210$. The number through $(x,y)$ is $B(x,y)=\binom{x+y}x\binom{10-x-y}{4-x}$, so allowed paths number $210-B(x,y)$. Over the 33 possible forbidden points, the least blocked count is 1 (at $(4,0)$ or $(0,6)$), and the greatest is 126 (at $(0,1)$ or $(4,5)$). The finite exact table calculation below verifies both extrema. Hence the requested difference is $(210-1)-(210-126)=\boxed{125}$.
\begin{verbatim}
from math import comb
blocked={(x,y):comb(x+y,x)*comb(10-x-y,4-x)
 for x in range(5) for y in range(7)
 if (x,y) not in [(0,0),(4,6)]}
assert len(blocked)==33
assert min(blocked.values())==1 and max(blocked.values())==126
\end{verbatim}
