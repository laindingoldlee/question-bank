Calvin takes a $25$-question multiple-choice test on which each question has five possible answers and each correct answer scores $1$ point. He answers the first $16$ questions correctly, then guesses randomly on the last $9$. What is the probability that Calvin scores exactly $20$? Express your answer as a common fraction.
