Only $x=0$. If $x\ne0$ and both $x$ and $\dfrac{\pi x}{180}$ were integers, then $\pi=\dfrac{180}{x}\cdot\dfrac{\pi x}{180}$ would be a quotient of integers, i.e. rational. But $\pi$ is irrational. So the only such value is $\boxed{x=0}$.
