For $n=1$, $3+5=8=2^3$. We show there are no other solutions. The cubes modulo $9$ are $0,1,8$, and the cubes modulo $7$ are $0,1,6$.

\textbf{Modulo $9$.} Let $n\ge2$. Then $9\mid3^n$, so $3^n+5^n\equiv5^n\pmod 9$. The powers $5^1,5^2,\dots,5^6$ are $\equiv5,7,8,4,2,1\pmod9$, and then they repeat. So $5^n\in\{0,1,8\}\pmod9$ only when $n\equiv0$ or $3\pmod 6$, i.e.\ when $3\mid n$.

\textbf{Modulo $7$.} Both $3^n$ and $5^n$ repeat with period $6$ modulo $7$, since $3^6\equiv5^6\equiv1$. For $n\equiv3\pmod6$ we get $3^n+5^n\equiv27+125=152\equiv5\pmod7$, and for $n\equiv0\pmod6$ we get $1+1=2\pmod7$. Neither $5$ nor $2$ is a cube modulo $7$.

So no $n\ge2$ works, and the only solution is $\boxed{n=1}$ (with $3+5=2^3$). (If $0$ is counted as a natural number: $3^0+5^0=2$ is not a cube.)
