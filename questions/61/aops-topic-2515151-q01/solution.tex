\textbf{(a)} Let $d=\gcd(a,b)$ and write $a=dx$, $b=dy$ with $\gcd(x,y)=1$; then $\operatorname{lcm}(a,b)=dxy$. So
\[\gcd(a,b)+\operatorname{lcm}(a,b)=d(1+xy).\]
If this is a prime $p$, then $d$ is a divisor of $p$, so $d=1$ or $d=p$. But $1+xy\ge2$, so $d=p$ would give $d(1+xy)\ge2p>p$. Hence $d=1$, i.e. $a$ and $b$ are relatively prime. $\blacksquare$

\textbf{(b)} No. If $\gcd(a,b)=1$, then $\gcd+\operatorname{lcm}=1+ab$, which need not be prime: $a=1$, $b=3$ are relatively prime, but $1+3=4$ is not prime.

$\boxed{\text{(a) proved; (b) false, e.g. }a=1,\ b=3}$
