The second equation is exactly twice the first, so the system says only that $5x+2y=4$. It has \textbf{infinitely many solutions}: $\boxed{\left(x,\ \dfrac{4-5x}{2}\right)}$ for any real number $x$ (for example $(0,2)$ and $(2,-3)$).
