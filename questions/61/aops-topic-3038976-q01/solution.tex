For completeness, the following algorithm stops exactly at the first repeated residue. Since each residue determines the next, its repeated suffix is precisely the cycle; earlier residues are the transient. This finite exact verification provides both lists and lengths without confusing transient entries with cycle entries.
\begin{verbatim}
def cycle(a,m):
 seq=[];x=1
 while x not in seq:
  seq.append(x);x=a*x%m
 k=seq.index(x)
 return seq[:k],seq[k:]
p,c=cycle(2,100);assert p==[1,2] and len(c)==20
p,c=cycle(2,1000);assert p==[1,2,4] and len(c)==100
p,c=cycle(3,100);assert p==[] and len(c)==20
\end{verbatim}
