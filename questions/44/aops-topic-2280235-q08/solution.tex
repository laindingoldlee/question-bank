Let $S=f(1)+f(2)+\cdots+f(1985)$. Adding the relation for $n=1,2,\ldots,1985$:
\[f(2)+f(3)+\cdots+f(1986)=\sum_{n=1}^{1985}(-1)^{n+1}n-2S .\]
The left side is $S-f(1)+f(1986)=S$. The alternating sum is
\[(1-2)+(3-4)+\cdots+(1983-1984)+1985=-992+1985=993 .\]
So $S=993-2S$, and $S=\boxed{331}$.

(Such a function exists: every $f(n)$ is determined by $f(1)$, and $f(1986)=(-2)^{1985}f(1)+c$ for some constant $c$; since $(-2)^{1985}\ne1$, the equation $f(1986)=f(1)$ has exactly one solution $f(1)$.)
