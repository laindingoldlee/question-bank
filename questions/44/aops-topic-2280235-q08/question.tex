A function $f$ on the positive integers satisfies
\[f(n+1)=(-1)^{n+1}n-2f(n)\quad\text{for all integers } n\ge1,\]
and $f(1)=f(1986)$. Find $f(1)+f(2)+f(3)+\cdots+f(1985)$.
