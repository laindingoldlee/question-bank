The first digit is always written. Each later digit is written exactly when it differs from the digit before it, which (since the later digits are uniform and independent of the earlier ones) happens with probability $\dfrac9{10}$. By linearity of expectation the expected number is $1+5\cdot\dfrac9{10}=\dfrac{11}2$. Answer $\boxed{\textbf{(D)}\ \dfrac{11}2}$.
