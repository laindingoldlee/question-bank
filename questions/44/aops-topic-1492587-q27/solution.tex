Write $V=\left(a+\dfrac{b}{c}\right)(d+e)$ and $s=d+e$. Since $\dfrac{b}{c}>0$, we have $V>as$.

\textbf{If $a\ge2$.} If $s\ge4$ then $V>2\cdot4=8$. If $s=3$ then $\{d,e\}=\{1,2\}$, so $a\ge3$ and $V>9$. Either way $V>8$.

\textbf{If $a=1$.} Then $d,e\ne1$, so $s\ge2+3=5$, and $V=s+\dfrac{sb}{c}$. For $V$ to be an integer, $\dfrac{sb}{c}$ must be a positive integer, so $V\ge s+1\ge6$. We rule out $V=6$ and $V=7$.
\begin{itemize}
\item $s=5$: then $\{d,e\}=\{2,3\}$, so $b,c\ge4$, and we would need $\dfrac{5b}{c}=1$ or $2$, i.e.\ $c=5b\ge20$ or $c=\dfrac{5b}{2}\ge10$. Impossible.
\item $s=6$: then $\{d,e\}=\{2,4\}$, and $V=7$ needs $c=6b\ge18$. Impossible.
\end{itemize}
So $V\ge8$, and $V=8$ is attained:
\[
\left(1+\dfrac{3}{9}\right)(2+4)=\dfrac{4}{3}\cdot6=8 .
\]
The smallest integer value is $\boxed{8}$, not the poster's $11$.
