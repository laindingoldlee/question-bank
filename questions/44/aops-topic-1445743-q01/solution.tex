\textbf{(a)} If $n=a+b$, then $\dfrac{1}{a}+\dfrac{1}{b}=\dfrac{a+b}{ab}=\dfrac{n}{ab}$, and this equals $\dfrac{n}{10^k}$ exactly when $ab=10^k$.

\textbf{(b)} We need the factor pairs $a\le b$ of $10^k$ whose sum $a+b$ has exactly $k$ digits.
\begin{itemize}
\item $k=1$, $ab=10$: the pairs $(1,10)$ and $(2,5)$ give sums $11$ and $7$; only $7$ has one digit. ($\dfrac{1}{2}+\dfrac{1}{5}=0.7$.)
\item $k=2$, $ab=100$: pairs $(1,100),(2,50),(4,25),(5,20),(10,10)$ with sums $101,52,29,25,20$; the two-digit ones are $52,29,25,20$.
\item $k=3$, $ab=1000$: pairs $(1,1000),(2,500),(4,250),(5,200),(8,125),(10,100),(20,50),(25,40)$ with sums $1001,502,254,205,133,110,70,65$; the three-digit ones are $502,254,205,133,110$.
\end{itemize}
So the slippery numbers below $1000$ are
\[
\boxed{7,\ 20,\ 25,\ 29,\ 52,\ 110,\ 133,\ 205,\ 254,\ 502},
\]
nine besides $20$. (For example $\dfrac{1}{8}+\dfrac{1}{125}=0.125+0.008=0.133$.)

\textbf{(c)} Yes. For every $k\ge2$ take $a=2$ and $b=5\cdot10^{k-1}$. Then $ab=10^k$ and $n=5\cdot10^{k-1}+2$ has exactly $k$ digits, so $n$ is slippery by (a). Hence there are \textbf{infinitely many} slippery numbers.
