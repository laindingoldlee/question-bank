Find the smallest positive integer $n$ with all of the following properties:
\begin{itemize}
\item $n>100$;
\item $n$ is a multiple of $3$;
\item when $n$ is written in base $2$, in base $4$ and in base $8$, and each of these digit strings is read as an ordinary base-$10$ number, each of the three resulting numbers is a multiple of $3$.
\end{itemize}
(For example, $42=101010_2$, and $101010$ is a multiple of $3$.)
