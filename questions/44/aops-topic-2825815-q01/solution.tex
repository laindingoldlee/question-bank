$105=3\cdot5\cdot7$. Modulo $3$: $11\equiv2$, order $2$. Modulo $5$: $11\equiv1$, order $1$. Modulo $7$: $11\equiv4$, and $4^2=16\equiv2$, $4^3=64\equiv1$, order $3$. The order modulo $105$ is $\operatorname{lcm}(2,1,3)=\boxed{6}$.
