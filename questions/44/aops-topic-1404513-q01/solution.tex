Let the visible escalator have $N$ steps, let Sam take $s$ steps per unit time, so Ted takes $4s$, and let the escalator move $e$ steps per unit time.
\begin{itemize}
\item Sam walks for $\dfrac{24}{s}$ time units, during which the escalator carries him $\dfrac{24e}{s}$ steps in the same direction: $N=24+\dfrac{24e}{s}$.
\item Ted walks for $\dfrac{48}{4s}=\dfrac{12}{s}$ time units, during which the escalator carries him back $\dfrac{12e}{s}$ steps: $N=48-\dfrac{12e}{s}$.
\end{itemize}
Let $u=\dfrac{e}{s}$. Then $24+24u=48-12u$, so $u=\dfrac{2}{3}$ and $N=24+16=\boxed{40}$. (Check: $48-8=40$.)
