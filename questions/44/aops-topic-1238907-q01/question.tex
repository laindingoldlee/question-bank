A function $f$ satisfies $f(a)+f(b)=f(ab)$ for all positive integers $a$ and $b$.
\begin{enumerate}
\item[(a)] If $f(3)=5$, find $f(27)$.
\item[(b)] Determine all possible values of $f(1)$.
\end{enumerate}
