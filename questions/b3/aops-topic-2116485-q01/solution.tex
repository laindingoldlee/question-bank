Each of the $5$ problems can go to any of the $10$ friends, independently of the others, so by the multiplication principle the number of ways is
\[10^5=\boxed{100000}.\]
(Stars and bars does not apply here: it counts ways to distribute \emph{identical} objects. If the five papers were identical, the answer would be $\dbinom{14}{5}=2002$; because the problems are different, each assignment of problems to friends counts separately.)
