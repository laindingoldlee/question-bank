We count ordered triples $(a,b,c)$ with $1\le a,b,c\le26$ and $a+b+c=51$. Put $a'=26-a$, etc., with $0\le a',b',c'\le25$; then $a'+b'+c'=78-51=27$.

Without upper bounds the number of solutions is $\dbinom{29}{2}=406$. A variable $\ge26$ leaves $27-26=1$ for the three variables: $\dbinom{3}{2}=3$ ways, for each of $3$ choices of variable; two variables cannot both be $\ge26$. So the count is $406-9=\boxed{397}$.
