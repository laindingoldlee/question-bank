The claim $x^2=2^{2^{2^{\cdots}}}$ is false. If the tower had a value $x$, then removing the bottom $2$ leaves the same tower, so the correct relation is
\[2^{x}=x,\]
not $x^2=x$. But $2^x>x$ for every real $x$ (for $x\le 0$ because $2^x>0\ge x$, and for $x>0$ because $2^x\ge 1+x$ on $[0,1]$ and $2^x$ doubles each time $x$ grows by $1$, faster than $x$), so this equation has no solution.

Directly: the finite towers $2,\ 2^2=4,\ 2^4=16,\ 2^{16}=65536,\dots$ increase without bound, so the infinite tower diverges to $\boxed{\infty}$; it has no finite value. (Even $x=1$ fails the correct equation, since $2^1\ne1$.)
