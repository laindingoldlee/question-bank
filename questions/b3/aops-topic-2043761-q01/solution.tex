The inner sum is \(N\cdot\dfrac{(i-1)i}{2}\), so the left side is
\[
L(x)=\sum_{i=1}^{x}\left(1+N\dfrac{i^2-i}{2}\right)=x+\dfrac {N}{2}\left(\dfrac{x(x+1)(2x+1)}{6}-\dfrac{x(x+1)}{2}\right)=x+\dfrac{N(x^3-x)}{6}.
\]
\emph{Case \(N=0\).} Then \(L(x)=x\), and \(x=x^p\) for \(x=2\) forces \(p=1\); conversely \(p=1\) works.

\emph{Case \(N\ne0\).} Then \(\dfrac{L(x)}{x^3}\to\dfrac {N}{6}\ne0\) as \(x\to\infty\), so \(x^{p-3}\to\dfrac {N}{6}\), which forces \(p=3\) (if \(p>3\) it tends to \(\infty\), if \(p<3\) to \(0\)), and then \(\dfrac {N}{6}=1\), \(N=6\). Check: \(x+(x^3-x)=x^3\) for all \(x\).

So the pairs are \(\boxed{(N,p)=(0,1)\text{ and }(6,3)}\).

(Geometrically, for \(N=6\) the summands \(1+6\cdot\dfrac{i(i-1)}{2}=3i^2-3i+1\) are the centred hexagonal numbers, and stacking the first \(x\) of them builds an \(x\times x\times x\) cube.)
