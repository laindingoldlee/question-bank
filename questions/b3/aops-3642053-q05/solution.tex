A maximal four-head run at either end forces the next inward flip to be T, leaving three free flips: eight strings for each end. A run starting at position two, three or four requires tails on both sides, leaving two free flips: four strings for each. No eight-flip string contains two separate maximal four-runs, and no free fragment can reach length five. Thus there are $8+8+3\cdot4=28$ strings, with probability $\dfrac{28}{256}=\dfrac{7}{64}$. Hence $m+n=\boxed{71}$.
