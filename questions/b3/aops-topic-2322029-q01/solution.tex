If the units digit is $2$, the tens digit is $8$, which is not allowed. So the units digit is $3$ and the tens digit is $9$. These are both odd, so the hundreds digit is even; it is not $0$ (three digits), $4$, $6$ or $8$, so it is $2$. The number is $293$, which is at most $670$, and $293$ is prime (it is not divisible by $2,3,5,7,11,13$ or $17$, and $17^2=289<293<361=19^2$). So the bucket contains $\boxed{293}$ mL.
