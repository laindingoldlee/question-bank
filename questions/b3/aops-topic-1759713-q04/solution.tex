If the population has $N$ dolphins, the proportion tagged is $\dfrac{1000}{N}$, and the sample should show about the same proportion: $\dfrac{400}{2000}=\dfrac{1}{5}$. So $\dfrac{1000}{N}=\dfrac{1}{5}$ and $N=\boxed{5000}$.
