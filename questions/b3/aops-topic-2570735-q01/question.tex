Five classes $A$, $B$, $C$, $D$, $E$ each sent $2$ participants to a chess competition. No two participants played each other more than once, and two participants from the same class never played each other. After some rounds, one participant from class $A$ noticed that the other $9$ participants had all completed different numbers of games. How many games had each of the two participants from class $A$ completed?
