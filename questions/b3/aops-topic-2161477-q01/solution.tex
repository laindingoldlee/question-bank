The function $f$ is strictly increasing (because $x^3$ is), so it has an inverse, and $f^{-1}(33)$ is the number $x$ with $f(x)=33$:
\[4x^3+1=33\iff x^3=8\iff x=2 .\]
So $f^{-1}(33)=\boxed{2}$.
