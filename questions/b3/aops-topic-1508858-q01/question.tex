Solve the inequality $0<|4x+5|<1$. A student argued as follows:
\begin{itemize}
\item If $4x+5>0$: $0<4x+5<1$, so $-\dfrac{5}{4}<x<-1$.
\item If $4x+5<0$: $0<-4x-5<1$, so $-\dfrac{3}{2}<x<-\dfrac{5}{6}$.
\item The answer is the union of the two cases: $-\dfrac{3}{2}<x<-\dfrac{5}{6}$.
\end{itemize}
Find the error and give the correct solution set.
