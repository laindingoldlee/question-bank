The curve consists of the four arcs $y=\pm\sqrt{x^2-1}$, $|x|\ge1$, symmetric about both axes, so it suffices to treat $x\ge1$, $y=\sqrt{x^2-1}$, and the line $y=x$. The vertical gap is
\[x-\sqrt{x^2-1}=\dfrac{1}{x+\sqrt{x^2-1}}<\dfrac1x,\]
which is positive and tends to $0$ as $x\to\infty$. So this arc approaches $y=x$ from below; by symmetry the other arcs approach $y=x$ or $y=-x$. Hence $y=\pm x$ are the asymptotes. $\blacksquare$

\begin{asy}
usepackage("amsmath");
size(3.5cm);
defaultpen(fontsize(10pt));
import graph;real f(real t){return sqrt(t^2-1);}
draw(graph(f,1,3),linewidth(0.8));draw(reflect((0,0),(1,0))*graph(f,1,3),linewidth(0.8));
draw(reflect((0,0),(0,1))*graph(f,1,3),linewidth(0.8));draw(rotate(180)*graph(f,1,3),linewidth(0.8));
draw((-3,-3)--(3,3),dashed);draw((-3,3)--(3,-3),dashed);draw((-3.3,0)--(3.3,0),gray,Arrow);draw((0,-3.3)--(0,3.3),gray,Arrow);
label("$y=x$",(3,3),NE,fontsize(7pt));label("$y=-x$",(3,-3),SE,fontsize(7pt));label("$1$",(1,0),SE,fontsize(7pt));
\end{asy}
