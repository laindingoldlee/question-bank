Subtracting two consecutive triple sums gives $a_{i+3}\equiv a_i\pmod5$. Thus each of the three position classes modulo three uses only one residue modulo five, and each residue has only two decimal digits. At most six distinct digits can occur. Repeat the block $0,1,4,5,6,9$ three times and append $0,1$. Every position class has residues $0,1,4$, whose sum is zero modulo five, so every triple works. All six digits occur, attaining $\boxed6$.
