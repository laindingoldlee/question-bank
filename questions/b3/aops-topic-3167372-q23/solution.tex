If $z<0$, the right side is strictly between $77$ and $78$, impossible for an integer left side. For $z\ge1$, reduction modulo $7$ gives $x^2+y^2\equiv0$. The square residues $0,1,2,4$ show this requires $7\mid x,y$. If $z\ge2$, the right side is $77\equiv28\pmod{49}$ but the left side is divisible by $49$, a contradiction. Thus only $z=0,1$ occur, so the admissible set of $x$ is finite. This set is symmetric under $x\mapsto-x$, since the equation contains $x^2$. Every pair cancels, and any zero would contribute nothing. Therefore the requested sum is $\boxed0$.
