First sequence: the first $k$ terms sum to $k^2$, so $a_k=k^2-(k-1)^2=2k-1$ and $a_{100}=199$. Second sequence: it is increasing with first term $1$, so the range of the first $k$ terms is $b_k-1=k$, giving $b_{100}=101$. The difference is $98$. Answer $\boxed{\textbf{(A)}\ 98}$.
