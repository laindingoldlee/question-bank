Write $n=3+7a$. Modulo 11, $7a\equiv2$, so $a\equiv5$ and $n=38+77b$. Modulo 13 this gives $12+12b\equiv6$, hence $b\equiv6$. Therefore $n\equiv500\pmod{1001}$, and the least positive value is $\boxed{500}$.
