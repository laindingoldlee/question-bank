Pair the terms: $3^{2k}+3^{2k+1}=3^{2k}\cdot4$. Since $3^2=9\equiv1\pmod8$, $3^{2k}\equiv1$, so each pair is $\equiv4\pmod8$. The $2010$ terms form $1005$ pairs, so the sum is
\[
\equiv1005\cdot4=4020=502\cdot8+4\pmod8 .
\]
The remainder is $\boxed{4}$.
