The numeral $10$ in base $a$ means $1\cdot a+0=a$, so $a=b^2$. Then
\[
a+a^2+a^3=b^2+b^4+b^6=1\cdot b^6+0\cdot b^5+1\cdot b^4+0\cdot b^3+1\cdot b^2+0\cdot b+0,
\]
so in base $b$ it is written $\boxed{1010100}$.
