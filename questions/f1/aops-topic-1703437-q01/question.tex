Star polygons are created as follows. $n$ points are equally spaced around a unit circle. An initial point $P_0$ is chosen and the other points are labelled $P_1,P_2,\dots,P_{n-1}$ clockwise. Segment $P_0P_m$ is drawn, where $0<m<n$; then a chord of the same length is drawn from $P_m$ to the $m$th point clockwise from $P_m$, and this is repeated until the path returns to $P_0$. The figure counts as a star polygon only if all $n$ points were used. How many distinct star polygons are there for $n=36$?
