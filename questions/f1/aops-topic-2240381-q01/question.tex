Compute
\[\dfrac{31+71+111}{1+3+5}\cdot\dfrac{5+15+25}{111+71+31}.\]
A student cancels the first numerator against the last denominator, obtaining $\dfrac{5+15+25}{1+3+5}$, and then writes
\[\dfrac{5+15+25}{1+3+5}=\dfrac{5}{1}+\dfrac{15}{3}+\dfrac{25}{5}=15 .\]
Find the correct value and explain the error.
