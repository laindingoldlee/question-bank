The progression condition is $2ac=b(a+c)$. Write $a=mt,c=nt$ with coprime $m>n>0$. Then $b=\dfrac{2mnt}{m+n}$. Because $\gcd(m+n,mn)=1$, primitivity forces
\[
t=\dfrac{m+n}{d},\qquad d=\gcd(m+n,2).
\]
Thus $(a,b,c)=\dfrac{1}{d}(m(m+n),2mn,n(m+n))$. Since $a>\dfrac{m^2}{2}$, only $2\le m\le6$ need checking. The admissible pairs are $(2,1),(3,1),(3,2),(4,1),(5,1),(5,3)$, producing distinct $a$ values $6,15,20$. Therefore the sum is $\boxed{\dfrac{1}{6}+\dfrac{1}{15}+\dfrac{1}{20}=\dfrac{17}{60}}$.
