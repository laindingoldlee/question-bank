Add column by column: the units column gives $5+5=10$, so write $0$ and carry $1$; each of the other eleven columns gives $5+5+1=11$, so write $1$ and carry $1$; the final carry gives a leading $1$. The sum is $1{,}111{,}111{,}111{,}110$. So the digit $0$ appears $\boxed{1}$ time.
