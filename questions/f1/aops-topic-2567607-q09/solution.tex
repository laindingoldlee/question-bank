Label the teams $1,2,3,4$ in order of skill. \emph{The order is known exactly when the three ``adjacent'' pairs $\{1,2\}$, $\{2,3\}$, $\{3,4\}$ have all played.} If they have, the results give $1>2>3>4$ directly. If some adjacent pair $\{i,i+1\}$ has not played, then swapping the skills of $i$ and $i+1$ is consistent with all results, because any other team is better than both or worse than both, so the manager cannot tell.

Each day the pair is uniform among $6$ pairs. While $j$ of the three adjacent pairs are still unseen, a new one appears each day with probability $\dfrac j6$, so the expected wait is $\dfrac6j$. The total expected time is
\[\dfrac63+\dfrac62+\dfrac61=2+3+6=\boxed{11}\text{ days}.\]
