Each reflection preserves the angle to the chord, so successive boundary hits advance by a fixed central angle. For first return on hit 30, this advance is $360^\circ \dfrac{k}{30}$ with $\gcd(k,30)=1$. Opposite orientations give the same initial angle, so take k=1,7,11,13 below 15. Then $\angle BAA^{\prime}=90^\circ-6^\circ k$, giving $84^\circ,48^\circ,24^\circ,12^\circ$. Their sum is $\boxed{168^\circ}$. If earlier returns are allowed and only being at A on hit 30 is required, k=1 through 15 give distinct angles $84^\circ,78^\circ,\ldots,0^\circ$, whose sum is 630 degrees.
\begin{asy}
import graph;import geometry;usepackage("amsmath");size(7cm);
int k=1;draw(circle((0,0),1));pair A=(1,0),B=(-1,0),T=dir(12*k);draw(A--B,dashed);path p=A;for(int j=1;j<=30;++j)p=p--dir(12*k*j);draw(p,blue+linewidth(.35));draw(A--T,red+linewidth(1));label("$A$",A,(1,0));label("$B$",B,(-1,0));label("$A^{\prime}$",T,unit(T));label("$k=1$: first return at hit 30",(0,-1.5));
\end{asy}
