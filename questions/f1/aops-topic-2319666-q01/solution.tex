There are
\[N=10^4\cdot26^5=10000\cdot11881376=118813760000\]
possible strings. Buying the same string twice does not help, so the best strategy is to buy $k$ different strings, which wins with probability $\dfrac kN$. We need $\dfrac kN\ge\dfrac1{100}$, that is,
\[k\ge\dfrac{N}{100}=1188137600.\]
So you need $\boxed{1188137600}$ tickets (about $1.19$ billion).
