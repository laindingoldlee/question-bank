A state lottery ticket is a string of $4$ digits followed by $5$ letters (each digit from $0$ to $9$, each letter from $A$ to $Z$; repetitions allowed). One winning string is drawn, all strings being equally likely. What is the least number of tickets you must buy to have at least a $1\%$ chance of winning?
