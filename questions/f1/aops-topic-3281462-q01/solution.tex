The couple occupy each ordered pair of distinct seats equally likely, giving $12\cdot11=132$ possibilities. Each row has two adjacent unordered seat pairs, so there are $4\cdot2\cdot2=16$ favourable ordered pairs. The probability is $\boxed{\dfrac{4}{33}}$. The other passengers have the same number of arrangements for each couple placement, so multiplying the numerator alone by ten would be invalid.
