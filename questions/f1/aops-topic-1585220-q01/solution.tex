The largest value is $6+4\cdot5+2\cdot10+3\cdot25=121$ cents. We show that \emph{every} value from $1$ to $121$ cents can be formed, so the answer is $121$.

\textbf{Nickels and dimes.} With $n\le4$ nickels and $d\le2$ dimes we get $5(n+2d)$ cents, and $n+2d$ takes every value $0,1,\dots,8$. So nickels and dimes give every multiple of $5$ from $0$ to $40$.

\textbf{Add quarters.} With $q=0,1,2,3$ quarters we get the multiples of $5$ in $[25q,\,25q+40]$. These intervals overlap (consecutive ones start $25$ apart, and each has length $40$), so together they give every multiple of $5$ from $0$ to $115$.

\textbf{Add pennies.} Every integer $v$ from $0$ to $121$ can be written as $v=5m+p$ with $0\le p\le4$ and $0\le 5m\le115$, except $116,\dots,121$, which are $115+p$ with $1\le p\le6$. Since there are $6$ pennies, all values from $0$ to $121$ are formed.

Excluding $0$ (at least one coin is used), there are $\boxed{121}$ distinct values.
