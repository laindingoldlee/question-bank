Decreasing every digit by $2$ turns each number of the first list into a number of the second list, and this is a one-to-one correspondence. It preserves order: two numbers are compared by their first differing digit, and decreasing all digits by $2$ keeps that comparison. So the $k$-th numbers correspond, and each difference is $2222$. Each list has $4!=24$ numbers, so the sum is $24\cdot2222=\boxed{53328}$.
