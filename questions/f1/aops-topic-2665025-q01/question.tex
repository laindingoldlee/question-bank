All $4$-digit numbers that use each of the digits $5,6,7,8$ exactly once are listed from smallest to largest. Similarly, all $4$-digit numbers that use each of the digits $3,4,5,6$ exactly once are listed from smallest to largest. For each $k$, the $k$-th number of the second list is subtracted from the $k$-th number of the first list. What is the sum of these differences?
