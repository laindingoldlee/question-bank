Write $[\ \cdot\ ]$ for area. In triangle $A'BB'$ we have $BA'=AB$, $BB'=2BC$, and $\angle A'BB'=180^\circ-\angle ABC$, so
\[[A'BB']=\dfrac{1}{2}\cdot AB\cdot 2BC\sin\angle ABC=2[ABC].\]
In the same way $[B'CC']=2[BCD]$, $[C'DD']=2[CDA]$ and $[D'AA']=2[DAB]$. The big quadrilateral is $ABCD$ together with these four triangles, so
\[[A'B'C'D']=[ABCD]+2\bigl([ABC]+[CDA]\bigr)+2\bigl([BCD]+[DAB]\bigr)=1+2+2=\boxed{5}.\]
