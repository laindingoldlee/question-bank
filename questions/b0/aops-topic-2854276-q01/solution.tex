One solution is $(x,y)=(2,0)$. If $(x,y)$ is any solution, then $3(x-2)=-5y$, so $5\mid x-2$. Writing $x=2+5t$ gives $y=-3t$. So the solutions are $\boxed{(x,y)=(2+5t,\,-3t),\ t\in\mathbb Z}$.
