If $n=p_1^{e_1}\cdots p_r^{e_r}$, the number of divisors is $(e_1+1)\cdots(e_r+1)$. This equals $10=10\cdot1=5\cdot2$ only for $n=p^9$ or $n=p^4q$ with distinct primes $p,q$.

Since $11\mid n$: $n=11^9$ is far too large; $n=11^4q\ge14641\cdot2$ is too large; so $n=11p^4$ with $p\ne11$. The three-digit values are $11\cdot2^4=176$ and $11\cdot3^4=891$, while $11\cdot5^4=6875$ is too large.

The sum is $176+891=\boxed{1067}$.
