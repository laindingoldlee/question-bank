By rule 1, problems $1,2,4,5$ use all four categories, one each: there are $4!=24$ ways to choose them.

By rule 2, problem $3$ must differ from problems $1$ and $2$, so it is one of the two categories of problems $4$ and $5$: $2$ choices. Similarly problem $6$ is one of the two categories of problems $1$ and $2$: $2$ choices.

Rule 3 is then automatic, because problem $3$ is in the categories of problems $4,5$ and problem $6$ in those of problems $1,2$, and these sets do not overlap.

So there are $24\cdot2\cdot2=\boxed{96}$ combinations.
