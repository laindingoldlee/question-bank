Put one coin in each box first; the remaining $2$ identical coins go into $4$ boxes with no restriction, which by stars and bars can be done in $\dbinom{2+3}{3}=\boxed{10}$ ways (both in one box: $4$ ways; in two different boxes: $\dbinom42=6$ ways). The student's $10$ is correct for distinguishable boxes. The key's $6$ counts only the second case; if the boxes were identical, the answer would be $2$ (the patterns $3,1,1,1$ and $2,2,1,1$).
