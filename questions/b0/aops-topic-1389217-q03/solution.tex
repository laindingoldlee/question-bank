Let $L=\dfrac{1+\sqrt{1+4k}}{2}$, the positive root of $t^2-t-k=0$; the other root $\dfrac{1-\sqrt{1+4k}}{2}$ is negative. For $0<t<L$ we have $k+t-t^2>0$.

Since $c_1=\sqrt k$ and $L^2=L+k>k$, we get $0<c_1<L$. If $0<c_n<L$, then $c_{n+1}=\sqrt{k+c_n}<\sqrt{k+L}=L$, and $c_{n+1}^2-c_n^2=k+c_n-c_n^2>0$, so $c_{n+1}>c_n$. Thus $(c_n)$ is increasing and bounded above by $L$, hence convergent, and its limit $p\ge0$ satisfies $p^2=k+p$. The only nonnegative root is $L$, so
\[
\sqrt{k+\sqrt{k+\sqrt{k+\cdots}}}=\boxed{\dfrac{1+\sqrt{1+4k}}{2}}.
\]
For $k=5$ this is $\dfrac{1+\sqrt{21}}{2}$; for $k=2$ it is $2$, and for $k=6$ it is $3$.
