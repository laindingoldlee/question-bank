Suppose $a<b$ (the other case is symmetric). If $a=1$ then $b=1$, which is not allowed, so $a\ge2$. From $a^b=b^a$,
\[b^a=a^b=a^a\cdot a^{b-a}\quad\Longrightarrow\quad\left(\dfrac {b}{a}\right)^a=a^{b-a},\]
an integer. A rational number whose $a$-th power is an integer must itself be an integer, so $b=ka$ with an integer $k\ge2$. Then $a^{ka}=(ka)^a$ gives $a^k=ka$, that is $a^{k-1}=k$. Since $a\ge2$,
\[2^{k-1}\le a^{k-1}=k,\]
and $2^{k-1}>k$ for $k\ge3$; so $k=2$ and $a=2$, $b=4$. Indeed $2^4=4^2=16$. The pairs are $\boxed{(2,4)\text{ and }(4,2)}$.
