Every odd $n$ with $5\le n\le125$ can be written:
\[\begin{gathered}5=3+2,\ 7=5+2,\ 9=7+2,\ 11=7+4,\ 13=11+2,\ 15=13+2,\ 17=13+4,\ 19=17+2,\ 21=19+2,\ 23=19+4,\\ 25=23+2,\ 27=23+4,\ 29=13+16,\ 31=29+2,\ 33=31+2,\ 35=31+4,\ 37=29+8,\ 39=37+2,\ 41=37+4,\\ 43=41+2,\ 45=43+2,\ 47=43+4,\ 49=47+2,\ 51=47+4,\ 53=37+16,\ 55=53+2,\ 57=53+4,\ 59=43+16,\\ 61=59+2,\ 63=61+2,\ 65=61+4,\ 67=59+8,\ 69=67+2,\ 71=67+4,\ 73=71+2,\ 75=73+2,\ 77=73+4,\\ 79=71+8,\ 81=79+2,\ 83=79+4,\ 85=83+2,\ 87=83+4,\ 89=73+16,\ 91=89+2,\ 93=89+4,\ 95=79+16,\\ 97=89+8,\ 99=97+2,\ 101=97+4,\ 103=101+2,\ 105=103+2,\ 107=103+4,\ 109=107+2,\ 111=109+2,\\ 113=109+4,\ 115=113+2,\ 117=113+4,\ 119=103+16,\ 121=113+8,\ 123=107+16,\ 125=109+16.\end{gathered}\]
For $127$, the differences $127-2^k$ for $k=0,\dots,6$ are $126=2\cdot63$, $125=5^3$, $123=3\cdot41$, $119=7\cdot17$, $111=3\cdot37$, $95=5\cdot19$, $63=7\cdot9$, all composite (and $2^7>127$). So the answer is $\boxed{127}$.
