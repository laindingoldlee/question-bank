Class A has $m$ boys and $11$ girls; class B has $9$ boys and $n$ girls, where $m,n$ are positive integers. Each class contributes $mn+9m+11n+145$ pesos, divided equally among its own students in whole pesos. Find all possible per-student contributions for class B.
