An under-word is a string of letters from $\{M,U,D,K,I,P\}$ that looks the same after reflecting it in a horizontal line (turning it upside down top to bottom, letter by letter, without changing the order). For example, KID is an under-word but DIP is not. How many under-words have at most $4$ letters?
