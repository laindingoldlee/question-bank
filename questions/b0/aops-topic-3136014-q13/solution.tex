Using $x^3+y^3=(x+y)^3-3xy(x+y)$ gives $208=64-12xy$, so $xy=-12$. Therefore $\dfrac{1}{x}+\dfrac{1}{y}=\dfrac{x+y}{xy}=\boxed{-\dfrac{1}{3}}$.
