First give each house $5$ pieces, using $35$. The remaining $85$ pieces can be distributed arbitrarily among the $7$ houses; by stars and bars this can be done in
\[\dbinom{85+6}{6}=\dbinom{91}{6}=\dfrac{91\cdot90\cdot89\cdot88\cdot87\cdot86}{720}=\boxed{\textbf{(C) }666563898}\]
ways.
