\textbf{An invariant.} Note that $x+y+xy=(x+1)(y+1)-1$. So if we add $1$ to every number on the board, a move replaces two numbers $x+1$ and $y+1$ by their product. Hence the product of the numbers ``each plus one'' never changes.

At the start this product is $(3+1)(5+1)(7+1)=4\cdot6\cdot8=192$. At the end there is one number $z$, and $z+1=192$, so $z=191$ whichever pairs are chosen.

So only $\boxed{1}$ value is possible (namely $191$).
