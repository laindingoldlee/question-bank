Suppose that from some position on the digits repeat with period $p$: there are $N$ and $p\ge1$ such that the digit in position $k+p$ equals the digit in position $k$ for every $k\ge N$.

For every $m$, the number $10^m$ is written somewhere in the decimal, and it contributes a $1$ followed by $m$ consecutive zeros. Choose $m$ so large that $m\ge p$ and the block for $10^m$ starts after position $N$. This block contains $p$ consecutive zeros, at some positions $k,k+1,\dots,k+p-1$ with $k\ge N$. By periodicity, every digit after position $k$ is a copy of one of these $p$ digits, so every digit from position $k$ on is $0$.

But after $10^m$ the number $10^m+1$ is written, which contains the digit $1$. This contradiction shows that the decimal is not eventually periodic. Since a real number is rational exactly when its decimal expansion is eventually periodic, the number is irrational. $\blacksquare$
