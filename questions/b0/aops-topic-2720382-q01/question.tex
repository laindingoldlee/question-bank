A robot stands on the middle cell of a $1\times19$ board (cells numbered $1$ to $19$, so it starts on cell $10$). It makes $5$ moves whose directions alternate between left and right (the first move may go either way). The moves have lengths $1,2,3,4,5$ in some order, each used exactly once, and the robot must never leave the board. On how many cells can the robot \emph{not} end up?
