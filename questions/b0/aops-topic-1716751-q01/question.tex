A student wants to find $n$ from the equation $5\cdot6=n$. The student argues: ``Whatever we do to one side we may do to the other, so raise both sides to the power $0$. This gives $(5\cdot6)^0=n^0$, that is, $1=1$, which is true for every $n$. Hence $n$ can be any number.'' But clearly $n=30$ only. Explain exactly where the argument goes wrong.
