For string $abc$, the rotated string is $bca$. If $b>a$, it is later regardless of $c$, giving $\binom{26}2\cdot26$ strings. If $b=a$, it is later exactly when $c>a$, giving $\binom{26}2$. No other case works. Total $325\cdot27=\boxed{8775}$.
