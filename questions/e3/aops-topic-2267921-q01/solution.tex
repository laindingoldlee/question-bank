\textbf{(a)} If $y\ne1$, then $y-1\ne0$, so the quotient $-\dfrac{1}{y-1}$ is defined, and it is a single number; this is the only possible value of $x$. If $y=1$, the denominator is $0$; no number $x$ satisfies $x\cdot0=-1$, so there is no $x$.

\textbf{(b)} Suppose $-\dfrac{1}{y_1-1}=-\dfrac{1}{y_2-1}$ with $y_1,y_2\ne1$. Taking reciprocals, $y_1-1=y_2-1$, so $y_1=y_2$. Thus different values of $y$ give different values of $x$.

The value $x=0$ never occurs, because a fraction with numerator $-1$ is never $0$. If $x\ne0$, solve for $y$: $y-1=-\dfrac{1}{x}$, so
\[y=1-\dfrac{1}{x}=\dfrac{x-1}{x},\]
and this $y$ is not $1$ and does give the value $x$. So exactly the real numbers $\boxed{x\ne0}$ occur, each for exactly one $y$, namely $y=\dfrac{x-1}{x}$.
