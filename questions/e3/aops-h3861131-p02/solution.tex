The value $-20$ is attained by $0-5(2+2)$. To check minimality exhaustively with exact arithmetic, label the two copies of $2$ separately. For each nonempty subset $S$ of the four labeled numbers, let $V(S)$ contain every attainable rational value. For a singleton it contains that number. For every split $S=A\sqcup B$ into nonempty subsets, insert $u+v,u-v,uv$ and, if $v\ne0$, $\dfrac{u}{v}$ for all $u\in V(A),v\in V(B)$. Considering both ordered splits includes reverse subtraction and division. Every parenthesized expression has one such final split, so induction proves completeness. Applying this recurrence to the four numbers gives minimum $\boxed{-20}$.
