Ramazan placed positive integers into the cells of a $4\times4$ table so that the following conditions are satisfied:

$\qquad\bullet$ all numbers in the table are distinct;

$\qquad\bullet$ one of the numbers is equal to $2025$;

$\qquad\bullet$ if we compute the product of the numbers in each row and then add these four products, the resulting number is divisible by $5$;

$\qquad\bullet$ if we compute the product of the numbers in each column and then add these four products, the resulting number is not divisible by $5$.

Provide an example of such an arrangement of numbers.
