We use induction on $n$. For $n=2$: $25+9=34<36$. If $5^n+9<6^n$ for some $n\ge2$, then
\[5^{n+1}+9=5\left(5^n+9\right)-36<5\cdot6^n-36<6\cdot6^n=6^{n+1}.\]
So the inequality holds for all $n\ge2$. $\blacksquare$
