Let $g$ and $c$ be the weights of a genuine and a counterfeit coin, $g\ne c$. The pair weights can be $2g$, $g+c$ or $2c$, and these are all different. So equal weights happen exactly when both pairs are genuine-genuine, or both are genuine-counterfeit (both pairs counterfeit-counterfeit is impossible with only two counterfeits).

Count ordered selections (first pair, second pair):
\begin{itemize}
\item both pairs genuine: $\dbinom82\dbinom62=28\cdot15=420$;
\item each pair one counterfeit and one genuine: $(2\cdot8)(1\cdot7)=112$.
\end{itemize}
All ordered selections are equally likely, so the conditional probability is
\[
\dfrac{420}{420+112}=\dfrac{420}{532}=\boxed{\dfrac{15}{19}},\qquad\textbf{(D)}.
\]
\textbf{The student is right}, apart from not simplifying: $\dfrac{105}{133}=\dfrac{7\cdot15}{7\cdot19}=\dfrac{15}{19}$.
