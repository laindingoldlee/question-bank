Write $N=5q+r$ with $0\le r\le4$. The conditions say that $N=3r+q$ with $0\le q\le2$ (since $q$ is now a remainder on division by $3$). Equating, $5q+r=3r+q$, so $r=2q$.
\begin{itemize}
\item $q=0$: $r=0$, $N=0$, not positive.
\item $q=1$: $r=2$, $N=7$. Check: $7=5\cdot1+2=3\cdot2+1$.
\item $q=2$: $r=4$, $N=14$. Check: $14=5\cdot2+4=3\cdot4+2$.
\end{itemize}
The product of the possible values is $7\cdot14=\boxed{98}$.
