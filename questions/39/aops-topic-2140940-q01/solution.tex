Since $792=8\cdot9\cdot11$ with $8$, $9$, $11$ pairwise coprime, the number must be divisible by $8$, $9$ and $11$.
\begin{itemize}
\item \textbf{By $8$:} the last three digits $\overline{B04}=100B+4\equiv4B+4=4(B+1)\pmod8$ must be divisible by $8$, so $B+1$ is even: $B$ is odd.
\item \textbf{By $9$:} the digit sum $5+9+0+1+A+B+0+4=19+A+B$ is a multiple of $9$, so $A+B=8$ or $A+B=17$.
\item \textbf{By $11$:} the alternating sum of digits from the right, $4-0+B-A+1-0+9-5=9+B-A$, is a multiple of $11$, so $A-B=9$ or $A-B=-2$.
\end{itemize}
If $A-B=9$ then $A=9$, $B=0$, but $B$ must be odd. So $A-B=-2$; with $A+B=17$ there is no integer solution, so $A+B=8$, giving $A=3$, $B=5$ ($B$ is odd, as required). Hence $A+B=\boxed{8}$. Check: $59013504=792\cdot74512$.
