The second expression does not need the first equation at all. Rationalise:
\[
\dfrac{1}{x^2-\sqrt{x^4+1}}=\dfrac{x^2+\sqrt{x^4+1}}{x^4-(x^4+1)}=-\left(x^2+\sqrt{x^4+1}\right).
\]
So the expression equals $x^2+\sqrt{x^4+1}-\left(x^2+\sqrt{x^4+1}\right)=\boxed{0}$, for every real $x$.

(For the record, the first equation does have a solution: since $\left(x+\sqrt{x^2-1}\right)\left(x-\sqrt{x^2-1}\right)=1$, it says $2x=20$, so $x=10$.)
