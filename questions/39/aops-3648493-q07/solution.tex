Up to rotations, a colouring is determined by its number of red faces, 0 through 4. Tetrahedral rotations are transitive on faces and on pairs of faces, so each count gives exactly one class. Hence $\boxed5$.
\begin{asy}
import graph;import geometry;usepackage("amsmath");size(7cm);
pair A=(0,2),B=(-1,0),C=(1,0),D=(.2,.6);fill(A--B--D--cycle,lightred);draw(A--B--C--cycle);draw(A--D^^B--D^^C--D,dashed);label("tetrahedron",(0,-.5));
\end{asy}
