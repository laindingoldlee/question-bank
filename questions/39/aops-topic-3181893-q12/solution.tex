Using $x^3\equiv7$, the remainder is $R(x)=6\cdot7^{672}x-1$. Modulo 1000, $7^4\equiv401$, $7^8\equiv801$, $7^{12}\equiv201$, and $7^{20}\equiv1$. Thus $7^{672}\equiv7^{12}\equiv201$, so $R(1)\equiv6\cdot201-1\equiv\boxed{205}$.
