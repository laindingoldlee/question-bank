Number the sectors $1$ to $6$ around the circle. For a colouring, consider the smallest positive rotation (by $d$ sectors) that leaves it unchanged; $d$ divides $6$, so $d\in\{1,2,3,6\}$, and the colouring is determined by its first $d$ sectors. Rotating such a colouring gives exactly $d$ different colourings, so each spinner (rotation class) with period $d$ contains exactly $d$ colourings.

Count the colourings with each exact period:
\begin{itemize}
\item $d=1$ (one colour): $4$.
\item $d=2$ (pattern $ababab$, $a\ne b$): $4^2-4=12$.
\item $d=3$ (pattern $abcabc$ not of period $1$): $4^3-4=60$.
\item $d=6$: all the rest, $4^6-4-12-60=4096-76=4020$.
\end{itemize}
(Period $2$ and period $3$ patterns overlap only in the constant ones, which have been removed.) The number of different spinners is
\[
\dfrac{4}{1}+\dfrac{12}{2}+\dfrac{60}{3}+\dfrac{4020}{6}=4+6+20+670=\boxed{700}.
\]
