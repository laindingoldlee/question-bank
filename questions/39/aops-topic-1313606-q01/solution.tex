The first person (in some fixed order) can be paired in $13$ ways; then the first unpaired person in $11$ ways; and so on. The number of ways is
\[
13\cdot11\cdot9\cdot7\cdot5\cdot3\cdot1=\boxed{135135}=\dfrac{14!}{2^7\cdot7!}.
\]
