By definition of the logarithm, $x=\log_27$. Using common logarithms,
\[
x=\boxed{\log_27}=\dfrac{\log7}{\log2}\approx\dfrac{0.8451}{0.3010}\approx2.807 .
\]
This is reasonable: $2^2=4<7<8=2^3$, so $2<x<3$, and $7$ is close to $8$, so $x$ is close to $3$.
