A number ending in zero cannot qualify, because its reversal has fewer digits. There are $9\cdot10^3\cdot9=81000$ five-digit numbers with both end digits nonzero. Among them, $9\cdot10\cdot10=900$ are palindromes. Reversal pairs up the remaining $80100$ numbers into unequal pairs, with exactly the smaller number in each pair qualifying. Thus the count is $\boxed{40050}$.
