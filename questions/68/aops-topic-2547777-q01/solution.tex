Write the left side as $\left(x^{2017}\right)^x$. For a fixed $x>0$, the function $u\mapsto u^x$ is strictly increasing on the positive reals, so $\left(x^{2017}\right)^x=(2017x)^x$ holds exactly when $x^{2017}=2017x$, i.e. $x^{2016}=2017$. The only positive solution is
\[\boxed{x=\sqrt[2016]{2017}}.\]
