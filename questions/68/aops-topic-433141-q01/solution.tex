The slope is $\dfrac{12-4}{5-3}=4$, so the line is $y-4=4(x-3)$, i.e. $y=4x-8$.
\begin{asy}
usepackage("amsmath");
size(4cm);
defaultpen(fontsize(10pt));
import graph;draw((-1,0)--(7,0),Arrow);draw((0,-9)--(0,14),Arrow);
real f(real x){return 4x-8;}draw(graph(f,-0.25,5.5));dot((3,4));dot((5,12));label("$(3,4)$",(3,4),E);label("$(5,12)$",(5,12),E);label("$y=4x-8$",(1,-4),E);
\end{asy}

Multiplying by $4$ to get the coefficient $-4$ on $y$: $16x-4y-32=0$. So $A=16$, $C=-32$ and $A+C=\boxed{-16}$.
