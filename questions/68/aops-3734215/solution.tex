There are $\binom{15}{3}=455$ triples. Subtract collinear triples. Horizontal rows contribute $3\binom53=30$. Every other collinear triple must use one point in each of the three rows, and its middle point is the midpoint of the top and bottom points. Thus the top and bottom $x$-coordinates must have the same parity. There are $3^2+2^2=13$ ordered choices of such coordinates, each giving one middle point. These include the five vertical triples and eight slanted triples. Therefore the number of triangles is $455-30-13=\boxed{412}$.
