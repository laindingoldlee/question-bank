\textbf{(a)} Each of the five distinct primes goes into exactly one of $a$, $b$, $c$, independently, and this determines the triple. So there are $3^5=\boxed{243}$ ordered triples. Yes, $1$ must be allowed: it occurs when a factor receives no primes, e.g. $(1,1,2310)$.

\textbf{(b)} Two of $a,b,c$ can be equal only if their common value squared divides $2310$; since $2310$ is squarefree, this value is $1$, giving $\{1,1,2310\}$, which accounts for $3$ ordered triples. All three equal is impossible. The other $243-3=240$ ordered triples have distinct entries and come in groups of $3!=6$. So the number of unordered triples is $\dfrac{240}{6}+1=\boxed{41}$.
