Let $N=8^n+2^n+1$.

\emph{$n$ odd.} Modulo $3$, $8\equiv2\equiv-1$, so $N\equiv(-1)^n+(-1)^n+1=-1\equiv2\pmod3$. Squares are $0$ or $1\pmod 3$, so $N$ is not a square.

\emph{$n$ even,} $n=2m$ with $m\ge1$. Let $A=2^{3m}$, so $8^n=A^2$ and $2^n=2^{2m}$. Then $N>A^2$, and
\[(A+1)^2-N=2\cdot2^{3m}+1-2^{2m}-1=2^{2m}(2^{m+1}-1)>0.\]
So $A^2<N<(A+1)^2$, and $N$ lies strictly between consecutive squares.

In both cases $N$ is not a perfect square. $\blacksquare$
