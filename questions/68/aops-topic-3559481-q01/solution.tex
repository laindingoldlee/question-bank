Each exact fraction is $\dfrac{1}{3}$, or $33\dfrac{1}{3}\%$. The displayed value truncates the repeating decimal $33.33333\ldots\%$. Each slice is understated by $\dfrac{1}{3000}$ percentage point, so the total understatement is $0.001$ percentage point. The exact total remains $100\%$; no cake is missing.
