\emph{All positive solutions.} For each $c$ we need $2b\le149-6c$, i.e. $b\le74-3c$, and then $a$ is determined. So $c=1,\dots,24$ and the count is $\sum_{c=1}^{24}(74-3c)=1776-900=876$.

\emph{Remove those with two equal values.} $a=b$: $3b+6c=150$, $b=50-2c$, $c=1,\dots,24$: $24$ triples. $a=c$: $7c+2b=150$ needs $c$ even, $c=2k$, $b=75-7k$, $k=1,\dots,10$: $10$ triples. $b=c$: $a=150-8c$, $c=1,\dots,18$: $18$ triples. All three equal would need $9c=150$, impossible, so these sets do not overlap.

The answer is $876-24-10-18=\boxed{824}$.
