Use $\sqrt{t^2}=|t|$. Since $3<\sqrt{11}<4$, we have $2-\sqrt{11}<0$ and $11-\sqrt{11}>0$, so
\[
\sqrt{\left(2-\sqrt{11}\right)^2}=\sqrt{11}-2,\qquad \sqrt{\left(11-\sqrt{11}\right)^2}=11-\sqrt{11}.
\]
Therefore the expression equals
\[
\left(\sqrt{11}-2\right)-\left(11-\sqrt{11}\right)=\boxed{2\sqrt{11}-13}\approx-6.37 .
\]
The answer $-13$ is wrong: it takes $|2-\sqrt{11}|$ as $2-\sqrt{11}$, ignoring that this number is negative.
