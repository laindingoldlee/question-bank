Put $r=13\sqrt{15}$, so $r^2=2535$ and $r$ is irrational. Every expression can be written uniquely as $u+vr$ with integers $u,v$; two are equal exactly when both coefficients agree. If $a=d$, the first and fourth expressions coincide, so these cases are excluded.

For the six ordered choices with $a\ne d$, test the nine possibilities for $(b,c)$ by these coefficient pairs. The numbers that pass are:
\[
\begin{array}{c|rrr}
a\backslash d&15&169&r\\ \hline
15&0&6&4\\
169&6&0&4\\
r&5&5&0
\end{array}
\]
This table can be reproduced using $r^2=2535$; for instance multiplication of coefficient pairs is $(u,v)(s,t)=(us+2535vt,ut+vs)$. Compute the four pairs for each $(b,c)$ and reject a case if any two match. This enumerates all $3^4$ assignments without rounding. Adding gives $\boxed{30}$.
