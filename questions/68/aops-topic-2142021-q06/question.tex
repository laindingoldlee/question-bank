Alice and Bob run around a circular track, each at a constant speed of his or her own. They both start at point $A$ and run counterclockwise. After $8$ minutes Alice has run exactly $46$ complete laps (and possibly part of another), and after $7$ minutes Bob has run exactly $41$ complete laps. After $29$ minutes Alice and Bob have both run exactly $x$ complete laps. What is the sum of all possible integer values of $x$?
