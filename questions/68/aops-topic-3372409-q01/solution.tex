Put the long base on $y=0$ from $x=-12$ to $12$. The short base has endpoints $(\pm6,6\sqrt3)$, by Pythagoras. To be nearer the bottom than the top requires $0\le y\le3\sqrt3$. The internal angle bisectors between the bottom and the legs are $x=\pm(12-\sqrt3y)$, so the favorable region lies between them. It is a trapezoid of height $3\sqrt3$, bottom width $24$, and top width $6$. Its area is $\dfrac{24+6}{2}\cdot3\sqrt3=45\sqrt3$. The original area is $\dfrac{24+12}{2}\cdot6\sqrt3=108\sqrt3$. Boundaries have probability zero, so the probability is $\boxed{\dfrac{5}{12}}$.
