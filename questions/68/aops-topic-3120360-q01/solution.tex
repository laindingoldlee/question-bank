If $n$ is even, $2n\mid n^2$, so $n^2=14n-24$, giving $(n-2)(n-12)=0$. Both $2,12$ work. If $n$ is odd, $\gcd(2n,n^2)=n$, so the least common multiple is $2n^2$. Then $n^2-7n+12=0$, giving $n=3,4$, of which only $3$ is odd. Thus the sum is $2+12+3=\boxed{17}$.
