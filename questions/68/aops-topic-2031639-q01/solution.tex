Note $\sqrt{288}=12\sqrt2$. From $\sqrt a=12\sqrt2-\sqrt b$, squaring gives
\[
a=288+b-24\sqrt{2b},\qquad\text{so}\qquad \sqrt{2b}=\dfrac{288+b-a}{24}
\]
is rational. A positive integer whose square root is rational is a perfect square, so $2b=s^2$ for a positive integer $s$; then $s$ is even, $s=2n$, and $b=2n^2$. By symmetry $a=2m^2$ for a positive integer $m$.

Now $\sqrt a+\sqrt b=(m+n)\sqrt2$, so the equation becomes $m+n=12$ with $m,n\ge1$. There are $11$ choices $m=1,2,\dots,11$, each giving one ordered pair $(a,b)=(2m^2,2(12-m)^2)$. Hence the number of ordered pairs is
\[\boxed{11}.\]
(If zero were allowed, $(0,288)$ and $(288,0)$ would add two more.)
