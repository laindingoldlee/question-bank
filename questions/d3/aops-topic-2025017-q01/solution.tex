\textbf{(b)} If $\operatorname{lcm}(x,y)=N$, then $x$ and $y$ divide $N$, so $x=\prod p_i^{a_i}$ and $y=\prod p_i^{b_i}$ with $0\le a_i,b_i\le e_i$, and $\operatorname{lcm}(x,y)=\prod p_i^{\max(a_i,b_i)}$. So the condition is $\max(a_i,b_i)=e_i$ for every $i$, and the choices for different primes are independent.

For one prime, the pairs $(a_i,b_i)$ with $0\le a_i,b_i\le e_i$ number $(e_i+1)^2$; those with $\max(a_i,b_i)<e_i$ number $e_i^2$. So there are $(e_i+1)^2-e_i^2=2e_i+1$ good pairs. Multiplying over the primes gives $(2e_1+1)\cdots(2e_r+1)$.

\textbf{(a)} $400=2^4\cdot5^2$, so the number of pairs is $(2\cdot4+1)(2\cdot2+1)=9\cdot5=\boxed{45}$.
