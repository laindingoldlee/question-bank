With $j$ clockwise moves, the net displacement is $j-2(12-j)=3j-24$, which must be $\equiv0\pmod6$. So $3j\equiv0\pmod6$, i.e. $j$ is even. The probability is $\dfrac{1}{2^{12}}\sum_{j\text{ even}}\dbinom{12}j=\dfrac{2^{11}}{2^{12}}=\boxed{\dfrac12}$.
