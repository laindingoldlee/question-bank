An affine change preserves all relevant line ratios, so set $A=(0,0)$, $B=(7,0)$, $C=(0,6)$. Then
\[
D=(2,0),\ E=(5,0),\ F=\left(\dfrac{35}{6},1\right),\
G=\left(\dfrac{7}{3},4\right),\ H=(0,2),\ K=(0,5).
\]
Parameterize $DG$ by $\left(2+\dfrac{t}{3},4t\right)$. On $FH$, $y=2-\dfrac{6}{35}x$, which yields $t_P=\dfrac{29}{71}$. On $EK$, $x+y=5$, which yields $t_Q=\dfrac{9}{13}$. Thus
\[
\dfrac{DP}{QG}=\dfrac{t_P}{1-t_Q}
=\dfrac{\dfrac{29}{71}}{\dfrac{4}{13}}=\dfrac{377}{284}.
\]
Hence $\boxed{DP:QG=377:284}$.
