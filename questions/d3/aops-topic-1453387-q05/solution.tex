Here $f(x)=kx+5$ with $k=a+b+1$. From $f(-4)=-4k+5=3$ we get $4k=2$, so
\[
f(4)=4k+5=2+5=\boxed{7}.
\]
More generally, $f(x)-5$ is an odd function, so $f(4)-5=-(f(-4)-5)=2$. The same reasoning gives $7$ if the intended function was $ax^5+bx^3+x+5$.
