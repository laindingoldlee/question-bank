Call a sequence of rolls \emph{good} if it has no run of $4$ or more equal consecutive rolls, and let $t_k$ be the number of good sequences of length $k$. A good sequence ends with a final run of length $1$, $2$ or $3$. Removing that run leaves a good sequence of length $k-1$, $k-2$ or $k-3$, and the value of the final run can be any of the $5$ numbers different from the last roll before it. So for $k\ge4$
\[
t_k=5\,(t_{k-1}+t_{k-2}+t_{k-3}),\qquad t_1=6,\ t_2=36,\ t_3=216 .
\]
This gives
\[
t_4=1290,\ t_5=7710,\ t_6=46080,\ t_7=275400,\ t_8=1645950,\ t_9=9837150,\ t_{10}=58792500 .
\]
So the probability is
\[
\dfrac{58792500}{6^{10}}=\dfrac{58792500}{60466176}=\boxed{\dfrac{544375}{559872}}\approx0.9723 .
\]
