Let Richard's number be $r$ and Harvey's $h$; the point $(h,r)$ is uniform in the square $[18,20]^2$ of area $4$. We want $r\ge2h-21$.

If $h\le19.5$, then $2h-21\le18\le r$, so the condition always holds. For $19.5\le h\le20$ the condition fails when $18\le r<2h-21$; this is the triangle with vertices $(19.5,18)$, $(20,18)$, $(20,19)$, with legs $0.5$ and $1$ and area $\dfrac{1}{2}\cdot0.5\cdot1=\dfrac{1}{4}$.

So the probability is $1-\dfrac{\dfrac{1}{4}}{4}=\boxed{\textbf{(e)}\ \dfrac{15}{16}}$.
