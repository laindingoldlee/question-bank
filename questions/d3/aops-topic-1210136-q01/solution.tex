Let the first rectangle be $w$ by $3w$.

\begin{asy}
usepackage("amsmath");
size(6cm);
defaultpen(fontsize(10pt));
draw((0,0)--(36,0)--(36,12)--(0,12)--cycle,linewidth(0.9)); draw((45,0)--(72,0)--(72,16)--(45,16)--cycle,blue+linewidth(0.9));
label("$3w$",(18,0),S); label("$w$",(0,6),W); label("$3w-9$",(58.5,0),S); label("$w+4$",(72,8),E);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

 Then $3w\cdot w=(3w-9)(w+4)=3w^2+3w-36$, so $w=12$. The second rectangle is $27$ by $16$, with perimeter $2(27+16)=\boxed{86}$. (The value $96$ is the perimeter of the first rectangle, $12$ by $36$, which is not what is asked.)
