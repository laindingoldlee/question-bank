Oron takes $\dfrac{420}{8}=52.5$ seconds. If Salmon uses the slow speed on $k$ segments, the time is $12k+6(7-k)=42+6k$. To finish sooner requires $k<\dfrac{7}{4}$, so $k=0$ or $1$. The probability is $\left(\dfrac{2}{5}\right)^7+7\left(\dfrac{3}{5}\right)\left(\dfrac{2}{5}\right)^6=\boxed{\dfrac{1472}{78125}}$.
