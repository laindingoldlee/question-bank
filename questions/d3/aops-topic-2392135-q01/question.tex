Todd and Jeff play a game with a pair of standard six-sided dice, and Todd takes the first turn. On each turn the player rolls both dice. If the sum is a multiple of $3$, the same player takes the next turn; otherwise the other player takes the next turn. The game lasts exactly $5$ turns. What is the probability that Todd takes the last turn?
