An invertible function $f$ is known only through the values $f(0)=1$, $f(6)=7$, $f(7)=8$ and $f(8)=9$.
\begin{enumerate}
\item[(a)] Find $f^{-1}(7)$ and $f^{-1}(9)$.
\item[(b)] Can $f^{-1}(2)$ be found from this information?
\end{enumerate}
