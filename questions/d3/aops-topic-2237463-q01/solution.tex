\textbf{(a)} $f^{-1}(y)$ is the input $x$ with $f(x)=y$. Since $f(6)=7$ and $f(8)=9$, we get $f^{-1}(7)=\boxed6$ and $f^{-1}(9)=\boxed8$.

\textbf{(b)} No. The table only tells us the inputs that give the outputs $1,7,8,9$. The function $g(x)=x+1$ fits the table and gives $g^{-1}(2)=1$. But so does the invertible function
\[h(x)=\begin{cases}5,&x=1,\\2,&x=4,\\x+1,&\text{otherwise},\end{cases}\]
which swaps the values of $x+1$ at $1$ and $4$; it agrees with the table, and $h^{-1}(2)=4$. So the information does not determine $f^{-1}(2)$.
