Write $B$, $T$, $Y$ for the sets of dogs with blue, turquoise and yellow ribbons, and $t=|B\cap T\cap Y|$.

\textbf{(a)} The dogs in $B$ that also have another ribbon form $(B\cap T)\cup(B\cap Y)$, which by inclusion-exclusion has $5+10-t$ dogs. With $t=3$ that is $12$ dogs, more than the $10$ dogs in $B$. So the data are impossible. (Blindly applying the formula would give $10+15+20-5-10-15+3=18$ dogs, but the number of dogs with only a blue ribbon would be $10-5-10+3=-2$.)

\textbf{(b)} The eight regions of the Venn diagram must all be nonnegative. In terms of $t$:
\[\text{only } B:\ 10-15+t,\qquad \text{only } T:\ 15-20+t,\qquad \text{only } Y:\ 20-25+t,\]
\[\text{exactly } B,T:\ 5-t,\qquad \text{exactly } B,Y:\ 10-t,\qquad \text{exactly } T,Y:\ 15-t,\qquad\text{all three}:\ t .\]
The first three require $t\ge5$ and the fourth requires $t\le5$, so $t=5$; then all regions are nonnegative ($0,0,0,0,5,10,5$). The number of dogs is
\[10+15+20-5-10-15+5=\boxed{20}.\]
