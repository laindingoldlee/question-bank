For real $u,v$, $\max(|u+v|,|u-v|)=|u|+|v|$, so the region is $|x|^3+|y|^3\le1000$. It is contained in the vertical strip $-10\le x\le10$, hence any contained circle has radius at most $10$.
The radius-ten circle centred at the origin fits: if $x^2+y^2\le100$, then $|x|,|y|\le10$, so $|x|^3+|y|^3\le10(x^2+y^2)\le1000$. Thus the maximum radius is ten and $\boxed{K=100}$.
\begin{asy}
usepackage("amsmath");
size(7cm);
path p;for(int k=0;k<=360;++k){real t=k*pi/180,c=cos(t),s=sin(t);real x=10*(c>=0?1:-1)*abs(c)^(2/3),y=10*(s>=0?1:-1)*abs(s)^(2/3);p=p--(x,y);}draw(p,blue);draw(circle((0,0),10),red);draw((-10,-12)--(-10,12),dashed);draw((10,-12)--(10,12),dashed);label("$O$",(0,0),SW);draw((0,0)--(10,0),dashed);label("$10$",(5,0),S);label("$|x|^3+|y|^3=1000$",(0,13));
\end{asy}
