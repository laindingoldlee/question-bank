Let the friends get $a,b,c,d$ shares, so $a+b+c+d=24$ with all variables positive integers. ``$a$ is at most the other three combined'' means $a\le24-a$, i.e. $a\le12$; similarly for $b,c,d$.

\textbf{All positive solutions.} By stars and bars there are $\dbinom{23}{3}=1771$ positive solutions of $a+b+c+d=24$.

\textbf{Bad solutions.} A solution is bad if some variable is at least $13$. Two variables cannot both be at least $13$ (their sum would exceed $24$), so we count each variable separately. If $a\ge13$, put $a'=a-12\ge1$; then $a'+b+c+d=12$ in positive integers has $\dbinom{11}{3}=165$ solutions. The same holds for $b,c,d$, giving $4\cdot165=660$ bad solutions.

The number of ways is $1771-660=\boxed{1111}$.
