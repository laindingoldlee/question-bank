Let $k$ be the common value of $M$. Then
\[
ax+by=k(cx+dy)\qquad\text{whenever } cx+dy\ne0 .
\]
\begin{itemize}
\item Take $x=1$, $y=0$: then $cx+dy=c\ne0$, so $a=kc$, i.e.\ $\dfrac {a}{c}=k$.
\item Take $x=0$, $y=1$: then $cx+dy=d\ne0$, so $b=kd$, i.e.\ $\dfrac {b}{d}=k$.
\end{itemize}
Hence $\boxed{\dfrac {a}{c}=\dfrac {b}{d}}\,(=k)$, so $a$, $b$, $c$, $d$ form a proportion. $\blacksquare$

(Conversely, if $\dfrac {a}{c}=\dfrac {b}{d}=k$, then $ax+by=k(cx+dy)$ and $M=k$ for every admissible $x$, $y$.)
