There are $6!-5!=600$ valid block orders, but some yield the same string. Ambiguity of the block $10$ occurs exactly when singleton blocks $1,0$ are consecutive in that order; call this event A. There are $5!=120$ such orders. Ambiguity of $23$ similarly requires consecutive singleton blocks $2,3$, event B; there are $5!-4!=96$ valid orders. Both occur in $4!=24$ orders. The two independent block exchanges give four representations when both events hold, two when exactly one holds, and one otherwise. No other ambiguity is possible, since the only multi-digit blocks are $10,23$ and each uses different digits. Thus $N=(600-120-96+24)+\dfrac{120+96-48}{2}+\dfrac{24}{4}=408+84+6=498$. Its digit sum is $\boxed{21}$.
