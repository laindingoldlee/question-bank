Let $u=\sqrt[3]{13x+37}$, $v=\sqrt[3]{13x-37}$ and $c=\sqrt[3]2$, so $u-v=c$ and $u^3-v^3=74$. Since $u^3-v^3=(u-v)^3+3uv(u-v)$, we get $74=2+3uvc$, so $uv=\dfrac{24}c$. Cubing, $(13x)^2-37^2=\dfrac{24^3}2=6912$. Then $169x^2=8281$, so $x=\pm7$.

Both check: for $x=7$, $\sqrt[3]{128}-\sqrt[3]{54}=4c-3c=c$; for $x=-7$, $\sqrt[3]{-54}-\sqrt[3]{-128}=-3c+4c=c$. So $\boxed{x=\pm7}$.
