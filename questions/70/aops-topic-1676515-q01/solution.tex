All the steps up to $(x-v)^2=(y-v)^2$ are correct. The error is ``taking square roots'': from $p^2=q^2$ one can only conclude $|p|=|q|$, that is, $p=q$ \emph{or} $p=-q$, since $p^2-q^2=(p-q)(p+q)$.

Here $p=x-v$ and $q=y-v$, and since $2v=x+y$,
\[
x-v=\dfrac{x-y}{2},\qquad y-v=\dfrac{y-x}{2}=-(x-v).
\]
So the true relation is $x-v=-(y-v)$, which only says $x+y=2v$, the equation we started with. The choice $x-v=+(y-v)$ would require $x-v=0$, i.e.\ $x=y$, which is false for an elephant and a mosquito. For instance, with $x=4$ and $y=2$ we get $v=3$ and $(4-3)^2=(2-3)^2=1$, but $4-3=1\ne-1=2-3$. $\blacksquare$
