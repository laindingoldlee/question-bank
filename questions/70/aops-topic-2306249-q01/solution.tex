Count the occupied slots. Each box other than the outermost one lies in exactly one slot, and each occupied slot contains exactly one box; the outermost box lies in no slot. So exactly $m-1$ slots are occupied, whatever the arrangement.

There are $mn$ slots in total, so the number of vacant slots is always
\[mn-(m-1)=\boxed{m(n-1)+1}.\]
This proves (a) and answers (b). (For example, $3$ boxes with $2$ slots each always leave $4$ vacant slots: either one box holds the other two, or the boxes are nested in a chain.)
