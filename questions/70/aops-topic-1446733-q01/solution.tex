In one game, whatever the first player chooses, the second player matches it with probability $\dfrac{1}{3}$; so a single game is a tie with probability $\dfrac{3}{9}=\dfrac{1}{3}$. The games are independent, so the probability of $50$ ties in a row is
\[
\boxed{\left(\dfrac{1}{3}\right)^{50}=\dfrac{1}{3^{50}}}\approx 1.4\times10^{-24}.
\]
