$n$ students take a $10$-question test. Their performance is called \emph{laughable} if there is a pair of questions and a set of $57$ students such that either all $57$ of them answered both questions correctly, or all $57$ of them answered both questions incorrectly. Find the smallest $n$ for which the performance is necessarily laughable.
