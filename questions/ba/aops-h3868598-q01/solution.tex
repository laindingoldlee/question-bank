The domain is $x<1$. Set $t=1-x>0$. The equation becomes $\log_2t=t$, equivalently $\dfrac{\log t}{t}=\log2$.

The function $g(t)=\dfrac{\log t}{t}$ has derivative $\dfrac{(1-\log t)}{t^2}$, so its global maximum is $g(e)=\dfrac{1}{e}$. But $\log2>\dfrac{1}{2}>\dfrac{1}{e}$: the first inequality follows from $\int_1^2\dfrac{du}{u}>\dfrac{1}{2}$, and the second from $e>2$. Hence $\dfrac{\log t}{t}$ never reaches $\log2$. There are $\boxed0$ real solutions.
