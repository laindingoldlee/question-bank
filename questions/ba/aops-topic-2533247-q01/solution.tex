There are $3^5=243$ equally likely choices. Count those in which some question is not chosen, by inclusion--exclusion. For a given question, there are $2^5=32$ choices avoiding it; for a given pair of questions, $1$ choice avoids both; no choice avoids all three. So
\[3\cdot32-3\cdot1+0=93\]
choices leave some question unsolved, and $243-93=150$ choices cover all three questions. The probability is
\[\dfrac{150}{243}=\boxed{\dfrac{50}{81}}.\]
