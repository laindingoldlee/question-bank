Suppose not. Then the set
\[
S=\{\,n\ge2:\ n\text{ has no prime divisor}\,\}
\]
is a nonempty set of positive integers, so by the well-ordering principle it has a least element $m$.

The number $m$ is not prime, since otherwise $m$ itself would be a prime divisor of $m$. As $m\ge2$ is not prime, it is composite: $m=ab$ with $2\le a<m$. Since $a<m$ and $m$ is the least element of $S$, we have $a\notin S$, so $a$ has a prime divisor $p$. But $p\mid a$ and $a\mid m$, so $p\mid m$, contradicting $m\in S$.

Therefore $S$ is empty: every integer $n\ge2$ has a prime divisor. $\blacksquare$

(This ``minimal counterexample'' pattern is the typical use of well-ordering; it is equivalent to proof by strong induction. The \emph{well-ordering theorem} of set theory is a different, much more general statement: every set can be given some ordering in which every nonempty subset has a least element.)
