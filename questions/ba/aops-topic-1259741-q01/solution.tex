Write $d\cdot N=d\left(10^n-1\right)=(d-1)\cdot10^n+\left(10^n-d\right)$. Since $2\le d\le9$, the number $10^n-d$ has $n$ digits: $n-1$ nines followed by the digit $10-d$ (for example $10^4-7=9993$). So $d\cdot N$ is the digit $d-1$ followed by these $n$ digits, and its digit sum is
\[(d-1)+9(n-1)+(10-d)=9n.\qquad\blacksquare\]
(For example $7\cdot9999=69993$, with digit sum $36$.)
