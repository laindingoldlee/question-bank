Given that $2^{2004}$ is a $604$-digit number whose first digit is $1$, how many elements of the set $S=\{2^0,2^1,2^2,\ldots,2^{2003}\}$ have a first digit of $4$?

$\textbf{(A)}\ 194\qquad\textbf{(B)}\ 195\qquad\textbf{(C)}\ 196\qquad\textbf{(D)}\ 197\qquad\textbf{(E)}\ 198$

A student notices that $2^2$, $2^{12}$, $2^{22}$, \ldots\ begin with $4$ and claims that the answer is the $201$ numbers $2^{10k+2}$ with $0\le k\le200$. Explain what is wrong with this argument.
