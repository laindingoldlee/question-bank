A student reads that the cube root of a negative integer is irrational, but notes that $\sqrt[3]{-1}=-1$ is rational. Settle the question by proving: for an integer $n$, the real number $\sqrt[3]{n}$ is rational if and only if $n$ is a perfect cube (the cube of an integer, possibly negative).
