If $n=m^3$ for an integer $m$, then $\sqrt[3]{n}=m$ is rational. In particular $\sqrt[3]{-1}=-1$ and $\sqrt[3]{-8}=-2$ are rational, so the statement the student read is false as stated.

Conversely, suppose $\sqrt[3]{n}=\dfrac{p}{q}$ with integers $p$, $q$, $q>0$ and $\gcd(p,q)=1$. Then $nq^3=p^3$. If $q>1$, let $r$ be a prime factor of $q$. Then $r\mid p^3$, so $r\mid p$, contradicting $\gcd(p,q)=1$. Hence $q=1$ and $n=p^3$ is a perfect cube. $\blacksquare$

So the cube root of a negative integer $n$ is rational exactly when $-n$ is a perfect cube; for example $\sqrt[3]{-2}$ is irrational.
