Both parabolas have the same shape ($y=3u^2-1$ with $u=x-1$ or $u=x+1$). The first has vertex $(1,-1)$ and the second has vertex $(-1,-1)$. More precisely, the point $(x_0,y_0)$ lies on the first graph exactly when $(x_0-2,y_0)$ lies on the second, because $3\bigl((x_0-2)+1\bigr)^2-1=3(x_0-1)^2-1$.

\begin{asy}
usepackage("amsmath");
size(5.5cm);
defaultpen(fontsize(10pt));
import graph;
real f(real x){return 3(x-1)^2-1;} real g(real x){return 3(x+1)^2-1;}
draw((-3.2,0)--(3.2,0),gray,Arrow(TeXHead));draw((0,-1.5)--(0,5.5),gray,Arrow(TeXHead));
label("$x$",(3.2,0),E,gray);label("$y$",(0,5.5),N,gray);
draw(graph(f,-0.35,2.35),blue+linewidth(0.9));
draw(graph(g,-2.35,0.35),red+linewidth(0.9));
dot((1,-1),blue);dot((-1,-1),red);
label("$(1,-1)$",(1,-1),SE,blue);label("$(-1,-1)$",(-1,-1),SW,red);
draw((0.9,-1.95)--(-0.9,-1.95),Arrow(TeXHead));label("$2$",(0,-1.95),S);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

So the graph was translated $\boxed{2\text{ units to the left}}$ (and not vertically).
