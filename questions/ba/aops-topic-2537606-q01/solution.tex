One possible set of expressions (each can be checked directly):
\[3\times3-3=6,\qquad\sqrt4+\sqrt4+\sqrt4=6,\qquad5+5\div5=6,\qquad6+6-6=6,\]
\[7-7\div7=6,\qquad8-\sqrt{\sqrt{8+8}}=8-2=6,\qquad\sqrt9\times\sqrt9-\sqrt9=9-3=6.\]
This proves the claim. (Many other expressions work, e.g. $6\times6\div6$ or $(3\times3)-3$; for $8$ the cube root would also allow $\sqrt[3]8+\sqrt[3]8+\sqrt[3]8$.)
