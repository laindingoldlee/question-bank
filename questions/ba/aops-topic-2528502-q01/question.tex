A function $f:\mathbb R\to\mathbb R$ is \emph{even} if $f(-x)=f(x)$ for all $x$, and \emph{odd} if $f(-x)=-f(x)$ for all $x$. Is the function $f(x)=0$ even or odd? Prove that it is the only function $\mathbb R\to\mathbb R$ that is both even and odd.
