For $f(x)=0$: $f(-x)=0=f(x)$ and $f(-x)=0=-0=-f(x)$, so it is \textbf{both} even and odd.

Conversely, if $f$ is both even and odd, then for every $x$,
\[f(x)=f(-x)=-f(x),\]
so $2f(x)=0$ and $f(x)=0$. So the zero function is the only function that is both even and odd. $\blacksquare$
