After the first step, each further step continues in the same direction with probability $\dfrac14$, independently. So the run length $L$ satisfies $P(L=k)=\left(\dfrac14\right)^{k-1}\cdot\dfrac34$, a geometric distribution with success probability $\dfrac34$, and
\[E[L]=\dfrac{1}{\dfrac34}=\boxed{\dfrac43}.\]
