The estimate is $26\cdot60+15=1575$ seconds. Let the actual time be $t$ seconds, with $t<1575$. Percent error relative to the actual value means
\[
\dfrac{1575-t}{t}=0.05\quad\Longrightarrow\quad 1575=1.05\,t\quad\Longrightarrow\quad t=1500 .
\]
So the pasta took $1500$ seconds, that is, $\boxed{25\text{ minutes}}$.

(If the error were measured relative to the estimate instead, the actual time would be $0.95\cdot1575=1496.25$ seconds; the usual definition of percent error divides by the actual value, as above.)
