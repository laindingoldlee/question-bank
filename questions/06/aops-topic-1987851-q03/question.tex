Jhon glues equal unit cubes to build the ``skeleton'' of an $n\times n\times n$ cube ($n\ge2$): the skeleton consists of all the unit cubes along the $12$ edges of the big cube. Filling in all the missing unit cubes would complete the solid $n\times n\times n$ cube. For one value of $n$, the number of cubes in the skeleton equals the number of cubes needed to fill in the empty spaces. How many cubes does this skeleton use?
