Set $A=(0,0)$, $B=(b,0)$, $C=(b,12)$, and $D=(d,12)$ with $0<d<b$. Since AX is vertical and AXC is equilateral, C is halfway up AX, giving $X=(0,24)$ and $b=12\sqrt 3$. The slope of CX is $-\dfrac{1}{\sqrt 3}$, so AD has slope $\sqrt 3$ and $d=\dfrac{12}{\sqrt 3}=4\sqrt 3$. Thus $CD=b-d=8\sqrt 3$. Area is $\dfrac{1}{2}(12\sqrt 3+8\sqrt 3)12=120\sqrt 3$, and $m+n=\boxed{123}$.
\begin{asy}
import geometry; size(220);
pair A=(0,0),B=(12*sqrt(3),0),C=(12*sqrt(3),12),D=(4*sqrt(3),12),X=(0,24);draw(A--B--C--D--cycle);draw(A--X--C--A,dashed);label("$A$",A,SW);label("$B$",B,SE);label("$C$",C,E);label("$D$",D,N);label("$X$",X,N);
\end{asy}
