We need $k\ne0$ (for $k=0$ the equation reads $12=0$). Then
\[
x=\dfrac{3k-12}{k}=3-\dfrac{12}{k}.
\]
For $x$ to be an integer, $k$ must divide $12$, and we need $3-\dfrac{12}{k}\ge1$, that is, $\dfrac{12}{k}\le2$.
\begin{itemize}
\item Positive divisors: $\dfrac{12}{k}\le2$ means $k\ge6$, so $k=6$ ($x=1$) or $k=12$ ($x=2$).
\item Negative divisors $k=-1,-2,-3,-4,-6,-12$: then $\dfrac{12}{k}<0$ and $x=3+\dfrac{12}{|k|}$ is a positive integer ($15,9,7,6,5,4$).
\end{itemize}
So there are $2+6=\boxed{8}$ values of $k$.
