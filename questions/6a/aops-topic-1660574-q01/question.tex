How many six-digit numbers $d_1d_2d_3d_4d_5d_6$ can be formed using only the digits $1,2,3,4$, each of the four digits appearing at least once, such that $d_2\ne d_1$, $d_3\ne d_2$, $d_4\ne d_3$, $d_5\ne d_4$ and $d_6\ne d_4$? (Note that the last rule compares $d_6$ with $d_4$, not with $d_5$.)
