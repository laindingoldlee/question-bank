\textbf{Ignoring the ``all four digits'' condition.} Choose $d_1$ ($4$ ways), then $d_2,d_3,d_4$ ($3$ ways each, each different from the previous digit), then $d_5\ne d_4$ and $d_6\ne d_4$ ($3$ ways each). This gives $T=4\cdot3^5=972$ strings.

\textbf{Inclusion-exclusion over missing digits.} For a fixed set of $k$ allowed digits, the same count gives $f(k)=k(k-1)^5$ strings ($f(3)=96$, $f(2)=2$, $f(1)=0$). The number of valid strings using all four digits is
\[
f(4)-\dbinom41f(3)+\dbinom42f(2)-\dbinom43f(1)=972-4\cdot96+6\cdot2-0=\boxed{600}.
\]
(Checked by listing all $4^6$ strings.)
