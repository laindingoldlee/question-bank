If both primes were odd, $n+p$ would be even and greater than two, impossible. If $n=2$, then $n-p\le0$ for prime $p\ge2$, also impossible. Thus $p=2$ and $n$ is odd. Among $n-2,n,n+2$, one is divisible by three; all three can be prime only if one equals three. The only working choice is $n=5$, producing $3,5,7$. Hence the number of possible primes is $\boxed1$.
