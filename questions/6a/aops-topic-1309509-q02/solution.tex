$x=0$ is not a solution (it gives $1$). For $x\ne0$ divide by $x^{10}$ and put $t=\dfrac{x^2-9x-1}{x}$:
\[
t^{10}-10t+9=0 .
\]
The function $f(t)=t^{10}-10t+9$ has $f'(t)=10(t^9-1)$, so it decreases for $t<1$ and increases for $t>1$, with minimum $f(1)=0$. Hence $t=1$ is its only real zero. So $x^2-9x-1=x$, i.e. $x^2-10x-1=0$, giving $\boxed{x=5\pm\sqrt{26}}$.
