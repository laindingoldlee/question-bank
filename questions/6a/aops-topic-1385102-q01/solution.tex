The left side equals $1111A+111B+11C+D$. Since $1111A\le2002$, $A=1$, and then $111B+11C+D=891$. As $11C+D\le99+9=108$, we need $111B\ge783$, so $B\ge8$; and $B\le8$ because $999>891$. So $B=8$ and $11C+D=3$, which forces $C=0$, $D=3$. The only solution is
\[
\boxed{A=1,\ B=8,\ C=0,\ D=3},\qquad 1+18+180+1803=2002 .
\]
