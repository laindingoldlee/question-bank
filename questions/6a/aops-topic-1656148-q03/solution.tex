A square with side $s$ has diagonal $d=s\sqrt2$ (here $d=20\sqrt{18}$), so its area is $s^2=\dfrac{d^2}{2}$.

\begin{asy}
usepackage("amsmath");
size(3.5cm);
defaultpen(fontsize(10pt));
pair A=(0,0),B=(4,0),C=(4,4),D=(0,4);
draw(A--B--C--D--cycle,linewidth(0.9));draw(A--C,blue);
label("$d$",(2,2),NW,blue);label("$s$",(2,0),S);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

Here $d^2=400\cdot18=7200$, so the area is $\dfrac{7200}{2}=\boxed{\textbf{(c)}\ 3600}$. (Simplifying first: $20\sqrt{18}=60\sqrt2$, so $s=60$.)
