A total $n$ is possible when $n=5a+7b$ with $a,b\ge0$. The multiples of $7$ in $0,7,14,21,28$ have remainders $0,2,4,1,3$ modulo $5$, so the smallest reachable number in each remainder class mod $5$ is one of $0,7,14,21,28$, and from there every larger number in that class is reachable by adding $5$s. The largest number that is not reachable is therefore $28-5=\boxed{23}$ (in the class of $28$). Indeed $24=14+10$, $25=5\cdot5$, $26=21+5$, $27=7+20$, $28=4\cdot7$, and then every number above $28$ is one of these plus a multiple of $5$. (This agrees with $5\cdot7-5-7=23$.)
