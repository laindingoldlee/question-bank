\textbf{Parity.} If $a$ and $b$ are both odd, $c^3=a^2+b^2$ is even, so $c=2$ and $b=3a+2$. Then $a^2+(3a+2)^2=8$, i.e.\ $10a^2+12a-4=0$, which has no prime solution (for $a\ge2$ the left side exceeds $8$). If $b=2$, then $c=2-3a<0$, impossible. Hence $a=2$.

\textbf{Then} $c=b-6$ and $4+b^2=(b-6)^3$, i.e.
\[
b^3-19b^2+108b-220=0 .
\]
Trying $b=11$: $1331-2299+1188-220=0$. Dividing, $b^3-19b^2+108b-220=(b-11)\left(b^2-8b+20\right)$, and $b^2-8b+20=(b-4)^2+4>0$, so $b=11$ is the only real root. Then $c=5$, and indeed $2^2+11^2=125=5^3$ with $2,11,5$ prime.

So $abc=2\cdot11\cdot5=\boxed{110}$.
