Expand both sides:
\[-15x-10-x+3=-16x-7,\qquad -16x-20+13=-16x-7.\]
Both sides equal $-16x-7$, so the equation holds for every $x$: $\boxed{\text{every real number }x\text{ is a solution}}$. (Moving $-16x$ to the left gives $-7=-7$, which is always true.)
