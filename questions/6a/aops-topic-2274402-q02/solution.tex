An amount uses $a$ three-cent coins and $b$ five-cent coins with $0\le a\le4$, $0\le b\le3$, not both zero; the amount is $3a+5b$ cents. There are $5\cdot4-1=19$ such pairs $(a,b)$.

Different pairs give different amounts: if $3a+5b=3a'+5b'$, then $3(a-a')=5(b'-b)$, so $5$ divides $a-a'$. But $|a-a'|\le4$, so $a=a'$ and then $b=b'$.

Hence there are $\boxed{19}$ different amounts.
