Sort them as $a\le b\le5\le d\le e$. The sum is $40$. Since $5$ is a mode, it occurs at least twice. If $b=5$, then $b+5+d\ge15$; otherwise the second occurrence is $d=5$, and uniqueness of the mode excludes $a=b<5$, so $a+b\ge3$. In the second case, $e-a=30-2a-b\le26$, attained by $1,2,5,5,27$, whose sum is40 and range26. In the first case $e-a\le25-2a\le23$. Therefore the maximum is $\boxed{26}$, attained by $(1,2,5,5,27)$.
