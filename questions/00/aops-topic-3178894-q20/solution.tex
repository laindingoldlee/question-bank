Weigh 16 balls against the other 16. If unequal, stop. If balanced, each half contains eight heavy and eight light balls: equal cardinalities make total mass depend only on the heavy count. Retain one half and weigh its two groups of 8. If balanced, retain a half containing four of each type. Continue with 4 against 4 and then 2 against 2, stopping whenever unequal. If all four weighings balance, the retained two-ball set contains one heavy and one light. Weighing these individually must be unequal. Therefore $\boxed{\text{at most five weighings suffice}}$.
