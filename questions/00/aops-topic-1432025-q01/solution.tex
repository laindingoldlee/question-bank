Both brackets contain the same number $X=\left(\dfrac{2}{5}\right)^{12}\left(\dfrac{3}{16}\right)^{-8}$, which is not zero. The expression is $X\cdot X^{-1}=\dfrac{X}{X}=\boxed{1}$. No computation of $X$ is needed.
