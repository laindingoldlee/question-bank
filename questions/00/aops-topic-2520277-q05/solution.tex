The full score is $5\cdot3+3\cdot4+2\cdot5=37$, so passing means losing at most $37-22=15$ points. Count the sets of correctly answered questions that pass, according to the number $k$ of correct answers.
\begin{itemize}
\item $k\le4$: the score is at most $5+5+4+4=18<22$, so none pass.
\item $k=5$: five questions are wrong, and the five smallest values add up to $3\cdot5=15$. So only one set passes: all five $3$-point questions wrong and the other five right.
\item $k=6$: four questions are wrong. If $a$, $b$, $c$ of them are worth $3$, $4$, $5$ points ($a+b+c=4$), the loss is $3a+4b+5c=12+b+2c$, which is at most $15$ exactly when $b+2c\le3$. The possibilities are
\[(b,c)=(0,0),(1,0),(2,0),(3,0),(0,1),(1,1),\]
giving
\[\dbinom54+\dbinom53\dbinom31+\dbinom52\dbinom32+\dbinom51\dbinom33+\dbinom53\dbinom21+\dbinom52\dbinom31\dbinom21=5+30+30+5+20+60=150\]
passing sets.
\item $k\ge7$: at most three questions are wrong, losing at most $5+5+4=14$ points, so every such set passes: $\dbinom{10}7+\dbinom{10}8+\dbinom{10}9+\dbinom{10}{10}=120+45+10+1=176$ sets.
\end{itemize}
Each question is right with probability $\dfrac1n$ and wrong with probability $\dfrac{n-1}{n}$, independently, so a particular set of $k$ correct answers has probability $\dfrac{(n-1)^{10-k}}{n^{10}}$. Hence the probability of passing is
\[P_n=\dfrac{(n-1)^5+150(n-1)^4+120(n-1)^3+45(n-1)^2+10(n-1)+1}{n^{10}}.\]
\textbf{$n=2$:} $P_2=\dfrac{1+150+120+45+10+1}{2^{10}}=\dfrac{327}{1024}$, which is at least $\dfrac15$ because $5\cdot327=1635>1024$.

\textbf{$n=3$:} $P_3=\dfrac{32+2400+960+180+20+1}{3^{10}}=\dfrac{3593}{59049}$, which is less than $\dfrac15$ because $5\cdot3593=17965<59049$.

\textbf{$n\ge4$:} more choices can only lower the chance. To see this, let each question have a random number $U_i$, uniform on $[0,1]$, and let the answer to question $i$ be right with $n$ choices exactly when $U_i<\dfrac1n$; this gives each question the right probability, independently. For $n\ge4$ we have $\dfrac1n<\dfrac13$, so every question answered correctly with $n$ choices is also answered correctly with $3$ choices, and the score with $3$ choices is at least as large. So whenever the student passes with $n$ choices, the student also passes with $3$ choices, and $P_n\le P_3<\dfrac15$.

Therefore the greatest number of answer choices is $\boxed{2}$.
