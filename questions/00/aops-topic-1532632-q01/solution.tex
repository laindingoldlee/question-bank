$\log_b N$ is the exponent $x$ with $b^x=N$.
\begin{enumerate}
\item[(a)] $2^5=32$, so $\log_232=\boxed{5}$.
\item[(b)] $9^2=81$, so $\log_981=\boxed{2}$.
\item[(c)] $3^5=243$, so $\log_3243=\boxed{5}$.
\end{enumerate}
