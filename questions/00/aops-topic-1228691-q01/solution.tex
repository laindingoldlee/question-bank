By inclusion--exclusion, the number of assignments in which no dog gets its own bone (derangements) is
\[D_{20}=\sum_{k=0}^{20}(-1)^k\dbinom{20}{k}(20-k)!=20!\sum_{k=0}^{20}\dfrac{(-1)^k}{k!}.\]
So the probability is
\[\boxed{\sum_{k=0}^{20}\dfrac{(-1)^k}{k!}}=1-1+\dfrac{1}{2!}-\dfrac{1}{3!}+\cdots+\dfrac{1}{20!}\approx0.3679,\]
which agrees with $\dfrac{1}{e}$ to about $18$ decimal places.
