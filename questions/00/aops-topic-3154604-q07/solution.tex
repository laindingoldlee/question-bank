The inverse powers equal $ z^6,z^5,z^4 $, so the sum is $ z+z^2+\cdots+z^6 $. Since $(z-1)(1+z+\cdots+z^6)=z^7-1=0 $ and $ z\ne1 $, the latter seven-term sum is zero. The requested value is $\boxed{-1}$.
