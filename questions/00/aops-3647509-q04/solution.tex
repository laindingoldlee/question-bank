There are $4\cdot9=36$ single-digit changes, allowing an initial zero. Of the resulting numbers, the only squares are $0025=5^2$, $3025=55^2$, and $9025=95^2$. This can be checked by listing squares from $0^2$ through $99^2$ and retaining strings at Hamming distance one from 2025. Hence $36-3=\boxed{33}$ changes are not squares. If four-digit numbers are required, exclude 0025 from both totals; the answer is unchanged.
