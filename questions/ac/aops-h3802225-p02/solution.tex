Build the number from right to left. If a suffix has $o$ odd and $e$ even digits, an even digit can be prepended only as $o$ when $o$ is even; an odd digit can be prepended only as $e$ when $e$ is odd. Each chosen value must be at most nine. Start with the empty suffix, for which $o=e=0$, and apply these two rules eight times, discarding final strings with initial zero. This exhaustive recurrence gives
\[\boxed{\begin{gathered}11111110,22222110,22233000,25500000,33322110,\\33333000,34411110,43322110,43333000,44411110,\\52222110,52233000,55500000,61111110,70000000.\end{gathered}}\]
The recurrence is both necessary and sufficient at every step: once the suffix is fixed, its parity counts determine the only possible value of a prepended digit of either parity. Thus every listed number works and no other one can occur.
