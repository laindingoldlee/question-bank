Call a cell's colour $X$-coloured neighbours its \emph{matches}; every cell has exactly two matches.

\emph{Corners.} A corner has only two neighbours, so both match it. For the top-left corner $(1,1)$ with colour $X$, cell $(1,2)$ already matches $(1,1)$ and needs exactly one more match among $(1,3)$ and $(2,2)$; similarly for $(2,1)$. So either
\begin{itemize}
\item[(A)] $(2,2)$ is $X$: the corner $2\times2$ block is all $X$, and its cells already have two matches each, so no cell next to the block is $X$; or
\item[(B)] $(2,2)$ is not $X$, and $(1,3)$ and $(3,1)$ are $X$.
\end{itemize}
\emph{All corners have the same type.} If the top-left corner is of type B, then $(1,3)$ is $X$, so the top-right corner $(1,4)$, which matches its neighbour $(1,3)$, is also $X$. Now $(1,3)$ has its two matches $(1,2)$ and $(1,4)$, so $(2,3)$ is not $X$. If the top-right corner were of type A, $(2,3)$ would be $X$; so it is of type B too. By symmetry, all four corners have the same type.

\emph{Type B everywhere.} The $12$ border cells all have colour $X$ and the four inner cells do not. An inner cell, say $(2,2)$ with colour $Y\ne X$, has two $X$ neighbours, so its other two neighbours $(2,3)$ and $(3,2)$ are $Y$; hence the inner $2\times2$ block is all $Y$, and every cell has exactly two matches. This gives $4\cdot3=12$ colourings.

\emph{Type A everywhere.} The grid splits into four monochromatic $2\times2$ blocks, and blocks sharing a side must differ (otherwise cells would have three matches), while diagonal blocks are free. These are proper colourings of a $4$-cycle with $4$ colours: $3^4+3=84$.

The total is $84+12=\boxed{96}$.
