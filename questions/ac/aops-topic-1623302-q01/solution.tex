We need $\dfrac{m(m+1)}{2}+n=2300$ with $1\le n<m$, so
\[
\dfrac{m(m+1)}{2}<2300<\dfrac{m(m+1)}{2}+m .
\]
Now $\dfrac{67\cdot68}{2}=2278$, so $m=67$ gives $n=22<67$, which works. For $m\le66$, $\dfrac{m(m+1)}{2}+m\le2211+66<2300$; for $m\ge68$, $\dfrac{m(m+1)}{2}\ge2346>2300$. So $m=67$, $n=22$, and $m+n=\boxed{89}$.
