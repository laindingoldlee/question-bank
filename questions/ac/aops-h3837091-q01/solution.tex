Take $a=\arctan(\dfrac{\pi}{2})$. Then $\tan a=\dfrac{\pi}{2}$, so the expression equals $\cos 1$, which is strictly less than $1$ because $0<1<\dfrac{\pi}{2}$. Thus the proposed identity is $\boxed{\text{false}}$ already for one application. Moreover, $\tan a$ is undefined at $a=\dfrac{\pi}{2}+k\pi$, so the formula is not defined for all real inputs.
