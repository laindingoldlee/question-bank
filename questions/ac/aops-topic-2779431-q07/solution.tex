For any point in a rectangle, coordinate expansion gives $AP^2+CP^2=BP^2+DP^2$: each horizontal and vertical squared displacement appears once on either side. Hence $DP^2=25+49-36=38$, so $\boxed{\sqrt{38}}$.

\end{asy}
