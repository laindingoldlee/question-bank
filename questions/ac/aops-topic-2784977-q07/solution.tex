If $A$ is the apex angle, then $B=65^\circ$. If $A$ is a base angle, then $B$ can be the other 50-degree base angle or the 80-degree apex. Thus the possible values are 50,65,80, and the requested sum is $\boxed{130^\circ}$.
\begin{asy}
usepackage("amsmath");
size(7cm);
pair A=(0,0),B=(2,0),C=(1,tan(50*pi/180));draw(A--B--C--cycle);label("$50^\circ$",A,S);label("$50^\circ$",B,S);label("$80^\circ$",C,N);pair D=(4,0),Ee=(6,0),F=(5,tan(65*pi/180));draw(D--Ee--F--cycle);label("$65^\circ$",D,S);label("$65^\circ$",Ee,S);label("$50^\circ$",F,N);
\end{asy}
