Let $x$ be the value obtained just before the operation with $2$, so the expression is $(x*2)*1$. Every value $a*b$ is nonnegative, and the starting value $2012$ is positive, so $x\ge0$. (All radicands are positive: for $a\ge0$, $b\ge1$, $a^2+a(3b-2)+(b^2-2b+4)>0$.)

Now
\[x*2=\dfrac{\sqrt{x^2+6x+4-2x-4+4}}{2x+4}=\dfrac{\sqrt{(x+2)^2}}{2(x+2)}=\dfrac{x+2}{2(x+2)}=\dfrac{1}{2},\]
whatever $x\ge0$ is. Then
\[\dfrac{1}{2}*1=\dfrac{\sqrt{\dfrac{1}{4}+\dfrac{3}{2}+1-1-2+4}}{\dfrac{1}{2}+4}=\dfrac{\sqrt{\dfrac{15}{4}}}{\dfrac{9}{2}}=\dfrac{\sqrt{15}}{2}\cdot\dfrac{2}{9}=\boxed{\dfrac{\sqrt{15}}{9}}.\]
