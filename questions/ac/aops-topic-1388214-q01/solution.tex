A base-$c$ numeral can use only the digits $0,1,\dots,c-1$, so the digit $9$ forces $c\ge10$ (and $c$ must be an integer). But then
\[
98765_c=9c^4+8c^3+7c^2+6c+5\ \ge\ 9\cdot10^4+8\cdot10^3+7\cdot10^2+6\cdot10+5=98765>12345,
\]
because the left side increases with $c$. Hence \textbf{there is no such base}.

The Vieta approach is not valid. The equation $9c^4+8c^3+7c^2+6c-12340=0$ has four complex roots with sum $-\dfrac{8}{9}$ and product $-\dfrac{12340}{9}$, but none of these roots is an integer greater than $9$ (its only positive root is about $5.84$), so none of them is a base, and their sum and product say nothing about the problem.
