For $n\ge4$, $4\mid n!$, so $2019+n!\equiv2019\equiv3\pmod4$. But squares are $\equiv0$ or $1\pmod4$, so there is no solution with $n\ge4$. Check the rest:
\[
n=0,1:\ 2020,\qquad n=2:\ 2021,\qquad n=3:\ 2025=45^2 .
\]
Since $44^2=1936$ and $45^2=2025$, only $2025$ is a square. The answer is $\boxed{n=3}$.
