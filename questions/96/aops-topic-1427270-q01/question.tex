In a tournament with $n$ players, $n<10$, each player plays once against each other player, scoring $1$ point for a win and $0$ for a loss; there are no draws. In a particular tournament, only one player ended with an odd number of points, and this player was ranked fourth (exactly three players scored more than this player). Is this possible? If so, find the number of players and the number of wins of this player.
