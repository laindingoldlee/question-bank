Write $x=101a+10b$ with $1\le a\le9$, $0\le b\le9$. Then $101x=10201a+1010b$, whose formal digit pattern is $a,b,2a,b,a$. For $a\le4$ no carry occurs, so all $4\cdot10=40$ choices work.
For $a\ge5$, the middle digit carries $1$ into the thousands column. If $b\le8$, the thousands digit becomes $b+1$ while the tens digit stays $b$, so it is not a palindrome. If $b=9$, that carry raises the leading digit, which then differs from the final digit $a$. A six-digit result can occur only for $a=9$ and begins with $1$ but ends with $9$. Hence there are exactly $\boxed{40}$.
