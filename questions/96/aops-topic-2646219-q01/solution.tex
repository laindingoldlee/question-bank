If $z$ is real, then $z^2=|z|^2$ is a nonnegative real number, so $\sqrt{z^2}=|z|$.

Conversely, suppose $\sqrt{z^2}=|z|$. Squaring, $z^2=|z|^2$, a nonnegative real number. Write $z=x+iy$; then $z^2=x^2-y^2+2ixy$, so $xy=0$ and $x^2-y^2\ge0$. If $x=0$ then $-y^2\ge0$ forces $y=0$; otherwise $y=0$. Either way $z$ is real. $\blacksquare$
