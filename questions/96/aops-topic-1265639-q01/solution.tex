Let $t=2^x>0$, so $4^x=t^2$. The left side is $5(t-2)(t+2)=5t^2-20$, so
\[5t^2-20=3t^2+12\quad\Longrightarrow\quad t^2=16\quad\Longrightarrow\quad t=4\]
(since $t>0$). Thus $2^x=4$ and $x=\boxed{2}$.
