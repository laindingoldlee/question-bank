\textbf{(a)} Every number $3^n+2$ is odd, so $p=2$ divides none of them. The answer is $\boxed{2}$.

\textbf{(b)} Note that $3$ also divides none of them, since $3^n+2\equiv2\pmod3$. For the next primes:
\begin{itemize}
\item $5\mid3^1+2=5$; $\quad11\mid3^2+2=11$; $\quad7\mid3^5+2=245=5\cdot7^2$.
\item Modulo $13$: $3^3=27\equiv1$, so the powers of $3$ modulo $13$ repeat $3,9,1,3,9,1,\dots$, and $3^n+2$ is $5$, $11$ or $3$ modulo $13$, never $0$.
\end{itemize}
So the answer is $\boxed{13}$.
