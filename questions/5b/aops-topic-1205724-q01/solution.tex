$\{a,b,c\}=\{1,2,3\}$. If $a=1$ the value is $1$. If $b=1$ it is $a^1=a\le3$. Otherwise $c=1$ and $(a,b)=(2,3)$ or $(3,2)$, giving $2^{3}=8$ and $3^{2}=9$. The greatest value is $\boxed{9}$. (The poster's $2^{81}$ used $c=4$, which is not less than $4$.)
