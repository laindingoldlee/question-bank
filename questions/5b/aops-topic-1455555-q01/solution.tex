The digits $6$ and $9$ both use the $6$ stickers, so these run out first. Count the $6$s and $9$s in the numbers $1$ to $66$:
\begin{itemize}
\item units digit $6$: $6,16,26,36,46,56,66$ ($7$ stickers);
\item tens digit $6$: $60,61,\dots,66$ ($7$ stickers);
\item digit $9$: $9,19,29,39,49,59$ ($6$ stickers).
\end{itemize}
That is $7+7+6=20$ stickers, all of the $6$s. No other digit runs out before this: the most used other digit is $1$, which appears $7+10=17$ times in $1$ to $66$. So numbers $1$ to $66$ can be made, but $67$ needs a $6$. The first number he cannot make is $\boxed{67}$.
