An analog dial shows the correct time again exactly when the clock has fallen behind by a whole number of $12$-hour cycles. The first time is when it has lost $12$ hours $=720$ minutes. It loses $2$ minutes per $3$ hours, so this takes
\[
\dfrac{720}{2}\cdot3=1080\text{ hours}=\boxed{45\text{ days}}.
\]
(If the clock had a $24$-hour display it would need to lose $1440$ minutes, which takes $90$ days.)
