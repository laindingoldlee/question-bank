This is misere Nim. Except when every nonempty pile has size one, a position is losing precisely when the binary xor of the pile sizes is zero; when all are one, it is losing precisely when their number is odd. In the given positive range, xor-zero triples must use only sizes 1 through 7: using eight would require another eight and a zero, or a value above eight. Choosing distinct $a,b\in\{1,\ldots,7\}$ forces $c=a\mathbin{\oplus}b\in\{1,\ldots,7\}$, giving $7\cdot6=42$ losing triples. Add $(1,1,1)$ for 43. Thus $8^3-43=\boxed{469}$ are winning. The xor strategy keeps zero xor until the endgame, then leaves an odd number of singletons to the opponent.
