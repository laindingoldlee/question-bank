Split the process into stages: stage $k$ (for $k=1,\dots,5$) lasts from the moment $k-1$ different shirts have been seen until a new one is drawn. During stage $k$, each draw is new with probability $p_k=\dfrac{5-(k-1)}{5}$, independently, so the stage length is geometric with expected value $\dfrac{1}{p_k}=\dfrac{5}{6-k}$. By linearity of expectation, the expected total is
\[\dfrac55+\dfrac54+\dfrac53+\dfrac52+\dfrac51=5\left(1+\dfrac12+\dfrac13+\dfrac14+\dfrac15\right)=5\cdot\dfrac{137}{60}=\boxed{\dfrac{137}{12}}\approx11.42.\]
