The divisor is $1151+1264+1323=3738=2\cdot3\cdot7\cdot89$. Reduce modulo each prime factor.
\begin{itemize}
\item Modulo $2$: the numbers are $\equiv1,0,1$, so $N\equiv1+0+1\equiv0$.
\item Modulo $3$: they are $\equiv-1,1,0$, so $N\equiv-1+1+0=0$.
\item Modulo $7$: $1151=7\cdot164+3$, $1264=7\cdot180+4$, $1323=7\cdot189$, so $N\equiv3^5+(-3)^5+0=0$.
\item Modulo $89$: $1151=13\cdot89-6$, $1264=14\cdot89+18$, $1323=15\cdot89-12$, so
\[
N\equiv(-6)^5+18^5+(-12)^5=6^5\left(-1+3^5-2^5\right)=7776\cdot210 .
\]
Since $7776=87\cdot89+33$ and $210=2\cdot89+32$, we get $N\equiv33\cdot32=1056=11\cdot89+77\equiv77$.
\end{itemize}
So $N\equiv0\pmod{42}$ and $N\equiv77\pmod{89}$. Write $N\equiv42k$; then $42k\equiv77\pmod{89}$. Dividing by $7$ (allowed, as $\gcd(7,89)=1$) gives $6k\equiv11$, and since $6\cdot15=90\equiv1$, $k\equiv165\equiv76\pmod{89}$. By the Chinese remainder theorem the remainder is
\[
42\cdot76=\boxed{3192}.
\]
