The first $k$ blocks contain $1+2+\cdots+k=\dfrac{k(k+1)}{2}$ terms. Since $\dfrac{12\cdot13}{2}=78<88\le91=\dfrac{13\cdot14}{2}$, the $88$th term lies in block $13$. The block digits cycle with period $5$, and $13=2\cdot5+3$, so block $13$ consists of $3$s. The $88$th term is $\boxed{3}$.
