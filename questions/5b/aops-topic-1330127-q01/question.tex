Let $f(x)=x^n$ and start from a number $x_0>0$. Form $x_1=f(x_0)$, $x_2=f(x_1)$, and so on. A student conjectures that whenever $n<1$, the sequence $x_k$ always tends to $1$. Prove that this is true for $-1<n<1$, and show that it is false for $n\le-1$.
