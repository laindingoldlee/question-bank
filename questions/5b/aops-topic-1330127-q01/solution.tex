By induction $x_k=x_0^{\,n^k}$, since $x_{k+1}=\left(x_0^{\,n^k}\right)^n=x_0^{\,n^{k+1}}$.

If $-1<n<1$, then $n^k\to0$, so $x_k=e^{n^k\ln x_0}\to e^0=1$, for every $x_0>0$.

If $n=-1$, then $x_k$ alternates between $x_0$ and $\dfrac{1}{x_0}$; for $x_0=2$ it is $2,\dfrac{1}{2},2,\dfrac{1}{2},\dots$, which does not tend to $1$. If $n<-1$, then $|n^k|\to\infty$ with alternating sign, so for $x_0=2$ the terms $2^{n^k}$ alternately become huge and tiny. So the conjecture holds exactly for $-1<n<1$ (and trivially whenever $x_0=1$).
