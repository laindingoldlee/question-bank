Begin with the set $\{1,2\}$. Repeatedly choose two distinct existing numbers $a>b$; if $\dfrac{a+b}{a-b}$ is a positive integer, adjoin it, retaining all old numbers. Which positive integers can eventually appear? Answer the same question starting with $\{1,3\}$.
