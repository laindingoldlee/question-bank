From $2,1$ we obtain $3$, and from $3,2$ we obtain $5$; from $5,3$ we obtain $4$. Thus $1,2,3,4$ are available. Strong induction generates every integer $n\ge5$. If $n=2k+1$ is odd, the already available $k+1,k$ produce $n$. If $n=2k$ is even, first produce $2k+1$ from $k+1,k$; the number $2k-1$ is already available, and these two odd numbers produce $\dfrac{(2k+1)+(2k-1)}{2}=2k$. No non-positive or noninteger numbers are ever adjoined by the rule, so the obtainable set is exactly all positive integers. Starting with $1,3$, one obtains $2$ immediately from $\dfrac{3+1}{3-1}=2$, reducing to the first case.
