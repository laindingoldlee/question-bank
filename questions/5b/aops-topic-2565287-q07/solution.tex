With $x$ blue marbles there are $2x$ green and $x+5$ red, so $x+2x+x+5=45$, giving $x=10$: $15$ red, $10$ blue and $20$ green.

\textbf{(a)} The ratio $1:2:1$ requires as many red as green, and twice as many blue as red. Adding only red leaves blue $=10$ and green $=20$, but then blue would have to equal twice green ($40$). Adding only blue leaves red $15\ne$ green $20$. Adding only green leaves red $=15$ and blue $=10$, but blue would have to be $30$. So the answer is \textbf{no}.

\textbf{(b)} Finally there must be $m$ red, $2m$ blue and $m$ green marbles with $m\ge15$, $2m\ge10$ and $m\ge20$, so $m\ge20$. The number added is $4m-45\ge35$, with equality for $m=20$: add $5$ red and $30$ blue marbles. The smallest total is $\boxed{35}$.
