The perpendicular line is $y=-\dfrac{x}{3}+\dfrac{25}{3}$. The four vertices in the specified order are $A=(-\dfrac{5}{3},0),B=(0,5),C=(0,\dfrac{25}{3}),D=(25,0)$. Applying the shoelace formula gives $\dfrac{1}{2}|(-\dfrac{25}{3})-(\dfrac{625}{3})|=\boxed{\dfrac{325}{3}}$. The specified polygon is concave, so its vertex order matters.
