The numeral $1729_b$ uses the digit $9$, so the base must satisfy $b\ge10$. Its value is $f(b)=b^3+7b^2+2b+9$, which is increasing for $b>0$. Now
\[
f(10)=1729<2017,\qquad f(11)=1331+847+22+9=2209>2017,
\]
so for integers $b\ge10$ the value $f(b)$ is never $2017$: it is $1729$ for $b=10$ and at least $2209$ for $b\ge11$. Hence $\boxed{\text{there is no such base}}$. $\blacksquare$
