We have $n\le2018$, so $S(n)\le28$ and $S(S(n))\le10$. Hence $1981\le n\le2018$. Write $n=1900+10a+b$ in the first part of this interval, and $n=2000+10a+b$ in the second, where $b$ is a digit.
\[
\begin{array}{c|c|c|c}
\text{form}&\text{condition}&\text{equation}&\text{valid }(a,b)\\ \hline
1900+10a+b&a+b\le9&4a+b=36&(9,0)\\
1900+10a+b&a+b\ge10&4a+b=39&(8,7),(9,3)\\
2000+10a+b&a+b\le7&4a+b=5&(0,5),(1,1)\\
2000+10a+b&a+b\ge8&4a+b=8&(0,8)
\end{array}
\]
For example in the second row, $S(n)=10+a+b$ and $S(S(n))=a+b-8$, producing $1902+12a+3b=2019$. The other rows follow in the same way. The six values are $1987,1990,1993,2005,2008,2011$; each satisfies the equation. Thus the answer is $\boxed6$.
