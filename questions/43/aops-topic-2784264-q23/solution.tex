Put $t=\dfrac{1}{\log_{10}(\dfrac{5}{2})}$. Then $(\dfrac{5}{2})^t=10$, while $(\dfrac{4}{25})^t=10^{-2}$. The value is $10+\dfrac{1}{100}=\dfrac{1001}{100}$, giving $\boxed{1101}$.
