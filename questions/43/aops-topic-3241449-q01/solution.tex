The radicand is $202-x^2$, so only finitely many $x$ occur. Whenever $x$ is a solution, $-x$ is also a solution, with the same positive square root. These pairs cancel, while a possible zero contributes zero. Thus the sum is $\boxed0$. (For example, $x=\pm9,\pm11$ work.)
