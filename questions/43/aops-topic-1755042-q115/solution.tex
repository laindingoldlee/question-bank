There are $9\cdot8\cdot7=504$ such numbers. The map replacing each digit $a$ by $10-a$ is a bijection of this set onto itself (digits stay distinct and nonzero), and it sends $\overline{abc}$ to $1110-\overline{abc}$. So the numbers pair up with sum $1110$ (or are fixed, when equal to $555$, which is not in the set), and the mean is $\dfrac{1110}{2}=\boxed{555}$.
