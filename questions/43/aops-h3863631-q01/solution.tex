All $9!$ permutations of the cards are equally likely. For each permutation, accumulate odd-position cards for player one and even-position cards for player two, stopping at the first divisible-by-three sum after that player\textquotesingle s initial draw. This gives $202176$ permutations on which the first player loses, so the probability is $\dfrac{202176}{362880}=\boxed{\dfrac{39}{70}}$. Equivalently one can recurse on remaining residue counts $(c_0,c_1,c_2)$, initially $(3,3,3)$: each next residue $r$ has probability $\dfrac{c_r}{c_0+c_1+c_2}$, and updates only the active player\textquotesingle s sum. The stopping rule ensures losses after an earlier opponent loss are not counted.
