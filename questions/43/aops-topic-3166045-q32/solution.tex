The number $1999$ is prime (trial division by primes at most $43$ verifies this), so $b$ has an inverse. Put $r=ab^{-1}$. The equation becomes $r^2-r+1\equiv0$. Direct substitution shows $r=809,1191$ are roots, and the polynomial factors as $(r-809)(r-1191)$ modulo $1999$, so these are the only roots. For each of the $1998$ nonzero values of $b$, each root specifies exactly one nonzero residue $a$. Therefore the count is $2\cdot1998=\boxed{3996}$.
