The condition is $N^2\equiv N\pmod{10000}$, i.e. $10000=2^4\cdot5^4$ divides $N(N-1)$. The numbers $N$ and $N-1$ are coprime, so $2^4=16$ divides one of them and $5^4=625$ divides one of them.
\begin{itemize}
\item $16\mid N$ and $625\mid N$: $N\equiv0\pmod{10000}$, last four digits $0000$.
\item $16\mid N-1$ and $625\mid N-1$: last four digits $0001$.
\item $625\mid N$ and $16\mid N-1$: $N\equiv0\pmod{625}$; among $625k$ with $0\le k<16$, $625\equiv1\pmod{16}$, so $k\equiv1\pmod{16}$ and the last four digits are $0625$.
\item $16\mid N$ and $625\mid N-1$: $N=625k+1$ with $625k+1\equiv k+1\equiv0\pmod{16}$, so $k=15$ and $N\equiv9376\pmod{10000}$.
\end{itemize}
Only the last case has a nonzero first digit $a$: $abcd=9376$. (Check: $9376^2=87909376$.) So $abc=\boxed{937}$.
