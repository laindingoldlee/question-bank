If the class has $ n $ students, the trips the particular student misses are precisely the triples selected from the other $ n-1 $. Thus $\binom{n-1}{3}=84=\binom93 $. For integer arguments at least $ 3 $, this binomial coefficient is strictly increasing, so $ n-1=9 $ and $\boxed{n=10}$.
