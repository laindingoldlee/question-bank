The first ant takes $60$ seconds. The diagonals of this rhombus are $AC=600\sqrt3$ and $BD=600$, so the second ant takes $100$ seconds and $x=40$. The last ant travels $AB+BD=1200$ in $140$ seconds; its speed is $\dfrac{60}{7}$ centimetres per second. Hence $mn=\boxed{420}$.

usepackage("amsmath");
size(7cm);
pair A=(0,0),B=(4,0),D=4*dir(60),C=B+D;draw(A--B--C--D--cycle);draw(A--C^^B--D,dashed);label("$A$",A,SW);label("$B$",B,S);label("$C$",C,NE);label("$D$",D,N);label("$60^\circ$",(.6,.3));
\end{asy}
