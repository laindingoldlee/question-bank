The units column gives $2A=A$ modulo 10, so $A=0$ and there is no carry. The hundreds column, including a carry $c$ from tens, gives $O+c=10k$. Since $O\ne A$, this forces $O=9,c=k=1$. The thousands column gives $S=2C+1<10$, so $C\in\{1,2,3,4\}$. If $C=1$, no unused $L$ makes $C+L\ge10$. If $C=2$, only $L=8$ is available but gives $D=0=A$. If $C=4$, $S=9=O$ is forbidden. Thus $C=3$, and the tens column forces $L=8,D=1$ (the other feasible $L=7$ gives $D=0$). Indeed $3930+3980=7910$. Therefore $\boxed{D=1}$.
