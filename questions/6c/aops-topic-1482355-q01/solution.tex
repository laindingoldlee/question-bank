Look at the digit sum. Every move changes exactly one digit by $1$, so every move changes the digit sum by $\pm1$, that is, it changes the \emph{parity} of the digit sum.

The starting string $1337$ has digit sum $14$, which is even. So after an odd number of moves the digit sum is odd, and after an even number of moves it is even.

The target $3173$ has digit sum $3+1+7+3=14$, which is even. Hence the target can only appear after an even number of moves. Bob makes moves number $1,3,5,\dots$ and Alex makes moves number $2,4,6,\dots$, so the winning move is always Alex's. Bob can never win. $\blacksquare$

(The same holds for any starting string: $\overline{abcd}$ and $\overline{badc}$ always have the same digit sum, so the player moving second is the only one who can end the game. The repetition rule only makes the game finite.)
