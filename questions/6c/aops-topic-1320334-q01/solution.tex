(a) If $b=50-a$, then $b^2=2500-100a+a^2$, which differs from $a^2$ by a multiple of $100$. So the last two digits agree (e.g. $24^2=576$, $26^2=676$).

(b) In general $(s-a)^2-a^2=s(s-2a)$. If $50\mid s$, write $s=50m$; then $s-2a$ is even, so $s(s-2a)$ is divisible by $50\cdot2=100$, and the property holds. Conversely, if the property holds for all $a$, then $100$ divides $s(s-2a)$ for $a=0$ and $a=1$, hence divides their difference $2s$, so $50\mid s$. So the property holds exactly when $s$ is a \textbf{multiple of $50$} (such as $100$, $450$ or $6000$, but not $30$).
