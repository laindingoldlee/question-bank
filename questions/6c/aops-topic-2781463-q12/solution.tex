The first crossing is either one of each type, or both of one type. In the first case, each bank has $(1,1)$, and any single return leaves unequal positive numbers on the starting bank; returning both restores the initial state. In the second case the banks each contain two of just one type. Returning one creates a bank with counts $(2,1)$ or $(1,2)$; returning both again restores the initial state. A one-person first crossing is immediately unsafe. Therefore $\boxed{\text{impossible}}$.
