The claim is \textbf{false}: take $a=5$ and $m=n=x=2$. Then $m\equiv n\equiv x\pmod5$, but $mn=4\not\equiv2\pmod5$.

What is always true is $mn\equiv x^2\pmod a$. Indeed, write $m=x+ka$ and $n=x+la$; then
\[mn=x^2+a(kx+lx+kla)\equiv x^2\pmod a.\]
So $mn\equiv x\pmod a$ holds exactly when $x^2\equiv x\pmod a$ (for instance when $x\equiv0$ or $x\equiv1$). $\blacksquare$
