There are $4^4=256$ functions, each specified by the tuple $(f(1),f(2),f(3),f(4))$. For each tuple, check all four inequalities $f(f(x))+x\ne2f(x)$. This is a complete finite enumeration: loop each of the four tuple entries from one through four, reject a tuple as soon as an equality occurs, and count survivors. The survivor count is $\boxed{52}$.
