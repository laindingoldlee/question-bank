Group the terms in pairs:
\[(2007-2006)+(2005-2004)+\cdots+(3-2)+1 .\]
The pairs start at the odd numbers $2007,2005,\dots,3$, so there are $\dfrac{2007-3}{2}+1=1003$ pairs, each equal to $1$. The value is
\[1003+1=\boxed{1004}.\]
