Rewrite as $x^2-4x+1=0$ and complete the square: $(x-2)^2=3$, so $x-2=\pm\sqrt3$ and
\[x=\boxed{2\pm\sqrt3}.\]
Both values work, since the discriminant $16-4=12$ is positive.
