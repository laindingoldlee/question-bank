Let $\overline{A0B}=k\cdot\overline{AB}$ for a positive integer $k$, that is, $100A+B=k(10A+B)$, which rearranges to
\[
B(k-1)=10A(10-k).
\]
Since $B\ge1$ and $A\ge1$, both sides are positive, so $2\le k\le9$, and $B=\dfrac{10A(10-k)}{k-1}\le9$.
\begin{itemize}
\item $k=9$: $B=\dfrac{10A}{8}=\dfrac{5A}{4}$, so $A=4$, $B=5$.
\item $k=8$: $B=\dfrac{20A}{7}$ needs $7\mid A$, so $A=7$ and $B=20$: too big.
\item $k=7$: $B=5A$, so $A=1$, $B=5$.
\item $k=6$: $B=8A$, so $A=1$, $B=8$.
\item $k\le5$: $B\ge\dfrac{10\cdot5}{4}A>9$, impossible.
\end{itemize}
So $\overline{AB}\in\{45,15,18\}$. Now use $\overline{CACBC}$:
\begin{itemize}
\item $\overline{AB}=45$: $\overline{C4C5C}$ must be divisible by $5$, so $C=5$; but $54555$ has digit sum $24$, not divisible by $9$. No solution.
\item $\overline{AB}=15$: $\overline{C1C5C}$ divisible by $5$ forces $C=5$, and $51555$ has digit sum $21$, divisible by $3$. So $51555=15\cdot3437$ works.
\item $\overline{AB}=18$: $\overline{C1C8C}$ must be even and have digit sum $3C+9$ divisible by $9$, so $C$ is even and a multiple of $3$: $C=6$. Indeed $61686=18\cdot3427$.
\end{itemize}
There are two solutions:
\[
\boxed{(A,B,C)=(1,5,5)\ \text{ or }\ (1,8,6)}
\]
($105=15\cdot7$, $51555=15\cdot3437$; $108=18\cdot6$, $61686=18\cdot3427$).
