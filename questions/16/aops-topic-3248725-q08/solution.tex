If symbol $j$ occurs on $k_j$ cards, then $\sum k_j=100$ and $\sum\binom{k_j}{2}=\binom{10}{2}=45$, since each card pair is counted exactly once. For $k_j\ge1$, $k_j-1\le\binom{k_j}{2}$. If there are $v$ symbols, then $100-v\le45$, giving $v\ge55$. Equality is attained by giving every pair of cards its own symbol, placed on both cards; each card receives nine pair symbols, and adding one private symbol per card gives ten. There are $45+10=\boxed{55}$ symbols.
