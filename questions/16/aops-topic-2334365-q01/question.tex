A function assigns to each input exactly one output. Decide whether each of the following rules defines a function, and explain.
\begin{enumerate}
\item[(a)] Each whole number $n\ge2$ is matched with a prime factor of $n$.
\item[(b)] Each natural number is matched with its greatest divisor.
\item[(c)] Each real number is matched with a real fourth root of it.
\end{enumerate}
