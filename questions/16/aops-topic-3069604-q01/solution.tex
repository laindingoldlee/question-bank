Let $r=x^k$ and $S=1+r+\cdots+r^{n-1}$. Subtracting $rS$ from $S$ gives $(1-r)S=1-r^n$. If $r\ne1$, the sum is $\boxed{\dfrac{x^{kn}-1}{x^k-1}}$. If $r=1$, each of the $n$ terms is 1, so the sum is $\boxed{n}$.
