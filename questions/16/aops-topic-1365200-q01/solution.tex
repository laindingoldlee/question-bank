We want positive integers with $y^2-5x^2=31$. The smallest possible $x$ is $x=1$, and it works: $5\cdot1+31=36=6^2$, so $y=6$.

Is this the least $y$ as well? Any solution has $y^2=5x^2+31\ge36$, so $y\ge6$. Hence the least solution is $\boxed{x=1,\ y=6}$, and it minimises both $x$ and $y$ at once.
