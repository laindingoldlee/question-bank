A fourth power divisible by $4$ has an even base, so each pair sum $p+q,q+r,r+p$ must be divisible by $4$. If one prime is $2$, either pair containing it forces the other prime to be $2$, because the only prime congruent to $2$ modulo $4$ is $2$. Thus all three are $2$.

If all primes are odd, divisibility of $p+q$ and $q+r$ by $4$ forces $p,r$ to have the same odd residue modulo $4$. Then $p+r\equiv2\pmod4$, a contradiction. Finally $(2,2,2)$ works because each original expression is $16=2^4$. The unique triple is $\boxed{(2,2,2)}$.
