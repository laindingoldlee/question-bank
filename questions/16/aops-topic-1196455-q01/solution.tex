Square both sides: $1+8r-r^2=16$, so $r^2-8r+15=0=(r-3)(r-5)$. Check in the original equation: for $r=3$, $1+24-9=16$ and for $r=5$, $1+40-25=16$, so both work: $\boxed{r=3\text{ or }r=5}$.
