The order of the digits matters (the code $1234$ is different from $4321$), so we count ordered choices. The first dial can show any of $10$ digits, the second any of the remaining $9$, the third any of $8$ and the fourth any of $7$. By the multiplication principle there are
\[
10\cdot9\cdot8\cdot7=\boxed{5040}
\]
possible codes. (Despite its name, a ``combination'' lock counts arrangements, not combinations: the number of \emph{sets} of four different digits is only $\binom{10}{4}=210$.)
