Both sides are positive, and $\ln$ is increasing, so the inequality is equivalent to
\[
x\ln y<y\ln x\qquad\Longleftrightarrow\qquad\dfrac{\ln y}{y}<\dfrac{\ln x}{x}.
\]
Let $f(t)=\dfrac{\ln t}{t}$ for $t>0$. Then
\[
f'(t)=\dfrac{\dfrac{1}{t}\cdot t-\ln t}{t^2}=\dfrac{1-\ln t}{t^2},
\]
which is negative for $t>e$. So $f$ is strictly decreasing on $[e,\infty)$ (it is continuous there, with negative derivative inside), and $e\le x<y$ gives $f(y)<f(x)$, which is the inequality above. $\blacksquare$

(The inequality is reversed for some pairs below $e$, for instance $x=2$, $y=3$: $3^2=9>8=2^3$. The function $f$ has its maximum at $t=e$, which is where the threshold $e$ comes from. The result has no standard name; it is usually quoted as the fact that $\dfrac{\ln t}{t}$ decreases for $t>e$.)
