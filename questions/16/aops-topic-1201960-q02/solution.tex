Write $(a-4b)(a+4b)=2016=2^5\cdot63$ with $u=a-4b$, $v=a+4b$, so $v-u=8b$ and $u\equiv v\pmod 8$; in particular $u,v$ have the same parity, and since $uv$ is even both are even. Put $u=2u_1$, $v=2v_1$: then $u_1v_1=504$ and $v_1-u_1=4b$, so $u_1,v_1$ again have the same parity and must both be even. Put $u_1=2u_2$, $v_1=2v_2$: then $u_2v_2=126$ and $v_2-u_2=2b$, so $u_2,v_2$ have the same parity. Both odd would make $126$ odd, and both even would make $126$ divisible by $4$; neither holds. Hence there are no solutions.
