The separate proportionalities combine as $x=k\dfrac{yz}{w}$, with constant k. The given values give $12=k\dfrac{6}{5}$, hence $k=10$. Therefore the new value is $10\dfrac{4\cdot 6}{10}=\boxed{24}$. Equivalently doubling y and z multiplies x by 4, while doubling w halves it, for a net factor 2.
