If $a=b=c=0$ the left side is $0$. Otherwise $a+b+c>0$, and we show that each term satisfies
\[
\dfrac{a}{bc+1}\le\dfrac{2a}{a+b+c}.
\]
Since $b,c\le1$, we have $(1-b)(1-c)\ge0$, i.e.\ $bc+1\ge b+c$. Hence, using also $1\ge a$,
\[
2(bc+1)=(bc+1)+(bc+1)\ge(b+c)+1\ge b+c+a .
\]
So $bc+1\ge\dfrac{a+b+c}{2}$, which gives the claimed bound for the first term (it is trivial if $a=0$). By symmetry the same holds for the other two terms, and adding,
\[
\dfrac{a}{bc+1}+\dfrac{b}{ca+1}+\dfrac{c}{ab+1}\le\dfrac{2a+2b+2c}{a+b+c}=2 .\qquad\blacksquare
\]
Equality occurs, for example, at $a=b=1$, $c=0$: $\dfrac{1}{1}+\dfrac{1}{1}+0=2$.
