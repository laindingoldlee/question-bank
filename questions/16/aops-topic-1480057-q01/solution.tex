Among $2,3,\dots,101$, the number $64=2^6$ is the only one divisible by $2^6$ (the next multiple of $64$ is $128>101$). Let $m$ be the least common multiple of the odd numbers $1,3,5,\dots,101$ (so $m$ is odd), and multiply $S$ by $Q=2^5m$:
\[
QS=\sum_{k=2}^{101}\dfrac{2^5m}{k}.
\]
For $k\ne64$, write $k=2^jt$ with $t$ odd and $j\le5$; then $t\mid m$, so $\dfrac{2^5m}{k}=2^{5-j}\cdot\dfrac {m}{t}$ is an integer. For $k=64$ the term is $\dfrac{2^5m}{2^6}=\dfrac {m}{2}$, which is not an integer because $m$ is odd. So $QS$ is an integer plus $\dfrac {m}{2}$, hence not an integer. If $S$ were an integer, $QS$ would be one too. Therefore $S$ is not an integer. $\blacksquare$

(Numerically, $S\approx4.197$.)
