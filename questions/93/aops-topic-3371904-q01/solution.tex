Write the digits as $a,b,c$ with $1\le a\le9$ and $0\le b,c\le9$. The equation becomes $99a+b(10-b)=c^3-c$. Since $0\le b(10-b)\le25$, compare $c^3-c$ with the intervals $[99a,99a+25]$. For $c=0,1,2,3,4$ it is below $99$. For $c=5,6,7,8,9$, the values are $120,210,336,504,720$, whose remainders on division by $99$ are $21,12,39,9,27$. Only $21,12,9$ are at most $25$. The equation $b(10-b)=21$ gives $b=3,7$; value $12$ gives no integer digit; value $9$ gives $b=1,9$. The valid numbers are $135,175,518,598$, so the largest is $\boxed{598}$.
