$2012!$ contains far more factors $2$ than factors $5$ (for instance $1006$ even numbers against $\left\lfloor\dfrac{2012}5\right\rfloor+\left\lfloor\dfrac{2012}{25}\right\rfloor+\dots=501$ fives). Removing the trailing zeros divides by $10^{501}$, leaving a number that is still even, so its last digit is $\boxed{\text{even}}$.
