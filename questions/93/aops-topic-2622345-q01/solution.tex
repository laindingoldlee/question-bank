By Vieta's formulas a monic quadratic with root sum $s$ and root product $p$ is $x^2-sx+p$, so there is only one:
\[x^2-128x+4096=(x-64)^2.\]
So the only such quadratic is $\boxed{x^2-128x+4096}$, with the double root $64$.
