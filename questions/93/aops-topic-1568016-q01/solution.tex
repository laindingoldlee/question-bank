We need nonnegative integers with $25q+10d+5n=65$, i.e., dividing by $5$,
\[
5q+2d+n=13 .
\]
For fixed $q$ and $d$ the number of nickels $n=13-5q-2d$ is determined, so we only need to count the pairs $(q,d)$ with $5q+2d\le13$:
\begin{itemize}
\item $q=0$: $2d\le13$, $d=0,\dots,6$: $7$ ways;
\item $q=1$: $2d\le8$, $d=0,\dots,4$: $5$ ways;
\item $q=2$: $2d\le3$, $d=0,1$: $2$ ways.
\end{itemize}
In total $7+5+2=\boxed{14}$ ways. The point is to fix the largest coins and count the possible numbers of the middle coin at once, instead of listing every combination.
