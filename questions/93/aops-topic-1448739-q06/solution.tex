By the Cauchy-Schwarz inequality (or QM-AM),
\[
(a+b+c+d)^2\le(1+1+1+1)(a^2+b^2+c^2+d^2)=32,
\]
so $a+b+c+d\le\sqrt{32}=4\sqrt2$, with equality for $a=b=c=d=\sqrt2$. The maximum is $\boxed{4\sqrt2}$.

(The post asks instead for the minimum positive value of $a+b+c+d$; that does not exist. The sum takes every value in $[-4\sqrt2,4\sqrt2]$, so positive values arbitrarily close to $0$ occur. Even for positive $a,b,c,d$ the sum is always greater than $\sqrt8=2\sqrt2$, as $(a+b+c+d)^2>a^2+b^2+c^2+d^2$, but it gets arbitrarily close to $2\sqrt2$, so there is no minimum.)
