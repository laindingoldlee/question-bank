Work backwards. An output $m$ can come from the input $2m$ (always) or from an odd input $k$ with $3k+1=m$, i.e. $k=\dfrac{m-1}3$, when this is an odd positive integer. Starting from $1$ and going back one step at a time:
\begin{itemize}
\item $1\leftarrow2$ (since $\dfrac{1-1}{3}=0$ is not positive);
\item $2\leftarrow4$;
\item $4\leftarrow8$ or $1$ (since $\dfrac{4-1}{3}=1$ is odd);
\item $8\leftarrow16$; $1\leftarrow2$;
\item $16\leftarrow32$ or $5$; $2\leftarrow4$;
\item $32\leftarrow64$; $5\leftarrow10$; $4\leftarrow8$ or $1$.
\end{itemize}
So the inputs that reach $1$ after exactly $6$ steps are $64$, $10$, $8$ and $1$, with sum $64+10+8+1=83$. The answer is $\boxed{\textbf{(E) }83}$.
