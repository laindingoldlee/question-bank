Since $c$ is the largest, $3c^2>121$, so $c\ge7$; and $c^2<121$, so $c\le10$.
\begin{itemize}
\item $c=10$: $a^2+b^2=21$. The squares below $21$ are $1,4,9,16$, and no two add up to $21$.
\item $c=9$: $a^2+b^2=40=4+36$, so $(a,b)=(2,6)$. (The other candidates $40-1=39$, $40-9=31$, $40-16=24$, $40-25=15$ are not squares.)
\item $c=8$: $a^2+b^2=57$ with $b\le7$. Then $57-49=8$, $57-36=21$, $57-25=32$, $57-16=41$ are not squares (and $b\ge6$ is needed, since $2b^2>57$).
\item $c=7$: $a^2+b^2=72$ with $b\le6$, but then $a^2+b^2\le25+36=61<72$.
\end{itemize}
So the only solution is $\boxed{(a,b,c)=(2,6,9)}$. Check: $4+36+81=121$.
