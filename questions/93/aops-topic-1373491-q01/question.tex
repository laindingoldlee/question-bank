Each of the $26$ letters $a,b,c,\dots,z$ stands for a real number (so $e$ and $i$ are ordinary variables). For each $k=1,2,\dots,26$, the sum of all the variables except the $k$th letter of the alphabet equals $k$. For example, $b+c+\dots+z=1$ (the $1$st letter $a$ is missing), $a+c+d+\dots+z=2$ (the $2$nd letter $b$ is missing), and the sum of all the letters except $h$ equals $8$. Find the values of $a,b,\dots,z$.
