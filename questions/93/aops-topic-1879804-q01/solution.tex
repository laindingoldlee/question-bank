Let $k$ be the common value. Adding $2$ to each fraction,
\[
\dfrac{a+b+c}{c}=\dfrac{a+b+c}{b}=\dfrac{a+b+c}{a}=k+2 .
\]
\begin{itemize}
\item If $a+b+c\ne0$, the three denominators must be equal: $a=b=c$. Then the expression is $\dfrac{2a\cdot2a\cdot2a}{a^3}=8$.
\item If $a+b+c=0$, then $a+b=-c$, $b+c=-a$, $c+a=-b$, and the expression is $\dfrac{(-c)(-a)(-b)}{abc}=-1$.
\end{itemize}
Both cases occur: $a=b=c=1$ gives $8$, and $(a,b,c)=(1,1,-2)$ satisfies the condition (all three fractions equal $-2$) and gives $-1$. So the possible values are $\boxed{-1\text{ and }8}$.
