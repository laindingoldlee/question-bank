He lands on $15$ iff some initial run of jumps sums to $15$, i.e. uses $i$ twos and $j$ threes with $2i+3j=15$: $(i,j)=(6,1),(3,3),(0,5)$. These are disjoint events determined by the first $i+j$ jumps:
\[\dbinom71\left(\dfrac23\right)^6\dfrac13+\dbinom63\left(\dfrac23\right)^3\left(\dfrac13\right)^3+\left(\dfrac13\right)^5=\dfrac{448+480+9}{2187}=\dfrac{937}{2187}.\]
So the probability of never landing there is $\dfrac{1250}{2187}$ and $p+q=\boxed{3437}$.
