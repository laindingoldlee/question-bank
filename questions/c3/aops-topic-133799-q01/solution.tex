Since $4^{29}=2^{58}$,
\[
2^{2009}\times5^{1957}\div4^{29}=2^{1951}\cdot5^{1957}=(2\cdot5)^{1951}\cdot5^{6}=15625\cdot10^{1951}.
\]
This is the $5$-digit number $15625$ followed by $1951$ zeros, so it has $5+1951=\boxed{1956}$ digits.
