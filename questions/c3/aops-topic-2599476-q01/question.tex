Logarithms $\log_bx$ are defined only for bases $b>0$ with $b\ne1$. This exercise shows why.
\begin{enumerate}
\item[(a)] For the negative base $-2$, the power $(-2)^x$ is a real number when $x$ is an integer, or a fraction $\dfrac pq$ in lowest terms with $q$ odd, using $(-2)^{\dfrac pq}=\left(\sqrt[q]{-2}\right)^p$. Show that $(-2)^x=2$ has no solution of this kind, so $\log_{-2}2$ cannot be defined.
\item[(b)] Explain why the base $b=1$ is also excluded.
\end{enumerate}
