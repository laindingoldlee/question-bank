\textbf{Which integers work.} Squares are $\equiv0$ or $1\pmod4$, so a difference of two squares is $\equiv0,1$ or $3\pmod4$; numbers $\equiv2\pmod4$ never work. Every other number does:
\begin{itemize}
\item if $n$ is odd, $n=\left(\dfrac{n+1}{2}\right)^2-\left(\dfrac{n-1}{2}\right)^2$;
\item if $4\mid n$, $n=\left(\dfrac {n}{4}+1\right)^2-\left(\dfrac {n}{4}-1\right)^2$.
\end{itemize}
From $16$ to $30$ there are $15$ integers, of which $18,22,26,30$ are $\equiv2\pmod4$. So $15-4=\boxed{11}$ of them can be written as a difference of two squares. (For example $16=5^2-3^2$, $20=6^2-4^2$, $29=15^2-14^2$; the answer is the same whether or not $0$ is allowed as a square, because both formulas use positive squares for these $n$.)
