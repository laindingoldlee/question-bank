Apply Cauchy-Schwarz to the vectors $(x,y,z)$ and $(y,z,x)$:
\[\left(x^2+y^2+z^2\right)\left(y^2+z^2+x^2\right)\ge(xy+yz+zx)^2 .\]
So $\left(x^2+y^2+z^2\right)^2\ge(xy+yz+zx)^2$, and since $x^2+y^2+z^2\ge0$, taking square roots gives
\[x^2+y^2+z^2\ge|xy+yz+zx|\ge xy+yz+zx. \qquad\blacksquare\]

\textbf{Equality.} If $x=y=z$, both sides equal $3x^2$. Conversely, suppose equality holds and $(x,y,z)\ne(0,0,0)$. Then equality holds in Cauchy-Schwarz, so $(x,y,z)=\lambda(y,z,x)$ for some real $\lambda$. Then $x=\lambda y=\lambda^2z=\lambda^3x$, and similarly $y=\lambda^3y$, $z=\lambda^3z$; since some coordinate is nonzero, $\lambda^3=1$, so $\lambda=1$ and $x=y=z$. Hence equality holds exactly when $\boxed{x=y=z}$.

(The inequality holds for all real numbers, not only positive ones. A proof without Cauchy-Schwarz: twice the difference of the two sides is $(x-y)^2+(y-z)^2+(z-x)^2\ge0$.)
