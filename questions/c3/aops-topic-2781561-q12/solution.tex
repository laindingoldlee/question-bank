If there are $ T $ teachers and each course has $ c $ students, then $ Tc=7\cdot1001=7007 $. We need $ T>7 $, since seven courses would force everyone to take the same set. The smallest divisor of $ 7007=7^2\cdot11\cdot13 $ greater than 7 is 11. This is achievable: divide the 1001 students into 11 groups of 91 and label 11 courses cyclically. Group $ j $ takes courses $ j,j+1,\ldots,j+6 $ modulo 11. Each course then has $ 7\cdot91=637 $ students. Thus the minimum is $\boxed{11}$.
