Put $y=0$: $f(x)+f(0)=2f(x)$, so $f(x)=f(0)$ for all $x$: $f$ is constant. Conversely every constant $f\equiv c$ works ($c+c=2c$). Answer: $\boxed{f(x)=c}$ for any real constant $c$.
