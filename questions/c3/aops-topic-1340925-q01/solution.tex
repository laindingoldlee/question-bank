Let $x$ consist of $k$ sixes followed by a $5$. Then $3x=1\underbrace{9\dots9}_{k}5=2\cdot10^{k+1}-5$ (for example $3\cdot65=195$ and $3\cdot665=1995$), so $x=\dfrac{2\cdot10^{k+1}-5}{3}$ and
\[
x^2=\dfrac{4\cdot10^{2k+2}-20\cdot10^{k+1}+25}{9}.
\]
One checks that this equals the number with $k$ fours, then $k+1$ twos, then a $5$: for $k=1,2,3$ we get $4225$, $442225$, $44422225$. Indeed
\[
\underbrace{4\dots4}_{k}\underbrace{2\dots2}_{k+1}5=4\cdot\dfrac{10^k-1}{9}\cdot10^{k+2}+2\cdot\dfrac{10^{k+1}-1}{9}\cdot10+5=\dfrac{4\cdot10^{2k+2}-20\cdot10^{k+1}+25}{9}.
\]
So $\#[x^2]=4k+2(k+1)+5=6k+7$. Setting $6k+7=49$ gives $k=7$, so
\[
x=\boxed{66666665}.
\]
