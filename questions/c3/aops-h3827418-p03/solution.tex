Regard the tuple as a function $f:\{1,\ldots,7\}\to\{1,\ldots,7\}$. The condition is $f(f(i))=f(i)$, so every image point is fixed. If the image has size $k$, choose its $k$ fixed points in $\binom7k$ ways, then map every other point freely to one of them in $k^{7-k}$ ways. Thus
\[
N=\sum_{k=1}^7\binom7k k^{7-k}
=7+672+2835+2240+525+42+1=6322.
\]
The requested remainder is $\boxed{322}$.
