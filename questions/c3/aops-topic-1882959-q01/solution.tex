Since $y=x^2\ge0$, we need $x^2<10$, that is $x\in\{-3,-2,-1,0,1,2,3\}$. Each such $x$ gives exactly one pair $(x,x^2)$, so there are $\boxed{7}$ ordered pairs: $(0,0),(\pm1,1),(\pm2,4),(\pm3,9)$.
