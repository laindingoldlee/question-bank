For example, $f(x)=\sqrt x$ has domain $\boxed{[0,\infty)}$: for $x<0$ there is no real number whose square is $x$ (squares of real numbers are never negative), so $\sqrt x$ is not a real number. Another example is $g(x)=\dfrac1x$, with domain all real numbers except $0$, because division by $0$ is undefined. (Any function whose formula involves an even root of an expression that can be negative, or a denominator that can be $0$, works.)
