The polynomial is unchanged by $x\mapsto\dfrac{1}{x}$ (after multiplying by $x^8$), so look for a factorisation $\left(x^4+ax^3+bx^2-ax+1\right)\left(x^4-ax^3+bx^2+ax+1\right)$. Writing it as $\left(x^4+bx^2+1\right)^2-\left(ax^3-ax\right)^2$, it expands to
\[x^8+\left(2b-a^2\right)x^6+\left(b^2+2+2a^2\right)x^4+\left(2b-a^2\right)x^2+1\]
(the odd terms cancel). We need $2b=a^2$ and $b^2+2+2a^2=98$: with $b=\dfrac{a^2}{2}$ this gives $\dfrac{a^4}{4}+2a^2-96=0$, so $a^2=16$, $a=4$, $b=8$. Hence
\[x^8+98x^4+1=\boxed{\left(x^4-4x^3+8x^2+4x+1\right)\left(x^4+4x^3+8x^2-4x+1\right)}.\]
