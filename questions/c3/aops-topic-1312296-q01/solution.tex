Each factor is $\dfrac{9^k}{3^k}=3^k$, so $a=3^1\cdot3^2\cdot3^3=3^6=729$. The sum adds the constant $a$ to itself $a$ times: $a^2=729^2=\boxed{531441}=3^{12}$.
