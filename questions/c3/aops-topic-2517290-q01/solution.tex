Steps 1--3 are correct: $\sqrt{-1}\cdot\sqrt{-1}=i\cdot i=i^2=-1$, so step 3 says $2=-1+3$, which is true.

The error is in step 4, which uses the rule $\sqrt a\cdot\sqrt b=\sqrt{ab}$. This rule is proved only for $a,b\ge0$: then $\sqrt a\sqrt b$ is a nonnegative number whose square is $ab$, so it is the nonnegative square root of $ab$. For negative numbers it fails. Here
\[\sqrt{-1}\cdot\sqrt{-1}=i^2=-1,\qquad\text{but}\qquad\sqrt{(-1)(-1)}=\sqrt1=1.\]
(Both $-1$ and $1$ square to $1$; the principal square root $\sqrt1$ is $1$, while the product of the principal roots $i\cdot i$ is the other square root, $-1$.) So step 4 replaces $-1$ by $1$, turning the true equation $2=-1+3$ into the false $2=1+3$. Step 5 is a correct deduction from a false equation.

$\boxed{\text{Step 4: }\sqrt a\sqrt b=\sqrt{ab}\text{ is false for }a=b=-1}$
