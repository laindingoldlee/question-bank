Find the error in the following ``proof'' that $1=2$.
\begin{enumerate}
\item Start from $-1=-1$; taking square roots, $\sqrt{-1}=\sqrt{-1}$, i.e. $i=i$.
\item Multiplying both sides by $\sqrt{-1}$: $\ -1=\sqrt{-1}\cdot\sqrt{-1}$.
\item Adding $3$: $\ 2=\sqrt{-1}\cdot\sqrt{-1}+3$.
\item Combining the square roots: $\ 2=\sqrt{(-1)(-1)}+3=\sqrt1+3=1+3=4$.
\item Dividing $2=4$ by $2$ gives $1=2$.
\end{enumerate}
