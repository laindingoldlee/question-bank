We count solutions of $p+5n+10d+25q=1000$ in nonnegative integers.

\textbf{Pennies, nickels and dimes first.} For an amount $m=5j$ cents, the number of ways with pennies, nickels and dimes is $\displaystyle\sum_{d=0}^{\left\lfloor\dfrac{j}{2}\right\rfloor}(j-2d+1)$: choose the number $d$ of dimes, then any number of nickels from $0$ to $j-2d$, and pennies make up the rest. This sum is
\[
(i+1)^2\ \text{ if } j=2i,\qquad (i+1)(i+2)\ \text{ if } j=2i+1,
\]
since it is $1+3+\cdots+(2i+1)$, respectively $2+4+\cdots+(2i+2)$.

\textbf{Now the quarters.} With $q$ quarters the remaining amount is $1000-25q=5(200-5q)$, so $j=200-5q$.
\begin{itemize}
\item $q=2r$ ($0\le r\le20$): $j=200-10r$ is even with $i=100-5r$, giving $(101-5r)^2$ ways.
\item $q=2r+1$ ($0\le r\le19$): $j=195-10r$ is odd with $i=97-5r$, giving $(98-5r)(99-5r)$ ways.
\end{itemize}
So the total is
\[
\sum_{r=0}^{20}(101-5r)^2+\sum_{r=0}^{19}(98-5r)(99-5r)=73871+68640=\boxed{142511}.
\]

\textbf{A recursion.} Let $W_k(m)$ be the number of ways to make $m$ cents with the first $k$ coin types (in the order $1,5,10,25$). Either no coin of type $k$ is used, or at least one is; removing one such coin gives
\[
W_k(m)=W_{k-1}(m)+W_k(m-c_k),
\]
with $W_k(0)=1$, $W_k(m)=0$ for $m<0$ and $W_1(m)=1$. Filling in the table for $m=0,1,\dots,1000$ gives $W_4(1000)=142511$ again.
