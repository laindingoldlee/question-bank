Place $A=(0,0)$, $B=(8,0)$, $C=(8,8)$, $D=(0,8)$. Then $E=(4,0)$ and $F=(2,4)$, so $\overrightarrow{FD}=(-2,4)$.

The tangent at $D$ is perpendicular to the radius $FD$, so it has direction $(2,1)$: line $L$ consists of the points $(2t,\,8+t)$. Line $M$ is $y=4$, so $8+t=4$, $t=-4$ and $G=(-8,4)$. Hence
\[GF=2-(-8)=\boxed{10}.\]

\begin{asy}
usepackage("amsmath");
size(6cm);
defaultpen(fontsize(10pt));
pair A=(0,0),B=(8,0),C=(8,8),D=(0,8),Ep=(4,0),F=(2,4),G=(-8,4);
draw(A--B--C--D--cycle,linewidth(0.8));
draw(Ep--D); draw(circle(F,sqrt(20)),gray);
draw(D+0.6*(D-G)--G-0.25*(D-G),blue); draw(G-(1,0)--(10,4),red);
draw(F--D,dashed);
pair u=unit(F-D), w=unit(G-D); draw(D+0.6*u--D+0.6*u+0.6*w--D+0.6*w);
dot(Ep); dot(F); dot(G); dot(D);
label("$A$",A,SW); label("$B$",B,SE); label("$C$",C,NE); label("$D$",D,NE); label("$E$",Ep,S); label("$F$",F,dir(35)); label("$G$",G,NW);
label("$L$",D+0.6*(D-G),N,blue); label("$M$",(10,4),E,red);
\end{asy}

(Synthetically: triangle $FDG$ has a right angle at $D$, and $\cos\angle DFG=\dfrac{2}{\sqrt{20}}$ because $FD$ has horizontal component $2$; so $GF=\dfrac{FD}{\cos\angle DFG}=\dfrac{\sqrt{20}\cdot\sqrt{20}}{2}=10$.)
