There are $n!$ ways to put the keys in a row. Arranging them on a ring, each arrangement can be rotated into $n$ positions, so there are $\dfrac{n!}{n}=(n-1)!$ arrangements up to rotation. Flipping the keychain over reverses the cyclic order; for $n\ge3$ distinct keys this always gives a different cyclic order (the order of any three of the keys around the ring is reversed), so the arrangements up to rotation pair off, and the number of keychains is
\[\dfrac{(n-1)!}{2}=3\cdot4\cdots(n-1)=\prod_{i=3}^{n-1}i .\]
So $a=3$ and $b=1$. These are the only constants that work for every $n$: $\prod_{i=a}^{n-b}i=\dfrac{(n-b)!}{(a-1)!}$, and comparing consecutive values of $n$ gives $n+1-b=n$, so $b=1$, and then $(a-1)!=2$ gives $a=3$. Hence $a+b=\boxed{4}$.
