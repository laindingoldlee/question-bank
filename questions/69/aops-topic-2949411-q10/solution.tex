Order the sides $a\le b\le c$. Each is at most 44 because $45^2>2019$. The equation $a^2+b^2+c^2=2019$ can therefore be checked exhaustively in a finite range:
\begin{verbatim}
from math import isqrt
solutions=[]
for a in range(1,45):
    for b in range(a,45):
        rest=2019-a*a-b*b
        if rest>0:
            c=isqrt(rest)
            if c>=b and c*c==rest:
                solutions.append((a+b+c,a,b,c))
assert min(solutions)==(57,1,13,43)
\end{verbatim}
The minimizing sides $1,13,43$ satisfy $1+169+1849=2019$. The least perimeter sum is $4\cdot57=\boxed{228}$.
