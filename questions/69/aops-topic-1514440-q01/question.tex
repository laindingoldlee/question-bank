A zoo has orang-utans, gorillas and chimpanzees, $100$ apes altogether. Each orang-utan is given $4$ bananas per day, each gorilla $6$ and each chimpanzee $1$. If $200$ bananas are needed every day, find the smallest possible number of chimpanzees.
