Call blue and red blocks type $X$ and green and purple blocks type $Y$, and first choose the pattern of types (a word with four $X$s and four $Y$s). Within a maximal run of $X$s neighbours must have the same colour, so each run of $X$s is a single colour, and likewise for $Y$.

Colouring the $X$-runs so that blue and red are each used twice: run lengths $1,1,1,1$ give $\binom42=6$ ways; $1,1,2$ give $2$ (the $2$-run gets one colour, the two single blocks the other); $2,2$ give $2$; and $1,3$ or $4$ give $0$. The same holds for $Y$.

So only patterns whose $X$-runs and $Y$-runs both have types $1111$, $112$ or $22$ count. Since the numbers of $X$-runs and $Y$-runs differ by at most $1$:
\begin{itemize}
\item $1111$ and $1111$: $XYXYXYXY$ or $YXYXYXYX$, $2$ patterns, $2\cdot6\cdot6=72$.
\item $1111$ and $112$ (or the reverse): $4$ runs of one type at both ends, the $3$ runs of the other type inside in $3$ orders: $2\cdot3\cdot6\cdot2=72$.
\item $112$ and $112$: $3$ runs each, $2$ choices of starting type and $3\cdot3$ run orders: $18\cdot2\cdot2=72$.
\item $112$ and $22$ (or the reverse): the $3$-run type at both ends, $3$ orders: $2\cdot3\cdot2\cdot2=24$.
\item $22$ and $22$: $2$ patterns, $2\cdot2\cdot2=8$.
\end{itemize}
Total $72+72+72+24+8=\boxed{248}$, confirmed by checking all $\dfrac{8!}{2!^4}=2520$ arrangements by computer.
