Let $\omega$ be a root of $x^2+x+1$, so $\omega^3=1$ and $\omega\ne1$. Then $\omega^{10}+\omega^5+1=\omega+\omega^2+1=0$, and likewise for $\bar\omega$, so $x^2+x+1$ divides $x^{10}+x^5+1$. To find the quotient quickly, write $x^{10}+x^5+1=\dfrac{x^{15}-1}{x^5-1}$ and $x^2+x+1=\dfrac{x^3-1}{x-1}$, so the quotient is
\[
\dfrac{(x^{15}-1)(x-1)}{(x^5-1)(x^3-1)}=\boxed{x^8-x^7+x^5-x^4+x^3-x+1},
\]
which can be checked by multiplying back. (This is the cyclotomic polynomial $\Phi_{15}(x)$.)
