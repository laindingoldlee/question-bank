The first equality changes only parentheses and is associativity. The second also changes the order of $B,C$ and needs commutativity. A valid chain is $(A+B)+C=A+(B+C)=A+(C+B)=(A+C)+B$, using associativity, commutativity, then associativity. Thus associativity alone does not justify the second equality.
