A cube has edges of length $120$ cm. It is cut into some number of smaller cubes, all of equal size, each with an integer edge length. One of those smaller cubes is then cut into some number of even smaller cubes, all of equal size. If the edge length of each of the even smaller cubes is $n$ cm, where $n$ is an integer, find the number of possible values of $n$.
