If $p$ is odd, $p^k+1$ is even and greater than $2$, so not prime. Hence $p=2$. If $k$ has an odd factor $m>1$, write $k=jm$; then $2^j+1$ divides $2^{jm}+1$ (since $x+1\mid x^m+1$ for odd $m$), and $1<2^j+1<2^k+1$, so $2^k+1$ is not prime. So $k=2^m$ is a power of $2$, and $2^k+1$ is then a Fermat number $F_m=2^{2^m}+1$.

The answer is: $p=2$ and $k=2^m$ with $F_m$ prime. The known cases are $\boxed{(2,1),(2,2),(2,4),(2,8),(2,16)}$, giving the primes $3,5,17,257,65537$. Whether any other Fermat number is prime is an open problem.
