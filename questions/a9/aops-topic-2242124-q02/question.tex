A student answers all $25$ questions of a test, and each answer is independently correct or incorrect with probability $\dfrac{1}{2}$. Write the results in question order as a string of $25$ digits, $1$ for a correct answer and $0$ for an incorrect one.
\begin{enumerate}
\item[(a)] What is the probability that the string contains no block $10$ (a $1$ immediately followed by a $0$)?
\item[(b)] What is the probability that the string contains no block $101$?
\end{enumerate}
