The answer is $\boxed{0}$.

Call the number at the end of a minute an \emph{end value}. An end value is either $7m$ for a one-digit $m$ (so one of $7,14,\dots,63$) or the reversal of a two-digit number (and $100$ becomes $50$ and then $5$). In particular every end value is at most $99$, and \textbf{no end value is a multiple of $10$}: the multiples $7m$ with $1\le m\le9$ do not end in $0$, and a reversal ends in the first digit of the original number, which is not $0$.

A minute ends with a one-digit number only if, after the halving step, the number is $1$ (giving $7$) or a two-digit multiple of $10$ (whose reversal has one digit).

\textbf{Ending with $2,3,5$ or $7$ by reversal.} After halving in minute $4$ the number would be $20,30,50$ or $70$. So the end value of minute $3$ would be one of these (if not divisible by $4$) or twice one of them that is divisible by $4$ and at most $99$, namely $40$ or $60$. All of these are multiples of $10$, which is impossible for an end value.

\textbf{Ending with $7$ from $1$.} After halving in minute $4$ the number would be $1$, so the end value of minute $3$ is $1$ (the number $2$ is not divisible by $4$). The end value $1$ arises only by reversing $10$, so after halving in minute $3$ the number was $10$. Then the end value of minute $2$ was $10$ or $20$, again multiples of $10$, which is impossible.

So no starting number leads to a one-digit prime after four minutes.
