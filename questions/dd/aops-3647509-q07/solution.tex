Let $X$ count boundaries whose two neighbouring sectors have different colours. Each of the ten boundaries contributes with probability $\dfrac{9}{10}$, so $\mathbb{E} X=9$. Unless every sector has one colour, the number of regions equals $X$. In the monochromatic case it is one instead of zero. This exception has probability $10\cdot10^{-10}=10^{-9}$. The expectation is therefore $\boxed{9+10^{-9}}$.
