Number the days of the week $0$ (Sunday) to $6$ (Saturday), and let March 1 be day $w$.

\textbf{The real March.} $31=4\cdot7+3$ days contain every day of the week four times, plus March 29, 30, 31, which repeat the days of March 1, 2, 3. So there are five Saturdays exactly when Saturday is one of $w,w+1,w+2$, i.e. $w\in\{4,5,6\}$ (Thursday, Friday or Saturday).

\textbf{Bob's calendar.} On March $1+k$ it shows $w+2k\pmod7$. As $k$ runs through $0,\dots,6$, the values $2k$ run through all residues mod $7$, so the first $28$ days show each day four times; March 29, 30, 31 ($k=28,29,30$) show $w$, $w+2$, $w+4$. It shows four Saturdays exactly when $6\notin\{w,w+2,w+4\}\pmod7$.

For $w=4$ we have $w+2=6$, and for $w=6$ we have $w=6$; only $w=5$ (Friday) works: $\{5,0,2\}$ contains no $6$. So March 1 is a Friday, and March 31, which is $30=4\cdot7+2$ days later, is a $\boxed{\textbf{(E) }\text{Sunday}}$.
