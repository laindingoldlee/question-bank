For a positive integer $x$, let $T(x)=1^2+2^2+3^2+\cdots+x^2$ (for example, $T(4)=30$ is the number of squares of all sizes in a $4\times4$ grid of unit squares). $T(1)=1$ is a perfect square. Find the smallest $x>1$ for which $T(x)$ is a perfect square.
