Taking logarithms gives $(2\log n-3\log m)x=4\log m-\log n$. If $2\log n\ne3\log m$, there is exactly one solution $\boxed{x=\dfrac{4\log m-\log n}{2\log n-3\log m}}$. If the coefficient is zero, consistency additionally requires $4\log m=\log n$. Together these force $\log m=\log n=0$. Thus if $m=n=1$, every real $x$ works; if $n^2=m^3$ but $(m,n)\ne(1,1)$, no real $x$ works.
