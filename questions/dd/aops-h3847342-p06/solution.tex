The root formula is $\alpha_k=\dfrac{k+\sqrt{k^2+4}}{2}$. For every $k\ge1$, $k<\alpha_k<k+1$, since $k^2<k^2+4<(k+2)^2$. Therefore
\[
\sum_{k=1}^{62}\alpha_k<\sum_{k=1}^{62}(k+1)=2015<2016,
\]
while
\[
\sum_{k=1}^{63}\alpha_k>\sum_{k=1}^{63}k=2016.
\]
All terms are positive, so the least index is $\boxed{63}$.
