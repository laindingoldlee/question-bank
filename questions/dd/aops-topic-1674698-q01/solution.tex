Each row contains $n-1$ horizontally adjacent pairs, so there are $n(n-1)$ such pairs, and likewise $n(n-1)$ vertically adjacent pairs. All $\dbinom{n^2}{2}$ pairs are equally likely, so for $n\ge2$
\[
P=\dfrac{2n(n-1)}{\dfrac{n^2(n^2-1)}{2}}=\dfrac{4n(n-1)}{n^2(n-1)(n+1)}=\dfrac{4}{n(n+1)} .
\]
(For $n=1$ there is only one square and no pair can be chosen.) We need $\dfrac{4}{n(n+1)}<\dfrac{1}{2017}$, i.e.\ $n(n+1)>8068$. Since $89\cdot90=8010<8068<8190=90\cdot91$, the least such $n$ is $\boxed{90}$.
