Draw from the bag labeled mixed. It cannot be mixed, so the observed color is its entire content type. If it shows gold, the bag labeled silver cannot be silver and cannot be the already located all-gold bag; hence it is mixed, leaving the gold-labeled bag all silver. If it shows silver, exchange the color names in this argument. One draw always suffices.
