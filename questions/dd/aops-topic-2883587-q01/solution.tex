There are $\dbinom{45}5=1221759$ equally likely draws. Exactly $k$ matches: $\dbinom5k\dbinom{40}{5-k}$ draws. So
\[P(4)=\dfrac{5\cdot40}{1221759}=\boxed{\dfrac{200}{1221759}},\qquad P(3)=\dfrac{10\cdot780}{1221759}=\boxed{\dfrac{2600}{407253}}.\]
Summing $\dbinom5k\dbinom{40}{5-k}$ over $k=0,\dots,5$ gives $\dbinom{45}5$ (Vandermonde), so the probabilities add to $1$.
