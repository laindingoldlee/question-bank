\textbf{Bounding $x$.} Since $t-1<\lfloor t\rfloor\le t$,
\[x^2+\dfrac{5x}{6}-2<x^2+\left\lfloor\dfrac {x}{2}\right\rfloor+\left\lfloor\dfrac {x}{3}\right\rfloor\le x^2+\dfrac{5x}{6}.\]
So a solution satisfies $6x^2+5x-60\ge0$ and $6x^2+5x-72<0$. The roots of $6x^2+5x-60$ are $\dfrac{-5\pm\sqrt{1465}}{12}\approx-3.61,\ 2.77$, and those of $6x^2+5x-72$ are $\dfrac{-5\pm\sqrt{1753}}{12}\approx-3.91,\ 3.07$. Hence
\[-3.91<x\le-3.60\qquad\text{or}\qquad2.77\le x<3.08\]
(rounding outwards).

\textbf{Positive range.} Here $\left\lfloor\dfrac {x}{2}\right\rfloor=1$. If $x<3$, then $\left\lfloor\dfrac {x}{3}\right\rfloor=0$ and $x^2=9$, so $x=3$, which is not less than $3$. If $3\le x<3.08$, then $\left\lfloor\dfrac {x}{3}\right\rfloor=1$ and $x^2=8$, so $x=2\sqrt2<3$, again impossible.

\textbf{Negative range.} Here $\dfrac {x}{2}\in(-1.96,-1.80]$ and $\dfrac {x}{3}\in(-1.31,-1.20]$, so both floors equal $-2$, and $x^2=14$. The negative root $x=-\sqrt{14}\approx-3.742$ lies in the range. Check: $\left\lfloor\dfrac{-\sqrt{14}}{2}\right\rfloor=\lfloor-1.87\rfloor=-2$ and $\left\lfloor\dfrac{-\sqrt{14}}{3}\right\rfloor=\lfloor-1.25\rfloor=-2$, so the left side is $14-2-2=10$.

So the only solution is $\boxed{x=-\sqrt{14}}$. (The value $x=3$ is not a solution: it gives $9+1+1=11$.)
