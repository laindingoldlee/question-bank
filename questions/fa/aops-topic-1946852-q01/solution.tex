Complete the squares:
\[
x^2+2y^2-6x+4y+11=(x-3)^2+2(y+1)^2,\qquad x^2+3y^2+2x+6y+4=(x+1)^2+3(y+1)^2 .
\]
Both are nonnegative, so the expression is defined everywhere, and since $2(y+1)^2\ge0$ and $3(y+1)^2\ge0$,
\[
\sqrt{(x-3)^2+2(y+1)^2}+\sqrt{(x+1)^2+3(y+1)^2}\ \ge\ |x-3|+|x+1|\ \ge\ |(3-x)+(x+1)|=4 .
\]
Equality holds when $y=-1$ and $-1\le x\le3$ (for example $x=0$, $y=-1$, where the value is $3+1=4$). So the minimum is $\boxed{4}$.
