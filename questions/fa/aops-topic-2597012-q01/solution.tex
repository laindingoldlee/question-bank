If $(a,b)$ is a solution, so is $(b,a)$. Hence the set of possible values of $a$ is unchanged by $a\mapsto10000-a$. There is at least one solution, for example $59+9941=10000$ ($9941$ is prime: it has no prime factor up to $99$, and $100^2>9941$). If $a_{\min}$ is the smallest possible value of $a$, then the largest is $10000-a_{\min}$, since $a\le10000-a_{\min}$ for every possible $a$ by the symmetry. The required sum is
\[a_{\min}+\left(10000-a_{\min}\right)=\boxed{10000}.\]
(In fact $a_{\min}=59$ and $a_{\max}=9941$.)
