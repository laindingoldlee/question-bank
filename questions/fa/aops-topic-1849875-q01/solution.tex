We show that only $k=1$ works ($5+3=8=2^3$).

\textbf{$k$ even.} Then $5^k\equiv1$ and $3^k\equiv1\pmod4$, so $5^k+3^k\equiv2\pmod4$: it is even but not divisible by $4$. But if $n^m$ is even then $n$ is even and $4\mid n^m$ (as $m\ge2$). No solution.

\textbf{$k$ odd.} Then
\[
5^k+3^k=(5+3)\left(5^{k-1}-5^{k-2}\cdot3+\cdots+3^{k-1}\right),
\]
and the second factor is a sum of $k$ odd terms, hence odd. So $5^k+3^k$ is divisible by $8$ but not by $16$. If $5^k+3^k=n^m$, then $n$ is even, and if $2^e$ is the exact power of $2$ dividing $n$, the exact power dividing $n^m$ is $2^{em}$; so $em=3$, which forces $m=3$. Thus $5^k+3^k$ must be a perfect cube.

Now let $k\ge3$ be odd. Then $9\mid3^k$, so $5^k+3^k\equiv5^k\pmod9$. The powers of $5$ modulo $9$ cycle with period $6$: $5,7,8,4,2,1$. Cubes modulo $9$ are only $0,1,8$. For odd $k$, $5^k\equiv5,8,2$ according as $k\equiv1,3,5\pmod6$, so we need $k\equiv3\pmod6$. Then work modulo $7$: since $5^3=125\equiv6$, $3^3=27\equiv6$ and $5^6\equiv3^6\equiv1$, for $k\equiv3\pmod6$ we get
\[
5^k+3^k\equiv6+6=12\equiv5\pmod7 .
\]
But cubes modulo $7$ are only $0,1,6$. So no odd $k\ge3$ works.

Hence the only value is $\boxed{k=1}$ (with $n=2$, $m=3$).
