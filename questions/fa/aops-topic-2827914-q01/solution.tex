Yes, and infinitely many. Let $n\ge2$ be an integer that is not of the form $k^k$ (e.g. $n=2,3,5,\dots$). The function $x\mapsto x^x$ is continuous and increasing for $x\ge1$, with $1^1=1$ and values tending to infinity, so $x^x=n$ has a solution $x>1$.

Suppose $x=\dfrac pq$ in lowest terms. Then $\left(\dfrac pq\right)^p=n^q$, so $p^p=n^qq^p$. If $q>1$, a prime factor of $q$ divides $p^p$ and hence $p$, contradicting $\gcd(p,q)=1$. So $q=1$ and $x=p$ is an integer with $p^p=n$, which we excluded. Hence $x$ is irrational while $x^x=n$ is rational.

Different $n$ give different $x$, so there are $\boxed{\text{infinitely many}}$ such $x$; for example the solution of $x^x=2$, $x\approx1.5596$.
