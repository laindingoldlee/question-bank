Apply the weighted AM-GM inequality to the numbers $c^b$ and $c^{-a}$ with weights $\dfrac {a}{a+b}$ and $\dfrac {b}{a+b}$:
\[\dfrac{a\cdot c^b+b\cdot c^{-a}}{a+b}\ge\left(c^b\right)^{\dfrac {a}{a+b}}\left(c^{-a}\right)^{\dfrac {b}{a+b}}=c^{\dfrac{ab-ab}{a+b}}=c^0=1,\]
with equality only if $c^b=c^{-a}$, i.e. $c^{a+b}=1$, i.e. $c=1$. Since $c\ne1$, the inequality is strict: $ac^b+bc^{-a}>a+b$.

(Alternatively, use $e^t\ge1+t$ with equality only at $t=0$: $c^b=e^{b\ln c}\ge1+b\ln c$ and $c^{-a}\ge1-a\ln c$, so $ac^b+bc^{-a}\ge a+ab\ln c+b-ab\ln c=a+b$, with equality only if $\ln c=0$.)
