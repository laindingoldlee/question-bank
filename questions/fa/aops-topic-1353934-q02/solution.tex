The $k$-th row from the top is $\dbinom{k-1}{0},\dbinom{k-1}{1},\dots,\dbinom{k-1}{k-1}$, whose sum is $2^{k-1}$ (each term counts the subsets of a $(k-1)$-element set of a given size). So the $10$th row carries $2^9=\boxed{512}$ ornaments.
