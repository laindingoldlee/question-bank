Divisibility by $4$: the number $\overline{3B}$ must be a multiple of $4$, so $B=2$ ($32$) or $B=6$ ($36$).

Divisibility by $9$: the digit sum $6+A+B$ must be a multiple of $9$, so $A+B=3$ or $A+B=12$ (as $0\le A+B\le18$).
\begin{itemize}
\item $B=2$: $A=1$ or $A=10$; only $A=1$ is a digit.
\item $B=6$: $A=-3$ or $A=6$; $A=6$ is ruled out because $A\ne B$.
\end{itemize}
So $A=\boxed{1}$ (the number is $12132=4\cdot3033=9\cdot1348$).

(The poster's equation $1+2+A+3+B=9$ misses the possibility $A+B=12$; the answer is still $1$ because that case gives $A=B=6$.)
