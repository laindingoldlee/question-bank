Define a sequence of functions by $g_0(T)=T^2$ and
\[g_{i+1}(T)=g_0^{\,g_i(T)}(T)\qquad\text{for all integers } i\ge0,\]
where $g_0^{\,k}$ means $g_0$ applied $k$ times. For example, $g_1(2)=g_0^{\,4}(2)=g_0(g_0(g_0(g_0(2))))=g_0(g_0(g_0(4)))=g_0(g_0(16))=g_0(256)=65536$. What are the last two digits of $g_{42}(42)$?

$\textbf{(A) } 18 \qquad \textbf{(B) } 24 \qquad \textbf{(C) } 28 \qquad \textbf{(D) } 44 \qquad \textbf{(E) } 56$
