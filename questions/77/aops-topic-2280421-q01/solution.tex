The left side is nonnegative, so we need $2x+2\ge0$, i.e. $x\ge-1$. Squaring,
\[x^2+7=4x^2+8x+4\quad\Longleftrightarrow\quad3x^2+8x-3=0\quad\Longleftrightarrow\quad(3x-1)(x+3)=0,\]
so $x=\dfrac{1}{3}$ or $x=-3$. The value $-3$ violates $x\ge-1$ (it gives $\sqrt{16}=4\ne-4$), while $x=\dfrac{1}{3}$ gives $\sqrt{\dfrac{1}{9}+7}=\dfrac{8}{3}=\dfrac{2}{3}+2$. The only solution is $\boxed{x=\dfrac{1}{3}}$.
