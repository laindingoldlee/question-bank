For $t>0$, $t^3-3t+2=(t-1)^2(t+2)\ge0$, so $t^3+2\ge3t$. From the equations, $3y=x^3+2\ge3x$, $3z=y^3+2\ge3y$ and $3x=z^3+2\ge3z$. So $y\ge x$, $z\ge y$ and $x\ge z$, hence $x=y=z$ with $(x-1)^2(x+2)=0$. The only solution is $\boxed{x=y=z=1}$.
