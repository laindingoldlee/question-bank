Let $v_n$ be the game value when $n$ uses of $S$ remain. Then $v_0=0$, since $T$ chooses $E$ against the forced $I$. For $n>0$, the payoff matrix for $M$, with rows $S,I$ and columns $D,E$, is $\begin{pmatrix}v_{n-1}&1\\1&0\end{pmatrix}$. If $M$ chooses $S$ with probability $p$, the payoffs against $D,E$ are $1-p+p v_{n-1}$ and $p$. Equalizing gives $p=\dfrac{1}{2-v_{n-1}}$; the same mixture for the columns bounds $M$'s payoff above by this value, proving optimality. Thus $v_n=\dfrac{1}{2-v_{n-1}}=\dfrac{n}{n+1}$ by induction. The answer is $\boxed{v_8=\dfrac{8}{9}}$.
