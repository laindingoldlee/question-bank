The root $-1$ is absent, so every term is defined. Apart from the root $1$, the roots pair into distinct inverse pairs $\omega,\omega^{-1}$. Each pair contributes $\dfrac{1}{1+\omega}+\dfrac{1}{1+\omega^{-1}}=1$. There are $1009$ pairs, and the root $1$ contributes $\dfrac{1}{2}$. Thus the sum is $\boxed{\dfrac{2019}{2}}$.
