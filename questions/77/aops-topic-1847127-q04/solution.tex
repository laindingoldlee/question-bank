Solving the system: $5\cdot(5x-4y)+4\cdot(4x+5y)$ gives $41x=35+4k$, and $4\cdot(5x-4y)-5\cdot(4x+5y)$ gives $-41y=28-5k$, i.e.\ $41y=5k-28$. So the solution is integral exactly when $41$ divides both $4k+35$ and $5k-28$. Since
\[
5(4k+35)-4(5k-28)=175+112=287=7\cdot41,
\]
if $41\mid4k+35$ then $41\mid4(5k-28)$ and so $41\mid5k-28$. So we only need $41\mid4k+35$, i.e.\ $4k\equiv-35\equiv6\pmod{41}$. As $4\cdot31=124\equiv1\pmod{41}$, this means $k\equiv6\cdot31=186\equiv22\pmod{41}$.

The numbers $k\equiv22\pmod{41}$ are $\dots,1908,1949,1990,2031,\dots$, and the ones with $1910<k<2010$ are $1949$ and $1990$. So there are $\boxed{2}$ such integers. (For example, $k=1949$ gives $x=191$, $y=237$.)
