If (I) were true, Bob would be the oldest, so Alex would not be the oldest and (II) would also be true; two true statements is impossible. So (I) is false.

If (II) were true (with (I) false), the oldest would be neither Alex nor Bob, so Ciara is the oldest; then Ciara is not the youngest and (III) is also true. Impossible again. So (II) is false, i.e.\ Alex is the oldest.

Hence (III) is the true statement: Ciara is not the youngest, so Bob is. The order is $\boxed{\text{Alex, Ciara, Bob}}$. Check: (I) false, (II) false, (III) true.
