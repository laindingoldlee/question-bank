We need integers $x$ for which $2x-3$ divides $x+9$. Since $2x-3$ is odd, $\gcd(2x-3,2)=1$, so
\[2x-3\mid x+9\iff2x-3\mid2(x+9)\iff2x-3\mid2(x+9)-(2x-3)=21.\]
So $2x-3\in\{\pm1,\pm3,\pm7,\pm21\}$, i.e. $x\in\{2,1,3,0,5,-2,12,-9\}$, and each gives an integer $y$:
\[(2,11),\ (1,-10),\ (3,4),\ (0,-3),\ (5,2),\ (-2,-1),\ (12,1),\ (-9,0).\]
There are $\boxed{8}$ lattice points. (Equivalently, $y=\dfrac12+\dfrac{21}{2(2x-3)}$, a hyperbola with asymptotes $x=\dfrac32$ and $y=\dfrac12$.)

\begin{asy}
usepackage("amsmath");

import graph;

draw(graph(f,-10,1.08),linewidth(0.8));draw(graph(f,1.97,13),linewidth(0.8));
draw((-10,0)--(13,0),gray,Arrow(4));draw((0,-11)--(0,12),gray,Arrow(4));
draw((1.5,-11)--(1.5,12),dashed);draw((-10,0.5)--(13,0.5),dashed);
pair[] P={(-9,0),(-2,-1),(0,-3),(1,-10),(2,11),(3,4),(5,2),(12,1)};
for(pair p:P)dot(p,red);
label("$(-9,0)$",(-9,0),S,fontsize(7pt));label("$(-2,-1)$",(-2,-1),SW,fontsize(7pt));label("$(0,-3)$",(0,-3),W,fontsize(7pt));
label("$(1,-10)$",(1,-10),W,fontsize(7pt));label("$(2,11)$",(2,11),E,fontsize(7pt));label("$(3,4)$",(3,4),E,fontsize(7pt));
label("$(5,2)$",(5,2),NE,fontsize(7pt));label("$(12,1)$",(12,1),N,fontsize(7pt));
label("$x=\dfrac32$",(1.5,-11),S,fontsize(7pt));label("$y=\dfrac12$",(13,0.5),E,fontsize(7pt));
\end{asy}
