A message was encrypted with a toy RSA system whose public key is the exponent $e=17$ and the modulus $n=437$. Each character of the message was replaced by its ASCII code $m$ (for example A is $65$, a is $97$ and ! is $33$), and each code $m$ was encrypted as the number $c$ with $0\le c<437$ and
\[c\equiv m^{17}\pmod{437}.\]
The ciphertext is
\[97\quad44\quad261\quad221\quad114\quad314\quad162\quad317\quad326\quad314\quad162\quad420\quad44\quad261\quad115\quad224 .\]
\begin{enumerate}
\item[(a)] Factor $437$ and find the decryption exponent $d$, the integer with $0<d<\varphi(437)$ and $17d\equiv1\pmod{\varphi(437)}$. Prove that $c^d\equiv m\pmod{437}$ for every $m$ with $0\le m<437$.
\item[(b)] Decrypt the message. (A calculator may be used.)
\end{enumerate}
