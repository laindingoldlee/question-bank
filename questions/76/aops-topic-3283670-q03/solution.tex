The condition is $n^2\ge10^9$, so $n\ge\lceil\sqrt{10^9}\rceil=31623$, while $n\le99999$. The count is $99999-31623+1=\boxed{68377}$. The threshold is checked by $31622^2<10^9<31623^2$.
