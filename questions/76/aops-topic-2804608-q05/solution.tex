Let the circle have length $L$ and the speed be $v$, and let there be $n$ ants. Imagine that colliding ants pass through each other instead: the set of positions occupied at each moment is the same, since a collision just swaps which ant carries which "virtual" trajectory. After time $T=\dfrac Lv$ every virtual ant is back at its start, so the set of occupied positions equals the initial set.

The ants never pass each other, so their cyclic order is preserved. Hence at time $T$ the real ants occupy the initial positions shifted by some fixed cyclic rotation $\sigma$ of the labels. The motion is the same after each period, so at time $kT$ the shift is $\sigma^k$, and at $k=n$ we get $\sigma^n=\text{identity}$: every ant is back at its own starting point. $\blacksquare$
