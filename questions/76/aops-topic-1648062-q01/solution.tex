\textbf{(a)} For $k=3,4,\dots,11$ the values of $2k^2+1$ are
\[
19,\ 33,\ 51,\ 73,\ 99,\ 129,\ 163,\ 201,\ 243,
\]
none of which is a square (each lies strictly between consecutive squares, e.g. $16<19<25$, $225<243<256$). For $k=12$, $2\cdot144+1=289=17^2$. So the least such $k$ is $\boxed{12}$, and the claim fails. (No argument modulo $2,3,4$ or $8$ can work, since a genuine solution exists.)

\textbf{(b)} We need $m^2-2k^2=1$. If $(m,k)$ is a solution in positive integers, so is $(m',k')=(3m+4k,\,2m+3k)$:
\[
(3m+4k)^2-2(2m+3k)^2=9m^2+24mk+16k^2-8m^2-24mk-18k^2=m^2-2k^2=1 .
\]
Starting from $(3,2)$ we get $(17,12)$, $(99,70)$, $(577,408)$, $\dots$, and $k'>k$ each time, so the solutions are all different. Hence $2k^2+1$ is a square for infinitely many $k$ (for example $2\cdot70^2+1=9801=99^2$).
