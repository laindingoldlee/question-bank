$4\equiv-1\pmod5$, so $4^n+1\equiv0\pmod5$ for odd $n$. Modulo $13$, $4^3=64\equiv-1$, so $4^n\equiv-1$ whenever $n\equiv3\pmod6$. All $n=6k+3$ are odd, so they work: $\boxed{n=3,9,15,\dots}$. $\blacksquare$
