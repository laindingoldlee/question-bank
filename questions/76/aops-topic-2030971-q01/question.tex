A student argues: ``A police officer found his hat at some whole number of feet away from him: $1$ foot, $2$ feet, $3$ feet, and so on. There are infinitely many equally likely possibilities, so each has probability $\dfrac{1}{\infty}=0$. Adding them up gives total probability $0$, not $1$. Contradiction!''

Prove that there is no way to assign the \emph{same} probability $p$ to each of the outcomes $1,2,3,\dots$ so that the probabilities add up to $1$, and use this to explain the error in the argument.
