Base and height are $2a,a^2$, so area $a^3=64$ gives $a=4$. The base is $8$ and each equal side is $\sqrt{4^2+16^2}=4\sqrt{17}$. The perimeter is $\boxed{8+8\sqrt{17}}$.
\begin{asy}
usepackage("amsmath");
size(7cm);
pair O=(0,0),A=(-4,16),B=(4,16);path p;for(int i=0;i<=80;++i){real x=-4+i/10.0;p=p--(x,x*x);}draw(p,gray);draw(O--A--B--cycle);label("$(0,0)$",O,S);label("$(-a,a^2)$",A,NW);label("$(a,a^2)$",B,NE);
\end{asy}
