Let $r_n=\dfrac{a_n}{a_{n+1}}>0$. Then
\[r_{n+1}=\dfrac{a_{n+1}}{a_n+a_{n+1}}=\dfrac{1}{1+r_n}.\]
The number $\phi$ satisfies $\phi^2+\phi=1$, i.e. $\phi=\dfrac{1}{1+\phi}$. Therefore
\[\left|r_{n+1}-\phi\right|=\left|\dfrac{1}{1+r_n}-\dfrac{1}{1+\phi}\right|=\dfrac{|r_n-\phi|}{(1+r_n)(1+\phi)}\le\dfrac{|r_n-\phi|}{1+\phi}=\phi\,|r_n-\phi|,\]
using $r_n>0$. Since $0<\phi<1$, we get $|r_n-\phi|\le\phi^{\,n-1}|r_1-\phi|\to0$, so $r_n\to\phi$ for every choice of positive starting values. $\blacksquare$
