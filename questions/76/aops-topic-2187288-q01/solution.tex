First put $k$ pieces into jar $J_k$ for every $k$. This uses
\[1+2+\cdots+63=\dfrac{63\cdot64}{2}=2016\]
pieces, leaving $4$ pieces, which can now be distributed among the $63$ jars without restriction. Conversely, every valid distribution arises in exactly one way like this. By stars and bars, the number of ways to distribute $4$ identical pieces among $63$ jars is
\[\dbinom{4+62}{62}=\dbinom{66}{4}=\dfrac{66\cdot65\cdot64\cdot63}{24}=\boxed{720720}.\]
