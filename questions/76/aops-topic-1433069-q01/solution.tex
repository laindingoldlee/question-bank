The number $1000$ has digit sum $1$, so consider $1$ to $999$ and write each as a three-digit string $\overline{xyz}$ with leading zeros ($0$ itself has digit sum $0$, so including it changes nothing). We need
\[
x+y+z=4,\qquad x,y,z\ge0 ,
\]
and no digit can exceed $9$ automatically. By stars and bars the number of solutions is $\dbinom{4+2}{2}=\boxed{15}$.
