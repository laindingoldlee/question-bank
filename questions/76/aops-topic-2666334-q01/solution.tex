If $n$ has $k$ digits, then $n=\dfrac59\left(10^k-1\right)$. Since $2003$ is a prime not dividing $5\cdot9$, the condition is $2003\mid10^k-1$. (Such $k$ exist, e.g. $k=2002$ by Fermat's little theorem.) For $k\le6$, the numbers $10^k-1$ are $9$, $99$, $999$, $9999$, $99999$, $999999$, whose prime factors are all below $2003$ ($999999=3^3\cdot7\cdot11\cdot13\cdot37$, $99999=3^2\cdot41\cdot271$, $9999=3^2\cdot11\cdot101$). So $k\ge7$, and $n$ ends in $555555$.

Let $q=\dfrac{n}{2003}$. Then $2003q\equiv555555\pmod{10^6}$. Because $\gcd(2003,10)=1$, $2003$ is invertible mod $10^6$, so this congruence determines $q$ mod $10^6$ uniquely. Since
\[2003\cdot395185=791555555\equiv555555\pmod{10^6},\]
the last six digits of $\dfrac n{2003}$ are $\boxed{395185}$, whichever valid $n$ is chosen.
