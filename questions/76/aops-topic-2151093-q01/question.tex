Start with a nonzero integer $n$ and repeatedly apply the rule: if the current number is even, divide it by $2$; if it is odd, replace it by $3$ times itself plus $1$. Prove or disprove: for \emph{every} nonzero integer $n$, positive or negative, the resulting sequence eventually contains the number $1$.
