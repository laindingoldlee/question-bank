Alice's calculator is defective: it shows only the digit $4$, and every other digit appears as $*$. Fill in the stars so that the multiplication
\[
\begin{array}{r}
**4\\
\times\ \ **\\
\hline
44*4
\end{array}
\]
is correct; that is, find a three-digit number ending in $4$ and a two-digit number whose product is $44d4$ for some digit $d$, where every digit shown as $*$ is different from $4$. Find all solutions.
