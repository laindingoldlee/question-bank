A cyclic $ABCD$ is called good if $BD^2 - AB^2 = CD^2 - AC^2$. Let $ABCD$ be a good quadrilateral with $AB = 5$, $AD = 2$, and $BC = 5$. If $\sin^2(\angle ACD)$ can be written as $\dfrac{m}{n}$, where $m$ and $n$ are relatively prime positive integers, what is $m + n$?

$\textbf{(A) } 29 \qquad\textbf{(B) } 121 \qquad\textbf{(C) } 126 \qquad\textbf{(D) } 128 \qquad\textbf{(E) } 129$
