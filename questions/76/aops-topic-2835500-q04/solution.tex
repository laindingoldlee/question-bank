Since $n^2-c$ depends only on $|n|$, assume $n\ge0$. Suppose $p=n^2-k^2=(n-k)(n+k)$ is prime. Then $n>k$, so both factors are positive and $n-k<n+k$. A prime has only the factorisation $1\cdot p$, so $n-k=1$ and $p=n+k=2k+1$.

So $n^2-c$ can be prime only for $n=\pm(k+1)$, giving at most one prime, $2k+1$. (For $k=0$ there are none, since $n^2$ is never prime.) In particular there are finitely many. $\blacksquare$
