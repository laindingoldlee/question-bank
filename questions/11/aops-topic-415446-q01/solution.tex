The endpoints have no digit $5$. Every integer strictly between them has the form $\overline{1abcdef}$, where the six digits $a,\dots,f$ are arbitrary ($000000$ to $999999$, excluding only $000000$, which has no $5$). So we count strings of $6$ digits with at least four $5$s:
\begin{itemize}
\item exactly four $5$s: $\dbinom64\cdot9^2=15\cdot81=1215$;
\item exactly five $5$s: $\dbinom65\cdot9=54$;
\item six $5$s: $1$.
\end{itemize}
The total is $1215+54+1=\boxed{1270}$.
