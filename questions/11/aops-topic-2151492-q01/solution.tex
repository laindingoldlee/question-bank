\textbf{(a)} For an integer $x\ge0$, the only prime factor of $2^x$ is $2$, so $2^x$ is not divisible by $5$, and hence not by $10$. For an integer $x<0$, $0<\dfrac{2^x}{10}<\dfrac{1}{10}$, which is not an integer. So no integer $x$ works.

\textbf{(b)} Since $2^x>0$, the integer $\dfrac{2^x}{10}$ would have to be a positive integer $m\ge1$. Then $2^x=10m\ge10$, so $x=\log_2(10m)\ge\log_2 10$, and $x=\log_2 10$ gives $\dfrac{2^x}{10}=1$. So the smallest real $x$ is
\[x=\boxed{\log_2 10}\approx3.32 .\]
