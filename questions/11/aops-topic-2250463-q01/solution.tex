\textbf{(a)} Every hand is a uniformly random set of $4$ of the $52$ cards. A given hand has no spade with probability
\[\dfrac{\dbinom{39}{4}}{\dbinom{52}{4}}=\dfrac{82251}{270725},\]
so it contains at least one spade with probability $1-\dfrac{82251}{270725}=\dfrac{188474}{270725}$. By linearity of expectation (summing the indicator of ``hand $i$ has a spade'' over the $13$ hands), the expected number of hands with at least one spade is
\[13\cdot\dfrac{188474}{270725}=\boxed{\dfrac{188474}{20825}}\approx9.05,\]
using $270725=13\cdot20825$.

\textbf{(b)} A hand holds at most $4$ spades, so the $13$ spades occupy at least $\left\lceil\dfrac{13}{4}\right\rceil=4$ hands; this happens when three hands consist of spades only and a fourth hand holds the last spade. At most all $13$ hands contain a spade, which happens when every hand gets exactly one spade. So the number is between $\boxed{4}$ and $\boxed{13}$, and both extremes occur.
