\textbf{One of the primes is $2$.} If $p$ and $q$ are both odd, then $p^q+q^p$ is even and greater than $2$, so it is not prime. If $p=q=2$, then $p^q+q^p=8$ is not prime. So exactly one of them is $2$; by symmetry take $p=2$ and $q$ an odd prime, so the number is $2^q+q^2$.

\textbf{$q=3$ works:} $2^3+3^2=17$ is prime.

\textbf{$q>3$ fails.} Then $3\nmid q$, so $q^2\equiv1\pmod 3$. Since $q$ is odd, $2^q\equiv(-1)^q=-1\pmod 3$. Hence $2^q+q^2\equiv0\pmod3$, and as $2^q+q^2>3$, it is not prime.

So the pairs are $\boxed{(p,q)=(2,3)\text{ and }(3,2)}$, both giving $17$.
