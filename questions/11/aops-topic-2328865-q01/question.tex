On a test with $15$ algebra problems, Joe enters each problem into a computer algebra system, which would always give the right answer, but Joe mistypes each problem independently with probability $25\%$, and then his answer is wrong. Bob solves each problem by hand and makes an error on each problem independently with probability $10\%$. Let $j$ and $k$ be the expected numbers of problems that Joe and Bob, respectively, get right. Find $j-k$.
