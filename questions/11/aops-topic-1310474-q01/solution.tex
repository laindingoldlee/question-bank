Solving, $\dfrac{1}{x}=\dfrac{3}{2}-c$. If $c\ne\dfrac{3}{2}$, then $x=\dfrac{1}{\dfrac{3}{2}-c}=\dfrac{2}{3-2c}$ is a solution. If $c=\dfrac{3}{2}$, we would need $\dfrac{1}{x}=0$, which is impossible. So the only such value is $\boxed{c=\dfrac{3}{2}}$.
