We want $N^2$ close to $\dfrac{2017}{3}\approx672.3$. Since $25^2=625$ and $26^2=676$, compare $3\cdot625=1875$, which is $142$ below $2017$, with $3\cdot676=2028$, which is $11$ above. Values of $N$ below $25$ or above $26$ are farther still, since $3N^2$ moves away from $2017$. So $N=\boxed{26}$.
