Write each numerator as $2k$: the numerators are $2\cdot2,\ 2\cdot3,\ 2\cdot4,\ 2\cdot5,\ 2\cdot6,\ 2\cdot7$. So the product is
\[
\dfrac{2^6\,(2\cdot3\cdot4\cdot5\cdot6\cdot7)}{3\cdot4\cdot5\cdot6\cdot7\cdot8}=\dfrac{2^6\cdot2}{8}=\boxed{16}.
\]
