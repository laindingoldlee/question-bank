Set $u=x^2$. The common value is positive, so $n<u<2024$, and the equation becomes $(2024-u)(u-n)=1$. This concave quadratic is zero at the two endpoints and has maximum $\dfrac{(2024-n)^2}{4}$. Exactly one admissible $u$, and hence exactly two values of $x$, occurs only when this maximum is 1. Thus $n=2022$ and $u=2023=17^2\cdot7$. Hence $|a|=17\sqrt7$ and $\boxed{jk=119}$.
