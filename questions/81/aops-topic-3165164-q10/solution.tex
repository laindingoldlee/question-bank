Every root $\zeta$ of $P$ is a nontrivial $36$th root of unity. A common root must satisfy $\zeta^{j-i}=-1$. If $j-i$ is odd, $x+1$ divides both polynomials. If $j-i\equiv2\pmod4$, $x^2+1$ divides both. If $4\mid j-i$, then $(\zeta^{j-i})^9=1$, because $36\mid9(j-i)$, which rules out $\zeta^{j-i}=-1$. Thus exactly the pairs in different residue classes modulo four work. There are $\binom{36}{2}$ total pairs, while the four residue classes each contain nine exponents. The answer is $\binom{36}{2}-4\binom92=630-144=\boxed{486}$.
