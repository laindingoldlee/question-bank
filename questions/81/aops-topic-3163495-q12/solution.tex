Write the common ratio in lowest terms as $\dfrac{v}{u}>1$. The three integers must be $ku^2,kuv,kv^2$, where $k\ge1$, $1\le u<v$, and $\gcd(u,v)=1$. Thus $v\le4$, and for each $v$ there are $\varphi(v)\lfloor\dfrac{20}{v^2}\rfloor$ choices. The count is $1\cdot5+2\cdot2+2\cdot1=\boxed{11}$.
