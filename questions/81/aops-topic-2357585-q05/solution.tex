The sum is $\dfrac{x(x+1)}{2}$, so we need $x(x+1)<20000$. Since $\sqrt{20000}\approx141.4$, test values near $141$:
\[140\cdot141=19740<20000,\qquad141\cdot142=20022>20000.\]
So the largest $x$ is $\boxed{140}$ (the sum is $9870$, and adding $141$ gives $10011$).
