Let $X_k$ be the radical that starts with $10^{2^k}$ (so the requested value is $X_0$, with first term $10$). Then $X_k^2=10^{2^k}+X_{k+1}$. Write $X_k=10^{2^{k-1}}y_k$; then
\[10^{2^k}y_k^2=10^{2^k}+10^{2^k}y_{k+1},\quad\text{so}\quad y_k^2=1+y_{k+1}.\]
All $y_k$ satisfy the same relation, and the consistent value is the positive root of $y^2=1+y$, namely $\varphi=\dfrac{1+\sqrt5}2$ (numerically, the truncations converge to it). So
\[X_0=\sqrt{10}\,\varphi=\boxed{\dfrac{\sqrt{10}+5\sqrt2}2}\approx5.1167.\]
