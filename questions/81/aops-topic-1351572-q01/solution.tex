There are $11$ terms, the odd numbers from $1$ to $21$. Pair the first with the last, the second with the second-to-last, and so on: $1+21=3+19=5+17=7+15=9+13=22$, which is $5$ pairs, and the middle term $11$ is left over. So the sum is $5\cdot22+11=121$.

Another way: the sum of the first $n$ odd numbers is $n^2$, because adding the odd number $2n-1$ to an $(n-1)\times(n-1)$ square of dots completes an $n\times n$ square (an L-shaped border of $2n-1$ dots). Here $n=11$, so the sum is $11^2=\boxed{121}$.
