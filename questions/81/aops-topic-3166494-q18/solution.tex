For any power $5^j$, the factor is divisible by $5^j$ exactly when $i\equiv2021^{-1}\pmod{5^j}$. For moduli $5,25,125,625$, the least positive residues are $1,6,6,381$, giving $405,81,17,3$ eligible indices up to $2021$. For modulus $3125$ the residue is $2256$, already beyond the range, and any higher-power solution would also solve this congruence, so there are none. Hence the exponent of five is $405+81+17+3=506$. The $1011$ odd indices each give an even factor, so there are more than enough twos. The number of trailing zeros is $\boxed{506}$.
