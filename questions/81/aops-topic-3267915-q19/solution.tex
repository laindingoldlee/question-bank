Conditioned on distinctness, each four-element subset is equally likely. Map the grades to $1,\ldots,10$ by subtracting $69$. The five gaps before, between, and after the four selected integers contain the six unchosen integers; by symmetry the expected size of each gap is $\dfrac{6}{5}$. The largest selected integer is $10$ minus the last gap, so its expectation is $10-\dfrac{6}{5}=\dfrac{44}{5}$. Adding $69$ gives $\boxed{\dfrac{389}{5}}$. More explicitly, the gap vectors are all nonnegative five-tuples summing to six, in bijection with the subsets, proving the symmetry used.
