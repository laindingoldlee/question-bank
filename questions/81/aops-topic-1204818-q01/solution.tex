The left inequality: $\dfrac{2}{3}t-1<t+7\iff-8<\dfrac{1}{3}t\iff t>-24$. The right inequality: $t+7\le-2t+15\iff3t\le8\iff t\le\dfrac{8}{3}$. So the solution set is $\boxed{\left(-24,\dfrac{8}{3}\right]}$. (The posted answer $[2,-23]$ is not even a valid interval.)
