Factoring,
\[
\dfrac{x^2+x-6}{x^2+7x-18}=\dfrac{(x+3)(x-2)}{(x+9)(x-2)}=\dfrac{x+3}{x+9}\qquad(x\ne2,-9).
\]
The coefficients are $1,3$ and $1,9$, so $a=14=2\cdot7$, which has $\boxed{4}$ positive divisors ($1,2,7,14$).
