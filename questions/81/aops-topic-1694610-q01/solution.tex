A square with this property has at least $4$ digits.

\textbf{Four digits.} It would use each of $1,2,5,6$ exactly once. A square cannot end in $2$. If it ends in $5$, it ends in $25$, so it is $1625$ or $6125$; but $40^2=1600<1625<1681=41^2$ and $78^2=6084<6125<6241=79^2$. If it ends in $1$ or $6$, it is one of
\[
2561,2651,5261,5621,6251,6521,\quad 1256,1526,2156,2516,5126,5216,
\]
and each lies strictly between consecutive squares:
$50^2<2561<51^2$, $51^2<2651<52^2$, $72^2<5261<73^2$, $74^2<5621<75^2$, $79^2<6251<80^2$, $80^2<6521<81^2$, $35^2<1256<36^2$, $39^2<1526<40^2$, $46^2<2156<47^2$, $50^2<2516<51^2$, $71^2<5126<72^2$, $72^2<5216<73^2$. So there is no such four-digit square.

\textbf{Five digits.} The smallest five-digit square with only these digits must start with $1$. The squares $100^2,\dots,124^2$ are
\[
10000,10201,10404,10609,10816,11025,11236,11449,11664,11881,12100,12321,12544,
\]
\[
12769,12996,13225,13456,13689,13924,14161,14400,14641,14884,15129,15376,
\]
and each contains a digit outside $\{1,2,5,6\}$. Next, $125^2=15625$ uses exactly the digits $1,5,6,2,5$. So the answer is $\boxed{15625}$.
