If the intersections are $P,Q$, triangles $ABP,ABQ$ are equilateral. Each common segment is a $120^\circ$ sector minus an isosceles triangle. The common area is $2(\dfrac{120}{360}\pi\cdot100-\dfrac{1}{2}\cdot100\sin120^\circ)=\dfrac{200\pi}{3}-50\sqrt3\approx\boxed{122.8}$ square units.
\begin{asy}
usepackage("amsmath");
size(7cm);
pair A=(0,0),B=(10,0),P=(5,5sqrt(3)),Q=(5,-5sqrt(3));draw(circle(A,10));draw(circle(B,10));draw(A--P--B--Q--cycle,dashed);draw(A--B,dashed);label("$A$",A,W);label("$B$",B,E);label("$P$",P,N);label("$Q$",Q,S);
\end{asy}
