$\overline{AABB}=1100A+11B=11(100A+B)$. For a square, $11\mid100A+B$. Since $100A+B\equiv A+B\pmod{11}$ and $1\le A+B\le18$, $A+B=11$, so $100A+B=99A+11=11(9A+1)$ and $\overline{AABB}=11^2(9A+1)$. We need $9A+1$ to be a square with $2\le A\le9$: $9A+1\in\{19,28,37,46,55,64,73,82\}$, and only $64$ ($A=7$) works. So yes: $\boxed{7744=88^2}$ is the only one.
