The answer is $\boxed{2050}$. The diagram lists all thirteen hexomino types that fit in a strip of height two, up to rotations and reflections. Any other hexomino has width and height at least three in every orientation and cannot occur. The straight hexomino and the $2\times3$ rectangle each tile uniquely. Two other types, B and E in the diagram, each give $2^{10}=1024$ tilings; all remaining types give zero. Here is an exact recurrence that both verifies this classification and the counts, without assumptions about where tile boundaries occur. For a fixed type, let $F(U)$ count completions after the cells in $U$ are occupied. Set $F(\text{whole board})=1$. Otherwise choose the first empty cell in column order, bottom cell first, and sum $F(U\cup T)$ over every distinct translated, rotated or reflected copy $T$ of that type which contains that cell, stays in the board, and avoids $U$. This recurrence terminates because six cells are added each time, and counts each partition once because its tile covering the first empty cell is unique. Applying it gives the displayed counts, summing to $1+1024+1024+1=2050$. The thirteen types themselves are obtained by starting with one cell, adjoining edge-neighbour cells until there are six, identifying rotations/reflections, and retaining the types that fit in two rows.
