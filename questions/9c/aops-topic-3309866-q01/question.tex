For each $k=1,\ldots,9$, let $A_k$ be the base-$k$ numeral of length $k$ whose digits alternate $1,0,1,0,\ldots$ from the left. Set $A_1=1$ by convention. Find the last two digits of $A_1+\cdots+A_9$.
