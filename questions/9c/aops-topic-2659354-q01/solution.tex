\emph{$n$ not a perfect square.} Then $\sqrt n$ is irrational, and $\sqrt n\cdot\dfrac{n-3}{n-48}$ is irrational unless $n-3=0$. For $n=3$ the value is $0$, an integer.

\emph{$n=k^2$ with $k\ge0$.} $k=0$ gives $0$. For $k\ge1$ we need $k^2-48\mid k\left(k^2-3\right)=k\left(k^2-48\right)+45k$, i.e. $k^2-48\mid45k$. Then also $k^2-48\mid45k\cdot k=45\left(k^2-48\right)+2160$, so $k^2-48$ divides $2160=2^4\cdot3^3\cdot5$.
\begin{itemize}
\item $1\le k\le6$: $k^2-48\in\{-47,-44,-39,-32,-23,-12\}$; only $-12$ divides $2160$, but $k=6$ gives $\dfrac{45\cdot6}{12}$, not an integer.
\item $k\ge7$: $d=k^2-48$ is a positive divisor of $2160$ with $d+48$ a perfect square. Among the divisors $1,2,3,4,5,6,8,9,10,12,15,16,18,20,24,27,30,36,40,45,48,54,60,72,80,90,108,120,135,144,180,216,240,270,360,432,540,720,1080,2160$, adding $48$ gives a square only for $d=1$ ($k=7$) and $d=16$ ($k=8$). $k=8$ fails since $16\nmid360$; $k=7$ gives $\dfrac{7\cdot46}{1}=322$.
\end{itemize}
So $n\in\boxed{\{0,\ 3,\ 49\}}$, giving the values $0$, $0$ and $322$.
