Pair the factors so that the constant terms agree:
\[
(x+2)(x+12)=x^2+14x+24,\qquad(x+3)(x+8)=x^2+11x+24 .
\]
The number $x=0$ is not a solution (the left side would be $576$). Dividing by $x^2$,
\[
\left(x+\dfrac{24}{x}+14\right)\left(x+\dfrac{24}{x}+11\right)=4 .
\]
Put $t=x+\dfrac{24}{x}$: $(t+14)(t+11)=4$, i.e.\ $t^2+25t+150=0$, so $(t+10)(t+15)=0$.
\begin{itemize}
\item $t=-10$: $x^2+10x+24=0$, so $x=-4$ or $x=-6$.
\item $t=-15$: $x^2+15x+24=0$, so $x=\dfrac{-15\pm\sqrt{225-96}}{2}=\dfrac{-15\pm\sqrt{129}}{2}$.
\end{itemize}
The solutions are $\boxed{x=-4,\ x=-6,\ x=\dfrac{-15\pm\sqrt{129}}{2}}$.
