Let $k=\lfloor n\rfloor$, so $k\le n<k+1$ and $kn=3$; in particular $k\ne0$.
\begin{itemize}
\item $k\ge1$: $kn\in\left[k^2,k^2+k\right)$, which contains $3$ for no integer $k\ge1$ (the intervals are $[1,2)$, $[4,6)$, \dots).
\item $k\le-1$: $n$ is negative and $kn\in\left(k^2+k,k^2\right]$; this contains $3$ only for $k=-2$, the interval $(2,4]$.
\end{itemize}
So $k=-2$ and $n=-\dfrac32=\boxed{-1.5}$.
