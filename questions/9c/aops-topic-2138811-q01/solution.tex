Subtracting the equations,
\[a-b=\dfrac{1}{b}-\dfrac{1}{a}=\dfrac{a-b}{ab},\qquad\text{so}\qquad(a-b)\left(1-\dfrac{1}{ab}\right)=0 .\]
If $ab=1$, then $\dfrac{1}{b}=a$ and the first equation becomes $a=1+a$, which is impossible. So $a=b$, and $a=1+\dfrac{1}{a}$, that is, $a^2-a-1=0$, giving $a=\dfrac{1\pm\sqrt5}{2}$. Both values are nonzero and work, so there are two ordered pairs:
\[\boxed{\left(\dfrac{1+\sqrt5}{2},\ \dfrac{1+\sqrt5}{2}\right)\ \text{ and }\ \left(\dfrac{1-\sqrt5}{2},\ \dfrac{1-\sqrt5}{2}\right)}.\]
