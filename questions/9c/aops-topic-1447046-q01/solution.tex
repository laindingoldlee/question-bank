\textbf{(a)} The argument assumes that a real number has only one decimal expansion, so that different strings of digits must name different numbers. That is not true for decimals ending in an infinite string of $9$s: for instance $\dfrac{1}{2}$ can be written $0.5$ and also $0.4999\ldots$. The digits do not decide the matter; we have to compare the values.

\textbf{(b)} By definition, $x$ is the limit of the partial values $0.9$, $0.99$, $0.999$, $\dots$, so for every $n$ the number $x$ is at least $0.\underbrace{99\ldots9}_{n}=1-10^{-n}$, and $x\le1$. Hence
\[
0\le 1-x\le10^{-n}\qquad\text{for every } n\ge1 .
\]
If $1-x$ were positive, we could choose $n$ with $10^{-n}<1-x$, a contradiction. So $1-x=0$, that is, $x=1$. $\blacksquare$

Two shorter routes give the same thing. The teacher's argument: $\dfrac{1}{3}=0.333\ldots$, and multiplying by $3$ gives $1=0.999\ldots$. Or: $10x=9.999\ldots$, so $10x-x=9$ and $x=1$. Both use arithmetic with infinite decimals, which is justified by the limit argument above; equivalently $x=\displaystyle\sum_{k\ge1}\dfrac{9}{10^k}=\dfrac{\dfrac{9}{10}}{1-\dfrac{1}{10}}=1$ as a geometric series.
