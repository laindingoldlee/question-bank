Since $n>0$ and $\dfrac{n}{n+k}>0$, we have $n+k>0$, so we may clear denominators:
\[\dfrac{8}{15}<\dfrac{n}{n+k}\iff 8(n+k)<15n\iff 8k<7n,\qquad \dfrac{n}{n+k}<\dfrac{7}{13}\iff 13n<7(n+k)\iff 6n<7k.\]
So the condition is $\dfrac{6n}{7}<k<\dfrac{7n}{8}$, i.e. $48n<56k<49n$. We need exactly one multiple of $56$ strictly between $48n$ and $49n$; this open interval has length $n$.

If $n\ge113$, let $56m$ be the smallest multiple of $56$ greater than $48n$. Then $56m\le48n+56$, so $56(m+1)\le48n+112<48n+n=49n$, and there are at least two values of $k$.

For $n=112$ the interval is $(5376,5488)=(56\cdot96,\,56\cdot98)$, which contains exactly one multiple of $56$, namely $56\cdot97$. So $k=97$ is the unique value (indeed $\dfrac{8}{15}<\dfrac{112}{209}<\dfrac{7}{13}$).

The answer is $\boxed{112}$.
