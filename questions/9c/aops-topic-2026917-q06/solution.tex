One mouse eats $\dfrac{6}{4\cdot15}=\dfrac{1}{10}$ block per minute, so $3$ mice eat $\dfrac{3}{10}$ block per minute. Eating $18$ blocks takes
\[18\div\dfrac{3}{10}=\boxed{60}\ \text{minutes}.\]
