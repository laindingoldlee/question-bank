Since $b>0$, we have $\sqrt b>0$, so
\[\sqrt a+\sqrt b=\left(\sqrt a-\sqrt b\right)+2\sqrt b=21+2\sqrt b>21 .\]
This rules out $14$, $7$ and $21$. On the other hand every value $S>21$ is possible: take $\sqrt a=\dfrac{S+21}{2}$ and $\sqrt b=\dfrac{S-21}{2}>0$. For $S=26$ this gives $\sqrt a=23.5$ and $\sqrt b=2.5$, that is, $a=552.25$ and $b=6.25$. So the answer is $\boxed{\text{(d) } 26}$.
