A base-$10$ number is a multiple of $4$ exactly when its last two digits form a multiple of $4$. The base-$5$ digits are $0$ to $4$, so the last two base-$5$ digits, read in base $10$, must be one of
\[
00,\ 04,\ 12,\ 20,\ 24,\ 32,\ 40,\ 44
\]
(the two-digit multiples of $4$ with both digits at most $4$). In base $5$ these endings have values $0,4,7,10,14,17,20,24$. A number $n$ qualifies exactly when $n\bmod25$ is one of these eight values (for $n<25$ the leading zero is harmless: $04$ is just $4$).

So the qualifying numbers are, in order,
\[
4,7,10,14,17,20,24,\ 25,29,32,35,39,42,45,49,\ 50,54,57,\ldots
\]
($0$ is excluded as not positive, and each block of $25$ contributes $8$). The $18$th is $\boxed{57}$. (Check: $57=212_5$, and $212=4\cdot53$.)
