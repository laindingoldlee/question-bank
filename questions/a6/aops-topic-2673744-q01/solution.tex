For a five-digit $n$, $10^8\le n^2<10^{10}$, so $n^2$ has $9$ or $10$ digits.
\begin{itemize}
\item $9$ digits: $271820000\le n^2\le271829999$. Now $16486^2=271788196$ is too small, $16487^2=271821169$ works and $16488^2=271854144$ is too large.
\item $10$ digits: $2718200000\le n^2\le2718299999$. Now $52136^2=2718162496$ is too small, $52137^2=2718266769$ works and $52138^2=2718371044$ is too large.
\end{itemize}
(The candidates come from $\sqrt{2.7182\cdot10^8}\approx16487.0$ and $\sqrt{2.7182\cdot10^9}\approx52136.4$.) So $n\in\boxed{\{16487,\ 52137\}}$.
