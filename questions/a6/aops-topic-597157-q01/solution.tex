The number is $N=111\ldots1_2$ ($15$ ones) $=2^{15}-1$. Then
\[
3N=3\cdot2^{15}-3 .
\]
Since $2^{16}=2\cdot2^{15}<3\cdot2^{15}-3<4\cdot2^{15}=2^{17}$, the number $3N$ satisfies $2^{16}\le3N<2^{17}$, so it has $\boxed{17}$ binary digits. (Indeed $3N=98301=10111111111111101_2$.)
