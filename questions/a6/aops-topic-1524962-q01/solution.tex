First convert the final speed to metres per second:
\[
300\ \dfrac{\text{km}}{\text{h}}=\dfrac{300\cdot1000\text{ m}}{3600\text{ s}}=\dfrac{250}{3}\ \dfrac{\text{m}}{\text{s}}\approx83.33\ \dfrac{\text{m}}{\text{s}}.
\]
The speed changes from $0$ to $\dfrac{250}{3}$ m/s in $30$ s, so the average acceleration is
\[
\dfrac{\dfrac{250}{3}}{30}=\dfrac{25}{9}\approx2.78\ \dfrac{\text{m}}{\text{s}^2},
\]
which is $\boxed{2.8}$ to the nearest tenth.
