Let there be $s$ small and $l$ large chips, so $s+l=54$ and $s-l=p$ is prime. Then
\[
l=\dfrac{54-p}{2}.
\]
To make $l$ as large as possible we want the smallest prime $p$. The smallest prime is $p=2$, which gives $s=28$, $l=26$, and indeed $28-26=2$ is prime. (Here $p$ must be even anyway, because $s-l=54-2l$ is even, so $p=2$ is in fact the only possibility.)

The greatest possible number of large chips is $\boxed{26}$.
