Use the ordinary Fibonacci sequence $ F_0=0,F_1=1 $, so $ a_n=F_{n+2}$. Modulo $ 7 $, the terms from $ F_0 $ through $ F_{17}$ are \[0,1,1,2,3,5,1,6,0,6,6,5,4,2,6,1,0,1.\]The pair $(F_{16},F_{17})$ repeats $(0,1)$, so determinism of the recurrence makes these residues repeat every sixteen terms. In each such block exactly two terms are zero. Shifting the initial index changes any count by only a bounded amount, so the limiting proportion is $\boxed{\dfrac{2}{16}=\dfrac{1}{8}}$.
