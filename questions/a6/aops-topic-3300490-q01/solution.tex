For every integer $k\ge2$, one step takes $k^2$ to $k^2-k=k(k-1)$. Since $(k-1)^2\le k(k-1)<k^2$, the next step removes $k-1$, leaving $(k-1)^2$. Thus each pair of steps decreases the square root of a square state by one. Beginning at $100^2$ and ending at $1^2$ takes $2(100-1)=\boxed{198}$ steps. Intermediate values exceed their following square state, so none equals $1$ earlier.
