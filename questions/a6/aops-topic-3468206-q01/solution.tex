(a) Each sheet has four independent choices, giving $\boxed{4^{100}}$. (b) If the occupancy numbers are $n_1,n_2,n_3,n_4\ge4$ with sum 100, the number is the multinomial coefficient $\dfrac{100!}{n_1!n_2!n_3!n_4!}$. Thus an exact answer is\[\boxed{\sum_{n_1=4}^{88}\ \sum_{n_2=4}^{92-n_1}\ \sum_{n_3=4}^{96-n_1-n_2}\dfrac{100!}{n_1!n_2!n_3!(100-n_1-n_2-n_3)!}}.\]The outer upper limit leaves four for each other envelope; the inner limits enforce the same requirement. Every valid distribution has one unique occupancy vector and is counted exactly once.
