Jack and Jill run $10$ km. They start at the same point, run $5$ km up a hill, and return to the starting point by the same route. Jack has a $10$ minute head start and runs at the rate of $15$ km per hour uphill and $20$ km per hour downhill. Jill runs $16$ km per hour uphill and $22$ km per hour downhill. How far from the top of the hill are they when they pass each other going in opposite directions?
