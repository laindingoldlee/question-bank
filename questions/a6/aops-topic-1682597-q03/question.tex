An integer $c$ is \emph{square-friendly} if for every integer $m$ the number $m^2+18m+c$ is a perfect square. (For example, $6$ is not square-friendly, because for $m=2$ we get $46$.) Show that exactly one square-friendly integer exists:
\begin{enumerate}
\item[(a)] find a square-friendly integer and prove that it is square-friendly;
\item[(b)] prove that there cannot be two different square-friendly integers.
\end{enumerate}
