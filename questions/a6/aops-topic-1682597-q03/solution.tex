(a) $c=81$ works: $m^2+18m+81=(m+9)^2$ is a perfect square for every integer $m$.

(b) Let $c$ be square-friendly and put $d=c-81$, so that $m^2+18m+c=(m+9)^2+d$. We show $d=0$. Suppose $d\ne0$ and let $k=|d|+1\ge2$; take $m=k-9$, so $(m+9)^2+d=k^2+d$ must be a perfect square.
\begin{itemize}
\item If $d>0$: $k^2<k^2+d<k^2+2k+1=(k+1)^2$, because $d<2k+1$.
\item If $d<0$: $(k-1)^2=k^2-2k+1<k^2+d<k^2$, because $|d|=k-1<2k-1$.
\end{itemize}
In both cases $k^2+d$ lies strictly between two consecutive squares, so it is not a perfect square. This contradiction shows $d=0$, i.e.\ $c=81$. So $\boxed{81}$ is the only square-friendly integer. $\blacksquare$

(The poster's argument for (b) assumes that $m^2+18m+c$ must equal $(m+a)^2$ as a polynomial; that does not follow from its values being squares, and the squeeze between consecutive squares supplies the missing step.)
