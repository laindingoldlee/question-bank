Let $K,L$ count knights and knaves. Each knight has exactly one knave friend, so there are exactly $K$ friendships joining the two groups. Each knave's false statement means that knave has at least one knight friend, so these same cross-group friendships number at least $L$. Therefore $K\ge L$. Since $K+L=2023$ is odd, equality is impossible. Thus $\boxed{K>L}$: there are more knights.
