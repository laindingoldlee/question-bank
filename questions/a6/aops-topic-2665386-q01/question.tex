Find the number of sets $A$ that satisfy all three conditions:
\begin{itemize}
\item $A$ is a set of two positive integers;
\item each of the numbers in $A$ is at least $22\%$ of the other number;
\item $A$ contains the number $30$.
\end{itemize}
