Write $A=\{30,x\}$ with $x$ a positive integer, $x\ne30$ (a set of two numbers has two different elements). The conditions are
\[x\ge0.22\cdot30=6.6\qquad\text{and}\qquad30\ge0.22x,\ \text{i.e.}\ x\le\dfrac{30}{0.22}=136.36\ldots\]
So $7\le x\le136$, which gives $130$ integers, and removing $x=30$ leaves $\boxed{129}$ sets.

(The count $130$ comes from forgetting that $x=30$ would give the one-element set $\{30\}$.)
