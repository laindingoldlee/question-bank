Repeated multiplication by 7 produces digits and remainders: $ 0.3\mapsto2+0.1 $, $ 0.1\mapsto0+0.7 $, $ 0.7\mapsto4+0.9 $, $ 0.9\mapsto6+0.3 $. The remainder returns to its start, so $\boxed{(0.\overline{2046})_7}$. As a check, the block value is $ 2\cdot7^3+4\cdot7+6=720 $ and the repeating value is $\dfrac{720}{7^4-1}=\dfrac{3}{10}$.
