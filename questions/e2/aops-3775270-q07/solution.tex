Along the line, $AC+BD=AD+BC$. Therefore $BC=10+15-22=\boxed3$ metres.
\begin{asy}
import graph;
usepackage("amsmath");
import geometry;
size(7cm);
pair A=(0,0),B=(7,0),C=(10,0),D=(22,0);draw(A--D);dot(A);dot(B);dot(C);dot(D);label("$A$",A,(0,-1));label("$B$",B,(0,-1));label("$C$",C,(0,-1));label("$D$",D,(0,-1));
\end{asy}
