All quantities are positive, and raising to the $n$th power preserves inequalities between positive numbers, so the condition is equivalent to $3^n<100<5^n$.
\begin{itemize}
\item $3^n<100$: $3^4=81<100<243=3^5$, so $n\le4$.
\item $100<5^n$: $5^2=25<100<125=5^3$, so $n\ge3$.
\end{itemize}
So $n=3$ or $n=4$: there are $\boxed{2}$ such integers.
