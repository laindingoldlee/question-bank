The triangle angles are $B=30^\circ,C=102^\circ,A=48^\circ$. Put $\alpha=\angle DAB$, so $\angle DAC=48^\circ-\alpha$. Applying the sine rule to $ABD,ACD,BCD$ gives
\[\dfrac{AD}{BD}=\dfrac{\sin12^\circ}{\sin\alpha},\quad
\dfrac{AD}{CD}=\dfrac{\sin63^\circ}{\sin(48^\circ-\alpha)},\quad
\dfrac{BD}{CD}=\dfrac{\sin39^\circ}{\sin18^\circ}.\]
Therefore
\[\dfrac{\sin(48^\circ-\alpha)}{\sin\alpha}
=\dfrac{\sin18^\circ\sin63^\circ}{\sin12^\circ\sin39^\circ}
=\dfrac{\sin33^\circ}{\sin15^\circ}.\]
To verify the last equality, product-to-sum reduces
$\sin33^\circ\sin12^\circ\sin39^\circ=\sin15^\circ\sin18^\circ\sin63^\circ$
to $\sin66^\circ-\sin6^\circ=\dfrac{1}{2}+\sin18^\circ$. Its left side equals $\cos36^\circ$, and the right side has the same value because $\cos36^\circ-\sin18^\circ=\dfrac{1}{2}$.

For $0<\alpha<48^\circ$, the function $\dfrac{\sin(48^\circ-\alpha)}{\sin\alpha}=\sin48^\circ\cot\alpha-\cos48^\circ$ is strictly decreasing. Since $\alpha=15^\circ$ satisfies the equality, it is the unique solution. Thus $\angle DAB=\boxed{15^\circ}$.
