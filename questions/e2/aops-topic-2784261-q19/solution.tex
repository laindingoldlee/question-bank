The type counts must be $(2,1,1)$ in some order. If the doubled type is flying or ground there are $\binom32\cdot3\cdot2=18$ ways to choose minions, and if aquatic there are $\binom22\cdot3\cdot3=9$. Assign each chosen set to locations in $4!$ ways, giving $(18+18+9)\cdot24=\boxed{1080}$.
