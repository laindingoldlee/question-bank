Factor the denominator: $x^2-x-2=(x-2)(x+1)$. The decomposition into partial fractions is
\[
\dfrac{5x+2011}{(x-2)(x+1)}=\dfrac{A}{x-2}+\dfrac{B}{x+1},\qquad 5x+2011=A(x+1)+B(x-2).
\]
Put $x=2$: $2021=3A$, so $A=\dfrac{2021}{3}$. Put $x=-1$: $2006=-3B$, so $B=-\dfrac{2006}{3}$.

Since partial fraction decompositions are unique, $\{x+b,x+d\}=\{x-2,x+1\}$, with matching numerators; the order of the two terms does not change the sum. So
\[
a+b+c+d=A+B+(-2)+1=\dfrac{2021-2006}{3}-1=5-1=\boxed{4}.
\]
