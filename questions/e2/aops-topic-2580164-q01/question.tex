A student conjectures: ``Every prime number is divisible by some number of the form $2^n-1$ with $n\ge2$.'' (The case $n=1$ is excluded, since $2^1-1=1$ divides every integer.) Is the conjecture true? Determine exactly which primes are divisible by some number $2^n-1$ with $n\ge2$.
