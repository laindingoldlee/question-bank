Let original spending on each type be $M,N$. Then $M+N=50$ and $\dfrac{M}{2}+\dfrac{3N}{2}=50$. Subtracting gives $M=N=25$. The proposed cost is $\dfrac{3M}{2}+\dfrac{N}{2}=37.5+12.5=\boxed{50\text{ dollars}}$. The original count ratio is consistent with different unit prices but unnecessary.
