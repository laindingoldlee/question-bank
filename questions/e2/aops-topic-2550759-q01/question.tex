The numbers $1,2,\dots,9$ are to be shared among three people, Ann, Ben and Cal, so that each person receives exactly three of the numbers. One student counts the ways as $\dbinom93\dbinom63$; another as $3!\dbinom93\dbinom63$. Which count is correct? Find the number of ways and explain the error in the other count.
