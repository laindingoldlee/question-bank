$S$ is a set of $32$ points on a circle. A set $T$ of $16$ segments is chosen uniformly at random among all ways of pairing up the points of $S$ (each point is an endpoint of exactly one segment). Find the expected number of pairs of segments in $T$ that intersect.

$\textbf{(A)}\ 30\qquad\textbf{(B)}\ 40\qquad\textbf{(C)}\ 45\qquad\textbf{(D)}\ 50\qquad\textbf{(E)}\ 60$
