Number rows and columns $1,2,3,4$. Corner cell $A=(1,1)$ has only two possible neighbours, $B=(2,3)$ and $C=(3,2)$. In a closed tour, every visited cell must use exactly two incident moves, so both $AB$ and $AC$ are forced.

The opposite corner $D=(4,4)$ has the same two possible neighbours, $B$ and $C$. Thus $DB$ and $DC$ are also forced. These four forced moves form the cycle $A\to B\to D\to C\to A$.

Both allowed tour moves at each of $A,B,C,D$ are now used within that four-cell cycle. It cannot be connected to the other twelve cells as part of a single tour. This contradiction proves that $\boxed{\text{no closed knight's tour exists}}$.
