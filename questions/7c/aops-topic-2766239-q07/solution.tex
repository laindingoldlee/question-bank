Successive directed edges turn 60 degrees. Rotate the first edge to horizontal. The vertical components sum to $\dfrac{\sqrt3}{2}(5+3-3-x)=0$, so $\boxed{x=5}$. Horizontal closure is also satisfied: $6+\dfrac{5}{2}-\dfrac{3}{2}-8-\dfrac{3}{2}+\dfrac{5}{2}=0$. The resulting convex hexagon supplies existence.
\begin{asy}
usepackage("amsmath");
size(7cm);
pair P=(0,0);real[] L={6,5,3,8,3,5};for(int k=0;k<6;++k){pair Q=P+L[k]*dir(60*k);draw(P--Q);label(string(L[k]),(P+Q)/2,dir(60*k-90));P=Q;}
\end{asy}
