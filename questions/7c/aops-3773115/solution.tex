From $43$ the sequence is $43,25,29,85,89,145,42,20,4,16,37,58,89$. It returns to $89$ and repeats the same cycle, so it never reaches $1$. In general a $d$-digit number maps to at most $81d$. For $d\ge4$, $81d<10^{d-1}$ (check $d=4$, then induct), so the value strictly decreases while it has at least four digits. Once below $1000$, the next value is at most $243$ and later values stay at most $243$. A deterministic sequence in a finite set must repeat, by the pigeonhole principle.
