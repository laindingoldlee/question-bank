The slope is $m=\dfrac{-4-(-5)}{-4-(-6)}=\dfrac12$. Using the point $(-4,-4)$:
\[y+4=\dfrac12(x+4)\quad\Longrightarrow\quad\boxed{y=\dfrac12x-2}.\]
Check: $\dfrac12(-6)-2=-5$ and $\dfrac12(-4)-2=-4$.
