A student's proof that the sum of an even number and an odd number is odd reads:

``An even number is written as $2n$, and an odd number is written as $2n+1$. So an even number plus an odd number equals $2n+2n+1=4n+1$. Any number multiplied by $4$ is even, and $1$ plus an even number is odd. Therefore an even number plus an odd number is odd.''

Explain what is wrong with this argument, and give a correct proof.
