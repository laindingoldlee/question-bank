There are $12$ aliens, so $\dbinom{12}{2}=66$ pairs of aliens.

\textbf{Pairs from the same base.} Each base gives $\dbinom42=6$ pairs, so there are $3\cdot6=18$ such pairs, each wrestling once: $18$ matches.

\textbf{Pairs from different bases.} There are $66-18=48$ such pairs (or $\dbinom32\cdot4\cdot4=48$), each wrestling three times: $144$ matches.

In total there are $18+144=\boxed{162}$ wrestling matches.
