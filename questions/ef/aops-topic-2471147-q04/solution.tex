Since $8=2^3$, a binary number converts to base $8$ by splitting its digits into blocks of three from the right: the block in binary places $3k+2,3k+1,3k$ has value $4d_{3k+2}+2d_{3k+1}+d_{3k}$ between $0$ and $7$, and it contributes this value times $2^{3k}=8^k$. So each block becomes one octal digit.

Grouping $011101010101010$ from the right:
\[011\ \ 101\ \ 010\ \ 101\ \ 010\quad\longrightarrow\quad 3\ \ 5\ \ 2\ \ 5\ \ 2.\]
So the number is $\boxed{35252_8}$.

(Check: both equal $15018$ in base $10$, since $3\cdot4096+5\cdot512+2\cdot64+5\cdot8+2=15018$ and $2^{13}+2^{12}+2^{11}+2^9+2^7+2^5+2^3+2^1=15018$.)
