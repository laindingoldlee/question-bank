Let $g(x)=f(x)-2x$. Then $g$ is a monic quartic with roots $3$, $4$, $5$, so $g(x)=(x-3)(x-4)(x-5)(x-r)$ for some $r$. From $g(8)=196-16=180$ we get $5\cdot4\cdot3\cdot(8-r)=180$, so $r=5$. Hence
\[f(10)=g(10)+20=7\cdot6\cdot5\cdot5+20=1050+20=\boxed{1070}.\]
