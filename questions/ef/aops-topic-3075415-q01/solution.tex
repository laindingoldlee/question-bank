For a positive integer $m$, the exponent rule gives $x^{m-m}=\dfrac{x^m}{x^m}=1$, so extending it consistently to exponent zero requires $x^0=1$. For products, concatenating two lists should multiply their products; concatenating an empty list changes nothing, so its product must be the multiplicative identity $1$. This does not assign a universal value to $0^0$, which was excluded.
