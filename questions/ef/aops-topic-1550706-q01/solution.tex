Define a map from $J_n$ to the set of $3$-element subsets of $\{1,2,\dots,n\}$ by
\[
(i,j,k)\longmapsto\{i,j,k\}.
\]
It is well defined, since $i<j<k$ are three distinct elements.

\textbf{It is injective.} The triple is the subset listed in increasing order, so two different triples give different subsets.

\textbf{It is surjective.} Any $3$-element subset $\{x,y,z\}$ can be listed in increasing order, $x<y<z$, and then $(x,y,z)\in J_n$ maps to it.

Hence the map is a bijection, and $|J_n|$ equals the number of $3$-element subsets of an $n$-element set, which is $\dbinom n3$. $\blacksquare$
