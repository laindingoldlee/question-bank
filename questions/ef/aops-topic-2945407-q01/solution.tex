If the friend is at $(x,y)$, every answered meow decreases the taxicab distance $D=|x|+|y|$ by exactly $1$. So the cat arrives after exactly $D$ answers. The number of meows needed for $D$ answers has mean $2D$ (each answer takes on average $2$ meows), so the expected time is $5\cdot2D=10D$ seconds.

With $x,y$ independent and uniform on $\{-10,\dots,10\}$, $E|x|=\dfrac{2(1+2+\cdots+10)}{21}=\dfrac{110}{21}$, so $E[D]=\dfrac{220}{21}$. The answer is
\[10\cdot\dfrac{220}{21}=\boxed{\dfrac{2200}{21}}\approx104.8\text{ seconds}.\]
