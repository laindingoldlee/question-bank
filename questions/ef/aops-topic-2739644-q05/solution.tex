Use the Sophie Germain identity $a^4+4b^4=(a^2+2b^2+2ab)(a^2+2b^2-2ab)$ with $a=x$, $b=x+3$:
\[a^2+2b^2+2ab=x^2+2(x+3)^2+2x(x+3)=5x^2+18x+18,\]
\[a^2+2b^2-2ab=x^2+2(x+3)^2-2x(x+3)=x^2+6x+18.\]
Both have negative discriminant, so the answer is $\boxed{(x^2+6x+18)(5x^2+18x+18)}$.
