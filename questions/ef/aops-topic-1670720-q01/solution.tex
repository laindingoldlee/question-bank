For a nonzero real $t$, $\dfrac{t}{|t|}$ is $1$ if $t>0$ and $-1$ if $t<0$.

Since $a+b+c=0$ and none of the numbers is $0$, they cannot all have the same sign. So either two are positive and one is negative, or two are negative and one is positive.
\begin{itemize}
\item Two positive, one negative: the first three terms add to $1+1-1=1$, and $abc<0$, so the last term is $-1$. The total is $0$.
\item Two negative, one positive: the first three terms add to $-1-1+1=-1$, and $abc>0$, so the last term is $1$. The total is $0$.
\end{itemize}
Both cases occur (for example $(a,b,c)=(1,1,-2)$ and $(-1,-1,2)$), so the only possible value is $0$: $\boxed{\textbf{(A)}\ 0}$.
