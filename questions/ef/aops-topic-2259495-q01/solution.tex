\textbf{(a)} If $\dfrac {a}{b}=\dfrac {c}{d}$, multiply both sides by $bd$: $\dfrac {a}{b}\cdot bd=ad$ and $\dfrac {c}{d}\cdot bd=bc$, so $ad=bc$. Conversely, if $ad=bc$, divide both sides by $bd$, which is allowed because $bd\ne0$: $\dfrac{ad}{bd}=\dfrac{bc}{bd}$, i.e. $\dfrac {a}{b}=\dfrac {c}{d}$. Since multiplying by the nonzero number $bd$ can be undone by dividing by it, the two equations are equivalent.

\textbf{(b)} $73\cdot301=21973$ and $43\cdot511=21973$, so by (a) the fractions are \textbf{equal}. This is no accident: $\dfrac{511}{301}=\dfrac{7\cdot73}{7\cdot43}=\dfrac{73}{43}$, and correspondingly $73\cdot301=73\cdot7\cdot43=43\cdot511$.
