If $k$ turns are clockwise, the net number of 120-degree turns is $2k-4$. For $0\le k\le4$, this is divisible by 3 only when $k=2$. Thus probability $\dfrac{\binom42}{16}=\dfrac{3}{8}$ and $\boxed{11}$.
\begin{asy}
usepackage("amsmath");
size(7cm);
draw(unitcircle);for(int k=0;k<3;++k){dot(dir(90+120*k));label(string(k),dir(90+120*k),dir(90+120*k));}draw(arc((0,0),.7,90,210),Arrow);label("$120^\circ$",(0,0));
\end{asy}
