Write the digits as $a,b,c,d$, where $a\ne0$. Exactly one of the pairs $(a,d),(b,c)$ must differ. If $a=d$ and $b\ne c$, there are $9\cdot10\cdot9=810$ choices. If $a\ne d$ and $b=c$, there are $9\cdot9\cdot10=810$ choices. In the second case, changing $d$ to $a$ preserves a nonzero leading digit. Thus all counted numbers qualify, giving $\boxed{1620}$.
