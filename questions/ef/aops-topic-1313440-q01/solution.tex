If $x$ is odd, $x^y+1$ is even and greater than $2$, not prime. So $x=2$ and $z=2^y+1$. If $y$ is an odd prime, $2^y\equiv(-1)^y=-1\pmod3$, so $3\mid2^y+1>3$, not prime. So $y=2$ and $z=5$. There is $\boxed{1}$ triple, $(2,2,5)$.
