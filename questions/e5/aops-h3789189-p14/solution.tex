There are $10^3=1000$ ordered digit triples. If $S=a+b+c$, every possible reported sum is an integer between $0$ and $9S$, so unique recovery requires $9S+1\ge1000$, or $S\ge111$. This bound is attained with $(a,b,c)=(100,10,1)$, because the reported integer has decimal digits $x,y,z$, including leading zeros when needed. Thus the minimum sum is $\boxed{111}$.
