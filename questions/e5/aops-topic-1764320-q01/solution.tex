There are $9000$ four-digit integers, $1000$ to $9999$. Pair each one ending in $0,2,4,6,8$ with the number obtained by increasing its last digit by $1$ (ending in $1,3,5,7,9$); this pairs all $9000$ numbers, and in each pair the digit sums differ by $1$, so exactly one of the pair has an odd digit sum. Hence there are $\dfrac{9000}{2}=\boxed{4500}$ such integers.
