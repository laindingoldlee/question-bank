There are $100$ doors. Behind $99$ of them is a red object and behind one is a green object; the green object is equally likely to be behind each door. You must write down a guess (red or green) for every door, all at once, before any door is opened. Each correct guess earns $\$1$, and you get a bonus of $\$97$ if all $100$ guesses are correct. Which strategy maximises your expected earnings, and what is the maximum expected amount?
