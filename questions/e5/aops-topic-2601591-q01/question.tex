A test consists of tossing $z$ fair coins once each ($z$ a fixed positive integer) and declaring success for a chosen set of outcomes.
\begin{enumerate}
\item[(a)] Prove that no such test has success probability exactly $\dfrac13$.
\item[(b)] For which fractions $\dfrac xy$ in lowest terms with $0<x<y$ is there a test (for some $z$) whose success probability is exactly $\dfrac xy$?
\end{enumerate}
