For $\log_x$ to be defined as a real logarithm, the base must satisfy $x>0$ and $x\ne1$. For every such base, $x^0=1$, so
\[\log_x 1=0 .\]
The equation therefore becomes $0=x+2$, so $x=-2$. But $-2$ is not an allowed base. Hence the equation has $\boxed{\text{no solution}}$.
