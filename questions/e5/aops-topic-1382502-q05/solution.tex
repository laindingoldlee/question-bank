We have $g(f(x))=\sqrt{2(x^2+1)}$, which is defined for every real $x$ because $x^2+1>0$. Then
\[
\sqrt{2x^2+2}=10\iff 2x^2+2=100\iff x^2=49\iff x=\pm7 .
\]
Both values work: $f(\pm7)=50$ and $g(50)=\sqrt{100}=10$. So $\boxed{x=7\text{ or }x=-7}$.
