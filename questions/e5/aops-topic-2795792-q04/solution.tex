Test $\{1,2\}$.

\emph{If it shows a counterfeit}, test $\{1\}$: if positive, coin $1$ is counterfeit; otherwise coin $2$ is.

\emph{If not}, coins $1,2$ are genuine and coins $3,\dots,8$ contain $5$ counterfeits and $1$ genuine. Test $\{3\}$: if positive, coin $3$ is counterfeit. Otherwise $1,2,3$ are the three genuine coins and every one of $4,\dots,8$ is counterfeit, e.g. coin $4$.
