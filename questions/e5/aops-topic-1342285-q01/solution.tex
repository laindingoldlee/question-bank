For any real $t$, $\sqrt{t^2}=|t|$. Since $\sqrt{11}<\sqrt{25}=5$, the number $5-\sqrt{11}$ is positive, so
\[
\sqrt{\left(5-\sqrt{11}\right)^2}=\left|5-\sqrt{11}\right|=\boxed{5-\sqrt{11}}.
\]
