\textbf{Counting.} Let the walk use $R$ right, $L$ left, $U$ up and $D$ down steps. We need $R=L$, $U=D+2$ and $R+L+U+D=6$, so $R+D=2$:
\begin{itemize}
\item $R=L=0$, $U=4$, $D=2$: $\dfrac{6!}{4!\,2!}=15$ walks;
\item $R=L=1$, $U=3$, $D=1$: $\dfrac{6!}{1!\,1!\,3!\,1!}=120$ walks;
\item $R=L=2$, $U=2$, $D=0$: $\dfrac{6!}{2!\,2!\,2!}=90$ walks.
\end{itemize}
The total is $15+120+90=\boxed{225}$.

\textbf{A slicker way.} Use the coordinates $u=x+y$ and $v=y-x$. Each step changes $u$ by $\pm1$ and $v$ by $\pm1$, and the four steps correspond exactly to the four sign pairs. The endpoint $(0,2)$ has $u=2$, $v=2$. So we need two independent sequences of six $\pm1$'s, each with sum $2$, that is, with four $+1$'s: $\dbinom64^2=15^2=225$.
