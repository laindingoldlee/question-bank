Order $23$ means $97^{23}\equiv1\pmod k$ but $97\not\equiv1\pmod k$, since $23$ is prime. For a qualifying $k<47$, every prime-power factor $p^e$ would have order dividing $23$. If all had order one, so would $k$; thus some factor has order $23$, forcing $23\mid\varphi(p^e)=p^{e-1}(p-1)$. This requires either $p=23,e\ge2$ (then $p^e\ge529$), or $p\equiv1\pmod{23}$ (the least such prime is $47$). Both contradict $k<47$. For $k=47$, $97\equiv3$; repeated squaring gives $3^2\equiv9,3^4\equiv34,3^8\equiv28,3^{16}\equiv32$, and $3^{23}\equiv32\cdot34\cdot9\cdot3\equiv1$. Since $3\not\equiv1$, its order is $23$. Hence $\boxed{k=47}$.
