Pair each divisor $d$ with $\dfrac {n}{d}$: the product of all divisors is $n^{\dfrac{d(n)}{2}}$. So we need $d(n)=12$. Numbers with $12$ divisors have the form $p^{11}$, $p^5q$, $p^3q^2$, $p^2qr$; the smallest values are $2^{11}$, $2^5\cdot3=96$, $2^3\cdot3^2=72$, $2^2\cdot3\cdot5=60$. The answer is $\boxed{60}$.
