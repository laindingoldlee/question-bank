In ABMC problem writing, one hard problem takes $1$ minute to write. It is also known that

(a) $3$ easy problems take the same amount of time to write as a medium problem

(b) $2$ medium problems take the same amount of time to write as a hard problem

(c) $7$ hard problems take the same amount of time to write as a sadistic problem

How many seconds would it take to write one easy problem, two medium problems, three hard problems, and four sadistic problems?
