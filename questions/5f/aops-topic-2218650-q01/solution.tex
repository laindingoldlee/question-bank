\textbf{(a)} The ratio says $\dfrac{L_1+0.05}{L_2+0.05}=14$, so
\[L_1+0.05=14L_2+0.7\qquad\Longrightarrow\qquad\boxed{L_1=14L_2+0.65}.\]
(The division bar groups $L_1+0.05$ and $L_2+0.05$ as wholes, so the additions inside are done before the division.)

\textbf{(b)} There is only one equation for two unknowns: for every value of $L_2$ other than $-0.05$ there is a matching $L_1$, so infinitely many pairs work.

\textbf{(c)} $L_1=14\cdot0.2+0.65=\boxed{3.45}$. (Check: $\dfrac{3.5}{0.25}=14$.)
