If the numbers with a minus sign sum to $s$, the value is $10-2s$. Here $s$ is a subset sum of $\{1,2,3,4\}$, and every integer from $0$ to $10$ occurs ($0,1,2,3,4,5=1+4,6=2+4,7=3+4,8=1+3+4,9=2+3+4,10$). So the value can be any even number from $-10$ to $10$: $\boxed{11}$ values.
