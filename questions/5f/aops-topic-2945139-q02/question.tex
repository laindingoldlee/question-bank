Alice writes a three-digit base-$7$ number. Bob reads the same digits as a base-$9$ number, and Carlos reads them as a base-$5$ number. Bob's number minus Alice's number equals twice Carlos's number. Find all possible numbers Alice wrote, or prove none exist.
