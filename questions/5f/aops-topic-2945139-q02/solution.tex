Let the digits be $a,b,c$ with $1\le a\le4$ and $0\le b,c\le4$ (they must be valid base-$5$ digits). Then
\[(81a+9b+c)-(49a+7b+c)=2(25a+5b+c)\iff32a+2b=50a+10b+2c\iff18a+8b+2c=0.\]
This is impossible since $a\ge1$. So $\boxed{\text{no such number exists}}$.
