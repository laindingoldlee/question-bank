On each interval $(-\dfrac{\pi}{2}+k\pi,\dfrac{\pi}{2}+k\pi)$, tangent is strictly increasing. (a) Since $\tan(\dfrac{\pi}{3})=\sqrt3$, the solution is $\boxed{-\dfrac{\pi}{2}+k\pi<x<\dfrac{\pi}{3}+k\pi}$ for integers $k$. (b) Rearranging gives $-\sqrt3<\tan x<\dfrac{1}{\sqrt3}$, so $\boxed{-\dfrac{\pi}{3}+k\pi<x<\dfrac{\pi}{6}+k\pi}$ for integers $k$. All endpoints are excluded, and no tangent poles are included.
