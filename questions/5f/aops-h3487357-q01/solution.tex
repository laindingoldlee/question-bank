The common ratio is a positive rational number $\dfrac{u}{v}$ in lowest terms. Integrality of all terms forces $v^k$ to divide the fixed integer $a_1$ for every $k$, so $v=1$. Write the integer ratio as $r$. The transition $76\to52$ gives $19r\equiv13\pmod{25}$, hence $r\equiv2\pmod{25}$.

For every multiple of 4, multiplication by $r$ has the same effect modulo 100 as multiplication by 2. The relevant cycle is
\[4,8,16,32,64,28,56,12,24,48,96,92,84,68,36,72,44,88,76,52,\]
followed by 4 again. To end the list at 52, its first entry into this cycle must be 4.

If $r$ is odd, it is coprime to 100, so there is no transient part: $a_1\equiv4$ and $a_2\equiv8$. If $4\mid r$, the first multiplication reaches a multiple of 4. Since no term can be divisible by 5, that term is in this cycle. Thus either $a_1\equiv4$ and $a_2\equiv8$, or $a_2\equiv4$. Finally, if $r\equiv2\pmod4$, then $r\equiv2\pmod{100}$. If $4\mid a_1$, the same reasoning gives $a_2\equiv8$; if $a_1$ is even but not divisible by 4, it gives $a_2\equiv4$; if $a_1$ is odd, $a_3$ is the first multiple of 4, so $a_3\equiv4$ and $a_2\equiv2$.

Therefore $a_2$ ends in 02, 04, or 08. Conversely, each such positive number $n$ is attainable: for $n\equiv2$, choose $(a_1,r)=(1,n)$; for $n\equiv4$, choose $(2,\dfrac{n}{2})$; for $n\equiv8$, choose $(4,\dfrac{n}{4})$. These give the stated cycle and last two entries. There are ten numbers of each residue at most 1000, for a total of $\boxed{30}$.
