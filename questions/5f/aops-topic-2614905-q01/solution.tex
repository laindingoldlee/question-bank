The rounded value is a multiple of $100$ (it equals the rounding to the nearest hundred), so it is automatically divisible by $4$. The smallest odd number above $300$ is $301$. It rounds to $300$ both to the nearest ten and to the nearest hundred, and $300=4\cdot75$. So the least value is $\boxed{301}$.
