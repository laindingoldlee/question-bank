For $x\le12$, acuteness requires $12^2<5^2+x^2$, or $x^2>119$, leaving $x=11,12$. For $x>12$, acuteness requires $x^2<5^2+12^2=169$, so there is no integer $x>12$. Both $11,12$ satisfy the triangle inequality. The answer is $\boxed2$.
