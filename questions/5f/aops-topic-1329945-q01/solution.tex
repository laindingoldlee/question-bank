Let $t=x-y>0$. Then $x^2+y^2=(x-y)^2+2xy=t^2+6$, so the expression is
\[
\dfrac{t^2+6}{t}=t+\dfrac{6}{t}\ge2\sqrt6
\]
by AM-GM, with equality at $t=\sqrt6$. This value is attained: $x-y=\sqrt6$ and $xy=3$ give $y=\dfrac{-\sqrt6+\sqrt{18}}{2}=\dfrac{3\sqrt2-\sqrt6}{2}>0$. The minimum is $\boxed{2\sqrt6}$.
