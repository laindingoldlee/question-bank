Move number $k$ has length $k$, and the directions repeat east, north, west, south. The $2020$th turn is made right after move $2020$.

\emph{$x$-coordinate.} Moves $k\equiv1\pmod4$ go east ($+k$) and moves $k\equiv3\pmod4$ go west ($-k$). Pair them as $(1,3),(5,7),\dots,(2017,2019)$: there are $505$ pairs, each contributing $-2$. So $x=-20-1010=-1030$.

\emph{$y$-coordinate.} Moves $k\equiv2\pmod4$ go north and moves $k\equiv0\pmod4$ go south. Pair them as $(2,4),(6,8),\dots,(2018,2020)$: again $505$ pairs of $-2$. So $y=20-1010=-990$.

The point is $\boxed{\textbf{(B) }(-1030,-990)}$.
