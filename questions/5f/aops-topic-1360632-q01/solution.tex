Split according to the value of $x$; on each piece, $\big||x|-4\big|$ is linear.
\begin{itemize}
\item $x\ge4$: $x-4=\dfrac{x}{100}+1$ gives $x=\dfrac{500}{99}\approx5.05$, which is $\ge4$. One point.
\item $0\le x<4$: $4-x=\dfrac{x}{100}+1$ gives $x=\dfrac{300}{101}\approx2.97$, in range. One point.
\item $-4\le x<0$: $4+x=\dfrac{x}{100}+1$ gives $x=-\dfrac{300}{99}\approx-3.03$, in range. One point.
\item $x<-4$: $-x-4=\dfrac{x}{100}+1$ gives $x=-\dfrac{500}{101}\approx-4.95$, in range. One point.
\end{itemize}
Each piece contributes exactly one solution, so there are $\boxed{4}$ intersection points.
