The total is $110$. If Philip has $P$ eggs, Kitty has $3P$, so $110-r=4P$ where $r$ is the remaining basket; hence $r\equiv110\equiv2\pmod4$, so $r=14$ (the only basket $\equiv2\pmod4$). Check: $P=24$ from $4+5+7+8$, and Kitty has $12+13+23+24=72=3\cdot24$. The answer is $\boxed{14}$.
