Let there be $n$ candidates and $k$ seats, so $n=k+r$. A vote is a set of between $1$ and $k$ candidates, so
\[
\binom n1+\binom n2+\cdots+\binom nk=967,\qquad \binom n1+\binom n2+\cdots+\binom n{r-1}=55 .
\]

\textbf{Find $n$.} All the subsets of the candidates number $2^n$, so $967\le2^n-1$, i.e.\ $n\ge10$. Also $\binom n1+\cdots+\binom n{r-1}=55$ with $r\ge2$ (the sum is $0$ if $r=1$). If $r=2$ we would need $n=55$; then $k=53$ and the first sum would be enormous. If $r\ge3$, the sum contains $\binom n1+\binom n2=n+\dfrac{n(n-1)}{2}$, which exceeds $55$ for $n\ge11$; with $n=10$ it equals $10+45=55$ exactly, so $r=3$.

\textbf{Check $k$.} With $n=10$ and $r=3$ we get $k=7$, and
\[
\sum_{i=1}^{7}\binom{10}{i}=2^{10}-\binom{10}{0}-\binom{10}{8}-\binom{10}{9}-\binom{10}{10}=1024-1-45-10-1=967 ,
\]
as required. ($n=10$ with $r\ge4$ is impossible, since already $\binom{10}1+\binom{10}2+\binom{10}3=175>55$.)

So $\boxed{10}$ candidates contest the election, $7$ are elected and $\boxed{3}$ lose.
