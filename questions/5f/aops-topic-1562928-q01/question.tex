In an election for a club committee, the number of candidates exceeds the number of members to be elected by $r$, where $r>0$. A voter may vote for any number of candidates from $1$ up to the number of members to be elected; in this way a voter can vote in $967$ different ways. If instead a voter could vote for any number of candidates from $1$ up to $r-1$, there would be $55$ different ways to vote. How many candidates are contesting the election, and how many of them lose?
