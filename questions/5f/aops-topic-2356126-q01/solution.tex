If $x$ and $\dfrac1x$ are both integers, then neither is $0$, so $|x|\ge1$ and $\left|\dfrac1x\right|\ge1$, that is, $|x|\le1$. Hence $|x|=1$: $x=1$ (with $\dfrac1x=1$) or $x=-1$ (with $\dfrac1x=-1$); these are the only such pairs. The same holds for $y$ and $z$.

So $x+y+z$ is a sum of three numbers, each $1$ or $-1$. With $k$ of them equal to $-1$ ($k=0,1,2,3$) the sum is $3-2k$, giving the values $3,1,-1,-3$. There are $\boxed{4}$ possible values.
