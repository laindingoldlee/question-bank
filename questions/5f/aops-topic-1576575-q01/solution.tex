\textbf{Telescoping.} For every $k\ge1$,
\[
k(k+1)=\dfrac{k(k+1)(k+2)-(k-1)k(k+1)}{3},
\]
because the numerator is $k(k+1)\bigl[(k+2)-(k-1)\bigr]=3k(k+1)$. Adding these identities for $k=1,2,\dots,n$, all intermediate products cancel and only the last one survives (the first subtracted product is $0\cdot1\cdot2=0$):
\[
\sum_{k=1}^{n}k(k+1)=\dfrac{n(n+1)(n+2)}{3}.
\]
For $n=99$:
\[
1\cdot2+2\cdot3+\cdots+99\cdot100=\dfrac{99\cdot100\cdot101}{3}=33\cdot100\cdot101=\boxed{333300}.
\]
(Equivalently, $\sum k(k+1)=\sum k^2+\sum k=\dfrac{99\cdot100\cdot199}{6}+\dfrac{99\cdot100}{2}=328350+4950$.)
