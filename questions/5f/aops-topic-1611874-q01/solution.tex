\textbf{$A$.} The product $\overline{DCBA}$ has four digits, so $4\cdot\overline{ABCD}<10000$ and $\overline{ABCD}<2500$, so $A\le2$. Also $A$ is the units digit of $4\cdot\overline{ABCD}$, which is even. So $A=2$.

\textbf{$D$.} Since $\overline{ABCD}\ge2000$, $\overline{DCBA}\ge8000$, so $D\ge8$. The units digit of $4D$ must be $A=2$, so $D=3$ or $8$. Hence $D=8$.

\textbf{$B$ and $C$.} Now
\[
4(2000+100B+10C+8)=8000+100C+10B+2
\]
simplifies to $390B+30=60C$, i.e. $2C=13B+1$. As $C\le9$, we need $13B+1\le18$, so $B\le1$; $B=0$ gives $C=\dfrac{1}{2}$, and $B=1$ gives $C=7$.

So $A=2$, $B=1$, $C=7$, $D=8$: $\boxed{2178\times4=8712}$.
