Let the equal sides be $a$ and the third side $b$, so $2a+b=2017$ with positive integers $a,b$:

An equilateral triangle is impossible, since $3\nmid2017$, so each triangle is described by exactly one pair $(a,b)$ with $b\ne a$.

\textbf{Conditions.} $b=2017-2a\ge1$ gives $a\le1008$. The triangle inequality $a+a>b$ gives $2a>2017-2a$, i.e.\ $a>504.25$, so $a\ge505$ (the inequality $a+b>a$ is automatic).

So $a$ can be any integer from $505$ to $1008$: there are $1008-505+1=\boxed{504}$ triangles.
