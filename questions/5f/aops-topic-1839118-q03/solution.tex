By the rational root test, try $x=-1$: $3+5-8=0$, so $x+1$ is a factor, and
\[3x^4-5x^3-8=(x+1)(3x^3-8x^2+8x-8).\]
Try $x=2$ in the cubic: $24-32+16-8=0$, so $x-2$ is a factor:
\[3x^3-8x^2+8x-8=(x-2)(3x^2-2x+4).\]
The quadratic $3x^2-2x+4$ has discriminant $4-48<0$, so it has no real roots and does not factor further. Hence
\[3x^{4}-5x^{3}-8=\boxed{(x+1)(x-2)(3x^2-2x+4)}.\]
