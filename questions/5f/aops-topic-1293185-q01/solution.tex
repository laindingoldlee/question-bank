Note that $63^2+63+1=3969+64=4033$. If $n\equiv63\pmod{4033}$, then $n^2+n+1\equiv63^2+63+1=4033\equiv0\pmod{4033}$. So every $n=63+4033k$ ($k$ an integer) works, giving infinitely many. $\blacksquare$ (The hint $4033=2\cdot2016+1$ is not needed.)
