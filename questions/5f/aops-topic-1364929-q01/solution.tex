Order matters: the dice are distinguishable, so there are $6^4=1296$ equally likely outcomes.

(a) Choose the repeated number ($6$ ways), the different number ($5$ ways) and which die shows it ($4$ ways): $6\cdot5\cdot4=120$ outcomes, so the probability is $\dfrac{120}{1296}=\boxed{\dfrac{5}{54}}$.

(b) Add the $6$ outcomes with all four the same: $\dfrac{126}{1296}=\boxed{\dfrac{7}{72}}$.

(Forgetting the factor $4$ for the position of the odd die, i.e.\ treating the dice as unordered, would wrongly give $\dfrac{30}{1296}$.)
