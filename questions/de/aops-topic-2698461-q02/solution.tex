\textbf{(a)} Any number of correct answers from $0$ to $25$: $\boxed{26}$ scores.

\textbf{(b)} Every score is $1.5m$ with $m=4c+b$, where $c$ correct and $b$ blank answers satisfy $c+b\le25$; so $0\le m\le100$. For fixed $c$, $m$ takes every value from $4c$ to $3c+25$. These intervals overlap or touch for consecutive $c$ as long as $4(c+1)\le3c+26$, i.e. up to $c=23$, so together they cover $0\le m\le94$. Then $c=24$ adds $m=96,97$ and $c=25$ adds $m=100$. The missing values are $m=95,98,99$ (scores $142.5$, $147$, $148.5$), so there are $101-3=\boxed{98}$ possible scores.
