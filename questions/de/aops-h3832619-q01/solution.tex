All three polynomials are monic with integer coefficients, so the rational-root theorem says every rational zero would be an integer.

For $f$, an integer root must divide the constant $1$, so only $\pm1$ are possible. But $f(1)=30$ and $f(-1)=-18$.

For $g$, reduction modulo $2$ gives $x^5+x^4+x^3+x^2+1$. For either integer parity the value is $1$ modulo $2$, so $g$ has no integer root.

For $h$, every term is nonnegative at an integer $x\ge0$ and the constant is positive. Also $h(-1)=27$. For $x=-t$ with integer $t\ge2$,
\[
h(-t)=-t^7-t^5-t+6t^2+24<0,
\]
because $t^7=t^2t^5\ge32t^2>6t^2+24$. Thus no integer input gives zero, completing all three proofs.
