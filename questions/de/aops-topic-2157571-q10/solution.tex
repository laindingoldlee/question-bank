Arranging $8$ keys in a circle up to rotation gives $\dfrac{8!}{8}=7!=5040$ arrangements. Flipping the keychain over pairs each arrangement with its mirror image, and these are always different for $8$ distinct keys (the cyclic order is reversed), so each keychain is counted twice. The answer is $\dfrac{7!}{2}=\boxed{2520}$.
