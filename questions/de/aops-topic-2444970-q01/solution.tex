Factor:
\[ab+bc+cd+da=b(a+c)+d(a+c)=(a+c)(b+d).\]
So the value depends only on how $\{16,17,18,19\}$ is split into the two pairs $\{a,c\}$ and $\{b,d\}$. There are three such splits:
\[\{16,17\},\{18,19\}:\ 33\cdot37=1221;\qquad\{16,18\},\{17,19\}:\ 34\cdot36=1224;\qquad\{16,19\},\{17,18\}:\ 35\cdot35=1225.\]
These are different, so there are $\boxed{3}$ possible values.
