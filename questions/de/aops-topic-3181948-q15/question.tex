A calculator has keys 1 through 9 and the signs $+,-$. Four keys are independently chosen uniformly. Consecutive digits concatenate into an integer. A run of signs immediately preceding a number is combined by multiplication of signs; a leading number with no sign is positive. Trailing signs are ignored, and a string with no digits has value 0. If the expected result is $\dfrac{x}{11^4}$, find $x\bmod1000$.
