A number $N$ is successively divided by $5$, $7$ and $9$, leaving remainders $3$, $4$ and $7$ respectively (that is, $N=5q_1+3$, $q_1=7q_2+4$, $q_2=9q_3+7$). What is the remainder when $N$ is divided by $35$?

$\textbf{(A) } 13\qquad\textbf{(B) } 17\qquad\textbf{(C) } 19\qquad\textbf{(D) } 23$
