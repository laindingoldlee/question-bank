\textbf{Squares:} $1^2,2^2,\dots,10^2$, so $10$ of them. \textbf{Cubes:} $1,8,27,64$, so $4$. \textbf{Both} (sixth powers): $1$ and $64$, so $2$.

``Square or cube but not both'' excludes the $2$ numbers that are both, from each list:
\[
(10-2)+(4-2)=10 .
\]
The probability is $\dfrac{10}{100}=\boxed{\dfrac{1}{10}}$.

The poster's $\dfrac{3}{25}=\dfrac{12}{100}$ counts $10+4-2=12$, the squares \emph{or} cubes, which still includes the two sixth powers.
