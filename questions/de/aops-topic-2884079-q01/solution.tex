Let $d=3i+5$. Solving $5j\equiv-3\pmod{|d|}$ is possible iff $\gcd(5,d)\mid3$, i.e. $5\nmid d$, i.e. $5\nmid i$. So a $j$ exists $\boxed{\text{iff }5\nmid i}$, and then $j$ is determined modulo $|3i+5|$. Example: $i=1$, $j=1$ ($8\mid8$). For $i=0$ none exists, since $5\nmid3+5j$.
