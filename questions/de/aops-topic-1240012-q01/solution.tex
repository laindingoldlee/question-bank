Check $x=-1$: $(a+c-b)-2c+(b+c-a)=0$, so $-1$ is a root. By Vieta the other root is $-r$ with $r=\dfrac{b+c-a}{a+c-b}$, so the roots are rational iff $r$ is rational. Then
\[1+r=\dfrac{2c}{a+c-b},\qquad1-r=\dfrac{2(a-b)}{a+c-b},\qquad\dfrac{1+r}{1-r}=\dfrac{c}{a-b}\]
($r\ne1$ since $a\ne b$). So $\dfrac {c}{a-b}$ is rational: $\boxed{\text{(B)}}$. Conversely (A) need not hold, e.g. $a=\sqrt2+1$, $b=\sqrt2$, $c=2$ gives $\dfrac{c}{a-b}=2$ and rational roots.
