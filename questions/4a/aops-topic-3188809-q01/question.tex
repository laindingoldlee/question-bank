A bowl initially contains 50 candies. Independently, each of 100 visitors requests $1,3,4,10$, or all remaining candies with probabilities $\dfrac{1}{4},\dfrac{1}{4},\dfrac{1}{4},\dfrac{7}{32},\dfrac{1}{32}$, respectively. A request larger than the remaining supply takes all that remains. Just before a visitor arrives, an empty bowl is refilled to 50; there is no refill after the last visitor. Find the expected number of refills to three decimal places.
