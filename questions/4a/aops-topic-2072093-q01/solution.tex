If Amy's number is $n$, the possible replies are
\[
2n+5,\quad 2n-5,\quad \dfrac {n}{2}+5,\quad \dfrac {n}{2}-5 .
\]
Since $23$ is one of them, $n$ is one of $9,\ 14,\ 36,\ 56$ (from $2n+5$, $2n-5$, $\dfrac {n}{2}+5$, $\dfrac {n}{2}-5$ respectively). Check whether $12$ is also a possible reply:
\begin{itemize}
\item $n=9$: replies $23,13,9.5,-0.5$ --- no $12$;
\item $n=14$: replies $33,23,12,2$ --- contains $12$;
\item $n=36$: replies $77,67,23,13$ --- no $12$;
\item $n=56$: replies $117,107,33,23$ --- no $12$.
\end{itemize}
Hence Amy's favourite number is $\boxed{14}$ (first time: $14\cdot2-5=23$; second time: $14\div2+5=12$).
