With $s$ scoop types and $t$ toppings, $s\binom t2=630$ and $s\binom{t+1}{2}=840$. Dividing gives $\dfrac{t+1}{t-1}=\dfrac{4}{3}$, so $t=7$. Then $21s=630$, so $s=30$. Adding a scoop type gives $31\cdot21=\boxed{651}$.
