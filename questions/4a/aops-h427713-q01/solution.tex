Complete the square to obtain $(2x+y)^2+3y^2=112$, so $|y|\le6$. For $|y|=0,1,\ldots,6$, the possible squares $112-3y^2$ are
\[
112,\ 109,\ 100,\ 85,\ 64,\ 37,\ 4.
\]
Only $|y|=2,4,6$ work; each of the six signed values gives two integer values $x=\dfrac{(-y\pm\sqrt{112-3y^2})}{2}$. Thus there are $\boxed{12}$ ordered pairs.
