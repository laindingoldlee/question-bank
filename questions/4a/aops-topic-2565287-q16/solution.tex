Since $27=3^3$, we get $27^{\left(27^{27}\right)}=3^{3\cdot27^{27}}$, so $x=3\cdot27^{27}$. Also $27^{27}=\left(3^3\right)^{27}=3^{81}$, so
\[x=3\cdot3^{81}=\boxed{3^{82}}.\]
