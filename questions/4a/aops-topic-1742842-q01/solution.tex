Let there be $n$ houses. Since Dale counts a $16$th house, $n\ge16$. Both count clockwise, so Dale's number of a house is Chip's number plus a constant $c$, modulo $n$. Then $16\equiv4+c$ and $7\equiv12+c\pmod n$, so $c\equiv12$ and $c\equiv-5$, giving $17\equiv0\pmod n$. With $n\ge16$, $n=\boxed{17}$. (Check: with $c=12$, Chip's $4$th is Dale's $16$th, and Chip's $12$th is Dale's $24-17=7$th.)
