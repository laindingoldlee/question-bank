Use $\sin3\alpha=\sin\alpha(3-4\sin^2\alpha)$ and $\sin(x-\alpha)\sin(x+\alpha)=\sin^2x-\sin^2\alpha$. The equation becomes $\sin\alpha(3-4\sin^2x)=0$. If $\sin\alpha=0$, every real $x$ works. Otherwise $\sin^2 x = \dfrac{3}{4}$, giving $\boxed{x = \dfrac{\pi}{3} + k \pi \text{ or } x = \dfrac{2 \pi}{3} + k \pi}$ for integer $k$.
