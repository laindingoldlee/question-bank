If $H$ is the number of heads, the final position is $2H-50$, with $H$ binomial with parameters $50,\dfrac{1}{2}$. Thus (a) is $\boxed{\dfrac{\binom{50}{25}}{2^{50}}}$. For (b), $2H-50>20$ means $H\ge36$, so the exact answer is $\boxed{\dfrac{\sum_{h=36}^{50}\binom{50}{h}}{2^{50}}}$. These are discrete binomial probabilities; a normal curve is only an approximation.
