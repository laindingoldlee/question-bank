Since $|x|$ is a distance, it is never negative: $|x|=x$ for $x\ge0$ and $|x|=-x$ for $x<0$. So $\left|-\dfrac{1}{4}\right|=\dfrac{1}{4}$ and $|-10|=10$.

\textbf{(a)} False: $\left|-\dfrac{1}{4}\right|=\dfrac{1}{4}$, which is equal to $\dfrac{1}{4}$, not greater.

\textbf{(b)} True: $|-10|=10>7$. The left side is not the negative number $-10$ but its distance from $0$, which is $10$.

\textbf{(c)} True, since $\dfrac{1}{4}\ge\dfrac{1}{4}$.

So the answers are $\boxed{\text{(a) false, (b) true, (c) true}}$.
