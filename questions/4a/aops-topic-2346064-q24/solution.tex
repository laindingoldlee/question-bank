Along one side of the large square there are $n$ tiles and $n+1$ border strips of width $d$ (between neighbouring tiles and at both ends):

\begin{asy}
usepackage("amsmath");
size(4.5cm);
defaultpen(fontsize(10pt));
real s=1, d=0.25; int n=3;
real L=n*s+(n+1)*d;
draw((0,0)--(L,0)--(L,L)--(0,L)--cycle,linewidth(0.9));
for(int i=0;i<n;++i) for(int j=0;j<n;++j){ real x=d+i*(s+d), y=d+j*(s+d); filldraw((x,y)--(x+s,y)--(x+s,y+s)--(x,y+s)--cycle,gray(0.6),black); }
for(int i=0;i<=n;++i){ real x=i*(s+d); draw((x,-0.2)--(x+d,-0.2),red,Arrows(3)); }
for(int i=0;i<n;++i){ real x=d+i*(s+d); draw((x,-0.2)--(x+s,-0.2),blue,Arrows(3)); label("$s$",(x+s/2,-0.2),S,blue); }
label("$d$",(d/2,-0.2),S,red); label("$d$",(L-d/2,-0.2),S,red);
label("side $=ns+(n+1)d$",(L/2,L),N);
\end{asy}

So for $n=24$ the large square has side $24s+25d$. The tiles cover $(24s)^2$, so
\[\dfrac{(24s)^2}{(24s+25d)^2}=0.64\quad\Longrightarrow\quad\dfrac{24s}{24s+25d}=0.8\quad\Longrightarrow\quad24s=19.2s+20d\quad\Longrightarrow\quad4.8s=20d.\]
Hence $\dfrac ds=\dfrac{4.8}{20}=\dfrac{6}{25}$. The answer is $\boxed{\textbf{(A) }\dfrac{6}{25}}$.
