\textbf{Counting pairs with $ab\mid n$.} If $n=\prod p_i^{e_i}$, a pair $(a,b)$ with $ab\mid n$ is given by choosing, for each prime, exponents $\alpha_i,\beta_i\ge0$ with $\alpha_i+\beta_i\le e_i$; there are $\dbinom{e_i+2}{2}$ such choices. (If $ab\mid n$, then automatically $a\mid n$ and $b\mid n$.)

\textbf{Reduce the condition.} If $(a,b)$ is disjoint with respect to $720$ and also with respect to $600$, then $ab$ divides $\gcd(720,600)=120$; conversely, if $ab\mid120$, the pair is disjoint with respect to both. So the pairs we want are those with $ab\mid720$ but $ab\nmid120$.

\textbf{Count.} $720=2^4\cdot3^2\cdot5$ gives $\dbinom62\dbinom42\dbinom32=15\cdot6\cdot3=270$ pairs, and $120=2^3\cdot3\cdot5$ gives $\dbinom52\dbinom32\dbinom32=10\cdot3\cdot3=90$ pairs. The answer is $270-90=\boxed{180}$.
