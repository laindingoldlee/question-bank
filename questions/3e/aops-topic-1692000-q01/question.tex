For a positive integer $n$, call an ordered pair $(a,b)$ of positive divisors of $n$ \emph{disjoint with respect to $n$} if $ab$ also divides $n$. Find the number of ordered pairs that are disjoint with respect to $720$ but not disjoint with respect to $600$.
