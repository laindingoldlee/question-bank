Write the number as $\overline{abc}$ with $1\le a\le 9$. We need $c=a+b\le 9$, so for each $a$ the digit $b$ can be $0,1,\dots,9-a$: that is $10-a$ choices, and then $c$ is determined. The number of such integers is
\[\sum_{a=1}^{9}(10-a)=9+8+\cdots+1=45.\]
There are $900$ three-digit numbers, so the probability is $\dfrac{45}{900}=\boxed{\dfrac{1}{20}}$.
