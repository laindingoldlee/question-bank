The only successful path during one attempt is $1\to3\to4\to6\to7$. Its first three choices each have probability $\dfrac{1}{2}$, and the last jump is forced, so an attempt succeeds with probability $p=\dfrac{1}{8}$. Every failed attempt causes exactly one death and restarts with the same independent rules. The expected number of failures before success is $\dfrac{1-p}{p}=\boxed7$. Equivalently, its expectation $D$ satisfies $D=\dfrac{7}{8}(1+D)$.
