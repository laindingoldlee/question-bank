Write $x=m^2$ and $2m=k^2$ with positive integers. The square $k^2$ is even, so $k=2t$, giving $m=2t^2$ and $x=4t^4$. For $t=1,2,3,4,5$, the values are $\boxed{4,64,324,1024,2500}$. Conversely each has $2\sqrt x=4t^2$, a square.
