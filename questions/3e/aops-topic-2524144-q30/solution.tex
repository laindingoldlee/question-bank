Each online user is among the $100$ posters with probability $\dfrac{100}N$, so by linearity of expectation the expected number of friends among the posters is $5\cdot\dfrac{100}{N}=\dfrac{500}N$. Setting $\dfrac{500}N=2$ gives $N=\boxed{250}$.
