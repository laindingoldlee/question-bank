Write $n=13k$. Modulo $9$, $4k\equiv2$, so $k\equiv5\pmod9$. Set $k=5+9t$. Modulo $7$, $6k\equiv3$, hence $k\equiv4$, so $5+2t\equiv4$ and $t\equiv3\pmod7$. Thus $k=32+63u$ and $n=416+819u$. The least value above $250$ is $\boxed{416}$.
