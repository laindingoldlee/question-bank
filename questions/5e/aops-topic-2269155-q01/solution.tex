\textbf{(a)} By definition of the logarithm, $3^x=2.5$ means $x=\log_3 2.5$. The function $3^x$ is increasing and takes every positive value exactly once, so there is exactly one real solution. Since $3^0=1<2.5<3=3^1$ and $3^x$ is increasing, $\boxed{0<\log_32.5<1}$.

\textbf{(b)} $3^{10}=59049\ne2.5$, so $x=10$ is \emph{not} a solution; there is no rule that ``no nice answer'' means $10$. (The confusion may come from $\log x$ written without a base, which often means base $10$.) Using natural logarithms,
\[x=\log_32.5=\dfrac{\ln2.5}{\ln3}\approx\dfrac{0.91629}{1.09861}\approx\boxed{0.834}.\]
Check: $3^{0.834}\approx2.50$.
