Write every integer from $0$ to $999999$ as a string of $6$ digits, with leading zeros; leading zeros do not create a $2$ or a $4$, and $0$ itself contains neither digit, so it does not matter that $0$ is not positive.

The strings containing no $4$ number $9^6$, and among them those also containing no $2$ number $8^6$. So exactly $9^6-8^6=531441-262144=269297$ strings contain a $2$ but no $4$. By symmetry the same number contain a $4$ but no $2$. The answer is
\[
2\left(9^6-8^6\right)=\boxed{538594}.
\]
