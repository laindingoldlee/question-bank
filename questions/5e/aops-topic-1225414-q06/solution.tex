If $a\ge3$ or $b\ge3$, then $3\mid a!\,b!$ and $3\mid315$, so the number is a multiple of $3$ greater than $3$: not prime. So $a,b\in\{1,2\}$, giving $1+315=316$, $2+315=317$, $4+315=319$. Now $316$ is even, $319=11\cdot29$, and $317$ is prime. The answer is $\boxed{317}$.
