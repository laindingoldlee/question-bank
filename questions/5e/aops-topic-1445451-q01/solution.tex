Call the urns $U_1=\{G,R\}$ and $U_2=\{G,R,R,R\}$. The first two draws give four cases:
\begin{itemize}
\item green from both: probability $\dfrac{1}{2}\cdot\dfrac{1}{4}=\dfrac{1}{8}$. You have eaten two greens and stop.
\item green from $U_1$, red from $U_2$: probability $\dfrac{1}{2}\cdot\dfrac{3}{4}=\dfrac{3}{8}$. The urn still containing a green piece is $U_2$, which now holds $G,R,R$, so the third candy is green with probability $\dfrac{1}{3}$. Contribution $\dfrac{3}{8}\cdot\dfrac{1}{3}=\dfrac{1}{8}$.
\item red from $U_1$, green from $U_2$: probability $\dfrac{1}{2}\cdot\dfrac{1}{4}=\dfrac{1}{8}$. The urn still containing a green piece is $U_1$, which now holds only $G$, so the third candy is green for sure. Contribution $\dfrac{1}{8}$.
\item red from both: probability $\dfrac{1}{2}\cdot\dfrac{3}{4}=\dfrac{3}{8}$; no green eaten.
\end{itemize}
Total:
\[
\dfrac{1}{8}+\dfrac{1}{8}+\dfrac{1}{8}=\boxed{\dfrac{3}{8}}.
\]
The poster's $\dfrac{1}{4}$ leaves out the first case, in which both greens are eaten immediately.
