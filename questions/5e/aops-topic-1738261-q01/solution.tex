Let $t_n$ be the $n$-th term, so $t_n=t_{n-1}+t_{n-2}+t_{n-3}$ for $n\ge4$. A small time-saver: $t_{n}=2t_{n-1}-t_{n-4}$, since $t_{n-1}=t_{n-2}+t_{n-3}+t_{n-4}$. Either way,
\[
1,\ 2,\ 3,\ 6,\ 11,\ 20,\ 37,\ 68,\ 125,\ 230,\ 423,
\]
so the $11$th term is $\boxed{423}$. (For example $t_{11}=2\cdot230-37=423$.)
