Without the restriction, a selection is a solution of $c+j+g=6$ in nonnegative integers, and by stars and bars there are $\dbinom{8}{2}=28$ of them.

Now remove the selections with more than $3$ glazed donuts. If $g=4$, then $c+j=2$ has $3$ solutions; if $g=5$, $c+j=1$ has $2$; if $g=6$, there is $1$. That is $3+2+1=6$ forbidden selections.

So there are $28-6=\boxed{22}$ selections. (This confirms the poster's answer.)
