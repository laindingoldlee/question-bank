Every such path consists of $70$ steps right and $50$ steps up (for the rectangle $70$ wide and $50$ high; the other orientation gives the same count), $120$ steps in all, and any order of these steps gives a path. A path is determined by choosing which $50$ of the $120$ steps go up, so the number of paths is
\[\boxed{\dbinom{120}{50}}.\]
