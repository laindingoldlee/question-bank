For a complex number $z=a+bi$ ($a,b$ real), $|z|=\sqrt{a^2+b^2}$ is its distance from $0$ in the complex plane; in particular $|z|\ge0$. For $i=0+1\cdot i$ this gives $|i|=\sqrt{0^2+1^2}=\boxed{1}$.

The student's steps $|i|^2=|i^2|=|-1|=1$ are correct (since $|zw|=|z||w|$), but from $x^2=1$ only the root $x=1$ is possible: an absolute value is never negative, so $x=-1$ must be rejected.
