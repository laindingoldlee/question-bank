Expand the square of the sum:
\[1=\left(\sum_{j=1}^na_j\right)^2=\sum_{j=1}^na_j^2+2\sum_{i<j}a_ia_j.\]
For $i<j$ we have $0\le a_i\le a_j$, so $a_ia_j\le a_j^2$. For a fixed $j$ there are $j-1$ indices $i<j$, hence
\[1\le\sum_{j=1}^na_j^2+2\sum_{j=1}^n(j-1)a_j^2=\sum_{j=1}^n(2j-1)a_j^2. \qquad\blacksquare\]
Equality holds when all $a_j=\dfrac1n$.
