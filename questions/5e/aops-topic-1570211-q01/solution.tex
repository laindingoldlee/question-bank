One block has $1+2+\cdots+9=45$ digits, so the sequence is periodic with period $45$, and the $N$-th digit depends only on $N\bmod45$.

\textbf{$2^{2018}\bmod45$.} Work modulo $9$ and modulo $5$. Modulo $9$: $2^6=64\equiv1$, so $2^{2018}=2^{6\cdot336+2}\equiv2^2=4$. Modulo $5$: $2^4=16\equiv1$, so $2^{2018}=2^{4\cdot504+2}\equiv4$. A number that is $4$ more than a multiple of $9$ and of $5$ is $4$ more than a multiple of $45$, so
\[
2^{2018}\equiv4\pmod{45}.
\]

So the $2^{2018}$-th digit is the $4$th digit of a block. The block starts $1,2,2,3$, so the digit is $\boxed{3}$.
