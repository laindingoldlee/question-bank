(a) $9(y-x)=3x+y$ gives $8y=12x$, so $\dfrac yx=\boxed{\dfrac32}$.

(b) Let the common value be $k$. Then $A=3k$, $B=4k$, $C=5k$, so $B=\dfrac43A$, $C=\dfrac53A$ and $\dfrac{A+B+C}A=\dfrac{12k}{3k}=\boxed{4}$.
