Put $a = \dfrac{1+\sin^2x}{4}$ and $b = \dfrac{2+\cos^2x}{4}$. Then $\dfrac{1}{4} \le a \le \dfrac{1}{2} \le b \le \dfrac{3}{4} < \dfrac{\pi}{4}$. Let $h (t) = \dfrac{\ln (\sin t)}{\ln (\cos t)}$. On $(0 , \dfrac{\pi}{4})$, $h(t)>1$, and $h^{\prime} (t) = \dfrac{[\cot t\ln(\cos t)+\tan t\ln(\sin t)]}{[\ln(\cos t)]^2} < 0$. Hence $h(a)\ge h(b)>1$. The desired expression is $h (a) + \dfrac{1}{h (b)} \ge h (b) + \dfrac{1}{h (b)} > 2$, the last strict inequality following from $(h(b)-1)^2>0$.
