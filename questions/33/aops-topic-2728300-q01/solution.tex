We need $16m\equiv-1\pmod{45}$. Since $16\cdot31=496=11\cdot45+1$, the inverse of $16$ mod $45$ is $31$, so $m\equiv-31\equiv14\pmod{45}$. Thus $\boxed{m=45k+14}$ for integers $k$ (check: $16\cdot14+1=225=5\cdot45$). The answer is a residue class mod $45$ because the condition depends only on $m$ mod $45$: changing $m$ by $45$ changes $16m+1$ by $720$, a multiple of $45$.
