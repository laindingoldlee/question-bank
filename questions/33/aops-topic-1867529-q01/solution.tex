The left side is defined only for $x\ne0$, and then it equals $1$. The right side equals $0$ for every $x$. Since $1\ne0$, there is $\boxed{\text{no solution}}$ ($x=0$ is excluded because $\dfrac{0}{0}$ is undefined).
