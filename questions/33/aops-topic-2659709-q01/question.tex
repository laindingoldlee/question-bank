A student writes: ``$4a\equiv4b\pmod6$, so $a\equiv b\pmod{\dfrac32}$.'' Explain what is wrong with this step, and find the correct simplification: for integers $a,b$, show that $4a\equiv4b\pmod6$ holds if and only if $a\equiv b\pmod3$.
