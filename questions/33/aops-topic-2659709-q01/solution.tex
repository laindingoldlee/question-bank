A congruence $u\equiv v\pmod m$ is defined for a positive integer modulus $m$ (it means $m\mid u-v$), so ``mod $\dfrac32$'' is not a congruence in the usual sense, and dividing the modulus by $4$ is not a valid rule. The correct rule divides the modulus by $\gcd(4,6)=2$:
\[4a\equiv4b\pmod6\iff6\mid4(a-b)\iff3\mid2(a-b)\iff3\mid a-b,\]
where the last step uses $\gcd(2,3)=1$. So $4a\equiv4b\pmod6$ if and only if $\boxed{a\equiv b\pmod3}$.

(If one insists on reading ``$a\equiv b\pmod{\dfrac32}$'' as ``$\dfrac{a-b}{\dfrac32}=\dfrac{2(a-b)}3$ is an integer'', it says the same thing, but the standard statement uses the integer modulus $3$.)
