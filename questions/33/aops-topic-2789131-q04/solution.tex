For any $m=4k+1$, use transfer sizes $(2,1,3,4),(6,5,7,8),\ldots,(4k-2,4k-3,4k-1,4k)$, followed by $m$. In each four-move block starting with Jerry at 0, his successive holdings are $4i+2,1,4i+4,0$, so the play is legal whenever $N\ge m$. After the final move Jerry has $m$ coins and all sizes 1 through $m$ have been used; Tom cannot move. For 13 use $m=13$, achieving all 13, clearly maximal. For 50 use $m=49$, achieving 49. Jerry cannot finish with 50: if he did, Tom could use any unused size 1 through 50, so all 50 sizes would need to have been used. But 50 moves end with Tom's move, which decreases Jerry's holding, not with a Jerry move giving him all coins. Hence $\boxed{13,49}$.
