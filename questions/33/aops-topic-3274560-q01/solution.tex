Division gives $\boxed{\dfrac{3}{8}=0.375}$. But $\dfrac{1}{3}=0.333\ldots$ has infinitely many threes, and $\dfrac{1}{3}-0.333=\dfrac{1}{3000}>0$. Thus $0.333$ is only an approximation; an exact fraction need not be converted to be correct.
