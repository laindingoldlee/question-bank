The terms decrease geometrically (eventually $\dfrac{(n+1)^2}{3^{n+1}}\le\dfrac12\cdot\dfrac{n^2}{3^n}$), so all sums below converge.

First, $T=\displaystyle\sum_{n\ge1}\dfrac{n}{3^n}$: shifting the index, $\dfrac T3=\displaystyle\sum_{n\ge1}\dfrac{n-1}{3^n}$, so
\[T-\dfrac T3=\sum_{n\ge1}\dfrac1{3^n}=\dfrac12,\qquad T=\dfrac34.\]
Next, $S=\displaystyle\sum_{n\ge1}\dfrac{n^2}{3^n}$: similarly $\dfrac S3=\displaystyle\sum_{n\ge1}\dfrac{(n-1)^2}{3^n}$, so
\[S-\dfrac S3=\sum_{n\ge1}\dfrac{2n-1}{3^n}=2T-\dfrac12=1,\qquad S=\dfrac32.\]
So $\dfrac mk=\dfrac32$ and $m+k=\boxed{5}$.
