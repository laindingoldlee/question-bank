$29$ yards is $29\cdot36=1044$ inches, so each jump was $\dfrac{1044}{261}=4$ inches. With the hurt toe each jump is $3$ inches, so $29$ yards takes $\dfrac{1044}{3}=348$ jumps, which is $348-261=\boxed{87}$ more.
