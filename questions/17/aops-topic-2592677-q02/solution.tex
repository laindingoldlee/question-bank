For sides $n$, $n+1$, $n+2$, the hypotenuse is the longest side, so we need
\[n^2+(n+1)^2=(n+2)^2\iff n^2-2n-3=0\iff(n-3)(n+1)=0.\]
The only positive solution is $n=3$, giving the triangle $3,4,5$. There is $\boxed{1}$ such triple.
