A curve is given by $x=\sin^2(4y)$, with $0\le y\le\dfrac{\pi}{8}$.
\begin{enumerate}\item Find $y$ when $x=\dfrac{1}{4}$.
\item Find $\dfrac{dx}{dy}$.
\item For $0<x<1$, express $\dfrac{dy}{dx}$ as $\dfrac{1}{\sqrt{q+r(x+s)^2}}$ and identify $q,r,s$.
\item Find the minimum value of $\dfrac{dy}{dx}$ and where it occurs.\end{enumerate}
