Every maximal run has length 1,2, or 3. Choose the first bit in 2 ways; subsequent runs must alternate. Thus the count is twice the number of compositions of 12 into parts 1,2,3. If $c_0=1$ and $c_n=c_{n-1}+c_{n-2}+c_{n-3}$ with negative indices 0, then $c_1,\ldots,c_{12}=1,2,4,7,13,24,44,81,149,274,504,927$. The answer is $2c_{12}=\boxed{1854}$.
