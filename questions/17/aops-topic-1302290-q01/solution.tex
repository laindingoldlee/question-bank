The value is $(a+d)-bc$, where $b,c$ are multiplied. Since $a+d=9.05-(b+c)$, the value is $9.05-(b+c)-bc=10.05-(1+b)(1+c)$, so we want $(1+b)(1+c)$ as small as possible, which means choosing the two smallest numbers, $0.45$ and $1$, for $b$ and $c$. The maximum is
\[
6-0.45\times1+1.6=\boxed{7.15}
\]
(or $1.6-1\times0.45+6$). The identity $(a+d)-bc=10.05-(1+b)(1+c)$ replaces casework.
