If $a_i+a_{i+1}+a_{i+2}=13=a_{i+1}+a_{i+2}+a_{i+3}$, then $a_i=a_{i+3}$ (indices mod $13$). Since $\gcd(3,13)=1$, stepping by $3$ reaches every position, so all numbers are equal, to $a$ say, and $3a=13$, impossible for an integer. So $\boxed{\text{no}}$.
