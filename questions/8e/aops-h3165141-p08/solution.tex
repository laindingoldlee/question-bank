Count boundaries between differently coloured adjacent sections. Each of the four boundaries survives with probability $\dfrac{3}{4}$, so the expected surviving-boundary count is $3$. When at least one boundary survives, this is the number of final sections. The only exception is a monochromatic spinner, where there are no boundaries but one section. Its probability is $\dfrac{4}{4^4}=\dfrac{1}{64}$. Thus the expected number is $3+\dfrac{1}{64}=\dfrac{193}{64}$, giving $\boxed{m+n=257}$.
