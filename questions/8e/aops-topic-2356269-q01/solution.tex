Write $x=7k+4$. Modulo $49$, the value of $x$ depends on $k\bmod7$: $k=0,1,\dots,6$ give
\[x\equiv4,\ 11,\ 18,\ 25,\ 32,\ 39,\ 46\pmod{49},\]
and $k$ and $k+7$ give the same residue since $7\cdot7=49$. So there are $7$ possible values: $\boxed{4,11,18,25,32,39,46}$.
