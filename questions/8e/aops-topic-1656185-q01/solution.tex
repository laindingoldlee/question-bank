Use coordinates $A=(0,0)$, $B=(4,0)$, $C=(4,3)$, $D=(0,3)$, $M=(2,3)$, and let $X=AC\cap BM$. Triangles $XAB$ and $XCM$ are similar ($AB\parallel MC$) with ratio $AB:CM=4:2$, so $X$ divides the height $3$ in the ratio $2:1$: $X$ is at height $2$ (indeed $X=\left(\dfrac{8}{3},2\right)$).

\begin{asy}
usepackage("amsmath");
size(5.5cm);
defaultpen(fontsize(10pt));
pair A=(0,0),B=(4,0),C=(4,3),D=(0,3),M=(2,3);pair X=extension(A,C,B,M);
draw(A--B--C--D--cycle,linewidth(0.9));draw(A--C);draw(B--M);
dot(M);dot(X);
label("$A$",A,SW);label("$B$",B,SE);label("$C$",C,NE);label("$D$",D,NW);label("$M$",M,N);label("$X$",X,E);
label("$5$",(1.1,2.1));label("$4$",(2.4,0.6));label("$2$",(3.6,1.6),fontsize(9pt));label("$1$",(2.9,2.75),fontsize(8pt));
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

The regions are:
\begin{itemize}
\item triangle $ABX$: $\dfrac{1}{2}\cdot4\cdot2=4$;
\item triangle $MCX$: $\dfrac{1}{2}\cdot2\cdot1=1$;
\item triangle $BCX$: base $BC=3$, height $4-\dfrac{8}{3}=\dfrac{4}{3}$, area $2$;
\item quadrilateral $AXMD$: $12-4-1-2=5$.
\end{itemize}
In decreasing order $5,4,2,1$, so $[R_1]-[R_2]+[R_3]-[R_4]=5-4+2-1=\boxed{\textbf{(a)}\ 2}$.
