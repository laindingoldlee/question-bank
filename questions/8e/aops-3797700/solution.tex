Differentiation gives $f\prime(x)=\dfrac{1-2x-x^2}{(1+x^2)^2}$, with zeros $-1\pm\sqrt2$. On $[-1+\sqrt2,\infty)$ the function is strictly decreasing, hence injective. Any interval starting to the left includes values on both sides of the local maximum at $-1+\sqrt2$, so it is not injective. Thus $r=\sqrt2-1$ and $\boxed{\lfloor100r\rfloor=41}$, since $1.41<\sqrt2<1.42$.
