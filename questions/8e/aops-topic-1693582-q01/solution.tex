Since $2.236^2=4.999696<5<5.00014321=2.2361^2$, we have $2.236<\sqrt5<2.2361$, so $0.618<y<0.61805$.
\begin{itemize}
\item $2009y$ lies between $2009\cdot0.618=1241.562$ and $2009\cdot0.61805=1241.66$, so $\lfloor2009y\rfloor=1241$.
\item Then $y\lfloor2009y\rfloor+y=1242y$ lies between $1242\cdot0.618=767.556$ and $1242\cdot0.61805=767.62$, so its floor is $767$.
\item $2010y$ lies between $1242.18$ and $1242.29$, so $\lfloor2010y\rfloor=1242$.
\end{itemize}
The value is $767+1242=\boxed{2009}$.
