In one attempt each answer is right with probability $\dfrac{1}{1000}$, independently, so the whole test is right with probability
\[
p=\left(\dfrac{1}{1000}\right)^{15}=10^{-45}.
\]
The number of attempts until the first success has a geometric distribution with success probability $p$, whose mean is $\dfrac{1}{p}$. So the expected number of attempts is $\boxed{10^{45}}$.
