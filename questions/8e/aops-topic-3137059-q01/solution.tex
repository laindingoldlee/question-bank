Both sets contain the 50 odd integers 1,3,\ldots,99. The first has 101 equally likely outcomes, giving $\boxed{\dfrac{50}{101}}$. The second has 100 outcomes, giving $\boxed{\dfrac{1}{2}}$. Including the extra even number 0 changes the denominator but not the favourable count.
