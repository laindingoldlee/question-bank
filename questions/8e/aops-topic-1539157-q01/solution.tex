We need $a^2=b!+10$.

\textbf{Small $b$.} For $b=0$ and $b=1$: $a^2=11$, impossible. For $b=2$: $a^2=12$, impossible. For $b=3$: $a^2=16$, so $a=\pm4$.

\textbf{$b\ge4$.} Then $4\mid b!$, so $a^2=b!+10\equiv2\pmod4$. But a square is $\equiv0$ or $1\pmod4$, a contradiction.

So the solutions are $\boxed{(a,b)=(4,3)\text{ and }(-4,3)}$.
