Suppose, for contradiction, that \(x^n+y^n=z^n\) with \(n\ge z\). By symmetry assume \(x\le y\). Since \(z^n>y^n\), we have \(z>y\), so \(z\ge y+1\). By the binomial theorem,
\[
z^n\ge (y+1)^n\ge y^n+ny^{n-1},
\]
so \(x^n=z^n-y^n\ge ny^{n-1}\).

On the other hand, \(x\le y\) and \(x<z\le n\), so
\[
x^n=x\cdot x^{n-1}\le x\cdot y^{n-1}<n\,y^{n-1}.
\]
This contradicts the previous inequality. Hence there is no solution with \(n\ge z\). \(\blacksquare\)
