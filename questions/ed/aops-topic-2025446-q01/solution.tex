\textbf{(a)} Write the middle number as $x=n$, so the set is $n-2,n-1,n,n+1,n+2$. The condition becomes
\[
(n-2)^2+(n-1)^2+n^2=(n+1)^2+(n+2)^2,
\]
that is, $3n^2-6n+5=2n^2+6n+5$, or $n^2-12n=0$. So $n=0$ or $n=12$, and every solution is one of the two sets
\[
\{-2,-1,0,1,2\}\qquad\text{and}\qquad\{10,11,12,13,14\}.
\]
Both work: $4+1+0=1+4$ and $100+121+144=365=169+196$. So there are exactly two sets.

\textbf{(b)} The sums are $0$ and $60$, so the average of the ten numbers is $\dfrac{60}{10}=\boxed{6}$.

\textbf{(c)} The possible values of $z$ are $2$ and $14$, so the maximum is $\boxed{14}$ and the minimum is $\boxed{2}$.
