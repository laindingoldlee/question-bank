Divisors pair as $d$ and $\dfrac{i}{d}$, so $d(i)$ is odd exactly when $i$ is a square. Therefore $\sum_{i=1}^n d(i)$ is odd exactly when $\lfloor\sqrt n\rfloor$ is odd.

For an odd integer $k$, this occurs on $k^2\le n\le(k+1)^2-1$, an interval of $2k+1$ integers. Since $44^2=1936<2023<45^2=2025$, all contributing intervals have $k=1,3,\ldots,43$, and each is complete. Thus
\[
r=\sum_{j=0}^{21}(4j+3)=4\cdot231+66=990.
\]
The requested digit sum is $\boxed{18}$.
