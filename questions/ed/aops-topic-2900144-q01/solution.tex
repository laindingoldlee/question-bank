Suppose a prime $p$ divides both numbers. Since $p\mid a^nc^mb^k$, $p$ divides $a$, $b$ or $c$.

If $p\mid a$, then $p\mid(a^n+c^mb^k)-a^n=c^mb^k$, so $p\mid b$ or $p\mid c$. This contradicts $\gcd(a,b)=\gcd(a,c)=1$.

If $p\mid b$ or $p\mid c$, then $p\mid c^mb^k$, so $p\mid a^n$ and $p\mid a$, the same contradiction.

Hence the gcd is $1$. $\blacksquare$
