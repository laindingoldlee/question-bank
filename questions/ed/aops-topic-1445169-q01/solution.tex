The order in which the machine releases the $8$ items is a uniformly random ordering of them: the first item is uniform among the $8$, the second uniform among the remaining $7$, and so on. The child in place $k$ gets the $k$th item released. In a random ordering, the lollipop is equally likely to be in each of the $8$ positions, so every child gets it with probability $\dfrac{1}{8}$.

Directly, for place $k$:
\[
P(\text{lollipop at place }k)=\dfrac{7}{8}\cdot\dfrac{6}{7}\cdots\dfrac{8-k+1}{8-k+2}\cdot\dfrac{1}{8-k+1}=\dfrac{8-k+1}{8}\cdot\dfrac{1}{8-k+1}=\dfrac{1}{8} .
\]
So \textbf{no place is better than another}: every place has probability $\boxed{\dfrac{1}{8}}$.
