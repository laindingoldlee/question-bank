The first $n$ rows use $1^2+2^2+\cdots+n^2=\dfrac{n(n+1)(2n+1)}{6}$ triangles. For $n=13$ this is $\dfrac{13\cdot14\cdot27}{6}=819\le1000$, and for $n=14$ it is $\dfrac{14\cdot15\cdot29}{6}=1015>1000$. So he can make $\boxed{13}$ full rows (with $181$ triangles left over).
