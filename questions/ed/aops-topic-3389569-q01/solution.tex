Subtracting adjacent three-digit sums gives $d_i=d_{i+3}$ wherever both sides occur. Thus the string repeats a three-digit pattern. Positions $2,5$ contain $6$, and positions $3,12$ contain $8$. The first pattern digit is $17-6-8=3$. Hence $d_1+d_9+d_{10}=3+8+3=\boxed{14}$.
