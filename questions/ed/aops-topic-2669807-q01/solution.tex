Let the edges be $a\le b\le c$. The condition $abc=2(ab+bc+ca)$ is equivalent to
\[\dfrac1a+\dfrac1b+\dfrac1c=\dfrac12.\]
Since $\dfrac1a<\dfrac12\le\dfrac3a$, we have $3\le a\le6$.
\begin{itemize}
\item $a=3$: $\dfrac1b+\dfrac1c=\dfrac16$, i.e. $(b-6)(c-6)=36$ with $0<b-6\le c-6$. So $b-6\in\{1,2,3,4,6\}$, giving $(b,c)=(7,42),(8,24),(9,18),(10,15),(12,12)$.
\item $a=4$: $(b-4)(c-4)=16$ with $0<b-4\le c-4$, giving $(5,20),(6,12),(8,8)$.
\item $a=5$: $\dfrac1b+\dfrac1c=\dfrac3{10}$, i.e. $(3b-10)(3c-10)=100$. Here $5\le3b-10\le10$ and $3b-10\equiv2\pmod3$, so $3b-10=5$: $(b,c)=(5,10)$.
\item $a=6$: $\dfrac1b+\dfrac1c=\dfrac13$ with $6\le b\le c$ forces $b=c=6$.
\end{itemize}
So there are ten boxes:
\[\boxed{3\times7\times42,\ 3\times8\times24,\ 3\times9\times18,\ 3\times10\times15,\ 3\times12\times12,\ 4\times5\times20,\ 4\times6\times12,\ 4\times8\times8,\ 5\times5\times10,\ 6\times6\times6}.\]
