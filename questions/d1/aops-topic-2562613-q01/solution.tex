At minute $t$ Alice writes $-120+8t$ and Bob writes $-14+3t$. Alice reaches $300$ when $8t\ge420$, i.e. $t\ge52.5$, so first at $t=53$ (with $304$). Bob would need $3t\ge314$, i.e. $t\ge105$. So Alice is first, at $t=53$, when Bob writes $-14+159=145$. The difference is $304-145=\boxed{159}$.
