Call $n$ attainable if $n=9a+13b+17c$ with $a,b,c\ge0$.

\textbf{From $60$ on, everything is attainable.} The nine consecutive numbers $60,\ldots,68$ are attainable:
\[60=13\cdot2+17\cdot2,\quad 61=9+13\cdot4,\quad 62=9\cdot4+13\cdot2,\quad 63=9\cdot7,\quad 64=13+17\cdot3,\]
\[65=13\cdot5,\quad 66=9\cdot3+13\cdot3,\quad 67=9\cdot6+13,\quad 68=17\cdot4 .\]
Adding packs of $9$ reaches every larger number.

\textbf{$59$ is not attainable.} List the values $13b+17c\le59$ and check whether $59$ minus each is a multiple of $9$:
\begin{itemize}
\item $c=0$: $59-0,\ 59-13,\ 59-26,\ 59-39,\ 59-52$ are $59,46,33,20,7$;
\item $c=1$: $59-17,\ 59-30,\ 59-43,\ 59-56$ are $42,29,16,3$;
\item $c=2$: $59-34,\ 59-47$ are $25,12$;
\item $c=3$: $59-51=8$.
\end{itemize}
None is a multiple of $9$. So the answer is $\boxed{59}$.
