We need $3a+5b=70$ with nonnegative integers $a,b$ and want to minimise $10a+20b$. Per metre the short pipes are cheaper ($\dfrac{10}{3}<\dfrac{20}{5}$), so we want $b$ as small as possible. Since $3a=70-5b$, $5b\equiv70\equiv1\pmod3$, so $b\equiv2\pmod3$. The least is $b=2$, $a=20$, costing $200+40=\boxed{\$240}$. (The other options $b=5,8,11,14$ cost $\$250,\$260,\$270,\$280$.)
