The first error adds $100$ to the multiplier, so $100\cdot(\text{multiplicand})=3800$ and the multiplicand is $38$. The second adds $30$ to the multiplicand, so $30\cdot(\text{multiplier})=6030$ and the multiplier is $201$. Both digits match, and the product is $38\cdot201=\boxed{7638}$.
