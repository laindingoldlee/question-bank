For integers the inequality means $x^2+y^2+z^2+4\le xy+3y+2z$, i.e.
\[\left(x-\dfrac y2\right)^2+3\left(\dfrac y2-1\right)^2+(z-1)^2\le0.\]
So $y=2$, $x=1$, $z=1$. Check: $1+4+1+3=9<2+6+2=10$. The only triple is $\boxed{(1,2,1)}$.
