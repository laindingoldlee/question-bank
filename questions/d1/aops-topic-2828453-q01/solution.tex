If each leg has length $ d>0 $, total time is $\dfrac{d}{40}+\dfrac{d}{60}=\dfrac{d}{24}$ hours. Total distance is $ 2d $, so average speed is $\boxed{48\text{ mph}}$. The slower leg takes more time, so the arithmetic mean of the speeds is inappropriate.
