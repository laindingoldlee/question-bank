(a) $\dfrac1{x^{-n}}=x^n$, so the left side is $x^{2m}\cdot x^{2n}=x^{2m+2n}=x^{2(m+n)}$.

(b) $\dfrac{y}{y^{-n}}=y^{1-(-n)}=y^{n+1}$, so the left side is $y^m\cdot y^{n+1}=y^{m+n+1}$. $\blacksquare$
