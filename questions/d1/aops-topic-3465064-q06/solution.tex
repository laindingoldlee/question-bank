The constant term shows $x\ne0$. Divide by $x^2$ and let $t=x+\dfrac{1}{x}$. Then $x^2+x^{-2}=t^2-2$, so the equation becomes $t^2+4t=0$. If $t=0$, then $x^2+1=0$ giving $x=\pm i$. If $t=-4$, then $x^2+4x+1=0$ giving $x=-2\pm\sqrt3$. Thus all four roots are $\boxed{i,-i,-2+\sqrt3,-2-\sqrt3}$.
