The mixed number $1\dfrac{1}{b}$ means $1+\dfrac{1}{b}=\dfrac{b+1}{b}$. So $\dfrac {a}{b}=1\dfrac{1}{b}$ exactly when $a=b+1$. It fails otherwise; for example $\dfrac{5}{2}=2\dfrac{1}{2}$, not $1\dfrac{1}{2}$. (The rule works for $\dfrac{4}{3},\dfrac{5}{4},\dots$ because in each the numerator is one more than the denominator.)
