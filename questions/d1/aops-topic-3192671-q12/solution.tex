Mark an occurrence of SUS and treat it as a block. The remaining letters are $S,U,B$, so there are $4!=24$ marked arrangements. Two occurrences must overlap to form SUSUS, since there are only three $S$ letters. This happens only in BSUSUS and SUSUSB, each counted twice. Hence there are $24-2=\boxed{22}$ distinct strings.
