Multiply the three equations: $(mn)(np)(mp)=pmn$, that is, $(mnp)^2=mnp$. So $mnp=0$ or $mnp=1$.

\textbf{Case $mnp=0$.} If $m=0$, then $p=mn=0$ and $n=mp=0$. Similarly $n=0$ forces $p=mn=0$ and then $m=np=0$, and $p=0$ forces $m=np=0$ and $n=mp=0$. So the only triple is $(0,0,0)$, which works.

\textbf{Case $mnp=1$.} Integers with product $1$ are each $\pm1$, with an even number of $-1$s:
\[
(1,1,1),\quad(1,-1,-1),\quad(-1,1,-1),\quad(-1,-1,1).
\]
Each works: for $m,n,p\in\{1,-1\}$ with $mnp=1$ we have $p=\dfrac{1}{mn}=mn$, and likewise $m=np$ and $n=mp$.

So there are $1+4=\boxed{5}$ ordered triples.
