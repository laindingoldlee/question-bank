We need $x\ne a$ and $x\ne b$. Put $u=\dfrac{x-a}{b}$ and $v=\dfrac{x-b}{a}$, both non-zero. The equation becomes
\[
u+v=\dfrac{1}{u}+\dfrac{1}{v}=\dfrac{u+v}{uv},\qquad\text{i.e.}\qquad (u+v)(uv-1)=0 .
\]
\emph{Case $uv=1$:} $(x-a)(x-b)=ab$, i.e.\ $x^2-(a+b)x=0$, so $x=0$ or $x=a+b$. Both are allowed: $0\ne a,b$, and $a+b\ne a,b$ since $a,b\ne0$.

\emph{Case $u+v=0$:} $a(x-a)+b(x-b)=0$, i.e.\ $(a+b)x=a^2+b^2$. If $a+b=0$ there is no solution (as $a^2+b^2>0$). If $a+b\ne0$, $x=\dfrac{a^2+b^2}{a+b}$; this equals $a$ iff $a^2+b^2=a^2+ab$ iff $b=a$ (and similarly for $b$), so it is allowed iff $a\ne b$.

\textbf{Answer.}
\begin{itemize}
\item If $a\ne\pm b$: $\boxed{x=0,\quad x=a+b,\quad x=\dfrac{a^2+b^2}{a+b}}$ (three distinct solutions).
\item If $a=b$: $x=0$ and $x=2a$.
\item If $a=-b$: only $x=0$ (here $a+b=0$).
\end{itemize}
