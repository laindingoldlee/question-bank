In each case, first simplify and then isolate the unknown.

\textbf{(a)} $40-2y=20.4$, so $2y=19.6$ and $y=\boxed{9.8}$.

\textbf{(b)} $40-39.2x=20.4$, so $39.2x=19.6$ and $x=\boxed{0.5}$.

\textbf{(c)} $40-4.9a=20.4$, so $4.9a=19.6$ and $a=\boxed{4}$.
