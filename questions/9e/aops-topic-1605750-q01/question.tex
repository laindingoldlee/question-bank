A student argues as follows. ``The sum of the first $n$ positive integers is $\dfrac{n(n+1)}{2}$. For $1+2+3+\cdots$ we have $n=\infty$, so the sum is $\dfrac{\infty(\infty+1)}{2}$. If this equalled $-\dfrac{1}{12}$, then $\infty^2+\infty+\dfrac{1}{6}=0$, so $\infty$ would be one of the roots $\dfrac{-3\pm\sqrt3}{6}$ of this quadratic, which is absurd. Therefore $1+2+3+\cdots\ne-\dfrac{1}{12}$.''
\begin{enumerate}
\item[(a)] Explain what is wrong with this argument.
\item[(b)] Give a correct proof that the series $1+2+3+\cdots$ does not converge to $-\dfrac{1}{12}$ (or to any real number).
\end{enumerate}
