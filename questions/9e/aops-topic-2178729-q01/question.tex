Nathan has a collection of weights each weighing either $1$, $2$, $3$ or $5$ pounds, and he has an unlimited number of weights of each kind. In how many ways can he measure out eight pounds, that is, choose a collection of weights with total weight $8$ pounds? (Only the number of weights of each kind matters.)

$\mathrm{(A)}\ 11\qquad\mathrm{(B)}\ 12\qquad\mathrm{(C)}\ 13\qquad\mathrm{(D)}\ 14\qquad\mathrm{(E)}\ 15$
