DRANOLISCOOL has $12$ letters: three O's, two L's, and D, R, A, N, I, S, C once each. The number of distinguishable arrangements is
\[\dfrac{12!}{3!\,2!}=39916800.\]
ROLAND uses R, O, L, A, N, D once each, and since there is only one R it can appear at most once. Glue it into a single block; the remaining letters are I, S, C, O, O, L. Arranging the block and these $6$ letters (two of them O's) gives
\[\dfrac{7!}{2!}=2520\]
arrangements, each containing ROLAND exactly once, and every arrangement containing ROLAND arises exactly once. The probability is
\[\dfrac{2520}{39916800}=\boxed{\dfrac{1}{15840}}.\]
