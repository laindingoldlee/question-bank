A student makes the following conjecture.

\emph{Let $x$ and $y$ be positive integers, at least one of which is odd. Then every integer $n$ can be written using only additions and subtractions of copies of $x$ and $y$, each used as often as we like.}

For example, with $x=7$ and $y=12$ we have $15=12-7+12-7+12-7$.
\begin{enumerate}
\item[(a)] Show that the conjecture is false.
\item[(b)] Prove that every integer can be written in this way if and only if $\gcd(x,y)=1$.
\end{enumerate}
