Run the Euclidean algorithm on $28$ and $13$:
\[28=2\cdot13+2,\qquad13=6\cdot2+1.\]
Work backwards to write $1$ as a combination of $13$ and $28$:
\[1=13-6\cdot2=13-6\,(28-2\cdot13)=13\cdot13-6\cdot28.\]
So $13\cdot13\equiv1\pmod{28}$, and the inverse is $\boxed{13}$. (Check: $13^2=169=6\cdot28+1$.)

The same back-substitution works for any $a$ coprime to $m$: it produces $ax+my=1$, and $x$ reduced modulo $m$ is the inverse.
