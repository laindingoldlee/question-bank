The five-letter block can start in any of four positions. Its capitalization has $2^5=32$ choices. For the three digits $d_1,d_2,d_3$, set $e_i=9-d_i$. Then $e_1+e_2+e_3=27-25=2$. Every nonnegative solution automatically has $e_i\le9$, so stars and bars gives $\binom42=6$ ordered digit triples. The choices are independent and determine the password uniquely. Thus
\[
\boxed{4\cdot32\cdot6=768}.
\]
