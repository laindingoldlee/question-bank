Write the number as $2020+100h+u$ with $0\le h,u\le9$. Divisibility by $7$ is equivalent to $4+2h+u\equiv0\pmod7$. For $h=0,1,\ldots,9$, the respective numbers of admissible units digits are
\[
1,2,1,1,2,2,1,1,2,1.
\]
For example $h=1$ allows $u=1,8$, whereas $h=0$ allows only $u=3$. Their sum is $\boxed{14}$.
