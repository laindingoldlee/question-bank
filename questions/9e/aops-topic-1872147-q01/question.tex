For integers $n\ge5$ define $f(n)$ as follows: if $n$ is prime, $f(n)=n+1$; if $n$ is composite, $f(n)$ is the sum of the prime factors of $n$ counted with multiplicity (for example $f(20)=2+2+5=9$). Prove that if we start from any $n\ge5$ and apply $f$ repeatedly, we eventually reach $6$. (For example $1001\to31\to32\to10\to7\to8\to6$.)
