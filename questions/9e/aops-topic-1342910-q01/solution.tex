Since $35=5\cdot7$ with $\gcd(5,7)=1$, we need $n^3-n+1\equiv0$ both modulo $5$ and modulo $7$.

Modulo $5$, try $n\equiv0,1,2,3,4$: the values of $n^3-n+1$ are $1,1,7,25,61\equiv1,1,2,0,1$. So $n\equiv3\pmod 5$.

Modulo $7$, try $n\equiv0,1,\dots,6$: the values are $1,1,7,25,61,121,211\equiv1,1,0,4,5,2,1$. So $n\equiv2\pmod 7$.

By the Chinese remainder theorem these combine into a single class modulo $35$. Among $3,8,13,18,23,28,33$ (the numbers $\equiv3\pmod5$) the one that is $\equiv2\pmod7$ is $23$. Hence
\[
\boxed{n\equiv23\pmod{35}},\qquad\text{that is, } n=23,58,93,\dots
\]
Check: $23^3-23+1=12145=35\cdot347$.
