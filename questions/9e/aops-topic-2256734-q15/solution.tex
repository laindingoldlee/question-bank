Both bags sell for $\dfrac{21}{35}=\dfrac{24}{40}=0.6$ dollars per cookie, so the money is $0.6$ times the number of cookies sold, and we want to sell as many as possible. Can all $2020$ be sold? We need $35r+40y=2020$, i.e. $7r+8y=404$. Then $7r\equiv404\equiv4\pmod8$, so $r\equiv4\pmod8$; $r=4$ gives $y=\dfrac{404-28}{8}=47$. So $4$ red and $47$ yellow bags sell all cookies, for $0.6\cdot2020=\boxed{\textbf{(D) }1212}$ dollars ($4\cdot21+47\cdot24=84+1128=1212$).
