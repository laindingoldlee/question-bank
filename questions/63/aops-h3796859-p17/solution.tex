The year contributes digits $2,3$, so neither may occur in day or month. The only possible months are $01,04,05,06,07,08,09,10$. Months $01,10$ allow no day, since every valid day has a tens digit among $0,1,2,3$, all already used or forbidden. For each month $04$ through $09$, the day must start with $1$, and its units digit can be any of $4,5,6,7,8,9$ except that month\textquotesingle s units digit: five choices. These days are all valid in each month. Thus there are $6\cdot5=\boxed{30}$ beautiful dates.
