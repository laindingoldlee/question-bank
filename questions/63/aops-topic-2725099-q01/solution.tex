Write $a=q_1c$ and $b=q_2c$ with integers $q_1,q_2$. Then $a-b=(q_1-q_2)c$, and $q_1-q_2$ is an integer, so $c\mid a-b$. $\blacksquare$ (The poster's proof is correct; its last line should say that $c$ divides $a-b$ because $a-b=c(q_1-q_2)$ with $q_1-q_2$ an integer.)
