A factor is $2^a3^b5^c7^d$ with $a\le3$, $b\le4$, $c\le6$, $d\le8$. Since $7^4=2401>2018$, we need $d\le3$. Sort by $d$ and look for $m=2^a3^b5^c$ ($a\le3$, $b\le4$) with $1000<7^dm<2018$.
\begin{itemize}
\item $d=3$: $2.9<m<5.9$, so $m=3,4,5$: $1029$, $1372$, $1715$. ($3$ factors)
\item $d=2$: $20.4<m<41.2$, so $m=24,25,27,30,36,40$ ($32=2^5$ is not allowed): $1176,1225,1323,1470,1764,1960$. ($6$)
\item $d=1$: $142.8<m<288.3$, so $m=150,162,180,200,216,225,250,270$ (not $144=2^4\cdot9$, $160$, $192$, $240$, $243=3^5$, $256$, $288$): $1050,1134,1260,1400,1512,1575,1750,1890$. ($8$)
\item $d=0$: $1000<m<2018$, so $m=1080,1125,1250,1350,1500,1620,1800,1875$ (not $1024$, $1152$, $1200$, $1215$, $1280$, $1296$, $1440$, $1458$, $1536$, $1600$, $1728$, $1920$, $1944$, $2000$, which need $2^4$ or $3^5$ or more). ($8$)
\end{itemize}
In total $3+6+8+8=\boxed{25}$ factors.
