The base has side $\dfrac{36}{4}=9$ cm. The cut is $4$ cm above the base, so the top pyramid has height $12-4=8$ cm. It is similar to the whole pyramid with ratio $\dfrac{8}{12}=\dfrac{2}{3}$, so its base has side $\dfrac{2}{3}\cdot9=6$ cm (the height $12$ is split as $4+8$):

\begin{asy}
usepackage("amsmath");
size(5.5cm);
defaultpen(fontsize(10pt));
pair P(real x,real y,real z){ return (x+0.45*y,z+0.3*y); }
real a=9,h=12;
pair A=P(0,0,0),B=P(a,0,0),C=P(a,a,0),D=P(0,a,0),T=P(a/2,a/2,h);
real s=2/3; real z0=h/3;
pair A1=P(a/2-s*a/2,a/2-s*a/2,z0),B1=P(a/2+s*a/2,a/2-s*a/2,z0),C1=P(a/2+s*a/2,a/2+s*a/2,z0),D1=P(a/2-s*a/2,a/2+s*a/2,z0);
pair O=P(a/2,a/2,0),O1=P(a/2,a/2,z0);
fill(A1--B1--C1--D1--cycle,paleblue);
draw(A--B--C,linewidth(0.9));draw(C--D--A,dashed);
draw(A--T,linewidth(0.9));draw(B--T,linewidth(0.9));draw(C--T,linewidth(0.9));draw(D--T,dashed);
draw(A1--B1--C1,blue);draw(C1--D1--A1,blue+dashed);
draw(T--O,dashed);dot(O);dot(O1);
label("$9$",(A+B)/2,S);
label("$4$",O+(0,0.65),E);
label("$8$",O1+(0,2.5),E,blue);
label("$6$",(A1+B1)/2,S,blue);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

Its volume is
\[
\dfrac{1}{3}\cdot6^2\cdot8=\boxed{96}\text{ cm}^3 .
\]
(Equivalently, $\left(\dfrac{2}{3}\right)^3$ of the whole volume $\dfrac{1}{3}\cdot81\cdot12=324$.)
