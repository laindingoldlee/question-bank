Pair $k$ with $1314-k$ for $k=1,\dots,656$: since $135$ is odd, $(1314-k)^{135}\equiv(-k)^{135}=-k^{135}\pmod{1314}$, so each pair contributes $0$. The unpaired term is $657^{135}$. Now $1314=2\cdot657$ and $657^{135}$ is an odd multiple of $657$, so $657^{135}\equiv657\pmod{1314}$. The remainder is $\boxed{657}$.
