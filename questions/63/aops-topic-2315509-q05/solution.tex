Halloween in month-day-year form must read $10$-$31$-, which uses the digits $1,0,3,1$. The remaining digits $0,1,2,3$ (all different) form the year. They can be arranged in $4!=24$ orders, of which $3!=6$ begin with $0$. So there are $24-6=\boxed{18}$ ways (including the original $2013$).
