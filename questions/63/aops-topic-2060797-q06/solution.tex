For $h\ge3$ we have $2h\ge6>5\ge\dfrac{15}{h}$, so $S(h)=2h-\dfrac{15}{h}$ for all the hours involved. Hence
\[\sum_{h=8}^{18}S(h)=2\sum_{h=8}^{18}h-15\sum_{h=8}^{18}\dfrac{1}{h}=2\cdot143-15H,\qquad H=\dfrac{1}{8}+\dfrac{1}{9}+\cdots+\dfrac{1}{18}\approx0.90225 .\]
So the sum is about $286-13.534=272.466$, and the average is
\[\dfrac{272.466}{11}\approx24.770\approx\boxed{24.8}.\]
(Treating the day as continuous, the average value of $2h-\dfrac{15}{h}$ on $[8,18]$ is $\dfrac{1}{10}\left[h^2-15\ln h\right]_8^{18}=26-1.5\ln\dfrac{9}{4}\approx24.78$, which also rounds to $24.8$.)
