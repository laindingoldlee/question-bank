Let $L(N)$ count the numbers up to $N$ with leading digit $2$. We need $L(N)=0.36N$. Check each range of $N$:

$N\le9$: $L\le1$, impossible. $20\le N\le29$: $L=N-18$, giving $N=28.125$. $30\le N\le199$: $L=11$, giving $N=30.6$. $200\le N\le299$: $L=N-188$, giving $N=293.75$. $300\le N\le1999$: $L=111$, giving $N=308.3$. $2000\le N\le2999$: $L=N-1888$, giving $0.64N=1888$, $N=2950$.

So the first such $N$ is $\boxed{2950}$ (check: $1062$ of $2950$ is $36\%$).
