The fractions are $\dfrac{a}{30}$ with $1\le a<300$ and $\gcd(a,30)=1$. In each block of $30$ numerators, the admissible residues are $1,7,11,13,17,19,23,29$, so there are $80$ fractions. Pair numerator $a$ with $300-a$. Each pair of fractions sums to $10$; no numerator is fixed because $150$ is inadmissible. There are $40$ pairs, giving $\boxed{400}$.
