Since the digit $9$ appears, $b\ge10$. Factor:
\[
792_b=7b^2+9b+2=(7b+2)(b+1),\qquad 297_b=2b^2+9b+7=(2b+7)(b+1).
\]
So we need $2b+7\mid7b+2$. Then $2b+7$ also divides $2(7b+2)-7(2b+7)=-45$. With $b\ge10$, $2b+7\ge27$, and the only divisor of $45$ that large is $45$, giving $b=19$. Check: $7\cdot19+2=135=3\cdot45$, so $792_{19}=3\cdot297_{19}$. The base is $\boxed{19}$.
