The expressions inside the absolute values change sign at $x=-2$ and $x=3$.
\begin{itemize}
\item For $x\le-2$: $f(x)=(3-x)+(-x-2)=1-2x$.
\item For $-2\le x\le3$: $f(x)=(3-x)+(x+2)=5$.
\item For $x\ge3$: $f(x)=(x-3)+(x+2)=2x-1$.
\end{itemize}
So the graph is a ``flat-bottomed V'': a horizontal segment at height $5$ from $(-2,5)$ to $(3,5)$, with rays of slope $-2$ to the left and slope $2$ to the right. The minimum value $5$ is the distance between $-2$ and $3$ on the number line.
\begin{asy}
usepackage("amsmath");
size(5.5cm);
defaultpen(fontsize(10pt));
import graph;
real f(real x){return abs(x-3)+abs(x+2);}
draw(graph(f,-4.5,5.5),blue+linewidth(1));
xaxis(-5.5,6.5,Arrow); yaxis(-0.8,11.5,Arrow);
dot((-2,5)); dot((3,5));
label("$(-2,5)$",(-2,5),SW); label("$(3,5)$",(3,5),SE);
draw((-2,0)--(-2,5),gray+dashed); draw((3,0)--(3,5),gray+dashed);
label("$y=1-2x$",(-4,9),W,blue); label("$y=2x-1$",(5,9),E,blue);
label("$x$",(6.5,0),S); label("$y$",(0,11.5),E);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}
