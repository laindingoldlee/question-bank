A bag contains $5$ red marbles and $3$ blue marbles, and all $8$ marbles are placed in a row.
\begin{enumerate}
\item[(a)] How many different rows are possible if marbles of the same colour are indistinguishable, so that only the pattern of colours matters?
\item[(b)] How many different rows are possible if all $8$ marbles are distinguishable (for example, each has a different number written on it)?
\item[(c)] Explain why the answer to (b) is the answer to (a) multiplied by $5!\cdot3!$.
\end{enumerate}
