Put $T(n)=s(n+87)$ and $U(m)=s(m)+87$. The equation is $f(T(n))=U(f(n))$. The orbit $1,16,4,10,7,13,1$ under $T$ has period six, so $U^6(f(1))=f(1)$. Every periodic point of $U$ lies in $[88,105]$: $U(m)\ge88$, the interval is closed under $U$, and for $m\ge106$ the value decreases until entering it (for a number at least $100$, $m-s(m)\ge99$). Listing $U$ on this short interval gives exactly four cycles: $(90,96,102)$, $(91,97,103)$, $(92,98,104)$, $(93,99,105)$. Hence at most twelve values are possible. All occur. Choose any cycle member $v$ for $f(1)$ and define $f$ on residues $1,7,4$ modulo $9$ as $v,U(v),U^2(v)$, respectively. On each of the residue cycles $(2,8,5)$ and $(3,0,6)$ use values $90,96,102$ in order. Since $T(n)\equiv n+6\pmod9$, this definition satisfies $f(T(n))=U(f(n))$ everywhere. All twelve values are below $1000$, so the answer is $\boxed{12}$.
