Count segment starts. Link 1 starts a segment if it remains, with probability $\dfrac{5}{7}$. For each $i=2,\ldots,7$, link $i$ starts a segment exactly if $i-1$ is removed and $i$ remains, which has probability $\dfrac{2}{7}\dfrac{5}{6}=\dfrac{5}{21}$. By linearity of expectation the answer is $\dfrac{5}{7}+6\dfrac{5}{21}=\boxed{2\dfrac{1}{7}}$.
