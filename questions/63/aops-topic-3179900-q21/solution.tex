The sum is $\dfrac{7}{2}S$, where $S=\sum_{i\ge1}\dfrac{i^2}{2^i}$. First $T=\sum_{i\ge1}\dfrac{i}{2^i}$ satisfies $T-\dfrac{T}{2}=\sum_{i\ge1}\dfrac{1}{2^i}=1$, so $T=2$. Next $S-\dfrac{S}{2}=\sum_{i\ge1}\dfrac{2i-1}{2^i}=2T-1=3$, giving $S=6$. The result is $\boxed{21}$.
