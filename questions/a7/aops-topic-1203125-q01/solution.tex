Use Burnside's lemma over the $4$ rotations. The identity fixes all $4^4=256$ colourings; the rotations by $90^\circ$ and $270^\circ$ fix only the $4$ one-colour colourings; the rotation by $180^\circ$ fixes colourings with opposite sectors equal, $4^2=16$. So the number of colourings is
\[
\dfrac{256+4+16+4}{4}=\boxed{70}.
\]
(This replaces the casework on how many rotations each colouring has.)
