Set $f(x)=0$: $x^2+4x+1=0$. Completing the square, $(x+2)^2=3$, so $x=-2\pm\sqrt3$. With $\sqrt3\approx1.732$, the intercepts are $x\approx\boxed{-0.3\text{ and }-3.7}$.
