For a chromatic number of length $k$, the first digit is one and each next digit either repeats or increases by one, so there are $2^{k-1}$ possibilities. At position $j$, the average digit is $1+\dfrac{(j-1)}{2}=\dfrac{(j+1)}{2}$. Thus the sum for length $k\ge2$ is $2^{k-2}\sum_{j=1}^k(j+1)10^{k-j}$. For lengths one through nine these sums are $1,23,468,9380,187648,3753072,75061696,1501234496,30024691200$. Their total is $31604937984=256\cdot123456789$. The greatest odd divisor is therefore $\boxed{123456789}$.
