If $y=z=1$ the equation reads $4=0$, so $yz\ge2$ and
\[x=\dfrac{2(y+z)}{yz-1}.\]
The equation is symmetric in $y$ and $z$, so first assume $y\le z$.

\textbf{$y=1$.} Then $x=\dfrac{2(z+1)}{z-1}=2+\dfrac{4}{z-1}$, so $z-1$ divides $4$: $z=2,3,5$, giving $x=6,4,3$.

\textbf{$y\ge2$.} Since $x\ge1$, we need $yz-1\le2y+2z$, that is, $(y-2)(z-2)\le5$.
\begin{itemize}
\item $y=2$: $x=\dfrac{2(z+2)}{2z-1}=1+\dfrac{5}{2z-1}$, so $2z-1$ divides $5$; with $z\ge2$ this gives $z=3$ and $x=2$.
\item $y=3$: $z-2\le5$, so $3\le z\le7$, and $x=\dfrac{2(z+3)}{3z-1}$ equals $\dfrac{12}{8},\dfrac{14}{11},\dfrac{16}{14},\dfrac{18}{17},\dfrac{20}{20}$ for $z=3,4,5,6,7$. Only $z=7$ works, with $x=1$.
\item $y=4$: $2(z-2)\le5$ forces $z=4$, and $x=\dfrac{16}{15}$ is not an integer.
\item $y\ge5$: $(y-2)(z-2)\ge9>5$, impossible.
\end{itemize}
So the solutions with $y\le z$ are $(6,1,2)$, $(4,1,3)$, $(3,1,5)$, $(2,2,3)$, $(1,3,7)$, and swapping $y$ and $z$ gives all solutions:
\[(x,y,z)=\boxed{(6,1,2),\ (6,2,1),\ (4,1,3),\ (4,3,1),\ (3,1,5),\ (3,5,1),\ (2,2,3),\ (2,3,2),\ (1,3,7),\ (1,7,3)}\]
(ten ordered triples).
