Count the stories each person has \emph{not} read: Alex has missed $100-75=25$, Bob has missed $100-60=40$, and Carl has missed $100-52=48$.

A story fails to be read by all three exactly when at least one of them has missed it. Hence the number of stories not read by all three is at most $25+40+48=113$. Since $113\ge 100$, this bound does not force any story to be read by everyone. (The attempted computation $75+60+52-2\cdot 100=-13$ is exactly this bound, $100-113$; a negative bound only says that $0$ is not ruled out.)

To see that $0$ is actually possible, number the stories $1$ to $100$ and let
\begin{itemize}
\item Alex miss stories $1$--$25$,
\item Bob miss stories $26$--$65$ ($40$ stories),
\item Carl miss stories $66$--$100$ and $1$--$13$ ($35+13=48$ stories).
\end{itemize}
Then every story is missed by somebody, and each person has read the required number of stories. So the least possible number of stories read by all three is
\[\boxed{0}.\]
