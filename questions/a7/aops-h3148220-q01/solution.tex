Set $D_n=a_n^2-a_{n-1}a_{n+1}$ for $n\ge1$. By the recurrence,
\[D_{n+1}=a_{n+1}^2+4a_na_{n+1}+7a_n^2=7(a_n^2-a_{n-1}a_{n+1})=7D_n,\]
using $a_{n+1}+4a_n=-7a_{n-1}$. Since $a_2=9$, $D_1=16-9=7$. Therefore $D_{50}=7^{50}$, whose positive divisors are $1,7,\ldots,7^{50}$. Their number is $\boxed{51}$.
