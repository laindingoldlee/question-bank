A line of sight through this cube contains exactly two unit cubes. Associate those unit cubes with adjacent vertices of a cube graph. The condition says that no adjacent pair may both be transparent; hence the transparent cubes form an independent set of the cube graph.

Split the eight vertices into the two parity classes of four. Each vertex is adjacent to three of the four vertices in the opposite class, missing only its antipode. Independent sets contained in just one class contribute
\[
1+2(2^4-1)=31,
\]
including the empty set once. An independent set using both classes must consist of exactly one antipodal pair: two vertices from one class have no common non-neighbour in the other. There are four such pairs. Thus the count is $\boxed{31+4=35}$.
