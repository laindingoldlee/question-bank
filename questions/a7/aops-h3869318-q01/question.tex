A \(2\times 2\times 2\) cube is built from \(8\) unit cubes. Each unit cube is either transparent or colored. When looking directly at any one of the \(6\) faces of the cube, the view appears completely colored if every line of sight contains at least one colored unit cube. How many ways are there to choose which unit cubes are colored so that the cube appears completely colored when viewed directly from any face?
