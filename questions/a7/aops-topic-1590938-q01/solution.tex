We have $13^2=169$ and $17^2=289=229+60$, so $17^2\equiv60\pmod{229}$. Also $169=229-60$, so $13^2\equiv-60\pmod{229}$. Hence
\[
13^{2k}+17^{2k}=\left(13^2\right)^k+\left(17^2\right)^k\equiv(-60)^k+60^k=60^k\left((-1)^k+1\right)\pmod{229}.
\]
\begin{itemize}
\item If $k$ is odd, $(-1)^k+1=0$, so $229$ divides $13^{2k}+17^{2k}$.
\item If $k$ is even, the right side is $2\cdot60^k$. The number $229$ is prime (it is not divisible by $2,3,5,7,11$ or $13$, and $17^2>229$), and it divides neither $2$ nor $60$, so it does not divide $2\cdot60^k$.
\end{itemize}
So $229\mid13^{2k}+17^{2k}$ exactly when $k$ is odd. $\blacksquare$
