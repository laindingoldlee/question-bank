For $x\ne2019$ the equation says $6|x-2018|=|x-2019|$, so $6(x-2018)=\pm(x-2019)$.
\begin{itemize}
\item $6(x-2018)=x-2019$: $5x=12108-2019=10089$, so $x=\dfrac{10089}{5}$.
\item $6(x-2018)=-(x-2019)$: $7x=12108+2019=14127$, so $x=\dfrac{14127}{7}$.
\end{itemize}
The difference is
\[
\dfrac{14127}{7}-\dfrac{10089}{5}=\dfrac{70635-70623}{35}=\boxed{\dfrac{12}{35}}.
\]
(Shortcut: put $t=x-2018$; then $6|t|=|t-1|$ gives $t=-\dfrac{1}{5}$ or $t=\dfrac{1}{7}$, which differ by $\dfrac{12}{35}$.)
