Row $k$ contains $k+1$ numbers, so rows $0$ to $k$ contain $1+2+\dots+(k+1)=\dfrac{(k+1)(k+2)}{2}$ numbers. Rows $0$ to $61$ contain $\dfrac{62\cdot63}{2}=1953$ numbers and rows $0$ to $62$ contain $\dfrac{63\cdot64}{2}=2016$. Since $1953<2009\le2016$, the $2009$th number is in row $\boxed{62}$ (the $63$rd row from the top; it is the $56$th number of that row).
