\textbf{(a)} Suppose $f_1$ and $f_2$ both have inverse $g$. For every $a\in A$,
\[
f_1(a)=f_1\bigl(g(f_2(a))\bigr)=\bigl(f_1\circ g\bigr)\bigl(f_2(a)\bigr)=f_2(a),
\]
using $g(f_2(a))=a$ first and then $f_1(g(b))=b$ with $b=f_2(a)$. So $f_1=f_2$: a function has at most one function of which it is the inverse.

\textbf{(b)} If such an $f$ exists, then $g$ is one-to-one (if $g(b)=g(b')$ then $b=f(g(b))=f(g(b'))=b'$) and onto (each $a\in A$ equals $g(f(a))$), so $g$ is a bijection. Conversely, if $g$ is a bijection, its inverse $g^{-1}:A\to B$ satisfies both conditions, and by (a) it is the only such function. So the answer to "does every inverse function come from exactly one function?" is \textbf{yes}, provided the domains are fixed: for example $g(x)=\sqrt{x}$ on $[0,\infty)$ is the inverse of $f(x)=x^2$ on $[0,\infty)$ only, not of $x^2$ on all real numbers (which has no inverse).
