If there were $N$ balls, blue balls initially numbered $\dfrac{N}{3}$. Thus $\dfrac{N}{3}+25=\dfrac{3}{4}(N+25)$. Multiplying by $12$ gives $4N+300=9N+225$, so $N=\boxed{15}$.
