Long division returns to the initial remainder precisely when $10^k\equiv1\pmod7$. Since $10\equiv3\pmod7$, the successive residues of $10^k$ for $k=1,\ldots,6$ are $3,2,6,4,5,1$. The first return to one occurs at $k=6$, so the repeating block has length $\boxed6$.
