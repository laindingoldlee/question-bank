The operation satisfies $1+(a+b+ab)=(1+a)(1+b)$. Therefore the product of one plus each current number is invariant. Initially it is $\prod_{k=1}^{2023}(1+\dfrac{1}{k})=\prod_{k=1}^{2023}\dfrac{k+1}{k}=2024$. If the final number is $t$, then $1+t=2024$, so $t=\boxed{2023}$ regardless of the order of moves; this is also the maximum.
