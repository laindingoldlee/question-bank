A school has $1434$ students and a fixed class of $18$. Initially a uniformly chosen set of $665$ students owns bottle H. Each week a new student, chosen uniformly without replacement from non-adopters, adopts bottle S; this choice is independent of H ownership. When does the expected number of S owners in the class first exceed the expected number of H owners?
