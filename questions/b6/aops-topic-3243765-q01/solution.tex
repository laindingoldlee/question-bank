Each class member has H with probability $\dfrac{665}{1434}$, so the expected count is $18\cdot\dfrac{665}{1434}$. After $t$ weeks each has S with probability $\dfrac{t}{1434}$, giving expected count $18\cdot\dfrac{t}{1434}$. The second first exceeds the first when the integer $t>665$, namely $\boxed{666\text{ weeks}}$.
