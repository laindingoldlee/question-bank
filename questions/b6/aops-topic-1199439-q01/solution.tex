First, $3^{100}\equiv1\pmod{1000}$: indeed $3^{10}=59049\equiv49$, $3^{20}\equiv49^2=2401\equiv401$, $3^{40}\equiv401^2\equiv801$, $3^{80}\equiv801^2\equiv601$, and $3^{100}=3^{80}\cdot3^{20}\equiv601\cdot401=241001\equiv1$. So we need $n\bmod100$.

$2016^{2016}\equiv16^{2016}\pmod{100}$. Powers of $16$ modulo $100$ cycle with period $5$ from the first power: $16,56,96,36,76,16,\dots$; since $2016\equiv1\pmod5$, $16^{2016}\equiv16$. Hence $3^n\equiv3^{16}=43046721\equiv\boxed{721}\pmod{1000}$.
