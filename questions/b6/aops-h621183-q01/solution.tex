Positivity forces $1\le n<2015$. Set the fraction equal to $k^2$ with $k\ge1$. Then $n=\dfrac{2015k^2}{k^2+1}$, which is an integer exactly when $k^2+1\mid2015$, because $\gcd(k^2,k^2+1)=1$.

The factorization $2015=5\cdot13\cdot31$ gives divisors $1,5,13,31,65,155,403,2015$. Only $5$ and $65$ are one more than a positive square, giving $k=2,8$ and $n=1612,1984$. Hence the count is $\boxed2$, choice $\boxed{\text{B}}$.
