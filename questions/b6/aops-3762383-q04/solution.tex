Let $c_i$ be the carry out of binary position $i$. Each binary carry changes the reinterpreted value by $3^{i+1}-2\cdot3^i=3^i$, so the difference is $\sum c_i3^i$, with all $c_i\in\{0,1\}$. Conversely any finite nonzero carry pattern is achievable: choose the two input bits both 1 when a carry out is desired, and both 0 otherwise; their sum together with any incoming carry produces precisely that carry-out decision. Add a final zero column to terminate the carries. Both resulting inputs are positive. Thus the values are exactly positive integers whose ternary digits are only 0 and 1. Since $3^7=2187>2026$ and $1+3+\cdots+3^6=1093<2026$, there are $2^7-1=\boxed{127}$.
