By Cauchy--Schwarz, $\sum \dfrac{x^3}{y}=\sum \dfrac{(x^2)^2}{xy}\ge\dfrac{(x^2+y^2+z^2)^2}{xy+yz+zx}$. Set $q=xy+yz+zx\le \dfrac{1}{3}$. Then $x^2+y^2+z^2=1-2q\ge \dfrac{1}{3}$, so the bound is at least $\dfrac{(\dfrac{1}{3})^2}{\dfrac{1}{3}}=\dfrac{1}{3}$. Equality holds at $x=y=z=\dfrac{1}{3}$. The minimum is $\dfrac{1}{3}$, giving $\boxed{p+q=4}$.
