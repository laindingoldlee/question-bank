Modulo $7$, $7-a\equiv-a$, $7-b\equiv-b$, $7-c\equiv-c$, so $(7-a)(7-b)(7-c)\equiv-abc$. Therefore
\[
abc+(7-a)(7-b)(7-c)\equiv abc-abc=0\pmod7. \qquad\blacksquare
\]
(The argument works for all integers $a,b,c$; distinctness is not needed.)
