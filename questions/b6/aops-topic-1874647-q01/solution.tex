Group the numerator in pairs: $(100-99)+(98-97)+\cdots+(2-1)$ is $50$ pairs each equal to $1$, so it equals $50$. Similarly the denominator is $(1-2)+(3-4)+\cdots+(99-100)=50\cdot(-1)=-50$. The value is $\dfrac{50}{-50}=\boxed{-1}$.
