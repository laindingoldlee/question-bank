One machine makes $\dfrac{500}{15\cdot15}=\dfrac{20}{9}$ raviolis per minute, so $75$ machines make $\dfrac{1500}{9}=\dfrac{500}{3}$ per minute. They need $6000\div\dfrac{500}{3}=\boxed{36\text{ minutes}}$.
