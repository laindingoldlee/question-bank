If $n=a^2-b^2=(a-b)(a+b)$, the factors $a-b$ and $a+b$ have the same parity, so $n$ is odd or divisible by $4$; a number $\equiv2\pmod4$ is impossible.

Conversely, an odd $n=2k+1=(k+1)^2-k^2$, and $n=4k=(k+1)^2-(k-1)^2$.

So the representable numbers are exactly those not $\equiv2\pmod4$. Among $1,\dots,1000$ there are $250$ numbers $\equiv2\pmod4$, leaving $\boxed{750}$.
