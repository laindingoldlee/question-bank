An infinite decimal $0.d_1d_2d_3\ldots$ is defined as the number that its truncations $0.d_1$, $0.d_1d_2$, $0.d_1d_2d_3$, \ldots{} approach. A forum user argues: ``For every digit $a$, $0.aaa\ldots=\dfrac {a}{9}$; taking $a=9$ gives $0.999\ldots=1$.'' Another user objects that this is circular reasoning.
\begin{enumerate}
\item[(a)] Prove directly from the definition that $0.aaa\ldots=\dfrac{a}{9}$ for every digit $a\in\{0,1,\ldots,9\}$.
\item[(b)] Explain why the argument is not circular.
\end{enumerate}
