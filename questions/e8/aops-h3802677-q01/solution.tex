Modulo $k$, the pair $(c_n,c_{n+1})$ evolves by $(u,v)\mapsto(v,av+bu)$. Because $b$ is invertible modulo $k$, this map is a bijection, with inverse $(v,w)\mapsto(b^{-1}(w-av),v)$. It permutes the finite set of $k^2$ pairs. The orbit of $(0,c_1)$ is therefore periodic from its start: for some $T>0$, $(c_T,c_{T+1})\equiv(0,c_1)$. Iterating gives $c_{jT}\equiv0\pmod k$ for every positive $j$. This proves the claim.
