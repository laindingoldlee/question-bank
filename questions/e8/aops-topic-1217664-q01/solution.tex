Write $\sqrt{x-2}=4-x$. This needs $4-x\ge0$. Squaring gives $x-2=16-8x+x^2$, that is $x^2-9x+18=0$, so $x=3$ or $x=6$. The value $x=6$ is extraneous ($6+\sqrt4=8\ne4$), while $x=3$ works ($3+1=4$). The equation has exactly one root, $\boxed{\textbf{(E)}}$.
