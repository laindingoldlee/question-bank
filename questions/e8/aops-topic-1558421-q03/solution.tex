\textbf{Combine the first two.} $n=7j+5$ with $7j+5\equiv6\pmod{11}$, i.e.\ $7j\equiv1\pmod{11}$. Since $7\cdot8=56\equiv1\pmod{11}$, $j\equiv8\pmod{11}$, so $n\equiv7\cdot8+5=61\pmod{77}$.

\textbf{Add the third.} $n=61+77m$ with $61+77m\equiv4\pmod{13}$. Modulo $13$: $61\equiv9$ and $77\equiv12\equiv-1$, so $9-m\equiv4$, i.e.\ $m\equiv5\pmod{13}$. Then $n\equiv61+77\cdot5=446\pmod{1001}$.

The smallest positive solution is $\boxed{446}$. Check: $446=7\cdot63+5=11\cdot40+6=13\cdot34+4$.
