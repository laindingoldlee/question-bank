The congruence holds exactly when $n\mid4^{18}-2^{16}=2^{16}\left(2^{20}-1\right)$. Now $2^{20}-1=\left(2^{10}-1\right)\left(2^{10}+1\right)=1023\cdot1025=(3\cdot11\cdot31)\left(5^2\cdot41\right)$, so
\[4^{18}-2^{16}=2^{16}\cdot3\cdot5^2\cdot11\cdot31\cdot41,\]
which has $17\cdot2\cdot3\cdot2\cdot2\cdot2=\boxed{816}$ positive divisors.
