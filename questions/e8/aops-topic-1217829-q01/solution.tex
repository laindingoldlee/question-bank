Let $p=\dfrac{1}{100000}$ and let $X$ be the number of flips needed. Either the first flip is a head (probability $p$, one flip), or it is a tail and we start over having used one flip. So
\[E[X]=1+(1-p)E[X],\qquad\text{hence}\qquad E[X]=\dfrac{1}{p}=\boxed{100000}.\]
