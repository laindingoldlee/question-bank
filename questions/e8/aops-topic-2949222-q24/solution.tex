The expression is unchanged by $x\mapsto-x$, so put $t=x^2>0$. For $m\le t\le m+1$ with $0\le m\le10$ (using the appropriate unbounded end intervals), the expression is $(2m-10)\sqrt t+\dfrac{55-m(m+1)}{\sqrt t}$. On all intervals with $m\le5$ it decreases, and for $m\ge7$ it increases. For $6\le t\le7$ it is $2\sqrt t+\dfrac{13}{\sqrt t}$, whose AM--GM minimum is $2\sqrt{26}$ at $t=\dfrac{13}{2}$, inside that interval. Therefore the global minimum is $\boxed{2\sqrt{26}}$.
