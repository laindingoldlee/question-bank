$806=2\cdot13\cdot31$. If the wrong digit were in $31$, the other factor would still be $66$, but $66\nmid806$. So $31$ was entered correctly and the other factor was $\dfrac{806}{31}=26$, which differs from $66$ in exactly one digit. The sum is $26+31=\boxed{57}$.
