A horizontal line can meet cell interiors only in one row. Within that row, it cuts all $2020$ cells at the same height, so either all are shaved or none are. Each row can be shaved by choosing a line at distance $\varepsilon$ above its lower boundary, where $0<\varepsilon<\dfrac{1}{2021}$; then $\varepsilon<\dfrac{(1-\varepsilon)}{2020}$.
This gives exactly $2020$ distinct row sets. Vertical lines similarly give $2020$ column sets. A row set cannot equal a column set because the grid has more than one row and column. The total is $4040$, giving remainder $\boxed{40}$.
