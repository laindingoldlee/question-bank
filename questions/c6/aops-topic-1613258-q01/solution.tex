We need $x\ne1$ and $x\ne3$. Multiplying both sides by $(x-1)(x-3)$,
\[
(x+1)(x-3)=(x+3)(x-1)\iff x^2-2x-3=x^2+2x-3\iff4x=0 ,
\]
so $x=0$. This value is allowed, and indeed $\dfrac{0+1}{0-1}=-1=\dfrac{0+3}{0-3}$. The solution is $\boxed{x=0}$.
