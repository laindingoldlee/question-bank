Look at the unshaded squares instead. Each row and each column has exactly $3-2=1$ unshaded square, so the unshaded squares form a pattern with exactly one square in each row and each column, and conversely every such pattern gives a valid shading. Such a pattern is determined by choosing, row by row, a column not used before: $3\cdot2\cdot1$ choices. So there are
\[3!=\boxed{6}\]
shadings.
