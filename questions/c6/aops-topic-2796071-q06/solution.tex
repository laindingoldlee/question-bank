The numerator is $\dfrac{n(n+1)}2$ and the denominator is $n^2$, so $a_n=\dfrac{n+1}{2n}$ and $a_n-\dfrac12=\dfrac1{2n}$. We need $2n>2012$, so $n=\boxed{1007}$.
