Complete the square:
\[
5x^2+18x+23=5\left(x^2+\dfrac{18}{5}x\right)+23=5\left(x+\dfrac{9}{5}\right)^2-5\cdot\dfrac{81}{25}+23=5\left(x+\dfrac{9}{5}\right)^2+\dfrac{34}{5}.
\]
So $a=5$, $c=\dfrac{9}{5}$ and $-k=\dfrac{34}{5}$, that is $k=\boxed{-\dfrac{34}{5}}$. (The quadratic has minimum value $\dfrac{34}{5}>0$, so it has no real roots.)
