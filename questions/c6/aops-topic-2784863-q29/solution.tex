Reflect $ A $ across the horizontal axis to $ A'=(3,-2)$. Then $ AC+BC=A'C+CB\ge A'B $, with equality precisely when $ C $ lies on segment $ A'B $. The line rises 3 units while running 3; at height 0 it has traveled 2 units right from $ A'$. Thus $\boxed{x=5}$.
\begin{asy}
usepackage("amsmath");
size(7cm);
pair A=(3,2),B=(6,1),C=(5,0),Ap=(3,-2);draw((1,0)--(7,0));draw(A--C--B);draw(Ap--B,dashed);label("$A$",A,N);label("$B$",B,NE);label("$C$",C,SE);label("$A\prime$",Ap,S);
\end{asy}
