By clue 2, $\{B,E,F,J\}=\{1,2,4,8\}$, so $A,C,D,G,H,I$ occupy $\{3,5,6,7,9,10\}$.
\begin{itemize}
\item Clue 3: $D^2=C+J\le10+8$, so $D\le4$; as $D\notin\{1,2,4\}$, $D=3$ and $C+J=9$. Since $C\notin\{1,2,4,8\}$, $J\in\{2,4\}$ and $C\in\{7,5\}$.
\item Clue 6: $G=B-J$ with $B,J$ powers of $2$ and $G\in\{5,6,7,9,10\}$. The only possibility is $B=8$, $J=2$, $G=6$. Hence $C=7$, and $\{E,F\}=\{1,4\}$.
\item Now $A,H,I$ occupy $\{5,9,10\}$, and $A<G=6$ gives $A=5$.
\item Clue 5: $I=5+E\in\{9,10\}$ with $E\in\{1,4\}$, so $E=4$, $I=9$, $F=1$, and then $H=I+F=10$ (clue 4), with $G<H$.
\end{itemize}
The finishing order is
