A certain computer program would take $2000$ years to run using current technology. Every year, advances in technology halve the time the program would take if started then: if it is started after waiting $k$ whole years, it takes $\dfrac{2000}{2^k}$ years. Once started, the program cannot be interrupted to use newer technology. Including the years spent waiting, what is the least number of years it can take to finish running the program? Give the answer to the nearest integer.
