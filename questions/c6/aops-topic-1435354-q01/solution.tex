There are $\dbinom{8}{2}=28$ equally likely pairs. Pairs of the same colour: $2\cdot\dbinom{4}{2}=12$. Pairs of the same letter: $4$ (one red and one green card of each letter). No pair is counted twice, since two cards with the same letter have different colours. So
\[
P(\text{winning pair})=\dfrac{12+4}{28}=\boxed{\dfrac{4}{7}} .
\]
