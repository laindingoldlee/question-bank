A three-digit repeating block gives $0.\overline{D75}=\dfrac{100D+75}{999}$. Since $814=22\cdot37$ and $999=27\cdot37$,
\[
n=814\cdot\dfrac{100D+75}{999}=\dfrac{22(100D+75)}{27}=\dfrac{22\cdot25\,(4D+3)}{27}.
\]
As $22$ and $25$ are coprime to $27$, $n$ is an integer only if $27\mid 4D+3$. For a digit $D$, $3\le4D+3\le39$, so $4D+3=27$ and $D=6$. Then
\[
n=\dfrac{22\cdot25\cdot27}{27}=\boxed{550}.
\]
Check: $\dfrac{550}{814}=\dfrac{25}{37}=\dfrac{675}{999}=0.\overline{675}$.
