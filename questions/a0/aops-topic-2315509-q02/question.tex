A piano has $88$ keys, numbered $1$ to $88$ from the lowest key, which is an A; the names of the keys repeat every $12$ keys, so keys $1,13,25,\dots$ are all A's. A pianist plays a chromatic scale with each hand, one key per note: the left hand starts on key $1$ and moves up at $120$ notes per minute, and the right hand starts on some key and moves down at twice that rate. Both hands start at the same moment, and exactly $10$ seconds later they play the same key at the same moment (the hands cross). On which key did the right hand start? Give its number and its name.
