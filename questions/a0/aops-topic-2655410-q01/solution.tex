Let $N=20202020$.

\textbf{(a)} $4000^2=16000000<N<25000000=5000^2$, so $\dfrac1{5000}<x<\dfrac1{4000}$, i.e. $0.0002<x<0.00025$. The first four digits after the decimal point are $\boxed{0,0,0,2}$.

\textbf{(b)} Refine the bounds on $\sqrt N$:
\[4494.5^2=20200530.25<N<20205025=4495^2,\]
so $\dfrac1{4495}<x<\dfrac1{4494.5}$. Now $4495\times0.0002224=0.999688<1$, so $\dfrac1{4495}>0.0002224$; and $4494.5\times0.0002225=1.00002625>1$, so $\dfrac1{4494.5}<0.0002225$. Hence $0.0002224<x<0.0002225$, and the first four nonzero digits are $\boxed{2,2,2,4}$ (in fact $x\approx0.00022249$).
