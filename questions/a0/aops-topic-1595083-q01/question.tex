Two suspects are questioned separately, and each chooses independently either to stay silent or to accuse the other.
\begin{itemize}
\item If both stay silent, each is jailed for $1$ year.
\item If one accuses and the other stays silent, the accuser goes free and the silent one is jailed for $4$ years.
\item If both accuse, each is jailed for $3$ years.
\end{itemize}
\begin{enumerate}
\item[(a)] Show that, whatever the other suspect does, each suspect spends less time in jail by accusing.
\item[(b)] Show that if both suspects act on this, each is jailed for longer than if both had stayed silent.
\end{enumerate}
