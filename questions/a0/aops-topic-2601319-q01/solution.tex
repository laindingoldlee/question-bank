\textbf{(a)} In $t$ minutes there are $\dfrac{t}{30}$ doubling periods, so $\boxed{n(t)=1500\cdot2^{\dfrac{t}{30}}}$.

\textbf{(b)} $2$ hours is $120$ minutes, so $n(120)=1500\cdot2^4=\boxed{24000}$.

\textbf{(c)} Solve $1500\cdot2^{\dfrac t{30}}=4000$: $2^{\dfrac t{30}}=\dfrac83$, so
\[t=30\log_2\dfrac83=90-30\log_23\approx\boxed{42.45\text{ minutes}}.\]
