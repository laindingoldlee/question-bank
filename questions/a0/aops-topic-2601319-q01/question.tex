A culture contains $1500$ bacteria initially and doubles every $30$ minutes.
\begin{enumerate}
\item[(a)] Find a function $n(t)$ giving the number of bacteria after $t$ minutes.
\item[(b)] Find the number of bacteria after $2$ hours.
\item[(c)] After how many minutes will the culture contain $4000$ bacteria? Give the exact value and a decimal approximation.
\end{enumerate}
