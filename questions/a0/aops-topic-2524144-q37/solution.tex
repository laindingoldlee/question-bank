Let $c$, $u$, $w$ be the numbers of correct, unanswered and wrong answers, with $c+u+w=25$. Then $6c+1.5u=120$, i.e. $u=80-4c$. We need $u\ge0$, so $c\le20$, and $w=25-c-u=3c-55\ge0$, so $c\ge19$. Both values work:
\[(c,u,w)=(19,4,2)\qquad\text{and}\qquad(20,0,5).\]
So there are $\boxed{2}$ ways.
