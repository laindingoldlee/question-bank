Multiply the two equations:
\[
\left(x+\dfrac{1}{y}\right)\left(y+\dfrac{1}{x}\right)=xy+1+1+\dfrac{1}{xy}=\dfrac{7}{2}\cdot\dfrac{7}{5}=\dfrac{49}{10}.
\]
With $t=xy$ this gives $t+\dfrac{1}{t}=\dfrac{49}{10}-2=\dfrac{29}{10}$, i.e. $10t^2-29t+10=0$, so $(2t-5)(5t-2)=0$ and $t=\dfrac{5}{2}$ or $t=\dfrac{2}{5}$.

Both values actually occur. From the first equation, $x+\dfrac{1}{y}=x+\dfrac{x}{t}=x\cdot\dfrac{t+1}{t}=\dfrac{7}{2}$.
\begin{itemize}
\item $t=\dfrac{5}{2}$: $x\cdot\dfrac{7}{5}=\dfrac{7}{2}$, so $x=\dfrac{5}{2}$, $y=\dfrac {t}{x}=1$. Check: $y+\dfrac{1}{x}=1+\dfrac{2}{5}=\dfrac{7}{5}$.
\item $t=\dfrac{2}{5}$: $x\cdot\dfrac{7}{2}=\dfrac{7}{2}$, so $x=1$, $y=\dfrac{2}{5}$. Check: $\dfrac{2}{5}+1=\dfrac{7}{5}$.
\end{itemize}
The maximum of $xy$ is therefore $\dfrac{5}{2}=\boxed{2.5}$.

(The poster's value $\dfrac{29+7\sqrt{89}}{20}\approx4.74$ is not attainable: $xy$ must satisfy $t+\dfrac{1}{t}=\dfrac{29}{10}$, whose only roots are $2.5$ and $0.4$.)
