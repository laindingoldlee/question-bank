Timothy's toolbox has a combination lock with a $10$-digit code; each digit of the code is one of $0,1,\dots,9$. He has forgotten the code, so he guesses a code at random, choosing each of the $10$ digits uniformly and independently. A digit of his guess is \emph{correct} if it equals the digit of the code in the same position.
\begin{enumerate}
\item[(a)] What is the probability that exactly $7$ digits are correct?
\item[(b)] What is the probability that at least $7$ digits are correct?
\end{enumerate}
