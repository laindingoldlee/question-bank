Each digit is correct with probability $\dfrac{1}{10}$, independently of the others, so the number of correct digits is binomial: exactly $k$ digits are correct with probability $\dbinom{10}{k}\dfrac{9^{10-k}}{10^{10}}$.

\textbf{(a)}
\[\dbinom{10}{7}\cdot\dfrac{9^3}{10^{10}}=\dfrac{120\cdot729}{10^{10}}=\dfrac{87480}{10^{10}}=\boxed{\dfrac{2187}{250\,000\,000}}\approx8.75\times10^{-6}.\]

\textbf{(b)} Adding the cases of $8$, $9$ and $10$ correct digits,
\[\dfrac{120\cdot9^3+45\cdot9^2+10\cdot9+1}{10^{10}}=\dfrac{87480+3645+90+1}{10^{10}}=\dfrac{91216}{10^{10}}=\boxed{\dfrac{5701}{625\,000\,000}}\approx9.12\times10^{-6}.\]
