The expression factors as $(x^2+1)(y^2+1)$. Primality requires one factor to be $1$, so $x=0$ or $y=0$. For $n=0,1,\ldots,10$, the prime values of $n^2+1$ occur exactly at $n=1,2,4,6,10$, giving $2,5,17,37,101$. The pair $(0,0)$ does not qualify, so each of these five values produces two ordered pairs. Total: $\boxed{10}$.
