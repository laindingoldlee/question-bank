Write the number as $10a+b$ with digits $a\in\{1,\dots,9\}$ and $b\in\{0,\dots,9\}$. The condition is $10a+b=2ab$, so $b(2a-1)=10a$ and
\[
b=\dfrac{10a}{2a-1}.
\]
Since $\gcd(a,2a-1)=\gcd(a,-1)=1$, the number $2a-1$ must divide $10$. It is odd, so $2a-1\in\{1,5\}$:
\begin{itemize}
\item $2a-1=1$ gives $a=1$, $b=10$, not a digit;
\item $2a-1=5$ gives $a=3$, $b=6$.
\end{itemize}
So the number is $\boxed{36}$: indeed $3\cdot6=18=\dfrac{36}{2}$.
