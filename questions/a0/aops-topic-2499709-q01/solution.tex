For every real $u$, $\sqrt{u^2}=|u|$. Work from the inside out:
\begin{itemize}
\item $\sqrt{\left(x-2\sqrt3\right)^2}=\left|x-2\sqrt3\right|$;
\item $\left|x-2\sqrt3\right|+2\sqrt3>0$, so $\sqrt{\left(\left|x-2\sqrt3\right|+2\sqrt3\right)^2}=\left|x-2\sqrt3\right|+2\sqrt3$;
\item subtracting $2\sqrt3$ leaves $\left|x-2\sqrt3\right|$, and the outer root gives $\Bigl|\left|x-2\sqrt3\right|\Bigr|=\left|x-2\sqrt3\right|$.
\end{itemize}
So the equation is $\left|x-2\sqrt3\right|=6$, i.e. $x=2\sqrt3\pm6$. The product is $\left(2\sqrt3\right)^2-36=12-36=-24$, with absolute value $\boxed{24}$.
