The digits of a two-digit number add to $12$, and reversing the digits gives a number $54$ \emph{greater} than the original. A student sets the units digit to $x$, writes the number as $10(12-x)+x$, and solves $(120-9x)-(9x+12)=54$, getting $93$. Find the error and the correct number.
