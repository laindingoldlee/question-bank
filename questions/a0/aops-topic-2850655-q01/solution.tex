The reversed number is $9x+12$ and it is the \emph{larger} one, so the equation should be $(9x+12)-(120-9x)=54$. The student subtracted in the wrong order. Correctly, $18x-108=54$, so $x=9$: the units digit is $9$ and the tens digit is $3$. The number is $\boxed{39}$ (and $93-39=54$).
