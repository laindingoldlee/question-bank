A scale $3:1$ means $3$ units on the drawing represent $1$ unit of the object, so the drawing is \emph{larger} (an enlargement, as used for small parts). A $2$ cm object is drawn $3\cdot2=\boxed{6\text{ cm}}$ long. (A scale $1:n$ is a reduction.)
