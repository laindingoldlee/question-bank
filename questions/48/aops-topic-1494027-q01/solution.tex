When Alex finished, Benny had run $15-4=11$ km and Calvin $15-7=8$ km in the same time. With constant speeds, the ratio of the distances they cover in any time interval is the ratio of their speeds:
\[
\text{Benny}:\text{Calvin}=11:8 .
\]
When Benny finishes, he has run $15$ km, so Calvin has run
\[
15\cdot\dfrac{8}{11}=\dfrac{120}{11}\text{ km},
\]
and the distance between them is
\[
15-\dfrac{120}{11}=\boxed{\dfrac{45}{11}\text{ km}}\approx4.09\text{ km}.
\]
\textbf{The error.} $3$ km $=7-4$ km is the gap between Benny and Calvin at the moment \emph{Alex} finishes. After that Benny still runs $4$ km, and during that time Calvin runs only $4\cdot\dfrac{8}{11}=\dfrac{32}{11}$ km, so the gap grows by $4-\dfrac{32}{11}=\dfrac{12}{11}$ km, to $3+\dfrac{12}{11}=\dfrac{45}{11}$ km.
