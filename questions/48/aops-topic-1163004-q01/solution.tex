Let $S=\displaystyle\sum_{n\ge1}\dfrac1{n^2}$. It converges, because for $n\ge2$, $\dfrac1{n^2}<\dfrac1{n(n-1)}=\dfrac1{n-1}-\dfrac1n$, and these terms telescope, so $S<1+1=2$.

The even terms give $\displaystyle\sum_{k\ge1}\dfrac1{(2k)^2}=\dfrac14S$, so the odd terms give $S-\dfrac14S=\dfrac34S$. The ratio is
\[\dfrac{\dfrac34S}{\dfrac14S}=\boxed{3}.\]
(The value $S=\dfrac{\pi^2}6$ is not needed.)
