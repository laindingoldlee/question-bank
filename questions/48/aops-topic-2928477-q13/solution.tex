Call the polynomial $P$. Substituting $x=-y$ makes $P=0$, and likewise for the other two variable pairs. Therefore $(x+y)(y+z)(z+x)$ divides $P$. The quotient is a symmetric homogeneous quadratic, so it has form $A(x^2+y^2+z^2)+B(xy+yz+zx)$. At $z=0$,\[(x+y)^5-x^5-y^5=5xy(x+y)(x^2+xy+y^2),\]which forces $A=B=5$. Hence the factorization is\[\boxed{5(x+y)(y+z)(z+x)(x^2+y^2+z^2+xy+yz+zx)}.\]The derivation is a polynomial identity, so it also holds when any of the displayed linear factors vanishes.
