Add $1$ to each equation. Since $(w+1)(x+1)(y+1)=wxy+wx+xy+yw+w+x+y+1$, and similarly for the others, the system becomes, with $a=w+1$, $b=x+1$, $c=y+1$, $d=z+1$,
\[
abc=12,\qquad bcd=36,\qquad cda=48,\qquad dab=144 .
\]
Multiplying all four equations,
\[
(abcd)^3=12\cdot36\cdot48\cdot144=\left(2^2\cdot3\right)\left(2^2\cdot3^2\right)\left(2^4\cdot3\right)\left(2^4\cdot3^2\right)=2^{12}3^{6}=144^3 .
\]
For real numbers the cube root is unique, so $abcd=144$. Dividing by each equation,
\[
d=\dfrac{144}{12}=12,\qquad a=\dfrac{144}{36}=4,\qquad b=\dfrac{144}{48}=3,\qquad c=\dfrac{144}{144}=1 .
\]
Hence $w=3$, $x=2$, $y=0$, $z=11$, and these values do satisfy the system (they satisfy the four product equations, which are equivalent to it). The only solution is
\[
(w,x,y,z)=\boxed{(3,2,0,11)}.
\]
