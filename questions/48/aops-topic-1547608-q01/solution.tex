There are $78$ possible integers.

\textbf{Six questions are not enough.} Six yes/no answers give at most $2^6=64<78$ different answer patterns, so two different integers would receive the same answers, whatever the questions.

\textbf{Seven questions suffice.} Since $78\le2^7=128$, write the integer in base $2$ with $7$ digits and ask for each digit in turn (``Is the $2^k$ digit $1$?''); equivalently, halve the range of possibilities with each question.

So the answer is $\boxed{7}$.
