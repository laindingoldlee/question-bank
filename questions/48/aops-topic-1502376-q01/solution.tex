Let $E$ be the expected number of rolls. The first roll is a $5$ with probability $\dfrac{1}{6}$, and then we stop. Otherwise, with probability $\dfrac{5}{6}$, we have used one roll and the situation starts afresh. So
\[
E=1+\dfrac{5}{6}E ,\qquad\text{hence}\qquad E=\boxed{6}.
\]
(Equivalently, the number of rolls is geometric with success probability $p=\dfrac{1}{6}$, and its mean is $\dfrac{1}{p}=6$. This is already an integer, so rounding changes nothing.)
