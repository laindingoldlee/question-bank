Exactly 800 grams must be four small boxes, so each costs $\dfrac{8.80}{4}=2.20$ dollars. Exactly 900 grams must be two small boxes and one large box, so the large box costs $7.90-4.40=3.50$. The difference is $\boxed{1.30\text{ dollars}}$.
