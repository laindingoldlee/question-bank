A car radio shows the elapsed time of a track as minutes$'$seconds, so $60$ seconds is shown as $1'00$. A driver who reads the display as a plain number of seconds would read $1'00$ as $100$ seconds. Is there any time of at least one minute whose display, read as a plain number, equals the actual number of seconds?
