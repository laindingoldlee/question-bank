\textbf{No solutions with $x\ge2$.} Since $2018=2\cdot1009$, $2018^x$ is divisible by $4$ when $x\ge2$, so $y^2+z^2\equiv-1\equiv3\pmod4$. But every square is $\equiv0$ or $1\pmod 4$, so $y^2+z^2\equiv0,1,2\pmod4$, a contradiction.

\textbf{$x=1$.} We need $y^2+z^2=2017$. Suppose $y\ge z$; then $2y^2\ge2017$ and $y^2\le2016$, so $32\le y\le44$. The values $2017-y^2$ for $y=32,\dots,44$ are $993,928,861,792,721,648,573,496,417,336,253,168,81$; each of the first twelve lies strictly between two consecutive squares ($31^2<993<32^2$, $30^2<928<31^2$, $29^2<861<30^2$, $28^2<792<29^2$, $26^2<721<27^2$, $25^2<648<26^2$, $23^2<573<24^2$, $22^2<496<23^2$, $20^2<417<21^2$, $18^2<336<19^2$, $15^2<253<16^2$, $12^2<168<13^2$), and only $81=9^2$ is a square. So $\{y,z\}=\{44,9\}$.

The solutions are $\boxed{(x,y,z)=(1,44,9)\text{ and }(1,9,44)}$.
