Each rank has four cards, so a king followed by a ten has probability $\dfrac{4}{52}\cdot\dfrac{4}{52}=\dfrac{1}{169}$. The reverse order has the same probability, and the two events are disjoint. Thus the answer is $\boxed{\dfrac{2}{169}}$. The value $\dfrac{1}{169}$ would apply only to one prescribed order.
