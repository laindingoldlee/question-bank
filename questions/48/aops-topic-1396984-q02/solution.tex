We have $33_6=3\cdot6+3=21$, so $(33_6)^2=21^2=441$. Converting back: $441=2\cdot216+9=2\cdot6^3+0\cdot6^2+1\cdot6+3$, so
\[
(33_6)^2=\boxed{2013_6}\ (=441).
\]
(Mentally: $33_6=3\cdot11_6$, and $(11_6)^2=121_6$, so the answer is $9\cdot121_6=13_6\cdot121_6=2013_6$.)
