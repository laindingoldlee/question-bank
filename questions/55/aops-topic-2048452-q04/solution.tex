The left side is an integer, so $\dfrac {x}{2}=n$ for some integer $n$, and $x=2n$ is an integer. Then $\lfloor x\rfloor=2n$, and the equation says $2n=n$, so $n=0$. Check: $\lfloor0\rfloor=0=\dfrac{0}{2}$. The only solution is $\boxed{x=0}$.
