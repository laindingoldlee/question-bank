As printed, $x,y\ge20$ implies $(x-1)(y-1)\ge361$, whereas the equation requires $(x-1)(y-1)=105$. Thus there is no solution for the literal set. If the intended set is $\{2^0,2^1,\ldots,2^{10}\}$, test the factor pairs $(1,105),(3,35),(5,21),(7,15)$: only the last makes both factors one less than a power of two. It gives $x,y=8,16$ and sum 24.
