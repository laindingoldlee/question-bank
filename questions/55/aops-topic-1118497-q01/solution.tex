Let $L=\dfrac{1+\sqrt{397}}{2}$, the positive root of $x^2=x+99$.

\textbf{The limit exists.} By induction $0<a_n<L$: true for $n=1$ since $99<L^2=L+99$; and if $a_n<L$ then $a_{n+1}=\sqrt{99+a_n}<\sqrt{99+L}=L$. Also $a_{n+1}>a_n$: this holds for $n=1$ (since $a_2=\sqrt{99+a_1}>\sqrt{99}=a_1$), and if $a_n>a_{n-1}$ then $a_{n+1}=\sqrt{99+a_n}>\sqrt{99+a_{n-1}}=a_n$. An increasing bounded sequence converges.

\textbf{The value.} If $a_n\to x$, then letting $n\to\infty$ in $a_{n+1}^2=99+a_n$ gives $x^2=99+x$, so $x^2-x-99=0$ and
\[
x=\dfrac{1\pm\sqrt{1+396}}{2}.
\]
Since $x>0$, the value is $\boxed{\dfrac{1+\sqrt{397}}{2}}\approx10.46$.

(With $1$ in place of $99$ the same method gives $x^2=x+1$, so the value is the golden ratio $\dfrac{1+\sqrt5}{2}$, not infinity.)
