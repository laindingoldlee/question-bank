Each dimension occurs four times, so the sum is $4(5+10-x+x-7)=\boxed{32}$. Positivity simply requires $7<x<10$.
\begin{asy}
usepackage("amsmath");
size(7cm);
pair A=(0,0),B=(3,0),C=(3,2),D=(0,2),v=(1,1);draw(A--B--C--D--cycle);draw(B--(B+v)--(C+v)--(D+v)--D);draw(C--(C+v));label("$10-x$",(1.5,0),S);label("$5$",(0,1),W);label("$x-7$",B+v/2,SE);
\end{asy}
