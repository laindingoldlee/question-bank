If the first integer is $ a $, then $ N(2a+N-1)=54 $. Therefore $ N $ divides 54 and $ a=\dfrac{\dfrac{54}{N}-N+1}{2}$ must be integral. Every divisor of 54 works: if $ N $ is odd then $\dfrac{54}{N}$ is even, while if $ N $ is even then $\dfrac{54}{N}$ is odd, since 54 has exactly one factor 2. The eight divisors 1, 2, 3, 6, 9, 18, 27, 54 are all valid. Thus the answer is $\boxed{8}$.
