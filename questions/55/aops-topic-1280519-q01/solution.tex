$1024=2^{10}$, so $a+b=2^k$ and $kc=10$. Since $a<b$, $a+b\ge3$, so $k\ge2$; since $c>b\ge2$, $c\ge3$.
\begin{itemize}
\item $k=2$, $c=5$: $a+b=4$ with $a<b$ gives $(a,b)=(1,3)$, and $3<5$. This works.
\item $k=5$, $c=2$ or $k=10$, $c=1$: then $c\le2$, impossible.
\end{itemize}
So $b=\boxed{3}$.
