For $i=1,\ldots,107$, let $E_i$ mean song $i$ is immediately followed by song $i+1$. For any specified $k$ of these adjacencies, glue the songs along each selected link into blocks. Even overlapping links form a single consecutive block, so there are exactly $108-k$ objects to permute and $(108-k)!$ permutations satisfying the selected events. Inclusion-exclusion therefore gives\[\boxed{\Pr\Bigl(\bigcup E_i\Bigr)=\sum_{k=1}^{107}(-1)^{k+1}\binom{107}{k}\dfrac{(108-k)!}{108!}=\sum_{k=1}^{107}(-1)^{k+1}\dfrac{108-k}{108\,k!}}.\]The probability is approximately $0.6287142677$. It is essential to allow selected adjacency events to overlap; treating all 107 events as independent would be incorrect.
