Take the numbers
\[21!+2,\quad21!+3,\quad\dots,\quad21!+21.\]
For each $k$ with $2\le k\le21$, $k$ divides $21!=1\cdot2\cdots21$, so $k$ divides $21!+k$. Since $21!+k>k\ge2$, the number $21!+k$ has the divisor $k$ strictly between $1$ and itself, so it is composite. These are $20$ consecutive integers, all composite. $\blacksquare$

The same idea gives $n$ consecutive composites $(n+1)!+2,\dots,(n+1)!+(n+1)$ for every $n$. The numbers need not be this large: for example $1130,1131,\dots,1149$ are all composite, since $1129$ and $1151$ are consecutive primes.
