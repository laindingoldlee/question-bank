We need \(q\mid p^2+1\) and \(p\mid (q-1)(q+1)\). Note \(p\ne q\), since \(p\nmid p^2-1\).

\textbf{\(q=2\).} Then \(p^2+1\) is even, so \(p\) is odd, and \(p\mid 3\), so \(p=3\). Check: \(\dfrac{10}{2}=5\), \(\dfrac{3}{3}=1\). This gives \((3,2)\).

\textbf{\(p=2\).} Then \(q\mid 5\), so \(q=5\). Check: \(\dfrac{5}{5}=1\), \(\dfrac{24}{2}=12\). This gives \((2,5)\).

\textbf{\(p,q\) odd.} Then \(p\) divides \(q-1\) or \(q+1\), and \(p^2+1\) is even, so \(p^2+1=qt\) with \(t\) even.
\begin{itemize}
\item If \(p\mid q-1\): since \(q-1\) is even and \(p\) is odd, \(q-1\ge 2p\), so \(q\ge 2p+1\). Modulo \(p\), \(qt\equiv t\) and \(p^2+1\equiv 1\), so \(t\equiv 1\pmod p\). But \(1\le t\le\dfrac{p^2+1}{2p+1}<p\), so \(t=1\), contradicting that \(t\) is even.
\item If \(p\mid q+1\): similarly \(q+1\ge 2p\), so \(q\ge 2p-1\), and \(q\equiv -1\pmod p\) gives \(t\equiv -1\pmod p\). Also \(t\le\dfrac{p^2+1}{2p-1}<p\) (as \(p^2-p-1>0\) for \(p\ge 3\)). Hence \(t=p-1\) and \(q=\dfrac{p^2+1}{p-1}=p+1+\dfrac{2}{p-1}\). So \(p-1\mid 2\), giving \(p=3\) and \(q=5\). Check: \(\dfrac{10}{5}=2\), \(\dfrac{24}{3}=8\).
\end{itemize}
The pairs are
\[
\boxed{(p,q)=(2,5),\ (3,2),\ (3,5)}.
\]
