Enumerate the distinct digit assignments and test the positional-value equation. The complete exact search below finds 8 assignments, each having digit sum 42. Thus $\boxed{42}$. Allowing the leading zero is essential: no assignment exists with $I\ne0$.
\begin{verbatim}
from itertools import permutations
sums=[]
for I,N,T,E,G,R,L,S in permutations(range(10),8):
    if G==0: continue
    if (1000*I+100*N+10*T+E+
        10000*G+1000*I+100*R+10*L+S)==51819:
        sums.append(I+N+T+E+G+R+L+S)
assert len(sums)==8 and set(sums)=={42}
\end{verbatim}
