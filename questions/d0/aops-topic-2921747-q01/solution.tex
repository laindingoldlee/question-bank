Solving, $y=-\dfrac abx+\dfrac cb$. For two distinct solutions $(x_1,y_1)$, $(x_2,y_2)$, the slope between them is $\dfrac{y_2-y_1}{x_2-x_1}=-\dfrac ab$, the same for every pair. So all solutions lie on the line through $\left(0,\dfrac cb\right)$ with slope $-\dfrac ab$.

label("$P_1$",(0,2.875),NE);label("$P_2$",(2,1.375),NE);label("$P_3$",(4,-0.125),NE);
\end{asy}

Conversely, every point $(x,y)$ of that line satisfies $y=-\dfrac abx+\dfrac cb$, i.e. $ax+by=c$. So the solution set is exactly this line. (If $b=0$ and $a\ne0$ it is the vertical line $x=\dfrac ca$.) $\blacksquare$
