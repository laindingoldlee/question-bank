$2021=3\cdot512+7\cdot64+4\cdot8+5$, so $2021=3745_8$ and we need $\overline{abcd}_8\le3745_8$.
\begin{itemize}
\item If $a\le2$, then $a+b+c+d\le2+7+7+7=23$.
\item If $a=3$ and $b\le6$, the sum is at most $3+6+7+7=23$.
\item If $a=3$, $b=7$, then $c\le4$; with $c=4$ we need $d\le5$ (sum $19$), and with $c\le3$ the sum is at most $3+7+3+7=20$.
\end{itemize}
The value $23$ is attained, e.g. by $2777_8=1535$ or $3677_8=1983$. The answer is $\boxed{23}$.
