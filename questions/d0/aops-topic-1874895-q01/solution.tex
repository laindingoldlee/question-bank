Let the radius be $r=\dfrac {d}{2}$, where $d=376{,}216$.

\begin{asy}
usepackage("amsmath");
size(4cm);
defaultpen(fontsize(10pt));
draw(circle((0,0),2),linewidth(1));
draw((-2,0)--(2,0),blue+linewidth(1));dot((0,0));
label("$O$",(0,0),N);label("$d=376216$",(0,0),3*S,blue);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

The ratio is
\[
\dfrac{\pi r^2}{2\pi r}=\dfrac {r}{2}=\dfrac {d}{4}=\dfrac{376216}{4}=\boxed{94054}.
\]
The value of $\pi$ cancels, so the approximation $3.14$ is not needed.
