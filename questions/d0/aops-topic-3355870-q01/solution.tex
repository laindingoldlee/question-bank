There are $7\cdot6=42$ ordered seat assignments. Adjacent seats form six pairs, each with two orders, so $12$ assignments are adjacent. The probability is $1-\dfrac{12}{42}=\boxed{\dfrac{5}{7}}$. Using unordered pairs instead gives the equivalent denominator $\binom72$ and adjacent count $6$.
