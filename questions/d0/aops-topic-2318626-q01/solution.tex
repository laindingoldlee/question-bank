Split at $x=-3$ and $x=3$.
\begin{itemize}
\item If $x\ge3$: $|x+3|-|x-3|=(x+3)-(x-3)=6$, and $6\le1$ is false.
\item If $x\le-3$: $|x+3|-|x-3|=-(x+3)+(x-3)=-6$, and $|-6|=6\le1$ is false.
\item If $-3<x<3$: $|x+3|-|x-3|=(x+3)-(3-x)=2x$, so the inequality is $|2x|\le1$, that is, $-\dfrac12\le x\le\dfrac12$.
\end{itemize}
The solution set is $\boxed{-\dfrac12\le x\le\dfrac12}$.
