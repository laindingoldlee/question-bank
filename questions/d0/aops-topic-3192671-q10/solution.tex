Because $\angle BAD=60^\circ$ equals two-thirds of $\angle BAC$, the latter is $90^\circ$. Also $\angle ABC=60^\circ$, so $\angle C=30^\circ$. If $AB=s$, the right triangle has $BC=2s$, while the equilateral triangle has $BD=s$. Both triangles have the same altitude to $BC$, so $[ABC]=2[ABD]=\boxed2$.
