Let $n$ be the number of tests before the $96$. Then $84n+96=86(n+1)$, so $2n=10$ and $n=5$. After six tests the total is $6\cdot86=516$. After seven tests the total is $7\cdot85=595$, so the last test was $595-516=\boxed{79\%}$.
