The values $n=1,2$ fail directly. For $n\ge3$, reduction modulo $8$ forces $n\equiv0\pmod8$. Hence $2^n\equiv1\pmod5$, so $n\equiv1\pmod5$ and $n=16+40t$.

Modulo $25$, the power has exponent $16$ modulo $20$, so $2^n\equiv2^{16}\equiv11$. Thus $16+40t\equiv11\pmod{25}$, giving $t\equiv3\pmod5$ and $n=136+200u$.

Modulo $125$, the exponent is $36$ modulo $100$, so $2^n\equiv2^{36}\equiv111$. Therefore $136+200u\equiv111\pmod{125}$, giving $u\equiv3\pmod5$. Altogether
\[
n\equiv736\pmod{1000}.
\]
Conversely $736$ meets the congruences modulo $8$ and $125$, so it works modulo $1000$. The least positive solution is $\boxed{736}$.
