Let the initial number be $d$. Every written number is a multiple of $d$, so a final sum of $2023$ would require $d\mid2023$. Every operation adds $4x+9x=13x$, so the sum is always congruent to $d$ modulo $13$. Since $2023\equiv8\pmod{13}$, we need $d\equiv8\pmod{13}$.
But $2023=7\cdot17^2$, and its positive divisors $1,7,17,119,289,2023$ have residues $1,7,4,2,3,8$ modulo $13$. Only $d=2023$ is possible, and any operation strictly increases its initial sum. Hence the target is $\boxed{\text{impossible}}$.
