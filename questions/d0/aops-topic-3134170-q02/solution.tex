Write the quotient as $k$. Suppose a nonsquare $k$ occurs, and choose a solution with $a+b$ minimal, taking $a\ge b$. Regard $a$ as a root of $t^2-kbt+(b^2-k)=0$. Its other root $c=kb-a$ is an integer and satisfies $ac=b^2-k$. We show $c\ge0$. If $c=-u<0$, then $a=kb+u$ and $b^2-k=-au$, so $k=b^2+kbu+u^2>k$, a contradiction because $b,u\ge1$. If $c=0$, then $k=b^2$, also a contradiction to nonsquare $k$. Thus $c>0$. Moreover $c=\dfrac{b^2-k}{a}<\dfrac{b^2}{a}\le b$. The root equation implies $b^2+c^2=k(bc+1)$, so $(b,c)$ is a smaller positive solution for the same nonsquare $k$, contradicting minimality. Therefore $k$ is a square.
