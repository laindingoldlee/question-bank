A relation fails to be a function exactly when one input is paired with two different outputs. The outputs $-4$ and $0$ are different, so the relation is not a function exactly when the two inputs are equal:
\[
-2m+1=-6m+8\iff4m=7\iff m=\boxed{\dfrac{7}{4}}.
\]
