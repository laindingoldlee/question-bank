Three hexagons of increasing size are shown below. Suppose the dot pattern continues so that each successive hexagon contains one more band of dots. How many dots are in the next hexagon?

\begin{asy}
usepackage("amsmath");
size(7cm);
defaultpen(fontsize(10pt));
pair[] shifts={(0,0),(3.2,0),(8.4,0)};
for(int m=0;m<3;++m){
  int k=m;
  for(int q=-k;q<=k;++q) for(int r=-k;r<=k;++r){
    if(abs(q+r)<=k) dot(shifts[m]+q*(1,0)+r*(0.5,sqrt(3)/2));
  }
  if(k>0){ path h=shift(shifts[m])*scale(k)*((1,0)--dir(60)--dir(120)--(-1,0)--dir(240)--dir(300)--cycle); draw(h,gray); }
}
\end{asy}

$\textbf{(A) }35 \qquad \textbf{(B) }37 \qquad \textbf{(C) }39 \qquad \textbf{(D) }43 \qquad \textbf{(E) }49$
