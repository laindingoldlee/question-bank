If $n=p_1^{e_1}\cdots p_k^{e_k}$, then $d(n)=(e_1+1)\cdots(e_k+1)$. This is prime only if $k=1$ and $e_1+1$ is prime, that is, $n=p^{q-1}$ for a prime $p$ and a prime $q$. Below $100$:
\begin{itemize}
\item $q=2$: the primes, $25$ numbers;
\item $q=3$: $p^2\in\{4,9,25,49\}$, $4$ numbers;
\item $q=5$: $p^4\in\{16,81\}$, $2$ numbers;
\item $q=7$: $p^6=64$, $1$ number; and $p^{10}\ge1024$ is too big.
\end{itemize}
The total is $25+4+2+1=\boxed{32}$.
