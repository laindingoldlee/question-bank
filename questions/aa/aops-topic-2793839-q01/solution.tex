The ending point equals the starting point, so the distance between them is $\boxed0$. This is displacement magnitude, not the total distance run.
\begin{asy}
usepackage("amsmath");
size(7cm);
draw(ellipse((0,0),3,1.5));dot((3,0));label("start = finish",(3,0),E);
\end{asy}
