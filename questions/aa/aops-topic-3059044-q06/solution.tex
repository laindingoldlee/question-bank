The first inequality is equivalent to $2y>-x^3-2x^2+x+3$. Thus the full solution set is $\boxed{\dfrac{-x^3-2x^2+x+3}{2}<y<x}$. For a given $x$ this interval is nonempty exactly when $x^3+2x^2+x-3>0$. This additional observation describes precisely which vertical intervals occur, without requiring a cubic radical expression.
