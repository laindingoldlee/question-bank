Use the cell labels in the diagram and cut along boundaries between different letters. Each letter forms one connected piece. If a piece has $n$ unit cells and $e$ shared cell edges, its perimeter is $4n-2e$. For A, B, C respectively, $(n,e)=(9,9),(8,7),(8,7)$, giving perimeter $18$ in every case. Thus this is a valid equal-perimeter dissection.

\end{asy}
