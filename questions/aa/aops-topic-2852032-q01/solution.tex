Let the numbers be $a$, $a+15$, $a+30$; their sum is $3a+45$, so we minimise $a$. We need $8\cdot3\cdot5\mid a(a+15)(a+30)$.
\begin{itemize}
\item $5$: the three numbers are congruent modulo $5$, so $5\mid a$.
\item $3$: likewise $3\mid a$.
\item $8$: the numbers $a$, $a+15$, $a+30$ have the parities of $a$, $a+1$, $a$. If $a$ is odd only $a+15$ is even, and we need $8\mid a+15$. If $a$ is even, $a$ and $a+30$ are even, and $v_2(a)+v_2(a+30)\ge3$.
\end{itemize}
So $15\mid a$. Test multiples of $15$: $a=15$: $15\cdot30\cdot45$ has $2^1$; $a=30$: $30\cdot45\cdot60$ has $2^1\cdot2^2=2^3$. So $a=30$ works, and the minimum sum is $3\cdot30+45=\boxed{135}$.
