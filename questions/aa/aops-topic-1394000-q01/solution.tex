\textbf{(a)} Let $S_n=a+ar+\cdots+ar^{n-1}$. Then $rS_n=ar+ar^2+\cdots+ar^n$, and subtracting,
\[
S_n-rS_n=a-ar^n,\qquad S_n=\dfrac{a\left(1-r^n\right)}{1-r}\quad(r\ne1).
\]
If $|r|<1$, then $r^n\to0$ as $n\to\infty$, so $S_n\to\dfrac{a}{1-r}$. The infinite sum is, by definition, this limit.

\textbf{(b)} Expanding the first $n$ levels of nesting gives exactly the partial sum:
\[
1+r\big(1+r(1+\cdots+r(1)\cdots)\big)=1+r+r^2+\cdots+r^{n-1},
\]
so the nested expression is the geometric series with $a=1$, and its value is $\boxed{\dfrac{1}{1-r}}$. (Assuming the value $x$ exists, the self-similarity $x=1+rx$ also gives $x=\dfrac{1}{1-r}$; part (a) shows the value does exist when $|r|<1$.)
