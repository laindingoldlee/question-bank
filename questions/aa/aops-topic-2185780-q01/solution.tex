There are \textbf{no} such real numbers; we show that the left side is always smaller than the right side.

Let $u=5x^2+2x+5$. Completing the square, $u=5\left(x+\dfrac{1}{5}\right)^2+\dfrac{24}{5}\ge\dfrac{24}{5}$. (Also $4x^2+13x+20>0$ for all $x$, since its discriminant $169-320$ is negative, so the left side is defined everywhere.) Next,
\[6u-\left(4x^2+13x+20\right)=26x^2-x+10>0\]
for all $x$, because the discriminant $1-1040$ is negative. Hence
\[\sqrt{4x^2+13x+20}<\sqrt{6u}.\]
Finally $\sqrt{6u}<u^2$, because this is equivalent to $6u<u^4$, that is, $u^3>6$, which holds since $u\ge\dfrac{24}{5}>2$. Therefore
\[\sqrt{4x^2+13x+20}<\sqrt{6u}<u^2=\left(5x^2+2x+5\right)^2\]
for every real $x$, and the equation has $\boxed{\text{no real solutions}}$.
