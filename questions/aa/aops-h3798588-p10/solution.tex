The last day is even, so its surviving single alga must be red. Reverse the operations from $(G,R)=(0,1)$: undoing an even day replaces $(G,R)$ by $(G+R,R)$, while undoing an odd day replaces it by $(G,R+G)$. In reverse order the pairs are
\[(0,1),(1,1),(1,2),(3,2),(3,5),(8,5),(8,13),(21,13),(21,34),(55,34),(55,89),(144,89),(144,233).\]
Thus initially there were $\boxed{144}$ green algae. Reversing this list verifies that each consuming colour has enough prey.
