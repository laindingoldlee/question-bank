Count functions from an $n$-element set onto an $r$-element labelled set. There are $r^n$ unrestricted functions. Inclusion--exclusion over the missing target elements gives precisely the stated sum. Alternatively partition the domain into $r$ nonempty unlabelled blocks, then assign the $r$ target labels to the blocks in $r!$ ways. Thus the sum equals $\boxed{r!\,S(n,r)}$, where $S(n,r)$ is the number of such partitions; it is zero when $r>n$.
