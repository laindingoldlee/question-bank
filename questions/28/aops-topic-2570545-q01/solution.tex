Suppose $\sqrt5=\dfrac pq$ with positive integers $p,q$ having no common factor. Then $p^2=5q^2$, so $5\mid p^2$, and since $5$ is prime, $5\mid p$. Write $p=5m$: then $25m^2=5q^2$, so $q^2=5m^2$ and in the same way $5\mid q$. Then $5$ divides both $p$ and $q$, a contradiction. Hence $\sqrt5$ is irrational. $\blacksquare$
