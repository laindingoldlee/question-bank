Blue adjacency, together with equality, is an equivalence relation. For transitivity, if $AB,BC$ are blue but $AC$ red, the red edge $AC$ followed by blue $CB$ would force $AB$ red, a contradiction. Thus vertices partition into blue cliques, with every edge between different classes red. A vertex in a class of size $s$ has $n-s=3$ red neighbours, so all classes have the same size $s$. If there are $k$ classes, $(k-1)s=3$. The positive possibilities are $(k,s)=(4,1),(2,3)$, giving $n=4,6$. Both constructions work. The requested sum is $\boxed{10}$.
