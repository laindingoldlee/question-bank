Subtracting values factors as $(A-B)(A(A+B)+B)=0 $. Since $ A-B=-6 $, the second factor is zero. Substitute $ B=A+6 $ to get $ 2A^2+7A+6=(2A+3)(A+2)=0 $. Thus $ A=-\dfrac{3}{2}$ or $-2 $, giving $\boxed{B=\dfrac{9}{2}\text{ or }4}$. Either allows arbitrary $ C $.
