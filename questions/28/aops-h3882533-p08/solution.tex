For each size $k$ with $0<k<p$, cyclically translating a subset in $\mathbb Z_p$ changes its sum by $k$. Since $k$ is invertible modulo $p$, every translation orbit has $p$ members and contains exactly one subset of each sum residue. Thus exactly $\dfrac{\binom pk}{p}$ subsets of size $k$ have sum zero.

The number of all subsets with size divisible by $3$ is
\[
\dfrac{2^p+2\cos(p\dfrac{\pi}{3})}{3}=\dfrac{2^p+1}{3},
\]
by the cube-root-of-unity filter and $p\equiv5\pmod6$. Excluding the empty set leaves $\dfrac{(2^p-2)}{3}$. The full set has size $p\not\equiv0\pmod3$, so all remaining sizes are in $(0,p)$. Dividing by $p$ gives $K=\dfrac{(2^{2027}-2)}{(3\cdot2027)}$, hence $\boxed{b=6081}$.
