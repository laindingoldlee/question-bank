Work modulo $7$; each term depends only on the previous two, so the residues are eventually periodic. Computing $a_{n+2}\equiv a_n+a_{n+1}^2$:
\[
1,\ 2,\ 5,\ 6,\ 6,\ 0,\ 6,\ 1,\ 0,\ 1,\ 1,\ 2,\ \dots
\]
For example $a_2=1+4=5$, $a_3=2+25=27\equiv6$, $a_4\equiv5+36=41\equiv6$, $a_5\equiv6+36=42\equiv0$, $a_6\equiv6+0=6$, $a_7\equiv0+36\equiv1$, $a_8\equiv6+1=7\equiv0$, $a_9\equiv1+0=1$, $a_{10}\equiv0+1=1$, $a_{11}\equiv1+1=2$. Since $(a_{10},a_{11})\equiv(1,2)=(a_0,a_1)$, the residues repeat with period $10$. As $2009=10\cdot200+9$, $a_{2009}\equiv a_9\equiv\boxed{1}$, choice (B).
