Choose coordinates $A=(0,0)$, $B=(w,0)$, $C=(w,h)$, $D=(0,h)$, $P=(x,y)$. The left side is $x^2+y^2+(x-w)^2+(y-h)^2$. The right side is $(x-w)^2+y^2+x^2+(y-h)^2$, exactly the same terms. Thus the equality holds; in fact the argument works for any point in the plane.
\begin{asy}
import geometry; size(220);
pair A=(0,0),B=(5,0),C=(5,4),D=(0,4),P=(3,1.5);draw(A--B--C--D--cycle);draw(A--P--C,dashed);draw(B--P--D,dashed);label("$A$",A,SW);label("$B$",B,SE);label("$C$",C,NE);label("$D$",D,NW);label("$P$",P,N);
\end{asy}
