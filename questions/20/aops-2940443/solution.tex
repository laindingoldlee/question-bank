Write $s_i$ for statement $i$. Suppose first that $s_2$ is false. Then statement 1 is false, statement 4 is true (its antecedent is false), and statement 6 is false because statements 1 and 4 differ. Statement 3 then has the same truth value as statement 5, since among 4,5,6 only 4 is certainly true. But statement 5 says an even number of 1,2,3 are true, so with 1 and 2 false it is true exactly when statement 3 is false. This contradiction shows $s_2$ is true. Consequently $s_4=\neg s_3$, $s_1=\neg s_5$, and statement 2 requires $s_6=\neg s_1=s_5$. Because statement 6 says $s_1=s_4$, it follows that $s_4$ is false: if $s_4$ were true, it would give $s_6=s_1$, a contradiction. Therefore $s_3$ is true. Statement 3 now requires both 5 and 6 true, hence 1 false. The unique list is $\boxed{(F,T,T,F,T,T)}$. Substitution checks statement 5: exactly two of 1,2,3 are true.
