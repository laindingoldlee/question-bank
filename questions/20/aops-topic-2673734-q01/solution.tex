If the number is $\overline{abcd}$, the result is
\[1000a+100b+10c+d-10(a+b+c+d)=990a+90b-9d,\]
a multiple of $9$. So its digit sum is a multiple of $9$: $0+2+4+x=6+x$ with $0\le x\le9$, which forces $x=\boxed{3}$. (For example $2103-10\cdot6=2043$.)
