Subtracting $5x$: $\boxed{-2x^2-5x+1=0}$, so $\boxed{a=-2,\ b=-5,\ c=1}$. (Multiplying by $-1$ gives the equivalent form $2x^2+5x-1=0$ with $a=2$, $b=5$, $c=-1$; either set of values gives the same solutions $x=\dfrac{-5\pm\sqrt{33}}{4}$.)
