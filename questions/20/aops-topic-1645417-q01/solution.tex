The value $2$ is fixed by the procedure: $\dfrac{2+2}{2}=2$. Compare each term with $2$:
\[
x_{n+1}-2=\dfrac{x_n+2}{2}-2=\dfrac{x_n-2}{2}.
\]
So the distance from $2$ is halved at every step, and
\[
x_n-2=\dfrac{x_0-2}{2^n}.
\]
As $n\to\infty$, $2^n\to\infty$, so $x_n-2\to0$. The numbers approach $\boxed{2}$ for every starting integer. (They reach $2$ exactly only if $x_0=2$; otherwise they get arbitrarily close to $2$ from one side, so ``the final number'' means this limit.)
