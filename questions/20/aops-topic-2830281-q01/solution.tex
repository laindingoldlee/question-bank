If there are $b$ blue numbers, all at most $b$ (the largest is $b$), then the blue numbers are exactly $1,\dots,b$. The red numbers are $b+1,\dots,101$, so the smallest red number is $b+1$ and there are $101-b$ red numbers. Then $b+1=\dfrac{101-b}2$, so $b=33$, and there are $\boxed{68}$ red numbers.
