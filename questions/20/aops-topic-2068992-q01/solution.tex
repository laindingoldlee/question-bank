Rearranging, $f(x)(x-1)=x$.
\begin{itemize}
\item If $x=1$ the equation reads $1+f(1)=f(1)$, which is impossible; so $1$ cannot be in the domain.
\item If $x\ne1$ we must have $f(x)=\dfrac{x}{x-1}$.
\end{itemize}
Conversely, for $x\ne1$, $x+\dfrac{x}{x-1}=\dfrac{x(x-1)+x}{x-1}=\dfrac{x^2}{x-1}=x\cdot\dfrac{x}{x-1}$, so this works. Hence
\[
\boxed{f(x)=\dfrac{x}{x-1}},\qquad\text{defined for all real }x\ne1 .
\]
