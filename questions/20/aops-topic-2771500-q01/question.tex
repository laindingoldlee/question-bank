Pascal's triangle has entries $\binom nk $ in row $ n $, starting with row $ 0 $. Begin at $\binom22=1 $ and move down-left repeatedly, so each move increases the row index and keeps $ k=2 $. Find the entry after $ j $ moves. Does any finite move reach infinity?
