The available blocks are $T=\{16,25,36,49,64,81\}$, and a candidate is $N=10000A+100B+C$ with $A,B,C\in T$. A square must lie in the quadratic-residue set modulo every modulus. For example, modulo $16$ we have $N\equiv4B+C$ and the allowed residues are $0,1,4,9$; if $B$ is odd this forces $C$ to be $16$ or $64$.

Continue the same residue sieve using $N=10000A+100B+C$ modulo $3,7,11,13$. The successive candidate counts are $144,80,40,21,8$ for moduli $16,3,7,11,13$. The eight survivors are
\[
161616,\ 166464,\ 252564,\ 256425,\ 363636,\ 641664,\ 646416,\ 646464.
\]
Modulo $9$, only $166464,363636,641664,646416$ survive. Modulo $17$, $363636$ is excluded; modulo $19$, $641664$ is excluded. Finally,
\[
\boxed{166464=408^2,\qquad646416=804^2}.
\]
Thus residue conditions eliminate all other block combinations without testing each of the original $216$ numbers by square-root calculation.
