Consider any one marble when the bag holds $m\ge2$ marbles. It is among the two drawn with probability $\dfrac{2}{m}$, and if so it is thrown away with probability $\dfrac{1}{2}$. So each step throws away each marble in the bag with the same probability $\dfrac{1}{m}$: a step simply removes a uniformly random marble.

The procedure never looks at colours, so it treats all nine marbles alike: by symmetry each of them has the same chance $\dfrac{1}{9}$ of being the last one left. Four of the nine are red, so the probability is
\[
\boxed{\dfrac{4}{9}}.
\]
(If John chose the marble to keep deliberately, the answer would depend on his strategy. For instance, if he always keeps a red marble when he draws one, a red marble is thrown away only when two reds are drawn, and then the other red stays; so the last marble is certainly red.)
