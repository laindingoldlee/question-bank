\textbf{They are the same decimal.} A decimal expansion is a list of digits, one for each place after the point. Both $0.\overline9$ and $0.\overline{99}$ have the digit $9$ in every place, so they are the same expansion and denote the same number. (``Even infinite'' has no meaning here: there is one $9$ in each decimal place, in both.)

\textbf{The common value.} As a geometric series,
\[0.\overline{99}=\dfrac{99}{100}+\dfrac{99}{100^2}+\cdots=\dfrac{\dfrac{99}{100}}{1-\dfrac1{100}}=1,\qquad0.\overline9=\dfrac{9}{10}+\dfrac{9}{10^2}+\cdots=\dfrac{\dfrac9{10}}{1-\dfrac1{10}}=1.\]
(Or: if $x=0.\overline9$, then $10x-x=9.\overline9-0.\overline9=9$, so $x=1$.) So $0.\overline9=0.\overline{99}=\boxed{1}$.
