$6!=720=2^4\cdot3^2\cdot5$ and $\log_{10}5=1-\log_{10}2\approx0.699$, so $\log_{10}720\approx4(0.301)+2(0.4771)+0.699=2.8572$. Then $\log_{10}720^{720}\approx720\cdot2.8572\approx2057.2$, so the number has $\lfloor2057.2\rfloor+1=\boxed{2058}$ digits. (The true value $2057.28\ldots$ confirms it.)
