Replace each original coin of value $c$ cents by $c$ coins each worth $\dfrac{100}{c}$ cents. This is an allowed denomination for every listed $c$. The replacement produces $c$ coins totaling $100$ cents. Summing over the original $B$ coins yields $A$ coins with total value $100B$ cents, namely $B$ dollars.
