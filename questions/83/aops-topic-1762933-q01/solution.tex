The first digit $f$ is $1,\dots,9$, and then the last digit must be $10-f$, which is a digit from $9$ down to $1$; so there are $9$ choices for the pair. The $8$ middle digits are arbitrary: $10^8$ choices. The total is $9\cdot10^8=\boxed{900000000}$.
