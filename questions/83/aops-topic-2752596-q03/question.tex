In a game of tag, one player starts at time $0$, swims $5$ metres in the first $2$ seconds and then swims at $10$ metres per second along a straight path. The chaser waits $10$ seconds, then swims along the same path at $20$ metres per second. How many seconds after the start does the chaser catch the first player?
