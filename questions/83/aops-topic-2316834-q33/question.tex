A student solved $3x^2-7x-6=0$ with the quadratic formula as follows:
\[x=\dfrac{-7\pm\sqrt{(-7)^2-4(3)(-6)}}{2(3)}=\dfrac{-7\pm\sqrt{121}}{6},\qquad x=\dfrac23\text{ and }x=-3.\]
Which statement describes the error?

$\textbf{(A)}$ In the numerator, the first $-7$ should be $7$.

$\textbf{(B)}$ The expression $(-7)^2-4(3)(-6)$ does not simplify to $121$.

$\textbf{(C)}$ The expression $(-7)^2-4(3)(-6)$ should be $7^2-4(3)(-6)$.

$\textbf{(D)}$ Before using the quadratic formula, both sides must be divided by $3$.

Correct the error and find the solutions.
