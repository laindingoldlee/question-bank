Follow the number of slices. The first four uses give
\[49\to24\to29\to14\to19,\]
and dropping a slice leaves $18$. After that:
\[18\to23\to11\to5\to2\to7\to3\to1\to0\to5\to2\to\cdots\]
($18$ is even, so $18+5=23$; $23$ is odd, so $\dfrac{22}{2}=11$; then $\dfrac{10}{2}=5$, $\dfrac42=2$, $2+5=7$, $\dfrac62=3$, $\dfrac22=1$, $\dfrac02=0$, $0+5=5$.)

The next number depends only on the current one, so once $5$ appears for the second time, the numbers repeat the cycle $5,2,7,3,1,0$ forever. The numbers that ever occur are $49,24,29,14,19,18,23,11$ and the cycle, and none of them is $10$. So $\boxed{\text{the pizza never has exactly }10\text{ slices}}$, and the friends can never get exactly $2$ slices each.
