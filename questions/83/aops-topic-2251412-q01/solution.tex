Let there be $U$ upvotes, $D$ downvotes and $T=U+D$ voters. Then $U-D=55200$.

\textbf{(a)} If $U=0.89T$ then $D=0.11T$ and $0.78T=55200$, so $T=\dfrac{55200}{0.78}=70769.2\ldots$, not an integer. So exactly $89\%$ is impossible.

\textbf{(b)} $U=\dfrac{T+55200}{2}$, so $T$ is even and $\dfrac UT=\dfrac12+\dfrac{27600}{T}$. Rounding to $89\%$ requires $0.885\le\dfrac UT<0.895$, i.e.
\[0.385\le\dfrac{27600}{T}<0.395\iff69873.4\ldots<T\le71688.3\ldots.\]
The smallest even $T$ in this range is $\boxed{69874}$ (then $U=62537$, $D=7337$, and $\dfrac UT=0.89499\ldots$).
