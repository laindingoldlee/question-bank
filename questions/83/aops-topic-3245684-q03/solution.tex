Each exterior angle is $180-172=8^\circ$. Their total is $360^\circ$, so the number of sides is $\boxed{45}$.
\begin{asy}
usepackage("amsmath");
size(7cm);
path p;for(int i=0;i<45;++i)p=p--2dir(8*i);draw(p--cycle);label("45 sides; exterior turn $8^\circ$",(0,-2.6));
\end{asy}
