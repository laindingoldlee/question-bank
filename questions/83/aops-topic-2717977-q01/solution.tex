$\gcd(792,1000)=8$ divides $48$, so dividing by $8$: $99n\equiv6\pmod{125}$. By the Euclidean algorithm $24\cdot99-19\cdot125=1$, so $99^{-1}\equiv24\pmod{125}$ and $n\equiv6\cdot24=144\equiv19\pmod{125}$. So $\boxed{n\equiv19\pmod{125}}$, i.e. $n\equiv19,144,269,394,519,644,769,894\pmod{1000}$. (Check: $792\cdot19=15048$.)
