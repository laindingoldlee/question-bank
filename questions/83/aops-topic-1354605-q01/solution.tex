Each player picks one of $\dbinom{12}{2}=66$ chords, so there are $66^2=4356$ equally likely ordered pairs of chords.
\begin{itemize}
\item Same chord: $66$ pairs.
\item Exactly one shared endpoint: choose the shared point ($12$), then the other endpoints of Red's and Blue's chords, which are different ($11\cdot10$): $1320$ pairs.
\item Four different endpoints: choose the $4$ points ($\dbinom{12}{4}=495$); of the three ways to pair them into two chords exactly one pairing crosses, and it can be assigned to Red and Blue in $2$ ways: $990$ crossing pairs.
\end{itemize}
(a) $P(\text{Red})=\dfrac{66+1320+990}{4356}=\dfrac{2376}{4356}=\boxed{\dfrac{6}{11}}$, so $P(\text{Blue})=\dfrac{5}{11}$; the game slightly favours Red.

(b) $P(\text{Red})=\dfrac{990}{4356}=\boxed{\dfrac{5}{22}}$, which now strongly favours Blue. (So neither rule is exactly fair; the original rule is the closer of the two.)
