Set $ u=x+\dfrac{1}{x}$. Then $ x^2+\dfrac{1}{x^2}=u^2-2 $, so $ u^2+u-12=0 $, giving $ u=3 $ or $ u=-4 $. Both are attainable by real $ x $, since $ x^2-ux+1=0 $ has discriminant $ u^2-4>0 $ in both cases. The values are $\boxed{3,-4}$.
