Set $ d=m-n $. Then $ 37n+20d=2017 $, so $ d\equiv25\equiv-12\pmod{37}$. The representative closest to zero is $-12 $, attained at $ n=61,m=49 $. Thus the minimum is $\boxed{12}$.
