Name the corners of the frame lower left, upper left, upper right, lower right (clockwise). A clockwise quarter turn moves the vertex in each corner to the next corner clockwise, so the new position is the old one shifted: the old last letter comes first. A reflection in the vertical axis swaps lower left with lower right and upper left with upper right, which reverses the four letters.

Starting from square $1$:
\[
ABCD\ \xrightarrow{\text{rotate}}\ DABC\ \xrightarrow{\text{reflect}}\ CBAD\ \xrightarrow{\text{rotate}}\ DCBA\ \xrightarrow{\text{reflect}}\ ABCD .
\]

\begin{asy}
usepackage("amsmath");
size(10cm);
defaultpen(fontsize(10pt));
void sq(pair o,string[] L){
  pair[] c={o,o+(0,1),o+(1,1),o+(1,0)};
  pair[] d={SW,NW,NE,SE};
  draw(o--o+(0,1)--o+(1,1)--o+(1,0)--cycle,linewidth(0.9));
  for(int i=0;i<4;++i) label("$"+L[i]+"$",c[i],d[i]);
}
sq((0,0),new string[]{"A","B","C","D"});
sq((2.6,0),new string[]{"D","A","B","C"});
sq((5.2,0),new string[]{"C","B","A","D"});
sq((7.8,0),new string[]{"D","C","B","A"});

draw((6.55,0.5)--(7.45,0.5),Arrow(TeXHead));label("rotate",(7,0.5),N,fontsize(8pt));
label("$1$",(0.5,-0.5));label("$2$",(3.1,-0.5));label("$3$",(5.7,-0.5));label("$4$",(8.3,-0.5));

\end{asy}

(The dashed line on square $3$ is the axis of the next reflection, shown for reference; the arrows show the moves.) So square $5$ is in the starting position again and the positions repeat with period $4$. Since $2007=4\cdot501+3$, the $2007$th square is in the same position as the third:
\[
\boxed{CBAD}.
\]
