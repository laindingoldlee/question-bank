For any positive integers $a$ and $b$,
\[
\gcd(a,b)\cdot\operatorname{lcm}(a,b)=ab .
\]
Indeed, write $g=\gcd(a,b)$, $a=gx$ and $b=gy$ with $\gcd(x,y)=1$. The least common multiple is $gxy$, so $g\cdot gxy=(gx)(gy)=ab$.

So if the other number is $b$, then $91b=7\cdot546$, and
\[
b=\dfrac{7\cdot546}{91}=\dfrac{3822}{91}=\boxed{42}.
\]
Check: $91=7\cdot13$ and $42=7\cdot6$, so $\gcd(91,42)=7$ and $\operatorname{lcm}(91,42)=7\cdot13\cdot6=546$.
