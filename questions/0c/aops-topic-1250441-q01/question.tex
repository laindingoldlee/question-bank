Side-side-angle (SSA) is not a valid congruence test in general. Prove that it \emph{is} valid when the given angle is not acute: if in triangles $ABC$ and $A'B'C'$ we have $AB=A'B'$, $BC=B'C'$ and $\angle A=\angle A'\ge90^\circ$, then the triangles are congruent.
