Fix the first vertex colour. Let $a_n,b_n$ count proper path colourings of $n$ vertices whose last colour is respectively the same as or different from the first. Then $a_1=1,b_1=0$, and $a_{n+1}=b_n$, $b_{n+1}=2a_n+b_n$. The values of $b_n$ for $n=1,\ldots,8$ are 0, 2, 2, 6, 10, 22, 42, 86. Closing the cycle requires the last colour differ from the first, so 86 choices work per first colour. Multiplying by 3 gives $\boxed{258}$.

\end{asy}
