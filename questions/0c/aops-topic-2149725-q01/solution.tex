A three-digit palindrome is $\overline{aba}=101a+10b$ with $1\le a\le9$ and $0\le b\le9$. Then
\[\overline{aba}\cdot101=\overline{aba}\cdot100+\overline{aba}=10000a+1000b+100\cdot2a+10b+a .\]
If $a\le4$, then $2a\le8$ is a single digit and there are no carries, so the product is the five-digit palindrome $\overline{a\,b\,(2a)\,b\,a}$. For example $494\cdot101=49894$.

So the answer has $a\ge5$, and the smallest candidate is $505$:
\[505\cdot101=51005,\]
which is not a palindrome (the carry from $2a=10$ spoils the middle). The answer is $\boxed{505}$.
