Let $g=\gcd(a,b)$ and write $a=gx$, $b=gy$ with $\gcd(x,y)=1$. Then $\operatorname{lcm}(a,b)=gxy$ and the equation becomes
\[g^2xy+63=20gxy+12g,\qquad\text{that is,}\qquad g(g-20)xy=12g-63 .\]
Since $g$ divides every other term, $g\mid63$, so $g\in\{1,3,7,9,21,63\}$.
\begin{itemize}
\item $g=1,3,7,9$: then $g-20<0$, so the left side is negative, while $12g-63$ equals $-51,-27,21,45$. For $g=7,9$ the signs differ. For $g=1$: $19xy=51$; for $g=3$: $51xy=27$; neither has an integer solution.
\item $g=21$: $21xy=189$, so $xy=9$ with $\gcd(x,y)=1$: $(x,y)=(1,9)$ or $(9,1)$ (the pair $(3,3)$ is not coprime).
\item $g=63$: $63\cdot43\,xy=693$, impossible since $63\cdot43>693$.
\end{itemize}
So $(a,b)=(21,189)$ or $(189,21)$. Check: $21\cdot189+63=4032$ and $20\cdot189+12\cdot21=3780+252=4032$. There are $\boxed{2}$ ordered pairs.
