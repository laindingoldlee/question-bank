Rewrite the equation as $(3a-4)x=6a+8b$. A linear expression in $x$ is zero for all $x$ only if both coefficients are zero, so $3a-4=0$ and $6a+8b=0$. Hence $a=\dfrac{4}{3}$ and $8b=-6a=-8$, so $\boxed{b=-1}$. ($b$ is a number, not an expression in $a$, because the condition ``for all $x$'' also determines $a$.)
