Find the error in the following ``proof'' that $0=1$:
\begin{align*}
0+0+0+\cdots&=(1-1)+(1-1)+(1-1)+\cdots\\
&=1-1+1-1+1-1+\cdots\\
&=1+(-1+1)+(-1+1)+\cdots\\
&=1+0+0+\cdots,
\end{align*}
so $0=1$.
