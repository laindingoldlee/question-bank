No entry has three or more digits: even the smallest three-digit construction, $ 123 $ with the remaining digits used singly, totals $ 162>135 $. Larger positional weights only increase this lower bound. Let $ T $ be the set of tens digits of the two-digit entries. Since all digits sum to $ 45 $, the sum is $ 45+9\sum_{t\in T}t $, so $\sum T=10 $. The possible sets are four pairs $\{1,9\},\{2,8\},\{3,7\},\{4,6\}$; four triples $\{1,2,7\},\{1,3,6\},\{1,4,5\},\{2,3,5\}$; and $\{1,2,3,4\}$. For a set of size $ k $, assign distinct units digits from the other $ 9-k $ digits in $\dfrac{(9-k)!}{(9-2k)!}$ ways, then arrange the $ 9-k $ distinct entries. Thus the count is $ 4(7\cdot6)7!+4(6\cdot5\cdot4)6!+(5\cdot4\cdot3\cdot2)5!=\boxed{1206720}$.
