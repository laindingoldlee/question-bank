The case $x=0$ has limit zero and does not work. For $x>0$, induction gives $R_n=x^{1-2^{-n}}$. The exponent tends to one, so the limit is $x$. Hence $\boxed{x=\sqrt{2022}}$. This value does yield the required limit.
