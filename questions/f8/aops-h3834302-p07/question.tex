Eric is randomly labeling each cell of a rectangular $8\times 10$ grid with the numbers $1,2,\dots,80$ such that each number is used once. A cell is called a pit if its number is smaller than all adjacent cells (two cells are adjacent if they share an edge). If the expected number of pits can be expressed as $\dfrac{a}{b}$ where $a$ and $b$ are relatively prime positive integers, find $a+b$.
