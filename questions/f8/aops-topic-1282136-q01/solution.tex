Expanding,
\[
n^3-9n^2+27n-27+n^3=n^3+9n^2+27n+27\iff n^3-18n^2=54\iff n^2(n-18)=54 .
\]
If $n\le18$, the left side is at most $0$. If $n\ge19$, then $n^2(n-18)\ge361>54$. So there is no integer solution. $\blacksquare$
