$\dfrac1{k^3-k}=\dfrac12\left(\dfrac1{k(k-1)}-\dfrac1{k(k+1)}\right)$, so the sum telescopes to $\dfrac12\left(\dfrac12-\dfrac1{n(n+1)}\right)<\dfrac14$. It is never an integer: there are $\boxed{\text{no such }n}$.
