By Vieta's formulas $r+s+t=33$, so
\[(r+s)(r+t)(s+t)=(33-t)(33-s)(33-r)=P(33),\]
where $P(x)=x^3-33x^2+270x-616=(x-r)(x-s)(x-t)$. Now
\[P(33)=33^3-33\cdot33^2+270\cdot33-616=8910-616=\boxed{8294}.\]
