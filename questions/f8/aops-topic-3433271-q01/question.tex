An $n$-question test uses $n$ distinct answer symbols, each used exactly once in the correct answer key. A guess is chosen uniformly from all permutations of these symbols. (a) What is the probability that a specified answer is correct? (b) What is the expected number correct? (c) What is the probability that all are correct?
