A monic quadratic $x^2+ax+c$ with integer coefficients has integer roots iff its discriminant $a^2-4c$ is a perfect square (then the roots $\dfrac{-a\pm\sqrt{a^2-4c}}{2}$ are integers, because $a^2-4c\equiv a^2\pmod 2$ makes the numerator even). So we need
\[
a^2-4b=m^2,\qquad a^2-4b-4=n^2
\]
for non-negative integers $m,n$. Then $m^2-n^2=4$, i.e.\ $(m-n)(m+n)=4$. The factors have the same parity, so $m-n=m+n=2$, giving $m=2$, $n=0$. Hence $a^2-4b=4$, so $a$ is even, $a=2t$, and $b=t^2-1$.

Conversely, for $a=2t$ and $b=t^2-1$ the quadratics are $(x+t-1)(x+t+1)$ and $(x+t)^2$, both with integer roots. The condition $0\le t^2-1\le2002$ with $t\ge1$ means $1\le t\le44$ (as $44^2=1936\le2003<2025=45^2$). So there are $\boxed{44}$ values of $a$.
