Fix any outcome of the first five rolls, with sum $s$. The last roll takes the values $1,2,3,4,5,6$, which have six different remainders mod $6$, so $s+1,\dots,s+6$ are six consecutive integers and exactly one of them is divisible by $6$. Thus, whatever the first five rolls are, exactly one of the six equally likely values of the last roll works, and the probability is $\boxed{\dfrac{1}{6}}$.
