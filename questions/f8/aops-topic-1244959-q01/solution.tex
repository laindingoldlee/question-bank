\textbf{True.} A line $y=mx+k$ passes through $(x_0,y_0)$ exactly when $k=-x_0m+y_0$, i.e. when the point $(m,k)$ lies on the line $L:\ k=-x_0m+y_0$ in the $(m,k)$-plane. So three lines with distinct slopes are concurrent if and only if the three points $(m,k)$ are collinear on a non-vertical line (a vertical line $m=$ const would force equal slopes).

By hypothesis $(a,b)$, $(c,d)$, $(e,f)$ are collinear. Swapping coordinates (reflecting in the line $m=k$) preserves collinearity, so $(b,a)$, $(d,c)$, $(f,e)$ are collinear, and their common line is not vertical because $b,d,f$ are distinct. If that line is $k=pm+q$, then all three new lines pass through the point $(x,y)=(-p,q)$. $\blacksquare$
