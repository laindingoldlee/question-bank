The square root requires $x\ge0$. Set $t=\sqrt x\ge0$. The equation is $(\sqrt2-1)t^2=2t$, so either $t=0$ or $t=\dfrac{2}{\sqrt2-1}=2(\sqrt2+1)$. Squaring gives $\boxed{x=0\text{ or }12+8\sqrt2}$. Both arose through reversible steps and satisfy the original equation.
