The primes from $1$ to $15$ are $2,3,5,7,11,13$, so each deck has $6$ prime and $9$ non-prime cards. The first card must be one of the $6$ red primes: probability $\dfrac{6}{60}$. That card is prime, so all $36$ non-prime cards remain among the $59$ cards left, and the second card is non-prime with probability $\dfrac{36}{59}$. The probability is
\[
\dfrac{6}{60}\cdot\dfrac{36}{59}=\boxed{\dfrac{18}{295}}.
\]
(Note that $1$ is not prime, so it counts as non-prime.)
