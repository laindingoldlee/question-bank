Fix $c$. We need positive integers $a,b$ with $a+b\le c-1$. For each $s=a+b$ with $2\le s\le c-1$ there are $s-1$ ordered pairs, so the number of pairs is
\[
1+2+\dots+(c-2)=\dbinom{c-1}{2}.
\]
For $c=1,2,3,4,5$ this gives $0,0,1,3,6$, in total $\boxed{10}$.
