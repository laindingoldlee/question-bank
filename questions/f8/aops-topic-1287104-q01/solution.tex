Squaring gives $x+1=1-2x+x^2$, i.e. $x^2-3x=0$, so $x=0$ or $x=3$. Squaring can introduce extra roots, so both must be checked.

The symbol $\sqrt{\phantom{x}}$ denotes the nonnegative (principal) square root, so the equation requires $1-x\ge0$. For $x=0$: $\sqrt1=1=1-0$, a solution. For $x=3$: $\sqrt4=2$ but $1-3=-2$; although $(-2)^2=4$, the number $\sqrt4$ is $2$, not $-2$, so $x=3$ solves $-\sqrt{x+1}=1-x$ instead and is extraneous. The only solution is $\boxed{x=0}$.
