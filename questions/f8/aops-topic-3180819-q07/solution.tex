Write $n=10a+b$, where $1\le a\le9$ and $0\le b\le9$. The condition is $a\mid b$. For each $a$ there are $1+\lfloor\dfrac{9}{a}\rfloor$ choices, including $b=0$. These counts are $10,5,4,3,2,2,2,2,2$, summing to $\boxed{32}$.
