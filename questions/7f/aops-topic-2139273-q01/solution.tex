We need $\overline{SAT}^{\,2}=\overline{STARS}$, a five-digit number, so $100\le\overline{SAT}\le316$ and $S\in\{1,2,3\}$.
\begin{itemize}
\item If $S=2$, then $\overline{SAT}\ge200$ and its square is at least $40000$, whose first digit is not $2$. If $S=3$, the square is at least $90000$. So $S=1$.
\item The square must begin with $1$, so it is less than $20000$ and $\overline{SAT}\le141$.
\item The square ends in $S=1$, so $T=1$ or $T=9$; as $T\ne S$, $T=9$.
\item So $\overline{SAT}=\overline{1A9}\le141$ with $A$ a nonzero digit different from $1$: $A=2$ or $A=3$. Now $129^2=16641$ does not have second digit $T=9$, while $139^2=19321$ has the form $\overline{STARS}$ with $S=1$, $T=9$, $A=3$, $R=2$.
\end{itemize}
So $\boxed{A=3,\ R=2,\ S=1,\ T=9}$, since $\sqrt{19321}=139$, and the answer is unique.
