Each friend independently chooses one of the $3$ clubs, so there are $3^6=\boxed{729}$ ways. The count ``$6\cdot5\cdot4$'' would place exactly one friend in each club (and ignore the other three), as if the clubs chose single members; it does not describe the situation, in which a club may have any number of members, including none. Count from the point of view of the objects that make exactly one choice each (here, the friends).
