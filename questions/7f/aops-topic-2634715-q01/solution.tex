Since $600=2^3\cdot3\cdot5^2$, an ordered triple $(a,b,c)$ with $abc=600$ amounts to splitting each exponent among $a,b,c$. By stars and bars there are
\[\dbinom52\dbinom32\dbinom42=10\cdot3\cdot6=180\]
ordered triples. A triple with a repeated entry, say $a=b$, needs $a^2\mid600$, so $a\in\{1,2,5,10\}$; no triple has all entries equal, since $600$ is not a cube. These $4$ choices, each with $3$ positions for the odd entry, give $12$ ordered triples. The remaining $168$ ordered triples have distinct entries, and each set $\{a,b,c\}$ appears $3!=6$ times. So the answer is $\dfrac{168}{6}=\boxed{28}$.
