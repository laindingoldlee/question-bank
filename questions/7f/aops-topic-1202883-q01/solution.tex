$\gcd(224,140)=28$, and by Bezout's identity $224x+140y$ takes exactly the values $28k$, $k$ any integer. So $A=28k+531$. Since $531=28\cdot18+27$, the least positive value is $27$, at $k=-18$ ($k=-19$ gives $-1$). For example, $224x+140y=-504$ means $8x+5y=-18$, solved by $x=-1$, $y=-2$: $A=-224-280+531=27$. So the minimum is $\boxed{27}$.
