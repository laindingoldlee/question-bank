\emph{$n<0$:} then $0<2^n<1\le n^2$, so there is no solution. \emph{$n=0,1,2,3,4$:} $n^2=0,1,4,9,16$ and $2^n=1,2,4,8,16$, so $n=2$ and $n=4$ work.

\emph{$n\ge5$:} we show $2^n>n^2$ by induction. For $n=5$, $32>25$. If $2^n>n^2$ with $n\ge5$, then $2^{n+1}>2n^2\ge(n+1)^2$, because $2n^2-(n+1)^2=(n-1)^2-2>0$. So there are no solutions with $n\ge5$.

The solutions are $\boxed{n=2\text{ and }n=4}$.
