Every path consists of $6$ moves right and $5$ moves down, $11$ moves in all, in some order. Conversely every arrangement of $6$ R's and $5$ D's is a path that stays on the grid. A path is determined by choosing which $5$ of the $11$ moves are downward, so the number of paths is
\[
\dbinom{11}{5}=\dfrac{11\cdot10\cdot9\cdot8\cdot7}{5\cdot4\cdot3\cdot2\cdot1}=\boxed{\text{(A) }462}.
\]
