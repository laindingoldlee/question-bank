Put $s=b+\dfrac{1}{b}$, which has the same sign as $b$ and is nonzero. If $c<0$, the discriminant $s^2-4c$ is positive and the root product is negative, so exactly one root is positive. If $c=0$, the roots are 0 and $-s$, giving one positive root exactly when $b<0$. If $c>0$, real roots have the same sign. They can give exactly one distinct positive root only when the discriminant is zero and their common value $-\dfrac{s}{2}$ is positive; this requires $b<0$ and $c=\dfrac{s^2}{4}$. Therefore for $b>0$ the answer is $\boxed{c<0}$, while for $b<0$ it is $\boxed{c\le0\text{ or }c=\dfrac{(b+\dfrac{1}{b})^2}{4}}$.
