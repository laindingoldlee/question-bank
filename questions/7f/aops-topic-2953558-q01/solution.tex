Call $1,2,3$ the stars. Exactly one team gets two stars.

\emph{Player $3$ always wins.} If neither captain is a star, the order is: high captain takes $1$, low captain takes $2$, high captain takes $3$, so $3$ is with $1$. If exactly one captain $k$ is a star, the other captain (higher-numbered) takes the best remaining star and $k$ takes the last one. If $k=3$ that last star joins $3$; if $k\in\{1,2\}$ it is $3$ itself, joining $k$. Either way $3$ is on the two-star team. If both captains are stars, the higher one takes the third star. If $3$ is a captain it gets that star; otherwise the captains are $1,2$ and captain $2$ takes $3$. In every case $3$ wins.

\emph{Player $4$ always loses.} In each case above, once the stars are used up, the next pick goes to the team that does not have two stars, and that pick is $4$. If $4$ is itself a captain, the other captain or the first picks take two stars against it.

So player $\boxed{3}$ wins with probability $1$ and player $\boxed{4}$ with probability $0$. For comparison, players $1$ and $5$ win with probability $\dfrac{29}{45}$.
