(a) If $ax\equiv1\pmod m$, then $ax-1=my$ for some integer $y$, so $ax-my=1$. Any common divisor of $a$ and $m$ divides $ax-my=1$, so $\gcd(a,m)=1$.

Conversely, if $\gcd(a,m)=1$, B\'ezout's identity (which follows from running the Euclidean algorithm backwards) gives integers $x,y$ with $ax+my=1$. Then $ax\equiv1\pmod m$.

(b) The Euclidean algorithm on $43$ and $17$:
\[
43=2\cdot17+9,\qquad 17=1\cdot9+8,\qquad 9=1\cdot8+1.
\]
Working backwards,
\[
1=9-8=9-(17-9)=2\cdot9-17=2(43-2\cdot17)-17=2\cdot43-5\cdot17.
\]
So $17\cdot(-5)\equiv1\pmod{43}$, and $-5\equiv38$. Check: $17\cdot38=646=15\cdot43+1$. Hence
\[\boxed{x=38}.\]
