(a) There are $26^4\cdot10=4{,}569{,}760$ objects. Since $2^{22}=4{,}194{,}304<4{,}569{,}760\le2^{23}$, $23$ bits are necessary and sufficient. Whole-byte storage requires $\boxed3$ bytes.
(b) There are $26^2\cdot6\cdot12\cdot95=4{,}623{,}840<2^{24}=16{,}777{,}216$ objects. Number them from zero and encode each index in $24$ bits. Thus $\boxed{\text{yes}}$.
