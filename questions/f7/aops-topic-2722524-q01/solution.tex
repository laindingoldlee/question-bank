When Vic finishes $2$ miles, Harold has run $1.9$, so $h=\dfrac{1.9}{2}v=0.95v$. Similarly $c=\dfrac{1.8}{2}h=0.9h=0.855v$. When Vic finishes, Charlie has run $0.855\cdot2=1.71$ miles, so Vic wins by $\boxed{0.29}$ mile.

``Beats by $\dfrac1{10}$ mile'' means Harold is $\dfrac1{10}$ mile short \emph{when Vic finishes $2$ miles}, i.e. distances $2$ and $1.9$ in the same time, a ratio of $\dfrac{19}{20}$. Modelling it as $2.1$ versus $2$ gives the ratio $\dfrac{20}{21}$, a slightly different race. (Likewise $c=\dfrac9{10}h$, not $h=\dfrac{11}{10}c$.)
