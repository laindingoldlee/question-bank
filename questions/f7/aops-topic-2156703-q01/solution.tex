From the second equation $xy=3$, so the first two equations give
\[(x+y)^2=x^2+y^2+2xy=4+6=10 .\]
But the third equation gives $(x+y)^2=1$. This is a contradiction, so the system has \textbf{no solutions}, real or complex.
