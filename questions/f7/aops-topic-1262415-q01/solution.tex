The tank is full at the start (just filled), and filling it again later measures exactly the gas used since the previous fill. So the gas used during the trip is $12+20=32$ gallons; the first $6$ gallons were bought before the trip started (they only topped up the tank) and were replaced by later fills. The distance is $57060-56200=860$ miles, so the average is
\[\dfrac{860}{32}=26.875\approx\boxed{\textbf{(D) } 26.9}.\]
