Ignore the $0$. The six letters are the five capitals $A,P,S,R,X$ and the single lowercase $o$. Caps Lock is turned on once for each maximal run of capitals (a run of capitals separated from the previous one by the $o$).

If $o$ is first or last among the six letters, the capitals form one run and Caps Lock is turned on exactly once. If $o$ is in positions $2$ to $5$, there are capitals before and after it, and Caps Lock is turned on twice.

By symmetry $o$ is equally likely to be in any of the $6$ letter positions, so the probability is $\dfrac{2}{6}=\boxed{\dfrac{1}{3}}$.
