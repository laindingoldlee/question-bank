A player pays $\$5$ to play a game. A die is rolled. If the number on the die is odd, the game is lost. If the number is even, the die is rolled again, and the player wins if the second number matches the first and loses otherwise. How much should the player receive on a win for the game to be fair? (A game is fair when the probability of winning times the amount won equals the amount the player pays.)
