The identity $a+b=(a\star b)+2(a\mathbin{\&}b)$, where the last operation keeps the shared $1$ bits, shows that equality holds precisely when no bit position contains a $1$ in both numbers. There are eleven binary positions. Each admits exactly $(0,0),(0,1),(1,0)$, independently, giving $3^{11}$ pairs.

Because $11$ is prime, the only representation of $3^{11}$ as $m^n$ with integers $m,n>1$ has $m=3,n=11$. Therefore $\boxed{m+n=14}$.
