Since $x,y,z\ne0$ we may divide each equation by $xyz$. With $p=\dfrac{1}{x}$, $q=\dfrac{1}{y}$, $r=\dfrac{1}{z}$ (note $\dfrac{xy}{xyz}=r$, $\dfrac{yz}{xyz}=p$, $\dfrac{zx}{xyz}=q$) the system becomes linear:
\[
r+2p+3q=2015,\qquad 2r+3p+q=2016,\qquad 3r+p+2q=2017 .
\]
Adding all three: $6(p+q+r)=6048$, so $p+q+r=1008$.

Subtracting $2(p+q+r)=2016$ from the first equation gives $q-r=-1$; subtracting it from the second gives $p-q=0$. So $p=q$ and $r=q+1$, and $3q+1=1008$ gives $q=\dfrac{1007}{3}$. Hence $p=q=\dfrac{1007}{3}$, $r=\dfrac{1010}{3}$, and
\[
\boxed{x=y=\dfrac{3}{1007},\qquad z=\dfrac{3}{1010}} .
\]
(The poster's value $x=\dfrac{3}{1007}$ is correct.) If zero values were allowed there would be many more solutions, for example $x=y=0$ with any $z$.
