Use inclusion-exclusion on the events ``A and S adjacent'' and ``M and N adjacent''. Treating a pair as a block, each event occurs in $2\cdot6!=1440$ arrangements, and both occur in $2\cdot2\cdot5!=480$. So the count is
\[7!-2\cdot1440+480=5040-2880+480=\boxed{2640}.\]
