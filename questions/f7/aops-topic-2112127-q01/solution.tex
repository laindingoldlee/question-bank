The weekly distances form a geometric sequence with ratio $1.1$, so in week $7$ he runs $1.1^6x$ miles. Since
\[1.1^2=1.21,\qquad 1.1^3=1.331,\qquad 1.1^6=1.331^2=1.771561,\]
we need $1.771561\,x\ge50$, that is,
\[x\ge\dfrac{50}{1.771561}\approx28.2237 .\]
So the least value is $x=\dfrac{50}{1.1^6}\approx\boxed{28.22}$ miles. (Since $28.22$ is rounded down, in practice he should run a little more, for example $28.23$ miles, in week $1$.)
