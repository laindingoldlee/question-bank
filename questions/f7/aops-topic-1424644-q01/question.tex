Identical cubes are painted so that each face is a solid colour and the six faces of each cube have six different colours. There are seven colours to choose from. Two cubes are indistinguishable if one can be rotated to look exactly like the other.
\begin{enumerate}
\item[(a)] Show that a cube has exactly $24$ rotational symmetries (including the identity).
\item[(b)] How many distinguishable cubes can be produced?
\end{enumerate}
