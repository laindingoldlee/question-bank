The digit keys of a calculator are arranged as follows:
\[\begin{array}{ccc}7&8&9\\4&5&6\\1&2&3\\0&&\end{array}\]
with the $0$ key directly below the $1$ key. A ten-digit number is typed using each of the ten keys exactly once, and each key pressed after the first is a knight's move away from the previous key (two places in one direction and one place in the perpendicular direction, as on a chessboard). How many different ten-digit numbers can be typed this way?
