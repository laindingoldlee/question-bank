\textbf{(b)} A subset $T$ that contains $k$ is determined by $T\setminus\{k\}$, which is an arbitrary subset of the $(n-1)$-element set $\{1,\ldots,n\}\setminus\{k\}$; conversely, adding $k$ to any subset of that set gives a subset containing $k$. This is a bijection, so the number of subsets containing $k$ equals the number of subsets of an $(n-1)$-element set, which is $2^{n-1}$ (each of the $n-1$ elements is either in or out). $\blacksquare$

\textbf{(a)} With $n=4$, there are $2^3=\boxed{8}$ subsets containing $3$: $\{3\}$, $\{1,3\}$, $\{2,3\}$, $\{3,4\}$, $\{1,2,3\}$, $\{1,3,4\}$, $\{2,3,4\}$, $\{1,2,3,4\}$.

(Equivalently, the subsets come in pairs $T$, $T\cup\{k\}$ or $T\setminus\{k\}$, exactly one of each pair containing $k$, so half of the $2^n$ subsets contain $k$.)
