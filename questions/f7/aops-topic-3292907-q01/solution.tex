Multiplication gives $b(10-a)=10a^2$, so $b=\dfrac{10a^2}{10-a}$. If $a\ge3$, this exceeds $9$ (already $\dfrac{90}{7}>9$ and it increases). For $a=1$, $b=\dfrac{10}{9}$ is not integral; for $a=2$, $b=5$. Therefore $\boxed{a+b=7}$.
