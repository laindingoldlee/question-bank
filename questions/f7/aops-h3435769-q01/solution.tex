Each of the four clothing categories lacks exactly one of the four colors, and the missing colors are all different. Fix the two colors to be used; there are $\binom42=6$ choices. The category lacking the first color is forced to use the second, and the category lacking the second is forced to use the first. The remaining two categories each offer both colors, and they must choose one of each in $2$ ways. Therefore the number of outfits is $\boxed{6\cdot2=12}$.
