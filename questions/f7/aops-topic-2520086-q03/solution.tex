If $x$ is odd, then $x^y+1$ is even and greater than $2$, so it is not prime. Hence $x=2$ and $z=2^y+1$.

If $y$ is an odd prime, then $2^y\equiv(-1)^y=-1\pmod3$, so $3\mid2^y+1$; and $2^y+1\ge9>3$, so $z$ is not prime. Hence $y=2$, and $z=2^2+1=5$ is prime.

The only solution is $\boxed{(x,y,z)=(2,2,5)}$.
