Rationalise:
\[
\sqrt{n+1}-\sqrt n=\dfrac{1}{\sqrt{n+1}+\sqrt n}.
\]
So the inequality is equivalent to $\sqrt{n+1}+\sqrt n>100$. The left side increases with $n$.

For $n=2499$: $\sqrt{2500}+\sqrt{2499}=50+\sqrt{2499}<100$, so it fails.

For $n=2500$: $\sqrt{2501}+\sqrt{2500}=\sqrt{2501}+50>100$, so it holds.

The least such $n$ is $\boxed{2500}$.
