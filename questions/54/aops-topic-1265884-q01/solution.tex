Let $\ell$ be the slant height (the height of a triangular face).

\begin{asy}
usepackage("amsmath");
size(4.5cm);
defaultpen(fontsize(10pt));
pair A=(0,0),B=(4,0),C=(5.3,1.2),D=(1.3,1.2),O=(A+C)/2,T=O+(0,3.5),M=(A+B)/2;
draw(A--B--C); draw(C--D--A,dashed); draw(A--T--B); draw(T--C); draw(T--D,dashed);
draw(T--O,dashed); draw(O--M,dashed); draw(T--M,red);
label("$x$",M,S); label("$h$",(T+O)/2,E); label("$\ell$",(T+M)/2,W);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

The apex is directly above the centre of the base, which is $\dfrac {x}{2}$ from the midpoint of each base edge, so by the Pythagorean theorem $\ell=\sqrt{h^2+\dfrac{x^2}{4}}=\dfrac{1}{2}\sqrt{4h^2+x^2}$. Each of the four faces has area $\dfrac{1}{2}x\ell$, so
\[\text{Surface area}=x^2+4\cdot\dfrac{1}{2}x\ell=\boxed{x^2+x\sqrt{x^2+4h^2}}.\]
