The $144$th place that Voldemort checks is some particular place (which one depends on his random order), and the red hairbrush is in any given place with probability $\dfrac{1}{165}$, independently of the order in which he checks. So the probability is
\[\boxed{\dfrac{1}{165}}.\]
Equivalently: list the $165$ places in the order he checks them. By symmetry, the red hairbrush is equally likely to be in each of the $165$ positions of this list, so it is in position $144$ with probability $\dfrac{1}{165}$. The other $11$ hairbrushes, and the number $144$, do not matter.
