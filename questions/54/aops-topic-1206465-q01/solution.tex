The equation is $y=-\dfrac{1}{2}x^2$, which has the form $y=a(x-h)^2+k$ with $a=-\dfrac{1}{2}$, $h=0$, $k=0$. So the vertex is $\boxed{(0,0)}$ (the highest point, since $a<0$).

\begin{asy}
usepackage("amsmath");
size(4cm);
defaultpen(fontsize(10pt));
guide g; for(real x=-3;x<=3.001;x+=0.1) g=g--(x,-x^2/2); draw((-3.5,0)--(3.5,0),gray); draw((0,-5)--(0,1),gray); draw(g,blue+linewidth(0.9)); dot((0,0)); label("$(0,0)$",(0,0),NE); label("$-2y=x^2$",(2.2,-2.4),E,blue);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}
