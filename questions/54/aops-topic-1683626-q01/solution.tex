The order of the winners does not matter, so we count $3$-element subsets of $6$ students:
\[
\binom63=\dfrac{6\cdot5\cdot4}{3!}=\boxed{20}.
\]
The value $120=6\cdot5\cdot4$ counts \emph{ordered} choices (first, second, third winner); each group of three is counted $3!=6$ times there.
