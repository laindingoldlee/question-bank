All truth values below are on January $1$, $2017$. Note that $S$ itself was said before $2017$, so it is one of the statements it talks about.

\textbf{(a)} Suppose $S$ is true. Then every statement made before $2017$ is false; in particular $S$ is false. This contradicts the assumption, so $S$ is not true.

\textbf{(b)} Let $T$ be another statement made before $2017$ that is true. Then not everything said before $2017$ is false, so what $S$ claims does not hold, and $S$ is false. This is consistent: $S$ being false only requires that \emph{some} statement made before $2017$ is true, and $T$ is one. So $S$ is a lie.

\textbf{(c)} Suppose every other statement made before $2017$ is false. By (a), $S$ is not true. If $S$ were false, then some statement made before $2017$ would be true; it cannot be one of the others, so it would have to be $S$ itself, i.e. $S$ would be true, a contradiction. So $S$ can be neither true nor false: a paradox, like the liar's ``this statement is false''.

\textbf{Conclusion.} $S$ is never true. It is a paradox only for a speaker every one of whose other statements before $2017$ becomes false. Any real speaker has surely also said something that stays true (for example, ``$2+2=4$''), so
\[\boxed{\text{the statement was a lie.}}\]
