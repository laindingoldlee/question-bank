Write the roots as $a,b,c$ with $ab=c$. Vieta gives $abc=c^2=100$, so $c=\pm10$. If $c=10$, write $p(x)=(x-10)(x^2-sx+10)$; integrality of the $x^2$ coefficient forces $s\in\mathbb Z$. The coefficient sum is $101+|s+10|+10|s+1|$. The triangle inequality gives $|s+10|\ge9-|s+1|$, so this is at least $110$, attained at $s=-1$. If $c=-10$, write $(x+10)(x^2-sx-10)$, giving $101+|10-s|+10|s+1|\ge112$. Thus the minimum is $\boxed{110}$, attained by $x^3-9x^2-100$.
