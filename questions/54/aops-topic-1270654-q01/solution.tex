The smallest angle is opposite the shortest side $4$. Its sine is $\dfrac{4}{8}=\dfrac{1}{2}$, so it is $\boxed{30^\circ}$: this is a $30$--$60$--$90$ triangle with sides in ratio $1:\sqrt3:2$.

\begin{asy}
usepackage("amsmath");
size(4.5cm);
defaultpen(fontsize(10pt));
path ra(pair P,pair u,pair v,real s=0.2){return P+s*unit(u)--P+s*unit(u)+s*unit(v)--P+s*unit(v);}
pair A=(0,0),B=(4*sqrt(3),0),C=(0,4); draw(A--B--C--cycle); draw(ra(A,(1,0),(0,1),0.4));
label("$4\sqrt3$",(B/2),S); label("$4$",(0,2),W); label("$8$",(B+C)/2,NE); draw(arc(B,1.2,150,180),red); label("$30^\circ$",B+(-1.6,0.3),red);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}
