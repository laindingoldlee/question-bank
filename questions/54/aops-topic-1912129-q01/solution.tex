Yes; \textbf{one} question is enough, and it is clearly needed (with no questions, both doors remain possible). Ask either cat:
\begin{center}
$Q^*$: ``If I asked you `Does door $A$ lead to heaven?', would you answer Meow?''
\end{center}
\textbf{Claim.} The answer to $Q^*$ is ``Meow'' exactly when door $A$ leads to heaven. Let $H$ be the statement ``door $A$ leads to heaven''. Check the four cases.
\begin{itemize}
\item Truthful cat, Meow $=$ yes. Asked about $H$, it would say Meow exactly when $H$ is true. So $Q^*$ is true exactly when $H$ is true, and it truthfully answers ``yes'' $=$ Meow exactly then.
\item Truthful cat, Meow $=$ no. Asked about $H$, it would say Meow exactly when $H$ is false. So $Q^*$ is true exactly when $H$ is false; it answers ``no'' $=$ Meow exactly when $Q^*$ is false, that is, when $H$ is true.
\item Lying cat, Meow $=$ yes. Asked about $H$, it would say Meow ($=$ yes) exactly when $H$ is false. So $Q^*$ is true exactly when $H$ is false; it lies, answering ``yes'' $=$ Meow exactly when $Q^*$ is false, that is, when $H$ is true.
\item Lying cat, Meow $=$ no. Asked about $H$, it would say Meow ($=$ no) exactly when $H$ is true. So $Q^*$ is true exactly when $H$ is true; it lies, answering ``no'' $=$ Meow exactly when $Q^*$ is true, that is, when $H$ is true.
\end{itemize}
In every case the answer is Meow if and only if $H$ is true. The question concerns a definite fact (what the cat would say), so it causes no paradox.

So: ask $Q^*$ to either cat; if the answer is Meow, take door $A$, and if it is Nya, take door $B$. The least number of questions is $\boxed{1}$.
