When they meet, $A$ has ridden $60-12=48$ km and $B$ has ridden $60+12=72$ km, in the same time. If $A$'s speed is $v$, then
\[
\dfrac{48}{v}=\dfrac{72}{v+4}\iff 48v+192=72v\iff v=8 .
\]
So $A$'s speed was $\boxed{\textbf{(b) }8\text{ km per hour}}$ (and $B$'s was $12$; both take $6$ hours).
