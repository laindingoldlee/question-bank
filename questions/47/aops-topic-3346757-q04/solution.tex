The first roll certainly uses box $1$. For each subsequent roll, the previous die is fair regardless of how its box was chosen, so the probability of choosing box $1$ is $\dfrac{1}{6}$. Linearity of expectation gives $1+23\cdot\dfrac{1}{6}=\boxed{\dfrac{29}{6}}$.
