\textbf{$7$ is representable:} $1-2+3+4+5+6+7-8-9=7$.

\textbf{$8$ is not.} Let $S$ be the sum of the numbers that get a minus sign. Then the value of the expression is
\[
(1+2+\cdots+9)-2S=45-2S,
\]
which is odd. So every representable number is odd, and $8$ is not representable. $\blacksquare$
