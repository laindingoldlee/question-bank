For $B=1$, $12\triangle1=12\cdot1\cdot1=12$. For $B\ge2$, $12\triangle B=12+12\triangle(B-1)$. So by induction $12\triangle B=12B$: it holds for $B=1$, and if $12\triangle(B-1)=12(B-1)$ then $12\triangle B=12+12(B-1)=12B$. Hence $12\triangle13=12\cdot13=\boxed{156}$.
