Existence: put $g(x)=\dfrac{f(x)-f(-x)}2$ and $h(x)=\dfrac{f(x)+f(-x)}2$. Then $g(-x)=-g(x)$, $h(-x)=h(x)$ and $g+h=f$.

Uniqueness: if $f=g_1+h_1=g_2+h_2$, then $g_1-g_2=h_2-h_1$ is both odd and even. A function $u$ that is both satisfies $u(x)=u(-x)=-u(x)$, so $u=0$. Hence $g_1=g_2$ and $h_1=h_2$. $\blacksquare$
