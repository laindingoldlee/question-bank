The sequence stops exactly when some term equals $1$. Suppose some term equals $1$, and let $a_i=1$ be the first such term.

If $i=1$, then $a_1=1$. Otherwise $a_1,\dots,a_{i-1}$ are all different from $1$, and for $k<i$ the rule can be reversed: $a_{k+1}=\dfrac{1}{a_k-1}$ is never $0$, and
\[a_k=1+\dfrac{1}{a_{k+1}}.\]
\textbf{Claim:} $\dfrac32\le a_k\le2$ for all $k<i$. For $k=i-1$, $a_{i-1}=1+\dfrac11=2$. If $\dfrac32\le a_{k+1}\le2$, then $\dfrac12\le\dfrac{1}{a_{k+1}}\le\dfrac23$, so $\dfrac32\le a_k\le\dfrac53\le2$. By induction downwards from $k=i-1$ to $k=1$ the claim holds.

So if the sequence ever stops, then either $a_1=1$ or $\dfrac32\le a_1\le2$. The only integers with this property are $1$ and $2$. In particular, if $a_1$ is an integer greater than $2$, no term equals $1$ and the sequence never stops. $\blacksquare$

The integers that make the sequence stop are $\boxed{a_1=1\text{ and }a_1=2}$: $a_1=1$ stops at once, and $a_1=2$ gives $a_2=1$. (For example, $a_1=3$ gives $3,\dfrac12,-2,-\dfrac13,-\dfrac34,-\dfrac47,\dots$)
