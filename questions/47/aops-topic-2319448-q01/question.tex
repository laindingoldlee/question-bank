A sequence of real numbers is defined by a first term $a_1$ and the rule
\[a_{i+1}=\dfrac{1}{a_i-1}\qquad\text{for all positive integers }i,\]
as long as $a_i\ne1$. Prove that if $a_1$ is an integer greater than $2$, then $a_i\ne1$ for every $i$, so that the sequence never stops. Which integers $a_1$ make the sequence stop?
