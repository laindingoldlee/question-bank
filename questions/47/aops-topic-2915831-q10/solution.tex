Set $u=\dfrac{1}{x},v=\dfrac{1}{y}$. Eliminating gives $22v=77$, hence $v=\dfrac{7}{2}$; then $7u=63$, so $u=9$. Therefore $x+y=\dfrac{1}{9}+\dfrac{2}{7}=\boxed{\dfrac{25}{63}}$.
