Write $a$ with three digits $a_1a_2a_3$, padding with leading zeros if needed. Since $999-a$ never needs a borrow, $b$ has the padded digits $(9-a_1)(9-a_2)(9-a_3)$. The map $d\mapsto9-d$ is a bijection on digits, so the padded strings of $a$ and $b$ have the same number of distinct digits. Leading zeros are not written, so we split into cases.

\textbf{Case 1: $100\le a\le899$.} Both $a$ and $b$ are genuine three-digit numbers, so we need the string $a_1a_2a_3$ (with $1\le a_1\le8$) to use at most two digits. For each of the $8$ choices of $a_1$, the string $a_2a_3$ uses only $a_1$ and at most one other digit $e$: there is $1$ string with no other digit, and for each of the $9$ choices of $e$ there are $2^2-1=3$ strings that use $e$. That gives $8(1+27)=224$ pairs.

\textbf{Case 2: $0\le a\le99$.} Then $a$ has at most two digits, so it is always fine, and $b=\overline{9(9-a_2)(9-a_3)}$ has at most two distinct digits exactly when $a_2=0$, or $a_3=0$, or $a_2=a_3$. There are $10+10-1=19$ pairs $(a_2,a_3)$ with a zero and $9$ more with $a_2=a_3\ne0$: $28$ values.

\textbf{Case 3: $900\le a\le999$.} This is Case 2 with $a$ and $b$ swapped: $28$ values.

The total is $224+28+28=\boxed{280}$.
