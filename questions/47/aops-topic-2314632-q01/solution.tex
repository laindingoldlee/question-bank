Let the first cauldron contain $a$ stems. Then the cauldrons contain $a,a+1,\dots,a+6$ stems, with total $7a+21$, and the $7$th contains $a+6$. So
\[7a+21=3(a+6)+3=3a+21,\]
which gives $4a=0$ and $a=\boxed{0}$. The first cauldron is empty, and the cauldrons contain $0,1,\dots,6$ stems (total $21=3\cdot6+3$). (If every cauldron had to contain at least one stem, there would be no solution.)
