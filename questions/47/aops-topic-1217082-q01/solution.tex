If $y>0$, dividing both sides of $x>y$ by the positive number $y$ keeps the direction of the inequality, so $\dfrac {x}{y}>\dfrac {y}{y}=1$. $\blacksquare$

If $y<0$, dividing reverses the inequality. For example $x=1$, $y=-1$ gives $x>y$ but $\dfrac {x}{y}=-1<1$. So the statement is false in general; it needs $y>0$.
