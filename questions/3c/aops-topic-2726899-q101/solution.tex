If all primes were $ p_1,\ldots,p_k $, the integer $ N=p_1\cdots p_k+1>1 $ would have a prime divisor. None of the listed primes divides $ N $, since each leaves remainder $ 1 $. This contradicts completeness of the list, proving infinitude.
