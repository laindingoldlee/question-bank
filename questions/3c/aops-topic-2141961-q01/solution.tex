We need a number $t$ with $F=C=t$, that is,
\[t=\dfrac{9}{5}t+32.\]
Subtracting $\dfrac{9}{5}t$ from both sides gives $-\dfrac{4}{5}t=32$, so $t=32\cdot\left(-\dfrac{5}{4}\right)=-40$.

So $\boxed{-40^\circ}$: $-40^\circ\text{C}$ is the same temperature as $-40^\circ\text{F}$. (Check: $\dfrac{9}{5}\cdot(-40)+32=-72+32=-40$.)
