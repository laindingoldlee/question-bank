\begin{enumerate}
\item[(a)] List all the positive divisors of $100$, and explain how to be sure that none is missing.
\item[(b)] In how many ways can you make $97$ cents using pennies ($1$ cent), nickels ($5$ cents), dimes ($10$ cents), quarters ($25$ cents) and half-dollars ($50$ cents)? (Coins of the same kind are identical, and you may use any number of each kind, including none.)
\end{enumerate}
