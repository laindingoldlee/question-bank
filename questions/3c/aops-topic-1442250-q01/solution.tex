Each candidate's number of votes is binomial: $P(k\text{ votes})=\dfrac{\binom5k}{32}$. The votes are independent, so
\[
P(\text{tie})=\sum_{k=0}^{5}\left(\dfrac{\binom5k}{32}\right)^2=\dfrac{1+25+100+100+25+1}{1024}=\dfrac{252}{1024}=\boxed{\dfrac{63}{256}}.
\]
(The numerator is $\sum\binom5k^2=\binom{10}{5}=252$.)
