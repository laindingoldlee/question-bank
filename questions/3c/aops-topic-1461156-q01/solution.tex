Rewrite the equation as $x^4=4x+1$ and add $2x^2+1$ to both sides:
\[x^4+2x^2+1=2x^2+4x+2,\qquad\text{i.e.}\qquad\left(x^2+1\right)^2=2(x+1)^2.\]
Hence $x^2+1=\sqrt2(x+1)$ or $x^2+1=-\sqrt2(x+1)$.
\begin{itemize}
\item $x^2-\sqrt2x+1-\sqrt2=0$ has discriminant $2-4\left(1-\sqrt2\right)=4\sqrt2-2>0$, so $x=\dfrac{\sqrt2\pm\sqrt{4\sqrt2-2}}{2}$.
\item $x^2+\sqrt2x+1+\sqrt2=0$ has discriminant $2-4\left(1+\sqrt2\right)=-\left(2+4\sqrt2\right)<0$, so $x=\dfrac{-\sqrt2\pm i\sqrt{2+4\sqrt2}}{2}$.
\end{itemize}
So the solutions are
\[\boxed{x=\dfrac{\sqrt2\pm\sqrt{4\sqrt2-2}}{2}\quad\text{and}\quad x=\dfrac{-\sqrt2\pm i\sqrt{2+4\sqrt2}}{2}},\]
the two real ones being approximately $1.6633$ and $-0.2490$.
