We need $(a+bi)^2=a^2-b^2+2abi=i$, so $a^2-b^2=0$ and $2ab=1$. The first gives $b=\pm a$; with $2ab=1>0$ we need $b=a$ and $2a^2=1$, so $a=b=\pm\dfrac{\sqrt2}{2}$. Thus
\[\sqrt{i}=\pm\left(\dfrac{\sqrt2}{2}+\dfrac{\sqrt2}{2}i\right)=\boxed{\pm\dfrac{\sqrt2}{2}(1+i)}.\]
(Check: $\left(\dfrac{1+i}{\sqrt2}\right)^2=\dfrac{1+2i-1}{2}=i$.)
