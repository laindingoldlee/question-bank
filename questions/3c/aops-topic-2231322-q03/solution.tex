The claim is false. Every one-digit number is a palindrome, but $2\times6=12$ is not. A counterexample with two-digit palindromes: $22\times55=1210$, which is not a palindrome.

(The product is sometimes a palindrome, for instance $11\times121=1331$ or $7\times88=616$, but not always.) So the statement is $\boxed{\text{false}}$.
