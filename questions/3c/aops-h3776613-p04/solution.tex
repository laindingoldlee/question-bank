The triangle inequality gives $|x-1|+|x-5|\ge4$, with equality for $1\le x\le5$. Adding $|x-3|$ shows the denominator is at least $4$, with equality only at $\boxed{x=3}$. The maximum value is $\dfrac{2025}{4}$.
\begin{asy}
texpreamble("\usepackage{amsmath,amssymb}");
size(240);
defaultpen(fontsize(9pt));
import graph;size(300,150,IgnoreAspect);real f(real x){return abs(x-1)+abs(x-3)+abs(x-5);}draw(graph(f,-1,7),blue);dot((3,4),red);label("$(3,4)$",(3,4),S);label("$|x-1|+|x-3|+|x-5|$",(3,10),N);
\end{asy}
