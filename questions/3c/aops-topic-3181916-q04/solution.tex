The number of sides is $\dfrac{360}{4}=90$. One third is $\boxed{30}$.
\begin{asy}
usepackage("amsmath");
size(7cm);
path p;for(int k=0;k<6;++k)p=p--dir(60*k);draw(p--cycle);draw(dir(0)--(dir(0)+.5*(dir(0)-dir(300))),dashed);label("Regular polygon (schematic)",(0,-1.5));
\end{asy}
