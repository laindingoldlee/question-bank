Call a nonnegative rational number \emph{semi-dyadic} if it can be expressed as \[\dfrac{a}{2^b - 2^c}\]where $a$, $b$, and $c$ are nonnegative integers, and $b > c.$ Let $N$ be the number of distinct \emph{semi-dyadic} numbers where $0 \leq b, c \leq 10$ that are there in the range $[0, 1]$. Find the remainder when $N$ is divided by $1000.$
