Subtracting the equations: $342a+48b+6c=978$, i.e. $57a+8b+c=163$. Since each variable is at least $1$, $b+c\le 9-a$.

$a=1$: $8b+c=106$ but $8b+c\le 8\cdot7+1=57$ when $b+c\le8$. Impossible.
$a=2$: $8b+c=49$ with $b+c\le7$: $b=6,c=1$ (then $b=5$ needs $c=9$). So $d=10-9=1$.
$a\ge3$: $57a>163-9$, impossible.

So $(a,b,c,d)=(2,6,1,1)$ (indeed $988=2611_7$), and the answer is $\boxed{2611}$.
