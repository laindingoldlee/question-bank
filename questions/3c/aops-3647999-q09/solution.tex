For a fixed integer $a$, the possible distinct positive pairs summing to it are disjoint and number $\lfloor\dfrac{(a-1)}{2}\rfloor$. A uniform random subset includes each element independently with probability one half. Thus $a$ is an atom with probability $(\dfrac{1}{2})(\dfrac{3}{4})^{\lfloor\dfrac{(a-1)}{2}\rfloor}$: include $a$, and do not include both members of any pair. By linearity, $N=\sum_{j=0}^{1011}(\dfrac{3}{4})^j=4(1-(\dfrac{3}{4})^{1012})$. This is just below four and above 3.5, so the nearest integer is $\boxed4$.
