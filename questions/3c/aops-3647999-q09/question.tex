For a set $S$, an element $a \in S$ is called an atom if there does not exist distinct,elements $b, c \in S$ such that $a = b+c$. Let $U = \{1, 2,..., 2024\}$. A subset $A$ of $U$ is chosen uniformly at random from all of the subsets of $U$ (including the empty set and the full set). Suppose $N$ is the expected number of atoms in $A$. What is the closest integer to $N$?
