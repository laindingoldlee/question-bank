Choose $a+c+1$ elements from an ordered set of $a+b+1$ elements and classify by the $(a+1)$st selected element. If it has position $a+k+1$, there are $\binom{a+k}a$ choices before it and $\binom{b-k}c$ after it. The allowable positions correspond exactly to $0\le k\le b-c$. Every subset is counted once, so the sum is $\boxed{\binom{a+b+1}{a+c+1}}$.
