\textbf{Odd inputs.} If $x>1$ is odd, then $x=2n+1$ with $n\ge1$ and $f(x)=2f(n)$ is even. And $f(1)=1$ is odd.

\textbf{Even inputs.} $f(2n)=3f(n)+2$ has the same parity as $3f(n)$, which has the same parity as $f(n)$. So halving an even input does not change the parity of $f$.

Now write $x=2^k m$ with $m$ odd. Halving $k$ times,
\[f(x)\equiv f(2^{k-1}m)\equiv\cdots\equiv f(m)\pmod2 .\]
So $f(x)$ is odd exactly when $f(m)$ is odd, that is, when $m=1$; in other words, exactly when $x$ is a power of $2$. (This is what the quoted solution means by ``if $x$ has an odd factor other than $1$, then $f(x)$ is even''.) The powers of $2$ up to $100$ are
\[1,\ 2,\ 4,\ 8,\ 16,\ 32,\ 64,\]
so the answer is $\boxed{7}$.
