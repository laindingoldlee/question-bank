\textbf{(a)} If $d\mid m$, say $m=dq$, then $a^m=\left(a^d\right)^q\equiv1^q=1\pmod p$.

Conversely, suppose $a^m\equiv1$. Divide: $m=qd+r$ with $0\le r<d$. Then
\[1\equiv a^m=\left(a^d\right)^q a^r\equiv a^r\pmod p .\]
If $r>0$, this contradicts the minimality of $d$. So $r=0$ and $d\mid m$. $\blacksquare$

\textbf{(b)} By Fermat's little theorem $a^{p-1}\equiv1\pmod p$, so by (a) $d\mid p-1=\varphi(p)$.

Modulo $13$ the order of $2$ divides $12$, so it is one of $1,2,3,4,6,12$: $2^1=2$, $2^2=4$, $2^3=8$, $2^4=16\equiv3$, $2^6=64\equiv12\equiv-1$, so none of $1,2,3,4,6$ works and the order is $\boxed{12}$. Modulo $7$ the order divides $6$: $2^2=4$, $2^3=8\equiv1$, so the order is $\boxed{3}$ (a proper divisor of $6$).
