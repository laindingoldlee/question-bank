At $ n=1 $, the recurrence reads $ 1!=1\cdot0!$. Since $ 1!=1 $, it forces $\boxed{0!=1}$. Combinatorially, there is exactly one ordering of an empty collection: the empty ordering. The product definition for 0 factors is an empty product, whose value is 1; it is not a product beginning with a factor 0.
