By Bayes' theorem,
\[P(\text{biased}\mid20\text{ heads})=\dfrac{\dfrac1{1000}\cdot0.8^{20}}{\dfrac1{1000}\cdot0.8^{20}+\dfrac{999}{1000}\cdot0.5^{20}}=\dfrac{1}{1+\dfrac{999}{1.6^{20}}}.\]
Now $1.6^5=10.48576$, so $1.6^{20}=10.48576^4\approx12089$, and the probability is
\[\dfrac{1}{1+\dfrac{999}{12089}}\approx\dfrac{1}{1.0826}\approx0.924.\]
So the answer is $\boxed{\textbf{(E) }90\%}$ (about $92\%$): twenty heads in a row are about $12000$ times as likely with the biased coin, which outweighs its prior odds of $1:999$.
