The expression equals $\dfrac{x^2+x+y^2+y}{xy}$, so $xy\mid x^2+y^2+x+y$. Let $d=\gcd(x,y)$. Then $d^2\mid xy$, so $d^2\mid x^2+y^2+x+y$. Since $d^2\mid x^2$ and $d^2\mid y^2$, we get $d^2\mid x+y$, hence $d^2\le x+y$ and $d\le\sqrt{x+y}$. As $d$ is an integer, $d\le\left\lfloor\sqrt{x+y}\right\rfloor$. $\blacksquare$
