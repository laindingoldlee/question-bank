$42=2\cdot3\cdot7$, and these primes are distinct, so it suffices to show each divides $n^7-n$. By Fermat's little theorem $n^7\equiv n\pmod7$. Mod $2$: $n^7$ and $n$ have the same parity. Mod $3$: $n^3\equiv n$, so $n^7=n^3\cdot n^3\cdot n\equiv n\cdot n\cdot n=n^3\equiv n$. $\blacksquare$
