$D(9)=99$, and $8+99=107$ has $3$ digits, so $D(107)=107107$ has $6$ digits. From then on each value is $D(m)$ for a number $m$ starting with the digit $1$, so it also starts with $1$, and adding $k\le7$ cannot change the number of digits (that would need all its digits to be $9$s). Each further application of $D$ doubles the digit count. The applications for $7,6,5,4,3,2,1$ take the count $6\to12\to24\to48\to96\to192\to384\to768$. The final number has $\boxed{768}$ digits.
