Divisibility by both is equivalent to divisibility by 42. Check the 161 multiples $42k$, $1\le k\le161$, for both digits. The qualifying numbers are $672,756,1176,1764,3276,4746,5376,5670,5796,6174,6678,6720,6762$, giving $\boxed{13}$. This finite check is exhaustive because $42\cdot162=6804$ exceeds the bound.
