In base $b$,
\[2021_b-221_b=(2b^3+2b+1)-(2b^2+2b+1)=2b^3-2b^2=2b^2(b-1).\]
This is divisible by $3$ exactly when $3\mid b$ or $3\mid b-1$. So it is not divisible by $3$ exactly when $\boxed{b\equiv2\pmod3}$, i.e. $b=5,8,11,\dots$ (For example, $b=8$ gives $2\cdot64\cdot7=896$, not a multiple of $3$.)
