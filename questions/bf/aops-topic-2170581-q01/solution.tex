One set of solutions (there are others):
\begin{align*}
5+5\div5&=5+1=6,\\
6+6-6&=6\qquad(\text{or } 6\times6\div6=6),\\
7-7\div7&=7-1=6,\\
8-\sqrt{\sqrt{8+8}}&=8-\sqrt{4}=8-2=6,\\
\sqrt9\times\sqrt9-\sqrt9&=3\cdot3-3=6\qquad(\text{or } 9-9\div\sqrt9=6).
\end{align*}
The only tricky one is $8$: the key is that $8+8=16$ and taking the square root twice gives $\sqrt{\sqrt{16}}=2$.
