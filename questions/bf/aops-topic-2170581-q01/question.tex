Using only the symbols $+$, $-$, $\times$, $\div$, $\sqrt{\ }$ and parentheses (as many or as few as you like), make each equation true by inserting symbols around and between the three equal digits. The first two are done for you:
\[3\times3-3=6,\qquad \sqrt{4\times4}+\sqrt4=6 .\]
Complete
\[5\ \ 5\ \ 5=6,\qquad 6\ \ 6\ \ 6=6,\qquad 7\ \ 7\ \ 7=6,\qquad 8\ \ 8\ \ 8=6,\qquad 9\ \ 9\ \ 9=6 .\]
