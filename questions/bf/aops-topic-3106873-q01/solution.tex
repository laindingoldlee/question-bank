Write $ k^2=k(k-1)+k $. The identities $ k(k-1)\binom nk=n(n-1)\binom{n-2}{k-2}$ and $ k\binom nk=n\binom{n-1}{k-1}$ give a sum of $ n(n-1)2^{n-2}+n2^{n-1}=n(n+1)2^{n-2}$. Each binomial sum equals the number of subsets of a set of the indicated size.
