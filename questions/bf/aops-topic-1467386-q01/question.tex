Bucket $A$ contains $5$ litres of milk and bucket $B$ contains $5$ litres of water; the buckets can hold any amount. You have a $5$-litre beaker with measurement marks, and liquid can be moved only with the beaker: in each step you pour some liquid from a bucket into the beaker, or from the beaker into a bucket (the beaker may already contain liquid). After every pour the receiving container is stirred, so its contents are uniformly mixed. At no time may either bucket be empty. Is it possible to reach a state in which each bucket contains as much milk as water?
