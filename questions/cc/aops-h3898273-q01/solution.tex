Write $M=3\cdot10^k+a$, where $0\le a<10^k$. The moved number is $10a+3$, so $4(10a+3)=3\cdot10^k+a$, or $13a=10^k-4$. Powers of $10$ modulo $13$ for $k=0,1,2,3,4,5$ are $1,10,9,12,3,4$, so the first admissible $k$ is $5$. Then $a=7692$, written as five digits $07692$, and $M=307692$. Indeed its moved number is $76923=\dfrac{M}{4}$. The digit sum is $\boxed{27}$.
