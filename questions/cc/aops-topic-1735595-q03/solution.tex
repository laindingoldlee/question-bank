If $k=0$, then $f(x)=3x$ has the single zero $x=0$, so $k=0$ counts. If $k\ne0$, $f$ is quadratic and has exactly one distinct zero when its discriminant vanishes: $9-8k^2=0$, so $k=\pm\dfrac{3}{2\sqrt2}=\pm\dfrac{3\sqrt2}{4}$. The values are $0$ and $\pm\dfrac{3\sqrt2}{4}$, and their sum is $\boxed{0}$.
