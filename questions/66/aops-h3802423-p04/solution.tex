Each move toggles six cells, so the parity of the total number of black cells is unchanged. The target has $9N$ black cells. Hence odd $N$, in particular $2019$, is impossible.
For even $N$, pair the boards. For each pair, perform three moves choosing numbers $1,5,9$, always using the same board for columns and the other for rows. Each of the first board's three columns and each of the second board's three rows is toggled exactly once, making both boards black. Thus $\boxed{\text{(a) yes; (b) no}}$.
