Measure the position of a hand as a fraction of a full turn, starting from $12$. At time $t$ hours after midnight ($0\le t<12$) the hour hand is at $h=\dfrac{t}{12}$, and the minute hand is at the fractional part of $t=12h$. So a pair of positions $(h,m)$ is a real time exactly when $m\equiv12h\pmod1$, and each such pair is a different time.

The time cannot be read exactly when the swapped pair (hour hand at $m$, minute hand at $h$) is also a real time and is a different time. The swap is a real time when $h\equiv12m\equiv144h\pmod1$, i.e.\ $143h$ is an integer:
\[
h=\dfrac{j}{143},\qquad j=0,1,\dots,142,
\]
which gives $143$ moments. The swapped time is the same time exactly when the hands coincide, $m=h$, i.e.\ $11h$ is an integer: $h=\dfrac{i}{11}$ for $i=0,\dots,10$. These $11$ moments are among the $143$ ($j=13i$). So the number of ambiguous moments is
\[
143-11=\boxed{132}.
\]
