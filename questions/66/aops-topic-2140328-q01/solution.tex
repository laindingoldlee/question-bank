Solve for $a$: $a(b+1)=7b-7$, so
\[a=\dfrac{7(b-1)}{b+1}=7-\dfrac{14}{b+1}.\]
For $a$ to be an integer, $b+1$ must divide $14$; since $b\ge1$, $b+1\in\{2,7,14\}$. The value $b+1=2$ gives $a=0$, which is not positive. So $b+1=7$ (then $a=5$) or $b+1=14$ (then $a=6$). Check: $6\cdot13+6-91+7=0$. The largest possible value of $b$ is $\boxed{13}$.
