Since $3x+4y+xy>0$, divisibility requires $3x+4y+xy\ge4xy+4$, i.e. $(3x-4)(y-1)\le0$. For positive integers this forces $y=1$ or $x=1$.

If $y=1$: $4x+4$ divides $4x+4$, which always holds, giving $100$ pairs. If $x=1$ and $y\ge2$: we need $4y+4\mid5y+3$ with $4y+4<5y+3<2(4y+4)$, which is impossible. The answer is $\boxed{100}$.
