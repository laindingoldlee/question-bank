$f(x)=x\iff ax+b=x\iff(1-a)x=b\iff x=\dfrac{b}{1-a}$, which is defined because $a\ne1$. So the unique fixed point is $x=\dfrac b{1-a}$. (For $a=1$ there is no fixed point if $b\ne0$, and every point is fixed if $b=0$.) $\blacksquare$
