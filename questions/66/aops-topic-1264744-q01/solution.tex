Only the relative arrangement matters: relabel positions so that the first row reads $1,2,\dots,8$. Then the second row is a uniformly random permutation of $1,\dots,8$, and we want the probability that it has at least one fixed point.

The number of permutations with no fixed point (derangements) is
\[D_8=8!\left(1-\dfrac{1}{1!}+\dfrac{1}{2!}-\cdots+\dfrac{1}{8!}\right)=14833.\]
Hence the probability is
\[1-\dfrac{14833}{40320}=\boxed{\dfrac{25487}{40320}}\approx0.632.\]
