There are $5$ yellow pegs, $4$ red pegs, $3$ green pegs, $2$ blue pegs and $1$ orange peg to be placed on a triangular peg board with $15$ holes. The holes form $5$ horizontal rows containing $1,2,3,4,5$ holes from top to bottom, lined up on the left so that they also form $5$ vertical columns containing $5,4,3,2,1$ holes from left to right:

\begin{asy}
usepackage("amsmath");
size(3cm);
defaultpen(fontsize(10pt));
for(int r=1;r<=5;++r) for(int c=1;c<=r;++c) draw(circle((c,-r),0.22));
draw((0.5,0.2)--(0.5,-5.6)--(6.3,-5.6)--cycle,gray);
\end{asy}

\begin{enumerate}
\item[(a)] In how many ways can the pegs be placed so that no (horizontal) row and no (vertical) column contains two pegs of the same colour? (Pegs of the same colour are identical.)
\item[(b)] How many placements would there be if all $15$ pegs were distinguishable (for example, numbered)? Explain why (a) is the intended reading.
\end{enumerate}
