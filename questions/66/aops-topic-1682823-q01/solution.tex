From Day $1$ to Day $14$ there are $13$ daily increases, each multiplying the number by $1.3$. So the number on Day $14$ is
\[
4\cdot1.3^{13}\approx4\cdot30.2875=121.15\ldots,
\]
which rounds to $\boxed{121}$ patients.
