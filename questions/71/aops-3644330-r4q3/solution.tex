Let the numbers of blue-red, blue-green and red-green pairs be $a,b,c$. The colour totals give $a+b=2$, $a+c=4$, $b+c=4$, hence $(a,b,c)=(1,1,3)$. There are $\dfrac{5!}{(1!1!3!)}=\boxed{20}$ chronological orders of these five pair types. Thus one new order per day takes 20 days. If order is ignored, there is only one grouping by colour types.
