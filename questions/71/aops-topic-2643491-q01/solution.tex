Jaber's notation is base $3$. So
\[12201_3=81+2\cdot27+2\cdot9+0\cdot3+1=154,\qquad212_3=2\cdot9+3+2=23,\]
and the difference is $154-23=\boxed{131}$. In base $3$: $131=81+27+2\cdot9+3+2$, i.e. $\boxed{11212}$ in Jaber's notation.
