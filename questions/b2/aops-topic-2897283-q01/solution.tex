Label the grid $\begin{smallmatrix}a&b&c\\d&e&f\\g&h&i\end{smallmatrix}$. Equal top sub-squares give $a+b+d+e=b+c+e+f$, so $a+d=c+f$. Equal bottom sub-squares give $d+g=f+i$. Subtracting, $a-g=c-i$, so $a+i=c+g$. Adding $e$: $a+e+i=c+e+g$. $\blacksquare$
