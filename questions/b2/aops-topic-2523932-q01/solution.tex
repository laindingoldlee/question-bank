$\left(x^2+1\right)^4$ has degree $8$ and $\left(x^3+1\right)^3$ has degree $9$, so $p$ has degree $17$. If $p=dq+r$ with $\deg d=2$ and $\deg r<2$, then $\deg(dq)=17$, so $\deg q=17-2=\boxed{15}$.
