If $N=s^3$ is a three-digit number, then $100\le s^3\le999$, so $5\le s\le9$. Check the five cubes:
\[
\begin{array}{c|ccccc}
s&5&6&7&8&9\\\hline
s^3&125&216&343&512&729\\
\text{digit sum}&8&9&10&8&18
\end{array}
\]
Only $512$ has digit sum $s$: $5+1+2=8$ and $8^3=512$. So the only such number is $\boxed{512}$.
