Each measurable weight is the total of a nonempty set of the masses. The $2^3-1=7$ nonempty sets give
\[
2,\ 5,\ 10,\ 2+5=7,\ 2+10=12,\ 5+10=15,\ 2+5+10=17,
\]
which are all different. So $\boxed{7}$ different weights can be measured.
