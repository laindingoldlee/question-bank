\textbf{Increasing.} Any $3$ distinct digits can be written in increasing order in exactly one way. The first digit is then the smallest, and it must be nonzero, so the digits come from $\{1,\ldots,9\}$: $\dbinom93=84$ numbers.

\textbf{Decreasing.} Any $3$ distinct digits from $\{0,1,\ldots,9\}$ written in decreasing order give a valid number (the first digit is the largest, so it is not $0$): $\dbinom{10}3=120$ numbers.

No number is both, so the total is $84+120=\boxed{204}$.
