Order them as $a\le b\le c$, so $a\le17$. If $a=2$, parity forces $b=2$ and $c=47$. Otherwise all are odd. The complete pairs $(b,c)$ for each possible smallest prime are: $a=3$: $(5,43),(7,41),(11,37),(17,31),(19,29)$; $a=5$: $(5,41),(17,29),(23,23)$; $a=7$: $(7,37),(13,31)$; $a=11$: $(11,29),(17,23)$; $a=13$: $(19,19)$; $a=17$: $(17,17)$. These exhaust primes $b$ between $a$ and $\dfrac{51-a}{2}$. The total is $1+5+3+2+2+1+1=\boxed{15}$.
