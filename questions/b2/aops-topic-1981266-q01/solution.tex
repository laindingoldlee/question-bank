The right side is at most $9+2\cdot9+3\cdot9+4\cdot9=90$, while $4^4=256$, so $a\le3$.
\begin{itemize}
\item $a=1$: $2b+3c+4d=0$, so $b=c=d=0$: $1000$.
\item $a=2$: $2b+3c+4d=2$, so $b=1$, $c=d=0$: $2100$.
\item $a=3$: $2b+3c+4d=24$. Then $3c$ is even, so $c$ is even, $c\in\{0,2,4,6,8\}$, and $b+2d=12-\dfrac{3c}{2}$:
\begin{itemize}
\item $c=0$: $b+2d=12$, $(b,d)=(0,6),(2,5),(4,4),(6,3),(8,2)$: $3006,3205,3404,3603,3802$;
\item $c=2$: $b+2d=9$, $(b,d)=(1,4),(3,3),(5,2),(7,1),(9,0)$: $3124,3323,3522,3721,3920$;
\item $c=4$: $b+2d=6$, $(b,d)=(0,3),(2,2),(4,1),(6,0)$: $3043,3242,3441,3640$;
\item $c=6$: $b+2d=3$, $(b,d)=(1,1),(3,0)$: $3161,3360$;
\item $c=8$: $b+2d=0$: $3080$.
\end{itemize}
\end{itemize}
In total $2+5+5+4+2+1=\boxed{19}$ numbers: $1000$, $2100$, $3006$, $3043$, $3080$, $3124$, $3161$, $3205$, $3242$, $3323$, $3360$, $3404$, $3441$, $3522$, $3603$, $3640$, $3721$, $3802$, $3920$.
