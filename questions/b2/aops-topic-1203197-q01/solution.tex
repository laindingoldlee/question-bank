Multiply the equations:
\[\left(x+\dfrac{1}{y}\right)\left(y+\dfrac{1}{x}\right)=xy+2+\dfrac{1}{xy}=\dfrac{49}{10}.\]
With $t=xy$: $t+\dfrac{1}{t}=\dfrac{29}{10}$, so $10t^2-29t+10=0$ and $t=\dfrac{5}{2}$ or $\dfrac{2}{5}$. Both occur: $t=\dfrac{5}{2}$ with $x=\dfrac{5}{2}$, $y=1$, and $t=\dfrac{2}{5}$ with $x=1$, $y=\dfrac{2}{5}$. So the maximum is $\boxed{\dfrac{5}{2}}$. The value $3.9$ came from adding the equations, which does not determine $xy$; no solution has $xy=3.9$.
