The right side must be an integer, so $P(\lfloor x\rfloor)$ is a perfect square. For $\lfloor x\rfloor=5,6,\dots,14$, $P$ takes the values $1,9,19,31,45,61,79,99,121,145$, so only $\lfloor x\rfloor=5,6,13$ can work (with square roots $1,3,11$).
\begin{itemize}
\item $5\le x<6$: we need $P(x)<4$, i.e. $x<\dfrac{3+\sqrt{61}}{2}$; this is an interval of length $\dfrac{\sqrt{61}-7}{2}$.
\item $6\le x<7$: we need $P(x)<16$, i.e. $x<\dfrac{3+\sqrt{109}}{2}$; length $\dfrac{\sqrt{109}-9}{2}$.
\item $13\le x<14$: we need $P(x)<144$, i.e. $x<\dfrac{3+\sqrt{621}}{2}$; length $\dfrac{\sqrt{621}-23}{2}$.
\end{itemize}
(On each interval $P$ is increasing, so the lower bound on $\left\lfloor\sqrt{P(x)}\right\rfloor$ holds automatically.) Dividing the total length by $10$, the probability is $\dfrac{\sqrt{61}+\sqrt{109}+\sqrt{621}-39}{20}$, and the answer is $61+109+621+39+20=\boxed{850}$.
