The division is determined by what the first child gets: $a$ apples, $p$ pears and $g$ pomegranates with
\[
a+p+g=9,\qquad 0\le a,p,g\le6 ;
\]
the second child gets the rest, which is automatically $9$ fruits with at most $6$ of each kind. Without the upper bounds, stars and bars gives $\dbinom{11}{2}=55$ solutions. If, say, $a\ge7$, write $a=7+a'$: then $a'+p+g=2$, which has $\dbinom{4}{2}=6$ solutions; the same for $p\ge7$ and $g\ge7$, and two variables cannot both be at least $7$. So the number of ways is
\[
55-3\cdot6=\boxed{37}.
\]
