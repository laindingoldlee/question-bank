Use Burnside's lemma over the $24$ rotations of the cube, counting colourings in which all four colours appear.

Identity: $4^6-4\cdot3^6+6\cdot2^6-4\cdot1^6=4096-2916+384-4=1560$.

A rotation fixes a colouring only if the colouring is constant on each cycle of faces, so it needs at least $4$ cycles. Rotations by $90^\circ$ about a face axis ($6$) have cycle type $1,1,4$; by $120^\circ$ about a vertex axis ($8$) type $3,3$; by $180^\circ$ about an edge axis ($6$) type $2,2,2$: all have fewer than $4$ cycles and fix nothing. Rotations by $180^\circ$ about a face axis ($3$) have type $1,1,2,2$: the four cycles get the four colours in $4!=24$ ways.

Number of cubes $=\dfrac{1560+3\cdot24}{24}=\dfrac{1632}{24}=\boxed{68}$, matching an exhaustive computer check.
