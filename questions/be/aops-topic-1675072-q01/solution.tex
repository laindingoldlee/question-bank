The condition $x+y>xy$ is equivalent to $xy-x-y+1<1$, that is,
\[
(x-1)(y-1)<1 .
\]
For $x,y\in(0,2]$ we have $x-1,\ y-1\in(-1,1]$, so $|x-1|\le1$, $|y-1|\le1$ and $(x-1)(y-1)\le|x-1|\,|y-1|\le1$. Equality $(x-1)(y-1)=1$ would need $|x-1|=|y-1|=1$ with equal signs; since $x-1=-1$ is impossible ($x>0$), the only such point is $x=y=2$, where $x+y=4=xy$.

So the condition fails only at the single point $(2,2)$ of the square $(0,2]\times(0,2]$, a set of area $0$. The probability is $\boxed{1}$.

In the figure the curve $x+y=xy$, i.e.\ $y=\dfrac{x}{x-1}$ (dashed), touches the square $(0,2]^2$ only at the corner $(2,2)$, so the whole square except that corner satisfies $x+y>xy$.
