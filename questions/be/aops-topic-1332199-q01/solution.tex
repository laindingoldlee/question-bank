Let $q=ab+bc+ca$ and $r=abc$. Since $a+b+c=1$,
\[
a^3+b^3+c^3=(a+b+c)^3-3(a+b+c)(ab+bc+ca)+3abc=1-3q+3r,
\]
so the inequality reads $1-3q+9r\ge\dfrac{1}{4}$, that is, $4q-12r\le1$.

Schur's inequality $\sum a(a-b)(a-c)\ge0$ can be written as $(a+b+c)^3-4(a+b+c)(ab+bc+ca)+9abc\ge0$, i.e. $1-4q+9r\ge0$, so $4q\le1+9r$. Therefore
\[
4q-12r\le1+9r-12r=1-3r\le1,
\]
as $r\ge0$. Equality holds when $r=0$ and Schur is tight, e.g. $(a,b,c)=\left(\dfrac{1}{2},\dfrac{1}{2},0\right)$. $\blacksquare$
