The rest of the first row is B, C in some order ($2$ ways), and the rest of the first column is B, C in some order ($2$ ways). Say the first row is A, $x$, $y$ and the first column is A, $u$, $w$. These choices determine the rest. The centre differs from $u$ (its row) and $x$ (its column). If $u\ne x$, the centre must be A. If $u=x$, the centre is A or $y$; but if it were A, the last square of row $2$ would be $y$, the same as the top of column $3$; so the centre is $y$. Once the centre is known, each remaining square is the only letter missing from its row, and the result is a valid grid in all four cases. For example, with first row A B C and first column A B C the grid is
\[\begin{array}{ccc}A&B&C\\B&C&A\\C&A&B\end{array}\]
So there are $2\cdot2=\boxed{4}$ arrangements.
