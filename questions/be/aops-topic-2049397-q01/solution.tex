Writing a $0$ at the end of the decimal representation of $n$ shifts every digit one place to the left, so the new number is $10n$. The difference is
\[10n-n=9n,\]
which is a multiple of $9$ (in fact it is exactly $9$ times the original number). $\blacksquare$

For example, $20\to200$ and $200-20=180=9\cdot20$. (The poster's example "$20-2=18$" is not this computation.)
