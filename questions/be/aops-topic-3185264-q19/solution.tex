If a perfect power $n^k$ is one more than a prime, then $n^k-1=(n-1)(1+n+\cdots+n^{k-1})$ is prime. Thus $n=2$. Since $2^k<1000$, we need $2\le k\le9$; if $k$ is composite then $2^k-1$ factors, so only $k=2,3,5,7$ need checking. They yield the primes $3,7,31,127$. The desired powers are $4,8,32,128$, whose sum is $\boxed{172}$.
