The numbers have the same sign. Set $p=xy\ge1$.
If both are positive, AM--GM gives $x^3+y^3\ge2p^{\dfrac{3}{2}}\ge2p$. Consequently $5\ge5p\ge5$, forcing $p=1$ and equality in AM--GM. Thus $x=y=1$.
If both are negative, apply AM--GM to $-x,-y$ to get $x^3+y^3\le-2p^{\dfrac{3}{2}}$. Writing $q=\sqrt p\ge1$,
\[
3p-2p^{\dfrac{3}{2}}=3q^2-2q^3
=1-(q-1)^2(2q+1)\le1,
\]
contradicting the required value $5$. Hence the only solution is $\boxed{(1,1)}$.
