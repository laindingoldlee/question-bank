The set has fewer than $4$ elements exactly when two of the four numbers coincide. Check the six pairs:
\begin{itemize}
\item $n-2=n+2$: never.
\item $n-2=2n$: $n=-2$, giving $\{-4,0,-4,-1\}=\{-4,0,-1\}$.
\item $n-2=\dfrac{n}{2}$: $n=4$, giving $\{2,6,8,2\}=\{2,6,8\}$.
\item $n+2=2n$: $n=2$, giving $\{0,4,4,1\}=\{0,4,1\}$.
\item $n+2=\dfrac{n}{2}$: $n=-4$, giving $\{-6,-2,-8,-2\}=\{-6,-2,-8\}$.
\item $2n=\dfrac{n}{2}$: $n=0$, giving $\{-2,2,0,0\}=\{-2,2,0\}$.
\end{itemize}
The five values of $n$ are different, and in each case exactly one coincidence occurs, so the set has exactly $3$ elements. The answer is $\boxed{5}$.
