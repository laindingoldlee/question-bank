For a positive integer $N$, the number of non-squares among $1,2,\dots,N$ is $N-\left\lfloor\sqrt N\right\rfloor$, since exactly $\left\lfloor\sqrt N\right\rfloor$ of them are squares. This count increases by $1$ exactly at each non-square.

Try $N=2066$: $45^2=2025\le2066<2116=46^2$, so $\left\lfloor\sqrt{2066}\right\rfloor=45$ and the count is $2066-45=2021$. Since $2066$ is not a square, it is the $2021$st non-square. The answer is $\boxed{2066}$.

(How to find it: the $2021$st non-square $N$ satisfies $N\approx2021+\sqrt N\approx2021+45$.)
