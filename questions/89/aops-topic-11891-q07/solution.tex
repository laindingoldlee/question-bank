Work modulo $2$. Squaring repeatedly, $(1+x)^{2^m}\equiv1+x^{2^m}$, because every middle coefficient of $(1+y)^2=1+2y+y^2$ is even.
\begin{itemize}
\item If $n=2^m$, then $(1+x)^n\equiv1+x^n$, so every inner entry $\dbinom{n}{k}$, $0<k<n$, is even.
\item If $n$ is not a power of $2$, write $n=2^m+r$ with $2^m$ the largest power of $2$ below $n$, so $0<r<2^m$. Then
\[
(1+x)^n=(1+x)^{2^m}(1+x)^r\equiv(1+x^{2^m})(1+x)^r .
\]
Since $(1+x)^r$ has degree $r<2^m$, the coefficient of $x^{2^m}$ on the right is $1$. So $\dbinom{n}{2^m}$ is odd, and it is an inner entry because $0<2^m<n$.
\end{itemize}
So the rows with the property are the powers of $2$: among rows $2$ to $19$ these are rows $2,4,8,16$. The answer is $\boxed{4}$.
