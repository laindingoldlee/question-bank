\textbf{(a)} There are $5!$ ways to seat the people in $5$ labelled seats. Each seating has $5$ rotations, all different (no rotation other than the identity fixes a seating of distinct people), so there are $\dfrac{5!}{5}=4!=\boxed{24}$ seatings.

\textbf{(b)} Now each arrangement is also identified with its mirror image. A mirror image is never a rotation of the original (for $5$ distinct beads, the clockwise order around the circle would have to equal the counterclockwise order), so each bracelet corresponds to $10$ of the $5!$ labelled arrangements, and there are $\dfrac{5!}{10}=\boxed{12}$ bracelets.

\textbf{(c)} Two arrangements count as the same when some allowed physical motion turns one into the other. A bracelet can be picked up and turned over, which reverses the cyclic order of its beads, so mirror images are the same bracelet. People sitting at a table cannot be "turned over": the mirror image of a seating has every person's left and right neighbours swapped, which is a genuinely different seating (each person now sees different people on each side), and rotating the table cannot produce it. So only rotations are identified for the table. (Which motions are allowed is part of the problem statement; if a problem says only "arranged in a circle" with no way to flip, reflections are not identified.)
