If there are $g$ girls, the $k$-th girl danced with $7+k$ boys, so the last girl danced with $7+g$ boys, which is all of them: there are $b=g+7$ boys. Then $g+b=2g+7=31$ gives $g=12$ and $b=\boxed{19}$.
