The power set of an $m$-element set has $2^m$ elements, so it has $2^{2^m}$ subsets. Hence
\[2^{2^p}-2^{2^q}=240,\qquad\text{i.e.}\qquad 2^{2^q}\left(2^{2^p-2^q}-1\right)=240=2^4\cdot15.\]
The second factor is odd (as $2^p-2^q\ge1$), so $2^{2^q}=2^4$ and $2^{2^p-2^q}-1=15$. Thus $2^q=4$, i.e. $q=2$, and $2^p-4=4$, i.e. $p=3$. (Check: $2^8-2^4=256-16=240$.) So $p+q=\boxed{5}$.
