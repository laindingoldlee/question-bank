Place $B=(0,0)$ and $C=(15,0)$. From $x^2+y^2=14^2$ and $(x-15)^2+y^2=13^2$ we get $-30x+225=-27$, so $A=\left(\dfrac{42}{5},\dfrac{56}{5}\right)$. The altitude from $A$ is the line $x=\dfrac{42}{5}$, so $H=\left(\dfrac{42}{5},t\right)$. The altitude from $B$ is perpendicular to $AC$, whose direction is $C-A=\left(\dfrac{33}{5},-\dfrac{56}{5}\right)$, so $H\cdot(C-A)=0$:
\[
\dfrac{42}{5}\cdot\dfrac{33}{5}-\dfrac{56}{5}t=0\quad\Longrightarrow\quad t=\dfrac{99}{20}.
\]

Then
\[
AH=\dfrac{56}{5}-\dfrac{99}{20}=\dfrac{25}{4},\qquad BH=\sqrt{\left(\dfrac{42}{5}\right)^2+\left(\dfrac{99}{20}\right)^2}=\dfrac{39}{4},\qquad CH=\sqrt{\left(\dfrac{33}{5}\right)^2+\left(\dfrac{99}{20}\right)^2}=\dfrac{33}{4}.
\]
(For $BH$: $\dfrac{1}{400}\left(168^2+99^2\right)=\dfrac{38025}{400}=\left(\dfrac{195}{20}\right)^2$; for $CH$: $\dfrac{1}{400}\left(132^2+99^2\right)=\dfrac{27225}{400}=\left(\dfrac{165}{20}\right)^2$.) So $AH+BH+CH=\dfrac{97}{4}$ and $a+b=\boxed{101}$.

This agrees with $AH=2R\cos A$ etc.: $R=\dfrac{65}{8}$ and $\cos A+\cos B+\cos C=\dfrac{5}{13}+\dfrac{3}{5}+\dfrac{33}{65}=\dfrac{97}{65}$, so the sum is $2R\cdot\dfrac{97}{65}=\dfrac{97}{4}$.
