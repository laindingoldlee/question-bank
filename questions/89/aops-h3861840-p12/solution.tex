In base three, any positive number with a zero digit has $f(n)=0$. A number containing only digits $1,2$ has value $3^{-s}$, where $s$ is its digit sum. Summing over all such strings of length $k$ gives $(\dfrac{1}{3}+\dfrac{1}{9})^k=(\dfrac{4}{9})^k$. Thus the required sum over positive integers is $\sum_{k=1}^{\infty}(\dfrac{4}{9})^k=\boxed{\dfrac{4}{5}}$.
