Each cell of a table with $8$ rows and $7$ columns is coloured yellow, red or green. In each row, the number of red cells is at least the number of yellow cells and at least the number of green cells. In each column, the number of yellow cells is at least the number of red cells and at least the number of green cells. What is the greatest possible number of green cells?
