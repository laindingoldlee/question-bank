\textbf{(a)} We need $a=bc$, $b=ca$ and $c=ab$. Multiplying the three equations gives $abc=(abc)^2$, and $abc\ne0$, so $abc=1$. Then
\[a=bc=\dfrac{abc}{a}=\dfrac{1}{a},\]
so $a^2=1$; similarly $b^2=c^2=1$. So $a,b,c\in\{1,-1\}$ with product $1$, which means an even number of them are $-1$:
\[(1,1,1),\quad(1,-1,-1),\quad(-1,1,-1),\quad(-1,-1,1).\]
Each of these works (for example $(1,-1,-1)$: $1=(-1)(-1)$, $-1=1\cdot(-1)$, $-1=1\cdot(-1)$). There are $\boxed{4}$ triples.

\textbf{(b)} The condition ``each number is the product of the other two'' implies $abc=1$, but $abc=1$ does not imply the condition. For $\left(x,\dfrac{1}{x},1\right)$ the first requirement says $x=\dfrac{1}{x}\cdot1$, which forces $x=\pm1$. For example $\left(2,\dfrac{1}{2},1\right)$ has product $1$, but $2\ne\dfrac{1}{2}\cdot1$. The student checked a consequence of the condition instead of the condition itself.
