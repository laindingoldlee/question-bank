Since $66666666=6\cdot11111111$ and $77777777=7\cdot11111111$, the fraction equals $\dfrac{6}{7}$. Also $(6-7)^0=(-1)^0=1$ (any nonzero number to the power $0$ is $1$). So the value is
\[
\dfrac{6}{7}-1=\boxed{-\dfrac{1}{7}}.
\]
