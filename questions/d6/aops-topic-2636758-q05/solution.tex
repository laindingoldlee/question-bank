The last digit must be $2$, $4$ or $6$. There are $3$ such one-digit numbers and $6\cdot3=18$ two-digit ones, $21$ in all. So we need the $54^{\text{th}}$ three-digit one. For each hundreds digit there are $6\cdot3=18$ of them, and $54=3\cdot18$, so we need the largest one with hundreds digit $3$, namely $\boxed{366}$.
