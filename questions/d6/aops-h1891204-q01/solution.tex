Let $u$ be the number of handleless cups and $v$ the number with handles. We require
\[\binom u2\binom v3=1200,\qquad u\ge2,\ v\ge3.\]
Since $\binom{21}{3}=1330$, necessarily $v\le20$. If $v=3$, then $u(u-1)=2400$, impossible because $49\cdot48<2400<50\cdot49$. If $v=4$, then $\binom u2=300$, giving $u=25$ and total 29.

It remains to exclude larger totals. For $5\le v\le9$, $\binom u2\le120$, so $u\le16$ and $u+v\le25$. For $10\le v\le20$, $\binom u2\le10$, so $u\le5$ and again $u+v\le25$. Therefore the maximum total is $\boxed{29}$.
