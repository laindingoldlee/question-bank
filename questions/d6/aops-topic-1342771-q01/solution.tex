MULTIPLE has $8$ letters: M, U, L, T, I, P, L, E. Only the letter L repeats (twice); all others appear once. Swapping the two L's does not change an arrangement, so the number of arrangements is
\[
\dfrac{8!}{2!}=\dfrac{40320}{2}=\boxed{20160}.
\]
The answer key's $40320=8!$ is wrong: it treats the two L's as different letters.
