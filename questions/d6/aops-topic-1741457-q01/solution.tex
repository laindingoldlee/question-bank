The primes up to $20$ are $2,3,5,7,11,13,17,19$: eight cards. Only the relative order of these eight cards and the joker matters, and all $9!$ relative orders are equally likely. The number of prime cards kept is the number of them that precede the joker, and the joker's position among the nine cards is uniform on $1,\dots,9$. So the number of primes kept is equally likely to be any of $0,1,\dots,8$, and the probability that it is $4$ is $\boxed{\dfrac{1}{9}}$.
