If there are g girls, there are $20-g$ boys and $21-g$ possible boy-friend counts, including zero. At most two girls can have each count, so $g\le2(21-g)$, giving $g\le14$. With fourteen girls and six boys, assign two girls each count from zero to six; for instance, let each such girl be friends with the first j boys. This attains $\boxed{14}$ girls.
