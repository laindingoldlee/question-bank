Let $a_n$ be the count for length $n$. We have $a_1=3,a_2=9,a_3=27$. For $n\ge4$, classify by final run length 1, 2, 3. Removing it leaves a valid string ending in a different letter, and there are two choices for the new final letter. Hence $a_n=2(a_{n-1}+a_{n-2}+a_{n-3})$. This gives $a_4=78,a_5=228,a_6=666,a_7=1944,a_8=\boxed{5676}$.
