Group the pairs of segments by their set of four endpoints. Any four vertices of a convex polygon form a convex quadrilateral, say $PQRS$ in order around the polygon, and they can be joined in pairs in exactly $3$ ways:
\[
\{PQ,RS\},\qquad\{QR,SP\},\qquad\{PR,QS\}.
\]
The first two use opposite sides of the quadrilateral, which do not meet; the third uses its two diagonals, which cross inside it. So for every set of four vertices exactly $2$ of the $3$ pairings give non-intersecting segments, and since every set of four vertices gives the same number of pairs, the probability is $\boxed{\dfrac{2}{3}}$. (The number of sides, $12$, does not matter.)
