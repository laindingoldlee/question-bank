\textbf{(a)} With a calculator, and using reference angles for the signs:
\begin{itemize}
\item $\sin40^\circ\approx\boxed{0.64}$ (first quadrant, positive).
\item $215^\circ$ is in the third quadrant with reference angle $35^\circ$, where cosine is negative: $\cos215^\circ=-\cos35^\circ\approx\boxed{-0.82}$.
\item $337^\circ$ is in the fourth quadrant with reference angle $23^\circ$, where tangent and cotangent are negative: $\cot337^\circ=-\cot23^\circ=-\dfrac{1}{\tan23^\circ}\approx\boxed{-2.36}$.
\item $-50^\circ$ is in the fourth quadrant: $\tan(-50^\circ)=-\tan50^\circ\approx\boxed{-1.19}$.
\end{itemize}

\textbf{(b)} The distance from the origin to $D$ is $r=\sqrt{5^2+12^2}=13$. With $x$-coordinate $5$ and $y$-coordinate $-12$,
\[
\sin x=-\dfrac{12}{13},\quad\cos x=\dfrac{5}{13},\quad\tan x=-\dfrac{12}{5},\quad\csc x=-\dfrac{13}{12},\quad\sec x=\dfrac{13}{5},\quad\cot x=-\dfrac{5}{12}.
\]

\begin{asy}
usepackage("amsmath");

import graph;

xaxis(Label("$x$",position=EndPoint,align=E),-3,8,gray,Arrow);
yaxis(Label("$y$",position=EndPoint,align=N),-14,3,gray,Arrow);
draw((0,0)--D,blue+linewidth(0.9));
draw(D--(5,0),gray+dashed);
draw((5,0)+(-0.6,0)--(5,0)+(-0.6,-0.6)--(5,0)+(0,-0.6),gray);
draw(arc((0,0),1.3,0,360+degrees(D)),red,Arrow);
dot(D); label("$D(5,-12)$",D,SE);
label("$13$",D/2,W,blue); label("$x$",1.3*dir(150),NW,red);
label("$5$",(2.5,0),N); label("$12$",(5,-6),E);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

The angle $x$ ends in the fourth quadrant, so only cosine and secant are positive.
