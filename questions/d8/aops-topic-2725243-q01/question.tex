Machines A and B each make one bottle per minute while working. Machine A must rest $1$ minute after every $3$ bottles, and machine B must rest $1.5$ minutes after every $5$ bottles. Both start at time $0$. What is the least number of minutes after which they have produced $2015$ bottles together?
