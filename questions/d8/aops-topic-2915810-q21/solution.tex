Let the factor be $c$. The data require $7.5\le5c<8.5$ and $11.5\le7c<12.5$, so $\dfrac{23}{14}\le c<\dfrac{17}{10}$. Thus $\dfrac{23161}{7}\le2014c<\dfrac{17119}{5}$, approximately $3308.714\le2014c<3423.8$. Rounded values run through every integer 3309 to 3424, for $3424-3309+1=\boxed{116}$.
