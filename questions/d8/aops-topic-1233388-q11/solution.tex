Count by number of digits.
\begin{itemize}
\item $0$ itself: $1$.
\item $10$ to $99$: units digit $0$: $9$.
\item $100$ to $999$: tens digit $0$: $9\cdot10=90$; units digit $0$: $90$. Total $180$.
\item $1000$ to $1999$: each of the last three places is $0$ in $100$ numbers: $300$.
\item $2000$ to $2016$: $2000$ has $3$; $2001$ to $2009$ have $2$ each ($18$); $2010$ has $2$; $2011$ to $2016$ have $1$ each ($6$). Total $29$.
\end{itemize}
Altogether $1+9+180+300+29=\boxed{519}$.
