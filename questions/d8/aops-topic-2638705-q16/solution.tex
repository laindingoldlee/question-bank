If the first person gives $x$ cards and receives $y$, then $5x-7y=1$, with $x,y\ge0$. Modulo $7$, $x\equiv3$, so $x=3+7t$ and $y=2+5t$ with $t\ge0$. The minimum total is $3+2=\boxed5$ cards, giving value $15$ and receiving $14$.
