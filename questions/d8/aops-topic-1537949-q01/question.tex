Each face of a cube is painted one of $2$ colours. Two painted cubes are considered the same if one can be rotated to look exactly like the other.
\begin{enumerate}
\item[(a)] How many different cubes are there?
\item[(b)] Find a formula for the number of different cubes when $n$ colours are available.
\end{enumerate}
