A number is congruent to its digit sum modulo $9$, so $\Psi(n)\equiv n\pmod 9$ and $\Psi(n)\in\{1,\dots,9\}$. Hence $\Psi(n)$ is $9$ if $9\mid n$ and the remainder of $n$ modulo $9$ otherwise.

\textbf{The inner sum.} The values $\Psi(1),\Psi(2),\dots$ run through $1,2,\dots,9$ repeatedly. The numbers $1$ to $999$ form $111$ complete blocks of nine, each contributing $1+2+\cdots+9=45$, and $\Psi(1000)=1$. So
\[
\sum_{n=1}^{1000}\Psi(n)=111\cdot45+1=4996 .
\]

\textbf{The outer $\Psi$.} $\Psi(4996)=\Psi(4+9+9+6)=\Psi(28)=\Psi(10)=\boxed{1}$. (Equivalently, $4996=9\cdot555+1\equiv1\pmod9$.)
