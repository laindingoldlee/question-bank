Each choice of $3$ different letters can be written in alphabetical order in exactly one way, and different choices give different triples. So the number of triples is the number of $3$-element subsets of the $26$ letters:
\[\dbinom{26}{3}=\dfrac{26\cdot25\cdot24}{6}=\boxed{2600}.\]
