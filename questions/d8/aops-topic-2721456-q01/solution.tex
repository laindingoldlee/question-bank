Pages $1$--$9$ use $9$ digits and pages $10$--$99$ use $180$, for $189$ in all. The remaining $2022-189=1833$ digits number $\dfrac{1833}{3}=611$ three-digit pages, $100$ through $710$. So the book has $\boxed{710}$ pages.
