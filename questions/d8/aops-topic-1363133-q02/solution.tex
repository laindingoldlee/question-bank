The value satisfies $x=\sqrt{2-\sqrt{2+\sqrt{2+x}}}$ with $0\le x\le 2$. (The map $g(x)=\sqrt{2-\sqrt{2+\sqrt{2+x}}}$ sends $[0,2]$ into $[0,2]$ and its derivative there has absolute value well below $1$, so the truncations converge to its unique fixed point in $[0,2]$.)

Write $x=2\cos t$ with $0\le t\le\dfrac{\pi}{2}$. Using $2+2\cos t=4\cos^2\dfrac{t}{2}$ and $2-2\cos t=4\sin^2\dfrac{t}{2}$:
\[
\sqrt{2+x}=2\cos\dfrac{t}{2},\qquad \sqrt{2+\sqrt{2+x}}=2\cos\dfrac{t}{4},\qquad \sqrt{2-2\cos\dfrac{t}{4}}=2\sin\dfrac{t}{8}=2\cos\left(\dfrac{\pi}{2}-\dfrac{t}{8}\right).
\]
So the equation becomes $2\cos t=2\cos\left(\dfrac{\pi}{2}-\dfrac{t}{8}\right)$, and with both angles in $\left[0,\dfrac{\pi}{2}\right]$ this means $t=\dfrac{\pi}{2}-\dfrac{t}{8}$, that is $t=\dfrac{4\pi}{9}$. Hence
\[
x=\boxed{2\cos\dfrac{4\pi}{9}=2\cos80^\circ}\approx0.3473 .
\]
