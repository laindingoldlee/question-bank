Find the value of the infinite nested radical
\[
x=\sqrt{2-\sqrt{2+\sqrt{2+\sqrt{2-\sqrt{2+\sqrt{2+\cdots}}}}}}
\]
in which the signs repeat with period $-,+,+$ (interpret $x$ as the limit of the finite truncations). Express $x$ using a cosine.
