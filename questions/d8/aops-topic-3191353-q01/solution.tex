The horizontal offset of each leg is $1$, so the height is $\sqrt{17-1}=4$. The trapezoid area is $\dfrac{2+4}{2}\cdot4=12$. Thus $[ADE]=6=\dfrac{1}{2}\cdot DE\cdot4$, yielding $DE=\boxed3$.
