$T_{n+8}-T_n=\dfrac{(n+8)(n+9)-n(n+1)}{2}=8n+36\equiv0\pmod4$, so the remainders repeat with period $8$. For $n=1,\dots,8$ the triangular numbers $1,3,6,10,15,21,28,36$ leave remainders
\[
1,\ 3,\ 2,\ 2,\ 3,\ 1,\ 0,\ 0,
\]
with sum $12$. Since $100=8\cdot12+4$, the sum is $12\cdot12+(1+3+2+2)=144+8=\boxed{152}$.
