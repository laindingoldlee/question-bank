A real number $x$ satisfies $x+\dfrac{1}{x}=3$. Find all possible values of
\begin{enumerate}
\item[(a)] $x-\dfrac{1}{x}$;
\item[(b)] $x^2-\dfrac{1}{x^2}$;
\item[(c)] $x^3-\dfrac{1}{x^3}$.
\end{enumerate}
