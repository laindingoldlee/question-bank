A set $T$ is a subset of $S=\{1,2,\dots,10\}$ when every element of $T$ is an element of $S$. Under this definition the whole set $S$ is a subset of itself, and the empty set is a subset too, because it has no element that could fail to lie in $S$. (A subset other than $S$ itself is called a \emph{proper} subset.)

To build a subset we decide, for each of the $10$ elements, whether it is in or out. These are $10$ independent choices with $2$ options each, and different choices give different subsets, so there are
\[
2^{10}=\boxed{1024}
\]
subsets. The choice ``all out'' gives the empty set and ``all in'' gives $S$; there are $1024-1=1023$ proper subsets and $1024-2=1022$ subsets that are neither empty nor all of $S$.
