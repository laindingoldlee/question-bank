The flight path is essentially the equator, a circle of radius $4000$ miles.

\begin{asy}
usepackage("amsmath");
size(4cm);
defaultpen(fontsize(10pt));
pair O=(0,0);
draw(circle(O,1),linewidth(0.9));
draw(O--dir(30),dashed); label("$4000$",0.5*dir(30),NW,fontsize(8pt));
draw(arc(O,1.14,-60,200),blue,Arrow(5));
label("flight path",1.14*dir(-60),SE,blue+fontsize(8pt));
dot(O); label("$O$",O,SW);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

Its length is $2\pi\cdot4000=8000\pi$ miles, so the flight takes
\[\dfrac{8000\pi}{500}=16\pi\approx50.3\text{ hours}.\]
The best estimate is $50$, answer $\boxed{\textbf{(C)}}$.
