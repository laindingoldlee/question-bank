If $p$ dominates $q$, substitute $n=p$. Since $s_p(p)=1$ and digit sums of positive integers are positive, $s_q(p)=1$, forcing $p=q^k$ for an integer $k\ge1$. Conversely, if $p=q^k$, expand each base-$p$ digit as a block of $k$ base-$q$ digits. The sum of digits of each block is at most its numerical value, so $s_q(n)\le s_p(n)$. Distinctness requires $k\ge2$. Counting powers up to $100$ gives $5$ for base $2$, $3$ for $3$, $2$ for $4$, and one each for bases $5,6,7,8,9,10$. The total is $\boxed{16}$.
