The coefficients add up to $2-15+41-48+20=0$, so $x=1$ is a root. Also $2\cdot16-15\cdot8+41\cdot4-48\cdot2+20=32-120+164-96+20=0$, so $x=2$ is a root. Dividing by $(x-1)(x-2)=x^2-3x+2$,
\[
2x^4-15x^3+41x^2-48x+20=(x^2-3x+2)(2x^2-9x+10)=(x-1)(x-2)(x-2)(2x-5).
\]
So the solutions are $\boxed{x=1,\ 2,\ \dfrac{5}{2}}$, where $x=2$ is a double root. All roots are real and rational.
