The one-digit odd numbers $1,3,5,7,9$ use the first $5$ digits. After that the two-digit odd numbers $11,13,\dots,99$ follow, each using $2$ digits. The $64$th digit is digit number $64-5=59$ of this two-digit part. Since $59=2\cdot29+1$, it is the first digit of the $30$th two-digit odd number, which is $11+2\cdot29=69$. So the $64$th digit is $\boxed{6}$.
