Each digit appears once in each place, so
\[S=100(a+b+c)+10(a+b+c)+(a+b+c)=111(a+b+c)=3\cdot37\cdot(a+b+c).\]
\begin{itemize}
\item (a) and (d) are always true, since $3$ and $37$ divide $111$.
\item (e) is always true: $\dfrac{S}{a+b+c}=111$.
\item (c) is always true: $a+b+c\ge3$, so $S\ge333>330$.
\item (b) fails when $a+b+c$ is odd, for example $a=b=c=1$ gives $S=333$.
\end{itemize}
The answer is $\boxed{\text{(b)}}$.
