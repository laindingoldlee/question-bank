Let solution B be $p\%$ alcohol, so solution A is $2p\%$ alcohol. The alcohol in grams is
\[
1000\cdot0.15+100\cdot\dfrac{2p}{100}+400\cdot\dfrac{p}{100}=150+2p+4p=150+6p ,
\]
and the final $1500$ grams contain $0.14\cdot1500=210$ grams. So $6p=60$, $p=10$, and solution A is $\boxed{20\%}$ alcohol.
