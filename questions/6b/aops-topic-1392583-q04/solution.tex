We need $1018^{1729}\equiv18^{1729}\pmod{100}$; use the Chinese remainder theorem with $100=4\cdot25$.
\begin{itemize}
\item Modulo $4$: $18^{1729}$ is divisible by $4$, so it is $\equiv0$.
\item Modulo $25$: $\varphi(25)=20$ and $1729=86\cdot20+9$, so $18^{1729}\equiv18^9\equiv(-7)^9$. Since $7^2=49\equiv-1$, we have $7^8\equiv1$ and $(-7)^9=-7^9\equiv-7\equiv18\pmod{25}$.
\end{itemize}
The number $x\equiv18\pmod{25}$ with $0\le x<100$ and $4\mid x$ is $68$ (the candidates are $18,43,68,93$). So the last two digits are $6,8$ and their sum is $\boxed{14}$.
