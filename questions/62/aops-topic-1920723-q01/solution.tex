Since $5^{50}=\left(5^2\right)^{25}=25^{25}$, the value $n=25$ works. It is the only one: for positive integers $1\le m<n$ we have $m^m<n^m\le n^n$, so $n\mapsto n^n$ is strictly increasing and takes the value $5^{50}$ only once. The answer is $n=\boxed{25}$.
