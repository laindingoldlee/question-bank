Let $f(t)=\sqrt{1+t}$, which is increasing; the equation is $f(f(f(x)))=x$ with $x\ge0$ (the left side is positive). If $f(x)>x$, then $f(f(x))>f(x)>x$ and $f(f(f(x)))>f(f(x))>x$, a contradiction; similarly $f(x)<x$ is impossible. So $f(x)=x$, i.e. $x^2=1+x$ with $x>0$, giving $x=\boxed{\dfrac{1+\sqrt5}{2}}$, which works.
