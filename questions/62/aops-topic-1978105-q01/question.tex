Write each of the numbers $1,2,\dots,12$ as an expression that uses the digits $1$, $2$ and $3$ exactly once each, in this order. You may use $+$, $-$, $\times$, $\div$, powers, square roots, factorials, the greatest integer function $\lfloor\ \rfloor$ and parentheses. (For example, $0=1+2-3$.)
