Let $I$ be the number of doors between two rooms. Each such door is counted twice (once from each of its rooms), and each outside door is counted once. So
\[
2I+N=25 ,
\]
and $N=25-2I$ is odd. Hence $N=2$ is impossible, and the answer is $\boxed{\textbf{(D)}}$. The odd values $7$, $5$, $3$ are possible (with $I=9$, $10$, $11$ doors between rooms, which can be arranged among ten rooms).
