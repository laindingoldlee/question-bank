Let $x$ speak all three. Then English only $=87-31-19-x=37-x$, Spanish only $=86-31-1-x=54-x$, French only $=39-19-1-x=19-x$. Adding all seven regions:
\[(37-x)+(54-x)+(19-x)+31+19+1+x=161-2x=135,\]
so $x=\boxed{13}$.
