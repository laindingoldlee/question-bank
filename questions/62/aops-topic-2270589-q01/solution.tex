Since $\dfrac{1}{i}=-i$,
\[i^{\dfrac{1}{i}}=e^{\dfrac{1}{i}\operatorname{Log}i}=e^{-i\cdot\dfrac{\pi i}{2}}=e^{\dfrac{\pi}{2}}\approx4.81 .\]
So the principal value is the real number $\boxed{e^{\dfrac{\pi}{2}}}$.

With $\log i=\dfrac{\pi i}{2}+2\pi ki$, we get $e^{-i\left(\dfrac{\pi i}{2}+2\pi ki\right)}=e^{\dfrac{\pi}{2}+2\pi k}$ for integers $k$: infinitely many values, all positive real numbers.
