Using the principal value $z^w=e^{w\operatorname{Log}z}$, where $\operatorname{Log}i=\dfrac{\pi i}{2}$, compute the $i$th root of $i$, that is, $i^{\dfrac{1}{i}}$. What are all the values if every logarithm $\log i=\dfrac{\pi i}{2}+2\pi ki$ ($k$ an integer) is allowed?
