If some digit is $0$ the product is $0$ but the sum is positive (the first digit is at least $1$), so all digits are $1$ to $9$. Sort the digits as $a\le b\le c\le d$. Then
\[
abcd=a+b+c+d\le4d\quad\Longrightarrow\quad abc\le4 .
\]
So $(a,b,c)$ is $(1,1,1)$, $(1,1,2)$, $(1,1,3)$, $(1,1,4)$ or $(1,2,2)$:
\begin{itemize}
\item $(1,1,1)$: $d=3+d$, impossible.
\item $(1,1,2)$: $2d=4+d$, so $d=4$: digits $1,1,2,4$ (sum $8$, product $8$).
\item $(1,1,3)$: $3d=5+d$, $d=\dfrac{5}{2}$, impossible.
\item $(1,1,4)$: $4d=6+d$, $d=2<c$, impossible.
\item $(1,2,2)$: $4d=5+d$, $d=\dfrac{5}{3}$, impossible.
\end{itemize}
So the digits must be $1,1,2,4$ in some order. The number of orders is $\dfrac{4!}{2!}=12$, and none starts with $0$. The answer is $\boxed{12}$.
