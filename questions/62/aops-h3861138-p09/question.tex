Label the vertices of a regular $21$-gon $0,1,\ldots,20$ in counterclockwise order. Choose an integer $k$ with $2\le k\le10$ and $\gcd(k,21)=1$. Starting at vertex $0$, repeatedly travel to the vertex whose label is $k$ greater, reducing labels modulo $21$. This produces a closed tour visiting every vertex exactly once before returning to $0$.

Count a crossing once for each unordered pair of tour edges whose interiors intersect. If several edges meet at one point, count each crossing pair separately. Among these constant-step tours, find the difference between the maximum and minimum crossing counts.
