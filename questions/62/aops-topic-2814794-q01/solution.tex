$x^4-8x^3+24x^2-32x+16=(x-2)^4$, so the equation is $(x-2)^4=n+2$. This has two real solutions when $n+2>0$, none when $n+2<0$, and exactly one ($x=2$) when $n+2=0$. So $n=\boxed{-2}$.
