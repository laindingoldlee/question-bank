If $D=11$, then $DK\equiv0$, a loss. If $D\in\{1,\dots,10\}$, then since $11$ is prime there is exactly one $K\in\{1,\dots,10\}$ with $DK\equiv1\pmod{11}$ (the inverse of $D$), and $K=11$ never works. So there are $10$ winning pairs out of $121$: probability $\boxed{\dfrac{10}{121}}$.
