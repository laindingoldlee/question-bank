At 9:30 Newton has run $2.5\cdot\dfrac{1}{2}=1.25$ miles. After that Tao gains $3-2.5=0.5$ mile per hour, so he closes the gap in
\[
\dfrac{1.25}{0.5}=\boxed{2.5\text{ hours}},
\]
that is at 12:00 noon, well before 4:00 PM. (Check: by noon Tao has run $3\cdot2.5=7.5$ miles and Newton $2.5\cdot3=7.5$ miles.)
