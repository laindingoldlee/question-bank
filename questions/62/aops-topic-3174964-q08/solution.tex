The running time is $\dfrac{600}{2}+\dfrac{600}{1.5}+\dfrac{600}{1}+\dfrac{600}{0.5}=300+400+600+1200=2500$ seconds. The dog's speed is $\dfrac{10}{3}$ meters per second, so it travels $\dfrac{25000}{3}$ meters. Rounded as requested this is $\boxed{8300}$ meters. The dog's direction changes do not alter its distance at constant speed.
