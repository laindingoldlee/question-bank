Let the repeated root be $r$ and the other root $s$. Then the polynomial is
\[
9(x-r)^7(x-s).
\]
Expanding, $(x-r)^7=x^7-7rx^6+21r^2x^5-35r^3x^4+\cdots$, so
\[
9(x-r)^7(x-s)=9x^8-9(7r+s)x^7+9(21r^2+7rs)x^6-9(35r^3+21r^2s)x^5+\cdots .
\]
\textbf{No $x^7$ term:} $7r+s=0$, so $s=-7r$.

\textbf{Coefficient of $x^6$:} $9(21r^2-49r^2)=-252r^2=-28$, so $r^2=\dfrac{1}{9}$ and $r=\pm\dfrac{1}{3}$.

\textbf{Coefficient of $x^5$:} $-9(35r^3-147r^3)=1008r^3$, which is negative only for $r=-\dfrac{1}{3}$.

So $r=-\dfrac{1}{3}$ and the eighth root is $s=-7r=\boxed{\dfrac{7}{3}}$. (Without the sign condition on the $x^5$ term, $r=\dfrac{1}{3}$, $s=-\dfrac{7}{3}$ would also fit the given terms.)
