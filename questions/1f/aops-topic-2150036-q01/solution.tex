\textbf{(a)} Let $K=\dfrac{xw}{yz}$. We show that $K$ does not change when only one of $w,y,z$ changes.
\begin{itemize}
\item If only $y$ changes, then $\dfrac {x}{y}$ is constant (direct proportion), and so is $\dfrac {w}{z}$; hence $K=\dfrac {x}{y}\cdot\dfrac {w}{z}$ is unchanged.
\item If only $z$ changes, then $K=\dfrac {x}{z}\cdot\dfrac {w}{y}$ is unchanged in the same way.
\item If only $w$ changes, then $xw$ is constant (inverse proportion), and so is $yz$; hence $K=\dfrac{xw}{yz}$ is unchanged.
\end{itemize}
Any triple $(w,y,z)$ can be turned into any other triple $(w',y',z')$ by changing one coordinate at a time:
\[(w,y,z)\to(w',y,z)\to(w',y',z)\to(w',y',z').\]
$K$ is unchanged at each step, so it is the same for both triples. Thus $\dfrac{xw}{yz}$ is a constant, that is, $x=K\dfrac{yz}{w}$.

\textbf{(b)} From the first data, $K=\dfrac{4\cdot6}{8\cdot5}=\dfrac{3}{5}$. So for $(w,y,z)=(4,10,9)$,
\[x=\dfrac{3}{5}\cdot\dfrac{10\cdot9}{4}=\boxed{\dfrac{27}{2}}.\]
