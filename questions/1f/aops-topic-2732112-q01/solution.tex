Let $u=4^4=256$ and $v=9^4=6561$; then $uv=36^4=6^8$, so $6^4=1296=\sqrt{uv}$. Hence
\[4^8+6^8+9^8=u^2+uv+v^2=(u+v)^2-uv=\left(u+v-6^4\right)\left(u+v+6^4\right).\]
So the product is $(256+6561-1296)(256+6561+1296)=\boxed{5521\cdot8113}$, which equals $44791873$.
