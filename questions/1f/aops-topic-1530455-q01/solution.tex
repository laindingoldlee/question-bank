\textbf{(a)} The doubled last digit is subtracted from the number \emph{with its last digit removed}, not from the whole number. For $14$: remove $4$, leaving $1$; then $1-2\cdot4=-7$, which is divisible by $7$, so $14$ is. For $2016$: $201-12=189$; again $18-18=0$, so $189$ and hence $2016=7\cdot288$ are divisible by $7$.

\textbf{(b)} Let $n=10a+b$. Then
\[
n-10(a-2b)=10a+b-10a+20b=21b ,
\]
which is a multiple of $7$. Hence $n\equiv10(a-2b)\pmod 7$.
\begin{itemize}
\item If $7\mid a-2b$, then $7\mid10(a-2b)$, so $7\mid n$.
\item If $7\mid n$, then $7\mid10(a-2b)$, and since $\gcd(7,10)=1$, $7\mid a-2b$.
\end{itemize}
$\blacksquare$

(The poster subtracted $2\cdot4=8$ from $14$ itself, getting $6$; that is not the rule. With the correct step the rule works for every number.)
