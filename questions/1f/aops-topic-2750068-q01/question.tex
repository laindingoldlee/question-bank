Akshal and Bjarn play a game. In each round Akshal flips a fair coin. If it lands heads, Bjarn earns a point; if it lands tails, Akshal earns a point and the game ends immediately. Find the ratio of the expected number of points Bjarn earns to the expected number of points Akshal earns.
