Between displayed 12:00 and 6:00, the permissible hours are 12,1,2,4,5. Each has 45 permissible minute values: among 00 through 59, fifteen contain a 3. Thus exactly $5\cdot45=225$ one-minute advances bring the display to 6:00. The actual elapsed time is 3 hours 45 minutes, so the true time is 3:45 and $\boxed{a+b+c=12}$.
