Complete squares to obtain $(x+1)^2+(y+3)^2+(z-4)^2=100$. Hence the radius is $\boxed{10}$.
\begin{asy}
import graph;
usepackage("amsmath");
import geometry;
size(7cm);
pair O=(0,0),P=(3,0);draw(circle(O,3));draw(ellipse(O,3,0.8),dashed);draw(O--P);dot(O);label("$(-1,-3,4)$",O,(0,1));label("$r=10$",(O+P)/2,(0,-1));
\end{asy}
