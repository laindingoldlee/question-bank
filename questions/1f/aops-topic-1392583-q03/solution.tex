Use $k(k+1)=\dfrac{k(k+1)(k+2)-(k-1)k(k+1)}{3}$, which telescopes: $\sum_{k=1}^{8}k(k+1)=\dfrac{8\cdot9\cdot10}{3}=240$. Removing the term $1\cdot2$ gives $238$, so the number is $239$.

Since $15^2=225<239<256=16^2$, it suffices to test the primes up to $13$: $239$ is odd, its digit sum $14$ is not a multiple of $3$, it does not end in $0$ or $5$, and $239=7\cdot34+1=11\cdot21+8=13\cdot18+5$. So $239$ is prime: \textbf{yes}, the number $\boxed{239}$ is prime.
