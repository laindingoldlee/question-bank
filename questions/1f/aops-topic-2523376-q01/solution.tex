Let $g(p)=p+\dfrac3p$. The condition says $g(p_{i+1})=g(p_i)+\dfrac1{20}$, so
\[g(p_i)=g(1)+\dfrac{i}{20}=4+\dfrac{i}{20}.\]
On $(0,1]$, $g$ is strictly decreasing: for $0<p<q\le1$,
\[g(p)-g(q)=(q-p)\left(\dfrac{3}{pq}-1\right)>0,\]
since $pq<1<3$. Also $g$ is continuous and takes all values $\ge4$ on $(0,1]$, so each $p_i$ exists and is uniquely determined. (The other solution of $g(p)=c$ is $\dfrac3p>1$, which is not a probability.)

Because $g$ is decreasing on $(0,1]$,
\[p_i\ge0.6\iff g(p_i)\le g(0.6)=0.6+5=5.6\iff4+\dfrac{i}{20}\le5.6\iff i\le32.\]
So he can procrastinate at most $\boxed{32}$ minutes (and then $p_{32}=0.6$ exactly).
