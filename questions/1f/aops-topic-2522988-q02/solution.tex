\textbf{If $\gcd(a,n)=d>1$, then $a$ is not invertible modulo $n$:} $ab\equiv1$ would mean $n\mid ab-1$, so $d\mid ab-1$; but $d\mid ab$, so $d\mid1$, a contradiction.

Now $63=3^2\cdot7$ and $70=2\cdot5\cdot7$. The numbers $1$ to $5$ each have an inverse modulo $63$ or modulo $70$:
\[1\cdot1\equiv1,\quad 2\cdot32=64\equiv1\pmod{63},\quad 3\cdot47=141\equiv1\pmod{70},\]
\[4\cdot16=64\equiv1\pmod{63},\quad 5\cdot38=190\equiv1\pmod{63}.\]
For $x=6$: $\gcd(6,63)=3>1$ and $\gcd(6,70)=2>1$, so $6$ is invertible modulo neither. The answer is $\boxed{6}$.
