\textbf{Table 1.} The differences of consecutive $y$-values are $2.5,7.5,12.5,17.5$, and their differences are all $5$. Constant second differences mean a quadratic. An exponential function cannot take the value $0$, so it is not exponential. Since $y=0$ at $x=0$ and each $y$ is $2.5$ times $x^2$ ($0,1,4,9,16$), the function is
\[
\boxed{y=\dfrac{5}{2}x^2}\quad\text{(quadratic)}.
\]
\textbf{Table 2.} The differences are all $2$, so $y$ is linear with slope $2$, and $y=-5$ at $x=0$:
\[
\boxed{y=2x-5}\quad\text{(linear)}.
\]
