For each term,
\[\dfrac{1+a}{1+b}=1+\dfrac{a-b}{1+b}=1+(a-b)+\dfrac{b(b-a)}{1+b}\le1+(a-b)+\dfrac{b^2}{1+b}\le1+(a-b)+b^2,\]
using $a\ge0$ and $1+b\ge1$. Summing cyclically, the terms $(a-b)+(b-c)+(c-a)$ cancel, leaving $3+a^2+b^2+c^2$. $\blacksquare$
