Continuing, $a_{10}=19$, $a_{11}=29,\dots,a_{18}=99$ (the smallest number above $a_n$ with digit sum $n+1$ is obtained by increasing the tens digit by $1$). For $a_{19}$ we need a number above $99$ with digit sum $19$: three-digit numbers $1bc$ need $b+c=18$, so $a_{19}=199$. Then $a_{20}$: above $199$ with digit sum $20$; numbers $2bc$ with $b+c=18$ give $299$. In the same way $a_{21}=399,\dots$, $a_{25}=\boxed{799}$.
