Place value gives $b^2+4b=6b+5b$, so $b^2=7b$. A valid base is positive and exceeds digit $6$, hence $b=7$. One item costs $77$ in decimal, so seven cost $539=343+4\cdot49$. Therefore $\boxed{1400_7}$.
