If $\gcd(x,y)=5$ then $5\mid x$ and $5\mid y$, so $25\mid xy$. But $25\nmid40$. So no such integers exist. The identity only applies to integers that exist; here it would give $\operatorname{lcm}=8$, which is impossible anyway because the lcm is a multiple of the gcd, and $5\nmid8$. $\blacksquare$
