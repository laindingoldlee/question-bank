The difference of the two readings is
\[
\sum_{i=0}^{k}d_i\left(10^i-b^i\right).
\]
Each term is nonnegative, and the term with $i\ge1$ is positive whenever $d_i=1$, because $10^i>b^i$. So the two values agree exactly when all digits except possibly $d_0$ are $0$, i.e. only for the strings $0$ and $1$. Hence there is \textbf{no} such string other than $0$ and $1$ in base two, in base three, or in any base $b<10$. (The same argument works for any digits less than $b$.)
