A string of digits $d_k d_{k-1}\ldots d_1d_0$ using only the digits $0$ and $1$ can be read both in base ten and in base $b$ (for $2\le b\le9$). For which such strings are the two values equal? In particular, is there such a string, other than $0$ and $1$, whose base-two value equals its base-ten value? Its base-three value?
