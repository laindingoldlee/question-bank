All the expressions are defined because $m,n\ne0$ and $m\ne n$. First,
\[
\dfrac{1}{m}-\dfrac{1}{n}=\dfrac{n-m}{mn},\qquad\text{so}\qquad\left(\dfrac{1}{m}-\dfrac{1}{n}\right)^2=\dfrac{(m-n)^2}{m^2n^2}.
\]
Then
\[
\dfrac{2}{mn}\div\dfrac{(m-n)^2}{m^2n^2}=\dfrac{2}{mn}\cdot\dfrac{m^2n^2}{(m-n)^2}=\dfrac{2mn}{(m-n)^2}.
\]
Hence the expression equals
\[
\dfrac{2mn-\left(m^2+n^2\right)}{(m-n)^2}=\dfrac{-(m-n)^2}{(m-n)^2}=-1,
\]
which does not depend on $m$ and $n$. The value is $\boxed{-1}$. $\blacksquare$
