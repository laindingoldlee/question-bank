Write the integers $0$ to $999999$ with six digits (leading zeros add nothing). In each of the $6$ positions every digit $0$--$9$ appears $100000$ times, so the digit sum is $6\cdot100000\cdot(0+1+\cdots+9)=6\cdot100000\cdot45=27000000$. Adding $1$ for $1000000$ gives $\boxed{27000001}$.
