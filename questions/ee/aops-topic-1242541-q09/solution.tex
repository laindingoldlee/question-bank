Label $n$ sits $2+3+\cdots+n=\dfrac{n(n+1)}{2}-1$ steps clockwise from label $1$. So $k$ and $1993$ share a point exactly when
\[\dfrac{k(k+1)}{2}\equiv\dfrac{1993\cdot1994}{2}\pmod{2000}.\]
Compute $\dfrac{1993\cdot1994}{2}=1987021\equiv1021\pmod{2000}$. (Reducing first, $\dfrac{(-7)(-6)}{2}=21$, is wrong: halving is not compatible with reduction modulo $2000$; one must reduce $1993\cdot1994$ modulo $4000$ before halving, giving $\dfrac{2042}{2}=1021$.)

So we need $k(k+1)\equiv2042\pmod{4000}$, i.e. $k(k+1)\equiv2042\pmod{32}$ and $\pmod{125}$. Checking, the smallest positive solution is $k=\boxed{118}$: $\dfrac{118\cdot119}{2}=7021\equiv1021\pmod{2000}$.
