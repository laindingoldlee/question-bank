We need $35^{13579}\bmod1000$, with $1000=8\cdot125$.
\begin{itemize}
\item Modulo $125$: $35^3=5^3\cdot7^3$ is divisible by $125$, so $35^{13579}\equiv0$.
\item Modulo $8$: $35\equiv3$ and $3^2\equiv1$, so $3^{13579}\equiv3$ (odd exponent).
\end{itemize}
We need a multiple of $125$ that is $3$ modulo $8$: $125k\equiv5k\equiv3\pmod8$ gives $k\equiv7$, so the number is $875$. The last three digits are $\boxed{875}$.
