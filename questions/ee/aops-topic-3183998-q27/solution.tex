The permitted colour orders are some green candies followed by some red candies. If $k$ of the five candies are green, then $1\le k\le5$ because only four red candies exist. Treat the candies as distinct. The respective counts of ordered selections are $(8)_k(4)_{5-k}$, where $(n)_j=n(n-1)\cdots(n-j+1)$. For $k=1,2,3,4,5$ these are $192,1344,4032,6720,6720$, summing to $19008$. There are $(12)_5=95040$ total ordered selections. The probability is $\dfrac{1}{5}$, so $m+n=\boxed6$.
