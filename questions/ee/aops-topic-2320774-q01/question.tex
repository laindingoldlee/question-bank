This month a website gains on average $1$ new user per minute, and $1$ of every $10080$ new users is a troll. Before the pandemic it gained only $0.3$ new users per minute. Assuming that new trolls arrived at the same rate per minute as this month, what was the ratio of new users to new trolls before the pandemic?
