Set $Q(x)=P(x)-x-3$, so $Q(17)=Q(24)=-10$. If an integer $n$ is a root of $Q$, integer-coefficient polynomial divisibility gives $n-17\mid10$ and $n-24\mid10$. Thus $n$ must lie in the intersection
\[
\{7,12,15,16,18,19,22,27\}\cap
\{14,19,22,23,25,26,29,34\}=\{19,22\}.
\]
The assumed two distinct integer roots must therefore be $19,22$, giving $\boxed{418}$. These conditions are consistent, for example with $Q(x)=-(x-19)(x-22)$.
