Since $i^4=(i^2)^2=(-1)^2=1$, writing $n=4q+r$ with $0\le r\le3$ gives $i^n=(i^4)^q\,i^r=i^r$. So $i^n$ is $1,i,-1,-i$ for $n\equiv0,1,2,3\pmod4$.

$2017\equiv1$, so $i^{2017}=\boxed{i}$. $2018\equiv2$ and $2019\equiv3$, so $i^{2018}+i^{2019}=\boxed{-1-i}$.
