Neither event occurs with probability $(1-0.7)(1-0.8)=0.3\cdot0.2=0.06$, by independence. So at least one occurs with probability $1-0.06=\boxed{0.94}$.

(Alternatively, by inclusion--exclusion: $0.7+0.8-0.7\cdot0.8=1.5-0.56=0.94$. Simply adding $0.7+0.8=1.5$ is wrong, because the outcomes where both events occur would be counted twice.)
