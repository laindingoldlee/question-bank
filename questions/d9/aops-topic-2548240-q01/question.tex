A sequence of positive integers with $2020$ terms is called an FT sequence if each term after the second is the sum of the previous two terms. For example, if the first two terms are $8$ and $7$, the sequence begins $8,7,15,22,37,\dots$. For some positive integer $m$, there are exactly $2415$ FT sequences whose first two terms are each less than $2m$ and in which the number of odd terms is more than twice the number of even terms. What is $m$?

$\textbf{(A) } 21 \qquad \textbf{(B) } 69 \qquad \textbf{(C) } 115 \qquad \textbf{(D) } 35 \qquad \textbf{(E) } 105$
