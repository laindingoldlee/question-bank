The prime digits are $2,3,5,7$. The first digit can be any of these $4$, and the last digit any of the other $3$. Each of the three middle digits can be any of the $10$ digits. So there are
\[
4\cdot3\cdot10^3=\boxed{12000}
\]
such numbers.
