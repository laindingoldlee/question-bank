Since $y$ and $35$ are positive, the two powers with the same exponent combine:
\[y^{\dfrac{x}{29}}\cdot35^{\dfrac{x}{29}}=(35y)^{\dfrac{x}{29}},\]
so the equation says $(35y)^{t}=1$ with $t=\dfrac{x}{29}>0$.

For a positive base $c$ and a positive exponent $t$, we have $c^t>1$ if $c>1$ and $c^t<1$ if $0<c<1$. So $c^t=1$ forces $c=1$. Hence $35y=1$, that is, $y=\dfrac{1}{35}$, and then $x=\dfrac{1}{y}=35$.

Check: $35y=1$ and $1^{\dfrac{35}{29}}=1$. The only solution is
\[\boxed{x=35,\quad y=\dfrac{1}{35}}.\]
(The number $29$ plays no role: any nonzero exponent gives the same answer.)
