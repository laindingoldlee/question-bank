If neither $p$ nor $q$ is three, their squares are one modulo three, forcing $r=3$, impossible since $p^2+2q^2\ge12>9$. If $p=3$ but $q\ne3$, then $r^2\equiv2\pmod3$, impossible. Thus $q=3$. If $p$ is odd, $p^2+18\equiv3\pmod8$, not a square; if $p=2$, it equals 22, also not square. There are $\boxed{0}$ triples, choice A.
