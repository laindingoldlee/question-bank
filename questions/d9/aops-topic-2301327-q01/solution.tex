There are $10\cdot10=100$ equally likely ordered outcomes. The sum is $12$ for the $9$ outcomes $(2,10)$, $(3,9)$, $(4,8)$, $(5,7)$, $(6,6)$, $(7,5)$, $(8,4)$, $(9,3)$, $(10,2)$ (a first card $1$ would need $11$, which is not a card). So the probability is $\boxed{\dfrac{9}{100}}$.
