Let the spacing be $d$ and number the points $1,2,\dots,n$. The segment joining points $i<j$ has length $(j-i)d$, and $j-i$ can be any of $1,2,\dots,n-1$ (for example $j-i=k$ for $i=1$, $j=k+1$). So there are exactly $\boxed{n-1}$ different lengths.
