The first differences are $6,24,42,60$ and the second differences are $18,18,18$, constant as they must be for a quadratic. Continuing, the next first difference is $60+18=78$, so
\[
f(6)=129+78=\boxed{207}.
\]
(Explicitly, $f(n)=9n^2-21n+9$, and $f(6)=324-126+9=207$.)
