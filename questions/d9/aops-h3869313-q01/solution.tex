The fiction count changes by $-36+15=-21$, while the nonfiction count changes by $36-24=12$. Their difference therefore decreases by $33$ books. This represents a decrease of six percentage points, so if the total is $T$,
\[
\dfrac{33}{T}=\dfrac{6}{100}.
\]
Thus the library contains $\boxed{550}$ books.
