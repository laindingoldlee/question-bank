The displacement is $(215-44,\,482-83)=(171,399)$. Since $171=3\cdot57$ and $399=7\cdot57$ with $\gcd(3,7)=1$, we have $\gcd(171,399)=57$.

The points of the segment are $(44+171t,\ 83+399t)$ for $0\le t\le1$. Such a point is a lattice point exactly when $171t$ and $399t$ are integers. If $t=\dfrac{k}{57}$ with $k$ an integer, then $171t=3k$ and $399t=7k$ are integers. Conversely, if both are integers then so is $399t-2\cdot171t=57t$, so $t=\dfrac{k}{57}$.

\begin{asy}
usepackage("amsmath");
size(3.5cm);
defaultpen(fontsize(10pt));
pair P=(0,0),Q=(3*1.2,7*1.2);
draw((-0.3,0)--(4.2,0),gray); draw((0,-0.3)--(0,9),gray);
draw(P--Q,blue+linewidth(1));
for(int k=0;k<=3;++k){ dot(P+k*(Q-P)/3); }
label("$(44,83)$",P,SW); label("$(215,482)$",Q,E);
label("$(44+3k,\ 83+7k)$",P+(Q-P)/3,E);
label("step $(3,7)$",P+1.5*(Q-P)/3,W);
\end{asy}

So the lattice points are $(44+3k,\ 83+7k)$ for $k=0,1,\dots,57$ (consecutive ones differ by the step $(3,7)$), and the bee pollinates $\boxed{58}$ flowers.
