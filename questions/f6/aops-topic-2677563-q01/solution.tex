Each day multiplies the price by $1+\dfrac{a_i}{100}$, so
\[p_{100}=\prod_{i=1}^{100}\left(1+\dfrac{a_i}{100}\right)=\prod_{k=1}^{100}\dfrac{100+k}{100}=\dfrac{200!}{100!\cdot100^{100}},\]
because multiplication is commutative and the $a_i$ are $1,\dots,100$ in some order. So $\boxed{\text{every permutation gives the same final price}}$, $\dfrac{200!}{100!\cdot100^{100}}$ dollars; none is greater than another.
