The weights add up to $1+2+\cdots+26=351$, so the $k$th letter has probability $\dfrac{k}{351}$. The letters $S$, $E$, $O$ are the $19$th, $5$th and $15$th, with probabilities $\dfrac{19}{351}$, $\dfrac{5}{351}$ and $\dfrac{15}{351}$.

Use inclusion-exclusion on the events ``$S$ never appears'', ``$E$ never appears'', ``$O$ never appears''. For example, $S$ never appears in $12$ independent rolls with probability $\left(\dfrac{351-19}{351}\right)^{12}$, and neither $S$ nor $E$ appears with probability $\left(\dfrac{351-24}{351}\right)^{12}$. So the probability that all three appear is
\[1-\dfrac{332^{12}+346^{12}+336^{12}}{351^{12}}+\dfrac{327^{12}+317^{12}+331^{12}}{351^{12}}-\dfrac{312^{12}}{351^{12}},\]
which equals
\[\boxed{\dfrac{20262934422841803612657100}{766363705802591889501432027}}\approx0.0264,\]
about $2.64\%$.
