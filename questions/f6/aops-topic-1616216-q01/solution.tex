The equation needs $x^2>1$. If $x<-1$, both terms on the left are negative, so the left side is negative and cannot equal $\sqrt8$. Hence $x>1$.

Put $p=x>0$ and $q=\dfrac{x}{\sqrt{x^2-1}}>0$. Then
\[
\dfrac{1}{p^2}+\dfrac{1}{q^2}=\dfrac{1}{x^2}+\dfrac{x^2-1}{x^2}=1 .
\]
By AM-GM, $1=\dfrac{1}{p^2}+\dfrac{1}{q^2}\ge\dfrac{2}{pq}$, so $pq\ge2$, and then $p+q\ge2\sqrt{pq}\ge2\sqrt2=\sqrt8$. The equation says that $p+q=\sqrt8$, so equality holds throughout, which forces $\dfrac{1}{p^2}=\dfrac{1}{q^2}$ and $p=q$; then $\dfrac{2}{p^2}=1$ and $p=\sqrt2$. So the only possible solution is
\[
x=\boxed{\sqrt2}.
\]
Check: $\sqrt2+\dfrac{\sqrt2}{\sqrt{2-1}}=2\sqrt2=\sqrt8$. (In fact $\sqrt8$ is the minimum value of the left side for $x>1$, reached only at $x=\sqrt2$.)
