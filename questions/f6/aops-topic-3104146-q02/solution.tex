Triangles $ ADC $ and $ BDC $ have the same base and altitude. Subtracting $ CDE $ shows $[BCE]=[ADE]=20 $. Triangles $ ADE,ABE $ have the same altitude to line $ BD $, so $\dfrac{DE}{BE}=\dfrac{20}{50}=\dfrac{2}{5}$. Similar triangles $ CDE,ABE $ then give $[CDE]=\left(\dfrac{2}{5}\right)^2(50)=8 $. Adding the four triangles gives $\boxed{98}$.
