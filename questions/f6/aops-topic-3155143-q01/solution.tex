An expression $(\sqrt a+\sqrt b)^2=a+b+2\sqrt{ab}$ has the required form. Matching terms suggests $ a+b=3 $, $ ab=2 $, solved by $ a=1,b=2 $. Since $ 1+\sqrt2>0 $, the principal root is $\boxed{1+\sqrt2}$. This is a useful substitution, not an obligatory one: naming the root $ x $ and solving with $ x\ge0 $ is equally valid.
