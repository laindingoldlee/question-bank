Let Joe's speed be $j$ miles per hour, so Sue's is $2.5j$. Then $j+2.5j=42$, so $j=12$ and Sue's speed is $30$. The new combined distance is
\[
\dfrac{1}{2}\cdot30+\dfrac{3}{2}\cdot12=15+18=\boxed{33}\text{ miles}.
\]
