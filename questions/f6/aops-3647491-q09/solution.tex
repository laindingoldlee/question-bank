If each side has length $s$ and the inradius is $r$, splitting into six triangles from the centre gives hexagon area $\dfrac{1}{2}r(6s)=3rs$. Since this equals $s>0$, $r=\dfrac{1}{3}$. The circle area is $\boxed{\dfrac{\pi}{9}}$. The argument does not require regularity.
\begin{asy}
import graph;import geometry;usepackage("amsmath");size(7cm);
path p;for(int k=0;k<6;++k)p=p--(2/sqrt(3)*dir(60*k));draw(p--cycle);draw(unitcircle);for(int k=0;k<6;++k)draw((0,0)--(2/sqrt(3)*dir(60*k)),dashed);label("$O$",(0,0),(0,-1));label("$r$",.5dir(30),(0,1));
\end{asy}
