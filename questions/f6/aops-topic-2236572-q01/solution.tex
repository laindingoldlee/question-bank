The key is that $13^3=2197=2194+3$, so $13^3\equiv3\pmod{2194}$. Since $64=3\cdot21+1$,
\[13^{64}=13\cdot\left(13^3\right)^{21}\equiv13\cdot3^{21}\pmod{2194}.\]
Next, $3^7=2187=2194-7$, so $3^7\equiv-7$ and
\[3^{21}=\left(3^7\right)^3\equiv(-7)^3=-343 .\]
Hence $13^{64}\equiv13\cdot(-343)=-4459\equiv-4459+3\cdot2194=2123\pmod{2194}$. The answer is $\boxed{\textbf{(E) } 2123}$.
