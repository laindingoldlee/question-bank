Three noncollinear points have a circumcircle, with centre $O$ and radius $R>0$. Write its disk test as $F(X)=|X|^2-2O\cdot X+|O|^2-R^2$. At the three points, $F=0$. Any sufficiently small prescribed changes to these three values can be obtained by changing the two coordinates of $O$ and the constant term: the corresponding three-by-three affine interpolation matrix is invertible because the points are noncollinear. The resulting radius remains positive. Prescribe negative values for the chosen points and positive values for the others, obtaining exactly the desired subset. For four points $P_i$ in the plane, there are real coefficients $\lambda_i$, not all zero, with $\sum\lambda_i=0$ and $\sum\lambda_iP_i=0$. No three collinear ensures every coefficient is nonzero, and both signs occur. For every disk test $F$, $\sum\lambda_iF(P_i)=\sum\lambda_i|P_i|^2=K$, independent of the disk. If $K\ge0$, requiring the positive-coefficient points strictly inside and the negative-coefficient points strictly outside would make this sum negative, impossible. If $K<0$, reverse that assignment to make it positive, again impossible. Thus every three noncollinear points can be shattered by disks, but no such four-point set can; the largest number is $\boxed3$.
