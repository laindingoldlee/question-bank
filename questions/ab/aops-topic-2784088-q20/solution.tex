We need $\sqrt{40b}$ rational, hence an integer, so $40b=4\cdot10b$ is a perfect square and $b=10m^2$. Then $H=\dfrac{40+20m+10m^2}3=\dfrac{10(m+1)^2+30}3$, an integer iff $3\mid(m+1)^2$, i.e. $m\equiv2\pmod3$. $b>40$ needs $m\ge3$, so $m=5$ and $b=\boxed{250}$ (with $H=\dfrac{40+100+250}3=130$).
