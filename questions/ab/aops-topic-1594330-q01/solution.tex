Let the smaller number be $n=\overline{htu}$ (digits $h,t,u$ with $h\ge1$); the pair is $n$ and $n+9$, with $n+9\le999$. Adding $9$ means adding $10$ and subtracting $1$.

\textbf{Case $u=0$.} Then $n+9=\overline{ht9}$: the digit $0$ is replaced by $9$, so the digits differ.

\textbf{Case $u\ge1$, $t=9$.} Then $n+9=\overline{(h+1)\,0\,(u-1)}$ (and $h\le8$). The digit $9$ of $n$ would have to appear in $n+9$, so $h+1=9$ (as $u-1\le8$), and then the multisets $\{8,9,u\}$ and $\{9,0,u-1\}$ would need $\{8,u\}=\{0,u-1\}$, which is impossible ($u=0$ is excluded and $u-1=8$ forces $u=9\ne0$). No pairs.

\textbf{Case $u\ge1$, $t\le8$.} Then $n+9=\overline{h\,(t+1)\,(u-1)}$. The multisets $\{h,t,u\}$ and $\{h,t+1,u-1\}$ agree exactly when $\{t,u\}=\{t+1,u-1\}$, i.e.\ when $u=t+1$. So $n=\overline{h\,t\,(t+1)}$ with $0\le t\le8$.

\textbf{Divisibility by $9$.} We need $9\mid h+2t+1$. For each $t=0,1,\dots,8$, exactly one digit $h\in\{1,\dots,9\}$ satisfies $h\equiv8-2t\pmod9$, because $1,\dots,9$ is a complete set of residues modulo $9$. Each of these $n$ is at most $945$, so $n+9\le999$ always holds. This gives the $9$ pairs
\[
(801,810),\ (612,621),\ (423,432),\ (234,243),\ (945,954),\ (756,765),\ (567,576),\ (378,387),\ (189,198)
\]
for $t=0,1,\dots,8$. The answer is $\boxed{9}$.
