Write the contents of the $10$-, $7$- and $3$-litre containers as a triple. One possible sequence of pourings is
\[
(10,0,0)\to(3,7,0)\to(3,4,3)\to(6,4,0)\to(6,1,3)\to(9,1,0)\to(9,0,1)\to(2,7,1)\to(2,5,3)\to(5,5,0).
\]
In words:
\begin{enumerate}
\item fill the $7$ from the $10$;
\item fill the $3$ from the $7$ (the $7$ now holds $4$);
\item empty the $3$ into the $10$;
\item fill the $3$ from the $7$ again (the $7$ now holds $1$);
\item empty the $3$ into the $10$ (which now holds $9$);
\item pour the $1$ litre from the $7$ into the $3$;
\item fill the $7$ from the $10$ (the $10$ now holds $2$);
\item fill the $3$ from the $7$, which needs $2$ litres, so the $7$ now holds $\boxed{5}$ litres;
\item empty the $3$ into the $10$, which now holds $2+3=5$ litres.
\end{enumerate}
Each pour either empties the source or fills the receiver, and no milk leaves the containers, so the two portions of $5$ litres are exact. After $8$ pourings the $7$-litre container already holds exactly $5$ litres; the ninth pouring leaves $5$ litres in the $10$-litre container as well. (An exhaustive search of all reachable states shows that $9$ pourings is the fewest possible for the $5+5$ split.)
