If $2n-1\mid n+1$ then $2n-1\mid2(n+1)-(2n-1)=3$. So $2n-1\in\{\pm1,\pm3\}$, giving $n\in\{1,0,2,-1\}$. Checking: $\dfrac21=2$, $\dfrac1{-1}=-1$, $\dfrac33=1$, $\dfrac0{-3}=0$. All work, so $n\in\boxed{\{-1,0,1,2\}}$.
