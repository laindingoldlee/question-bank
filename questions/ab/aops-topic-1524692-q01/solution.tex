Block $n$ consists of $n$ copies of each of $1,2,\dots,n$, so it has $n^2$ terms. The first $m$ blocks contain
\[
1^2+2^2+\cdots+m^2=\dfrac{m(m+1)(2m+1)}{6}
\]
terms. For $m=17$ this is $\dfrac{17\cdot18\cdot35}{6}=1785$, and for $m=18$ it is $2109$. So the $2014$th term is term number $2014-1785=229$ of block $18$.

Block $18$ is eighteen $1$'s, eighteen $2$'s, and so on. Since $12\cdot18=216<229\le13\cdot18=234$, term $229$ of the block is a $\boxed{13}$.
