The domain requires $n\ge3$. Set $t=\sqrt{n-3}\ge0$. Then $\sqrt{2t^2+1}=1-t$, requiring $t\le1$. Squaring gives $2t^2+1=1-2t+t^2$, or $t(t+2)=0$. The only nonnegative possibility is $t=0$, hence $n=3$. Substitution verifies it, so $\boxed{n=3}$.
