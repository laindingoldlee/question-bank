Grogg is building snowmen. He is only happy if each snowman he builds uses twice as much snow as either the snowman before it or the snowman before that. The first two snowmen each used $1$ cubic foot of snow. How many different possibilities are there for the number of cubic feet of snow Grogg uses for the $10$th snowman? How about the $100$th snowman?
