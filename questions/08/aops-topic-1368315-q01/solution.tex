The number is a little less than $10^8=10000^2$, so try $(10000-k)^2=10^8-20000k+k^2$. We need
\[20000k-k^2=10^8-99\,920\,016=79\,984 .\]
Since $20000\cdot4=80000$ and $80000-16=79984$, $k=4$ works. So
\[\sqrt{99\,920\,016}=\boxed{9996},\]
as $9996^2=10^8-80000+16=99\,920\,016$.
