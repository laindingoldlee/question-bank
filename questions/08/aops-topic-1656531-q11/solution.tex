Simulate, writing the set of lights that are on after each second:
\[
\begin{array}{c|ccccccc}
\text{second}&0&1&2&3&4&5&6\\\hline
\text{on}&\{1,2,3,4\}&\{2,3,4\}&\{3,4\}&\varnothing&\{4\}&\{3,4\}&\{1,2,3,4\}
\end{array}
\]
(At second $2$ the count fell from $3$ to $2$, so at second $3$ both are switched off; at second $5$ it rose from $1$ to $2$, so at second $6$ all are switched on.) After $6$ seconds the initial state returns, with the same history, so the pattern has period $6$. Since $2018=6\cdot336+2$, the state after second $2018$ is the state after second $2$: lights $\boxed{\textbf{(b)}\ 3,4}$.
