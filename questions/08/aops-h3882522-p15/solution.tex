Here $a,b,c\in\{1,\ldots,9\}$ and $d,e\in\{0,\ldots,9\}$. An exhaustive digit count can be done in three short stages: keep $(a,b,c)$ only when $100a+10b+c\equiv0\pmod7$; keep $d$ only when $100b+10c+d\equiv0\pmod8$; then keep $e$ only when $100c+10d+e\equiv0\pmod9$.

For each first digit, this gives
\[
\begin{array}{c|rrrrrrrrr}
a&1&2&3&4&5&6&7&8&9\\\hline
\text{count}&17&15&15&15&16&15&15&17&15
\end{array}
\]
Every admissible integer is generated once by its five digits, so the sum is $\boxed{140}$.
