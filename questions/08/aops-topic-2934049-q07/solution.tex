If the distance is $D$, the planned time is $D$ seconds. The initial walk takes $\dfrac{D}{2}$ and the return $\dfrac{D}{4}$, leaving $\dfrac{D}{4}$. Covering the whole distance in that time requires $\boxed{4\text{ metres per second}}$.
