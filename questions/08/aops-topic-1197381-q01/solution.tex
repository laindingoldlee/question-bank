\textbf{(a)} We need $x+1\ge0$, and then the denominator is at least $3$, so it is never $0$. The domain is $[-1,\infty)$.

As $x$ runs over $[-1,\infty)$, $\sqrt{x+1}$ takes every value in $[0,\infty)$, so the denominator takes every value in $[3,\infty)$ and $f$ takes every value in $\left(0,\dfrac{1}{3}\right]$. The range is $\boxed{\left(0,\dfrac{1}{3}\right]}$, with the maximum $\dfrac{1}{3}$ at $x=-1$.

\textbf{(b)} Multiplying the numerator and denominator by $\sqrt{x+1}-3$ is allowed only where this factor is nonzero, and it is zero exactly at $x=8$. So the new expression equals $f(x)$ only for $x\ne8$; at $x=8$ it becomes $\dfrac{0}{0}$, while $f$ itself is perfectly defined, with $f(8)=\dfrac{1}{3+3}=\dfrac{1}{6}$. The domain must be read from the original expression; the rewriting introduced a removable gap that was not in $f$.
