The sum of the three absolute differences equals twice the maximum minus twice the minimum. Thus the range is $4$. Choose the minimum $m\in\{1,2,3,4\}$; the maximum is $m+4$. For each $m$, triples using only these extremes have $2^3-2=6$ orders. If the third value is strictly intermediate, it has three choices and the three distinct values have $6$ orders, giving $18$ more. Total: $4(6+18)=\boxed{96}$.
