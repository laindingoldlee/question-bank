If there are $k$ diagonal steps, there must be $6-k$ horizontal and $6-k$ vertical steps, making $12-k$ steps total. Their orders number $\dfrac{(12-k)!}{(6-k)!^2k!}$. Sum over $k=0,\ldots,6$ to get $\boxed{8989}$. The cases are disjoint and every path has exactly one such diagonal-step count.
\begin{verbatim}
from math import factorial as f
assert sum(f(12-k)//(f(6-k)**2*f(k)) for k in range(7))==8989
\end{verbatim}
\begin{asy}
usepackage("amsmath");
size(7cm);
for(int i=0;i<=6;++i){draw((0,i)--(6,i),gray);draw((i,0)--(i,6),gray);}draw((0,0)--(1,1)--(2,1)--(3,2)--(3,3)--(4,4)--(5,5)--(6,6),blue+linewidth(1.2));label("$(0,0)$",(0,0),SW);label("$(6,6)$",(6,6),NE);
\end{asy}
