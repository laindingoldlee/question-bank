Relabel the columns so that the rooks stand on the main diagonal, at squares $(i,i)$. For each pair $i<j$, swap the columns of rooks $i$ and $j$: rooks at $(i,j)$ and $(j,i)$, the others unchanged. This gives $\dbinom82=28$ new non-attacking arrangements.

Each uses exactly two off-diagonal squares, $(i,j)$ and $(j,i)$, and different pairs use disjoint squares. A red square lies off the diagonal, so it spoils at most one of the $28$ arrangements. With only $27$ red squares, some arrangement contains no red square. $\blacksquare$
