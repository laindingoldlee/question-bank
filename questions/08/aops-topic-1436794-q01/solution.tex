We have $1^2+\cdots+k^2=\dfrac{k(k+1)(2k+1)}{6}$, so we need $240=2^4\cdot3\cdot5$ to divide $k(k+1)(2k+1)$. The factor $3$ always divides it (the sum is an integer, so $6$ divides $k(k+1)(2k+1)$). So we need:
\begin{itemize}
\item $16\mid k(k+1)(2k+1)$: since $2k+1$ is odd and only one of $k$, $k+1$ is even, this means $16\mid k$ or $16\mid k+1$, that is, $k\equiv0$ or $15\pmod{16}$.
\item $5\mid k(k+1)(2k+1)$: $k\equiv0$, $4$ or $2\pmod5$ (the last one from $5\mid2k+1$).
\end{itemize}
The smallest $k$ with $k\equiv0$ or $15\pmod{16}$ are $15, 16, 31, 32,\dots$, and $15\equiv0\pmod5$ already works. So $k=\boxed{15}$; indeed $1^2+\cdots+15^2=1240=40\cdot31$.
