For a number $a\ge0$, the symbol $\sqrt a$ is \emph{defined} as the non-negative number whose square is $a$ (the principal square root). This makes $\sqrt{\phantom{a}}$ a function: each input has exactly one output. Both $5$ and $-5$ square to $25$, but only $5$ is non-negative, so $\sqrt{25}=\boxed{5}$.

The equation $x^2=25$ asks for \emph{all} numbers whose square is $25$, so it has two solutions: $x=\sqrt{25}=5$ or $x=-\sqrt{25}=-5$, written $\boxed{x=\pm5}$. The sign $\pm$ comes from solving the equation, not from the square root symbol.

Finally, $\sqrt{x^2}$ is the non-negative number whose square is $x^2$, which is $\boxed{|x|}$; for example $\sqrt{(-5)^2}=\sqrt{25}=5=|-5|$.
