For cyclic entries $a_i$, define $s_i=a_i+a_{i+3}-a_{i+1}-a_{i+2}$. The six values sum to zero. If none were positive, all would be zero. Setting $d_i=a_i-a_{i+1}$, these equalities give $d_i=d_{i+2}$, so the differences alternate p,q. Their cyclic sum is $3(p+q)=0$, hence $a_i-a_{i+2}=p+q=0$, contradicting distinct entries. Therefore some s is positive in every arrangement, and the probability is $\boxed1$.
