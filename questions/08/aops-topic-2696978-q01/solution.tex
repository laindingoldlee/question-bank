Every positive odd integer is a positive integer, so $\mathbb O\subseteq\mathbb Z^+$, and $2\in\mathbb Z^+\setminus\mathbb O$, so $\mathbb O\ne\mathbb Z^+$. The map $n\mapsto2n-1$ from $\mathbb Z^+$ to $\mathbb O$ is a bijection (its inverse is $m\mapsto\dfrac{m+1}{2}$). So the sets have the same cardinality even though one is a proper subset of the other, which is possible only for infinite sets. $\blacksquare$
