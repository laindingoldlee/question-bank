One expression is
\[\boxed{9+\dfrac{\left(\sqrt9\right)!}{\sqrt9}}=9+\dfrac{3!}{3}=9+\dfrac{6}{3}=11.\]
It uses exactly three $9$s and only a square root, a factorial, a division and an addition.

(Other answers are possible, for example $\left(\sqrt9\right)!+\left(\sqrt9\right)!-\dfrac{\sqrt9}{\sqrt9}$ would also give $11$, but it uses four $9$s; any expression obeying the rules is correct.)
