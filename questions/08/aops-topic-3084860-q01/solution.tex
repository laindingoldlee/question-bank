For one item, the sandwich and salad options are disjoint alternatives, so add: $ 3+2=\boxed5 $. For a pair, each of three sandwich choices can be combined with either salad, so multiply: $ 3\cdot2=\boxed6 $. Addition counts disjoint alternatives; multiplication counts successive choices with a fixed number of continuations.
