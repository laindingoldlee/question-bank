If $x>\dfrac{3}{2}$, the base is positive. A positive-base power equals $1$ exactly when the base is $1$ or the exponent is zero. These give $x=2$ and $x=7$. The zero base occurs at $x=\dfrac{3}{2}$, with negative exponent, so it is excluded. If $x<\dfrac{3}{2}$, a defined power requires integer exponent. For a negative base to have value $1$, its absolute value must be $1$ and the exponent must be even. Thus $2x-3=-1$, giving $x=1$, with exponent $-6$, which works. The solutions are $\boxed{1,2,7}$.
