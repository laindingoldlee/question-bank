The letters have the values $a=10$, $d=13$, $g=16$, $j=19$ and $m=22$. So the digit sum is
\[4+2+16+13+7+6+19+22+5+10+13=117 .\]
Since $117=7\cdot16+5$, in hexadecimal this is
\[\boxed{75_{16}}.\]
