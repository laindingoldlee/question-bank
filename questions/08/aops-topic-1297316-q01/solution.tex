We need $2x>0$, $2x\ne1$, and $(2x)^x=216=6^3$. Then $x=3$ works: $6^3=216$.

It is the only solution. For $0<x<\dfrac{1}{2}$, $(2x)^x<1$. For $x>\dfrac{1}{2}$, $g(x)=x\ln(2x)$ has $g'(x)=\ln(2x)+1>0$, so $(2x)^x$ is increasing and takes the value $216$ only once. Hence $x=\boxed{3}$.
