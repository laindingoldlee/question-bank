By symmetry, first search $\binom nk$ with $k\le\dfrac{n}{2}$. If $k\ge7$, then $\binom nk\ge\binom{14}{7}=3432$, so only $k=1,\ldots,6$ need checking. For fixed $k$ the values increase strictly with $n$. We find $\binom{3003}{1}=3003$, $\binom{78}{2}=3003$, $\binom{15}{5}=3003$, and $\binom{14}{6}=3003$. For $k=3$, adjacent values $\binom{27}{3}=2925$ and $\binom{28}{3}=3276$ bracket the target; for $k=4$, $\binom{17}{4}=2380$ and $\binom{18}{4}=3060$ bracket it. Each of the four matches is off the center and has a distinct symmetric partner. Thus the total is $\boxed8$.
