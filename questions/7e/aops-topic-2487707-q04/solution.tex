The sine function is continuous, so the limit equals the value of the function at $\pi$:
\[\lim_{x\to\pi}\sin x=\sin\pi=\boxed{0}.\]

\begin{asy}
usepackage("amsmath");
size(5cm);
defaultpen(fontsize(10pt));
import graph;
real k=1.2;
draw((0.8,0)--(5.6,0),Arrow(4));
draw(graph(new pair(real x){return (x,k*sin(x));},1.1,5.2),blue+linewidth(0.9));
dot((pi,0),red); label("$(\pi,0)$",(pi,0),NE,red+fontsize(8pt));
label("$\dfrac{\pi}{2}$",(pi/2,0),S,fontsize(8pt)); label("$\dfrac{3\pi}{2}$",(3pi/2,0),N,fontsize(8pt));
draw((pi/2,-0.05)--(pi/2,0.05)); draw((3pi/2,-0.05)--(3pi/2,0.05));
label("$y=\sin x$",(1.6,k*sin(1.6)),N,blue+fontsize(8pt));
\end{asy}

(As $x$ approaches $\pi$ from either side, the graph approaches the point $(\pi,0)$.)
