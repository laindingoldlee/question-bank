$a=1$ works: $\sqrt[1]1=1$. For $a\ge2$, $\sqrt[a]a>1$; and $\sqrt[a]a<2$ because $a<2^a$. So $\sqrt[a]a$ is strictly between $1$ and $2$ and is not an integer. The only answer is $\boxed{a=1}$.
