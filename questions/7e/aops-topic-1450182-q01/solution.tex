\textbf{Upper bound.} Fix a person $X$. In each game $X$ plays with $3$ other people, and $X$ never plays twice with the same person. There are only $11$ other people, so $X$ plays in at most $\left\lfloor\dfrac{11}{3}\right\rfloor=3$ games. Counting (person, game) pairs, $4g\le12\cdot3=36$, so the number of games is $g\le9$.

\textbf{Construction.} Number the people $1,\dots,12$. The $9$ games
\[
\begin{array}{lll}
\{1,2,3,4\}, & \{1,5,6,7\}, & \{1,8,9,10\},\\
\{2,5,8,11\}, & \{2,6,9,12\}, & \{3,5,10,12\},\\
\{3,7,9,11\}, & \{4,6,10,11\}, & \{4,7,8,12\}
\end{array}
\]
never put two people together twice: each game contains $6$ pairs, the $54$ pairs listed are all different (this is checked directly: for instance person $1$ meets $2,\dots,10$, each once, and never meets $11$ or $12$).

So the maximum number of games is $\boxed{9}$. (Only $54$ of the $66$ pairs ever meet; the bound $\dfrac{66}{6}=11$ from counting pairs alone is not attainable.)
