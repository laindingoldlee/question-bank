Put $u=x+\dfrac{1}{x}\ge2$. The equation is $u^2+u-1=10$, so its only admissible root is $u=\dfrac{-1+3\sqrt5}{2}$. Thus there is one distinct requested value, $\boxed{\dfrac{1+3\sqrt5}{2}}$. It is attainable since every $u\ge2$ equals $x+\dfrac{1}{x}$ for some positive $x$.
