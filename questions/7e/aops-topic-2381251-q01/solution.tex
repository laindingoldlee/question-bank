\textbf{(a)} Write $x=\dfrac pq$ with integers $p$ and $q\ge1$, and let $s=n^{\dfrac1q}>0$. Then $n^x=s^p$, and there are three cases:
\begin{itemize}
\item $p>0$: $s^p=s\cdot s\cdots s$ ($p$ factors) is a product of positive numbers, so it is positive;
\item $p=0$: $s^0=1>0$;
\item $p<0$: $s^p=\dfrac1{s^{-p}}$, and $s^{-p}>0$ by the first case, so its reciprocal is positive.
\end{itemize}
So $n^x>0$. (The poster's argument ``$n$ repeated $x$ times'' only makes sense when $x$ is a positive integer, which is why the root $s$ is needed.)

\textbf{(b)} For rational $x$ this is (a), and $1^x=1>0$. Let $n\ge2$ and $x$ irrational, and let $m=\lfloor x\rfloor$, an integer with $m<x$. Then $m$ is one of the rationals $r<x$, so $n^m$ belongs to the set whose least upper bound is $n^x$. An upper bound of a set is at least each of its elements, hence
\[n^x\ge n^m>0\]
by (a). So $n^x>0$ for every real $x$. $\blacksquare$
