No digit is zero, because the sum is positive. To minimize the number, maximize the initial run of ones and sort remaining digits increasingly. Five ones and a last digit $d$ would require $5+d=d$, impossible. Four ones and last digits $b\le c$ require $4+b+c=bc$, or $(b-1)(c-1)=5$. Thus $b=2,c=6$, producing $\boxed{111126}$. Every number with fewer than four leading ones is larger.
