A website gives the following formula for the median of a data set of $n$ values written in increasing order as $X[1]\le X[2]\le\cdots\le X[n]$:
\[\mathrm{Med}(X)=\begin{cases}X\left[\dfrac n2\right]&\text{if }n\text{ is even,}\\[2ex]\dfrac{X\left[\dfrac{n-1}{2}\right]+X\left[\dfrac{n+1}{2}\right]}{2}&\text{if }n\text{ is odd.}\end{cases}\]
(a) Show that the formula gives the wrong median for the data sets $1,2,3$ and $1,2,3,4$. (b) Write a correct formula.
