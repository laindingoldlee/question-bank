First number the seats $1,\dots,k$. Seating the people one at a time, there are
\[
k(k-1)\cdots(k-n+1)=\dfrac{k!}{(k-n)!}
\]
seatings.

Now group the seatings into rotation classes. Rotating the table through $1,2,\dots,k-1$ seats never gives back the same seating (a person would have to stay in place, which only the identity rotation allows, since $n\ge1$). So every class contains exactly $k$ seatings, and the number of arrangements is
\[
\dfrac{k!}{k\,(k-n)!}=\boxed{\dfrac{(k-1)!}{(k-n)!}}.
\]
For $n=5$, $k=7$ this gives $\dfrac{6!}{2!}=360$; for $n=k$ it gives the familiar $(n-1)!$.
