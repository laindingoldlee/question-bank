The first powers of $2$ modulo $7$ are
\[2^0=1,\qquad 2^1=2,\qquad 2^2=4,\qquad 2^3=8\equiv1\pmod7 .\]
Write $k=3q+r$ with $r\in\{0,1,2\}$. Then
\[2^k=\left(2^3\right)^q\cdot2^r\equiv1^q\cdot2^r=2^r\pmod7,\]
and $2^r$ is $1$, $2$ or $4$ for $r=0,1,2$. So $2^k\equiv1\pmod7$ exactly when $r=0$:
\[\boxed{2^k\equiv1\pmod7\iff k\text{ is a multiple of }3.}\]
(In other words, the order of $2$ modulo $7$ is $3$, and the powers of $2$ repeat with period $3$: $1,2,4,1,2,4,\dots$)

\emph{Remark.} If negative exponents are allowed, with $2^{-1}$ meaning the inverse of $2$ modulo $7$ (which is $4$, since $2\cdot4=8\equiv1$), the same answer holds for all integers $k$, because $2^{-3}$ is the inverse of $2^3\equiv1$, which is again $1$.
