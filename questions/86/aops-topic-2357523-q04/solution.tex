If $n=p_1^{e_1}p_2^{e_2}\cdots p_k^{e_k}$, then $n$ has $(e_1+1)(e_2+1)\cdots(e_k+1)$ divisors. Since $13$ is prime, this product equals $13$ only for one prime with $e_1=12$: $n=p^{12}$. The smallest such number is $2^{12}=\boxed{4096}$.
