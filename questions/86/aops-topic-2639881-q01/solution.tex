Suppose $(-1)^p3^{\dfrac pq}=3$. The right side is positive, so $p$ is even. Then $3^{\dfrac pq}=3$ forces $\dfrac pq=1$, i.e. $p=q$; but $q$ is odd and $p$ is even, a contradiction. So $\boxed{\text{no such }r}$ exists. $\blacksquare$

So although $9=(-3)^2$ has a ``base $-3$ logarithm'', the positive number $3$ has none. The function $r\mapsto(-3)^r$ is defined only for some rational exponents, its values alternate in sign, and it misses many positive numbers. It therefore has no inverse defined on all positive reals, which is why a logarithm base is required to be positive (and different from $1$).
