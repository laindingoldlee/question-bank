A student claims that $\log_{-3}9=2$, because $(-3)^2=9$. For a rational number $r=\dfrac pq$ in lowest terms with $q>0$ odd, the power $(-3)^r$ can be defined as a real number by
\[(-3)^r=\left(\sqrt[q]{-3}\right)^p=(-1)^p\,3^r,\]
while for other exponents, such as $r=\dfrac12$, no real value is available. Show that no exponent $r$ of this kind satisfies $(-3)^r=3$, and explain why logarithms with base $-3$ are not defined.
