Here $\sqrt{-5}=i\sqrt5$, so $x=a+bi\sqrt5$ is a complex number with $|x|^2=a^2+5b^2$, a nonnegative integer. If $xy=1$ with $x,y\in X$, then
\[|x|^2\,|y|^2=|xy|^2=1,\]
a product of two positive integers equal to $1$. So $a^2+5b^2=1$, which forces $b=0$ and $a=\pm1$. Conversely $1\cdot1=1$ and $(-1)(-1)=1$. So the special elements are $\pm1$: there are $2$, answer $\boxed{\textbf{(A) } 2}$.
