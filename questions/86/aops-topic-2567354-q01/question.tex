Let $X=\left\{a+b\sqrt{-5}\ :\ a,b\in\mathbb Z\right\}$. An element $x\in X$ is called \emph{special} if there is $y\in X$ with $xy=1$. How many special elements does $X$ have?

$\textbf{(A) } 2\qquad\textbf{(B) } 4\qquad\textbf{(C) } 6\qquad\textbf{(D) } 8$
