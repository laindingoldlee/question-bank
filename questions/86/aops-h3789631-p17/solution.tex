Let $K$ be the number of knaves. If any knight is present, that knight sees exactly $K$ knaves, so $K=2$. The two knaves each see one knave and lie, while the other $2016$ guests tell the truth. A second consistent case is that all $2018$ guests are knaves: each sees $2017$ knaves and makes a false claim. No other case is possible, so the possible truth-teller counts are $\boxed{0\text{ or }2016}$.
