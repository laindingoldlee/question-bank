Cat uses each of the digits $0$ through $9$ exactly once to write four positive integers: a $1$-digit integer, a $2$-digit integer, a $3$-digit integer and a $4$-digit integer (none with a leading zero). Each of the four integers is divisible by $9$. What is the greatest possible value of the $4$-digit integer?
