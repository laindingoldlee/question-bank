Write the sum as $\sum_{k=1}^{1009}(2019-k)k!\equiv-\sum_{k=1}^{1009}k\,k!\pmod{2019}$. Since $k\,k!=(k+1)!-k!$, this telescopes to $1-1010!$. Now $2019=3\cdot673$ divides $1010!$, so the remainder is $\boxed1$.
