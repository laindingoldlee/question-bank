The equation $n=0k$ holds exactly when $n=0$. Thus $\boxed{0\mid n\iff n=0}$. In particular $0\mid0$ under this divisibility definition. This existential assertion does not define a quotient: when $n=0$, every integer $k$ works, so there is no unique value of $\dfrac{0}{0}$.
