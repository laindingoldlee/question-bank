The expression is $1280+2^n$. For $0\le n<8$, it lies between $1281$ and $1408$. The only squares in this interval are $36^2=1296$ and $37^2=1369$; their differences from $1280$ are $16$ and $89$, respectively, so only $n=4$ works. For $n\ge8$, factor as $2^8(5+2^{n-8})$. Since $2^8$ is itself a square, we need $5+2^m$ square with $m=n-8\ge0$. For $m=0,1,2$ the values are $6,7,9$, so only $m=2$ works. For $m\ge3$, the value is $5$ modulo $8$, impossible for a square. Thus $\boxed{n=4,10}$.
