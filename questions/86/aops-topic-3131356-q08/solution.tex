Each deck has $ 4\cdot5+4\cdot10+4\cdot10=100 $ points, so the total is 200. A score $ s $ wins when $ s\ge\dfrac{3}{2}(200-s)$, giving $ s\ge120 $. The score 120 is attainable by taking twelve 10-point cards, so the answer is $\boxed{120}$.
