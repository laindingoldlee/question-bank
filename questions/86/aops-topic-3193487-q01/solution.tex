One construction for each target is: $1=(3-3)!^3$; $2=(3+3)\div3$; $3=3+3-3$; $4=3!-3!\div3$; $5=3!-3\div3$; $6=3\cdot3-3$; $7=3!+3\div3$; $8=3!+3!\div3$; $9=3+3+3$. Each uses exactly three written $3$s and evaluates to its stated target.
