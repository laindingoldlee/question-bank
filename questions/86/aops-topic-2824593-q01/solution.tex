(a) $P(\max\le j)=\dfrac{j^2}{x^2}$, so $P(\max=j)=\dfrac{j^2-(j-1)^2}{x^2}=\dfrac{2j-1}{x^2}$. Then
\[E=\dfrac1{x^2}\sum_{j=1}^x j(2j-1)=\dfrac1{x^2}\left(\dfrac{x(x+1)(2x+1)}3-\dfrac{x(x+1)}2\right)=\dfrac{(x+1)(4x-1)}{6x}.\]

(b) $P(\max\le t)=t^k$ for $0\le t\le1$, so $E[\max]=\displaystyle\int_0^1P(\max>t)\,dt=\int_0^1(1-t^k)\,dt=1-\dfrac1{k+1}=\boxed{\dfrac k{k+1}}$. (This matches (a): $\dfrac1x E\to\dfrac23$ as $x\to\infty$.) $\blacksquare$
