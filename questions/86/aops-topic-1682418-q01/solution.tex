The units digit of a product depends only on the units digits of the factors, so $123^{123}$ has the same units digit as $3^{123}$. The units digits of the powers of $3$ repeat with period $4$:
\[3^1\to3,\quad 3^2\to9,\quad 3^3\to7,\quad 3^4\to1,\quad 3^5\to3,\ \dots\]
Since $123=4\cdot30+3$, the units digit of $3^{123}$ is the same as that of $3^3=27$, namely $\boxed{7}$.

The answer $1$ is wrong: the units digit is $1$ only when the exponent is a multiple of $4$.
