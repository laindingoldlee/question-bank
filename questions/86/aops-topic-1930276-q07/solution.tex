A number containing all ten digits has at least $10$ digits. A $10$-digit such number uses each digit exactly once, so its digit sum is $45$ and it is divisible by $9$. It is divisible by $36$ exactly when it is also divisible by $4$, i.e.\ when its last two digits form a multiple of $4$. So the answer is the least $10$-digit number using every digit once whose last two digits form a multiple of $4$ (such numbers exist, and they are smaller than any number with $11$ or more digits).

For numbers with the same number of digits, comparing size means comparing digits from the left. The smallest possible start is $1,0,2,3,4,5$ followed by the digits $6,7,8,9$ in some order.
\begin{itemize}
\item If the seventh digit is $6$, the last two digits come from $7,8,9$: $78,79,87,89,97,98$, none a multiple of $4$.
\item With seventh digit $7$, the remaining digits $6,8,9$ in the order $8,9,6$ end in $96=4\cdot24$, while the smaller orders $6,8,9$, $6,9,8$ and $8,6,9$ end in $89$, $98$ and $69$.
\end{itemize}
Since a valid number with the smallest possible start $102345$ exists, the answer has this start.
Hence the least such number is $\boxed{1023457896}$. (Check: $1023457896=36\cdot28429386$.)
