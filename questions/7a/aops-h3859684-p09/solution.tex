Put $k=\lfloor x\rfloor$. For $k=0$, the equation forces $x=0$. For $k\ge1$, division by $k^2$ shows $t=\dfrac{x}{k}$ solves $t^2-2025t+2025=0$. The larger root exceeds $2$, whereas $x<k+1\le2k$, so only $\alpha=\dfrac{2025-\sqrt{4092525}}{2}$ is possible. We need $k(\alpha-1)<1$. Rationalization gives $\dfrac{1}{\alpha-1}=\dfrac{2023+\sqrt{4092525}}{2}$. Since $2021^2<4092525<2023^2$ and more precisely $2021<\sqrt{4092525}<2023$, the threshold lies strictly between $2022$ and $2023$. Thus $k=1,\ldots,2022$ each gives one solution, in addition to zero: $\boxed{2023}$.
