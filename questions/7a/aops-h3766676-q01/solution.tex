Alice first covers the top cells in columns $2,3$. Bob can now play only in column $1$ or $4$. If he chooses column $1$, Alice covers the bottom cells in columns $3,4$; if he chooses column $4$, she covers the bottom cells in columns $1,2$. In either case every column contains an occupied cell, so Bob has no vertical move and loses.
