For $x<0$ the sum exceeds $119$, so consider $x\ge0$. This is a convex piecewise-linear function with breakpoints $\dfrac{1}{k}$. The total of the weights $k$ is $7140$. A minimum occurs when weights on either side of a breakpoint are each at most $3570$. Since $\sum_{k=1}^{83}k=3486<3570$ and $\sum_{k=1}^{84}k=3570$, the function is constant between $\dfrac{1}{85}$ and $\dfrac{1}{84}$. At $x = \dfrac{1}{84}$ its value is $\sum_{k=1}^{84} (1 - \dfrac{k}{84}) + \sum_{k=85}^{119} (\dfrac{k}{84} - 1) = 84 - \dfrac{3570}{84} + \dfrac{3570}{84} - 35 = \boxed{49}$. Convexity ensures this is the global minimum.
