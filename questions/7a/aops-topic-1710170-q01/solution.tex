\textbf{(a)} $f\bigl(2x-g(x)\bigr)=3\bigl(2x-g(x)\bigr)-2=6x-3g(x)-2$. Setting this equal to $-3(1+2m)x+34$:
\[
3g(x)=6x+3x+6mx-36\quad\Longrightarrow\quad \boxed{g(x)=(2m+3)x-12}.
\]

\textbf{(b)} The equation becomes $(2m+3)x-12=4(m-1)x-4m-4$, i.e.
\[
(2m+3-4m+4)x=12-4m-4\quad\Longrightarrow\quad (7-2m)x=8-4m .
\]
\begin{itemize}
\item If $m\ne\dfrac{7}{2}$: exactly one solution, $\boxed{x=\dfrac{8-4m}{7-2m}}$.
\item If $m=\dfrac{7}{2}$: the equation reads $0\cdot x=-6$, which has \textbf{no solution}.
\end{itemize}
