Let $f(x)=3x-2$, and let $m$ be a real parameter.
\begin{enumerate}
\item[(a)] Find the function $g$ such that $f\bigl(2x-g(x)\bigr)=-3(1+2m)x+34$ for all real $x$.
\item[(b)] Solve the equation $g(x)=4(m-1)x-4(m+1)$ in $x$, discussing all values of $m$.
\end{enumerate}
