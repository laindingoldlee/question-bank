The step $\sqrt4=\sqrt{-2}\cdot\sqrt{-2}$ is false. It silently uses the rule $\sqrt{xy}=\sqrt x\,\sqrt y$ with $x=y=-2$, but this rule is only valid for $x,y\ge0$.

For $x,y\ge0$ it holds because $\sqrt x\sqrt y\ge0$ and $\left(\sqrt x\sqrt y\right)^2=xy$, so $\sqrt x\sqrt y$ is the nonnegative square root of $xy$. For negative numbers, with the principal value $\sqrt{-2}=i\sqrt2$, we get $\sqrt{-2}\cdot\sqrt{-2}=\left(i\sqrt2\right)^2=-2$, while $\sqrt{(-2)(-2)}=\sqrt4=2$. These are different numbers.

The other steps are correct: $2=\sqrt4$, $\sqrt{-2}=i\sqrt2$ and $i\sqrt2\cdot i\sqrt2=2i^2=-2$. So the only error is $\boxed{\sqrt4=\sqrt{-2}\cdot\sqrt{-2}}$, which misuses $\sqrt{xy}=\sqrt x\sqrt y$ for negative $x,y$.
