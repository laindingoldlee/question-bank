Writing $1$ on the left gives $100000+N$; writing $1$ on the right gives $10N+1$.

If $10N+1=3(100000+N)$, then $7N=299999$, so $N=42857$.

If $100000+N=3(10N+1)$, then $29N=99997$, which has no integer solution ($29\cdot3448=99992$).

So $N=\boxed{42857}$. Check: $428571=3\cdot142857$.
