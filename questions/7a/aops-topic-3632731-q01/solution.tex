Start both at time $0$. At time $4$, turn the 4-minute glass. At time $7$, turn the 7-minute glass. At time $8$, the 4-minute glass empties; the 7-minute glass has run for one minute, so turn it again. The sand that fell during that minute is now above the neck and takes one minute to run out. It empties at time $\boxed 9$.
