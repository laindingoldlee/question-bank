Each time, the books in positions $3,6,\dots,30$ are shredded, so exactly $10$ books are shredded. After a uniformly random shuffle, the set of books in these $10$ positions is equally likely to be any of the $\dbinom{30}{10}$ sets of $10$ books. Exactly one of these sets is the set shredded the first time, so the probability is
\[\dfrac{1}{\dbinom{30}{10}}=\boxed{\dfrac{1}{30\,045\,015}}.\]
(Equivalently, the $10$ positions must hold the $10$ previously shredded books in some order and the other $20$ positions the other books: $\dfrac{10!\,20!}{30!}$.)
