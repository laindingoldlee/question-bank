The last two equations give $b=ac-2$ and $a c(c+1)-2c=8$, so $c\mid8$ and $c\ne0$. For $c=-1$, the latter equation would read $2=8$, impossible. Otherwise $a=\dfrac{8+2c}{c(c+1)}$. For $c=-8,-4,-2,1,2,4,8$, these values are $-\dfrac{1}{7},0,2,5,2,\dfrac{4}{5},\dfrac{1}{3}$. Only $c=-4,-2,1,2$ give integral $a$. Their $(a,b,c)$ are $(0,-2,-4),(2,-6,-2),(5,3,1),(2,2,2)$; substitution into the first equation gives respectively $-4,24,21,12$. Only the last works, so $a=\boxed2$.
