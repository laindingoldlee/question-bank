Use $ A=(0,0),B=(w,0),C=(w,h),D=(0,h)$ and $ T=(u,v)$. Expanding squared distances shows $ TA^2+TC^2=TB^2+TD^2 $, because each coordinate-square term occurs equally on both sides. Hence $ TD^2=225+625-400=450 $, so $\boxed{TD=15\sqrt2}$.
\begin{asy}
usepackage("amsmath");
size(7cm);
pair A=(0,0),B=(25,0),C=(25,12+3*sqrt(41)),D=(0,12+3*sqrt(41)),T=(9,12);draw(A--B--C--D--cycle);draw(T--A^^T--B^^T--C^^T--D,dashed);label("$A$",A,SW);label("$B$",B,SE);label("$C$",C,NE);label("$D$",D,NW);label("$T$",T,E);label("schematic",(12.5,-5));
\end{asy}
