Define $f:\{1,2,3\}\to\{2,4,6\}$ by $f(n)=2n$. If $f(a)=f(b)$ then $2a=2b$, so $a=b$; hence it is injective. Every target $2,4,6$ is $f(1),f(2),f(3)$ respectively, so it is surjective. Together these properties prove bijectivity.
