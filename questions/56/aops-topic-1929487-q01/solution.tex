Since $(a-1)^2\ge0$, we have $a^2+1\ge2a$, and similarly $b^2+1\ge2b$. Hence
\[
\dfrac{a^2+1}{b}+\dfrac{b^2+1}{a}\ge\dfrac{2a}{b}+\dfrac{2b}{a}=2\left(\dfrac {a}{b}+\dfrac {b}{a}\right)\ge2\cdot2=4,
\]
using AM-GM for $\dfrac {a}{b}+\dfrac {b}{a}\ge2$. Equality holds exactly when $a=b=1$.
