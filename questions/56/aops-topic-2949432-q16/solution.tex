The recurrence gives $a_{n+1}=\dfrac{a_n^2-a_n+a_{n-1}}{a_{n-1}}$ whenever $a_{n-1}\ne0$, so the sequence is determined. Computing $1,4,13,40,121,\dots$ suggests $a_n=\dfrac{3^{n+1}-1}2$. Check: with $t=3^n$,
\[a_n^2-a_{n-1}a_{n+1}=\dfrac{(3t-1)^2-(t-1)(9t-1)}4=\dfrac{4t}4=t,\qquad a_n-a_{n-1}=\dfrac{3t-t}2=t.\]
So we need $440\mid3^{k+1}-1$. The order of $3$ is $2$ modulo $8$, $4$ modulo $5$ and $5$ modulo $11$. So we need $20\mid k+1$, and the smallest is $k=\boxed{19}$.
