Think of the rows $r_1,\dots,r_5$ and the columns $c_1,\dots,c_5$ as points, and join $r_i$ to $c_j$ when the square in row $i$ and column $j$ has an X. Every point is joined to exactly $2$ others, and each line joins a row to a column. Following the lines from any point, we go row, column, row, column, \dots\ until we return; so the lines split into disjoint closed cycles alternating between rows and columns, each using at least $2$ rows and $2$ columns. With $5$ rows, the cycles use either all $5$ rows in one cycle, or $2$ rows in one cycle and $3$ rows in another. Conversely, every such set of cycles gives a valid board.

\textbf{One cycle through $2$ rows and $2$ columns, one through $3$ and $3$.} Choose the $2$ rows and the $2$ columns: $\dbinom52\dbinom52=100$ ways; these four squares are all X. The remaining $3\times3$ block must have two X's in each row and column, i.e. exactly one O in each row and column: $3!=6$ ways. Total $600$.

\textbf{One cycle through all $5$ rows and $5$ columns.} Write the cycle starting at $r_1$: $r_1,c_{\ast},r_{\ast},c_{\ast},\dots$. The other rows appear in some order ($4!$ ways) and the columns in some order ($5!$ ways), and each cycle is obtained twice, once for each direction. So there are $\dfrac{4!\cdot5!}{2}=1440$ such boards.

The total is $600+1440=\boxed{2040}$.
