The number of seats per row in an auditorium increases from the front to the back. The first row has $15$ seats, the second row has $2$ more seats than the first, the third row has $3$ more seats than the second, the fourth row has $2$ more than the third, the fifth row has $3$ more than the fourth, and so on, the increases alternating between $2$ and $3$. There are $30$ rows. How many seats are in the auditorium? A student argued: ``the rows form an arithmetic sequence with first term $15$ and common difference $5$, so with $15$ terms up to $85$, and then the $30$th row has $87$ seats; the total is $\dfrac{15(15+85)}{2}+87=837$.'' Find the error and the correct total.
