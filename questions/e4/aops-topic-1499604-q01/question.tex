A person has $2$ feet, and a sock and a shoe for each foot. In how many orders can the person put on the $2$ socks and $2$ shoes, if on each foot the sock must go on before the shoe? Answer the same question for a creature with $3$ feet and for one with $4$ feet (one sock and one shoe per foot).
