One kilometre is $1{,}000{,}000$ mm, so the string has $\dfrac{1{,}000{,}000}{8}=125{,}000$ ants. Their weight is
\[
125{,}000\cdot7=875{,}000\text{ mg}=875\text{ g}=\boxed{\dfrac{7}{8}}\text{ kg}.
\]
