Since $x\mid4x$, we have $x\mid4x-3\iff x\mid3$, so $x\in\{\pm1,\pm3\}$. Similarly $x\mid4x+4\iff x\mid4$. For $x=3$: $3\mid9$, but $3\nmid16$. So the statement is \textbf{false}; $\boxed{x=3}$ (or $x=-3$) is a counterexample. (It does hold for $x=\pm1$.)
