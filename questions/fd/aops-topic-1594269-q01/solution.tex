A pizza is determined by its size and by \emph{which} toppings it has. For each of the $9$ toppings there are $2$ choices (on or off), so there are $2^9=512$ sets of toppings, and
\[
3\cdot2^9=3\cdot512=\boxed{1536}
\]
different pizzas.

\textbf{The error.} The student counts only \emph{how many} toppings a pizza has, not which ones. For example, "one topping" is not one choice but $\dbinom91=9$ choices (pepperoni, mushrooms, \dots), and "two toppings" is $\dbinom92=36$ choices. Counting correctly by the number of toppings gives
\[
\dbinom90+\dbinom91+\cdots+\dbinom99=1+9+36+84+126+126+84+36+9+1=512,
\]
the same $2^9$ as before.
