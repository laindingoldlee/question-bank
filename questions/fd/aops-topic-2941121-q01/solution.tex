If the common value is $k$, then $\dfrac{x+1}x=\dfrac1k$ gives $\dfrac1x=\dfrac1k-1$. Likewise $\dfrac2y=\dfrac1k-1$ and $\dfrac3z=\dfrac1k-1$. So $\dfrac1x=\dfrac2y=\dfrac3z=\dfrac{54}3=18$, giving $x=\dfrac1{18}$, $y=\dfrac19$, $z=\dfrac16$ and $x+y+z=\boxed{\dfrac13}$.
