\begin{itemize}
\item $(2,5)$: $2\cdot2+1=5$. Yes.
\item $(-3,-2)$: $2\cdot(-3)+1=-5\ne-2$. No.
\item $(n,2n-1)$: the line requires $2n+1$, which is never $2n-1$. No, for every $n$.
\item $(2a,4a+1)$: $2\cdot2a+1=4a+1$. Yes, for every $a$.
\end{itemize}
So $\boxed{2}$ of the points lie on the line.
