As a quadratic in $x^3$ it has discriminant $25-32<0$, so it does not split as $(x^3+\alpha)(x^3+\beta)$ with real $\alpha,\beta$. Instead look for a monic quadratic factor $x^2+ux+v$; its constant term must divide $8$. Trying small values leads to $x^2-x+2$. Indeed, if $r^2=r-2$, then $r^3=r^2-2r=-r-2$, so
\[r^6+5r^3+8=(r+2)^2-5(r+2)+8=r^2-r+2=0,\]
so every root of $x^2-x+2$ is a root of $x^6+5x^3+8$. Dividing gives
\[x^{6}+5x^{3}+8=\boxed{(x^2-x+2)(x^4+x^3-x^2+2x+4)}.\]
Check by expanding: $(x^2-x+2)(x^4+x^3-x^2+2x+4)=x^6+(1-1)x^5+(-1-1+2)x^4+(2+1+2)x^3+(4-2-2)x^2+(-4+4)x+8=x^6+5x^3+8$.
