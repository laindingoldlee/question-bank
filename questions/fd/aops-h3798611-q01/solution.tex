Using unit-cell coordinates with the lower-left cell $(0,0)$, take these four pieces:
\[\begin{gathered}\{(0,2),(0,3),(1,3)\},\quad\{(0,0),(1,0),(0,1)\},\\\{(2,0),(3,0),(3,1)\},\quad\{(1,1),(1,2),(2,1)\}.\end{gathered}\]
Each consists of three cells forming an L, so the pieces are congruent under rotations or reflections. The twelve listed cells are distinct and exhaust the original region, proving that this is a valid dissection.
\begin{asy}
texpreamble("\usepackage{amsmath,amssymb}");
size(240);
defaultpen(fontsize(9pt));
pair[][] p={ {(0,2),(0,3),(1,3)}, {(0,0),(1,0),(0,1)}, {(2,0),(3,0),(3,1)}, {(1,1),(1,2),(2,1)} };pen[] co={lightblue,lightred,lightgreen,lightgray};for(int i=0;i<4;++i)for(pair q:p[i]){filldraw(box(q,q+(1,1)),co[i]);label(string(i+1),q+(.5,.5));}
\end{asy}
