If $3+\sqrt p=q$ were rational, then $\sqrt p=q-3$ would be rational. Write $\sqrt p=\dfrac ab$ in lowest terms; then $a^2=pb^2$, so $p\mid a$. Writing $a=pc$ gives $pc^2=b^2$, so $p\mid b$, which contradicts lowest terms. $\blacksquare$
