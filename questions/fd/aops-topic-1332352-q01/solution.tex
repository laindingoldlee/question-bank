Put $y=0$: $f(x)=x+f(0)$ for every $x$. So $f(x)=x+c$ for a constant $c$. Conversely, every such function works: $f(x+y)=x+y+c=x+(y+c)=x+f(y)$. The solutions are
\[
\boxed{f(x)=x+c\ \text{ for a constant } c}.
\]
