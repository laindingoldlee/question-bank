Let the circumference be $ C $. Simultaneous return requires both $\dfrac{9t}{C}$ and $\dfrac{5t}{C}$ to be integers. Since $ 9,5 $ are coprime, the least positive time is $ t=C $. Meetings occur when the total distance covered, $ 14t $, is a multiple of $ C $, at times $\dfrac{mC}{14}$. Strictly between $ 0 $ and $ C $, these correspond to $ m=1,\ldots,13 $, giving $\boxed{13}$ meetings.
