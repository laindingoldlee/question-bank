\emph{Odd terms.} For $k=1,3,\dots,99$: $\left\lfloor\dfrac {k}{8}\right\rfloor$ is $0$ for $k=1,3,5,7$, is $1$ for the four odd $k$ from $9$ to $15$, and so on, up to $11$ for $k=89,\dots,95$; finally it is $12$ for $k=97,99$. The sum is $4(0+1+\dots+11)+2\cdot12=264+24=288$.

\emph{Even terms.} For $k=2m$, $m=1,\dots,50$: $\left\lceil\dfrac{2m}{8}\right\rceil=\left\lceil\dfrac {m}{4}\right\rceil$, which is $1$ for $m=1,\dots,4$, $2$ for $m=5,\dots,8$, \dots, $12$ for $m=45,\dots,48$ and $13$ for $m=49,50$. The sum is $4(1+2+\dots+12)+2\cdot13=312+26=338$.

Total: $288+338=\boxed{626}$.
