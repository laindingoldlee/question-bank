The word has the letters T, H, R, I, F, T, Y, P, I, A, N, O: the letters T and I appear twice, and the other $8$ letters once. There are $\dbinom{12}{3}=220$ equally likely choices.

\begin{itemize}
\item If the three tiles show three different letters, there are $3!=6$ strings.
\item If two tiles show the same letter, there are $\dfrac{3!}{2!}=3$ strings. This happens when the choice contains both T's (and any of the other $10$ tiles) or both I's (and any of the other $10$ tiles): $20$ choices. (Three equal letters are impossible.)
\end{itemize}
So $200$ choices give $6$ strings and $20$ choices give $3$, and the expected number is
\[\dfrac{200\cdot6+20\cdot3}{220}=\dfrac{1260}{220}=\boxed{\dfrac{63}{11}}.\]
