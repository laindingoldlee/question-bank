Factor: $n^2-3n+2=(n-1)(n-2)$. This is $0$ exactly when $n=1$ or $n=2$, so the only positive integers with $n^2-3n+2=0$ are $\boxed{n=1\text{ and }n=2}$. For example, $n=3$ gives $9-9+2=2\ne0$, so the conclusion is false.

A proof by induction needs, besides the first case, the inductive step: for every $k\ge1$, if the statement holds for $n=k$ then it holds for $n=k+1$. Here the step fails from $k=2$ to $k=3$: the statement is true for $n=2$ and false for $n=3$. Checking finitely many cases never replaces the inductive step.
