The sum of $n,n+1,n+2,n+3$ is $4n+6=2(2n+3)$. Since $2n+3$ is odd, the sum is twice an odd number: it is always divisible by $2$ but never by $4$. It can be divisible by $5$ and by $10$: for example $1+2+3+4=10$. The answer is $\boxed{\text{(B) } 4}$.
