For each $m$, compute the residue sum without large powers: for each $n=1,\ldots,m$, initialise $r=0,t=1$ and repeat $m$ times the updates $r\leftarrow(r+t)\bmod m$, $t\leftarrow nt\bmod m$. Count the $n$ for which $r=0$; call the result $c_m$. The values of $c_m$ for $m=1,\ldots,30$ are $1,1,1,2,1,2,1,4,3,2,1,4,1,2,1,8,1,6,1,8,3,2,1,8,5,2,9,4,1,4$. Computing $\varphi(m)$ by counting integers coprime to $m$, equality $c_m=\varphi(m)$ occurs precisely for $m=1,2,4,6,8,12,16,18,20,24$; for the other twenty values the inequality is strict. Thus the answer is $\boxed{20}$. The recurrence computes each geometric sum term exactly modulo $m$, so this finite enumeration covers all possibilities.
