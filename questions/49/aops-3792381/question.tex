Find the number of positive integers $m\leq30$ such that the number of positive integers $n\leq m$ in which $m$ divides $\sum_{i=0}^{m-1}n^i$ is less than $\varphi(m)$.



Note: $\varphi(x)$ is the number of positive integers $y\le x$ such that $\gcd(x,y)=1$.
