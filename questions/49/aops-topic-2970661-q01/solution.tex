$(0,0,0)$ works. Suppose a nonzero solution exists; choose one with $|x|+|y|+|z|$ minimal and positive. Then $7\mid x^5$, so $7\mid x$; write $x=7x_1$. Dividing by $7$: $7^4x_1^5+y^5+7z^5=0$, so $7\mid y$; $y=7y_1$ and dividing by $7$: $7^3x_1^5+7^4y_1^5+z^5=0$, so $7\mid z$, $z=7z_1$. Then $7^5(x_1^5+7y_1^5+49z_1^5)=0$, so $(x_1,y_1,z_1)$ is a smaller nonzero solution, a contradiction. Hence the only solution is $\boxed{(0,0,0)}$.
