For $x<-1$, the ordering is $x<x^2<x^4$; for $-1<x<0$, it is $x<x^4<x^2$; for $0<x<1$, it is $x^4<x^2<x$; for $x>1$, it again is $x<x^2<x^4$. At $x=-1,0,1$ there are equalities. These cases exhaust the real line, so exactly $\boxed3$ orderings occur.
