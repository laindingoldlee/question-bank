Since $35n$ is a multiple of both $5$ and $7$, we need $13m\equiv1000\pmod 5$ and $13m\equiv1000\pmod 7$.
\begin{itemize}
\item Modulo $5$: $1000\equiv0$ and $13\equiv3$, so $3m\equiv0$, that is, $m\equiv0\pmod5$.
\item Modulo $7$: $1000=994+6\equiv6\equiv-1$ and $13\equiv-1$, so $-m\equiv-1$, that is, $m\equiv1\pmod7$.
\end{itemize}
The multiples of $5$ that are $1$ more than a multiple of $7$ are $15,50,85,\dots$, so $m\equiv15\pmod{35}$. Also $13m<1000$ forces $m\le76$, so $m=15$ or $m=50$:
\[m=15:\ n=\dfrac{1000-195}{35}=\dfrac{805}{35}=23,\qquad m=50:\ n=\dfrac{1000-650}{35}=\dfrac{350}{35}=10.\]
So the solutions are $\boxed{(m,n)=(15,23)\text{ and }(50,10)}$.

(In general, all integer solutions are $m=15+35t$, $n=23-13t$ for integers $t$; positivity allows only $t=0$ and $t=1$.)
