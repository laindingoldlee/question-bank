\textbf{(a)} $\sqrt{96}=\sqrt{16\cdot6}=\boxed{4\sqrt6}$.

\textbf{(b)} $\sqrt{\dfrac{x^2}{64}}=\dfrac{\sqrt{x^2}}{8}=\boxed{\dfrac{|x|}{8}}$. The absolute value is needed: a square root is never negative, while $\dfrac x8$ is negative for $x<0$ (for example, $x=-8$ gives $\sqrt1=1$, not $-1$).
