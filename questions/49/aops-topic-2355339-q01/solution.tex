Each face has probability $\dfrac1n$. Face $n$ gives the result $n$, and face $k$ for $k=1,2,\dots,n-1$ gives $2k$. So the expected result is
\[\dfrac1n\Bigl(n+2\bigl(1+2+\cdots+(n-1)\bigr)\Bigr)=\dfrac1n\left(n+2\cdot\dfrac{(n-1)n}{2}\right)=1+(n-1)=\boxed{n}.\]
For example, for $n=6$ it is $\dfrac{6+2+4+6+8+10}{6}=\dfrac{36}{6}=6$. $\blacksquare$

(If instead every face other than $n$ gave the fixed result $2n$, the expected value would be $n\cdot\dfrac1n+2n\cdot\dfrac{n-1}{n}=2n-1$, which is $11$ for $n=6$; so the pattern Sarah found belongs to the rule ``twice the number shown''.)
