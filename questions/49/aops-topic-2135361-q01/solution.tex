Choose the letters from left to right. The first letter can be any of the $26$ letters. Each later letter can be anything except the letter immediately before it, so there are $25$ choices for each of the remaining $10$ positions. By the multiplication principle the number of strings is
\[26\cdot25^{10}=26\cdot95367431640625=\boxed{2479553222656250}.\]
