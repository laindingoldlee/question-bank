Since $\gcd(7,50)=1$, $7$ has an inverse modulo $50$: $7\cdot43=301=6\cdot50+1$, so $7^{-1}\equiv43\pmod{50}$. Multiplying both sides by $43$:
\[u\equiv43\cdot23=989=19\cdot50+39\equiv39\pmod{50}.\]
So $\boxed{u\equiv39\pmod{50}}$. Check: $7\cdot39=273=5\cdot50+23$.

(Alternatively: $7u\equiv23\equiv73\equiv123\equiv\cdots$; the first of $23,73,123,173,223,273$ divisible by $7$ is $273=7\cdot39$.)
