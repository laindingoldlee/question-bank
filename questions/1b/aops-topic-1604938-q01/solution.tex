Work from the inside out, writing each radicand as a perfect square (each square root is the nonnegative root).
\begin{itemize}
\item $3-2\sqrt2=\left(\sqrt2-1\right)^2$, so $\sqrt{3-2\sqrt2}=\sqrt2-1$ (positive).
\item $10+4\left(\sqrt2-1\right)=6+4\sqrt2=\left(2+\sqrt2\right)^2$, so the next root is $2+\sqrt2$.
\item $23-6\left(2+\sqrt2\right)=11-6\sqrt2=\left(3-\sqrt2\right)^2$, and $3-\sqrt2>0$, so the next root is $3-\sqrt2$.
\item $9-2\left(3-\sqrt2\right)=3+2\sqrt2=\left(1+\sqrt2\right)^2$.
\end{itemize}
Hence the whole expression equals $\boxed{1+\sqrt2}$.
