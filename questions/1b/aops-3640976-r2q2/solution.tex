For real x,y,z, $x^2+y^2+z^2-xy-yz-zx=\dfrac{1}{2}[(x-y)^2+(y-z)^2+(z-x)^2]\ge0$. The stated values would give -3, impossible. Thus there is no real solution. Formally $(x+y+z)^2=1+8=9$ would give positive sum three, but this does not establish existence; complex triples can realise that sum if complex variables are allowed.
