A passcode has three digits, each from $0$ to $9$ (repeats allowed), and all $1000$ codes are equally likely. You try one code per day.
\begin{enumerate}
\item[(a)] If you never repeat a code (trying the codes in some fixed order), what is the expected number of tries until you find the passcode?
\item[(b)] If instead each day you choose a code uniformly at random from all $1000$, independently of earlier days, what is the expected number of tries?
\end{enumerate}
