Yes. Let the original counts be $c_1,\ldots,c_5$ and $S=\sum c_i$. For each coin originally in box $i$, add one coin to each of the other four boxes, doing so in two allowed pairwise operations. These instructions refer only to original coins, so the procedure is finite. Box $j$ receives $S-c_j$ coins and ends with exactly $S$. Thus every box can be made equal.
