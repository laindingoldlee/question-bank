Lines $1$ to $n$ contain $1+2+\cdots+n=\dfrac{n(n+1)}{2}$ integers, so the last integer on line $n$ is $\dfrac{n(n+1)}{2}$. The last integer on line $17$ is $\dfrac{17\cdot18}{2}=153$. Line $17$ contains $17$ consecutive integers, so its first integer is $153-16=137$. The sum is $137+153=\boxed{290}$.
