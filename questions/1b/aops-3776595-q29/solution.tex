Put $s=S(n)$, so $n=1404s$. Modulo $9$, $n\equiv0$ while $S(n)\equiv n$, so $s$ is a positive multiple of $9$. The first possibility $s=9$ gives $n=12636$ with digit sum $18$, so it fails. The next possibility $s=18$ gives $n=25272$ with digit sum $18$. All later $s$ give larger $n$. Thus $\boxed{25272}$ is least.
