Write the line as $2x+y-7=0$. The distance is $\dfrac{|2\cdot10+7-7|}{\sqrt{2^2+1^2}}=\dfrac{20}{\sqrt5}=4\sqrt5\approx\boxed{8.9}$.

\begin{asy}
usepackage("amsmath");
size(3.5cm);
defaultpen(fontsize(10pt));
draw((-1,0)--(11,0),gray,Arrow); draw((0,-14)--(0,9),gray,Arrow);
draw((-0.5,8)--(10.5,-14),blue); pair Pp=(10,7), F=(2,3); draw(Pp--F,red); dot(Pp); dot(F); label("$(10,7)$",Pp,E);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}
