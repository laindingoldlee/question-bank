Without rain the tree would grow $31\cdot1=31$ cm. It rains for $0.05\cdot31=1.55$ days, during which it grows an extra $\dfrac{1}{2}$ cm per day, an extra $1.55\cdot\dfrac{1}{2}=0.775$ cm. So the tree is
\[31+0.775=\boxed{31.775\text{ cm}}\]
tall at the end of March.
