If H is the number of heads, the condition is $H(10-H)\ge 20$. Among integers 0 through 10, this is exactly $3\le H\le 7$. The excluded counts 0,1,2,8,9,10 have total $2(\binom{10}0+\binom{10}1+\binom{10}2)=2(1+10+45)=112$ outcomes. Thus the probability is $1-\dfrac{112}{1024}=\boxed{\dfrac{57}{64}}$.
