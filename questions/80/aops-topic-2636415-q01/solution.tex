We need $0\le\dfrac{x^2+y^2+1}{2x}\le1$. The numerator is positive, so $x>0$. Then the upper bound says $x^2+y^2+1\le2x$, i.e.
\[(x-1)^2+y^2\le0,\]
so $x=1$ and $y=0$. These work, with $\sin^2\theta=1$ (e.g. $\theta=90^\circ$). Hence $\boxed{x=1,\ y=0}$.
