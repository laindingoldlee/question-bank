A building has $2$ levels with $4$ windows each. On level one, each window has a set of blue Christmas lights; on level two, each window has a wreath. Bill takes down all the decorations one at a time: each time he picks a level and takes down the rightmost decoration remaining on that level. He never takes down more than $2$ decorations on the same level in a row before switching levels. How many ways can Bill take down the decorations?

(A) $10$\qquad (B) $15$\qquad (C) $25$\qquad (D) $30$\qquad (E) $34$
