$\overrightarrow{AB}=(3,2,3)=\overrightarrow{DC}$, so $ABCD$ is a parallelogram (in particular, planar).

With $\overrightarrow{AD}=(-7,4,7)$, we get $\overrightarrow{AB}\cdot\overrightarrow{AD}=-21+8+21=8\ne0$, so it is not a rectangle. Also $|AB|=\sqrt{22}\ne\sqrt{114}=|AD|$, so it is not a rhombus. Answer: a $\boxed{\text{parallelogram}}$ that is neither a rectangle nor a rhombus.
