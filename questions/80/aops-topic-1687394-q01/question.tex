In the ``$n$ $n$s'' game you must use exactly $n$ copies of the number $n$, together with any number of the following operations, to produce a target number: addition, subtraction, multiplication, division, exponentiation, square roots, logarithms (to any base that is itself built from copies of $n$), factorials, and the fractional part $\{x\}=x-\lfloor x\rfloor$. Prove that if $n\ge4$ is an integer, every integer can be produced.
