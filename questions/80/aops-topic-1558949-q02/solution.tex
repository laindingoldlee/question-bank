The procedure picks $9$ different numbers, the last one uniformly among those not yet chosen. Equivalently, it chooses an ordered list of $9$ distinct numbers, all such lists being equally likely. Given which $9$ numbers are chosen, each of them is equally likely to be the one chosen last. The event is that the last one is the smallest of the $9$, so its probability is
\[
\boxed{\dfrac{1}{9}}.
\]
(As a check by counting: for a fixed set of $9$ numbers, the last number must be its minimum, and the first $8$ can be any of the others; so the probability is $\dfrac{1}{9}$.)
