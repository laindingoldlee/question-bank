For each of 64 king cells, 49 rook cells lie in neither its row nor its column. Among these, exclude diagonal-neighbour cells. There are 49 adjacent 2-by 2 subsquares, each contributing 4 ordered diagonal king-rook placements, so the allowed labelled count is $64\cdot49-4\cdot49=2940$. No nonidentity rotation fixes a distinguished king cell on an even-sized board, so every rotation orbit has size 4. The answer is $\boxed{735}$.
