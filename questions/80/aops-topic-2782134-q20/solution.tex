Set $ u=a-c,v=b-d $. Then $ u+v=-29 $ and $ uv=190 $, so $ u,v $ are the roots of $ t^2+29t+190=(t+10)(t+19)$. Therefore $ a+d=u+(c+d)=u+39 $ equals $\boxed{20\text{ or }29}$. Both occur: choose any $ c $, set $ a=c+u $, $ b=10-a $, and $ d=39-c $ for either root $ u $.
