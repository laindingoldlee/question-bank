Imagine drawing all five chips in a random order. The drawing stops when one colour is exhausted, and the chips not yet drawn are all of the other colour. The last chip drawn is white exactly when the whites run out first, that is, when the chip at the very end of the full random order is red. That happens with probability $\dfrac{3}{5}$.

So the answer is $\boxed{\textbf{(D) } \dfrac{3}{5}}$. (A direct count: the $\dbinom52=10$ equally likely positions of the white chips; the whites are exhausted first unless position $5$ is white, which happens in $4$ of the $10$ cases.)
