Number the people $1$ to $1000$. Within $99$ jumps the bug stays between person $401$ and person $599$, so it never reaches an end of the row and every jump really changes its position by $\pm1$. Each jump changes the parity of the bug's position, so after an odd number of jumps the position has the opposite parity to $500$ and cannot be $500$. The probability is $\boxed{0}$.
