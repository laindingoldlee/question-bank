Order the side lengths $a\le b$. Then $a^3\le3555$, so $1\le a\le15$, and $b^3<7110$, so $b\le19$. The following exhaustive integer check on these proven finite bounds gives only $(a,b)=(13,17)$; indeed $2197+4913=7110$. Thus the only side-sum is 30 and the requested sum is $\boxed{30}$.
\begin{verbatim}
pairs=[(a,b) for a in range(1,16) for b in range(a,20)
       if a**3+b**3==7110]
assert pairs==[(13,17)]
\end{verbatim}
