Let running speed be $v$ and downward escalator speed $e$. Equal travel times for the same distance imply $v-e=\dfrac{v}{3}+e$, so $\dfrac{2v}{3}=2e$ and $\boxed{v:e=3:1}$. This also shows the escalator must move downward; upward motion would make the faster uphill run faster still and the slower downhill walk slower still.
