Expanding, $a(bc-1)+b(ac-1)+c(ab-1)=3abc-(a+b+c)=3abc-576$. So we must maximise $abc$.

By AM-GM, $abc\le\left(\dfrac{a+b+c}{3}\right)^3=192^3$, with equality for $a=b=c=192$, which are allowed integers. Since $192^3=7077888$, the maximum is
\[
3\cdot7077888-576=21233664-576=\boxed{21233088}.
\]
