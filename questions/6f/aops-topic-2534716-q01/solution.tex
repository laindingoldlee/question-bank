Number the people $1,2,3,4,5$ by their original chairs. A new seating is a sequence listing who sits in chairs $1,\dots,5$. The second condition says that $k$ and $k+1$ are never neighbours in the sequence.

\textbf{Step 1: sequences without neighbouring consecutive numbers.} The pairs allowed to be neighbours are those differing by at least $2$: $13,14,15,24,25,35$. These form the $5$-cycle $1-3-5-2-4-1$ together with the extra edge $1-5$. We need paths through all five numbers using allowed pairs.
\begin{itemize}
\item Paths not using $1-5$: delete one edge of the cycle, giving $5$ paths, each in $2$ directions: $35241,14253$; $52413,31425$; $24135,53142$; $41352,25314$; $13524,42531$.
\item Paths using $1-5$: the number $3$ is allowed only next to $1$ and $5$, so it must be an end of the path, attached to $1$ or to $5$. This gives $3-1-5-2-4$ and $3-5-1-4-2$, each in $2$ directions: $31524,42513$; $35142,24153$.
\end{itemize}
So there are $14$ such sequences.

\textbf{Step 2: no one in the old chair.} Remove the sequences with $k$ in position $k$ for some $k$: $35241$ (the $4$), $14253$, $52413$, $31425$, $24135$, $53142$, $41352$, $25314$, $13524$, $42531$, $42513$, $35142$ all fail. Only
\[31524\qquad\text{and}\qquad24153\]
remain. So there are $\boxed{2}$ ways.
