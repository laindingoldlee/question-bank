Since $P(A\cup B\cup C)=1$, inclusion-exclusion gives
\[
1=3P(A)-(0.3+0.2+0.4)+0.1=3P(A)-0.8,
\]
so $P(A)=\boxed{0.6}$. The resulting regions of the Venn diagram are all nonnegative ($A$ only $0.2$, $B$ only $0$, $C$ only $0.1$, exactly $A,B$: $0.2$, exactly $A,C$: $0.1$, exactly $B,C$: $0.3$, all three $0.1$), so the data are consistent.
