Let there be $K$ knights. Person $k$'s statement is true iff $K\le k-1$, i.e. $k\ge K+1$. Knights are exactly the people making true statements, so $K=\#\{k:K+1\le k\le12\}=12-K$, giving $K=\boxed{6}$ (persons $7$ to $12$). This is consistent: persons $1$ to $6$ say "at most $0,\dots,5$ knights", which is false.
