A combination with repetition is described by how many of each of the $6$ items you buy: $x_1+x_2+\cdots+x_6=4$ with $x_i\ge 0$. By sticks and stones ($4$ stones, $5$ sticks) the number of solutions is
\[\dbinom{4+5}{5}=\dbinom94=\boxed{126}.\]
If the items must be different, the answer is simply $\dbinom64=\boxed{15}$.

The expression $\dfrac{9!}{3!\,6!}=\dbinom93=84$ is the sticks-and-stones count for $6$ stones and $3$ sticks, which corresponds to a different problem (buying $6$ items from a menu of $4$).
