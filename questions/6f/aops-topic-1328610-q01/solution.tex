No fixed base works (for example $1+1=10$ would force base $2$, which has no digit $3$). The system is the \emph{factorial number system}: the $k$-th digit from the right has place value $k!$, so $\overline{d_k\ldots d_2d_1}=\sum d_i\,i!$ with $0\le d_i\le i$.

Check: $321=3\cdot3!+2\cdot2!+1\cdot1!=23$ and $23+1=24=4!=1000$; $1+1=2=2!=10$; $10\times20=2\cdot4=8=3!+2!=110$; $121=6+4+1=11$ and $11^2=121=5!+1=10001$.

Now $2321=2\cdot24+3\cdot6+2\cdot2+1=71$, and $71^2=5041=7!+1$. So
\[
2321^2=\boxed{1000001}.
\]
