Each child gets $3$ toys, so a distribution is determined by the numbers of dolls $d_1,\dots,d_4$ the children get, with $0\le d_i\le3$ and $d_1+\cdots+d_4=6$ (the rest of each child's toys are trucks). Without the upper bound there are $\dbinom{9}{3}=84$ solutions; those with some $d_i\ge4$ number $4\dbinom53=40$ (two values $\ge4$ are impossible). So there are $84-40=\boxed{44}$ ways.
