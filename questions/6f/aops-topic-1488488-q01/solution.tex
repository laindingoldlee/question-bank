A $4$-digit number is an integer from $1000$ to $9999$, so its first digit cannot be $0$: a ``number'' $0\,1\,x\,y$ is really the $3$-digit number $1xy$. So pairs such as $01$, $02$, $03$ must be left out.

Let the digits be $a,b,c,d$ with $a\ge1$ and $d=a+b\le9$. For each first digit $a$ from $1$ to $9$ the second digit $b$ can be $0,1,\dots,9-a$, which is $10-a$ choices; then $d$ is determined and $c$ is any of the $10$ digits. The number of choices of $(a,b)$ is
\[
9+8+\dots+1=45,
\]
and the total is $45\cdot10=\boxed{450}$.
