Put $a=3x$, $b=5y$, $c=15z$ (all positive). Then $9x^2+25y^2+225z^2=a^2+b^2+c^2$ and
\[
xy=\dfrac{ab}{15},\qquad 3xz=3\cdot\dfrac {a}{3}\cdot\dfrac {c}{15}=\dfrac{ac}{15},\qquad 5yz=5\cdot\dfrac {b}{5}\cdot\dfrac {c}{15}=\dfrac{bc}{15},
\]
so the conditions become
\[
a^2+b^2+c^2\le675,\qquad ab+bc+ca=15\cdot45=675 .
\]
For all real $a,b,c$,
\[
a^2+b^2+c^2-(ab+bc+ca)=\dfrac{1}{2}\left[(a-b)^2+(b-c)^2+(c-a)^2\right]\ge0 .
\]
Hence $675\ge a^2+b^2+c^2\ge ab+bc+ca=675$, so equality holds throughout, which forces $a=b=c$. Then $3a^2=675$, so $a=15$ (as $a>0$). Therefore $3x=5y=15z=15$, and the only solution is
\[
\boxed{(x,y,z)=(5,3,1)} .
\]
Check: $9\cdot25+25\cdot9+225\cdot1=675$ and $15+15+15=45$.

\emph{Remark.} With the right-hand side $75$ instead of $45$, the same substitution gives $ab+bc+ca=1125$, and then $a^2+b^2+c^2\ge1125>675$, so that system has no solution at all.
