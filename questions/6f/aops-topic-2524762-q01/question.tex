Let
\[x=1^3-2^3+3^3-4^3+5^3-\cdots+121^3.\]
\begin{enumerate}
\item[(a)] Compute $x$.
\item[(b)] Someone defines $y=1-\sqrt{1+\sqrt{1-\sqrt{1+\cdots}}}$ and asks for $\left\lceil\dfrac xy\right\rceil$. If the infinite expression has a value, the part after the first ``$1-$'' repeats the whole expression, so $y$ is a real number with
\[y=1-\sqrt{1+\sqrt y}.\]
Find all real $y$ satisfying this equation, and decide whether $\left\lceil\dfrac xy\right\rceil$ is defined.
\end{enumerate}
