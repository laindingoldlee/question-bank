\textbf{(a)} The sum of all cubes up to $121^3$ is $\left(\dfrac{121\cdot122}{2}\right)^2=7381^2$, and the subtracted even cubes are $8\left(1^3+\cdots+60^3\right)=8\left(\dfrac{60\cdot61}{2}\right)^2=8\cdot1830^2$, each subtracted where it should have been added. So
\[x=7381^2-2\cdot8\cdot1830^2=54479161-53582400=\boxed{896761}.\]

\textbf{(b)} For $\sqrt y$ to be real we need $y\ge0$. Then $\sqrt{1+\sqrt y}\ge1$, so $y=1-\sqrt{1+\sqrt y}\le0$. Hence $y=0$, and indeed $1-\sqrt{1+\sqrt0}=0$. So the only solution is $\boxed{y=0}$.

Then $\dfrac xy$ is a division by zero, so $\left\lceil\dfrac xy\right\rceil$ is \textbf{not defined}: the problem as posed has no answer.
