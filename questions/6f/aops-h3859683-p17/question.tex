Each point in a $16\times 16$ lattice is independently colored red with probability $p$ or blue with probability $1-p$. Let $X$ denote the number of ordered quadruples $(P_1,P_2, P_3, P_4)$ of distinct points such that:

\begin{itemize}

\item $P_1$ and $P_2$ lie in the same column,

\item $P_2$, $P_3$, $P_4$ lie in the same row,

\item $P_1$, $P_3$, $P_4$ are red, and $P_2$ is blue.

\end{itemize}

Compute the maximum expected value of $X$ over all values of $p$.
