With $k$ stamps the letter weighs $w=\dfrac{9}{10}+\dfrac{k}{30}$ oz, and if $w$ is more than $m-1$ but at most $m$ ounces the postage is $37+23(m-1)$ cents. We need $k$ equal to this postage.

The postage is $37+23(m-1)$ for some $m\ge1$, so $k$ must be one of $37,60,83,106,129,152,\dots$ Test them in order:
\begin{itemize}
\item $k=37$: $w=0.9+1.2\overline{3}=2.1\overline{3}$, so $m=3$ and the postage is $83\ne37$;
\item $k=60$: $w=2.9$, $m=3$, postage $83\ne60$;
\item $k=83$: $w=0.9+2.7\overline{6}=3.6\overline{6}$, $m=4$, postage $106\ne83$;
\item $k=106$: $w=0.9+3.5\overline{3}=4.4\overline{3}$, $m=5$, postage $129\ne106$;
\item $k=129$: $w=0.9+4.3=5.2$, $m=6$, postage $152\ne129$;
\item $k=152$: $w=0.9+5.0\overline{6}=5.9\overline{6}$, $m=6$, postage $152$. It works.
\end{itemize}
So the least number is $\boxed{152}$ stamps.

\textbf{Other solutions.} The answer is not unique without the word "least": the same test shows that $175$, $198$, $221$ and $244$ stamps also pay exactly the postage ($w=6.73$, $7.5$, $8.27$, $9.03$ oz, needing $7,8,9,10$ ounces of postage, i.e.\ $175,198,221,244$ cents). Beyond that there are no more: each extra $23$ cents of postage requires $23$ more stamps, which add $\dfrac{23}{30}$ oz, less than an ounce, so the weight eventually falls behind and the next candidate $267$ gives $w=9.8$, postage $244$; from then on the number of stamps exceeds the postage.
