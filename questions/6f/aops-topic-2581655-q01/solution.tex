Let $n=\lfloor x\rfloor$, so $n\le x<n+1$, and the equation is $x^2-x=n^2$.

For each integer $n\ge1$, the positive root of $x^2-x-n^2=0$ is
\[x_n=\dfrac{1+\sqrt{1+4n^2}}{2}.\]
It lies in $[n,n+1)$, because $2n-1<\sqrt{1+4n^2}<2n+1$ (square all three: $4n^2-4n+1<4n^2+1<4n^2+4n+1$). So $x_n$ is a solution with $\lfloor x_n\rfloor=n$, and the other root is negative. Since $x<10$ forces $n\le9$, the solutions with $n\ge1$ are $x_1<x_2<\cdots<x_9$, and any solution with $n\le0$ is less than $1$. So the largest solution below $10$ is
\[x_9=\dfrac{1+\sqrt{325}}{2}\approx9.51.\]

This form is the only one allowed. If $\dfrac{a+\sqrt b}{c}=\dfrac{1+\sqrt{325}}2$, then $2\sqrt b=r+c\sqrt{325}$ with $r=c-2a$ rational. Squaring gives $4b=r^2+325c^2+2rc\sqrt{325}$. As $\sqrt{325}$ is irrational, $rc=0$, so $c=2a$ and $b=325a^2$. Then $\gcd(b,c)=\gcd\left(325a^2,2a\right)\ge a$ forces $a=1$.

So $a=1$, $b=325$, $c=2$, and $a+b+c=\boxed{328}$.
