Use $B=(2,0),D=(0,2),E=(1,2)$. Since $EF=2BE$ in the same direction, $F=E+2(E-B)=(-1,6)$. Triangle $DEF$ has base one and height four, so its area is $\boxed2$.
\begin{asy}
import graph;import geometry;usepackage("amsmath");size(7cm);
pair A=(0,0),B=(2,0),C=(2,2),D=(0,2),E=(1,2),F=(-1,6);draw(A--B--C--D--cycle);draw(B--F^^D--F,blue);label("$A$",A,(-1,-1));label("$B$",B,(1,-1));label("$C$",C,(1,1));label("$D$",D,(-1,0));label("$E$",E,(1,0));label("$F$",F,(0,1));
\end{asy}
