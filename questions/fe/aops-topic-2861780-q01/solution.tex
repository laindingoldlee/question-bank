The tower is evaluated from the top: $2^2=4$, $2^4=16$, $2^{16}=65536$, so the number is $2^{65536}$. It has $\lfloor65536\log_{10}2\rfloor+1=\lfloor19728.3\rfloor+1=\boxed{19729}$ digits.
