Put $a=\dfrac{yz}{x}$, $b=\dfrac{xz}{y}$, $c=\dfrac{xy}{z}$, which are positive. Then
\[ab=z^2,\qquad bc=x^2,\qquad ca=y^2,\qquad\text{so}\qquad ab+bc+ca=1.\]
For all reals, $(a+b+c)^2-3(ab+bc+ca)=\dfrac12\left[(a-b)^2+(b-c)^2+(c-a)^2\right]\ge0$. Hence $(a+b+c)^2\ge3$ and $a+b+c\ge\sqrt3$.

Equality holds when $a=b=c$, i.e. $x=y=z=\dfrac{1}{\sqrt3}$, and then the expression is $3\cdot\dfrac{1}{\sqrt3}=\sqrt3$. So the minimum is $\boxed{\sqrt3}$.
