One valid set of constructions is\[\begin{aligned}0&=(3-3)3,&1&=\left(\dfrac{3}{3}\right)^3,&2&=3-\dfrac{3}{3},\\3&=3\left(\dfrac{3}{3}\right),&4&=3+\dfrac{3}{3},&5&=3!-\dfrac{3}{3},\\6&=3!\left(\dfrac{3}{3}\right),&7&=3!+\dfrac{3}{3},&8&=\left(\dfrac{3!}{3}\right)^3,\\9&=3+3+3.\end{aligned}\]Each expression uses exactly three 3 s; $3!=6$ verifies the factorial cases.
