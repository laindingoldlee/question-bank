If the council has $n$ members, then $\dbinom n2=\dfrac{n(n-1)}{2}=10$, so $n(n-1)=20$ and $n=5$ (the other root $-4$ is impossible). The number of three-person committees is $\dbinom53=10$, so the answer is $\boxed{\textbf{(A)}\ 10}$. (In general $\dbinom n3=\dbinom n{n-3}$, and here $n-3=2$.)
