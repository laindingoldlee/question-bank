The left side equals $1111a+111b+11c+d$. Since $2\cdot1111>2021$, $a=1$ and $111b+11c+d=910$. As $11c+d\le99+9=108$, we need $111b\ge802$, so $b\ge8$; and $111b\le910$ gives $b\le8$. So $b=8$ and $11c+d=22$, which forces $c=2$, $d=0$ (since $c=1$ would need $d=11$). The digits $1,8,2,0$ are distinct, and $1820+182+18+1=2021$. So $\overline{abcd}=\boxed{1820}$ (the only possibility).
