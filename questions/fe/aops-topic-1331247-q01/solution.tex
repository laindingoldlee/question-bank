Everything is correct up to $\bigl((-1)^2\bigr)^{\dfrac{1}{2}}=\bigl(1^2\bigr)^{\dfrac{1}{2}}$, both sides being $\sqrt1=1$. The error is the next step, which uses the rule $(a^m)^n=a^{mn}$. That rule is valid for $a>0$ (or for integer exponents), but not for a negative base with a fractional exponent: in fact $\sqrt{a^2}=|a|$, not $a$. So $\bigl((-1)^2\bigr)^{\dfrac{1}{2}}=|-1|=1$, while $(-1)^{2\cdot\dfrac{1}{2}}=(-1)^1=-1$; these are different, and the ``proof'' breaks there.
