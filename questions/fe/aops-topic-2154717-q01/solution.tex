The statement is \textbf{true}. Factor the difference:
\[x^3+y^3-x^2y-xy^2=x^2(x-y)-y^2(x-y)=\left(x^2-y^2\right)(x-y)=(x+y)(x-y)^2 .\]
For positive $x\ne y$ we have $x+y>0$ and $(x-y)^2>0$, so the difference is positive. $\blacksquare$

(Equality holds exactly when $x=y$; positivity is needed, since for example $x=1$, $y=-2$ gives $x^3+y^3=-7<2=x^2y+xy^2$.)
