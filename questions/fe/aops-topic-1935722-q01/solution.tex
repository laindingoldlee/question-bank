For every integer $n$, the number $n^2-n=n(n-1)$ is a product of two consecutive integers, so it is even; hence $n^2$ and $n$ have the same parity. Therefore
\[
a+b+c\equiv a^2+b^2+c^2=2c^2\equiv0\pmod 2,
\]
so $a+b+c$ is even. $\blacksquare$

(Equivalently: $a$ and $b$ cannot both be odd, since then $a^2+b^2\equiv2\pmod4$ is not a square. If $a,b$ are both even then so is $c$, and if exactly one of them is odd then $c$ is odd. In every case an even number of $a,b,c$ are odd.)
