(a) Squares modulo $8$ are $0,1,4$, whereas $8n+10\equiv2$, so a square array is impossible. (b) An even cube is divisible by $8$, while an odd cube is odd. Neither can have residue $2$ modulo $8$, so a cubic array is also impossible.
