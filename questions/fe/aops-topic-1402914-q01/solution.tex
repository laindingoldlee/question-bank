\textbf{(a)} A terminating decimal $d_0.d_1d_2\dots d_k$ equals $\dfrac{N}{10^k}$ for the integer $N=\overline{d_0d_1\dots d_k}$, so it is rational. Since $\pi$ is irrational, its decimal expansion cannot terminate (and, for the same reason, it cannot eventually repeat either).

\textbf{(b)} Suppose, for contradiction, that $2\pi=\dfrac{p}{q}$ for integers $p,q$ with $q\ne0$. Then $\pi=\dfrac{p}{2q}$ is a ratio of integers, so $\pi$ is rational, contradicting the assumption. Hence $\tau=2\pi$ is irrational. (More generally, any nonzero rational multiple of an irrational number is irrational.)
