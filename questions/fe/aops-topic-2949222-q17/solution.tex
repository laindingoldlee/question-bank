For a fixed unique $m$, the allowed n-range is $9m\le n\le10m$. To exclude $m-1$ and $m+1$, we need $n>10(m-1)$ and $n<9(m+1)$. Thus $10m-9\le n\le9m+8$, implying $m\le17$. Consequently $n\le161$. For $n=161$, the interval $[\dfrac{n}{10},\dfrac{n}{9}]$ contains only 17, so $\boxed{161}$.
