(a) If the number of red widgets is $r$, the number of blue widgets is $3r$. Hence $4r=200$, so there are $\boxed{50\text{ red and }150\text{ blue}}$ per day. (b) Multiplying by five gives $\boxed{250\text{ red and }750\text{ blue}}$ per week.
