\textbf{(a)} $P(A)$ is the average of the conditional probability $f(\theta)=\dfrac{1}{2}-\dfrac{\theta}{2\pi}$ over the uniformly chosen $\theta$. Pair each $\theta$ with $\dfrac{\pi}{2}-\theta$, which is equally likely. Since $f$ is linear,
\[
\dfrac{f(\theta)+f\left(\dfrac{\pi}{2}-\theta\right)}{2}=\dfrac{1}{2}-\dfrac{1}{2\pi}\cdot\dfrac{\theta+\left(\dfrac{\pi}{2}-\theta\right)}{2}=\dfrac{1}{2}-\dfrac{1}{8}=\dfrac{3}{8}
\]
for every pair, so the average over all $\theta$ is $P(A)=\boxed{\dfrac{3}{8}}$. (With calculus: $P(A)=\dfrac{2}{\pi}\displaystyle\int_0^{\dfrac{\pi}{2}}\left(\dfrac{1}{2}-\dfrac{\theta}{2\pi}\right)d\theta=\dfrac{1}{2}-\dfrac{1}{8}=\dfrac{3}{8}$.)

\textbf{(b)} For a linear function $f(\theta)=p+q\theta$, the average of $f(\theta)$ is $p+q\cdot(\text{average of }\theta)=f\left(\dfrac{\pi}{4}\right)$; the pairing above is exactly this fact. So substituting the mean $\theta=\dfrac{\pi}{4}$ is valid because $\dfrac{1}{2}-\dfrac{\theta}{2\pi}$ is linear in $\theta$.

It fails for non-linear functions. For example, if the conditional probability were $g(\theta)=\left(\dfrac{2\theta}{\pi}\right)^2$, then with $t=\dfrac{2\theta}{\pi}$ uniform on $[0,1]$,
\[
P=\int_0^1t^2\,dt=\dfrac{1}{3},\qquad\text{while}\qquad g\left(\dfrac{\pi}{4}\right)=\dfrac{1}{4}\ne\dfrac{1}{3} .
\]
