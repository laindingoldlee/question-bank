By induction $a_n=5^{\,1-2^{-n}}$: indeed $a_1=5^{\dfrac{1}{2}}$, and if $a_n=5^{1-2^{-n}}$ then $a_{n+1}=\left(5\cdot5^{1-2^{-n}}\right)^{\dfrac{1}{2}}=5^{1-2^{-n-1}}$. As $n\to\infty$, $2^{-n}\to0$, so the limit is $5^1=\boxed{5}$.

(The shortcut "call the value $p$; then $p=\sqrt{5p}$, so $p=0$ or $p=5$" gives the right answer, but it assumes the limit exists, and it cannot by itself rule out $p=0$; the formula for $a_n$ settles both. In the same way $\sqrt{z\sqrt{z\sqrt{z\cdots}}}=z$ for every $z>0$.)
