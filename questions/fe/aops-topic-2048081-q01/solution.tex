Completing the square,
\[ax^2+bx+c=a\left(x+\dfrac {b}{2a}\right)^2-\dfrac{b^2-4ac}{4a}=a\left(x+\dfrac {b}{2a}\right)^2=a(x-r)^2 .\]
So $p(x)=a(x-r)(x-r)$: the linear factor $x-r$ occurs twice. The equation $p(x)=0$ has exactly one distinct solution, $x=r$. The statement that a quadratic has two roots (a consequence of the fundamental theorem of algebra) counts roots \emph{with multiplicity}, that is, according to how many times each linear factor appears. Here the root $r$ has multiplicity $2$, so the two roots are $r$ and $r$. There is no contradiction: $\boxed{p(x)=a(x-r)^2,\ \text{a double root at } r}$.

For example, $x^2-6x+9=(x-3)^2$ has the single solution $x=3$, which is a double root.
