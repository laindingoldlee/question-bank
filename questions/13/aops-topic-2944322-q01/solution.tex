Let $S=1+2^n+3^n+4^n$. Modulo $10$, $9\equiv-1$, $8\equiv-2$, $7\equiv-3$, $6\equiv-4$, so the expression is congruent to $(-1)^nS-S$. If $n$ is even this is $0$. If $n$ is odd it is $-2S$, so we need $5\mid S$: modulo $5$, $4^n\equiv(-1)^n=-1$ and $3^n\equiv(-2)^n=-2^n$, so $S\equiv1+2^n-2^n-1=0$. $\blacksquare$
