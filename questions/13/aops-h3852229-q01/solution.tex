The first word starts one phrase. Each subsequent word starts a new phrase exactly when its language differs from the previous word, an event of probability $\dfrac{3}{4}$. By linearity of expectation, no independence between these boundary indicators is needed:
\[
E=1+499\cdot\dfrac{3}{4}=\dfrac{1501}{4}.
\]
The fraction is reduced, so $\boxed{a+b=1505}$.
