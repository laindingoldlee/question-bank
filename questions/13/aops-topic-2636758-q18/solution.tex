For every $k$, the number $2^{k-1}$ has exactly $k$ divisors. For $k\le14$, $2^{k-1}\le8192<10000$. Also $144=2^4\cdot3^2$ has $15$ divisors and $120=2^3\cdot3\cdot5$ has $16$. So for every $k\le16$ some number below $10000$ has exactly $k$ divisors.

For $k=17$, which is prime, a number $n=\prod p_i^{e_i}$ with $\prod(e_i+1)=17$ must be a single prime to the $16$th power. The smallest is $2^{16}=65536$, which has five digits. So $k=\boxed{17}$.
