We have
\[a^5+b^5-a^3b^2-a^2b^3=a^3\left(a^2-b^2\right)-b^3\left(a^2-b^2\right)=\left(a^2-b^2\right)\left(a^3-b^3\right).\]
Both factors contain $a-b$:
\[\left(a^2-b^2\right)\left(a^3-b^3\right)=(a-b)^2(a+b)\left(a^2+ab+b^2\right)\ge0,\]
because $(a-b)^2\ge0$, $a+b>0$ and $a^2+ab+b^2>0$. Hence $a^5+b^5\ge a^3b^2+a^2b^3=(a+b)a^2b^2$, with equality exactly when $a=b$. $\blacksquare$

(The argument only uses $a,b>0$, so the hypothesis $a,b\ge1$ is stronger than needed.)
