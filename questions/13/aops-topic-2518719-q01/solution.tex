\textbf{(a)} By the difference of squares, $(n-k)(n+k)=n^2-k^2$, so $k^2+(n-k)(n+k)=n^2$.

\textbf{(b)} $(m+1)^2=m^2+2m+1$ by expanding. Adding these equations for $m=k,k+1,\dots,n-1$, the intermediate squares cancel (a telescoping sum):
\[n^2-k^2=\sum_{m=k}^{n-1}\left((m+1)^2-m^2\right)=\sum_{m=k}^{n-1}(2m+1).\]

\textbf{(c)} Using (a) with $k=410$ and $410^2=168100$:
\[413^2=168100+3\cdot823=168100+2469=170569.\]
Using (b) instead: $413^2=168100+821+823+825=170569$.

Using (a) with $k=2000$:
\[1997^2=2000^2+(1997-2000)(1997+2000)=4000000-3\cdot3997=4000000-11991=3988009.\]
So $413^2=\boxed{170569}$ and $1997^2=\boxed{3988009}$.
