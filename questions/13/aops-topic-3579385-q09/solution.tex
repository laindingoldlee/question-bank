Encode A, B, C, D as $(+,+),(-,-),(+,-),(-,+)$. In a row or column, both sign sums vanish exactly when A and B counts agree and C and D counts agree. Thus a valid filling is equivalent to an ordered pair of binary $4\times4$ matrices each having two $1$s in every row and column. Count such matrices. There are $6$ choices for the first row; fix it as $1100$. If the second row overlaps it in two positions, it is $1100$ and the final two rows are forced, giving one completion. If the overlap is zero, the second row is $0011$ and the third row can be any of six balanced rows, with the fourth forced. If the overlap is one, there are four choices for row two, each allowing two completions. This totals $1+6+4\cdot2=15$ per first row, or $90$ matrices. Hence $N=90^2=8100\equiv\boxed1\pmod7$, choice (B).
