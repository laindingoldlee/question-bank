Write the number as $\overline{abcabc}$ with digits $a,b,c$ and $a\ne0$. Let $m=\overline{abc}=100a+10b+c$. Then
\[
\overline{abcabc}=1000\cdot\overline{abc}+\overline{abc}=1001m.
\]
Since $1001=7\cdot11\cdot13$, the number equals $7\cdot11\cdot13\cdot m$, so it is divisible by each of $7$, $11$, and $13$. $\blacksquare$
