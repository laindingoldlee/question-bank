First write down the three digits that are not $1$; each is a $2$ or a $3$, giving $2^3=8$ choices. These three digits leave $4$ gaps (before the first, between neighbours, after the last):
\[
\_\ \ d\ \ \_\ \ d\ \ \_\ \ d\ \ \_
\]
Two $1$s are adjacent exactly when they are put into the same gap, so a valid number puts the three $1$s into three \emph{different} gaps, at most one $1$ per gap. Conversely, every number with no two adjacent $1$s arises this way exactly once (its non-$1$ digits determine the gaps). Choosing $3$ of the $4$ gaps can be done in $\dbinom43=4$ ways. So there are
\[
8\cdot4=\boxed{32}
\]
such numbers.
