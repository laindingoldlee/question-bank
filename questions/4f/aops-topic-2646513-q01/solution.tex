As the expression is a quadratic, $a>0$. The arithmetic condition is $b=\dfrac{a+c}{2}$, and a single root means $b^2=4ac$:
\[\dfrac{(a+c)^2}{4}=4ac\iff a^2-14ac+c^2=0\iff t^2-14t+1=0,\quad t=\dfrac ca.\]
Since $c\le a$, $t=7-4\sqrt3=\left(2-\sqrt3\right)^2$. The double root is
\[-\dfrac{b}{2a}=-\dfrac{a+c}{4a}=-\dfrac{1+t}{4}=-\dfrac{8-4\sqrt3}{4}=-2+\sqrt3,\]
which is $\boxed{\textbf{(D) }-2+\sqrt3}$. (Equivalently, the double root $r$ has $r^2=\dfrac ca$ and $r<0$, so $r=-\left(2-\sqrt3\right)$.)

In the attempted solution, $(a-c)^2=12ac$ is right, but with common difference $d$ we have $a-c=2d$, so $d^2=3ac$, not $4ac$.
