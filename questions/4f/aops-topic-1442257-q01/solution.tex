Suppose $f(x)=99$ and $x+99=m^2$. Since $m^2$ must be the \emph{least} square greater than $x$, we need $(m-1)^2\le x=m^2-99$, which means $2m-1\ge99$, i.e.\ $m\ge50$. Conversely for every $m\ge50$, $x=m^2-99$ satisfies $(m-1)^2\le x<m^2$, so $f(x)=m^2-x=99$.

So the values of $x$ with $f(x)=99$ are $m^2-99$ for $m=50,51,52,\dots$ (the first is $2401=49^2$, where the next square is $2500$). The $52$nd corresponds to $m=101$:
\[
x=101^2-99=10201-99=\boxed{10102}.
\]
