No. If $\dfrac n6=a^2$ with $a$ a positive integer, then $2n=12a^2=4\cdot3a^2$. This is a perfect square only if $3a^2$ is a perfect square, i.e. only if $3$ is the square of a rational number $\dfrac{c}{a}$, which it is not. $\blacksquare$
