(a) The numerator is $(x+y)^3+2xy(x+y)=343-420=-77$, and the denominator is $(-30)^2=900$. Thus the value is $\boxed{-\dfrac{77}{900}}$.
(b) Set $u=x^2\ge0$. Then $u+\dfrac{16}{81}u^2=25$, so $(u-9)(16u+225)=0$. Only $u=9$ is nonnegative; hence $\boxed{x=3,y=-4}$.
(c) Cancel $xy\ne0$ to get $\dfrac{x+y-2}{xy}=\dfrac{-3}{-12}=\dfrac{1}{4}$, so the denominator is $\boxed4$.
