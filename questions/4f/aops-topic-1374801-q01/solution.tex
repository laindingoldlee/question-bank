We have $\ln23000=\ln23+3\ln10\approx3.1355+6.9078=10.0432$. Then
\[
R=0.67\cdot10.0432+1.17\approx6.729+1.17=7.899,
\]
so $R\approx\boxed{7.9}$. The value $6.73$ is $0.67\ln E$ alone: the student forgot to add the constant $1.17$.
