Compute the values just below $1000$, in this order:
\begin{itemize}
\item $f(999)=f(f(1004))=f(1001)=998$,
\item $f(998)=f(f(1003))=f(1000)=997$,
\item $f(997)=f(f(1002))=f(999)=998$,
\item $f(996)=f(f(1001))=f(998)=997$,
\item $f(995)=f(f(1000))=f(997)=998$.
\end{itemize}
\textbf{Claim:} for $n<1000$, $f(n)=997$ if $n$ is even and $f(n)=998$ if $n$ is odd. This holds for $995\le n\le999$. For $n\le994$, assume it for all larger values below $1000$. Then $n+5<1000$ has the opposite parity to $n$. If $n$ is even, $f(n+5)=998$ and $f(n)=f(998)=997$; if $n$ is odd, $f(n+5)=997$ and $f(n)=f(997)=998$. This proves the claim by downward induction.

Since $84$ is even, $f(84)=\boxed{997}$.
