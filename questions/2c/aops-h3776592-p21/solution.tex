The function decreases on the positive axis, so
\[
b^2+6a=2025,\qquad a^2+6b=2025.
\]
Subtracting yields $(b-a)(a+b-6)=0$. If $a<b$, then $a+b=6$, which makes $b^2+6a<72$, impossible. Therefore $a=b=-3+\sqrt{2034}$, the positive root of $a^2+6a=2025$. Hence $\boxed{a+b=2\sqrt{2034}-6}$. If a nondegenerate interval were required, there would be no solution.
