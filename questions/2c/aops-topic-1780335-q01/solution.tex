Count by position. Units digit $1$: $1,11,21,\dots,91$, which is $10$ numbers. Tens digit $1$: $10,11,\dots,19$, another $10$ (the number $11$ is counted once in each list, correctly, since it contains two $1$s). Hundreds digit $1$: only $100$. In total $10+10+1=\boxed{21}$.
