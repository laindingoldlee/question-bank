Let $s=\sqrt x\ge0$. Then $s^2+s-1=0$, so $s=\dfrac{\sqrt5-1}{2}$ and $x=s^2=1-s=\dfrac{3-\sqrt5}{2}$. Then
\[
\dfrac{1}{x}=\dfrac{2}{3-\sqrt5}=\dfrac{2(3+\sqrt5)}{9-5}=\dfrac{3+\sqrt5}{2},
\]
so
\[
x+\dfrac{1}{x}=\dfrac{3-\sqrt5}{2}+\dfrac{3+\sqrt5}{2}=\boxed{3}.
\]
(Without solving: $\sqrt x=1-x$ squares to $x=1-2x+x^2$, so $x^2+1=3x$ and $x+\dfrac{1}{x}=3$.)
