Both sides are positive, so the inequality is equivalent to the one between their squares:
\[a+b\le\left(\sqrt a+\sqrt b\right)^2=a+b+2\sqrt{ab},\]
which is true because $\sqrt{ab}>0$. (In fact the inequality is strict.) $\blacksquare$
