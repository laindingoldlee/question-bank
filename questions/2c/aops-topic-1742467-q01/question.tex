A convex sequence is a sequence of integers in which each term other than the first and the last is no greater than the arithmetic mean of the terms immediately before and after it. For example, $4,1,2,3$ is convex because $1\le\dfrac{4+2}{2}$ and $2\le\dfrac{1+3}{2}$. How many convex sequences use each number of the set $\{1,2,3,4,5,6,7,8\}$ exactly once?
