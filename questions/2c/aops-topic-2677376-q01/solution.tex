``If $x=2$ then $x^2=4$'' is true. The converse ``if $x^2=4$ then $x=2$'' is false: $x=-2$ is a counterexample. So the ``if and only if'' statement is $\boxed{\text{false}}$; the correct statement is ``$x^2=4$ if and only if $x=2$ or $x=-2$''.
