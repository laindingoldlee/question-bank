Assume $ B\subseteq A $ and every element not in $ B $ is not in $ C $. The sets are not identical. Which conclusions necessarily hold: (i) $ A\subseteq C $; (ii) $ B\subseteq C $; (iii) $ C\subseteq A $; (iv) $ C\subseteq B $?
