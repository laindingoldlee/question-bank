\textbf{(a)} $x=11$ gives $9x=99$, whose digit sum is $18$.

\textbf{(b)} Let $s(n)$ be the digit sum of $n$. If $n=\sum d_k10^k$, then since $10^k\equiv1\pmod9$, $n\equiv\sum d_k=s(n)\pmod9$. As $9\mid9x$, we get $9\mid s(9x)$; and $s(9x)\ge1$ because $9x>0$ has a nonzero digit. So $s(9x)$ is a positive multiple of $9$.

Each replacement keeps the number a positive multiple of $9$, by the same argument. If $n\ge10$, then $n-s(n)=\sum d_k\left(10^k-1\right)>0$ because some digit beyond the units digit is nonzero, so the number strictly decreases. Hence the process reaches a one-digit number, which is a positive multiple of $9$, so it reaches $\boxed{9}$. $\blacksquare$
