Reversing a one-digit number does not change it, and reversing $100$ gives $001=1$, which is smaller. So Betty's number has two digits, say $10a+b$ with $1\le a\le9$ and $0\le b\le9$. Reversed it becomes $10b+a$, and the increase is
\[(10b+a)-(10a+b)=9(b-a).\]
This is positive, so $1\le b-a\le8$, and the increase is one of $9,18,27,36,45,54,63,72$. Only $72$ ends in $2$, so $b-a=8$, which forces $a=1$ and $b=9$. Betty's number is $\boxed{19}$ (and $91-19=72$).
