Each list has $9$ numbers, so the median is the $5$th number in increasing order.
\begin{itemize}
\item First list: $1,6,8,12,\mathbf{44},78,92,123,235$, median $44$.
\item Second list: $2,4,9,11,\mathbf{53},71,106,124,241$, median $53$.
\end{itemize}
The $\boxed{\text{median of the second list }(53)}$ is greater.
