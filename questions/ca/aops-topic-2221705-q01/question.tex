A student claims: ``A system of linear equations in $n$ unknowns has a solution only if it consists of $n$ independent equations.''
\begin{enumerate}
\item[(a)] Show that the claim is false: give a system of $2$ linear equations in $3$ unknowns that has a solution, and a system of $3$ linear equations in $2$ unknowns that has a solution.
\item[(b)] Prove the correct statement behind the claim in the smallest interesting case: a system of two linear equations in three unknowns,
\[a_1x+b_1y+c_1z=d_1,\qquad a_2x+b_2y+c_2z=d_2,\]
never has exactly one solution; if it has a solution, it has infinitely many.
\end{enumerate}
