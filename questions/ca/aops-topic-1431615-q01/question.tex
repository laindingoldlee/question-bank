There is no simple closed formula for the number of ways to write a positive integer $n$ as an unordered sum of positive integers, but some related counts are easy.
\begin{enumerate}
\item[(a)] In how many ways can $n$ be written as an \emph{ordered} sum of positive integers (for example $3=3=2+1=1+2=1+1+1$ gives $4$ ways)?
\item[(b)] Prove that the number of ways to write $n$ as an unordered sum of \emph{distinct} positive integers equals the number of ways to write $n$ as an unordered sum of \emph{odd} positive integers. List both kinds for $n=8$.
\end{enumerate}
