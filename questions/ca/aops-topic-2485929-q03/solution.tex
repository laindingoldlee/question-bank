\textbf{(a)} If $J(x)=c_nx^n+\cdots+c_1x+c_0$, then $J(1)=c_n\cdot1^n+\cdots+c_1\cdot1+c_0=c_n+\cdots+c_1+c_0$. $\blacksquare$

\textbf{(b)} By (a), $t=1$ works for every polynomial. Conversely, suppose $t$ works for every polynomial. Taking $J(x)=x$, whose coefficient sum is $1$, gives $J(t)=t=1$. So the only such value is $\boxed{t=1}$.
