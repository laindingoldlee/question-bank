A regular polygon has $2n$ vertices, where $n\ge2$. Repeat the following move until every vertex is either circled or crossed out: choose a vertex that is not yet marked, circle it, and cross out the vertex diametrically opposite to it. For which $n$ can this be done so that no two adjacent vertices end up with the same mark (both circled or both crossed out)?
