Five independent reels each show a uniformly random integer from $1$ to $10$. Reels are used in order, and payments accumulate. Reel 1 pays $2$ dollars for $1,2,3,5,7$. Reel 2 pays $8$ if reel 1 paid and reel 2 exceeds $7$; it pays $3$ if reel 1 did not pay and reel 2 is below $4$. Reel 3 pays $30$ on an odd result if both earlier reels paid, and $2$ on an odd result otherwise. Reel 4 pays $80$ on $7$ or $10$ only if the first three reels paid nothing. Reel 5 changes the total: results $1,6$ add $3,4$ respectively; results $8,9,10$ add $1$; results $2,3,4,5,7$ multiply it by $1.2,1.5,1.8,2,4$ respectively. Find the fair entry price (expected final payment) when using (a) one, (b) two, (c) three, (d) four, or (e) all five reels.
