\textbf{(a)} Since $z$ is an integer with $z<6$, $z\le5$. Then $x>10-z\ge10-5=5$, so $x\ge6$. And $x=6$ is possible, with $z=5$: $6+5=11>10$ and $5<6$. The least value is $\boxed{6}$.

\textbf{(b)} The inequality $x>4$ is true, but it is only a \emph{necessary} condition; it does not show that $x=5$ can actually occur. Adding inequalities loses information. Here the step also throws away integrality: from $z<6$ the integer $z$ satisfies $z\le5$, and using $-z\ge-5$ instead of $-z>-6$ gives $x>5$, the sharp bound. Checking $x=5$ directly: it would need $z>5$, contradicting $z\le5$. A lower bound only gives the minimum once it is shown to be attained.
