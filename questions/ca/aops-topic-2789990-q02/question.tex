A $3\times3\times3$ cube is built from $14$ red and $13$ blue unit cubes. A row is a line of $3$ cubes in one of the three directions ($27$ rows in all). (a) Can every row contain an odd number of red cubes? (b) Can every row contain an odd number of blue cubes?
