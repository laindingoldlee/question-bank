Choose the first row in $\binom42=6$ ways. Fix its two occupied columns. If the second row uses the same pair, the remaining two rows are forced:1 completion. If it uses the complementary pair, the third row can use any pair and the fourth is forced:6 completions. Otherwise it shares exactly one column; there are 4 such pairs. The remaining two rows must both use the column unused so far and split the two singly used columns, giving 2 completions each. Thus the total is $6(1+6+4\cdot2)=\boxed{90}$.
