There are $32$ subsets. Those lacking a factor of $2$ can use only $3,7$, giving $4$ subsets. Those lacking a factor of $3$ can use only $2,7,8$, giving $8$. Combinations lacking both can use only $7$, giving $2$. Inclusion--exclusion gives $32-4-8+2=\boxed{22}$.
