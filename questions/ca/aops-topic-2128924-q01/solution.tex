The left side is even, so $y^3$ is even and $y$ is even; write $y=2z$. Dividing by $8$,
\[x^3+x=z^3 .\]
\begin{itemize}
\item If $x>0$, then $x^3<x^3+x<x^3+3x^2+3x+1=(x+1)^3$, so $z^3$ lies strictly between the consecutive cubes $x^3$ and $(x+1)^3$, which is impossible for an integer $z$.
\item If $x<0$, then $(-x,-z)$ is a solution of the same equation with $-x>0$, which is impossible by the previous case.
\item If $x=0$, then $z^3=0$, so $z=0$.
\end{itemize}
Hence the only solution is $\boxed{(x,y)=(0,0)}$.
