Sort the denominators so that $a\le b\le c$. Since the other reciprocals are positive, $a>x$; and $\dfrac{1}{x}\le\dfrac{3}{a}$ gives $a\le3x$. For each integer $x<a\le3x$, set $r=\dfrac{1}{x}-\dfrac{1}{a}=\dfrac{a-x}{ax}>0$. The equation $r=\dfrac{1}{b}+\dfrac{1}{c}$ implies $b>\dfrac{1}{r}$ and $b\le\dfrac{2}{r}$, as well as $b\ge a$. Test these finitely many integers $b$. For each, the only possible value is $c=\dfrac{1}{r-\dfrac{1}{b}}=\dfrac{abx}{b(a-x)-ax}$. Retain it exactly when it is an integer with $c\ge b$. Every retained triple works by construction, and the derived bounds show none are missed. The procedure is nonempty because $(a,b,c)=(3x,3x,3x)$ always works.
