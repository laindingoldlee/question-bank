Let $x$ be real.
\begin{itemize}
\item If $x=0$, then $x^2=0$.
\item If $x>0$, then $x^2=x\cdot x$ is a product of two positive numbers, so $x^2>0$.
\item If $x<0$, then $-x>0$ and $x^2=(-x)(-x)>0$.
\end{itemize}
So $x^2\ge0$ always. If $a<0$ had a real square root $x$, then $x^2=a<0$, which is impossible. $\blacksquare$
