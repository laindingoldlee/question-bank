There are $2^5=32$ subsets, contributing $32\cdot4=128$ dollars in base costs. Each topping belongs to $2^4=16$ subsets, so topping costs total $5\cdot16\cdot\dfrac{1}{2}=40$ dollars. Total $\boxed{168\text{ dollars}}$.
