Write $a_j=\sin\theta_j$, where $0<\theta_j\le\dfrac{\pi}{2}$. Strict increase at step $j$ implies $2\sqrt{1-a_j^2}>1$, so $\theta_j<\dfrac{\pi}{3}$ for $j\le25$. For $j\le24$, if $\theta_j\ge\dfrac{\pi}{4}$, the recurrence would give $\theta_{j+1}=\pi-2\theta_j>\dfrac{\pi}{3}$, a contradiction. Thus $\theta_{j+1}=2\theta_j$ for $j\le24$. Consequently $2^{25}\theta_0=\theta_{25}<\dfrac{\pi}{3}$. Since $\sin t<t$ for positive $t$, $a_0<\dfrac{\pi}{3\cdot2^{25}}<10^{-7}$.
