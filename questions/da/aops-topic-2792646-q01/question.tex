Jody and Shelli each receive a box of buttons on Saturday and on Sunday; each button is red or white, and each box contains $1$ to $100$ buttons. On each day the percentage of red buttons in Jody's box is greater than in Shelli's. If $J\%$ of all Jody's buttons and $S\%$ of all Shelli's buttons are red, what is the least possible value of $J-S$, to the nearest integer?
