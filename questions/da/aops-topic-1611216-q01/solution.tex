\textbf{First list.} The sum is $122+145+198+241+5+67+12+41=831$ for $8$ numbers, so the average is $\dfrac{831}{8}=103.875$.

\textbf{Second list.} The sum is $123+144+199+240+6+11+42=765$ for $7$ numbers, so the average is $\dfrac{765}{7}=109\dfrac{2}{7}\approx109.29$.

The $\boxed{\text{average of the second list}}$ is greater. (The lists almost match number by number, but the first list also contains $67$, which is well below the other numbers' average and pulls its average down.)
