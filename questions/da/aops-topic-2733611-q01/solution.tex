$x\cdot10^y-x=x\left(10^y-1\right)$, so the condition for all $x$ is $99\mid10^y-1$. Since $10^2=100\equiv1\pmod{99}$, $10^y\equiv1$ when $y$ is even and $10^y\equiv10$ when $y$ is odd. So it holds exactly for $\boxed{\text{even }y}$. For odd $y$ it fails, e.g. $x=1$, $y=1$ gives $9$.
