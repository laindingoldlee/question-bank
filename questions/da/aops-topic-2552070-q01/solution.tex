Fix the shutdown interval: it is a $10$-minute interval inside the $60$-minute hour, so a uniformly random visiting time falls in it with probability $\dfrac{10}{60}$. This holds for every possible shutdown time, so averaging over the shutdown time does not change it. The probability is $\boxed{\dfrac16}$.
