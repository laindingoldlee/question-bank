Inserting parentheses fully means choosing, recursively, which of the four operations is performed last. Split on the last operation.

\textbf{First, the shorter pieces.}
\begin{itemize}
\item $20+9-14$: $(20+9)-14=20+(9-14)=15$.
\item $20+9-14-12$: the possible values are $((20+9)-14)-12=3$, $(20+(9-14))-12=3$, $20+((9-14)-12)=3$, $(20+9)-(14-12)=27$, $20+(9-(14-12))=27$; so $3$ or $27$.
\item $14-12\times6$: $(14-12)\times6=12$ or $14-(12\times6)=-58$.
\item $9-14-12\times6$: $((9-14)-12)\times6=-102$, $(9-(14-12))\times6=42$, $(9-14)-(12\times6)=-77$, $9-((14-12)\times6)=-3$, $9-(14-(12\times6))=67$.
\end{itemize}

\textbf{The last operation.}
\begin{itemize}
\item $\times$ last: $(20+9-14-12)\times6\in\{3\cdot6,\ 27\cdot6\}=\{18,162\}$.
\item the second $-$ last: $(20+9-14)-(12\times6)=15-72=-57$.
\item the first $-$ last: $(20+9)-(14-12\times6)\in\{29-12,\ 29+58\}=\{17,87\}$.
\item $+$ last: $20+(9-14-12\times6)\in\{-82,62,-57,17,87\}$.
\end{itemize}

So the only obtainable values are
\[
-82,\ -57,\ 17,\ 18,\ 62,\ 87,\ 162 ,
\]
the largest being $\boxed{162}=\bigl(20+9-(14-12)\bigr)\times6$. Since $517$ is not among them, no placement of parentheses gives $517$. $\blacksquare$
