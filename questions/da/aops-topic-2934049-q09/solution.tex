The bottom row must be entirely black. Remove it and subtract 1 from all column requirements; the last column then has requirement 0, so it is entirely white in the remaining rows. Removing that column leaves exactly the same problem on a 5-by 5 grid. Repeating forces the entire pattern, with row $r$ black exactly in its first $r$ columns. It satisfies all counts, so there is $\boxed1$ colouring.
\begin{asy}
usepackage("amsmath");
size(7cm);
for(int r=1;r<=6;++r)for(int c=1;c<=6;++c)filldraw((c-1,6-r)--(c,6-r)--(c,7-r)--(c-1,7-r)--cycle,c<=r?black:white);label("row counts 1 to 6",(3,-.5));
\end{asy}
