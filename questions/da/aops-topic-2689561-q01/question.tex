Using a $26$-letter alphabet, call a string \emph{palindrome starting} if for some integer $n\ge6$ its first $n$ letters form a palindrome, and its first $6$ letters are not all the same. Write the number of palindrome-starting strings of length $15$ in base $26$, and find the sum of its digits.
