For a number $x$ that is not an integer, $\lceil x\rceil=\lfloor x\rfloor+1$. Let $F$ be the sum of the $30$ rounded-down values (Wednesday's sum), and let there be $R$ red and $B$ blue numbers, $R+B=30$.

On Monday each red number contributes one more than its rounded-down value, so the Monday sum is $F+R=2018$. Similarly the Tuesday sum is $F+B=2014$. Adding, $2F+30=4032$, so
\[
F=\boxed{2001}.
\]
(Also $R-B=4$, so $R=17$ and $B=13$.)
