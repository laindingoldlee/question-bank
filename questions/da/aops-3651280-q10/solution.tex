An exhaustive reduction uses the opposite vertices $a,c$. For each $1\le a<c\le100$, compute $s_b=\gcd(a,b)+\gcd(b,c)$ for the 98 values $b\notin\{a,c\}$. The greatest cycle value for those opposite vertices is the sum of the two largest $s_b$ values, from distinct choices $b,d$. This examines every permissible cycle and proves the finite maximum test complete. Evaluating the 4950 opposite pairs gives maximum $\boxed{128}$, attained by $(a,b,c,d)=(32,96,48,64)$: the four gcds are $32,48,16,32$. All intermediate gcds can be computed by Euclid' s algorithm, so the check uses only exact integer operations.
