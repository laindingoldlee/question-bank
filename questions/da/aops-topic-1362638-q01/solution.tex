Let $d=\gcd(b,m)>1$ and suppose, for contradiction, that $bx\equiv1\pmod m$ for some integer $x$. Then $bx-1=km$ for some integer $k$, so
\[
1=bx-km .
\]
Now $d$ divides $b$ and $d$ divides $m$, so $d$ divides $bx-km=1$. This is impossible because $d>1$. Hence no inverse exists. $\blacksquare$

(Conversely, if $\gcd(b,m)=1$, B\'ezout's identity gives integers $x,y$ with $bx+my=1$, and this $x$ is an inverse of $b$ modulo $m$.)
