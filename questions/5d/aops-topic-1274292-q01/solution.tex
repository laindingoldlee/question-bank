Adding $1$ to both sides, $(x^2+1)(y^2+1)=504^4+4$. By the Sophie Germain identity $a^4+4=(a^2-2a+2)(a^2+2a+2)$ with $a=504$,
\[
504^4+4=(504^2-2\cdot504+2)(504^2+2\cdot504+2)=(503^2+1)(505^2+1),
\]
so $(x,y)=(505,503)$ is a solution.

\textbf{Uniqueness.} Since $x>y$, $(y^2+1)^2<(x^2+1)(y^2+1)=504^4+4<(504^2+1)^2$, so $y^2+1\le504^2$ and $y\le503$. For each $y$ from $1$ to $503$, $x$ is determined by $x^2=\dfrac{504^4+4}{y^2+1}-1$, and one checks (a finite computation, done by computer) that this is a perfect square only for $y=503$. Hence the unique solution is $\boxed{(x,y)=(505,503)}$.
