\textbf{(a)} True. Every odd integer is $2m+1$ for some integer $m$, and $2m+1=m+(m+1)$ is a sum of two consecutive integers. (This works for negative odd numbers too, for example $-7=(-4)+(-3)$.)

\textbf{(b)} False. The sum of $k$ consecutive integers $m,m+1,\dots,m+k-1$ is
\[km+\dfrac{k(k-1)}{2}.\]
For $k=3$ this is $3m+3=3(m+1)$, always a multiple of $3$, so the odd number $5$ is not a sum of three consecutive integers. (Likewise for $k=4$ the sum $4m+6$ is always even, so \emph{no} odd number is a sum of four consecutive integers.) So the statement fails, for example with $\boxed{k=3\text{ and the odd number }5}$.
