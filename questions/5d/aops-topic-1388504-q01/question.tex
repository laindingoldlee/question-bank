Each of the ten digits $0,1,2,\dots,9$ is written in exactly one of the ten asterisks so that the equation
\[
**+**+*+*+*+*=**
\]
holds, where $**$ denotes a two-digit number (whose first digit is not $0$) and $*$ a one-digit number. Find all possible values of the two-digit number on the right-hand side, and give a valid assignment for each.
