Write $N=3q$. Then $1000\le q\le3333$. Equal digit multisets imply equal digit sums, so $3q\equiv q\pmod9$ and $q\equiv0\pmod9$. This reduces the search to the $259$ integers $q=1008,1017,\ldots,3330$. For each, discard $q$ or $3q$ if it contains $2$ or $4$, then compare their four sorted digits. The only surviving pair is $q=1035$, $3q=3105$. This is an exhaustive finite procedure: the bounds cover every four-digit quotient, divisibility by nine was necessary, and the final test is exactly the required condition. Directly, both numbers use $0,1,3,5$. Thus $\boxed{N=3105}$.
