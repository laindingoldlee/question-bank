Write the number as $\overline{d_1d_2\,5\,d_4d_5}$.
\begin{itemize}
\item $d_1\in\{4,5,6\}$, but $5$ is already used: $2$ choices.
\item $d_5$ is odd and not $5$: $d_5\in\{1,3,7,9\}$, $4$ choices (none equals $d_1$, which is even).
\item $d_2$ and $d_4$ are chosen from the $10-3=7$ remaining digits, in order: $7\cdot6=42$ choices.
\end{itemize}
In total $2\cdot4\cdot42=\boxed{336}$.
