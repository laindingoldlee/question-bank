Digits \(A,B,C\) satisfy \(0\le A,B,C\le 9\), and the two-digit strings \(\overline{AB}\), \(\overline{BC}\), \(\overline{CA}\) (leading zeros allowed) satisfy \(\overline{AB}+\overline{BC}+\overline{CA}=88\). Find the maximum value of \(A\cdot B\cdot C\).

\(\textbf{(A) } 18 \qquad\textbf{(B) } 36 \qquad\textbf{(C) } 72 \qquad\textbf{(D) } 144 \qquad\textbf{(E) } 486\)
