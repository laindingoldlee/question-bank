In base $b$ the numeral $10$ means $b$, so $\dfrac{b}{2}=3$ and $b=6$. Check the second equation: $20_6=12$ and $\dfrac{12}{3}=4$. So the base is $6$.

Then $55_6=5\cdot6+5=35$, and $35+1=36=1\cdot6^2$, so
\[55+1=\boxed{100}\quad\text{(in base }6\text{, the number }36\text{)}.\]
(Directly: $5+1=10_6$, so the units digit is $0$ with a carry, and $5+1=10_6$ again in the sixes place.)
