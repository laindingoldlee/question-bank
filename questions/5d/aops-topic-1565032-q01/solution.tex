Write $n=10a+b$ with digits $1\le a\le9$, $0\le b\le9$. Since $P(n)=ab\le9a$ and $n\ge10a$,
\[
n^2-136=15ab\le135a<14n\qquad\Longrightarrow\qquad n^2-14n-136<0\qquad\Longrightarrow\qquad n<7+\sqrt{185}<21 .
\]
Also $n^2=15ab+136\ge136$, so $n\ge12$. Check $n=12,\dots,20$:
\begin{itemize}
\item $n=12$: $15\cdot2=30$, but $144-136=8$.
\item $n=13$: $45$ vs $33$.
\item $n=14$: $15\cdot4=60$ and $196-136=60$. It works.
\item $n=15,\dots,19$: $75,90,105,120,135$ vs $89,120,153,188,225$; the right side is larger from $n=16$ on.
\item $n=20$: $0$ vs $264$.
\end{itemize}
So $n=\boxed{14}$.
