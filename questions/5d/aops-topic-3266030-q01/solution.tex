For nonzero $b$, the quotient $\dfrac{a}{b}$ is the unique real $x$ satisfying $bx=a$. For $a=1,b=0$, this would require $0x=1$, impossible because $0x=0$ for every real $x$. Neither quotient is defined as a real number, so there is no equality to multiply by zero. Naming an infinite symbol does not extend the real division laws in this way.
