Let $k$ be the common value, and put $X=b+6\ge7$ and $Y=c+5\ge6$. Then $X=kY$, so $k=\dfrac {X}{Y}$ is a positive rational number. Also $a-1997=kX=k^2Y$, and
\[Y-2=c+3=k(a-2011)=k\bigl((a-1997)-14\bigr)=k^3Y-14k,\]
so
\[Y(k^3-1)=14k-2 .\tag{1}\]
If $k=1$, (1) reads $0=12$, impossible. If $k<1$, then $k^3-1<0$, and since $Y>0$ we need $14k-2<0$; but then $Y=\dfrac{2-14k}{1-k^3}<\dfrac{2}{1-k^3}<\dfrac{2}{1-\dfrac{1}{343}}<3$, contradicting $Y\ge6$. So $k>1$. Moreover $Y\ge6$ gives $14k-2\ge6k^3-6$, i.e.\ $6k^3-14k-4\le0$, which fails at $k=2$ and for all larger $k$. Hence $1<k<2$.

Write $k=\dfrac {p}{q}$ in lowest terms, so $q<p<2q$. From (1),
\[Y=\dfrac{q^2(14p-2q)}{p^3-q^3}.\]
Since $\gcd(p^3-q^3,q)=\gcd(p^3,q)=1$, the integer $p^3-q^3$ must divide $14p-2q$. As $p-q\ge1$ and $q>\dfrac {p}{2}$,
\[p^3-q^3\ge p^2+pq+q^2>\dfrac{7}{4}p^2,\qquad 14p-2q<14p,\]
so $\dfrac{7}{4}p^2<14p$, giving $p\le7$. Checking the coprime pairs with $\dfrac {p}{2}<q<p\le7$:
\[\begin{array}{c|ccccccc}
(p,q)&(3,2)&(4,3)&(5,3)&(5,4)&(6,5)&(7,4),(7,5),(7,6)\\\hline
p^3-q^3&19&37&98&61&91&279,\ 218,\ 127\\
14p-2q&38&50&64&62&74&90,\ 88,\ 86
\end{array}\]
Only $(p,q)=(3,2)$ works ($19\mid38$). Then $k=\dfrac{3}{2}$, $Y=\dfrac{4\cdot38}{19}=8$, $X=kY=12$, and $a-1997=kX=18$. So $c=3$, $b=6$, $a=2015$.

Check: $\dfrac{18}{12}=\dfrac{12}{8}=\dfrac{6}{4}=\dfrac{3}{2}$. The only solution is $\boxed{(a,b,c)=(2015,6,3)}$.
