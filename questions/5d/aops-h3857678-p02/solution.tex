The year difference is $100+9(B-A)$, so test $B^A=100+9(B-A)$ for digits $A,B$. For a finite enumeration, $A=0,1$ gives no solution; for $A=2,\ldots,9$ compare each digit power $0^A,\ldots,9^A$ with the corresponding right side. The sole pair is $(A,B)=(6,2)$: $2^6=64=2026-1962$. Thus $\boxed{A+B=8}$, choice D.
