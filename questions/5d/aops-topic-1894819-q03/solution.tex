The only odd digit is $1$, so the last digit is $1$. The first digit cannot be $0$ (or $1$), so it is $4$, $6$ or $8$: $3$ choices. The two middle digits are then chosen in order from the remaining $3$ digits: $3\cdot2=6$ ways. The answer is $3\cdot6=\boxed{18}$.
