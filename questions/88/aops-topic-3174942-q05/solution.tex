There are $\binom84=70$ equally likely empty-seat sets. Four consecutive empties form one run and can start in $8$ positions. Otherwise a qualifying set has exactly a run of three and one isolated empty seat. There are $8$ choices for the start of the triple and $3$ choices for the isolated seat, which must avoid the triple and its two neighboring seats. These $24$ sets are distinct because each has a unique triple. Thus the probability is $\dfrac{8+24}{70}=\boxed{\dfrac{16}{35}}$.
