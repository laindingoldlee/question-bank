Let there be $g$ gold, $s$ silver and $b$ bronze coins, with $6g+2s+5b=100$ and $g,s,b\ge1$. Gold is worth $5$ droubles per gram, silver $4$ and bronze $3$, so
\[
30g+8s+15b=5(6g+2s+5b)-2s-10b=500-(2s+10b).
\]
We must make $2s+10b$ as small as possible.

From $6g=100-2s-5b$, the number $5b$ must be even, so $b$ is even and $b\ge2$. With $b=2$ we need $6g=90-2s$, i.e. $s\equiv0\pmod3$, so $s\ge3$; then $2s+10b\ge6+20=26$. With $b\ge4$ already $2s+10b\ge2+40=42$. So $2s+10b\ge26$, with equality for $b=2$, $s=3$, $g=14$ (check: $84+6+10=100$ grams).

The greatest value is $500-26=\boxed{474}$ droubles.
