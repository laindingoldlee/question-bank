Let Billy read $p$ pages per day, so Arnold reads $2p$. Suppose they reach $\dfrac23$ of the book when Arnold has read for $t$ days (Billy for $t+2$ days). Then $2pt=p(t+2)$, so $t=2$, and $\dfrac23$ of the book is $4p$ pages; the book has $6p$ pages.

Arnold reads the last $2p$ pages in $1$ more day, during which Billy reads $p$ pages. So when Arnold finishes, Billy has read $5p$ pages, $p$ pages behind. Hence $p=\boxed{10}$ pages per day (and the book has $60$ pages).
