Powers of $3$ modulo $5$ repeat with period $4$: $3,4,2,1$; since $4143\equiv3\pmod4$, $3^{4143}\equiv2$. Powers of $2$ modulo $5$ repeat as $2,4,3,1$; since $2006\equiv2\pmod4$, $2^{2006}\equiv4$. So the sum is $\equiv2+4=6\equiv\boxed{1}\pmod5$.
