Reorder so $a\le b\le c$. Then $a\ne1$ and $\dfrac{3}{a}\ge\dfrac{6}{7}$, so $a=2$ or $3$. If $a=3$, the remaining sum $\dfrac{11}{21}$ forces $3\le b\le\dfrac{42}{11}<4$, hence $b=3$, giving nonintegral $c=\dfrac{21}{4}$. If $a=2$, the remaining sum is $\dfrac{5}{14}$ and $3\le b\le5$. For $b=3,4,5$, respectively, $c=42,\dfrac{28}{3},\dfrac{70}{11}$. Only $(2,3,42)$ works. Thus $\boxed{a+b+c=47}$.
