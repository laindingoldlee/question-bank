$\sqrt{-6}\cdot\sqrt{-6}=\left(i\sqrt6\right)^2=i^2\cdot6=\boxed{-6}$, while $\sqrt{(-6)(-6)}=\sqrt{36}=\boxed{6}$.

The rule $\sqrt a\sqrt b=\sqrt{ab}$ holds for $a,b\ge0$: both sides are nonnegative and have the same square $ab$. When $a,b<0$, the left side is $\left(i\sqrt{|a|}\right)\left(i\sqrt{|b|}\right)=-\sqrt{ab}$, which is negative, so the rule fails (it gives the wrong sign).
