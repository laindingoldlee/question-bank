Let $p$ be the probability of heads, with $0<p<\dfrac12$. Exactly $3$ heads in $4$ flips has probability $\dbinom43p^3(1-p)=4p^3(1-p)$, so
\[p^3(1-p)=0.0064=\dfrac{4}{625}.\]
The value $p=\dfrac15$ works: $\dfrac1{125}\cdot\dfrac45=\dfrac4{625}$. It is the only solution below $\dfrac12$, because $f(p)=p^3(1-p)$ is increasing for $0\le p\le\dfrac34$ (as $f(p)=p^3-p^4$ and $f'(p)=p^2(3-4p)>0$ there). So $p=\boxed{\dfrac15}$.

(Without the extra condition there is a second solution: $f\left(\dfrac34\right)=\dfrac{27}{256}>\dfrac4{625}$ and $f(1)=0$, so $f(p)=\dfrac{4}{625}$ also has a root between $\dfrac34$ and $1$, about $0.9935$. It is a root of $125p^3-100p^2-20p-4=0$, which has no rational root in that interval, so it is not a common fraction.)
