Tomorrow there will be exactly one of: rain (probability $40\%$), hail ($50\%$) or a flash flood ($10\%$). If it rains, there is a $15\%$ chance that it also rains the day after. If there is hail, there is a $20\%$ chance that a hailstorm arises. If there is a flash flood, there is a $96\%$ chance that it fades quickly and a $4\%$ chance that it stays. What is the probability that one of the following happens: there is a flash flood that does not fade; there is hail but no hailstorm arises; it rains and also rains the day after?
