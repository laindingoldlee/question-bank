$x^2+9x-162=(x-9)(x+18)=0$, so $\boxed{x=9\text{ or }x=-18}$. The new equation factors as $x(x-9)(x+18)=0$. Multiplying by $x$ is not reversible when $x=0$ (both sides become $0$), so it adds the root $x=0$, which does not satisfy the original equation ($0\ne162$). It is an extraneous solution.
