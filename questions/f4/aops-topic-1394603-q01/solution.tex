Let $t=\log_A B$. Then $\log_B A=\dfrac{1}{t}$, so $t=\dfrac{1}{t}$ and $t=\pm1$. If $t=1$ then $B=A$, which is excluded. So $t=-1$, that is $B=A^{-1}$, and
\[
AB=\boxed{1}.
\]
Conversely, every $A>0$ with $A\ne1$ and $B=\dfrac{1}{A}$ works: $\log_A\dfrac{1}{A}=-1=\log_{\dfrac{1}{A}}A$. So the condition holds exactly when $B=\dfrac{1}{A}$.
