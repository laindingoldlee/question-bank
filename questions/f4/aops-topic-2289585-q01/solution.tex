If every man builds at the same constant rate, the number of houses $H$ built is proportional to the number of men $M$ (twice as many men build twice as many houses in the same time) and to the number of days $D$ (twice as many days give twice as many houses). So $H$ varies jointly with $M$ and $D$:
\[H=kMD,\qquad k=\dfrac{H}{MD}=\dfrac{4}{2\cdot3}=\dfrac23,\]
and $k$ is the number of houses one man builds in one day (``houses per man-day''). For $6$ men and $16$ houses,
\[16=\dfrac23\cdot6\cdot D=4D,\qquad D=\boxed{4}\text{ days}.\]
