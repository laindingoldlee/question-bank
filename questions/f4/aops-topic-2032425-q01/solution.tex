(a) Since $\dfrac{a}{b}<\dfrac{p}{q}$ and $b,q>0$, we have $pb-aq>0$; it is an integer, so $pb-aq\ge1$. Similarly $\dfrac{p}{q}<\dfrac{c}{d}$ gives $cq-pd\ge1$. Now
\[
b(cq-pd)+d(pb-aq)=bcq-adq=q(bc-ad)=q.
\]
Hence $q\ge b\cdot1+d\cdot1=b+d$.

If $q=b+d$, equality must hold in both bounds: $pb-aq=1$ and $cq-pd=1$. This is a linear system in $p,q$ whose determinant is $b\cdot c-(-a)(-d)=bc-ad=1\ne0$, so it has exactly one solution. The pair $p=a+c$, $q=b+d$ is a solution, because $(a+c)b-a(b+d)=bc-ad=1$ and $c(b+d)-(a+c)d=bc-ad=1$. So the only fraction with denominator $b+d$ strictly between the two is $\dfrac{a+c}{b+d}$ (and it does lie between them, since $pb-aq=1>0$ and $cq-pd=1>0$).

(b) With $\dfrac{a}{b}=\dfrac{7}{11}$ and $\dfrac{c}{d}=\dfrac{9}{14}$ we have $bc-ad=11\cdot9-7\cdot14=99-98=1$. By part (a), every fraction strictly between them has denominator at least $25$, and the only one with denominator $25$ is
\[\boxed{\dfrac{16}{25}}.\]
(Indeed $\dfrac{7}{11}\approx0.636<0.64<0.643\approx\dfrac{9}{14}$.)
