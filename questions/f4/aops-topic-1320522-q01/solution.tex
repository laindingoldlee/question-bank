Treat $y^2+0\cdot y+(x-4)=0$ as a quadratic in $y$. The quadratic formula gives
\[
y=\dfrac{0\pm\sqrt{0-4(x-4)}}{2}=\pm\sqrt{4-x}.
\]
For every $x<4$ there are two different values of $y$; for example $x=0$ gives $y=2$ and $y=-2$, so the points $(0,2)$ and $(0,-2)$ are both on the graph. A function assigns only one output to each input, so the graph is not the graph of a function of $x$. (It is a function of $y$: $x=4-y^2$.)
