For the row-by-row list, an inversion is a pair of entries out of increasing order. Swapping adjacent entries changes the inversion count by exactly one. Hence at least as many swaps as the starting inversion count are necessary.

Conversely, whenever a list is unsorted it contains an adjacent inverted pair; swapping that pair decreases the count by one. Repeating sorts the list using exactly the inversion count. The largest possible count occurs in decreasing order, when every pair is inverted:
\[
\boxed{\binom{36}{2}=630}.
\]
