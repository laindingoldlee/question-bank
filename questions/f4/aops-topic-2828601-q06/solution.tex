$\sin^{-1}$ returns the angle in $\left[-90^\circ,90^\circ\right]$ with the given sine. Since $\sin45^\circ=\dfrac{\sqrt2}2$,
\begin{asy}
usepackage("amsmath");
size(5cm);
defaultpen(fontsize(10pt));
draw(circle((0,0),1));draw((-1.3,0)--(1.3,0),Arrow);draw((0,-1.3)--(0,1.3),Arrow);pair P=dir(45);
draw((0,0)--P);draw(P--(P.x,0),dashed);dot(P);label("$\left(\dfrac{\sqrt2}2,\dfrac{\sqrt2}2\right)$",P,NE);draw(arc((0,0),0.3,0,45));label("$45^\circ$",0.3*dir(22),E);
\end{asy}

the answer is $\boxed{45^\circ=\dfrac\pi4}$.
