Find the flaw in the following ``proof'' that $0^0=1$:

``Divide $0^0$ by $0$. By the rule $\dfrac{a^m}{a^n}=a^{m-n}$ this is $0^{-1}=\dfrac{1}{0}$. So $\dfrac{1}{0}=\dfrac{0^0}{0}$, and therefore $1=0^0$.
