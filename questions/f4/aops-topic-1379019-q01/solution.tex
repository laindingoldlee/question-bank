The argument divides by $0$ twice, and division by $0$ is undefined.
\begin{itemize}
\item The rule $\dfrac{a^m}{a^n}=a^{m-n}$ is proved only for $a\ne0$: it comes from cancelling factors of $a$, which is not allowed when $a=0$. So the step $\dfrac{0^0}{0}=0^{-1}$ is unjustified, and $0^{-1}=\dfrac{1}{0}$ is itself undefined.
\item The last step ``$\dfrac{1}{0}=\dfrac{0^0}{0}$, so $1=0^0$'' multiplies both sides by $0$ to clear denominators; but $\dfrac{1}{0}$ and $\dfrac{0^0}{0}$ are not numbers at all, so there is no equation to begin with. (The same reasoning would ``prove'' $1=2$ from $\dfrac{1}{0}=\dfrac{2}{0}$.)
\end{itemize}
So the argument proves nothing. Whether $0^0$ is assigned a value is a matter of definition: in algebra and combinatorics it is usually defined to be $1$ (so that formulas like $(x+y)^n=\sum\dbinom{n}{k}x^ky^{n-k}$ and $x^0=1$ hold for all $x$), while in analysis it is often left undefined because $x^y$ has no limit at $(0,0)$; but no such definition can be derived by this kind of manipulation.
