Let $n=16S$, where $S$ is the digit sum of $n$.

\emph{Size.} If $n$ has $d$ digits, then $n\ge10^{d-1}$ and $S\le9d$, so $10^{d-1}\le144d$, which forces $d\le3$; hence $S\le27$.

\emph{Mod $9$.} A number is congruent to its digit sum modulo $9$, so $16S\equiv S$, that is, $9\mid15S$, so $3\mid S$.

So $S\in\{3,6,\dots,27\}$. Check $n=16S$:
\[
\begin{array}{c|ccccccccc}
S&3&6&9&12&15&18&21&24&27\\ \hline
16S&48&96&144&192&240&288&336&384&432\\
\text{digit sum}&12&15&9&12&6&18&12&15&9
\end{array}
\]
The digit sum equals $S$ exactly for $S=9,12,18$. The numbers are $\boxed{144,\ 192,\ 288}$.
