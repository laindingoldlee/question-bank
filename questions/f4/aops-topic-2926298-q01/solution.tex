The first condition is $y\le-(x-2)^2$. The two boundary curves meet where $-(x-2)^2=x^2+2x-8$, i.e. $2x^2-2x-4=0$, at $x=-1$ and $x=2$. Their difference is $(x^2+2x-8)+(x-2)^2=2(x+1)(x-2)$, which is negative exactly for $-1<x<2$.
\begin{asy}
usepackage("amsmath");
size(4cm);
defaultpen(fontsize(10pt));
import graph;real f(real x){return -(x-2)^2;}real g(real x){return x^2+2*x-8;}
draw(graph(f,-2.5,4.5));draw(graph(g,-4.8,2.8),dashed);draw((-5,0)--(5,0),Arrow);draw((0,-14)--(0,3),Arrow);
dot((2,0));dot((-1,-9));label("$(2,0)$",(2,0),NE);label("$(-1,-9)$",(-1,-9),W);
\end{asy}

So the solution set is
\[\boxed{\{(x,y):\ y<x^2+2x-8\text{ if }-1\le x\le2;\ \ y\le-(x-2)^2\text{ otherwise}\}}.\]
At $x=-1$ and $x=2$ both bounds are equal, and the strict inequality applies.
