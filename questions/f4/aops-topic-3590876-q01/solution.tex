Write $N=s^2-1=(s-1)(s+1)$ with $32\le s\le100$. Since $N$ ends in $99$, $s^2$ is divisible by $100$, so $s$ is a multiple of $10$. Both factors exceed $1$, so each must be prime. The possible $s$ are $40,50,60,70,80,90,100$. The pairs $(s-1,s+1)$ are $(39,41),(49,51),(59,61),(69,71),(79,81),(89,91),(99,101)$. Only $(59,61)$ consists of two primes. Therefore only $3599$ works and the answer is $\boxed1$.
