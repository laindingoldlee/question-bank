The remainder $3$ on division by $10$ means the units digit is $3$: $N\in\{13,23,\ldots,93\}$. The remainder $1$ on division by $9$ means the digit sum is $\equiv1\pmod9$: for $N=\overline{d3}$ we need $d+3\equiv1$, so $d\equiv7\pmod 9$, i.e.\ $d=7$. So $N=73$ (unique, as the conditions fix $N$ modulo $90$).

Then $73=6\cdot11+7$, so the remainder is $\boxed{\textbf{(E) }7}$.
