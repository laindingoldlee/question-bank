Label cube vertices by three binary coordinates; each step flips one coordinate. A walk returns exactly when all three flip counts are even. Parity filtering gives the count $\dfrac{(1+1+1)^{10}+3(1+1-1)^{10}+3(1-1-1)^{10}+(-1-1-1)^{10}}{8}=\dfrac{2\cdot3^{10}+6}{8}=\boxed{14763}$. Each of the $3^{10}$ walks is equally likely, so this is the requested numerator.

\end{asy}
