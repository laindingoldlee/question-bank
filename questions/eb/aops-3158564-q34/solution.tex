For integer endpoints, compute $L=\log_{2015}(2015!)=\sum_{j=1}^{2015}\log_{2015}j\approx1750.78103448$. Hence $\boxed{a=1750,b=1751}$ work. Their width is one, giving the maximum score 20. Bounds can be verified with directed rounding of the sum; the value is over 0.2 away from either endpoint, so ordinary high-precision evaluation is more than sufficient.
