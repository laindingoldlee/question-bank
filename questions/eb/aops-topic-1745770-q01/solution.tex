The odometer uses the five digits $0,2,4,6,8$, which stand for $0,1,2,3,4$; so it writes the distance in base $5$ with each digit doubled. The reading $8866$ corresponds to the base-$5$ numeral $4433_5$:
\[
4\cdot125+4\cdot25+3\cdot5+3=500+100+15+3=\boxed{618}\text{ miles}.
\]
