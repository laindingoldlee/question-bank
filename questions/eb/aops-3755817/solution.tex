Pairs with a zero coordinate fail, so begin with $299^2$ positive pairs. Count violations $u\ge3i$: only $1\le i\le99$ contribute, with $300-3i$ choices each. The number is $99\cdot300-3\cdot\dfrac{99\cdot100}{2}=14850$. By symmetry the opposite inequality fails for another $14850$ pairs. These sets are disjoint for positive coordinates. The valid count is $299^2-2(14850)=59701$, with remainder $\boxed{701}$.
