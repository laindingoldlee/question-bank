\textbf{(a)} $f:X\to X$ says that $f$ is a function with domain $X$ (the inputs) taking values in $X$ (the codomain): it assigns to every element $x$ of $X$ exactly one element $f(x)$, which is again in $X$.

\textbf{(b)} Each of the $3$ inputs can be sent to any of the $3$ elements independently, so there are $3^3=27$ functions. A one-to-one function sends $1,2,3$ to three different values: $3$ choices for $f(1)$, then $2$ for $f(2)$, then $1$ for $f(3)$, so $3!=6$ of them (these are the permutations of $X$). The answer is $\boxed{27\text{ functions, }6\text{ one-to-one}}$.
