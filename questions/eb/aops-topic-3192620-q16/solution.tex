The domain is $0\le x\le20$. Set $t=\sqrt{x(20-x)}\ge0$. Squaring gives $20+2t=20+t^2$, so $t=0$ or 2. These give $x=0,20,10\pm4\sqrt6$, all valid because both sides are nonnegative. The sum is $\boxed{40}$.
