If the boxes were labelled, each ball could go into either box: $2^5=32$ ways. Since the boxes are identical, each split is counted twice (swapping the boxes gives the same arrangement, and no arrangement is fixed by the swap, as the boxes cannot have the same contents). So there are $\dfrac{32}{2}=\boxed{16}$ ways if a box may be empty. Excluding the one way with all balls in one box leaves $\boxed{15}$ ways with both boxes nonempty.
