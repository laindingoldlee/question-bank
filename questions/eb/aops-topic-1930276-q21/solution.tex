For $k\ge1$,
\[
1+\dfrac{1}{k^2}+\dfrac{1}{(k+1)^2}=\dfrac{k^2(k+1)^2+(k+1)^2+k^2}{k^2(k+1)^2}=\dfrac{\left(k^2+k+1\right)^2}{k^2(k+1)^2},
\]
since $k^2(k+1)^2+(k+1)^2+k^2=k^4+2k^3+3k^2+2k+1=\left(k^2+k+1\right)^2$. Hence
\[
\sqrt{1+\dfrac{1}{k^2}+\dfrac{1}{(k+1)^2}}=\dfrac{k^2+k+1}{k(k+1)}=1+\dfrac{1}{k(k+1)}=1+\dfrac{1}{k}-\dfrac{1}{k+1}.
\]
The sum telescopes: for $n$ terms,
\[
\sum_{k=1}^{n}\left(1+\dfrac{1}{k}-\dfrac{1}{k+1}\right)=n+1-\dfrac{1}{n+1}.
\]
For $n=2011$ the value is $\boxed{2012-\dfrac{1}{2012}=\dfrac{4048143}{2012}}$.
