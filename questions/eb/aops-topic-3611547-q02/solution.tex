Write $n=2^a m$ with $m$ odd. Its odd divisors are exactly the divisors of $m$. An odd integer has at most four divisors precisely when it is $1$, $p$, $p^2$, $p^3$, or $pq$ for distinct odd primes $p,q$. One can therefore count the complement in each interval $\left\lceil\dfrac{100}{2^a}\right\rceil\le m\le\left\lfloor\dfrac{999}{2^a}\right\rfloor$. Alternatively, the following direct divisor-pair enumeration gives the counts of qualifying $m$ for $a=0,1,\ldots,9$: $(120, 51, 20, 7, 1, 0, 0, 0, 0, 0)$. For each odd $m$ in its interval, count the divisors $d\le\sqrt m$; each contributes two divisors except $d^2=m$, which contributes one. Keep $m$ exactly when that count exceeds four. Summing these disjoint counts yields $\boxed{199}$.
