Count the man--woman dancing pairs in two ways. Each of the $m$ men is in $3$ pairs, so there are $3m$ pairs; each of the $w$ women is in $4$ pairs, so there are $4w$ pairs. Hence
\[
3m=4w .
\]

\textbf{(a)} With $m=9$ we would get $4w=27$, which is impossible since $27$ is not divisible by $4$. So $9$ men is impossible (the computation $w=\dfrac{27}{4}$ is not a number of women).

\textbf{(b)} From $3m=4w$ and $\gcd(3,4)=1$, $4$ divides $m$: $m=4t$ and then $w=3t$ for a positive integer $t$. Conversely, every such pair is possible: split the people into $t$ groups of $4$ men and $3$ women, and in each group let every man dance with every woman. Then each man dances with $3$ women and each woman with $4$ men. So the party is possible exactly when the number of men is a \textbf{multiple of $4$}, and then the number of women is $\boxed{\dfrac{3}{4}\text{ of the number of men}}$ (for example $4$ men and $3$ women, or $12$ men and $9$ women).
