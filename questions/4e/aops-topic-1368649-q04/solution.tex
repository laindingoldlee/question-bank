When Kendi finishes $2$ miles, Jerry has run $2-\dfrac{1}{3}=\dfrac{5}{3}$ miles, so Jerry's speed is $\dfrac{5}{6}$ of Kendi's. When Jerry runs $2$ miles, Micah runs $\dfrac{3}{2}$, so Micah's speed is $\dfrac{3}{4}$ of Jerry's.

So Micah's speed is $\dfrac{3}{4}\cdot\dfrac{5}{6}=\dfrac{5}{8}$ of Kendi's. When Kendi finishes $2$ miles, Micah has run $\dfrac{5}{8}\cdot2=\dfrac{5}{4}$ miles, so Kendi wins by $2-\dfrac{5}{4}=\boxed{\dfrac{3}{4}}$ mile.
