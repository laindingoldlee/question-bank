In a two-mile race, Kendi beat Jerry by $\dfrac{1}{3}$ mile, and in a second two-mile race, Jerry beat Micah by $\dfrac{1}{2}$ mile. If Kendi and Micah run a third two-mile race, and each runner runs at the same constant speed in every race, by how many miles will Kendi beat Micah?
