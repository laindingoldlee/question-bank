The roots of $x^2+bx+c$ are $b$ and $c$ exactly when $x^2+bx+c=(x-b)(x-c)$, that is (Vieta), when
\[
b+c=-b\qquad\text{and}\qquad bc=c.
\]
From $bc=c$ we get $c=0$ or $b=1$.
\begin{itemize}
\item If $c=0$, then $b+0=-b$, so $b=0$: the quadratic $x^2$ has the double root $0=b=c$.
\item If $b=1$, then $1+c=-1$, so $c=-2$: indeed $x^2+x-2=(x-1)(x+2)$ has roots $1=b$ and $-2=c$.
\end{itemize}
So it is possible, and the pairs are $\boxed{(b,c)=(0,0)\text{ and }(1,-2)}$.
