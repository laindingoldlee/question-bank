Put $u=x-y$, which can be any real number because $x,y$ can be recovered from $xy=1$ and their difference. Then $(x+y)^2=u^2+4$, so the expression is $\dfrac{u^2-u+2}{u^2+u+2}$. For a possible value $v$, rearrangement gives $(v-1)u^2+(v+1)u+2(v-1)=0$. Its discriminant must be nonnegative: $(v+1)^2-8(v-1)^2\ge0$, or $7v^2-18v+7\le0$. The endpoints $\dfrac{9\pm4\sqrt2}{7}$ are attained (their discriminants vanish); the denominator $u^2+u+2$ is always positive. Thus $\boxed{T+t=\dfrac{18}{7}}$.
