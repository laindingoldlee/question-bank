Since $\angle C=\angle A+\angle B$ and all angles sum to $180^\circ$, $\angle C=90^\circ$. A right triangle\textquotesingle s median to the hypotenuse is half the hypotenuse. Hence $AB=2CD=\boxed{16}$.
\begin{asy}
import graph;
usepackage("amsmath");
import geometry;
size(7cm);
pair[] p={(0,0),(16,0),(4,4sqrt(3))}; pair labelCentre=(0,0);for(pair labelVertex:p)labelCentre+=labelVertex;labelCentre/=p.length; draw(p[0]--p[1]--p[2]--cycle); dot(p[0]);label("$A$",p[0],unit(p[0]-labelCentre));dot(p[1]);label("$B$",p[1],unit(p[1]-labelCentre));dot(p[2]);label("$C$",p[2],unit(p[2]-labelCentre));pair D=(8,0);draw(p[2]--D);label("$D$",D,(0,-1));
\end{asy}
