The letter in position $n$ has value $n$ if $n$ is odd and $-n$ if $n$ is even. So
\[
\text{MATH}: M(13)+A(1)+T(-20)+H(-8)=13+1-20-8=-14,
\]
\[
\text{COUNTS}: C(3)+O(15)+U(21)+N(-14)+T(-20)+S(19)=24 .
\]
The positive difference is $24-(-14)=\boxed{38}$. (A small shortcut: the letter T occurs in both words with the same value, so it cancels in the difference, which is $(3+15+21-14+19)-(13+1-8)=44-6=38$.)
