Clearly $n\ne1$. Every prime factor of $n$ divides $n^n=3^{1215}$, so by unique factorisation $n=3^k$ for some integer $k\ge1$. Then
\[n^n=\left(3^k\right)^{3^k}=3^{k\cdot3^k},\qquad\text{so}\qquad k\cdot3^k=1215=5\cdot3^5.\]
The function $k\mapsto k\cdot3^k$ is strictly increasing on positive integers and $k=5$ satisfies the equation, so $k=5$ is the only solution. Hence
\[n=3^5=\boxed{243}.\]
