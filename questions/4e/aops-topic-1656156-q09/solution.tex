When order does not matter, a sum of $1$s and $2$s equal to $n$ is determined by the number $k$ of $2$s, which can be any integer with $0\le2k\le n$; the rest are $1$s. For $n=20$, $k=0,1,\dots,10$, so $M=11$. For $n=18$, $k=0,\dots,9$, so $N=10$. Hence $M-N=\boxed{\textbf{(b)}\ 1}$.
