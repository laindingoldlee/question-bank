This is an arithmetic sequence with first term $1$ and common difference $3$. The term $103$ is term number $\dfrac{103-1}{3}+1=35$, so there are $35$ terms. Pairing the first and last, second and second-to-last, and so on, each pair sums to $1+103=104$, so
\[1+4+\cdots+103=\dfrac{35\cdot104}{2}=\boxed{1820}.\]
