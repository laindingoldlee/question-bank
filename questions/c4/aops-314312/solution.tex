If $70^\circ$ is the vertex angle, the two base angles are $\dfrac{180-70}{2} = 55^\circ$, so $x=55$. If $70^\circ$ is a base angle, the other angles are $70^\circ$ and $40^\circ$, giving $x=70$ or $40$. These exhaust whether the given angle is a base or vertex angle. The sum is $\boxed{55+70+40=165}$.
