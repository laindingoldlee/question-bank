The intersecting-chords theorem gives $KP\cdot KT=KA\cdot KB=4\cdot2=\boxed8$. Both products use ordinary positive lengths because $K$ is inside the circle.
\begin{asy}
import graph;
usepackage("amsmath");
import geometry;
size(7cm);
pair A=(-3,0),B=(3,0),K=(1,0),P=(1,sqrt(8)),T=(1,-sqrt(8));draw(circle((0,0),3));draw(A--B);draw(P--T);label("$A$",A,(-1,0));label("$B$",B,(1,0));label("$K$",K,(1,-1));label("$P$",P,(0,1));label("$T$",T,(0,-1));
\end{asy}
