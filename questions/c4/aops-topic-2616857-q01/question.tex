An $n$-pointed fork consists of a handle weighing $12$ ounces and $n$ skewers, all of the same positive integer weight (in ounces). Call a positive integer $n$ \emph{possible} if some $n$-pointed fork has total weight $n^2$ ounces. Find the sum of all possible values of $n$.
