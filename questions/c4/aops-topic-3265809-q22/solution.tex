Let $P_k=r^k+s^k+t^k$. Vieta's formulas give $P_0=3$, $P_1=0$, and $P_2=-2$. Every root satisfies $u^3=-u-1$, so for $k\ge3$, $P_k=-P_{k-2}-P_{k-3}$. Thus
\[(P_3,P_4,P_5,P_6,P_7,P_8,P_9)=(-3,2,5,1,-7,-6,6).\]
The desired value is $\boxed6$.
