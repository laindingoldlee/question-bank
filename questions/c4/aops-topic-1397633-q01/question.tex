Albert forgot the page number where he stopped reading. He remembers four clues about it:
\begin{enumerate}
\item The page number is a three-digit number.
\item The page number is at most $296$ (the book has $296$ pages).
\item Every digit of the page number is either prime or composite (so no digit is $0$ or $1$).
\item The digits are in strictly increasing order from left to right.
\end{enumerate}
Exactly one of the four clues is false. How many possibilities are there for the page number? (A page number is a positive integer.)
