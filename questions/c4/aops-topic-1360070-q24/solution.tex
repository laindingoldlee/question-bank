Let both teams score $a$ in the first quarter. The Raiders score $a,ar,ar^2,ar^3$ with $r>1$, and the Wildcats $a,a+d,a+2d,a+3d$ with $d\ge1$ an integer.

\textbf{The ratio is an integer.} If $r=\dfrac{p}{q}$ in lowest terms with $q\ge2$, then $ar^3$ is an integer only if $q^3\mid a$, so the Raiders' total is at least $q^3+q^2p+qp^2+p^3\ge8+12+18+27=65$ (with $q=2$, $p=3$, $a=8$); the next options exceed $100$. In that single case the total is $65$, and $4a+6d+1=65$ gives $6d=32$, impossible. So $r$ is an integer $n\ge2$.

\textbf{The possible values of $a$} (this is what the list $n=2$: $a\in[1,6]$, $n=3$: $a\in[1,2]$, $n=4$: $a=1$ means). The Raiders' total $a(1+n+n^2+n^3)$ is at most $100$: for $n=2$, $15a\le100$, so $1\le a\le6$; for $n=3$, $40a\le100$, so $a\le2$; for $n=4$, $85a\le100$, so $a=1$; for $n\ge5$, $156a>100$.

\textbf{The one-point win.} We need $a(1+n+n^2+n^3)=4a+6d+1$.
\begin{itemize}
\item $n=2$: $15a=4a+6d+1$, so $11a=6d+1$; with $a\le6$, only $a=5$, $d=9$ works.
\item $n=3$: $36a=6d+1$, impossible since the left side is divisible by $6$.
\item $n=4$: $81=6d+1$, so $6d=80$, impossible.
\end{itemize}
So the Raiders scored $5,10,20,40$ (total $75$) and the Wildcats $5,14,23,32$ (total $74$). The first half total is $5+10+5+14=\boxed{34}$.
