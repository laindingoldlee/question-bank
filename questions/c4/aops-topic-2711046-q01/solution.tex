We show $80<4^{\sqrt{10}}<81$, so the answer is $\boxed{81}$.

\emph{Upper bound.} $\left(\dfrac{19}{6}\right)^2=\dfrac{361}{36}>10$, so $4^{\sqrt{10}}<4^{\dfrac{19}{6}}=2^{\dfrac{19}{3}}=64\sqrt[3]2$. And $64\sqrt[3]{2}<81$ because $2\cdot64^3=524288<531441=81^3$.

\emph{Lower bound.} $98^2=9604<9610=10\cdot31^2$, so $\sqrt{10}>\dfrac{98}{31}$ and $4^{\sqrt{10}}>2^{\dfrac{196}{31}}$. Now $2^{\dfrac{196}{31}}>80$ is equivalent to $2^{196}>80^{31}=2^{124}\cdot5^{31}$, i.e. $2^{72}>5^{31}$, i.e. $4\cdot128^{10}>5\cdot125^{10}$, i.e. $\left(\dfrac{128}{125}\right)^{10}>\dfrac54$. By the binomial theorem,
\[\left(1+\dfrac{3}{125}\right)^{10}>1+10\cdot\dfrac{3}{125}+45\cdot\left(\dfrac{3}{125}\right)^2=1+0.24+0.02592>1.25.\ \blacksquare\]
(Numerically $4^{\sqrt{10}}\approx80.15$.)
