\textbf{Yes.} Use $\left(a^b\right)^c=a^{bc}$. For four $7$s,
\[\left(7^7\right)^{\left(7^7\right)}=7^{7\cdot7^7}=7^{7^8}\quad\text{and}\quad\left(7^{\left(7^7\right)}\right)^7=7^{7^7\cdot7}=7^{7^8}.\]
Now raise both to the power $7$ three more times: with $X=\left(7^7\right)^{\left(7^7\right)}$ and $Y=\left(7^{\left(7^7\right)}\right)^7$, the expressions $\left(\left(X^7\right)^7\right)^7$ and $\left(\left(Y^7\right)^7\right)^7$ each use seven $7$s and five pairs of parentheses, are different parenthesisations, and have the same value $7^{7^{11}}$.
