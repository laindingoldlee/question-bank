Since $10^{x+h}=10^x\cdot10^h$,
\[
\dfrac{f(x+h)-f(x)}{h}=\dfrac{10^x\cdot10^h-10^x}{h}=\dfrac{10^h-1}{h}\cdot10^x .
\]
So the quotient is $a\cdot10^x$ with $\boxed{a=\dfrac{10^h-1}{h}}$, which depends only on $h$. (For example, $h=1$ gives $a=9$: $10^{x+1}-10^x=9\cdot10^x$.)
