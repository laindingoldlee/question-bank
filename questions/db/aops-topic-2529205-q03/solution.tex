Let $m=p-1=\dfrac{q-1}{2}$.

\textbf{Euler's criterion: $k^m\equiv1$ if $k$ is a quadratic residue mod $q$, and $k^m\equiv-1$ otherwise.} By Fermat's little theorem $k^{q-1}\equiv1$, so $\left(k^m-1\right)\left(k^m+1\right)\equiv0$, and since $q$ is prime, $k^m\equiv\pm1$. If $k\equiv y^2$, then $k^m\equiv y^{q-1}\equiv1$. The nonzero squares mod $q$ are exactly $m$ residues, since $y^2\equiv z^2$ iff $y\equiv\pm z$. All of them are roots of $X^m-1$, which has at most $m$ roots modulo the prime $q$. So a non-residue $k$ has $k^m\not\equiv1$, i.e. $k^m\equiv-1$.

\textbf{The sum.} Let $x\equiv k^{-1}$, so $x\not\equiv1$ and $S\equiv x+x^2+\cdots+x^m$. Then
\[(x-1)S\equiv x^{m+1}-x=x\left(x^m-1\right).\]
Let $\varepsilon\equiv k^m\in\{1,-1\}$. Then $x^m\equiv\varepsilon^{-1}=\varepsilon$, so $(x-1)S\equiv x(\varepsilon-1)$. Multiplying by $k$ (and using $kx\equiv1$) gives $(1-k)S\equiv\varepsilon-1$, so
\[S\equiv\dfrac{1-\varepsilon}{k-1}\pmod q,\qquad\text{i.e.}\qquad\boxed{S\equiv\begin{cases}0,&k\text{ a quadratic residue mod }q,\\ 2(k-1)^{-1},&k\text{ a non-residue mod }q.\end{cases}}\]
For example, with $p=7$, $q=13$, $k=5$ (a non-residue, since the squares mod $13$ are $1,3,4,9,10,12$): $S\equiv2\cdot4^{-1}\equiv2\cdot10\equiv7\pmod{13}$; with $k=4$ (a residue), $S\equiv0$.
