(a) All $\binom42=6$ pairs are equally likely and exactly one of them is \{pink, purple\}, so the probability is $\boxed{\dfrac16}$.

(b) A given pony is in $3$ of the $6$ pairs, so it is chosen with probability $\boxed{\dfrac12}$. Two ponies are chosen, so the four individual probabilities must add up to $2$, not $1$; the value $\dfrac14$ would be right only if a single pony were chosen.
