Since $m-1\mid m-1$ and $m-1\mid m+1$, the number $m-1$ divides the difference $(m+1)-(m-1)=2$. (Note $m-1\ne0$, because $0$ divides only $0$ and $m+1=2\ne0$ when $m=1$.) The divisors of $2$ are $\pm1$ and $\pm2$, so $m-1\in\{-2,-1,1,2\}$. $\blacksquare$

This gives $m\in\{-1,0,2,3\}$, and each of them works:
\[m=-1:\ -2\mid0,\qquad m=0:\ -1\mid1,\qquad m=2:\ 1\mid3,\qquad m=3:\ 2\mid4.\]
So the integers are $\boxed{m=-1,\ 0,\ 2,\ 3}$.
