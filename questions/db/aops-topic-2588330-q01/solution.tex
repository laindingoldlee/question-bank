No, it is impossible. Let $n$ be the number of $I$'s in the string; initially $n=1$. We show that $n$ is never divisible by $3$.
\begin{itemize}
\item Rule 1 doubles $n$. If $3\nmid n$, then $3\nmid2n$, since $3$ is prime and $3\nmid2$.
\item Rule 2 changes $n$ to $n-3$, which leaves the remainder mod $3$ unchanged.
\item Rules 3 and 4 do not change $n$.
\end{itemize}
So $n\not\equiv0\pmod3$ holds at the start and is preserved by every rule. The string $MU$ has $n=0$, which is divisible by $3$, so it can never be reached. $\boxed{\text{No}}$ $\blacksquare$
