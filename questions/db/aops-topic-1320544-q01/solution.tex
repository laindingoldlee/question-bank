Complete the square (Sophie Germain's identity):
\[
4x^4+y^4=(2x^2+y^2)^2-4x^2y^2=\boxed{(2x^2+2xy+y^2)(2x^2-2xy+y^2)}.
\]
Each factor is positive unless $x=y=0$, since $2x^2\pm2xy+y^2=x^2+(x\pm y)^2$. So the only real solution of $4x^4+y^4=0$ is $x=y=0$.
