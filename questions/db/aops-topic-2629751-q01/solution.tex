Since $\phi^2=\phi+1$, multiplying by $\phi^{n-1}$ gives $\phi^{n+1}=\phi^n+\phi^{n-1}$, i.e. $\phi^n-\phi^{n+1}=-\phi^{n-1}$. Apply this repeatedly from the right:
\[\phi^{10}-\phi^{11}=-\phi^9,\quad\phi^8-\phi^9=-\phi^7,\quad\phi^6-\phi^7=-\phi^5,\quad\phi^4-\phi^5=-\phi^3.\]
So the expression equals $\boxed{-\phi^3}$.
