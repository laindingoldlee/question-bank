Ordered selections number $ 15\cdot14\cdot13 $. Each three-element set is counted $ 3!=6 $ times, once per ordering. Thus the answer is $\binom{15}{3}=\dfrac{15\cdot14\cdot13}{6}=\boxed{455}$.
