The coefficients add up to $1+1-7-1+6=0$, so $x=1$ is a root; with alternating signs $1-1-7+1+6=0$, so $x=-1$ is a root too. Hence $x^2-1$ is a factor, and dividing,
\[
x^4+x^3-7x^2-x+6=(x^2-1)(x^2+x-6)=(x-1)(x+1)(x-2)(x+3).
\]
(Check: $(x^2-1)(x^2+x-6)=x^4+x^3-6x^2-x^2-x+6$.) The solutions are
\[
x=\boxed{-3,\ -1,\ 1,\ 2}.
\]
