Note $x^2+2\sqrt{x^2-1}=\left(\sqrt{x^2-1}+1\right)^2$, so $\sqrt{2\sqrt{x^2-1}+x^2}=\sqrt{x^2-1}+1$. Then
\[A^2=x^2+4+4\sqrt{x^2-1},\qquad B^2=x^2+4+4x.\]
Since $\sqrt{x^2-1}<x$, $A^2<B^2$, and both are positive, so $\boxed{A<B}$ for every $x\ge1$.
