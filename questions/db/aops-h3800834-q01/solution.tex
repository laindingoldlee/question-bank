Number the vertices $A=0,B=1,\ldots,F=5,G=6$. Regard the position just before token one as $F$, since adding two reaches $A$. Seven equal jumps of any of $2,3,4,5$ return to the same vertex modulo seven, so every block begins from preceding position $F$ and ends at $F$.
Since $2015=7\cdot287+6$, the token is sixth in block $288$. The jumps in that block are five, because $288$ is divisible by four. Its position is $5+6\cdot5=35\equiv0\pmod7$, namely $\boxed A$.
