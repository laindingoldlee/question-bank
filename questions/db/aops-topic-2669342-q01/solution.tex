$p=2$ is impossible ($3=2x^2$), so $p$ is odd. Since $2x^2=p+1<p^2+1=2y^2<2p^2$, we have $x<y<p$. Subtracting the equations,
\[2(y-x)(y+x)=p^2-p=p(p-1).\]
The odd prime $p$ does not divide $2$ or $y-x$ (as $0<y-x<p$), so $p\mid y+x$; and $0<x+y<2p$, hence $x+y=p$. Then $2(y-x)p=p(p-1)$ gives $y-x=\dfrac{p-1}{2}$, and so $x=\dfrac{p+1}{4}$. Substituting into $p+1=2x^2$:
\[p+1=\dfrac{(p+1)^2}{8}\quad\Longrightarrow\quad p+1=8,\quad p=7.\]
Indeed $7+1=2\cdot2^2$ and $7^2+1=2\cdot5^2$. The only such prime is $7$, so the sum is $\boxed{7}$.
