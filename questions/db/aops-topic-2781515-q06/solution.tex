If $n=\prod p_i^{e_i}$, then $\tau(n)=\prod(e_i+1)$. Divisibility by 7 forces some $e_i+1$ to be divisible by 7, hence $e_i\ge6$. Thus $n\ge2^6=64$. This bound is attained since 64 has 7 divisors. Answer $\boxed{64}$.
