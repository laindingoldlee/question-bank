The quadratic factors:
\[2n^2+65n+93=(2n+3)(n+31).\]
For an integer $n$ both factors are integers. If $|2n+3|\cdot|n+31|$ is a prime $q$, then one of the two factors has absolute value $1$ (the only factorisations of $q$ into positive integers are $1\cdot q$ and $q\cdot1$). So we only need to check four values of $n$:
\begin{itemize}
\item $2n+3=1$, $n=-1$: the value is $1\cdot30=30$, not prime;
\item $2n+3=-1$, $n=-2$: the value is $(-1)\cdot29$, and $|-29|=29$ is prime;
\item $n+31=1$, $n=-30$: the value is $(-57)\cdot1$, and $57=3\cdot19$ is not prime;
\item $n+31=-1$, $n=-32$: the value is $(-61)\cdot(-1)=61$, which is prime.
\end{itemize}
So $n=-2$ and $n=-32$, and the sum is $\boxed{-34}$.
