We choose an unordered set of $7$ shirts from $10$, so the number of ways is
\[
\dbinom{10}{7}=\dbinom{10}{3}=\dfrac{10\cdot9\cdot8}{3\cdot2\cdot1}=\boxed{120}.
\]
(Choosing the $7$ shirts to wear is the same as choosing the $3$ shirts to leave out.)
