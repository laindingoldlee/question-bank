The interior angles of a $20$-gon add to $(20-2)\cdot180^\circ=3240^\circ$, so each of the $20$ equal angles is $\dfrac{3240^\circ}{20}=\boxed{162^\circ}$. (Equivalently, each exterior angle is $\dfrac{360^\circ}{20}=18^\circ$, and $180^\circ-18^\circ=162^\circ$.)

\begin{asy}
usepackage("amsmath");
size(4cm);
defaultpen(fontsize(10pt));
int n=20; pair[] V; for(int i=0;i<n;++i) V.push(dir(90+360*i/n));
for(int i=0;i<n;++i) draw(V[i]--V[(i+1)%n],linewidth(0.8));
pair Pv=V[0];
draw(arc(Pv,0.12,degrees(V[1]-Pv),degrees(V[19]-Pv)),red);
label("$162^\circ$",Pv+(0,-0.16),S,red);
for(int i=0;i<n;++i) dot(V[i]);
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}
