We show that $n=\boxed{5}$ is the only value; it occurs for $(a,b)=(2,1)$, since $\dfrac{4+1}{2-1}=5$.

Fix such an $n$ and, among all pairs of positive integers $(a,b)$ with $ab>1$ and $\dfrac{a^2+b^2}{ab-1}=n$, choose one with $a\ge b$ and $a+b$ as small as possible.

\emph{$a\ne b$.} If $a=b$ then $a^2-1$ divides $2a^2=2(a^2-1)+2$, so $a^2-1$ divides $2$, impossible for $a\ge2$.

\emph{Vieta jump.} So $a>b$. The equation $a^2+b^2=n(ab-1)$ says that $a$ is a root of
\[
t^2-nb\,t+(b^2+n)=0 .
\]
The other root is $a'=nb-a=\dfrac{b^2+n}{a}$, an integer (first form) and positive (second form). The pair $(a',b)$ satisfies the same equation, so by minimality $a'+b\ge a+b$, i.e.\ $a'\ge a$, which means $b^2+n=aa'\ge a^2$, so
\[
n\ge a^2-b^2. \tag{1}
\]

\emph{Case $b\ge2$.} Then $ab-1\ge2a-1>a$, and $b\le a-1$, so
\[
n<\dfrac{a^2+b^2}{a}\le\dfrac{a^2+(a-1)^2}{a}<2a .
\]
With (1): $(a-b)(a+b)<2a$. If $a-b\ge2$ the left side is at least $2(a+b)>2a$, so $a=b+1$. But then
\[
n=\dfrac{a^2+(a-1)^2}{a(a-1)-1}=\dfrac{2(a^2-a-1)+3}{a^2-a-1}=2+\dfrac{3}{a^2-a-1},
\]
so $a^2-a-1$ is $1$ or $3$, giving $a=2$ (then $b=1$, not $\ge2$) or $a^2-a=4$ (no integer). Contradiction.

\emph{Case $b=1$.} Then $n=\dfrac{a^2+1}{a-1}=a+1+\dfrac{2}{a-1}$, so $a-1\in\{1,2\}$, and $a=2$ or $a=3$; both give $n=5$.

Hence every possible $n$ equals $5$.
