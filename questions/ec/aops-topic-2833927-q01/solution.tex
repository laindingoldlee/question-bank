Define $\cot\theta=\dfrac{\cos\theta}{\sin\theta}$ (not as $\dfrac1{\tan\theta}$, which fails where $\tan$ is undefined). At $90^\circ$ the unit-circle point is $(0,1)$, so $\cos90^\circ=0$ and $\sin90^\circ=1$.
\begin{asy}
usepackage("amsmath");
size(3.5cm);
defaultpen(fontsize(10pt));
draw(circle((0,0),1));draw((-1.3,0)--(1.3,0),Arrow);draw((0,-1.3)--(0,1.3),Arrow);
draw((0,0)--(0,1),linewidth(1));dot((0,1));label("$(\cos90^\circ,\sin90^\circ)=(0,1)$",(0,1),NE);
\end{asy}

So $\cot90^\circ=\dfrac01=\boxed{0}$.
