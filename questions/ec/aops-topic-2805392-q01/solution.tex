Let $x=2018$. The last denominator factors: $x^4+2x^3+2x^2+x=x(x+1)(x^2+x+1)$. Over this common denominator the numerator is
\[x(x^2+x+1)+x(x+1)+1=x^3+2x^2+2x+1=(x+1)(x^2+x+1).\]
So the sum is $\dfrac1x=\boxed{\dfrac1{2018}}$.
