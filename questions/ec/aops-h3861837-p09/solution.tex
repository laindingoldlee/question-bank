Measure elapsed seconds $t=1,\ldots,3601$. If only the 23-second signal is absent, $36\mid t$ and $23\nmid t$, giving $100-4=96$ instants. If only the 4-second signal is absent, $414\mid t$ and $4\nmid t$, giving four. If only the 9-second signal is absent, $276\mid t$ and $9\nmid t$, giving $13-4=9$. Missing any of the 2-,3-,6-second signals is impossible because the other five periods force it. Total $\boxed{109}$.
