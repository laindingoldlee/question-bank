We have
\[\dfrac{x^2-7x+60}{x}=x-7+\dfrac{60}{x},\]
which is an integer exactly when $x$ divides $60$. Since $60=2^2\cdot3\cdot5$ has $(2+1)(1+1)(1+1)=12$ positive divisors, the answer is
\[\boxed{12}.\]
