Put $x=1$: $f(f(y))=\dfrac cy$ with $c=f(f(1))$. So the equation reads $f(xf(y))=\dfrac c{xy}$, which is symmetric: $f(xf(y))=f(yf(x))$.

Now put $x=f(t)$: $f(f(t)f(y))=\dfrac c{f(t)\,y}$. Swapping $t$ and $y$ leaves the left side unchanged, so $f(t)\,y=f(y)\,t$, i.e. $f(x)=kx$ for a constant $k>0$. Then $f(xf(y))=k^2xy$ must equal $\dfrac c{xy}$ for all $x,y$, which is impossible. Hence $\boxed{\text{no such function exists}}$.
