Round each number: $304\approx300$, $29.7\approx30$, $399\approx400$. Then
\[
\dfrac{300^5}{30\cdot400^4}=\dfrac{300}{30}\cdot\left(\dfrac{300}{400}\right)^4=10\cdot\left(\dfrac{3}{4}\right)^4=10\cdot\dfrac{81}{256}\approx3.2 .
\]
The rounding errors are small (each number changed by about $1\%$ or less, so the value changes by well under a factor of $2$), and the choices differ by factors of $10$. The exact value is about $3.45$, so the answer is $\boxed{\textbf{(D)}\ 3}$.
