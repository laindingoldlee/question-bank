The digit $9$ requires $b\ge10$. Write $b^2+9b=m^2$, so $(2b+9-2m)(2b+9+2m)=81$. The factors are positive odd integers. The possible pairs are $(1,81),(3,27),(9,9)$, giving $2b+9=41,15,9$, respectively. Only $b=16$ is a valid base. Thus the sum is $\boxed{16}$; indeed $190_{16}=400=20^2$.
