Checking $x=1,2,3,4$ gives equality only for 1 and 4. For $x=5$, $5!\ge6^2$. If $x!\ge(x+1)^2$ for $x\ge5$, then $(x+1)!\ge(x+1)^3\ge(x+2)^2$, so the inequality persists by induction. Thus for every $x\ge5$, the floor is at least $x+1$. The only solutions sum to $\boxed5$.
