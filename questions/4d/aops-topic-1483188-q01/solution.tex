Use the Sophie Germain identity $4a^4+1=(2a^2+2a+1)(2a^2-2a+1)$, which follows from
\[
4a^4+1=(2a^2+1)^2-(2a)^2 .
\]
With $a=2^{14}$, $4a^4=2^{58}$, so
\[
2^{58}+1=\left(2^{29}+2^{15}+1\right)\left(2^{29}-2^{15}+1\right).
\]
Modulo $5$: $2^4\equiv1$, so $2^{29}\equiv2$ and $2^{15}\equiv2^3\equiv3$. Hence $2^{29}+2^{15}+1\equiv6\equiv1$ and $2^{29}-2^{15}+1\equiv0\pmod5$. Therefore
\[
\dfrac{2^{58}+1}{5}=\left(2^{29}+2^{15}+1\right)\cdot\dfrac{2^{29}-2^{15}+1}{5},
\]
and both factors are integers greater than $1$ (the second is about $1.07\cdot10^8$). So the number is $\boxed{\text{composite}}$.
