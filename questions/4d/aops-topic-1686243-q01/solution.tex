The numerator is $\sqrt[3]{(c+d)^3}=c+d$. Since $c^2-d^2>0$, the denominator is $\sqrt{(c^2-d^2)(c^2+d^2)}=\sqrt{c^4-d^4}$. Rationalising,
\[
\dfrac{c+d}{\sqrt{c^4-d^4}}=\dfrac{(c+d)\sqrt{c^4-d^4}}{c^4-d^4}=\dfrac{(c+d)\sqrt{c^4-d^4}}{(c-d)(c+d)(c^2+d^2)}=\dfrac{\sqrt{c^4-d^4}}{(c^2+d^2)(c-d)} ,
\]
using $c+d>0$. The answer is $\boxed{\textbf{(D)}}$.
