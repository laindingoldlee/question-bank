Let the digits be $x,y,z$.

\textbf{A zero digit.} Then the product is $0$, while the sum is at least $1$ (the first digit is nonzero). Such numbers never work, so all digits are from $1$ to $9$.

\textbf{At least two digits equal to $1$.} If the digits are $1,1,z$, the product $z$ is less than the sum $z+2$. These never work.

\textbf{Exactly one digit equal to $1$.} With digits $1,y,z$ and $y,z\ge2$, we need $1+y+z<yz$, that is,
\[(y-1)(z-1)>2 .\]
This fails only when $(y-1)(z-1)\le2$, i.e. for $(y,z)=(2,2),(2,3),(3,2)$. So $8\cdot8-3=61$ ordered pairs $(y,z)$ work, and the digit $1$ can be in any of $3$ places: $3\cdot61=183$ numbers.

\textbf{No digit equal to $1$.} Order the digits as $2\le x\le y\le z$. Then $xyz\ge4z>3z\ge x+y+z$, so every such number works: $8^3=512$ numbers.

The total is $512+183=\boxed{695}$.
