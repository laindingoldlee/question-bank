If each side grows by $x$ inches, $(5+x)(6+x)=182$, i.e. $x^2+11x-152=0$, so $(x-8)(x+19)=0$. Since $x>0$, each side was enlarged by $\boxed{8}$ inches (to $13\times14$).

\begin{asy}
usepackage("amsmath");
size(3.5cm);
defaultpen(fontsize(10pt));
draw((0,0)--(13,0)--(13,14)--(0,14)--cycle,linewidth(0.9));
filldraw((0,0)--(5,0)--(5,6)--(0,6)--cycle,lightgray);
label("$5$",(2.5,0),S); label("$6$",(0,3),W); label("$x$",(9,0),S); label("$x$",(0,10),W);
label("$13$",(6.5,14),N); label("$14$",(13,7),E);
\end{asy}
