Factor both sides: $p(3p+1)=n(n+3)$. Since $p$ is prime and divides $n(n+3)$, $p\mid n$ or $p\mid n+3$.

\textbf{Case $p\mid n$.} Write $n=kp$ with $k\ge1$. Then $p(3p+1)=kp(kp+3)$, so $3p+1=k^2p+3k$, i.e.\ $p\left(3-k^2\right)=3k-1>0$. This needs $k=1$, and then $2p=2$, $p=1$, not a prime. No solutions.

\textbf{Case $p\mid n+3$.} Write $n+3=kp$ with $k\ge1$, so $n=kp-3$. Then $3p+1=k(kp-3)$, i.e.\ $p\left(k^2-3\right)=3k+1$.
\begin{itemize}
\item $k=1$: $-2p=4$, impossible.
\item $k=2$: $p=7$, and then $n=2\cdot7-3=11$.
\item $k=3$: $6p=10$, impossible.
\item $k\ge4$: $k^2-3>3k+1$ (since $k^2-3k-4=(k-4)(k+1)\ge0$ with equality only at $k=4$, where $13p=13$ gives $p=1$), so $p<1$, impossible.
\end{itemize}

Check: $3\cdot49+7=154=121+33=11^2+3\cdot11$. The only prime is $\boxed{p=7}$ (with $n=11$).
