To guarantee a red sock you must be able to draw every non-red sock first, so the number of non-red socks is $20$. Similarly there are $12$ non-blue and $18$ non-green socks. With $R,B,G$ the numbers of each colour,
\[B+G=20,\qquad R+G=12,\qquad R+B=18.\]
Adding, $R+B+G=25$, so $R=25-20=\boxed{5}$ (and $B=13$, $G=7$).
