The nine letters are B, U, T, T, E, R, F, L, Y, with the letter T twice. The number of different arrangements is
\[\dfrac{9!}{2!}=\dfrac{362880}{2}=181440.\]
Exactly one of them is the correct spelling, so there are $181440-1=\boxed{181439}$ misspellings.
