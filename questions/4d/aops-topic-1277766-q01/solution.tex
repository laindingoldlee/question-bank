$f(42)=42+4+2=48$ and $\operatorname{rev}48=84$, so $g(42)=132$. Also $f(69)=69+6+9=84$ and $\operatorname{rev}84=48$, so $g(69)=132$. Hence $g(42)=g(69)$.

There is no contradiction: from $g(42)=g(69)$ one may conclude $42=69$ only if $g$ is one-to-one, so that $g^{-1}$ exists. Here $g$ is not one-to-one, as this very example shows, so $g^{-1}$ is not a function and the step "apply $g^{-1}$" is invalid.
