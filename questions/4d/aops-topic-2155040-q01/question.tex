Write each set of real numbers $x$ in interval notation.
\begin{enumerate}
\item[(a)] $2>x>1$
\item[(b)] $1<x<2$
\item[(c)] $2>x\ge1$
\item[(d)] $1\le x<2$
\item[(e)] $2\ge x\ge1$
\item[(f)] $2\le x\le1$
\item[(g)] $x>1$ or $x<-2$
\item[(h)] $x\ge1$ or $x\le-2$
\item[(i)] $x\ge1$ or $x<-2$
\item[(j)] $x>1$ or $x\le-2$
\end{enumerate}
