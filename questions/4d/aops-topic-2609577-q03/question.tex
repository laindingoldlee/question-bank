Number the rows of Pascal's triangle from $0$, so that row $n$ consists of $\dbinom n0,\dbinom n1,\dots,\dbinom nn$ (entries $0$ to $n$). Some row contains three consecutive entries in the ratio $8:9:10$. Find the row, and the positions of these three entries.
