If $z=x^2-y^2=(x-y)(x+y)$ with $x>y\ge1$, then $z=de$ with $d=x-y$ and $e=x+y$, where $1\le d<e$ and $d,e$ have the same parity. Conversely, such $d,e$ give $x=\dfrac{e+d}{2}$ and $y=\dfrac{e-d}{2}\ge1$. So $z$ is representable exactly when it has a factorisation $z=de$ with $d<e$ and $d\equiv e\pmod2$.
\begin{itemize}
\item $z$ odd: $z=1\cdot z$ works when $z\ge3$; $z=1$ only has $1\cdot1$, so $1$ is not representable.
\item $z\equiv2\pmod4$: two odd factors would give an odd product, and two even factors a multiple of $4$; so none of these is representable.
\item $z=4k$: $z=2\cdot2k$ works when $k\ge2$; $z=4$ only has $1\cdot4$ (different parity) and $2\cdot2$ (equal factors), so $4$ is not representable.
\end{itemize}
The non-representable numbers are $1$, $4$, and the $25$ numbers $2,6,10,\dots,98$, so there are $\boxed{27}$.
