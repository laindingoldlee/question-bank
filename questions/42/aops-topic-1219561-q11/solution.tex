Every second remaining child leaves: this is the Josephus problem with step $2$. For $n=2^m+L$ ($0\le L<2^m$) the last child is $2L+1$. Here $50=32+18$, so the child who never gets a chocolate is number $2\cdot18+1=\boxed{37}$.
