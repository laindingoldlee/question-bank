For any divisor $d$ of $b-1$, we have $b\equiv1\pmod d$, so $D(b)\equiv1+\cdots+(b-1)=\dfrac{b(b-1)}{2}\pmod d$. If $b$ is even, choose $d=b-1\ge3$; the digit sum is divisible by $d$. If $b\ge5$ is odd, choose $d=\dfrac{b-1}{2}\ge2$, which also divides the digit sum. In either case $1<d<D(b)$, so the number is composite. For $b=3$, $D(3)=(21)_3=7$ is prime. Thus exactly $\boxed1$ descending base number is prime.
