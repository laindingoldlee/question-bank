There are two common rules for rounding a number that ends in exactly $.5$ to a whole number:
\begin{itemize}
\item \emph{round half up}: always round up, so $2.5\to3$ and $3.5\to4$;
\item \emph{round half to even}: round to whichever neighbouring whole number is even, so $2.5\to2$ and $3.5\to4$.
\end{itemize}
\begin{enumerate}
\item[(a)] Round each of $0.5,1.5,2.5,\dots,9.5$ by both rules.
\item[(b)] For each rule, compare the sum of the ten rounded numbers with the true sum $0.5+1.5+\cdots+9.5$. Explain why the second rule is often preferred when many rounded numbers are added.
\end{enumerate}
