The map is $(x,y)\mapsto(1+\dfrac{x}{5},2+\dfrac{y}{5})$. A fixed point satisfies $\dfrac{4}{5}x=1 $ and $\dfrac{4}{5}y=2 $, so $\boxed{(x,y)=(\dfrac{5}{4},\dfrac{5}{2})}$. It lies inside both squares, as required.
