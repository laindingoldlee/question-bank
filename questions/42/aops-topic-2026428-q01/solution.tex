Any three non-collinear dots form a triangle, so we subtract the collinear triples from $\dbinom{16}{3}=560$.

Use coordinates $(x,y)$ with $x,y\in\{0,1,2,3\}$. The lines containing at least three dots are:

\begin{asy}
usepackage("amsmath");
size(4.2cm);
defaultpen(fontsize(10pt));
for(int i=0;i<4;++i) for(int j=0;j<4;++j) dot((i,j));
for(int i=0;i<4;++i){ draw((0,i)--(3,i), gray+linewidth(0.4)); draw((i,0)--(i,3), gray+linewidth(0.4)); }
draw((0,0)--(3,3), red+linewidth(0.9)); draw((0,3)--(3,0), red+linewidth(0.9));
draw((1,0)--(3,2), blue+linewidth(0.9)); draw((0,1)--(2,3), blue+linewidth(0.9));
draw((0,2)--(2,0), blue+linewidth(0.9)); draw((1,3)--(3,1), blue+linewidth(0.9));
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

\begin{itemize}
\item the $4$ rows and $4$ columns (grey), each with $4$ dots: $8\dbinom43=32$ triples;
\item the $2$ main diagonals (red), each with $4$ dots: $2\dbinom43=8$ triples;
\item the $4$ shorter diagonals with $3$ dots (blue): $4\dbinom33=4$ triples.
\end{itemize}
No other line contains three dots: three collinear dots would include two consecutive ones differing by a vector $(p,q)$ with $\gcd(p,q)=1$, and the third would differ by $2(p,q)$; this needs $|p|,|q|\le 1$, i.e.\ a row, column or diagonal direction.

So the number of triangles is
\[
560-32-8-4=\boxed{516}.
\]
The calculation in the post subtracted only the rows and columns and forgot the $12$ collinear triples on the diagonals.
