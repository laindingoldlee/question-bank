On day $n$ the first pile has $2^{n-1}$ coins and the second has $3^{n-1}$.

\textbf{Doubled pile.} $2^{18}=262{,}144<500{,}000\le2^{19}=524{,}288$, so it first reaches $500{,}000$ on day $20$.

\textbf{Tripled pile.} $3^{11}=177{,}147<500{,}000\le3^{12}=531{,}441$, so it first reaches $500{,}000$ on day $13$.

The tripled pile gets there $20-13=\boxed{7}$ days sooner.
