In base $b$, the equation
\[
4022_b-k_b=1665_b
\]
holds, where $k_b$ is a four-digit numeral in base $b$, and $b$ is the smallest base in which the numerals $4022_b$ and $1665_b$ make sense. Find $k$ in base $10$ (and write $k$ in base $b$).
