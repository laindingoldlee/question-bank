The digit $6$ appears, so $b\ge7$; the smallest base is $b=7$. In base $10$,
\[
4022_7=4\cdot343+0\cdot49+2\cdot7+2=1388,\qquad 1665_7=343+6\cdot49+6\cdot7+5=684 .
\]
Hence
\[
k=1388-684=\boxed{704}.
\]
In base $7$: $704=2\cdot343+0\cdot49+2\cdot7+4$, so $k_7=2024_7$, which is indeed a four-digit numeral. (Check by column subtraction in base $7$: $4022_7-2024_7=1665_7$.)

\textbf{Why the base must be specified.} For a general base $b\ge7$,
\[
k=(4b^3+2b+2)-(b^3+6b^2+6b+5)=3b^3-6b^2-4b-3,
\]
and $b^3\le k<b^4$ for every $b\ge7$, so every base from $7$ up gives a valid four-digit $k$ (for example $b=8$ gives $k=1117$). Only the smallest base gives a single answer.
