A number with five divisors is $ p^4 $ for a prime $ p $, so $ n=p^4+10 $. A number with an odd divisor count is a square; hence $ p^4+20 $ is a square. If $ p $ is odd, $ p^4+20\equiv5\pmod{16}$, impossible because square residues modulo 16 are 0, 1, 4, 9. Therefore $ p=2 $, giving $ n=26 $. Indeed $ n-10=16 $ has 5 divisors and $ n+10=36 $ has 9. Since $ 26=2\cdot13 $, the answer is $\boxed4 $.
