Let $T=p+q+r+s$. By AM-GM, $\sqrt{p(q+r+s)}\le\dfrac{p+(q+r+s)}{2}=\dfrac {T}{2}$. Hence
\[
\sqrt{\dfrac{p}{q+r+s}}=\dfrac{p}{\sqrt{p(q+r+s)}}\ge\dfrac{2p}{T},
\]
with equality only if $p=q+r+s$. Adding the four similar inequalities,
\[
\sum\sqrt{\dfrac{p}{q+r+s}}\ge\dfrac{2(p+q+r+s)}{T}=2 .
\]
Equality would need $p=q+r+s$ and $q=p+r+s$ at the same time, which gives $r+s=0$, impossible. So the inequality is strict: the sum is greater than $2$ (and $\ge2$ as posted). $\blacksquare$
