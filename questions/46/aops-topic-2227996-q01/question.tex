Prove that the function $f(x)=x-\dfrac{1}{x}$, defined for all real $x\ne0$, takes every real value: for every real $y$ there is a real $x\ne0$ with $x-\dfrac{1}{x}=y$. How many such $x$ are there for each $y$?
