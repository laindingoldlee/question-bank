One solution is
\[
\boxed{10+2\times5+4=24},
\]
since $2\times5=10$ and $10+10+4=24$. Any expression that uses each of the four numbers exactly once and equals $24$ is a correct answer; this one is found by noticing $24=10+10+4$ and $10=2\times5$.
