Factor repeatedly as differences of squares:
\[f^{2^{1000}}-1=(f-1)(f+1)(f^2+1)(f^4+1)\cdots\left(f^{2^{999}}+1\right).\]
\begin{itemize}
\item $(f-1)(f+1)$ is a product of two consecutive even numbers, one of them a multiple of $4$, so it is divisible by $8$.
\item For $j\ge1$, $f^{2^j}$ is the square of an odd number, so $f^{2^j}\equiv1\pmod8$ and $f^{2^j}+1\equiv2\pmod 8$: each of the $999$ factors $f^{2^j}+1$ ($j=1,\ldots,999$) contains exactly one factor $2$.
\end{itemize}
So $2^{3+999}=2^{1002}$ divides $n$ for every odd $f$. For $f=3$, $(f-1)(f+1)=8$ contains exactly $2^3$, so $n$ is divisible by $2^{1002}$ but not by $2^{1003}$. The answer is $\boxed{\textbf{(C) } 2^{1002}}$.
