In base $b$, $14_b=b+4$, $24_b=2b+4$ and $41_b=4b+1$. So $3b+8=4b+1$ and $b=7$. The digits $1,2,4$ are less than $7$, so the numerals make sense in base $7$, and the answer is base $\boxed{7}$. (Check: $11+18=29=4\cdot7+1$.)
