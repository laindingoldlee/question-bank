Set $u=x_1,v=x_2$. The inequalities require $0\le u\le\dfrac{1}{3}$, $0\le v\le\dfrac{2}{3}-u$, and $0\le x_3\le1-u-v$. The last upper bound is between $0$ and $1$ throughout this region. Since the joint density is $1$, the probability is
\[
\int_0^{\dfrac{1}{3}}\int_0^{\dfrac{2}{3}-u}(1-u-v)\,dv\,du
=\int_0^{\dfrac{1}{3}}\left(\dfrac{4}{9}-u+\dfrac{u^2}{2}\right)\,du
=\boxed{\dfrac{8}{81}}.
\]
