If $a=1$, then $a^b=1$. Let $a>1$.

\textbf{Integer exponents.} $a^0=1$, and if $a^k\ge1$ then $a^{k+1}=a^k\cdot a\ge1\cdot1=1$; so $a^k\ge1$ for every integer $k\ge0$ by induction.

\textbf{Rational exponents.} Let $b=\dfrac pq$ with integers $p\ge0$, $q\ge1$. Then $r=a^{\dfrac pq}$ is the positive number with $r^q=a^p$. If $r<1$, then $r^q<1$ (a product of $q$ positive numbers less than $1$), while $a^p\ge1$ by the integer case; this is impossible, so $r\ge1$.

\textbf{Real exponents.} For real $b$, the power is defined by $a^b=e^{b\ln a}$ (this agrees with the rational powers above). Since $a>1$, $\ln a>0$, so $t=b\ln a\ge0$, and $e^t\ge e^0=1$ because the exponential function is increasing.

In every case $a^b\ge1$. $\blacksquare$ (Equality holds exactly when $a=1$ or $b=0$.)
