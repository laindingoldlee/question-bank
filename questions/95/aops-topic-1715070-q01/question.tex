$605$ equal spheres are divided into two groups. From the first group an upright pyramid with a square base is built (each layer is a square array, with $1,4,9,\dots$ spheres from the top), and from the second group an upright pyramid with an equilateral triangular base is built (each layer is a triangular array, with $1,3,6,\dots$ spheres from the top). Both pyramids have the same number of layers. How many spheres are in each pyramid?
