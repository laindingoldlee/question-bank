Because $52=2^2\cdot13$, the trailing-zero count is $\min(\lfloor\dfrac{v_2(5168!)}{2}\rfloor,v_{13}(5168!))$. The exponent of $13$ is $\lfloor\dfrac{5168}{13}\rfloor+\lfloor\dfrac{5168}{169}\rfloor+\lfloor\dfrac{5168}{2197}\rfloor=397+30+2=429$. Already $v_2(5168!)\ge\lfloor\dfrac{5168}{2}\rfloor=2584>2\cdot429$, so $13$ is limiting. The answer is $\boxed{429}$.
