In a set of dominoes, each integer from $0$ through $12$ is paired exactly once with each integer from $0$ through $12$ (including itself): one number of the pair is written on one half of a domino and the other number on the other half. If one domino is selected at random from the set, what is the probability that the same number is on both halves?
