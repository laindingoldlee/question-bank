Starting from the graph of $f(x)=x^2$, write the equation of the graph obtained by each of the following transformations.
\begin{enumerate}
\item[1.] Move it $3$ units up.
\item[2.] Move it $5$ units left.
\item[3.] Move it $5$ units right and $4$ units down.
\end{enumerate}
