Set $u=x-y-z$, $v=y-z$, and $w=x+y-z=x+v\ge0$. The equation becomes
\[
u^2+v^2=2\sqrt w-w-v-\dfrac{5}{4}.
\]
Completing squares gives
\[
u^2+(v+\dfrac{1}{2})^2+(\sqrt w-1)^2=0.
\]
Each term is nonnegative, so $u=0,v=-\dfrac{1}{2},w=1$. Therefore $x=\dfrac{3}{2}$, $y+z=\dfrac{3}{2}$, and $y-z=-\dfrac{1}{2}$, yielding $y=\dfrac{1}{2},z=1$. Substitution verifies the equation. The required value is $\boxed{300}$.
