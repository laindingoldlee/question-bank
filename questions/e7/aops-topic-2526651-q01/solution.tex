Let $P(q)$ be the statement ``there is no positive integer $p$ with $p^2=2q^2$''. We prove $P(q)$ for all $q\ge1$ by strong induction.

\textbf{Base case $q=1$:} $p^2=2$ has no integer solution, since $1^2<2<2^2$.

\textbf{Inductive step.} Let $q\ge2$ and assume $P(q')$ for all $1\le q'<q$. Suppose $p^2=2q^2$ for some positive integer $p$. Then $p^2$ is even, so $p$ is even: $p=2p'$ with $p'\ge1$. Then $4p'^2=2q^2$, i.e.
\[q^2=2p'^2.\]
Here $p'^2=\dfrac{q^2}{2}<q^2$, so $1\le p'<q$, and the positive integer $q$ satisfies $q^2=2p'^2$. This contradicts $P(p')$. So $P(q)$ holds.

Hence $P(q)$ holds for every $q\ge1$. If $\sqrt2=\dfrac pq$ with positive integers $p,q$, then $p^2=2q^2$, contradicting $P(q)$. So $\sqrt2$ is irrational. $\blacksquare$

(This is the usual ``infinite descent'' argument written as an induction.)
