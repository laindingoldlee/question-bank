The squares are $k^2$ for $1\le k\le31$. The group containing $k^2$ has index $1+\lfloor\dfrac{k^2-1}{20}\rfloor$. The distinct indices are $1,2,3,4,5,7,8,9,10,12,13,15,17,19,20,23,25,27,29,32,34,37,40,43,45,49$. Thus $\boxed{26}$ groups contain squares. Computing these indices from all thirty-one squares checks every possible group.
