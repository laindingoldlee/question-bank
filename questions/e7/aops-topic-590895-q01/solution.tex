Use inclusion--exclusion over the set of required digits that are missing. For a set $S\subseteq\{0,1,2,4\}$ let $T(S)$ be the number of six-digit numbers using no digit of $S$, so $m=10-|S|$ digits are available:
\begin{itemize}
\item if $0\in S$, $T(S)=m^6$;
\item if $0\notin S$, the first digit has $m-1$ choices (not $0$), so $T(S)=(m-1)m^5$.
\end{itemize}
Then the answer is $\sum_S(-1)^{|S|}T(S)$:
\begin{align*}
&\left(9\cdot10^5\right)-\left(9^6+3\cdot8\cdot9^5\right)+\left(3\cdot8^6+3\cdot7\cdot8^5\right)-\left(3\cdot7^6+6\cdot7^5\right)+6^6\\
&=900000-(531441+1417176)+(786432+688128)-(352947+100842)+46656=\boxed{18810}.
\end{align*}
(For $|S|=k$, the sets containing $0$ number $\dbinom3{k-1}$ and the others $\dbinom3k$.)
