A student argues: ``$f(x)=x^{\dfrac{1}{4}}$ is not a function, because $81$ has four fourth roots, $3$, $-3$, $3i$ and $-3i$, so $81^{\dfrac{1}{4}}$ has four values.''
\begin{enumerate}
\item[(a)] Find all complex numbers $z$ with $z^4=81$.
\item[(b)] Explain the error in the student's argument, and state the value of $81^{\dfrac{1}{4}}$.
\end{enumerate}
