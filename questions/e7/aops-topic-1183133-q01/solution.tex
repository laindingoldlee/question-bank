\textbf{(a)} $z^4-81=(z^2-9)(z^2+9)=(z-3)(z+3)(z-3i)(z+3i)$, so $z^4=81$ has exactly the four solutions $z=3,-3,3i,-3i$.

\textbf{(b)} The student confuses the \emph{equation} $z^4=81$, which has four solutions, with the \emph{expression} $81^{\dfrac{1}{4}}$. For a real number $x\ge0$, the symbol $x^{\dfrac{1}{4}}=\sqrt[4]{x}$ is \emph{defined} as the unique nonnegative real number whose fourth power is $x$ (the principal fourth root). It exists and is unique because $t\mapsto t^4$ is increasing on $[0,\infty)$ and takes every value in $[0,\infty)$. So each $x\ge0$ has exactly one output, and $f(x)=x^{\dfrac{1}{4}}$ (like $\sqrt{x}$) is a function on $[0,\infty)$. In particular
\[
81^{\dfrac{1}{4}}=\boxed{3},
\]
while $-3$, $3i$, $-3i$ are the other solutions of $z^4=81$, not values of $81^{\dfrac{1}{4}}$. (The book's $16^{\dfrac{1}{4}}=2$ uses the same convention.)
