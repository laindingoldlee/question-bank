No. If $a$ and $b$ have the same sign, then $ab>0$ and $\dfrac{1}{b}-\dfrac{1}{a}=\dfrac{a-b}{ab}>0$, so $\dfrac{1}{a}<\dfrac{1}{b}$. But if $a>0>b$, then $\dfrac{1}{a}>0>\dfrac{1}{b}$; for example $a=1$, $b=-1$.
