Write the number as $10a+b$ with digits $a\in\{1,\dots,9\}$ and $b\in\{0,\dots,9\}$. Then
\[
\dfrac{10a+b}{a+b}=1+\dfrac{9a}{a+b}=1+\dfrac{9}{1+\dfrac{b}{a}} .
\]
This is smallest when $\dfrac{b}{a}$ is largest, that is, with $b=9$ and $a=1$, where $\dfrac{b}{a}=9$. The smallest quotient is
\[
\dfrac{19}{10}=\boxed{1.9},
\]
attained only by the number $19$.
