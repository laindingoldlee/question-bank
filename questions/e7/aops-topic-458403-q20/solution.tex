Write the difference as $\overline{ABC}-\overline{DEF}=100(A-D)+\left(\overline{BC}-\overline{EF}\right)$, where $\overline{BC}$ and $\overline{EF}$ are two-digit numbers.

\textbf{The hundreds digits.} For a positive difference we need $A>D$. If $A\ge D+2$, the difference is at least $200-\left(\overline{EF}-\overline{BC}\right)\ge200-(98-24)=126$. So for a small difference we want $A=D+1$, and then the difference is $100-\left(\overline{EF}-\overline{BC}\right)$, which we minimise by making $\overline{EF}-\overline{BC}$ as large as possible.

\textbf{The other digits.} With the remaining digits $w<x<y<z$, the largest value of $\overline{EF}-\overline{BC}$ is $\overline{zy}-\overline{wx}=10(z-w)+(y-x)$: the tens digits matter most, so $E=z$ and $B=w$, and then $F=y$, $C=x$. The pairs of consecutive digits available for $(A,D)$ are:
\begin{itemize}
\item $(5,4)$: remaining $2,6,8,9$: $\overline{EF}-\overline{BC}=98-26=72$, difference $28$ ($526-498$);
\item $(6,5)$: remaining $2,4,8,9$: $98-24=74$, difference $26$ ($624-598$);
\item $(9,8)$: remaining $2,4,5,6$: $65-24=41$, difference $59$ ($924-865$).
\end{itemize}
The least positive difference is $\boxed{26}$, from $624-598$.
