Unit cubes are stacked in the corner of a $3\times3\times3$ box (as in the AoPS logo). Number the positions $(i,j,k)$ with $1\le i,j,k\le3$, where $k$ is the height. A set of positions is allowed if, whenever $(i,j,k)$ is filled, so are $(i-1,j,k)$, $(i,j-1,k)$ and $(i,j,k-1)$ (whenever these exist): each cube is supported from below and pushed against both back walls. How many allowed sets are there, counting the empty box and the full cube?
