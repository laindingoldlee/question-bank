There is no need to expand everything; compare two convenient coefficients.
\begin{itemize}
\item Coefficient of $x$: only $ax\cdot(-1)$ and $2\cdot5x$ contribute, so $10-a=3$ and $a=7$.
\item Coefficient of $x^4$: only $4x^2\cdot bx^2$ and $ax\cdot10x^3$ contribute, so $4b+10a=94$, giving $4b=24$ and $b=6$.
\end{itemize}
(The other coefficients agree: $x^3$: $4\cdot5+ab+2\cdot10=20+42+20=82$; $x^2$: $4\cdot(-1)+5a+2b=-4+35+12=43$.) Hence $a+b=\boxed{13}$.
