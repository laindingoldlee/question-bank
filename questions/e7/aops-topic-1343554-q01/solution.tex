\textbf{(a)} $3$ occurs twice and every other value once: the only mode is $3$, a unique mode.

\textbf{(b)} $1$ and $4$ each occur twice and $6$ once: both $1$ and $4$ are modes, so there is no unique mode (the data set is bimodal).

\textbf{(c)} $8$ occurs three times, $2$ and $9$ twice each: the only mode is $8$, a unique mode.

So $\boxed{\text{(a) and (c) have a unique mode, (b) does not}}$. The word ``unique'' in a problem such as ``the unique mode is $4$'' tells us that no other value occurs as often as $4$.
