A \emph{mode} of a data set is a value that occurs most often. A data set has a \emph{unique mode} if exactly one value occurs most often. For each data set, list all its modes and say whether it has a unique mode.
\begin{enumerate}
\item[(a)] $2,3,3,5,7$
\item[(b)] $1,1,4,4,6$
\item[(c)] $8,2,8,9,2,8,9$
\end{enumerate}
