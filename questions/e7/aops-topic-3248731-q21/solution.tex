The roots are integers exactly when $\Delta=b^2-4c\ge0$ is a perfect square and $b+\sqrt\Delta$ is even. The following exact enumeration checks all $21^2$ quadratics and sums each once, yielding $\boxed{70}$.
\begin{verbatim}
from math import isqrt
answer=0
for b in range(-10,11):
 for c in range(-10,11):
  d=b*b-4*c
  if d>=0 and isqrt(d)**2==d and (b+isqrt(d))%2==0:
   answer+=1+b+c
print(answer)
\end{verbatim}
