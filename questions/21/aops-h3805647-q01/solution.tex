Induction gives $a_n=a_0^{\dfrac{1}{2^n}}$. It equals $1$ if and only if $a_0=1$. If $a_0>1$, the sequence decreases while remaining above $1$; if $0<a_0<1$, it increases while remaining below $1$. Thus in either case it has a positive limit $L$, and the recurrence gives $L=\sqrt L$, forcing $L=1$. Every positive starting value therefore approaches $\boxed1$, but no starting value other than $1$ reaches it in finitely many steps.
