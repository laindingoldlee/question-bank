\textbf{No.} Each number $k\in\{1,\dots,6\}$ appears on $6$ remaining dominoes, with the double $k$--$k$ counting twice, so on $7$ halves in total. Inside a chain, halves meet in matching pairs, so every number appearing an odd number of times must occupy an end of the chain. All six numbers appear an odd number of times, but a chain has only $2$ ends. $\boxed{\text{Impossible}}$.
