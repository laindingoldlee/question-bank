Write the number as $10a+b$ with $1\le a\le9$, $0\le b\le9$. Then
\[10a+b=6(a+b)\iff4a=5b .\]
Since $\gcd(4,5)=1$, $5\mid a$ and $4\mid b$; with $a\ge1$ this forces $a=5$, $b=4$. The only such number is $54$ ($6\cdot9=54$), so there is $\boxed{1}$.
