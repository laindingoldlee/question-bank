Given chosen numbers $x_1<x_2<\cdots<x_k$ with gaps at least $2$, set $y_i=x_i-(i-1)$. Then $1\le y_1<y_2<\cdots<y_k\le n-k+1$, and this map is a bijection onto $k$-subsets of $\{1,\dots,n-k+1\}$. So the count is $\boxed{\binom{n-k+1}{k}}$, and for $n=10$, $k=4$ it is $\binom74=\boxed{35}$.
