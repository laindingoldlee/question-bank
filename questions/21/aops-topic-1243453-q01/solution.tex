By symmetry $\dbinom{30}{18}=\dbinom{30}{12}$, so $n=30$ works. It is the only solution: for $n\ge12$, $\dbinom{n+1}{12}=\dbinom n{12}\cdot\dfrac{n+1}{n-11}>\dbinom n{12}$, so $\dbinom n{12}$ is strictly increasing in $n$ and takes each value at most once. Hence $n=\boxed{30}$.
