Factor: $(x-y)(x^2+xy+y^2)=721=7\cdot103$, with $103$ prime. Since $x^3>y^3$, $x>y$, so $x-y\ge1$. Also $(x-y)^2<x^2+xy+y^2$, so $x-y$ is the smaller factor and $(x-y)^2<721$; hence $x-y\in\{1,7\}$.
\begin{itemize}
\item $x-y=1$: $x^2+xy+y^2=3y^2+3y+1=721$, so $y^2+y=240=15\cdot16$, giving $y=15$, $x=16$.
\item $x-y=7$: $x^2+xy+y^2=3y^2+21y+49=103$, so $y^2+7y-18=0=(y+9)(y-2)$, giving $y=2$, $x=9$.
\end{itemize}
The solutions are
\[
\boxed{(x,y)=(16,15)\ \text{and}\ (9,2)}
\]
(check: $4096-3375=721$ and $729-8=721$).
