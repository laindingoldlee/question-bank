First count the ways when the boxes are labelled $1,2,3,4$: these are the functions from the $10$ donuts to the $4$ boxes that leave no box empty. By inclusion-exclusion on the set of empty boxes, their number is
\[4^{10}-\dbinom41 3^{10}+\dbinom42 2^{10}-\dbinom43 1^{10}=1048576-236196+6144-4=818520.\]
Since every box is nonempty, the $4$ boxes receive $4$ different sets of donuts, so each way of filling identical boxes corresponds to exactly $4!=24$ labelled ways. Hence the answer is
\[\dfrac{818520}{24}=\boxed{34105}.\]
(This is the Stirling number of the second kind $S(10,4)$.)
