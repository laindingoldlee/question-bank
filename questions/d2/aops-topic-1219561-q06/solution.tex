Five-digit multiples of $3$: $\dfrac{99999-10000+1}{3}=30000$. Count those with no digit $3$: the first digit has $8$ choices ($1$--$9$ except $3$), the next three $9$ each ($0$--$9$ except $3$), and for the last digit, among the $9$ allowed digits $\{0,1,2,4,5,6,7,8,9\}$ the residues mod $3$ are $0$: $\{0,6,9\}$, $1$: $\{1,4,7\}$, $2$: $\{2,5,8\}$, three each, so exactly $3$ choices make the number divisible by $3$. That gives $8\cdot9^3\cdot3=17496$. The answer is $30000-17496=\boxed{12504}$.
