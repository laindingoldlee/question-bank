$p=1$ fails, as both numbers are $0$. Let $p\ge2$. Since $\gcd(p^p-1,p)=1$ and $p^{2016}-p=p\left(p^{2015}-1\right)$,
\[
\gcd\left(p^p-1,\,p^{2016}-p\right)=\gcd\left(p^p-1,\,p^{2015}-1\right)=p^{\gcd(p,2015)}-1,
\]
using $\gcd(p^m-1,p^n-1)=p^{\gcd(m,n)}-1$. This equals $1$ only if $p^{\gcd(p,2015)}=2$, i.e. $p=2$ (and indeed $\gcd(2,2015)=1$). For $p\ge3$ the gcd is at least $p-1\ge2$. So the only answer is $\boxed{p=2}$: $\gcd(3,\,2^{2016}-2)=1$ because $2^{2016}-2\equiv1-2\equiv2\pmod3$.
