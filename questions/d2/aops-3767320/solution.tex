The function is even and has $f(0)=0$. Suppose $T>0$ is a period. Then $f(nT)=0$ for every positive integer $n$, so $k_n=\sqrt{n^2T^2+1}$ is an integer. Moreover $k_{n+1}-k_n\to T$. An integer sequence that converges is eventually constant, so $T$ is a positive integer and eventually $k_{n+1}-k_n=T$. But for integer $T$ and sufficiently large $n$, $(nT)^2<n^2T^2+1<(nT+1)^2$, making $k_n$ nonintegral. This contradiction proves that the function is not periodic.
