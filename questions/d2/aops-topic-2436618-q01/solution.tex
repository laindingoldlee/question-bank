First, every term is positive. Indeed, if some term $a_{n+1}$ were negative, then $a_{n+2}^2=a_{n+1}<0$, which is impossible for a real number $a_{n+2}$; and no term is $0$, since then all earlier terms would be $0$, but $a_0=3$. So $a_{n+1}=\sqrt{a_n}$ for every $n$.

Now $a_n=3^{\dfrac{1}{2^n}}$ by induction: it holds for $n=0$, and if $a_n=3^{\dfrac1{2^n}}$, then $a_{n+1}=\sqrt{a_n}=3^{\dfrac{1}{2^{n+1}}}$. So
\[a_n=\boxed{3^{\dfrac{1}{2^n}}}=\sqrt{\sqrt{\cdots\sqrt3}}\quad(n\text{ square roots}).\]
