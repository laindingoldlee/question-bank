An inversion is a pair in decreasing order. Swapping an inverted pair removes at least that inversion and cannot increase the total: intermediate values between the swapped values remove two additional inversions each, while other changes cancel. The initial decreasing string has $\binom92=36 $ inversions, so at most 36 moves occur. Swapping adjacent inverted pairs removes exactly one inversion each and eventually sorts the string, attaining 36 moves. Thus the maximum is $\boxed{36}$.
