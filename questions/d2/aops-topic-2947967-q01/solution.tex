Each number appears on $7$ dominoes, and the double counts twice, so each number appears on $8$ halves. Inside the chain, halves are matched in equal pairs, so for each number the count of its halves at the ends has the same parity as $8$, i.e. is even. One end is $5$, so the other end is also $\boxed{5}$.
