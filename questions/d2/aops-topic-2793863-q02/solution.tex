The digits are increasing, so none is $0$. If the last digit is the odd digit $d$, the first two are any $2$ of $1,\dots,d-1$: $\binom22+\binom42+\binom62+\binom82=1+6+15+28=\boxed{50}$ for $d=3,5,7,9$.
