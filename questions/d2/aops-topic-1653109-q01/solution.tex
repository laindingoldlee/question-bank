Each fugitive lands in your town with probability
\[
p=\dfrac{100{,}000}{325{,}000{,}000}=\dfrac{1}{3250}.
\]

\textbf{(a)} By linearity of expectation the expected number is $300p=\dfrac{300}{3250}=\boxed{\dfrac{6}{65}\approx0.092}$.

\textbf{(b)} The probability that none of the $300$ independent fugitives comes is $(1-p)^{300}$, so
\[
P(\text{at least one})=1-\left(1-\dfrac{1}{3250}\right)^{300}\approx\boxed{0.0882}.
\]
This is close to the expected number because $p$ is tiny. So there is only about a $9\%$ chance; the fear is not really justified.
