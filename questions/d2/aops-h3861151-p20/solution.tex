If $n\equiv0\pmod3$, then $n-3$ is a multiple of $3$ greater than $3$, so $f(n)=3$. If $n\equiv2\pmod3$, then $n-5$ is a multiple of $3$ greater than $3$, so $f(n)\le5$. If $n\equiv1\pmod3$, then $n-7$ is a multiple of $3$ greater than $3$, so $f(n)\le7$. For $n=16$, the differences with $3,5$ are prime, whereas $16-7=9$ is not. Thus $\boxed{\max f(n)=7}$.
