We have $30=2\cdot3\cdot5$ and $72=2^3\cdot3^2$. The three conditions are
\[N\mid30\cdot72,\qquad72\mid30N,\qquad30\mid72N.\]
\begin{itemize}
\item $72\mid30N$: since $30N=2\cdot3\cdot5\cdot N$, the number $N$ must supply the missing factors $2^2\cdot3$, so $12\mid N$.
\item $30\mid72N$: since $72$ already contains $2$ and $3$, the factor $5$ must come from $N$, so $5\mid N$.
\end{itemize}
So $60\mid N$, and $N\ge60$. For $N=60$ all three conditions hold: $30\cdot72=2160=36\cdot60$, $30\cdot60=1800=25\cdot72$ and $72\cdot60=4320=144\cdot30$. The smallest value is $\boxed{60}$.
