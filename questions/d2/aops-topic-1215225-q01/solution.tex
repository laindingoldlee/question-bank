Note that
\[n(n+1)(n+2)(n+3)=(n^2+3n)(n^2+3n+2)=(n^2+3n+1)^2-1.\]
So the product is less than $10000$ exactly when $(n^2+3n+1)^2<10001$, that is $|n^2+3n+1|\le100$ (because $100^2<10001<101^2$). The value $n^2+3n+1$ is never below $-\dfrac{5}{4}$, so we need $n^2+3n-99\le0$, i.e.
\[\dfrac{-3-\sqrt{405}}{2}\le n\le\dfrac{-3+\sqrt{405}}{2},\qquad -11.56\le n\le 8.56.\]
Thus $n=-11,-10,\dots,8$, giving $\boxed{20}$ sequences. (If only positive integers are allowed, $n=1,\dots,8$ gives $8$ sequences: $8\cdot9\cdot10\cdot11=7920$ but $9\cdot10\cdot11\cdot12=11880$.)
