In a magic square, the sums of the numbers in each row, each column and both main diagonals are all equal. The numbers in the square below are written in some base $b$, not base $10$. For what base $b$ is it a magic square?
\[
\begin{array}{ccc}
13&1&11\\
3&10&12\\
4&14&2
\end{array}
\]
