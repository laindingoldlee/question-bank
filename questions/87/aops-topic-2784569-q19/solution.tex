A finite width requires $n\ge2$. The two rounding possibilities together say $n-1<\dfrac{1000}{d}<n+1$, equivalently $\dfrac{1000}{n+1}<d<\dfrac{1000}{n-1}$. The exact interval width is $\dfrac{2000}{n^2-1}$. Hence $n^2-1=16899$, so $\boxed{n=130}$.
