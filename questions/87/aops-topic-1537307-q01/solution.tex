Write $n=2k$ with $k\ge2$. Then
\[
n=\underbrace{2+2+\cdots+2}_{k\text{ terms}}
\]
is a sum of $k\ge2$ primes. $\blacksquare$

(The ``trick'' is that the number of primes is not fixed. Requiring \emph{exactly two} primes gives Goldbach's conjecture, which is still unproved.)
