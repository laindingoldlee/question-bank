If a finite limit $L$ exists, continuity gives $L=x^L$, hence $\ln x=\dfrac{\ln L}{L}$. For $L>0$, the function $\dfrac{\ln L}{L}$ has maximum $\dfrac{1}{e}$ at $L=e$, so convergence is impossible when $x>e^{\dfrac{1}{e}}$. In that case the iterates are increasing; if bounded they would converge to a fixed point, so they tend to infinity. Conversely, if $1\le x\le e^{\dfrac{1}{e}}$, monotonicity gives an increasing iteration, and $t_n\le e$ implies $t_{n+1}\le x^e\le e$. Starting at $1$, induction bounds all iterates by $e$, so they converge. Thus $\boxed{M=e^{\dfrac{1}{e}}}$.
