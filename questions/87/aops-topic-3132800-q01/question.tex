A finite set of points is partitioned into $A$ and $B$. A bipartite spanning tree uses only edges joining the two sets. Suppose $A_1B_1,B_1A_2,A_2B_2$ form a three-edge path. A move replaces $A_1B_1$ by $A_1B_2$, but is allowed only when $A_1B_2<A_1B_1$. Prove that the result is still a bipartite spanning tree and that every sequence of allowed moves terminates.
