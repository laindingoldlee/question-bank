Count ordered sequences of draws with the multiplication principle.
\begin{enumerate}
\item[(a)] $12$ choices, then $11$, then $10$: $12\cdot11\cdot10=\boxed{1320}$.
\item[(b)] Always $12$ choices: $12^3=\boxed{1728}$.
\item[(c)] $12$ choices for the first ball; it is replaced, so $12$ choices for the second; the second is kept out, so $11$ for the third: $12\cdot12\cdot11=\boxed{1584}$.
\end{enumerate}
