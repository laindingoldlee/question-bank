Try $y=z+1$. Then $y^2-z^2=2z+1$, and the equation becomes $x^2+2z+1=1999$, that is
\[
z=\dfrac{1998-x^2}{2}.
\]
This is an integer whenever $x$ is even. So for every integer $t$,
\[
x=2t,\qquad y=1000-2t^2,\qquad z=999-2t^2
\]
is a solution: indeed $y^2-z^2=(y-z)(y+z)=1\cdot(1999-4t^2)$, so $x^2+y^2-z^2=4t^2+1999-4t^2=1999$. Different values of $t\ge0$ give different values of $x$, so there are infinitely many solutions (for example $t=0$ gives $(0,1000,999)$ and $t=1$ gives $(2,998,997)$).
