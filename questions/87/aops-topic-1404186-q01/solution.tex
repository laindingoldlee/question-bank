Count by the number of digits; the first digit cannot be $0$.
\begin{itemize}
\item $1$ digit: $2,1,7$: $3$.
\item $2$ digits: first digit $3$ choices (not $0$), second $3$ choices: $9$.
\item $3$ digits: $3\cdot3\cdot2=18$.
\item $4$ digits: $3\cdot3\cdot2\cdot1=18$.
\end{itemize}
The total is $3+9+18+18=\boxed{48}$.
