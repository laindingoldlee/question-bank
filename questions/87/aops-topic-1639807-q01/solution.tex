Let $T=0+1+2+\cdots+n$. Write the sum forwards and backwards and add the two rows term by term:
\[
\begin{array}{rcccccc}
T=&0&+&1&+\cdots+&n\\
T=&n&+&(n-1)&+\cdots+&0\\\hline
2T=&n&+&n&+\cdots+&n
\end{array}
\]
Each column adds up to $n$ (the $j$-th column is $j+(n-j)$), and there are $n+1$ columns. So $2T=n(n+1)$ and
\[
T=\dfrac{n(n+1)}{2}. \qquad\blacksquare
\]
For example, $1+2+\cdots+100=\dfrac{100\cdot101}{2}=5050$.
