Since $n!=n\cdot(n-1)!$, multiplying by $n$ in base $n$ just appends a digit $0$. So $n!$ in base $n$ is $(n-1)!$ written in base $n$ followed by a $0$.

For $n=8$: $7!=5040$. Converting to base $8$:
\[
5040=1\cdot8^4+1\cdot8^3+6\cdot8^2+6\cdot8+0
\]
(since $4096+512+384+48=5040$), so $7!=11660_8$ and
\[
8!=\boxed{116600_8}.
\]
Check: $116600_8=8\cdot5040=40320=8!$. (One can repeat the trick: $7!=7\cdot6!$, $6!=720=1320_8$, and $1320_8\cdot7=11660_8$.)
