Each row is one of $\dfrac{4!}{2!}=12$ distinct permutations of TTOE. Enumerate the $12^4=20736$ ordered choices of four rows. Retain an array if sorting the four symbols in each column and each disjoint 2 by 2 box gives EOTT. Exactly $\boxed{112}$ arrays survive. This finite enumeration is exhaustive because the row condition gives precisely these twelve choices and the remaining checks impose exactly the other constraints.
