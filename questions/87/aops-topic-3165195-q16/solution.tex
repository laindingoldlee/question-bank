Move all terms to one side and write $2(a-b-3c)^2+3(b-3c)^2=0$. Each square is nonnegative, so $b=3c$ and $a=b+3c=6c$. The expression is $\dfrac{9(10c)^3}{5(6c)(3c)c}=\boxed{100}$, valid because $c\ne0$.
