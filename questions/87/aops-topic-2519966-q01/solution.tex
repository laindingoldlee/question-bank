\textbf{(a)} Since $b\ge1$, $\dfrac ab\le a$. But the decimal ``$a.b$'' has integer part $a$ and a nonzero fractional part (its digits after the point are those of $b\ge1$), so it is greater than $a$. Hence it never equals $\dfrac ab$.

\textbf{(b)} With single digits, ``$b.a$'' $=b+\dfrac{a}{10}$. So we need
\[\dfrac ab=b+\dfrac a{10}\iff10a=10b^2+ab\iff a(10-b)=10b^2.\]
Since $a\le9$, we need $10b^2\le9(10-b)$, i.e. $10b^2+9b\le90$, so $b\le2$.
\begin{itemize}
\item $b=1$: $9a=10$, no integer solution.
\item $b=2$: $8a=40$, $a=5$. Indeed $\dfrac52=2.5$.
\end{itemize}
The only fraction is $\boxed{\dfrac52=2.5}$.
