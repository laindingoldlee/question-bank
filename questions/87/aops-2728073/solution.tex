Using the principal logarithm, $\operatorname{Log}(-16)=\log16+i\pi$, so the value is $\exp((\dfrac{3}{2})(\log16+i\pi))=64e^{\dfrac{3\pi i}{2}}=\boxed{-64i}$. In general $(z^a)^b=z^{ab}$ fails for principal complex powers because taking a principal logarithm again can change the argument by $2\pi$. In particular $((-16)^6)^{\dfrac{1}{4}}=64$, which is a different operation. Also $(-16)^3=-4096$, not positive 4096.
