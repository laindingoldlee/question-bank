A string of two letters with numbers $a$ and $b$ (each from $1$ to $26$) becomes the digit string $\overline{a}\,\overline{b}$. Bob can decode it exactly when no other pair $(a',b')$ gives the same digit string, i.e.\ when the digit string has only one split into two letter numbers. Classify by the lengths of $a$ and $b$ ($1$-digit letters are $1$--$9$, $2$-digit letters are $10$--$26$).

\textbf{Two one-digit letters} ($81$ strings, two digits $d_1d_2$): the only other split would be a single two-digit number, which is not two letters. All $81$ are unambiguous.

\textbf{Two two-digit letters} ($17^2=289$ strings, four digits): the splits are $1+3$, $2+2$, $3+1$, and a $3$-digit part is never a letter. All $289$ are unambiguous.

\textbf{A one-digit and a two-digit letter} (in either order; the digit string has three digits $d_1d_2d_3$): the two possible splits are $d_1\mid d_2d_3$ and $d_1d_2\mid d_3$. The string is ambiguous exactly when both splits are valid, i.e.\ when $d_1\ne0$, $d_2d_3\in[10,26]$, $d_1d_2\in[10,26]$ and $d_3\ne0$.
\begin{itemize}
\item For $d_2d_3$ to be a two-digit letter we need $d_2\in\{1,2\}$; for $d_1d_2$ to be one as well we need $d_1\in\{1,2\}$ (then $d_1d_2\in\{11,12,21,22\}$). Finally $d_3\ne0$ and $d_2d_3\le26$: for $d_2=1$, $d_3\in\{1,\dots,9\}$ ($9$ choices); for $d_2=2$, $d_3\in\{1,\dots,6\}$ ($6$ choices). That gives $2\cdot(9+6)=30$ ambiguous digit strings, each produced by $2$ different letter pairs, i.e.\ $60$ ambiguous letter pairs.
\item The letter pairs of this type number $2\cdot9\cdot17=306$, so $306-60=246$ are unambiguous.
\end{itemize}

\textbf{Total.} $81+289+246=\boxed{616}$.
