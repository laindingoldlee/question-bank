Alice and Bob encrypt strings of letters with the scheme $A=1$, $B=2$, $C=3$, $\dots$, $Z=26$; for example, $CAT$ is encrypted as 3-1-20. Alice encrypts a two-letter string but leaves out the dash, so Bob receives only a string of digits. Bob knows that Alice sent two letters, and he can decode her string with certainty. How many two-letter strings could Alice have sent?
