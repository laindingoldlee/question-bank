Measure distance in laps. In $t$ hours Superman covers $\dfrac{t}{2.5}=\dfrac{2t}{5}$ laps and Flash $\dfrac{t}{1.5}=\dfrac{2t}{3}$ laps. Running in opposite directions, they meet each time their combined distance is a whole number of laps:
\[
\dfrac{2t}{5}+\dfrac{2t}{3}=\dfrac{16t}{15}=k,\qquad\text{i.e. } t=\dfrac{15k}{16}\text{ hours},\ k=1,2,3,\dots
\]
We need $\dfrac{15k}{16}\le24$, i.e.\ $k\le\dfrac{384}{15}=25.6$. So they pass each other $\boxed{25}$ times.
