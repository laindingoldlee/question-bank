First count the integers from $0$ to $99999$. Write each one with exactly five digits, using leading zeros (leading zeros do not introduce a $5$ or a $7$). Each of the five digits can be any of the $8$ digits other than $5$ and $7$, giving $8^5=32768$ strings, one of which is $00000$, that is, the number $0$.

So $32767$ integers from $1$ to $99999$ qualify. Finally $100000$ itself contains no $5$ and no $7$. The answer is $32767+1=\boxed{32768}$.
