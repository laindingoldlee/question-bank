Write the second equation as $bx-(b-4)y=12$. The system has a unique solution unless the coefficient determinant vanishes:
\[3\cdot\left(-(b-4)\right)-(-4)\cdot b=b+12=0,\qquad b=-12.\]
For $b=-12$ the second equation is $-12x+16y=12$, i.e. $3x-4y=-3$, which contradicts $3x-4y=12$. So the system has no solutions exactly for $b=\boxed{-12}$.
