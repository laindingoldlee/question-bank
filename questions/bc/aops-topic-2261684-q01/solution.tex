\textbf{(a)} By definition, $\log_b y$ is the number $x$ with $b^x=y$; this only makes sense if there is \emph{exactly one} such $x$. For $b=1$, every power is $1^x=1$ (for integer $x$ this is repeated multiplication of $1$; in general $1^x$ is defined as $1$). So the equation $1^x=1$ is satisfied by $x=0$, $x=1$, $x=2$, and every other number: there is no single number that could be called $\log_1 1$. (And for $y\ne1$, the equation $1^x=y$ has no solution at all.) The student's chain treats $\log_1 1$ as a number equal to $0$, to $1$, to $2,\dots$ at the same time, which is exactly the error: the expression $\log_11$ is undefined, and nothing follows from it.

\textbf{(b)} $\log_b y$ is defined for bases $b>0$ with $b\ne1$ (and $y>0$); for such $b$, $x\mapsto b^x$ is strictly monotonic, so each $y>0$ has exactly one logarithm. For these bases $\log_b1=0$ (because $b^0=1$), and $\log_b1+\log_b1=0+0=0=\log_b1$ is correct; it is the rule $\log_b(uv)=\log_bu+\log_bv$ with $u=v=1$. The only mistake is the base $1$.
