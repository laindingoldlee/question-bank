The rule is $a_n=a_{n-3}+a_{n-2}-a_{n-1}$ for $n\ge4$.

\textbf{Spotting the pattern.} Rewrite the rule as
\[
a_n+a_{n-1}=a_{n-2}+a_{n-3}.
\]
Now let $d_n=a_n-a_{n-2}$. From $a_n+a_{n-1}=a_{n-2}+a_{n-3}$ we get $d_n=a_n-a_{n-2}=a_{n-3}-a_{n-1}=-d_{n-1}$. The first values are $d_3=a_3-a_1=2$ and $d_4=a_4-a_2=2000-2002=-2$, consistent with $d_4=-d_3$. Hence
\[
d_n=(-1)^{n+1}\cdot2\qquad(n\ge3),
\]
that is, the odd-numbered terms go up by $2$ each time and the even-numbered terms go down by $2$ each time:
\[
a_{2k+1}=2001+2k,\qquad a_{2k}=2002-2(k-1)=2004-2k .
\]
(Listing a few terms, $2001,2002,2003,2000,2005,1998,2007,1996,\dots$, shows the same thing; the computation above explains why it continues for ever.)

\textbf{Answer.} With $2k=2004$, i.e.\ $k=1002$, the $2004^\text{th}$ term is $2004-2004=0$, answer $\boxed{\textbf{(C)}\ 0}$.
