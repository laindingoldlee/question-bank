A student must choose a program of $5$ courses from a menu of $8$ courses: English, Algebra, Geometry, History, Art, Music, Coding and Latin. The program must contain at least one mathematics course (the mathematics courses are Algebra and Geometry). In how many ways can the program be chosen?
