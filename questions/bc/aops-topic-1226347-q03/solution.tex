Only decisive games matter. Let $N$ be the number of decisive games until one colour has $4$ wins; each decisive game is won by either colour with probability $\dfrac{1}{2}$. $N=k$ ($k=4,\dots,7$) when the leader gets its $4$th win in game $k$ having $3$ wins in the first $k-1$:
\[P(N=k)=2\dbinom{k-1}{3}\dfrac{1}{2^k}:\quad P(4)=\dfrac{1}{8},\ P(5)=\dfrac{1}{4},\ P(6)=\dfrac{5}{16},\ P(7)=\dfrac{5}{16}.\]
So $E[N]=\dfrac{4}{8}+\dfrac{5}{4}+\dfrac{30}{16}+\dfrac{35}{16}=\dfrac{93}{16}$. Each decisive game takes on average $\dfrac{1}{0.1}=10$ games, so the expected number of games is $10\cdot\dfrac{93}{16}=\boxed{\dfrac{465}{8}}=58.125$.
