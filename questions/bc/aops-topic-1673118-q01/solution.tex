\textbf{Decode the symbols.} Try the simplest rule consistent with $2+3=4$: each Martian symbol stands for the digit one less, i.e.\ Martian $1,2,\dots,9$ mean $0,1,\dots,8$. Then the statements read
\[
1+2=3,\quad 15+43=58,\quad 38-15=23,\quad 4\cdot5=20,\quad 18\cdot34=612,\quad \dfrac{504}{8}=63,\quad 12^4=20736,\quad \sqrt{64}=8,
\]
all of which are true (note that the exponent and the divisor are decoded too). This rule is forced: a search over all base-ten assignments of digits to the nine symbols shows it is the only one satisfying all eight statements.

\textbf{Evaluate.} Decoding the expression gives
\[
\left(\left(\dfrac{28}{4}\right)^3-20\right)\sqrt{146+23}=\left(7^3-20\right)\sqrt{169}=(343-20)\cdot13=323\cdot13=\boxed{4199}.
\]
(In Martian notation this would be written with the symbols for $4,1,9,9$, i.e.\ $5$, $2$ and twice the Martian symbol for nine, which does not occur in the riddle.)
