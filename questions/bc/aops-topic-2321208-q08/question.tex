In a bow duel, Dream and Techno each start with $10$ hearts, and every arrow that hits takes away $4$ hearts. A player whose hearts reach $0$ or less dies. In each round both fire at the same time: Techno hits Dream with probability $\dfrac34$ and Dream hits Techno with probability $\dfrac12$, independently. The first to die loses; if both die in the same round, nobody wins. What is the probability that Dream wins?
