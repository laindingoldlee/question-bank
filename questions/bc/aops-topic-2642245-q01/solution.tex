Each term splits as $\dfrac{1}{(2k-1)(2k+1)}=\dfrac12\left(\dfrac{1}{2k-1}-\dfrac{1}{2k+1}\right)$, so the sum telescopes:
\[\dfrac12\left(\dfrac11-\dfrac13+\dfrac13-\dfrac15+\cdots+\dfrac{1}{97}-\dfrac{1}{99}\right)=\dfrac12\left(1-\dfrac{1}{99}\right)=\boxed{\dfrac{49}{99}}.\]
