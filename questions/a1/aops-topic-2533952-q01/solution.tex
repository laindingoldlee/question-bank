First, $a$ and $b+ma$ are not both zero: if $a=0$ then $b+ma=b\ne0$. So both greatest common divisors exist.

If $d$ divides $a$ and $b$, then $d$ divides $b+ma$. Conversely, if $d$ divides $a$ and $b+ma$, then $d$ divides $(b+ma)-ma=b$. So the pairs $(a,b)$ and $(a,b+ma)$ have exactly the same common divisors, and therefore the same greatest common divisor. $\blacksquare$

(This is the step behind the Euclidean algorithm: for instance $\gcd(91,35)=\gcd(91-2\cdot35,35)=\gcd(21,35)=7$.)
