Last digits of powers of $2$, $3$ and $7$ repeat with period $4$, so only the exponents mod $4$ matter.
\begin{itemize}
\item The first exponent ends in $34$, so it is $\equiv2\pmod4$, and $2^{\cdots}$ ends in $4$.
\item The second exponent ends in $15$, so it is $\equiv3$, and $3^{\cdots}$ ends in $7$.
\item Every power of $5$ ends in $5$.
\item The last exponent ends in $91$, so it is $\equiv3$, and $7^{\cdots}$ ends in $3$.
\end{itemize}
The bracket is positive and ends in the last digit of $4-7+5-3=-1$, i.e. $9$. The product ends in the last digit of $8\cdot9=72$, which is $\boxed{2}$.
