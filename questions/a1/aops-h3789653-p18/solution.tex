Subtracting the first equation from the second yields
\[(y-x)(x^2+xy+y^2+z)=23.\]
The second factor is a positive integer greater than one, so primality forces $y-x=1$ and $x^2+xy+y^2+z=23$. Thus $z=22-3x(x+1)>0$, which permits only $x=1,2$. If $x=1$, then $y=2,z=16$, which fails $x^3-yz+4=0$. If $x=2$, then $y=3,z=4$, which satisfies all three original equations. Consequently $x+y+z=\boxed9$.
