If exactly $L$ statements are false, precisely the statements numbered $1,\ldots,L$ are true. Thus the number of true statements is also $L$, forcing $L+L=6$. Hence $\boxed3$ statements are false. This is consistent: statements 1,2,3 are true and 4,5,6 are false.
