If Ana told the truth, Banana would also be truthful, but exactly one of them lies. So Ana lies and Banana tells the truth, which is consistent: Banana's statement (five apples, Ana lying) is then true and Ana's is false. The liar is $\boxed{\text{Ana}}$.
