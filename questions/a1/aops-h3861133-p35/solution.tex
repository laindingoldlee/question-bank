An exhaustive count gives $\boxed{570450}$. A ten-digit integer is in range $10^9\le N<10^{10}$. By symmetry take $1\le a\le b$. At least one base is at least two, so only $2\le k\le33$ need be tested. For each $k$, list all powers $a^k<10^{10}$, add every unordered pair whose sum is in range, and retain a sum if its ten decimal digits have bit mask $2^{10}-1$ with no repeated bit. Insert retained sums in a set to remove overlaps between representations and exponents. For $k=2$, divisibility by nine of every pandigital number forces both bases divisible by three, which accelerates the search. Squares give 568805 distinct sums; cubes raise the cumulative count to 570450; all higher exponents add none. These bounds and loops test every permitted representation.
