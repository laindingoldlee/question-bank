Allow digits from $D=\{0,3,4,5,6,7,8,9\}$, whose sum is $42$. The repeating decimal is $\dfrac{100a+10b+c}{999}$. Each digit occurs $8^2=64$ times in each position, so the total is $\dfrac{64\cdot42\cdot111}{999}=\dfrac{896}{3}$. Including or excluding $000$ has no effect. Thus $m+n=\boxed{899}$.
