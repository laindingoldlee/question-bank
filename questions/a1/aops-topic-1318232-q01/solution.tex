First count arrangements in $6$ labelled positions around the ring: $\dfrac{6!}{3!}=120$. The symmetry group of the ring has $12$ elements ($6$ rotations and $6$ reflections). By Burnside's lemma, the number of distinct rings is the average number of arrangements fixed by a symmetry.
\begin{itemize}
\item The identity fixes all $120$.
\item A non-trivial rotation moves every position, so it would have to map the single green key to another green key, impossible: $0$.
\item A reflection fixes at most $2$ positions, but the green, blue and white keys must each sit on a fixed position (each colour occurs once): $0$.
\end{itemize}
So there are $\dfrac{120}{12}=\boxed{10}$ distinct key rings. (Since no arrangement has a symmetry, each ring corresponds to exactly $12$ arrangements.)
