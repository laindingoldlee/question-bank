There are $3^4=81$ equally likely outcomes. For a given pair of elves, the outcomes where they throw at each other number $3^2=9$ (the other two elves are free). There are $\dbinom42=6$ pairs. Two pairs can both be mutual only if they are disjoint, and then all four throws are determined: $3$ such outcomes (one for each way to split the elves into two pairs). By inclusion--exclusion the number of outcomes with a mutual pair is $6\cdot9-3=51$, so the probability is $\dfrac{51}{81}=\dfrac{17}{27}$ and $m+n=\boxed{44}$.
