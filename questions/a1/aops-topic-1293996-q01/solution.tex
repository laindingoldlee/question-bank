$x^2-y^2-3(x-y)=(x-y)(x+y-3)=0$, so $x=y$ or $x+y=3$. If $x=y$, then $x+y=2x\in\{-6,-4,-2,0,2,4,6\}$; if $x+y=3$ (possible, e.g. $x=0$, $y=3$), we get $3$. So there are $\boxed{8}$ values, answer (B).
