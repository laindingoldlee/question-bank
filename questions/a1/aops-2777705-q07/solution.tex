Drop perpendiculars from the shorter-base endpoints to the longer base. Each end triangle has hypotenuse $2\sqrt2$ and height 2, so its horizontal leg is $\sqrt{8-4}=2$. The longer base is therefore $4+2+2=8$. The area is $\dfrac{4+8}{2}\cdot2=\boxed{12}$.
