A sum uses $2m+1$ sevens for some $m\ge0$, so it has the form
\[N=7+(5a+14m+9c),\qquad a,m,c\ge0.\]
Hence $N$ can be formed exactly when $N-7$ lies in the set $S$ of numbers of the form $5a+9c+14m$ with $a,c,m\ge0$.

\textbf{$31\notin S$.} Using $m=0,1,2$ fourteens leaves $31$, $17$ or $3$, which must be of the form $5a+9c$. But $31-9c\in\{31,22,13,4\}$, $17-9c\in\{17,8\}$ and $3$ contain no multiple of $5$. So $31\notin S$.

\textbf{Every integer $M\ge32$ is in $S$.} We have
\[32=5+27,\quad 33=15+18,\quad 34=25+9,\quad 35=5\cdot7,\quad 36=9\cdot4,\]
and adding $5$s to these five consecutive numbers reaches every larger integer.

So every $N\ge39$ can be formed and $N=7+31=38$ cannot. The answer is $\boxed{38}$.
