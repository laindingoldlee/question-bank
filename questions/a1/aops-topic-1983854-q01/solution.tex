\textbf{$7^{169}<5^{343}$:} $5^{343}>5^{338}=(5^2)^{169}=25^{169}>7^{169}$.

\textbf{$13^{121}<7^{169}$:} we have $13^3=2197<2401=7^4$. Hence
\[
13^{121}<13^{123}=(13^3)^{41}<(7^4)^{41}=7^{164}<7^{169}.
\]
So the order is $\boxed{13^{121}<7^{169}<5^{343}}$.
