In a $3\times3$ grid of nine square cells, in how many ways can Jacob shade a nonzero number of cells so that each row, each column and each diagonal contains at most one shaded cell? (A diagonal is any set of cells whose centres lie on a line making a $45^\circ$ angle with the sides of the grid, so there are more than two diagonals.)
