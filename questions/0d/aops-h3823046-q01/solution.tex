Each polynomial is continuous on its own side. Continuity at the join requires their values there to agree:
\[
6c+2=7c^2-5c+2
\quad\Longleftrightarrow\quad c(7c-11)=0.
\]
The only real joining values are $\boxed{c=0,\dfrac{11}{7}}$. Neither is a nonzero integer, so every permitted integer choice gives a discontinuity.
