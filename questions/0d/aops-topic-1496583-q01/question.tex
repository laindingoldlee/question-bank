Using principal values (the principal logarithm, and the principal square root, which has argument in $\left(-\dfrac{\pi}{2},\dfrac{\pi}{2}\right]$), evaluate each of the following as a complex number:
\begin{enumerate}
\item[(a)] $i^i$;
\item[(b)] $\sqrt i$;
\item[(c)] $\sqrt{1+\sqrt i}$.
\end{enumerate}
