Write $a=6m$ and $b=6n$. If $2\mid m$ then $4\mid a$, and if $3\mid m$ then $9\mid a$; both are forbidden, so $m$ is coprime to $6$, and in particular $m$ is odd. Likewise $n$ is odd. Then
\[
\dfrac{a}{2}+\dfrac{b}{3}=3m+2n,
\]
which is odd $+$ even, hence always odd. So (A) and (C) are never true.

Primality is not decided:
\begin{itemize}
\item $a=b=6$ (so $m=n=1$) gives $3+2=5$, which is prime, so (B) is not always true;
\item $a=b=30$ (so $m=n=5$; $30=2\cdot3\cdot5$ is squarefree) gives $15+10=25$, which is composite, so (D) is not always true.
\end{itemize}
Hence none of (A)--(D) always holds, and the answer is $\boxed{\textbf{(E)}}$.
