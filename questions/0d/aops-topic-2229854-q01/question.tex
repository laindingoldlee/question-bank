Sam has $3$ loose basketballs and $6$ boxes with $2$ basketballs in each box.
\begin{enumerate}
\item[(a)] Write a single expression for the total number of basketballs and evaluate it.
\item[(b)] Explain, using the basketballs, why $3+6\times2$ equals $15$ and not $18$.
\end{enumerate}
