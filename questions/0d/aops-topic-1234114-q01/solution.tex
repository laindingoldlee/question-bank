$8192000000=2^{13}\cdot10^6$, so the cube root is $100\cdot2^{\dfrac{13}{3}}=1600\cdot\sqrt[3]2\approx1600\cdot1.25992=2015.87$. To be sure, compare with $2015.5$ and $2016.5$: $2016^3=8193540096$, which exceeds $8192000000$ by $1540096$, while $3\cdot2016^2\cdot0.5\approx6.1\times10^6$ is much larger, so the cube root is between $2015.5$ and $2016$. It rounds to $\boxed{2016}$.
