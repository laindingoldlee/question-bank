With $m$ missing types, a random package supplies a new type with probability $\dfrac{m}{N}$. Random purchases until the next new type cost an expected $\dfrac{cN}{m}$, while a chosen type costs 4; both lead to the same state with $m-1$ missing. The first-step equation is $V_m=\min\{4+V_{m-1},c+\dfrac{m}{N} V_{m-1}+(1-\dfrac{m}{N})V_m\}$, giving optimal marginal cost $\min(4,\dfrac{cN}{m})$. Buy randomly when this is cheaper, directly when it is dearer, and either way at equality. (a) The costs for $m=4,3,2,1$ are $2,\dfrac{8}{3},4,4$, totaling $\boxed{\dfrac{38}{3}}$ dollars. (b) They are $3,4,4,4$, totaling $\boxed{15}$. (c) All four marginal costs are 4, totaling $\boxed{16}$; random purchases tie only with four missing.
