There are $N$ equally likely figurine types in independent random packages. A random package costs $c$ dollars, and a chosen type costs 4 dollars. Packages may be opened immediately; duplicates have no value. Minimize expected additional spending: (a) $N=4,c=2$, none owned; (b) $N=4,c=3$, none owned; (c) $N=8,c=2$, four types already owned.
