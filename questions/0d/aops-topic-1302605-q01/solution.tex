Only the primes $2$ and $3$ can appear: $x=2^a3^c$, $y=2^b3^d$. We need $2a+3b=12$ and $2c+3d=12$ with nonnegative integers. For $2a+3b=12$, $b$ must be even: $(a,b)=(6,0),(3,2),(0,4)$, so $3$ choices; likewise $3$ for $(c,d)$. There are $3\cdot3=\boxed{9}$ pairs.
