Let $ C,I $ be the counts. Then $ C\le2I $ and $ C+I=342 $, so $ C\le228 $. Attain equality by making rows 2,5,8,11,14,17 irrigation rows and all other rows crop rows. Each irrigation cell serves the cells immediately above and below it. This uses 114 irrigation cells and $\boxed{228}$ crop cells.
\begin{asy}
usepackage("amsmath");
size(7cm);
for(int r=0;r<18;++r)if(r%3==1)fill((0,r)--(19,r)--(19,r+1)--(0,r+1)--cycle,lightblue);for(int k=0;k<=19;++k)draw((k,0)--(k,18));for(int k=0;k<=18;++k)draw((0,k)--(19,k));label("blue: irrigation",(9.5,-1));
\end{asy}
