Let the number be $10a+b$ with digits $a,b$ ($a\ge1$; also $b\ge1$, since the reversal is larger). Then
\[10b+a=\dfrac65(10a+b)\iff50b+5a=60a+6b\iff44b=55a\iff4b=5a.\]
Since $a,b\le9$, the only solution is $a=4$, $b=5$. The number is $\boxed{45}$ (and $54=1.2\cdot45$).
