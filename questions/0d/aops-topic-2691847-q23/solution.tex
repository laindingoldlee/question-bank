The determinants are $-4$, $7$, $6$, $-5$ and $3$, so the system is
\[-4x+3y+7z=25,\qquad2x-y+6z=17,\qquad-8x-5y+3z=-5.\]
Solving (for example by elimination) gives $x=\dfrac12$, $y=2$, $z=3$, which satisfy all three equations. Then
\[\begin{vmatrix}x&y\\z&1\end{vmatrix}=x-yz=\dfrac12-6=\boxed{-\dfrac{11}{2}}.\]
