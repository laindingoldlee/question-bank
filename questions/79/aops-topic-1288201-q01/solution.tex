\textbf{Symmetry.} For any $j\ne1$, swapping the labels $2$ and $j$ (conjugating $f$ by the transposition $(2\ j)$, which fixes $1$) is a bijection between functions with $f^{101}(1)=2$ and those with $f^{101}(1)=j$. So these $100$ counts are equal and
\[
N=\dfrac{101^{101}-M}{100},
\]
where $M$ counts functions with $f^{101}(1)=1$.

\textbf{Counting $M$.} $f^{101}(1)=1$ means $1$ lies on a cycle of $f$ whose length divides $101$, so the length is $1$ or $101$. Length $1$: $f(1)=1$ and the other $100$ values are free, $101^{100}$ functions. Length $101$: $f$ is a single $101$-cycle, $100!$ functions. So $M=101^{100}+100!$.

\textbf{Modulo $103$.} Here $101\equiv-2$, $100\equiv-3$, and $2^{102}\equiv1$ by Fermat's little theorem, so $2^{100}\equiv2^{-2}$ and $2^{101}\equiv2^{-1}$. By Wilson's theorem $-1\equiv102!=100!\cdot101\cdot102\equiv100!\cdot(-2)(-1)$, so $100!\equiv-2^{-1}$. Therefore
\[
101^{101}-101^{100}-100!\equiv-2^{-1}-2^{-2}+2^{-1}=-4^{-1},
\]
and
\[
N\equiv\dfrac{-4^{-1}}{-3}=12^{-1}\pmod{103}.
\]
Since $12\cdot43=516=5\cdot103+1$, the remainder is $\boxed{43}$.
