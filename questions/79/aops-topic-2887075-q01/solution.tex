If $m=\prod p_i^{a_i}$, distributing each exponent $a_in$ among $x,y,z$ gives $S=\displaystyle\prod_i\dbinom{a_in+2}2=\prod_i\dfrac{(a_in+1)(a_in+2)}2$.

\emph{$n$ odd:} $2$ is invertible mod $n$, and each factor is $\equiv\dfrac{1\cdot2}2=1\pmod n$. So $S\equiv1$ and $n\nmid S$.

\emph{$n$ even:} each factor equals $(a_in+1)\left(\dfrac{a_in}2+1\right)\equiv\dfrac{a_in}2+1\pmod n$, which is $1$ if $a_i$ is even and $\dfrac n2+1$ if $a_i$ is odd. Every product of such factors is $\equiv1$ or $\dfrac n2+1\pmod n$: if $4\mid n$, then $\left(\dfrac n2+1\right)^2\equiv1$; if $n\equiv2\pmod4$, then $\left(\dfrac n2+1\right)^2\equiv\dfrac n2+1$. Neither is $0$ unless $\dfrac n2+1=n$, i.e. $n=2$.

For $n=2$, $S=\prod(a_i+1)(2a_i+1)$ is even iff some $a_i$ is odd. So $S$ is divisible by $n$ iff $\boxed{n=2\text{ and }m\text{ is not a perfect square}}$.
