\textbf{Bounding $x$.} Since $\dfrac{1}{x}<\dfrac{7}{8}$, $x\ge2$; since $\dfrac{1}{x}$ is the largest of the three fractions, $\dfrac{3}{x}\ge\dfrac{7}{8}$, so $x\le3$.

\textbf{$x=2$.} Then $\dfrac{1}{y}+\dfrac{1}{z}=\dfrac{3}{8}$. As before $\dfrac{1}{y}<\dfrac{3}{8}$ gives $y\ge3$, and $\dfrac{2}{y}\ge\dfrac{3}{8}$ gives $y\le5$.
\begin{itemize}
\item $y=3$: $\dfrac{1}{z}=\dfrac{3}{8}-\dfrac{1}{3}=\dfrac{1}{24}$, so $z=24$.
\item $y=4$: $\dfrac{1}{z}=\dfrac{3}{8}-\dfrac{1}{4}=\dfrac{1}{8}$, so $z=8$.
\item $y=5$: $\dfrac{1}{z}=\dfrac{3}{8}-\dfrac{1}{5}=\dfrac{7}{40}$, not of the form $\dfrac{1}{z}$.
\end{itemize}

\textbf{$x=3$.} Then $\dfrac{1}{y}+\dfrac{1}{z}=\dfrac{7}{8}-\dfrac{1}{3}=\dfrac{13}{24}$ with $y\ge3$; $\dfrac{2}{y}\ge\dfrac{13}{24}$ forces $y\le3$, so $y=3$ and $\dfrac{1}{z}=\dfrac{13}{24}-\dfrac{1}{3}=\dfrac{5}{24}$, which is impossible.

So the solutions are $\boxed{(x,y,z)=(2,3,24)\text{ and }(2,4,8)}$.
