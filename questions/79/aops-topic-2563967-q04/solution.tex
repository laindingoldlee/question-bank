If $n=p_1^{e_1}\cdots p_k^{e_k}$, the number of factors is $(e_1+1)\cdots(e_k+1)$. This equals $3$ only if $k=1$ and $e_1=2$, so $n=p^2$ for a prime $p$ (and then the factors are $1,p,p^2$). With $p^2\le100$ we get $p=2,3,5,7$, i.e. $4,9,25,49$: $\boxed{4}$ integers.
