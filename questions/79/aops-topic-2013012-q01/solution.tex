The order of the list does not matter: every set of five digits appears in the same number ($5!$) of orders, so we may count sets.

The five largest digits sum to $5+6+7+8+9=35$, so a set with sum $31$ is obtained from $\{5,6,7,8,9\}$ by lowering the digits by a total of $4$ while keeping them distinct. Listing systematically by the largest digits:
\[
\{1,6,7,8,9\},\ \{2,5,7,8,9\},\ \{3,4,7,8,9\},\ \{3,5,6,8,9\},\ \{4,5,6,7,9\}.
\]
(If $9$ is absent, the maximum sum is $4+5+6+7+8=30<31$, so $9$ is always present; then the other four digits sum to $22$ from $\{0,\dots,8\}$, and if $8$ is absent their maximum is $4+5+6+7=22$, giving only $\{4,5,6,7\}$; with $8$ present the other three sum to $14$ from $\{0,\dots,7\}$, giving $\{1,6,7\}$, $\{2,5,7\}$, $\{3,4,7\}$, $\{3,5,6\}$.)

The primes among the digits are $2,3,5,7$. The sets contain respectively $1$, $3$, $2$, $2$, $2$ primes. So $3$ of the $5$ equally likely sets contain exactly two primes, and the probability is
\[
\boxed{\dfrac{3}{5}}.
\]
