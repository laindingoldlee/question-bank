Every dead creature had an even kill count. If a knight alone survived, all 99 princesses would have been killed by dragons, yet all dragons would be dead with even kill counts, making the number of princess deaths even: impossible. If a princess survived, all 101 dragons would have been killed by dead knights with even kill counts, also impossible. A dragon can survive: first let 50 knights each kill 2 dragons, removing 100 dragons; next let 50 princesses each kill 2 knights, removing all 100 knights; finally let the remaining dragon kill all 99 princesses. All victims have killed either 0 or 2 others and are eligible. Thus only $\boxed{\text{a dragon}}$ is possible.
