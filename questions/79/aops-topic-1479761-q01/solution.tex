Use the common denominator $4$:
\[
\dfrac{-2x+3}{4}+\dfrac{2(x+3)}{4}=\dfrac{-2x+3+2x+6}{4}=\boxed{\dfrac{9}{4}} .
\]
The $x$ terms cancel, so the expression has the value $\dfrac{9}{4}$ for every $x$ (there is nothing to ``solve'' for).
