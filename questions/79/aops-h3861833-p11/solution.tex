The units column adds to $13$. Since $b\ge9$, its carry is either $0$ or $1$. A zero carry would require $b>13$, and then the next column would also add to $13<b$, so the result would have only two digits. Therefore the carry is $1$.

The units column gives $T=13-b$. The next column totals $8+5+1=14$, and the leading digit is $1$, so $S=14-b$. Thus
\[
7=S+T=27-2b,
\]
giving $b=10$, $S=4$ and $T=3$. These digits are valid and $85+58=143$, so the requested sum is $\boxed{17}$.
