The exponent $2k-5$ is odd. The units digit of $2^m$ for odd $m$ is $2$ if $m\equiv1\pmod4$ and $8$ if $m\equiv3\pmod4$; as $k$ increases by $1$, $2k-5$ increases by $2$, so these alternate, starting with $2^5$ (units digit $2$) at $k=5$. The terms $1+3\cdot2^{2k-5}$ therefore have units digits $1+6=7$ and $1+24\to5$ alternately. There are $2018-5+1=2014$ terms, i.e.\ $1007$ pairs, each contributing $7+5=12$. The units digit of the sum is that of $1007\cdot12=12084$, namely $\boxed{4}$.
