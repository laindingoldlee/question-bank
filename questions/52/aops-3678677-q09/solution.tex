Use a finite occupancy recurrence. Number the 12 cells row by row and mark the missing bottom-left cell occupied initially. For occupied set $S$, let $F(S)$ count completions. If all cells are occupied, set $F=1$. Otherwise take the first unoccupied cell $v$; sum $F(S\cup\{v\})$ for a monomino and $F(S\cup\{v,w\})$ for each unoccupied right or lower neighbour $w$. These cases are disjoint and exhaustive because every tiling has exactly one tile covering $v$. Evaluating from the initial set gives $\boxed{331}$.
