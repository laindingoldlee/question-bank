Note that $i\,\overline u=i(a-bi)=ai-bi^2=b+ai=v$. So $\boxed{v=i\,\overline u}$. (Systematically: $a=\dfrac{u+\overline u}{2}$ and $b=\dfrac{u-\overline u}{2i}$, so $v=b+ia=\dfrac{u-\overline u}{2i}+\dfrac{i\left(u+\overline u\right)}{2}=-\dfrac i2\left(u-\overline u\right)+\dfrac i2\left(u+\overline u\right)=i\,\overline u$.)
