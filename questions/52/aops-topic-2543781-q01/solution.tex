For $a=1$, $N=1+4=5$, which is prime.

If $a\ge2$ is even, then $a^4+4^a$ is even and greater than $2$, so it is not prime.

If $a\ge3$ is odd, write $a=2k+1$ with $k\ge1$ and $b=2^k$, so $4^a=4\cdot4^{2k}=4b^4$. By the Sophie Germain identity,
\[a^4+4b^4=\left(a^2+2b^2\right)^2-(2ab)^2=\left(a^2+2ab+2b^2\right)\left(a^2-2ab+2b^2\right).\]
The smaller factor is $(a-b)^2+b^2\ge b^2=4^k\ge4$, so both factors exceed $1$ and $N$ is composite.

Hence the only prime of this form is $N=\boxed{5}$. $\blacksquare$
