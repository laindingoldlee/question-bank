An answer sheet is an ordered list of $15$ different integers from $0$ to $999$. The number of such lists is
\[
1000\cdot999\cdot998\cdots986=\dfrac{1000!}{985!}.
\]
After that many attempts you have handed in every possible sheet, including the correct one. With fewer attempts some possible sheet has not been tried, and the correct answers could be exactly that sheet, so success is not guaranteed. Hence the number of attempts needed is
\[
\boxed{\dfrac{1000!}{985!}=1000\cdot999\cdots986}\approx9\cdot10^{44}.
\]
