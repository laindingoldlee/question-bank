Let $g(x)=\dfrac{\sqrt{2x-2}-\sqrt{\dfrac{1-x}{2}}}{x-1}$. Show that $g(x)$ is undefined (as a real number) for every real $x\ne1$. What does this say about the question ``find $n$ so that $f(x)=g(x)$ for $x\ne1$, $f(1)=n$, is continuous''?
