Let $\alpha=\arctan\dfrac {x}{2}$ and $\beta=\arctan\dfrac{2x}{3}$, both in $\left(-\dfrac{\pi}{2},\dfrac{\pi}{2}\right)$. If $\alpha+\beta=\dfrac{\pi}{4}$, then $\tan(\alpha+\beta)=1$, and the addition formula gives
\[
\dfrac{\dfrac {x}{2}+\dfrac{2x}{3}}{1-\dfrac {x}{2}\cdot\dfrac{2x}{3}}=1\iff\dfrac{7x}{6}=1-\dfrac{x^2}{3}\iff2x^2+7x-6=0,
\]
so $x=\dfrac{-7\pm\sqrt{49+48}}{4}=\dfrac{-7\pm\sqrt{97}}{4}$.

This step only uses $\tan(\alpha+\beta)=1$, which also holds when $\alpha+\beta=-\dfrac{3\pi}{4}$, so each root must be checked.
\begin{itemize}
\item $x_1=\dfrac{\sqrt{97}-7}{4}\approx0.712$ is positive, so $\alpha,\beta\in\left(0,\dfrac{\pi}{2}\right)$; moreover $\dfrac {x}{2}\cdot\dfrac{2x}{3}=\dfrac{x^2}{3}<1$, so $\alpha+\beta<\dfrac{\pi}{2}$ and hence $\alpha+\beta=\dfrac{\pi}{4}$. It is a solution.
\item $x_2=\dfrac{-7-\sqrt{97}}{4}\approx-4.21$ is negative, so $\alpha+\beta<0$; it satisfies $\alpha+\beta=-\dfrac{3\pi}{4}$ and is rejected.
\end{itemize}
The graph of the increasing function $y=\arctan\dfrac {x}{2}+\arctan\dfrac{2x}{3}$ (vertical scale enlarged) crosses the level $\dfrac{\pi}{4}$ once, at $x_1$, and the level $-\dfrac{3\pi}{4}$ at $x_2$.

Answer: $x=\boxed{\dfrac{\sqrt{97}-7}{4}}$.
