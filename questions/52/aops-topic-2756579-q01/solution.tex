For $n=2$: if $a^{u}=x_1$ and $a^{v}=x_2$, then $a^{u+v}=x_1x_2$, so $\log_ax_1+\log_ax_2=\log_a(x_1x_2)$. Induction on $n$ using this finishes the proof. $\blacksquare$
