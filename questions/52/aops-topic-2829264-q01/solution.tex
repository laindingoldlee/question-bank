\textbf{Existence.} The numbers $a,a+m,a+2m,\dots,a+(n-1)m$ leave different remainders modulo $n$: if $a+im\equiv a+jm$ then $n\mid(i-j)m$, so $n\mid i-j$ (as $\gcd(m,n)=1$), forcing $i=j$. These $n$ numbers therefore hit every residue modulo $n$, including $b$. That number $x$ satisfies both congruences.

\textbf{Uniqueness.} If $x$ and $x'$ both work, then $m\mid x-x'$ and $n\mid x-x'$, so $mn=\operatorname{lcm}(m,n)$ divides $x-x'$. $\blacksquare$
