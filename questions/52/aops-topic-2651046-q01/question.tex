Allan has $5$ tickets. There are two slot machines, and each game on either machine costs $1$ ticket. One machine always pays out a win; the other wins with probability $\dfrac12$ on each play, independently. Allan does not know which machine is which, and after each game he only learns whether he won or lost. If he plays optimally, his expected number of wins is $\dfrac mn$ with $m,n$ relatively prime positive integers. Find $m+n$.
