Let $f(x)=x^2+\cos x$. Then $f(-x)=f(x)$, so if $r$ is a root, so is $-r$; and $0$ is not a root since $f(0)=1$.

There is exactly one positive root: for $x>0$, $f'(x)=2x-\sin x>0$ (because $\sin x\le x<2x$ for $0<x\le1$ and $\sin x\le1<2x$ for $x>1$), so $f$ is strictly increasing on $[0,\infty)$; moreover $f(0)=1<2019$ and $f(50)>2500-1>2019$. Call this root $r$.

So the real roots are exactly $r$ and $-r$, and their sum is $\boxed{0}$.
