Let each food be eaten by $n$ people. Each pairwise intersection has size $\dfrac{n}{3}$, and the triple intersection has size $3$. Inclusion--exclusion gives $67=3n-3(\dfrac{n}{3})+3=2n+3$. Thus $\boxed{n=32}$. However, $\dfrac{n}{3}=\dfrac{32}{3}$ is not an integer, so no actual group of people can satisfy all the data. The formal calculation exposes an inconsistency: $\boxed{\text{no such configuration exists}}$.
