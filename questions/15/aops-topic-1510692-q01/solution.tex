Multiply by $a\ne0$:
\[
3ax+2a=2x-2b\quad\Longleftrightarrow\quad(3a-2)x=-2(a+b).
\]
\begin{itemize}
\item If $a\ne\dfrac{2}{3}$, there is exactly one solution, $\boxed{x=-\dfrac{2(a+b)}{3a-2}=\dfrac{2(a+b)}{2-3a}}$.
\item If $a=\dfrac{2}{3}$, the equation reads $0\cdot x=-2\left(\dfrac{2}{3}+b\right)$. It has infinitely many solutions (every $x$) when $b=-\dfrac{2}{3}$, and no solution when $b\ne-\dfrac{2}{3}$.
\end{itemize}
Check: with $a=1$, $b=1$ the formula gives $x=-4$, and indeed $3(-4)+2=-10=\dfrac{2(-4-1)}{1}$.
