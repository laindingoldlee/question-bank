Expanding, $(qx-c)^2=q^2x^2-2qcx+c^2$. Comparing coefficients:
\[
q^2=19,\qquad -2qc=16,\qquad c^2=y .
\]
So $q=\pm\sqrt{19}$, $c=-\dfrac{8}{q}$ and $y=c^2=\dfrac{64}{19}$.
\begin{itemize}
\item If $q=\sqrt{19}$, then $c=-\dfrac{8\sqrt{19}}{19}$ and $q+c+y=\dfrac{19\sqrt{19}-8\sqrt{19}+64}{19}=\dfrac{64+11\sqrt{19}}{19}$.
\item If $q=-\sqrt{19}$, then $c=\dfrac{8\sqrt{19}}{19}$ and $q+c+y=\dfrac{64-11\sqrt{19}}{19}$.
\end{itemize}
So $q+c+y=\boxed{\dfrac{64\pm11\sqrt{19}}{19}}$ (both values occur).
