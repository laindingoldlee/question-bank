Parity of the second equation forces exactly one of $p_1,p_2,p_3$ to be $2$. If $p_1=2$, then $7p_2+9p_3=140$. Reducing modulo $7$ forces $p_3=7$, hence $p_2=11$, but the first equation would give $7p_4=90$, impossible. If $p_2=2$, then $11p_1+9p_3=148$. Modulo $11$, $p_3\equiv3$; also $p_3<17$, so primality gives $p_3=3$, then $p_1=11$ and $p_4=17$. If $p_3=2$, then $11p_1+7p_2=144$, so $p_1\equiv1\pmod7$ and $p_1<13$, leaving only $1,8$, neither prime. Thus the product is $11\cdot2\cdot3\cdot17=\boxed{1122}$.
