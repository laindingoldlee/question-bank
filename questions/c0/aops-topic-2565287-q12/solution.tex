By induction, after $k$ moves the robot is at $(1+k,\,3-k)$. This holds for $k=0$; and if the robot is at $(1+k,3-k)$, then its $x$-coordinate $1+k$ is positive, so the next point is $(2+k,\,2-k)$. The $x$-coordinates $1,2,3,\dots$ are all different, so the points are all different, and the robot visits $\boxed{\text{infinitely many}}$ points. $\blacksquare$
