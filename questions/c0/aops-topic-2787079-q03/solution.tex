Use induction on the number of digits. For a single digit there is equality. Write a longer number as $10q+d$, where $q\ge1$ and $0\le d\le9$. If $P$ denotes digit product, the induction hypothesis gives $P(10q+d)=P(q)d\le qd\le9q<10q+d$. This proves the claim.
