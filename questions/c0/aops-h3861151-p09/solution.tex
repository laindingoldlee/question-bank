Both permitted operations are increasing functions of the current value. Therefore a smaller current value can never worsen the smallest achievable future value, and choosing the smaller next value is optimal. Doubling is smaller than adding $300$ for values below $300$. The first nine doublings give $512$ after nine minutes (the eighth value is $256$). Thereafter adding $300$ is smaller. Six additions give $512+1800=\boxed{2312}$.
