Let $N$ be a positive integer with decimal digits $d_m\ldots d_2d_1d_0$, so that $N=d_0+10d_1+100d_2+\cdots+10^md_m$. Prove the following divisibility rules.
\begin{enumerate}
\item[(a)] $N$ is divisible by $2$ (by $5$, by $10$) if and only if its last digit $d_0$ is.
\item[(b)] $N$ is divisible by $4$ if and only if the number formed by its last two digits is; $N$ is divisible by $8$ if and only if the number formed by its last three digits is.
\item[(c)] $N$ is divisible by $3$ (by $9$) if and only if its digit sum $d_0+d_1+\cdots+d_m$ is.
\item[(d)] $N$ is divisible by $6$ if and only if it is divisible by both $2$ and $3$.
\item[(e)] $N$ is divisible by $11$ if and only if the alternating sum $d_0-d_1+d_2-\cdots+(-1)^md_m$ is.
\end{enumerate}
