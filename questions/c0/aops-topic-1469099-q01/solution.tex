Write the sum as $\dfrac{9a^2+14b^2}{9ab}$; it is an integer $m$ when $9a^2+14b^2=9abm$.
\begin{itemize}
\item $b$ divides $9a^2+14b^2-14b^2=9a^2$, and $\gcd(a,b)=1$, so $b\mid9$.
\item $a$ divides $9a^2+14b^2-9a^2=14b^2$, so $a\mid14$.
\item $9$ divides $9a^2+14b^2$, so $9\mid14b^2$, so $3\mid b$. Hence $b=3$ or $b=9$.
\end{itemize}
If $b=9$: $9a\cdot9=81a$ would have to divide $9a^2+14\cdot81$, so $9\mid a^2$, impossible since $a\mid14$. So $b=3$ and $a\in\{1,2,7,14\}$ (all coprime to $3$). Check: the sum is $\dfrac{9a^2+126}{27a}=\dfrac{a^2+14}{3a}$, which equals $5$, $3$, $3$, $5$ for $a=1,2,7,14$. So there are $\boxed{4}$ pairs.
