Index the target by $(i,j)$, with both coordinates uniform on $0,\ldots,7$. Its shortest distance is $i+j$, so the expectation is $\dfrac{0+1+\cdots+7}{8}+\dfrac{0+1+\cdots+7}{8}=\boxed7$.
