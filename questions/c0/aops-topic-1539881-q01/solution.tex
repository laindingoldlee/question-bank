\textbf{Two parallelograms.} The quadrilateral $EPGB$ has $EP\parallel BG$ and $PG\parallel EB$, so it is a parallelogram and $EP=BG$. Likewise $PHCF$ has $PH\parallel FC$ and $PF\parallel HC$, so $PH=FC$. Hence $x=EH=EP+PH=BG+FC$. On side $BC$ the points lie in the order $B,G,F,C$, so
\[
GF=BC-BG-FC=a-x .
\]

\textbf{Similar triangles.} Since $DF\parallel AC$, triangle $DBF$ is similar to triangle $ABC$, so $\dfrac{BF}{a}=\dfrac{DF}{b}=\dfrac {x}{b}$. Since $GI\parallel AB$, triangle $IGC$ is similar to triangle $ABC$, so $\dfrac{GC}{a}=\dfrac{GI}{c}=\dfrac {x}{c}$. The segments $BF$ and $GC$ overlap exactly in $GF$, so
\[
\dfrac{ax}{b}+\dfrac{ax}{c}=BF+GC=BC+GF=a+(a-x)=2a-x .
\]
Dividing by $a$:
\[
\dfrac {x}{a}+\dfrac {x}{b}+\dfrac {x}{c}=2,\qquad\text{so}\qquad x=\dfrac{2}{\dfrac{1}{a}+\dfrac{1}{b}+\dfrac{1}{c}}.
\]

\textbf{Computation.} $\dfrac{1}{450}+\dfrac{1}{510}+\dfrac{1}{425}$: with the common denominator $7650=2\cdot3^2\cdot5^2\cdot17$ this is $\dfrac{17+15+18}{7650}=\dfrac{50}{7650}=\dfrac{1}{153}$. Hence $x=2\cdot153=\boxed{306}$.
