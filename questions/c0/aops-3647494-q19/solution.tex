Fix one of the $6!$ possible performance orders. It is valid exactly when no singer requests a singer appearing later. There are $5+4+3+2+1=15$ such forbidden requests. Under independent uniformly random subsets, each request is absent with probability one half. Thus a fixed order is valid with probability $2^{-15}$. By linearity of expectation, the expected number is $\dfrac{6!}{2^{15}}=\boxed{\dfrac{45}{2048}}$.
