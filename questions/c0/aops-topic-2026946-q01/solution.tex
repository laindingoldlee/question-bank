Each digit appears once in each place, so
\[
ABC_7+BCA_7+CAB_7=(A+B+C)(49+7+1)=57(A+B+C).
\]
Also $1221_7=343+2\cdot49+2\cdot7+1=456=57\cdot8$. Hence $A+B+C=8$.

The number of ordered triples of positive integers with sum $8$ is $\binom72=21$ by stars and bars, and every entry is then at most $6$, so all are valid base-$7$ digits. Different triples give different numbers $ABC_7$, so there are
\[\boxed{21}\]
possible values.
