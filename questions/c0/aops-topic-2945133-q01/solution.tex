The system has a unique solution iff $AE\ne BD$. Count the $6^4=1296$ outcomes with $AE=BD$: for each product value $v$, if $r(v)$ ordered pairs from $\{1,\dots,6\}^2$ have product $v$, there are $r(v)^2$ outcomes. The nonzero counts are ($v=1{:}1,\ 2{:}2,\ 3{:}2,\ 4{:}3,\ 5{:}2,\ 6{:}4,\ 8{:}2,\ 9{:}1,\ 10{:}2,\ 12{:}4,\ 15{:}2,\ 16{:}1,\ 18{:}2,\ 20{:}2,\ 24{:}2,\ 25{:}1,\ 30{:}2,\ 36{:}1$), so $\sum r(v)^2=1+4+4+9+4+16+4+1+4+16+4+1+4+4+4+1+4+1=86$. Hence the probability is
\[1-\dfrac{86}{1296}=\dfrac{1210}{1296}=\boxed{\dfrac{605}{648}}.\]
(For coefficients drawn from a continuous distribution the probability would be $1$; ``$\dfrac{\infty}{3\cdot\infty}$'' is meaningless.)
