Count by position.
\begin{itemize}
\item Units digit $3$: $3,13,23,\dots,93$, which is $10$ numbers.
\item Tens digit $3$: $30,31,\dots,39$, which is $10$ numbers.
\end{itemize}
The number $33$ is in both lists, and $100$ contains no $3$. By inclusion-exclusion the count is $10+10-1=\boxed{19}$.
