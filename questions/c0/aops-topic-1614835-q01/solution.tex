\textbf{Signs.} However the parentheses are placed, the result is $\pm1\pm2\pm\dots\pm8$ for some choice of signs. The first number is always added: it is never to the right of a minus sign. The second number always gets a minus sign: whatever bracket starts with $2$, that bracket is subtracted, and inside it $2$ comes first. So the value is
\[
1-2+(\pm3\pm4\pm5\pm6\pm7\pm8).
\]

\textbf{Parity.} Changing a sign changes the sum by an even number, and $1-2-3-\dots-8=-34$ is even, so every value is even. The smallest positive value is therefore at least $2$.

\textbf{Achieving $2$.} We need $\pm3\pm4\dots\pm8=3$. The numbers $3,\dots,8$ add up to $33$, so the numbers with a plus sign must add up to $\dfrac{33+3}{2}=18$, for instance $3+7+8$. This is the sign pattern $+1-2+3-4-5-6+7+8$, and it is produced by
\[
1-\big(2-3\big)-4-5-\big(6-7-8\big)=1+1-4-5+9=2 .
\]
So the smallest positive value is $\boxed{2}$.

(In fact every sign pattern with $+1$ and $-2$ can be produced, but we only need the one above.)
