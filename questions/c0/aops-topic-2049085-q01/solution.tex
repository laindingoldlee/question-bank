\textbf{Case $x_0>1$.} Then every $x_k>1$. For $t>1$,
\[t-1=\left(\sqrt[3]t-1\right)\left(\sqrt[3]{t^2}+\sqrt[3]t+1\right)\ge3\left(\sqrt[3]t-1\right),\]
because each of the three terms in the second factor exceeds $1$. Hence $x_{k+1}-1\le\dfrac{x_k-1}{3}$, and by induction
\[0<x_k-1\le\dfrac{x_0-1}{3^k}.\]
Since $3^k$ grows without bound, $x_k-1$ becomes smaller than any given positive number.

\textbf{Case $0<x_0<1$.} Apply the first case to $y_k=\dfrac{1}{x_k}$, which satisfies $y_{k+1}=\sqrt[3]{y_k}$ and $y_0>1$. So $y_k\to1$, and hence $x_k=\dfrac{1}{y_k}\to1$.

\textbf{Case $x_0=1$.} Every $x_k=1$.

So in all cases $x_k\to1$. The same argument works for repeated square roots, with $t-1=(\sqrt t-1)(\sqrt t+1)\ge2(\sqrt t-1)$. A calculator eventually shows exactly $1$ because it keeps only finitely many digits. $\blacksquare$
