The equally likely label strings number $\dfrac{9!}{(3!)^3}=1680$. A good string has one of each label in each block, so there are $(3!)^3=216$ good strings. The required complementary probability is $1-\dfrac{216}{1680}=\boxed{\dfrac{61}{70}}$.
