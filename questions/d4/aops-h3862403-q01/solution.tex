Factor the expression as $(1+20^n)(1+101^n)$. A candidate prime is lucky exactly when one of the two bases has a power congruent to $-1$. Modulo $7$, $20\equiv-1$, so $n=1$ works. Modulo $11$, $101\equiv2$ and $2^5\equiv-1$, so $n=5$ works. Modulo $13$, $20\equiv7$ and $7^6\equiv-1$, so $n=6$ works. Modulo $17$, $101\equiv-1$, so $n=1$ works. Modulo $19$, $20\equiv1$ and $101\equiv6$, while $6^9\equiv1$. Every power of $6$ has odd order dividing nine, so none equals the element $-1$ of order two. Hence exactly $\boxed4$ candidates are lucky.
