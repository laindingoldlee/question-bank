Put $a=0$: $f(b)=11f(b)-506$, so $f(b)=50.6$ for every $b$, contradicting $f(357)=7842$. (Even without that value, a constant $f$ fails for $a\ne0$, since then $f(a+b)=a^2+50.6\ne50.6$.) So $\boxed{\text{no such function exists}}$.

Plugging in $a=338$, $b=357$ formally gives $f(695)=338^2+11\cdot7842-506=114244+86262-506=200000$, but this value is meaningless because the hypotheses are contradictory.
