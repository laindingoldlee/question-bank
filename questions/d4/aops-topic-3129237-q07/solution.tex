If a zero occurs, choose that single digit. Otherwise every digit factors using only the primes $2,3,5,7$. Record the parity of the exponents of these four primes in each prefix product, including the empty prefix. There are $17$ prefixes but only $2^4=16$ parity vectors. Two prefixes therefore have the same vector. Dividing the longer prefix product by the shorter leaves a nonempty consecutive block in which all four prime exponents are even. Its product is a perfect square.
