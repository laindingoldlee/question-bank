Completing squares gives $(2p-2)^2+(2q-3)^2+(2r-5)^2=38$. Therefore $p\in\{2,3\}$, $q\in\{2,3\}$, and $r\in\{2,3,5\}$. The first two squares have possible sums $5,13,17,25$. The last square is $1$ for $r=2,3$ and $25$ for $r=5$. To total $38$, only $13+25$ works, requiring $p=2,q=3,r=5$. These values satisfy the original equation, so $\boxed{(p,q,r)=(2,3,5)}$.
