Let $f(x)=|x-8|+|x+12|-|x-10|$ and split at $-12,8,10$.
\begin{itemize}
\item $x\le-12$: $f(x)=(8-x)+(-x-12)-(10-x)=-x-14$, so $f(x)\le50$ iff $x\ge-64$.
\item $-12\le x\le8$: $f(x)=(8-x)+(x+12)-(10-x)=x+10\le18$, always fine.
\item $8\le x\le10$: $f(x)=3x-6\le24$, always fine.
\item $x\ge10$: $f(x)=x+14$, so $f(x)\le50$ iff $x\le36$.
\end{itemize}
The solutions are the integers $\boxed{-64\le x\le36}$, which is $101$ integers.
