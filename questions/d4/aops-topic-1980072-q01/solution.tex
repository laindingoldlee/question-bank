Represent a solution by a row of \(10\) stars and \(3\) bars: the stars before the first bar count \(a\), those between the first and second bars count \(b\), and so on. For example \(\ast|\ast\ast\ast|\ast\ast|\ast\ast\ast\ast\) is \((1,3,2,4)\). This is a bijection between solutions and arrangements of \(10\) stars and \(3\) bars in \(13\) positions, so the number of solutions is
\[
\binom{13}{3}=\boxed{286}.
\]
