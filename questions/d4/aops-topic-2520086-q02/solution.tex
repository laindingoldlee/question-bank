The $k$-th marked number ($k=0,1,2,\dots$) is the number in position $1+15k$, reduced modulo $1000$ (with positions $1,\dots,1000$). The numbers for $k$ and $j<k$ coincide exactly when $1000\mid15(k-j)$. Since $1000=2^3\cdot5^3$ and $15=3\cdot5$, this means $2^3\cdot5^2=200\mid3(k-j)$, i.e. $200\mid k-j$.

So the marks for $k=0,1,\dots,199$ are all different, and the next mark ($k=200$) is $1$ again, which is already marked. Exactly $200$ numbers are marked, and $1000-200=\boxed{800}$ remain unmarked.
