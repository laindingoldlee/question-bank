Each die has $20^3$ equally likely ordered triples. For D1 the scaled sum is 30, with $\binom{29}2-3\binom92=298$ triples after excluding values above 20. For D2 the underlying sum is 15, with $\binom{14}2=91$ triples. For D3 it is ten, with $\binom92=36$. Equal prior die probabilities cancel, so the posterior is $\dfrac{298}{(298+91+36)}=\boxed{\dfrac{298}{425}}$.
