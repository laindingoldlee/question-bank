Let $x=0.4999\ldots$. Then $10x=4.999\ldots$ and $100x=49.999\ldots$, so $90x=45$ and $x=\dfrac{1}{2}$ exactly: $0.4999\ldots$ and $0.5$ are the same number written in two ways. So it rounds exactly as $0.5$ does, which depends on the rounding convention: to $\boxed{1}$ under the usual ``round half up'' rule (and to $0$ under ``round half to even''). The comparison with angles approaching $180^\circ$ does not apply: an infinite decimal is a single number (a limit), not a process that never arrives.
