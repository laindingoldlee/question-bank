Since $P(2010)=0$, $P(x)=(x-2010)R(x)$; dividing by the monic polynomial $x-2010$ keeps integer coefficients, so $R$ has integer coefficients. Since $P(2017)=0$ and $2017-2010\ne0$, $R(2017)=0$, so in the same way $R(x)=(x-2017)Q(x)$ with $Q$ having integer coefficients. Hence
\[
P(2013)=(2013-2010)(2013-2017)Q(2013)=-12\,Q(2013),
\]
and $Q(2013)$ is an integer. So $P(2013)$ is a multiple of $12$. The only multiple of $12$ with absolute value less than $11$ is $0$, so $P(2013)=\boxed{0}$. (This happens, for example, for $P(x)=(x-2010)(x-2013)(x-2017)$.)
