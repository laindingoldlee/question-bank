Induct on its size. A one-element set has that element as both extremes. If a set of $k$ elements has minimum $m$ and maximum $M$, adding an element $x$ changes them to $\min(m,x)$ and $\max(M,x)$. These bound every old element and the new one and belong to the enlarged set. Induction proves the assertion.
