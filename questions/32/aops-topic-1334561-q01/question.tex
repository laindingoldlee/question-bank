Corey has lost the answer key to a $10$-question true/false test. He knows that
\begin{itemize}
\item there are as many true answers as false answers;
\item the first and last answers are the same;
\item somewhere there are at least $3$ false answers in a row;
\item the answers to questions $5$ and $9$ are false, and the answer to question $8$ is true;
\item there are more true answers than false answers among the first $5$ questions.
\end{itemize}
How many answer keys meet all the criteria?
