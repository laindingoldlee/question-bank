The first entry starts one run. Every later entry starts a new run exactly when it differs from its predecessor. Thus by linearity of expectation the answer is $1+\sum_{k=1}^{98}\Pr(a_k\ne a_{k+1})$. Independence gives each summand $\dfrac{k(99-k)+(100-k)(k+1)}{10000}=\dfrac{100+198k-2k^2}{10000}$. Using $\sum_{1}^{98}k=4851$ and $\sum_{1}^{98}k^2=318549$ gives $\boxed{\dfrac{858}{25}}$.
