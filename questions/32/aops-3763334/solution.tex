All three primes are odd, because each divides an odd integer. Cyclically rename them so that $p$ is a smallest one. Since $r\ge p$ divides $2p+1$, a proper quotient would be an odd integer at least $3$, giving $r \le \dfrac{2p+1}{3} < p$. Thus $r=2p+1$. Now $q\mid4p+3$ and $q\ge p$, so the odd quotient $\dfrac{4p+3}{q}$ is $1,3$ or $5$. If it is $1$, $q=4p+3$ and $p\mid2q+1=8p+7$, forcing $p=7$; but then $r=15$ is not prime. If it is $3$, divisibility forces $p=3$, then $q=5$, contradicting $3\mid11$. If it is $5$, the bound $5p\le4p+3$ forces $p=3$, then $q=3$, contradicting $3\mid7$. Every case fails.
