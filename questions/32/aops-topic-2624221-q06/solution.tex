One square mile is $1.609344^2\approx2.589988$ square kilometers, because both dimensions are converted. So
\[34\text{ km}^2=\dfrac{34}{1.609344^2}\text{ mi}^2\approx\boxed{13.13\text{ square miles}}.\]
(Dividing by $1.609344$ only once, giving $21.13$, is the common error.)
