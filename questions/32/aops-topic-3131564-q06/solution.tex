Choosing colors for the seven distinct letters determines every cell. Test all $4^7$ assignments against the ten cyclic adjacency constraints:\begin{verbatim}
from itertools import product
word='EXETERMATH'; letters=sorted(set(word)); ans=0
for colors in product(range(4),repeat=len(letters)):
 d=dict(zip(letters,colors))
 ans+=all(d[word[i]]!=d[word[(i+1)%len(word)]] for i in range(len(word)))
print(ans) # 1440
\end{verbatim}
The exhaustive test counts each valid assignment once, so the answer is $\boxed{1440}$.
