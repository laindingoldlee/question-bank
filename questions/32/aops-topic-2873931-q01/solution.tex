Suppose $r(x_1)=r(x_2)$. Cross-multiplying, $(ax_1+b)(cx_2+d)=(ax_2+b)(cx_1+d)$, which simplifies to $adx_1+bcx_2=adx_2+bcx_1$, i.e.
\[(ad-bc)(x_1-x_2)=0.\]
If $ad-bc\ne0$ this forces $x_1=x_2$, so $r$ is one-to-one.

If $ad-bc=0$, then $a(cx+d)=acx+ad=acx+bc=c(ax+b)$, so $r(x)=\dfrac ac$ for every $x$ in the domain. A constant function on an infinite set is not one-to-one; for example $\dfrac{2x+2}{x+1}=2$ for all $x\ne-1$. $\blacksquare$
