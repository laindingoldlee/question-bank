We count solutions of $d_1+d_2+d_3+d_4=15$ with $1\le d_i\le6$. Put $e_i=d_i-1$, so $e_1+e_2+e_3+e_4=11$ with $0\le e_i\le5$. Without the upper bound there are $\dbinom{14}3=364$ solutions (stars and bars). If $e_1\ge6$, set $e_1'=e_1-6$: there are $\dbinom{8}3=56$ solutions, and the same for each of the $4$ variables. Two variables cannot both be at least $6$, since $12>11$. By inclusion--exclusion,
\[364-4\cdot56=\boxed{140}.\]
