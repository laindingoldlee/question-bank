Subtracting the second equation from the first,
\[xz-5x-yz+5y=0\iff(x-y)(z-5)=0.\]
So $x=y$ or $z=5$.

\textbf{Case $x=y$.} Then $2x^2=50$, so $x=y=5$ or $x=y=-5$.
\begin{itemize}
\item $x=y=5$: $5(z)=7$, so $z=\dfrac75$.
\item $x=y=-5$: $-5(z-10)=7$, so $z=10-\dfrac75=\dfrac{43}{5}$.
\end{itemize}

\textbf{Case $z=5$.} Then both equations say $xy=7$, and $x^2+y^2=50$. So $(x+y)^2=50+14=64$ and $(x-y)^2=50-14=36$, i.e. $x+y=\pm8$ and $x-y=\pm6$. This gives $(x,y)=(7,1),(1,7),(-7,-1),(-1,-7)$.

The solutions are
\[\boxed{\left(5,5,\dfrac75\right),\ \left(-5,-5,\dfrac{43}5\right),\ (7,1,5),\ (1,7,5),\ (-7,-1,5),\ (-1,-7,5)}.\]
(Each one checks; for example $5\left(5+\dfrac75-5\right)=7$ and $-5\left(-5+\dfrac{43}5-5\right)=7$.)
