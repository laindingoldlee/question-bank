Write $a+b=m^2$ and $a-b=n^2$ with positive integers $m>n$ ($m>n$ because $b>0$). Then
\[
a=\dfrac{m^2+n^2}{2},\qquad b=\dfrac{m^2-n^2}{2},
\]
so $m$ and $n$ must have the same parity. If $n=1$, then $m$ is odd and $m\ge3$, so $a\ge\dfrac{9+1}{2}=5$. If $n\ge2$, then $m\ge n+2\ge4$, so $a\ge\dfrac{16+4}{2}=10$. So $a\ge5$ always, and $(m,n)=(3,1)$ gives $a=5$.

Hence the smallest Benson rectangular number is $\boxed{5}$, with $b=4$: $5+4=9=3^2$ and $5-4=1=1^2$. (Directly: $a=1$ has no $b$ with $a-b>0$; for $a=2,3,4$ the pairs $(a+b,a-b)$ are $(3,1)$; $(4,2),(5,1)$; $(5,3),(6,2),(7,1)$, and none consists of two squares.)
