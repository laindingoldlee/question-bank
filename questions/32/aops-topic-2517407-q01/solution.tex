\textbf{(a)} Solve $x=\dfrac{2y-1}{y+3}$ for $y$: $xy+3x=2y-1$, so $y(x-2)=-1-3x$ and, for $x\ne2$,
\[y=\dfrac{-1-3x}{x-2}=\dfrac{3x+1}{2-x}.\]
For $x=2$ the equation reads $2y+6=2y-1$, which has no solution; so $2$ is not a value of $g$. Indeed $g(x)=2-\dfrac{7}{x+3}\ne2$. Hence
\[g^{-1}(x)=\dfrac{3x+1}{2-x},\qquad x\ne2.\]
Check: $g\left(\dfrac{3x+1}{2-x}\right)=\dfrac{2\cdot\dfrac{3x+1}{2-x}-1}{\dfrac{3x+1}{2-x}+3}=\dfrac{6x+2-2+x}{3x+1+6-3x}=\dfrac{7x}{7}=x.$

\textbf{(b)} Yes. Every step is reversible for $x\ne2$, and
\[\dfrac{-1-3x}{x-2}=\dfrac{(-1)(3x+1)}{(-1)(2-x)}=\dfrac{3x+1}{2-x},\]
so the student's formula is the same function as in (a), written differently. The marking must have expected a particular form (or the domain $x\ne2$).

$\boxed{g^{-1}(x)=\dfrac{3x+1}{2-x}\ (x\ne2);\ \text{the student's answer is correct}}$
