$f$ is a polynomial, so its domain is $\boxed{\mathbb R}$. As $x$ runs over $\mathbb R$, $g(x)$ takes every real value, so $g(x)^2$ takes every value in $[0,\infty)$ and $f$ takes every value in $\boxed{[-39,\infty)}$ (the minimum $-39$ occurs at $x=\dfrac{2\pi}{15}$).
