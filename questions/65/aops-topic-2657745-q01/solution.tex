The numbers $p$, $p+2$, $p+4$ leave remainders $p$, $p+2$, $p+1$ modulo $3$, which are all different, so one of them is divisible by $3$. Being prime, that number equals $3$. Since $p+2=3$ and $p+4=3$ give $p\le1$, we need $p=3$, and $(3,5,7)$ is indeed a triple of primes. So there is exactly $\boxed{1}$ triple.
