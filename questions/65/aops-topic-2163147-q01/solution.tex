For an integer $x$:
\begin{itemize}
\item $x\ge a$ if and only if $x\ge\lceil a\rceil$, because $\lceil a\rceil$ is the least integer that is at least $a$;
\item $x\le b$ if and only if $x\le\lfloor b\rfloor$, because $\lfloor b\rfloor$ is the greatest integer that is at most $b$.
\end{itemize}
So the integers in $[a,b]$ are exactly the integers $x$ with $\lceil a\rceil\le x\le\lfloor b\rfloor$. For integers $m\le M$ there are $M-m+1$ integers from $m$ to $M$; if $M=m-1$ there are none, which the formula $M-m+1=0$ also gives. Here $\lfloor b\rfloor\ge\lceil a\rceil-1$ (because $\lfloor b\rfloor>b-1\ge a-1$ and $\lceil a\rceil<a+1$, so $\lfloor b\rfloor>\lceil a\rceil-2$), so the number of integers is
\[\lfloor b\rfloor-\lceil a\rceil+1,\]
a finite number. For example, $[0.2,\,0.7]$ contains $0-1+1=0$ integers and $[-2.5,\,3]$ contains $3-(-2)+1=6$. $\blacksquare$
