The first move has two choices, clockwise or counterclockwise. Thereafter the island behind has sunk, so each next move is forced in the chosen direction. After visiting all twenty islands the frog is trapped, giving exactly one maximal path for each initial direction. Thus there are $\boxed2$ paths.
