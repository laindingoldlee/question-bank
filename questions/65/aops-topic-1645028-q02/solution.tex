We need $4^{200}\bmod100$. Since $100=4\cdot25$ with $\gcd(4,25)=1$, work modulo $4$ and $25$.
\begin{itemize}
\item Modulo $4$: $4^{200}\equiv0$.
\item Modulo $25$: $4^5=1024\equiv-1$, so $4^{10}\equiv1$ and $4^{200}=\left(4^{10}\right)^{20}\equiv1\pmod{25}$.
\end{itemize}
The numbers below $100$ that are $\equiv1\pmod{25}$ are $1,26,51,76$, and the only multiple of $4$ among them is $76$. So the last two digits are $\boxed{76}$.
