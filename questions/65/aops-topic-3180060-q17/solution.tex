The other base is $b+2$. The two user counts are $b+3$ and $2b+3$. If the second speaker uses base $b$, inclusion-exclusion gives $3b+4=(b+3)+(2b+3)-b+9$, hence $b=11$ and total 37. All displayed digits are valid in bases 11 and 13. If the second speaker uses base $b+2$, the equation becomes $3(b+2)+4=(b+3)+(2b+3)-(b+2)+9$, giving $b=3$. This is invalid, since the second speaker's base 5 cannot use digit 9 (and the first cannot use digit 3 in base 3). Thus only the first case works, and the answer is $\boxed{37}$.
