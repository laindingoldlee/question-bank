\textbf{(a)} By the difference of squares,
\[(10a+1)^2-(10a)^2=\bigl((10a+1)-10a\bigr)\bigl((10a+1)+10a\bigr)=20a+1=10\cdot(2a)+1 .\]
Writing the digit $1$ after the number $2a$ produces exactly $10\cdot(2a)+1$, so the shortcut is correct for every positive integer $a$. $\blacksquare$

\textbf{(b)} Examples only show that the rule works in the cases tried; a general claim needs an argument covering every $a$, as in (a). (A rule can agree with many examples and still fail, for instance the false claim that $n^2+n+41$ is always prime holds for $n=0,1,\ldots,39$.)

The same computation gives
\[(10a+6)^2-(10a+5)^2=(10a+6)+(10a+5)=20a+11=10\cdot(2a+1)+1:\]
\textbf{double $a$, add $1$, and append the digit $1$}. For example $46^2-45^2=91$ ($2\cdot4+1=9$, then append $1$).
