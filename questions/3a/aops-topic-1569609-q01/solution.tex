Let the digits be $a$, $b$, $c$ with $a\ne0$, and suppose $a+b+c=abc$.

\textbf{No zero digit.} If some digit is $0$, the product is $0$ but the sum is at least $a\ge1$. So all three digits are at least $1$.

\textbf{Bounding.} Order the digits as $x\le y\le z$. Then
\[
xyz=x+y+z\le3z\qquad\Longrightarrow\qquad xy\le3 ,
\]
so $(x,y)$ is $(1,1)$, $(1,2)$ or $(1,3)$.
\begin{itemize}
\item $(1,1)$: $z=2+z$, impossible.
\item $(1,2)$: $2z=3+z$, so $z=3$.
\item $(1,3)$: $3z=4+z$, so $z=2<y$, contradicting $y\le z$.
\end{itemize}
So the digits are $1,2,3$ in some order ($1+2+3=6=1\cdot2\cdot3$), and the three-digit summyprods are
\[
\boxed{123,\ 132,\ 213,\ 231,\ 312,\ 321}.
\]
