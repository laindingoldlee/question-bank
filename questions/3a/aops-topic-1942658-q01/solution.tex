(a) $\dbinom73=\dfrac{7\cdot6\cdot5}{3\cdot2\cdot1}=35$ and $\dbinom{10}8=\dbinom{10}{2}=\dfrac{10\cdot9}{2}=45$. So the answers are $\boxed{35\text{ and }45}$.

(b) From the formula, $\dbinom n{n-k}=\dfrac{n!}{(n-k)!\,(n-(n-k))!}=\dfrac{n!}{(n-k)!\,k!}=\dbinom nk$. By counting: choosing which $k$ elements to take is the same as choosing which $n-k$ elements to leave out, so the $k$-subsets and the $(n-k)$-subsets correspond one to one (each subset to its complement). (In \LaTeX\ the symbol is written \verb|\binom{a}{b}|.)
