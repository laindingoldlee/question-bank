Using denominator $1400$, the four numerators are $1260,672,720,735$. Their integer HCF is 3, so the required HCF is $\boxed{\dfrac{3}{1400}}$. Indeed each numerator is divisible by 3, and an integer linear combination of the four numerators equals 3 by the Euclidean algorithm. If $h$ divides all four fractions in the stated sense, the same linear combination shows that $\dfrac{3}{1400h}$ is a positive integer; hence $h\le\dfrac{3}{1400}$.
