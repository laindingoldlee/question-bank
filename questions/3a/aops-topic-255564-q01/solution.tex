Let $t=\sqrt[3]2$, so $t^3=2$, and let $R$ be the right side. Then
\[R=\dfrac{1-t+t^2}{\sqrt[3]9}.\]
Since $(1+t)\left(1-t+t^2\right)=1+t^3=3$, we have $1-t+t^2=\dfrac3{1+t}$, so
\[R^3=\dfrac{27}{9(1+t)^3}=\dfrac{3}{(1+t)^3}.\]
Also $(1+t)^3=1+3t+3t^2+t^3=3\left(1+t+t^2\right)$, hence
\[R^3=\dfrac1{1+t+t^2}=\dfrac{t-1}{(t-1)\left(1+t+t^2\right)}=\dfrac{t-1}{t^3-1}=t-1.\]
$R$ is a real number whose cube is $t-1=\sqrt[3]2-1$, and a real number has only one real cube root, so $R=\sqrt[3]{\sqrt[3]2-1}$. $\blacksquare$
