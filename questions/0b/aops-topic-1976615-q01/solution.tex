A regular $n$-gon coincides with itself after a rotation about its centre exactly when the angle is a multiple of $\dfrac{360^\circ}{n}$, the angle between neighbouring vertices as seen from the centre.

\begin{asy}
usepackage("amsmath");
size(4.5cm);
defaultpen(fontsize(10pt));
int n=6;
pair[] V; for(int i=0;i<n;++i) V.push(dir(90+360*i/n));
for(int i=0;i<n;++i) draw(V[i]--V[(i+1)%n],linewidth(1));
dot((0,0));draw((0,0)--V[0],dashed);draw((0,0)--V[n-1],dashed);
draw(arc((0,0),0.22,90-360/n,90),Arrow(TeXHead));
label("$\dfrac{360^\circ}{n}$",0.52*dir(90-180/n));
label("\mbox{}",(min(currentpicture,user=true)+max(currentpicture,user=true))/2,black); // keeps the text after the figure black when LaTeX typesets the labels inline
\end{asy}

So we need $2019=k\cdot\dfrac{360}{n}$ for an integer $k$, i.e.\ $360$ divides $2019n$. Since $2019=3\cdot673$ and $360=2^3\cdot3^2\cdot5$, we have $\gcd(2019,360)=3$, so this is equivalent to $\dfrac{360}{3}=120$ dividing $n$. The least number of sides is $\boxed{120}$.
