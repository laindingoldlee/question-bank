For a two-digit candidate, the condition is $n^3\equiv n\pmod{100}$. In particular $25\mid n(n-1)(n+1)$. Only one of these three consecutive integers can be divisible by five, so that factor must be divisible by $25$. Hence $n\equiv0,1,-1\pmod{25}$. No integer from $11$ through $23$ has one of these residues. The next candidate is $24$, and $24^3=13824$ indeed ends in $24$. Thus the minimum is $\boxed{24}$.
