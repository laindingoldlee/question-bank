Work modulo $19$ and let $x_n=2^{2^n}$, $y_n=3^{2^n}$, $z_n=5^{2^n}$, so that $x_{n+1}=x_n^2$, $y_{n+1}=y_n^2$, $z_{n+1}=z_n^2$.

For $n=1$: $(x_1,y_1,z_1)=(4,9,25)\equiv(4,9,6)$. Squaring, $4^2=16$, $9^2=81\equiv5$, $6^2=36\equiv17$, so $(x_2,y_2,z_2)\equiv(16,5,17)$. Squaring again, $16^2=256\equiv9$, $5^2=25\equiv6$, $17^2=289\equiv4$, so $(x_3,y_3,z_3)\equiv(9,6,4)$.

So squaring maps the set $\{4,6,9\}$ to $\{16,17,5\}$, and maps $\{5,16,17\}$ back to $\{6,9,4\}$. By induction, for every $n\ge1$ the three residues form the set $\{4,6,9\}$ ($n$ odd) or $\{5,16,17\}$ ($n$ even). The sums are $4+6+9=19$ and $5+16+17=38$, both divisible by $19$. Hence $\boxed{19\mid2^{2^n}+3^{2^n}+5^{2^n}}$ for all $n\ge1$.
