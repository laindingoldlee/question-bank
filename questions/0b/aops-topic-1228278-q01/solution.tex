Let $t=b^2+b\ge0$. Then $b^4+2b^3+3b^2+2b=(b^2+b)^2+2(b^2+b)=t^2+2t$. For $t\ge1$,
\[t^2+t<t^2+2t<(t+1)^2+(t+1)=t^2+3t+2,\]
and $n\mapsto n^2+n$ is increasing for $n\ge0$, so $t^2+2t=a^2+a$ would need $t<a<t+1$, impossible. Hence $t=0$, so $b=0$, and then $a^2+a=0$ gives $a=0$. The only solution is $\boxed{(a,b)=(0,0)}$; in particular there are no solutions in positive integers.
