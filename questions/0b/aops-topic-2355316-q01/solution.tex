Row $5$ has $10-4=6$ free squares, and the rest of the board has $86-6=80$ free squares. There are $\dbinom{86}{5}=34826302$ equally likely choices. Count by the number of fruits in row $5$:
\begin{itemize}
\item exactly $3$: $\dbinom63\dbinom{80}{2}=20\cdot3160=63200$;
\item exactly $4$: $\dbinom64\dbinom{80}{1}=15\cdot80=1200$;
\item exactly $5$: $\dbinom65=6$.
\end{itemize}
The total is $64406$, so the probability is
\[\dfrac{64406}{34826302}=\boxed{\dfrac{32203}{17413151}}\approx0.00185.\]
