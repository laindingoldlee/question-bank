A path from $(0,0,0)$ to $(2,2,2)$ is a sequence of $6$ steps, two in each direction: $\dfrac{6!}{2!\,2!\,2!}=90$ paths. A path from $(2,2,2)$ to $(3,3,3)$ is an ordering of one step in each direction: $3!=6$ paths. So there are
\[90\cdot6=\boxed{540}\]
paths through $(2,2,2)$.
