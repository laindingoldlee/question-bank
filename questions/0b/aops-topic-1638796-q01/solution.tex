We need $n^2=18a+20b$ with positive integers $a,b$. The right side is even, so $n$ is even; write $n=2m$. Then
\[
2m^2=9a+10b,\qquad a,b\ge1,
\]
so $2m^2\ge19$ and $m\ge4$. Reducing modulo $10$, $9a\equiv-a\equiv2m^2\pmod{10}$, which fixes $a$ modulo $10$:
\begin{itemize}
\item $m=4$: $2m^2=32$, so $a\equiv8\pmod{10}$; but $a=8$ gives $9a=72>32$.
\item $m=5$: $2m^2=50$, so $a\equiv0\pmod{10}$; but $a=10$ gives $90>50$.
\item $m=6$: $2m^2=72$, so $a\equiv8\pmod{10}$; $a=8$ gives $b=0$, not positive, and $a=18$ is too big.
\item $m=7$: $2m^2=98$, so $a\equiv2\pmod{10}$; $a=2$ gives $10b=80$, $b=8$.
\end{itemize}
So $n=2\cdot7=\boxed{14}$: indeed $14^2=196=18\cdot2+20\cdot8$.
