(a) The sum is $\boxed{32}$. (b) For every nonnegative integer $n$, $\sum_{k=0}^n\binom nk=\boxed{2^n}$. (c) Algebraically, put $x=y=1$ in the binomial theorem $(x+y)^n=\sum_{k=0}^n\binom nkx^{n-k}y^k$. Combinatorially, a set of $n$ elements has $2^n$ subsets, because every element is either included or excluded. Partitioning those subsets by size $k$ gives $\binom nk$ subsets in each class, proving the same identity.
