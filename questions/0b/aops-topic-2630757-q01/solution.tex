By definition, $\ln y$ (for $y>0$) is the unique real number $t$ with $e^t=y$; that is, $\ln$ is the inverse function of $t\mapsto e^t$. The number $t=\pi$ satisfies $e^t=e^{\pi}$, and it is the only such number because $t\mapsto e^t$ is strictly increasing, hence one-to-one. Therefore $\ln\left(e^{\pi}\right)=\pi$. (The same argument gives $\ln\left(e^x\right)=x$ for every real $x$.) $\blacksquare$
