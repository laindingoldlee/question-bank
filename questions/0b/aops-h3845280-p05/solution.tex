A run of heads and a run of tails must each have length at least two. If there are two runs, their lengths are $(2,3)$ or $(3,2)$, and either symbol can start, giving $4$ sequences. With three runs, the middle run and one of the end runs must have length two; the other end run has length one. There are $2$ choices of doubled end and $2$ starting symbols, giving $4$ more. Four runs would need at least six flips to contain both kinds of doubled run. Hence the count is $\boxed8$.
