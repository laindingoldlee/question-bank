Across the width, the centre block has $\dfrac{91-1}{2}=45$ blocks on each side; along the length it has $\dfrac{125-1}{2}=62$ blocks on each side. After $k$ spreads, the fire covers the square of blocks within $k$ steps of the centre in each direction, so it reaches the border first in the width direction, when $k=45$. This happens after $45\cdot3=\boxed{135}$ seconds.
