For $a=0$ we have $a^n=0$ for every positive integer $n$, so $\dfrac{a^n}{a^n}$ would be $\dfrac00$, which is undefined: we cannot divide by $0$. The quotient rule itself is only valid for $a\ne0$, for the same reason. So the argument gives no value for $0^0$; the expression $0^0$ is either left undefined or given the value $1$ by convention, not by this argument.
