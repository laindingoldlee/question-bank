Coprimality to $30$ depends only on the remainder modulo $30$, and $\varphi(30)=30\cdot\dfrac12\cdot\dfrac23\cdot\dfrac45=8$ residues work in each block of $30$. The integers $1,\dots,299$ lie in the $10$ blocks $1$--$30$, $\dots$, $271$--$300$, and removing $300$ (not coprime) changes nothing. So there are $10\cdot8=\boxed{80}$.
