The first nine terms write the digits $1,2,\ldots,9$ into the units, tens, $\ldots$, $10^8$ places, so
\[1+2\cdot10+\cdots+9\cdot10^8=987\,654\,321 .\]
The last term is $10\cdot10^9=10^{10}=10\,000\,000\,000$. Adding,
\[N=10\,000\,000\,000+987\,654\,321=10\,987\,654\,321,\]
which has $\boxed{11}$ digits. (Since $10^{10}\le N<10^{11}$.)
