Let $u=y^3-7y^2-38y+237$. The equation is $u^3+9u^2+27u+27=(u+3)^3=0$, so $u=-3$, i.e.
\[y^3-7y^2-38y+240=0.\]
$y=5$ is a root ($125-175-190+240=0$), and dividing gives $(y-5)\left(y^2-2y-48\right)=(y-5)(y-8)(y+6)$. So $\boxed{y\in\{-6,\ 5,\ 8\}}$.
