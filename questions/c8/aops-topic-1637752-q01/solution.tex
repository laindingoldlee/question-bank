Each class is determined by its teacher, so a split amounts to giving every teacher a set of $10$ students, with every student in exactly one set.

List the teachers in a fixed order $T_1,T_2,\dots,T_{150}$. Choose the students of $T_1$ in $\dbinom{1500}{10}$ ways, then those of $T_2$ in $\dbinom{1490}{10}$ ways, and so on. The number of splits is
\[
\dbinom{1500}{10}\dbinom{1490}{10}\cdots\dbinom{10}{10}=\dfrac{1500!}{1490!\,10!}\cdot\dfrac{1490!}{1480!\,10!}\cdots\dfrac{10!}{0!\,10!}=\boxed{\dfrac{1500!}{(10!)^{150}}} .
\]
(The same count arises by first splitting the students into $150$ unlabelled groups of $10$, in $\dfrac{1500!}{(10!)^{150}\,150!}$ ways, and then matching the groups with the teachers in $150!$ ways.)
