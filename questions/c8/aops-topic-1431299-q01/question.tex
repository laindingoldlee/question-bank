A function $f$, defined for all positive real numbers, satisfies
\[
f(a)+f(b)=f(ab)\quad\text{for all }a,b>0,
\]
and $f(2)=3$. Find $f(1)$, $f(8)$, $f\left(\dfrac{1}{2}\right)$ and $f\left(\sqrt2\right)$.
