Use the equation with well-chosen values.
\begin{itemize}
\item $a=b=1$: $f(1)+f(1)=f(1)$, so $f(1)=\boxed{0}$.
\item $a=b=2$: $f(4)=2f(2)=6$; then $a=4$, $b=2$: $f(8)=f(4)+f(2)=\boxed{9}$.
\item $a=2$, $b=\dfrac{1}{2}$: $f(2)+f\left(\dfrac{1}{2}\right)=f(1)=0$, so $f\left(\dfrac{1}{2}\right)=\boxed{-3}$.
\item $a=b=\sqrt2$: $2f\left(\sqrt2\right)=f(2)=3$, so $f\left(\sqrt2\right)=\boxed{\dfrac{3}{2}}$.
\end{itemize}
In general $f\left(2^r\right)=3r$ for every rational $r$; one function with these properties is $f(x)=3\log_2x$.
