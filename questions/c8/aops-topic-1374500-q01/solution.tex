Note that $\lfloor x\rfloor$ is \emph{not} the same as $x$ unless $x$ is an integer: for example $\lfloor2.5\rfloor=2$, so $f(2.5)=2.5^2=6.25$.

On each interval where $\lfloor x\rfloor=n$ is constant, $f(x)=x^n$ is continuous and increasing (for $n\ge1$):
\begin{itemize}
\item $0<x<1$: $f(x)=x^0=1$.
\item $1\le x<2$: $f(x)=x$ takes all values in $[1,2)$; integer $1$.
\item $2\le x<3$: $f(x)=x^2$ takes all values in $[4,9)$; integers $4,5,6,7,8$.
\item $x\ge3$: $f(x)=x^n\ge3^3=27>10$.
\end{itemize}
So the integers from $1$ to $10$ in the range are $1,4,5,6,7,8$, and the answer is $\boxed{6}$. ($2,3,9,10$ are missed: $9$ would need $x=3$, but $f(3)=27$.)
