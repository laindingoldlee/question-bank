A positive integer $N$ has $d$ digits exactly when $10^{d-1}\le N<10^d$, so $d=\lfloor\log_{10}N\rfloor+1$. Hence
\[
d=\left\lfloor4444\log_{10}4444\right\rfloor+1.
\]
For example, the bounds $3.6477740<\log_{10}4444<3.6477741$ give
\[
16210.7076560<4444\log_{10}4444<16210.7081004.
\]
Thus the number of digits is $\boxed{16211}$.
