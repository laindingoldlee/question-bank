Factor: $x(x-5)=0$, so $\boxed{x=0\text{ or }x=5}$. Division by x is permitted only when $x\ne 0$; it correctly finds the nonzero solution 5 but discards the case $x=0$ before checking it. To divide safely, first treat $x=0$ separately.
