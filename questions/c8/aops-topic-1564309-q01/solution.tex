From $x\equiv3\pmod9$, write $x=9k+3$. Then $9k+3\equiv k+3\equiv2\pmod 8$, so $k\equiv-1\equiv7\pmod8$, i.e.\ $k=8j+7$ and
\[
x=9(8j+7)+3=72j+66 .
\]
So $x\equiv66\pmod{72}$ (by the Chinese remainder theorem this is the only residue class, as $\gcd(8,9)=1$). The values are $66,138,210,\dots$, and the only one between $100$ and $200$ is $\boxed{138}$. Check: $138=17\cdot8+2=15\cdot9+3$.
