Let $g=\gcd(5a+3,7a+8)$. Then $g$ divides
\[7(5a+3)-5(7a+8)=21-40=-19,\]
so $g$ is $1$ or $19$. The value $19$ occurs: we need $5a+3\equiv0\pmod{19}$, that is, $5a\equiv16\pmod{19}$; since $4\cdot5=20\equiv1$, $a\equiv4\cdot16=64\equiv7\pmod{19}$. For $a=7$: $5a+3=38=2\cdot19$ and $7a+8=57=3\cdot19$, with $\gcd(38,57)=19$. The greatest possible value is $\boxed{19}$.
