Colour the top-left $5\times5$ block arbitrarily: $2^{25}$ ways. Then the last square of each of the first five rows is forced (to make the row even), and so is the bottom square of each of the first five columns. Finally the bottom-right corner is forced by the last row; it also makes the last column even, because the total number of red squares in the first five rows is even (each row is even), so the parity condition for the last column agrees with that for the last row. Conversely every good colouring arises this way, so there are exactly $2^{25}$ good colourings out of $2^{36}$. The probability is
\[
\dfrac{2^{25}}{2^{36}}=\dfrac{1}{2^{11}}=\boxed{\dfrac{1}{2048}} .
\]
