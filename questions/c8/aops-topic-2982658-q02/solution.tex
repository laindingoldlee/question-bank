Let $q_n$ be the probability that minute $n$ uses the minute-$1$ pile. Then $q_1=1$ and $q_{n+1}=\dfrac{1-q_n}{9}$ (it can return only from a different pile, with probability $\dfrac19$). So $q_2=0$, $q_3=\dfrac19$, $q_4=\dfrac19\cdot\dfrac89=\dfrac{8}{81}$.

The answer is $\boxed{\dfrac8{81}}$.
