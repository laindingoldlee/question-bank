A dog is surrounded by $10$ piles of treats. Each minute it eats one treat from a pile chosen uniformly at random, except that it never picks the same pile as in the previous minute (it chooses uniformly among the other $9$). What is the probability that in minute $4$ it eats from the same pile as in minute $1$?
