$P(n)=0$ for the $100$ integers $n=1^2,2^2,\dots,100^2$.

For $n<1$ all $100$ factors are negative, so $P(n)>0$; for $n>100^2$ all are positive. If $k^2<n<(k+1)^2$ with $1\le k\le99$, the negative factors are $n-j^2$ for $j=k+1,\dots,100$, which is $100-k$ of them. So $P(n)<0$ exactly when $100-k$ is odd, i.e. $k$ is odd.

Strictly between $k^2$ and $(k+1)^2$ there are $2k$ integers. Summing over odd $k=1,3,\dots,99$:
\[2(1+3+5+\cdots+99)=2\cdot50^2=5000.\]
Together with the $100$ zeros, the count is $5000+100=\boxed{\textbf{(E) }5100}$.
