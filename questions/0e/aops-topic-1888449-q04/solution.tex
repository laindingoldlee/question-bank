Long division, bringing down one digit at a time after the first five digits:
\begin{itemize}
\item $21212=1\cdot12121+9091$;
\item $90912=7\cdot12121+6065$;
\item $60652=5\cdot12121+47$;
\item $471=0\cdot12121+471$;
\item $4712=0\cdot12121+4712$;
\item $47122=3\cdot12121+10759$;
\item $107591=8\cdot12121+10623$.
\end{itemize}
So the quotient is $\boxed{1750038}$ and the remainder is $\boxed{10623}$. Check: $12121\cdot1750038=21211750000+460598=21212210598$, and $21212210598+10623=21212221221$.
