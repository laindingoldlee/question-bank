Work modulo $13$. Since $182=14\cdot13$, the left side must be $\equiv0\pmod{13}$. The residues are
\[12\equiv-1,\qquad14\equiv1,\qquad37\equiv-2,\qquad65\equiv0\pmod{13}.\]
Consider which letter is $65$.
\begin{itemize}
\item $x=65$: the left side is $\equiv yt\not\equiv0$, since $y,t\in\{-1,1,-2\}$.
\item $y=65$: the left side is $\equiv-xz\not\equiv0$.
\item $t=65$: the left side is $\equiv x(y-z)$, which is nonzero because $x\not\equiv0$ and $y\not\equiv z$.
\item $z=65$: the left side is $\equiv xy+yt=y(x+t)$. As $y\not\equiv0$, we need $x+t\equiv0$, so $\{x,t\}=\{12,14\}$ and $y=37$.
\end{itemize}
This leaves two cases: $(x,y,z,t)=(12,37,65,14)$ gives $444-780+518=182$, while $(14,37,65,12)$ gives $518-910+444=52$. So
\[\boxed{x=12,\ y=37,\ z=65,\ t=14}.\]
