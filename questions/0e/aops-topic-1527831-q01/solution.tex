Both equations are unchanged by permuting $a,b,c$ or $x,y,z$, so we find the solutions with $a\ge b\ge c$ and $x\ge y\ge z$ and then allow all rearrangements within each triple.

\textbf{A key quantity.} For positive integers $p\ge q\ge r$ let $g(p,q,r)=pqr-(p+q+r)$. Adding the two equations gives
\[
g(a,b,c)+g(x,y,z)=0 .
\]
We list the triples with small $g$.
\begin{itemize}
\item If $r\ge2$, then $g\ge2$, with equality only for $(2,2,2)$: indeed $pqr-p-q-r\ge 4p-p-q-r\ge 4p-3p=p\ge2$ when $q,r\ge2$, and $g(2,2,2)=2$, $g(3,2,2)=5$, while larger triples give more.
\item If $r=1$ and $q=1$: $g=p-p-2=-2$.
\item If $r=1$ and $q\ge2$: $g=pq-p-q-1=(p-1)(q-1)-2\ge-1$.
\end{itemize}
So $g\ge-2$ always, and since the two values of $g$ add to $0$, both lie in $\{-2,-1,0,1,2\}$. The triples with these values are
\[
g=-2:\ (p,1,1);\quad g=-1:\ (2,2,1);\quad g=0:\ (3,2,1);\quad g=1:\ (4,2,1);\quad g=2:\ (5,2,1),(3,3,1),(2,2,2),
\]
using $(p-1)(q-1)=1,2,3,4$ for $g=-1,0,1,2$ with $r=1$.

\textbf{Cases} (by symmetry assume $g(a,b,c)\le g(x,y,z)$).
\begin{itemize}
\item $g=0$ and $0$: $(a,b,c)=(x,y,z)=(3,2,1)$; indeed $6=6$ both ways.
\item $g=-1$ and $1$: $(2,2,1)$ and $(4,2,1)$; but $abc=4\ne7=x+y+z$. No solution.
\item $g=-2$ and $2$: $(a,b,c)=(p,1,1)$, so $x+y+z=p$ and $xyz=p+2$, with $(x,y,z)$ one of $(5,2,1)$, $(3,3,1)$, $(2,2,2)$. These have sum and product $(8,10)$, $(7,9)$, $(6,8)$, and each satisfies product $=$ sum $+2$, giving $p=8,7,6$.
\end{itemize}

\textbf{Answer.} Up to the order within each triple, the solutions are
\[
\boxed{\{a,b,c\},\{x,y,z\}=\{1,2,3\},\{1,2,3\};\quad \{1,1,8\},\{1,2,5\};\quad \{1,1,7\},\{1,3,3\};\quad \{1,1,6\},\{2,2,2\},}
\]
together with the solutions obtained by swapping the roles of $(a,b,c)$ and $(x,y,z)$ in the last three.
