Let $r=\dfrac nm$. Since $40\le n\le80$ and $20\le m\le40$, we have $1\le r\le4$. The function $r+\dfrac1r$ is increasing for $r\ge1$, so the maximum is at $r=4$ ($n=80$, $m=20$): $4+\dfrac14=\boxed{\dfrac{17}4}$.
