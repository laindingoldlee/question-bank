\textbf{(a)} is correct: $y=1\cdot(3x+2)$, with constant $k=1$.

\textbf{(b)} is correct: $y-2=3x=1\cdot(3x)$, again with $k=1$ (and $y-2$ is also proportional to $x$, with $k=3$).

So the answer is $\boxed{\text{(c)}}$. Note that $y$ is \emph{not} directly proportional to $x$, since $y=2$ when $x=0$.
