If $y=3x+2$, which of the following is correct? (A quantity $u$ is directly proportional to $v$ if $u=kv$ for a nonzero constant $k$.)

(a) $y$ is directly proportional to $3x+2$.\qquad (b) $y-2$ is directly proportional to $3x$.\qquad (c) Both (a) and (b).
