The right side is $\dfrac{z}{4z}$, which is defined only for $z\ne0$, and then equals $\dfrac{1}{4}$. The left side needs $z\ne-4$. So we solve
\[
\dfrac{4-z}{4+z}=\dfrac{1}{4}\iff 4(4-z)=4+z\iff 16-4z=4+z\iff z=\dfrac{12}{5}.
\]
This value is allowed ($z\ne0,-4$). Check: $\dfrac{4-\dfrac{12}{5}}{4+\dfrac{12}{5}}=\dfrac{\dfrac{8}{5}}{\dfrac{32}{5}}=\dfrac{1}{4}$. So $z=\boxed{\dfrac{12}{5}}$.
