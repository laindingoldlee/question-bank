Return paths either use only one axis or use both. Using one axis requires two steps each way: $2\binom42=12$ paths. Using both requires one step in each of the four directions: $4!=24$ paths. Thus $36$ of the $4^4=256$ paths return, giving $\boxed{\dfrac{9}{64}}$.
