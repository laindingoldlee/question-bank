The polynomial factors as $(x-1)(x^2+x-9)$. One root is $1$, contributing $1^2+1+1=3$. Each other root $u$ satisfies $u^2+u=9$, so it contributes $10$. The product is $3\cdot10\cdot10=\boxed{300}$.
